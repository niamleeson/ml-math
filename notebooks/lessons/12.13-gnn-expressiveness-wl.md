# 12.13 — GNN Expressiveness & the Weisfeiler-Leman Test

Message-passing graph neural networks learn by repeatedly mixing each node with its neighbors, so their power is tied to what local aggregation can distinguish. In this lesson, you will build the 1-Weisfeiler-Leman (1-WL) color-refinement test, compare it to message passing, and see why GIN-style injective multiset aggregation is the clean design response to mean/sum collisions.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build GNN expressiveness one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math is spelled out so nothing is a black box. This walkthrough uses a `_w` suffix on its variables so it never clashes with the examples below.

### 1. 1-WL starts from node colors and neighbor multisets

The 1-WL test begins with a color for every node, then repeatedly replaces a node's color by a signature made from its old color plus the **multiset** of neighbor colors. A multiset is a bag, not a set: `[1,1,2]` is different from `[1,2]` because multiplicity carries degree/count information.

```python
import numpy as np  # arrays + linear algebra for graphs and features.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for any randomized examples.
```
▶ What you'll see: the only imports used in this notebook: NumPy and Matplotlib.

```python
A_w = np.array([[0, 1, 1, 1],
                [1, 0, 0, 0],
                [1, 0, 0, 0],
                [1, 0, 0, 0]], dtype=int)  # a 4-node star: node 0 is the center.
colors_w = np.ones(4, dtype=int)  # every node starts with the same color.
print("degrees:", A_w.sum(axis=1).astype(int))  # [3,1,1,1].
print("initial colors:", colors_w)  # no labels distinguish nodes yet.
assert A_w.sum(axis=1).tolist() == [3, 1, 1, 1]
```
▶ What you'll see: all nodes begin identical by color, but their neighbor counts already differ.

```python
def wl_step_w(A, colors):  # one deterministic 1-WL recoloring step.
    signatures = []  # store (old color, sorted neighbor colors) for each node.
    for v in range(A.shape[0]):
        neigh = np.where(A[v] == 1)[0]  # neighbor indices of node v.
        bag = tuple(sorted(colors[neigh].tolist()))  # sorted list represents the multiset.
        signatures.append((int(colors[v]), bag))  # old color + neighbor multiset.
    palette = {sig: i + 1 for i, sig in enumerate(sorted(set(signatures)))}  # canonical IDs.
    return np.array([palette[sig] for sig in signatures]), signatures  # new colors and raw signatures.

new_colors_w, signatures_w = wl_step_w(A_w, colors_w)  # refine the star once.
print("signatures:", signatures_w)  # center sees three 1s; leaves see one 1.
print("new colors:", new_colors_w)  # center separates from leaves.
assert len(set(new_colors_w)) == 2
```
▶ What you'll see: the center has signature `(1, (1,1,1))`, while each leaf has `(1, (1,))`.

```python
xy_w = np.array([[0, 0], [-1, -1], [0, -1.4], [1, -1]])  # hand-picked star layout.
plt.figure(figsize=(4, 3))
for i_w, j_w in zip(*np.where(np.triu(A_w) == 1)):
    plt.plot([xy_w[i_w, 0], xy_w[j_w, 0]], [xy_w[i_w, 1], xy_w[j_w, 1]], color="gray")
plt.scatter(xy_w[:, 0], xy_w[:, 1], c=new_colors_w, s=600, cmap="viridis", edgecolor="black")
for v_w, (x_w, y_w) in enumerate(xy_w):
    plt.text(x_w, y_w, str(v_w), ha="center", va="center", color="white")
plt.title("1: 1-WL separates star center and leaves"); plt.axis("off"); plt.show()
```
▶ What you'll see: the center and leaves have different colors after one WL refinement.

*Why it's done this way:* 1-WL uses sorted neighbor-color bags because graph node order is arbitrary. Sorting gives a canonical representation of the multiset; including the old color prevents forgetting the node's previous role. On a star, the center's bag has three entries and a leaf's bag has one, so the refinement exposes degree as a first-order structural signal.

### 2. Repeating refinement finds stable structural roles

A single WL step captures one-hop neighborhoods. Repeating the update expands the radius: after `k` rounds, a color summarizes the rooted `k`-hop tree that 1-WL can see. The process stops changing when every node keeps the same structural role pattern.

```python
A_path_w = np.array([[0, 1, 0, 0, 0],
                     [1, 0, 1, 0, 0],
                     [0, 1, 0, 1, 0],
                     [0, 0, 1, 0, 1],
                     [0, 0, 0, 1, 0]], dtype=int)  # a 5-node path.
colors_path_w = np.ones(5, dtype=int)  # all nodes initially identical.
history_w = [colors_path_w.copy()]  # record colors over rounds.
for round_w in range(3):
    colors_path_w, _ = wl_step_w(A_path_w, colors_path_w)  # one more radius.
    history_w.append(colors_path_w.copy())
print(np.array(history_w))
```
▶ What you'll see: endpoints match each other, near-endpoints match each other, and the middle becomes its own color.

```python
counts_w = [len(set(row_w)) for row_w in history_w]  # number of distinct roles per round.
print("number of colors by round:", counts_w)
assert counts_w[-1] == 3
plt.figure(figsize=(4, 3))
plt.plot(range(len(counts_w)), counts_w, marker="o", color="purple")
plt.xlabel("WL round"); plt.ylabel("distinct colors")
plt.title("2: refinement discovers roles then stabilizes"); plt.ylim(0, 4); plt.show()
```
▶ What you'll see: the color count rises and then stops once the path's three role types are found.

*Why it's done this way:* each round composes the previous color with neighbor colors, so information travels one edge per round. Stabilization means another local multiset pass does not split any role further. That is a structural fixed point, not a learned convergence criterion.

### 3. Message-passing GNNs inherit the 1-WL boundary

A basic message-passing GNN layer also updates a node from its old feature and aggregated neighbor features. If two nodes have the same old feature and the same neighbor-feature multiset, a permutation-invariant aggregator gives them the same next feature. That is the same equivalence rule 1-WL uses, so such GNNs cannot distinguish beyond 1-WL.

```python
X_w = np.ones((5, 1))  # identical scalar node features on the path.
H1_w = np.concatenate([X_w, A_path_w @ X_w], axis=1)  # old feature and sum of neighbor features.
print("[self, neighbor_sum]:\n", H1_w.astype(int))
assert H1_w[:, 1].tolist() == [1, 2, 2, 2, 1]
```
▶ What you'll see: endpoints separate from degree-2 nodes after one sum-aggregation layer.

```python
H2_w = np.concatenate([H1_w, A_path_w @ H1_w], axis=1)  # second layer sees two-hop summaries.
print("second-layer rows:\n", H2_w.astype(int))
print("unique second-layer rows:", np.unique(H2_w, axis=0))
assert np.unique(H2_w, axis=0).shape[0] == 3
```
▶ What you'll see: the same three roles as 1-WL on the path: endpoint, near-endpoint, center.

```python
plt.figure(figsize=(5, 3))
plt.imshow(H2_w, cmap="magma", aspect="auto")
plt.colorbar(label="feature value")
plt.xlabel("feature coordinate"); plt.ylabel("node")
plt.title("3: message passing mirrors WL role refinement"); plt.show()
```
▶ What you'll see: nodes with the same WL role have identical learned-feature rows.

*Why it's done this way:* `A @ H` is a permutation-invariant neighbor sum: it ignores neighbor order but preserves additive counts. Because the update is a deterministic function of `(self feature, neighbor aggregate)`, equal WL signatures force equal GNN embeddings. This is the WL upper bound in code.

### 4. Some non-isomorphic graphs remain WL-indistinguishable

1-WL can fail when every node keeps seeing the same regular local structure. A 6-cycle and two disjoint triangles are not isomorphic — one is connected and one is not — but every node has degree 2, every neighbor also has degree 2, and that symmetry persists forever for 1-WL started from identical node features.

```python
C6_w = np.zeros((6, 6), dtype=int)  # connected 6-cycle.
for i_w in range(6):
    C6_w[i_w, (i_w - 1) % 6] = 1
    C6_w[i_w, (i_w + 1) % 6] = 1
T2_w = np.zeros((6, 6), dtype=int)  # two disjoint triangles.
for tri_w in ([0, 1, 2], [3, 4, 5]):
    for i_w in tri_w:
        for j_w in tri_w:
            if i_w != j_w:
                T2_w[i_w, j_w] = 1
print("cycle degrees:", C6_w.sum(axis=1).astype(int))
print("two-triangle degrees:", T2_w.sum(axis=1).astype(int))
assert C6_w.sum() == T2_w.sum() == 12
```
▶ What you'll see: both graphs are 2-regular with six nodes and six undirected edges.

```python
def wl_hist_w(A, rounds=4):  # multiset of colors after each WL round.
    c = np.ones(A.shape[0], dtype=int)
    out = []
    for _ in range(rounds):
        c, _ = wl_step_w(A, c)
        vals, cnts = np.unique(c, return_counts=True)
        out.append(tuple(zip(vals.tolist(), cnts.tolist())))
    return out

hist_C6_w = wl_hist_w(C6_w, 4)
hist_T2_w = wl_hist_w(T2_w, 4)
print("C6 WL hist:", hist_C6_w)
print("2 triangles WL hist:", hist_T2_w)
assert hist_C6_w == hist_T2_w
```
▶ What you'll see: every round has one color appearing six times in both graphs.

```python
X_same_w = np.ones((6, 1))
H_C6_w = X_same_w.copy(); H_T2_w = X_same_w.copy()
for _ in range(3):
    H_C6_w = np.concatenate([H_C6_w, C6_w @ H_C6_w], axis=1)
    H_T2_w = np.concatenate([H_T2_w, T2_w @ H_T2_w], axis=1)
graph_C6_w = H_C6_w.sum(axis=0)
graph_T2_w = H_T2_w.sum(axis=0)
print("graph embeddings equal:", np.allclose(graph_C6_w, graph_T2_w))
assert np.allclose(graph_C6_w, graph_T2_w)
```
▶ What you'll see: a sum-readout message-passing GNN also gives identical graph embeddings here.

*Why it's done this way:* 1-WL is local and color-multiset based. Connectivity is a global property, and these two regular graphs hide it from local color refinement when all initial features match. A message-passing GNN using the same symmetry-respecting ingredients cannot invent a distinction that its node updates never receive.

### 5. GIN responds with injective multiset aggregation

GIN is designed around the lesson that aggregation should preserve multisets as much as possible. Its simplified update is

$$h_v^{(k+1)}=\operatorname{MLP}^{(k)}\left((1+\epsilon)h_v^{(k)}+\sum_{u\in N(v)}h_u^{(k)}\right).$$

The sum keeps multiplicities, while a mean can collapse different bags such as `[1,1]` and `[1]`.

```python
bag1_w = np.array([1., 1.])  # two neighbors with feature 1.
bag2_w = np.array([1.])  # one neighbor with feature 1.
print("sum bag1, bag2:", bag1_w.sum(), bag2_w.sum())
print("mean bag1, bag2:", bag1_w.mean(), bag2_w.mean())
assert bag1_w.mean() == bag2_w.mean()
```
▶ What you'll see: the means are identical even though the multiplicities are different.

```python
bag3_w = np.array([1., 1., 1.])  # three ones.
bag4_w = np.array([1., 2.])  # one and two.
print("sum collision:", bag3_w.sum(), bag4_w.sum())
print("count differs:", len(bag3_w), len(bag4_w))
assert bag3_w.sum() == bag4_w.sum() == 3
```
▶ What you'll see: sums can also collide if features are not rich enough; an MLP after a sum helps learn richer encodings.

```python
def gin_scalar_w(self_x, neigh_x, eps=0.0):  # GIN pre-MLP scalar update.
    return (1 + eps) * self_x + float(np.sum(neigh_x))

def mean_scalar_w(self_x, neigh_x):  # mean-style pre-update for comparison.
    return self_x + float(np.mean(neigh_x)) if len(neigh_x) else self_x

print("GIN [1,1] vs [1]:", gin_scalar_w(0., bag1_w), gin_scalar_w(0., bag2_w))
print("mean [1,1] vs [1]:", mean_scalar_w(0., bag1_w), mean_scalar_w(0., bag2_w))
assert gin_scalar_w(0., bag1_w) != gin_scalar_w(0., bag2_w)
```
▶ What you'll see: GIN's sum distinguishes a doubled neighbor from a single neighbor, while the mean does not.

*Why it's done this way:* WL's signature is an injective code of a multiset. GIN imitates that goal by summing neighbor embeddings, adding a weighted self-term, and letting an MLP transform the result. It still cannot beat 1-WL on symmetric counterexamples, but it avoids weaker collisions introduced by non-injective choices like mean aggregation.

### ✍️ Toy 1 · WL signatures keep neighbor multiplicity

A 1-WL signature is the node's old color plus the sorted **bag** of neighbor colors. The star center sees three copies of color 1, while a leaf sees one copy.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)                                  # seeded generator for reproducibility.
t1_A = np.array([[0, 1, 1, 1], [1, 0, 0, 0], [1, 0, 0, 0], [1, 0, 0, 0]], dtype=int)  # tiny star adjacency.
t1_colors = np.ones(4, dtype=int)                                  # every node starts with color 1.  # -> [1, 1, 1, 1]
t1_degrees = t1_A.sum(axis=1).astype(int)                          # count neighbors per node.  # -> [3, 1, 1, 1]
print("initial colors:", t1_colors.tolist())                       # -> [1, 1, 1, 1]
print("degrees:", t1_degrees.tolist())                             # -> [3, 1, 1, 1]

t1_center = 0                                                       # inspect node 0.
t1_center_neighbors = np.where(t1_A[t1_center] == 1)[0]             # center neighbor ids.  # -> [1, 2, 3]
t1_center_bag = tuple(sorted(t1_colors[t1_center_neighbors].tolist()))  # center neighbor-color multiset.  # -> (1, 1, 1)
t1_center_signature = (int(t1_colors[t1_center]), t1_center_bag)    # old color plus center bag.  # -> (1, (1, 1, 1))
print("center neighbors:", t1_center_neighbors.tolist())           # -> [1, 2, 3]
print("center signature:", t1_center_signature)                    # -> (1, (1, 1, 1))

t1_leaf = 1                                                         # inspect one leaf.
t1_leaf_neighbors = np.where(t1_A[t1_leaf] == 1)[0]                 # leaf neighbor ids.  # -> [0]
t1_leaf_bag = tuple(sorted(t1_colors[t1_leaf_neighbors].tolist()))  # leaf neighbor-color multiset.  # -> (1,)
t1_leaf_signature = (int(t1_colors[t1_leaf]), t1_leaf_bag)          # old color plus leaf bag.  # -> (1, (1,))
t1_colors_after = np.array([2, 1, 1, 1])                            # center gets a distinct refined color.  # -> [2, 1, 1, 1]
print("leaf neighbors:", t1_leaf_neighbors.tolist())               # -> [0]
print("leaf signature:", t1_leaf_signature)                        # -> (1, (1,))
print("refined colors:", t1_colors_after.tolist())                 # -> [2, 1, 1, 1]
assert t1_center_signature != t1_leaf_signature

t1_xy = np.array([[0.0, 0.8], [-1.0, -0.5], [0.0, -0.9], [1.0, -0.5]])
plt.figure(figsize=(4.5, 3.2))
for t1_i, t1_j in zip(*np.where(np.triu(t1_A) == 1)):
    plt.plot([t1_xy[t1_i, 0], t1_xy[t1_j, 0]], [t1_xy[t1_i, 1], t1_xy[t1_j, 1]], color="gray")
plt.scatter(t1_xy[:, 0], t1_xy[:, 1], c=t1_colors_after, s=700, cmap="viridis", edgecolor="black")
for t1_v, (t1_x, t1_y) in enumerate(t1_xy):
    plt.text(t1_x, t1_y, str(t1_v), ha="center", va="center", color="white")
plt.title("Toy 1 · WL splits center from leaves")
plt.axis("off")
plt.show()
```
▶ What you'll see: the center signature contains three neighbor colors, so it gets a different color from the leaves.

### ✍️ Toy 2 · Repeated WL refinement stabilizes roles

Each WL round expands the visible radius by one hop. On a 5-node path, the colors settle into endpoint, near-endpoint, and center roles.

```python
import numpy as np

t2_rng = np.random.default_rng(0)                                  # seeded generator for reproducibility.
t2_A = np.array([[0, 1, 0, 0, 0], [1, 0, 1, 0, 0], [0, 1, 0, 1, 0], [0, 0, 1, 0, 1], [0, 0, 0, 1, 0]], dtype=int)  # 5-node path.
t2_colors0 = np.ones(5, dtype=int)                                 # round-0 colors.  # -> [1, 1, 1, 1, 1]
print("round 0:", t2_colors0.tolist())                             # -> [1, 1, 1, 1, 1]

def t2_wl_step(t2_A_in, t2_colors_in):
    t2_signatures = []
    for t2_v in range(t2_A_in.shape[0]):
        t2_neighbors = np.where(t2_A_in[t2_v] == 1)[0]
        t2_bag = tuple(sorted(t2_colors_in[t2_neighbors].tolist()))
        t2_signatures.append((int(t2_colors_in[t2_v]), t2_bag))
    t2_palette = {t2_sig: t2_i + 1 for t2_i, t2_sig in enumerate(sorted(set(t2_signatures)))}
    t2_next = np.array([t2_palette[t2_sig] for t2_sig in t2_signatures], dtype=int)
    return t2_next

t2_colors1 = t2_wl_step(t2_A, t2_colors0)                          # first refinement.  # -> [1, 2, 2, 2, 1]
t2_colors2 = t2_wl_step(t2_A, t2_colors1)                          # second refinement.  # -> [1, 2, 3, 2, 1]
t2_colors3 = t2_wl_step(t2_A, t2_colors2)                          # third refinement.  # -> [1, 2, 3, 2, 1]
t2_history = np.vstack([t2_colors0, t2_colors1, t2_colors2, t2_colors3])  # stack colors by round.
t2_counts = np.array([len(set(t2_row.tolist())) for t2_row in t2_history])  # distinct colors by round.  # -> [1, 2, 3, 3]
print("round 1:", t2_colors1.tolist())                             # -> [1, 2, 2, 2, 1]
print("round 2:", t2_colors2.tolist())                             # -> [1, 2, 3, 2, 1]
print("round 3:", t2_colors3.tolist())                             # -> [1, 2, 3, 2, 1]
print("distinct color counts:", t2_counts.tolist())                # -> [1, 2, 3, 3]
assert np.array_equal(t2_colors2, t2_colors3)
assert t2_counts.tolist() == [1, 2, 3, 3]

plt.figure(figsize=(4.6, 3))
plt.imshow(t2_history, cmap="viridis", aspect="auto")
plt.colorbar(label="WL color")
plt.xlabel("node")
plt.ylabel("round")
plt.title("Toy 2 · path roles stabilize")
plt.show()
```
▶ What you'll see: the path reaches three stable structural roles after two refinements.

### ✍️ Toy 3 · Sum message passing mirrors WL roles

A sum-aggregation GNN layer with identical initial features recovers degree first, then two-hop roles, just like WL on this path.

```python
import numpy as np

t3_rng = np.random.default_rng(0)                                  # seeded generator for reproducibility.
t3_A = np.array([[0, 1, 0, 0, 0], [1, 0, 1, 0, 0], [0, 1, 0, 1, 0], [0, 0, 1, 0, 1], [0, 0, 0, 1, 0]], dtype=int)  # 5-node path.
t3_X = np.ones((5, 1), dtype=float)                                # identical scalar node features.  # -> [[1], [1], [1], [1], [1]]
t3_neighbor_sum = t3_A @ t3_X                                      # one-hop sum messages.  # -> [1, 2, 2, 2, 1]
t3_H1 = np.concatenate([t3_X, t3_neighbor_sum], axis=1)            # self plus one-hop sum.  # -> [[1,1],[1,2],[1,2],[1,2],[1,1]]
t3_H2 = np.concatenate([t3_H1, t3_A @ t3_H1], axis=1)              # append two-hop summaries.
t3_unique_rows = np.unique(t3_H2, axis=0)                          # distinct node embeddings.  # -> 3 rows
print("neighbor sums:", t3_neighbor_sum.astype(int).ravel().tolist())  # -> [1, 2, 2, 2, 1]
print("first-layer rows:", t3_H1.astype(int).tolist())             # -> [[1, 1], [1, 2], [1, 2], [1, 2], [1, 1]]
print("second-layer rows:", t3_H2.astype(int).tolist())            # -> [[1, 1, 1, 2], [1, 2, 2, 3], [1, 2, 2, 4], [1, 2, 2, 3], [1, 1, 1, 2]]
print("unique second-layer rows:", t3_unique_rows.astype(int).tolist())  # -> [[1, 1, 1, 2], [1, 2, 2, 3], [1, 2, 2, 4]]
assert t3_unique_rows.shape[0] == 3

plt.figure(figsize=(5, 3))
plt.imshow(t3_H2, cmap="magma", aspect="auto")
plt.colorbar(label="feature value")
plt.xlabel("feature coordinate")
plt.ylabel("node")
plt.title("Toy 3 · message passing finds the same roles")
plt.show()
```
▶ What you'll see: endpoints match, near-endpoints match, and the center has its own feature row.

### ✍️ Toy 4 · 1-WL ties a cycle with two triangles

A 6-cycle and two disjoint triangles are different graphs, but every node in both graphs keeps seeing the same 2-regular local pattern.

```python
import numpy as np

t4_rng = np.random.default_rng(0)                                  # seeded generator for reproducibility.
t4_C6 = np.zeros((6, 6), dtype=int)                                # connected 6-cycle.
for t4_i in range(6):
    t4_C6[t4_i, (t4_i - 1) % 6] = 1
    t4_C6[t4_i, (t4_i + 1) % 6] = 1
t4_T2 = np.zeros((6, 6), dtype=int)                                # two disjoint triangles.
for t4_tri in ([0, 1, 2], [3, 4, 5]):
    for t4_i in t4_tri:
        for t4_j in t4_tri:
            if t4_i != t4_j:
                t4_T2[t4_i, t4_j] = 1
t4_C6_degrees = t4_C6.sum(axis=1).astype(int)                      # cycle degrees.  # -> [2, 2, 2, 2, 2, 2]
t4_T2_degrees = t4_T2.sum(axis=1).astype(int)                      # triangle-pair degrees.  # -> [2, 2, 2, 2, 2, 2]
print("C6 degrees:", t4_C6_degrees.tolist())                       # -> [2, 2, 2, 2, 2, 2]
print("two-triangle degrees:", t4_T2_degrees.tolist())             # -> [2, 2, 2, 2, 2, 2]

def t4_wl_step(t4_A_in, t4_colors_in):
    t4_signatures = []
    for t4_v in range(t4_A_in.shape[0]):
        t4_neighbors = np.where(t4_A_in[t4_v] == 1)[0]
        t4_bag = tuple(sorted(t4_colors_in[t4_neighbors].tolist()))
        t4_signatures.append((int(t4_colors_in[t4_v]), t4_bag))
    t4_palette = {t4_sig: t4_i + 1 for t4_i, t4_sig in enumerate(sorted(set(t4_signatures)))}
    t4_next = np.array([t4_palette[t4_sig] for t4_sig in t4_signatures], dtype=int)
    return t4_next

def t4_wl_hist(t4_A_in, t4_rounds):
    t4_colors = np.ones(t4_A_in.shape[0], dtype=int)
    t4_out = []
    for _ in range(t4_rounds):
        t4_colors = t4_wl_step(t4_A_in, t4_colors)
        t4_vals, t4_counts = np.unique(t4_colors, return_counts=True)
        t4_out.append(tuple(zip(t4_vals.tolist(), t4_counts.tolist())))
    return t4_out
```

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, graph adjacency matrices, feature updates, and numerical checks.
import matplotlib.pyplot as plt # load Matplotlib for inspecting graph structure, color histograms, and feature trajectories.
np.random.seed(0) # make every random toy graph or feature initialization reproducible.

def make_cycle(n): # create an undirected n-cycle adjacency matrix.
    A = np.zeros((n, n), dtype=int) # start with no edges.
    for i in range(n): # connect each node to its predecessor and successor.
        A[i, (i - 1) % n] = 1 # add the left cycle edge.
        A[i, (i + 1) % n] = 1 # add the right cycle edge.
    return A # return a symmetric 0/1 adjacency matrix.

def wl_step(A, colors): # perform one canonical 1-WL color-refinement step.
    signatures = [] # collect old-color plus neighbor-color multiset signatures.
    for v in range(A.shape[0]): # process one node at a time.
        neigh = np.where(A[v] == 1)[0] # find neighbor indices from the adjacency row.
        bag = tuple(sorted(colors[neigh].tolist())) # sort neighbor colors to encode the multiset order-invariantly.
        signatures.append((int(colors[v]), bag)) # include the node's previous color and its neighbor bag.
    palette = {sig: i + 1 for i, sig in enumerate(sorted(set(signatures)))} # assign deterministic small color IDs.
    return np.array([palette[sig] for sig in signatures], dtype=int), signatures # return new colors and raw signatures.

def wl_history(A, rounds=3): # record WL colors across several rounds.
    colors = np.ones(A.shape[0], dtype=int) # start from one shared initial color.
    hist = [colors.copy()] # include round 0 for inspection.
    for _ in range(rounds): # refine repeatedly.
        colors, _ = wl_step(A, colors) # update colors by neighbor multisets.
        hist.append(colors.copy()) # keep a copy so later updates do not mutate history.
    return hist # list of color arrays.

def graph_color_hist(colors): # summarize a coloring as counts per color.
    vals, cnts = np.unique(colors, return_counts=True) # count each color ID.
    return tuple(zip(vals.tolist(), cnts.tolist())) # return a hashable histogram.

def message_sum(A, X): # one simple message-passing aggregation.
    return A @ X # sum neighbor features with adjacency matrix multiplication.

def gin_pre(A, X, eps=0.0): # GIN pre-MLP update using sum aggregation.
    return (1.0 + eps) * X + A @ X # self term plus summed neighbor features.

def mean_agg(A, X): # mean aggregation for comparison with GIN.
    deg = A.sum(axis=1, keepdims=True) # count neighbors for each node.
    deg = np.maximum(deg, 1) # avoid division by zero for isolated nodes.
    return (A @ X) / deg # average neighbor features.

def draw_graph(A, colors=None, title="graph"): # draw a tiny graph with nodes around a circle.
    n = A.shape[0] # number of nodes.
    angles = np.linspace(0, 2 * np.pi, n, endpoint=False) # evenly spaced node angles.
    xy = np.c_[np.cos(angles), np.sin(angles)] # circular layout coordinates.
    plt.figure(figsize=(4, 3.5)) # compact figure for notebooks.
    for i, j in zip(*np.where(np.triu(A) == 1)): # draw each undirected edge once.
        plt.plot([xy[i, 0], xy[j, 0]], [xy[i, 1], xy[j, 1]], color="gray", linewidth=1.5) # edge segment.
    c = np.ones(n) if colors is None else colors # default node color when none is supplied.
    plt.scatter(xy[:, 0], xy[:, 1], c=c, cmap="viridis", s=500, edgecolor="black") # draw colored nodes.
    for v in range(n): # label node indices.
        plt.text(xy[v, 0], xy[v, 1], str(v), ha="center", va="center", color="white") # centered label.
    plt.title(title) # explain what graph is shown.
    plt.axis("off") # graph diagrams do not need axes.
    plt.show() # display the graph.
```
