# 10.9 — Normalizing Flows

Normalizing flows generate data by applying invertible transformations to a simple base distribution while exactly tracking how density changes. In this lesson, you will build the whole mechanism from scratch in NumPy: change of variables, log-determinants, affine coupling layers, exact likelihood, and sampling.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build normalizing flows one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, especially change of variables and the log-determinant Jacobian, is exposed instead of hidden behind a deep-learning library. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, linear algebra, and toy sampling for flows.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for samples and tiny training loops.
```

### 1. The easy base density

A flow starts from a distribution we can already sample from and score exactly. We use a 2-D standard Gaussian, whose log-density is a quadratic penalty plus a constant.

```python
z_w = np.array([[0., 0.], [1., -1.], [2., 0.5]])
logp_w = -0.5 * np.sum(z_w ** 2, axis=1) - np.log(2 * np.pi)
print("z points:\n", z_w)
print("base log densities:", np.round(logp_w, 3))
assert round(float(logp_w[0]), 3) == -1.838
```

▶ What you'll see: points farther from the origin receive lower Gaussian log-density.

```python
grid_w = np.linspace(-3, 3, 121)
X_w, Y_w = np.meshgrid(grid_w, grid_w)
dens_w = np.exp(-0.5 * (X_w ** 2 + Y_w ** 2) - np.log(2 * np.pi))
plt.figure(figsize=(4, 3.4)); plt.contourf(X_w, Y_w, dens_w, levels=20, cmap="viridis")
plt.scatter(z_w[:, 0], z_w[:, 1], c="red", s=35); plt.colorbar(label="base density")
plt.title("1: easy Gaussian base density"); plt.xlabel("z0"); plt.ylabel("z1"); plt.show()
```

▶ What you'll see: circular probability contours centered at zero.

*Why it's done this way:* exact likelihood needs a known starting density. The flow only has to account for how each invertible layer changes volume, not learn a normalizing constant from scratch.

### 2. Change of variables and the log-det Jacobian

If $x=f(z)$ is invertible, probability mass is conserved. Stretching area by $|\det J_f|$ lowers density by that factor, so $\log p_X(x)=\log p_Z(z)-\log|\det J_f(z)|$.

```python
z2_w = np.array([1.2, -0.7])
a_w = 1.5
t_w = np.array([0.3, -0.2])
x2_w = a_w * z2_w + t_w
logdet_w = 2 * np.log(abs(a_w))
print("x = a z + t:", np.round(x2_w, 3))
print("log |det J|:", round(float(logdet_w), 4))
assert np.allclose(np.round(x2_w, 3), [2.1, -1.25])
assert round(float(logdet_w), 4) == 0.8109
```

▶ What you'll see: the lesson numbers `(2.100, -1.250)` and log-determinant `0.8109`.

```python
logpz2_w = -0.5 * np.sum(z2_w ** 2) - np.log(2 * np.pi)
logpx2_w = logpz2_w - logdet_w
print("log p_Z(z):", round(float(logpz2_w), 3))
print("log p_X(x):", round(float(logpx2_w), 3))
assert round(float(logpx2_w - logpz2_w), 4) == -0.8109
```

▶ What you'll see: the transformed log-density is lower by exactly the log-volume expansion.

```python
square_w = np.array([[0,0], [1,0], [1,1], [0,1], [0,0]], dtype=float)
stretched_w = a_w * square_w + t_w
plt.figure(figsize=(4, 3.4)); plt.plot(square_w[:,0], square_w[:,1], "o-", label="unit area")
plt.plot(stretched_w[:,0], stretched_w[:,1], "o-", label="area × 2.25")
plt.axis("equal"); plt.legend(); plt.title("2: stretching explains log-det"); plt.show()
```

▶ What you'll see: scaling by 1.5 in two dimensions multiplies area by 2.25.

*Why it's done this way:* the determinant is the local volume multiplier. The absolute value matters because orientation flips can make determinants negative, but density only cares about positive volume.

### 3. Invertibility ties sampling to likelihood

Forward generation maps base noise to data-like points. Reverse scoring maps data back to base coordinates. A normalizing flow requires both directions to be exact.

```python
samples_z_w = np.random.randn(400, 2)
scale_w = np.array([1.8, 0.6])
shift_w = np.array([1.0, -0.5])
samples_x_w = samples_z_w * scale_w + shift_w
recovered_z_w = (samples_x_w - shift_w) / scale_w
print("max inverse error:", np.max(np.abs(samples_z_w - recovered_z_w)))
assert np.max(np.abs(samples_z_w - recovered_z_w)) < 1e-12
```

▶ What you'll see: the inverse reconstructs the original base samples up to floating-point roundoff.

```python
logdet_diag_w = np.sum(np.log(np.abs(scale_w)))
idx_w = 0
logpx_idx_w = (-0.5 * np.sum(recovered_z_w[idx_w] ** 2) - np.log(2 * np.pi)) - logdet_diag_w
print("sample x:", np.round(samples_x_w[idx_w], 3))
print("log p_X(sample):", round(float(logpx_idx_w), 3))
assert round(float(logdet_diag_w), 3) == 0.077
```

▶ What you'll see: the same inverse used for reconstruction gives an exact likelihood correction.

```python
plt.figure(figsize=(4, 3.4)); plt.scatter(samples_z_w[:,0], samples_z_w[:,1], s=8, alpha=0.35, label="base z")
plt.scatter(samples_x_w[:,0], samples_x_w[:,1], s=8, alpha=0.35, label="flow x")
plt.axis("equal"); plt.legend(); plt.title("3: forward samples are transformed noise"); plt.show()
```

▶ What you'll see: a round Gaussian cloud becomes shifted and elongated.

*Why it's done this way:* flows accept architectural constraints so every output has exactly one input. That one-to-one pairing makes generation and likelihood two directions of the same model.

### 4. Affine coupling layers keep determinants cheap

A coupling layer leaves part of the vector unchanged and uses it to scale and shift the other part. The Jacobian is triangular, so its determinant is just the product of diagonal entries.

```python
def coupling_forward_w(x):
    y = x.copy()
    s = 0.7 * np.tanh(x[:, 0])
    t = 0.5 * np.sin(x[:, 0])
    y[:, 1] = x[:, 1] * np.exp(s) + t
    return y, s
x_c_w = np.array([[0.0, 1.0], [1.0, -0.5], [-1.0, 0.5]])
y_c_w, logdet_c_w = coupling_forward_w(x_c_w)
print("y after coupling:\n", np.round(y_c_w, 3))
print("log-det per point:", np.round(logdet_c_w, 3))
```

▶ What you'll see: coordinate 0 stays fixed while coordinate 1 is scaled and shifted by a rule depending on coordinate 0.

```python
def coupling_inverse_w(y):
    x = y.copy()
    s = 0.7 * np.tanh(y[:, 0])
    t = 0.5 * np.sin(y[:, 0])
    x[:, 1] = (y[:, 1] - t) * np.exp(-s)
    return x, -s
x_back_w, inv_logdet_c_w = coupling_inverse_w(y_c_w)
print("recovered x:\n", np.round(x_back_w, 3))
print("forward + inverse logdet:", np.round(logdet_c_w + inv_logdet_c_w, 6))
assert np.allclose(x_back_w, x_c_w)
assert np.allclose(logdet_c_w + inv_logdet_c_w, 0)
```

▶ What you'll see: the inverse recovers the inputs and the log-determinants cancel exactly.

```python
cloud_w = np.random.randn(700, 2)
warped_w, _ = coupling_forward_w(cloud_w)
plt.figure(figsize=(4, 3.4)); plt.scatter(cloud_w[:,0], cloud_w[:,1], s=7, alpha=0.25, label="before")
plt.scatter(warped_w[:,0], warped_w[:,1], s=7, alpha=0.25, label="after")
plt.legend(); plt.title("4: coupling bends one coordinate"); plt.show()
```

▶ What you'll see: nonlinear deformation without losing invertibility.

*Why it's done this way:* a dense Jacobian determinant can be expensive; a triangular coupling Jacobian has a determinant equal to the scale term, so exact likelihood remains practical.

### 5. Stacking layers adds expressiveness

One coupling layer directly changes only one coordinate. Stacking layers and alternating which coordinate is fixed lets both coordinates influence each other. Log-determinants add because determinants multiply under composition.

```python
def layer0_forward_w(x):
    y = x.copy(); s = 0.6 * np.tanh(x[:, 0]); t = 0.4 * np.sin(1.5 * x[:, 0])
    y[:, 1] = x[:, 1] * np.exp(s) + t
    return y, s
def layer1_forward_w(x):
    y = x.copy(); s = -0.5 * np.tanh(x[:, 1]); t = 0.35 * np.cos(1.2 * x[:, 1])
    y[:, 0] = x[:, 0] * np.exp(s) + t
    return y, s
z_stack_w = np.random.randn(500, 2)
h_stack_w, ld0_w = layer0_forward_w(z_stack_w)
x_stack_w, ld1_w = layer1_forward_w(h_stack_w)
print("mean total log-det:", round(float(np.mean(ld0_w + ld1_w)), 3))
print("sample output row:", np.round(x_stack_w[0], 3))
```

▶ What you'll see: each sample accumulates one log-determinant contribution from each layer.

```python
def layer1_inverse_w(y):
    x = y.copy(); s = -0.5 * np.tanh(y[:, 1]); t = 0.35 * np.cos(1.2 * y[:, 1])
    x[:, 0] = (y[:, 0] - t) * np.exp(-s)
    return x, -s
def layer0_inverse_w(y):
    x = y.copy(); s = 0.6 * np.tanh(y[:, 0]); t = 0.4 * np.sin(1.5 * y[:, 0])
    x[:, 1] = (y[:, 1] - t) * np.exp(-s)
    return x, -s
h_back_w, ild1_w = layer1_inverse_w(x_stack_w)
z_back_stack_w, ild0_w = layer0_inverse_w(h_back_w)
print("max reconstruction error:", np.max(np.abs(z_stack_w - z_back_stack_w)))
assert np.max(np.abs(z_stack_w - z_back_stack_w)) < 1e-12
```

▶ What you'll see: the nonlinear two-layer flow is still exactly invertible.

```python
plt.figure(figsize=(4, 3.4)); plt.scatter(z_stack_w[:,0], z_stack_w[:,1], s=7, alpha=0.22, label="base")
plt.scatter(x_stack_w[:,0], x_stack_w[:,1], s=7, alpha=0.22, label="flow")
plt.legend(); plt.title("5: stacked couplings make richer samples"); plt.show()
```

▶ What you'll see: transformed samples are curved rather than merely elliptical.

*Why it's done this way:* composition gives expressive shape changes while preserving auditable layer-by-layer density accounting.

### 6. Maximum likelihood trains the flow

Because every data point can be inverted and scored, flows can train by maximizing exact likelihood. This tiny demo fits only an affine flow, but the objective is the same for richer coupling stacks.

```python
rng_w = np.random.default_rng(0)
data_w = rng_w.normal(size=(600, 2)) * np.array([1.8, 0.5]) + np.array([2.0, -1.0])
mu_w = np.zeros(2)
log_scale_w = np.zeros(2)
print("data mean/std:", np.round(data_w.mean(axis=0), 3), np.round(data_w.std(axis=0), 3))
```

▶ What you'll see: the target cloud is shifted and anisotropic.

```python
losses_fit_w = []
for step_w in range(120):
    scale_fit_w = np.exp(log_scale_w)
    z_fit_w = (data_w - mu_w) / scale_fit_w
    grad_mu_w = -np.mean(z_fit_w / scale_fit_w, axis=0)
    grad_log_scale_w = np.mean(1 - z_fit_w ** 2, axis=0)
    mu_w -= 0.08 * grad_mu_w
    log_scale_w -= 0.08 * grad_log_scale_w
    nll_w = float(np.mean(0.5 * np.sum(z_fit_w ** 2, axis=1) + np.log(2 * np.pi) + np.sum(log_scale_w)))
    losses_fit_w.append(nll_w)
print("learned mu:", np.round(mu_w, 3), "learned scale:", np.round(np.exp(log_scale_w), 3))
assert abs(mu_w[0] - 2.0) < 0.25 and abs(np.exp(log_scale_w)[0] - 1.8) < 0.25
```

▶ What you'll see: learned shift and scale move close to the target data's empirical values.

```python
base_draw_w = rng_w.normal(size=(600, 2))
gen_draw_w = base_draw_w * np.exp(log_scale_w) + mu_w
plt.figure(figsize=(4, 3.4)); plt.scatter(data_w[:,0], data_w[:,1], s=7, alpha=0.25, label="data")
plt.scatter(gen_draw_w[:,0], gen_draw_w[:,1], s=7, alpha=0.25, label="flow samples")
plt.legend(); plt.title("6: likelihood-fitted affine flow"); plt.show()
```

▶ What you'll see: generated samples overlap the target cloud.

*Why it's done this way:* maximum likelihood is possible because the inverse gives a base log-density and the Jacobian gives the exact volume correction.

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, random toy data, log-density arithmetic, and hand-coded flow layers.
import matplotlib.pyplot as plt # load Matplotlib for scatter plots, contours, density heatmaps, and diagnostics.
np.random.seed(0) # make every stochastic example reproducible across notebook runs.

def log_standard_normal(x): # compute log N(0,I) for each row.
    x = np.asarray(x, dtype=float)
    d = x.shape[1]
    return -0.5 * np.sum(x ** 2, axis=1) - 0.5 * d * np.log(2 * np.pi)

def toy_moons(n=400, noise=0.06, seed=0): # synthesize two curved arcs using NumPy only.
    rng = np.random.default_rng(seed); n1 = n // 2; n2 = n - n1
    t1 = rng.uniform(0, np.pi, n1); t2 = rng.uniform(0, np.pi, n2)
    upper = np.c_[np.cos(t1), np.sin(t1)]
    lower = np.c_[1 - np.cos(t2), -np.sin(t2) - 0.5]
    return np.vstack([upper, lower]) + noise * rng.normal(size=(n, 2))

def affine_forward(z, scale, shift): # x = scale*z + shift.
    scale = np.asarray(scale, dtype=float); shift = np.asarray(shift, dtype=float)
    x = z * scale + shift
    logdet = np.full(z.shape[0], np.sum(np.log(np.abs(scale))))
    return x, logdet

def affine_inverse(x, scale, shift): # z = (x-shift)/scale.
    scale = np.asarray(scale, dtype=float); shift = np.asarray(shift, dtype=float)
    z = (x - shift) / scale
    inv_logdet = np.full(x.shape[0], -np.sum(np.log(np.abs(scale))))
    return z, inv_logdet

def coupling_forward(x, flip=False): # 2-D affine coupling layer.
    y = x.copy(); fixed = 1 if flip else 0; changed = 0 if flip else 1
    s = 0.65 * np.tanh(y[:, fixed]); t = 0.45 * np.sin(1.3 * y[:, fixed])
    y[:, changed] = y[:, changed] * np.exp(s) + t
    return y, s

def coupling_inverse(y, flip=False): # inverse coupling layer.
    x = y.copy(); fixed = 1 if flip else 0; changed = 0 if flip else 1
    s = 0.65 * np.tanh(x[:, fixed]); t = 0.45 * np.sin(1.3 * x[:, fixed])
    x[:, changed] = (x[:, changed] - t) * np.exp(-s)
    return x, -s

def two_layer_flow_forward(z): # compose alternating coupling layers.
    h, ld0 = coupling_forward(z, flip=False)
    x, ld1 = coupling_forward(h, flip=True)
    return x, ld0 + ld1

def two_layer_flow_inverse(x): # invert the composed flow in reverse order.
    h, ild1 = coupling_inverse(x, flip=True)
    z, ild0 = coupling_inverse(h, flip=False)
    return z, ild0 + ild1

def show_density_heatmap(points, title): # visualize empirical 2-D sample density.
    plt.figure(figsize=(4, 3)); plt.hist2d(points[:,0], points[:,1], bins=35, cmap="viridis")
    plt.colorbar(label="count"); plt.title(title); plt.xlabel("x0"); plt.ylabel("x1"); plt.show()
```

## 🟢 Basics (warm-up)

### Basic 1 — Score the standard Gaussian base

**Goal.** Compute exact log-density for a 2-D standard normal, because flows need a tractable base distribution before any transformation happens. We build it in 2 steps.

```python
z_b1 = np.array([[0.0, 0.0], [1.0, 0.0], [1.0, 2.0]])
quad_b1 = np.sum(z_b1 ** 2, axis=1)
print("squared radii:", quad_b1)
```

▶ What you'll see: log-density decreases as radius grows.

```python
logp_b1 = log_standard_normal(z_b1)
print("log p(z):", np.round(logp_b1, 3))
assert round(float(logp_b1[0]), 3) == -1.838
plt.figure(figsize=(4, 3)); plt.bar(["origin", "one step", "far"], logp_b1, color="teal")
plt.title("Basic 1: base log-density"); plt.ylabel("log probability density"); plt.show()
```

▶ What you'll see: log-density decreases as radius grows.

👀 Takeaway: a flow starts from a distribution whose samples and log probabilities are easy.

### Basic 2 — Apply an affine flow

**Goal.** Transform base points with x = scale*z + shift, because a flow layer is an invertible map from simple noise to data space. We build it in 2 steps.

```python
z_b2 = np.array([[0.0, 0.0], [1.0, -1.0], [2.0, 0.5]])
scale_b2 = np.array([1.5, 0.5]); shift_b2 = np.array([0.3, -0.2])
print("scale:", scale_b2, "shift:", shift_b2)
```

▶ What you'll see: points are shifted and stretched, with a negative logdet because total area shrinks.

```python
x_b2, ld_b2 = affine_forward(z_b2, scale_b2, shift_b2)
print("transformed x:\n", np.round(x_b2, 3)); print("logdet:", np.round(ld_b2, 3))
assert round(float(ld_b2[0]), 3) == round(float(np.log(0.75)), 3)
plt.figure(figsize=(4, 3)); plt.scatter(z_b2[:,0], z_b2[:,1], s=80, label="z")
plt.scatter(x_b2[:,0], x_b2[:,1], s=80, label="x"); plt.legend(); plt.axis("equal")
plt.title("Basic 2: affine forward map"); plt.show()
```

▶ What you'll see: points are shifted and stretched, with a negative logdet because total area shrinks.

👀 Takeaway: affine flows are the simplest invertible density transformations.

### Basic 3 — Invert the affine flow

**Goal.** Recover z from x exactly, because exact likelihood requires mapping data back to the base distribution. We build it in 2 steps.

```python
x_b3 = np.array([[0.3, -0.2], [1.8, -0.7], [3.3, 0.05]])
scale_b3 = np.array([1.5, 0.5]); shift_b3 = np.array([0.3, -0.2])
print("x points:\n", x_b3)
```

▶ What you'll see: the original base points reappear exactly.

```python
z_back_b3, inv_ld_b3 = affine_inverse(x_b3, scale_b3, shift_b3)
print("recovered z:\n", np.round(z_back_b3, 3)); print("inverse logdet:", np.round(inv_ld_b3, 3))
assert np.allclose(np.round(z_back_b3, 3), [[0, 0], [1, -1], [2, 0.5]])
plt.figure(figsize=(4, 3)); plt.scatter(z_back_b3[:,0], z_back_b3[:,1], color="purple", s=80)
plt.title("Basic 3: inverse affine map"); plt.axis("equal"); plt.show()
```

▶ What you'll see: the original base points reappear exactly.

👀 Takeaway: invertibility is what lets a flow use the same model for generation and scoring.

### Basic 4 — Compute a log-determinant correction

**Goal.** Subtract log|det J| from the base log-density, because stretching or shrinking changes density per unit area. We build it in 3 steps.

```python
z_b4 = np.array([[1.2, -0.7]])
scale_b4 = np.array([1.5, 1.5]); shift_b4 = np.array([0.3, -0.2])
x_b4, ld_b4 = affine_forward(z_b4, scale_b4, shift_b4)
print("x:", np.round(x_b4[0], 3), "logdet:", round(float(ld_b4[0]), 4))
assert np.allclose(np.round(x_b4[0], 3), [2.1, -1.25]); assert round(float(ld_b4[0]), 4) == 0.8109
```

▶ What you'll see: the flow log-density equals the base log-density plus the negative logdet term.

```python
logpz_b4 = log_standard_normal(z_b4)[0]
logpx_b4 = logpz_b4 - ld_b4[0]
print("log pz:", round(float(logpz_b4), 3), "log px:", round(float(logpx_b4), 3))
```

▶ What you'll see: the flow log-density equals the base log-density plus the negative logdet term.

```python
plt.figure(figsize=(4, 3)); plt.bar(["base logp", "-logdet", "flow logp"], [logpz_b4, -ld_b4[0], logpx_b4], color=["gray", "orange", "teal"])
plt.title("Basic 4: change-of-variables accounting"); plt.ylabel("log units"); plt.show()
```

▶ What you'll see: the flow log-density equals the base log-density plus the negative logdet term.

👀 Takeaway: density tracking is exact because log probability and log volume are added in the same units.

### Basic 5 — Use absolute determinant value

**Goal.** Flip one axis and verify density stays valid, because a negative determinant reverses orientation but not probability volume. We build it in 2 steps.

### Basic 6 — Build one affine coupling layer

```python
y_b6, ld_b6 = coupling_forward(x_b6, flip=False)

```

▶ What you'll see: x0 is unchanged, while x1 moves by a nonlinear affine rule.

```python
plt.figure(figsize=(4, 3)); plt.scatter(x_b6[:,0], x_b6[:,1], s=80, label="x")
```

▶ What you'll see: x0 is unchanged, while x1 moves by a nonlinear affine rule.

👀 Takeaway: coupling layers are invertible because the transformed coordinate can be solved with a one-line affine inverse.

### Basic 7 — Invert the coupling layer

**Goal.** Undo the coupling transform exactly, because every flow layer must be reversible. We build it in 2 steps.

```python
x_orig_b7 = np.array([[0.2, 1.3], [1.1, -0.4], [-0.8, 0.7]])
y_b7, ld_b7 = coupling_forward(x_orig_b7, flip=False)
print("forward y:\n", np.round(y_b7, 3))
```

▶ What you'll see: reconstruction error is essentially zero.
