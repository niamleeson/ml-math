# 24.4 — Differential Evolution

Differential evolution (DE) is a continuous black-box optimizer that learns its step sizes from the population itself. Instead of asking for gradients, it mutates candidates by adding scaled differences between other candidates, mixes that mutant with the current target, and keeps the better vector.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build differential evolution one idea at a time. Run each cell in order and watch the figures: every mutation, crossover, and greedy replacement is visible. This walkthrough is self-contained and uses a `_w` suffix so it never clashes with the examples below.

```python
import numpy as np  # arrays, random numbers, and numerical checks.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for the walkthrough.
```

### 1. Continuous black-box optimization

DE is for problems where a candidate is a real-valued vector and the objective can be evaluated but not differentiated. We will minimize a two-dimensional bowl with ripples so the population has a landscape to explore.

```python
def obj_w(X):
    X = np.asarray(X, dtype=float)
    return (X[..., 0] - 1.0) ** 2 + (X[..., 1] + 0.5) ** 2 + 0.25 * np.sin(3 * X[..., 0]) ** 2

xs_w = np.linspace(-3, 3, 140)
ys_w = np.linspace(-3, 3, 140)
XX_w, YY_w = np.meshgrid(xs_w, ys_w)
ZZ_w = obj_w(np.stack([XX_w, YY_w], axis=-1))
best_grid_w = np.unravel_index(np.argmin(ZZ_w), ZZ_w.shape)
print("best grid point:", round(float(XX_w[best_grid_w]), 3), round(float(YY_w[best_grid_w]), 3))
assert ZZ_w[best_grid_w] < 0.2
plt.figure(figsize=(4.6, 3.8))
plt.contourf(XX_w, YY_w, ZZ_w, levels=28, cmap="viridis")
plt.colorbar(label="objective")
plt.scatter([XX_w[best_grid_w]], [YY_w[best_grid_w]], c="red", s=60, label="low region")
plt.title("1: a black-box objective surface")
plt.xlabel("x0")
plt.ylabel("x1")
plt.legend()
plt.show()
```
▶ What you'll see: a low basin near the red point, but DE only needs objective values at candidate locations.

*Why it's done this way:* black-box optimizers start from evaluations rather than gradients, so drawing the surface clarifies what the algorithm is trying to discover without analytic derivative information.

### 2. A population supplies the search scale

DE keeps many candidates at once. If they are spread out, their pairwise differences are large exploratory moves; after convergence, the same difference operation naturally becomes small and local.

```python
rng_w2 = np.random.default_rng(2)
pop_w2 = rng_w2.uniform(-2.8, 2.8, size=(12, 2))
fitness_w2 = obj_w(pop_w2)
spread_w2 = np.mean(np.linalg.norm(pop_w2 - pop_w2.mean(axis=0), axis=1))
print("population shape:", pop_w2.shape)
print("mean spread:", round(float(spread_w2), 3), "best fitness:", round(float(fitness_w2.min()), 3))
assert pop_w2.shape == (12, 2)
plt.figure(figsize=(4.6, 3.8))
plt.contour(XX_w, YY_w, ZZ_w, levels=18, cmap="gray")
plt.scatter(pop_w2[:, 0], pop_w2[:, 1], c=fitness_w2, cmap="plasma", s=70, edgecolor="black")
plt.colorbar(label="candidate fitness")
plt.title("2: population spread becomes step scale")
plt.xlabel("x0")
plt.ylabel("x1")
plt.show()
```
▶ What you'll see: candidates cover different parts of the contour map, so differences between them encode useful directions and distances.

*Why it's done this way:* the population is not just parallel guesses; it is the measuring stick from which DE constructs mutation steps.

### 3. Mutation by vector arithmetic: `rand/1`

For target vector `x_i`, DE/rand/1 chooses three distinct peers `a`, `b`, and `c`, then forms the mutant `v = a + F(b - c)`. The difference `b - c` provides both direction and scale.

```python
F_w3 = 0.7
a_w3 = np.array([0.8, -0.2])
b_w3 = np.array([2.2, 1.0])
c_w3 = np.array([-1.0, -0.8])
diff_w3 = b_w3 - c_w3
v_w3 = a_w3 + F_w3 * diff_w3
print("b-c:", np.round(diff_w3, 3), "mutant v:", np.round(v_w3, 3))
assert np.allclose(v_w3, [3.04, 1.06])
plt.figure(figsize=(4.8, 3.8))
plt.contour(XX_w, YY_w, ZZ_w, levels=18, cmap="gray")
plt.scatter([a_w3[0], b_w3[0], c_w3[0], v_w3[0]], [a_w3[1], b_w3[1], c_w3[1], v_w3[1]], c=["blue", "orange", "green", "red"], s=80)
for p_w3, name_w3 in [(a_w3, "a"), (b_w3, "b"), (c_w3, "c"), (v_w3, "v")]:
    plt.text(p_w3[0] + 0.05, p_w3[1] + 0.05, name_w3)
plt.quiver(c_w3[0], c_w3[1], diff_w3[0], diff_w3[1], angles="xy", scale_units="xy", scale=1, color="orange", label="b-c")
plt.quiver(a_w3[0], a_w3[1], F_w3 * diff_w3[0], F_w3 * diff_w3[1], angles="xy", scale_units="xy", scale=1, color="red", label="F(b-c)")
plt.xlim(-3, 3.4)
plt.ylim(-3, 3)
plt.title("3: DE/rand/1 mutation")
plt.legend()
plt.show()
```
▶ What you'll see: the orange difference vector is copied, scaled, and anchored at `a` to create the red mutant.

*Why it's done this way:* DE uses relative differences among candidates, so the mutation scale adapts to the current population instead of relying on a fixed Gaussian noise width.

### 4. Binomial crossover creates a trial

The mutant does not automatically replace the target. Binomial crossover copies each coordinate from the mutant with probability `CR`; at least one coordinate is forced to come from the mutant so the trial is genuinely new.

```python
x_w4 = np.array([-0.6, 1.4])
v_w4 = np.array([1.8, -0.2])
CR_w4 = 0.5
rng_w4 = np.random.default_rng(4)
mask_w4 = rng_w4.random(2) < CR_w4
mask_w4[rng_w4.integers(2)] = True
u_w4 = np.where(mask_w4, v_w4, x_w4)
print("crossover mask:", mask_w4.astype(int), "trial:", np.round(u_w4, 3))
assert np.any(mask_w4)
plt.figure(figsize=(4.8, 3.4))
plt.scatter([x_w4[0], v_w4[0], u_w4[0]], [x_w4[1], v_w4[1], u_w4[1]], c=["black", "red", "teal"], s=90)
for p_w4, name_w4 in [(x_w4, "target x"), (v_w4, "mutant v"), (u_w4, "trial u")]:
    plt.text(p_w4[0] + 0.04, p_w4[1] + 0.04, name_w4)
plt.plot([x_w4[0], u_w4[0]], [x_w4[1], u_w4[1]], "k--", alpha=0.5)
plt.plot([v_w4[0], u_w4[0]], [v_w4[1], u_w4[1]], "r--", alpha=0.5)
plt.xlim(-1.2, 2.4)
plt.ylim(-0.8, 1.8)
plt.title("4: trial mixes target and mutant coordinates")
plt.xlabel("x0")
plt.ylabel("x1")
plt.show()
```
▶ What you'll see: the trial lands by copying selected coordinates from the mutant and the rest from the target.

*Why it's done this way:* crossover lets DE change a subset of coordinates, which can be safer than replacing the whole target with a large mutant jump.

### 5. Greedy target-vs-trial selection

Selection is local: target `x_i` competes only with its own trial child `u`. For minimization, keep the trial if `f(u) <= f(x_i)`; otherwise keep the target.

```python
x_w5 = np.array([-1.2, 1.0])
u_w5 = np.array([0.9, -0.4])
fx_w5 = float(obj_w(x_w5))
fu_w5 = float(obj_w(u_w5))
winner_w5 = u_w5 if fu_w5 <= fx_w5 else x_w5
print("f(target):", round(fx_w5, 3), "f(trial):", round(fu_w5, 3), "winner:", np.round(winner_w5, 3))
assert fu_w5 < fx_w5
plt.figure(figsize=(4.6, 3.8))
plt.contourf(XX_w, YY_w, ZZ_w, levels=28, cmap="viridis")
plt.colorbar(label="objective")
plt.scatter([x_w5[0]], [x_w5[1]], c="white", s=90, edgecolor="black", label="target")
plt.scatter([u_w5[0]], [u_w5[1]], c="red", s=90, edgecolor="black", label="trial kept")
plt.plot([x_w5[0], u_w5[0]], [x_w5[1], u_w5[1]], "w--")
plt.title("5: greedy target-vs-trial replacement")
plt.xlabel("x0")
plt.ylabel("x1")
plt.legend()
plt.show()
```
▶ What you'll see: the lower-objective trial sits in a better contour region and replaces the target.

*Why it's done this way:* local greedy replacement gives monotone pressure without needing to rank the entire population after every child is created.

### 6. Diversity makes difference vectors meaningful

If the population collapses too early, `b - c` becomes tiny and mutation loses its exploratory power. A useful DE run balances contraction toward good regions with enough spread to keep proposing moves.

```python
wide_w6 = np.array([[-2.5, -2.0], [2.2, 1.7], [-1.8, 2.3], [1.4, -2.4], [0.2, 0.9]])
tight_w6 = np.array([[0.8, -0.4], [0.9, -0.45], [0.75, -0.5], [0.85, -0.35], [0.7, -0.55]])
wide_diffs_w6 = np.linalg.norm(wide_w6[1:] - wide_w6[:-1], axis=1)
tight_diffs_w6 = np.linalg.norm(tight_w6[1:] - tight_w6[:-1], axis=1)
print("mean wide difference:", round(float(wide_diffs_w6.mean()), 3))
print("mean tight difference:", round(float(tight_diffs_w6.mean()), 3))
assert wide_diffs_w6.mean() > tight_diffs_w6.mean()
plt.figure(figsize=(4.8, 3.8))
plt.contour(XX_w, YY_w, ZZ_w, levels=18, cmap="gray")
plt.scatter(wide_w6[:, 0], wide_w6[:, 1], c="orange", s=75, label="diverse")
plt.scatter(tight_w6[:, 0], tight_w6[:, 1], c="teal", s=75, label="collapsed")
plt.quiver(wide_w6[:-1, 0], wide_w6[:-1, 1], (wide_w6[1:] - wide_w6[:-1])[:, 0], (wide_w6[1:] - wide_w6[:-1])[:, 1], angles="xy", scale_units="xy", scale=1, color="orange", alpha=0.5)
plt.quiver(tight_w6[:-1, 0], tight_w6[:-1, 1], (tight_w6[1:] - tight_w6[:-1])[:, 0], (tight_w6[1:] - tight_w6[:-1])[:, 1], angles="xy", scale_units="xy", scale=1, color="teal", alpha=0.8)
plt.title("6: diversity controls difference-vector length")
plt.legend()
plt.show()
```
▶ What you'll see: broad populations create long arrows, while collapsed populations create barely visible arrows.

*Why it's done this way:* DE's mutation is relative, so maintaining diversity is necessary for nontrivial proposals.

### 7. A full DE loop tracks convergence

Putting mutation, crossover, and selection together gives the DE/rand/1/bin loop. The best fitness should improve over generations, while the population visibly contracts toward a good basin.

```python
def de_step_w(pop, F=0.7, CR=0.8, seed=7):
    rng = np.random.default_rng(seed)
    new = pop.copy()
    for i in range(len(pop)):
        choices = np.delete(np.arange(len(pop)), i)
        a_idx, b_idx, c_idx = rng.choice(choices, size=3, replace=False)
        mutant = pop[a_idx] + F * (pop[b_idx] - pop[c_idx])
        mutant = np.clip(mutant, -3, 3)
        mask = rng.random(pop.shape[1]) < CR
        mask[rng.integers(pop.shape[1])] = True
        trial = np.where(mask, mutant, pop[i])
        if obj_w(trial) <= obj_w(pop[i]):
            new[i] = trial
    return new

rng_w7 = np.random.default_rng(7)
pop_w7 = rng_w7.uniform(-3, 3, size=(24, 2))
history_w7 = []
first_pop_w7 = pop_w7.copy()
for gen_w7 in range(45):
    history_w7.append(float(np.min(obj_w(pop_w7))))
    pop_w7 = de_step_w(pop_w7, F=0.7, CR=0.8, seed=700 + gen_w7)
print("best start -> end:", round(history_w7[0], 3), "->", round(history_w7[-1], 4))
assert history_w7[-1] < history_w7[0]
fig, ax_w7 = plt.subplots(1, 2, figsize=(8, 3.4))
ax_w7[0].contour(XX_w, YY_w, ZZ_w, levels=18, cmap="gray")
ax_w7[0].scatter(first_pop_w7[:, 0], first_pop_w7[:, 1], c="orange", s=35, label="start")
ax_w7[0].scatter(pop_w7[:, 0], pop_w7[:, 1], c="teal", s=35, label="end")
ax_w7[0].set_title("population moves")
ax_w7[0].legend()
ax_w7[1].plot(history_w7, color="purple")
ax_w7[1].set_title("best fitness over generations")
ax_w7[1].set_xlabel("generation")
ax_w7[1].set_ylabel("best f")
plt.suptitle("7: full DE/rand/1/bin loop")
plt.show()
```
▶ What you'll see: the population shifts into a low contour region and the best-fitness curve decreases.

*Why it's done this way:* convergence curves reveal whether the greedy pressure is actually improving the best discovered solution.

### ✍️ Toy 1 · Objective values score candidate vectors

DE is black-box: it only compares objective values. Score four tiny 2-D candidates on a shifted bowl.

```python
import numpy as np                              # arrays and objective values.
import matplotlib.pyplot as plt                 # one picture per toy.

t1_rng = np.random.default_rng(0)               # seeded generator       # -> seed 0
t1_pop = np.array([[0.0, 0.0], [1.0, -1.0], [2.0, -1.0], [-1.0, 1.0]])  # candidates
t1_target = np.array([1.0, -1.0])               # optimum location       # -> [1, -1]
t1_diff = t1_pop - t1_target                    # displacements          # -> compare to optimum
t1_obj = np.sum(t1_diff ** 2, axis=1)           # objective values       # -> [2, 0, 1, 8]
t1_best = int(np.argmin(t1_obj))                # best index             # -> 1
print("population:", t1_pop.tolist())          # -> [[0,0], [1,-1], [2,-1], [-1,1]]
print("objective:", t1_obj.tolist())           # -> [2.0, 0.0, 1.0, 8.0]
print("best vector:", t1_pop[t1_best].tolist()) # -> [1.0, -1.0]
assert t1_best == 1                             # the optimum candidate has zero loss.

plt.figure(figsize=(4.6, 3.2))
t1_grid = np.linspace(-2.0, 3.0, 80)
t1_X, t1_Y = np.meshgrid(t1_grid, t1_grid)
t1_Z = (t1_X - 1.0) ** 2 + (t1_Y + 1.0) ** 2
plt.contour(t1_X, t1_Y, t1_Z, levels=14, cmap="viridis")
plt.scatter(t1_pop[:, 0], t1_pop[:, 1], c=t1_obj, cmap="magma", s=90, edgecolor="black")
plt.scatter([1.0], [-1.0], marker="*", s=140, color="crimson")
plt.xlabel("x0"); plt.ylabel("x1"); plt.title("Toy 1 · black-box scores"); plt.show()
```
▶ What you'll see: `[1,-1]` has objective `0` and sits at the star.

### ✍️ Toy 2 · Population differences set step scale

DE mutation uses differences between candidates. A wide population creates long difference vectors;
a collapsed population creates tiny ones.

```python
import numpy as np                              # arrays and vector norms.

t2_rng = np.random.default_rng(0)               # seeded generator       # -> seed 0
t2_wide = np.array([[-2.0, -1.0], [2.0, 1.0], [-1.0, 2.0], [1.0, -2.0]])  # diverse pop
t2_tight = np.array([[0.8, -0.9], [1.0, -1.0], [1.1, -0.8], [0.9, -1.1]]) # tight pop
t2_wide_steps = t2_wide[1:] - t2_wide[:-1]      # consecutive differences  # -> [[4,2],[-3,1],[2,-4]]
t2_tight_steps = t2_tight[1:] - t2_tight[:-1]   # consecutive differences  # -> [[0.2,-0.1],[0.1,0.2],[-0.2,-0.3]]
t2_wide_norms = np.linalg.norm(t2_wide_steps, axis=1)   # wide lengths      # -> [4.472, 3.162, 4.472]
t2_tight_norms = np.linalg.norm(t2_tight_steps, axis=1) # tight lengths     # -> [0.224, 0.224, 0.361]
t2_wide_mean = float(np.mean(t2_wide_norms))    # mean wide length       # -> 4.036
t2_tight_mean = float(np.mean(t2_tight_norms))  # mean tight length      # -> 0.269
print("wide lengths:", np.round(t2_wide_norms, 3).tolist())   # -> [4.472, 3.162, 4.472]
print("tight lengths:", np.round(t2_tight_norms, 3).tolist()) # -> [0.224, 0.224, 0.361]
print("mean length:", round(t2_wide_mean, 3), "vs", round(t2_tight_mean, 3))  # -> 4.036 vs 0.269
assert t2_wide_mean > t2_tight_mean             # diversity supplies bigger mutation steps.

plt.figure(figsize=(4.8, 3.2))
plt.scatter(t2_wide[:, 0], t2_wide[:, 1], s=80, color="orange", label="wide")
plt.scatter(t2_tight[:, 0], t2_tight[:, 1], s=80, color="teal", label="tight")
plt.quiver(t2_wide[:-1, 0], t2_wide[:-1, 1], t2_wide_steps[:, 0], t2_wide_steps[:, 1], angles="xy", scale_units="xy", scale=1, color="orange", alpha=0.55)
plt.quiver(t2_tight[:-1, 0], t2_tight[:-1, 1], t2_tight_steps[:, 0], t2_tight_steps[:, 1], angles="xy", scale_units="xy", scale=1, color="teal", alpha=0.9)
plt.axis("equal"); plt.legend(); plt.title("Toy 2 · diversity controls difference length"); plt.show()
```
▶ What you'll see: orange arrows are long, while teal arrows near the optimum are tiny.

### ✍️ Toy 3 · `rand/1` mutation copies a scaled difference

For DE/rand/1, the mutant is `a + F(b-c)`. Trace the difference, scale, and anchor operation.

```python
import numpy as np                              # arrays and vector arithmetic.

t3_rng = np.random.default_rng(0)               # seeded generator       # -> seed 0
t3_a = np.array([0.0, -1.0])                    # anchor vector a        # -> [0, -1]
t3_b = np.array([2.0, 1.0])                     # peer b                 # -> [2, 1]
t3_c = np.array([-1.0, -2.0])                   # peer c                 # -> [-1, -2]
t3_F = 0.5                                      # scale factor           # -> 0.5
t3_diff = t3_b - t3_c                           # difference b-c         # -> [3, 3]
t3_scaled = t3_F * t3_diff                      # scaled difference      # -> [1.5, 1.5]
t3_mutant = t3_a + t3_scaled                    # mutant vector          # -> [1.5, 0.5]
print("b-c:", t3_diff.tolist())                # -> [3.0, 3.0]
print("F(b-c):", t3_scaled.tolist())           # -> [1.5, 1.5]
print("mutant:", t3_mutant.tolist())           # -> [1.5, 0.5]
assert np.allclose(t3_mutant, [1.5, 0.5])       # arithmetic matches DE/rand/1.

plt.figure(figsize=(4.8, 3.2))
plt.scatter([t3_a[0], t3_b[0], t3_c[0], t3_mutant[0]], [t3_a[1], t3_b[1], t3_c[1], t3_mutant[1]], s=90, color=["blue", "orange", "green", "crimson"])
plt.quiver(t3_c[0], t3_c[1], t3_diff[0], t3_diff[1], angles="xy", scale_units="xy", scale=1, color="orange", label="b-c")
plt.quiver(t3_a[0], t3_a[1], t3_scaled[0], t3_scaled[1], angles="xy", scale_units="xy", scale=1, color="crimson", label="F(b-c)")
plt.axis("equal"); plt.legend(); plt.title("Toy 3 · mutant = a + F(b-c)"); plt.show()
```
▶ What you'll see: the same direction is copied from `c→b`, scaled, and anchored at `a`.

### ✍️ Toy 4 · Binomial crossover mixes coordinates

Crossover chooses which coordinates come from the mutant, then forces at least one mutant coordinate
so the trial is not identical to the target.

```python
import numpy as np                              # arrays and Bernoulli masks.

t4_rng = np.random.default_rng(0)               # seeded generator       # -> seed 0
t4_target = np.array([0.0, 0.0, 2.0])           # target vector          # -> [0, 0, 2]
t4_mutant = np.array([1.0, -1.0, 3.0])          # mutant vector          # -> [1, -1, 3]
t4_CR = 0.2                                     # crossover probability # -> 0.2
t4_draws = t4_rng.random(3)                     # uniform draws          # -> [0.637, 0.27, 0.041]
t4_mask_before = t4_draws < t4_CR               # raw mask               # -> [False, False, True]
t4_force = int(t4_rng.integers(3))              # forced coordinate      # -> 0
t4_mask = t4_mask_before.copy()                 # final mask copy        # -> [False, False, True]
t4_mask[t4_force] = True                        # force one mutant gene  # -> [True, False, True]
t4_trial = np.where(t4_mask, t4_mutant, t4_target)  # trial vector        # -> [1, 0, 3]
print("draws:", np.round(t4_draws, 3).tolist()) # -> [0.637, 0.27, 0.041]
print("mask before force:", t4_mask_before.astype(int).tolist()) # -> [0, 0, 1]
print("forced coordinate:", t4_force)          # -> 0
print("final mask:", t4_mask.astype(int).tolist())  # -> [1, 0, 1]
print("trial:", t4_trial.tolist())             # -> [1.0, 0.0, 3.0]
assert np.any(t4_mask) and np.allclose(t4_trial, [1.0, 0.0, 3.0])  # trial changed.

plt.figure(figsize=(4.8, 2.8))
t4_idx = np.arange(3)
plt.bar(t4_idx - 0.2, t4_target, width=0.2, label="target", color="gray")
plt.bar(t4_idx, t4_mutant, width=0.2, label="mutant", color="crimson")
plt.bar(t4_idx + 0.2, t4_trial, width=0.2, label="trial", color="teal")
plt.xticks(t4_idx); plt.xlabel("coordinate"); plt.legend()
plt.title("Toy 4 · crossover chooses coordinates"); plt.show()
```
▶ What you'll see: coordinates 0 and 2 come from the mutant, while coordinate 1 stays from the target.

### ✍️ Toy 5 · Greedy selection keeps the lower objective

The trial only replaces its own target if it is no worse. Here the trial is much closer to the
optimum, so it survives.

```python
import numpy as np                              # arrays and objective comparison.

t5_rng = np.random.default_rng(0)               # seeded generator       # -> seed 0
t5_optimum = np.array([1.0, -1.0])              # objective minimum      # -> [1, -1]
t5_target = np.array([0.0, 1.0])                # current target         # -> [0, 1]
t5_trial = np.array([1.0, -0.5])                # proposed trial         # -> [1, -0.5]
t5_target_diff = t5_target - t5_optimum         # target displacement    # -> [-1, 2]
t5_trial_diff = t5_trial - t5_optimum           # trial displacement     # -> [0, 0.5]
t5_f_target = float(np.sum(t5_target_diff ** 2)) # target objective      # -> 5.0
t5_f_trial = float(np.sum(t5_trial_diff ** 2))   # trial objective       # -> 0.25
t5_winner = t5_trial if t5_f_trial <= t5_f_target else t5_target  # selected vector
print("f(target):", t5_f_target)               # -> 5.0
print("f(trial):", t5_f_trial)                 # -> 0.25
```

## 🛠️ Setup

```python
import numpy as np  # NumPy supplies arrays, vector arithmetic, random sampling, and assertions.
import matplotlib.pyplot as plt  # Matplotlib supplies contour, quiver, scatter, and convergence plots.
np.random.seed(0)  # Keep examples reproducible.

def sphere_shifted(X):  # Define a smooth two-dimensional minimization objective used in many examples.
    X = np.asarray(X, dtype=float)  # Accept either one vector or a batch of vectors.
    return (X[..., 0] - 1.0) ** 2 + (X[..., 1] + 0.5) ** 2  # Return squared distance to the optimum (1, -0.5).

def rippled_objective(X):  # Define a slightly harder black-box objective with a ripple in x0.
    X = np.asarray(X, dtype=float)  # Convert inputs so vectorized arithmetic is predictable.
    return sphere_shifted(X) + 0.25 * np.sin(3 * X[..., 0]) ** 2  # Add nonconvex-looking local ripples.

def make_grid(bounds=(-3, 3), n=120):  # Create a reusable contour grid for 2-D visualizations.
    xs = np.linspace(bounds[0], bounds[1], n)  # Grid coordinates for x0.
    ys = np.linspace(bounds[0], bounds[1], n)  # Grid coordinates for x1.
    XX, YY = np.meshgrid(xs, ys)  # Form a rectangular mesh.
    ZZ = rippled_objective(np.stack([XX, YY], axis=-1))  # Evaluate the objective on the grid.
    return XX, YY, ZZ  # Return arrays ready for contour plotting.

def de_rand1_bin_step(pop, objective, F=0.7, CR=0.8, bounds=(-3, 3), rng=None):  # Implement one DE/rand/1/bin generation.
    rng = np.random.default_rng(0) if rng is None else rng  # Use a local generator when none is supplied.
    pop = np.asarray(pop, dtype=float)  # Ensure the population is a float array.
    new_pop = pop.copy()  # Store accepted targets or trials here.
    trials = np.zeros_like(pop)  # Store all trial vectors for visualization and debugging.
    mutants = np.zeros_like(pop)  # Store all mutant vectors for visualization and debugging.
    accepted = np.zeros(len(pop), dtype=bool)  # Track which trials replaced their targets.
    for i in range(len(pop)):  # Build and test one trial for every target vector.
        choices = np.delete(np.arange(len(pop)), i)  # Exclude the target from parent sampling.
        a, b, c = rng.choice(choices, size=3, replace=False)  # Pick distinct random parents for DE/rand/1.
        mutant = pop[a] + F * (pop[b] - pop[c])  # Create the mutant by scaled population difference.
        mutant = np.clip(mutant, bounds[0], bounds[1])  # Keep the demo inside the plotted box.
        mask = rng.random(pop.shape[1]) < CR  # Decide which coordinates come from the mutant.
        mask[rng.integers(pop.shape[1])] = True  # Force at least one mutant coordinate.
        trial = np.where(mask, mutant, pop[i])  # Create the binomial-crossover trial.
        mutants[i] = mutant  # Save mutant for inspection.
        trials[i] = trial  # Save trial for inspection.
        if objective(trial) <= objective(pop[i]):  # Greedy minimization replacement.
            new_pop[i] = trial  # Accept the trial child.
            accepted[i] = True  # Mark the successful replacement.
    return new_pop, trials, mutants, accepted  # Return enough state to explain the generation.

def run_de(objective, pop_size=24, generations=40, F=0.7, CR=0.8, bounds=(-3, 3), seed=0):  # Run a compact DE optimizer from scratch.
    rng = np.random.default_rng(seed)  # Local reproducible randomness.
    pop = rng.uniform(bounds[0], bounds[1], size=(pop_size, 2))  # Initialize a 2-D population uniformly.
    history = []  # Record best fitness values.
    spreads = []  # Record population spread values.
    for _ in range(generations):  # Repeat generations.
        history.append(float(np.min(objective(pop))))  # Store current best objective.
        spreads.append(float(np.mean(np.linalg.norm(pop - pop.mean(axis=0), axis=1))))  # Store diversity/spread.
        pop, _, _, _ = de_rand1_bin_step(pop, objective, F=F, CR=CR, bounds=bounds, rng=rng)  # Advance one generation.
    history.append(float(np.min(objective(pop))))  # Store final best objective.
    spreads.append(float(np.mean(np.linalg.norm(pop - pop.mean(axis=0), axis=1))))  # Store final spread.
    return pop, np.array(history), np.array(spreads)  # Return final population and diagnostics.
```
