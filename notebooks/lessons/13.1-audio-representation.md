# 13.1 — Audio Representation

Audio representation turns a pressure waveform into numerical evidence that ML models can use: samples describe pressure over time, Fourier analysis separates mixed waves into frequencies, STFTs track how frequencies change locally, and mel/MFCC features compress spectral shape into compact perceptual coordinates.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build audio representation one idea at a time. Run each cell in order and read the printed intermediate values — sampling, Fourier bins, windows, spectrograms, mel bands, logs, and MFCC-like cosine projections are all derived with NumPy. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, vectorized math, and matrix multiplication for audio features.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for synthetic noise and examples.
```

### 1. Sampling: pressure over time becomes a vector

A microphone waveform is a function of time, but a computer stores samples. At sample rate $f_s$, sample index $n$ corresponds to time $t=n/f_s$. For a 440 Hz sine wave sampled at 8000 Hz, the array is $x[n]=\sin(2\pi\,440\,n/8000)$. The important habit is to read every index through the sample rate: the same index spacing means a different physical duration when $f_s$ changes.

```python
fs_w = 8000  # samples per second.
dur_w = 0.01  # 10 milliseconds.
n_w = np.arange(int(fs_w * dur_w))  # sample indices 0..79.
t_w = n_w / fs_w  # convert indices to seconds.
x_w = np.sin(2 * np.pi * 440 * t_w)  # synthesize a 440 Hz tone.
print("samples:", len(x_w), "duration seconds:", round(float(t_w[-1] + 1 / fs_w), 4))
print("first five samples:", np.round(x_w[:5], 3))
assert np.allclose(np.round(x_w[:5], 3), [0.000, 0.339, 0.637, 0.861, 0.982])
```
▶ What you'll see: 80 samples cover 0.01 seconds, and the first samples match the lesson's 440 Hz waveform numbers.

```python
plt.figure(figsize=(5, 3))
plt.plot(t_w * 1000, x_w, marker="o", markersize=3, color="teal")
plt.title("1: 440 Hz waveform sampled at 8000 Hz")
plt.xlabel("time (ms)")
plt.ylabel("amplitude")
plt.show()
```
▶ What you'll see: a smooth-looking oscillation drawn from discrete dots; the dots are the only values the computer actually stores.

*Why it's done this way:* Sampling replaces a continuous pressure curve by a vector because ML models consume arrays. The rate $f_s$ is the conversion key: $n/f_s$ gives time, and $f/f_s$ gives cycles per sample. If the sampling rate is too low, different continuous frequencies can produce the same discrete pattern, so representation begins by choosing enough samples per second for the frequencies we care about.

### 2. Energy and phase: strength without caring where the wave starts

Two signals can have the same perceived loudness even if one starts at a crest and another starts at a zero crossing. Mean squared energy summarizes signal strength while ignoring the phase offset. This is why many audio features look at magnitude or power rather than raw sample signs.

```python
phase_w = np.pi / 2  # shift the same sine wave by a quarter cycle.
y_w = np.sin(2 * np.pi * 440 * t_w + phase_w)
energy_x_w = float(np.mean(x_w ** 2))
energy_y_w = float(np.mean(y_w ** 2))
print("energy original:", round(energy_x_w, 3), "energy shifted:", round(energy_y_w, 3))
assert round(energy_x_w, 3) == 0.506
```
▶ What you'll see: the original 10 ms segment has mean squared energy about 0.506; a phase-shifted segment is similarly strong.

```python
plt.figure(figsize=(5, 3))
plt.plot(t_w * 1000, x_w, label="phase 0", color="teal")
plt.plot(t_w * 1000, y_w, label="phase π/2", color="orange", alpha=0.8)
plt.title("2: phase changes samples, not overall strength")
plt.xlabel("time (ms)")
plt.ylabel("amplitude")
plt.legend()
plt.show()
```
▶ What you'll see: the curves are shifted relative to each other, but both have comparable amplitude and energy.

*Why it's done this way:* Raw waveforms are phase-sensitive: a tiny time shift changes many sample values. Energy squares the samples, so positive and negative pressure deviations both count as strength. Spectrograms and MFCCs inherit this idea by keeping magnitude or power, because many recognition tasks care more about which frequencies are present than exactly where the sinusoid's phase began.

### 3. DFT: matching the waveform against frequency templates

The discrete Fourier transform asks how much the frame matches each complex sinusoid. For a frame of length $N$, bin $k$ corresponds to $k f_s/N$ Hz and computes $X[k]=\sum_{n=0}^{N-1}x[n]e^{-j2\pi kn/N}$. We build the DFT matrix directly so the calculation is visible: every row is one frequency template, and multiplying by the waveform returns all frequency coefficients.

```python
N_w = 256
nN_w = np.arange(N_w)
tone_w = np.sin(2 * np.pi * 440 * nN_w / fs_w)
hann_w = 0.5 - 0.5 * np.cos(2 * np.pi * nN_w / (N_w - 1))
frame_w = tone_w * hann_w
k_w = np.arange(N_w)[:, None]
W_w = np.exp(-2j * np.pi * k_w * nN_w / N_w)  # DFT matrix from the formula.
X_w = W_w @ frame_w
mag_w = np.abs(X_w[: N_w // 2 + 1])
freqs_w = np.arange(N_w // 2 + 1) * fs_w / N_w
peak_bin_w = int(np.argmax(mag_w))
print("nearest bin:", round(440 * N_w / fs_w), "peak bin:", peak_bin_w, "bin Hz:", freqs_w[peak_bin_w])
print("peak magnitude:", round(float(mag_w[peak_bin_w]), 3))
assert peak_bin_w == 14 and round(float(freqs_w[peak_bin_w]), 1) == 437.5
assert abs(round(float(mag_w[peak_bin_w]), 3) - 63.489) < 0.02
```
▶ What you'll see: the strongest bin is 14, whose frequency is 437.5 Hz, close to the 440 Hz tone.

```python
plt.figure(figsize=(5, 3))
plt.plot(freqs_w[:45], mag_w[:45], color="purple")
plt.axvline(440, color="black", linestyle="--", label="true 440 Hz")
plt.scatter([freqs_w[peak_bin_w]], [mag_w[peak_bin_w]], color="red", label="DFT peak")
plt.title("3: DFT magnitude spectrum")
plt.xlabel("frequency (Hz)")
plt.ylabel("magnitude")
plt.legend()
plt.show()
```
▶ What you'll see: a large peak near 440 Hz rather than at every frequency; windowing spreads a little energy to neighboring bins.

*Why it's done this way:* The DFT is a bank of dot products with sinusoidal templates. A frequency that lines up with the waveform adds coherently and produces a large magnitude; mismatched frequencies cancel. Bin spacing is $f_s/N$, so finite frames quantize frequency evidence — 440 Hz cannot be represented exactly with 31.25 Hz spacing, so the nearest bin is 437.5 Hz.

### 4. STFT: local spectra for sounds that change over time

One Fourier transform over a whole recording would assume the same frequencies are present for the entire signal. Speech and music are nonstationary, so we slice the waveform into short overlapping frames, multiply by a window, and compute one spectrum per frame. The result is a spectrogram: frequency on one axis, time frame on the other, color as energy.

```python
dur2_w = 0.6
t2_w = np.arange(int(fs_w * dur2_w)) / fs_w
chirp_w = np.sin(2 * np.pi * (220 * t2_w + (880 - 220) / (2 * dur2_w) * t2_w ** 2))
Nstft_w, hop_w = 256, 64
window_w = 0.5 - 0.5 * np.cos(2 * np.pi * np.arange(Nstft_w) / (Nstft_w - 1))
Wstft_w = np.exp(-2j * np.pi * np.arange(Nstft_w)[:, None] * np.arange(Nstft_w) / Nstft_w)
frames_w = []
for start_w in range(0, len(chirp_w) - Nstft_w + 1, hop_w):
    frames_w.append(np.abs((Wstft_w @ (chirp_w[start_w:start_w + Nstft_w] * window_w))[:Nstft_w // 2 + 1]) ** 2)
S_w = np.array(frames_w).T
print("spectrogram shape (freq bins, frames):", S_w.shape)
assert S_w.shape[0] == 129 and S_w.shape[1] == 72
```
▶ What you'll see: a matrix with 129 positive-frequency bins across 72 local time frames.

```python
plt.figure(figsize=(6, 3.5))
plt.imshow(10 * np.log10(S_w + 1e-8), origin="lower", aspect="auto", cmap="magma",
           extent=[0, dur2_w, 0, fs_w / 2])
plt.colorbar(label="power (dB)")
plt.title("4: STFT spectrogram of an upward chirp")
plt.xlabel("time (s)")
plt.ylabel("frequency (Hz)")
plt.show()
```
▶ What you'll see: a bright ridge climbs from low to high frequency; that diagonal is the chirp's changing pitch.

*Why it's done this way:* The STFT makes a controlled approximation: each short frame is treated as locally stable even though the full recording is not. The window reduces edge discontinuities, and the hop controls time resolution. Short windows track onsets better but blur frequencies; long windows sharpen frequencies but smear fast changes.

### 5. Mel filterbanks: smooth frequency evidence on a perceptual scale

Raw FFT bins are narrow and linearly spaced, while hearing has coarser resolution at high frequencies. A mel filterbank groups neighboring FFT bins with triangular weights after mapping Hz to mel. We build those triangles manually: each band rises from zero to a center frequency, then falls back to zero.

```python
def hz_to_mel_w(hz):
    return 2595 * np.log10(1 + hz / 700)

def mel_to_hz_w(mel):
    return 700 * (10 ** (mel / 2595) - 1)

num_bands_w = 4
mel_edges_w = np.linspace(hz_to_mel_w(0), hz_to_mel_w(fs_w / 2), num_bands_w + 2)
hz_edges_w = mel_to_hz_w(mel_edges_w)
centers_w = hz_edges_w[1:-1]
filters_w = np.zeros((num_bands_w, len(freqs_w)))
for b_w in range(num_bands_w):
    left_w, center_w, right_w = hz_edges_w[b_w], hz_edges_w[b_w + 1], hz_edges_w[b_w + 2]
    for i_w, f_w in enumerate(freqs_w):
        if left_w < f_w <= center_w:
            filters_w[b_w, i_w] = (f_w - left_w) / (center_w - left_w)
        elif center_w < f_w < right_w:
            filters_w[b_w, i_w] = (right_w - f_w) / (right_w - center_w)
print("mel-like centers Hz:", np.round(centers_w, 1))
assert np.allclose(np.round(centers_w, 1), [324.5, 799.3, 1494.3, 2511.4])
```
▶ What you'll see: four band centers get farther apart in Hz, reflecting the mel scale's nonlinear spacing.

```python
band_energy_w = filters_w @ (mag_w ** 2)
print("band energies:", np.round(band_energy_w, 3))
assert np.allclose(np.round(band_energy_w, 3)[:2], [4631.027, 1488.973], atol=0.5)
plt.figure(figsize=(5, 3))
for b_w in range(num_bands_w):
    plt.plot(freqs_w, filters_w[b_w], label=f"band {b_w}")
plt.title("5: triangular mel-style filters")
plt.xlabel("frequency (Hz)")
plt.ylabel("weight")
plt.xlim(0, 4000)
plt.legend()
plt.show()
```
▶ What you'll see: overlapping triangles cover the spectrum; the 440 Hz tone mostly activates the first two low-frequency bands.

*Why it's done this way:* A filterbank replaces many fragile FFT bins with smoother band energies. The triangular overlap prevents hard boundaries: a tone near a band edge contributes partly to both neighboring bands. Mel spacing spends more bands where human hearing is finer and fewer where it is coarser, giving a compact perceptual summary.

### 6. Log energies and MFCC-like cosine projection

Filterbank energies are positive and often span huge ranges. Taking a log turns multiplicative loudness changes into additive shifts and prevents large bands from dominating everything. MFCCs then apply a cosine projection to the log energies, keeping coefficients that summarize the spectral envelope.

```python
floor_w = 1e-7
log_energy_w = np.log(np.maximum(band_energy_w, floor_w))
B_w = len(log_energy_w)
C_w = np.zeros((B_w, B_w))
for c_w in range(B_w):
    for b_w in range(B_w):
        C_w[c_w, b_w] = np.cos(np.pi * c_w * (b_w + 0.5) / B_w)
coeff_w = C_w @ log_energy_w
print("log energies:", np.round(log_energy_w, 3))
print("MFCC-like coeffs:", np.round(coeff_w, 3))
assert np.allclose(np.round(log_energy_w, 3), [8.441, 7.306, -11.513, -16.118], atol=0.7)
```
▶ What you'll see: empty high-frequency bands become large negative log values because of the floor, and the cosine projection turns four logs into four coefficients.

```python
plt.figure(figsize=(6, 3))
plt.subplot(1, 2, 1)
plt.bar(range(B_w), log_energy_w, color="teal")
plt.title("log band energies")
plt.xlabel("band")
plt.subplot(1, 2, 2)
plt.bar(range(B_w), coeff_w, color="orange")
plt.title("MFCC-like coefficients")
plt.xlabel("coefficient")
plt.tight_layout()
plt.show()
```
▶ What you'll see: the log-energy vector says where spectral power lives; the coefficient vector repackages that shape into a compact basis.

*Why it's done this way:* Logs make ratios easier to model: doubling all energies adds a constant rather than multiplying the vector. The cosine projection acts like a smooth-change basis over frequency bands, so early coefficients describe broad spectral envelope rather than individual bins. The floor is essential because $\log(0)$ is undefined.

### ✍️ Toy 1 · Sampling maps indices to time

A sample rate is the conversion rule from integer index `n` to physical time `t=n/fs`. With only 8 samples, you can see one full 1 Hz cycle.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)
t1_fs = 8
t1_freq = 1
t1_n = np.arange(8)
t1_t = t1_n / t1_fs
t1_x = np.sin(2 * np.pi * t1_freq * t1_t)
t1_x_show = np.round(t1_x, 3)
print("sample rate:", t1_fs)  # -> 8
print("frequency:", t1_freq)  # -> 1
print("sample indices:", t1_n.tolist())  # -> [0, 1, 2, 3, 4, 5, 6, 7]
print("times seconds:", np.round(t1_t, 3).tolist())  # -> [0.0, 0.125, 0.25, 0.375, 0.5, 0.625, 0.75, 0.875]
print("samples:", t1_x_show.tolist())  # -> [0.0, 0.707, 1.0, 0.707, 0.0, -0.707, -1.0, -0.707]
assert np.allclose(t1_x_show, [0.0, 0.707, 1.0, 0.707, 0.0, -0.707, -1.0, -0.707])

plt.figure(figsize=(4.8, 2.8))
plt.plot(t1_t, t1_x, marker="o", color="teal")

plt.ylabel("pressure")

```
▶ What you'll see: eight dots trace one sine-wave cycle, with index spacing converted into seconds.

### ✍️ Toy 2 · Phase shift preserves mean squared energy

Energy squares the samples before averaging, so a quarter-cycle phase shift changes the signs and positions but keeps the strength.

```python
import numpy as np

t2_rng = np.random.default_rng(0)
t2_n = np.arange(8)
t2_t = t2_n / 8
t2_x = np.sin(2 * np.pi * t2_t)
t2_y = np.sin(2 * np.pi * t2_t + np.pi / 2)
t2_x_show = np.round(t2_x, 3)
t2_y_show = np.round(t2_y, 3)
t2_y_show = np.where(np.abs(t2_y_show) < 1e-12, 0.0, t2_y_show)
t2_x2 = t2_x ** 2
t2_y2 = t2_y ** 2
t2_energy_x = float(np.mean(t2_x2))
t2_energy_y = float(np.mean(t2_y2))
print("phase-0 samples:", t2_x_show.tolist())  # -> [0.0, 0.707, 1.0, 0.707, 0.0, -0.707, -1.0, -0.707]
print("phase-shifted samples:", t2_y_show.tolist())  # -> [1.0, 0.707, 0.0, -0.707, -1.0, -0.707, 0.0, 0.707]
print("squared phase-0:", np.round(t2_x2, 3).tolist())  # -> [0.0, 0.5, 1.0, 0.5, 0.0, 0.5, 1.0, 0.5]
print("squared shifted:", np.round(t2_y2, 3).tolist())  # -> [1.0, 0.5, 0.0, 0.5, 1.0, 0.5, 0.0, 0.5]
print("mean squared energies:", round(t2_energy_x, 3), round(t2_energy_y, 3))  # -> 0.5 0.5
assert round(t2_energy_x, 3) == round(t2_energy_y, 3) == 0.5

plt.figure(figsize=(4.8, 2.8))
plt.plot(t2_t, t2_x, marker="o", label="phase 0")
plt.plot(t2_t, t2_y, marker="s", label="phase π/2")
plt.xlabel("time (s)")
plt.ylabel("pressure")
plt.title("Toy 2 · shifted waves, same energy")
plt.legend()
plt.show()
```
▶ What you'll see: the two waves are shifted, but their squared averages both equal `0.5`.

### ✍️ Toy 3 · DFT bin matching finds a tone

The DFT asks which frequency template adds up coherently. A 2-cycle cosine in 8 samples lands exactly on bin 2.

```python
import numpy as np

t3_rng = np.random.default_rng(0)
t3_fs = 8
t3_N = 8
t3_n = np.arange(t3_N)
t3_x = np.cos(2 * np.pi * 2 * t3_n / t3_N)
```

### ✍️ Toy 4 · STFT slices time into local spectra

An STFT repeats the same frame-and-FFT mechanic at several start positions. The hop controls where those local spectra are measured.

```python
import numpy as np

t4_rng = np.random.default_rng(0)
t4_x = np.array([0.0, 1.0, 0.0, -1.0, 0.0, 2.0, 0.0, -2.0, 0.0, 1.0, 0.0, -1.0])
t4_frame_len = 4
t4_hop = 2
t4_starts = np.arange(0, len(t4_x) - t4_frame_len + 1, t4_hop)
t4_frames = np.stack([t4_x[t4_start:t4_start + t4_frame_len] for t4_start in t4_starts])
t4_window = np.hanning(t4_frame_len)
t4_windowed = t4_frames * t4_window
t4_power = np.abs(np.fft.rfft(t4_windowed, axis=1)) ** 2
t4_windowed_show = np.round(t4_windowed, 3)
t4_windowed_show = np.where(np.abs(t4_windowed_show) < 1e-12, 0.0, t4_windowed_show)
print("signal:", t4_x.tolist())  # -> [0.0, 1.0, 0.0, -1.0, 0.0, 2.0, 0.0, -2.0, 0.0, 1.0, 0.0, -1.0]
print("frame starts:", t4_starts.tolist())  # -> [0, 2, 4, 6, 8]
print("frames:", t4_frames.tolist())  # -> [[0.0, 1.0, 0.0, -1.0], [0.0, -1.0, 0.0, 2.0], [0.0, 2.0, 0.0, -2.0], [0.0, -2.0, 0.0, 1.0], [0.0, 1.0, 0.0, -1.0]]
print("Hann window:", np.round(t4_window, 3).tolist())  # -> [0.0, 0.75, 0.75, 0.0]
print("windowed frames:", t4_windowed_show.tolist())  # -> [[0.0, 0.75, 0.0, 0.0], [0.0, -0.75, 0.0, 0.0], [0.0, 1.5, 0.0, 0.0], [0.0, -1.5, 0.0, 0.0], [0.0, 0.75, 0.0, 0.0]]
print("power spectra:", np.round(t4_power, 3).tolist())  # -> [[0.562, 0.562, 0.562], [0.562, 0.562, 0.562], [2.25, 2.25, 2.25], [2.25, 2.25, 2.25], [0.562, 0.562, 0.562]]
assert t4_power.T.shape == (3, 5)

plt.figure(figsize=(4.8, 2.8))
plt.imshow(t4_power.T, origin="lower", aspect="auto", cmap="magma")
plt.colorbar(label="power")
plt.xlabel("frame index")
plt.ylabel("DFT bin")
plt.title("Toy 4 · local spectra over time")
plt.show()
```
▶ What you'll see: the middle frames have larger power because that part of the signal has larger amplitude.

### ✍️ Toy 5 · Mel triangles turn bins into band energies

A triangular filterbank weights nearby FFT bins instead of using hard frequency cuts. Each band energy is a weighted sum of powers.

```python
import numpy as np

t5_rng = np.random.default_rng(0)
t5_freqs = np.array([0.0, 100.0, 200.0, 300.0, 400.0])
t5_edges = np.array([0.0, 100.0, 250.0, 400.0])
t5_filters = np.zeros((2, len(t5_freqs)))
for t5_b in range(2):
    t5_left = t5_edges[t5_b]
    t5_center = t5_edges[t5_b + 1]
    t5_right = t5_edges[t5_b + 2]
    for t5_i, t5_f in enumerate(t5_freqs):
        if t5_left < t5_f <= t5_center:
            t5_filters[t5_b, t5_i] = (t5_f - t5_left) / (t5_center - t5_left)
        elif t5_center < t5_f < t5_right:
            t5_filters[t5_b, t5_i] = (t5_right - t5_f) / (t5_right - t5_center)
t5_power = np.array([0.0, 4.0, 9.0, 1.0, 0.0])
t5_band_energy = t5_filters @ t5_power
print("frequency bins:", t5_freqs.astype(int).tolist())  # -> [0, 100, 200, 300, 400]
print("triangle edges:", t5_edges.astype(int).tolist())  # -> [0, 100, 250, 400]
print("filter weights:", np.round(t5_filters, 3).tolist())  # -> [[0.0, 1.0, 0.333, 0.0, 0.0], [0.0, 0.0, 0.667, 0.667, 0.0]]
print("bin powers:", t5_power.tolist())  # -> [0.0, 4.0, 9.0, 1.0, 0.0]
print("band energies:", np.round(t5_band_energy, 3).tolist())  # -> [7.0, 6.667]
assert np.allclose(np.round(t5_band_energy, 3), [7.0, 6.667])

plt.figure(figsize=(4.8, 2.8))
plt.plot(t5_freqs, t5_filters[0], marker="o", label="band 0")
plt.plot(t5_freqs, t5_filters[1], marker="s", label="band 1")
plt.xlabel("frequency (Hz)")
plt.ylabel("weight")
plt.title("Toy 5 · overlapping triangular bands")
plt.legend()
plt.show()
```
▶ What you'll see: the 200 Hz bin contributes partly to both bands, smoothing the spectral evidence.

### ✍️ Toy 6 · Safe logs compress band energy

Log features need a floor because `log(0)` is undefined. After flooring, multiplicative energy changes become additive log differences.

```python
import numpy as np

t6_rng = np.random.default_rng(0)
t6_energy = np.array([1.0, 10.0, 0.0, 100.0])
t6_floor = 0.1

```
▶ What you'll see: the zero band becomes a finite negative log value instead of breaking the feature vector.

### ✍️ Toy 7 · Cosine projection makes MFCC-like coefficients

```python
    left_e3, center_e3, right_e3 = edges_e3[b_e3], edges_e3[b_e3 + 1], edges_e3[b_e3 + 2]  # Read triangle edges.
```

### Advanced 4 — Spectral envelope versus pitch

**Goal.** Compare two signals with the same broad envelope but different fine pitch, because MFCC-style compression emphasizes envelope over individual harmonics. We build it in 4 steps.

```python
fs_a4 = 8000  # Set sample rate.
N_a4 = 256  # Set frame length.
n_a4 = np.arange(N_a4)  # Create sample indices.
x1_a4 = np.sin(2 * np.pi * 200 * n_a4 / fs_a4) + 0.5 * np.sin(2 * np.pi * 400 * n_a4 / fs_a4)  # First harmonic stack.
x2_a4 = np.sin(2 * np.pi * 240 * n_a4 / fs_a4) + 0.5 * np.sin(2 * np.pi * 480 * n_a4 / fs_a4)  # Shifted pitch stack.
print("signals built with fundamentals 200 and 240 Hz")  # Confirm setup.
```

```python
w_a4 = 0.5 - 0.5 * np.cos(2 * np.pi * n_a4 / (N_a4 - 1))  # Build Hann window.
W_a4 = np.exp(-2j * np.pi * np.arange(N_a4)[:, None] * n_a4 / N_a4)  # Build DFT matrix.
freqs_a4 = np.arange(N_a4 // 2 + 1) * fs_a4 / N_a4  # Convert bins to Hz.
p1_a4 = np.abs((W_a4 @ (x1_a4 * w_a4))[:N_a4 // 2 + 1]) ** 2  # Spectrum for signal 1.
p2_a4 = np.abs((W_a4 @ (x2_a4 * w_a4))[:N_a4 // 2 + 1]) ** 2  # Spectrum for signal 2.
print("raw spectrum MSE:", round(float(np.mean((p1_a4 - p2_a4) ** 2)), 1))  # Inspect fine-bin difference.
```

```python
edges_a4 = np.array([0, 250, 500, 1000, 2000, 4000], dtype=float)  # Use broad envelope bands.
filters_a4 = np.zeros((len(edges_a4) - 2, len(freqs_a4)))  # Initialize triangular filters.
for b_a4 in range(len(edges_a4) - 2):  # Build each broad triangle.
    left_a4, center_a4, right_a4 = edges_a4[b_a4], edges_a4[b_a4 + 1], edges_a4[b_a4 + 2]  # Read edges.
    rise_a4 = (freqs_a4 > left_a4) & (freqs_a4 <= center_a4)  # Rising side.
    fall_a4 = (freqs_a4 > center_a4) & (freqs_a4 < right_a4)  # Falling side.
    filters_a4[b_a4, rise_a4] = (freqs_a4[rise_a4] - left_a4) / (center_a4 - left_a4)  # Fill rise.
    filters_a4[b_a4, fall_a4] = (right_a4 - freqs_a4[fall_a4]) / (right_a4 - center_a4)  # Fill fall.
log1_a4 = np.log(np.maximum(filters_a4 @ p1_a4, 1e-6))  # Log envelope for signal 1.
log2_a4 = np.log(np.maximum(filters_a4 @ p2_a4, 1e-6))  # Log envelope for signal 2.
print("log-envelope distance:", round(float(np.linalg.norm(log1_a4 - log2_a4)), 3))  # Inspect compressed difference.
```

```python

plt.plot(freqs_a4, p1_a4 / max(p1_a4), label="200 Hz stack")  # Plot first normalized spectrum.
plt.plot(freqs_a4, p2_a4 / max(p2_a4), label="240 Hz stack", alpha=0.8)  # Plot second normalized spectrum.
plt.xlim(0, 1000)  # Focus on harmonics.
plt.title("Advanced 4: fine pitch changes raw bins")  # Title the plot.

plt.ylabel("normalized power")  # Label normalized power.
plt.legend()  # Show signal labels.
plt.show()  # Display spectra.
```
▶ What you'll see: peaks move between bins, but broad-band log energies are much closer than raw bin powers.

👀 Takeaway: MFCC-like compression intentionally keeps broad spectral envelope and discards some fine pitch detail.
