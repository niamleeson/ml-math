# 23.1 — Normal-Form Games & Nash Equilibrium

Normal-form games put strategic interaction into its smallest useful object: a payoff table. Each player chooses an action, the table returns payoffs, and equilibrium asks whether anyone can improve by changing **alone** while the other player stays fixed.

## 📖 Concept walkthrough — build each idea from scratch

Before the worked examples, we build normal-form games one idea at a time. Run each cell in order and read the printed values — every payoff comparison, best response, and mixed-strategy indifference equation is exposed. The walkthrough is self-contained and uses a `_w` suffix so it never clashes with examples below.

```python
import numpy as np  # arrays and small numerical game calculations.
import matplotlib.pyplot as plt  # payoff heatmaps, response diagrams, and dynamics plots.
np.random.seed(0)  # reproducibility for any simulated trajectories.
```

### 1. A normal-form game is two payoff tables on the same action grid

A two-player normal-form game lists one row action, one column action, and two payoffs for every cell. The row player reads matrix $A$; the column player reads matrix $B$. The key habit is to keep those two objectives separate: a cell can be good for row, good for column, both, or neither.

```python
A_w = np.array([[3., 0.], [5., 1.]])  # row payoffs for Prisoner's Dilemma: C,D by C,D.
B_w = np.array([[3., 5.], [0., 1.]])  # column payoffs on the same action grid.
actions_w = ["C", "D"]  # cooperate, defect.
print("row payoff matrix A:\n", A_w)  # inspect row's objective.
print("column payoff matrix B:\n", B_w)  # inspect column's objective.
assert A_w.shape == B_w.shape == (2, 2)  # both players evaluate the same action cells.
```
▶ What you'll see: two 2×2 tables over the same four action profiles.

```python
fig, ax = plt.subplots(1, 2, figsize=(7, 3))  # show both payoff tables side by side.
for k, (M, title) in enumerate([(A_w, "row payoff A"), (B_w, "column payoff B")]):
    im = ax[k].imshow(M, cmap="viridis", vmin=0, vmax=5)  # heatmap of payoff magnitudes.
    ax[k].set_xticks(range(2), actions_w); ax[k].set_yticks(range(2), actions_w)
    ax[k].set_xlabel("column action"); ax[k].set_ylabel("row action"); ax[k].set_title(title)
    for i in range(2):
        for j in range(2):
            ax[k].text(j, i, int(M[i, j]), ha="center", va="center", color="white")
fig.colorbar(im, ax=ax, shrink=0.75, label="payoff")
plt.suptitle("1: one action grid, two objectives")
plt.show()
```
▶ What you'll see: defection is bright for the deviator, but mutual defection is dimmer than mutual cooperation.

*Why it's done this way:* normal form strips time away so we can focus on the strategic object that matters for Nash equilibrium: payoffs from unilateral action changes.

### 2. Mixed strategies turn actions into probabilities and payoffs into expectations

A mixed strategy is a probability distribution over actions. If row uses $p$ and column uses $q$, expected payoffs are $u_R(p,q)=p^\top A q$ and $u_C(p,q)=p^\top B q$. This is just weighted averaging over the payoff table.

```python
p_w = np.array([0.7, 0.3])  # row plays C with probability .7 and D with probability .3.
q_w = np.array([0.4, 0.6])  # column plays C with probability .4 and D with probability .6.
joint_w = p_w[:, None] * q_w[None, :]  # independent mixed strategies induce cell probabilities.
row_u_w = float(p_w @ A_w @ q_w)  # expected row payoff.
col_u_w = float(p_w @ B_w @ q_w)  # expected column payoff.
print("joint probabilities:\n", np.round(joint_w, 3))
print("expected payoffs:", round(row_u_w, 3), round(col_u_w, 3))
assert np.isclose(joint_w.sum(), 1.0) and np.isclose(row_u_w, np.sum(joint_w * A_w))
```
▶ What you'll see: every cell gets a probability, and payoffs are averages over those cells.

```python
plt.figure(figsize=(4, 3))
plt.imshow(joint_w * A_w, cmap="magma", aspect="auto")  # visualize row's expected-value contributions.
plt.colorbar(label="probability × row payoff")
plt.xticks(range(2), actions_w); plt.yticks(range(2), actions_w)
for i in range(2):
    for j in range(2):
        plt.text(j, i, f"{joint_w[i,j]*A_w[i,j]:.2f}", ha="center", va="center", color="white")
plt.title("2: expected row payoff contributions")
plt.xlabel("column action"); plt.ylabel("row action")
plt.show()
```
▶ What you'll see: the expected payoff is the sum of the annotated contribution heatmap.

*Why it's done this way:* probability lets deterministic payoff tables describe randomized or uncertain play without changing the underlying game.

### 3. A best response maximizes one player's payoff holding the other fixed

Best response is local optimization. If column commits to one column, row scans that column of $A$ and chooses the largest entry. If row commits to one row, column scans that row of $B$ and chooses the largest entry.

```python
row_br_w = np.argmax(A_w, axis=0)  # for each column action, row's best row index.
col_br_w = np.argmax(B_w, axis=1)  # for each row action, column's best column index.
print("row best response to column C,D:", [actions_w[i] for i in row_br_w])
print("column best response to row C,D:", [actions_w[j] for j in col_br_w])
assert list(row_br_w) == [1, 1] and list(col_br_w) == [1, 1]
```
▶ What you'll see: defect is each player's best response to either opponent action.

```python
plt.figure(figsize=(4.2, 3.4))
plt.imshow(A_w, cmap="Blues", vmin=0, vmax=5)
for j in range(2):
    plt.scatter(j, row_br_w[j], s=260, facecolors="none", edgecolors="red", linewidths=2)
    for i in range(2):
        plt.text(j, i, int(A_w[i, j]), ha="center", va="center", color="black")
plt.xticks(range(2), actions_w); plt.yticks(range(2), actions_w)
plt.xlabel("column action"); plt.ylabel("row action")
plt.title("3: row best responses circled")
plt.show()
```
▶ What you'll see: the red circles mark row's maximizing payoff in each column.

*Why it's done this way:* Nash equilibrium is built from individual best responses, not from total welfare or moral preference.

### 4. A pure Nash equilibrium is a cell where best-response marks meet

A pure Nash equilibrium is a single action profile where row is best responding to the column action and column is best responding to the row action. In the prisoner's dilemma, the marks meet only at $(D,D)$ even though $(C,C)$ gives both players more.

```python
pure_ne_w = []  # collect cells where both best-response conditions hold.
for i in range(2):
    for j in range(2):
        row_ok = A_w[i, j] == np.max(A_w[:, j])  # row cannot improve by changing rows.
        col_ok = B_w[i, j] == np.max(B_w[i, :])  # column cannot improve by changing columns.
        if row_ok and col_ok:
            pure_ne_w.append((i, j))
print("pure Nash cells:", [(actions_w[i], actions_w[j]) for i, j in pure_ne_w])
print("payoffs at NE:", [(A_w[i, j], B_w[i, j]) for i, j in pure_ne_w])
assert pure_ne_w == [(1, 1)]
```
▶ What you'll see: the unique pure equilibrium is mutual defection with payoffs (1, 1).

```python
social_w = A_w + B_w  # total payoff is not the Nash criterion, but it is useful contrast.
plt.figure(figsize=(4.2, 3.4))
plt.imshow(social_w, cmap="YlGn", vmin=0, vmax=6)
for i in range(2):
    for j in range(2):
        label = f"{int(A_w[i,j])},{int(B_w[i,j])}\nΣ={int(social_w[i,j])}"
        plt.text(j, i, label, ha="center", va="center", color="black")
plt.scatter([1], [1], s=350, marker="*", color="red", label="Nash")
plt.scatter([0], [0], s=220, facecolors="none", edgecolors="blue", linewidths=2, label="efficient")
plt.xticks(range(2), actions_w); plt.yticks(range(2), actions_w); plt.legend(loc="lower left")
plt.title("4: Nash stability is not max total payoff")
plt.show()
```
▶ What you'll see: the efficient cell and the stable cell are different.

*Why it's done this way:* equilibrium checks whether one player can move alone, so it can select outcomes that are collectively worse than coordinated alternatives.

### 5. Mixed Nash equilibrium comes from indifference on the support

If a player mixes between two actions, both actions must give the same expected payoff; otherwise the player would put all probability on the better one. For $A=\begin{bmatrix}2&0\\0&1\end{bmatrix}$, row is indifferent when column plays Left with probability $q$ satisfying $2q=1-q$, so $q=1/3$.

```python
A_mix_w = np.array([[2., 0.], [0., 1.]])  # row payoffs for a coordination-style game.
q_grid_w = np.linspace(0, 1, 101)  # probability that column plays Left.
top_val_w = 2 * q_grid_w  # row payoff from Top.
bot_val_w = 1 - q_grid_w  # row payoff from Bottom.
q_star_w = 1 / 3  # solve 2q = 1 - q.
print("indifference q*:", round(q_star_w, 6), "payoff:", round(2*q_star_w, 6))
assert np.isclose(2 * q_star_w, 1 - q_star_w)
```
▶ What you'll see: $q^*=1/3$ makes Top and Bottom both worth 2/3.

```python
plt.figure(figsize=(5, 3))
plt.plot(q_grid_w, top_val_w, label="Top value = 2q")
plt.plot(q_grid_w, bot_val_w, label="Bottom value = 1-q")
plt.axvline(q_star_w, color="red", linestyle="--", label="indifference q*=1/3")
plt.scatter([q_star_w], [2*q_star_w], color="red")
plt.xlabel("Pr(column plays Left)"); plt.ylabel("row action value")
plt.title("5: mixed support requires equal action values")
plt.legend(); plt.show()
```
▶ What you'll see: the two payoff lines cross exactly where row can rationally mix.

*Why it's done this way:* mixed-strategy probabilities are not arbitrary noise; they are the probabilities that make the opponent just indifferent enough not to switch.

### 6. Matching pennies has no pure equilibrium but has a mixed fixed point

In matching pennies, row wants actions to match and column wants them to differ. Every pure cell gives one player a profitable deviation, so no pure equilibrium exists. The mixed equilibrium is $p=q=(0.5,0.5)$ because each player makes the other indifferent.

```python
A_mp_w = np.array([[1., -1.], [-1., 1.]])  # row wins on matching actions.
B_mp_w = -A_mp_w  # zero-sum: column's payoff is row's negative.
p_star_w = q_star_mp_w = 0.5  # symmetry suggests half-half.
row_H_w = q_star_mp_w * 1 + (1 - q_star_mp_w) * (-1)  # value of Heads for row.
row_T_w = q_star_mp_w * (-1) + (1 - q_star_mp_w) * 1  # value of Tails for row.
print("row action values at q=.5:", row_H_w, row_T_w)
assert row_H_w == row_T_w == 0.0 and np.allclose(B_mp_w, -A_mp_w)
```
▶ What you'll see: both row actions earn 0 against a half-half column strategy.

```python
p_grid_w = np.linspace(0, 1, 101)
row_pay_H_w = 2 * p_grid_w - 1  # column Heads value to row if row probability were p for a related display.
plt.figure(figsize=(5, 3))
plt.plot(p_grid_w, 2*p_grid_w - 1, label="column chooses Heads: row payoff")
plt.plot(p_grid_w, 1 - 2*p_grid_w, label="column chooses Tails: row payoff")
plt.axvline(0.5, color="red", linestyle="--", label="mixed equilibrium")
plt.scatter([0.5], [0.0], color="red")
plt.xlabel("Pr(row plays Heads)"); plt.ylabel("row payoff by column action")
plt.title("6: matching pennies indifference at one half")
plt.legend(); plt.show()
```
▶ What you'll see: the crossing at 0.5 is the only probability that removes a pure best response for the opponent.

*Why it's done this way:* mixed Nash is a fixed point of best responses even when no cell in the payoff matrix is stable.

### 7. Best-response learning can cycle, so equilibrium is not automatic convergence

A best response to the last move can fail to settle. In matching pennies, if each player repeatedly chooses a pure best response to the other player's previous action, play rotates around the table instead of converging to the mixed equilibrium.

```python
row_seq_w = [0]  # start row at Heads.
col_seq_w = [0]  # start column at Heads.
for _ in range(8):
    col_prev = col_seq_w[-1]
    row_next = int(np.argmax(A_mp_w[:, col_prev]))  # row best responds to previous column action.
    row_seq_w.append(row_next)
    col_next = int(np.argmax(B_mp_w[row_next, :]))  # column best responds to row's new action.
    col_seq_w.append(col_next)
print("row actions:", row_seq_w)
print("column actions:", col_seq_w)
assert len(set(zip(row_seq_w[-4:], col_seq_w[-4:]))) > 1
```
▶ What you'll see: actions keep changing rather than settling into one pure cell.

```python
points_w = np.array(list(zip(col_seq_w, row_seq_w)))  # x=column action, y=row action.
plt.figure(figsize=(4, 3.5))
plt.imshow(A_mp_w, cmap="coolwarm", vmin=-1, vmax=1)
for t, (x, y) in enumerate(points_w):
    plt.scatter(x, y, s=50 + 8*t, color="black", alpha=0.55)
    plt.text(x + 0.04, y + 0.04, str(t), color="black")
plt.xticks([0, 1], ["H", "T"]); plt.yticks([0, 1], ["H", "T"])
plt.xlabel("column action"); plt.ylabel("row action")
plt.title("7: pure best-response path cycles")
plt.show()
```
▶ What you'll see: numbered markers rotate among cells instead of landing at a pure equilibrium.

*Why it's done this way:* best response is a static equilibrium condition; using it as a dynamic update rule is a separate algorithm with its own convergence failures.

## 🛠️ Setup

```python
import numpy as np  # arrays and numerical operations for finite games.
import matplotlib.pyplot as plt  # relevant game visualizations.
np.random.seed(0)  # reproducible examples.

A_PD = np.array([[3., 0.], [5., 1.]])  # row payoffs for Prisoner's Dilemma.
B_PD = np.array([[3., 5.], [0., 1.]])  # column payoffs for Prisoner's Dilemma.
ACT2 = ["C", "D"]  # default two-action labels.

def expected_payoffs(A, B, p, q):  # compute mixed-strategy expected payoffs.
    p = np.asarray(p, dtype=float); q = np.asarray(q, dtype=float)  # ensure numeric arrays.
    return float(p @ A @ q), float(p @ B @ q)  # row payoff and column payoff.

def pure_nash(A, B):  # enumerate pure Nash equilibria from scratch.
    out = []  # store equilibrium cells.
    for i in range(A.shape[0]):
        for j in range(A.shape[1]):
            row_ok = np.isclose(A[i, j], np.max(A[:, j]))  # row best response to column j.
            col_ok = np.isclose(B[i, j], np.max(B[i, :]))  # column best response to row i.
            if row_ok and col_ok:
                out.append((i, j))
    return out

def dominated_rows(A):  # find strictly dominated row actions by pure row actions.
    dominated = []  # store row indices that are never better.
    for i in range(A.shape[0]):
        for k in range(A.shape[0]):
            if i != k and np.all(A[k] > A[i]):
                dominated.append((i, k))
    return dominated

def mixed_nash_2x2(A, B):  # solve interior 2x2 mixed Nash by indifference when it exists.
    a11, a12, a21, a22 = A[0, 0], A[0, 1], A[1, 0], A[1, 1]
    b11, b12, b21, b22 = B[0, 0], B[0, 1], B[1, 0], B[1, 1]
    denom_q = a11 - a12 - a21 + a22  # coefficient for column's mix making row indifferent.
    denom_p = b11 - b12 - b21 + b22  # coefficient for row's mix making column indifferent.
    if np.isclose(denom_q, 0) or np.isclose(denom_p, 0):
        return None
    q = (a22 - a12) / denom_q  # probability column plays action 0.
    p = (b22 - b21) / denom_p  # probability row plays action 0.
    if 0 <= p <= 1 and 0 <= q <= 1:
        return float(p), float(q)
    return None

def payoff_heatmap(A, B, title, row_labels=None, col_labels=None, mark=None):  # draw annotated payoff pairs.
    row_labels = row_labels or [str(i) for i in range(A.shape[0])]  # default row labels.
    col_labels = col_labels or [str(j) for j in range(A.shape[1])]  # default column labels.
    plt.figure(figsize=(4.4, 3.5))
    plt.imshow(A + B, cmap="YlGn", aspect="auto")  # color social payoff while annotations keep player payoffs visible.
    plt.colorbar(label="A+B")
    plt.xticks(range(A.shape[1]), col_labels); plt.yticks(range(A.shape[0]), row_labels)
    for i in range(A.shape[0]):
        for j in range(A.shape[1]):
            plt.text(j, i, f"({A[i,j]:.0f},{B[i,j]:.0f})", ha="center", va="center", color="black")
    if mark:
        ys = [i for i, j in mark]; xs = [j for i, j in mark]
        plt.scatter(xs, ys, s=260, marker="*", color="red", label="Nash")
        plt.legend(loc="lower left")
    plt.xlabel("column action"); plt.ylabel("row action"); plt.title(title); plt.show()
```

## 🟢 Basics

#### B1. Read a payoff matrix cell

**Goal.** Extract both players' payoffs from one action profile, because normal-form reasoning starts by reading the table correctly. We build it in 2 steps.

```python
A_b1 = np.array([[3., 0.], [5., 1.]])  # row's payoff table.
B_b1 = np.array([[3., 5.], [0., 1.]])  # column's payoff table.
row_action_b1, col_action_b1 = 0, 1  # row cooperates, column defects.
print("chosen actions:", ACT2[row_action_b1], ACT2[col_action_b1])  # inspect the profile.
assert A_b1.shape == B_b1.shape  # both payoff tables share the action grid.
```
▶ What you'll see: the selected cell is row C against column D.

```python
payoff_b1 = (A_b1[row_action_b1, col_action_b1], B_b1[row_action_b1, col_action_b1])  # read both payoffs.
print("payoff pair:", payoff_b1)  # inspect the ordered pair (row payoff, column payoff).
assert payoff_b1 == (0.0, 5.0)  # row gets sucker payoff, column gets temptation payoff.
plt.figure(figsize=(4.4, 3.5))
plt.imshow(A_b1 + B_b1, cmap="YlGn", aspect="auto")  # color total payoff while annotating both players.
plt.colorbar(label="A+B")
for i in range(2):
    for j in range(2):
        plt.text(j, i, f"({A_b1[i,j]:.0f},{B_b1[i,j]:.0f})", ha="center", va="center", color="black")
plt.scatter([col_action_b1], [row_action_b1], s=260, marker="*", color="red", label="chosen cell")
plt.xticks(range(2), ACT2); plt.yticks(range(2), ACT2)
plt.xlabel("column action"); plt.ylabel("row action"); plt.title("B1: payoff pair at each cell")
plt.legend(loc="lower left")
plt.show()
```
▶ What you'll see: the marked cell has payoff pair (0, 5).

👀 Takeaway: every normal-form cell carries one payoff per player, not one shared score.

#### B2. Compute a mixed expected payoff

**Goal.** Average payoffs under mixed strategies, because randomized play turns the payoff table into expected utility. We build it in 3 steps.

```python
A_b2 = A_PD.copy(); B_b2 = B_PD.copy()  # use the prisoner's dilemma payoffs.
p_b2 = np.array([0.25, 0.75])  # row cooperates with probability .25.
q_b2 = np.array([0.60, 0.40])  # column cooperates with probability .60.
print("p sums to", p_b2.sum(), "q sums to", q_b2.sum())  # confirm valid mixed strategies.
assert np.isclose(p_b2.sum(), 1) and np.isclose(q_b2.sum(), 1)
```
▶ What you'll see: both strategies are valid probability vectors.

```python
joint_b2 = p_b2[:, None] * q_b2[None, :]  # compute probability of each action profile.
row_pay_b2, col_pay_b2 = expected_payoffs(A_b2, B_b2, p_b2, q_b2)  # compute expected payoffs.
print("joint probabilities:\n", np.round(joint_b2, 3))
print("expected payoff pair:", round(row_pay_b2, 3), round(col_pay_b2, 3))
assert np.isclose(row_pay_b2, np.sum(joint_b2 * A_b2))
```

```python
plt.figure(figsize=(4.2, 3.2))
plt.imshow(joint_b2 * A_b2, cmap="magma", aspect="auto")
plt.colorbar(label="cell contribution to row payoff")
plt.xticks(range(2), ACT2); plt.yticks(range(2), ACT2)
for i in range(2):
    for j in range(2):
        plt.text(j, i, f"{joint_b2[i,j]*A_b2[i,j]:.2f}", ha="center", va="center", color="white")
plt.title("B2: expected payoff as heatmap sum")
plt.xlabel("column action"); plt.ylabel("row action")
plt.show()
```
▶ What you'll see: row's expected payoff is the sum of the four annotated contributions.

👀 Takeaway: $p^\top A q$ is just the probability-weighted average of row's payoff table.

#### B3. Find row's best response to a pure column action

**Goal.** Maximize down one column of the row payoff matrix, because row treats column's action as fixed when choosing a best response. We build it in 2 steps.

```python

col_action_b3 = 0  # assume column cooperates.
column_values_b3 = A_b3[:, col_action_b3]  # row's payoffs for C and D against column C.

assert np.array_equal(column_values_b3, np.array([3., 5.]))
```
▶ What you'll see: row compares 3 from cooperating with 5 from defecting.

```python
br_b3 = int(np.argmax(column_values_b3))  # choose the row with highest payoff.
print("best response:", ACT2[br_b3])  # inspect maximizing action.
assert br_b3 == 1
plt.figure(figsize=(4, 3))
plt.bar(ACT2, column_values_b3, color=["gray", "seagreen"])

plt.ylabel("row payoff")
plt.show()
```
▶ What you'll see: D has the taller bar, so D is row's best response.

👀 Takeaway: a best response is an ordinary argmax with the opponent's action held fixed.

#### B4. Find column's best response to a pure row action

**Goal.** Maximize across one row of the column payoff matrix, because column optimizes its own payoff while row is fixed. We build it in 2 steps.

```python
row_values_b4 = B_b4[row_action_b4, :]  # column's payoffs for C and D against row D.

assert np.array_equal(row_values_b4, np.array([0., 1.]))
```
▶ What you'll see: column compares 0 from cooperating with 1 from defecting.

```python
br_b4 = int(np.argmax(row_values_b4))  # choose the best column action.
print("best response:", ACT2[br_b4])
assert br_b4 == 1
plt.figure(figsize=(4, 3))
```

👀 Takeaway: each player scans a different payoff matrix even on the same action grid.

#### B5. Mark all pure best responses

**Goal.** Create row and column best-response masks, because pure Nash cells are intersections of those masks. We build it in 3 steps.

```python
A_b5 = A_PD.copy(); B_b5 = B_PD.copy()  # payoff tables.
row_mask_b5 = A_b5 == np.max(A_b5, axis=0, keepdims=True)  # row best responses in each column.
col_mask_b5 = B_b5 == np.max(B_b5, axis=1, keepdims=True)  # column best responses in each row.
print("row BR mask:\n", row_mask_b5.astype(int))
print("column BR mask:\n", col_mask_b5.astype(int))
assert row_mask_b5.shape == col_mask_b5.shape
```
▶ What you'll see: masks with 1s where each player is optimizing.

```python
both_b5 = row_mask_b5 & col_mask_b5  # intersection of best-response masks.
print("intersection mask:\n", both_b5.astype(int))  # candidate pure Nash cells.
assert np.argwhere(both_b5).tolist() == [[1, 1]]
```

```python
plt.figure(figsize=(4.2, 3.4))
plt.imshow(np.zeros_like(A_b5), cmap="Greys", vmin=0, vmax=1)
```

#### A3. Approximate a mixed equilibrium with replicator dynamics

**Goal.** Simulate a simple population update in matching pennies, because dynamics often orbit around mixed equilibria rather than landing exactly on them. We build it in 4 steps.

```python

```
▶ What you'll see: the system starts away from the mixed equilibrium (0.5, 0.5).

```python

    row_vals = A_a3 @ np.array([q_a3, 1-q_a3])  # row pure-action values.
    col_vals = np.array([p_a3, 1-p_a3]) @ B_a3  # column pure-action values.
    row_avg = p_a3 * row_vals[0] + (1-p_a3) * row_vals[1]  # row average payoff.
    col_avg = q_a3 * col_vals[0] + (1-q_a3) * col_vals[1]  # column average payoff.
```

#### A5. Check an equilibrium by unilateral deviations

**Goal.** Verify a candidate mixed equilibrium directly, because the definition requires no player can gain by changing their own strategy alone. We build it in 4 steps.

```python
A_a5 = np.array([[1., -1.], [-1., 1.]])  # matching pennies row payoff.
B_a5 = -A_a5  # matching pennies column payoff.
p_a5 = np.array([0.5, 0.5])  # candidate row strategy.
q_a5 = np.array([0.5, 0.5])  # candidate column strategy.
base_row_a5, base_col_a5 = expected_payoffs(A_a5, B_a5, p_a5, q_a5)  # candidate payoffs.
print("candidate payoff pair:", base_row_a5, base_col_a5)
assert base_row_a5 == base_col_a5 == 0.0
```
▶ What you'll see: both players get expected payoff 0 at the half-half profile.

```python
row_devs_a5 = np.array([expected_payoffs(A_a5, B_a5, np.eye(2)[i], q_a5)[0] for i in range(2)])  # row pure deviations.
col_devs_a5 = np.array([expected_payoffs(A_a5, B_a5, p_a5, np.eye(2)[j])[1] for j in range(2)])  # column pure deviations.
print("row pure-deviation payoffs:", row_devs_a5)
print("column pure-deviation payoffs:", col_devs_a5)
assert np.all(row_devs_a5 <= base_row_a5 + 1e-12) and np.all(col_devs_a5 <= base_col_a5 + 1e-12)
```

```python
eps_a5 = np.linspace(0, 1, 101)  # row deviation probability of Heads.
```
