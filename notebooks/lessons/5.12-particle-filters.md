# 5.12 — Particle Filters

Particle filters approximate a changing posterior with many simulated states called particles. In this lesson, you will build the predict → weight → resample loop from first principles, inspect the normalization arithmetic, and see why resampling fixes weight collapse while also reducing particle diversity.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build particle filters one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math is visible, including likelihood weights, normalization, effective sample size, and resampling. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, random draws, and vectorized probability arithmetic.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for particles, motion noise, and resampling.
```

### 1. Represent a posterior with movable particles

A particle filter replaces an analytic distribution with a weighted cloud: particles store possible states, and weights store how plausible those states are after seeing data. The approximate posterior is a sum of point masses, $\hat p(x_t\mid y_{1:t})\approx\sum_i w_t^{(i)}\delta_{x_t^{(i)}}$. That notation simply means: keep many candidate locations, attach probability mass to each one, and summarize the cloud with weighted averages instead of integrals.

```python
N_w = 200  # number of particles in the toy posterior approximation.
rng_w = np.random.default_rng(0)  # local generator so the worked arithmetic is stable.
particles_w = rng_w.normal(loc=0.0, scale=1.0, size=N_w)  # prior particles before evidence.
weights_w = np.ones(N_w) / N_w  # equal weights represent an unconditioned Monte Carlo sample.
print("particle count:", N_w)  # inspect how many point masses represent the posterior.
print("weight sum:", round(float(weights_w.sum()), 6))  # verify probabilities normalize to 1.
assert round(float(weights_w.sum()), 6) == 1.0  # concrete probability check.
```
▶ What you'll see: 200 states, each initially carrying 1/200 of the probability mass.

```python
mean_w = float(np.sum(weights_w * particles_w))  # weighted average approximates posterior mean.
var_w = float(np.sum(weights_w * (particles_w - mean_w) ** 2))  # weighted variance approximates spread.
print("weighted mean:", round(mean_w, 3))  # inspect the cloud center.
print("weighted std:", round(np.sqrt(var_w), 3))  # inspect the cloud width.
```
▶ What you'll see: the sample mean is near 0 and the sample standard deviation is near 1.

```python
plt.figure(figsize=(5, 3))  # compact histogram of particle mass.
plt.hist(particles_w, bins=25, weights=weights_w, color="steelblue", edgecolor="white")  # weighted density proxy.
plt.axvline(mean_w, color="black", linestyle="--", label="weighted mean")  # mark the estimate.
plt.title("1: particles as movable probability mass")  # label the concept.
plt.xlabel("state x")  # horizontal state axis.
plt.ylabel("weighted mass")  # vertical approximate probability mass.
plt.legend(); plt.show()  # display the plot.
```
▶ What you'll see: a Monte Carlo approximation to a bell-shaped prior, with tiny bars standing in for a smooth density.

*Why it's done this way:* exact filtering stores the whole posterior density, which may be impossible for nonlinear or non-Gaussian systems. Particles keep only sampled support points; the weights make sums like $\sum_i w_i f(x_i)$ stand in for integrals like $\int f(x)p(x)dx$.

### 2. Predict by pushing particles through the dynamics

Filtering is sequential. Before using the new measurement, we predict where each previous state could have moved. For a simple random-walk model, $x_t=x_{t-1}+u_t+\epsilon_t$, so every particle receives the same control input plus its own process noise. This is the step that carries prior belief forward through the transition model.

```python
control_w = 1.0  # known motion input from the previous time to the current time.
process_std_w = 0.2  # uncertainty in the motion model.
predicted_w = particles_w + control_w + rng_w.normal(0.0, process_std_w, size=N_w)  # propagate particles.
print("predicted particle mean:", round(float(predicted_w.mean()), 6))  # inspect the verified-run mean.
assert abs(float(predicted_w.mean()) - 0.997563) < 1e-6  # worked arithmetic number from the lesson content.
```
▶ What you'll see: the mean moves from near 0 to about 0.997563 because the control input shifts the cloud right by 1.

```python
plt.figure(figsize=(5, 3))  # compare prior and prediction clouds.
plt.hist(particles_w, bins=25, alpha=0.55, density=True, label="before prediction", color="gray")  # old cloud.
plt.hist(predicted_w, bins=25, alpha=0.55, density=True, label="after prediction", color="seagreen")  # propagated cloud.
plt.title("2: transition model shifts and spreads particles")  # label the concept.
plt.xlabel("state x"); plt.ylabel("density proxy"); plt.legend(); plt.show()  # render axes and legend.
```
▶ What you'll see: the particle cloud shifts right and widens slightly because process noise adds uncertainty.

*Why it's done this way:* the transition density $p(x_t\mid x_{t-1})$ is the prior for the current time. Sampling from it is easier than writing down the transformed density, especially when the dynamics are nonlinear.

### 3. Weight particles by how well they explain the observation

After prediction, evidence arrives. If the sensor says $y_t=1.2$ with noise standard deviation $0.3$, a particle near 1.2 should receive high likelihood and a far-away particle should receive low likelihood. The unnormalized update is $w_t^{(i)}\propto w_{t-1}^{(i)}p(y_t\mid x_t^{(i)})$; normalization turns those local scores into probabilities that sum to 1.

```python
def normal_pdf_w(y, mean, std):  # Gaussian likelihood evaluated at y for each candidate mean.
    return np.exp(-0.5 * ((y - mean) / std) ** 2) / (std * np.sqrt(2 * np.pi))  # N(y; mean, std^2).

y_w = 1.2  # observed sensor reading.
sensor_std_w = 0.3  # measurement noise standard deviation.
likelihood_w = normal_pdf_w(y_w, predicted_w, sensor_std_w)  # p(y | x_i) for every particle.
raw_weights_w = weights_w * likelihood_w  # prior mass times local evidence.
print("likelihood min/max:", round(float(likelihood_w.min()), 6), round(float(likelihood_w.max()), 6))  # inspect evidence contrast.
```
▶ What you'll see: particles close to 1.2 have much larger likelihood than particles in the tails.

```python
posterior_weights_w = raw_weights_w / raw_weights_w.sum()  # normalize so the particle weights sum to 1.
print("raw weight sum:", round(float(raw_weights_w.sum()), 6))  # normalizing constant estimate.
print("normalized sum:", round(float(posterior_weights_w.sum()), 6))  # probability check.
assert round(float(posterior_weights_w.sum()), 6) == 1.0  # concrete normalization check.
```
▶ What you'll see: raw likelihood scores become valid probability weights after division by their sum.

```python
plt.figure(figsize=(5, 3))  # show likelihood weighting.
plt.scatter(predicted_w, posterior_weights_w, s=14, alpha=0.7, color="darkorange")  # weight by particle location.
plt.axvline(y_w, color="black", linestyle="--", label="observation y=1.2")  # sensor reading.
plt.title("3: observation likelihood concentrates weights")  # label the concept.
plt.xlabel("predicted particle x"); plt.ylabel("normalized weight"); plt.legend(); plt.show()  # render plot.
```
▶ What you'll see: the highest weights form a peak around the measurement value 1.2.

*Why it's done this way:* Bayes' rule says posterior mass is prior mass times likelihood, divided by total evidence. The raw weights implement the numerator; the normalization constant implements the denominator so the discrete approximation is a probability distribution.

### 4. Estimate the posterior from weighted particles

Once particles have weights, summaries are weighted sums. The posterior mean estimate is $\sum_i w_i x_i$, and a credible region can be approximated by weighted quantiles or by inspecting high-mass particles. The key shift from ordinary averaging is that particles with little likelihood barely count.

```python
posterior_mean_w = float(np.sum(posterior_weights_w * predicted_w))  # weighted posterior mean.
unweighted_mean_w = float(np.mean(predicted_w))  # prediction mean before evidence was used.
print("prediction mean:", round(unweighted_mean_w, 3))  # prior-to-current estimate.
print("posterior mean:", round(posterior_mean_w, 3))  # evidence-updated estimate.
assert 1.0 < posterior_mean_w < 1.3  # lesson content: estimate lies between prediction center and observation.
```
▶ What you'll see: the posterior mean moves toward 1.2 but remains influenced by the predicted cloud.

```python
weighted_var_w = float(np.sum(posterior_weights_w * (predicted_w - posterior_mean_w) ** 2))  # posterior spread.
print("posterior std:", round(np.sqrt(weighted_var_w), 3))  # weighted uncertainty after seeing y.
plt.figure(figsize=(5, 3))  # visualize weighted posterior mass.
plt.hist(predicted_w, bins=25, weights=posterior_weights_w, color="purple", edgecolor="white")  # weighted posterior histogram.
plt.axvline(posterior_mean_w, color="black", linestyle="--", label="posterior mean")  # estimate line.
plt.axvline(y_w, color="orange", linestyle=":", label="observation")  # evidence line.
plt.title("4: weighted particles estimate the posterior")  # label the concept.
plt.xlabel("state x"); plt.ylabel("posterior mass"); plt.legend(); plt.show()  # render plot.
```
▶ What you'll see: posterior mass concentrates between the predicted center and the observation.

*Why it's done this way:* a weighted average is the Monte Carlo version of a posterior expectation. The observation should not simply replace the state estimate, because the motion model and sensor model both carry uncertainty.

### 5. Diagnose weight collapse with effective sample size

A particle set can have 200 particles but behave like far fewer if one or two weights dominate. Effective sample size, $\mathrm{ESS}=1/\sum_i w_i^2$, turns weight concentration into an interpretable count. Equal weights give ESS = N; concentrated weights give a much smaller value.

```python
ess_w = float(1.0 / np.sum(posterior_weights_w ** 2))  # effective number of weighted particles.
print("N:", N_w, "ESS:", round(ess_w, 3))  # compare nominal count with usable count.
assert ess_w < N_w  # evidence concentration reduces effective sample size.
```
▶ What you'll see: ESS is below 200 because the observation made some particles much more important than others.

```python
sorted_w = np.sort(posterior_weights_w)[::-1]  # weights from largest to smallest.
cum_w = np.cumsum(sorted_w)  # cumulative posterior mass by top particles.
print("top 10 particle mass:", round(float(cum_w[9]), 3))  # inspect concentration.
plt.figure(figsize=(5, 3))  # show cumulative weight concentration.
plt.plot(cum_w, color="crimson")  # cumulative mass curve.
plt.axhline(0.5, color="black", linestyle="--", linewidth=1)  # half-mass reference.
plt.title("5: weight concentration lowers ESS")  # label the concept.
plt.xlabel("particles sorted by weight"); plt.ylabel("cumulative mass"); plt.show()  # render plot.
```
▶ What you'll see: a small fraction of particles carries a large share of posterior mass.

*Why it's done this way:* ESS is a cheap degeneracy diagnostic. It estimates how many equally weighted samples would contain the same amount of information as the current unevenly weighted sample.

### 6. Resample to fight degeneracy, then notice diversity loss

Resampling draws a new particle set from the old one with probability proportional to weight. High-weight particles are duplicated, low-weight particles disappear, and the new weights reset to uniform. This combats degeneracy, but it also reduces the number of distinct particle values.

```python
indices_w = np.random.choice(N_w, size=N_w, replace=True, p=posterior_weights_w)  # multinomial resampling.
resampled_w = predicted_w[indices_w]  # duplicate likely particles and drop unlikely ones.
resampled_weights_w = np.ones(N_w) / N_w  # reset to equal weights after resampling.
unique_bins_w = len(np.unique(np.round(resampled_w, 2)))  # rough diversity count.
print("resampled weight sum:", round(float(resampled_weights_w.sum()), 6))  # probability check.
print("rounded unique particle values:", unique_bins_w)  # diversity proxy.
assert round(float(resampled_weights_w.sum()), 6) == 1.0  # concrete check.
```
▶ What you'll see: all weights are equal again, but many resampled particles are duplicates or near-duplicates.

```python
plt.figure(figsize=(5, 3))  # compare weighted and resampled views.
plt.hist(predicted_w, bins=25, weights=posterior_weights_w, alpha=0.6, label="weighted before", color="purple")  # before resampling.
plt.hist(resampled_w, bins=25, weights=resampled_weights_w, alpha=0.6, label="resampled", color="seagreen")  # after resampling.
plt.title("6: resampling turns weights into duplicated particles")  # label the concept.
plt.xlabel("state x"); plt.ylabel("mass"); plt.legend(); plt.show()  # render plot.
```
▶ What you'll see: the resampled histogram follows the weighted posterior shape, but represents it with repeated particles.

*Why it's done this way:* future prediction steps are easier when weights are uniform; otherwise old low-weight particles keep consuming computation. The price is sample impoverishment, so practical filters resample only when ESS is low.

### 7. Put predict, weight, and resample into a full filter

A particle filter repeats the same three moves over time: predict through dynamics, weight by the new observation, and resample if ESS is too low. The loop is approximate Bayes filtering: the particle cloud at time $t-1$ becomes the empirical prior for time $t$.

```python
T_w = 12  # number of filtering time steps.
true_w = np.cumsum(0.7 + np.random.normal(0, 0.12, size=T_w))  # hidden trajectory.
obs_w = true_w + np.random.normal(0, 0.35, size=T_w)  # noisy measurements.
particles_loop_w = np.random.normal(0, 1, size=N_w)  # initial particles.
weights_loop_w = np.ones(N_w) / N_w  # initial equal weights.
estimates_w, ess_history_w = [], []  # store posterior mean and ESS over time.
print("first observation:", round(float(obs_w[0]), 3))  # inspect the data stream.
```
▶ What you'll see: a short noisy time series that must be filtered sequentially.

```python
for t_w in range(T_w):  # sequential Bayes filtering loop.
    particles_loop_w = particles_loop_w + 0.7 + np.random.normal(0, 0.2, size=N_w)  # predict.
    like_loop_w = normal_pdf_w(obs_w[t_w], particles_loop_w, 0.35)  # measurement likelihood.
    weights_loop_w = weights_loop_w * like_loop_w  # unnormalized Bayes update.
    weights_loop_w = weights_loop_w / weights_loop_w.sum()  # normalize.
    estimates_w.append(float(np.sum(weights_loop_w * particles_loop_w)))  # posterior mean estimate.
    ess_now_w = float(1.0 / np.sum(weights_loop_w ** 2))  # ESS diagnostic.
    ess_history_w.append(ess_now_w)  # save ESS.
    if ess_now_w < N_w / 2:  # resample only when degeneracy is substantial.
        idx_loop_w = np.random.choice(N_w, size=N_w, replace=True, p=weights_loop_w)  # draw ancestors.
        particles_loop_w = particles_loop_w[idx_loop_w]  # keep selected states.
        weights_loop_w = np.ones(N_w) / N_w  # reset weights.
print("final estimate:", round(estimates_w[-1], 3), "final truth:", round(float(true_w[-1]), 3))  # compare final state.
assert len(estimates_w) == T_w and len(ess_history_w) == T_w  # loop bookkeeping check.
```
▶ What you'll see: the filter returns one posterior estimate and one ESS value per observation.

```python
plt.figure(figsize=(6, 3))  # trajectory plot.
plt.plot(true_w, label="hidden truth", color="black")  # true state.
plt.scatter(np.arange(T_w), obs_w, label="noisy observations", color="orange")  # measurements.
plt.plot(estimates_w, label="particle-filter estimate", color="seagreen")  # filtered estimates.
plt.title("7: sequential particle filtering")  # label the concept.
plt.xlabel("time"); plt.ylabel("state"); plt.legend(); plt.show()  # render plot.
```
▶ What you'll see: the estimate follows the hidden trajectory more smoothly than the noisy observations.

*Why it's done this way:* each iteration implements the recursive filtering identity: prediction integrates over prior state uncertainty, weighting conditions on new evidence, and resampling keeps computation focused on plausible regions.

## 🛠️ Setup

```python
import numpy as np # load NumPy for particles, vectorized likelihoods, weighted averages, and resampling.
import matplotlib.pyplot as plt # load Matplotlib for particle clouds, histograms, trajectories, and diagnostics.
np.random.seed(0) # make all random examples reproducible across notebook runs.

def normal_pdf(y, mean, std): # evaluate a Gaussian density with possibly vector-valued mean.
    return np.exp(-0.5 * ((y - mean) / std) ** 2) / (std * np.sqrt(2 * np.pi)) # return N(y; mean, std^2).

def normalize(w): # convert nonnegative scores into probabilities.
    total = np.sum(w) # compute the normalizing constant.
    return np.ones_like(w) / len(w) if total == 0 else w / total # use uniform fallback only if all scores vanish.

def weighted_mean(x, w): # compute the posterior mean of a weighted particle cloud.
    return float(np.sum(x * w)) # weighted Monte Carlo expectation.

def effective_sample_size(w): # compute the standard particle-filter degeneracy diagnostic.
    return float(1.0 / np.sum(w ** 2)) # ESS equals N for uniform weights and shrinks under concentration.

def systematic_resample(weights): # deterministic-offset low-variance resampling indices.
    n = len(weights) # number of particles to draw.
    positions = (np.arange(n) + np.random.rand()) / n # one equally spaced target per output particle.
    cumulative = np.cumsum(weights) # cumulative distribution over ancestors.
    return np.searchsorted(cumulative, positions) # ancestor index for each target position.

def show_particles(x, w, title): # compact visualization helper for weighted particle clouds.
    plt.figure(figsize=(5, 3)) # create a notebook-sized figure.
    plt.hist(x, bins=25, weights=w, color="steelblue", edgecolor="white") # draw weighted particle mass.
    plt.axvline(weighted_mean(x, w), color="black", linestyle="--", label="weighted mean") # mark the posterior mean.
    plt.title(title) # label the diagnostic plot.
    plt.xlabel("state x") # label state axis.
    plt.ylabel("probability mass") # label weighted mass axis.
    plt.legend() # show the mean label.
    plt.show() # display the figure.
```

### Basic 6 — Update particles with one observation

**Goal.** Perform one complete measurement update, because particle filtering multiplies prior mass by likelihood and renormalizes. We build it in 3 steps.

```python
particles_b6 = np.linspace(0.0, 2.0, 11) # predicted particles around the likely observation.
weights_prior_b6 = np.ones_like(particles_b6) / len(particles_b6) # uniform prior weights.
```

```python
like_b6 = normal_pdf(y_b6, particles_b6, 0.25) # score each particle under the sensor model.

post_mean_b6 = weighted_mean(particles_b6, weights_post_b6) # posterior mean.
print("posterior mean:", round(post_mean_b6, 3)) # inspect after evidence.
assert post_mean_b6 > 1.0 # evidence at 1.4 should pull the estimate upward.
```

▶ What you'll see: posterior mass is concentrated around x=1.4 rather than spread uniformly.

👀 Takeaway: one observation changes weights, not particle locations; prediction is what moves locations.

### Basic 7 — Compute effective sample size

**Goal.** Measure weight degeneracy, because many particles can become irrelevant after a sharp observation. We build it in 2 steps.

```python
uniform_b7 = np.ones(5) / 5 # five equally useful particles.
peaked_b7 = np.array([0.84, 0.04, 0.04, 0.04, 0.04]) # one dominant particle and four weak ones.
ess_uniform_b7 = effective_sample_size(uniform_b7) # ESS for equal weights.
ess_peaked_b7 = effective_sample_size(peaked_b7) # ESS for concentrated weights.
print("uniform ESS:", round(ess_uniform_b7, 3), "peaked ESS:", round(ess_peaked_b7, 3)) # compare counts.
assert round(ess_uniform_b7, 3) == 5.0 # equal weights use all five particles.
```
▶ What you'll see: the peaked distribution has an ESS much smaller than 5.

```python
plt.figure(figsize=(4, 3)); plt.bar(["uniform", "peaked"], [ess_uniform_b7, ess_peaked_b7], color=["gray", "crimson"]) # compare ESS values.
plt.title("Basic 7: ESS detects weight collapse"); plt.ylabel("effective particles"); plt.show() # display chart.
```

```python
print("left/right mass:", round(left_mass_a5, 3), round(right_mass_a5, 3)) # inspect both modes.
assert left_mass_a5 > 0.1 and right_mass_a5 > 0.1 # both modes survive.
```
