# 11.11 — Deep Q-Networks

Deep Q-Networks (DQN) take the Bellman idea from tabular Q-learning and replace the table with a neural network that predicts one Q-value per action. In this lesson, you will build the return, the bootstrap target, a tiny MLP, experience replay, a target network, and a full toy training loop from first principles with only NumPy and Matplotlib.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build DQN one idea at a time. Run each cell in order and read the printed intermediate values — every target, gradient, replay sample, and network update is exposed so the algorithm is not a black box. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, random sampling, and manual neural-network math.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for action choices, replay sampling, and weights.
```

### 1. Discounted consequence: rewards now versus rewards later

A DQN is still solving the same reinforcement-learning problem as tabular Q-learning: choose an action now while the meaningful payoff may arrive later. The return $G_t=r_t+\gamma r_{t+1}+\gamma^2 r_{t+2}+\cdots$ is the ledger that converts a reward stream into one number. The discount $\gamma$ makes future rewards count, but not as much as immediate rewards.

```python
rewards_w = np.array([1.0, 0.0, 2.0])  # immediate reward, then none, then a delayed payoff.
gamma_w = 0.9  # discount factor: future rewards still matter, but are slightly devalued.
powers_w = gamma_w ** np.arange(len(rewards_w))  # [1, gamma, gamma^2].
print("discount powers:", np.round(powers_w, 3))
print("discounted terms:", np.round(rewards_w * powers_w, 3))
```
▶ What you'll see: the reward two steps away contributes `1.62`, not `2.0`, because it is multiplied by `0.9²`.

```python
return_w = float(np.sum(rewards_w * powers_w))  # sum all discounted reward entries.
print("three-step return:", round(return_w, 3))
assert round(return_w, 3) == 2.620
```
▶ What you'll see: the return is `2.620`, matching the lesson's discounted-consequence calculation.

```python
gammas_w = np.linspace(0.0, 0.99, 60)  # compare very myopic to very patient agents.
returns_w = [float(np.sum(rewards_w * (g ** np.arange(len(rewards_w))))) for g in gammas_w]
plt.figure(figsize=(4.4, 3))
plt.plot(gammas_w, returns_w, color="purple")
plt.scatter([gamma_w], [return_w], color="black")
plt.title("1: return grows as future reward matters")
plt.xlabel("discount γ")
plt.ylabel("G for rewards [1,0,2]")
plt.show()
```
▶ What you'll see: the curve rises with γ because the delayed reward receives more weight.

*Why it's done this way:* DQN does not optimize immediate reward alone; it trains Q-values to summarize downstream consequence. Discounting is the mathematical compromise: it lets delayed payoffs influence action choice while keeping infinite-horizon sums finite and making nearer evidence more trustworthy than far-away evidence.

### 2. Bellman targets: bootstrapping action values

The action-value $Q(s,a)$ means "expected discounted return after taking action $a$ in state $s$ and then behaving well afterward." DQN trains a network prediction toward the one-step Bellman target $y=r+\gamma\max_{a'}Q(s',a')$. That target bootstraps: it uses an observed reward plus the learner's current estimate of the next state's best future.

```python
reward_w = 1.0  # observed reward from one transition.
next_q_w = np.array([0.2, 0.8])  # estimated Q-values for the next state.
old_q_w = 0.4  # current estimate for the action we actually took.
alpha_w = 0.5  # tabular learning rate for this inspection cell.
target_w = reward_w + gamma_w * np.max(next_q_w)  # one-step bootstrap target.
print("next Q-values:", next_q_w, "best next:", np.max(next_q_w))
print("target y = r + γ max Q(next):", round(target_w, 3))
assert round(target_w, 3) == 1.720
```
▶ What you'll see: the target is `1 + 0.9·0.8 = 1.720`.

```python
td_error_w = target_w - old_q_w  # signed correction signal.
new_q_w = old_q_w + alpha_w * td_error_w  # move partway toward the target.
print("TD error:", round(td_error_w, 3))
print("updated Q:", round(new_q_w, 3))
assert round(new_q_w, 3) == 1.060
```
▶ What you'll see: the estimate moves halfway from `0.4` toward `1.72`, landing at `1.06`.

```python
plt.figure(figsize=(4.4, 3))
plt.bar(["old Q", "target y", "new Q"], [old_q_w, target_w, new_q_w], color=["gray", "black", "seagreen"])
plt.title("2: TD update moves toward a bootstrap target")
plt.ylabel("value")
plt.show()
```
▶ What you'll see: the new value sits between the old estimate and the target, not at either extreme.

*Why it's done this way:* waiting for complete episode returns is high variance, while replacing the future with a current estimate is biased but much cheaper. The Bellman target is the controlled bootstrap: one real reward anchors the target, and the discounted next-state maximum estimates the rest of the consequence.

### 3. A neural Q-function: one MLP predicts all action values

Tabular Q-learning stores one number for every state-action pair. DQN replaces that table with a neural network $Q_\theta(s)$ that maps state features to a vector of action values. Even in this tiny line-world, the shape idea matters: input is a state feature vector, output has one coordinate per action, and only the coordinate for the action actually taken receives the TD loss.

```python
def one_hot_w(s, n):  # encode a discrete state as a feature vector.
    x = np.zeros(n)
    x[s] = 1.0
    return x

n_states_w, n_actions_w, hidden_w = 5, 2, 8  # line world has five positions and two actions.
rng_w = np.random.default_rng(0)
W1_w = 0.2 * rng_w.normal(size=(n_states_w, hidden_w))
b1_w = np.zeros(hidden_w)
W2_w = 0.2 * rng_w.normal(size=(hidden_w, n_actions_w))
b2_w = np.zeros(n_actions_w)
x_w = one_hot_w(2, n_states_w)  # inspect the middle state.
print("state feature:", x_w)
print("W1 shape:", W1_w.shape, "W2 shape:", W2_w.shape)
```
▶ What you'll see: a one-hot state feeds a hidden layer, then the output layer emits two action values.

```python
def forward_w(x, W1, b1, W2, b2):  # tiny ReLU MLP forward pass.
    z1 = x @ W1 + b1
    h = np.maximum(0.0, z1)
    q = h @ W2 + b2
    return z1, h, q

z1_w, h_w, q_w = forward_w(x_w, W1_w, b1_w, W2_w, b2_w)
print("hidden activations:", np.round(h_w, 3))
print("Q(left), Q(right):", np.round(q_w, 3))
assert q_w.shape == (2,)
```
▶ What you'll see: one state produces a length-2 Q-vector, not one scalar.

```python
plt.figure(figsize=(4.4, 3))
plt.bar(["left", "right"], q_w, color="teal")
plt.title("3: network output = one Q per action")
plt.ylabel("predicted Q")
plt.show()
```
▶ What you'll see: the untrained network has small arbitrary Q-values because the weights are random.

*Why it's done this way:* predicting all actions in one forward pass shares state features across actions and makes greedy action selection cheap. The network is a function approximator for the table: the table lookup becomes a forward pass, and the table update becomes backpropagation into weights.

### 4. TD loss and manual backpropagation

For one replayed transition $(s,a,r,s',done)$, DQN changes only $Q_\theta(s,a)$ toward the target $y$. The per-sample loss is $\frac12(Q_\theta(s,a)-y)^2$. The factor $\frac12$ cancels the 2 in the derivative, so the output gradient for the chosen action is simply $Q_\theta(s,a)-y$.

```python
s_w, a_w, r_w, sp_w, done_w = 2, 1, 1.0, 3, False  # one transition: from middle, move right, receive reward.
x_w = one_hot_w(s_w, n_states_w)
xp_w = one_hot_w(sp_w, n_states_w)
_, _, q_now_w = forward_w(x_w, W1_w, b1_w, W2_w, b2_w)
_, _, q_next_w = forward_w(xp_w, W1_w, b1_w, W2_w, b2_w)
y_w = r_w + gamma_w * np.max(q_next_w) * (1.0 - float(done_w))
print("Q(s):", np.round(q_now_w, 3), "chosen action:", a_w)
print("target y:", round(float(y_w), 3))
```
▶ What you'll see: the chosen action's current prediction is compared with a bootstrapped target.

```python
pred_chosen_w = q_now_w[a_w]
loss_w = 0.5 * (pred_chosen_w - y_w) ** 2
dq_w = np.zeros(n_actions_w)
dq_w[a_w] = pred_chosen_w - y_w  # gradient of 1/2(pred-target)^2 for the chosen action.
print("chosen prediction:", round(float(pred_chosen_w), 3))
print("loss:", round(float(loss_w), 3))
print("output gradient dL/dQ:", np.round(dq_w, 3))
assert dq_w[0] == 0.0
```
▶ What you'll see: the unchosen action receives gradient `0`; DQN updates only the action that generated the transition.

```python
lr_w = 0.1
z1_w, h_w, q_now_w = forward_w(x_w, W1_w, b1_w, W2_w, b2_w)
dW2_w = np.outer(h_w, dq_w)  # hidden-to-output gradient.
db2_w = dq_w.copy()
dh_w = dq_w @ W2_w.T  # backpropagate from output to hidden.
dz1_w = dh_w * (z1_w > 0)  # ReLU derivative gates inactive units.
dW1_w = np.outer(x_w, dz1_w)
db1_grad_w = dz1_w.copy()
print("||dW2||:", round(float(np.linalg.norm(dW2_w)), 3), "||dW1||:", round(float(np.linalg.norm(dW1_w)), 3))
```
▶ What you'll see: both layers receive gradients, but only through active ReLU units and the chosen output action.

```python
W1_new_w = W1_w - lr_w * dW1_w
b1_new_w = b1_w - lr_w * db1_grad_w
W2_new_w = W2_w - lr_w * dW2_w
b2_new_w = b2_w - lr_w * db2_w
_, _, q_after_w = forward_w(x_w, W1_new_w, b1_new_w, W2_new_w, b2_new_w)
print("chosen Q before -> after:", round(float(q_now_w[a_w]), 3), "->", round(float(q_after_w[a_w]), 3))
assert abs(q_after_w[a_w] - y_w) < abs(q_now_w[a_w] - y_w)
```
▶ What you'll see: one manual gradient step moves the chosen Q-value closer to its target.

*Why it's done this way:* the TD error is a supervised residual, but only for one action coordinate. Manual backprop shows the exact chain rule: chosen-output error changes output weights, then flows through ReLU gates into state-feature weights, letting many states share statistical strength through the same network parameters.

### 5. Experience replay: randomizing correlated experience

If we train only on the most recent transition, consecutive updates are highly correlated: the agent sees nearby states in streaks, so the network can chase the latest part of the trajectory. Experience replay stores past transitions and samples mini-batches uniformly, making updates look more like ordinary supervised learning on a shuffled dataset.

```python
replay_w = []
trajectory_w = [(0, 1, 0.0, 1, False), (1, 1, 0.0, 2, False), (2, 1, 0.0, 3, False), (3, 1, 1.0, 4, True),
                (3, 0, 0.0, 2, False), (2, 0, 0.0, 1, False), (1, 0, -1.0, 0, True)]
for tr_w in trajectory_w:
    replay_w.append(tr_w)
print("stored transitions:", len(replay_w))
print("first transition:", replay_w[0])
```
▶ What you'll see: replay is just a list of `(state, action, reward, next_state, done)` tuples.

```python
idx_w = rng_w.choice(len(replay_w), size=4, replace=False)
batch_w = [replay_w[i] for i in idx_w]
print("sampled indices:", idx_w)
print("sampled states:", [b[0] for b in batch_w])
assert len(batch_w) == 4
```
▶ What you'll see: sampled states are not necessarily adjacent in time, which breaks trajectory streaks.

```python
ordered_states_w = [tr[0] for tr in replay_w[:4]]
sampled_states_w = [tr[0] for tr in batch_w]
plt.figure(figsize=(4.6, 3))
plt.plot(ordered_states_w, marker="o", label="latest sequence")
plt.plot(sampled_states_w, marker="s", label="replay batch")
plt.title("5: replay shuffles experience")
plt.xlabel("position in update data")
plt.ylabel("state index")
plt.legend()
plt.show()
```
▶ What you'll see: the replay batch jumps around more than the chronological sequence.

*Why it's done this way:* stochastic gradient descent assumes updates are noisy but not systematically ordered. Replay reduces correlation, reuses rare reward transitions many times, and improves data efficiency because one environment interaction can produce many later learning updates.

### 6. Target networks: freezing the bootstrap teacher

The DQN target contains a Q-value too. If the same network both predicts $Q_\theta(s,a)$ and supplies $\max_{a'}Q_\theta(s',a')$, the target moves every time the student moves. A target network copies the online weights occasionally, then stays frozen while several gradient steps train against a stable teacher.

```python
online_W1_w, online_b1_w = W1_new_w.copy(), b1_new_w.copy()
online_W2_w, online_b2_w = W2_new_w.copy(), b2_new_w.copy()
target_W1_w, target_b1_w = online_W1_w.copy(), online_b1_w.copy()
target_W2_w, target_b2_w = online_W2_w.copy(), online_b2_w.copy()
print("initial online-target difference:", np.linalg.norm(online_W1_w - target_W1_w) + np.linalg.norm(online_W2_w - target_W2_w))
```
▶ What you'll see: right after copying, online and target networks are identical.

```python
online_W2_w = online_W2_w + 0.05 * rng_w.normal(size=online_W2_w.shape)  # pretend several online updates happened.
_, _, online_next_w = forward_w(xp_w, online_W1_w, online_b1_w, online_W2_w, online_b2_w)
_, _, frozen_next_w = forward_w(xp_w, target_W1_w, target_b1_w, target_W2_w, target_b2_w)
y_online_w = r_w + gamma_w * np.max(online_next_w)
y_frozen_w = r_w + gamma_w * np.max(frozen_next_w)
print("online target:", round(float(y_online_w), 3))
print("frozen target:", round(float(y_frozen_w), 3))
```
▶ What you'll see: the two targets can differ because the online bootstrap teacher moved.

```python
target_W1_w, target_b1_w = online_W1_w.copy(), online_b1_w.copy()
target_W2_w, target_b2_w = online_W2_w.copy(), online_b2_w.copy()
_, _, synced_next_w = forward_w(xp_w, target_W1_w, target_b1_w, target_W2_w, target_b2_w)
print("after sync target:", round(float(r_w + gamma_w * np.max(synced_next_w)), 3))
```
▶ What you'll see: copying the online weights makes the target teacher catch up at a controlled moment.

*Why it's done this way:* bootstrapping from a moving target can create feedback loops: an overestimate can become the label that trains an even larger overestimate. Freezing the target network converts a slippery fixed-point problem into short supervised-learning phases with periodic teacher refreshes.

### 7. Putting DQN together on a tiny line world

Now we combine the pieces: epsilon-greedy actions gather transitions, replay samples mini-batches, the online MLP trains on TD targets from the target MLP, and the target network syncs periodically. The environment is deliberately tiny: states are positions `0..4`, action `0` moves left, action `1` moves right, state `4` gives `+1`, state `0` gives `-1`, and episodes start in the middle.

```python
def step_line_w(s, a):  # deterministic five-state line world.
    sp = int(np.clip(s + (1 if a == 1 else -1), 0, 4))
    done = sp in (0, 4)
    reward = 1.0 if sp == 4 else (-1.0 if sp == 0 else 0.0)
    return sp, reward, done

print("from state 2, left ->", step_line_w(2, 0))
print("from state 3, right ->", step_line_w(3, 1))
```
▶ What you'll see: reaching the right terminal state gives `+1`, while the left terminal state gives `-1`.

```python
def init_net_w(seed):
    rg = np.random.default_rng(seed)
    return [0.15 * rg.normal(size=(5, 12)), np.zeros(12), 0.15 * rg.normal(size=(12, 2)), np.zeros(2)]

def fwd_net_w(x, params):
    W1, b1, W2, b2 = params
    z = x @ W1 + b1
    h = np.maximum(0.0, z)
    q = h @ W2 + b2
    return z, h, q

params_w = init_net_w(3)
target_params_w = [p.copy() for p in params_w]
print("network layers:", params_w[0].shape, params_w[2].shape)
```
▶ What you'll see: a 5→12→2 network, still tiny enough to backprop by hand.

```python
def train_one_w(params, target_params, batch, lr=0.08, gamma=0.9):
    W1, b1, W2, b2 = params
    total = 0.0
    for s, a, r, sp, done in batch:
        x = one_hot_w(s, 5); xp = one_hot_w(sp, 5)
        z, h, q = fwd_net_w(x, params)
        _, _, qn = fwd_net_w(xp, target_params)
        y = r if done else r + gamma * np.max(qn)
        err = q[a] - y
        total += 0.5 * err ** 2
        dq = np.zeros(2); dq[a] = err
        dW2 = np.outer(h, dq); db2 = dq
        dz = (dq @ W2.T) * (z > 0)
        dW1 = np.outer(x, dz); db1 = dz
        W1 -= lr * dW1; b1 -= lr * db1; W2 -= lr * dW2; b2 -= lr * db2
    return total / len(batch)

print("one helper defined for replay mini-batches")
```
▶ What you'll see: the training helper implements TD target construction plus manual backprop for every sampled transition.

```python
replay_w = []
returns_curve_w = []
loss_curve_w = []
rng_train_w = np.random.default_rng(4)
for ep_w in range(80):
    s = 2
    ep_return = 0.0
    eps = max(0.05, 0.8 * (0.96 ** ep_w))
    for t in range(8):
        _, _, qvals = fwd_net_w(one_hot_w(s, 5), params_w)
        a = int(rng_train_w.integers(2)) if rng_train_w.random() < eps else int(np.argmax(qvals))
        sp, r, done = step_line_w(s, a)
        replay_w.append((s, a, r, sp, done))
        ep_return += r
        if len(replay_w) >= 8:
            ids = rng_train_w.choice(len(replay_w), size=8, replace=False)
            loss_curve_w.append(train_one_w(params_w, target_params_w, [replay_w[i] for i in ids]))
        s = sp
        if done:
            break
    if ep_w % 10 == 0:
        target_params_w = [p.copy() for p in params_w]
    returns_curve_w.append(ep_return)
print("first 10 returns:", returns_curve_w[:10])
print("last 10 mean return:", round(float(np.mean(returns_curve_w[-10:])), 3))
assert np.mean(returns_curve_w[-10:]) > 0.5
```
▶ What you'll see: early returns are noisy, but the final episodes mostly reach the +1 terminal state.

```python
policy_q_w = np.array([fwd_net_w(one_hot_w(s, 5), params_w)[2] for s in range(5)])
print("learned Q-values by state:\n", np.round(policy_q_w, 2))
print("greedy actions:", np.argmax(policy_q_w, axis=1))
assert int(np.argmax(policy_q_w[2])) == 1
```
▶ What you'll see: the middle state prefers action `1` (right), the action that can reach the positive terminal.

```python
fig, ax = plt.subplots(1, 2, figsize=(8, 3))
ax[0].plot(returns_curve_w, color="seagreen")
ax[0].set_title("7: episode returns")
ax[0].set_xlabel("episode"); ax[0].set_ylabel("return")
ax[1].plot(loss_curve_w, color="purple")
ax[1].set_title("TD loss on replay batches")
ax[1].set_xlabel("update"); ax[1].set_ylabel("loss")
plt.tight_layout(); plt.show()
```
▶ What you'll see: the return curve climbs toward `+1`; the TD loss is noisy because targets, replay samples, and exploration all change during training.

*Why it's done this way:* DQN is not one trick; it is the combination that makes bootstrapped neural value learning usable. Epsilon-greedy creates policy support, replay makes updates less correlated, the target network stabilizes labels, and manual TD backprop turns Bellman errors into weight changes.

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, random sampling, and every manual DQN calculation.
import matplotlib.pyplot as plt # load Matplotlib for value bars, heatmaps, and learning curves.
np.random.seed(0) # fix global randomness so all examples are reproducible.

def one_hot(s, n): # encode a discrete state as a feature vector for the neural Q-network.
    x = np.zeros(n) # start with all coordinates off.
    x[int(s)] = 1.0 # turn on the coordinate for the current state.
    return x # return the state feature vector.

def line_step(s, a): # define the tiny deterministic environment used throughout the lesson.
    sp = int(np.clip(int(s) + (1 if int(a) == 1 else -1), 0, 4)) # move right for action 1 and left for action 0.
    done = sp in (0, 4) # terminal states are the two ends of the line.
    reward = 1.0 if sp == 4 else (-1.0 if sp == 0 else 0.0) # right end is good, left end is bad, middle is neutral.
    return sp, reward, done # return next state, reward, and terminal flag.

def init_qnet(seed=0, n_states=5, hidden=8, n_actions=2): # initialize a tiny ReLU MLP Q-network.
    rng = np.random.default_rng(seed) # use a local generator so examples do not fight over global state.
    W1 = 0.15 * rng.normal(size=(n_states, hidden)) # first layer maps state features into hidden units.
    b1 = np.zeros(hidden) # hidden bias starts at zero.
    W2 = 0.15 * rng.normal(size=(hidden, n_actions)) # output layer emits one Q-value per action.
    b2 = np.zeros(n_actions) # output bias starts at zero.
    return [W1, b1, W2, b2] # keep parameters in a simple mutable list.

def q_forward(x, params): # run a forward pass through the Q-network.
    W1, b1, W2, b2 = params # unpack parameters for readability.
    z = x @ W1 + b1 # compute hidden pre-activations.
    h = np.maximum(0.0, z) # apply ReLU nonlinearity.
    q = h @ W2 + b2 # compute one Q-value per action.
    return z, h, q # return intermediates needed by manual backprop.

def dqn_update(params, target_params, batch, lr=0.08, gamma=0.9): # train on a mini-batch of replay transitions.
    W1, b1, W2, b2 = params # unpack mutable online parameters.
    total_loss = 0.0 # accumulate average TD loss for diagnostics.
    for s, a, r, sp, done in batch: # loop over sampled transitions.
        x = one_hot(s, 5) # encode current state.
        xp = one_hot(sp, 5) # encode next state.
        z, h, q = q_forward(x, params) # online prediction for current state.
        _, _, q_next = q_forward(xp, target_params) # frozen target prediction for next state.
        y = r if done else r + gamma * np.max(q_next) # build the Bellman target.
        err = q[int(a)] - y # derivative of half squared error for the chosen action.
        total_loss += 0.5 * err ** 2 # record scalar TD loss.
        dq = np.zeros_like(q) # start with no output gradient for unchosen actions.
        dq[int(a)] = err # place the TD error on the action that was actually taken.
        dW2 = np.outer(h, dq) # output-layer weight gradient.
        db2 = dq # output-layer bias gradient.
        dz = (dq @ W2.T) * (z > 0) # backpropagate through ReLU gates.
        dW1 = np.outer(x, dz) # input-layer weight gradient.
        db1 = dz # input-layer bias gradient.
        W1 -= lr * dW1; b1 -= lr * db1; W2 -= lr * dW2; b2 -= lr * db2 # gradient-descent step.
    return float(total_loss / len(batch)) # return mean mini-batch TD loss.

def greedy_action(params, s): # choose the highest-Q action in a state.
    return int(np.argmax(q_forward(one_hot(s, 5), params)[2])) # forward pass then argmax over actions.
```

## 🟢 Basics (warm-up)

### Basic 1 — Discount a short reward stream

**Goal.** Compute a discounted return, because DQN targets value future consequence rather than only the immediate reward. We build it in 2 steps.

```python
rewards_b1 = np.array([1.0, 0.0, 2.0]) # store a three-step reward stream with a delayed payoff.
gamma_b1 = 0.9 # choose the lesson discount factor.
weights_b1 = gamma_b1 ** np.arange(len(rewards_b1)) # compute [1, gamma, gamma^2].
print("weights:", np.round(weights_b1, 3)) # inspect how much each time step counts.
```

### Easy 2 — Train from replay on the line world

```python
        s_a1 = 2; ret_a1 = 0.0; eps_a1 = max(0.05, 0.9 * (decay_a1 ** ep_a1)) # decayed exploration.
        for _ in range(8): # episode cap.
            q_a1 = q_forward(one_hot(s_a1, 5), params_a1)[2] # online action values.
            a_a1 = int(rng_a1.integers(2)) if rng_a1.random() < eps_a1 else int(np.argmax(q_a1)) # epsilon-greedy.
            sp_a1, r_a1, done_a1 = line_step(s_a1, a_a1) # step environment.
            replay_a1.append((s_a1, a_a1, r_a1, sp_a1, done_a1)); ret_a1 += r_a1 # store evidence.
            if len(replay_a1) >= 8: # train from replay.
                ids_a1 = rng_a1.choice(len(replay_a1), size=8, replace=False) # sample mini-batch.
                dqn_update(params_a1, target_a1, [replay_a1[i] for i in ids_a1], lr=0.08, gamma=0.9) # update online network.
            s_a1 = sp_a1 # advance.
            if done_a1: break # terminal stop.
        if ep_a1 % 10 == 0: target_a1 = [p.copy() for p in params_a1] # sync target.
        returns_a1.append(ret_a1) # save return.
    return np.array(returns_a1) # return curve.
print("sweep helper ready") # confirm helper definition.
```

### Advanced 3 — Inspect target-sync intervals

**Goal.** Sweep target-network sync frequency, because labels that move too fast or too slowly can both make training harder. We build it in 4 steps.

```python
def train_sync_a3(sync_every_a3, seed_a3): # train with a chosen target sync interval.
    params_a3 = init_qnet(seed=seed_a3) # online network.

    replay_a3 = [] # memory.

    return np.array(losses_a3), params_a3 # return diagnostics and model.
```
