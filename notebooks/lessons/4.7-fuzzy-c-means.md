# 4.7 — Fuzzy C-Means

Fuzzy c-means (FCM) clusters unlabeled data by letting each point belong partly to every cluster, then updating each center by a weighted average of the data. In this lesson, you will build the membership normalization, fuzziness knob, weighted center update, objective, and convergence loop from scratch with NumPy, while treating the algorithm as a lens whose geometry depends on scaling and distance.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build fuzzy c-means one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math is made visible so the soft assignments never feel like magic. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix on its variables so it never clashes with the examples below.

import numpy as np  # arrays, distances, normalization, and weighted averages.

### 1. The unlabeled geometry FCM tries to explain

Fuzzy c-means starts with only a matrix $X\in\mathbb{R}^{n\times d}$: rows are examples, columns are measured coordinates, and no labels tell us which group is correct. The algorithm must therefore invent structure by choosing centers and measuring distances to them. We begin with two overlapping clouds so a hard left/right decision would be visibly too confident near the middle.

```python
left_w = np.random.normal(loc=[0.0, 0.0], scale=[0.45, 0.35], size=(18, 2))  # soft cloud near the origin.
right_w = np.random.normal(loc=[2.0, 0.4], scale=[0.55, 0.35], size=(18, 2))  # nearby cloud with overlap.
X_w = np.vstack([left_w, right_w])  # unlabeled data matrix: 36 examples by 2 coordinates.
print("X shape:", X_w.shape)  # shape bookkeeping matters in unsupervised code.
print("first three rows:\n", np.round(X_w[:3], 3))  # inspect raw coordinates.
assert X_w.shape == (36, 2)  # concrete shape check.
```
▶ What you'll see: a 36×2 array of points; no row contains a cluster label.

```python
plt.figure(figsize=(4.4, 3.4))  # compact scatterplot for the unlabeled geometry.
plt.scatter(X_w[:, 0], X_w[:, 1], s=35, color="gray", alpha=0.8)  # draw all points in one color.
plt.title("1: unlabeled points for FCM")  # emphasize that the plot has no labels.
plt.xlabel("feature 0"); plt.ylabel("feature 1")  # both axes are measured features.
plt.show()  # render the data cloud.
```
▶ What you'll see: two visible groups with a fuzzy boundary; middle points do not obviously belong 100% to either side.

*Why it's done this way:* FCM is an optimization lens over geometry. It cannot see “true labels”; it only sees coordinates and distances, so inspecting the raw shape and scale is the first mathematical step, not decoration.

### 2. From distances to unnormalized soft scores

A center should own nearby points more than faraway points. We first turn squared Euclidean distances $d_{ik}^2=\lVert x_i-\mu_k\rVert^2$ into positive scores $q_{ik}=1/(d_{ik}^2+\epsilon)$, where closer means larger. These are **not** memberships yet because their rows do not have to sum to 1.

```python
centers_w = np.array([[0.0, 0.0], [2.0, 0.4]])  # two provisional representatives.
probe_w = np.array([[0.2, 0.1], [1.0, 0.2], [1.9, 0.5]])  # three easy-to-audit points.
d2_w = np.sum((probe_w[:, None, :] - centers_w[None, :, :]) ** 2, axis=2)  # squared distances to each center.
print("squared distances:\n", np.round(d2_w, 3))  # rows=points, columns=centers.
assert d2_w.shape == (3, 2)  # pairwise point-center table.
```
▶ What you'll see: each point has one distance to the left center and one to the right center.

```python
q_w = 1.0 / (d2_w + 1e-9)  # inverse-distance scores: close centers receive large scores.
print("unnormalized q:\n", np.round(q_w, 3))  # q is positive but not row-normalized.
print("row sums:", np.round(q_w.sum(axis=1), 3))  # these are not 1 yet.
```
▶ What you'll see: the middle point has comparable scores for both centers, while edge points strongly favor the nearer center.

```python
plt.figure(figsize=(4.6, 3))  # visualize score strength for the three probes.
plt.imshow(q_w, cmap="viridis", aspect="auto")  # rows are probes, columns are centers.
plt.colorbar(label="q = 1 / distance²")  # high color means strong unnormalized pull.
plt.xticks([0, 1], ["center 0", "center 1"]); plt.yticks([0, 1, 2], ["near left", "middle", "near right"])
plt.title("2: closeness scores before normalization"); plt.show()
```
▶ What you'll see: large score mass sits under the nearest center, but row totals differ wildly.

*Why it's done this way:* distances are costs, so we invert them to make “closer” become “more responsible.” The tiny epsilon prevents division by zero if a point lies exactly on a center; it is numerical hygiene, not a modeling assumption.

### 3. Normalize scores into memberships

Memberships must be comparable across clusters for the same point, so each row is normalized: $r_{ik}=q_{ik}/\sum_j q_{ij}$. This is the same probability-style normalization shown in the lesson content: competing explanations share one unit of responsibility for each datum.

```python
simple_q_w = np.array([0.30, 0.70])  # lesson-content toy scores.
simple_r_w = simple_q_w / simple_q_w.sum()  # normalize by the row denominator.
print("simple responsibilities:", simple_r_w)  # [0.30, 0.70].
assert np.allclose(simple_r_w, [0.30, 0.70])  # concrete normalization check.
```
▶ What you'll see: scores `[0.30, 0.70]` already sum to 1, so responsibilities match them.

```python
r_w = q_w / q_w.sum(axis=1, keepdims=True)  # normalize every point's two scores.
print("memberships r:\n", np.round(r_w, 3))  # rows now sum to 1.
print("row sums:", np.round(r_w.sum(axis=1), 6))  # every row should be one.
assert np.allclose(r_w.sum(axis=1), 1.0)  # memberships exhaust each point's responsibility.
```
▶ What you'll see: edge points are near `[1,0]` or `[0,1]`; the middle point splits roughly evenly.

```python
plt.figure(figsize=(4.4, 3.2))  # show the split for the three probes.
plt.bar(np.arange(3) - 0.17, r_w[:, 0], width=0.34, label="cluster 0", color="steelblue")
plt.bar(np.arange(3) + 0.17, r_w[:, 1], width=0.34, label="cluster 1", color="darkorange")
plt.xticks([0, 1, 2], ["near left", "middle", "near right"]); plt.ylim(0, 1.05)
plt.ylabel("membership"); plt.title("3: normalized fuzzy memberships"); plt.legend(); plt.show()
```
▶ What you'll see: the middle point keeps partial membership in both clusters instead of being forced to one side.

*Why it's done this way:* normalization converts arbitrary score magnitudes into a fair within-point allocation. Without the denominator, a point near both centers would simply have large numbers rather than an interpretable split.

### 4. The fuzzifier m controls softness

Standard FCM uses a fuzzifier $m>1$. With distances $d_{ik}$, the membership formula is $$u_{ik}=\frac{1}{\sum_j (d_{ik}/d_{ij})^{2/(m-1)}}.$$ As $m\to1$, the exponent explodes and memberships become hard; as $m$ grows, memberships flatten toward equal sharing. The common default is $m=2$ because it is soft but still distance-sensitive.

```python
def fcm_membership_w(d2, m=2.0):  # compute standard FCM memberships from squared distances.
    d2 = np.maximum(np.asarray(d2, dtype=float), 1e-12)  # avoid zero-distance division.
    power = 1.0 / (m - 1.0)  # squared-distance version of 2/(m-1) for distances.
    ratios = (d2[:, :, None] / d2[:, None, :]) ** power  # compare each center to every competing center.
    return 1.0 / ratios.sum(axis=2)  # invert summed ratios to get memberships.

for m_w in [1.2, 2.0, 5.0]:  # hard-ish, standard, very fuzzy.
    U_tmp_w = fcm_membership_w(d2_w, m=m_w)  # memberships for the three probes.
    print("m=", m_w, "middle memberships=", np.round(U_tmp_w[1], 3))  # inspect the ambiguous point.
```
▶ What you'll see: the middle point's split becomes more even as `m` increases.

```python
m_grid_w = np.array([1.2, 1.5, 2.0, 3.0, 5.0])  # fuzzifier values to compare.
middle_left_w = np.array([fcm_membership_w(d2_w, m=m_val_w)[1, 0] for m_val_w in m_grid_w])  # cluster-0 membership of middle point.
print("middle cluster-0 memberships:", np.round(middle_left_w, 3))  # softness curve values.
plt.figure(figsize=(4.6, 3))
plt.plot(m_grid_w, middle_left_w, marker="o", color="purple")
plt.axhline(0.5, color="gray", linestyle="--")
plt.xlabel("fuzzifier m"); plt.ylabel("membership in cluster 0")
plt.title("4: larger m softens decisions"); plt.show()
```
▶ What you'll see: the curve moves toward 0.5, meaning the ambiguous point is shared more evenly.

*Why it's done this way:* $m$ is a bias-variance style knob. Small $m$ trusts the nearest center almost completely; larger $m$ admits uncertainty and prevents one slightly closer center from fully owning an ambiguous point.

### 5. Update centers with fuzzy weighted averages

After memberships are known, FCM updates each center by a weighted mean: $$\mu_k=\frac{\sum_i u_{ik}^m x_i}{\sum_i u_{ik}^m}.$$ The power $u^m$ makes strong memberships count disproportionately more than weak memberships, so a point that is 0.9 in a cluster shapes the center far more than a point that is 0.1 in that cluster.

```python
x_line_w = np.array([0.0, 1.0, 4.0])  # lesson-content one-dimensional points.
weights_w = np.array([0.8, 0.6, 0.1])  # audit-friendly weights for one representative.
mu_line_w = float(np.sum(weights_w * x_line_w) / np.sum(weights_w))  # weighted update.
print("weighted center:", round(mu_line_w, 3))  # (0.8*0 + 0.6*1 + 0.1*4)/(1.5).
assert round(mu_line_w, 3) == 0.667  # concrete number from the lesson content.
```
▶ What you'll see: the weighted update is 0.667, pulled toward points 0 and 1 because their weights dominate.

```python
U_w = fcm_membership_w(np.sum((X_w[:, None, :] - centers_w[None, :, :]) ** 2, axis=2), m=2.0)  # memberships for all points.
Um_w = U_w ** 2.0  # m=2 fuzzy weights used in the center update.
new_centers_w = (Um_w.T @ X_w) / Um_w.sum(axis=0)[:, None]  # weighted mean per cluster.
print("old centers:\n", np.round(centers_w, 3))
print("updated centers:\n", np.round(new_centers_w, 3))
assert new_centers_w.shape == (2, 2)  # two centers in two dimensions.
```
▶ What you'll see: each center moves toward the weighted mass of points that belong to it most strongly.

```python
plt.figure(figsize=(4.6, 3.4))
plt.scatter(X_w[:, 0], X_w[:, 1], c=U_w[:, 1], cmap="coolwarm", s=35, alpha=0.8)  # color by right-cluster membership.
plt.scatter(centers_w[:, 0], centers_w[:, 1], marker="x", s=120, color="black", label="old centers")
plt.scatter(new_centers_w[:, 0], new_centers_w[:, 1], marker="*", s=180, color="gold", edgecolor="black", label="updated centers")
plt.colorbar(label="membership in cluster 1"); plt.title("5: fuzzy weighted center update")
plt.legend(); plt.show()
```
▶ What you'll see: gold stars shift toward the densest fuzzy-owned regions, while boundary points influence both centers lightly.

*Why it's done this way:* a centroid is the minimizer of weighted squared distance. Using $u_{ik}^m$ means the update solves the best weighted representative for the current fuzzy ownerships, exactly matching the objective FCM is trying to lower.

### 6. Iterate assignment and update until the objective stabilizes

FCM alternates the two moves: compute memberships from current centers, then update centers from current memberships. The objective is $$J=\sum_i\sum_k u_{ik}^m\lVert x_i-\mu_k\rVert^2.$$ Each full pass should reduce or stabilize this quantity because memberships and centers are chosen to better match one another.

```python
def fcm_step_w(X, centers, m=2.0):  # one assign-update pass.
    d2 = np.sum((X[:, None, :] - centers[None, :, :]) ** 2, axis=2)  # point-center squared distances.
    U = fcm_membership_w(d2, m=m)  # fuzzy assignments from distances.
    Um = U ** m  # objective weights.
    new_centers = (Um.T @ X) / Um.sum(axis=0)[:, None]  # weighted centroids.
    obj = float(np.sum(Um * d2))  # FCM objective for the current centers.
    return U, new_centers, obj  # expose all pieces for inspection.

centers_loop_w = np.array([[-0.8, -0.4], [2.8, 0.9]])  # deliberately imperfect initialization.
print("initial centers:\n", centers_loop_w)  # inspect starting representatives.
```
▶ What you'll see: centers start outside the middle of the two point clouds.

```python
objectives_w = []  # store objective values across iterations.
for it_w in range(12):  # small, inspectable loop.
    U_loop_w, centers_next_w, obj_w = fcm_step_w(X_w, centers_loop_w, m=2.0)  # assign then update.
    objectives_w.append(obj_w)  # record before replacing centers.
    centers_loop_w = centers_next_w  # move centers for the next pass.
print("objectives:", np.round(objectives_w[:5], 3), "...", round(objectives_w[-1], 3))
assert objectives_w[-1] < objectives_w[0]  # optimization made progress.
```
▶ What you'll see: the objective drops quickly, then changes by smaller amounts.

```python
plt.figure(figsize=(4.6, 3))
plt.plot(objectives_w, marker="o", color="teal")
plt.xlabel("iteration"); plt.ylabel("FCM objective J")
plt.title("6: alternating updates lower J"); plt.show()
```
▶ What you'll see: a decreasing convergence curve, the visual audit that the assignment-update loop is working.

*Why it's done this way:* FCM is not a one-shot formula; memberships depend on centers and centers depend on memberships. Alternating is the practical way to solve this coupled fixed-point problem.

### 7. Scaling, stability, and interpreting the lens

Because FCM is distance-based, feature scale silently decides what “close” means. A feature measured in large units can dominate squared distance, making the algorithm discover scale artifacts instead of meaningful structure. A responsible unsupervised workflow therefore rescales features and checks whether the result is stable under small changes.

```python
X_bad_w = X_w.copy()  # create a deliberately mis-scaled version.
X_bad_w[:, 1] *= 20.0  # make feature 1 dominate squared distances.
d2_bad_w = np.sum((X_bad_w[:, None, :] - np.array([[0.0, 0.0], [2.0, 8.0]])[None, :, :]) ** 2, axis=2)  # distances in bad units.
print("median squared distance contribution x:", round(float(np.median((X_bad_w[:, 0] - X_bad_w[:, 0].mean()) ** 2)), 3))
print("median squared distance contribution y:", round(float(np.median((X_bad_w[:, 1] - X_bad_w[:, 1].mean()) ** 2)), 3))
```
▶ What you'll see: the y-coordinate contribution is much larger after multiplying it by 20.

```python
X_scaled_w = (X_bad_w - X_bad_w.mean(axis=0)) / X_bad_w.std(axis=0)  # simple standardization.
print("scaled means:", np.round(X_scaled_w.mean(axis=0), 6))  # near zero.
print("scaled stds:", np.round(X_scaled_w.std(axis=0), 6))  # near one.
assert np.allclose(X_scaled_w.std(axis=0), [1.0, 1.0])  # both features now comparable.
```
▶ What you'll see: standardization puts both coordinates on the same unitless scale.

```python
plt.figure(figsize=(7, 3))
plt.subplot(1, 2, 1); plt.scatter(X_bad_w[:, 0], X_bad_w[:, 1], s=25, color="crimson"); plt.title("bad scale")
plt.subplot(1, 2, 2); plt.scatter(X_scaled_w[:, 0], X_scaled_w[:, 1], s=25, color="seagreen"); plt.title("standardized")
plt.suptitle("7: distance changes when units change"); plt.show()
```
▶ What you'll see: the raw plot is stretched vertically; the standardized plot restores balanced geometry.

*Why it's done this way:* FCM optimizes the structure its distance function can see. Scaling and stability checks are not preprocessing chores; they define the mathematical lens used to discover clusters.

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, distances, normalization, weighted averages, and numerical checks.
import matplotlib.pyplot as plt # load Matplotlib so memberships, centers, and convergence can be inspected visually.
np.random.seed(0) # make all random examples reproducible across notebook runs.

def squared_distances(X, centers): # compute squared Euclidean distances from each row of X to each center.
    X = np.asarray(X, dtype=float) # ensure predictable floating-point arithmetic.
    centers = np.asarray(centers, dtype=float) # ensure centers can broadcast against X.
    return np.sum((X[:, None, :] - centers[None, :, :]) ** 2, axis=2) # return an n-by-k distance table.

def fcm_membership(d2, m=2.0): # convert squared distances into fuzzy c-means memberships.
    d2 = np.maximum(np.asarray(d2, dtype=float), 1e-12) # protect exact-center points from division by zero.
    ratios = (d2[:, :, None] / d2[:, None, :]) ** (1.0 / (m - 1.0)) # compare every center distance with every competitor.
    return 1.0 / ratios.sum(axis=2) # normalize the inverse ratio sums so each row sums to one.

def update_centers(X, U, m=2.0): # compute fuzzy weighted centroids from memberships.
    weights = U ** m # raise memberships to m so strong ownership counts more.
    return (weights.T @ X) / weights.sum(axis=0)[:, None] # weighted mean for each cluster.

def fcm_objective(X, centers, U, m=2.0): # compute the standard FCM objective J.
    return float(np.sum((U ** m) * squared_distances(X, centers))) # weighted squared distance summed over points and clusters.
```

### Basic 7 — Use the fuzzifier
