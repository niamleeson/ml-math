# 5.19 — Sampling Methods

Sampling methods estimate expectations when exact sums or integrals are too expensive. In this lesson, we use tiny discrete targets so every number can be checked by hand, then scale the same logic to Monte Carlo estimates, rejection sampling, importance sampling, proposal diagnostics, and effective sample size.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build sampling one idea at a time. Run each cell in order and read the printed intermediate values — every probability, ratio, acceptance rule, and weight is exposed. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, probabilities, random draws, and numerical checks.
import matplotlib.pyplot as plt  # compact visualizations for distributions and estimates.
np.random.seed(0)  # reproducibility for every stochastic walkthrough cell.
```

### 1. Expectations are weighted averages under a target distribution

The concrete problem is an expectation: a target distribution $p(x)$ says how likely each state is, and a function $h(x)$ says what quantity we care about. The exact answer is $\mathbb E_p[h(X)] = \sum_x h(x)p(x)$. Sampling becomes useful when this sum is too large or continuous, but we start with four states so the goal is visible.

```python
x_w = np.array([0., 1., 2., 3.])  # four possible states.
p_w = np.array([0.1, 0.2, 0.4, 0.3])  # target probabilities; sum to 1.
h_w = x_w.copy()  # estimate E[X], so h(x)=x.
expect_exact_w = float(np.sum(h_w * p_w))  # exact expectation under p.
print("target p:", p_w, "sum:", p_w.sum())
print("exact E_p[X]:", round(expect_exact_w, 3))
assert round(expect_exact_w, 3) == 1.900
```
▶ What you'll see: the target puts most mass on states 2 and 3, so the exact mean is 1.900.

```python
plt.figure(figsize=(4.4, 3))
plt.bar(x_w, p_w, color="teal")
plt.title("1: target distribution p(x)")
plt.xlabel("state x")
plt.ylabel("probability")
plt.xticks(x_w)
plt.show()
```
▶ What you'll see: state 2 has the tallest bar, followed by state 3; those bars dominate the expectation.

*Why it's done this way:* an expectation is not an ordinary average over states; it is a probability-weighted average. Sampling methods try to reproduce that weighting with random draws, so the target distribution is the object every later correction must respect.

### 2. Proposal distributions must cover the target

A proposal distribution $q(x)$ is something easy to sample from. We may draw from $q$ instead of $p$, but only if $q(x)>0$ wherever $p(x)>0$. Otherwise, a state with real target probability can never be sampled, and no weight can repair the missing evidence.

```python
q_uniform_w = np.ones_like(p_w) / len(p_w)  # easy proposal: every state equally likely.
ratio_w = p_w / q_uniform_w  # importance ratio p(x)/q(x).
print("uniform q:", q_uniform_w)
print("target/proposal ratios:", np.round(ratio_w, 3))
assert np.allclose(ratio_w, np.array([0.4, 0.8, 1.6, 1.2]))
```
▶ What you'll see: the ratios are `[0.4, 0.8, 1.6, 1.2]`; state 2 needs the largest upward correction.

```python
q_bad_support_w = np.array([0.5, 0.3, 0.2, 0.0])  # impossible to draw state 3.
missing_support_w = (p_w > 0) & (q_bad_support_w == 0)
print("bad q:", q_bad_support_w)
print("states with p>0 but q=0:", x_w[missing_support_w])
assert missing_support_w.tolist() == [False, False, False, True]
```
▶ What you'll see: state 3 has positive target mass but zero proposal mass, so estimates of E[X] must miss its contribution.

*Why it's done this way:* proposal sampling is a change of distribution. A change of distribution can reweight events that occur too often or too rarely, but it cannot create samples from an event the proposal makes impossible.

### 3. Rejection sampling keeps exact draws by accepting proposals

Rejection sampling draws $x\sim q$, then accepts it with probability $p(x)/(M q(x))$, where $M$ is an envelope satisfying $p(x)\le Mq(x)$ for every state. Accepted samples follow the target exactly, but proposals are wasted whenever the acceptance coin fails.

```python
M_w = float(np.max(ratio_w))  # smallest valid envelope for uniform q.
accept_prob_w = p_w / (M_w * q_uniform_w)  # per-state acceptance probability.
accept_rate_w = float(np.sum(q_uniform_w * accept_prob_w))  # expected acceptance under q.
print("M:", M_w)
print("acceptance probabilities:", np.round(accept_prob_w, 3))
print("expected acceptance rate:", round(accept_rate_w, 3))
assert M_w == 1.6 and round(accept_rate_w, 3) == 0.625
```
▶ What you'll see: the envelope height is 1.6, so the average acceptance rate is exactly 1/1.6 = 0.625.

```python
plt.figure(figsize=(4.4, 3))
plt.bar(x_w - 0.12, p_w, width=0.24, label="target p", color="teal")
plt.bar(x_w + 0.12, M_w * q_uniform_w, width=0.24, label="envelope Mq", color="orange")
plt.title("3: rejection envelope covers p")
plt.xlabel("state x")
plt.ylabel("mass")
plt.xticks(x_w)
plt.legend()
plt.show()
```
▶ What you'll see: the orange envelope sits at 0.4 for every state and just touches the target at state 2.

*Why it's done this way:* the accept probability is the vertical fraction of the envelope occupied by the target. Because accepted proposals have density proportional to $q(x)\,p(x)/(Mq(x))=p(x)/M$, the $q$ cancels and the accepted distribution is exactly $p$ after normalization.

### 4. Importance sampling keeps every draw by weighting it

Importance sampling avoids rejection. It draws from $q$ and multiplies each value by $p(x)/q(x)$, using the identity $\mathbb E_p[h(X)] = \mathbb E_q[h(X)p(X)/q(X)]$. Every draw contributes, but uneven weights can make the estimate noisy.

```python
weighted_terms_w = h_w * ratio_w  # h(x) p(x)/q(x) for each uniform proposal state.
importance_exact_w = float(np.mean(weighted_terms_w))  # E_q[...] under uniform q.
print("h(x) * p/q terms:", np.round(weighted_terms_w, 3))
print("importance estimate from enumerating q:", round(importance_exact_w, 3))
assert round(importance_exact_w, 3) == 1.900
```
▶ What you'll see: averaging `[0.0, 0.8, 3.2, 3.6]` under uniform q recovers the same 1.900 target mean.

```python
norm_weights_w = ratio_w / np.sum(ratio_w)  # normalized weights for the four equally-spaced proposal states.
self_norm_w = float(np.sum(norm_weights_w * h_w))
print("normalized weights:", np.round(norm_weights_w, 3))
print("self-normalized estimate:", round(self_norm_w, 3))
assert np.allclose(norm_weights_w, p_w)
assert round(self_norm_w, 3) == 1.900
```
▶ What you'll see: with one copy of every uniform state, normalized importance weights become exactly the target probabilities.

*Why it's done this way:* multiplying by $p/q$ corrects the mismatch between where samples came from and where the expectation lives. The numerator inserts target belief; the denominator removes proposal bias.

### 5. Effective sample size exposes weight variance

If a proposal misses the target shape, a few samples get huge weights and most samples barely count. Effective sample size (ESS) summarizes that concentration: $\mathrm{ESS}=(\sum_i w_i)^2/\sum_i w_i^2$. Equal weights give ESS equal to the number of samples; spiky weights give a much smaller number.

```python
q_spiky_w = np.array([0.7, 0.1, 0.1, 0.1])  # over-samples state 0 and under-samples high-target states.
w_spiky_w = p_w / q_spiky_w
w_uniform_w = p_w / q_uniform_w
ess_uniform_w = float((np.sum(w_uniform_w) ** 2) / np.sum(w_uniform_w ** 2))
ess_spiky_w = float((np.sum(w_spiky_w) ** 2) / np.sum(w_spiky_w ** 2))
print("uniform proposal ESS:", round(ess_uniform_w, 3), "out of", len(x_w))
print("spiky proposal weights:", np.round(w_spiky_w, 3))
print("spiky proposal ESS:", round(ess_spiky_w, 3), "out of", len(x_w))
assert ess_spiky_w < 3.0
```
▶ What you'll see: the bad proposal lowers ESS below 3 out of 4 because states 2 and 3 carry large corrective weights.

```python
plt.figure(figsize=(4.6, 3))
plt.bar(x_w - 0.12, w_uniform_w, width=0.24, label="uniform q", color="seagreen")
plt.bar(x_w + 0.12, w_spiky_w, width=0.24, label="spiky q", color="crimson")
plt.title("5: proposal choice controls weight variance")
plt.xlabel("state x")
plt.ylabel("importance weight p/q")
plt.xticks(x_w)
plt.legend()
plt.show()
```
▶ What you'll see: the spiky proposal creates very uneven weights, while the uniform proposal is milder.

*Why it's done this way:* ESS turns the vague warning “high-variance weights are bad” into a diagnostic number. If ESS is low, the estimator behaves as if it had far fewer useful samples than it actually drew.

### ✍️ Toy 3 · Rejection sampling accepts under an envelope

```python
import numpy as np
```

### ✍️ Toy 5 · Effective sample size detects spiky weights

```python
import numpy as np

t5_rng = np.random.default_rng(0)
```

## 🟢 Basics (warm-up)

### Basic 1 — Normalize a target table

**Goal.** Turn unnormalized scores into a probability distribution, because sampling methods need masses that sum to one before they can represent a target. We build it in 1 step.

```python
scores_b1 = np.array([1., 2., 4., 3.])
p_b1 = scores_b1 / np.sum(scores_b1)
print("normalized p:", p_b1, "sum:", p_b1.sum())
assert np.allclose(p_b1, np.array([0.1, 0.2, 0.4, 0.3]))
plt.figure(figsize=(4, 3))
plt.bar(np.arange(4), p_b1, color="teal")
plt.title("Basic 1: normalized target")
plt.xlabel("state")
plt.ylabel("probability")
plt.show()
```
▶ What you'll see: scores `[1,2,4,3]` become probabilities `[0.1,0.2,0.4,0.3]`.

👀 Takeaway: normalization turns local scores into a valid target distribution.

### Basic 2 — Compute an exact expectation

**Goal.** Compute $E_p[X]$ directly, because the exact value is the benchmark every sampling estimate tries to match. We build it in 1 step.

```python
x_b2 = np.array([0., 1., 2., 3.])
p_b2 = np.array([0.1, 0.2, 0.4, 0.3])
terms_b2 = x_b2 * p_b2
mean_b2 = float(np.sum(terms_b2))
print("contribution terms:", terms_b2)
print("exact mean:", round(mean_b2, 3))
assert round(mean_b2, 3) == 1.900
plt.figure(figsize=(4, 3))
plt.bar(x_b2, terms_b2, color="orange")
plt.title("Basic 2: x times p(x)")
plt.xlabel("state")
plt.ylabel("contribution to mean")
plt.show()
```
▶ What you'll see: state 3 contributes 0.9 and state 2 contributes 0.8, producing mean 1.900.

👀 Takeaway: an expectation is the sum of per-state contributions, not just the average state label.

### Basic 3 — Build a uniform proposal

**Goal.** Compare the target to an easy proposal, because the target/proposal ratio is the correction used by both rejection and importance sampling. We build it in 1 step.

```python
p_b3 = np.array([0.1, 0.2, 0.4, 0.3])
q_b3 = np.ones(4) / 4
ratio_b3 = p_b3 / q_b3
print("q:", q_b3)
print("p/q:", np.round(ratio_b3, 3))
assert np.allclose(ratio_b3, np.array([0.4, 0.8, 1.6, 1.2]))
plt.figure(figsize=(4, 3))
plt.bar(np.arange(4), ratio_b3, color="purple")
plt.title("Basic 3: target/proposal ratios")
plt.xlabel("state")
plt.ylabel("p(x)/q(x)")
plt.show()
```
▶ What you'll see: states underrepresented by the uniform proposal receive ratios above 1.

👀 Takeaway: the ratio says how strongly each proposal draw must be corrected toward the target.

### Basic 4 — Verify the importance identity

**Goal.** Show $E_p[X]=E_q[Xp(X)/q(X)]$ by enumeration, because this identity is the core of importance sampling. We build it in 1 step.

```python
x_b4 = np.array([0., 1., 2., 3.])
p_b4 = np.array([0.1, 0.2, 0.4, 0.3])
q_b4 = np.ones(4) / 4
weighted_b4 = x_b4 * p_b4 / q_b4
estimate_b4 = float(np.sum(q_b4 * weighted_b4))
print("weighted values h*p/q:", np.round(weighted_b4, 3))
print("E_q[h*p/q]:", round(estimate_b4, 3))
assert round(estimate_b4, 3) == 1.900
plt.figure(figsize=(4, 3))
plt.bar(x_b4, q_b4 * weighted_b4, color="seagreen")
plt.title("Basic 4: q-weighted corrected terms")
plt.xlabel("state")
plt.ylabel("q(x) h(x) p/q")
plt.show()
```
▶ What you'll see: after multiplying by q, the corrected bars match the target expectation contributions.

👀 Takeaway: importance sampling changes where samples come from, then algebraically corrects that change.

### Basic 5 — Find a rejection envelope

**Goal.** Choose the smallest $M$ with $p(x)\le Mq(x)$, because rejection sampling is only valid when the envelope covers the target everywhere. We build it in 1 step.

```python
p_b5 = np.array([0.1, 0.2, 0.4, 0.3])
q_b5 = np.ones(4) / 4
M_b5 = float(np.max(p_b5 / q_b5))
envelope_b5 = M_b5 * q_b5
print("M:", M_b5)
print("envelope:", envelope_b5)
assert M_b5 == 1.6
assert np.all(envelope_b5 >= p_b5)
plt.figure(figsize=(4, 3))
plt.bar(np.arange(4) - 0.12, p_b5, width=0.24, label="p")
plt.bar(np.arange(4) + 0.12, envelope_b5, width=0.24, label="Mq")
plt.title("Basic 5: valid envelope")
plt.legend()
plt.show()
```
▶ What you'll see: the envelope equals 0.4 everywhere and never dips below the target.

👀 Takeaway: $M$ is a worst-case ratio, not an average ratio.

### Basic 6 — Compute acceptance probabilities

**Goal.** Convert the envelope into per-state acceptance probabilities, because rejection sampling keeps a proposal only with probability $p/(Mq)$. We build it in 1 step.

```python
p_b6 = np.array([0.1, 0.2, 0.4, 0.3])
q_b6 = np.ones(4) / 4
M_b6 = 1.6
accept_b6 = p_b6 / (M_b6 * q_b6)
rate_b6 = float(np.sum(q_b6 * accept_b6))
print("accept probabilities:", np.round(accept_b6, 3))
print("expected accept rate:", round(rate_b6, 3))
assert np.allclose(accept_b6, np.array([0.25, 0.5, 1.0, 0.75]))
assert round(rate_b6, 3) == 0.625
plt.figure(figsize=(4, 3))
```

### Advanced 1 — Reduce variance by oversampling an important region

**Goal.** Estimate $P(X=3)$ with two proposals, because a proposal that samples important rare-ish regions more often can reduce variance after weighting. We build it in 1 step.

```python
x_a1 = np.array([0, 1, 2, 3])
p_a1 = np.array([0.1, 0.2, 0.4, 0.3])
q_uniform_a1 = np.ones(4) / 4
q_tail_a1 = np.array([0.05, 0.15, 0.30, 0.50])
rng_a1 = np.random.default_rng(11)
reps_a1 = 300
n_a1 = 80
ests_uniform_a1 = []
ests_tail_a1 = []
for rep_a1 in range(reps_a1):
    iu_a1 = rng_a1.choice(4, size=n_a1, p=q_uniform_a1)
    it_a1 = rng_a1.choice(4, size=n_a1, p=q_tail_a1)
    hu_a1 = (x_a1[iu_a1] == 3).astype(float)
    ht_a1 = (x_a1[it_a1] == 3).astype(float)
    ests_uniform_a1.append(float(np.mean(hu_a1 * p_a1[iu_a1] / q_uniform_a1[iu_a1])))
    ests_tail_a1.append(float(np.mean(ht_a1 * p_a1[it_a1] / q_tail_a1[it_a1])))
var_uniform_a1 = float(np.var(ests_uniform_a1))
var_tail_a1 = float(np.var(ests_tail_a1))
print("mean estimates:", round(float(np.mean(ests_uniform_a1)), 3), round(float(np.mean(ests_tail_a1)), 3), "truth:", 0.3)
print("variance uniform/tail:", round(var_uniform_a1, 5), round(var_tail_a1, 5))
assert var_tail_a1 < var_uniform_a1
plt.figure(figsize=(5, 3))
plt.hist(ests_uniform_a1, bins=20, alpha=0.6, label="uniform q")
plt.hist(ests_tail_a1, bins=20, alpha=0.6, label="tail-focused q")
plt.axvline(0.3, color="black", linestyle="--", label="truth")
plt.title("Advanced 1: proposal affects estimator variance")
plt.xlabel("estimated P(X=3)")
plt.legend()
plt.show()
```
▶ What you'll see: the tail-focused proposal makes the repeated estimates cluster more tightly around 0.3.

👀 Takeaway: proposal design can target the parts of the distribution that matter most for the chosen function $h$.
