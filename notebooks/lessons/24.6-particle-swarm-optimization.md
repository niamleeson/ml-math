# 24.6 — Particle Swarm Optimization

Particle swarm optimization (PSO) treats optimization as coordinated motion. A swarm of candidate solutions flies through a continuous search space, and each particle updates its velocity from three forces: inertia, its own best-known position, and the swarm's best-known position.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build particle swarm optimization one idea at a time. Run each cell in order and read the printed intermediate values — positions, velocities, personal bests, global bests, and the velocity-update math are all shown. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np
import matplotlib.pyplot as plt
np.random.seed(0)

def sphere_w(X_w):
    return np.sum(X_w ** 2, axis=-1)

def contour_w(title_w, positions_w, velocities_w=None, pbest_w=None, gbest_w=None):
    grid_w = np.linspace(-5, 5, 90)
    Xg_w, Yg_w = np.meshgrid(grid_w, grid_w)
    Z_w = Xg_w ** 2 + Yg_w ** 2
    plt.figure(figsize=(5, 4))
    plt.contour(Xg_w, Yg_w, Z_w, levels=18, cmap="viridis")
    plt.scatter(positions_w[:, 0], positions_w[:, 1], color="white", edgecolor="black", s=55, label="particles")
    if velocities_w is not None:
        plt.quiver(positions_w[:, 0], positions_w[:, 1], velocities_w[:, 0], velocities_w[:, 1], angles="xy", scale_units="xy", scale=1, color="crimson", width=0.006, label="velocity")
    if pbest_w is not None:
        plt.scatter(pbest_w[:, 0], pbest_w[:, 1], marker="x", color="orange", s=75, label="pbest")
    if gbest_w is not None:
        plt.scatter([gbest_w[0]], [gbest_w[1]], marker="*", color="red", s=180, label="gbest")
    plt.xlim(-5, 5); plt.ylim(-5, 5)
    plt.xlabel("x0"); plt.ylabel("x1"); plt.title(title_w); plt.legend(loc="upper right")
    plt.show()
```

### 1. PSO turns black-box optimization into moving particles

The concrete problem is continuous black-box optimization: we can evaluate a candidate point, but we do not have a gradient telling us where to step. PSO keeps many candidate points at once. Each point is a particle with a position `x` and a velocity `v`; the optimizer improves by changing the swarm's motion rather than by recombining genomes.

```python
positions_w = np.array([[-4.0, 3.2], [-2.2, -3.6], [1.0, 4.0], [3.8, 1.7], [4.2, -2.8]])
velocities_w = np.array([[0.8, -0.5], [0.5, 0.7], [-0.3, -0.8], [-0.7, -0.2], [-0.9, 0.4]])
values_w = sphere_w(positions_w)
print("particle objective values:", np.round(values_w, 3))
print("best starting particle:", int(np.argmin(values_w)))
assert values_w.shape == (5,)
```
▶ What you'll see: each particle is just a real-valued candidate point with an objective value.

```python
contour_w("1: particles as moving candidate solutions", positions_w, velocities_w); plt.show()
```
▶ What you'll see: particles scattered on a 2-D bowl with arrows showing the current motion each candidate will carry into the next update.

*Why it's done this way: a swarm gives many simultaneous probes of a landscape, so the optimizer can explore several regions before deciding which discovered region deserves imitation.*

### 2. Personal and global memory are different signals

Each particle stores the best place **it personally** has found, called `pbest`. The swarm also stores the best place found by **anyone**, called `gbest`. These two memories matter because a particle that only chases the global best can collapse into the crowd too quickly, while personal memory lets several promising basins survive long enough to be compared.

```python
pbest_w = np.array([[-4.0, 3.2], [-1.5, -2.2], [0.7, 2.5], [2.6, 1.2], [2.0, -1.5]])
pbest_values_w = sphere_w(pbest_w)
gbest_w = pbest_w[int(np.argmin(pbest_values_w))]
print("personal best values:", np.round(pbest_values_w, 3))
print("global best:", np.round(gbest_w, 3), "value:", round(float(np.min(pbest_values_w)), 3))
assert np.allclose(gbest_w, [2.0, -1.5])
```
▶ What you'll see: every particle has its own memory, while only one remembered point is the current global champion.

```python
contour_w("2: pbest markers and one gbest star", positions_w, velocities_w, pbest_w, gbest_w); plt.show()
```
▶ What you'll see: orange x-marks can differ from current positions, and the red star marks the best remembered location in the whole swarm.

*Why it's done this way: personal memory preserves independent experience, while global memory spreads the best discovery so the swarm can exploit it.*

### 3. The velocity update mixes inertia, cognitive pull, and social pull

The PSO update is

$$v_i\leftarrow wv_i+c_1r_1(p_i-x_i)+c_2r_2(g-x_i),\qquad x_i\leftarrow x_i+v_i.$$

Inertia says "keep moving as you were." The cognitive term says "return toward the best place you personally found." The social term says "move toward the best place anyone found." The random vectors `r1` and `r2` make those attractions stochastic so particles do not all trace the same deterministic path.

```python
x_w = np.array([0.0, 4.0])
v_w = np.array([0.0, 0.0])
p_w = x_w.copy()
g_w = np.array([0.0, 0.0])
w_w, c1_w, c2_w = 0.5, 1.0, 1.0
r1_w = np.array([0.2, 0.2])
r2_w = np.array([0.3, 0.3])
inertia_w = w_w * v_w
cognitive_w = c1_w * r1_w * (p_w - x_w)
social_w = c2_w * r2_w * (g_w - x_w)
v_new_w = inertia_w + cognitive_w + social_w
x_new_w = x_w + v_new_w
print("inertia:", inertia_w, "cognitive:", cognitive_w, "social:", social_w)
print("new velocity:", v_new_w, "new position:", x_new_w)
assert np.allclose(v_new_w, [0.0, -1.2]) and np.allclose(x_new_w, [0.0, 2.8])
```
▶ What you'll see: only the social term is nonzero, so the particle moves downward toward the global best.

```python
pts_w = np.vstack([x_w, x_new_w, g_w])
plt.figure(figsize=(4.5, 4))
plt.contour(*np.meshgrid(np.linspace(-2, 2, 60), np.linspace(-1, 5, 60)), np.meshgrid(np.linspace(-2, 2, 60), np.linspace(-1, 5, 60))[0] ** 2 + np.meshgrid(np.linspace(-2, 2, 60), np.linspace(-1, 5, 60))[1] ** 2, levels=15, cmap="viridis")
plt.scatter([x_w[0]], [x_w[1]], color="white", edgecolor="black", s=70, label="old x")
plt.quiver([x_w[0]], [x_w[1]], [v_new_w[0]], [v_new_w[1]], angles="xy", scale_units="xy", scale=1, color="crimson", width=0.007, label="new v")
plt.scatter([x_new_w[0]], [x_new_w[1]], color="orange", s=70, label="new x")
plt.scatter([g_w[0]], [g_w[1]], marker="*", color="red", s=180, label="gbest")
plt.xlim(-2, 2); plt.ylim(-1, 5); plt.xlabel("x0"); plt.ylabel("x1"); plt.title("3: one PSO velocity update"); plt.legend(); plt.show()
```
▶ What you'll see: the arrow points from `(0, 4)` to `(0, 2.8)`, exactly matching the hand-computed velocity.

*Why it's done this way: velocity is a reusable state variable, so PSO can overshoot, coast, turn, and damp motion instead of taking memoryless jumps.*

### 4. Hyperparameters control exploration versus exploitation and bounds keep motion feasible

The coefficients decide swarm behavior. Large inertia preserves speed and exploration. Large cognitive weight makes particles trust their own histories. Large social weight makes them imitate the global best. Position bounds are part of the operator because an update can easily leave the feasible domain.

```python
velocity_w = np.array([1.0, -0.5])
inertias_w = np.array([0.2, 0.7, 1.0])
speeds_w = np.array([np.linalg.norm(wi_w * velocity_w) for wi_w in inertias_w])
print("inertia-only speeds:", np.round(speeds_w, 3))
assert np.allclose(np.round(speeds_w, 3), [0.224, 0.783, 1.118])
```
▶ What you'll see: higher inertia keeps more of the old speed.

```python
start_w = np.array([[4.4, 4.0], [3.8, -4.2], [-4.6, 3.5]])
vels_w = np.array([[1.0, 0.8], [0.9, -1.2], [-0.8, 0.5]])
raw_next_w = start_w + vels_w
clipped_next_w = np.clip(raw_next_w, -5, 5)
plt.figure(figsize=(5, 4))
plt.contour(*np.meshgrid(np.linspace(-5, 5, 80), np.linspace(-5, 5, 80)), np.meshgrid(np.linspace(-5, 5, 80), np.linspace(-5, 5, 80))[0] ** 2 + np.meshgrid(np.linspace(-5, 5, 80), np.linspace(-5, 5, 80))[1] ** 2, levels=18, cmap="viridis")
plt.scatter(start_w[:, 0], start_w[:, 1], color="white", edgecolor="black", label="start")
plt.quiver(start_w[:, 0], start_w[:, 1], vels_w[:, 0], vels_w[:, 1], angles="xy", scale_units="xy", scale=1, color="crimson", label="raw velocity")
plt.scatter(clipped_next_w[:, 0], clipped_next_w[:, 1], color="orange", label="bounded next")
plt.xlim(-5.5, 5.5); plt.ylim(-5.5, 5.5); plt.xlabel("x0"); plt.ylabel("x1"); plt.title("4: updates must respect search bounds"); plt.legend(); plt.show()
```
▶ What you'll see: some raw arrows leave the square search region, while the bounded next positions stay feasible.

*Why it's done this way: PSO is a dynamical system, so coefficient choices and boundary handling directly determine whether the swarm explores, converges, or flies out of the valid space.*

## 🛠️ Setup

```python
import numpy as np
import matplotlib.pyplot as plt
np.random.seed(0)

def sphere(X):
    X = np.asarray(X, dtype=float)
    return np.sum(X ** 2, axis=-1)

def rastrigin(X):
    X = np.asarray(X, dtype=float)
    return 20.0 + np.sum(X ** 2 - 10.0 * np.cos(2.0 * np.pi * X), axis=-1)

def pso_update(pos, vel, pbest, gbest, w=0.7, c1=1.4, c2=1.4, rng=None, bounds=(-5, 5)):
    if rng is None:
        rng = np.random.default_rng(0)
    r1 = rng.random(pos.shape)
    r2 = rng.random(pos.shape)
    new_vel = w * vel + c1 * r1 * (pbest - pos) + c2 * r2 * (gbest - pos)
    new_pos = np.clip(pos + new_vel, bounds[0], bounds[1])
    return new_pos, new_vel

def draw_surface(title, pos, vel=None, pbest=None, gbest=None, func=sphere, bounds=(-5, 5)):
    xs = np.linspace(bounds[0], bounds[1], 100)
    ys = np.linspace(bounds[0], bounds[1], 100)
    Xg, Yg = np.meshgrid(xs, ys)
    Z = func(np.stack([Xg, Yg], axis=-1))
    plt.figure(figsize=(5, 4))
    plt.contour(Xg, Yg, Z, levels=22, cmap="viridis")
    plt.scatter(pos[:, 0], pos[:, 1], color="white", edgecolor="black", s=55, label="particles")
    if vel is not None:
        plt.quiver(pos[:, 0], pos[:, 1], vel[:, 0], vel[:, 1], angles="xy", scale_units="xy", scale=1, color="crimson", width=0.006, label="velocity")
    if pbest is not None:
        plt.scatter(pbest[:, 0], pbest[:, 1], marker="x", color="orange", s=75, label="pbest")
    if gbest is not None:
        plt.scatter([gbest[0]], [gbest[1]], marker="*", color="red", s=180, label="gbest")
    plt.xlim(bounds); plt.ylim(bounds); plt.xlabel("x0"); plt.ylabel("x1"); plt.title(title); plt.legend(loc="upper right")
    plt.show()
```

#### B5. Compute the inertia term

**Goal.** Isolate `w*v`, because inertia controls how much a particle keeps moving in its old direction. We build it in 2 steps.

```python
pos_b5 = np.array([[1.0, 2.0], [-2.0, -1.0], [3.0, 0.0]])
vel_b5 = np.array([[1.0, -0.5], [0.5, 0.7], [-0.8, 0.2]])
```

👀 Takeaway: larger inertia preserves exploration; smaller inertia damps motion.

#### B6. Compute the cognitive pull

**Goal.** Build `c1*r1*(pbest-x)`, because cognitive attraction pulls each particle back toward its own best memory. We build it in 2 steps.

```python
pos_b6 = np.array([[2.0, 3.0], [-3.0, 1.0], [1.0, -4.0]])
pbest_b6 = np.array([[1.0, 1.0], [-2.0, 0.0], [0.5, -2.0]])
r1_b6 = np.full(pos_b6.shape, 0.5)

```

▶ What you'll see: arrows point from each particle toward its own orange personal-best marker.

👀 Takeaway: the cognitive term keeps multiple remembered basins alive.

#### B7. Compute the social pull

**Goal.** Build `c2*r2*(gbest-x)`, because social attraction shares the swarm's best discovery. We build it in 2 steps.

```python
pos_b7 = np.array([[3.0, 3.0], [-4.0, 1.0], [1.5, -3.0]])
gbest_b7 = np.array([0.0, 0.0])
r2_b7 = np.full(pos_b7.shape, 0.4)
```

▶ What you'll see: every arrow points toward the same red global-best star.

#### B8. Combine one full velocity update

**Goal.** Add inertia, cognitive, and social pieces, because PSO's behavior comes from their vector sum. We build it in 2 steps.

```python
x_b8 = np.array([[0.0, 4.0]])
v_b8 = np.array([[0.0, 0.0]])
pbest_b8 = x_b8.copy()
gbest_b8 = np.array([0.0, 0.0])
r1_b8 = np.array([[0.2, 0.2]])
r2_b8 = np.array([[0.3, 0.3]])
new_v_b8 = 0.5 * v_b8 + 1.0 * r1_b8 * (pbest_b8 - x_b8) + 1.0 * r2_b8 * (gbest_b8 - x_b8)
new_x_b8 = x_b8 + new_v_b8
print("new velocity:", new_v_b8[0], "new position:", new_x_b8[0])
assert np.allclose(new_v_b8[0], [0.0, -1.2])
```

```python

```
▶ What you'll see: the particle moves from `(0, 4)` toward the current global best.

👀 Takeaway: the velocity formula is a vector sum of old motion plus two memory pulls.

#### B10. Run a tiny PSO loop

**Goal.** Repeat updates for several iterations, because convergence emerges from many memory-guided moves. We build it in 2 steps.

```python
rng_b10 = np.random.default_rng(10)
pos_b10 = rng_b10.uniform(-4, 4, size=(8, 2))
vel_b10 = rng_b10.uniform(-0.5, 0.5, size=(8, 2))
pbest_b10 = pos_b10.copy()
pbest_val_b10 = sphere(pbest_b10)
best_curve_b10 = []
for _ in range(25):
    gbest_b10 = pbest_b10[int(np.argmin(pbest_val_b10))].copy()
    pos_b10, vel_b10 = pso_update(pos_b10, vel_b10, pbest_b10, gbest_b10, rng=rng_b10)
    vals_b10 = sphere(pos_b10)
    improved_b10 = vals_b10 < pbest_val_b10
    pbest_b10[improved_b10] = pos_b10[improved_b10]
    pbest_val_b10[improved_b10] = vals_b10[improved_b10]
    best_curve_b10.append(float(np.min(pbest_val_b10)))
print("best start -> end:", round(best_curve_b10[0], 4), "->", round(best_curve_b10[-1], 4))
assert best_curve_b10[-1] <= best_curve_b10[0]
```

```python
plt.figure(figsize=(5, 3))
plt.plot(best_curve_b10, color="teal", marker="o", markersize=3)
plt.title("B10: best fitness over PSO iterations")
plt.xlabel("iteration"); plt.ylabel("best sphere value")
plt.show()
```
▶ What you'll see: the best objective value generally falls as the swarm discovers better positions.

👀 Takeaway: PSO improves by updating memories after each movement step.

#### A5. Use local neighborhoods instead of one global best

**Goal.** Compare global-best and ring-neighborhood PSO, because local social memory can preserve diversity longer. We build it in 3 steps.


```python
def run_variant_a5(local):
    rng_local_a5 = np.random.default_rng(66)
    pos = initial_pos_a5.copy()
    vel = initial_vel_a5.copy()
    pbest = pos.copy()
    pbest_val = rastrigin(pbest)
    spreads, bests = [], []
    for _ in range(70):
        if local:
            social = np.empty_like(pos)
            for i in range(len(pos)):
                neigh = [(i - 1) % len(pos), i, (i + 1) % len(pos)]
                social[i] = pbest[neigh[int(np.argmin(pbest_val[neigh]))]]
        else:
            social = np.repeat(pbest[int(np.argmin(pbest_val))][None, :], len(pos), axis=0)
        r1 = rng_local_a5.random(pos.shape)
        r2 = rng_local_a5.random(pos.shape)
        vel = 0.65 * vel + 1.4 * r1 * (pbest - pos) + 1.4 * r2 * (social - pos)
        pos = np.clip(pos + vel, -5.12, 5.12)
        vals = rastrigin(pos)
        improved = vals < pbest_val
        pbest[improved] = pos[improved]
        pbest_val[improved] = vals[improved]
        spreads.append(float(np.mean(np.linalg.norm(pos - np.mean(pos, axis=0), axis=1))))
        bests.append(float(np.min(pbest_val)))
    return np.array(spreads), np.array(bests)
spread_global_a5, best_global_a5 = run_variant_a5(local=False)
spread_ring_a5, best_ring_a5 = run_variant_a5(local=True)
print("final best global/ring:", round(best_global_a5[-1], 3), round(best_ring_a5[-1], 3))
```
