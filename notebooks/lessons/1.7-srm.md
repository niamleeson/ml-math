# 1.7 · Structural Risk Minimization

Structural Risk Minimization (SRM) chooses model complexity by minimizing a bound-like score: training error plus a complexity penalty. Instead of fixing one hypothesis class, we climb a nested ladder $\mathcal{H}_1\subset\mathcal{H}_2\subset\cdots$ and stop where the sum is smallest.

## 📖 Concept walkthrough — build it from scratch

Before the worked examples, we build SRM one idea at a time. Run each cell in order and inspect the printed intermediate values. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix so it never clashes with the exercises below.

```python
import numpy as np  # arrays, logs, square roots, and polynomial fitting.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducible tiny data and noise.
```

### 1. A nested hypothesis ladder

SRM starts by arranging candidate model classes from simple to rich: $\mathcal{H}_1\subset\mathcal{H}_2\subset\mathcal{H}_3\subset\cdots$. The nesting matters because climbing the ladder can only add options; it should never remove a simpler model. We will use polynomial degree as the concrete ladder: constants, lines, quadratics, cubics, and so on.

```python
x_w = np.linspace(-1, 1, 9)  # tiny one-dimensional inputs.
y_w = 0.3 + 0.8 * x_w - 0.6 * x_w**2 + np.array([0.05, -0.03, 0.02, -0.04, 0.0, 0.04, -0.02, 0.03, -0.05])  # smooth signal plus fixed noise.
degrees_w = np.arange(0, 6)  # H_0 through H_5, ordered by polynomial degree.
print("x:", np.round(x_w, 2))  # inspect inputs.
print("y:", np.round(y_w, 3))  # inspect targets.
```
▶ What you'll see: a small regression dataset that a quadratic can explain better than a constant or line.

```python
fits_w = []  # store fitted coefficients for each rung.
for d_w in degrees_w:  # fit each class in the nested ladder.
    coef_w = np.polyfit(x_w, y_w, d_w)  # ERM inside the degree-d class under squared loss.
    pred_w = np.polyval(coef_w, x_w)  # training predictions.
    mse_w = float(np.mean((y_w - pred_w) ** 2))  # empirical risk R_S.
    fits_w.append((coef_w, mse_w))  # keep both fit and error.
    print(f"degree {d_w}: train MSE={mse_w:.5f}")  # training error never increases much as degree grows.
```
▶ What you'll see: empirical risk falls as the class gets richer, because higher-degree polynomials contain lower-degree ones.

```python
xx_w = np.linspace(-1.05, 1.05, 200)  # dense grid for smooth curves.
plt.figure(figsize=(5, 3.4))  # compact visualization of several ladder rungs.
plt.scatter(x_w, y_w, color="black", label="data")  # show the sample.
for d_w, color_w in zip([0, 1, 2, 5], ["gray", "teal", "orange", "crimson"]):  # representative classes.
    plt.plot(xx_w, np.polyval(fits_w[d_w][0], xx_w), color=color_w, label=f"degree {d_w}")  # fitted curve.
plt.title("1: nested polynomial classes")  # concept id in title.
plt.xlabel("x"); plt.ylabel("y"); plt.legend(); plt.show()  # render the ladder.
```
▶ What you'll see: richer curves hug the data more closely, but that is not yet a guarantee of lower true error.

*Why it's done this way: a nested ladder gives SRM a controlled menu of increasing capacity, so the selection problem becomes “how high should we climb?” rather than “which unrelated class should we guess?”*

### 2. ERM on one rung is not enough

Inside a fixed class, ERM chooses the model with lowest training error. But if we only compare training errors across rungs, the richest class almost always wins because it has the largest menu. SRM keeps ERM inside each rung, then adds a complexity charge before comparing rungs.

```python
train_errors_w = np.array([mse_w for _, mse_w in fits_w])  # collect empirical risks.
best_erm_degree_w = int(degrees_w[np.argmin(train_errors_w)])  # naive ERM across all rungs.
print("training errors:", np.round(train_errors_w, 5))  # inspect empirical risks.
print("naive ERM chooses degree:", best_erm_degree_w)  # usually the richest available rung.
```
▶ What you'll see: the lowest training error occurs at a high degree, even if the data-generating pattern is simpler.

```python
plt.figure(figsize=(4.6, 3))  # diagnostic plot of empirical risk only.
plt.plot(degrees_w, train_errors_w, marker="o", color="steelblue")  # training error curve.
plt.scatter([best_erm_degree_w], [train_errors_w[best_erm_degree_w]], color="red", zorder=3)  # naive ERM winner.
plt.title("2: ERM alone rewards richness")  # concept id.
plt.xlabel("polynomial degree (rung)"); plt.ylabel("training MSE"); plt.show()  # display.
```
▶ What you'll see: training error mostly decreases, so it cannot by itself decide when to stop.

*Why it's done this way: ERM is still useful locally — it finds the best model in each $\mathcal{H}_k$ — but comparing classes requires a second term that prices the extra freedom.*

### 3. The finite-class penalty

A generalization-bound penalty has the shape

$$\sqrt{\frac{\ln|\mathcal{H}_k|+\ln(1/\delta)}{2m}}.$$

The numerator grows with class size $|\mathcal{H}_k|$, while the denominator grows with sample size $m$. The square root means uncertainty shrinks like $1/\sqrt{m}$: more data makes every rung safer, but richer rungs still pay more.

```python
m_w = 200  # sample size used in the authored lesson's four-rung example.
delta_w = 0.05  # 95% confidence means ln(1/delta)=ln(20).
H_sizes_w = np.array([2, 16, 256, 65536], dtype=float)  # four nested finite classes.
penalties_w = np.sqrt((np.log(H_sizes_w) + np.log(1 / delta_w)) / (2 * m_w))  # complexity penalties.
print("ln|H|:", np.round(np.log(H_sizes_w), 3))  # complexity part.
print("penalties:", np.round(penalties_w, 3))  # should match the lesson values.
assert np.allclose(np.round(penalties_w, 3), [0.096, 0.120, 0.146, 0.188])  # grounded numbers.
```
▶ What you'll see: penalties rise from 0.096 to 0.188 as the class size grows.

```python
sample_sizes_w = np.array([50, 200, 800, 3200])  # show the 1/sqrt(m) behavior.
penalty_rung3_w = np.sqrt((np.log(256) + np.log(1 / delta_w)) / (2 * sample_sizes_w))  # fixed class.
print("rung-3 penalties as m grows:", np.round(penalty_rung3_w, 3))  # uncertainty shrinks.
plt.figure(figsize=(4.6, 3))  # plot penalty versus data size.
plt.plot(sample_sizes_w, penalty_rung3_w, marker="o", color="purple")  # decreasing curve.
plt.title("3: penalty shrinks with data")  # concept id.
plt.xlabel("sample size m"); plt.ylabel("penalty"); plt.show()  # display.
```
▶ What you'll see: quadrupling $m$ roughly halves the penalty.

*Why it's done this way: the penalty is the price of trusting ERM after searching a class; it grows with richness and shrinks with data, exactly matching the bias-complexity tradeoff.*

### 4. SRM chooses the lowest bound-like sum

SRM minimizes training error plus penalty over the ladder:

$$\hat k=\arg\min_k\left[R_S(\hat h_k)+\sqrt{\frac{\ln|\mathcal{H}_k|+\ln(1/\delta)}{2m}}\right].$$

The empirical term usually falls as classes become richer; the penalty rises. Their sum is often U-shaped, so SRM can stop before the training-error minimum.

```python
emp_w = np.array([0.30, 0.15, 0.07, 0.05])  # authored lesson training errors for four rungs.
bounds_w = emp_w + penalties_w  # SRM score = empirical risk + complexity penalty.
for k_w, (e_w, p_w, b_w) in enumerate(zip(emp_w, penalties_w, bounds_w), start=1):  # print table.
    print(f"rung {k_w}: emp={e_w:.2f}, penalty={p_w:.3f}, bound={b_w:.3f}")  # grounded table.
assert np.allclose(np.round(bounds_w, 3), [0.396, 0.270, 0.216, 0.238])  # grounded sums.
```
▶ What you'll see: rung 3 has the smallest sum, even though rung 4 has the smallest training error.

```python
srm_rung_w = int(np.argmin(bounds_w) + 1)  # convert 0-based index to rung number.
erm_rung_w = int(np.argmin(emp_w) + 1)  # naive training-error winner.
print("SRM rung:", srm_rung_w, " naive ERM rung:", erm_rung_w)  # compare choices.
assert srm_rung_w == 3 and erm_rung_w == 4  # lesson conclusion.
plt.figure(figsize=(5, 3.2))  # show all three curves.
plt.plot(np.arange(1, 5), emp_w, marker="o", label="training error")  # decreasing.
plt.plot(np.arange(1, 5), penalties_w, marker="o", label="penalty")  # increasing.
plt.plot(np.arange(1, 5), bounds_w, marker="o", label="sum")  # U-shaped.
plt.scatter([srm_rung_w], [bounds_w[srm_rung_w - 1]], color="red", zorder=4, label="SRM choice")  # winner.
plt.title("4: SRM minimizes error + penalty"); plt.xlabel("rung k"); plt.ylabel("risk proxy"); plt.legend(); plt.show()
```
▶ What you'll see: the SRM curve bottoms at rung 3, mechanically avoiding the richest rung.

*Why it's done this way: SRM = minimize training error + complexity penalty over a nested hypothesis hierarchy; the sum is a computable proxy for true risk, not a claim that the bound equals truth.*

### 5. A polynomial SRM choice in practice

The finite-class formula is easiest for a discrete class. For a polynomial ladder, we can still use the same SRM logic with a simple increasing penalty. The exact penalty depends on the theory you use, but the selection principle is unchanged: compare each rung by fit plus complexity.

```python
complexity_penalty_w = 0.01 * (degrees_w + 1) ** 2  # simple increasing complexity charge for the polynomial ladder.
srm_scores_w = train_errors_w + complexity_penalty_w  # SRM-style score.
poly_srm_degree_w = int(degrees_w[np.argmin(srm_scores_w)])  # selected degree.
print("train MSE:", np.round(train_errors_w, 4))  # empirical term.
print("penalty:", np.round(complexity_penalty_w, 4))  # complexity term.
print("SRM scores:", np.round(srm_scores_w, 4))  # combined objective.
print("selected degree:", poly_srm_degree_w)  # should be modest, not maximal.
```
▶ What you'll see: the score trades fit against simplicity and selects a lower degree than naive ERM.

```python
plt.figure(figsize=(5, 3.2))  # plot empirical, penalty, and sum for the polynomial ladder.
plt.plot(degrees_w, train_errors_w, marker="o", label="train MSE")  # fit term.
plt.plot(degrees_w, complexity_penalty_w, marker="o", label="penalty")  # complexity charge.
plt.plot(degrees_w, srm_scores_w, marker="o", label="sum")  # SRM objective.
plt.scatter([poly_srm_degree_w], [srm_scores_w[poly_srm_degree_w]], color="red", zorder=4)  # chosen degree.
plt.title("5: polynomial SRM score")  # concept id.
plt.xlabel("degree"); plt.ylabel("score"); plt.legend(); plt.show()  # display.
```
▶ What you'll see: low degrees underfit, high degrees pay too much penalty, and SRM chooses the bottom of the combined curve.

*Why it's done this way: the penalty converts model selection into ordinary minimization, so “pick complexity” becomes a reproducible calculation instead of a visual guess.*

## Setup

```python
# Uncomment the next line only if you are running outside an environment that already has numpy/matplotlib.
# %pip install numpy matplotlib

import numpy as np  # numerical arrays, logs, square roots, and polynomial fitting.
import matplotlib.pyplot as plt  # plotting for every exercise.
np.random.seed(7)  # deterministic exercises.

# Guarded finite-class penalty from the SRM/generalization-bound formula.
def finite_penalty(H_size, m, delta):
    H_size = max(float(H_size), 1.0)  # avoid log of a nonpositive class size.
    m = max(float(m), 1.0)  # avoid division by zero.
    delta = min(max(float(delta), 1e-12), 1.0)  # keep delta in a safe numeric range.
    return float(np.sqrt((np.log(H_size) + np.log(1.0 / delta)) / (2.0 * m)))  # bound penalty.

# Mean squared error helper for regression examples.
def mse(y_true, y_pred):
    y_true = np.asarray(y_true, dtype=float)  # ensure array arithmetic.
    y_pred = np.asarray(y_pred, dtype=float)  # ensure array arithmetic.
    return float(np.mean((y_true - y_pred) ** 2))  # empirical squared risk.

# Fit a polynomial and return predictions plus training MSE.
def fit_poly_degree(x, y, degree):
    coef = np.polyfit(x, y, int(degree))  # least-squares ERM in polynomial class H_degree.
    pred = np.polyval(coef, x)  # predictions on the supplied inputs.
    return coef, pred, mse(y, pred)  # reusable tuple for examples.

# A compact plotting helper for SRM tables.
def plot_three_terms(labels, emp, penalty, score, title):
    idx = np.arange(len(labels))  # x positions.
    plt.figure(figsize=(5, 3))  # compact figure size.
    plt.plot(idx, emp, marker="o", label="training error")  # empirical risk curve.
    plt.plot(idx, penalty, marker="o", label="penalty")  # complexity curve.
    plt.plot(idx, score, marker="o", label="sum")  # SRM objective.
    plt.xticks(idx, labels)  # readable rung labels.
    plt.title(title)  # example-specific title.
    plt.ylabel("risk proxy")  # shared y label.
    plt.legend()  # show curve names.
    plt.show()  # display the figure.
```
