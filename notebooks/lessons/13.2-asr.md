# 13.2 — Automatic Speech Recognition

Automatic speech recognition (ASR) maps a variable-length acoustic signal into a shorter word sequence by combining frame-level acoustic evidence, temporal alignment, and language constraints. In this lesson, every signal is synthetic and tiny, so you can see the core mechanics directly: feature frames, softmax acoustic probabilities, dynamic-programming alignment, beam search decoding, and word error rate.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build automatic speech recognition one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math is spelled out so ASR feels like structured prediction rather than a black box. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, probabilities, and dynamic programming tables.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for toy acoustic features.
```

### 1. Acoustic frames: turning a waveform into evidence over time

ASR begins with a sequence of short-time feature vectors, not with a whole audio file at once. Real systems use spectrogram or MFCC features; here we synthesize a tiny "spectrogram-like" matrix where each row is a time frame and each column is a frequency band. The important idea is shape: many acoustic frames must eventually collapse into fewer output symbols or words.

```python
T_w, F_w = 18, 6  # 18 time frames and 6 toy frequency bands.
time_w = np.arange(T_w)  # frame indices.
bands_w = np.arange(F_w)  # frequency-band indices.
centers_w = np.array([1.0, 3.8, 2.2])  # three phone-like spectral centers.
durations_w = [6, 5, 7]  # each phone lasts multiple frames.
phone_ids_w = np.repeat(np.arange(3), durations_w)  # hidden phone per frame.
features_w = np.exp(-0.5 * (bands_w[None, :] - centers_w[phone_ids_w, None]) ** 2)  # smooth band energies.
features_w += 0.04 * np.random.default_rng(0).normal(size=features_w.shape)  # small acoustic noise.
features_w = np.clip(features_w, 0, None)  # energies cannot be negative.
print("features shape:", features_w.shape)
print("hidden phone ids:", phone_ids_w)
assert features_w.shape == (18, 6)
```
▶ What you'll see: 18 short frames, but only 3 underlying phone regions; ASR must handle this duration mismatch.

```python
plt.figure(figsize=(6, 3))
plt.imshow(features_w.T, aspect="auto", origin="lower", cmap="magma")
plt.colorbar(label="energy")
plt.xlabel("time frame")
plt.ylabel("frequency band")
plt.title("1: toy acoustic feature sequence")
plt.show()
```
▶ What you'll see: three visible acoustic regions; each region occupies several frames before the next sound begins.

*Why it's done this way:* Speech is locally stationary only for short windows, so ASR first creates a frame sequence. The model does not know the phone boundaries; the repeated rows show why decoding needs alignment rather than one label per word.

### 2. Acoustic model: softmax probabilities and cross-entropy

An acoustic model converts each frame vector into logits for symbols such as phones, characters, or subwords. Softmax turns logits into probabilities, and cross-entropy charges the model when the correct symbol receives low probability. A frame classifier is useful evidence, but it is not a transcript decoder yet.

```python
def softmax_w(z_w):
    z_w = np.asarray(z_w, dtype=float)
    shifted_w = z_w - np.max(z_w, axis=-1, keepdims=True)
    exp_w = np.exp(shifted_w)
    return exp_w / np.sum(exp_w, axis=-1, keepdims=True)

prototypes_w = np.array([[0.20, 0.90, 1.00, 0.45, 0.10, 0.02],
                         [0.02, 0.08, 0.35, 0.95, 0.85, 0.25],
                         [0.10, 0.50, 1.00, 0.80, 0.25, 0.05]])  # phone templates.
logits_w = features_w @ prototypes_w.T  # frame-template scores.
probs_w = softmax_w(logits_w)
print("frame 0 probabilities:", np.round(probs_w[0], 3))
print("frame 9 probabilities:", np.round(probs_w[9], 3))
assert probs_w.shape == (18, 3)
```
▶ What you'll see: early frames favor phone 0, while middle frames favor a different symbol.

```python
frame_loss_w = -np.log(probs_w[np.arange(T_w), phone_ids_w])  # cross-entropy for known toy labels.
print("mean frame loss:", round(float(frame_loss_w.mean()), 3))
print("first six losses:", np.round(frame_loss_w[:6], 3))
assert round(float(probs_w[0].sum()), 6) == 1.0
```
▶ What you'll see: every row sums to 1, and the loss is small when the frame's true phone gets high probability.

```python
plt.figure(figsize=(6, 3))
plt.plot(probs_w[:, 0], label="p(phone 0)")
plt.plot(probs_w[:, 1], label="p(phone 1)")
plt.plot(probs_w[:, 2], label="p(phone 2)")
plt.xlabel("time frame")
plt.ylabel("probability")
plt.title("2: acoustic model probabilities by frame")
plt.legend()
plt.show()
```
▶ What you'll see: probability curves change smoothly, but transitions are fuzzy rather than clean vertical cuts.

*Why it's done this way:* Softmax normalizes competing symbol evidence so cross-entropy can reward the right class relative to alternatives. ASR still needs sequence decoding because independent frame labels can flicker and because multiple frames usually correspond to one output symbol.

### 3. DTW alignment: matching unequal-length acoustic and template sequences

Dynamic time warping (DTW) aligns two sequences when one stretches or compresses in time. It fills a cost table where each cell means "best cost to align prefixes ending here," and each step can move right, down, or diagonal. The diagonal says both sequences advance; horizontal or vertical movement says one side stretches.

```python
spoken_w = np.array([0.1, 0.2, 1.0, 1.1, 0.9, 2.0, 2.1, 1.9])  # stretched observation.
template_w = np.array([0.0, 1.0, 2.0])  # shorter canonical pattern.
D_w = np.full((len(spoken_w) + 1, len(template_w) + 1), np.inf)
D_w[0, 0] = 0.0
for i_w in range(1, len(spoken_w) + 1):
    for j_w in range(1, len(template_w) + 1):
        cost_w = abs(spoken_w[i_w - 1] - template_w[j_w - 1])
        D_w[i_w, j_w] = cost_w + min(D_w[i_w - 1, j_w], D_w[i_w, j_w - 1], D_w[i_w - 1, j_w - 1])
print("DTW cost:", round(float(D_w[-1, -1]), 3))
assert round(float(D_w[-1, -1]), 3) == 0.700
```
▶ What you'll see: the total alignment cost is low because repeated frames can align to the same template point.

```python
path_w = []
i_w, j_w = len(spoken_w), len(template_w)
while i_w > 0 and j_w > 0:
    path_w.append((i_w - 1, j_w - 1))
    choices_w = np.array([D_w[i_w - 1, j_w], D_w[i_w, j_w - 1], D_w[i_w - 1, j_w - 1]])
    step_w = int(np.argmin(choices_w))
    if step_w == 0:
        i_w -= 1
    elif step_w == 1:
        j_w -= 1
    else:
        i_w -= 1; j_w -= 1
path_w = path_w[::-1]
print("alignment path:", path_w)
assert path_w[0] == (0, 0) and path_w[-1] == (7, 2)
```
▶ What you'll see: several spoken frames map to the same template index, representing duration stretch.

```python
plt.figure(figsize=(5, 4))
plt.imshow(D_w[1:, 1:].T, origin="lower", aspect="auto", cmap="viridis")
plt.colorbar(label="cumulative cost")
plt.plot([p[0] for p in path_w], [p[1] for p in path_w], color="white", marker="o")
plt.xlabel("spoken frame")
plt.ylabel("template position")
plt.title("3: DTW alignment path")
plt.show()
```
▶ What you'll see: the white path bends horizontally where speech is stretched; the best path avoids high-cost regions.

*Why it's done this way:* The recurrence chooses the cheapest prefix alignment, so a global alignment is built from local optimal subproblems. This is the same dynamic-programming habit ASR uses for HMMs, CTC, and edit-distance metrics.

### 4. HMM/Viterbi decoding: acoustic likelihood plus temporal structure

An HMM adds a transition model over hidden speech states. Emissions say which state each frame sounds like, while transitions say which state sequences are plausible. Viterbi decoding finds the single most likely state path by adding log emission scores and log transition scores over time.

```python
states_w = ["AH", "S", "R"]
A_w = np.array([[0.72, 0.26, 0.02],
                [0.05, 0.75, 0.20],
                [0.02, 0.08, 0.90]])  # mostly stay, sometimes move forward.
start_w = np.array([0.98, 0.02, 0.00])
emit_w = np.column_stack([probs_w[:, 0], probs_w[:, 1], probs_w[:, 2]])
print("transition row sums:", A_w.sum(axis=1))
assert np.allclose(A_w.sum(axis=1), 1.0)
```
▶ What you'll see: transitions prefer staying in the same phone, matching the fact that phones last multiple frames.

```python
logA_w = np.log(A_w + 1e-12)
log_start_w = np.log(start_w + 1e-12)
log_emit_w = np.log(emit_w + 1e-12)
V_w = np.full_like(log_emit_w, -np.inf)
back_w = np.zeros_like(log_emit_w, dtype=int)
V_w[0] = log_start_w + log_emit_w[0]
for t_w in range(1, T_w):
    for j_w in range(3):
        scores_w = V_w[t_w - 1] + logA_w[:, j_w]
        back_w[t_w, j_w] = int(np.argmax(scores_w))
        V_w[t_w, j_w] = scores_w[back_w[t_w, j_w]] + log_emit_w[t_w, j_w]
print("final Viterbi log scores:", np.round(V_w[-1], 2))
assert int(np.argmax(V_w[-1])) == 2
```
▶ What you'll see: the best final state is the last phone because late frames and transitions agree there.

```python
best_w = [int(np.argmax(V_w[-1]))]
for t_w in range(T_w - 1, 0, -1):
    best_w.append(int(back_w[t_w, best_w[-1]]))
best_w = best_w[::-1]
print("best state ids:", best_w)
print("compressed phones:", [states_w[i] for k, i in enumerate(best_w) if k == 0 or i != best_w[k - 1]])
assert len(set(best_w)) == 3
```
▶ What you'll see: the path stays in each state for multiple frames, then moves forward in order.

```python
plt.figure(figsize=(6, 3))
plt.imshow(log_emit_w.T, origin="lower", aspect="auto", cmap="Blues")
plt.plot(np.arange(T_w), best_w, color="crimson", marker="o", label="Viterbi path")
plt.yticks(range(3), states_w)
plt.xlabel("time frame")
plt.title("4: HMM/Viterbi alignment over acoustic evidence")
plt.legend()
plt.show()
```
▶ What you'll see: the red path smooths noisy frame evidence by preferring legal, persistent state sequences.

*Why it's done this way:* In log space, products of many probabilities become sums, avoiding underflow and making the recurrence additive. The transition term prevents a noisy frame from causing an implausible jump unless the acoustic gain is worth the temporal penalty.

### 5. Beam search and WER: choosing and evaluating word sequences

A decoder must turn acoustic evidence into words. Beam search keeps only the best few partial hypotheses, combining acoustic log-probabilities with a language prior. After decoding, word error rate (WER) compares the final hypothesis to a reference using substitutions, deletions, and insertions.

```python
tokens_w = ["I", "like", "math", "maps"]
frames_tok_w = [np.array([-0.1, -2.0, -2.2, -2.5]),
                np.array([-1.8, -0.2, -2.0, -2.3]),
                np.array([-2.1, -1.2, -0.35, -0.55])]
lm_w = {(): {"I": 0.0}, ("I",): {"like": 0.0}, ("I", "like"): {"math": -0.15, "maps": -0.95}}
beam_w = [((), 0.0)]
for t_w, logp_w in enumerate(frames_tok_w):
    candidates_w = []
    for prefix_w, score_w in beam_w:
        for idx_w, tok_w in enumerate(tokens_w):
            lm_bonus_w = lm_w.get(prefix_w, {}).get(tok_w, -1.5)
            candidates_w.append((prefix_w + (tok_w,), score_w + float(logp_w[idx_w]) + lm_bonus_w))
    candidates_w = sorted(candidates_w, key=lambda x: x[1], reverse=True)[:2]
    beam_w = candidates_w
    print("beam after step", t_w + 1, beam_w)
best_words_w = list(beam_w[0][0])
assert best_words_w == ["I", "like", "math"]
```
▶ What you'll see: the beam keeps two hypotheses at each step; the language prior helps prefer a plausible phrase.

```python
def wer_counts_w(ref_w, hyp_w):
    n_w, m_w = len(ref_w), len(hyp_w)
    dp_w = np.zeros((n_w + 1, m_w + 1), dtype=int)
    back_w = [[None] * (m_w + 1) for _ in range(n_w + 1)]
    for i_w in range(1, n_w + 1):
        dp_w[i_w, 0] = i_w; back_w[i_w][0] = "D"
    for j_w in range(1, m_w + 1):
        dp_w[0, j_w] = j_w; back_w[0][j_w] = "I"
    for i_w in range(1, n_w + 1):
        for j_w in range(1, m_w + 1):
            sub_w = dp_w[i_w - 1, j_w - 1] + (ref_w[i_w - 1] != hyp_w[j_w - 1])
            dele_w = dp_w[i_w - 1, j_w] + 1
            ins_w = dp_w[i_w, j_w - 1] + 1
            best_w = min((sub_w, "M" if ref_w[i_w - 1] == hyp_w[j_w - 1] else "S"), (dele_w, "D"), (ins_w, "I"))
            dp_w[i_w, j_w], back_w[i_w][j_w] = best_w
    i_w, j_w = n_w, m_w; S_w = D_w = I_w = 0
    while i_w > 0 or j_w > 0:
        op_w = back_w[i_w][j_w]
        if op_w in ("M", "S"):
            S_w += (op_w == "S"); i_w -= 1; j_w -= 1
        elif op_w == "D":
            D_w += 1; i_w -= 1
        else:
            I_w += 1; j_w -= 1
    return S_w, D_w, I_w, dp_w

ref_w = "I like math today".split()
hyp_w = "I like maps".split()
S_w, D_w, I_w, edit_w = wer_counts_w(ref_w, hyp_w)
wer_w = (S_w + D_w + I_w) / len(ref_w)
print("S,D,I:", S_w, D_w, I_w, "WER:", round(wer_w, 3))
assert (S_w, D_w, I_w) == (1, 1, 0) and round(wer_w, 3) == 0.5
```
▶ What you'll see: one substitution and one deletion over four reference words gives WER = 0.5.

```python
plt.figure(figsize=(4, 3))
plt.imshow(edit_w, cmap="Greens", aspect="auto")
plt.colorbar(label="edit distance")
plt.xticks(range(len(hyp_w) + 1), ["∅"] + hyp_w, rotation=30)
plt.yticks(range(len(ref_w) + 1), ["∅"] + ref_w)
plt.title("5: WER dynamic-programming table")
plt.show()
```
▶ What you'll see: the bottom-right cell is the minimum number of word edits needed to transform the hypothesis into the reference.

*Why it's done this way:* Beam search approximates the best transcript without enumerating every possible word sequence, while WER evaluates the transcript at the level users care about. Frame accuracy can be high while WER is poor if alignments or language decisions create extra, missing, or wrong words.

## 🛠️ Setup

```python
import numpy as np
import matplotlib.pyplot as plt
np.random.seed(0)

symbols = np.array(["AH", "S", "R"])

def softmax(z):
    z = np.asarray(z, dtype=float)
    shifted = z - np.max(z, axis=-1, keepdims=True)
    exp = np.exp(shifted)
    return exp / np.sum(exp, axis=-1, keepdims=True)

def toy_features(durations=(4, 4, 4), noise=0.03, seed=0):
    centers = np.array([1.0, 3.8, 2.2])
    bands = np.arange(6)
    ids = np.repeat(np.arange(3), durations)
    X = np.exp(-0.5 * (bands[None, :] - centers[ids, None]) ** 2)
    X += noise * np.random.default_rng(seed).normal(size=X.shape)
    return np.clip(X, 0, None), ids

def dtw_path(a, b):
    a = np.asarray(a, dtype=float); b = np.asarray(b, dtype=float)
    D = np.full((len(a) + 1, len(b) + 1), np.inf); D[0, 0] = 0.0
    for i in range(1, len(a) + 1):
        for j in range(1, len(b) + 1):
            D[i, j] = abs(a[i - 1] - b[j - 1]) + min(D[i - 1, j], D[i, j - 1], D[i - 1, j - 1])
    path = []; i, j = len(a), len(b)
    while i > 0 and j > 0:
        path.append((i - 1, j - 1))
        step = int(np.argmin([D[i - 1, j], D[i, j - 1], D[i - 1, j - 1]]))
        if step == 0: i -= 1
        elif step == 1: j -= 1
        else: i -= 1; j -= 1
    return D, path[::-1]

def viterbi(log_emit, log_start, log_trans):
    T, K = log_emit.shape
    V = np.full((T, K), -np.inf); back = np.zeros((T, K), dtype=int)
    V[0] = log_start + log_emit[0]
    for t in range(1, T):
        for j in range(K):
            scores = V[t - 1] + log_trans[:, j]
            back[t, j] = int(np.argmax(scores))
            V[t, j] = scores[back[t, j]] + log_emit[t, j]
    path = [int(np.argmax(V[-1]))]
    for t in range(T - 1, 0, -1):
        path.append(int(back[t, path[-1]]))
    return V, path[::-1]

def beam_decode(frame_logp, vocab, lm=None, width=2):
    lm = {} if lm is None else lm
    beam = [((), 0.0)]
    for logp in frame_logp:
        cand = []
        for prefix, score in beam:
            for idx, tok in enumerate(vocab):
                cand.append((prefix + (tok,), score + float(logp[idx]) + lm.get(prefix, {}).get(tok, 0.0)))
        beam = sorted(cand, key=lambda x: x[1], reverse=True)[:width]
    return beam

def wer_counts(ref, hyp):
    n, m = len(ref), len(hyp)
    dp = np.zeros((n + 1, m + 1), dtype=int); back = [[None] * (m + 1) for _ in range(n + 1)]
    for i in range(1, n + 1): dp[i, 0] = i; back[i][0] = "D"
    for j in range(1, m + 1): dp[0, j] = j; back[0][j] = "I"
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            sub = dp[i - 1, j - 1] + (ref[i - 1] != hyp[j - 1])
            dele = dp[i - 1, j] + 1; ins = dp[i, j - 1] + 1
            dp[i, j], back[i][j] = min((sub, "M" if ref[i - 1] == hyp[j - 1] else "S"), (dele, "D"), (ins, "I"))
    i, j = n, m; S = D = I = 0
    while i > 0 or j > 0:
        op = back[i][j]
        if op in ("M", "S"):
            S += (op == "S"); i -= 1; j -= 1
        elif op == "D":
            D += 1; i -= 1
        else:
            I += 1; j -= 1
    return int(S), int(D), int(I), dp
```

### Basic 3 — Compute one frame loss

**Goal.** Measure cross-entropy for the correct symbol, because acoustic models train by rewarding probability on the target class. We build it in 2 steps.

▶ What you'll see: the loss is small because the correct class probability is 0.643, not tiny.

### Basic 5 — Smooth noisy frame labels

**Goal.** Compare raw argmax labels with a tiny majority smoother, because ASR should not let one noisy frame flip a phone. We build it in 2 steps.

```python
raw_b5 = np.array([0, 0, 1, 0, 1, 1, 1, 2, 1, 2, 2, 2])
smooth_b5 = raw_b5.copy()
for i_b5 in range(1, len(raw_b5) - 1):
    vals_b5, counts_b5 = np.unique(raw_b5[i_b5 - 1:i_b5 + 2], return_counts=True)
    smooth_b5[i_b5] = vals_b5[np.argmax(counts_b5)]
print("raw:   ", raw_b5)
print("smooth:", smooth_b5)
assert smooth_b5[2] == 0
```
▶ What you'll see: isolated blips are corrected by neighboring context.

```python
plt.figure(figsize=(5, 2.5))

plt.yticks([0, 1, 2], symbols)

plt.show()
```
