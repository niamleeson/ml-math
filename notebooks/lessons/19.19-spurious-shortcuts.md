# 19.19 — Spurious Correlations & Shortcuts

A model can score well for the wrong reason: it may learn a **shortcut** feature that predicts labels in training but breaks when the environment changes. In this lesson, we build a tiny synthetic world where a real causal signal and an accidental spurious signal compete, then audit average accuracy, environment shift, worst-group accuracy, reweighting, and GroupDRO from scratch.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build shortcut learning one idea at a time. Run each cell in order and inspect the printed weights, risks, group scores, and plots — every moving part is deliberately small enough to audit. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, random toy data, and vectorized optimization.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for the walkthrough.
```

### 1. A synthetic world with one stable cause and one shortcut

We create binary labels `y` and two visible features. The **causal** feature is noisy but keeps the same relationship to the label in every environment. The **spurious** feature is easier: in training it almost always matches the label, but that match rate is an environment choice, not a law of nature. A learner that only minimizes training loss is allowed to use either cue.

```python
def make_shortcut_data_w(n_w, spur_prob_w=0.95, seed_w=0, causal_noise_w=1.3, spur_noise_w=0.05):
    rng_w = np.random.default_rng(seed_w)
    y01_w = rng_w.integers(0, 2, n_w)                  # 0/1 labels for logistic loss.
    ysign_w = 2 * y01_w - 1                            # -1/+1 labels for feature construction.
    aligned_w = rng_w.random(n_w) < spur_prob_w         # whether the shortcut agrees with y.
    spur_clean_w = np.where(aligned_w, ysign_w, -ysign_w)
    x_causal_w = ysign_w + rng_w.normal(0, causal_noise_w, n_w)
    x_spur_w = spur_clean_w + rng_w.normal(0, spur_noise_w, n_w)
    x_noise_w = rng_w.normal(0, 1, n_w)
    X_w = np.column_stack([np.ones(n_w), x_causal_w, x_spur_w, x_noise_w])
    groups_w = y01_w * 2 + (spur_clean_w > 0).astype(int)  # four (label, shortcut-sign) groups.
    return X_w, y01_w, groups_w, ysign_w, spur_clean_w

Xtr_w, ytr_w, gtr_w, ysign_tr_w, spur_tr_w = make_shortcut_data_w(1200, 0.95, seed_w=1)
print("feature columns:", ["bias", "causal", "spurious", "noise"])
print("training shortcut agreement:", round(np.mean(ysign_tr_w == spur_tr_w), 3))
print("first 5 rows:\n", np.round(Xtr_w[:5], 2))
assert Xtr_w.shape == (1200, 4)
assert round(np.mean(ysign_tr_w == spur_tr_w), 3) == 0.943
```
▶ What you'll see: the spurious feature agrees with the label about 95% of the time, so it looks like an excellent predictor in the training environment.

```python
plt.figure(figsize=(4.8, 3.4))
plt.scatter(Xtr_w[:250, 1], Xtr_w[:250, 2], c=ytr_w[:250], cmap="coolwarm", s=18, alpha=0.8)
plt.axhline(0, color="black", linewidth=0.8); plt.axvline(0, color="black", linewidth=0.8)
plt.xlabel("causal feature"); plt.ylabel("spurious feature")
plt.title("Training data: stable cause plus easy shortcut")
plt.show()
```
▶ What you'll see: the spurious axis separates labels more cleanly than the causal axis, even though only the causal axis is meant to be stable.

*Why it's done this way: shortcut learning is easiest to see when the data-generating story separates stability from convenience. The causal feature has lower signal-to-noise but keeps its sign rule everywhere; the shortcut has high apparent signal only because the environment made it agree with the label.*

### 2. ERM rewards whichever cue lowers training loss fastest

Empirical risk minimization (ERM) minimizes average training loss. For logistic regression, the prediction is $\sigma(Xw)$ and the loss is average cross-entropy. Nothing in that objective asks whether a feature is causal; if the shortcut reduces loss, ERM will increase its weight.

```python
def sigmoid_w(z_w):
    return 1 / (1 + np.exp(-np.clip(z_w, -30, 30)))

def train_logreg_w(X_w, y_w, weights_w=None, steps_w=3500, lr_w=0.05, l2_w=0.001):
    if weights_w is None:
        weights_w = np.ones(len(y_w))
    weights_w = weights_w / np.mean(weights_w)
    w_w = np.zeros(X_w.shape[1])
    losses_w = []
    for step_w in range(steps_w):
        p_w = sigmoid_w(X_w @ w_w)
        loss_w = np.mean(weights_w * (-(y_w * np.log(p_w + 1e-12) + (1 - y_w) * np.log(1 - p_w + 1e-12))))
        loss_w += 0.5 * l2_w * np.sum(w_w[1:] ** 2)
        grad_w = X_w.T @ ((p_w - y_w) * weights_w) / len(y_w) + l2_w * np.r_[0, w_w[1:]]
        w_w -= lr_w * grad_w
        if step_w % 250 == 0:
            losses_w.append(loss_w)
    return w_w, np.array(losses_w)

w_erm_w, losses_erm_w = train_logreg_w(Xtr_w, ytr_w)
print("ERM weights [bias, causal, spurious, noise]:", np.round(w_erm_w, 3))
print("first loss -> last loss:", round(losses_erm_w[0], 3), "->", round(losses_erm_w[-1], 3))
assert abs(w_erm_w[2]) > 2.0
assert abs(w_erm_w[2]) > abs(w_erm_w[1])
```
▶ What you'll see: the learned spurious weight is larger than the causal weight because it is the easiest way to lower training loss.

```python
plt.figure(figsize=(4.8, 3.0))
plt.plot(np.arange(len(losses_erm_w)) * 250, losses_erm_w, marker="o")
plt.xlabel("gradient steps"); plt.ylabel("training loss")
plt.title("ERM optimizes average loss")
plt.show()
```
▶ What you'll see: training loss falls smoothly, so the optimization looks successful even though the reason for success is fragile.

*Why it's done this way: ERM estimates $\min_w \frac{1}{n}\sum_i \ell(h_w(x_i),y_i)$. The summation gives every training example the same voice but gives no special penalty to unstable mechanisms, so a highly predictive shortcut is mathematically indistinguishable from a stable cause inside one environment.*

### 3. Shift risk exposes the shortcut gap

The lesson's core scalar is the environment gap $\Delta_{env}=R_{shift}(h)-R_{train}(h)$. Here risk is classification error. We keep the causal rule fixed but change the shortcut agreement rate from 95% to 50% or 10%. If the model used the shortcut, shifted risk rises.

```python
def accuracy_w(X_w, y_w, w_w):
    return float(np.mean((sigmoid_w(X_w @ w_w) >= 0.5) == y_w))

def risk_w(X_w, y_w, w_w):
    return 1 - accuracy_w(X_w, y_w, w_w)

Xiid_w, yiid_w, giid_w, ysign_iid_w, spur_iid_w = make_shortcut_data_w(2000, 0.95, seed_w=2)
Xbal_w, ybal_w, gbal_w, ysign_bal_w, spur_bal_w = make_shortcut_data_w(2000, 0.50, seed_w=3)
Xanti_w, yanti_w, ganti_w, ysign_anti_w, spur_anti_w = make_shortcut_data_w(2000, 0.10, seed_w=4)
for name_w, X_w, y_w in [("train", Xtr_w, ytr_w), ("iid", Xiid_w, yiid_w), ("balanced-shift", Xbal_w, ybal_w), ("anti-shift", Xanti_w, yanti_w)]:
    print(name_w, "accuracy=", round(accuracy_w(X_w, y_w, w_erm_w), 3), "risk=", round(risk_w(X_w, y_w, w_erm_w), 3))
print("Delta_env balanced:", round(risk_w(Xbal_w, ybal_w, w_erm_w) - risk_w(Xtr_w, ytr_w, w_erm_w), 3))
assert risk_w(Xbal_w, ybal_w, w_erm_w) - risk_w(Xtr_w, ytr_w, w_erm_w) > 0.35
```
▶ What you'll see: ERM looks strong in the training-like environment but loses much of its accuracy when shortcut agreement is no longer guaranteed.

```python
names_w = ["train", "iid", "balanced", "anti"]
accs_w = [accuracy_w(Xtr_w, ytr_w, w_erm_w), accuracy_w(Xiid_w, yiid_w, w_erm_w), accuracy_w(Xbal_w, ybal_w, w_erm_w), accuracy_w(Xanti_w, yanti_w, w_erm_w)]
plt.figure(figsize=(5.2, 3.2))
plt.bar(names_w, accs_w, color=["tab:blue", "tab:blue", "tab:orange", "tab:red"])
plt.ylim(0, 1); plt.ylabel("accuracy")
plt.title("Average accuracy hides environment dependence")
plt.show()
```
▶ What you'll see: the average score collapses as the shortcut becomes less reliable; the bar height is not a property of the model alone, but of model plus environment.

*Why it's done this way: evaluating under a deliberately changed shortcut rate estimates whether the learned rule is stable. The sign of $\Delta_{env}$ matters: a positive gap means the deployment environment is riskier than the training environment, so the original score was overconfident.*

### 4. Groups reveal the failures hidden by an average

A shortcut creates four groups: `(label=0, shortcut=-)`, `(label=0, shortcut=+)`, `(label=1, shortcut=-)`, `(label=1, shortcut=+)`. The majority groups have shortcut and label aligned; the minority groups have them in conflict. **Worst-group accuracy** is the minimum group accuracy, a stricter audit than the average.

```python
group_names_w = {0: "y=0, s=-", 1: "y=0, s=+", 2: "y=1, s=-", 3: "y=1, s=+"}

def group_accuracies_w(X_w, y_w, groups_w, w_w):
    pred_w = (sigmoid_w(X_w @ w_w) >= 0.5).astype(int)
    return {group_names_w[k_w]: float(np.mean(pred_w[groups_w == k_w] == y_w[groups_w == k_w])) for k_w in sorted(np.unique(groups_w))}

def worst_group_accuracy_w(X_w, y_w, groups_w, w_w):
    vals_w = list(group_accuracies_w(X_w, y_w, groups_w, w_w).values())
    return min(vals_w)

gacc_train_w = group_accuracies_w(Xtr_w, ytr_w, gtr_w, w_erm_w)
gacc_bal_w = group_accuracies_w(Xbal_w, ybal_w, gbal_w, w_erm_w)
print("train group accuracies:", {k: round(v, 3) for k, v in gacc_train_w.items()})
print("balanced group accuracies:", {k: round(v, 3) for k, v in gacc_bal_w.items()})
print("balanced average vs worst:", round(accuracy_w(Xbal_w, ybal_w, w_erm_w), 3), round(worst_group_accuracy_w(Xbal_w, ybal_w, gbal_w, w_erm_w), 3))
assert worst_group_accuracy_w(Xbal_w, ybal_w, gbal_w, w_erm_w) < 0.2
```
▶ What you'll see: two groups remain near-perfect while the conflicting groups fail, so the average hides who paid for the shortcut.

```python
labels_w = list(gacc_bal_w.keys())
values_w = [gacc_bal_w[k_w] for k_w in labels_w]
plt.figure(figsize=(6.2, 3.2))
plt.bar(labels_w, values_w, color=["tab:blue", "tab:red", "tab:red", "tab:blue"])
plt.axhline(accuracy_w(Xbal_w, ybal_w, w_erm_w), color="black", linestyle="--", label="average")
plt.ylim(0, 1); plt.xticks(rotation=20); plt.ylabel("accuracy")
plt.legend(); plt.title("Worst-group accuracy spots shortcut harm")
plt.show()
```
▶ What you'll see: the dashed average line looks moderate, but the shortest red bars are the decision-relevant failure mode.

*Why it's done this way: worst-group accuracy computes $\min_g \Pr[h(X)=Y\mid G=g]$. The minimum refuses to let majority groups compensate for minority failures, which is exactly the audit we need when a shortcut works only for some environments or populations.*

### 5. Reweighting makes minority conflicts count

If group labels are available, a simple correction is inverse-frequency reweighting: examples from small groups get larger training weight. This does not prove causality, but it changes the ERM objective so the shortcut-conflict groups are no longer almost silent.

```python
def inverse_group_weights_w(groups_w):
    weights_w = np.zeros(len(groups_w))
    for k_w in np.unique(groups_w):
        weights_w[groups_w == k_w] = 1 / np.sum(groups_w == k_w)
    return weights_w / np.mean(weights_w)

weights_re_w = inverse_group_weights_w(gtr_w)
w_re_w, losses_re_w = train_logreg_w(Xtr_w, ytr_w, weights_w=weights_re_w)
print("group counts:", {group_names_w[k]: int(np.sum(gtr_w == k)) for k in sorted(np.unique(gtr_w))})
print("sample weights by group:", {group_names_w[k]: round(weights_re_w[gtr_w == k][0], 2) for k in sorted(np.unique(gtr_w))})
print("reweighted weights:", np.round(w_re_w, 3))
assert abs(w_re_w[2]) < 0.2
```
▶ What you'll see: rare conflict groups get much larger weights, and the learned spurious coefficient shrinks toward zero.

```python
models_w = {"ERM": w_erm_w, "reweighted": w_re_w}
for name_w, w_w in models_w.items():
    print(name_w, "balanced avg=", round(accuracy_w(Xbal_w, ybal_w, w_w), 3), "worst=", round(worst_group_accuracy_w(Xbal_w, ybal_w, gbal_w, w_w), 3))
assert worst_group_accuracy_w(Xbal_w, ybal_w, gbal_w, w_re_w) > 0.65
```
▶ What you'll see: reweighting lowers the flattering shortcut behavior and raises worst-group accuracy by making conflicts visible during training.

*Why it's done this way: inverse-frequency weights approximate an objective that averages group losses rather than examples. A tiny group with 30 examples can then have the same group-level influence as a majority group with 570 examples, so the optimizer is pushed toward the stable causal cue.*

### 6. GroupDRO optimizes the group that is currently suffering most

Group Distributionally Robust Optimization (GroupDRO) keeps a probability distribution over groups. After each pass it increases the weight on groups with higher loss, then takes a gradient step on the weighted loss. Instead of hard-coding equal group weights, it lets the worst current group speak louder.

```python
def train_groupdro_w(X_w, y_w, groups_w, steps_w=3500, lr_w=0.05, eta_w=0.08, l2_w=0.001):
    keys_w = np.array(sorted(np.unique(groups_w)))
    q_w = np.ones(len(keys_w)) / len(keys_w)
    w_w = np.zeros(X_w.shape[1])
    history_w = []
    for step_w in range(steps_w):
        p_w = sigmoid_w(X_w @ w_w)
        losses_w = -(y_w * np.log(p_w + 1e-12) + (1 - y_w) * np.log(1 - p_w + 1e-12))
        group_losses_w = np.array([np.mean(losses_w[groups_w == k_w]) for k_w in keys_w])
        q_w = q_w * np.exp(eta_w * group_losses_w)
        q_w = q_w / np.sum(q_w)
        sample_weights_w = np.zeros(len(y_w))
        for qi_w, k_w in zip(q_w, keys_w):
            sample_weights_w[groups_w == k_w] = qi_w / np.sum(groups_w == k_w)
        sample_weights_w = sample_weights_w / np.mean(sample_weights_w)
        grad_w = X_w.T @ ((p_w - y_w) * sample_weights_w) / len(y_w) + l2_w * np.r_[0, w_w[1:]]
        w_w -= lr_w * grad_w
        if step_w % 500 == 0:
            history_w.append((step_w, group_losses_w.copy(), q_w.copy()))
    return w_w, history_w

w_dro_w, hist_dro_w = train_groupdro_w(Xtr_w, ytr_w, gtr_w)
print("GroupDRO weights:", np.round(w_dro_w, 3))
print("final group mixture:", np.round(hist_dro_w[-1][2], 3))
print("balanced avg/worst:", round(accuracy_w(Xbal_w, ybal_w, w_dro_w), 3), round(worst_group_accuracy_w(Xbal_w, ybal_w, gbal_w, w_dro_w), 3))
assert worst_group_accuracy_w(Xbal_w, ybal_w, gbal_w, w_dro_w) > worst_group_accuracy_w(Xbal_w, ybal_w, gbal_w, w_erm_w)
```
▶ What you'll see: GroupDRO also suppresses shortcut dependence and improves the weakest groups relative to ERM.

```python
steps_dro_w = [row_w[0] for row_w in hist_dro_w]
q_hist_w = np.vstack([row_w[2] for row_w in hist_dro_w])
plt.figure(figsize=(5.6, 3.2))
for j_w, k_w in enumerate(sorted(np.unique(gtr_w))):
    plt.plot(steps_dro_w, q_hist_w[:, j_w], marker="o", label=group_names_w[k_w])
plt.xlabel("step"); plt.ylabel("DRO group weight q")
plt.title("GroupDRO shifts attention toward hard groups")
plt.legend(fontsize=8); plt.show()
```
▶ What you'll see: the group mixture moves away from uniform because high-loss groups get amplified by the exponentiated update.

*Why it's done this way: GroupDRO approximates $\min_w \max_g R_g(w)$. The inner maximum asks, "which group would make this model look worst?" The exponentiated update is a smooth way to chase that maximum while still using ordinary gradients for the model parameters.*

### 7. Compare average accuracy against the robustness metric you actually care about

The final audit puts ERM, reweighting, and GroupDRO on the same shifted data. Average accuracy answers "how many examples are right overall?" Worst-group accuracy answers "how bad is the most harmed group?" Robustness work begins when those two answers disagree.

```python
model_names_w = ["ERM", "Reweight", "GroupDRO"]
model_ws_w = [w_erm_w, w_re_w, w_dro_w]
avg_scores_w = [accuracy_w(Xbal_w, ybal_w, w_w) for w_w in model_ws_w]
worst_scores_w = [worst_group_accuracy_w(Xbal_w, ybal_w, gbal_w, w_w) for w_w in model_ws_w]
for name_w, avg_w, worst_w in zip(model_names_w, avg_scores_w, worst_scores_w):
    print(name_w, "avg=", round(avg_w, 3), "worst=", round(worst_w, 3), "gap=", round(avg_w - worst_w, 3))
assert worst_scores_w[1] > worst_scores_w[0]
assert max(worst_scores_w) > 0.65
```
▶ What you'll see: ERM has a large average-minus-worst gap; robust objectives trade some shortcut confidence for a much healthier weakest group.

```python
xpos_w = np.arange(len(model_names_w))
width_w = 0.36
plt.figure(figsize=(5.8, 3.2))
plt.bar(xpos_w - width_w/2, avg_scores_w, width_w, label="average")
plt.bar(xpos_w + width_w/2, worst_scores_w, width_w, label="worst group")
plt.xticks(xpos_w, model_names_w); plt.ylim(0, 1)
plt.ylabel("accuracy on balanced-shift test")
plt.title("Look for avg/worst disagreement")
plt.legend(); plt.show()
```
▶ What you'll see: the visual diagnostic is the distance between paired bars; a robust model should make the worst-group bar much less embarrassing.

*Why it's done this way: model selection follows the metric. If deployment risk is group- or environment-specific, a single average silently permits failures. Plotting average beside worst-group accuracy forces the release decision to confront the shortcut rather than celebrate a flattering aggregate.*

## 🟢 Basics (warm-up)

### Basic 1 — Make labels and a shortcut feature

Start with the smallest object: labels, a stable causal coordinate, and a shortcut coordinate that agrees with the label most of the time.

```python
rng_b1 = np.random.default_rng(11)
y_b1 = rng_b1.integers(0, 2, 12)
ysign_b1 = 2 * y_b1 - 1
aligned_b1 = rng_b1.random(12) < 0.9
shortcut_b1 = np.where(aligned_b1, ysign_b1, -ysign_b1)
causal_b1 = ysign_b1 + rng_b1.normal(0, 0.8, 12)
print("labels:", y_b1)
print("shortcut signs:", shortcut_b1)
print("agreement:", round(np.mean(shortcut_b1 == ysign_b1), 3))
assert len(y_b1) == 12
```
👀 Takeaway: a spurious feature can look predictive in one sample even when we created it as an environmental accident.

### Basic 2 — Visualize the easy cue

A scatterplot makes the shortcut obvious: color is the label, the x-axis is stable but noisy, and the y-axis is the shortcut.

```python
plt.figure(figsize=(4.2, 3.0))
plt.scatter(causal_b1, shortcut_b1, c=y_b1, cmap="coolwarm", s=60)
plt.axhline(0, color="black", linewidth=0.8); plt.axvline(0, color="black", linewidth=0.8)
plt.xlabel("causal_b1"); plt.ylabel("shortcut_b1")
plt.title("Basic 2: two possible cues")
plt.show()
print("shortcut agreement:", round(np.mean(shortcut_b1 == ysign_b1), 3))
assert set(np.unique(shortcut_b1)).issubset({-1, 1})
```
▶ What you'll see: the shortcut coordinate has two clean bands, so a classifier can separate many points by using it.

👀 Takeaway: shortcut learning starts when the easiest-looking feature is not the one we expect to remain stable.

### Basic 3 — Compute a linear score by hand

A linear model adds feature contributions. With a larger shortcut weight, the shortcut dominates the score.

```python
X_b3 = np.column_stack([np.ones(len(y_b1)), causal_b1, shortcut_b1])
w_b3 = np.array([0.0, 0.4, 1.6])
scores_b3 = X_b3 @ w_b3
pred_b3 = (scores_b3 >= 0).astype(int)
print("first score pieces:", round(w_b3[1] * causal_b1[0], 3), round(w_b3[2] * shortcut_b1[0], 3))
print("accuracy:", round(np.mean(pred_b3 == y_b1), 3))
assert scores_b3.shape == (12,)
```
👀 Takeaway: a model's decision can be decomposed into causal and shortcut contributions before any neural-network complexity is added.

### Basic 4 — Measure training risk

Risk is just average loss. For classification accuracy, the 0/1 risk is the fraction of mistakes.

```python
mistakes_b4 = (pred_b3 != y_b1)
risk_b4 = np.mean(mistakes_b4)
print("mistakes:", mistakes_b4.astype(int))
print("0/1 risk:", round(risk_b4, 3))
assert 0 <= risk_b4 <= 1
```
👀 Takeaway: high shortcut agreement can make empirical risk look small even before we ask whether the cue is stable.

### Basic 5 — Create a shifted environment

Now keep the label process but make shortcut agreement random. The same shortcut-heavy rule should become less reliable.

```python
rng_b5 = np.random.default_rng(12)
y_b5 = rng_b5.integers(0, 2, 200)
ysign_b5 = 2 * y_b5 - 1
shortcut_b5 = np.where(rng_b5.random(200) < 0.5, ysign_b5, -ysign_b5)
causal_b5 = ysign_b5 + rng_b5.normal(0, 0.8, 200)
X_b5 = np.column_stack([np.ones(200), causal_b5, shortcut_b5])
pred_b5 = (X_b5 @ w_b3 >= 0).astype(int)
print("shift agreement:", round(np.mean(shortcut_b5 == ysign_b5), 3))
print("shift accuracy:", round(np.mean(pred_b5 == y_b5), 3))
assert abs(np.mean(shortcut_b5 == ysign_b5) - 0.5) < 0.08
```
👀 Takeaway: environment shift changes shortcut usefulness without changing the meaning of the label.

### Basic 6 — Compute the environment gap

The scalar $\Delta_{env}$ compares shifted risk with training risk for the same model.

```python
risk_shift_b6 = np.mean(pred_b5 != y_b5)
delta_env_b6 = risk_shift_b6 - risk_b4
print("train risk:", round(risk_b4, 3))
print("shift risk:", round(risk_shift_b6, 3))
print("Delta_env:", round(delta_env_b6, 3))
assert delta_env_b6 > 0
```
👀 Takeaway: a positive environment gap says the training score was too optimistic for the shifted setting.

### Basic 7 — Name the four shortcut groups

Groups combine the true label and the shortcut sign. The conflict groups are where shortcut and label disagree.

```python
groups_b7 = y_b5 * 2 + (shortcut_b5 > 0).astype(int)
counts_b7 = {int(k_b7): int(np.sum(groups_b7 == k_b7)) for k_b7 in np.unique(groups_b7)}
print("group counts:", counts_b7)
print("0=(y0,s-), 1=(y0,s+ conflict), 2=(y1,s- conflict), 3=(y1,s+)")
assert sum(counts_b7.values()) == 200
```
👀 Takeaway: grouping turns a vague robustness concern into concrete subsets we can score.

### Basic 8 — Compute group accuracies

Average accuracy can hide failures; group accuracy prints each subset separately.

```python
group_acc_b8 = {}
for k_b8 in sorted(counts_b7):
    mask_b8 = groups_b7 == k_b8
    group_acc_b8[k_b8] = np.mean(pred_b5[mask_b8] == y_b5[mask_b8])

assert len(group_acc_b8) == 4
```
👀 Takeaway: the shortcut-conflict groups are the first place to look for hidden failures.

## 🟡 Easy

### Easy 1 — Train ERM logistic regression from scratch

We now optimize logistic regression with NumPy only. The objective is ordinary average cross-entropy over training examples.

```python
def make_data_e1(n_e1, p_e1, seed_e1):
    rng_e1 = np.random.default_rng(seed_e1)
    y_e1 = rng_e1.integers(0, 2, n_e1)
    sign_e1 = 2 * y_e1 - 1
    s_e1 = np.where(rng_e1.random(n_e1) < p_e1, sign_e1, -sign_e1)
    X_e1 = np.column_stack([np.ones(n_e1), sign_e1 + rng_e1.normal(0, 1.2, n_e1), s_e1 + rng_e1.normal(0, 0.05, n_e1)])
    g_e1 = y_e1 * 2 + (s_e1 > 0).astype(int)
    return X_e1, y_e1, g_e1

def sigmoid_e1(z_e1):
    return 1 / (1 + np.exp(-np.clip(z_e1, -30, 30)))

def train_e1(X_e1, y_e1, weights_e1=None, steps_e1=2500, lr_e1=0.06):
    if weights_e1 is None:
        weights_e1 = np.ones(len(y_e1))
    weights_e1 = weights_e1 / np.mean(weights_e1)
    w_e1 = np.zeros(X_e1.shape[1])
    losses_e1 = []
    for step_e1 in range(steps_e1):
        p_e1 = sigmoid_e1(X_e1 @ w_e1)
        grad_e1 = X_e1.T @ ((p_e1 - y_e1) * weights_e1) / len(y_e1) + 0.001 * np.r_[0, w_e1[1:]]
        w_e1 -= lr_e1 * grad_e1
        if step_e1 % 250 == 0:
            losses_e1.append(np.mean(-(y_e1*np.log(p_e1+1e-12)+(1-y_e1)*np.log(1-p_e1+1e-12))))
    return w_e1, np.array(losses_e1)

Xtr_e1, ytr_e1, gtr_e1 = make_data_e1(900, 0.95, 21)
w_erm_e1, loss_e1 = train_e1(Xtr_e1, ytr_e1)
print("ERM weights:", np.round(w_erm_e1, 3))
print("loss drop:", round(loss_e1[0], 3), "->", round(loss_e1[-1], 3))
assert abs(w_erm_e1[2]) > abs(w_erm_e1[1])
```
▶ What you'll see: ERM learns a strong positive shortcut weight because it is rewarded in the training distribution.

👀 Takeaway: the training objective alone cannot tell whether a predictive feature is stable or spurious.

## 🔴 Advanced

### Advanced 1 — Implement GroupDRO updates

GroupDRO learns model weights and group weights together. High-loss groups get multiplied upward in the group mixture.

```python
def train_dro_a1(X_a1, y_a1, g_a1, steps_a1=2500, lr_a1=0.05, eta_a1=0.08):
    w_a1 = np.zeros(X_a1.shape[1])
    q_a1 = np.ones(4) / 4
    hist_a1 = []
    for step_a1 in range(steps_a1):
        p_a1 = sigmoid_e1(X_a1 @ w_a1)
        losses_a1 = -(y_a1*np.log(p_a1+1e-12) + (1-y_a1)*np.log(1-p_a1+1e-12))
        group_losses_a1 = np.array([np.mean(losses_a1[g_a1 == k_a1]) for k_a1 in range(4)])
        q_a1 = q_a1 * np.exp(eta_a1 * group_losses_a1)
        q_a1 = q_a1 / np.sum(q_a1)
        sw_a1 = np.zeros(len(y_a1))
        for k_a1 in range(4):
            sw_a1[g_a1 == k_a1] = q_a1[k_a1] / np.sum(g_a1 == k_a1)
        sw_a1 = sw_a1 / np.mean(sw_a1)
        grad_a1 = X_a1.T @ ((p_a1 - y_a1) * sw_a1) / len(y_a1) + 0.001 * np.r_[0, w_a1[1:]]
        w_a1 -= lr_a1 * grad_a1
        if step_a1 % 250 == 0:
            hist_a1.append(q_a1.copy())
    return w_a1, np.array(hist_a1)

w_dro_a1, qhist_a1 = train_dro_a1(Xtr_e1, ytr_e1, gtr_e1)
print("GroupDRO weights:", np.round(w_dro_a1, 3))
print("final q:", np.round(qhist_a1[-1], 3))
assert abs(w_dro_a1[2]) < abs(w_erm_e1[2])
```
▶ What you'll see: GroupDRO reduces reliance on the shortcut compared with ERM.

👀 Takeaway: GroupDRO changes the objective from average performance toward the hardest group losses.
