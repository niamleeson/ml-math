# 21.2 — First-Order Logic

First-order logic (FOL) keeps the truth-table discipline of propositional logic, but lets statements talk about objects, relations, and reusable rules. Instead of copying one proposition per individual, we write formulas with variables and quantifiers, give them meaning through an interpretation, and automate reasoning with substitution, unification, Skolemization, and resolution.

### 1. Terms, predicates, and formulas are syntax first

FOL separates **syntax** from **meaning**. A term names an object: it can be a constant like `tweety`, a variable like `?x`, or a function term like `('mother', ('bob',))`. A predicate applied to terms, such as `('Bird', ('?x',))`, is an atomic formula. Connectives and quantifiers then build larger formulas from atoms.

```python
def var_w(name):
    return '?' + name

def func_w(name, *args):
    return (name, tuple(args))

def pred_w(name, *args):
    return (name, tuple(args))

x_w = var_w('x')
tweety_w = 'tweety'
term_w = func_w('mother', 'bob')
atom_w = pred_w('Bird', x_w)
rule_w = ('forall', x_w, ('implies', pred_w('Bird', x_w), pred_w('Wings', x_w)))
print('term:', term_w)
print('atom:', atom_w)
print('rule:', rule_w)
```
▶ What you'll see: constants, variables, function terms, predicates, and a quantified rule all appear as inspectable nested tuples.

```python
def vars_in_term_w(t):
    if isinstance(t, str):
        return {t} if t.startswith('?') else set()
    name, args = t
    out = set()
    for a in args:
        out |= vars_in_term_w(a)
    return out

print('variables in Bird(?x):', vars_in_term_w(atom_w[1][0]))

```
▶ What you'll see: variables are placeholders; constants and function symbols are not variables.

*Why it's done this way:* tuple syntax forces us to keep names, arguments, and binding structure explicit. That matters logically because `?x` can be substituted or quantified, while `tweety` is a fixed object name and `mother(bob)` is a structured term whose parts must be respected.

### 2. Interpretations and models give syntax meaning

An **interpretation** chooses a domain of objects and assigns each predicate an extension: the set of tuples where the predicate is true. A formula is true or false only after we evaluate it in an interpretation with an environment for variables. A **model** is an interpretation that makes a formula true.

```python
domain_w = ['Tweety', 'Opus', 'Fido']
interp_w = {
    'const': {'tweety': 'Tweety', 'opus': 'Opus', 'fido': 'Fido'},
    'pred': {
        'Bird': {('Tweety',), ('Opus',)},
        'Wings': {('Tweety',), ('Opus',)},
        'Flies': {('Tweety',)},
        'Parent': {('Ann', 'Bob'), ('Bob', 'Cal')}
    },
    'func': {}
}
print('domain:', domain_w)
print('Bird extension:', sorted(interp_w['pred']['Bird']))
```
▶ What you'll see: predicates are sets of true rows over the domain, like columns in a tiny spreadsheet.

```python
def eval_term_w(t, env, interp):
    if isinstance(t, str) and t.startswith('?'):
        return env[t]
    if isinstance(t, str):
        return interp['const'].get(t, t)
    name, args = t
    values = tuple(eval_term_w(a, env, interp) for a in args)
    return interp['func'][name][values]

def eval_formula_w(f, env, interp, domain):
    tag = f[0]
    if tag in interp['pred']:
        vals = tuple(eval_term_w(a, env, interp) for a in f[1])
        return vals in interp['pred'][tag]
    if tag == 'not':
        return not eval_formula_w(f[1], env, interp, domain)
    if tag == 'and':
        return eval_formula_w(f[1], env, interp, domain) and eval_formula_w(f[2], env, interp, domain)
    if tag == 'implies':
        return (not eval_formula_w(f[1], env, interp, domain)) or eval_formula_w(f[2], env, interp, domain)
    if tag == 'forall':
        _, v, body = f
        return all(eval_formula_w(body, {**env, v: obj}, interp, domain) for obj in domain)
    if tag == 'exists':
        _, v, body = f
        return any(eval_formula_w(body, {**env, v: obj}, interp, domain) for obj in domain)
    raise ValueError(tag)

universal_w = ('forall', '?x', ('implies', pred_w('Bird', '?x'), pred_w('Wings', '?x')))
existential_w = ('exists', '?x', ('and', pred_w('Bird', '?x'), pred_w('Flies', '?x')))
print('all birds have wings:', eval_formula_w(universal_w, {}, interp_w, domain_w))
print('some bird flies:', eval_formula_w(existential_w, {}, interp_w, domain_w))
assert eval_formula_w(universal_w, {}, interp_w, domain_w) is True
assert eval_formula_w(existential_w, {}, interp_w, domain_w) is True
```
▶ What you'll see: the universal rule is true row-by-row, and the existential has Tweety as a witness.

```python
truth_grid_w = np.array([[int((obj,) in interp_w['pred'][p]) for p in ['Bird', 'Wings', 'Flies']] for obj in domain_w])
plt.figure(figsize=(4.6, 3))
plt.imshow(truth_grid_w, cmap='Greens', aspect='auto')
plt.xticks(range(3), ['Bird', 'Wings', 'Flies']); plt.yticks(range(3), domain_w)
plt.title('1/0 predicate extensions in one interpretation')
plt.colorbar(label='truth value')
plt.show()
```
▶ What you'll see: each row is an object and each column is a predicate truth value; quantifiers scan these rows.

*Why it's done this way:* evaluation is recursive because formula meaning follows formula shape. Quantifiers are loops over the domain, connectives combine truth values, and predicates perform set membership; that separation lets the same syntax be tested in many possible worlds.

### 3. Substitution replaces variables while preserving structure

A **substitution** maps variables to terms, such as `{?x ↦ tweety}` or `{?x ↦ mother(?y)}`. Applying it must recurse through terms and formulas without flattening their structure. Substitution is the bridge between a general rule and a concrete instance.

```python
def subst_term_w(t, subst):
    if isinstance(t, str) and t.startswith('?'):
        return subst.get(t, t)
    if isinstance(t, str):
        return t
    name, args = t
    return (name, tuple(subst_term_w(a, subst) for a in args))

def subst_atom_w(atom, subst):
    name, args = atom
    return (name, tuple(subst_term_w(a, subst) for a in args))

atom2_w = pred_w('Parent', '?x', func_w('mother', '?y'))
subst_w = {'?x': 'ann', '?y': 'bob'}
print('before:', atom2_w)
print('after:', subst_atom_w(atom2_w, subst_w))
assert subst_atom_w(atom2_w, subst_w) == ('Parent', ('ann', ('mother', ('bob',))))
```
▶ What you'll see: variables change, but predicate and function nesting stay intact.

```python
def collect_edges_w(before, after, x0=0):
    edges, labels = [], []
    def walk(b, a, depth, xpos):
        labels.append((xpos, -depth, str(b) + ' → ' + str(a)))
        if isinstance(b, tuple) and isinstance(a, tuple):
            for k, (bb, aa) in enumerate(zip(b[1], a[1])):
                child = xpos + (k - len(b[1]) / 2 + 0.5)
                edges.append((xpos, -depth, child, -depth - 1))
                walk(bb, aa, depth + 1, child)
    walk(before, after, 0, x0)
    return edges, labels

before_w = atom2_w
after_w = subst_atom_w(atom2_w, subst_w)
edges_w, labels_w = collect_edges_w(before_w, after_w)
plt.figure(figsize=(7, 3))
for x1, y1, x2, y2 in edges_w:
    plt.plot([x1, x2], [y1, y2], color='gray')
for x, y, lab in labels_w:
    plt.text(x, y, lab, ha='center', va='center', bbox=dict(boxstyle='round', fc='white'))
plt.axis('off'); plt.title('Substitution preserves the term tree'); plt.show()
```
▶ What you'll see: only variable leaves are replaced; the outer `Parent` and inner `mother` nodes remain.

*Why it's done this way:* a substitution is not text replacement. It is structural replacement, which prevents accidental changes to predicate names or function symbols and makes later unification sound.

### 4. Unification finds the most general shared instance

**Unification** asks whether two terms or atoms can be made identical by substitution. Robinson's algorithm repeatedly picks a disagreement, binds a variable if safe, applies that binding everywhere, and continues. The safety check is the **occurs check**: `?x` cannot be bound to `f(?x)` because that would require an infinite term.

```python
def is_var_w(t):
    return isinstance(t, str) and t.startswith('?')

def occurs_w(v, t, subst):
    t = subst_term_w(t, subst)
    if v == t:
        return True
    if isinstance(t, tuple):
        return any(occurs_w(v, a, subst) for a in t[1])
    return False

def unify_var_w(v, x, subst):
    if v in subst:
        return unify_w(subst[v], x, subst)
    if is_var_w(x) and x in subst:
        return unify_w(v, subst[x], subst)
    if occurs_w(v, x, subst):
        return None
    new = dict(subst); new[v] = subst_term_w(x, subst)
    return new

def unify_w(a, b, subst=None):
    subst = {} if subst is None else dict(subst)
    a = subst_term_w(a, subst); b = subst_term_w(b, subst)
    if a == b:
        return subst
    if is_var_w(a):
        return unify_var_w(a, b, subst)
    if is_var_w(b):
        return unify_var_w(b, a, subst)
    if isinstance(a, tuple) and isinstance(b, tuple) and a[0] == b[0] and len(a[1]) == len(b[1]):
        for aa, bb in zip(a[1], b[1]):
            subst = unify_w(aa, bb, subst)
            if subst is None:
                return None
        return subst
    return None

left_w = pred_w('Parent', '?x', func_w('mother', '?x'))
right_w = pred_w('Parent', 'ann', func_w('mother', 'ann'))
mgu_w = unify_w(left_w, right_w)
print('MGU:', mgu_w)
print('left after MGU:', subst_atom_w(left_w, mgu_w))
print('right after MGU:', subst_atom_w(right_w, mgu_w))
assert subst_atom_w(left_w, mgu_w) == subst_atom_w(right_w, mgu_w)
assert mgu_w == {'?x': 'ann'}
```
▶ What you'll see: the most-general unifier is `{?x: ann}`, and both atoms become the same fact.

```python
bad_w = unify_w('?x', func_w('f', '?x'))
print('unify ?x with f(?x):', bad_w)
assert bad_w is None
```
▶ What you'll see: the occurs check rejects an infinite self-containing binding.

```python
pairs_w = ['Parent', '?x', 'ann', 'mother(?x)', 'mother(ann)']
y_w = [3, 2, 2, 1, 1]
x_w = [0, -1, 1, -1, 1]
plt.figure(figsize=(5.5, 3))
plt.scatter(x_w, y_w, s=220, color=['gray', 'orange', 'green', 'orange', 'green'])
for x, y, lab in zip(x_w, y_w, pairs_w):
    plt.text(x, y, lab, ha='center', va='center')
for a, b in [(0,1), (0,2), (1,3), (2,4)]:
    plt.plot([x_w[a], x_w[b]], [y_w[a], y_w[b]], color='black', alpha=.5)
plt.title('Unification tree: bind ?x to ann'); plt.axis('off'); plt.show()
```
▶ What you'll see: the disagreement at `?x` versus `ann` explains the single binding that repairs both branches.

*Why it's done this way:* the MGU is deliberately the least committed repair. Binding `?x` to `ann` is enough; adding extra irrelevant bindings would make a theorem prover less reusable and less complete.

### 5. Skolemization removes existentials by naming witnesses

Resolution works on clauses without explicit existential quantifiers. **Skolemization** replaces an existential variable with a new name for its witness. If the existential is inside universal variables, the witness may depend on them, so we use a Skolem function: `∀x ∃y Parent(x,y)` becomes `∀x Parent(x, child_of(x))`.

```python
def skolemize_w(formula, universals=(), counter=[0]):
    tag = formula[0]
    if tag == 'forall':
        _, v, body = formula
        return ('forall', v, skolemize_w(body, universals + (v,), counter))
    if tag == 'exists':
        _, v, body = formula
        counter[0] += 1
        sk = 'sk' + str(counter[0])
        replacement = sk if len(universals) == 0 else (sk, tuple(universals))
        return skolemize_w(subst_formula_w(body, {v: replacement}), universals, counter)
    if tag in ('and', 'or', 'implies'):
        return (tag, skolemize_w(formula[1], universals, counter), skolemize_w(formula[2], universals, counter))
    if tag == 'not':
        return ('not', skolemize_w(formula[1], universals, counter))
    return formula

def subst_formula_w(f, subst):
    tag = f[0]
    if tag in ('and', 'or', 'implies'):
        return (tag, subst_formula_w(f[1], subst), subst_formula_w(f[2], subst))
    if tag == 'not':
        return ('not', subst_formula_w(f[1], subst))
    if tag in ('forall', 'exists'):
        _, v, body = f
        small = {k: val for k, val in subst.items() if k != v}
        return (tag, v, subst_formula_w(body, small))
    return subst_atom_w(f, subst)

formula_w = ('forall', '?x', ('exists', '?y', pred_w('Parent', '?x', '?y')))
skolem_w = skolemize_w(formula_w, counter=[0])
print('before:', formula_w)
print('after:', skolem_w)
assert skolem_w == ('forall', '?x', ('Parent', ('?x', ('sk1', ('?x',)))))
```
▶ What you'll see: the existential `?y` is replaced by a function of the universal `?x`.

```python
formula2_w = ('exists', '?z', pred_w('Bird', '?z'))
skolem2_w = skolemize_w(formula2_w, counter=[0])
print('existential with no universal:', skolem2_w)
assert skolem2_w == ('Bird', ('sk1',))
```
▶ What you'll see: an existential outside any universal becomes a Skolem constant.


```python
plt.figure(figsize=(5, 2.6)) # create a Skolem-dependency diagram.

```
▶ What you'll see: an existential under `∀x` becomes a function of `?x`, while a standalone existential becomes a constant.

*Why it's done this way:* Skolem symbols do not claim we know the witness's ordinary name. They preserve satisfiability by giving the proof system a stable placeholder it can carry through clauses.

### 6. Resolution proves by contradiction with unification

FOL resolution uses clauses, complementary literals, and unification. To prove a goal, add its negation; if resolution derives the empty clause, the negated goal is impossible with the knowledge base, so the goal is entailed.

```python
def lit_w(name, args=(), neg=False):
    return (neg, name, tuple(args))

def apply_lit_w(lit, subst):
    neg, name, args = lit
    return (neg, name, tuple(subst_term_w(a, subst) for a in args))

def complementary_w(a, b):
    return a[0] != b[0] and a[1] == b[1] and len(a[2]) == len(b[2])

def resolve_pair_w(c1, c2):
    for i, l1 in enumerate(c1):
        for j, l2 in enumerate(c2):
            if complementary_w(l1, l2):
                s = unify_w((l1[1], l1[2]), (l2[1], l2[2]))
                if s is not None:
                    rest = [apply_lit_w(x, s) for k, x in enumerate(c1) if k != i]
                    rest += [apply_lit_w(x, s) for k, x in enumerate(c2) if k != j]
                    return tuple(dict.fromkeys(rest)), s, (l1, l2)
    return None, None, None

clause_rule_w = (lit_w('Bird', ('?x',), True), lit_w('Wings', ('?x',), False))
clause_fact_w = (lit_w('Bird', ('tweety',), False),)
clause_goal_neg_w = (lit_w('Wings', ('tweety',), True),)
res1_w, s1_w, used1_w = resolve_pair_w(clause_rule_w, clause_fact_w)
res2_w, s2_w, used2_w = resolve_pair_w(res1_w, clause_goal_neg_w)
print('resolvent 1:', res1_w, 'subst:', s1_w)
print('resolvent 2:', res2_w, 'subst:', s2_w)
assert res1_w == (lit_w('Wings', ('tweety',), False),)
assert res2_w == tuple()
```
▶ What you'll see: `Bird(tweety)` triggers the rule, derives `Wings(tweety)`, and clashes with the negated goal to produce the empty clause.

```python
sizes_w = [len(clause_rule_w), len(res1_w), len(res2_w)]
plt.figure(figsize=(4.5, 3))
plt.plot([0, 1, 2], sizes_w, marker='o', color='purple')
plt.xticks([0, 1, 2], ['rule', 'Wings', 'empty'])
plt.ylabel('literals in active clause')
plt.title('Resolution proof trace: 2 → 1 → 0')
plt.show()
```
▶ What you'll see: the proof shrinks to the empty clause, the contradiction marker.

*Why it's done this way:* resolution is useful because it reduces many proof steps to one repeatable operation: unify complementary literals, cancel them, and keep the remaining disjunction. The empty clause is a machine-checkable certificate of entailment.

### Easy 3 — Run Robinson unification on two atoms

**Goal.** Build a small unifier with an occurs check, because FOL resolution needs most-general unifiers rather than ad hoc string matching. We build it in 4 steps.

```python
def is_var_e3(t_e3): return isinstance(t_e3, str) and t_e3.startswith('?') # variable predicate.
def sub_e3(t_e3, s_e3): # recursively apply substitution.
    if is_var_e3(t_e3): return sub_e3(s_e3[t_e3], s_e3) if t_e3 in s_e3 else t_e3
    if isinstance(t_e3, str): return t_e3
    return (t_e3[0], tuple(sub_e3(a_e3, s_e3) for a_e3 in t_e3[1]))
def occurs_e3(v_e3, t_e3, s_e3): # occurs check.
    t_e3 = sub_e3(t_e3, s_e3)
    return v_e3 == t_e3 or (isinstance(t_e3, tuple) and any(occurs_e3(v_e3, a_e3, s_e3) for a_e3 in t_e3[1]))
print('helpers ready') # confirm definitions.
```
▶ What you'll see: the helper functions are defined for variables, substitution, and occurs checking.

```python
def unify_e3(a_e3, b_e3, s_e3=None): # Robinson-style recursive unification.
    s_e3 = {} if s_e3 is None else dict(s_e3) # copy bindings so calls are safe.
    a_e3, b_e3 = sub_e3(a_e3, s_e3), sub_e3(b_e3, s_e3) # apply current bindings first.
    if a_e3 == b_e3: return s_e3 # identical terms need no new binding.
    if is_var_e3(a_e3): # bind left variable if safe.
        if occurs_e3(a_e3, b_e3, s_e3): return None
        s_e3[a_e3] = b_e3; return s_e3
    if is_var_e3(b_e3): return unify_e3(b_e3, a_e3, s_e3) # symmetric variable case.
    if isinstance(a_e3, tuple) and isinstance(b_e3, tuple) and a_e3[0] == b_e3[0] and len(a_e3[1]) == len(b_e3[1]): # same symbol and arity.
        for aa_e3, bb_e3 in zip(a_e3[1], b_e3[1]): # unify corresponding arguments.
            s_e3 = unify_e3(aa_e3, bb_e3, s_e3)
            if s_e3 is None: return None
        return s_e3
    return None # different constants or symbols cannot unify.
print('unifier ready') # confirm algorithm definition.
```


### Advanced 3 — Standardize variables apart before resolution

▶ What you'll see: both clauses use `?x`, but those names came from separate universal scopes.

```python
def standardize_a3(clause_a3, suffix_a3): # rename every variable in a clause with a suffix.
    mapping_a3 = {} # remember old-to-new variable names.
    out_a3 = [] # store renamed literals.
    for neg_a3, name_a3, args_a3 in clause_a3: # loop over literals.
        new_args_a3 = [] # build renamed argument list.
        for arg_a3 in args_a3: # loop over arguments.

                mapping_a3.setdefault(arg_a3, arg_a3 + suffix_a3) # assign a fresh name.
                new_args_a3.append(mapping_a3[arg_a3]) # use fresh name.

                new_args_a3.append(arg_a3) # constants unchanged.

    return out_a3 # return standardized-apart clause.
```
