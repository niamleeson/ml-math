# 2.5 — Newton & Quasi-Newton Methods

Newton methods improve on plain gradient descent by using curvature: instead of moving only opposite the gradient, they rescale the gradient by the local Hessian so steep directions shrink and flat directions stretch. Quasi-Newton methods keep that second-order behavior without forming a full Hessian, learning curvature from the observed changes in parameters and gradients.

Before the terse worked examples, we build Newton and quasi-Newton optimization one idea at a time. Run each cell in order and inspect the printed arrays — the goal is to make every Hessian solve, damping decision, and curvature update visible rather than magical. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, matrix solves, eigenvalues, and dot products for optimization geometry.
```

### 1. Newton's step: solve a local quadratic model

Gradient descent asks only which direction decreases the function now. Newton asks a sharper question: if the function near the current point is approximated by a quadratic bowl, where is the bottom of that bowl? For a twice-differentiable function, the second-order Taylor model is

$$m(p)=f(x)+g^T p+\frac12 p^T H p,$$

where $g=\nabla f(x)$ and $H=\nabla^2 f(x)$. Minimizing this model gives $Hp=-g$, so the Newton direction is $p=-H^{-1}g$. We solve a linear system instead of explicitly inverting $H$ because solving is numerically cleaner and mirrors what large optimizers actually do.

```python
H_w = np.array([[4.0, 1.0], [1.0, 3.0]])  # symmetric positive-definite curvature matrix.
b_w = np.array([1.0, 2.0])  # linear term for f(x)=1/2 x^T H x - b^T x.
x0_w = np.array([0.0, 0.0])  # start at the origin.
g0_w = H_w @ x0_w - b_w  # gradient of the quadratic at x0.
print("H:\n", H_w)
print("gradient at x0:", g0_w)
```
▶ What you'll see: the gradient is `[-1, -2]`, so the origin is not stationary.

```python
p_newton_w = np.linalg.solve(H_w, -g0_w)  # solve H p = -g instead of computing inv(H) @ (-g).
x1_w = x0_w + p_newton_w  # take the full Newton step.
print("Newton direction:", np.round(p_newton_w, 6))
print("new point:", np.round(x1_w, 6))
assert np.allclose(np.round(x1_w, 6), np.array([0.090909, 0.636364]))
```
▶ What you'll see: the Newton step lands at `[0.090909, 0.636364]`, the exact quadratic minimizer.

```python
def quad_w(x):
    return 0.5 * float(x @ H_w @ x) - float(b_w @ x)

grid_x_w = np.linspace(-0.4, 0.7, 80)
grid_y_w = np.linspace(-0.1, 1.1, 80)
X_w, Y_w = np.meshgrid(grid_x_w, grid_y_w)
Z_w = 0.5 * (H_w[0, 0] * X_w**2 + 2 * H_w[0, 1] * X_w * Y_w + H_w[1, 1] * Y_w**2) - b_w[0] * X_w - b_w[1] * Y_w
plt.figure(figsize=(4.6, 3.6))
plt.contour(X_w, Y_w, Z_w, levels=18, cmap="viridis")
plt.plot([x0_w[0], x1_w[0]], [x0_w[1], x1_w[1]], marker="o", color="crimson")
plt.title("1: Newton jumps to the quadratic bottom")
plt.xlabel("x0"); plt.ylabel("x1"); plt.show()
```
▶ What you'll see: one red segment goes from the origin directly to the center of the quadratic contours.

*Why it's done this way:* the Hessian describes how the gradient changes by direction. Solving $Hp=-g$ finds the displacement that would make the linearized gradient $g+Hp$ equal zero. On an exactly quadratic objective, that linearized gradient is the true gradient everywhere, so one solve reaches the optimum.

### 2. Damped Newton: trust the model only locally

Newton's full step can be too aggressive when the quadratic approximation is only local. Damping keeps the Newton direction but chooses a step length $\alpha\in(0,1]$ by checking sufficient decrease. The simplest safe check here is Armijo backtracking: accept $x+\alpha p$ only if

$$f(x+\alpha p)\le f(x)+c\alpha g^T p.$$

The right side is not merely "lower than before"; it demands enough decrease relative to the predicted directional slope.

```python
def f1_w(x):
    return x**4 - 3 * x**3 + 2.0  # nonquadratic one-dimensional objective.

def g1_w(x):
    return 4 * x**3 - 9 * x**2  # derivative.

def h1_w(x):
    return 12 * x**2 - 18 * x  # second derivative.

x_w = 1.0
p_w = -g1_w(x_w) / h1_w(x_w)  # one-dimensional Newton direction.
print("x:", x_w, "gradient:", g1_w(x_w), "Hessian:", h1_w(x_w), "full Newton p:", round(p_w, 3))
```
▶ What you'll see: the full Newton direction is computable, but the local curvature is negative here.

```python
alpha_w = 1.0
c_w = 1e-4
trial_rows_w = []
for _ in range(8):
    lhs_w = f1_w(x_w + alpha_w * p_w)
    rhs_w = f1_w(x_w) + c_w * alpha_w * g1_w(x_w) * p_w
    trial_rows_w.append((alpha_w, lhs_w, rhs_w, lhs_w <= rhs_w))
    if lhs_w <= rhs_w:
        break
    alpha_w *= 0.5
print("alpha, f(trial), Armijo bound, accepted")
for row_w in trial_rows_w:
    print(round(row_w[0], 4), round(row_w[1], 4), round(row_w[2], 4), row_w[3])
```
▶ What you'll see: backtracking tests the full step first, then halves until the sufficient-decrease test passes.

```python
xs_plot_w = np.linspace(-0.2, 3.0, 200)
plt.figure(figsize=(5, 3))
plt.plot(xs_plot_w, f1_w(xs_plot_w), color="navy", label="f(x)")
plt.scatter([x_w], [f1_w(x_w)], color="black", label="start")
plt.scatter([x_w + alpha_w * p_w], [f1_w(x_w + alpha_w * p_w)], color="crimson", label="accepted")
plt.title("2: damping protects a local Newton step")
plt.xlabel("x"); plt.ylabel("f(x)"); plt.legend(); plt.show()
```
▶ What you'll see: the accepted point decreases the objective without blindly trusting the full local model.

*Why it's done this way:* Newton's direction comes from a local Taylor model, not a global promise. Backtracking keeps the curvature-aware direction but uses the true objective as a referee, so a bad or indefinite local model cannot force an unsafe full jump.

### 3. BFGS: learn curvature from secant information

BFGS avoids forming the true Hessian. It maintains an approximate Hessian $B_k$ and forces the next approximation to match the latest observed curvature:

$$B_{k+1}s_k=y_k,\qquad s_k=x_{k+1}-x_k,\quad y_k=g_{k+1}-g_k.$$

The BFGS Hessian update is

$$B_+=B-\frac{Bs(Bs)^T}{s^T Bs}+\frac{yy^T}{y^T s}.$$

The two rank-one corrections remove the old curvature along $s$ and insert the newly observed curvature $y$.

```python
B_w = np.eye(2)  # start with an identity Hessian approximation.
s_w = np.array([1.0, 2.0])  # observed parameter displacement.
y_w = np.array([3.0, 5.0])  # observed gradient displacement.
print("s^T B s:", float(s_w @ B_w @ s_w))
print("y^T s:", float(y_w @ s_w))
assert float(y_w @ s_w) == 13.0
```
▶ What you'll see: both denominators are positive, so the BFGS curvature update is safe.

```python
Bs_w = B_w @ s_w
B_plus_w = B_w - np.outer(Bs_w, Bs_w) / float(s_w @ Bs_w) + np.outer(y_w, y_w) / float(y_w @ s_w)
print("B+ :\n", np.round(B_plus_w, 6))
print("B+ s:", np.round(B_plus_w @ s_w, 6), "target y:", y_w)
assert np.allclose(B_plus_w @ s_w, y_w)
```
▶ What you'll see: `B+ s` equals `y`, so the secant equation is satisfied exactly.

```python
eigs_w = np.linalg.eigvalsh(B_plus_w)
plt.figure(figsize=(4.4, 3))
plt.bar(["eig 1", "eig 2"], eigs_w, color="seagreen")
plt.axhline(0, color="black", linewidth=1)
plt.title("3: BFGS keeps positive curvature")
plt.ylabel("eigenvalue")
plt.show()
```
▶ What you'll see: both eigenvalues are positive, so the approximate Hessian still defines a convex local bowl.

*Why it's done this way:* the secant pair $(s,y)$ is real evidence about curvature because gradients changed by $y$ after moving by $s$. The condition $s^Ty>0$ says the observed curvature along the step was positive; under that condition, BFGS preserves positive definiteness and therefore keeps producing descent directions when solved against the gradient.

### 4. L-BFGS: apply inverse curvature without storing a matrix

Full BFGS stores a dense $d\times d$ matrix, which is expensive when $d$ is large. L-BFGS stores only the last few $(s,y)$ pairs and applies an approximate inverse Hessian to a gradient using the two-loop recursion. This produces the preconditioned vector $H_k g$ without ever forming $H_k$.

```python
pairs_w = [
    (np.array([1.0, 0.0]), np.array([2.0, 0.0])),  # curvature 2 on coordinate 0.
    (np.array([0.0, 1.0]), np.array([0.0, 4.0])),  # curvature 4 on coordinate 1.
]
g_w = np.array([2.0, 4.0])  # gradient to precondition.
print("stored pairs:", len(pairs_w))
print("gradient:", g_w)
```
▶ What you'll see: two curvature pairs describe separate coordinate-wise scalings.

```python
q_w = g_w.copy()
alphas_w = []
for s_i_w, y_i_w in pairs_w[::-1]:
    rho_i_w = 1.0 / float(y_i_w @ s_i_w)
    alpha_i_w = rho_i_w * float(s_i_w @ q_w)
    alphas_w.append(alpha_i_w)
    q_w = q_w - alpha_i_w * y_i_w
print("after first loop q:", q_w)
print("stored alphas reversed:", np.round(alphas_w, 3))
```
▶ What you'll see: the first loop subtracts recently learned curvature components from the gradient.

```python
r_w = q_w.copy()  # use identity initial inverse scale for this diagonal teaching example.
for (s_i_w, y_i_w), alpha_i_w in zip(pairs_w, alphas_w[::-1]):
    rho_i_w = 1.0 / float(y_i_w @ s_i_w)
    beta_i_w = rho_i_w * float(y_i_w @ r_w)
    r_w = r_w + s_i_w * (alpha_i_w - beta_i_w)
direction_w = -r_w
print("H_inv g:", np.round(r_w, 6))
print("search direction:", np.round(direction_w, 6))
assert np.allclose(r_w, np.array([1.0, 1.0]))
```
▶ What you'll see: the inverse approximation maps gradient `(2,4)` to `(1,1)`, so the step is `-(1,1)`.

*Why it's done this way:* L-BFGS is a memory-efficient preconditioner. Each stored pair says, "when we moved this way, gradients changed that way." The two loops replay those facts algebraically so steep directions are divided by larger curvature and flat directions are not over-shrunk.

### Basic 7 — Backtrack a one-dimensional Newton step

**Goal.** Apply Armijo backtracking to a Newton direction, because damping prevents over-trusting a local model. We build it in 3 steps.

```python
def f_b7(x_b7):
    return (x_b7 - 2.0) ** 4 + 0.5 * (x_b7 - 2.0) ** 2

def g_b7(x_b7):
    return 4 * (x_b7 - 2.0) ** 3 + (x_b7 - 2.0)

def h_b7(x_b7):

x_b7 = 0.0
p_b7 = -g_b7(x_b7) / h_b7(x_b7)
print("Newton p:", round(p_b7, 3), "slope g*p:", round(g_b7(x_b7) * p_b7, 3))
```

```python
alpha_b7 = 1.0

    alpha_b7 *= 0.5

print("accepted alpha:", alpha_b7, "x_next:", round(x_next_b7, 3))
```

```python
xs_b7 = np.linspace(-0.5, 3.0, 200)

```
▶ What you'll see: the accepted step decreases the objective along the Newton direction.

👀 Takeaway: damping is a practical safeguard, not a rejection of Newton geometry.

### Easy 1 — Run Newton iterations on logistic loss

**Goal.** Minimize a simple one-parameter logistic loss, because Newton is common for generalized linear models. We build it in 4 steps.

```python
x_e1 = np.array([-2.0, -1.0, 1.0, 2.0])
y_e1 = np.array([0.0, 0.0, 1.0, 1.0])
w_e1 = 0.0
print("features:", x_e1)
print("labels:", y_e1)
```

```python
def sigmoid_e1(z_e1):
    return 1.0 / (1.0 + np.exp(-z_e1))

def loss_e1(w_val_e1):
    p_e1 = sigmoid_e1(w_val_e1 * x_e1)
    return -float(np.sum(y_e1 * np.log(p_e1 + 1e-12) + (1 - y_e1) * np.log(1 - p_e1 + 1e-12)))

losses_e1 = []
print("initial loss:", round(loss_e1(w_e1), 3))
```

```python
for step_e1 in range(6):
    p_e1 = sigmoid_e1(w_e1 * x_e1)
    grad_e1 = float(np.sum((p_e1 - y_e1) * x_e1))
    hess_e1 = float(np.sum(p_e1 * (1 - p_e1) * x_e1**2))
    w_e1 = w_e1 - grad_e1 / hess_e1
    losses_e1.append(loss_e1(w_e1))
```

### Easy 3 — Implement BFGS on a quadratic

**Goal.** Run a small BFGS optimizer, because the update should learn enough curvature to solve a quadratic without the true Hessian. We build it in 4 steps.


```python

    g_e3 = H_e3 @ x_e3 - b_e3
    if np.linalg.norm(g_e3) < 1e-10:
        break

    x_e3 = x_new_e3
    path_e3.append(x_e3.copy())
path_e3 = np.array(path_e3)
```

### Advanced 1 — Damped Newton on Rosenbrock's valley

**Goal.** Optimize the Rosenbrock function with damped Newton, because curved valleys show why full steps need line search. We build it in 5 steps.

```python
def rosen_a1(x_a1):
    return (1 - x_a1[0]) ** 2 + 100 * (x_a1[1] - x_a1[0] ** 2) ** 2

def grad_rosen_a1(x_a1):
    return np.array([-2 * (1 - x_a1[0]) - 400 * x_a1[0] * (x_a1[1] - x_a1[0] ** 2), 200 * (x_a1[1] - x_a1[0] ** 2)])

def hess_rosen_a1(x_a1):
    return np.array([[2 - 400 * x_a1[1] + 1200 * x_a1[0] ** 2, -400 * x_a1[0]], [-400 * x_a1[0], 200]])

x_a1 = np.array([-1.2, 1.0])
path_a1 = [x_a1.copy()]
values_a1 = [rosen_a1(x_a1)]
print("start value:", round(values_a1[-1], 3))
```

```python
for _ in range(20):
    g_a1 = grad_rosen_a1(x_a1)
    H_a1 = hess_rosen_a1(x_a1)
    p_a1 = np.linalg.solve(H_a1, -g_a1)
    alpha_a1 = 1.0
    while rosen_a1(x_a1 + alpha_a1 * p_a1) > rosen_a1(x_a1) + 1e-4 * alpha_a1 * float(g_a1 @ p_a1):
        alpha_a1 *= 0.5
    x_a1 = x_a1 + alpha_a1 * p_a1
    path_a1.append(x_a1.copy())
    values_a1.append(rosen_a1(x_a1))
    if np.linalg.norm(grad_rosen_a1(x_a1)) < 1e-8:
        break
path_a1 = np.array(path_a1)
```

### Advanced 2 — Compare full BFGS with true Newton on the same quadratic

**Goal.** Compare directions as BFGS learns, because its matrix should approach the true Hessian information. We build it in 4 steps.
