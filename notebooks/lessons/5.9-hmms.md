# 5.9 — Hidden Markov Models

Hidden Markov Models (HMMs) model sequences where the important state is hidden and each observation is only noisy evidence about it. In this lesson, we build the hidden chain, emission model, forward filtering, likelihood scaling, Viterbi decoding, and smoothing from first principles with tiny NumPy arrays so every probability can be inspected.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build Hidden Markov Models one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math is spelled out so nothing is a black box. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, probability vectors, and dynamic-programming tables.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for sampling demos.
```

### 1. Hidden states and noisy observations

An HMM separates the world into two layers: a hidden state $z_t$ that we care about, and an observed symbol $y_t$ that gives noisy evidence about it. Here state 0 means "healthy" and state 1 means "fever"; observation 0 means "normal temperature" and observation 1 means "hot." The key modeling move is that observations are not the state itself — a healthy person can sometimes look hot, and a fever can sometimes look normal.

```python
states_w = ["healthy", "fever"]  # names for hidden states z_t.
obs_w = ["normal", "hot"]  # names for observation symbols y_t.
pi_w = np.array([0.6, 0.4])  # p(z_1): prior belief before seeing data.
E_w = np.array([[0.9, 0.1],  # p(y|healthy): normal is likely.
                [0.2, 0.8]]) # p(y|fever): hot is likely.
print("prior p(z1):", pi_w)
print("emission rows p(y|state):\n", E_w)
assert np.allclose(E_w.sum(axis=1), 1.0)
```
▶ What you'll see: each emission row sums to 1, but neither row is deterministic.

```python
plt.figure(figsize=(4.4, 3))
plt.imshow(E_w, cmap="viridis", aspect="auto")
plt.colorbar(label="p(observation | state)")
plt.xticks(range(2), obs_w); plt.yticks(range(2), states_w)
plt.title("1: noisy emission probabilities")
plt.show()
```
▶ What you'll see: healthy strongly emits normal, fever strongly emits hot, but both off-diagonal probabilities remain nonzero.

*Why it's done this way:* The emission matrix stores a likelihood $p(y_t\mid z_t)$, not a posterior. We keep likelihoods separate from beliefs because evidence should multiply prior state probabilities and then be normalized; otherwise one noisy symptom would be mistaken for certain truth.

### 2. The Markov transition chain

The hidden state evolves through time. The first-order Markov assumption says the current state carries all relevant history: $p(z_t\mid z_{1:t-1})=p(z_t\mid z_{t-1})$. That is what lets a long sequence be handled with a small transition matrix instead of an exponential table over all histories.

```python
T_w = np.array([[0.7, 0.3],  # from healthy: usually stay healthy, sometimes fever.
                [0.2, 0.8]]) # from fever: usually stay feverish, sometimes recover.
print("transition T[r,s] = p(next=s | current=r):\n", T_w)
print("row sums:", T_w.sum(axis=1))
assert np.allclose(T_w.sum(axis=1), 1.0)
```
▶ What you'll see: every row is a conditional distribution over the next hidden state.

```python
belief0_w = np.array([0.87096774, 0.12903226])  # a filtered belief after one normal observation.
pred1_w = belief0_w @ T_w  # one-step prediction before the next observation.
print("belief now:", np.round(belief0_w, 3))
print("predicted next belief:", np.round(pred1_w, 3))
assert np.allclose(np.round(pred1_w, 3), [0.635, 0.365])
```
▶ What you'll see: even after evidence for healthy, transition uncertainty moves some mass toward fever.

```python
plt.figure(figsize=(4.6, 3))
x_w = np.arange(2)
plt.bar(x_w - 0.18, belief0_w, width=0.36, label="current")
plt.bar(x_w + 0.18, pred1_w, width=0.36, label="predicted next")
plt.xticks(x_w, states_w); plt.ylim(0, 1)
plt.title("2: transition prediction spreads belief")
plt.legend(); plt.show()
```
▶ What you'll see: the next-step prediction is less certain than the current filtered belief.

*Why it's done this way:* Matrix multiplication sums over all possible previous states: $p(z_t=s)=\sum_r p(z_{t-1}=r)T_{rs}$. This is exactly marginalization, and the Markov assumption makes the previous belief vector a sufficient summary of the whole past.

### 3. Filtering: combine prediction with the latest evidence

Filtering answers: after seeing observations up to time $t$, what do we believe about $z_t$? The recursion has two parts: predict with the transition matrix, then multiply by the emission likelihood for the new observation and normalize.

```python
y0_w = 0  # first observation is normal.
unnorm0_w = pi_w * E_w[:, y0_w]  # p(z1) p(y1|z1).
filter0_w = unnorm0_w / unnorm0_w.sum()  # normalize into p(z1|y1).
print("unnormalized:", unnorm0_w)
print("filtered p(z1 | normal):", np.round(filter0_w, 3))
assert np.allclose(np.round(filter0_w, 3), [0.871, 0.129])
```
▶ What you'll see: `[0.6·0.9, 0.4·0.2] = [0.54, 0.08]` normalizes to `[0.871, 0.129]`.

```python
y1_w = 1  # second observation is hot.
pred2_w = filter0_w @ T_w  # prior for z2 after the transition.
unnorm1_w = pred2_w * E_w[:, y1_w]  # multiply by p(hot | state).
filter1_w = unnorm1_w / unnorm1_w.sum()
print("prediction before hot:", np.round(pred2_w, 3))
print("filtered p(z2 | normal, hot):", np.round(filter1_w, 3))
assert np.allclose(np.round(filter1_w, 3), [0.179, 0.821])
```
▶ What you'll see: a hot observation overwhelms much of the previous healthy belief.

```python
plt.figure(figsize=(5, 3))
plt.plot([0, 1], [filter0_w[1], filter1_w[1]], marker="o", color="crimson")
plt.xticks([0, 1], ["after normal", "after hot"])
plt.ylim(0, 1); plt.ylabel("p(fever | evidence)")
plt.title("3: filtering updates with each observation")
plt.show()
```
▶ What you'll see: fever probability jumps after the hot observation.

*Why it's done this way:* Bayes' rule says posterior is proportional to prior times likelihood. The transition creates the prior for the current state; the emission likelihood scores how compatible each state is with the new observation; normalization turns the scores back into probabilities.

### 4. Forward messages and sequence likelihood

The unnormalized forward message $\alpha_t(s)=p(y_{1:t},z_t=s)$ carries both state belief and the probability of the evidence so far. If we normalize every step for numerical stability, we must keep the scale factors, because their product recovers the sequence likelihood $p(y_{1:T})$.

```python
seq_w = np.array([0, 1, 1])  # normal, hot, hot.
alpha_w = pi_w * E_w[:, seq_w[0]]
scales_w = [alpha_w.sum()]
alpha_scaled_w = alpha_w / scales_w[-1]
print("t=0 alpha:", alpha_w, "scale:", round(scales_w[-1], 6))
print("t=0 normalized:", np.round(alpha_scaled_w, 3))
```
▶ What you'll see: the first scale is the probability of observing `normal` under the prior.

```python
for y_w in seq_w[1:]:
    raw_w = (alpha_scaled_w @ T_w) * E_w[:, y_w]
    scales_w.append(raw_w.sum())
    alpha_scaled_w = raw_w / scales_w[-1]
    print("obs", obs_w[y_w], "scale", round(scales_w[-1], 6), "filtered", np.round(alpha_scaled_w, 3))
lik_w = float(np.prod(scales_w))
print("sequence likelihood:", round(lik_w, 6))
assert round(lik_w, 6) == 0.131542
```
▶ What you'll see: the filtering vector changes each step, and the scale product is `0.131542`.

```python
plt.figure(figsize=(5, 3))
plt.bar(["c0", "c1", "c2"], scales_w, color="steelblue")
plt.ylabel("normalization scale")
plt.title("4: scales multiply to p(sequence)")
plt.show()
```
▶ What you'll see: each bar is a local evidence probability; multiplying them gives the full sequence likelihood.

*Why it's done this way:* Normalization prevents tiny probabilities from underflowing, but it divides out exactly the evidence probability at each step. Saving the scales preserves the likelihood, which is needed for model comparison and learning.

### 5. Viterbi: the single most likely hidden path

Filtering gives marginal probabilities at each time. Viterbi answers a different question: which complete hidden path has the largest joint probability? It replaces the forward sum over previous states with a max and stores backpointers so the best path can be reconstructed.

```python
logT_w = np.log(T_w)
logE_w = np.log(E_w)
logpi_w = np.log(pi_w)
delta_w = np.zeros((len(seq_w), 2))
back_w = np.zeros((len(seq_w), 2), dtype=int)
delta_w[0] = logpi_w + logE_w[:, seq_w[0]]
print("initial log scores:", np.round(delta_w[0], 3))
```
▶ What you'll see: Viterbi starts from the same prior-times-emission ingredients, but in log space.

```python
for t_w in range(1, len(seq_w)):
    for s_w in range(2):
        candidates_w = delta_w[t_w - 1] + logT_w[:, s_w]
        back_w[t_w, s_w] = int(np.argmax(candidates_w))
        delta_w[t_w, s_w] = candidates_w[back_w[t_w, s_w]] + logE_w[s_w, seq_w[t_w]]
    print("t", t_w, "delta", np.round(delta_w[t_w], 3), "back", back_w[t_w])
```
▶ What you'll see: every state keeps only the best previous state, not a sum over all previous states.

```python
path_w = [int(np.argmax(delta_w[-1]))]
for t_w in range(len(seq_w) - 1, 0, -1):
    path_w.append(int(back_w[t_w, path_w[-1]]))
path_w = path_w[::-1]
print("Viterbi path:", path_w, [states_w[i] for i in path_w])
assert path_w == [0, 1, 1]
```
▶ What you'll see: the best complete path is `[healthy, fever, fever]`.

*Why it's done this way:* The most likely path is a global sequence decision. A locally best marginal state can be inconsistent with the transition rewards; backpointers preserve the dynamic-programming choices needed to recover the globally best chain.

### 6. Smoothing: use future evidence too

Filtering at time $t$ uses only $y_{1:t}$. Smoothing uses the whole sequence $y_{1:T}$ to revise earlier beliefs. The backward message $\beta_t(s)=p(y_{t+1:T}\mid z_t=s)$ says how compatible the future is with each current state.

```python
alpha_raw_w = np.zeros((len(seq_w), 2))
alpha_raw_w[0] = pi_w * E_w[:, seq_w[0]]
for t_w in range(1, len(seq_w)):
    alpha_raw_w[t_w] = (alpha_raw_w[t_w - 1] @ T_w) * E_w[:, seq_w[t_w]]
print("raw forward messages:\n", np.round(alpha_raw_w, 6))
```
▶ What you'll see: raw forward messages shrink because they include the probability of all evidence so far.

```python
beta_w = np.ones((len(seq_w), 2))
for t_w in range(len(seq_w) - 2, -1, -1):
    beta_w[t_w] = T_w @ (E_w[:, seq_w[t_w + 1]] * beta_w[t_w + 1])
print("backward messages:\n", np.round(beta_w, 6))
```
▶ What you'll see: early states receive different future-compatibility scores.

```python
smooth0_w = alpha_raw_w[0] * beta_w[0]
smooth0_w = smooth0_w / smooth0_w.sum()
filter0_again_w = alpha_raw_w[0] / alpha_raw_w[0].sum()
print("filtered at t=0:", np.round(filter0_again_w, 3))
print("smoothed at t=0:", np.round(smooth0_w, 3))
assert smooth0_w[1] > filter0_again_w[1]
```
▶ What you'll see: future hot observations raise the initial fever probability above its filtered value.

```python
plt.figure(figsize=(4.8, 3))
plt.bar(["filtered fever", "smoothed fever"], [filter0_again_w[1], smooth0_w[1]], color=["gray", "crimson"])
plt.ylim(0, 0.4); plt.title("6: future evidence revises the past")
plt.ylabel("p(fever at t=0)")
plt.show()
```
▶ What you'll see: smoothing is higher for fever because later hot observations make an early fever more plausible.

*Why it's done this way:* Forward and backward messages factor the joint probability into past evidence, current state, and future evidence. Multiplying $\alpha_t(s)\beta_t(s)$ combines both directions without enumerating every hidden path.

### Basic 1 — Create a tiny HMM

**Goal.** Store a prior, transition matrix, and emission matrix, because an HMM is completely defined by these three probability objects. We build it in 2 steps.

```python
states_b1 = ["healthy", "fever"] # name the two hidden states for readable output.
obs_b1 = ["normal", "hot"] # name the two possible observed symbols.
pi_b1 = np.array([0.6, 0.4]) # set p(z1), the initial hidden-state distribution.
print("states:", states_b1) # inspect hidden-state labels.
print("observations:", obs_b1) # inspect observation labels.
```
▶ What you'll see: two hidden states and two noisy observation types.

```python
T_b1 = np.array([[0.7, 0.3], [0.2, 0.8]]) # define p(z_t=s | z_{t-1}=r) by rows.
E_b1 = np.array([[0.9, 0.1], [0.2, 0.8]]) # define p(y_t | z_t=s) by rows.
print("T:\n", T_b1) # inspect transition probabilities.
print("E:\n", E_b1) # inspect emission probabilities.
assert np.allclose(T_b1.sum(axis=1), 1.0) # verify transition rows are distributions.
assert np.allclose(E_b1.sum(axis=1), 1.0) # verify emission rows are distributions.
```
▶ What you'll see: every row sums to 1, so each row is a valid conditional distribution.

👀 Takeaway: an HMM is a hidden transition model plus an observation model.

### Basic 2 — Normalize noisy evidence

**Goal.** Update the prior after one observation, because filtering begins with prior times likelihood followed by normalization. We build it in 2 steps.

```python
pi_b2 = np.array([0.6, 0.4]) # prior p(z1) before any observation.
E_b2 = np.array([[0.9, 0.1], [0.2, 0.8]]) # emission likelihood p(y|state).
y_b2 = 0 # observe normal temperature.
scores_b2 = pi_b2 * E_b2[:, y_b2] # multiply prior by likelihood for each state.
print("unnormalized scores:", scores_b2) # inspect prior-times-likelihood values.
```
▶ What you'll see: healthy receives score 0.54 and fever receives score 0.08.

```python
post_b2 = scores_b2 / scores_b2.sum() # divide by total evidence to get a posterior distribution.
print("posterior after normal:", np.round(post_b2, 3)) # inspect normalized belief.
assert np.allclose(np.round(post_b2, 3), [0.871, 0.129]) # verify the lesson arithmetic.
plt.figure(figsize=(4, 3)) # create a compact posterior chart.
plt.bar(["healthy", "fever"], post_b2, color="seagreen") # visualize filtered probabilities.
plt.ylim(0, 1); plt.title("Basic 2: one-step posterior") # title the chart.
plt.show() # display the bar chart.
```
▶ What you'll see: a normal reading makes healthy much more likely than fever.

👀 Takeaway: an HMM observation is evidence that must be normalized into a belief.

### Basic 3 — Predict one step forward

**Goal.** Move a belief through the hidden transition matrix, because the hidden state can change before the next observation arrives. We build it in 2 steps.

```python
belief_b3 = np.array([0.87096774, 0.12903226]) # filtered belief after seeing a normal observation.
T_b3 = np.array([[0.7, 0.3], [0.2, 0.8]]) # transition probabilities from current to next state.
contrib_b3 = belief_b3[:, None] * T_b3 # contribution from each current state to each next state.
print("transition contributions:\n", np.round(contrib_b3, 3)) # inspect the marginalization pieces.
```
▶ What you'll see: each current-state probability is split across possible next states.

```python
pred_b3 = belief_b3 @ T_b3 # sum contributions over previous states.
print("predicted next belief:", np.round(pred_b3, 3)) # inspect p(z_next | evidence so far).
assert np.allclose(np.round(pred_b3, 3), [0.635, 0.365]) # verify the prediction arithmetic.
plt.figure(figsize=(4, 3)) # create a compact prediction figure.
plt.bar(["healthy", "fever"], pred_b3, color="steelblue") # visualize next-step belief.

```
▶ What you'll see: probability mass moves from healthy to fever through transition uncertainty.

👀 Takeaway: prediction is marginalization over the previous hidden state.

### Basic 4 — Filter after a second observation

**Goal.** Combine a transition prediction with a hot observation, because filtering alternates prediction and evidence updates. We build it in 3 steps.

```python
pred_b4 = np.array([0.635, 0.365]) # belief before seeing the second observation.
E_b4 = np.array([[0.9, 0.1], [0.2, 0.8]]) # emission likelihood matrix.
y_b4 = 1 # observe hot.
like_b4 = E_b4[:, y_b4] # likelihood of hot under each state.
print("likelihood of hot:", like_b4) # inspect which state explains hot better.
```

```python
scores_b4 = pred_b4 * like_b4 # multiply prediction by new evidence.
```

### Basic 5 — Store a forward table

**Goal.** Fill a forward-probability table for a short sequence, because dynamic programming stores reusable messages instead of enumerating all paths. We build it in 3 steps.

```python
seq_b5 = np.array([0, 1, 1]) # observations: normal, hot, hot.
pi_b5 = np.array([0.6, 0.4]) # initial state probabilities.
T_b5 = np.array([[0.7, 0.3], [0.2, 0.8]]) # transition matrix.
E_b5 = np.array([[0.9, 0.1], [0.2, 0.8]]) # emission matrix.
alpha_b5 = np.zeros((len(seq_b5), 2)) # allocate one row per time and one column per hidden state.
print("alpha shape:", alpha_b5.shape) # inspect dynamic-programming table shape.
```
▶ What you'll see: the table has three time rows and two state columns.

```python
alpha_b5[0] = pi_b5 * E_b5[:, seq_b5[0]] # initialize with p(z1)p(y1|z1).
for t_b5 in range(1, len(seq_b5)): # step through remaining observations.
    alpha_b5[t_b5] = (alpha_b5[t_b5 - 1] @ T_b5) * E_b5[:, seq_b5[t_b5]] # forward recursion.
print("raw alpha table:\n", np.round(alpha_b5, 6)) # inspect joint probabilities p(y_1:t, z_t).
```

```python
plt.figure(figsize=(4.4, 3)) # create a table heatmap.
plt.imshow(alpha_b5, cmap="magma", aspect="auto") # visualize alpha magnitudes.
plt.colorbar(label="alpha") # add numeric color scale.
plt.xticks([0, 1], ["healthy", "fever"]); plt.ylabel("time") # label axes.
plt.title("Basic 5: forward table") # title the heatmap.
plt.show() # display the heatmap.
```
▶ What you'll see: forward probabilities shrink as more evidence is included.

👀 Takeaway: forward messages summarize all hidden histories ending in each current state.

### Basic 6 — Compute sequence likelihood

**Goal.** Sum the final forward message, because $p(y_{1:T})$ is obtained by marginalizing the last hidden state. We build it in 2 steps.

```python
seq_b6 = np.array([0, 1, 1]) # observations: normal, hot, hot.
pi_b6 = np.array([0.6, 0.4]) # prior.
T_b6 = np.array([[0.7, 0.3], [0.2, 0.8]]) # transitions.
E_b6 = np.array([[0.9, 0.1], [0.2, 0.8]]) # emissions.
alpha_b6 = pi_b6 * E_b6[:, seq_b6[0]] # first raw alpha message.
print("alpha t0:", alpha_b6) # inspect the starting joint message.
```
▶ What you'll see: the first message is `[0.54, 0.08]`.

```python
for y_b6 in seq_b6[1:]: # consume remaining observations.
    alpha_b6 = (alpha_b6 @ T_b6) * E_b6[:, y_b6] # update raw forward message.
lik_b6 = alpha_b6.sum() # sum over final hidden states.
print("final alpha:", np.round(alpha_b6, 6)) # inspect final joint state/evidence probabilities.
print("sequence likelihood:", round(float(lik_b6), 6)) # inspect p(observation sequence).
assert round(float(lik_b6), 6) == 0.131542 # verify the lesson likelihood.
```
▶ What you'll see: the final alpha entries sum to the probability of the full observation sequence.

👀 Takeaway: likelihood is not a normalized belief; it is the model's probability of the data.

### Basic 7 — Keep scaling factors

**Goal.** Normalize forward messages while preserving likelihood, because long raw probability products can underflow. We build it in 3 steps.

```python
seq_b7 = np.array([0, 1, 1]) # same toy sequence.
pi_b7 = np.array([0.6, 0.4]) # prior.
T_b7 = np.array([[0.7, 0.3], [0.2, 0.8]]) # transitions.
E_b7 = np.array([[0.9, 0.1], [0.2, 0.8]]) # emissions.
alpha_b7 = pi_b7 * E_b7[:, seq_b7[0]] # first unscaled message.
scale_b7 = [alpha_b7.sum()] # store first normalization constant.
alpha_b7 = alpha_b7 / scale_b7[-1] # normalize for stability.
print("scaled alpha t0:", np.round(alpha_b7, 3), "scale:", round(scale_b7[-1], 6)) # inspect both pieces.
```
▶ What you'll see: the scaled message is a probability vector and the scale stores evidence mass.

```python
for y_b7 in seq_b7[1:]: # process later observations.
    raw_b7 = (alpha_b7 @ T_b7) * E_b7[:, y_b7] # compute unnormalized filtered scores.
    scale_b7.append(raw_b7.sum()) # save local evidence probability.
    alpha_b7 = raw_b7 / scale_b7[-1] # normalize for the next step.
print("scales:", np.round(scale_b7, 6)) # inspect local normalizers.
print("likelihood from scales:", round(float(np.prod(scale_b7)), 6)) # recover p(y_1:T).
assert round(float(np.prod(scale_b7)), 6) == 0.131542 # verify scale product.
```

```python
plt.figure(figsize=(4.5, 3)) # create a scale-factor chart.
plt.bar(range(len(scale_b7)), scale_b7, color="darkorange") # plot one scale per time step.
plt.title("Basic 7: forward scaling factors") # title the plot.
plt.xlabel("time"); plt.ylabel("scale") # label axes.
plt.show() # display the plot.
```
▶ What you'll see: the product of these small normalizers is the full sequence likelihood.

👀 Takeaway: normalizing forward messages is safe only if the discarded scale factors are saved.

### Basic 8 — Build Viterbi scores

**Goal.** Replace sums with maxima in the forward recursion, because Viterbi searches for the best complete hidden path. We build it in 3 steps.

```python
seq_b8 = np.array([0, 1, 1]) # observations to decode.
pi_b8 = np.array([0.6, 0.4]) # prior.
T_b8 = np.array([[0.7, 0.3], [0.2, 0.8]]) # transitions.
E_b8 = np.array([[0.9, 0.1], [0.2, 0.8]]) # emissions.
delta_b8 = np.zeros((len(seq_b8), 2)) # best log score ending in each state.
back_b8 = np.zeros((len(seq_b8), 2), dtype=int) # best previous state pointers.
delta_b8[0] = np.log(pi_b8) + np.log(E_b8[:, seq_b8[0]]) # initialize log path scores.
print("delta t0:", np.round(delta_b8[0], 3)) # inspect initial log scores.
```
▶ What you'll see: Viterbi stores log joint scores, not normalized probabilities.

```python
for t_b8 in range(1, len(seq_b8)): # fill each later time row.
    for s_b8 in range(2): # compute best path ending at state s.
        candidates_b8 = delta_b8[t_b8 - 1] + np.log(T_b8[:, s_b8]) # previous best plus transition.
        back_b8[t_b8, s_b8] = int(np.argmax(candidates_b8)) # store best predecessor.
        delta_b8[t_b8, s_b8] = candidates_b8[back_b8[t_b8, s_b8]] + np.log(E_b8[s_b8, seq_b8[t_b8]]) # add emission.
print("delta table:\n", np.round(delta_b8, 3)) # inspect all best scores.
print("backpointers:\n", back_b8) # inspect reconstruction pointers.
```

```python
plt.figure(figsize=(4.5, 3)) # create a score heatmap.
```

### Basic 9 — Recover the Viterbi path

**Goal.** Follow backpointers from the best final state, because the best path is not visible from the final state alone. We build it in 2 steps.

```python
seq_b9 = np.array([0, 1, 1]) # observations to decode.
pi_b9 = np.array([0.6, 0.4]) # prior.
T_b9 = np.array([[0.7, 0.3], [0.2, 0.8]]) # transition model.
E_b9 = np.array([[0.9, 0.1], [0.2, 0.8]]) # emission model.
delta_b9 = np.zeros((len(seq_b9), 2)); back_b9 = np.zeros((len(seq_b9), 2), dtype=int) # allocate tables.
delta_b9[0] = np.log(pi_b9) + np.log(E_b9[:, seq_b9[0]]) # initialize scores.
for t_b9 in range(1, len(seq_b9)): # fill Viterbi tables.
    for s_b9 in range(2): # one destination state at a time.
        cand_b9 = delta_b9[t_b9 - 1] + np.log(T_b9[:, s_b9]) # predecessor scores.
        back_b9[t_b9, s_b9] = int(np.argmax(cand_b9)) # best predecessor.
        delta_b9[t_b9, s_b9] = cand_b9[back_b9[t_b9, s_b9]] + np.log(E_b9[s_b9, seq_b9[t_b9]]) # destination score.
print("best final state:", int(np.argmax(delta_b9[-1]))) # inspect where the best path ends.
```
▶ What you'll see: the final best state is fever.

```python
path_b9 = [int(np.argmax(delta_b9[-1]))] # start traceback at the best final state.
for t_b9 in range(len(seq_b9) - 1, 0, -1): # walk backward through time.
    path_b9.append(int(back_b9[t_b9, path_b9[-1]])) # append the predecessor for the current state.
path_b9 = path_b9[::-1] # reverse to chronological order.
print("decoded path:", path_b9) # inspect hidden-state indices.
assert path_b9 == [0, 1, 1] # verify the worked path.
```
▶ What you'll see: `[0, 1, 1]`, meaning healthy then fever then fever.

👀 Takeaway: Viterbi decoding is a global path choice, not independent per-time classification.

### Basic 10 — Smooth an early state

**Goal.** Combine forward and backward messages, because smoothing uses future observations to revise past hidden-state beliefs. We build it in 3 steps.

```python
seq_b10 = np.array([0, 1, 1]) # observations: normal, hot, hot.
pi_b10 = np.array([0.6, 0.4]) # prior.
T_b10 = np.array([[0.7, 0.3], [0.2, 0.8]]) # transition matrix.
E_b10 = np.array([[0.9, 0.1], [0.2, 0.8]]) # emission matrix.
alpha_b10 = np.zeros((len(seq_b10), 2)) # allocate forward messages.
alpha_b10[0] = pi_b10 * E_b10[:, seq_b10[0]] # initialize raw alpha.
for t_b10 in range(1, len(seq_b10)): # fill raw forward messages.
    alpha_b10[t_b10] = (alpha_b10[t_b10 - 1] @ T_b10) * E_b10[:, seq_b10[t_b10]] # raw forward update.
print("alpha t0:", np.round(alpha_b10[0], 6)) # inspect early forward evidence.
```
▶ What you'll see: alpha at time 0 uses only the first observation.

```python
beta_b10 = np.ones((len(seq_b10), 2)) # initialize backward message at the end to ones.
for t_b10 in range(len(seq_b10) - 2, -1, -1): # move backward through time.
    beta_b10[t_b10] = T_b10 @ (E_b10[:, seq_b10[t_b10 + 1]] * beta_b10[t_b10 + 1]) # backward recursion.
smoothed_b10 = alpha_b10[0] * beta_b10[0] # combine past and future evidence at t0.

print("smoothed t0:", np.round(smoothed_b10, 3)) # inspect p(z0 | y0:T).

```


👀 Takeaway: filtering is online; smoothing is retrospective.

### Advanced 1 — Prevent underflow with log-forward

**Goal.** Compute likelihood in log space for a longer sequence, because multiplying many probabilities can become numerically tiny. We build it in 4 steps.

```python
seq_a1 = np.tile(np.array([0, 1, 1, 0, 1]), 8) # create a length-40 observation sequence.
pi_a1 = np.array([0.6, 0.4]) # prior.
T_a1 = np.array([[0.7, 0.3], [0.2, 0.8]]) # transition matrix.
E_a1 = np.array([[0.9, 0.1], [0.2, 0.8]]) # emission matrix.
print("sequence length:", len(seq_a1)) # inspect why underflow can matter.
```
▶ What you'll see: even a toy sequence is long enough for probabilities to shrink sharply.

```python
alpha_raw_a1 = pi_a1 * E_a1[:, seq_a1[0]] # raw forward start.
for y_a1 in seq_a1[1:]: # raw forward recursion.
    alpha_raw_a1 = (alpha_raw_a1 @ T_a1) * E_a1[:, y_a1] # multiply probabilities directly.
raw_lik_a1 = float(alpha_raw_a1.sum()) # raw likelihood.
print("raw likelihood:", raw_lik_a1) # inspect tiny but still finite likelihood.
assert raw_lik_a1 > 0 # verify no underflow occurred in this modest example.
```

```python
log_alpha_a1 = np.log(pi_a1) + np.log(E_a1[:, seq_a1[0]]) # log forward start.
for y_a1 in seq_a1[1:]: # log-space recursion.
    next_log_a1 = np.zeros(2) # allocate next log message.
    for s_a1 in range(2): # destination state.
        vals_a1 = log_alpha_a1 + np.log(T_a1[:, s_a1]) # previous log alpha plus log transition.
        m_a1 = np.max(vals_a1) # max for stable log-sum-exp.
        next_log_a1[s_a1] = np.log(E_a1[s_a1, y_a1]) + m_a1 + np.log(np.sum(np.exp(vals_a1 - m_a1))) # stable log sum.
    log_alpha_a1 = next_log_a1 # advance message.
m_a1 = np.max(log_alpha_a1) # final max for log-sum-exp.
log_lik_a1 = float(m_a1 + np.log(np.sum(np.exp(log_alpha_a1 - m_a1)))) # final log likelihood.
print("log likelihood:", round(log_lik_a1, 3)) # inspect stable log probability.
assert np.allclose(np.exp(log_lik_a1), raw_lik_a1) # verify log and raw agree here.
```

```python

plt.bar(["raw likelihood", "exp(log likelihood)"], [raw_lik_a1, np.exp(log_lik_a1)], color=["gray", "teal"]) # compare methods.
plt.yscale("log") # use log scale so tiny probabilities are visible.
plt.title("Advanced 1: likelihood in log scale") # title the plot.
plt.show() # display the comparison.
```
▶ What you'll see: raw and log-space likelihoods agree, but log space is safer for longer sequences.

👀 Takeaway: log-sum-exp is the stable version of the forward sum-product recursion.

```python
plt.figure(figsize=(4.5, 3)) # create an emission heatmap.
```

### Advanced 5 — Score competing HMMs

**Goal.** Compare two HMMs by sequence likelihood, because model selection asks which parameters make the observed sequence more probable. We build it in 4 steps.

```python
seq_a5 = np.array([0, 1, 1]) # observations to score.
pi_a5 = np.array([0.6, 0.4]) # shared prior.
T_good_a5 = np.array([[0.7, 0.3], [0.2, 0.8]]) # transition model with persistence and recovery.
E_good_a5 = np.array([[0.9, 0.1], [0.2, 0.8]]) # emission model where hot suggests fever.
T_bad_a5 = np.array([[0.5, 0.5], [0.5, 0.5]]) # less structured transitions.
E_bad_a5 = np.array([[0.55, 0.45], [0.45, 0.55]]) # weakly informative emissions.
print("sequence:", seq_a5) # inspect data to score.
```
▶ What you'll see: the same observations will be evaluated under two parameter settings.

```python
alpha_good_a5 = pi_a5 * E_good_a5[:, seq_a5[0]] # initialize good-model forward message.
for y_a5 in seq_a5[1:]: # process remaining observations under good model.
    alpha_good_a5 = (alpha_good_a5 @ T_good_a5) * E_good_a5[:, y_a5] # forward recursion.
lik_good_a5 = float(alpha_good_a5.sum()) # good-model likelihood.
print("good likelihood:", round(lik_good_a5, 6)) # inspect p(data | good model).
```

```python
alpha_bad_a5 = pi_a5 * E_bad_a5[:, seq_a5[0]] # initialize bad-model forward message.
for y_a5 in seq_a5[1:]: # process remaining observations under bad model.
    alpha_bad_a5 = (alpha_bad_a5 @ T_bad_a5) * E_bad_a5[:, y_a5] # forward recursion.
lik_bad_a5 = float(alpha_bad_a5.sum()) # bad-model likelihood.
print("bad likelihood:", round(lik_bad_a5, 6)) # inspect p(data | weak model).
assert lik_good_a5 > lik_bad_a5 # verify the structured HMM explains this sequence better.
```

```python
plt.figure(figsize=(4.5, 3)) # create a model-comparison plot.
plt.bar(["structured HMM", "weak HMM"], [lik_good_a5, lik_bad_a5], color=["seagreen", "gray"]) # compare likelihoods.
plt.title("Advanced 5: likelihood compares HMMs") # title the plot.
plt.ylabel("p(observation sequence)") # label likelihood scale.
plt.xticks(rotation=10) # keep labels readable.
plt.show() # display the comparison.
```
▶ What you'll see: the HMM whose emissions match the observations assigns higher likelihood.

👀 Takeaway: forward likelihood is the HMM scoring rule for comparing parameter settings.
