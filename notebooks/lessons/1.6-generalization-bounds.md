# 1.6 · Generalization Bounds

Generalization bounds turn a training error you can measure into a high-probability ceiling on the true error you actually care about. In this lesson, you will build the finite-class bound from scratch, compute the exact penalties from the All ML lesson text, and see how the ceiling changes with data size, class size, and confidence.

### 1. Training risk versus true risk

A learned model is selected because it looks good on the sample, but the quantity we care about is its future error. The empirical risk $R_S(h)$ is the fraction of mistakes on the training sample; the true risk $R(h)$ is the expected mistake probability on the data distribution. A generalization bound says, with high probability, $R(h)$ is no worse than $R_S(h)$ plus a penalty for uncertainty and model-class complexity.

```python
train_errors_w = np.array([0.10, 0.18, 0.04])  # measured errors for three candidate hypotheses.
true_errors_w = np.array([0.16, 0.20, 0.22])  # hidden future errors for the same candidates.
names_w = ["simple", "medium", "wiggly"]  # readable labels for the hypotheses.
print("empirical risks:", dict(zip(names_w, train_errors_w)))  # inspect what ERM can see.
print("true risks:", dict(zip(names_w, true_errors_w)))  # inspect the target ERM cannot see.
```
▶ What you'll see: the wiggly model has the lowest training error but not the lowest true error.

```python
erm_idx_w = int(np.argmin(train_errors_w))  # ERM selects the hypothesis with smallest training risk.
best_true_idx_w = int(np.argmin(true_errors_w))  # oracle selection by true risk, unavailable in practice.
print("ERM picks:", names_w[erm_idx_w])  # training-data winner.
print("oracle would pick:", names_w[best_true_idx_w])  # future-error winner.
assert names_w[erm_idx_w] == "wiggly" and names_w[best_true_idx_w] == "simple"  # lesson setup.
```
▶ What you'll see: optimizing training error alone can pick the wrong hypothesis.

```python
plt.figure(figsize=(4.8, 3))  # create a compact comparison plot.
x_w = np.arange(len(names_w))  # bar locations.
plt.bar(x_w - 0.18, train_errors_w, width=0.36, label="training error")  # plot empirical risks.
plt.bar(x_w + 0.18, true_errors_w, width=0.36, label="true error")  # plot future risks.
plt.xticks(x_w, names_w)  # label hypotheses.
plt.ylabel("error")  # show all errors on the same scale.
plt.title("1: training error can be optimistic")  # title the lesson figure.
plt.legend()  # show which bar is which.
plt.show()  # display the chart.
```
▶ What you'll see: the lowest training bar is not necessarily the lowest future bar.

*Why it's done this way: the bound will repair ERM's optimism by adding a penalty that covers how much $R_S(h)$ can differ from $R(h)$ after the model was chosen from a class.*

### 2. Hoeffding: one fixed hypothesis concentrates

For one fixed hypothesis $h$, the training errors are Bernoulli trials: each example is either wrong or right. Hoeffding's inequality says the empirical mean concentrates around its expectation: $P(R(h)-R_S(h)>\epsilon)\le e^{-2m\epsilon^2}$. Solving $e^{-2m\epsilon^2}=\delta$ gives the one-hypothesis gap $\epsilon=\sqrt{\frac{\log(1/\delta)}{2m}}$.

```python
true_risk_w = 0.20  # suppose this fixed hypothesis makes mistakes with probability 0.20.
m_w = 100  # sample size.
delta_w = 0.05  # failure probability, so confidence is 95%.
one_gap_w = np.sqrt(np.log(1 / delta_w) / (2 * m_w))  # Hoeffding gap for one fixed h.
print("one-hypothesis gap:", round(float(one_gap_w), 4))  # inspect the concentration width.
assert round(float(one_gap_w), 4) == 0.1224  # sqrt(log(20)/200).
```
▶ What you'll see: for one fixed model at 100 samples, Hoeffding gives a gap of about 0.1224.

```python
rng_w = np.random.default_rng(1)  # local generator for reproducible experiments.
trials_w = 5000  # number of repeated training samples to simulate.
emp_w = rng_w.binomial(m_w, true_risk_w, size=trials_w) / m_w  # empirical risks from repeated samples.
miss_rate_w = float(np.mean(true_risk_w - emp_w > one_gap_w))  # observed frequency of bound failures.
print("simulated failure rate:", round(miss_rate_w, 4), "target ≤", delta_w)  # compare to δ.
assert miss_rate_w <= delta_w  # the empirical failure rate should be below the allowed probability.
```
▶ What you'll see: the simulated failure rate is below 0.05, as Hoeffding promised.

```python
plt.figure(figsize=(4.8, 3))  # create a histogram figure.
plt.hist(emp_w, bins=25, color="steelblue", alpha=0.75)  # show empirical risks over repeated samples.
plt.axvline(true_risk_w, color="black", linestyle="--", label="true risk")  # mark the expectation.
plt.axvline(true_risk_w - one_gap_w, color="red", linestyle=":", label="lower edge")  # mark failure edge.
plt.title("2: Hoeffding concentration for one h")  # title the plot.
plt.xlabel("training error")  # label x-axis.
plt.ylabel("count")  # label y-axis.
plt.legend()  # show markers.
plt.show()  # display the histogram.
```
▶ What you'll see: most empirical risks stay near the true risk; only a small left tail is overly optimistic.

*Why it's done this way: Hoeffding is the single-model ingredient; it does not yet protect a data-dependent ERM choice among many hypotheses.*

### 3. Union bound: make the guarantee simultaneous

ERM chooses after seeing the data, so a bound for one pre-chosen hypothesis is not enough. The union bound says the probability that **any** of $|H|$ hypotheses fails is at most the sum of their failure probabilities. Spending $\delta/|H|$ on each hypothesis yields the simultaneous finite-class penalty

$$\sqrt{\frac{\log|H|+\log(1/\delta)}{2m}}.$$

```python
H_w = 100  # finite hypothesis class size from the All ML lesson.
delta_w = 0.05  # 95% confidence.
m_w = 100  # sample size from the worked example.
num_w = np.log(H_w) + np.log(1 / delta_w)  # numerator from the finite-class bound.
pen_w = np.sqrt(num_w / (2 * m_w))  # complexity penalty.
print("numerator:", round(float(num_w), 3))  # ln100 + ln20 = 7.601.
print("penalty:", round(float(pen_w), 4))  # sqrt(7.601/200) = 0.1949.
assert round(float(num_w), 3) == 7.601 and round(float(pen_w), 4) == 0.1949  # cited numbers.
```
▶ What you'll see: the All ML numerator 7.601 and penalty 0.1949 are reproduced exactly by code.

```python
one_gap_w = np.sqrt(np.log(1 / delta_w) / (2 * m_w))  # penalty if there were only one fixed h.
extra_w = pen_w - one_gap_w  # extra price for testing a class of 100 hypotheses.
print("one-hypothesis gap:", round(float(one_gap_w), 4))  # 0.1224.
print("uniform extra price:", round(float(extra_w), 4))  # cost of simultaneous coverage.
```
▶ What you'll see: uniform coverage is wider than a one-model guarantee because it must hold for every $h\in H$.

```python
Hs_w = np.array([1, 10, 100, 1000, 10000])  # hypothesis-class sizes.
penalties_w = np.sqrt((np.log(Hs_w) + np.log(1 / delta_w)) / (2 * m_w))  # finite-class penalties.
plt.figure(figsize=(4.8, 3))  # create the complexity plot.
plt.plot(Hs_w, penalties_w, marker="o", color="purple")  # plot penalty by class size.
plt.xscale("log")  # class size grows multiplicatively.
plt.xlabel("|H| (log scale)")  # label class-size axis.
plt.ylabel("penalty")  # label penalty axis.
plt.title("3: union bound cost grows with log |H|")  # title the visualization.
plt.show()  # display the line chart.
```
▶ What you'll see: adding hypotheses costs only logarithmically, but it still widens the ceiling.

*Why it's done this way: the union bound buys the key design requirement — a guarantee that is valid after ERM chooses any hypothesis in the class.*

### 4. The $1/\sqrt{m}$ data scaling

The penalty shrinks as $1/\sqrt{m}$ because the sample mean gets more stable with more independent examples. Holding $|H|$ and $\delta$ fixed, multiplying $m$ by 10 divides the penalty by about $\sqrt{10}\approx3.16$; halving a gap requires roughly four times as much data.

```python
m_values_w = np.array([100, 1000, 10000])  # sample sizes from the All ML lesson.
pen_m_w = np.sqrt((np.log(100) + np.log(20)) / (2 * m_values_w))  # penalties with fixed |H| and δ.
print("penalties:", np.round(pen_m_w, 4))  # [0.1949, 0.0616, 0.0195].
assert np.allclose(np.round(pen_m_w, 4), [0.1949, 0.0616, 0.0195])  # cited shrinkage numbers.
```
▶ What you'll see: tenfold more data tightens the gap by about 3.16× each step.

```python
pen_100_w = float(np.sqrt((np.log(100) + np.log(20)) / (2 * 100)))  # baseline penalty.
pen_400_w = float(np.sqrt((np.log(100) + np.log(20)) / (2 * 400)))  # four-times-data penalty.
print("m=100:", round(pen_100_w, 4), "m=400:", round(pen_400_w, 4))  # 0.1949 and 0.0975.
assert round(pen_400_w, 4) == 0.0975  # cited half-gap number.
```
▶ What you'll see: quadrupling the sample size halves the penalty.

```python
m_grid_w = np.arange(50, 2001, 50)  # a smooth range of sample sizes.
curve_w = np.sqrt((np.log(100) + np.log(20)) / (2 * m_grid_w))  # finite-class penalty curve.
plt.figure(figsize=(4.8, 3))  # create the data-scaling plot.
plt.plot(m_grid_w, curve_w, color="seagreen")  # draw penalty versus sample size.
plt.scatter(m_values_w, pen_m_w, color="black", zorder=3)  # mark the cited examples.
plt.xlabel("sample size m")  # label x-axis.
plt.ylabel("penalty")  # label y-axis.
plt.title("4: penalty shrinks like 1/sqrt(m)")  # title the figure.
plt.show()  # display the curve.
```
▶ What you'll see: the curve falls quickly at first and then slowly — more data always helps, but with diminishing returns.

*Why it's done this way: the square root comes from concentration of averages, so accuracy is data-expensive; to make $\epsilon$ twice as small, you need about four times the samples.*

### 5. Confidence, vacuity, and reading the bound

The full ceiling is $R(h)\le R_S(h)+\sqrt{\frac{\log|H|+\log(1/\delta)}{2m}}$ with probability at least $1-\delta$. Because $\delta$ sits inside a logarithm, higher confidence is comparatively cheap. But if the penalty is too large, the ceiling can exceed 1 and become vacuous: technically true, but no more informative than saying an error rate is at most 100%.

```python
deltas_w = np.array([0.10, 0.05, 0.01])  # confidence levels from the All ML lesson.
m_w = 500  # fixed sample size.
H_w = 100  # fixed class size.
pen_delta_w = np.sqrt((np.log(H_w) + np.log(1 / deltas_w)) / (2 * m_w))  # penalties by δ.
print("delta penalties:", np.round(pen_delta_w, 4))  # [0.0831, 0.0872, 0.0960].
assert np.allclose(np.round(pen_delta_w, 4), [0.0831, 0.0872, 0.0960])  # cited confidence numbers.
```
▶ What you'll see: moving from 90% to 99% confidence widens the penalty by only a little over 0.01.

```python
emp_risk_w = 0.12  # measured training error for a selected hypothesis.
bounds_w = emp_risk_w + pen_delta_w  # high-probability ceilings at each confidence level.
print("risk ceilings:", np.round(bounds_w, 4))  # empirical risk plus penalty.
assert np.all(bounds_w >= emp_risk_w)  # the bound is always at least the training error.
```
▶ What you'll see: the reported guarantee is an upper bound, not a prediction of the exact true risk.

```python
small_m_w = np.array([5, 10, 20, 50, 100])  # sample sizes that may be too small.
vacuous_w = emp_risk_w + np.sqrt((np.log(10000) + np.log(20)) / (2 * small_m_w))  # huge class ceiling.
plt.figure(figsize=(4.8, 3))  # create the vacuity plot.
plt.plot(small_m_w, vacuous_w, marker="o", color="crimson")  # plot bound values.
plt.axhline(1.0, color="black", linestyle="--", label="error rate max = 1")  # mark vacuous threshold.
plt.xlabel("sample size m")  # label x-axis.
plt.ylabel("empirical risk + penalty")  # label y-axis.
plt.title("5: small data or huge |H| can be vacuous")  # title the chart.
plt.legend()  # show the threshold label.
plt.show()  # display the plot.
```
▶ What you'll see: some ceilings exceed 1, so the guarantee is true but practically useless.

*Why it's done this way: the bound is a conservative safety ceiling; read looseness as limited certificate strength, not as proof that the model's actual error is that high.*

## Setup

```python
# !pip install numpy matplotlib # install the only packages used in this lesson when running outside Colab.
import numpy as np # load NumPy for arrays, logarithms, square roots, simulations, and numerical checks.
import matplotlib.pyplot as plt # load Matplotlib so every concept can be inspected visually.
np.random.seed(0) # make all random examples reproducible across Colab runs.

def finite_penalty(H, delta, m): # compute sqrt((log|H| + log(1/delta)) / (2m)) safely.
    H = np.maximum(np.asarray(H, dtype=float), 1.0) # guard class sizes so log is defined.
    delta = np.clip(np.asarray(delta, dtype=float), 1e-12, 1.0) # guard confidence inputs.
    m = np.maximum(np.asarray(m, dtype=float), 1.0) # guard sample sizes against division by zero.
    return np.sqrt((np.log(H) + np.log(1 / delta)) / (2 * m)) # return the finite-H penalty.

def risk_bound(empirical_risk, H, delta, m): # compute empirical risk plus the finite-class penalty.
    return empirical_risk + finite_penalty(H, delta, m) # return the high-probability ceiling.

def show_curve(x, y, title, xlabel, ylabel): # small helper for line plots used throughout.
    plt.figure(figsize=(4.8, 3)) # create one compact figure.
    plt.plot(x, y, marker="o", color="teal") # draw the requested curve.
    plt.title(title) # label the figure with the exercise name.
    plt.xlabel(xlabel) # label the horizontal axis.
    plt.ylabel(ylabel) # label the vertical axis.
    plt.show() # display the plot.
```
