# 18.10 — Data Valuation (Shapley for Data)

Data valuation asks which training rows actually help a model, not just which rows happen to be present. In this lesson, we use tiny NumPy-only classifiers to build Data Shapley from the ground up: exact fair credit, negative value for harmful rows, Monte-Carlo approximation, and a KNN-Shapley shortcut for nearest-neighbor models.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build data valuation one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including the Shapley weights and the KNN recurrence, is exposed. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, distances, random permutations, and numerical checks.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
from itertools import combinations, permutations  # exact coalitions and exact row orders.
np.random.seed(0)  # reproducibility for sampled orders.
def fact_w(n_w):
    return int(np.prod(np.arange(1, n_w + 1))) if n_w > 1 else 1
```
▶ What you'll see: the only tools are NumPy, Matplotlib, and standard-library iterators.

### 1. Utility: value rows through validation performance

A Shapley value does not ask whether a row is pretty or rare in isolation. It asks how much utility changes when the row is added to many possible training subsets. We make utility concrete with one-nearest-neighbor validation accuracy on two validation points.

```python
X_train_w = np.array([[-1.0], [-0.8], [1.0]])
y_train_w = np.array([0, 0, 1])
X_val_w = np.array([[-1.1], [1.1]])
y_val_w = np.array([0, 1])
print("training rows:", list(zip(X_train_w.ravel(), y_train_w)))
print("validation rows:", list(zip(X_val_w.ravel(), y_val_w)))
```
▶ What you'll see: two negative-side training rows and one positive-side row are judged on one validation point from each side.

```python
def utility_w(subset_w):
    if len(subset_w) == 0:
        return 0.0
    idx_w = np.array(list(subset_w), dtype=int)
    distances_w = np.abs(X_val_w - X_train_w[idx_w].T)
    nearest_w = idx_w[np.argmin(distances_w, axis=1)]
    pred_w = y_train_w[nearest_w]
    return float(np.mean(pred_w == y_val_w))

for subset_w in [(), (0,), (1,), (2,), (0, 2), (1, 2), (0, 1, 2)]:
    print(subset_w, "U=", utility_w(subset_w))
```
▶ What you'll see: any single row gets one validation point right, while a negative row plus row 2 gets both right.

```python
subset_labels_w, subset_values_w = [], []
for r_w in range(4):
    for S_w in combinations(range(3), r_w):
        subset_labels_w.append(str(S_w))
        subset_values_w.append(utility_w(S_w))
plt.figure(figsize=(6, 3))
plt.bar(subset_labels_w, subset_values_w, color="teal")
plt.xticks(rotation=45)
plt.ylabel("U(S)")
plt.title("1: utility of every subset")
plt.show()
```
▶ What you'll see: utility is a step function over subsets; valuation explains the jumps.

*Why it's done this way:* Data value is only meaningful after choosing a utility. Validation accuracy makes the definition operational: a row is valuable if adding it improves held-out predictions, not because it looks important by itself.

### 2. Exact Shapley: fair average marginal contribution

For row $i$, exact Data Shapley averages $U(S\cup\{i\})-U(S)$ over all subsets $S$ that exclude $i$:

$$\phi_i=\sum_{S\subseteq N\setminus\{i\}}\frac{|S|!(n-|S|-1)!}{n!}\big(U(S\cup\{i\})-U(S)\big).$$

The factorial weight is the probability that exactly $S$ appears before row $i$ in a uniformly random ordering.

```python
def exact_shapley_w(n_w, utility_fn_w):
    phi_w = np.zeros(n_w)
    for i_w in range(n_w):
        others_w = [j_w for j_w in range(n_w) if j_w != i_w]
        for r_w in range(n_w):
            for S_w in combinations(others_w, r_w):
                weight_w = fact_w(r_w) * fact_w(n_w - r_w - 1) / fact_w(n_w)
                with_i_w = tuple(sorted(S_w + (i_w,)))
                phi_w[i_w] += weight_w * (utility_fn_w(with_i_w) - utility_fn_w(S_w))
    return phi_w

phi_w = exact_shapley_w(3, utility_w)
print("exact Shapley:", np.round(phi_w, 3))
print("sum phi:", round(float(phi_w.sum()), 3), "full utility gain:", utility_w((0, 1, 2)) - utility_w(()))
assert np.allclose(np.round(phi_w, 3), [0.25, 0.25, 0.5])
```
▶ What you'll see: row 2 receives 0.5, rows 0 and 1 receive 0.25 each, and total credit equals full utility gain.

```python
plt.figure(figsize=(4.5, 3))
plt.bar(["row0", "row1", "row2"], phi_w, color=["gray", "gray", "seagreen"])
plt.ylabel("Shapley value")
plt.title("2: exact fair row values")
plt.show()
```
▶ What you'll see: row 2 has the tallest value bar because it supplies the positive-side evidence.

*Why it's done this way:* Shapley is the unique credit rule satisfying efficiency, symmetry, dummy, and additivity. Efficiency forces the values to sum to $U(N)-U(\varnothing)$; symmetry splits credit among interchangeable rows; dummy gives zero to rows that never change utility; additivity keeps valuation consistent across combined utilities.

### 3. Negative value: harmful rows subtract utility

A mislabeled row can be useful alone but harmful in context. We place a negative-labeled row near the positive validation point, so it steals a nearest-neighbor decision when added to an otherwise good subset.

```python
X_bad_w = np.array([[-1.0], [0.95], [1.2]])
y_bad_w = np.array([0, 0, 1])
X_val_bad_w = np.array([[-1.1], [1.0]])
y_val_bad_w = np.array([0, 1])
print("bad training rows:", list(zip(X_bad_w.ravel(), y_bad_w)))
```
▶ What you'll see: row 1 sits near the positive validation point but has the wrong label.

```python
def utility_bad_w(subset_w):
    if len(subset_w) == 0:
        return 0.5  # baseline accuracy before adding any row.
    idx_w = np.array(list(subset_w), dtype=int)
    distances_w = np.abs(X_val_bad_w - X_bad_w[idx_w].T)
    nearest_w = idx_w[np.argmin(distances_w, axis=1)]
    return float(np.mean(y_bad_w[nearest_w] == y_val_bad_w))

before_w = utility_bad_w((0, 2))
after_w = utility_bad_w((0, 1, 2))
print("U({0,2}) before bad row:", before_w)
print("U({0,1,2}) after bad row:", after_w)
print("marginal of bad row:", after_w - before_w)
assert before_w == 1.0 and after_w == 0.5
```
▶ What you'll see: adding row 1 drops utility from 1.0 to 0.5 in this context.

```python
phi_bad_w = exact_shapley_w(3, utility_bad_w)
print("Shapley with bad row:", np.round(phi_bad_w, 3))
assert phi_bad_w[1] < 0
plt.figure(figsize=(4.5, 3))
plt.bar(["good neg", "bad label", "good pos"], phi_bad_w, color=np.where(phi_bad_w >= 0, "seagreen", "crimson"))
plt.axhline(0, color="black", linewidth=0.8)
plt.ylabel("Shapley value")
plt.title("3: negative value flags harm")
plt.show()
```
▶ What you'll see: the mislabeled row's bar is below zero.

*Why it's done this way:* Negative value means the row lowers the chosen utility on average across coalitions. That average is important: a single leave-one-out check can miss contexts where the row changes a decision boundary in the wrong direction.

### 4. Monte-Carlo Shapley: sample row orders

Exact Shapley is exponential because it enumerates subsets. The equivalent permutation view samples random row orders, walks through each order, and credits each row with the utility jump when it arrives.

```python
def mc_shapley_w(n_w, utility_fn_w, m_w=300, seed_w=1):
    rng_w = np.random.default_rng(seed_w)
    contrib_w = np.zeros((m_w, n_w))
    for t_w in range(m_w):
        order_w = rng_w.permutation(n_w)
        S_w = tuple()
        prev_w = utility_fn_w(S_w)
        for i_w in order_w:
            S_new_w = tuple(sorted(S_w + (int(i_w),)))
            now_w = utility_fn_w(S_new_w)
            contrib_w[t_w, i_w] = now_w - prev_w
            S_w, prev_w = S_new_w, now_w
    return contrib_w.mean(axis=0), contrib_w

mc_phi_w, contribs_w = mc_shapley_w(3, utility_w)
print("MC estimate:", np.round(mc_phi_w, 3))
print("exact:", np.round(phi_w, 3))
assert np.max(np.abs(mc_phi_w - phi_w)) < 0.08
```
▶ What you'll see: the sampled estimate is close to the exact Shapley values.

```python
running_w = np.cumsum(contribs_w[:, 2]) / np.arange(1, len(contribs_w) + 1)
plt.figure(figsize=(5, 3))
plt.plot(running_w, color="purple")
plt.axhline(phi_w[2], color="black", linestyle="--", label="exact row2")
plt.xlabel("permutations averaged")
plt.ylabel("running estimate")
plt.title("4: MC convergence for row 2")
plt.legend()
plt.show()
```
▶ What you'll see: the running average wiggles early, then settles near the exact value.

*Why it's done this way:* In a random permutation, the set before row $i$ has exactly the Shapley weighting. Sampling permutations is therefore unbiased; more samples reduce variance without requiring all subsets.

### 5. KNN-Shapley: use nearest-neighbor structure

For 1-NN utility, every validation query has a sorted list of training rows from nearest to farthest. KNN-Shapley uses that order to assign credit directly, avoiding retraining on every subset.

```python
X_knn_w = np.array([[-1.2], [-0.9], [0.2], [0.9], [1.1]])
y_knn_w = np.array([0, 0, 1, 0, 1])
xq_knn_w = 1.05
yq_knn_w = 1
order_knn_w = np.argsort(np.abs(X_knn_w.ravel() - xq_knn_w))
print("nearest-to-farthest rows:", order_knn_w)
print("labels in that order:", y_knn_w[order_knn_w])
```
▶ What you'll see: the closest row is correct, while the second closest is a wrong-label neighbor.

```python
def one_query_knn_shapley_w(X_w, y_w, xq_w, yq_w):
    n_w = len(y_w)
    order_w = np.argsort(np.abs(X_w.ravel() - float(xq_w)))
    correct_w = (y_w[order_w] == int(yq_w)).astype(float)
    sorted_values_w = np.zeros(n_w)
    sorted_values_w[-1] = correct_w[-1] / n_w
    for j_w in range(n_w - 2, -1, -1):
        sorted_values_w[j_w] = sorted_values_w[j_w + 1] + (correct_w[j_w] - correct_w[j_w + 1]) / (j_w + 1)
    values_w = np.zeros(n_w)
    values_w[order_w] = sorted_values_w
    return values_w, order_w, correct_w

knn_phi_w, _, correct_w = one_query_knn_shapley_w(X_knn_w, y_knn_w, xq_knn_w, yq_knn_w)
print("sorted correctness:", correct_w)
print("query-level KNN-Shapley:", np.round(knn_phi_w, 3))
assert round(float(knn_phi_w[4]), 3) == 0.833
```
▶ What you'll see: the closest correct row receives high positive value, and the close wrong row receives negative value.

```python
plt.figure(figsize=(5, 3))
plt.bar([f"row{i}" for i in range(len(y_knn_w))], knn_phi_w, color=np.where(knn_phi_w >= 0, "seagreen", "crimson"))
plt.axhline(0, color="black", linewidth=0.8)
plt.ylabel("query-level value")
plt.title("5: KNN-Shapley values by row")
plt.show()
```
▶ What you'll see: nearest rows dominate the valuation because they control the 1-NN prediction.

*Why it's done this way:* The recurrence distributes correctness changes backward through the distance ranking. A row gains value when being closer than later rows improves expected correctness and loses value when it replaces a correct later row with an incorrect label.

### ✍️ Toy 1 · Utility is validation accuracy after nearest-neighbor prediction

A data value needs a utility target. Here a two-row training subset predicts two validation points by nearest neighbor.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)
t1_X_train = np.array([[-2.0], [0.0], [2.0]])
t1_y_train = np.array([0, 1, 1])
t1_X_val = np.array([[-1.8], [1.5]])
t1_y_val = np.array([0, 1])
t1_subset = np.array([0, 2])
t1_distances = np.abs(t1_X_val - t1_X_train[t1_subset].T)  # -> [[0.2 3.8] [3.5 0.5]]
t1_nearest_pos = np.argmin(t1_distances, axis=1)  # -> [0 1]
t1_nearest_rows = t1_subset[t1_nearest_pos]  # -> [0 2]
t1_pred = t1_y_train[t1_nearest_rows]  # -> [0 1]
t1_correct = t1_pred == t1_y_val  # -> [ True  True]
t1_utility = float(t1_correct.mean())  # -> 1.0
print("training x:", t1_X_train.ravel().tolist())  # -> [-2.0, 0.0, 2.0]
print("subset rows:", t1_subset.tolist())  # -> [0, 2]

print("nearest rows:", t1_nearest_rows.tolist())  # -> [0, 2]
print("predictions:", t1_pred.tolist())  # -> [0, 1]
print("correct mask:", t1_correct.astype(int).tolist())  # -> [1, 1]
```

### ✍️ Toy 2 · Exact Shapley averages weighted marginal gains

Exact Shapley enumerates every subset not containing a row, weights the marginal gain, and sums those terms.

```python
import numpy as np

t2_rng = np.random.default_rng(0)
t2_values = np.array([0.0, 0.2, 0.0, 0.4, 0.5, 0.7, 0.5, 0.9])
t2_weight_by_size = np.array([1 / 3, 1 / 6, 1 / 3])  # -> [0.33333333 0.16666667 0.33333333]
t2_phi = np.zeros(3)
t2_terms = np.zeros((3, 4))
for t2_i in range(3):
    t2_k = 0
    for t2_mask in range(8):
        if (t2_mask >> t2_i) & 1:
            continue
        t2_size = bin(t2_mask).count("1")
        t2_with_i = t2_mask | (1 << t2_i)
        t2_marginal = t2_values[t2_with_i] - t2_values[t2_mask]
        t2_weighted = t2_weight_by_size[t2_size] * t2_marginal
        t2_terms[t2_i, t2_k] = t2_weighted
        t2_phi[t2_i] += t2_weighted
        t2_k += 1
t2_total_gain = t2_values[-1] - t2_values[0]  # -> 0.9
print("utility table by mask:", t2_values.tolist())  # -> [0.0, 0.2, 0.0, 0.4, 0.5, 0.7, 0.5, 0.9]
print("weights by subset size:", np.round(t2_weight_by_size, 3).tolist())  # -> [0.333, 0.167, 0.333]
print("weighted terms:", np.round(t2_terms, 3).tolist())  # -> [[0.067, 0.067, 0.033, 0.133], [0.0, 0.033, 0.0, 0.067], [0.167, 0.083, 0.083, 0.167]]
print("Shapley values:", np.round(t2_phi, 3).tolist())  # -> [0.3, 0.1, 0.5]
print("total gain:", round(float(t2_total_gain), 3))  # -> 0.9
assert np.allclose(t2_phi, [0.3, 0.1, 0.5])
assert round(float(t2_phi.sum()), 3) == round(float(t2_total_gain), 3)

plt.figure(figsize=(4.8, 2.8))
plt.bar(["row0", "row1", "row2"], t2_phi, color=["steelblue", "gray", "seagreen"])
plt.ylabel("Shapley value")
plt.title("Toy 2 · exact fair credit")
plt.show()
```
▶ What you'll see: row `2` gets the largest fair credit, and all credits sum to the full utility gain `0.9`.

### ✍️ Toy 4 · Monte-Carlo Shapley samples row orders

The permutation view walks through random row orders and averages each row's utility jump when it arrives.

```python
import numpy as np

t4_rng = np.random.default_rng(0)
t4_values = np.array([0.0, 0.2, 0.0, 0.4, 0.5, 0.7, 0.5, 0.9])
t4_exact = np.array([0.3, 0.1, 0.5])
t4_m = 24
t4_orders = np.zeros((t4_m, 3), dtype=int)
t4_contrib = np.zeros((t4_m, 3))
for t4_j in range(t4_m):
    t4_order = t4_rng.permutation(3)
    t4_orders[t4_j] = t4_order
    t4_mask = 0
    t4_prev = t4_values[t4_mask]
    for t4_i in t4_order:
        t4_new_mask = t4_mask | (1 << int(t4_i))
        t4_now = t4_values[t4_new_mask]
        t4_contrib[t4_j, t4_i] = t4_now - t4_prev
        t4_mask = t4_new_mask
        t4_prev = t4_now
t4_estimate = t4_contrib.mean(axis=0)  # -> [0.3 0.1 0.5]
t4_running_row2 = np.cumsum(t4_contrib[:, 2]) / np.arange(1, t4_m + 1)
print("first five orders:", t4_orders[:5].tolist())  # -> [[2, 0, 1], [2, 1, 0], [2, 0, 1], [1, 2, 0], [0, 2, 1]]
print("MC estimate:", np.round(t4_estimate, 3).tolist())  # -> [0.3, 0.1, 0.5]
print("exact values:", t4_exact.tolist())  # -> [0.3, 0.1, 0.5]
print("final running row2:", round(float(t4_running_row2[-1]), 3))  # -> 0.5
assert np.allclose(np.round(t4_estimate, 3), t4_exact)

plt.figure(figsize=(5.0, 2.8))
plt.plot(np.arange(1, t4_m + 1), t4_running_row2, color="purple")
plt.axhline(t4_exact[2], color="black", linestyle="--", label="exact row2")
plt.xlabel("sampled permutations")
plt.ylabel("running row2 value")
plt.title("Toy 4 · MC estimate settles")
plt.legend()
plt.show()
```
▶ What you'll see: the running estimate for row `2` settles at the exact value `0.5` for this seeded sample.

### ✍️ Toy 5 · KNN-Shapley uses distance order and a backward recurrence

For one validation query, KNN-Shapley sorts rows by distance and sends correctness changes backward through that order.

```python
import numpy as np

t5_rng = np.random.default_rng(0)
t5_X = np.array([[-1.0], [0.5], [0.8], [1.4]])
t5_y = np.array([0, 1, 0, 1])
t5_query = 1.0
t5_label = 1
t5_distances = np.abs(t5_X.ravel() - t5_query)  # -> [2.  0.5 0.2 0.4]
t5_order = np.argsort(t5_distances)  # -> [2 3 1 0]
t5_correct = (t5_y[t5_order] == t5_label).astype(float)  # -> [0. 1. 1. 0.]
t5_sorted_values = np.zeros(len(t5_y))
t5_sorted_values[-1] = t5_correct[-1] / len(t5_y)
for t5_j in range(len(t5_y) - 2, -1, -1):
    t5_sorted_values[t5_j] = t5_sorted_values[t5_j + 1] + (t5_correct[t5_j] - t5_correct[t5_j + 1]) / (t5_j + 1)
t5_values = np.zeros(len(t5_y))
t5_values[t5_order] = t5_sorted_values
print("distances:", np.round(t5_distances, 2).tolist())  # -> [2.0, 0.5, 0.2, 0.4]
print("nearest-to-farthest order:", t5_order.tolist())  # -> [2, 3, 1, 0]
print("correctness in order:", t5_correct.astype(int).tolist())  # -> [0, 1, 1, 0]
print("sorted recurrence values:", np.round(t5_sorted_values, 3).tolist())  # -> [-0.667, 0.333, 0.333, 0.0]
print("row-level KNN-Shapley:", np.round(t5_values, 3).tolist())  # -> [0.0, 0.333, -0.667, 0.333]
assert round(float(t5_values[2]), 3) == -0.667

plt.figure(figsize=(4.8, 2.8))
plt.bar(["row0", "row1", "row2", "row3"], t5_values, color=np.where(t5_values >= 0, "seagreen", "crimson"))
plt.axhline(0, color="black", linewidth=0.8)
plt.ylabel("query value")
plt.title("Toy 5 · closest wrong row loses value")
plt.show()
```
▶ What you'll see: row `2` is closest but wrong, so its KNN-Shapley value is negative.

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, distances, exact sums, and reproducible simulation.
import matplotlib.pyplot as plt # load Matplotlib for value bars, scatter plots, and convergence curves.
from itertools import combinations, permutations # load standard-library iterators for exact coalitions and row orders.
np.random.seed(0) # make all random examples reproducible.
def fact(n): # define factorial without extra imports so Shapley weights stay transparent.
    return int(np.prod(np.arange(1, n + 1))) if n > 1 else 1 # multiply 1 through n, with 0! and 1! equal to 1.
```
▶ What you'll see: only NumPy, Matplotlib, and `itertools` are used.

### Basic 2 — Define one-nearest-neighbor utility

**Goal.** Score a subset by validation accuracy, because Shapley values average utility changes. We build it in 2 steps.

```python
X_b2 = np.array([[-1.0], [-0.8], [1.0]]) # Recreate candidate rows.
y_b2 = np.array([0, 0, 1]) # Recreate labels.
Xv_b2 = np.array([[-1.1], [1.1]]) # Recreate validation features.
```

```python
def utility_b2(S_b2): # Define subset utility.
    if len(S_b2) == 0: return 0.0 # Empty training set has zero utility.
    idx_b2 = np.array(list(S_b2), dtype=int) # Convert subset to indices.
    d_b2 = np.abs(Xv_b2 - X_b2[idx_b2].T) # Compute validation-to-training distances.
    pred_b2 = y_b2[idx_b2[np.argmin(d_b2, axis=1)]] # Predict from nearest selected row.
    return float(np.mean(pred_b2 == yv_b2)) # Return validation accuracy.
```


👀 Takeaway: singleton utility is useful to inspect, but Shapley also cares about interaction contexts.

### Basic 5 — Compute Shapley weights

**Goal.** Calculate the factorial weights, because they convert coalitions into random-order probabilities. We build it in 2 steps.

```python
n_b5 = 3 # Use three rows.
weights_b5 = [] # Store weights by size.

print("weights by |S|:", weights_b5) # Inspect weights.
```
▶ What you'll see: end coalitions have weight 1/3; middle coalitions have weight 1/6 each.


👀 Takeaway: Shapley weights come from random permutations, not from hand-tuned importance.

### Basic 6 — Value one row exactly

**Goal.** Sum row 2's weighted marginals, because that is the exact formula in action. We build it in 2 steps.

```python
X_b6 = np.array([[-1.0], [-0.8], [1.0]]) # Define rows.
y_b6 = np.array([0, 0, 1]) # Define labels.
Xv_b6 = np.array([[-1.1], [1.1]]) # Define validation rows.
yv_b6 = np.array([0, 1]) # Define validation labels.
def utility_b6(S_b6): # Define utility.
    if len(S_b6) == 0: return 0.0 # Empty utility.
    idx_b6 = np.array(list(S_b6), dtype=int) # Subset indices.
    d_b6 = np.abs(Xv_b6 - X_b6[idx_b6].T) # Distances.
    return float(np.mean(y_b6[idx_b6[np.argmin(d_b6, axis=1)]] == yv_b6)) # Accuracy.
print("ready for exact row-2 terms") # Confirm setup.
```
▶ What you'll see: the utility is ready for row-specific terms.

```python
terms_b6 = [] # Store weighted terms.
for S_b6 in [(), (0,), (1,), (0, 1)]: # Loop over row-2 contexts.
    r_b6 = len(S_b6) # Get coalition size.
    w_b6 = fact(r_b6) * fact(3 - r_b6 - 1) / fact(3) # Compute Shapley weight.
    marginal_b6 = utility_b6(tuple(sorted(S_b6 + (2,)))) - utility_b6(S_b6) # Compute marginal.
    terms_b6.append(w_b6 * marginal_b6) # Store weighted marginal.
    print("S=", S_b6, "w=", round(w_b6, 3), "marginal=", marginal_b6) # Inspect each term.
phi2_b6 = float(np.sum(terms_b6)) # Sum terms.
print("φ₂:", round(phi2_b6, 3)) # Inspect row-2 value.
assert round(phi2_b6, 3) == 0.5 # Verify canonical value.
```
▶ What you'll see: row 2's weighted terms sum to 0.5.

```python
context_labels_b6 = ["∅", "{0}", "{1}", "{0,1}"] # Label row-2 contexts.
plt.figure(figsize=(4, 3)) # Create a compact contribution chart.
plt.bar(context_labels_b6, terms_b6, color="purple") # Plot row 2's weighted Shapley terms.
plt.axhline(phi2_b6, color="teal", linestyle="--", label="φ₂ total") # Mark the summed value.
plt.ylabel("weighted marginal") # Label contribution axis.
plt.title("Basic 6: row 2 value terms") # Title the plot.
plt.legend() # Explain the dashed line.
plt.show()
```
▶ What you'll see: the positive terms combine to the dashed total value of 0.5.

👀 Takeaway: exact Shapley is a weighted average of context-specific gains.

### Basic 7 — Compute all exact row values

### Easy 1 — Wrap exact Data Shapley

**Goal.** Implement exact Shapley as a reusable function, because small cases give a correctness reference. We build it in 3 steps.

```python
X_e1 = np.array([[-1.0], [-0.8], [1.0]]) # Define rows.
y_e1 = np.array([0, 0, 1]) # Define labels.
Xv_e1 = np.array([[-1.1], [1.1]]) # Define validation rows.
yv_e1 = np.array([0, 1]) # Define validation labels.
print("rows:", len(y_e1)) # Inspect exact problem size.
```
▶ What you'll see: exact enumeration is tiny for three rows.

```python
def utility_e1(S_e1): # Define utility.
    if len(S_e1) == 0: return 0.0 # Empty utility.
    idx_e1 = np.array(list(S_e1), dtype=int) # Indices.
    d_e1 = np.abs(Xv_e1 - X_e1[idx_e1].T) # Distances.
    return float(np.mean(y_e1[idx_e1[np.argmin(d_e1, axis=1)]] == yv_e1)) # Accuracy.
def exact_e1(n_e1, utility_fn_e1): # Define exact Shapley.
    phi_e1 = np.zeros(n_e1) # Store values.
    for i_e1 in range(n_e1): # Loop rows.
        others_e1 = [j_e1 for j_e1 in range(n_e1) if j_e1 != i_e1] # Exclude current row.
        for r_e1 in range(n_e1): # Loop sizes.
            for S_e1 in combinations(others_e1, r_e1): # Loop coalitions.
                w_e1 = fact(r_e1) * fact(n_e1 - r_e1 - 1) / fact(n_e1) # Weight.
                phi_e1[i_e1] += w_e1 * (utility_fn_e1(tuple(sorted(S_e1 + (i_e1,)))) - utility_fn_e1(S_e1)) # Add marginal.
    return phi_e1 # Return values.
phi_e1 = exact_e1(3, utility_e1) # Compute values.
print("exact values:", np.round(phi_e1, 3)) # Inspect result.
assert np.allclose(np.round(phi_e1, 3), [0.25, 0.25, 0.5]) # Verify exact values.
```
▶ What you'll see: the reusable function returns the canonical values.

```python
plt.figure(figsize=(4.5, 3)) # Create value bars.
plt.bar(["row0", "row1", "row2"], phi_e1, color="teal") # Plot values.
plt.ylabel("φ_i") # Label axis.
plt.title("Easy 1: exact Data Shapley") # Title plot.
plt.show() # Display bars.
```
▶ What you'll see: row 2 is highest.

👀 Takeaway: exact implementation is simple but exponential in row count.

### Easy 3 — Estimate with Monte-Carlo orders

**Goal.** Approximate Shapley by random permutations, because exact subset sums do not scale. We build it in 3 steps.

```python
X_e3 = np.array([[-1.0], [-0.8], [1.0]]) # Define rows.
y_e3 = np.array([0, 0, 1]) # Define labels.
Xv_e3 = np.array([[-1.1], [1.1]]) # Define validation rows.
yv_e3 = np.array([0, 1]) # Define validation labels.
print("target exact values:", [0.25, 0.25, 0.5]) # Inspect reference.
```
▶ What you'll see: the Monte-Carlo estimate has a known target in this tiny case.

```python
def utility_e3(S_e3): # Define utility.
    if len(S_e3) == 0: return 0.0 # Empty utility.
    idx_e3 = np.array(list(S_e3), dtype=int) # Indices.
    d_e3 = np.abs(Xv_e3 - X_e3[idx_e3].T) # Distances.
    return float(np.mean(y_e3[idx_e3[np.argmin(d_e3, axis=1)]] == yv_e3)) # Accuracy.
rng_e3 = np.random.default_rng(3) # Create reproducible random generator.
contribs_e3 = [] # Store per-permutation contribution vectors.
for t_e3 in range(250): # Sample many row orders.
    order_e3 = rng_e3.permutation(3) # Draw one random order.
    S_e3 = tuple() # Start empty.
    prev_e3 = utility_e3(S_e3) # Initial utility.
    c_e3 = np.zeros(3) # Contribution vector for this order.
    for i_e3 in order_e3: # Walk through arriving rows.

        c_e3[i_e3] = now_e3 - prev_e3 # Credit utility jump.
        S_e3, prev_e3 = S_new_e3, now_e3 # Advance.
    contribs_e3.append(c_e3) # Store contributions.

```

### Advanced 1 — Quantify Monte-Carlo uncertainty

**Goal.** Repeat Monte-Carlo estimates across seeds, because approximation should be checked for variance. We build it in 3 steps.

```python
def utility_a1(S_a1): # Define utility.
    if len(S_a1) == 0: return 0.0 # Empty utility.
    idx_a1 = np.array(list(S_a1), dtype=int) # Indices.
    d_a1 = np.abs(Xv_a1 - X_a1[idx_a1].T) # Distances.
    return float(np.mean(y_a1[idx_a1[np.argmin(d_a1, axis=1)]] == yv_a1)) # Accuracy.
estimates_a1 = [] # Store estimates.
for seed_a1 in range(20): # Repeat independent MC runs.
    rng_a1 = np.random.default_rng(seed_a1) # Seed generator.
    rows_a1 = [] # Store contribution vectors.
    for t_a1 in range(60): # Sample orders.
        order_a1 = rng_a1.permutation(3) # Random order.
        S_a1 = tuple() # Start empty.
        prev_a1 = utility_a1(S_a1) # Previous utility.

            S_a1, prev_a1 = S_new_a1, now_a1 # Advance.

estimates_a1 = np.array(estimates_a1) # Convert to matrix.
```

### Advanced 5 — Stress-test label noise

**Goal.** Flip labels and recompute values, because mislabeled influential rows can become top cleaning priorities. We build it in 3 steps.

```python
def utility_noise_a5(labels_a5, S_a5): # Define utility for a label vector.
    if len(S_a5) == 0: return 0.0 # Empty utility.
    idx_a5 = np.array(list(S_a5), dtype=int) # Indices.
    d_a5 = np.abs(Xv_a5 - X_a5[idx_a5].T) # Distances.
    return float(np.mean(labels_a5[idx_a5[np.argmin(d_a5, axis=1)]] == yv_a5)) # Accuracy.
def exact_noise_a5(labels_a5): # Exact Shapley for four rows.
    n_a5 = len(labels_a5) # Row count.
    phi_a5 = np.zeros(n_a5) # Store values.
    for i_a5 in range(n_a5): # Loop rows.
        others_a5 = [j_a5 for j_a5 in range(n_a5) if j_a5 != i_a5] # Exclude current row.

    return phi_a5 # Return values.
value_matrix_a5 = [] # Store scenario values.
for flips_a5 in flip_cases_a5: # Loop scenarios.
    labels_a5 = y_clean_a5.copy() # Start clean.

        labels_a5[idx_a5] = 1 - labels_a5[idx_a5] # Flip binary label.
    value_matrix_a5.append(exact_noise_a5(labels_a5)) # Compute values.
```
