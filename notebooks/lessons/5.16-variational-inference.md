# 5.16 — Variational Inference

Variational inference (VI) turns hard Bayesian posterior computation into optimization: choose an easy family of distributions $q$, then pick the member that gives the highest evidence lower bound (ELBO). In this lesson we use tiny discrete examples so the posterior, ELBO, KL gap, mean-field bias, and optimization behavior are all visible in NumPy.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build variational inference one idea at a time. Run each cell in order and read the printed intermediate values — every probability is normalized, every ELBO term is exposed, and every approximation choice is tied back to the math. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, logs, normalization, and optimization grids.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for stochastic examples.
```

### 1. Exact posterior = normalize the joint

Bayesian inference starts with joint scores $p(x,z)$ and turns them into $p(z\mid x)$ by dividing by the evidence $p(x)=\sum_z p(x,z)$. This is easy for three hidden states, but painful when $z$ is a huge vector or a continuous latent variable. VI exists because exact normalization is often the expensive step.

```python
joint_w = np.array([0.02, 0.06, 0.12])  # p(x,z) for three hidden states.
evidence_w = float(joint_w.sum())  # p(x), the normalizing constant.
posterior_w = joint_w / evidence_w  # exact posterior for this tiny model.
print("evidence:", round(evidence_w, 3))
print("posterior:", np.round(posterior_w, 3))
assert np.allclose(posterior_w, [0.1, 0.3, 0.6])
```
▶ What you'll see: the normalized posterior is `[0.1, 0.3, 0.6]`.

```python
plt.figure(figsize=(4.2, 3))
plt.bar(["z0", "z1", "z2"], posterior_w, color="teal")
plt.title("1: exact posterior after normalization")
plt.ylabel("p(z | x)")
plt.ylim(0, 0.7)
plt.show()
```
▶ What you'll see: state z2 carries the most posterior mass.

*Why it's done this way: Bayes' rule needs a global normalizer. VI replaces direct normalization with an optimization objective that only needs local joint scores and an easy q.*

### 2. Choose a tractable approximation q

VI chooses a distribution $q(z)$ from a convenient family. In this toy example, q is just a categorical vector; in real models it might be a factorized Gaussian or a product of categorical factors. The choice matters because q can only represent shapes inside the family.

```python
p_w = posterior_w.copy()  # exact posterior for comparison.
q_w = np.array([0.2, 0.5, 0.3])  # candidate variational approximation.
print("p sums to:", round(float(p_w.sum()), 3), "q sums to:", round(float(q_w.sum()), 3))
print("candidate q:", q_w)
assert abs(q_w.sum() - 1.0) < 1e-12
```
▶ What you'll see: q is a valid probability distribution but not the same as p.

```python
x_w = np.arange(3)
plt.figure(figsize=(4.6, 3))
plt.bar(x_w - 0.18, p_w, width=0.36, label="posterior p", color="black")
plt.bar(x_w + 0.18, q_w, width=0.36, label="approx q", color="orange")
plt.xticks(x_w, ["z0", "z1", "z2"])
plt.title("2: posterior vs approximation")
plt.legend()
plt.show()
```
▶ What you'll see: q overweights z0 and z1 and underweights z2.

*Why it's done this way: selecting q turns inference into a search over parameters. The approximation family is the speed/accuracy tradeoff: easy families optimize quickly but can be biased.*

### 3. Build the ELBO from its two terms

The ELBO is $\mathcal L(q)=\mathbb E_q[\log p(x,z)-\log q(z)]$. The first term rewards q for placing mass where the joint is high. The second term is entropy, which rewards q for keeping uncertainty unless the joint score justifies concentration.

```python
log_joint_w = np.log(joint_w)  # log p(x,z).
fit_w = float(np.sum(q_w * log_joint_w))  # E_q log p(x,z).
entropy_w = float(-np.sum(q_w * np.log(q_w)))  # -E_q log q(z).
elbo_w = fit_w + entropy_w
print("fit:", round(fit_w, 6), "entropy:", round(entropy_w, 6), "ELBO:", round(elbo_w, 6))
assert round(elbo_w, 6) == -1.795536
```
▶ What you'll see: the entropy term lifts the bound above the expected log joint alone.

```python
plt.figure(figsize=(4.4, 3))
plt.bar(["E_q log joint", "entropy", "ELBO"], [fit_w, entropy_w, elbo_w], color=["purple", "green", "orange"])
plt.axhline(0, color="black", linewidth=0.7)
plt.xticks(rotation=16)
plt.title("3: ELBO pieces")
plt.show()
```
▶ What you'll see: a negative fit term, a positive entropy term, and their sum.

*Why it's done this way: the ELBO uses quantities we can compute from q and the joint, so it avoids requiring the exact posterior during training.*

### 4. The KL gap explains why maximizing ELBO works

The identity $\log p(x)=\mathcal L(q)+\mathrm{KL}(q\|p(z\mid x))$ says the ELBO is below the log evidence by exactly a KL gap. Since $\log p(x)$ is fixed for the observed data, maximizing the ELBO minimizes that gap within the chosen q family.

```python
kl_w = float(np.sum(q_w * np.log(q_w / posterior_w)))  # KL(q || posterior).
log_evidence_w = float(np.log(evidence_w))
print("KL gap:", round(kl_w, 6))
print("ELBO + KL:", round(elbo_w + kl_w, 6), "log evidence:", round(log_evidence_w, 6))
assert round(kl_w, 6) == 0.186098
assert abs((elbo_w + kl_w) - log_evidence_w) < 1e-12
```
▶ What you'll see: the KL gap is 0.186098 and the identity closes exactly.

```python
plt.figure(figsize=(4.2, 3))
plt.bar(["ELBO", "KL", "log p(x)"], [elbo_w, kl_w, log_evidence_w], color=["orange", "red", "black"])
plt.title("4: log evidence = ELBO + KL")
plt.show()
```
▶ What you'll see: the ELBO is lower than log evidence by the red KL gap.

*Why it's done this way: VI does not change the Bayesian target; it optimizes a lower bound whose missing amount is exactly the posterior approximation error.*

### 5. Optimize q over a simplex

If q can be any categorical distribution, the ELBO peaks at the exact posterior. A grid search over the probability simplex is inefficient but excellent for teaching: it shows that approximation error comes from restricting q or optimizing poorly, not from the ELBO identity itself.

```python
qs_w, elbos_w = [], []
for q0_w in np.linspace(0.02, 0.96, 48):
    if 0.96 - q0_w <= 0.02:
        continue
    for q1_w in np.linspace(0.02, 0.96 - q0_w, 48):
        q2_w = 1.0 - q0_w - q1_w
        if q1_w > 0 and q2_w > 0:
            cand_w = np.array([q0_w, q1_w, q2_w])
            qs_w.append(cand_w)
            elbos_w.append(float(np.sum(cand_w * (np.log(joint_w) - np.log(cand_w)))))
qs_w = np.array(qs_w); elbos_w = np.array(elbos_w)
best_q_w = qs_w[int(np.argmax(elbos_w))]
print("best grid q:", np.round(best_q_w, 3))
assert np.linalg.norm(best_q_w - posterior_w) < 0.025
```
▶ What you'll see: the best grid point lands very close to the exact posterior.

```python
plt.figure(figsize=(4.4, 3.4))
plt.scatter(qs_w[:, 0], qs_w[:, 1], c=elbos_w, cmap="viridis", s=14)
plt.scatter([posterior_w[0]], [posterior_w[1]], color="red", s=75, label="posterior")
plt.xlabel("q(z0)"); plt.ylabel("q(z1)")
plt.title("5: ELBO over the simplex")
plt.colorbar(label="ELBO")
plt.legend()
plt.show()
```
▶ What you'll see: the bright high-ELBO region surrounds the posterior point.

*Why it's done this way: optimizing ELBO is posterior fitting in disguise; with an unrestricted family, the optimum is the true posterior.*

### 6. Mean-field factorization leaves correlation behind

Mean-field VI assumes $q(a,b)=q(a)q(b)$. That factorization makes expectations cheap, but it forbids posterior correlation. Even if we set q's marginals equal to the true marginals, the independent outer product cannot reproduce a correlated joint table.

```python
p_joint_w = np.array([[0.42, 0.08], [0.08, 0.42]])  # correlated posterior.
qa_w = p_joint_w.sum(axis=1)
qb_w = p_joint_w.sum(axis=0)
q_mf_w = np.outer(qa_w, qb_w)  # mean-field outer product.
resid_w = p_joint_w - q_mf_w
print("mean-field q:\n", q_mf_w)
print("residual:\n", resid_w)
assert np.allclose(q_mf_w, 0.25 * np.ones((2, 2)))
```
▶ What you'll see: q is uniform while the true posterior prefers diagonal states.

```python
fig, ax_w = plt.subplots(1, 3, figsize=(8, 2.6))
for a_w, mat_w, title_w in zip(ax_w, [p_joint_w, q_mf_w, resid_w], ["posterior p", "mean-field q", "p - q"]):
    im_w = a_w.imshow(mat_w, cmap="coolwarm", vmin=-0.25, vmax=0.45)
    a_w.set_title(title_w)
    a_w.set_xticks([0, 1]); a_w.set_yticks([0, 1])
fig.colorbar(im_w, ax=ax_w, fraction=0.04)
plt.suptitle("6: mean-field cannot store correlation")
plt.show()
```
▶ What you'll see: the residual checkerboard is the missing dependence.

*Why it's done this way: factorization is the main computational win in VI, but it is also a structural assumption. No optimizer can recover correlations that q is not allowed to represent.*

### 7. KL(q||p) can under-cover modes

The VI KL direction penalizes q heavily for putting mass where p is small. With a simple unimodal q and a bimodal target, q often chooses one mode and avoids the low-density valley, even though that leaves another mode under-covered.

```python
x_w = np.linspace(-5, 5, 801)
dx_w = x_w[1] - x_w[0]
target_w = 0.5 * np.exp(-0.5 * ((x_w + 2) / 0.55) ** 2) + 0.5 * np.exp(-0.5 * ((x_w - 2) / 0.55) ** 2)
target_w = target_w / np.sum(target_w * dx_w)
centers_w = np.linspace(-2.5, 2.5, 101)
kl_curve_w = []
for m_w in centers_w:
    qdens_w = np.exp(-0.5 * ((x_w - m_w) / 0.7) ** 2)
    qdens_w = qdens_w / np.sum(qdens_w * dx_w)
    kl_curve_w.append(float(np.sum(qdens_w * np.log((qdens_w + 1e-12) / (target_w + 1e-12)) * dx_w)))
best_center_w = float(centers_w[int(np.argmin(kl_curve_w))])
print("best center:", round(best_center_w, 2))
assert abs(abs(best_center_w) - 2.0) <= 0.15
```
▶ What you'll see: the best center sits near one target mode, not between modes.

```python
best_qdens_w = np.exp(-0.5 * ((x_w - best_center_w) / 0.7) ** 2)
best_qdens_w = best_qdens_w / np.sum(best_qdens_w * dx_w)
plt.figure(figsize=(5, 3))
plt.plot(x_w, target_w, label="bimodal p", color="black")
plt.plot(x_w, best_qdens_w, label="best simple q", color="orange")
plt.title("7: KL(q||p) can choose one mode")
plt.xlabel("z"); plt.ylabel("density")
plt.legend()
plt.show()
```
▶ What you'll see: q hugs one peak and misses the other.

*Why it's done this way: the ELBO's KL direction is convenient but asymmetric. It often gives fast approximations, yet its uncertainty can be too narrow for multi-modal posteriors.*

### Basic 1 — Normalize joint scores

**Goal.** Turn joint scores into a posterior, because exact inference is normalization when the state space is tiny. We build it in 2 steps.

```python
joint_b1 = np.array([0.02, 0.06, 0.12]) # store p(x,z) for three hidden states.

```
▶ What you'll see: the evidence is 0.2.

```python
posterior_b1 = joint_b1 / evidence_b1 # normalize into p(z|x).
```

### Basic 3 — Compute expected log joint

**Goal.** Compute $\mathbb E_q[\log p(x,z)]$, because this is the ELBO term that rewards high joint probability. We build it in 2 steps.

```python
joint_b3 = np.array([0.02, 0.06, 0.12]) # define joint probabilities.
q_b3 = np.array([0.2, 0.5, 0.3]) # define q.
log_joint_b3 = np.log(joint_b3) # move to log scale.
print("log joint:", np.round(log_joint_b3, 3)) # inspect log scores.
```
▶ What you'll see: all log probabilities are negative.

```python
fit_b3 = float(np.sum(q_b3 * log_joint_b3)) # compute E_q log p(x,z).
print("E_q log joint:", round(fit_b3, 6)) # inspect weighted average.
assert round(fit_b3, 6) == -2.825189 # verify arithmetic.
plt.figure(figsize=(4, 3)) # create a contribution chart.
plt.bar(["z0", "z1", "z2"], q_b3 * log_joint_b3, color="purple") # show q-weighted log scores.
plt.title("Basic 3: expected log joint") # title the plot.
plt.show() # display the chart.
```
▶ What you'll see: high-q states dominate the expected log joint.

👀 Takeaway: q is rewarded for putting mass where the joint model score is high.

### Basic 4 — Compute q's entropy

**Goal.** Compute $-\sum q\log q$, because the ELBO also rewards uncertainty represented by q. We build it in 2 steps.

```python
q_b4 = np.array([0.2, 0.5, 0.3]) # define q.
entropy_terms_b4 = -q_b4 * np.log(q_b4) # compute per-state entropy terms.
print("entropy terms:", np.round(entropy_terms_b4, 6)) # inspect each contribution.
```
▶ What you'll see: each state contributes a positive uncertainty term.

```python
entropy_b4 = float(entropy_terms_b4.sum()) # sum entropy terms.
print("entropy:", round(entropy_b4, 6)) # inspect q entropy.
assert round(entropy_b4, 6) == 1.029653 # verify arithmetic.
plt.figure(figsize=(4, 3)) # create a bar chart.
plt.bar(["z0", "z1", "z2"], entropy_terms_b4, color="seagreen") # show entropy contributions.
plt.title("Basic 4: entropy of q") # title the plot.
plt.show() # display the chart.
```
▶ What you'll see: the uncertainty bonus is largest where q has substantial but not total mass.

👀 Takeaway: entropy keeps the ELBO from collapsing q without evidence.

### Basic 5 — Combine terms into the ELBO

**Goal.** Add expected log joint and entropy, because that sum is the lower bound VI maximizes. We build it in 3 steps.

```python
joint_b5 = np.array([0.02, 0.06, 0.12]) # define p(x,z).
q_b5 = np.array([0.2, 0.5, 0.3]) # define q.
print("joint:", joint_b5, "q:", q_b5) # inspect inputs.
```
▶ What you'll see: the ELBO needs only q and the joint scores.

```python
fit_b5 = float(np.sum(q_b5 * np.log(joint_b5))) # compute expected log joint.
entropy_b5 = float(-np.sum(q_b5 * np.log(q_b5))) # compute entropy.
elbo_b5 = fit_b5 + entropy_b5 # compute ELBO.
print("ELBO:", round(elbo_b5, 6)) # inspect objective value.
assert round(elbo_b5, 6) == -1.795536 # verify arithmetic.
```

```python
plt.figure(figsize=(4, 3)) # create a component chart.

```

👀 Takeaway: VI maximizes a tractable lower bound, not the posterior directly.

### Basic 6 — Compute the KL gap

**Goal.** Calculate $\mathrm{KL}(q\|p)$, because this is the gap between log evidence and the ELBO. We build it in 2 steps.

```python
p_b6 = np.array([0.1, 0.3, 0.6]) # exact posterior for this toy example.
q_b6 = np.array([0.2, 0.5, 0.3]) # candidate approximation.
ratio_b6 = q_b6 / p_b6 # compute q/p ratios.
print("q/p:", np.round(ratio_b6, 3)) # inspect over- and under-coverage.
```
▶ What you'll see: q is too large on z0 and z1 and too small on z2.

```python
kl_terms_b6 = q_b6 * np.log(ratio_b6) # compute per-state KL terms.
kl_b6 = float(kl_terms_b6.sum()) # sum to KL(q||p).
print("KL:", round(kl_b6, 6)) # inspect total KL.
assert round(kl_b6, 6) == 0.186098 # verify worked KL.
plt.figure(figsize=(4, 3)) # create KL term chart.
plt.bar(["z0", "z1", "z2"], kl_terms_b6, color="crimson") # show term contributions.
plt.axhline(0, color="black", linewidth=0.7) # show sign boundary.
plt.title("Basic 6: KL terms") # title the plot.
plt.show() # display the chart.
```
▶ What you'll see: some terms can be negative, but the KL total is positive.

👀 Takeaway: the KL gap measures how much the current q lowers the bound.

### Basic 7 — Verify the ELBO identity

**Goal.** Check $\log p(x)=\mathcal L(q)+\mathrm{KL}(q\|p)$, because this identity justifies ELBO maximization. We build it in 2 steps.

```python
joint_b7 = np.array([0.02, 0.06, 0.12]) # define joint scores.
p_b7 = joint_b7 / joint_b7.sum() # exact posterior for checking.
q_b7 = np.array([0.2, 0.5, 0.3]) # candidate q.
log_px_b7 = float(np.log(joint_b7.sum())) # compute log evidence.
print("log p(x):", round(log_px_b7, 6)) # inspect fixed target.
```
▶ What you'll see: log evidence is fixed for the observed data.

```python
elbo_b7 = float(np.sum(q_b7 * (np.log(joint_b7) - np.log(q_b7)))) # compute ELBO.
kl_b7 = float(np.sum(q_b7 * np.log(q_b7 / p_b7))) # compute KL gap.
print("ELBO + KL:", round(elbo_b7 + kl_b7, 6)) # inspect decomposition.
assert abs(elbo_b7 + kl_b7 - log_px_b7) < 1e-12 # verify identity.
plt.figure(figsize=(4, 3)) # create identity chart.
plt.bar(["ELBO", "KL", "log p(x)"], [elbo_b7, kl_b7, log_px_b7], color=["orange", "red", "black"]) # compare pieces.
plt.title("Basic 7: bound plus gap") # title the plot.
plt.show() # display chart.
```
▶ What you'll see: the bound plus the KL gap equals the log evidence.

👀 Takeaway: raising the ELBO shrinks the hidden KL gap when log evidence is constant.

### Basic 10 — See mean-field residuals

### Easy 1 — Grid-search categorical q

**Goal.** Maximize the ELBO over a tiny simplex, because unrestricted categorical VI should recover the exact posterior. We build it in 3 steps.

```python
joint_e1 = np.array([0.02, 0.06, 0.12]) # define joint scores.
posterior_e1 = joint_e1 / joint_e1.sum() # exact posterior for checking.
```

### Advanced 5 — Monitor ELBO and KL during optimization

**Goal.** Track ELBO and KL while optimizing q, because a healthy VI run should raise the bound and shrink the gap. We build it in 5 steps.

```python
    elbos_a5.append(elbo_a5); kls_a5.append(kl_a5) # record diagnostics.
```
