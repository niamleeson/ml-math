# 11.13 — Distributional RL

Distributional reinforcement learning keeps the whole **random return** an action can produce, not only its average value. In this lesson, you will build return distributions from scratch with NumPy, inspect how the distributional Bellman backup shifts probability mass through reward and discounting, and implement the two classic approximations behind C51 and QR-DQN without deep-learning libraries.

## 📖 Concept walkthrough — build each idea from scratch

Before the worked examples, we build distributional RL one idea at a time. Run each cell in order and read the printed intermediate values — the goal is to see the random variable behind a value estimate, the projection step that makes C51 trainable, and the quantile loss that makes QR-DQN trainable. This walkthrough is self-contained and uses a `_w` suffix so it never clashes with the examples below.

```python
import numpy as np  # arrays, probabilities, and small distribution calculations.
import matplotlib.pyplot as plt  # compact visualizations for return distributions.
np.random.seed(0)  # reproducibility for sampling demonstrations.
```

### 1. Return distribution, not just expected return

A classical action-value $Q(s,a)$ is the mean of future discounted rewards. Distributional RL instead models $Z(s,a)$, a **random variable** whose possible values are returns and whose probabilities say how likely those returns are. Two actions can have the same mean and very different risk: one steady, one lottery-like. Keeping the distribution exposes that difference before we collapse it to an expectation.

```python
returns_w = np.array([0.0, 2.0, 4.0])  # possible discounted returns for one action.
probs_w = np.array([0.25, 0.50, 0.25])  # probability mass over those returns.
mean_w = float(np.sum(returns_w * probs_w))  # expectation E[Z].
print("support:", returns_w)
print("probabilities:", probs_w)
print("mean return:", round(mean_w, 3))
assert round(mean_w, 3) == 2.000
```
▶ What you'll see: the distribution has three possible returns but its mean is the single number 2.0.

```python
var_w = float(np.sum(probs_w * (returns_w - mean_w) ** 2))  # variance of the same return random variable.
print("variance:", round(var_w, 3))
plt.figure(figsize=(4.4, 3))
plt.bar(returns_w, probs_w, width=0.35, color="steelblue")
plt.axvline(mean_w, color="black", linestyle="--", label="mean")
plt.title("1: return distribution Z(s,a)")
plt.xlabel("return value")
plt.ylabel("probability")
plt.legend()
plt.show()
assert round(var_w, 3) == 2.000
```
▶ What you'll see: probability mass is spread around the dashed mean, so the expectation hides the uncertainty.

*Why it's done this way:* $Q(s,a)=\mathbb{E}[Z(s,a)]$ is a summary, not the object itself. Modeling $Z$ keeps information about spread, tails, and multimodality; the mean can still be recovered by summing value times probability whenever the policy needs a scalar score.

### 2. The distributional Bellman backup

The Bellman idea is still “reward now plus discounted consequence later,” but now it acts on a random variable: $Z(s,a)\stackrel{D}{=}R(s,a)+\gamma Z(s',a')$. The symbol $\stackrel{D}{=}$ means equality in distribution. A deterministic reward shifts the support, discounting compresses distances, and a stochastic next return keeps its probability mass.

```python
next_support_w = np.array([0.0, 2.0, 4.0])  # possible next-state returns.
next_probs_w = np.array([0.2, 0.5, 0.3])  # next-state distribution.
reward_w = 1.0  # observed immediate reward.
gamma_w = 0.9  # discount for future consequences.
target_support_w = reward_w + gamma_w * next_support_w  # Bellman-transformed support.
print("next support:", next_support_w)
print("Bellman target support:", np.round(target_support_w, 3))
assert np.allclose(target_support_w, [1.0, 2.8, 4.6])
```
▶ What you'll see: every possible next return is compressed by 0.9 and shifted upward by reward 1.

```python
mean_next_w = float(np.sum(next_support_w * next_probs_w))
mean_target_w = float(np.sum(target_support_w * next_probs_w))
print("E[next Z]:", round(mean_next_w, 3))
print("E[target Z]:", round(mean_target_w, 3))
plt.figure(figsize=(4.6, 3))
plt.bar(next_support_w - 0.08, next_probs_w, width=0.16, label="next Z", color="gray")
plt.bar(target_support_w + 0.08, next_probs_w, width=0.16, label="r + γ next Z", color="seagreen")
plt.title("2: Bellman backup moves a distribution")
plt.xlabel("return value")
plt.ylabel("probability")
plt.legend()
plt.show()
assert round(mean_target_w, 3) == 2.980
```
▶ What you'll see: the target distribution has the same probabilities but moved support; its mean is $1+0.9\cdot2.2=2.98$.

*Why it's done this way:* distributional Bellman updates preserve the uncertainty that a scalar target would average away. The same algebra that gives $r+\gamma V(s')$ for means now transforms every atom of the return distribution, so bootstrapping remains compatible with probability mass.

### 3. C51 categorical projection

C51 represents $Z(s,a)$ on a fixed grid of 51 atoms in the original algorithm; here we use 5 atoms so the mechanics are visible. The Bellman target usually lands between grid points, so C51 **projects** each target atom onto its two neighboring fixed atoms by linear interpolation. This keeps the distribution on a shared support while preserving total probability and approximately preserving the mean.

```python
z_w = np.linspace(0.0, 4.0, 5)  # fixed categorical support: [0,1,2,3,4].
target_values_w = np.array([0.6, 2.2, 3.7])  # Bellman-transformed atoms that do not all land on grid points.
target_probs2_w = np.array([0.2, 0.5, 0.3])  # probability carried by each target atom.
delta_w = z_w[1] - z_w[0]  # grid spacing.
print("fixed support:", z_w)
print("off-grid targets:", target_values_w)
assert delta_w == 1.0
```
▶ What you'll see: the target values sit between the reusable C51 atom locations.

```python
projected_w = np.zeros_like(z_w)  # probability mass after projection onto fixed support.
for value_w, prob_w in zip(target_values_w, target_probs2_w):
    clipped_w = float(np.clip(value_w, z_w[0], z_w[-1]))  # keep targets inside support bounds.
    b_w = (clipped_w - z_w[0]) / delta_w  # fractional grid coordinate.
    lo_w = int(np.floor(b_w))
    hi_w = int(np.ceil(b_w))
    if lo_w == hi_w:
        projected_w[lo_w] += prob_w
    else:
        projected_w[lo_w] += prob_w * (hi_w - b_w)  # left share by distance to right atom.
        projected_w[hi_w] += prob_w * (b_w - lo_w)  # right share by distance to left atom.
print("projected probabilities:", np.round(projected_w, 3))
print("mass sum:", round(float(projected_w.sum()), 3))
assert np.allclose(np.round(projected_w, 3), [0.08, 0.12, 0.4, 0.19, 0.21])
assert round(float(projected_w.sum()), 3) == 1.000
```
▶ What you'll see: every off-grid atom splits its probability between neighboring grid atoms, and total mass stays 1.

```python
mean_before_w = float(np.sum(target_values_w * target_probs2_w))
mean_after_w = float(np.sum(z_w * projected_w))
print("mean before projection:", round(mean_before_w, 3))
print("mean after projection:", round(mean_after_w, 3))
plt.figure(figsize=(4.8, 3))
plt.bar(z_w, projected_w, width=0.35, color="darkorange")
plt.scatter(target_values_w, target_probs2_w, color="black", zorder=3, label="off-grid target mass")
plt.title("3: C51 projection onto fixed atoms")
plt.xlabel("fixed atom value")
plt.ylabel("probability")
plt.legend()
plt.show()
assert abs(mean_before_w - mean_after_w) < 1e-12
```
▶ What you'll see: the bars live only on the fixed grid, while black dots show where the target mass originally landed.

*Why it's done this way:* neural networks need a fixed-size output. C51 makes the network output probabilities over fixed atoms, then uses interpolation so a target at 2.2 contributes mostly to atom 2 and partly to atom 3. The interpolation weights are distances, which is why probability mass and the first moment are preserved inside the support.

### 4. Quantile regression for QR-DQN

QR-DQN represents a distribution by learnable quantile locations instead of fixed categorical probabilities. Each quantile is trained with an asymmetric loss: underestimating a high quantile is penalized differently from overestimating it. The quantile Huber loss keeps the ordering pressure of quantile regression while smoothing the kink near zero.

```python
taus_w = np.array([0.2, 0.5, 0.8])  # target quantile levels.
pred_quantiles_w = np.array([1.0, 2.0, 3.0])  # current predicted quantile locations.
target_samples_w = np.array([1.5, 2.5, 4.0])  # sampled Bellman target returns.
errors_w = target_samples_w[None, :] - pred_quantiles_w[:, None]  # pairwise target minus prediction.
print("pairwise TD errors:\n", np.round(errors_w, 2))
assert errors_w.shape == (3, 3)
```
▶ What you'll see: each predicted quantile compares to every target return sample, producing a small error matrix.

```python
kappa_w = 1.0  # Huber transition point.
abs_errors_w = np.abs(errors_w)
huber_w = np.where(abs_errors_w <= kappa_w, 0.5 * errors_w ** 2, kappa_w * (abs_errors_w - 0.5 * kappa_w))
weights_w = np.abs(taus_w[:, None] - (errors_w < 0).astype(float))  # quantile asymmetry.
quantile_loss_w = weights_w * huber_w / kappa_w
loss_w = float(np.mean(quantile_loss_w))
print("quantile Huber loss:", round(loss_w, 3))
plt.figure(figsize=(4.6, 3))
plt.imshow(quantile_loss_w, cmap="magma", aspect="auto")
plt.colorbar(label="loss contribution")
plt.xticks(range(3), ["t0", "t1", "t2"])
plt.yticks(range(3), ["τ=.2", "τ=.5", "τ=.8"])
plt.title("4: pairwise quantile loss")
plt.show()
assert round(loss_w, 3) == 0.247
```
▶ What you'll see: loss contributions differ by quantile level; upper quantiles care more about being too low.

*Why it's done this way:* quantiles define the inverse CDF: the 0.8 quantile should sit above about 80% of returns. The asymmetric factor $|\tau-\mathbf{1}\{\delta<0\}|$ pushes each location until the right fraction of target samples falls below it, while the Huber part prevents very large TD errors from dominating the update.

### ✍️ Toy 1 · A return distribution has mean and spread

Distributional RL keeps probabilities over possible returns. The scalar Q-value is only the mean of
that distribution.

```python
import numpy as np                              # arrays and probability sums.
import matplotlib.pyplot as plt                 # one picture per toy.

t1_rng = np.random.default_rng(0)               # seeded generator for reproducibility.

t1_probs = np.array([0.25, 0.50, 0.25])         # probability mass       # -> [0.25, 0.5, 0.25]
```

### ✍️ Toy 2 · Bellman backup shifts a whole distribution

The distributional Bellman step applies reward and discount to every possible next return while
leaving the probabilities attached to those outcomes.

```python
import numpy as np                              # arrays and weighted means.

t2_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t2_next_support = np.array([0.0, 1.0, 3.0])     # next return atoms       # -> [0.0, 1.0, 3.0]
```

### ✍️ Toy 3 · C51 projection splits off-grid mass

When a target atom lands between fixed support points, C51 splits its mass between the two neighbors
in proportion to distance.

```python
import numpy as np                              # arrays, clipping, and interpolation.

t3_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t3_grid = np.array([0.0, 1.0, 2.0, 3.0])        # fixed atoms                 # -> [0.0, 1.0, 2.0, 3.0]
t3_values = np.array([0.25, 1.5, 2.75])         # off-grid target atoms       # -> [0.25, 1.5, 2.75]
t3_probs = np.array([0.2, 0.5, 0.3])            # target probabilities        # -> [0.2, 0.5, 0.3]
t3_delta = t3_grid[1] - t3_grid[0]              # grid spacing                # -> 1.0
t3_projected = np.zeros_like(t3_grid)           # projected mass accumulator  # -> [0.0, 0.0, 0.0, 0.0]
for t3_value, t3_prob in zip(t3_values, t3_probs):
    t3_coord = (t3_value - t3_grid[0]) / t3_delta
    t3_lo = int(np.floor(t3_coord))
    t3_hi = int(np.ceil(t3_coord))
    t3_projected[t3_lo] += t3_prob * (t3_hi - t3_coord)
    t3_projected[t3_hi] += t3_prob * (t3_coord - t3_lo)
t3_mean_before = float(np.sum(t3_values * t3_probs))  # target mean before projection # -> 1.625
t3_mean_after = float(np.sum(t3_grid * t3_projected)) # projected mean                # -> 1.625
print("grid:", t3_grid.tolist())                # -> [0.0, 1.0, 2.0, 3.0]
print("target values:", t3_values.tolist())     # -> [0.25, 1.5, 2.75]
print("projected probabilities:", np.round(t3_projected, 3).tolist())  # -> [0.15, 0.3, 0.325, 0.225]
print("mass sum:", round(float(t3_projected.sum()), 3))                # -> 1.0
print("means:", round(t3_mean_before, 3), round(t3_mean_after, 3))     # -> 1.625 1.625
assert np.allclose(t3_projected, [0.15, 0.3, 0.325, 0.225])
assert abs(t3_mean_before - t3_mean_after) < 1e-12

plt.figure(figsize=(4.8, 2.8))
plt.bar(t3_grid, t3_projected, width=0.35, color="darkorange")
plt.scatter(t3_values, t3_probs, color="black", label="off-grid targets")
plt.xlabel("fixed atom")
plt.ylabel("probability")
plt.title("Toy 3 · off-grid mass splits")
plt.legend()
plt.show()
```
▶ What you'll see: the projected bars stay on the fixed grid while preserving total mass and mean.

### ✍️ Toy 4 · Quantile Huber loss weights errors asymmetrically

QR-DQN compares every predicted quantile to target returns. The quantile level changes how costly it
is to be above or below the target.

```python
import numpy as np                              # arrays and pairwise losses.

t4_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t4_taus = np.array([0.25, 0.75])                # quantile levels           # -> [0.25, 0.75]
t4_pred = np.array([1.0, 3.0])                  # predicted quantiles       # -> [1.0, 3.0]
t4_target = np.array([2.0, 4.0])                # target return samples     # -> [2.0, 4.0]
t4_errors = t4_target[None, :] - t4_pred[:, None]  # pairwise target - pred # -> [[1.0, 3.0], [-1.0, 1.0]]
t4_abs = np.abs(t4_errors)                      # absolute errors          # -> [[1.0, 3.0], [1.0, 1.0]]
t4_kappa = 1.0                                  # Huber threshold          # -> 1.0
t4_huber = np.where(t4_abs <= t4_kappa, 0.5 * t4_errors ** 2, t4_kappa * (t4_abs - 0.5 * t4_kappa))  # -> [[0.5, 2.5], [0.5, 0.5]]
t4_weights = np.abs(t4_taus[:, None] - (t4_errors < 0).astype(float))  # quantile asymmetry # -> [[0.25, 0.25], [0.25, 0.75]]
t4_loss_matrix = t4_weights * t4_huber          # weighted loss pieces     # -> [[0.125, 0.625], [0.125, 0.375]]
t4_loss = float(np.mean(t4_loss_matrix))        # mean quantile Huber loss # -> 0.3125
print("errors:\n", t4_errors)                   # -> [[ 1.  3.] [-1.  1.]]
print("Huber:\n", t4_huber)                     # -> [[0.5 2.5] [0.5 0.5]]
print("weights:\n", t4_weights)                 # -> [[0.25 0.25] [0.25 0.75]]
print("loss matrix:\n", t4_loss_matrix)         # -> [[0.125 0.625] [0.125 0.375]]
print("loss:", t4_loss)                         # -> 0.3125
assert abs(t4_loss - 0.3125) < 1e-12

plt.figure(figsize=(4.4, 2.8))
plt.imshow(t4_loss_matrix, cmap="magma", aspect="auto")
plt.colorbar(label="loss")
plt.xticks([0, 1], ["target 2", "target 4"])
plt.yticks([0, 1], ["τ=.25", "τ=.75"])
plt.title("Toy 4 · asymmetric quantile loss")
plt.show()
```
▶ What you'll see: the upper quantile row weights positive errors more heavily than the lower quantile row.

### Basic 1 — Discount a short reward stream

**Goal.** Compute a discounted return, because every distributional target still starts from future rewards being weighted by powers of $\gamma$. We build it in 2 steps.

```python
rewards_b1 = np.array([1.0, 0.0, 2.0]) # store rewards at t, t+1, and t+2.
gamma_b1 = 0.9 # choose the discount from the lesson block.
powers_b1 = gamma_b1 ** np.arange(len(rewards_b1)) # compute [1, gamma, gamma^2].
print("discount powers:", np.round(powers_b1, 3))
```
▶ What you'll see: later rewards receive smaller weights.

```python
return_b1 = float(np.sum(powers_b1 * rewards_b1)) # sum discounted rewards.
print("discounted return:", round(return_b1, 3))
plt.figure(figsize=(4, 3))
plt.bar(range(3), powers_b1 * rewards_b1, color="teal")
plt.title("Basic 1: discounted reward contributions")
plt.xlabel("time offset")
plt.ylabel("discounted reward")
plt.show()
assert round(return_b1, 3) == 2.620
```
▶ What you'll see: the reward two steps away contributes 1.62 instead of 2.0.

👀 Takeaway: discounting lets delayed rewards matter without treating the future as free.

### Basic 4 — Shift support by immediate reward

**Goal.** Apply the reward part of the Bellman backup, because immediate reward translates every possible future return. We build it in 2 steps.

```python
future_b4 = np.array([0.0, 1.0, 3.0]) # next return support before reward.
probs_b4 = np.array([0.2, 0.5, 0.3]) # next return probabilities.
reward_b4 = 1.0 # immediate reward.
shifted_b4 = reward_b4 + future_b4 # add reward to every possible future return.
print("shifted support:", shifted_b4)
assert np.allclose(shifted_b4, [1.0, 2.0, 4.0])
```
▶ What you'll see: support values all move right by exactly 1.

```python
plt.figure(figsize=(4.4, 3))
plt.bar(future_b4, probs_b4, width=0.18, label="future", color="gray")
plt.bar(shifted_b4, probs_b4, width=0.18, label="reward + future", color="darkorange")
plt.title("Basic 4: reward shifts Z")
plt.xlabel("return")
plt.ylabel("probability")
plt.legend()
plt.show()
print("mean shift:", round(float(np.sum(shifted_b4 * probs_b4) - np.sum(future_b4 * probs_b4)), 3))
```

```python
delta_a4 = target_samples_a4[None, :] - quantiles_a4[:, None]
weights_a4 = taus_a4[:, None] - (delta_a4 < 0).astype(float) # signed subgradient factor.
grad_a4 = -np.mean(weights_a4, axis=1) # descent gradient for absolute quantile loss.
quantiles_new_a4 = quantiles_a4 - eta_a4 * grad_a4 # update locations.
print("subgradient:", np.round(grad_a4, 3))
print("updated quantiles:", np.round(quantiles_new_a4, 3))
assert np.all(quantiles_new_a4 > quantiles_a4)
```
▶ What you'll see: all quantiles move upward because targets are mostly above predictions.

```python
loss_before_a4 = float(np.mean(np.abs(delta_a4) * np.abs(taus_a4[:, None] - (delta_a4 < 0).astype(float))))
delta_new_a4 = target_samples_a4[None, :] - quantiles_new_a4[:, None]
```

▶ What you'll see: the asymmetric quantile loss decreases after one hand-coded update.

### Advanced 5 — Compare mean-greedy and risk-sensitive choices

**Goal.** Use the same learned distributions for two decision rules, because distributional RL separates prediction from the risk preference used at action selection time. We build it in 4 steps.

```python
support_a5 = np.array([0.0, 1.0, 2.0, 6.0]) # return atoms shared by actions.
steady_a5 = np.array([0.0, 0.2, 0.7, 0.1]) # action with reliable middle returns.
lottery_a5 = np.array([0.55, 0.0, 0.0, 0.45]) # action with a bad lower tail and high upside.
print("mass sums:", steady_a5.sum(), lottery_a5.sum())
assert np.allclose([steady_a5.sum(), lottery_a5.sum()], [1.0, 1.0])
```
▶ What you'll see: both action distributions are valid.

```python
mean_steady_a5 = float(np.sum(support_a5 * steady_a5))
mean_lottery_a5 = float(np.sum(support_a5 * lottery_a5))
print("means:", round(mean_steady_a5, 3), round(mean_lottery_a5, 3))
mean_choice_a5 = "lottery" if mean_lottery_a5 > mean_steady_a5 else "steady"
assert mean_choice_a5 == "lottery"
```
▶ What you'll see: the lottery wins by expectation because its upside is large.

```python
cdf_steady_a5 = np.cumsum(steady_a5)
cdf_lottery_a5 = np.cumsum(lottery_a5)
var25_steady_a5 = float(support_a5[np.searchsorted(cdf_steady_a5, 0.25)])
var25_lottery_a5 = float(support_a5[np.searchsorted(cdf_lottery_a5, 0.25)])
risk_choice_a5 = "lottery" if var25_lottery_a5 > var25_steady_a5 else "steady"
print("25% quantiles:", var25_steady_a5, var25_lottery_a5, "risk-sensitive choice:", risk_choice_a5)
assert risk_choice_a5 == "steady"
```
▶ What you'll see: the cautious rule rejects the lottery because its lower quartile is 0.

```python
plt.figure(figsize=(4.8, 3))
plt.bar(support_a5 - 0.12, steady_a5, width=0.24, label="steady", color="seagreen")
plt.bar(support_a5 + 0.12, lottery_a5, width=0.24, label="lottery", color="crimson")

```
▶ What you'll see: the lottery has more high-end mass but also a much heavier zero-return tail.

👀 Takeaway: distributional predictions let you choose by expectation, tail risk, or another criterion without retraining the return model.
