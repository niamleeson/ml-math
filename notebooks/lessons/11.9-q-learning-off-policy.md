# 11.9 — Q-Learning (Off-Policy)

Q-learning learns an action-value table for the greedy policy while the agent may behave exploratorily. In this lesson, we build the update from discounted returns, bootstrapping, the max operator, and exploration pressure, then train a tiny gridworld from scratch with only NumPy and Matplotlib.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build Q-learning one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math is shown so the off-policy backup is not a black box. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, random choices, and small RL tables.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for exploratory choices.
```

### 1. States, actions, rewards, and the Q-table shape

A tabular reinforcement-learning agent stores one number per **state-action pair**. In a gridworld, a state can be a square index and an action can be up, right, down, or left. The Q-table has shape $|S|\times|A|$, so `Q[s, a]` estimates the discounted consequence of taking action `a` in state `s` and then behaving greedily afterward.

```python
n_rows_w, n_cols_w = 3, 4  # a small 3x4 gridworld.
actions_w = np.array(["up", "right", "down", "left"])  # four discrete actions.
n_states_w = n_rows_w * n_cols_w  # one state per grid square.
Q_w = np.zeros((n_states_w, len(actions_w)))  # action-value table: states x actions.
goal_w, trap_w = 11, 7  # terminal states in the lower-right and middle-right.
print("Q shape:", Q_w.shape)
print("goal state:", goal_w, "trap state:", trap_w)
assert Q_w.shape == (12, 4)
```
▶ What you'll see: a 12×4 Q-table, because the grid has 12 states and 4 actions.

```python
labels_w = np.arange(n_states_w).reshape(n_rows_w, n_cols_w)  # state ids as a grid.
plt.figure(figsize=(4.5, 3))
plt.imshow(labels_w, cmap="Blues", alpha=0.35)
for r_w in range(n_rows_w):
    for c_w in range(n_cols_w):
        s_w = r_w * n_cols_w + c_w
        txt_w = "G" if s_w == goal_w else ("T" if s_w == trap_w else str(s_w))
        plt.text(c_w, r_w, txt_w, ha="center", va="center", fontsize=12)
plt.xticks(range(n_cols_w)); plt.yticks(range(n_rows_w))
plt.title("1: states in a tiny gridworld"); plt.show()
```
▶ What you'll see: each grid square is a state; `G` is rewarding terminal state and `T` is the trap.

*Why it's done this way: Q-learning needs values for decisions, not just states. A state value $V(s)$ says how good the state is after a policy has already chosen actions; an action value $Q(s,a)$ keeps the alternatives separate so the agent can improve the policy by choosing the largest entry in each row.*

### 2. Discounted consequence: reward now plus future reward

The immediate reward is not the full objective. The return $G=r_0+\gamma r_1+\gamma^2r_2+\cdots$ discounts future rewards by powers of $\gamma$, so delayed payoff still matters but counts less than payoff now. This is how RL can prefer a small sacrifice that unlocks a better future.

```python
rewards_w = np.array([1.0, 0.0, 2.0])  # reward now, one step later, two steps later.
gamma_w = 0.9  # discount factor.
powers_w = gamma_w ** np.arange(len(rewards_w))  # [1, gamma, gamma^2].
terms_w = powers_w * rewards_w  # discounted contribution from each reward.
print("discount powers:", np.round(powers_w, 3))
print("discounted terms:", np.round(terms_w, 3))
```
▶ What you'll see: the reward two steps away is multiplied by $0.9^2=0.81$.

```python
G_w = float(np.sum(terms_w))  # full three-step discounted return.
print("G =", round(G_w, 3))
assert round(G_w, 3) == 2.620
plt.figure(figsize=(4.5, 3))
plt.bar(["r0", "γ r1", "γ² r2"], terms_w, color="teal")
plt.title("2: discounted return contributions")
plt.ylabel("contribution to G"); plt.show()
```
▶ What you'll see: `G = 2.620`; the delayed reward contributes 1.620 instead of its raw value 2.000.

*Why it's done this way: discounting makes the infinite future finite and expresses impatience or uncertainty. With $\gamma<1$, a reward farther away must be larger to compete with reward now, which prevents the agent from treating every future page of the ledger as equally certain and equally valuable.*

### 3. The Bellman optimal target and the max operator

Q-learning uses a one-step target: $y=r+\gamma\max_{a'}Q(s',a')$. The `max` asks, "if I land in the next state, what is the best action value available there?" This is an **optimal-control** target: it backs up the greedy future, even if the behavior that produced the sample was exploratory.

```python
next_Q_w = np.array([0.1, 0.8, 0.3, -0.2])  # current estimates for actions in s'.
r_w = 1.0  # observed immediate reward.
gamma_w = 0.9  # discount.
best_next_w = float(np.max(next_Q_w))  # max over possible next actions.
target_w = r_w + gamma_w * best_next_w  # Bellman optimal target.
print("next-state Q values:", next_Q_w)
print("max_a' Q(s',a'):", best_next_w)
print("target y:", round(target_w, 3))
assert round(target_w, 3) == 1.720
```
▶ What you'll see: the target is `1 + 0.9*0.8 = 1.720`, using the best next action estimate.

```python
plt.figure(figsize=(4.5, 3))
plt.bar(actions_w, next_Q_w, color=["gray", "seagreen", "gray", "gray"])
plt.axhline(best_next_w, color="black", linestyle="--", label="max")
plt.title("3: max chooses the greedy next action")
plt.ylabel("Q(s', a')"); plt.legend(); plt.show()
```
▶ What you'll see: the green bar is the action selected by the max operator for the target.

*Why it's done this way: the max operator is the policy-improvement step hidden inside Q-learning. Instead of averaging over the behavior policy's next action, it says the value of the current action should include the best consequence now believed reachable from the next state.*

### 4. Moving a Q estimate partway toward a bootstrapped target

A Q-learning update does not overwrite the old estimate. It moves by a learning-rate fraction $\alpha$ of the temporal-difference error: $Q_{new}=Q_{old}+\alpha(y-Q_{old})$. The term $y-Q_{old}$ is the surprise in the current estimate; $\alpha$ controls how strongly one sample can change the ledger.

```python
q_old_w = 0.4  # current estimate for Q(s,a).
alpha_w = 0.5  # learning rate.
td_error_w = target_w - q_old_w  # target minus current estimate.
q_new_w = q_old_w + alpha_w * td_error_w  # partial move toward the target.
print("TD error:", round(td_error_w, 3))
print("new Q:", round(q_new_w, 3))
assert round(q_new_w, 3) == 1.060
```
▶ What you'll see: the estimate moves halfway from 0.400 toward 1.720, landing at 1.060.

```python
plt.figure(figsize=(4.5, 3))
plt.bar(["old Q", "target y", "new Q"], [q_old_w, target_w, q_new_w], color=["gray", "black", "seagreen"])
plt.title("4: learning rate controls the partial move")
plt.ylabel("value"); plt.show()
```
▶ What you'll see: the new estimate sits between the old value and the bootstrap target.

*Why it's done this way: the target is itself built from current estimates, so it can be noisy or wrong. A partial update damps bootstrapping error; too small an $\alpha$ learns slowly, but too large an $\alpha$ lets a moving target yank the table around.*

### 5. Off-policy learning: behavior can explore while the target is greedy

The defining feature of Q-learning is that the **behavior policy** can choose an exploratory action, while the **target policy** inside the update is greedy. SARSA is different: it backs up the value of the action actually chosen next. The two targets are identical only when the next behavior action is also greedy.

```python
Q_next_w = np.array([0.2, 0.8, 0.4, 0.1])  # values at the next state.
actual_next_action_w = 2  # behavior chose "down", not the greedy "right".
r_w, gamma_w = 0.0, 0.9
qlearn_target_w = r_w + gamma_w * np.max(Q_next_w)  # greedy next action.
sarsa_target_w = r_w + gamma_w * Q_next_w[actual_next_action_w]  # actual next action.
print("greedy action:", actions_w[int(np.argmax(Q_next_w))])
print("actual behavior action:", actions_w[actual_next_action_w])
print("Q-learning target:", round(qlearn_target_w, 3))
print("SARSA target:", round(sarsa_target_w, 3))
assert round(qlearn_target_w, 3) == 0.720 and round(sarsa_target_w, 3) == 0.360
```
▶ What you'll see: Q-learning backs up 0.720 while SARSA backs up 0.360 because behavior explored a lower-valued action.

```python
plt.figure(figsize=(4.5, 3))
plt.bar(["Q-learning", "SARSA"], [qlearn_target_w, sarsa_target_w], color=["seagreen", "darkorange"])
plt.title("5: greedy target vs behavior target")
plt.ylabel("one-step target"); plt.show()
```
▶ What you'll see: the off-policy Q-learning target is larger because it assumes greedy control after the sampled transition.

*Why it's done this way: exploration is needed to collect evidence, but the goal is usually the best policy, not the noisy exploratory policy. Q-learning separates those roles; SARSA intentionally does not, which can make SARSA more conservative when exploration itself is risky.*

### 6. Exploration pressure: epsilon-greedy and UCB bonuses

If the agent only exploits its current max, it may never discover better actions. Epsilon-greedy gives every action some probability; a UCB-style bonus raises the index of actions with small sample counts. Both mechanisms create **policy support**: the data must contain enough action coverage for off-policy estimates to be trustworthy.

```python
q_state_w = np.array([0.55, 0.50, 0.10, 0.20])  # current action means.
epsilon_w = 0.2  # explore 20% of the time.
greedy_w = int(np.argmax(q_state_w))
probs_w = np.ones(4) * epsilon_w / 4  # exploration mass spread over all actions.
probs_w[greedy_w] += 1 - epsilon_w  # exploitation mass on the greedy action.
print("epsilon-greedy probabilities:", np.round(probs_w, 3))
print("probability sum:", round(float(probs_w.sum()), 3))
assert round(float(probs_w[greedy_w]), 3) == 0.850
```
▶ What you'll see: the greedy action gets probability 0.85, while every other action still gets 0.05.

```python
t_w, counts_w, c_w = 20, np.array([5, 2, 10, 1]), 1.0
ucb_w = q_state_w + c_w * np.sqrt(2 * np.log(t_w) / counts_w)
print("UCB indices:", np.round(ucb_w, 3))
print("worked index for action 0:", round(float(ucb_w[0]), 3))
assert round(float(ucb_w[0]), 3) == 1.645
plt.figure(figsize=(4.5, 3))
plt.bar(actions_w, ucb_w, color="mediumpurple")
plt.title("6: uncertainty bonus lifts under-sampled actions")
plt.ylabel("mean + exploration bonus"); plt.show()
```
▶ What you'll see: the UCB index can exceed the observed mean because uncertainty is temporarily valuable.

*Why it's done this way: off-policy learning is only as good as the data coverage behind it. Epsilon and bonuses force the behavior policy to sample actions that a premature greedy policy would hide, reducing the chance that a never-tried action is incorrectly treated as bad.*

### 7. Training a gridworld and visualizing the learned greedy policy

Now we connect the pieces. Each episode starts at the upper-left state, follows epsilon-greedy behavior, observes a transition, and updates `Q[s,a]` toward `reward + gamma * max(Q[next])`. After many episodes, the greedy policy points toward the goal while avoiding the trap.

```python
n_rows_w, n_cols_w = 3, 4
goal_w, trap_w = 11, 7
Q_train_w = np.zeros((n_rows_w * n_cols_w, 4))
alpha_w, gamma_w, epsilon_w = 0.4, 0.9, 0.2
returns_w = []
def step_w(s_w, a_w):
    r0_w, c0_w = divmod(s_w, n_cols_w)
    moves_w = [(-1, 0), (0, 1), (1, 0), (0, -1)]
    dr_w, dc_w = moves_w[a_w]
    nr_w = min(max(r0_w + dr_w, 0), n_rows_w - 1)
    nc_w = min(max(c0_w + dc_w, 0), n_cols_w - 1)
    ns_w = nr_w * n_cols_w + nc_w
    reward_w = 1.0 if ns_w == goal_w else (-1.0 if ns_w == trap_w else -0.04)
    done_w = ns_w in [goal_w, trap_w]
    return ns_w, reward_w, done_w
print("training table:", Q_train_w.shape)
```
▶ What you'll see: the trainable Q-table starts as all zeros.

```python
for episode_w in range(350):
    s_w, total_w = 0, 0.0
    for _ in range(40):
        if np.random.rand() < epsilon_w:
            a_w = int(np.random.randint(4))
        else:
            a_w = int(np.argmax(Q_train_w[s_w]))
        ns_w, reward_w, done_w = step_w(s_w, a_w)
        target_w = reward_w if done_w else reward_w + gamma_w * np.max(Q_train_w[ns_w])
        Q_train_w[s_w, a_w] += alpha_w * (target_w - Q_train_w[s_w, a_w])
        total_w += reward_w
        s_w = ns_w
        if done_w:
            break
    returns_w.append(total_w)
print("first 5 returns:", np.round(returns_w[:5], 2))
print("last 5 returns:", np.round(returns_w[-5:], 2))
assert np.mean(returns_w[-50:]) > np.mean(returns_w[:50])
```
▶ What you'll see: late episodes earn higher returns than early episodes, showing the table improved.

```python
policy_symbols_w = np.array(["↑", "→", "↓", "←"])
values_grid_w = np.max(Q_train_w, axis=1).reshape(n_rows_w, n_cols_w)
policy_grid_w = np.argmax(Q_train_w, axis=1).reshape(n_rows_w, n_cols_w)
plt.figure(figsize=(5, 3.4))
plt.imshow(values_grid_w, cmap="viridis")
plt.colorbar(label="max_a Q(s,a)")
for r_w in range(n_rows_w):
    for c_w in range(n_cols_w):
        s_w = r_w * n_cols_w + c_w
        text_w = "G" if s_w == goal_w else ("T" if s_w == trap_w else policy_symbols_w[policy_grid_w[r_w, c_w]])
        plt.text(c_w, r_w, text_w, ha="center", va="center", color="white", fontsize=14, weight="bold")
plt.xticks(range(n_cols_w)); plt.yticks(range(n_rows_w))
plt.title("7: learned greedy policy and state values"); plt.show()
```
▶ What you'll see: arrows generally point toward the goal and away from the trap; brighter cells have larger learned values.

*Why it's done this way: the update is local but its max target propagates terminal consequences backward through the table. The learned policy is not stored separately; it is read from the table by taking `argmax` in each state.*

### Basic 2 — Encode gridworld transitions

**Goal.** Write a small transition function, because every RL update needs a current state, an action, a next state, a reward, and a done flag. We build it in 2 steps.

```python
rows_b2, cols_b2 = 2, 3 # define a 2x3 grid.
goal_b2, trap_b2 = 5, 2 # define terminal squares.
def step_b2(s_b2, a_b2): # action order: up, right, down, left.
    r_b2, c_b2 = divmod(s_b2, cols_b2)
    moves_b2 = [(-1, 0), (0, 1), (1, 0), (0, -1)]
    dr_b2, dc_b2 = moves_b2[a_b2]
    nr_b2 = min(max(r_b2 + dr_b2, 0), rows_b2 - 1)
    nc_b2 = min(max(c_b2 + dc_b2, 0), cols_b2 - 1)
    ns_b2 = nr_b2 * cols_b2 + nc_b2
    reward_b2 = 1.0 if ns_b2 == goal_b2 else (-1.0 if ns_b2 == trap_b2 else -0.04)
    return ns_b2, reward_b2, ns_b2 in [goal_b2, trap_b2]
print("from state 1, right ->", step_b2(1, 1)) # inspect a transition into the trap.
```
▶ What you'll see: moving right from state 1 reaches the trap with reward -1 and `done=True`.

```python
grid_b2 = np.arange(rows_b2 * cols_b2).reshape(rows_b2, cols_b2) # state ids for plotting.
```

### Basic 8 — Compare Q-learning and SARSA targets

**Goal.** Show the off-policy difference numerically, because Q-learning uses a greedy target while SARSA uses the next action actually taken. We build it in 2 steps.

### Advanced 4 — Add an exploration bonus to action selection

**Goal.** Implement a UCB-style action index, because uncertainty bonuses explicitly value actions with low counts. We build it in 3 steps.
