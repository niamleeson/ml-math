# 4.23 — Biclustering

Biclustering, or co-clustering, looks for structure in a matrix by choosing **rows and columns together**. Instead of clustering whole rows using every feature, it asks whether a subset of rows behaves coherently on a subset of columns — a powerful lens for gene expression tables, user-item matrices, text counts, and any setting where local block patterns matter more than global blobs.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build biclustering one idea at a time. Run each cell in order and read the printed intermediate values — every block score, row effect, column effect, and assignment rule is exposed so the method is auditable instead of mysterious. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, masks, means, and small linear-algebra checks.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for synthetic matrix noise and initial choices.
```

### 1. A matrix can hide local row-column structure

Biclustering starts with a data matrix $X$ where rows might be samples, users, documents, or genes, and columns might be features, items, words, or conditions. A normal row clustering would compare each row using **all** columns. Biclustering is different: it looks for a row set $I$ and a column set $J$ whose submatrix $X[I,J]$ forms a coherent block, even if those rows do not look similar on the remaining columns.

```python
X_w = np.array([[5.0, 5.0, 1.0, 0.0, 2.0],
                [5.0, 4.0, 1.0, 0.0, 2.0],
                [0.0, 1.0, 4.0, 4.0, 1.0],
                [1.0, 0.0, 4.0, 5.0, 1.0],
                [2.0, 2.0, 1.0, 1.0, 5.0]])
rows_w = np.array([0, 1])  # a candidate row set I.
cols_w = np.array([0, 1])  # a candidate column set J.
print("X shape:", X_w.shape)
print("candidate block:\n", X_w[np.ix_(rows_w, cols_w)])
```
▶ What you'll see: rows 0 and 1 are both high on columns 0 and 1, forming a visible 2×2 block.

```python
plt.figure(figsize=(4.6, 3.2))
plt.imshow(X_w, cmap="viridis", aspect="auto")
plt.colorbar(label="value")
plt.title("1: full matrix with local block structure")
plt.xlabel("column")
plt.ylabel("row")
plt.show()
```
▶ What you'll see: two bright local rectangles appear in different column subsets; the goal is to find such rectangles by computation.

*Why it's done this way:* A bicluster is not just a cluster of rows or a cluster of columns. It is a **Cartesian product** $I\times J$, so selecting rows without columns loses the pattern and selecting columns without rows loses the context. The matrix indexing is the model.

### 2. Constant block coherence: mean and squared residue

The simplest block model says every selected entry should be close to one shared block mean. If $B=X[I,J]$ and $\bar B$ is its mean, the constant-block residue is $\frac{1}{|I||J|}\sum_{i\in I,j\in J}(x_{ij}-\bar B)^2$. Small residue means the block is internally consistent; large residue means the selected rows and columns do not agree under this simple lens.

```python
B_w = X_w[np.ix_(rows_w, cols_w)]
mean_w = float(B_w.mean())
residuals_w = B_w - mean_w
constant_residue_w = float(np.mean(residuals_w ** 2))
print("block mean:", round(mean_w, 3))
print("residuals:\n", residuals_w)
print("constant residue:", round(constant_residue_w, 4))
assert round(mean_w, 3) == 4.750
assert round(constant_residue_w, 4) == 0.1875
```
▶ What you'll see: the mean is 4.75 and the squared residue is small, so this 2×2 block is coherent.

```python
plt.figure(figsize=(4, 3))
plt.imshow(residuals_w, cmap="coolwarm", vmin=-1, vmax=1)
plt.colorbar(label="x_ij - block mean")
plt.title("2: residuals around one block mean")
plt.xticks(range(2), cols_w)
plt.yticks(range(2), rows_w)
plt.show()
```
▶ What you'll see: residuals are small red/blue deviations around zero, not a chaotic mixture.

*Why it's done this way:* Squaring makes positive and negative deviations both count as errors, and averaging divides out block size so a 4-cell block can be compared with a 40-cell block. This score is a criterion: it defines which structure the algorithm is able to see.

### 3. Additive row-plus-column coherence

Many real biclusters are not constant. One row may be consistently higher than another, and one column may be consistently higher than another, while the **interaction pattern** is still coherent. The additive model predicts each entry with

$$\hat x_{ij}=\mu + r_i + c_j,$$

where $\mu$ is the block mean, $r_i$ is row $i$'s average deviation from the block mean, and $c_j$ is column $j$'s average deviation from the block mean. The residue then measures what remains after row and column effects are removed.

```python
B_add_w = np.array([[5.0, 5.0],
                    [5.0, 4.0]])
mu_w = float(B_add_w.mean())
row_effect_w = B_add_w.mean(axis=1) - mu_w
col_effect_w = B_add_w.mean(axis=0) - mu_w
pred_add_w = mu_w + row_effect_w[:, None] + col_effect_w[None, :]
print("mu:", round(mu_w, 3))
print("row effects:", np.round(row_effect_w, 3))
print("column effects:", np.round(col_effect_w, 3))
print("additive prediction:\n", np.round(pred_add_w, 3))
```
▶ What you'll see: the prediction is built from one block mean plus row offsets plus column offsets.

```python
add_resid_w = B_add_w - pred_add_w
add_score_w = float(np.mean(add_resid_w ** 2))
print("additive residuals:\n", np.round(add_resid_w, 3))
print("additive squared residue:", round(add_score_w, 4))
assert round(add_score_w, 4) == 0.0625
```
▶ What you'll see: the additive squared residue is 0.0625, matching the lesson's tiny numeric pass.

```python
fig, ax = plt.subplots(1, 2, figsize=(6.2, 2.8))
ax[0].imshow(B_add_w, cmap="viridis", vmin=4, vmax=5)
ax[0].set_title("observed block")
ax[1].imshow(add_resid_w, cmap="coolwarm", vmin=-0.5, vmax=0.5)
ax[1].set_title("additive residuals")
plt.suptitle("3: remove row and column effects")
plt.show()
```
▶ What you'll see: the observed block is high everywhere, and the remaining additive residuals are tiny.

*Why it's done this way:* The row-plus-column formula is the least complicated way to separate baseline row strength from baseline column strength. What remains is the part no row effect or column effect explains; if that leftover is small, the selected rows and columns move together in a coherent local pattern.

### 4. Scoring many candidate blocks

A biclustering algorithm needs to search, not merely score one hand-picked block. For a small matrix we can enumerate fixed-size row and column sets, compute the residue for each, and keep the best ones. Real algorithms use heuristics or optimization because exhaustive search grows combinatorially.

```python
def additive_residue_w(M_w, rs_w, cs_w):
    block_w = M_w[np.ix_(rs_w, cs_w)]
    mu = block_w.mean()
    row_eff = block_w.mean(axis=1) - mu
    col_eff = block_w.mean(axis=0) - mu
    pred = mu + row_eff[:, None] + col_eff[None, :]
    return float(np.mean((block_w - pred) ** 2))

scores_w = []
for a_w in range(X_w.shape[0] - 1):
    for b_w in range(a_w + 1, X_w.shape[0]):
        for c_w in range(X_w.shape[1] - 1):
            for d_w in range(c_w + 1, X_w.shape[1]):
                scores_w.append(((a_w, b_w), (c_w, d_w), additive_residue_w(X_w, [a_w, b_w], [c_w, d_w])))
scores_w = sorted(scores_w, key=lambda t: t[2])
print("best 5 blocks:")
for item_w in scores_w[:5]:
    print(item_w[0], item_w[1], round(item_w[2], 4))
```
▶ What you'll see: low-residue row-column pairs rise to the top because they form coherent local rectangles.

```python
best_rows_w, best_cols_w, best_score_w = scores_w[0]
highlight_w = np.zeros_like(X_w)
highlight_w[np.ix_(best_rows_w, best_cols_w)] = 1
print("best score:", round(best_score_w, 4))
plt.figure(figsize=(4.6, 3.2))
plt.imshow(X_w, cmap="viridis", aspect="auto")
plt.imshow(np.ma.masked_where(highlight_w == 0, highlight_w), cmap="autumn", alpha=0.35, aspect="auto")
plt.title("4: lowest-residue candidate block")
plt.xlabel("column")
plt.ylabel("row")
plt.show()
```
▶ What you'll see: the highlighted rectangle marks the candidate whose additive residue is smallest among the searched 2×2 blocks.

*Why it's done this way:* The objective turns a vague phrase like “interesting block” into a sortable number. Exhaustive enumeration is only for teaching; the important principle is that every candidate is judged by the same mathematical criterion.

### 5. Co-clustering by alternating row and column assignments

Co-clustering is a partition-style biclustering lens: assign rows to row groups and columns to column groups, then summarize each row-group×column-group block. A simple version alternates two moves: estimate block means from current assignments, then reassign rows or columns to reduce reconstruction error. This is the same “assign, summarize, improve” rhythm that appears throughout unsupervised learning.

```python
X2_w = np.array([[5.0, 5.0, 1.0, 1.0],
                 [4.0, 5.0, 1.0, 1.0],
                 [1.0, 1.0, 5.0, 4.0],
                 [1.0, 1.0, 4.0, 5.0]])
row_labels_w = np.array([0, 0, 1, 1])
col_labels_w = np.array([0, 0, 1, 1])
print("row labels:", row_labels_w)
print("column labels:", col_labels_w)
```
▶ What you'll see: rows and columns are both divided into two groups, creating four blocks.

```python
def block_means_w(M_w, rlab_w, clab_w, kr_w=2, kc_w=2):
    means_w = np.zeros((kr_w, kc_w))
    for r_w in range(kr_w):
        for c_w in range(kc_w):
            block_w = M_w[np.ix_(rlab_w == r_w, clab_w == c_w)]
            means_w[r_w, c_w] = block_w.mean()
    return means_w

means2_w = block_means_w(X2_w, row_labels_w, col_labels_w)
recon2_w = means2_w[row_labels_w][:, col_labels_w]
err2_w = float(np.mean((X2_w - recon2_w) ** 2))
print("block means:\n", means2_w)
print("reconstruction error:", round(err2_w, 4))
assert round(err2_w, 4) == 0.1094
```
▶ What you'll see: four block means reconstruct the matrix with small average squared error.

```python
fig, ax = plt.subplots(1, 2, figsize=(6.4, 2.8))
ax[0].imshow(X2_w, cmap="viridis", vmin=1, vmax=5)
ax[0].set_title("observed X")
ax[1].imshow(recon2_w, cmap="viridis", vmin=1, vmax=5)
ax[1].set_title("block-mean reconstruction")
plt.suptitle("5: co-clustering compresses into blocks")
plt.show()
```
▶ What you'll see: the reconstruction keeps the two high diagonal blocks and low off-diagonal blocks.

*Why it's done this way:* Row labels alone cannot define a block model because column groups decide which features belong together. Column labels alone cannot explain which samples share the pattern. Alternating between them is a practical way to improve a coupled row-column explanation.

### 6. Scaling and stability decide whether the pattern is trustworthy

The residue calculation only sees the numbers we feed it. If one column is measured in huge units, it can dominate every block score. And because biclustering is unsupervised, a clean-looking block is not ground truth; we should check whether the same pattern survives scaling choices, perturbations, and nearby hyperparameters.

```python
X_scale_w = X2_w.copy()
X_scale_w[:, 3] *= 20.0
raw_score_w = additive_residue_w(X_scale_w, [2, 3], [2, 3])
center_w = X_scale_w.mean(axis=0)
spread_w = X_scale_w.std(axis=0)
Z_scale_w = (X_scale_w - center_w) / spread_w
scaled_score_w = additive_residue_w(Z_scale_w, [2, 3], [2, 3])
print("raw score after huge column scaling:", round(raw_score_w, 3))
print("standardized score:", round(scaled_score_w, 3))
assert raw_score_w > scaled_score_w
```
▶ What you'll see: changing units can inflate a residue, while standardization puts columns back on comparable footing.

```python
rng_w = np.random.default_rng(0)
base_block_w = X2_w[np.ix_([0, 1], [0, 1])]
perturbed_scores_w = []
for repeat_w in range(40):
    noisy_w = X2_w + rng_w.normal(0, 0.25, size=X2_w.shape)
    perturbed_scores_w.append(additive_residue_w(noisy_w, [0, 1], [0, 1]))
print("mean perturbed residue:", round(float(np.mean(perturbed_scores_w)), 4))
print("max perturbed residue:", round(float(np.max(perturbed_scores_w)), 4))
plt.figure(figsize=(4.4, 3))
plt.hist(perturbed_scores_w, bins=10, color="slateblue", edgecolor="white")
plt.title("6: stability of one block under noise")
plt.xlabel("additive residue")
plt.ylabel("count")
plt.show()
```
▶ What you'll see: a stable block keeps low residue across small perturbations instead of flipping wildly.

*Why it's done this way:* Unsupervised objectives optimize their own arithmetic, not a hidden teacher label. Scaling checks protect the arithmetic from arbitrary units, and stability checks ask whether the discovered bicluster is a robust pattern rather than an artifact.

### ✍️ Toy 1 · Row-column slicing creates a bicluster

A bicluster is the Cartesian product of selected rows and selected columns. The first mechanic is simply
extracting that local rectangle.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)                  # reproducible toy seed.
t1_X = np.array([[6.0, 5.0, 0.0],
                 [5.0, 5.0, 1.0],
                 [0.0, 1.0, 4.0],
                 [1.0, 0.0, 5.0]])                # 4 rows × 3 columns.
t1_rows = np.array([0, 1])                         # selected rows I  # -> [0 1]
t1_cols = np.array([0, 1])                         # selected cols J  # -> [0 1]
t1_block = t1_X[np.ix_(t1_rows, t1_cols)]          # X[I,J]           # -> [[6. 5.] [5. 5.]]
t1_block_sum = float(t1_block.sum())               # block total      # -> 21.0
print("matrix shape:", t1_X.shape)                # -> (4, 3)
print("rows:", t1_rows.tolist(), "cols:", t1_cols.tolist())  # -> [0, 1] [0, 1]
print("selected block:\n", t1_block)              # -> [[6. 5.] [5. 5.]]
print("block sum:", t1_block_sum)                 # -> 21.0
assert t1_block.shape == (2, 2) and t1_block_sum == 21.0

plt.figure(figsize=(4.2, 3.0))
t1_mask = np.zeros_like(t1_X)
t1_mask[np.ix_(t1_rows, t1_cols)] = 1
plt.imshow(t1_X, cmap="viridis", aspect="auto")
plt.imshow(np.ma.masked_where(t1_mask == 0, t1_mask), cmap="autumn", alpha=0.35, aspect="auto")
plt.title("Toy 1 · selected row-column block")
plt.xlabel("column")
plt.ylabel("row")
plt.colorbar(label="value")
plt.show()
```
▶ What you'll see: the upper-left 2×2 rectangle is the bicluster, not the whole row or whole column set alone.

### ✍️ Toy 2 · Constant residue measures one-mean coherence

Under a constant block model, every selected entry is compared with the same block mean and the squared
residuals are averaged.

```python
import numpy as np

t2_rng = np.random.default_rng(0)                  # reproducible toy seed.
t2_B = np.array([[6.0, 5.0, 5.0],
                 [5.0, 6.0, 5.0]])                # 2 rows × 3 columns.
t2_mean = float(t2_B.mean())                       # shared block mean       # -> 5.333
t2_residual = t2_B - t2_mean                       # deviations from mean    # -> [[ 0.667 -0.333 -0.333] [-0.333  0.667 -0.333]]
t2_squared = t2_residual ** 2                      # squared deviations      # -> [[0.444 0.111 0.111] [0.111 0.444 0.111]]
t2_residue = float(np.mean(t2_squared))            # mean squared residue    # -> 0.222
print("block mean:", round(t2_mean, 3))            # -> 5.333
print("residuals:\n", np.round(t2_residual, 3))    # -> [[ 0.667 -0.333 -0.333] [-0.333  0.667 -0.333]]
print("squared residuals:\n", np.round(t2_squared, 3))  # -> [[0.444 0.111 0.111] [0.111 0.444 0.111]]
print("constant residue:", round(t2_residue, 3))   # -> 0.222
assert round(t2_residue, 3) == 0.222

plt.figure(figsize=(4.0, 2.8))
plt.imshow(t2_residual, cmap="coolwarm", vmin=-1, vmax=1, aspect="auto")
plt.colorbar(label="x - mean")
plt.title("Toy 2 · constant-block residuals")
plt.xlabel("column")
plt.ylabel("row")
plt.show()
```
▶ What you'll see: all entries sit close to the shared mean, so the residue is only `0.222`.

### ✍️ Toy 3 · Additive row and column effects remove baselines

An additive bicluster predicts each entry with one mean plus a row offset plus a column offset, then
scores only the leftover interaction.

```python
import numpy as np

t3_rng = np.random.default_rng(0)                  # reproducible toy seed.
t3_B = np.array([[2.0, 4.0, 6.0],
                 [3.0, 6.0, 7.0],
                 [4.0, 6.0, 8.0]])                # slanted 3×3 block.
t3_mu = float(t3_B.mean())                         # block mean              # -> 5.111
t3_row_effect = t3_B.mean(axis=1) - t3_mu           # row offsets             # -> [-1.111  0.222  0.889]
t3_col_effect = t3_B.mean(axis=0) - t3_mu           # column offsets          # -> [-2.111  0.222  1.889]
t3_pred = t3_mu + t3_row_effect[:, None] + t3_col_effect[None, :]  # additive prediction.
t3_residual = t3_B - t3_pred                       # leftover interaction.
t3_score = float(np.mean(t3_residual ** 2))         # additive residue        # -> 0.0494
print("mu:", round(t3_mu, 3))                      # -> 5.111
print("row effects:", np.round(t3_row_effect, 3))  # -> [-1.111  0.222  0.889]
print("column effects:", np.round(t3_col_effect, 3))  # -> [-2.111  0.222  1.889]
print("additive prediction:\n", np.round(t3_pred, 3))  # -> [[1.889 4.222 5.889] [3.222 5.556 7.222] [3.889 6.222 7.889]]
print("additive residuals:\n", np.round(t3_residual, 3))  # -> [[ 0.111 -0.222  0.111] [-0.222  0.444 -0.222] [ 0.111 -0.222  0.111]]
print("additive residue:", round(t3_score, 4))     # -> 0.0494
assert round(t3_score, 4) == 0.0494

fig, ax = plt.subplots(1, 2, figsize=(6.2, 2.6))
ax[0].imshow(t3_B, cmap="viridis", aspect="auto"); ax[0].set_title("observed")
ax[1].imshow(t3_residual, cmap="coolwarm", vmin=-0.5, vmax=0.5, aspect="auto"); ax[1].set_title("leftover")
plt.suptitle("Toy 3 · additive block fit")
plt.show()
```
▶ What you'll see: row and column baselines explain most of the slant, leaving tiny residuals.

### ✍️ Toy 4 · Candidate blocks are sortable by residue

A search procedure scores many row-column rectangles with the same criterion, then keeps the lowest
residue candidates.

```python
import numpy as np

t4_rng = np.random.default_rng(0)                  # reproducible toy seed.
t4_X = np.array([[6.0, 6.0, 0.0],
                 [5.0, 5.0, 1.0],
                 [0.0, 1.0, 5.0],
                 [1.0, 0.0, 6.0]])                # two local patterns.
def t4_constant_residue(t4_M, t4_rs, t4_cs):
    t4_block = t4_M[np.ix_(t4_rs, t4_cs)]
    t4_mean = t4_block.mean()
    return float(np.mean((t4_block - t4_mean) ** 2))

t4_scores = []                                     # candidate score table.
for t4_a in range(t4_X.shape[0] - 1):
    for t4_b in range(t4_a + 1, t4_X.shape[0]):
        for t4_c in range(t4_X.shape[1] - 1):
            for t4_d in range(t4_c + 1, t4_X.shape[1]):
                t4_scores.append(((t4_a, t4_b), (t4_c, t4_d), t4_constant_residue(t4_X, [t4_a, t4_b], [t4_c, t4_d])))
t4_scores = sorted(t4_scores, key=lambda item: item[2])
t4_top3 = [(r, c, round(s, 3)) for r, c, s in t4_scores[:3]]  # top candidates  # -> [((0, 1), (0, 1), 0.25), ((2, 3), (0, 1), 0.25), ((1, 2), (1, 2), 4.0)]
t4_best_rows, t4_best_cols, t4_best_score = t4_scores[0]       # best rectangle.
print("top three candidates:", t4_top3)                       # -> [((0, 1), (0, 1), 0.25), ((2, 3), (0, 1), 0.25), ((1, 2), (1, 2), 4.0)]
print("best score:", round(t4_best_score, 3))                  # -> 0.25
assert t4_best_rows == (0, 1) and t4_best_cols == (0, 1)

t4_mask = np.zeros_like(t4_X)
t4_mask[np.ix_(t4_best_rows, t4_best_cols)] = 1
plt.figure(figsize=(4.2, 3.0))
plt.imshow(t4_X, cmap="viridis", aspect="auto")
plt.imshow(np.ma.masked_where(t4_mask == 0, t4_mask), cmap="autumn", alpha=0.35, aspect="auto")
plt.title("Toy 4 · lowest-residue candidate")
plt.xlabel("column")
plt.ylabel("row")
plt.show()
```
▶ What you'll see: the highlighted block is selected because its residue is tied for the smallest searched score.

### ✍️ Toy 5 · Block means reconstruct a co-clustered matrix

Co-clustering stores row labels and column labels, then replaces each row-group×column-group block by
its mean.

```python
import numpy as np

t5_rng = np.random.default_rng(0)                  # reproducible toy seed.

                 [1.0, 1.0, 5.0],

t5_row_labels = np.array([0, 0, 1, 1])             # two row groups.
```

### ✍️ Toy 6 · Reassigning one row can lower error

An alternating co-clustering pass tries a row in each group and keeps the assignment with smaller
block-mean reconstruction error.

```python
import numpy as np

t6_rng = np.random.default_rng(0)                  # reproducible toy seed.
t6_X = np.array([[5.0, 5.0, 1.0],
                 [4.0, 5.0, 1.0],
                 [1.0, 1.0, 5.0],
                 [1.0, 2.0, 4.0]])                # same block-structured matrix.
t6_col_labels = np.array([0, 0, 1])                # fixed column groups.
def t6_block_means(t6_M, t6_rlab, t6_clab):
    t6_means = np.zeros((2, 2))
    for t6_r in range(2):
        for t6_c in range(2):
            t6_block = t6_M[np.ix_(t6_rlab == t6_r, t6_clab == t6_c)]
            t6_means[t6_r, t6_c] = t6_block.mean() if t6_block.size else 0.0
    return t6_means

def t6_mse(t6_M, t6_rlab, t6_clab):
    t6_means = t6_block_means(t6_M, t6_rlab, t6_clab)
    t6_recon = t6_means[t6_rlab][:, t6_clab]
    return float(np.mean((t6_M - t6_recon) ** 2)), t6_means

t6_start = np.array([0, 1, 1, 1])                  # row 1 starts in the wrong group.
t6_start_err, t6_start_means = t6_mse(t6_X, t6_start, t6_col_labels)  # -> 2.0
t6_try0 = t6_start.copy(); t6_try0[1] = 0           # candidate row 1 -> group 0.
t6_err0, t6_means0 = t6_mse(t6_X, t6_try0, t6_col_labels)             # -> 0.1667
t6_try1 = t6_start.copy(); t6_try1[1] = 1           # candidate row 1 -> group 1.
t6_err1, t6_means1 = t6_mse(t6_X, t6_try1, t6_col_labels)             # -> 2.0
t6_best_group = 0 if t6_err0 < t6_err1 else 1       # chosen group      # -> 0
print("start labels:", t6_start.tolist())          # -> [0, 1, 1, 1]
print("start block means:\n", np.round(t6_start_means, 3))  # -> [[5.    1.   ] [2.333 3.333]]
print("start error:", round(t6_start_err, 4))      # -> 2.0
print("row 1 -> group 0 error:", round(t6_err0, 4))  # -> 0.1667
print("row 1 -> group 1 error:", round(t6_err1, 4))  # -> 2.0
print("best group for row 1:", t6_best_group)      # -> 0
assert t6_best_group == 0 and t6_err0 < t6_start_err

plt.figure(figsize=(4.4, 2.8))
plt.bar(["start", "row→0", "row→1"], [t6_start_err, t6_err0, t6_err1], color=["gray", "teal", "orange"])
plt.ylabel("MSE")
plt.title("Toy 6 · one row reassignment")
plt.show()
```
▶ What you'll see: moving row 1 into group 0 sharply lowers the block-mean error.

### ✍️ Toy 7 · Standardizing columns changes residue scale

If one column's units are inflated, a block score can become large for unit reasons rather than pattern
reasons. Standardization puts columns back on comparable footing.

```python
import numpy as np

t7_rng = np.random.default_rng(0)                  # reproducible toy seed.
t7_X = np.array([[5.0, 5.0, 1.0],
                 [5.0, 4.0, 1.0],
                 [1.0, 1.0, 5.0],
                 [1.0, 2.0, 4.0]])                # matrix with a lower-right block.
def t7_additive_residue(t7_M, t7_rs, t7_cs):
    t7_B = t7_M[np.ix_(t7_rs, t7_cs)]
    t7_mu = t7_B.mean()
    t7_row = t7_B.mean(axis=1) - t7_mu
    t7_col = t7_B.mean(axis=0) - t7_mu
    t7_pred = t7_mu + t7_row[:, None] + t7_col[None, :]
    return float(np.mean((t7_B - t7_pred) ** 2))

t7_X_bad = t7_X.copy()                             # copy before changing units.
t7_X_bad[:, 2] *= 20.0                             # column 2 now dominates numerically.
t7_raw_residue = t7_additive_residue(t7_X_bad, [2, 3], [1, 2])  # raw score  # -> 27.562
t7_mean = t7_X_bad.mean(axis=0)                    # column means          # -> [ 3.  3. 55.]
t7_std = t7_X_bad.std(axis=0)                      # column stds           # -> [ 2.     1.581 35.707]
t7_Z = (t7_X_bad - t7_mean) / t7_std               # standardized matrix.
t7_scaled_residue = t7_additive_residue(t7_Z, [2, 3], [1, 2])   # standardized score  # -> 0.089
print("raw residue:", round(t7_raw_residue, 3))    # -> 27.562
print("column means:", np.round(t7_mean, 3))       # -> [ 3.  3. 55.]
print("column stds:", np.round(t7_std, 3))         # -> [ 2.     1.581 35.707]
print("standardized residue:", round(t7_scaled_residue, 3))  # -> 0.089
assert t7_raw_residue > t7_scaled_residue

plt.figure(figsize=(4.4, 2.8))
plt.bar(["raw units", "standardized"], [t7_raw_residue, t7_scaled_residue], color=["gray", "teal"])
plt.ylabel("additive residue")
plt.title("Toy 7 · scaling affects block scores")
plt.show()
```
▶ What you'll see: the same selected rows and columns score far smaller after standardization.

### ✍️ Toy 8 · Perturbation stability keeps a good block low

A stable bicluster should keep a low score under small noise, rather than disappearing after a tiny
perturbation.

```python
import numpy as np

t8_rng = np.random.default_rng(0)                  # reproducible toy seed.

t8_scores = []                                     # residue after each perturbation.
```

## 🛠️ Setup

```python
import numpy as np  # load NumPy for arrays, masks, block scores, and reproducible simulations.
import matplotlib.pyplot as plt  # load Matplotlib for matrix heatmaps, bar charts, and diagnostic curves.
np.random.seed(0)  # make every stochastic example repeatable.

def show_matrix(M, title):  # define a tiny heatmap helper for compact matrix inspection.
    plt.figure(figsize=(4, 3))
    plt.imshow(M, cmap="viridis", aspect="auto")
    plt.colorbar(label="value")
    plt.title(title)
    plt.xlabel("column")
    plt.ylabel("row")
    plt.show()

def constant_residue(M):  # score a block by deviations from one shared mean.
    mu = float(np.mean(M))
    return float(np.mean((M - mu) ** 2))

def additive_residue(M):  # score a block after removing row and column average effects.
    mu = float(np.mean(M))
    row_eff = np.mean(M, axis=1) - mu
    col_eff = np.mean(M, axis=0) - mu
    pred = mu + row_eff[:, None] + col_eff[None, :]
    return float(np.mean((M - pred) ** 2))

def extract_block(M, rows, cols):  # index a row set I and column set J as a bicluster block.
    return M[np.ix_(np.asarray(rows, dtype=int), np.asarray(cols, dtype=int))]
```

### Advanced 1 — Discover two blocks with masking

**Goal.** Find one low-residue block, mask it, then find another, because real matrices can contain multiple local patterns. We build it in 5 steps.

```python

    for i_a1 in range(3):
        for j_a1 in range(i_a1 + 1, 4):
            for c_a1 in range(3):
                for d_a1 in range(c_a1 + 1, 4):
```
