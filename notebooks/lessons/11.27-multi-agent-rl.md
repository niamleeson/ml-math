# 11.27 — Multi-Agent RL

Multi-agent reinforcement learning studies what changes when each learner's reward depends not only on its own action, but also on the actions and learning updates of other agents. In this lesson, we build the mechanics from scratch with tiny matrix games: joint actions, mixed policies, Nash equilibria, and independent learners whose targets move because other policies keep changing.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build multi-agent RL one idea at a time. Run each cell in order and inspect the numbers carefully: in MARL, most surprises come from shapes, expectations over joint actions, and the fact that another learner makes your environment non-stationary. This walkthrough is self-contained and uses a `_w` suffix so it does not clash with the examples below.

```python
import numpy as np  # arrays, random sampling, and small linear-algebra calculations.
import matplotlib.pyplot as plt  # compact plots for payoffs, policies, and learning traces.
np.random.seed(0)  # reproducibility for all stochastic demonstrations.
```

### 1. Joint actions turn one decision into a game

A single-agent bandit can store one reward per action. A two-agent game needs one reward for every **joint action** `(my_action, other_action)`. That shape change is the first MARL idea: my action value is not a fixed number until the other agent's behavior is specified.

```python
row_payoff_w = np.array([[3., 0.],
                         [5., 1.]])  # row agent payoff: rows=row actions, columns=column actions.
col_payoff_w = np.array([[3., 5.],
                         [0., 1.]])  # column agent payoff for the same joint actions.
row_actions_w = ["cooperate", "defect"]
col_actions_w = ["cooperate", "defect"]
print("row payoff shape:", row_payoff_w.shape)
print("payoff at (row=defect, col=cooperate):", row_payoff_w[1, 0], col_payoff_w[1, 0])
assert row_payoff_w.shape == (2, 2)
```
▶ What you'll see: a 2×2 payoff table, where one joint action gives row 5 and column 0.

```python
plt.figure(figsize=(4, 3))
plt.imshow(row_payoff_w, cmap="viridis")
plt.colorbar(label="row reward")
plt.xticks(range(2), col_actions_w, rotation=20)
plt.yticks(range(2), row_actions_w)
plt.title("1: row reward depends on both actions")
plt.show()
```
▶ What you'll see: each cell is a joint action; moving across columns changes row's reward even when row's action is unchanged.

*Why it's done this way:* MARL replaces `Q(a)` with `Q(a_i, a_-i)` because the reward-generating event is the joint action. Mathematically, the expectation must later sum over the other agent's policy; otherwise we pretend the other action is fixed when it is actually part of the environment.

### 2. A mixed policy induces expected value over joint actions

A **mixed policy** assigns probabilities to actions. If the row agent chooses actions with probabilities `π_r` and the column agent chooses with `π_c`, the probability of a joint action is the outer product `π_r[a] π_c[b]`. Expected reward is the payoff table averaged under those joint-action probabilities.

```python
pi_row_w = np.array([0.6, 0.4])  # row cooperates with probability 0.6 and defects with 0.4.
pi_col_w = np.array([0.25, 0.75])  # column cooperates with probability 0.25 and defects with 0.75.
joint_w = pi_row_w[:, None] * pi_col_w[None, :]  # independent mixed policies create a joint distribution.
print("joint distribution:\n", np.round(joint_w, 3))
print("sum:", joint_w.sum())
assert np.isclose(joint_w.sum(), 1.0)
```
▶ What you'll see: four joint-action probabilities that add to 1.

```python
row_value_w = float(np.sum(joint_w * row_payoff_w))
col_value_w = float(np.sum(joint_w * col_payoff_w))
print("row expected reward:", round(row_value_w, 3))
print("column expected reward:", round(col_value_w, 3))
assert round(row_value_w, 3) == 1.25
assert round(col_value_w, 3) == 3.0
```
▶ What you'll see: the same joint distribution gives different expected rewards to the two agents.

```python
plt.figure(figsize=(4, 3))
plt.imshow(joint_w, cmap="Blues", vmin=0, vmax=1)
plt.colorbar(label="joint probability")
plt.xticks(range(2), col_actions_w, rotation=20)
plt.yticks(range(2), row_actions_w)
plt.title("2: π_row × π_col over joint actions")
plt.show()
```
▶ What you'll see: most probability mass sits in the row-cooperate / column-defect cell because both policies favor those actions.

*Why it's done this way:* The expected-return formula is still an average, but the averaging object is now a joint distribution. The outer product is the independence assumption: each policy is sampled separately, so the probability of a pair is the product of its marginal probabilities.

### 3. Best responses and Nash equilibrium

A **best response** is the action that maximizes my expected payoff against the other agent's fixed policy. A **Nash equilibrium** is a pair of policies where both agents are already best-responding, so neither can improve by changing alone. In a pure matrix game, we can find it by checking whether a cell is a row maximum in its column and a column maximum in its row.

```python
row_best_mask_w = row_payoff_w == row_payoff_w.max(axis=0, keepdims=True)  # row best responses to each column action.
col_best_mask_w = col_payoff_w == col_payoff_w.max(axis=1, keepdims=True)  # column best responses to each row action.
nash_mask_w = row_best_mask_w & col_best_mask_w
print("row best-response mask:\n", row_best_mask_w.astype(int))
print("column best-response mask:\n", col_best_mask_w.astype(int))
print("pure Nash cells:", np.argwhere(nash_mask_w).tolist())
assert np.argwhere(nash_mask_w).tolist() == [[1, 1]]
```
▶ What you'll see: only `(defect, defect)` is a mutual best response in this prisoner's-dilemma payoff table.

```python
pure_values_w = []
for a_w in range(2):
    for b_w in range(2):
        pure_values_w.append([a_w, b_w, row_payoff_w[a_w, b_w], col_payoff_w[a_w, b_w]])
print("[row_action, col_action, row_reward, col_reward]:")
print(np.array(pure_values_w, dtype=float))
```
▶ What you'll see: `(cooperate, cooperate)` gives both agents 3, but it is not stable because either agent can defect alone.

```python
plt.figure(figsize=(4, 3))
plt.imshow(nash_mask_w.astype(int), cmap="Greens", vmin=0, vmax=1)
plt.xticks(range(2), col_actions_w, rotation=20)
plt.yticks(range(2), row_actions_w)
plt.title("3: pure Nash equilibrium mask")
plt.show()
```
▶ What you'll see: the only highlighted cell is defect/defect.

*Why it's done this way:* Nash equilibrium is not the same as maximum social reward. It is a fixed point of unilateral optimization: holding everyone else fixed, no agent has a profitable deviation. That is why MARL must reason about strategic stability, not just high reward cells.

### 4. Mixed Nash in matching pennies

Some games have no stable pure cell. In matching pennies, row wins if actions match and column wins if they differ. The mixed Nash equilibrium makes each opponent indifferent: if row plays heads with probability `p`, column's two actions must have equal expected value; solving that equality gives `p = 0.5`, and symmetry gives column probability `0.5`.

```python
mp_row_w = np.array([[1., -1.],
                     [-1., 1.]])  # row payoff; column payoff is the negative.
mp_col_w = -mp_row_w
row_best_mp_w = mp_row_w == mp_row_w.max(axis=0, keepdims=True)
col_best_mp_w = mp_col_w == mp_col_w.max(axis=1, keepdims=True)
print("pure Nash cells:", np.argwhere(row_best_mp_w & col_best_mp_w).tolist())
assert len(np.argwhere(row_best_mp_w & col_best_mp_w)) == 0
```
▶ What you'll see: no pure joint action is stable; one player always wants to switch.

```python
p_grid_w = np.linspace(0, 1, 101)  # probability row plays heads.
col_pay_heads_w = p_grid_w * mp_col_w[0, 0] + (1 - p_grid_w) * mp_col_w[1, 0]
col_pay_tails_w = p_grid_w * mp_col_w[0, 1] + (1 - p_grid_w) * mp_col_w[1, 1]
indiff_idx_w = int(np.argmin(np.abs(col_pay_heads_w - col_pay_tails_w)))
print("indifference p:", round(float(p_grid_w[indiff_idx_w]), 2))
assert round(float(p_grid_w[indiff_idx_w]), 2) == 0.5
```
▶ What you'll see: column is indifferent between actions when row randomizes 50/50.

```python
plt.figure(figsize=(4.5, 3))
plt.plot(p_grid_w, col_pay_heads_w, label="column chooses heads")
plt.plot(p_grid_w, col_pay_tails_w, label="column chooses tails")
plt.axvline(0.5, color="black", linestyle="--", label="mixed Nash")
plt.xlabel("row probability of heads")
plt.ylabel("column expected payoff")
plt.title("4: mixed Nash makes opponent indifferent")
plt.legend()
plt.show()
```
▶ What you'll see: the two payoff lines cross at 0.5, the point where column cannot exploit row's mix.

*Why it's done this way:* A mixed Nash equalizes the opponent's best-response payoffs. If one opponent action paid more, the opponent would shift probability there, so the original mixture could not be stable.

### 5. Independent learners see a non-stationary environment

Independent Q-learning treats the other agents as part of the environment. That is simple, but dangerous: if another policy changes, the expected reward of my same action changes even when the physical payoff matrix is fixed.

```python
col_policy_early_w = np.array([0.9, 0.1])  # mostly cooperate.
col_policy_late_w = np.array([0.1, 0.9])  # mostly defect.
q_against_early_w = row_payoff_w @ col_policy_early_w
q_against_late_w = row_payoff_w @ col_policy_late_w
print("row action values vs early column policy:", np.round(q_against_early_w, 3))
print("row action values vs late column policy:", np.round(q_against_late_w, 3))
assert np.allclose(q_against_early_w, [2.7, 4.6])
assert np.allclose(q_against_late_w, [0.3, 1.4])
```
▶ What you'll see: both row action values fall when the other agent switches from cooperation to defection.

```python
alph_w = 0.25
q_track_w = np.zeros(2)
trace_w = []
for t_w in range(40):
    pol_w = col_policy_early_w if t_w < 20 else col_policy_late_w
    target_w = row_payoff_w @ pol_w
    q_track_w += alph_w * (target_w - q_track_w)
    trace_w.append(q_track_w.copy())
trace_w = np.array(trace_w)
print("Q after early phase:", np.round(trace_w[19], 3))
print("Q after late phase:", np.round(trace_w[-1], 3))
assert trace_w[-1, 1] < trace_w[19, 1]
```
▶ What you'll see: the estimates first chase the early target, then bend toward a lower late target.

```python
plt.figure(figsize=(5, 3))
plt.plot(trace_w[:, 0], label="Q(cooperate)")
plt.plot(trace_w[:, 1], label="Q(defect)")
plt.axvline(19, color="black", linestyle="--", label="opponent policy changes")
plt.title("5: independent learner tracks a moving target")
plt.xlabel("update")
plt.ylabel("estimated value")
plt.legend()
plt.show()
```
▶ What you'll see: a visible kink at the policy-change line; the learner's target is non-stationary.

*Why it's done this way:* The one-step update `Q ← Q + α(target − Q)` assumes the target is meaningful long enough to chase. In MARL, the target contains the other policy, so another learner's update changes the target distribution and violates the stationarity assumption behind ordinary RL convergence intuition.

## 🛠️ Setup

```python
import numpy as np  # arrays, matrix games, random sampling, and simple numerical checks.
import matplotlib.pyplot as plt  # visualizations for payoff matrices, policies, and learning curves.
np.random.seed(0)  # make stochastic examples reproducible.

def softmax(x):
    x = np.asarray(x, dtype=float)
    z = x - np.max(x)
    e = np.exp(z)
    return e / e.sum()

def expected_payoffs(A, B, pi_r, pi_c):
    joint = pi_r[:, None] * pi_c[None, :]
    return float(np.sum(joint * A)), float(np.sum(joint * B))

def pure_nash(A, B):
    row_best = A == A.max(axis=0, keepdims=True)
    col_best = B == B.max(axis=1, keepdims=True)
    return np.argwhere(row_best & col_best)

def show_game(A, title):
    plt.figure(figsize=(4, 3))
    plt.imshow(A, cmap="viridis")
    plt.colorbar(label="row payoff")
    plt.title(title)
    plt.xlabel("column action")
    plt.ylabel("row action")
    plt.show()
```

### Basic 5 — Compute expected payoff

**Goal.** Average a payoff table under a joint policy, because value in a game means expectation over what all agents might do. We build it in 2 steps.

```python
pi_c_b5 = np.array([0.25, 0.75])
```

```python
plt.show()
```
▶ What you'll see: column has higher expected reward under these particular policies.

👀 Takeaway: value is an expectation over joint actions, not a lookup from one action alone.

### Basic 9 — One Q update for a joint action

**Goal.** Update a joint-action value estimate, because tabular MARL often tracks values for action tuples. We build it in 2 steps.

### Easy 2 — Simulate independent Q-learning in a matrix game

**Goal.** Let two epsilon-greedy learners update independently, because this simple baseline exposes how learning dynamics can settle into strategic patterns. We build it in 3 steps.

```python
A_e2 = np.array([[3., 0.], [5., 1.]])
B_e2 = np.array([[3., 5.], [0., 1.]])
Q_row_e2 = np.zeros(2)
Q_col_e2 = np.zeros(2)
alpha_e2 = 0.15
eps_e2 = 0.1
counts_e2 = np.zeros((2, 2), dtype=int)
print("initial Q:", Q_row_e2, Q_col_e2)
```
▶ What you'll see: each learner stores only its own action values, not a full model of the other learner.

```python

    ar_e2 = np.random.randint(2) if np.random.rand() < eps_e2 else int(np.argmax(Q_row_e2))
    ac_e2 = np.random.randint(2) if np.random.rand() < eps_e2 else int(np.argmax(Q_col_e2))
    counts_e2[ar_e2, ac_e2] += 1
    Q_row_e2[ar_e2] += alpha_e2 * (A_e2[ar_e2, ac_e2] - Q_row_e2[ar_e2])
    Q_col_e2[ac_e2] += alpha_e2 * (B_e2[ar_e2, ac_e2] - Q_col_e2[ac_e2])
print("learned Q row:", np.round(Q_row_e2, 3))
print("learned Q col:", np.round(Q_col_e2, 3))
assert counts_e2.sum() == 500
```
▶ What you'll see: both learners estimate rewards from samples generated by the other learner's changing choices.

```python

plt.colorbar(label="visits")
plt.title("Easy 2: visited joint actions")
plt.xlabel("column action")
plt.ylabel("row action")
plt.show()
```
▶ What you'll see: most visits concentrate near the actions favored by the learned greedy policies.

👀 Takeaway: independent learners are easy to implement, but their data distribution is created by multiple adapting policies.

### Advanced 2 — Solve a 2×2 mixed Nash by indifference

**Goal.** Solve matching pennies analytically, because mixed equilibrium probabilities come from making each opponent indifferent. We build it in 4 steps.

```python
A_a2 = np.array([[1., -1.], [-1., 1.]])
B_a2 = -A_a2
# For column to be indifferent: p*B[0,0] + (1-p)*B[1,0] = p*B[0,1] + (1-p)*B[1,1].
coef_p_a2 = (B_a2[0, 0] - B_a2[1, 0]) - (B_a2[0, 1] - B_a2[1, 1])
const_a2 = B_a2[1, 1] - B_a2[1, 0]
p_row_heads_a2 = const_a2 / coef_p_a2
print("row heads probability:", p_row_heads_a2)
```
▶ What you'll see: row must play heads with probability 0.5.

```python
coef_q_a2 = (A_a2[0, 0] - A_a2[0, 1]) - (A_a2[1, 0] - A_a2[1, 1])
const_q_a2 = A_a2[1, 1] - A_a2[0, 1]
p_col_heads_a2 = const_q_a2 / coef_q_a2
print("column heads probability:", p_col_heads_a2)
```
▶ What you'll see: column must also play heads with probability 0.5.

```python
pi_r_a2 = np.array([p_row_heads_a2, 1 - p_row_heads_a2])
pi_c_a2 = np.array([p_col_heads_a2, 1 - p_col_heads_a2])

assert np.isclose(value_a2, 0.0) and np.isclose(opp_value_a2, 0.0)
```
▶ What you'll see: both agents have value 0 under the fair mixed strategy.


### Advanced 3 — Demonstrate non-stationary TD targets

**Goal.** Track a TD target that includes an opponent policy, because bootstrapping from a moving policy can amplify instability. We build it in 4 steps.

```python
A_a3 = np.array([[3., 0.], [5., 1.]])
gamma_a3 = 0.9
V_next_a3 = np.array([2.0, 0.5])
opp_start_a3 = np.array([0.9, 0.1])
opp_end_a3 = np.array([0.1, 0.9])
print("next-state values:", V_next_a3)
```
▶ What you'll see: the future-value term is fixed so only opponent policy changes the target.

```python

for pi_a3 in policies_a3:
    reward_if_action1_a3 = float(A_a3[1] @ pi_a3)
    next_value_a3 = float(V_next_a3 @ pi_a3)
    targets_a3.append(reward_if_action1_a3 + gamma_a3 * next_value_a3)
```

### Advanced 5 — Run policy-gradient ascent in a differentiable matrix game

**Goal.** Update softmax logits by finite-difference gradients, because policy optimization changes probability mass rather than directly changing action values. We build it in 4 steps.

```python
A_a5 = np.array([[3., 0.], [5., 1.]])
B_a5 = np.array([[3., 5.], [0., 1.]])
logits_r_a5 = np.array([0.0, 0.0])
logits_c_a5 = np.array([0.0, 0.0])
eta_a5 = 0.4
eps_fd_a5 = 1e-4
values_a5 = []
print("initial policies:", softmax(logits_r_a5), softmax(logits_c_a5))
```
▶ What you'll see: both agents start uniform over two actions.

```python
def value_for_logits_a5(lr, lc):
    return expected_payoffs(A_a5, B_a5, softmax(lr), softmax(lc))

for step_a5 in range(35):
    vr_a5, vc_a5 = value_for_logits_a5(logits_r_a5, logits_c_a5)
    values_a5.append([vr_a5, vc_a5, softmax(logits_r_a5)[1], softmax(logits_c_a5)[1]])
    grad_r_a5 = np.zeros(2)
    grad_c_a5 = np.zeros(2)
    for k_a5 in range(2):
        bump_a5 = np.zeros(2); bump_a5[k_a5] = eps_fd_a5
        grad_r_a5[k_a5] = (value_for_logits_a5(logits_r_a5 + bump_a5, logits_c_a5)[0] - vr_a5) / eps_fd_a5
        grad_c_a5[k_a5] = (value_for_logits_a5(logits_r_a5, logits_c_a5 + bump_a5)[1] - vc_a5) / eps_fd_a5
    logits_r_a5 += eta_a5 * grad_r_a5
    logits_c_a5 += eta_a5 * grad_c_a5
values_a5 = np.array(values_a5)
print("final policies:", np.round(softmax(logits_r_a5), 3), np.round(softmax(logits_c_a5), 3))
```
▶ What you'll see: probability mass shifts toward each agent's individually attractive action.

```python
assert values_a5.shape == (35, 4)
assert softmax(logits_r_a5)[1] > 0.5
assert softmax(logits_c_a5)[1] > 0.5
```

```python
plt.figure(figsize=(5, 3))
plt.plot(values_a5[:, 2], label="row prob action 1")
plt.plot(values_a5[:, 3], label="column prob action 1")
plt.title("Advanced 5: policy probabilities under ascent")
plt.xlabel("gradient step")
plt.ylabel("probability")
plt.ylim(0, 1)
plt.legend()
plt.show()
```
▶ What you'll see: both curves move upward as the policies place more probability on action 1.

👀 Takeaway: policy optimization moves distributions, and in MARL each distribution changes the other agent's learning landscape.
