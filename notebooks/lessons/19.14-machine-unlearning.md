# 19.14 — Machine Unlearning

Machine unlearning asks a precise question: after a training example must be forgotten, can we remove its influence from the model and prove that the result behaves like a model retrained without it? In this lesson, we build that idea from scratch with tiny NumPy models, compare exact retraining to cheaper approximations, and inspect the bookkeeping needed to make an unlearning claim trustworthy.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build machine unlearning one idea at a time. Run each cell in order and read the printed intermediate values — every deletion, retraining baseline, shard update, influence approximation, and certificate check is small enough to audit by hand. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, linear algebra, and synthetic data for unlearning demos.
import matplotlib.pyplot as plt  # compact visual checks for deletion and certification.
np.random.seed(0)  # reproducibility for all toy examples.
```

### 1. What must be removed: data influence, not just the stored row

Unlearning begins with a subtle distinction. Deleting a row from storage is not enough if the row has already pushed the fitted parameters. We start with a one-dimensional linear model so the effect is visible: each point contributes a small pull toward a slope, and a suspicious point can pull the fitted line away from the clean pattern.

```python
x_w = np.array([-2., -1., 0., 1., 2., 3.])  # one feature per training example.
y_w = np.array([-4.1, -1.9, 0.1, 2.2, 4.0, 12.0])  # last point is an unusually large target.
forget_w = 5  # index of the point that receives the deletion request.
print("training pairs:", list(zip(x_w, y_w)))  # inspect raw data before fitting.
print("forget request:", (x_w[forget_w], y_w[forget_w]))  # the row to remove from influence.
```
▶ What you'll see: five points follow roughly y≈2x, while the last point at x=3, y=12 is much higher.

```python
def fit_slope_w(x, y, lam=0.1):  # ridge slope with no intercept, written from the normal equation.
    return float(np.sum(x * y) / (np.sum(x * x) + lam))  # theta = (X^T y)/(X^T X + lambda).

theta_full_w = fit_slope_w(x_w, y_w)  # fit before unlearning.
theta_deleted_storage_w = theta_full_w  # deleting storage alone leaves already-trained parameters unchanged.
print("full-data slope:", round(theta_full_w, 3))  # parameter still contains every point's influence.
print("after storage deletion only:", round(theta_deleted_storage_w, 3))  # same number, not unlearned.
assert round(theta_full_w, 3) == 2.948  # concrete lesson number.
```
▶ What you'll see: the fitted slope is 2.948, much steeper than the clean y≈2x trend.

```python
plt.figure(figsize=(4.6, 3.2))  # visualize the influence of the point to forget.
plt.scatter(x_w[:-1], y_w[:-1], color="teal", label="kept points")  # clean-looking points.
plt.scatter([x_w[forget_w]], [y_w[forget_w]], color="crimson", label="forget point")  # requested deletion.
grid_w = np.linspace(-2.2, 3.2, 80)  # x values for drawing the learned line.
plt.plot(grid_w, theta_full_w * grid_w, color="crimson", label="fit before unlearning")  # line still influenced by all data.
plt.axhline(0, color="gray", linewidth=0.5)  # reference axis.
plt.title("1: deleting storage is not deleting influence")  # title the diagnostic plot.
plt.xlabel("x"); plt.ylabel("y"); plt.legend(); plt.show()  # display labels and legend.
```
▶ What you'll see: the red line is pulled upward by the red point; removing the row from a table would not change that line.

*Why it's done this way:* A trained parameter is a downstream mixture of all training gradients. The deletion target must therefore be the point's effect on fitted artifacts, not merely the original record. The simple ridge slope exposes the math: the numerator $\sum x_i y_i$ and denominator $\sum x_i^2+\lambda$ already contain the forgotten point.

### 2. Exact retraining is the gold-standard unlearning baseline

The cleanest way to unlearn one point is to rebuild the model from the remaining data. This exact retraining baseline is expensive for large systems, but it gives us the reference answer that every faster method must approximate or certify against.

```python
keep_mask_w = np.ones(len(x_w), dtype=bool)  # start with every row included.
keep_mask_w[forget_w] = False  # remove the requested point from the training set.
x_keep_w = x_w[keep_mask_w]  # features after deletion.
y_keep_w = y_w[keep_mask_w]  # targets after deletion.
print("kept pairs:", list(zip(x_keep_w, y_keep_w)))  # inspect the retraining data.
```
▶ What you'll see: only the five clean-looking points remain.

```python
theta_retrain_w = fit_slope_w(x_keep_w, y_keep_w)  # exact unlearning by fitting from scratch on kept data.
delta_exact_w = theta_retrain_w - theta_full_w  # how far the parameter moves after real removal.
print("exact retrained slope:", round(theta_retrain_w, 3))  # gold-standard forgotten model.
print("exact parameter change:", round(delta_exact_w, 3))  # removal effect.
assert round(theta_retrain_w, 3) == 2.010  # concrete lesson number.
assert round(delta_exact_w, 3) == -0.938  # concrete lesson number.
```
▶ What you'll see: exact retraining lowers the slope from 2.948 to 2.010, almost back to the clean trend.

```python
plt.figure(figsize=(4.8, 3.2))  # compare full and retrained models.
plt.scatter(x_keep_w, y_keep_w, color="teal", label="kept points")  # retained data.
plt.scatter([x_w[forget_w]], [y_w[forget_w]], color="crimson", label="forgotten point")  # deleted point for context.
plt.plot(grid_w, theta_full_w * grid_w, color="crimson", label="before")  # full-data line.
plt.plot(grid_w, theta_retrain_w * grid_w, color="seagreen", label="exact retrain")  # gold-standard unlearned line.
plt.title("2: exact unlearning = retrain without the point")  # title the comparison.
plt.xlabel("x"); plt.ylabel("prediction"); plt.legend(); plt.show()  # display the plot.
```
▶ What you'll see: the green line follows the kept points, while the red line remembers the deleted outlier.

*Why it's done this way:* Exact retraining defines the target distribution of a valid unlearned model. If a shortcut does not match the retrained model closely enough on parameters, predictions, or an agreed audit metric, the unlearning claim is only a hope.

### 3. SISA sharding limits the blast radius of deletion

SISA unlearning — Sharded, Isolated, Sliced, Aggregated training — reduces deletion cost by splitting data into independent shards. A deletion only forces retraining of the shard that contained the point; the other shard models can be reused. We implement a small sharded ridge ensemble and compare it to a full exact retrain.

```python
shards_w = [np.array([0, 1, 2]), np.array([3, 4, 5])]  # fixed provenance: which rows trained each shard.
shard_thetas_w = np.array([fit_slope_w(x_w[idx], y_w[idx]) for idx in shards_w])  # fit one model per shard.
ensemble_theta_w = float(np.mean(shard_thetas_w))  # aggregate predictions by averaging shard slopes.
print("shard slopes before deletion:", np.round(shard_thetas_w, 3))  # inspect local models.
print("ensemble slope before deletion:", round(ensemble_theta_w, 3))  # average model.
assert np.allclose(np.round(shard_thetas_w, 3), np.array([1.980, 3.277]))  # concrete shard numbers.
```
▶ What you'll see: shard 1 has a much steeper slope because it contains the point to forget.

```python
shard_to_update_w = [k for k, idx in enumerate(shards_w) if forget_w in idx][0]  # locate the affected shard.
updated_shards_w = [idx[idx != forget_w] if k == shard_to_update_w else idx for k, idx in enumerate(shards_w)]  # delete only there.
shard_thetas_unlearn_w = np.array([fit_slope_w(x_w[idx], y_w[idx]) for idx in updated_shards_w])  # retrain affected shard; reuse others conceptually.
ensemble_unlearn_w = float(np.mean(shard_thetas_unlearn_w))  # aggregate updated shard ensemble.
print("affected shard:", shard_to_update_w)  # provenance tells what must be rebuilt.
print("shard slopes after deletion:", np.round(shard_thetas_unlearn_w, 3))  # updated local models.
print("SISA ensemble slope:", round(ensemble_unlearn_w, 3))  # sharded unlearned model.
assert round(ensemble_unlearn_w, 3) == 1.990  # concrete lesson number.
```
▶ What you'll see: only the second shard changes, dropping the ensemble slope toward the exact retrain.

```python
plt.figure(figsize=(4.8, 3.2))  # compare SISA with exact retraining.
plt.bar(["full", "SISA", "exact"], [theta_full_w, ensemble_unlearn_w, theta_retrain_w], color=["crimson", "orange", "seagreen"])  # parameter comparison.
plt.ylabel("slope")  # label parameter scale.
plt.title("3: SISA updates one shard instead of all data")  # title the plot.
plt.show()  # display bars.
```
▶ What you'll see: SISA is much closer to exact retraining than the full model, while avoiding a complete rebuild.

*Why it's done this way:* Sharding trades statistical efficiency for operational deletability. Each shard has an explicit lineage boundary, so the deletion request has a small retraining target. The average of shard predictions may not equal one global retrain exactly, but it gives a practical mechanism whose cost is proportional to the affected shard rather than the whole dataset.

### 4. Influence-based approximate unlearning uses curvature to take one Newton-like step

Exact retraining can be too costly, so influence methods estimate how parameters would move after removal. For a regularized empirical risk, the Hessian $H$ measures local curvature and the removed point gradient measures the point's pressure on the solution. A first-order deletion step subtracts the point's stored influence from the full model.

```python
n_w = len(x_w)  # number of original training examples.
lam_w = 0.1  # same ridge strength as before.
H_w = float(np.mean(x_w ** 2) + lam_w)  # Hessian of 0.5*mean squared loss + 0.5*lambda*theta^2 for 1-D ridge.
point_grad_w = float((theta_full_w * x_w[forget_w] - y_w[forget_w]) * x_w[forget_w])  # data gradient from the point to forget.
print("Hessian:", round(H_w, 3))  # curvature denominator.
print("forgotten point gradient:", round(point_grad_w, 3))  # point's local pressure at theta_full.
assert round(H_w, 3) == 3.267  # concrete lesson number.
assert round(point_grad_w, 3) == -9.471  # concrete lesson number.
```
▶ What you'll see: the forgotten point has a large negative gradient, meaning it was pulling the slope upward.

```python
theta_influence_w = theta_full_w + point_grad_w / (n_w * H_w)  # first-order removal approximation for this average-loss setup.
approx_error_w = abs(theta_influence_w - theta_retrain_w)  # compare against exact retraining.
print("influence unlearned slope:", round(theta_influence_w, 3))  # cheap approximate deletion.
print("absolute error vs exact:", round(approx_error_w, 3))  # certification candidate.
assert round(theta_influence_w, 3) == 2.464  # concrete lesson number.
```
▶ What you'll see: the influence step moves in the correct direction but does not reach the exact retrained slope.

```python
plt.figure(figsize=(4.8, 3.2))  # visualize approximate versus exact unlearning.
plt.plot(grid_w, theta_full_w * grid_w, color="crimson", label="full")  # before deletion.
plt.plot(grid_w, theta_influence_w * grid_w, color="orange", label="influence approx")  # shortcut.
plt.plot(grid_w, theta_retrain_w * grid_w, color="seagreen", label="exact retrain")  # gold standard.
plt.scatter(x_keep_w, y_keep_w, color="teal", s=24)  # kept points.
plt.title("4: approximate unlearning moves toward retraining")  # title the plot.
plt.xlabel("x"); plt.ylabel("prediction"); plt.legend(); plt.show()  # display comparison.
```
▶ What you'll see: the orange line lands between the still-tainted full model and the green retrained model.

*Why it's done this way:* The Hessian rescales the deletion gradient by how stiff the loss surface is. A large gradient in a flat direction causes a big parameter change; the same gradient in a high-curvature direction causes a small change. Because this is a local first-order approximation, it is best for small deletions near a well-behaved optimum.

### 5. Certification compares the unlearned artifact with a declared tolerance

A responsible unlearning system needs an audit output: what was updated, what was reused, and how close the result is to the exact retraining baseline or another agreed certificate. Here the certificate is a simple prediction-distance bound on a probe grid.

```python
probe_w = np.array([-2., -1., 0., 1., 2., 3.])  # audit inputs used to compare behavior.
pred_exact_w = theta_retrain_w * probe_w  # gold-standard predictions.
pred_sisa_w = ensemble_unlearn_w * probe_w  # SISA predictions.
pred_infl_w = theta_influence_w * probe_w  # influence predictions.
max_sisa_gap_w = float(np.max(np.abs(pred_sisa_w - pred_exact_w)))  # worst prediction discrepancy.
max_infl_gap_w = float(np.max(np.abs(pred_infl_w - pred_exact_w)))  # worst prediction discrepancy.
print("max SISA gap:", round(max_sisa_gap_w, 3))  # audit number for SISA.
print("max influence gap:", round(max_infl_gap_w, 3))  # audit number for approximation.
assert round(max_sisa_gap_w, 3) == 0.059  # concrete lesson number.
assert round(max_infl_gap_w, 3) == 1.364  # concrete lesson number.
```
▶ What you'll see: SISA is closer to exact retraining on this probe grid than the first-order influence step.

```python
tolerance_w = 1.0  # declared certificate tolerance for maximum prediction gap.
cert_sisa_w = max_sisa_gap_w <= tolerance_w  # pass/fail certificate for SISA.
cert_infl_w = max_infl_gap_w <= tolerance_w  # pass/fail certificate for influence approximation.
print("tolerance:", tolerance_w)  # inspect the policy threshold.
print("SISA certified?", cert_sisa_w)  # should pass under this tolerance.
print("influence certified?", cert_infl_w)  # should fail under this tolerance.
assert cert_sisa_w and not cert_infl_w  # concrete audit conclusion.
```
▶ What you'll see: the SISA artifact passes a 1.0 max-gap certificate, while the influence shortcut fails.

```python
plt.figure(figsize=(5, 3))  # plot certificate gaps.
plt.bar(["SISA", "influence"], [max_sisa_gap_w, max_infl_gap_w], color=["seagreen", "orange"])  # compare audit gaps.
plt.axhline(tolerance_w, color="crimson", linestyle="--", label="tolerance")  # show pass/fail line.
plt.ylabel("max |prediction - exact retrain|")  # label certificate metric.
plt.title("5: certification is a measurable claim")  # title the audit plot.
plt.legend(); plt.show()  # display with legend.
```
▶ What you'll see: bars below the dashed line satisfy the declared certificate; bars above it need retraining or a better approximation.

*Why it's done this way:* A certificate turns "we forgot it" into a falsifiable statement. The metric and tolerance must be chosen before deployment, and lineage must say which shards, caches, embeddings, and reports were refreshed. Otherwise an average score can hide a lingering influence path.

## 🟢 Basics (warm-up)

### Basic 1 — Fit a tiny model before any deletion

**Goal.** Fit a one-parameter ridge model, because unlearning has to remove influence from parameters, not just rows. We build it in 2 steps.

```python
x_b1 = np.array([-2., -1., 0., 1., 2., 3.])  # create one-feature training inputs.
y_b1 = np.array([-4.1, -1.9, 0.1, 2.2, 4.0, 12.0])  # create targets with one high-influence last point.
lam_b1 = 0.1  # set ridge regularization strength.
print("data shape:", x_b1.shape, "lambda:", lam_b1)  # inspect the fitting ingredients.
```
▶ What you'll see: a six-point toy regression problem with one regularization knob.

```python
theta_b1 = float(np.sum(x_b1 * y_b1) / (np.sum(x_b1 ** 2) + lam_b1))  # solve the 1-D ridge normal equation.
print("full-data slope:", round(theta_b1, 3))  # inspect the parameter before unlearning.
assert round(theta_b1, 3) == 2.948  # verify the canonical full-data slope.
plt.figure(figsize=(4, 3))  # create a compact scatter-and-line plot.
plt.scatter(x_b1, y_b1, color="teal")  # draw all training points.
grid_b1 = np.linspace(-2.2, 3.2, 80)  # create x values for the learned line.
plt.plot(grid_b1, theta_b1 * grid_b1, color="crimson")  # draw the fitted model.
plt.title("Basic 1: full model before unlearning")  # title the plot.
plt.xlabel("x"); plt.ylabel("y"); plt.show()  # display the diagnostic plot.
```
▶ What you'll see: the fitted line is steep because the rightmost point has strong leverage.

👀 Takeaway: unlearning starts from a fitted artifact whose parameters already mix all training examples.

### Basic 2 — Identify the forgotten point's contribution

**Goal.** Compute the numerator contribution xᵢyᵢ of each point, because this shows exactly how a row enters a closed-form fit. We build it in 2 steps.

```python
x_b2 = np.array([-2., -1., 0., 1., 2., 3.])  # recreate inputs for this local example.
y_b2 = np.array([-4.1, -1.9, 0.1, 2.2, 4.0, 12.0])  # recreate targets.
forget_b2 = 5  # choose the point to forget.
contrib_b2 = x_b2 * y_b2  # compute each point's contribution to X^T y.
print("x*y contributions:", np.round(contrib_b2, 2))  # inspect parameter numerator pieces.
```
▶ What you'll see: the forgotten point contributes 36.0, the largest numerator component.

```python
share_b2 = abs(contrib_b2[forget_b2]) / np.sum(np.abs(contrib_b2))  # compute its share of absolute numerator mass.
print("forgotten contribution share:", round(share_b2, 3))  # inspect concentration of influence.
assert round(share_b2, 3) == 0.639  # verify the contribution-share number.
plt.figure(figsize=(4, 3))  # create a contribution bar chart.
plt.bar(np.arange(len(contrib_b2)), contrib_b2, color=["teal"] * 5 + ["crimson"])  # highlight the forgotten point.
plt.title("Basic 2: numerator contribution by row")  # title the plot.
plt.xlabel("row index"); plt.ylabel("x_i y_i"); plt.show()  # display the chart.
```
▶ What you'll see: the red bar dominates the fitted slope's numerator.

👀 Takeaway: closed-form models make influence visible as concrete algebraic contributions.

### Basic 3 — Delete storage without changing the model

**Goal.** Show the deletion pitfall, because removing a record from a table does not alter already-trained parameters. We build it in 2 steps.

```python
x_b3 = np.array([-2., -1., 0., 1., 2., 3.])  # full inputs.
y_b3 = np.array([-4.1, -1.9, 0.1, 2.2, 4.0, 12.0])  # full targets.
theta_before_b3 = float(np.sum(x_b3 * y_b3) / (np.sum(x_b3 ** 2) + 0.1))  # fit before deletion.
x_storage_deleted_b3 = np.delete(x_b3, 5)  # remove row from storage.
y_storage_deleted_b3 = np.delete(y_b3, 5)  # remove matching target from storage.
print("rows in storage after deletion:", len(x_storage_deleted_b3))  # inspect data storage state.
```
▶ What you'll see: the stored dataset now has five rows.

```python
theta_after_storage_only_b3 = theta_before_b3  # the trained parameter is unchanged unless the model is updated.
print("parameter before:", round(theta_before_b3, 3))  # inspect original parameter.
print("parameter after storage-only deletion:", round(theta_after_storage_only_b3, 3))  # inspect unchanged artifact.
assert theta_after_storage_only_b3 == theta_before_b3  # verify no model unlearning happened.
plt.figure(figsize=(4, 3))  # create a before-after parameter plot.
plt.bar(["before", "storage deleted"], [theta_before_b3, theta_after_storage_only_b3], color=["crimson", "gray"])  # compare parameters.
plt.title("Basic 3: storage deletion is not unlearning")  # title the plot.
plt.ylabel("slope"); plt.show()  # display the chart.
```
▶ What you'll see: both bars are identical because no parameter update occurred.

👀 Takeaway: unlearning must update every affected artifact, not just the raw data store.

### Basic 4 — Exact retraining removes the row's influence

**Goal.** Refit on the kept rows, because exact retraining is the gold-standard unlearning reference. We build it in 3 steps.

```python
x_b4 = np.array([-2., -1., 0., 1., 2., 3.])  # full inputs.
y_b4 = np.array([-4.1, -1.9, 0.1, 2.2, 4.0, 12.0])  # full targets.
mask_b4 = np.ones(len(x_b4), dtype=bool)  # begin with every row kept.
mask_b4[5] = False  # mark the requested row as removed.
print("kept row indices:", np.where(mask_b4)[0])  # inspect retraining data lineage.
```
▶ What you'll see: row 5 is absent from the retraining set.

```python
theta_full_b4 = float(np.sum(x_b4 * y_b4) / (np.sum(x_b4 ** 2) + 0.1))  # full-data fit.
theta_exact_b4 = float(np.sum(x_b4[mask_b4] * y_b4[mask_b4]) / (np.sum(x_b4[mask_b4] ** 2) + 0.1))  # exact retrain.
print("full:", round(theta_full_b4, 3), "exact unlearned:", round(theta_exact_b4, 3))  # inspect both slopes.
assert round(theta_exact_b4, 3) == 2.010  # verify exact retraining number.
```

```python
plt.figure(figsize=(4, 3))  # create a comparison chart.
plt.bar(["full", "exact retrain"], [theta_full_b4, theta_exact_b4], color=["crimson", "seagreen"])  # compare parameter states.
plt.title("Basic 4: exact retraining baseline")  # title the plot.
plt.ylabel("slope"); plt.show()  # display the comparison.
```
▶ What you'll see: exact retraining drops the slope toward the clean pattern.

👀 Takeaway: exact retraining is expensive, but it tells us what successful unlearning should match.

### Basic 6 — Build a two-shard SISA ensemble

**Goal.** Train independent shard models, because SISA limits which submodel must be rebuilt after deletion. We build it in 2 steps.

```python
x_b6 = np.array([-2., -1., 0., 1., 2., 3.])  # full inputs.
y_b6 = np.array([-4.1, -1.9, 0.1, 2.2, 4.0, 12.0])  # full targets.
shards_b6 = [np.array([0, 1, 2]), np.array([3, 4, 5])]  # record row lineage for each shard.
print("shards:", shards_b6)  # inspect provenance mapping.
```
▶ What you'll see: each row belongs to exactly one shard.

```python
slopes_b6 = np.array([float(np.sum(x_b6[idx] * y_b6[idx]) / (np.sum(x_b6[idx] ** 2) + 0.1)) for idx in shards_b6])  # fit ridge slope per shard.
ensemble_b6 = float(np.mean(slopes_b6))  # aggregate shard predictions by averaging slopes.
print("shard slopes:", np.round(slopes_b6, 3), "ensemble:", round(ensemble_b6, 3))  # inspect the SISA model.
assert np.allclose(np.round(slopes_b6, 3), np.array([1.980, 3.277]))  # verify shard slopes.
plt.figure(figsize=(4, 3))  # create a shard bar chart.
plt.bar(["shard 0", "shard 1", "ensemble"], [slopes_b6[0], slopes_b6[1], ensemble_b6], color=["teal", "crimson", "gray"])  # compare local models.
plt.title("Basic 6: SISA shard models")  # title the plot.
plt.ylabel("slope"); plt.show()  # display bars.
```
▶ What you'll see: the shard containing the forgotten outlier has the steeper local model.

👀 Takeaway: SISA stores enough lineage to know which model fragment a deletion touches.

### Basic 7 — Retrain only the affected shard

**Goal.** Update the shard containing the forgotten point, because untouched shards can be reused. We build it in 2 steps.

```python
x_b7 = np.array([-2., -1., 0., 1., 2., 3.])  # full inputs.

```

```python

assert round(float(errors_a3[1]), 3) == 0.029  # verify bad-curvature error for this toy.
```

```python

plt.ylabel("absolute gap to exact"); plt.show()  # display bars.
```
▶ What you'll see: changing the Hessian changes how far the deletion step moves.

👀 Takeaway: influence methods are only as reliable as their local curvature estimate.

### Advanced 4 — Unlearn multiple artifacts from a lineage graph

**Goal.** Use a small lineage matrix, because a deletion request must discover every artifact that consumed the point. We build it in 4 steps.


