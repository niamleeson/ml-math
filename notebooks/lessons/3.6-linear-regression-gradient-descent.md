# 3.6 — Linear Regression via Gradient Descent

Linear regression via gradient descent turns the ERM promise into an explicit learning procedure: choose a linear rule, measure its average squared error, compute the downhill direction, and take repeated steps until the coefficients settle near the ordinary least squares solution. The notebook keeps the raw fit, the cost or stability term, and the validation comparison visible so the optimization never gets confused with generalization.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build linear regression with gradient descent one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including the gradient, is derived and shown. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, matrix multiplication, and numerical checks.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for toy data and stochastic variants.
```

### 1. The linear model and the intercept column

Linear regression starts with a promise about shape: predictions are a weighted sum of input features. For one input feature, that rule is \(\hat y=b+w x\). In matrix form we write \(\hat y=X\beta\), where the first column of \(X\) is all ones so the intercept \(b\) is learned by the same multiplication as the slope \(w\). This is why gradient descent updates a vector of coefficients instead of treating the intercept as a separate trick.

```python
x_w = np.array([0., 1., 2., 3., 4.])  # one input feature.
y_w = np.array([1.1, 2.0, 2.9, 4.2, 5.1])  # nearly linear targets.
X_w = np.c_[np.ones_like(x_w), x_w]  # design matrix: [1, x].
beta_w = np.array([0.0, 0.0])  # start with intercept 0 and slope 0.
print("X shape:", X_w.shape)
print("first rows:\n", X_w[:3])
```
▶ What you'll see: a 5×2 design matrix whose first column is 1, so the intercept is just another coefficient.

```python
pred0_w = X_w @ beta_w  # current predictions from beta = [0, 0].
print("initial predictions:", pred0_w)
print("targets:", y_w)
```
▶ What you'll see: the zero model predicts 0 for every point, which leaves large positive residuals.

```python
plt.figure(figsize=(4.4, 3))
plt.scatter(x_w, y_w, color="black", label="data")
plt.plot(x_w, pred0_w, color="crimson", label="initial line")
plt.xlabel("x"); plt.ylabel("y")
plt.title("1: a linear model before learning")
plt.legend(); plt.show(); plt.close()
```
▶ What you'll see: the starting line is flat at zero while the data rises almost linearly.

*Why it's done this way:* putting the intercept into `X` makes the model \(X\beta\) and the gradient \(X^\top( X\beta-y)\) have matching shapes. The ones column says “move the whole line up or down,” while the `x` column says “tilt the line.”

### 2. Empirical risk as average squared error

The learning target is not one point; it is the average loss over the sample. For squared error, each residual \(\hat y_i-y_i\) is squared, then the losses are averaged: \(J(\beta)=\frac{1}{m}\sum_i (\hat y_i-y_i)^2\). Squaring makes misses nonnegative, punishes large misses more than small misses, and creates a smooth surface that gradient descent can follow.

```python
resid0_w = pred0_w - y_w  # prediction minus target.
losses0_w = resid0_w ** 2  # one squared loss per example.
print("residuals:", np.round(resid0_w, 3))
print("per-example losses:", np.round(losses0_w, 3))
```
▶ What you'll see: every residual is negative because the zero line under-predicts every target.

```python
risk0_w = float(np.mean(losses0_w))  # empirical risk for beta = [0, 0].
print("mean squared error:", round(risk0_w, 3))
assert round(risk0_w, 3) == 11.454
```
▶ What you'll see: the starting risk is 11.454, the single scalar gradient descent tries to reduce.

```python
plt.figure(figsize=(4.4, 3))
plt.bar(range(len(losses0_w)), losses0_w, color="steelblue")
plt.axhline(risk0_w, color="black", linestyle="--", label="average")
plt.xlabel("example"); plt.ylabel("squared loss")
plt.title("2: empirical risk averages losses")
plt.legend(); plt.show(); plt.close()
```
▶ What you'll see: later points have larger losses because their targets are farther from the zero line.

*Why it's done this way:* ERM needs one objective value to compare models. Averaging keeps the scale comparable when the dataset size changes, and squaring gives a differentiable penalty whose slope is larger when a prediction is badly wrong.

### 3. Deriving the gradient from residuals

The gradient is the vector of partial derivatives of the MSE. With \(r=X\beta-y\), the objective is \(J=\frac{1}{m}r^\top r\). Differentiating gives \(\nabla J(\beta)=\frac{2}{m}X^\top(X\beta-y)\). The matrix product is not magic: each feature column takes a weighted sum of residuals, so a feature receives a large gradient when it consistently appears in examples the model misses.

```python
m_w = len(y_w)  # number of training examples.
grad0_w = (2 / m_w) * X_w.T @ resid0_w  # gradient at beta = [0, 0].
print("gradient at start:", np.round(grad0_w, 3))
assert np.allclose(np.round(grad0_w, 3), [-6.120, -16.320])
```
▶ What you'll see: both gradient components are negative, so subtracting the gradient will increase the intercept and slope.

```python
intercept_grad_manual_w = (2 / m_w) * np.sum(resid0_w)  # ones column dot residuals.
slope_grad_manual_w = (2 / m_w) * np.sum(x_w * resid0_w)  # x column dot residuals.
print("manual intercept gradient:", round(intercept_grad_manual_w, 3))
print("manual slope gradient:", round(slope_grad_manual_w, 3))
```
▶ What you'll see: the manual sums match the matrix gradient exactly.

```python
plt.figure(figsize=(4.4, 3))
plt.bar(["intercept", "slope"], grad0_w, color=["darkorange", "purple"])
plt.axhline(0, color="black", linewidth=0.8)
plt.title("3: gradient components")
plt.ylabel("partial derivative")
plt.show(); plt.close()
```
▶ What you'll see: the slope derivative has larger magnitude because errors grow with `x`.

*Why it's done this way:* the gradient points uphill, toward increasing loss. Gradient descent subtracts it. Since the start under-predicts, the residuals are negative, making the gradient negative; subtracting a negative number pushes the line upward and steeper.

### 4. Gradient descent as repeated downhill steps

The update rule is \(\beta_{t+1}=\beta_t-\eta\frac{2}{m}X^\top(X\beta_t-y)\). The learning rate \(\eta\) decides how much of the downhill direction to take. Too small learns slowly; too large can overshoot the bottom. On a squared-error surface for linear regression, a stable learning rate makes the MSE decrease smoothly toward the OLS solution.

```python
eta_w = 0.03  # learning rate for this small feature scale.
beta_gd_w = np.zeros(2)  # reset coefficients.
history_w = []  # store MSE values.
for step_w in range(200):
    pred_w = X_w @ beta_gd_w
    resid_w = pred_w - y_w
    history_w.append(float(np.mean(resid_w ** 2)))
    grad_w = (2 / m_w) * X_w.T @ resid_w
    beta_gd_w = beta_gd_w - eta_w * grad_w
print("learned beta:", np.round(beta_gd_w, 3))
print("loss start -> end:", round(history_w[0], 3), "->", round(history_w[-1], 4))
assert history_w[-1] < history_w[0]
```
▶ What you'll see: the coefficients become a positive intercept and slope, and the loss drops sharply.

```python
plt.figure(figsize=(4.6, 3))
plt.plot(history_w, color="seagreen")
plt.xlabel("step"); plt.ylabel("MSE")
plt.title("4: gradient descent lowers loss")
plt.show(); plt.close()
```
▶ What you'll see: a fast decrease followed by a flattening curve as the parameters approach the bottom.

```python
fit_w = X_w @ beta_gd_w
plt.figure(figsize=(4.6, 3))
plt.scatter(x_w, y_w, color="black", label="data")
plt.plot(x_w, fit_w, color="seagreen", label="GD line")
plt.xlabel("x"); plt.ylabel("y")
plt.title("4: fitted line after descent")
plt.legend(); plt.show(); plt.close()
```
▶ What you'll see: the learned line runs through the middle of the points instead of chasing any one point exactly.

*Why it's done this way:* every step recomputes the gradient at the current coefficients because the best downhill direction changes as the line moves. The learning rate is the trust knob: it converts derivative information into an actual parameter movement.

### 5. Connecting gradient descent to the OLS solution

Linear regression with squared loss has a closed-form minimizer, \(\beta=(X^\top X)^{-1}X^\top y\), when the inverse exists. Gradient descent is an iterative route to the same bottom, useful when the closed form is expensive or when later models no longer have a simple solution. Here we compare the two so the destination is visible.

```python
beta_ols_w = np.linalg.solve(X_w.T @ X_w, X_w.T @ y_w)  # normal-equation solution.
print("OLS beta:", np.round(beta_ols_w, 3))
print("GD beta:", np.round(beta_gd_w, 3))
assert np.allclose(beta_ols_w, [1.02, 1.02])
```
▶ What you'll see: OLS gives intercept 1.02 and slope 1.02, while gradient descent is very close after 200 steps.

```python
mse_ols_w = float(np.mean((X_w @ beta_ols_w - y_w) ** 2))
mse_gd_w = float(np.mean((X_w @ beta_gd_w - y_w) ** 2))
print("OLS MSE:", round(mse_ols_w, 4), "GD MSE:", round(mse_gd_w, 4))
assert mse_gd_w - mse_ols_w < 0.01
```
▶ What you'll see: both methods reach nearly the same training error.

```python
plt.figure(figsize=(4.6, 3))
plt.scatter(x_w, y_w, color="black", label="data")
plt.plot(x_w, X_w @ beta_ols_w, color="black", linestyle="--", label="OLS")
plt.plot(x_w, X_w @ beta_gd_w, color="seagreen", label="GD")
plt.xlabel("x"); plt.ylabel("y")
plt.title("5: GD approaches OLS")
plt.legend(); plt.show(); plt.close()
```
▶ What you'll see: the two lines are almost on top of each other.

*Why it's done this way:* OLS proves what the optimum is for this convex quadratic, while gradient descent shows the optimization mechanism used throughout ML: local slope information, repeated until improvement becomes small.

### 6. The score used for model choice includes cost and stability

The lesson's selection logic is broader than raw training loss. A tiny worked score averages per-example losses, adds a cost term, compares a tempting flexible alternative, and asks whether a stabilizing choice changes the decision. This keeps generalization in view: the best-looking training fragment is not automatically the best model to carry forward.

```python
losses_score_w = np.array([0.246, 0.096, 0.471])  # verified toy losses from the lesson prose.
raw_risk_w = float(np.mean(losses_score_w))
cost_w = 0.050
score_w = raw_risk_w + cost_w
print("raw risk:", round(raw_risk_w, 3))
print("decision score:", round(score_w, 3))
assert round(raw_risk_w, 3) == 0.271 and round(score_w, 3) == 0.321
```
▶ What you'll see: the training average is 0.271, but the selection score is 0.321 after cost.

```python
flex_score_w = 0.361
gap_w = flex_score_w - score_w
relative_gap_w = gap_w / flex_score_w
stable_w = 0.80 * score_w
print("gap:", round(gap_w, 3), "relative gap:", round(relative_gap_w, 3))
print("stabilized score:", round(stable_w, 3))
assert round(gap_w, 3) == 0.040 and round(relative_gap_w, 3) == 0.111 and round(stable_w, 3) == 0.257
```
▶ What you'll see: the stabilized score is lower than both the baseline score and the flexible alternative.

```python
labels_w = ["baseline", "flexible", "stabilized"]
scores_w = np.array([score_w, flex_score_w, stable_w])
print("winner:", labels_w[int(np.argmin(scores_w))])
plt.figure(figsize=(4.8, 3))
plt.bar(labels_w, scores_w, color=["steelblue", "darkorange", "seagreen"])
plt.ylabel("decision score, lower is better")
plt.title("6: compare full scores, not raw fit only")
plt.show(); plt.close()
```
▶ What you'll see: the stabilized bar is the lowest score in the final comparison.

*Why it's done this way:* optimization lowers the specified objective, but model selection asks whether the improvement survives costs, validation uncertainty, and stability constraints. The arithmetic makes the comparison scale explicit before declaring a winner.

## 🟢 Basics (warm-up)

### Basic 1 — Make a design matrix

**Goal.** Add an intercept column to one feature, because \(\hat y=X\beta\) learns the intercept and slope with one matrix multiplication. We build it in 2 steps.

```python
x_b1 = np.array([0., 1., 2., 3.])  # define one input feature.
X_b1 = np.c_[np.ones_like(x_b1), x_b1]  # prepend a column of ones for the intercept.
print("X_b1:\n", X_b1)
```
▶ What you'll see: each row is `[1, x]`, so coefficient 0 is the intercept and coefficient 1 is the slope.

```python
beta_b1 = np.array([2.0, 0.5])  # intercept 2, slope 0.5.
yhat_b1 = X_b1 @ beta_b1  # compute predictions for all rows.
print("predictions:", yhat_b1)
assert np.allclose(yhat_b1, [2.0, 2.5, 3.0, 3.5])
plt.figure(figsize=(4, 3)); plt.plot(x_b1, yhat_b1, marker="o", color="teal")
plt.title("Basic 1: y = 2 + 0.5x"); plt.xlabel("x"); plt.ylabel("prediction")
plt.show(); plt.close()
```
▶ What you'll see: a straight line whose value at x=0 is the intercept.

👀 Takeaway: the ones column turns the intercept into an ordinary coefficient.

### Basic 2 — Compute residuals

**Goal.** Measure prediction errors, because gradient descent learns from \(\hat y-y\). We build it in 2 steps.

```python
x_b2 = np.array([0., 1., 2.])  # define feature values.
y_b2 = np.array([1., 3., 5.])  # define targets.
X_b2 = np.c_[np.ones_like(x_b2), x_b2]  # make the design matrix.
beta_b2 = np.array([0.5, 1.5])  # choose a not-quite-right line.
print("beta:", beta_b2)
```

```python
pred_b2 = X_b2 @ beta_b2  # predict each example.
resid_b2 = pred_b2 - y_b2  # compute signed residuals.
print("predictions:", pred_b2)
print("residuals:", resid_b2)
assert np.allclose(resid_b2, [-0.5, -1.0, -1.5])
plt.figure(figsize=(4, 3)); plt.bar(range(3), resid_b2, color="crimson")
plt.axhline(0, color="black", linewidth=0.8); plt.title("Basic 2: signed residuals")
plt.show(); plt.close()
```
▶ What you'll see: all residuals are negative, meaning this line under-predicts each point.

👀 Takeaway: residual signs tell which direction predictions need to move.

### Basic 3 — Average squared errors

**Goal.** Convert residuals into MSE, because empirical risk averages per-example squared losses. We build it in 2 steps.

```python
resid_b3 = np.array([-0.5, -1.0, -1.5])  # reuse a tiny residual pattern.
losses_b3 = resid_b3 ** 2  # square each miss.
print("squared losses:", losses_b3)
```

```python
mse_b3 = float(np.mean(losses_b3))  # average the squared losses.
print("MSE:", round(mse_b3, 3))
assert round(mse_b3, 3) == 1.167
plt.figure(figsize=(4, 3)); plt.bar(["e0²", "e1²", "e2²"], losses_b3, color="steelblue")
plt.axhline(mse_b3, color="black", linestyle="--", label="mean")
plt.title("Basic 3: losses averaged into risk"); plt.legend(); plt.show(); plt.close()
```
▶ What you'll see: the largest residual contributes the largest squared penalty.

👀 Takeaway: MSE is a single ERM objective built from all training examples.

### Basic 4 — Compute the gradient vector

**Goal.** Use \(\frac{2}{m}X^\top(X\beta-y)\), because each coefficient needs its own derivative. We build it in 2 steps.

```python
x_b4 = np.array([0., 1., 2.])  # feature values.
y_b4 = np.array([1., 3., 5.])  # perfectly y = 1 + 2x.
X_b4 = np.c_[np.ones_like(x_b4), x_b4]  # design matrix.
beta_b4 = np.array([0., 0.])  # start from the zero line.
resid_b4 = X_b4 @ beta_b4 - y_b4  # residuals at the start.
print("residuals:", resid_b4)
```

```python
grad_b4 = (2 / len(y_b4)) * X_b4.T @ resid_b4  # compute the MSE gradient.
print("gradient:", np.round(grad_b4, 3))
assert np.allclose(np.round(grad_b4, 3), [-6.000, -8.667])
plt.figure(figsize=(4, 3)); plt.bar(["intercept", "slope"], grad_b4, color="purple")
plt.axhline(0, color="black", linewidth=0.8); plt.title("Basic 4: gradient components")
plt.show(); plt.close()
```
▶ What you'll see: both derivatives are negative, so subtracting them increases both coefficients.

👀 Takeaway: the gradient compresses all residual evidence into one update direction per coefficient.

### Basic 5 — Take one descent step

**Goal.** Update \(\beta\leftarrow\beta-\eta\nabla J\), because gradient descent moves opposite the direction of increasing loss. We build it in 3 steps.

```python
beta_b5 = np.array([0., 0.])  # start at the zero line.
grad_b5 = np.array([-6.0, -8.6666666667])  # gradient from Basic 4.
eta_b5 = 0.1  # choose a visible step size.
print("before beta:", beta_b5)
```

```python
beta_new_b5 = beta_b5 - eta_b5 * grad_b5  # descent subtracts the gradient.
print("after beta:", np.round(beta_new_b5, 3))
assert np.allclose(np.round(beta_new_b5, 3), [0.600, 0.867])
```

```python
x_grid_b5 = np.array([0., 1., 2.])
plt.figure(figsize=(4, 3)); plt.plot(x_grid_b5, beta_new_b5[0] + beta_new_b5[1] * x_grid_b5, marker="o", color="seagreen")
plt.title("Basic 5: line after one step"); plt.xlabel("x"); plt.ylabel("prediction")
plt.show(); plt.close()
```
▶ What you'll see: the line is no longer flat; the step moved it upward and tilted it.

👀 Takeaway: a negative gradient component increases its coefficient during descent.

### Basic 6 — Watch loss decrease for a few steps

**Goal.** Run repeated gradient steps, because one update rarely reaches the minimum. We build it in 3 steps.

```python
x_b6 = np.array([0., 1., 2., 3.])
y_b6 = 1.0 + 2.0 * x_b6
X_b6 = np.c_[np.ones_like(x_b6), x_b6]

```

```python
losses_b6 = []

```

```python
plt.figure(figsize=(4, 3)); plt.plot(losses_b6, color="teal")
plt.title("Basic 6: loss over steps"); plt.xlabel("step"); plt.ylabel("MSE")
plt.show(); plt.close()
```
▶ What you'll see: the curve descends quickly at first and then flattens.

👀 Takeaway: repeated small downhill moves turn a formula into a fitted model.

### Basic 7 — Compare two learning rates

**Goal.** Show the effect of step size, because \(\eta\) controls convergence speed and stability. We build it in 3 steps.

```python
x_b7 = np.array([0., 1., 2., 3.])
y_b7 = 1.0 + 2.0 * x_b7
X_b7 = np.c_[np.ones_like(x_b7), x_b7]
rates_b7 = [0.02, 0.10]
print("rates:", rates_b7)
```

```python
curves_b7 = []
for eta_b7 in rates_b7:
    beta_loop_b7 = np.zeros(2)
    curve_b7 = []
    for step_loop_b7 in range(25):
        resid_loop_b7 = X_b7 @ beta_loop_b7 - y_b7
        curve_b7.append(float(np.mean(resid_loop_b7 ** 2)))
        grad_loop_b7 = (2 / len(y_b7)) * X_b7.T @ resid_loop_b7
        beta_loop_b7 = beta_loop_b7 - eta_b7 * grad_loop_b7
    curves_b7.append(curve_b7)
print("final losses:", [round(c[-1], 3) for c in curves_b7])
assert curves_b7[1][-1] < curves_b7[0][-1]
```

```python
plt.figure(figsize=(4.5, 3))
plt.plot(curves_b7[0], label="eta=0.02")
plt.plot(curves_b7[1], label="eta=0.10")
plt.title("Basic 7: learning-rate comparison"); plt.xlabel("step"); plt.ylabel("MSE")
plt.legend(); plt.show(); plt.close()
```
▶ What you'll see: the larger stable step reaches a lower loss in the same number of steps.

👀 Takeaway: learning rate is an optimization knob, not a model coefficient.

## 🟡 Easy

### Easy 1 — Implement batch gradient descent

**Goal.** Fit all coefficients at once from the full gradient, because batch descent uses every training example in each update. We build it in 4 steps.

x_e1 = np.linspace(0, 5, 8)
