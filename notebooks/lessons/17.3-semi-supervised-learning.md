# 17.3 — Semi-Supervised Learning

Semi-supervised learning uses a small labeled set plus a larger unlabeled set, but the unlabeled points help only when their geometry matches the label function. In this lesson, we build pseudo-labeling, consistency regularization, and label propagation from scratch in NumPy so the confidence thresholds, smoothness penalties, and graph updates are visible rather than hidden inside a library.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build semi-supervised learning one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including confidence, entropy, consistency loss, and graph propagation, is shown directly. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, distances, softmaxes, and small optimization loops.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for toy data and perturbations.
```

### 1. Partially labeled geometry: what unlabeled data can and cannot say

Semi-supervised learning starts with two kinds of evidence. Labeled points say what the classes are; unlabeled points say where the data density lives. The core bet is the **cluster/low-density separation assumption**: nearby points inside the same dense region should usually share a label, while a decision boundary should prefer low-density gaps.

```python
rng_w = np.random.default_rng(0)
left_w = rng_w.normal(loc=[-1.4, 0.0], scale=0.28, size=(16, 2))
right_w = rng_w.normal(loc=[1.4, 0.0], scale=0.28, size=(16, 2))
X_w = np.vstack([left_w, right_w])
y_true_w = np.array([0] * len(left_w) + [1] * len(right_w))
labeled_idx_w = np.array([0, 5, 16, 21])
y_labeled_w = np.full(len(X_w), -1)
y_labeled_w[labeled_idx_w] = y_true_w[labeled_idx_w]
print("points:", X_w.shape[0], "labeled:", int(np.sum(y_labeled_w >= 0)), "unlabeled:", int(np.sum(y_labeled_w < 0)))
assert int(np.sum(y_labeled_w >= 0)) == 4
```
▶ What you'll see: only 4 of 32 points have labels, so most information is geometric rather than supervised.

```python
plt.figure(figsize=(4.8, 3.4))
plt.scatter(X_w[y_labeled_w < 0, 0], X_w[y_labeled_w < 0, 1], c="lightgray", s=45, label="unlabeled")
plt.scatter(X_w[y_labeled_w == 0, 0], X_w[y_labeled_w == 0, 1], c="royalblue", s=90, edgecolor="k", label="labeled 0")
plt.scatter(X_w[y_labeled_w == 1, 0], X_w[y_labeled_w == 1, 1], c="darkorange", s=90, edgecolor="k", label="labeled 1")
plt.axvline(0, color="black", linestyle="--", linewidth=1)
plt.title("1: labels are sparse, geometry is abundant")
plt.xlabel("feature 0"); plt.ylabel("feature 1"); plt.legend(); plt.show()
```
▶ What you'll see: two dense clouds with only two labels per cloud; the vertical gap is where a boundary should go.

*Why it's done this way:* unlabeled examples do not reveal class names by themselves. They become useful only through an assumption linking geometry to labels: if dense regions correspond to semantic classes, then unlabeled density tells the classifier where not to put a boundary.

### 2. Pseudo-label confidence and entropy

Self-training converts a model's confident predictions on unlabeled examples into temporary labels. The rule from the lesson is: keep $\hat y=\arg\max_k p(k\mid x)$ only if $\max_k p(k\mid x)>\tau$. Entropy makes the same idea visible: peaked probabilities have low entropy; ambiguous probabilities have high entropy.

```python
probs_w = np.array([[0.9, 0.1], [0.5, 0.5], [0.82, 0.18]])
entropy_w = -np.sum(probs_w * np.log(probs_w), axis=1)
conf_w = np.max(probs_w, axis=1)
pseudo_w = np.argmax(probs_w, axis=1)
print("confidence:", np.round(conf_w, 3))
print("entropy:", np.round(entropy_w, 3))
assert round(float(entropy_w[0]), 3) == 0.325
assert round(float(entropy_w[1]), 3) == 0.693
```
▶ What you'll see: `(0.9,0.1)` is confident with entropy 0.325, while `(0.5,0.5)` is ambiguous with entropy 0.693.

```python
tau_w = 0.8
keep_w = conf_w > tau_w
print("pseudo-labels:", pseudo_w)
print("kept by tau=0.8:", keep_w.astype(int))
assert keep_w.tolist() == [True, False, True]
plt.figure(figsize=(4.6, 3))
plt.bar(["0.9/0.1", "0.5/0.5", "0.82/0.18"], conf_w, color=np.where(keep_w, "seagreen", "crimson"))
plt.axhline(tau_w, color="black", linestyle="--", label="threshold τ")
plt.ylabel("max class probability"); plt.title("2: confidence gates pseudo-labels"); plt.legend(); plt.show()
```
▶ What you'll see: bars above the threshold are kept; the ambiguous 0.5/0.5 point is rejected.

*Why it's done this way:* pseudo-labels can amplify errors because the model trains on its own guesses. The threshold is therefore not cosmetic; it is the mechanism that lets low-entropy predictions add signal while high-entropy predictions stay out of the loss.

### 3. Self-training loop from scratch

A tiny linear softmax model is enough to show self-training. We first fit only the labeled points, then add high-confidence unlabeled points with pseudo-labels, then refit. The point is not that the model is fancy; the point is that unlabeled data changes the training set only when confidence justifies it.

```python
def softmax_w(z):
    z = z - np.max(z, axis=1, keepdims=True)
    e = np.exp(z)
    return e / np.sum(e, axis=1, keepdims=True)

def train_linear_w(X, y, steps=500, lr=0.4):
    Xb = np.c_[np.ones(len(X)), X]
    W = np.zeros((Xb.shape[1], 2))
    for _ in range(steps):
        P = softmax_w(Xb @ W)
        Y = np.eye(2)[y]
        grad = Xb.T @ (P - Y) / len(X)
        W -= lr * grad
    return W

W_lab_w = train_linear_w(X_w[labeled_idx_w], y_labeled_w[labeled_idx_w])
P_unlab_w = softmax_w(np.c_[np.ones(len(X_w)), X_w] @ W_lab_w)
print("first five probabilities:\n", np.round(P_unlab_w[:5], 3))
```
▶ What you'll see: the labeled-only model already produces class probabilities for every unlabeled point.

```python
unlabeled_idx_w = np.where(y_labeled_w < 0)[0]
conf_all_w = np.max(P_unlab_w[unlabeled_idx_w], axis=1)
pseudo_all_w = np.argmax(P_unlab_w[unlabeled_idx_w], axis=1)
keep_idx_w = unlabeled_idx_w[conf_all_w > 0.85]
keep_pseudo_w = pseudo_all_w[conf_all_w > 0.85]
print("kept pseudo-label count:", len(keep_idx_w))
print("kept pseudo-label accuracy for inspection:", round(float(np.mean(keep_pseudo_w == y_true_w[keep_idx_w])), 3))
assert len(keep_idx_w) >= 20
assert float(np.mean(keep_pseudo_w == y_true_w[keep_idx_w])) >= 0.95
```
▶ What you'll see: many unlabeled points are confidently pseudo-labeled, and in this aligned toy geometry they are nearly all correct.

```python
X_train2_w = np.vstack([X_w[labeled_idx_w], X_w[keep_idx_w]])
y_train2_w = np.r_[y_labeled_w[labeled_idx_w], keep_pseudo_w]
W_self_w = train_linear_w(X_train2_w, y_train2_w, steps=500, lr=0.25)
acc_lab_w = np.mean(np.argmax(P_unlab_w, axis=1) == y_true_w)
acc_self_w = np.mean(np.argmax(softmax_w(np.c_[np.ones(len(X_w)), X_w] @ W_self_w), axis=1) == y_true_w)
print("accuracy before self-training:", round(float(acc_lab_w), 3))
print("accuracy after self-training:", round(float(acc_self_w), 3))
assert acc_self_w >= acc_lab_w
```
▶ What you'll see: self-training keeps or improves accuracy when the cluster assumption is true.

```python
xx_w = np.linspace(-2.3, 2.3, 120)
yy_w = np.linspace(-1.1, 1.1, 80)
grid_w = np.array([[a, b] for b in yy_w for a in xx_w])
P_grid_w = softmax_w(np.c_[np.ones(len(grid_w)), grid_w] @ W_self_w)[:, 1].reshape(len(yy_w), len(xx_w))
plt.figure(figsize=(5, 3.4))
plt.contourf(xx_w, yy_w, P_grid_w, levels=20, cmap="coolwarm", alpha=0.55)
plt.scatter(X_w[:, 0], X_w[:, 1], c=y_true_w, cmap="coolwarm", edgecolor="k", s=35)
plt.scatter(X_w[keep_idx_w, 0], X_w[keep_idx_w, 1], facecolors="none", edgecolors="lime", s=90, label="pseudo-labeled")
plt.title("3: self-training adds confident unlabeled points"); plt.legend(); plt.show()
```
▶ What you'll see: pseudo-labeled points ring the dense clouds, and the learned boundary sits in the low-density gap.

*Why it's done this way:* the supervised loss supplies class meaning, while pseudo-labels expand that loss into dense regions. The confidence gate prevents the model from treating uncertainty as truth, which is why threshold choice is the central design decision.

### 4. Consistency regularization: stable predictions under small perturbations

Consistency regularization does not assign a hard pseudo-label. Instead, it says the model should output nearly the same probability distribution for $x$ and a small perturbation $x+\epsilon$. The penalty is often a squared distance $\lVert p(x)-p(x+\epsilon)\rVert^2$.

```python
x0_w = np.array([[0.9, 0.15]])
noise_w = np.array([[0.08, -0.05]])
p_clean_w = softmax_w(np.c_[np.ones(1), x0_w] @ W_self_w)[0]
p_noisy_w = softmax_w(np.c_[np.ones(1), x0_w + noise_w] @ W_self_w)[0]
cons_loss_w = float(np.sum((p_clean_w - p_noisy_w) ** 2))
print("p(clean):", np.round(p_clean_w, 3))
print("p(noisy):", np.round(p_noisy_w, 3))
print("consistency loss:", round(cons_loss_w, 6))
assert cons_loss_w < 0.02
```
▶ What you'll see: a small input change produces similar probabilities, so the consistency penalty is small.

```python
noises_w = rng_w.normal(scale=0.12, size=(25, 2))
P_aug_w = softmax_w(np.c_[np.ones(len(noises_w)), x0_w + noises_w] @ W_self_w)
losses_cons_w = np.sum((P_aug_w - p_clean_w) ** 2, axis=1)
print("mean consistency loss:", round(float(np.mean(losses_cons_w)), 5))
plt.figure(figsize=(4.6, 3))
plt.scatter(x0_w[0, 0] + noises_w[:, 0], x0_w[0, 1] + noises_w[:, 1], c=losses_cons_w, cmap="magma", s=55)
plt.scatter(x0_w[0, 0], x0_w[0, 1], c="cyan", edgecolor="k", s=120, label="clean x")
plt.colorbar(label="||p(x)-p(x+ε)||²")
plt.title("4: perturbations should not flip predictions"); plt.legend(); plt.show()
```
▶ What you'll see: nearby augmentations have low loss; points drifting toward the boundary would have higher loss.

*Why it's done this way:* consistency encodes a smoothness prior without trusting a hard guessed label. It says the function should be locally stable around data points, which pushes the decision surface away from high-density neighborhoods.

### 5. Label propagation on a similarity graph

Label propagation builds a graph over labeled and unlabeled examples, then repeatedly averages labels across edges. If two points are close, their edge weight is large, so label mass diffuses through dense regions. Labeled rows are clamped after every iteration so ground-truth labels remain anchors.

```python
D2_w = np.sum((X_w[:, None, :] - X_w[None, :, :]) ** 2, axis=2)
sigma2_w = 0.5
A_w = np.exp(-D2_w / (2 * sigma2_w))
np.fill_diagonal(A_w, 0.0)
S_w = A_w / np.maximum(A_w.sum(axis=1, keepdims=True), 1e-12)
Y0_w = np.zeros((len(X_w), 2))
Y0_w[labeled_idx_w, y_labeled_w[labeled_idx_w]] = 1.0
print("row sums of S first 3:", np.round(S_w[:3].sum(axis=1), 3))
assert np.allclose(S_w[:3].sum(axis=1), 1.0)
```
▶ What you'll see: each graph row sums to 1, so propagation is a weighted average of neighbors.

```python
F_w = Y0_w.copy()
for it_w in range(60):
    F_w = S_w @ F_w
    F_w[labeled_idx_w] = Y0_w[labeled_idx_w]
prop_pred_w = np.argmax(F_w, axis=1)
prop_acc_w = np.mean(prop_pred_w == y_true_w)
print("propagation accuracy:", round(float(prop_acc_w), 3))
print("first unlabeled soft labels:\n", np.round(F_w[1:5], 3))
assert prop_acc_w >= 0.95
```
▶ What you'll see: class probability mass spreads from the four labeled anchors to their surrounding unlabeled neighbors.

```python
plt.figure(figsize=(4.8, 3.4))
plt.scatter(X_w[:, 0], X_w[:, 1], c=F_w[:, 1], cmap="coolwarm", s=55, edgecolor="k")
plt.scatter(X_w[labeled_idx_w, 0], X_w[labeled_idx_w, 1], facecolors="none", edgecolors="yellow", s=150, linewidths=2, label="clamped labels")
plt.colorbar(label="propagated class-1 score")
plt.title("5: label propagation diffuses labels on the graph"); plt.legend(); plt.show()
```
▶ What you'll see: soft labels vary smoothly within each cluster, with labeled points acting as fixed sources.

*Why it's done this way:* graph averaging solves a discrete smoothness problem: connected points should have similar labels, but labeled nodes must remain fixed. It works when graph edges reflect semantic closeness; if edges connect across a nuisance direction, the same averaging spreads the wrong label.

### 6. The failure mode: wrong geometry amplifies wrong labels

Unlabeled data can hurt when geometry is misaligned with the task. If the dense clusters are separated vertically but the true label changes horizontally, then propagating or pseudo-labeling by cluster structure optimizes the wrong smoothness term.

```python
rng_bad_w = np.random.default_rng(3)
top_w = rng_bad_w.normal(loc=[0.0, 1.0], scale=0.22, size=(18, 2))
bot_w = rng_bad_w.normal(loc=[0.0, -1.0], scale=0.22, size=(18, 2))
X_bad_w = np.vstack([top_w, bot_w])
y_bad_w = (X_bad_w[:, 0] > 0).astype(int)
print("class balance from horizontal rule:", np.bincount(y_bad_w))
assert len(np.bincount(y_bad_w)) == 2
```
▶ What you'll see: labels depend on left-versus-right, not the two vertical density clusters.

```python
plt.figure(figsize=(4.8, 3.4))
plt.scatter(X_bad_w[:, 0], X_bad_w[:, 1], c=y_bad_w, cmap="coolwarm", edgecolor="k", s=45)
plt.axvline(0, color="black", linestyle="--", label="true boundary")
plt.title("6: density clusters are not the label classes")
plt.xlabel("feature 0"); plt.ylabel("feature 1"); plt.legend(); plt.show()
```
▶ What you'll see: each dense vertical cluster contains both colors, so a cluster-smooth label rule would be wrong.

*Why it's done this way:* the pitfall is not a coding bug; it is an assumption bug. Semi-supervised objectives add constraints from unlabeled structure, so validation must confirm that the structure matches the target label function.

## 🟢 Basics (warm-up)

### Basic 1 — Build a partially labeled toy set

**Goal.** Create two dense clusters with only a few labels, because semi-supervised learning starts by separating labeled evidence from unlabeled geometry. We build it in 2 steps.

```python
rng_b1 = np.random.default_rng(1)
X0_b1 = rng_b1.normal([-1.2, 0.0], 0.25, size=(8, 2))
X1_b1 = rng_b1.normal([1.2, 0.0], 0.25, size=(8, 2))
X_b1 = np.vstack([X0_b1, X1_b1])
y_true_b1 = np.array([0] * 8 + [1] * 8)
labeled_b1 = np.array([0, 3, 8, 11])
y_obs_b1 = np.full(16, -1)
y_obs_b1[labeled_b1] = y_true_b1[labeled_b1]
print("labeled count:", int(np.sum(y_obs_b1 >= 0)), "unlabeled count:", int(np.sum(y_obs_b1 < 0)))
assert int(np.sum(y_obs_b1 >= 0)) == 4
```
▶ What you'll see: 4 labeled points and 12 unlabeled points.

```python
plt.figure(figsize=(4, 3))
plt.scatter(X_b1[y_obs_b1 < 0, 0], X_b1[y_obs_b1 < 0, 1], c="lightgray", label="unlabeled")
plt.scatter(X_b1[y_obs_b1 == 0, 0], X_b1[y_obs_b1 == 0, 1], c="royalblue", edgecolor="k", label="label 0")
plt.scatter(X_b1[y_obs_b1 == 1, 0], X_b1[y_obs_b1 == 1, 1], c="darkorange", edgecolor="k", label="label 1")
plt.title("Basic 1: sparse labels, dense geometry"); plt.legend(); plt.show()
```
▶ What you'll see: the labels are rare, but the two clusters are visually clear.

👀 Takeaway: unlabeled data supplies geometry, not class names.

### Basic 2 — Separate labeled and unlabeled arrays

**Goal.** Build masks for supervised and unsupervised pieces, because every semi-supervised algorithm must know which points have trusted labels. We build it in 2 steps.

```python
rng_b2 = np.random.default_rng(2)
X_b2 = np.vstack([rng_b2.normal([-1, 0], 0.2, size=(5, 2)), rng_b2.normal([1, 0], 0.2, size=(5, 2))])
y_obs_b2 = np.array([0, -1, -1, 0, -1, 1, -1, -1, 1, -1])
mask_l_b2 = y_obs_b2 >= 0
mask_u_b2 = ~mask_l_b2
print("labeled indices:", np.where(mask_l_b2)[0])
print("unlabeled indices:", np.where(mask_u_b2)[0])
assert int(mask_l_b2.sum()) == 4
```
▶ What you'll see: two index lists, one for trusted labels and one for unlabeled candidates.

```python
plt.figure(figsize=(4, 3))
plt.bar(["labeled", "unlabeled"], [mask_l_b2.sum(), mask_u_b2.sum()], color=["seagreen", "gray"])
plt.title("Basic 2: split the training roles"); plt.ylabel("count"); plt.show()
```
▶ What you'll see: unlabeled points outnumber labeled points in the toy split.

👀 Takeaway: the label mask protects unknown labels from being treated as ordinary class values.

### Basic 3 — Compute softmax probabilities

**Goal.** Convert logits into class probabilities, because pseudo-labeling uses confidence from a probability vector. We build it in 2 steps.

```python
logits_b3 = np.array([[2.0, 0.0], [0.2, 0.1], [-1.0, 1.5]])
shift_b3 = logits_b3 - np.max(logits_b3, axis=1, keepdims=True)
exp_b3 = np.exp(shift_b3)
print("shifted logits:\n", np.round(shift_b3, 2))
```
▶ What you'll see: each row is shifted so its largest logit is 0, which keeps exponentials stable.

```python
probs_b3 = exp_b3 / np.sum(exp_b3, axis=1, keepdims=True)
print("probabilities:\n", np.round(probs_b3, 3))
assert np.allclose(probs_b3.sum(axis=1), 1.0)
plt.figure(figsize=(4, 3))
plt.imshow(probs_b3, cmap="Blues", aspect="auto"); plt.colorbar(label="probability")
plt.title("Basic 3: softmax rows sum to 1"); plt.xlabel("class"); plt.ylabel("example"); plt.show()
```
▶ What you'll see: every row is a normalized distribution over two classes.

👀 Takeaway: confidence is meaningful only after logits are normalized into probabilities.

### Basic 4 — Measure confidence and entropy

**Goal.** Compare maximum probability with entropy, because both diagnose whether a pseudo-label is safe enough to keep. We build it in 2 steps.

```python
probs_b4 = np.array([[0.9, 0.1], [0.5, 0.5], [0.7, 0.3]])
conf_b4 = np.max(probs_b4, axis=1)
ent_b4 = -np.sum(probs_b4 * np.log(probs_b4), axis=1)
print("confidence:", np.round(conf_b4, 3))
print("entropy:", np.round(ent_b4, 3))
assert round(float(ent_b4[0]), 3) == 0.325
assert round(float(ent_b4[1]), 3) == 0.693
```
▶ What you'll see: high confidence corresponds to low entropy.

```python
plt.figure(figsize=(4, 3))
plt.bar(["0.9/0.1", "0.5/0.5", "0.7/0.3"], ent_b4, color="purple")
plt.title("Basic 4: entropy reveals ambiguity"); plt.ylabel("entropy"); plt.show()
```
▶ What you'll see: the balanced distribution has the tallest entropy bar.

👀 Takeaway: a pseudo-label should come from a peaked distribution, not from a coin flip.

### Basic 5 — Apply a pseudo-label threshold

**Goal.** Keep only confident predictions, because self-training fails when uncertain guesses become training targets. We build it in 2 steps.

```python
probs_b5 = np.array([[0.92, 0.08], [0.61, 0.39], [0.12, 0.88], [0.51, 0.49]])
tau_b5 = 0.8
conf_b5 = np.max(probs_b5, axis=1)
pseudo_b5 = np.argmax(probs_b5, axis=1)
keep_b5 = conf_b5 > tau_b5
print("pseudo-labels:", pseudo_b5)
print("keep flags:", keep_b5.astype(int))
assert keep_b5.tolist() == [True, False, True, False]
```
▶ What you'll see: two examples are confident enough to become pseudo-labeled training data.

```python
plt.figure(figsize=(4, 3))
plt.bar(np.arange(len(conf_b5)), conf_b5, color=np.where(keep_b5, "seagreen", "crimson"))
plt.axhline(tau_b5, color="black", linestyle="--")
plt.title("Basic 5: threshold τ filters guesses"); plt.xlabel("unlabeled example"); plt.ylabel("confidence"); plt.show()
```
▶ What you'll see: only bars above τ are green.

👀 Takeaway: the threshold is the safety valve against self-reinforcing errors.

### Basic 6 — One pseudo-label loss

**Goal.** Compute cross-entropy on a kept pseudo-label, because self-training reuses the ordinary supervised loss after a label is guessed. We build it in 2 steps.

```python
p_b6 = np.array([0.92, 0.08])
yhat_b6 = int(np.argmax(p_b6))
loss_b6 = -np.log(p_b6[yhat_b6])
print("pseudo-label:", yhat_b6, "loss:", round(float(loss_b6), 3))
assert round(float(loss_b6), 3) == 0.083
```
▶ What you'll see: a confident pseudo-label has a small cross-entropy loss.

```python
pgrid_b6 = np.linspace(0.51, 0.99, 60)
lossgrid_b6 = -np.log(pgrid_b6)
plt.figure(figsize=(4, 3))
plt.plot(pgrid_b6, lossgrid_b6, color="navy")
plt.scatter([p_b6[yhat_b6]], [loss_b6], color="red")
plt.title("Basic 6: confident pseudo-label loss"); plt.xlabel("probability assigned to pseudo-label"); plt.ylabel("-log p"); plt.show()
```
▶ What you'll see: loss shrinks rapidly as the model assigns more probability to the chosen class.

👀 Takeaway: pseudo-labeling is supervised learning on selected guesses, so bad guesses are costly.

### Basic 7 — Measure consistency loss

**Goal.** Penalize prediction changes under small input perturbations, because labels should not flip for tiny harmless changes. We build it in 2 steps.

```python
p_clean_b7 = np.array([0.82, 0.18])
p_aug_b7 = np.array([0.78, 0.22])
cons_b7 = np.sum((p_clean_b7 - p_aug_b7) ** 2)
print("consistency loss:", round(float(cons_b7), 4))
assert round(float(cons_b7), 4) == 0.0032
```
▶ What you'll see: similar probabilities create a small squared consistency penalty.

```python
plt.figure(figsize=(4, 3))
plt.bar(["class 0 clean", "class 0 aug"], [p_clean_b7[0], p_aug_b7[0]], color=["teal", "orange"])
plt.ylim(0, 1); plt.title("Basic 7: prediction stability"); plt.ylabel("probability"); plt.show()
```
▶ What you'll see: the augmented prediction stays close to the clean prediction.

👀 Takeaway: consistency regularization uses unlabeled inputs without committing to a hard class.

### Basic 8 — Build a similarity graph

**Goal.** Convert distances into edge weights, because label propagation needs a graph telling which points should share labels. We build it in 2 steps.

```python
X_b8 = np.array([[-1.0, 0.0], [-0.8, 0.1], [0.9, 0.0], [1.1, -0.1]])
D2_b8 = np.sum((X_b8[:, None, :] - X_b8[None, :, :]) ** 2, axis=2)
A_b8 = np.exp(-D2_b8 / (2 * 0.4 ** 2))
np.fill_diagonal(A_b8, 0.0)
print("adjacency:\n", np.round(A_b8, 3))
assert A_b8[0, 1] > A_b8[0, 2]
```
▶ What you'll see: nearby points get much larger edge weights than far points.
