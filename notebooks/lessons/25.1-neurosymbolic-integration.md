# 25.1 — Neurosymbolic Integration

Neurosymbolic integration combines neural models that handle uncertainty with symbolic rules that encode structure. In this lesson, you will build a tiny NumPy classifier, reinterpret its probabilities as soft truth values, and add differentiable logic penalties so rules guide learning rather than merely patching predictions afterward.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build neurosymbolic integration one idea at a time. Run each cell in order and read the printed intermediate values — every neural score, truth value, rule penalty, and hybrid objective is shown. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, random numbers, and tiny neural training from scratch.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for the tiny neural examples.
```

### 1. Neural probabilities become soft truth values

A neural classifier usually ends with a probability such as `0.82`. In a symbolic system, a predicate is often true or false. Neurosymbolic integration keeps the probability instead of rounding it, treating it as a **soft truth value** in `[0, 1]`. That one choice preserves uncertainty: `0.51` and `0.99` are both positive if rounded, but they should not carry the same confidence in a rule.

```python
x_w = np.array([[-2.0], [-0.5], [0.4], [1.5], [2.5]])  # one perception feature per example.
w_w, b_w = 1.2, -0.1  # a tiny logistic classifier's weight and bias.
logits_w = x_w[:, 0] * w_w + b_w  # linear neural scores before the sigmoid.
truth_w = 1 / (1 + np.exp(-logits_w))  # probabilities interpreted as soft predicate truth values.
print("soft neural truth values:", np.round(truth_w, 3))
assert np.all((truth_w >= 0) & (truth_w <= 1))
```
▶ What you'll see: every example receives a graded truth value rather than a hard yes-or-no label.

```python
plt.figure(figsize=(4.6, 3))
plt.plot(x_w[:, 0], truth_w, marker="o", color="teal")
plt.axhline(0.5, color="gray", linestyle="--", label="hard threshold")
plt.title("1: neural probability as soft truth")
plt.xlabel("perception feature")
plt.ylabel("P(predicate true)")
plt.legend()
plt.show()
```
▶ What you'll see: probabilities rise smoothly with the feature, so logic can see confidence instead of just labels.

*Why it's done this way:* rounding would destroy the gradient and erase useful uncertainty; keeping probabilities lets later symbolic penalties say how badly, not merely whether, a rule is violated.

### 2. The data loss still teaches the neural model

Rules do not replace data. The classifier still minimizes binary cross-entropy, which charges high loss when a probability disagrees with the observed label. Neurosymbolic training starts with this familiar neural objective, then adds a rule term beside it.

```python
y_w = np.array([0, 0, 1, 1, 1], dtype=float)  # observed labels for the perception task.
eps_w = 1e-12  # numerical guard for log.
bce_terms_w = -(y_w * np.log(truth_w + eps_w) + (1 - y_w) * np.log(1 - truth_w + eps_w))
loss_neural_w = float(np.mean(bce_terms_w))
print("BCE terms:", np.round(bce_terms_w, 3))
print("mean neural loss:", round(loss_neural_w, 3))
assert loss_neural_w > 0
```
▶ What you'll see: confident correct examples have small BCE, while uncertain or wrong examples cost more.

```python
plt.figure(figsize=(4.6, 3))
plt.bar(range(len(bce_terms_w)), bce_terms_w, color="purple")
plt.title("2: data loss by example")
plt.xlabel("example")
plt.ylabel("binary cross-entropy")
plt.show()
```
▶ What you'll see: the largest bars identify examples where perception still needs data-driven correction.

*Why it's done this way:* the neural loss anchors the model to examples, so the symbolic rule regularizes learning instead of inventing labels by itself.

### 3. Logic enters as differentiable connectives

Classical `AND` and `OR` are discrete. To train with gradients, we use fuzzy relaxations: product `AND` is `A*B`, and probabilistic `OR` is `A + B - A*B`. These formulas preserve the intuition of conjunction and disjunction while changing smoothly when either neural score changes.

```python
A_w = np.linspace(0, 1, 6)  # possible truth values for predicate A.
B_w = 0.6  # keep predicate B fixed so one curve is easy to inspect.
and_w = A_w * B_w  # product t-norm AND.
or_w = A_w + B_w - A_w * B_w  # probabilistic OR.
print("A:", np.round(A_w, 2))
print("A AND 0.6:", np.round(and_w, 3))
print("A OR 0.6:", np.round(or_w, 3))
assert np.all(and_w <= or_w)
```
▶ What you'll see: AND stays below either uncertain input, while OR grows as soon as either input helps.

```python
plt.figure(figsize=(4.6, 3))
plt.plot(A_w, and_w, marker="o", label="product AND")
plt.plot(A_w, or_w, marker="s", label="probabilistic OR")
plt.title("3: differentiable logic curves")
plt.xlabel("truth value A")
plt.ylabel("soft connective value")
plt.legend()
plt.show()
```
▶ What you'll see: both connectives are smooth curves, not brittle step functions.

*Why it's done this way:* smooth connectives turn symbolic structure into numerical surfaces that a neural optimizer can descend.

### 4. Implication measures rule satisfaction

A common symbolic rule says, "if premise `A` is true, consequence `B` should be true." A simple soft implication satisfaction is `max(1-A, B)`. It is high when the premise is weak, or when the consequence is strong; it is low when the premise is high and the consequence is weak.

```python
premise_w = np.array([0.2, 0.7, 0.9])  # how true the rule condition is in three cases.
consequence_w = np.array([0.8, 0.6, 0.4])  # how true the required consequence is.
sat_w = np.maximum(1 - premise_w, consequence_w)  # soft satisfaction of A => B.
penalty_w = 1 - sat_w  # rule violation cost.
print("satisfaction:", np.round(sat_w, 3))
print("penalty:", np.round(penalty_w, 3))
assert np.allclose(penalty_w, [0.2, 0.4, 0.6])
```
▶ What you'll see: the strongest violation is high premise with weak consequence.

```python
plt.figure(figsize=(4.8, 3))
plt.bar(["case 1", "case 2", "case 3"], penalty_w, color="crimson")
plt.title("4: implication violation grows with mismatch")
plt.ylabel("1 - satisfaction")
plt.show()
```
▶ What you'll see: rule loss directly highlights the case where the model most contradicts the implication.

*Why it's done this way:* implication penalties focus learning on contradictions, not on cases where the premise was barely active.

### 5. A symbolic layer can repair predictions after perception

One integration pattern is a pipeline: neural perception proposes probabilities, and symbolic reasoning adjusts predictions to obey a known constraint. This is useful, but it is only a post-processor unless the rule also feeds back into training.

```python
raw_disease_w = np.array([0.82, 0.72])  # neural probabilities for two incompatible labels.
rule_adjusted_w = raw_disease_w.copy()  # start from neural perception.
if raw_disease_w.sum() > 1.0:  # symbolic constraint: not both can be simultaneously high.
    rule_adjusted_w = raw_disease_w / raw_disease_w.sum()  # renormalize to fit the constraint.
print("neural scores:", np.round(raw_disease_w, 3))
print("after symbolic layer:", np.round(rule_adjusted_w, 3))
assert rule_adjusted_w.sum() <= 1.0 + 1e-12
```
▶ What you'll see: the symbolic layer lowers mutually incompatible probabilities so their total is legal.

```python
plt.figure(figsize=(5.2, 3))
plt.text(0.05, 0.62, "Neural\nperception", bbox=dict(boxstyle="round", fc="lightblue"))
plt.text(0.42, 0.62, "Symbolic rule\nnot both", bbox=dict(boxstyle="round", fc="wheat"))
plt.text(0.78, 0.62, "Consistent\noutputs", bbox=dict(boxstyle="round", fc="lightgreen"))
plt.arrow(0.25, 0.7, 0.12, 0, head_width=0.04, length_includes_head=True)
plt.arrow(0.63, 0.7, 0.12, 0, head_width=0.04, length_includes_head=True)
plt.xlim(0, 1); plt.ylim(0, 1); plt.axis("off")
plt.title("5: perception → symbolic reasoning pipeline")
plt.show()
```
▶ What you'll see: the pipeline separates learned perception from rule-based consistency checking.

*Why it's done this way:* post-processing is simple and interpretable, but by itself it does not teach the neural model to avoid future violations.

### 6. Adding the rule to the loss creates feedback

A stronger integration pattern puts the rule penalty inside the training objective: `L_total = L_neural + λ(1 - S_rule)`. The parameter `λ` is the weight placed on symbolic consistency. If it is zero, the rule is ignored; if it is huge, the model may satisfy the rule at the expense of data fit.

```python
lambda_grid_w = np.array([0.0, 0.5, 1.0, 2.0, 5.0])  # candidate rule weights.
rule_penalty_w = 0.4  # a representative implication violation.
total_loss_w = loss_neural_w + lambda_grid_w * rule_penalty_w
print("lambda grid:", lambda_grid_w)
print("total losses:", np.round(total_loss_w, 3))
assert np.all(np.diff(total_loss_w) >= 0)
```
▶ What you'll see: increasing λ makes the same rule violation matter more in the total objective.

```python
plt.figure(figsize=(4.6, 3))
plt.plot(lambda_grid_w, total_loss_w, marker="o", color="darkorange")
plt.title("6: symbolic weight changes total loss")
plt.xlabel("λ")
plt.ylabel("L_neural + λ rule_penalty")
plt.show()
```
▶ What you'll see: λ acts like a dial for how loudly the symbolic teacher speaks.

*Why it's done this way:* putting the rule in the loss makes violations produce a training signal rather than a one-time correction.

### 7. The hybrid model should beat either side alone

A pure neural model can fit labels while breaking known facts. A pure symbolic system can enforce facts but cannot perceive noisy inputs. The hybrid goal is to combine their strengths: neural uncertainty, symbolic structure, and an objective that makes both visible during learning.

```python
models_w = ["neural", "symbolic", "hybrid"]
accuracy_w = np.array([0.78, 0.66, 0.86])  # illustrative validation accuracy.
violations_w = np.array([0.24, 0.02, 0.06])  # average rule violation rate.
print("accuracy:", dict(zip(models_w, accuracy_w)))
print("violation rate:", dict(zip(models_w, violations_w)))
assert accuracy_w[2] > accuracy_w[0] and violations_w[2] < violations_w[0]
```
▶ What you'll see: the hybrid keeps most neural accuracy while cutting symbolic violations.

```python
xpos_w = np.arange(len(models_w))
plt.figure(figsize=(5.2, 3))
plt.bar(xpos_w - 0.18, accuracy_w, width=0.36, label="accuracy", color="teal")
plt.bar(xpos_w + 0.18, 1 - violations_w, width=0.36, label="consistency", color="purple")
plt.xticks(xpos_w, models_w)
plt.ylim(0, 1)
plt.title("7: hybrid balances accuracy and rules")
plt.legend()
plt.show()
```
▶ What you'll see: the hybrid bar is strong on both task performance and rule consistency.

*Why it's done this way:* the point is not to make neural and symbolic modules compete; it is to let each correct the other's blind spot.

## 🛠️ Setup

```python
import numpy as np  # load NumPy for arrays, tiny neural models, and differentiable logic.
import matplotlib.pyplot as plt  # load Matplotlib so every concept can be inspected visually.
np.random.seed(0)  # make all examples reproducible.

def sigmoid(z):  # Convert logits into probabilities in [0, 1].
    return 1 / (1 + np.exp(-z))

def bce(y, p):  # Binary cross-entropy averaged over examples.
    p = np.clip(p, 1e-9, 1 - 1e-9)
    return float(np.mean(-(y * np.log(p) + (1 - y) * np.log(1 - p))))

def product_and(a, b):  # Product t-norm fuzzy AND.
    return np.asarray(a) * np.asarray(b)

def probabilistic_or(a, b):  # Smooth OR for probabilities.
    return np.asarray(a) + np.asarray(b) - np.asarray(a) * np.asarray(b)

def implication_sat(a, b):  # Soft satisfaction for A implies B.
    return np.maximum(1 - np.asarray(a), np.asarray(b))

def rule_penalty(a, b):  # Violation cost for A implies B.
    return 1 - implication_sat(a, b)

def tiny_train(X, y, lam=0.0, steps=300, lr=0.2):  # Train a tiny logistic classifier with optional monotonic rule pressure.
    w = np.zeros(X.shape[1])
    bias = 0.0
    losses = []
    for step in range(steps):
        p = sigmoid(X @ w + bias)
        grad_w = X.T @ (p - y) / len(y)
        grad_b = float(np.mean(p - y))
        if lam > 0:
            left = sigmoid(X[0] @ w + bias)
            right = sigmoid(X[-1] @ w + bias)
            violation = max(0.0, left - right)
            grad_w += lam * violation * (X[0] - X[-1])
            grad_b += 0.0
        w -= lr * grad_w
        bias -= lr * grad_b
        if np.mod(step, 10) == 0:
            losses.append(bce(y, sigmoid(X @ w + bias)))
    return w, bias, np.array(losses)
```

## 🟢 Basics

#### B1. Convert logits into neural truth values

**Goal.** Turn neural logits into probabilities, because neurosymbolic rules need soft predicate truth values rather than raw scores. We build it in 2 steps.

```python
logits_b1 = np.array([-2.0, -0.5, 0.0, 1.0, 2.0])  # Define five neural scores before calibration.
print("logits:", logits_b1)  # Inspect the unbounded neural outputs.
```
