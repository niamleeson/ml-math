# 9.10 — Knowledge Distillation for LMs (DistilBERT)

Knowledge distillation trains a smaller language model to imitate the probability shape of a larger teacher, not just its top answer. In this lesson, you will build the DistilBERT-style mechanics from first principles with tiny NumPy arrays: logits become softened distributions, KL divergence transfers "dark knowledge," temperature changes gradient scale, and a compact student learns useful behavior while keeping only a fraction of the teacher's parameters.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build knowledge distillation one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including temperature softmax and KL, is derived and shown. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, logits, probabilities, and tiny optimization loops.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for the toy student.
```

### 1. From teacher logits to probabilities

A language model does not directly output a word; it outputs **logits**, one raw score per vocabulary token. Softmax converts those raw scores into probabilities by exponentiating and normalizing. The highest logit becomes the top token, but the smaller probabilities still contain useful information: which alternatives the teacher considered plausible and which ones it ruled out.

```python
teacher_logits_w = np.array([2.0, 1.0, 0.0])  # teacher scores for three possible next tokens.
tokens_w = ["correct", "near", "wrong"]  # readable labels for the toy vocabulary.
shifted_w = teacher_logits_w - np.max(teacher_logits_w)  # subtract max for numerical stability.
exp_w = np.exp(shifted_w)  # exponentiate shifted logits.
print("shifted logits:", shifted_w)  # inspect stable logits before softmax.
print("exp values:", np.round(exp_w, 3))  # inspect positive unnormalized weights.
```
▶ What you'll see: subtracting the maximum keeps the largest exponent at 1 without changing the final probabilities.

```python
teacher_probs_w = exp_w / np.sum(exp_w)  # normalize exponentials into probabilities that sum to 1.
print("teacher probs:", np.round(teacher_probs_w, 3))  # [0.665, 0.245, 0.090].
print("sum:", round(float(np.sum(teacher_probs_w)), 3))  # probabilities sum to 1.
assert np.allclose(np.round(teacher_probs_w, 3), np.array([0.665, 0.245, 0.090]))  # lesson numbers.
```
▶ What you'll see: the teacher is confident in "correct" but still assigns 24.5% to the near alternative.

```python
plt.figure(figsize=(4.5, 3))  # create a probability bar chart.
plt.bar(tokens_w, teacher_probs_w, color="steelblue")  # visualize teacher belief over tokens.
plt.title("1: teacher distribution from logits")  # title the distribution plot.
plt.ylabel("probability")  # label the probability scale.
plt.ylim(0, 1)  # keep probabilities on a fixed scale.
plt.show()  # display the plot.
```
▶ What you'll see: one tall bar and two smaller bars — the small bars are the extra signal distillation tries to preserve.

*Why it's done this way: softmax turns arbitrary real-valued logits into a probability distribution by making every score positive and dividing by the total. Subtracting the maximum is algebraically harmless because softmax is unchanged by adding the same constant to every logit, but it prevents exponentials from overflowing.*

### 2. Temperature softens the teacher distribution

Temperature changes the sharpness of softmax: $$\sigma(z/T)$$ divides logits by $T$ before exponentiating. When $T=1$, the teacher's largest logit dominates. When $T>1$, the logits move closer together, so the probability mass spreads to non-top tokens. This is the "soft target" idea behind distillation: the student sees not only the answer but also the teacher's graded uncertainty.

```python
def softmax_temp_w(logits, T=1.0):  # compute temperature softmax from scratch.
    scaled = np.asarray(logits, dtype=float) / T  # divide logits by temperature.
    scaled = scaled - np.max(scaled)  # stabilize exponentials without changing probabilities.
    weights = np.exp(scaled)  # convert scores to positive weights.
    return weights / np.sum(weights)  # normalize to probabilities.

for T_w in [1.0, 2.0, 4.0]:  # compare sharp, softened, and very softened targets.
    probs = softmax_temp_w(teacher_logits_w, T_w)  # compute softened teacher distribution.
    print("T=", T_w, "probs=", np.round(probs, 3))  # inspect probability shape.
```
▶ What you'll see: higher temperature pushes the top probability down and lifts the non-top probabilities.

```python
T_grid_w = np.array([1.0, 2.0, 4.0])  # temperatures to plot.
prob_grid_w = np.vstack([softmax_temp_w(teacher_logits_w, T) for T in T_grid_w])  # one row per temperature.
print("T=2 probability:", np.round(prob_grid_w[1], 3))  # [0.506, 0.307, 0.186].
assert np.allclose(np.round(prob_grid_w[1], 3), np.array([0.506, 0.307, 0.186]))  # lesson numbers.
```
▶ What you'll see: at T=2, the teacher still prefers the top token but makes the alternatives much more visible.

```python
plt.figure(figsize=(5, 3))  # create a grouped line plot.
for j_w, tok_w in enumerate(tokens_w):  # plot each token's probability across temperatures.
    plt.plot(T_grid_w, prob_grid_w[:, j_w], marker="o", label=tok_w)  # one curve per token.
plt.title("2: temperature softens probabilities")  # title the temperature plot.
plt.xlabel("temperature T")  # label temperature axis.
plt.ylabel("probability")  # label probability axis.
plt.legend()  # show token labels.
plt.show()  # display the figure.
```
▶ What you'll see: the top token curve falls while the lower-token curves rise as T increases.

*Why it's done this way: dividing logits by T reduces their gaps. Because softmax is exponential, smaller gaps mean less extreme probability ratios, so a high-temperature target reveals the teacher's ranking among wrong answers instead of collapsing all non-top tokens toward zero.*

### 3. KL divergence transfers the whole distribution

Hard-label cross-entropy trains the student on only the teacher's top token. Distillation instead uses KL divergence from teacher distribution $p$ to student distribution $q$: $$\mathrm{KL}(p\Vert q)=\sum_i p_i\log\frac{p_i}{q_i}.$$ The term is small when the student assigns probability wherever the teacher assigns probability, and large when the student underestimates teacher-preferred tokens.

```python
p_teacher_w = np.array([0.7, 0.2, 0.1])  # a teacher soft target.
q_student_w = np.array([0.5, 0.3, 0.2])  # a student distribution to compare.
kl_terms_w = p_teacher_w * (np.log(p_teacher_w) - np.log(q_student_w))  # per-token KL contributions.
print("per-token KL terms:", np.round(kl_terms_w, 3))  # inspect which tokens drive mismatch.
```
▶ What you'll see: the top token contributes most because the student gives it too little probability.

```python
kl_w = float(np.sum(kl_terms_w))  # sum per-token KL terms.
hard_ce_w = -np.log(q_student_w[0])  # hard-label CE if only token 0 mattered.
print("KL(p||q):", round(kl_w, 3))  # 0.085.
print("hard CE on top token:", round(float(hard_ce_w), 3))  # 0.693.
assert round(kl_w, 3) == 0.085  # lesson number.
```
▶ What you'll see: KL is a distribution-matching penalty, while hard CE ignores how q splits mass across non-top tokens.

```python
x_w = np.arange(3)  # token positions.
plt.figure(figsize=(5, 3))  # create grouped probability bars.
plt.bar(x_w - 0.18, p_teacher_w, width=0.36, label="teacher", color="steelblue")  # teacher probabilities.
plt.bar(x_w + 0.18, q_student_w, width=0.36, label="student", color="orange")  # student probabilities.
plt.xticks(x_w, tokens_w)  # label tokens.
plt.title("3: KL compares full probability shapes")  # title comparison.
plt.ylabel("probability")  # label probability axis.
plt.legend()  # show labels.
plt.show()  # display grouped bars.
```
▶ What you'll see: the student is too flat relative to the teacher; KL charges every token according to teacher weight.

*Why it's done this way: KL weights each log-ratio by the teacher probability. That means matching the teacher's important tokens matters most, but the non-top probabilities still teach similarity structure — the "dark knowledge" discarded by a one-hot label.*

### 4. The T² factor keeps gradient scale comparable

Distillation loss is usually written $$\mathcal L_{KD}=T^2\,\mathrm{KL}(\sigma(z_T/T)\Vert\sigma(z_S/T)).$$ The $T^2$ factor looks strange until you track gradients: dividing logits by $T$ softens probabilities and also shrinks the logit sensitivity. Multiplying by $T^2$ keeps the distillation term from becoming artificially tiny when we raise temperature.

```python
student_logits_w = np.array([1.0, 0.8, -0.4])  # a student that is less confident than the teacher.
for T_w in [1.0, 2.0, 4.0]:  # compare KL with and without T squared.
    pT_w = softmax_temp_w(teacher_logits_w, T_w)  # teacher softened at T.
    qT_w = softmax_temp_w(student_logits_w, T_w)  # student softened at T.
    raw_kl_w = float(np.sum(pT_w * (np.log(pT_w) - np.log(qT_w))))  # KL at temperature T.
    print("T=", T_w, "raw KL=", round(raw_kl_w, 5), "T^2 KL=", round((T_w ** 2) * raw_kl_w, 5))  # inspect scale.
```
▶ What you'll see: raw KL shrinks as T grows, while T²·KL stays on a more comparable scale.

```python
Ts_w = np.array([1.0, 2.0, 4.0, 8.0])  # temperature sweep.
raw_kls_w = []  # store raw KL values.
scaled_kls_w = []  # store T^2-scaled KL values.
for T_w in Ts_w:  # compute each point.
    pT_w = softmax_temp_w(teacher_logits_w, T_w)  # teacher probabilities.
    qT_w = softmax_temp_w(student_logits_w, T_w)  # student probabilities.
    raw = float(np.sum(pT_w * (np.log(pT_w) - np.log(qT_w))))  # raw KL.
    raw_kls_w.append(raw)  # save raw KL.
    scaled_kls_w.append((T_w ** 2) * raw)  # save scaled KL.
print("raw KLs:", np.round(raw_kls_w, 5))  # inspect shrinkage.
print("T^2 KLs:", np.round(scaled_kls_w, 5))  # inspect scaled values.
```
▶ What you'll see: the scaled values vary much less than the raw values across temperatures.

```python
plt.figure(figsize=(5, 3))  # create a scale comparison figure.
plt.plot(Ts_w, raw_kls_w, marker="o", label="raw KL", color="crimson")  # plot raw loss.
plt.plot(Ts_w, scaled_kls_w, marker="o", label="T² × KL", color="seagreen")  # plot scaled loss.
plt.title("4: T² preserves distillation scale")  # title the plot.
plt.xlabel("temperature T")  # label temperature.
plt.ylabel("loss value")  # label loss.
plt.legend()  # show labels.
plt.show()  # display figure.
```
▶ What you'll see: without T² the distillation loss nearly disappears at high temperature.

*Why it's done this way: temperature appears inside softmax as z/T, so changes in student logits affect probabilities more weakly as T rises. The T² multiplier compensates for that scale effect, making temperature a shape knob rather than an accidental learning-rate knob.*

### 5. Combining distillation with the real label

A student can learn from both the teacher and the ground-truth label. A common toy objective is $$\alpha T^2\mathrm{KL}(p_T\Vert q_T)+(1-\alpha)\mathrm{CE}(y,q_1).$$ The KL term transfers the teacher's distributional shape; the hard-label CE keeps the student anchored to the actual correct answer when the teacher is imperfect.

```python
def cross_entropy_onehot_w(class_index, probs):  # hard-label CE from scratch.
    return -float(np.log(probs[class_index]))  # negative log probability of the true class.

y_true_w = 0  # the correct token index.
alpha_w = 0.7  # put more weight on distillation than hard labels.
T_w = 2.0  # use softened teacher and student distributions.
pT_w = softmax_temp_w(teacher_logits_w, T_w)  # teacher soft target at T.
qT_w = softmax_temp_w(student_logits_w, T_w)  # student soft prediction at T.
q1_w = softmax_temp_w(student_logits_w, 1.0)  # normal-temperature student probabilities for CE.
print("q at T=1:", np.round(q1_w, 3))  # inspect hard-label prediction distribution.
```
▶ What you'll see: the student gives the correct token only part of the probability mass.

```python
kd_loss_w = (T_w ** 2) * float(np.sum(pT_w * (np.log(pT_w) - np.log(qT_w))))  # distillation part.
ce_loss_w = cross_entropy_onehot_w(y_true_w, q1_w)  # hard-label part.
combined_w = alpha_w * kd_loss_w + (1 - alpha_w) * ce_loss_w  # weighted objective.
print("KD loss:", round(kd_loss_w, 3), "CE loss:", round(ce_loss_w, 3))  # inspect components.
print("combined loss:", round(combined_w, 3))  # inspect final objective.
```
▶ What you'll see: the combined objective is a weighted compromise between imitation and true-label accuracy.

```python
plt.figure(figsize=(4.5, 3))  # create a loss-component chart.
plt.bar(["KD", "CE", "combined"], [kd_loss_w, ce_loss_w, combined_w], color=["seagreen", "orange", "slateblue"])  # compare terms.
plt.title("5: blended student objective")  # title loss plot.
plt.ylabel("loss")  # label loss axis.
plt.show()  # display bars.
```
▶ What you'll see: alpha controls how much the final loss follows teacher imitation versus label supervision.

*Why it's done this way: teacher distributions can be richer than one-hot labels, but teachers can also be wrong. Mixing KL with CE keeps the student from blindly inheriting every teacher mistake while still learning the teacher's uncertainty pattern.*

### 6. A tiny student learns from a teacher distribution

Now we train the smallest possible "student": just a vector of logits. Gradient descent on KL moves the student's probabilities toward the teacher's softened probabilities. For softmax with cross-entropy/KL, the useful gradient direction is teacher probability minus student probability, so each step raises logits for under-predicted teacher tokens and lowers logits for over-predicted ones.

```python
teacher_target_w = softmax_temp_w(teacher_logits_w, T=2.0)  # softened target distribution.
student_train_logits_w = np.array([-0.2, 0.3, 0.1])  # deliberately mismatched student logits.
print("teacher target:", np.round(teacher_target_w, 3))  # inspect the target shape.
print("student start:", np.round(softmax_temp_w(student_train_logits_w, 2.0), 3))  # inspect start.
```
▶ What you'll see: the student begins too low on the teacher's top token and too high on the others.

```python
losses_w = []  # store distillation loss through training.
for step_w in range(80):  # run tiny gradient descent.
    student_probs_w = softmax_temp_w(student_train_logits_w, T=2.0)  # current student at T.
    loss_w = 4.0 * float(np.sum(teacher_target_w * (np.log(teacher_target_w) - np.log(student_probs_w))))  # T^2 KL.
    grad_direction_w = teacher_target_w - student_probs_w  # ascent direction for matching teacher probabilities.
    student_train_logits_w += 0.4 * grad_direction_w  # update logits toward teacher shape.
    losses_w.append(loss_w)  # record loss.
print("loss start -> end:", round(losses_w[0], 4), "->", round(losses_w[-1], 4))  # inspect improvement.
assert losses_w[-1] < losses_w[0]  # verify training reduced distillation loss.
```
▶ What you'll see: the KL loss falls as the student distribution approaches the teacher distribution.

```python
final_probs_w = softmax_temp_w(student_train_logits_w, T=2.0)  # final student distribution.
print("student final:", np.round(final_probs_w, 3))  # inspect learned probabilities.
plt.figure(figsize=(5, 3))  # create learning curve.
plt.plot(losses_w, color="purple")  # show KL loss over steps.
plt.title("6: student distillation loss decreases")  # title curve.
plt.xlabel("step")  # label step axis.
plt.ylabel("T² KL")  # label loss.
plt.show()  # display curve.
```
▶ What you'll see: a smooth downward curve and final probabilities much closer to the teacher target.

*Why it's done this way: the gradient compares two probability distributions token by token. If the teacher assigns more mass than the student, that logit is raised; if the student assigns too much mass, that logit is lowered. This is the exact imitation pressure used at much larger scale in LM distillation.*

### 7. Compression, inherited mistakes, and the DistilBERT tradeoff

Distillation is useful because a student can be much smaller than the teacher while preserving much of the behavior. DistilBERT is the archetype: fewer layers and parameters, trained to imitate a larger BERT-like teacher. The tradeoff is not magic: the student also inherits teacher biases and mistakes unless the objective includes data or evaluation that corrects them.

```python
teacher_params_w = 340  # millions of parameters in a toy teacher.
student_params_w = 110  # millions of parameters in a compact student.
ratio_w = student_params_w / teacher_params_w  # retained parameter fraction.
print("student/teacher parameter fraction:", f"{ratio_w:.1%}")  # 32.4%.
assert round(ratio_w, 3) == 0.324  # lesson number.
```
▶ What you'll see: the student keeps about one third of the teacher's parameters.

```python
teacher_bad_w = np.array([0.15, 0.75, 0.10])  # teacher is confidently wrong: token 1 gets most mass.
true_label_w = 0  # ground truth says token 0 is correct.
student_match_w = teacher_bad_w.copy()  # a pure imitator would match the teacher.
student_corrected_w = np.array([0.70, 0.20, 0.10])  # hard-label supervision can correct the top answer.
print("pure KD CE on truth:", round(cross_entropy_onehot_w(true_label_w, student_match_w), 3))  # bad truth loss.
print("corrected CE on truth:", round(cross_entropy_onehot_w(true_label_w, student_corrected_w), 3))  # better truth loss.
```
▶ What you'll see: copying a wrong teacher gives a poor true-label loss even if imitation loss is excellent.

```python
plt.figure(figsize=(5, 3))  # create mistake-transfer comparison.
plt.bar(tokens_w, teacher_bad_w, alpha=0.6, label="wrong teacher", color="crimson")  # wrong teacher distribution.
plt.plot(tokens_w, student_corrected_w, marker="o", label="label-corrected student", color="seagreen")  # corrected student.
plt.title("7: distillation can copy teacher mistakes")  # title pitfall plot.
plt.ylabel("probability")  # label probability axis.
plt.legend()  # show labels.
plt.show()  # display plot.
```
▶ What you'll see: the wrong teacher's peak is not the true label, so pure imitation would preserve the mistake.

*Why it's done this way: compression is a deployment constraint, not a guarantee of better knowledge. Distillation transfers the signal present in the teacher distribution; if that signal encodes an error, the student needs hard labels, filtering, or evaluation feedback to avoid copying it.*

### ✍️ Toy 1 · Softmax turns teacher logits into probabilities

A teacher logit vector is just raw scores. Subtract the max, exponentiate, and normalize to get a
probability distribution whose smaller bars still carry distillation signal.

```python
import numpy as np
import matplotlib.pyplot as plt

_t1_rng = np.random.default_rng(0)                    # -> seeded generator for reproducibility
t1_tokens = np.array(["cat", "cot", "car"])          # -> ['cat', 'cot', 'car']
t1_logits = np.array([3.0, 1.0, 0.0])                 # -> [3.0, 1.0, 0.0]
t1_shifted = t1_logits - np.max(t1_logits)            # -> [0.0, -2.0, -3.0]
t1_weights = np.exp(t1_shifted)                       # -> [1.0, 0.135, 0.05]
t1_probs = t1_weights / np.sum(t1_weights)            # -> [0.844, 0.114, 0.042]
print("shifted logits:", t1_shifted.tolist())          # -> [0.0, -2.0, -3.0]
print("exp weights:", np.round(t1_weights, 3).tolist()) # -> [1.0, 0.135, 0.05]
print("teacher probs:", np.round(t1_probs, 3).tolist()) # -> [0.844, 0.114, 0.042]
print("probability sum:", round(float(np.sum(t1_probs)), 3)) # -> 1.0
assert np.allclose(np.round(t1_probs, 3), np.array([0.844, 0.114, 0.042]))

plt.figure(figsize=(4.5, 2.8))
plt.bar(t1_tokens, t1_probs, color=["#4c78a8", "#72b7b2", "#f58518"])
plt.ylim(0, 1)
plt.ylabel("probability")
plt.title("Toy 1 · softmax preserves a full teacher shape")
plt.show()
```
▶ What you'll see: `cat` is the top token, but `cot` and `car` keep nonzero teacher probability.

### ✍️ Toy 2 · Temperature softens dark knowledge

Raising temperature divides logit gaps before softmax. The top token loses mass and the alternatives
become easier for a student to see.

```python
import numpy as np
import matplotlib.pyplot as plt

_t2_rng = np.random.default_rng(0)                    # -> seeded generator for reproducibility
t2_tokens = np.array(["top", "near", "far"])          # -> ['top', 'near', 'far']
t2_logits = np.array([4.0, 2.0, 0.0])                 # -> [4.0, 2.0, 0.0]
t2_scaled_1 = t2_logits / 1.0                         # -> [4.0, 2.0, 0.0]
t2_shifted_1 = t2_scaled_1 - np.max(t2_scaled_1)      # -> [0.0, -2.0, -4.0]
t2_exp_1 = np.exp(t2_shifted_1)                       # -> [1.0, 0.135, 0.018]
t2_probs_1 = t2_exp_1 / np.sum(t2_exp_1)              # -> [0.867, 0.117, 0.016]
t2_scaled_4 = t2_logits / 4.0                         # -> [1.0, 0.5, 0.0]
t2_shifted_4 = t2_scaled_4 - np.max(t2_scaled_4)      # -> [0.0, -0.5, -1.0]
t2_exp_4 = np.exp(t2_shifted_4)                       # -> [1.0, 0.607, 0.368]
t2_probs_4 = t2_exp_4 / np.sum(t2_exp_4)              # -> [0.506, 0.307, 0.186]
print("T=1 probs:", np.round(t2_probs_1, 3).tolist())  # -> [0.867, 0.117, 0.016]
print("T=4 probs:", np.round(t2_probs_4, 3).tolist())  # -> [0.506, 0.307, 0.186]
print("far-token lift:", round(float(t2_probs_4[2] - t2_probs_1[2]), 3)) # -> 0.17
assert t2_probs_4[0] < t2_probs_1[0]
assert t2_probs_4[2] > t2_probs_1[2]

plt.xticks(t2_x, t2_tokens)
plt.ylim(0, 1)
plt.ylabel("probability")
plt.legend()
plt.title("Toy 2 · temperature reveals alternatives")
plt.show()
```
▶ What you'll see: the high-temperature bars are flatter, so the non-top tokens are no longer almost invisible.

### ✍️ Toy 3 · KL divergence compares the whole distribution

KL charges the student for mismatching every teacher-weighted token, not just the top label. A hard
one-hot CE would look only at the first probability.

```python
import numpy as np
import matplotlib.pyplot as plt

_t3_rng = np.random.default_rng(0)                    # -> seeded generator for reproducibility
t3_tokens = np.array(["A", "B", "C"])                 # -> ['A', 'B', 'C']
t3_teacher = np.array([0.6, 0.3, 0.1])                # -> [0.6, 0.3, 0.1]
t3_student = np.array([0.5, 0.25, 0.25])              # -> [0.5, 0.25, 0.25]
t3_log_ratio = np.log(t3_teacher) - np.log(t3_student) # -> [0.182, 0.182, -0.916]
t3_terms = t3_teacher * t3_log_ratio                  # -> [0.109, 0.055, -0.092]
t3_kl = float(np.sum(t3_terms))                       # -> 0.072
t3_hard_ce = -float(np.log(t3_student[0]))            # -> 0.693
print("teacher:", t3_teacher.tolist())                # -> [0.6, 0.3, 0.1]
print("student:", t3_student.tolist())                # -> [0.5, 0.25, 0.25]
print("KL terms:", np.round(t3_terms, 3).tolist())     # -> [0.109, 0.055, -0.092]
print("KL(p||q):", round(t3_kl, 3))                    # -> 0.072
print("hard CE on A:", round(t3_hard_ce, 3))           # -> 0.693
assert round(t3_kl, 3) == 0.072

t3_x = np.arange(t3_tokens.size)
plt.figure(figsize=(4.8, 2.8))
plt.bar(t3_x - 0.18, t3_teacher, width=0.36, label="teacher", color="#4c78a8")
plt.bar(t3_x + 0.18, t3_student, width=0.36, label="student", color="#f58518")
plt.xticks(t3_x, t3_tokens)
plt.ylabel("probability")
plt.legend()
plt.title("Toy 3 · KL sees all token mass")
plt.show()
```
▶ What you'll see: the student puts too much mass on `C`, and KL includes that shape mismatch.

### ✍️ Toy 4 · T² rescales high-temperature KL

Raw KL gets smaller when logits are divided by a large temperature. Multiplying by `T²` keeps the
loss scale from vanishing just because the target was softened.

```python

import matplotlib.pyplot as plt

    t4_scaled = np.asarray(t4_logits, dtype=float) / t4_T
    t4_shifted = t4_scaled - np.max(t4_scaled)
    t4_exp = np.exp(t4_shifted)
    return t4_exp / np.sum(t4_exp)

t4_teacher_logits = np.array([2.0, 0.0, -1.0])        # -> [2.0, 0.0, -1.0]
```

## 🛠️ Setup

```python
import numpy as np # load NumPy for logits, softmax, KL divergence, and tiny optimization loops.
import matplotlib.pyplot as plt # load Matplotlib for probability bars, loss curves, and diagnostic plots.
np.random.seed(0) # make all examples reproducible across notebook runs.

def softmax_temp(logits, T=1.0): # Convert logits into probabilities after temperature scaling.
    scaled = np.asarray(logits, dtype=float) / T # Divide scores by temperature so T controls distribution sharpness.
    scaled = scaled - np.max(scaled) # Subtract the max for numerical stability without changing softmax.
    weights = np.exp(scaled) # Exponentiate shifted scores to get positive unnormalized weights.
    return weights / np.sum(weights) # Normalize weights so they sum to one.

def kl_div(p, q): # Compute KL(p||q) from scratch for positive probability vectors.
    p = np.asarray(p, dtype=float) # Convert teacher probabilities to a float array.
    q = np.asarray(q, dtype=float) # Convert student probabilities to a float array.
    eps = 1e-12 # Use a tiny floor to avoid log(0) in toy numerical experiments.
    return float(np.sum(p * (np.log(p + eps) - np.log(q + eps)))) # Sum p_i log(p_i/q_i) over tokens.

def hard_ce(class_index, probs): # Compute one-hot cross-entropy for one correct class.
    return -float(np.log(np.asarray(probs, dtype=float)[class_index])) # Negative log probability of the true token.
```
