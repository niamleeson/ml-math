# 27.2 — Neuromorphic Computing

Neuromorphic computing treats information as events in time. Instead of recomputing a dense neural network at every clock tick, a spiking system lets membrane voltage integrate evidence, leak old evidence away, emit sparse spikes at thresholds, and update synapses from spike timing.

### 1. Membrane voltage is recurrent memory

A leaky integrate-and-fire (LIF) neuron has a state variable: its membrane voltage. That voltage carries evidence from one time step to the next, so the neuron is a tiny recurrent dynamical system. In continuous time, the passive membrane obeys

$$\tau\frac{dv}{dt}=-(v-v_{rest})+R I(t).$$

Euler integration turns that differential equation into the update

$$v_{t+1}=v_t+\Delta t\frac{-(v_t-v_{rest})+R I_t}{\tau}.$$

The term `-(v - v_rest)` is the leak: voltage is pulled back toward rest unless input current keeps filling it.

```python
dt_w = 1.0  # one millisecond time step for Euler integration.
tau_w = 10.0  # membrane time constant: larger means slower leakage.
v_rest_w = 0.0  # resting voltage baseline.
I_w = np.r_[np.ones(20) * 0.7, np.zeros(30)]  # current arrives, then turns off.
v_w = np.zeros_like(I_w)  # store the voltage trace.
for t_w in range(1, len(I_w)):  # integrate the ODE forward in time.
    dv_w = dt_w * (-(v_w[t_w - 1] - v_rest_w) + I_w[t_w - 1]) / tau_w  # Euler step.
    v_w[t_w] = v_w[t_w - 1] + dv_w  # recurrent state update.
print("voltage after input:", round(float(v_w[20]), 3))  # inspect stored evidence.
print("voltage after decay:", round(float(v_w[-1]), 3))  # inspect leakage after silence.
assert v_w[20] > v_w[-1] > 0  # voltage rises with input and decays afterward.
```
▶ What you'll see: voltage rises while current is present, then fades rather than disappearing instantly.

```python
plt.figure(figsize=(5, 3))
plt.plot(v_w, label="membrane v", color="teal")
plt.plot(I_w, label="input current", color="gray", alpha=0.7)
plt.xlabel("time step"); plt.ylabel("value")
plt.title("1: LIF membrane stores and leaks evidence")
plt.legend(); plt.show()
```
▶ What you'll see: the voltage trace behaves like a leaky bucket: input fills it, leak drains it.

*Why it's done this way: the voltage state is the neuron's short-term memory, so neuromorphic computation can react to temporal structure without storing a separate history buffer.*

### 2. Thresholds turn analog voltage into sparse spikes

A spiking neuron does not transmit every voltage value. It emits an event when the pre-reset voltage crosses a threshold, then resets so the same stored charge does not fire forever:

$$\tilde v_t=v_t+\Delta t\frac{-(v_t-v_{rest})+RI_t}{\tau},\qquad s_t=\mathbf{1}[\tilde v_t\ge\theta],\qquad v_{t+1}=(1-s_t)\tilde v_t+s_t v_{reset}.$$

The hard threshold is the nonlinear activation; the reset is what makes a spike a discrete event rather than a permanent on-state.

```python
def lif_trace_w(current, tau=8.0, threshold=1.0, dt=1.0, v_rest=0.0, v_reset=0.0):
    current = np.asarray(current, dtype=float)
    v = np.zeros(len(current) + 1)
    spikes = np.zeros(len(current))
    pre = np.zeros(len(current))
    for t in range(len(current)):
        pre[t] = v[t] + dt * (-(v[t] - v_rest) + current[t]) / tau
        spikes[t] = 1.0 if pre[t] >= threshold else 0.0
        v[t + 1] = v_reset if spikes[t] else pre[t]
    return v[1:], spikes, pre

I2_w = np.ones(60) * 1.8  # sustained current strong enough to reach threshold repeatedly.
v2_w, s2_w, pre2_w = lif_trace_w(I2_w, tau=8.0, threshold=1.0)
print("spike times:", np.where(s2_w > 0)[0])
print("number of spikes:", int(s2_w.sum()))
assert int(s2_w.sum()) > 0  # the threshold was crossed at least once.
```
▶ What you'll see: the neuron emits a sparse list of spike times instead of a dense output at every step.

```python
plt.figure(figsize=(5, 3))
plt.plot(pre2_w, color="steelblue", label="pre-reset voltage")
plt.scatter(np.where(s2_w > 0)[0], pre2_w[s2_w > 0], color="crimson", label="spikes")
plt.axhline(1.0, color="black", linestyle="--", label="threshold")
plt.xlabel("time step"); plt.ylabel("voltage")
plt.title("2: threshold crossings create events")
plt.legend(); plt.show()
```
▶ What you'll see: spikes occur exactly where the pre-reset trace crosses the threshold.

*Why it's done this way: event emission is the neuromorphic nonlinearity — it converts continuous accumulation into sparse communication that downstream neurons can skip when nothing fires.*

### 3. The leak chooses the memory timescale

The leak constant is not a cosmetic hyperparameter. With a short membrane time constant, voltage forgets old input quickly; with a long time constant, weak evidence can accumulate across a longer window. The same input stream can therefore either vanish or trigger a late spike depending on the leak.

```python
I3_w = np.r_[np.ones(12) * 0.8, np.zeros(38)]  # a brief weak pulse followed by silence.
v_fast_w, s_fast_w, _ = lif_trace_w(I3_w, tau=3.0, threshold=1.5)
v_slow_w, s_slow_w, _ = lif_trace_w(I3_w, tau=18.0, threshold=1.5)
print("fast-leak spikes:", int(s_fast_w.sum()))
print("slow-leak spikes:", int(s_slow_w.sum()))
print("final voltages:", round(float(v_fast_w[-1]), 3), round(float(v_slow_w[-1]), 3))
assert v_slow_w[-1] > v_fast_w[-1]  # after silence, slower leak preserves more pulse evidence.
```
▶ What you'll see: the slow membrane retains more voltage from the same weak input.

```python
plt.figure(figsize=(5, 3))
plt.plot(v_fast_w, label="tau=3 fast leak", color="orange")
plt.plot(v_slow_w, label="tau=18 slow leak", color="teal")
plt.axhline(1.0, color="black", linestyle="--", label="threshold")
plt.xlabel("time step"); plt.ylabel("voltage")
plt.title("3: leak controls memory length")
plt.legend(); plt.show()
```
▶ What you'll see: the slow-leak curve climbs much closer to threshold.

*Why it's done this way: choosing the leak matches the neuron to the signal timescale; too much leak erases meaningful weak evidence, while too little leak preserves stale evidence.*

### 4. Synaptic input is still a weighted sum

Spiking changes *when* information is transmitted, but a postsynaptic neuron still receives weighted evidence. If presynaptic spike vector $x_t$ and weights $w$ arrive at time $t$, the input current is $I_t=x_t^T w$. Sparse spikes make this dot product cheap because inactive presynaptic neurons contribute exactly zero.

```python
X4_w = np.zeros((40, 3))  # three presynaptic spike trains.
X4_w[[5, 12, 19, 26, 33], 0] = 1
X4_w[[8, 16, 24, 32], 1] = 1
X4_w[[12, 13, 14, 15], 2] = 1
w4_w = np.array([0.45, 0.30, 0.20])  # synaptic strengths.
I4_w = X4_w @ w4_w  # event-driven weighted sum into one postsynaptic current.
v4_w, s4_w, _ = lif_trace_w(I4_w, tau=10.0, threshold=0.55)
print("active presynaptic events:", int(X4_w.sum()))
print("postsynaptic spikes:", np.where(s4_w > 0)[0])
assert I4_w[12] == 0.65  # simultaneous events add by a dot product.
```
▶ What you'll see: current is nonzero only at presynaptic event times, and simultaneous spikes add.

```python
plt.figure(figsize=(5, 3))
for n_w in range(3):
    plt.vlines(np.where(X4_w[:, n_w] > 0)[0], n_w + 0.1, n_w + 0.8, color="gray")
plt.plot(v4_w + 3.0, color="teal", label="postsynaptic voltage + offset")
plt.scatter(np.where(s4_w > 0)[0], np.ones(int(s4_w.sum())) * 4.05, color="crimson", label="output spikes")
plt.yticks([0.45, 1.45, 2.45, 3.6], ["pre0", "pre1", "pre2", "v"])
plt.xlabel("time step"); plt.title("4: weighted spikes drive voltage")
plt.legend(loc="upper right"); plt.show()
```
▶ What you'll see: the postsynaptic trace jumps most when multiple weighted spikes arrive together.

*Why it's done this way: neuromorphic hardware can skip multiply-adds for zeros because only actual events need to deliver their weights.*

### 5. STDP learns from relative spike timing

Spike-timing-dependent plasticity (STDP) is a local rule for changing a synapse from the timing difference $\Delta t=t_{post}-t_{pre}$. A common exponential rule is

$$\Delta w=\begin{cases}A_+e^{-\Delta t/\tau_+}, & \Delta t>0\\ -A_-e^{\Delta t/\tau_-}, & \Delta t<0.\end{cases}$$

If the presynaptic spike comes before the postsynaptic spike, the synapse is potentiated; if it comes after, the synapse is depressed.

```python
def stdp_delta_w(delta_t, A_plus=0.08, A_minus=0.06, tau_plus=12.0, tau_minus=15.0):
    delta_t = np.asarray(delta_t, dtype=float)
    return np.where(delta_t > 0, A_plus * np.exp(-delta_t / tau_plus), -A_minus * np.exp(delta_t / tau_minus))

dt_grid_w = np.arange(-40, 41)
dw_grid_w = stdp_delta_w(dt_grid_w)
print("Δw at +5 ms:", round(float(stdp_delta_w(5)), 4))
print("Δw at -5 ms:", round(float(stdp_delta_w(-5)), 4))
assert stdp_delta_w(5) > 0 and stdp_delta_w(-5) < 0  # causal order strengthens, anti-causal weakens.
```
▶ What you'll see: positive timing differences increase the weight, negative differences decrease it.

```python
plt.figure(figsize=(5, 3))
plt.plot(dt_grid_w, dw_grid_w, color="purple")
plt.axhline(0, color="black", linewidth=0.7); plt.axvline(0, color="black", linewidth=0.7)
plt.xlabel("Δt = t_post - t_pre")
plt.ylabel("Δw")
plt.title("5: STDP timing window")
plt.show()
```
▶ What you'll see: a positive lobe for causal pre-before-post timing and a negative lobe for the reverse.

*Why it's done this way: STDP is local in time and synapse state, so it fits event-driven hardware better than a global dense gradient update.*

### 6. Sparse events are the energy story

Neuromorphic systems are interesting when activity is sparse. If a dense layer has 1000 inputs but only 12 spike in a time bin, an event-driven implementation can process 12 weight deliveries instead of 1000 dense multiply-adds. The active fraction, not just model size, determines the possible savings.

```python
rng6_w = np.random.default_rng(6)
rates6_w = np.array([0.01, 0.03, 0.08, 0.20])  # spike probabilities per time step.
active6_w = []
for r_w in rates6_w:
    spikes_w = rng6_w.random((80, 1000)) < r_w
    active6_w.append(float(spikes_w.mean()))
skipped6_w = 1 - np.array(active6_w)
print("active fractions:", np.round(active6_w, 3))
print("skipped fractions:", np.round(skipped6_w, 3))
assert skipped6_w[0] > skipped6_w[-1]  # sparser events skip more work.
```
▶ What you'll see: lower spike rates leave most input lines inactive.

```python
plt.figure(figsize=(5, 3))
plt.plot(rates6_w, skipped6_w, marker="o", color="seagreen")
plt.xlabel("spike probability")
plt.ylabel("fraction of work skipped")
plt.title("6: sparsity creates event-driven savings")
plt.ylim(0, 1.05)
plt.show()
```
▶ What you'll see: skipped work falls as spike probability rises.

*Why it's done this way: sparse spikes are not automatically better accuracy, but they are the mechanism that can make event-driven hardware efficient.*

### 7. Surrogate gradients smooth the hard spike for training

The hard spike function $\mathbf{1}[v\ge\theta]$ is discontinuous, so its ordinary derivative is zero almost everywhere and undefined at the threshold. Gradient-based training therefore often uses a smooth surrogate derivative near threshold while keeping hard spikes in the forward pass.

```python
v7_w = np.linspace(-1.0, 2.0, 300)
theta7_w = 1.0
hard7_w = (v7_w >= theta7_w).astype(float)
beta7_w = 8.0
sig7_w = 1 / (1 + np.exp(-beta7_w * (v7_w - theta7_w)))
surr_grad7_w = beta7_w * sig7_w * (1 - sig7_w)
print("max surrogate gradient:", round(float(surr_grad7_w.max()), 3))
assert surr_grad7_w.max() > 1.9  # the surrogate concentrates learning signal near threshold.
```
▶ What you'll see: the forward spike is hard, while the surrogate derivative forms a smooth bump near threshold.

```python
plt.figure(figsize=(5, 3))
plt.plot(v7_w, hard7_w, label="hard spike", color="crimson")
plt.plot(v7_w, surr_grad7_w / surr_grad7_w.max(), label="scaled surrogate grad", color="navy")
plt.axvline(theta7_w, color="black", linestyle="--", label="threshold")
plt.xlabel("voltage"); plt.ylabel("value")
plt.title("7: surrogate gradient near threshold")
plt.legend(); plt.show()
```
▶ What you'll see: learning signal is concentrated where a small voltage change could flip a spike.

*Why it's done this way: surrogate gradients connect spiking models back to ordinary gradient learning without pretending the threshold is truly smooth.*

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, random spikes, and Euler integration.
import matplotlib.pyplot as plt # load Matplotlib so every example can be inspected visually.
np.random.seed(0) # make stochastic examples reproducible across runs.

def lif_sim(current, tau=10.0, threshold=1.0, dt=1.0, v_rest=0.0, v_reset=0.0, resistance=1.0): # integrate one LIF neuron from input current.
    current = np.asarray(current, dtype=float) # convert current to a predictable numeric vector.
    v = np.zeros(len(current) + 1, dtype=float) # store voltage including the initial state.
    pre = np.zeros(len(current), dtype=float) # store pre-reset voltage for threshold diagnostics.
    spikes = np.zeros(len(current), dtype=float) # store binary output spikes.
    for t in range(len(current)): # step through time with Euler integration.
        dv = dt * (-(v[t] - v_rest) + resistance * current[t]) / tau # Euler approximation to the LIF ODE.
        pre[t] = v[t] + dv # voltage before applying the spike reset.
        spikes[t] = 1.0 if pre[t] >= threshold else 0.0 # hard threshold nonlinearity.
        v[t + 1] = v_reset if spikes[t] else pre[t] # reset after a spike, otherwise keep integrating.
    return v[1:], spikes, pre # return voltage trace, spike train, and pre-reset trace.

def stdp_delta(delta_t, A_plus=0.08, A_minus=0.06, tau_plus=12.0, tau_minus=15.0): # compute an exponential STDP timing-window update.
    delta_t = np.asarray(delta_t, dtype=float) # support scalars and arrays.
    return np.where(delta_t > 0, A_plus * np.exp(-delta_t / tau_plus), -A_minus * np.exp(delta_t / tau_minus)) # causal timing strengthens; anti-causal weakens.

def spike_raster(spike_matrix, title): # draw a compact raster plot for a neurons-by-time binary matrix.
    spike_matrix = np.asarray(spike_matrix) # ensure indexing is consistent.
    plt.figure(figsize=(5, 3)) # create one compact figure.
    rows, cols = np.where(spike_matrix > 0) # locate spike events.
    plt.scatter(cols, rows, s=18, color="black") # plot each spike as one dot.
    plt.xlabel("time step") # label time.
    plt.ylabel("neuron") # label neuron rows.
    plt.title(title) # describe the raster.
    plt.show() # display the raster.
```

## 🟢 Basics

#### B1. Integrate a passive LIF voltage

**Goal.** Use Euler steps to integrate a membrane voltage under a constant current, because neuromorphic neurons are dynamical systems before they are classifiers. We build it in 2 steps.

```python
I_b1 = np.ones(50) * 0.8 # define a steady input current below the no-leak threshold current.
v_b1, spikes_b1, pre_b1 = lif_sim(I_b1, tau=12.0, threshold=2.0) # integrate without spiking by setting a high threshold.
print("first voltages:", np.round(v_b1[:5], 3)) # inspect early Euler accumulation.
print("final voltage:", round(float(v_b1[-1]), 3)) # inspect the approach toward the input-driven steady value.
assert np.all(spikes_b1 == 0) # no threshold crossings should occur in this passive demo.
```

```python
plt.figure(figsize=(5, 3)) # create a voltage trace plot.
plt.plot(v_b1, color="teal", label="membrane voltage") # show the integrated state.
plt.axhline(0.8, color="gray", linestyle="--", label="steady drive") # mark the steady-state target for this simple current.
plt.title("B1: passive membrane integration") # title the plot.
plt.xlabel("time step") # label time.
plt.ylabel("voltage") # label membrane voltage.
plt.legend() # show labels.
plt.show() # display the trace.
```
▶ What you'll see: voltage rises smoothly toward the driving current instead of jumping there instantly.

👀 Takeaway: the membrane equation gives a neuron temporal memory with a controllable time constant.

