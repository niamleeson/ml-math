# 13.3 — CTC & Sequence Transduction

Connectionist Temporal Classification (CTC) is the loss and decoding trick that lets a sequence model learn from long inputs and short targets when no one tells us the frame-by-frame alignment. In this lesson, you will build the collapse rule, the blank symbol, the alignment sum, forward-backward dynamic programming, and simple decoders from scratch with NumPy so the sequence probability is never a black box.

Before the terse worked examples, we build CTC one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including the forward-backward lattice, is derived and shown. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

### 1. Paths, blanks, and the collapse map

CTC begins with a frame-level path. Each frame chooses either a real label such as `a` or `b`, or a special blank `ϵ`. The collapse map first merges consecutive repeats, then deletes blanks. That order matters: `a,a` collapses to one `a`, but `a,ϵ,a` collapses to two `a` characters because the blank separates the repeats.

```python
symbols_w = ["ϵ", "a", "b"]  # blank plus two real labels.
blank_w = "ϵ"  # the distinguished no-label symbol.

def collapse_w(path_w):
    merged_w = []
    prev_w = None
    for token_w in path_w:
        if token_w != prev_w:
            merged_w.append(token_w)
        prev_w = token_w
    return tuple(token_w for token_w in merged_w if token_w != blank_w)

paths_w = [("a", "a"), ("a", "ϵ", "a"), ("ϵ", "a", "a", "ϵ"), ("ϵ", "a", "b")]
for path_w in paths_w:
    print(path_w, "->", collapse_w(path_w))
```
▶ What you'll see: repeated `a,a` becomes one `a`, while `a,ϵ,a` stays two `a` labels after blanks are removed.

```python
max_len_w = max(len(path_w) for path_w in paths_w)
path_grid_w = np.full((len(paths_w), max_len_w), np.nan)
for r_w, path_w in enumerate(paths_w):
    path_grid_w[r_w, :len(path_w)] = [symbols_w.index(tok_w) for tok_w in path_w]
plt.figure(figsize=(5, 2.6))
plt.imshow(path_grid_w, cmap="viridis", aspect="auto")
plt.yticks(range(len(paths_w)), ["".join(p_w) for p_w in paths_w])
plt.xticks(range(max_len_w), [f"t{j}" for j in range(max_len_w)])
plt.colorbar(label="symbol id")
plt.title("1: different paths can collapse to the same label string")
plt.show()
```
▶ What you'll see: visually different frame paths can represent the same transcript after repeat-merge and blank-delete.

*Why it's done this way:* the blank gives the model a way to say "no new character here." Merging repeats before deleting blanks lets a stretched single label (`a,a,a`) differ from a true repeated label (`a,ϵ,a`). Without that separation symbol, repeated letters such as `ll` or `aa` would be ambiguous.

### 2. Alignment marginalization: sum every valid path

If the target is `a` and there are three frames, CTC does not choose one hidden alignment. It sums the probability of every path whose collapse is `a`. For probabilities $p_t(k)$, a path probability is the product $\prod_t p_t(\pi_t)$, and the sequence probability is the sum over all valid paths.

```python
probs_w = np.array([[0.6, 0.3, 0.1],
                    [0.5, 0.4, 0.1],
                    [0.2, 0.6, 0.2]])  # columns are ϵ, a, b.
target_w = ("a",)
print("frame probabilities rows sum to:", probs_w.sum(axis=1))
print("target:", target_w)
assert np.allclose(probs_w.sum(axis=1), 1.0)
```
▶ What you'll see: each frame is a local softmax distribution over blank, `a`, and `b`.

```python
valid_w = []
for i0_w in range(3):
    for i1_w in range(3):
        for i2_w in range(3):
            idx_path_w = (i0_w, i1_w, i2_w)
            sym_path_w = tuple(symbols_w[i_w] for i_w in idx_path_w)
            prob_w = float(np.prod([probs_w[t_w, idx_path_w[t_w]] for t_w in range(3)]))
            if collapse_w(sym_path_w) == target_w:
                valid_w.append((sym_path_w, prob_w))
print("valid paths:", len(valid_w), "of", 3**3)
print("top valid path:", max(valid_w, key=lambda x: x[1]))
```
▶ What you'll see: several alignments collapse to `a`; the best single path is only one part of the total evidence.

```python
ctc_prob_enum_w = sum(prob_w for _, prob_w in valid_w)
best_prob_w = max(prob_w for _, prob_w in valid_w)
print("best single path probability:", round(best_prob_w, 3))
print("summed CTC probability:", round(ctc_prob_enum_w, 3))
print("CTC loss:", round(float(-np.log(ctc_prob_enum_w)), 3))
assert round(ctc_prob_enum_w, 3) == 0.498
```
▶ What you'll see: the sequence probability 0.498 is much larger than the best path 0.180 because all valid alignments get credit.

*Why it's done this way:* the transcript is observed but the alignment is hidden. Summing paths is marginalization: instead of pretending we know where the `a` occurred, we add the probability mass of every monotonic explanation that could have produced it.

### 3. Forward dynamic programming replaces exponential enumeration

Enumeration has $|\mathcal{A}|^T$ paths, which is impossible for real speech. CTC inserts blanks around the target, producing an expanded label sequence such as `[ϵ,a,ϵ]`, then computes forward masses. From state `s` at time `t`, mass can stay, advance by one, or skip over a blank into a new non-repeated label.

```python
extended_w = ["ϵ", "a", "ϵ"]  # target a with blanks inserted before, between, and after labels.
S_w = len(extended_w)
alpha_w = np.zeros((probs_w.shape[0], S_w))
alpha_w[0, 0] = probs_w[0, symbols_w.index(extended_w[0])]
alpha_w[0, 1] = probs_w[0, symbols_w.index(extended_w[1])]
print("extended states:", extended_w)
print("alpha at t=0:", np.round(alpha_w[0], 3))
```
▶ What you'll see: after the first frame, CTC can be at the leading blank or at the first `a`.

```python
for t_w in range(1, probs_w.shape[0]):
    for s_w in range(S_w):
        incoming_w = alpha_w[t_w - 1, s_w]
        if s_w - 1 >= 0:
            incoming_w += alpha_w[t_w - 1, s_w - 1]
        if s_w - 2 >= 0 and extended_w[s_w] != "ϵ" and extended_w[s_w] != extended_w[s_w - 2]:
            incoming_w += alpha_w[t_w - 1, s_w - 2]
        alpha_w[t_w, s_w] = incoming_w * probs_w[t_w, symbols_w.index(extended_w[s_w])]
print("alpha lattice:\n", np.round(alpha_w, 4))
ctc_prob_forward_w = float(alpha_w[-1, -1] + alpha_w[-1, -2])
print("accepting probability:", round(ctc_prob_forward_w, 3))
assert round(ctc_prob_forward_w, 3) == 0.498
```
▶ What you'll see: final mass in the last two states sums to the same 0.498 found by enumeration.

```python
plt.figure(figsize=(5, 3))
plt.imshow(alpha_w, cmap="magma", aspect="auto")
plt.colorbar(label="forward mass α")
plt.xticks(range(S_w), extended_w)
plt.yticks(range(probs_w.shape[0]), [f"t{t}" for t in range(probs_w.shape[0])])
plt.title("3: forward lattice α over expanded target states")
plt.show()
```
▶ What you'll see: mass flows left-to-right through blank, `a`, blank; the bright cells show which partial alignments carry most probability.

*Why it's done this way:* dynamic programming groups exponentially many paths by the state they reach at each frame. The skip rule is the mathematical encoding of CTC's collapse logic: it can jump over a blank only when doing so creates a new label that cannot be confused with a repeated copy.

### 4. Backward probabilities and frame-label responsibility

Forward mass says how much probability reaches a state. Backward mass says how much probability can finish the target from that state. Multiplying $\alpha_{t,s}\beta_{t,s}$ and dividing by $P(y\mid x)$ gives the posterior responsibility of state `s` at frame `t` under all valid alignments.

```python
beta_w = np.zeros_like(alpha_w)
beta_w[-1, -1] = probs_w[-1, symbols_w.index(extended_w[-1])]
beta_w[-1, -2] = probs_w[-1, symbols_w.index(extended_w[-2])]
print("beta at final time:", np.round(beta_w[-1], 3))
```
▶ What you'll see: at the last frame, a valid path can finish in the final blank or final label state.

```python
for t_w in range(probs_w.shape[0] - 2, -1, -1):
    for s_w in range(S_w):
        total_w = beta_w[t_w + 1, s_w]
        if s_w + 1 < S_w:
            total_w += beta_w[t_w + 1, s_w + 1]
        if s_w + 2 < S_w and extended_w[s_w] != "ϵ" and extended_w[s_w] != extended_w[s_w + 2]:
            total_w += beta_w[t_w + 1, s_w + 2]
        beta_w[t_w, s_w] = total_w * probs_w[t_w, symbols_w.index(extended_w[s_w])]
print("beta lattice:\n", np.round(beta_w, 4))
print("start probability:", round(float(beta_w[0, 0] + beta_w[0, 1]), 3))
assert round(float(beta_w[0, 0] + beta_w[0, 1]), 3) == 0.498
```
▶ What you'll see: the backward recursion recovers the same target probability from the beginning.

```python
posterior_w = alpha_w * beta_w / (probs_w[:, [symbols_w.index(z_w) for z_w in extended_w]] * ctc_prob_forward_w)
print("state posterior rows sum to:", np.round(posterior_w.sum(axis=1), 3))
plt.figure(figsize=(5, 3))
plt.imshow(posterior_w, cmap="viridis", aspect="auto", vmin=0, vmax=1)
plt.colorbar(label="posterior responsibility")
plt.xticks(range(S_w), extended_w)
plt.yticks(range(probs_w.shape[0]), [f"t{t}" for t in range(probs_w.shape[0])])
plt.title("4: alpha-beta state responsibilities")
plt.show()
```
▶ What you'll see: each row sums to 1; look for which frame is most responsible for emitting `a` versus blank.

*Why it's done this way:* forward-backward gives soft alignments without choosing one path. The posterior heatmap is the training signal: it tells the network how much each frame should shift probability toward each blank or label, averaged over all legal alignments.

### 5. Greedy and beam decoding are approximations to the best transcript

Training sums alignments for a known target. At inference, we need a transcript. Greedy decoding picks the most likely frame symbol and collapses it. Beam search keeps several partial transcripts and separates probabilities ending in blank from probabilities ending in nonblank, so repeated letters and blank endings are handled correctly.

```python
decode_probs_w = np.array([[0.10, 0.80, 0.10],
                           [0.70, 0.20, 0.10],
                           [0.10, 0.75, 0.15],
                           [0.20, 0.10, 0.70]])
greedy_idx_w = np.argmax(decode_probs_w, axis=1)
greedy_path_w = tuple(symbols_w[i_w] for i_w in greedy_idx_w)
greedy_text_w = "".join(collapse_w(greedy_path_w))
print("greedy path:", greedy_path_w)
print("collapsed text:", greedy_text_w)
assert greedy_text_w == "aab"
```
▶ What you'll see: the blank between two `a` frames lets greedy decoding output `aab` rather than collapsing to `ab`.

```python
def beam_decode_w(probs_in_w, beam_width_w=3):
    beams_w = {(): (1.0, 0.0)}  # prefix -> (prob ending blank, prob ending nonblank).
    for t_w in range(probs_in_w.shape[0]):
        new_w = {}
        for prefix_w, (pb_w, pnb_w) in beams_w.items():
            total_w = pb_w + pnb_w
            for k_w, sym_w in enumerate(symbols_w):
                p_w = probs_in_w[t_w, k_w]
                if sym_w == "ϵ":
                    nb_pb_w, nb_pnb_w = new_w.get(prefix_w, (0.0, 0.0))
                    new_w[prefix_w] = (nb_pb_w + total_w * p_w, nb_pnb_w)
                else:
                    new_prefix_w = prefix_w + (sym_w,)
                    nb_pb_w, nb_pnb_w = new_w.get(new_prefix_w, (0.0, 0.0))
                    if prefix_w and prefix_w[-1] == sym_w:
                        nb_pnb_w += pb_w * p_w
                        old_pb_w, old_pnb_w = new_w.get(prefix_w, (0.0, 0.0))
                        new_w[prefix_w] = (old_pb_w, old_pnb_w + pnb_w * p_w)
                    else:
                        nb_pnb_w += total_w * p_w
                    new_w[new_prefix_w] = (nb_pb_w, nb_pnb_w)
        beams_w = dict(sorted(new_w.items(), key=lambda kv_w: sum(kv_w[1]), reverse=True)[:beam_width_w])
    return sorted([(pref_w, pb_w + pnb_w) for pref_w, (pb_w, pnb_w) in beams_w.items()], key=lambda x_w: x_w[1], reverse=True)

beam_w = beam_decode_w(decode_probs_w, beam_width_w=4)
print("beam results:", [("".join(p_w), round(s_w, 4)) for p_w, s_w in beam_w])
```
▶ What you'll see: beam search returns multiple transcript candidates with summed prefix probabilities, not just one framewise argmax path.

```python
names_w = ["".join(p_w) if p_w else "∅" for p_w, _ in beam_w]
scores_w = [s_w for _, s_w in beam_w]
plt.figure(figsize=(5, 3))
plt.bar(names_w, scores_w, color="teal")
plt.title("5: beam transcript probabilities")
plt.ylabel("summed probability in beam")
plt.show()
```
▶ What you'll see: a compact ranking of transcript hypotheses; the top one is the beam's approximate decoded output.

*Why it's done this way:* greedy is cheap but commits to a single frame path. Prefix beam search is closer to the CTC objective because it keeps probability mass grouped by collapsed transcript and tracks blank/nonblank endings so repeated labels are treated legally.

## 🛠️ Setup

```python
import numpy as np  # load NumPy for arrays, synthetic emissions, dynamic programming, and assertions.
import matplotlib.pyplot as plt  # load Matplotlib for heatmaps, lattice plots, bars, and diagnostics.
np.random.seed(0)  # make all stochastic examples reproducible.

BLANK = "ϵ"  # name the CTC blank symbol used throughout the lesson.
VOCAB = [BLANK, "a", "b", "c"]  # define a small alphabet for toy sequence transduction.

def collapse_path(path):  # collapse a CTC frame path into an output label tuple.
    merged = []  # store labels after consecutive-repeat merging.
    prev = None  # remember the previous frame symbol.
    for token in path:  # scan frame symbols left to right.
        if token != prev:  # keep only the first symbol in each run.
            merged.append(token)  # append the run representative.
        prev = token  # update the previous symbol.
    return tuple(token for token in merged if token != BLANK)  # delete blanks after merging repeats.

def extend_target(target):  # insert blanks around and between target labels.
    out = [BLANK]  # start with a leading blank state.
    for token in target:  # process each target label.
        out += [token, BLANK]  # add the label followed by an inter-label blank.
    return out  # return the expanded CTC state sequence.

def ctc_forward(probs, target, vocab=VOCAB):  # compute forward masses for a target.
    ext = extend_target(target)  # expanded target with blanks.
    T, S = probs.shape[0], len(ext)  # number of frames and CTC states.
    alpha = np.zeros((T, S))  # allocate the forward lattice.
    alpha[0, 0] = probs[0, vocab.index(ext[0])]  # start in the leading blank.
    if S > 1:  # allow starting at the first label too.
        alpha[0, 1] = probs[0, vocab.index(ext[1])]  # initialize first label state.
    for t in range(1, T):  # fill later frames.
        for s in range(S):  # fill each expanded target state.
            total = alpha[t - 1, s]  # stay at the same state.
            if s - 1 >= 0:  # advance one state.
                total += alpha[t - 1, s - 1]  # add one-step predecessor.
            if s - 2 >= 0 and ext[s] != BLANK and ext[s] != ext[s - 2]:  # legal skip over blank.
                total += alpha[t - 1, s - 2]  # add skip predecessor.
            alpha[t, s] = total * probs[t, vocab.index(ext[s])]  # emit this state's symbol at frame t.
    prob = float(alpha[-1, -1] + (alpha[-1, -2] if S > 1 else 0.0))  # final blank or final label accepts.
    return alpha, ext, prob  # return lattice, expanded states, and target probability.

def ctc_backward(probs, target, vocab=VOCAB):  # compute backward masses for a target.
    ext = extend_target(target)  # expanded target with blanks.
    T, S = probs.shape[0], len(ext)  # number of frames and states.
    beta = np.zeros((T, S))  # allocate the backward lattice.
    beta[-1, -1] = probs[-1, vocab.index(ext[-1])]  # finish in the final blank.
    if S > 1:  # finish in the final label too.
        beta[-1, -2] = probs[-1, vocab.index(ext[-2])]  # initialize final label state.
    for t in range(T - 2, -1, -1):  # move backward through time.
        for s in range(S):  # compute each state.
            total = beta[t + 1, s]  # stay at same state next frame.
            if s + 1 < S:  # advance one state next frame.
                total += beta[t + 1, s + 1]  # add one-step successor.
            if s + 2 < S and ext[s] != BLANK and ext[s] != ext[s + 2]:  # legal skip successor.
                total += beta[t + 1, s + 2]  # add skip-over-blank successor.
            beta[t, s] = total * probs[t, vocab.index(ext[s])]  # include current-frame emission.
    prob = float(beta[0, 0] + (beta[0, 1] if S > 1 else 0.0))  # starting blank or first label accepts.
    return beta, ext, prob  # return lattice, states, and target probability.

def greedy_decode(probs, vocab=VOCAB):  # decode by framewise argmax followed by CTC collapse.
    idx = np.argmax(probs, axis=1)  # choose the most likely symbol at every frame.
    path = tuple(vocab[i] for i in idx)  # convert ids to symbols.
    return path, collapse_path(path)  # return raw path and collapsed transcript.

def simple_beam_decode(probs, beam_width=3, vocab=VOCAB):  # prefix beam search with blank/nonblank bookkeeping.
    beams = {(): (1.0, 0.0)}  # prefix -> (prob ending blank, prob ending nonblank).
    for t in range(probs.shape[0]):  # process frames left to right.
        new = {}  # collect updated prefixes.
        for prefix, (pb, pnb) in beams.items():  # expand each current prefix.
            total = pb + pnb  # total mass assigned to this prefix.
            for k, sym in enumerate(vocab):  # try every next frame symbol.
                p = probs[t, k]  # local emission probability.
                if sym == BLANK:  # blank keeps the same prefix.
                    old_pb, old_pnb = new.get(prefix, (0.0, 0.0))  # read existing mass.
                    new[prefix] = (old_pb + total * p, old_pnb)  # add blank-ending mass.
                else:  # nonblank may extend or repeat the prefix.
                    new_prefix = prefix + (sym,)  # candidate extension.
                    old_pb, old_pnb = new.get(new_prefix, (0.0, 0.0))  # read extension mass.
                    if prefix and prefix[-1] == sym:  # repeated last label needs special handling.
                        old_pnb += pb * p  # repeat after blank creates a true extra label.
                        same_pb, same_pnb = new.get(prefix, (0.0, 0.0))  # same prefix receives collapsed repeat mass.
                        new[prefix] = (same_pb, same_pnb + pnb * p)  # repeat without blank collapses to same prefix.
                    else:
                        old_pnb += total * p  # ordinary extension.
                    new[new_prefix] = (old_pb, old_pnb)  # write extension mass.
        beams = dict(sorted(new.items(), key=lambda kv: kv[1][0] + kv[1][1], reverse=True)[:beam_width])  # prune.
    return sorted([(p, pb + pnb) for p, (pb, pnb) in beams.items()], key=lambda x: x[1], reverse=True)  # rank prefixes.

def show_lattice(mat, states, title):  # visualize a CTC dynamic-programming lattice.
    plt.figure(figsize=(5, 3))  # create a compact heatmap.
    plt.imshow(mat, cmap="viridis", aspect="auto")  # draw state mass as color.
    plt.colorbar(label="mass")  # add numeric color scale.
    plt.xticks(range(len(states)), states)  # label expanded target states.
    plt.yticks(range(mat.shape[0]), [f"t{t}" for t in range(mat.shape[0])])  # label frames.
    plt.title(title)  # title the diagnostic figure.
    plt.xlabel("expanded target state")  # label state axis.
    plt.ylabel("frame")  # label time axis.
    plt.show()  # display the lattice.
```

### Basic 4 — One path probability is a product over frames

**Goal.** Multiply local emission probabilities along a path, because one alignment probability is a product of frame decisions. We build it in 2 steps.

```python
probs_b4 = np.array([[0.6, 0.3, 0.1, 0.0], [0.5, 0.4, 0.1, 0.0], [0.2, 0.6, 0.2, 0.0]])
path_b4 = ("ϵ", "ϵ", "a")
idx_b4 = [VOCAB.index(tok_b4) for tok_b4 in path_b4]
print("path columns:", idx_b4)
```
▶ What you'll see: the path selects blank, blank, then `a` columns.

```python
factors_b4 = np.array([probs_b4[t_b4, idx_b4[t_b4]] for t_b4 in range(len(path_b4))])
prob_b4 = float(np.prod(factors_b4))
```

### Advanced 1 — Use log-space forward recursion

**Goal.** Recompute CTC probability in log space, because real utterances can underflow in raw probability space. We build it in 4 steps.

```python
probs_a1 = np.array([[0.45, 0.45, 0.08, 0.02], [0.20, 0.55, 0.20, 0.05], [0.25, 0.10, 0.60, 0.05], [0.55, 0.10, 0.30, 0.05]])

ext_a1 = extend_target(target_a1)
logp_a1 = np.log(probs_a1)
print("expanded:", ext_a1)
```
▶ What you'll see: the same expanded states are used, but emissions become log probabilities.

```python
def logsumexp_a1(vals_a1):
    vals_a1 = np.array(vals_a1, dtype=float)
    m_a1 = np.max(vals_a1)
    if np.isneginf(m_a1):
        return -np.inf
    return float(m_a1 + np.log(np.sum(np.exp(vals_a1 - m_a1))))
T_a1, S_a1 = probs_a1.shape[0], len(ext_a1)
la_a1 = np.full((T_a1, S_a1), -np.inf)
la_a1[0, 0] = logp_a1[0, VOCAB.index(ext_a1[0])]
la_a1[0, 1] = logp_a1[0, VOCAB.index(ext_a1[1])]
print("log alpha t0:", np.round(la_a1[0], 3))
```
▶ What you'll see: impossible states start at negative infinity.

```python
for t_a1 in range(1, T_a1):
    for s_a1 in range(S_a1):
        preds_a1 = [la_a1[t_a1 - 1, s_a1]]
        if s_a1 - 1 >= 0:
            preds_a1.append(la_a1[t_a1 - 1, s_a1 - 1])
        if s_a1 - 2 >= 0 and ext_a1[s_a1] != BLANK and ext_a1[s_a1] != ext_a1[s_a1 - 2]:
            preds_a1.append(la_a1[t_a1 - 1, s_a1 - 2])
        la_a1[t_a1, s_a1] = logsumexp_a1(preds_a1) + logp_a1[t_a1, VOCAB.index(ext_a1[s_a1])]
log_prob_a1 = logsumexp_a1([la_a1[-1, -1], la_a1[-1, -2]])
_, _, prob_raw_a1 = ctc_forward(probs_a1, target_a1)
print("log-space prob:", round(float(np.exp(log_prob_a1)), 4), "raw prob:", round(prob_raw_a1, 4))
assert abs(float(np.exp(log_prob_a1)) - prob_raw_a1) < 1e-12
```
▶ What you'll see: log-space and raw-space probabilities match on the toy example.

```python
plt.figure(figsize=(5, 3)); plt.imshow(la_a1, cmap="viridis", aspect="auto")
plt.xticks(range(S_a1), ext_a1); plt.yticks(range(T_a1), [f"t{i}" for i in range(T_a1)])
plt.colorbar(label="log α"); plt.title("Advanced 1: log-space α lattice"); plt.show()
```
▶ What you'll see: log masses stay finite and comparable across the lattice.

👀 Takeaway: production CTC uses log-sum-exp to avoid multiplying tiny probabilities directly.

**Goal.** Contrast monotonic and reordered targets, because CTC only advances left-to-right through the target as time moves forward. We build it in 4 steps.
