# 3.16 — Generalized Linear Models

Generalized Linear Models (GLMs) keep the useful simplicity of a linear score while changing the probability model and the link function to match the kind of outcome we are predicting. In this lesson, we build the contract from scratch: a random response distribution, a linear predictor, a link that maps the mean to that predictor, and a decision score that adds empirical fit, cost, validation evidence, and stabilization instead of trusting the prettiest training number alone.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build generalized linear models one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math is exposed so the model is not a black box. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, vectorized math, and small numerical checks.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for synthetic examples.
```
▶ What you'll see: the only two libraries used in this notebook are NumPy and Matplotlib.

### 1. The GLM contract: random part, linear predictor, link

A GLM separates three jobs. The **random part** says what kind of outcome is plausible: Gaussian for roughly continuous measurements, Bernoulli for 0/1 outcomes, Poisson for counts. The **linear predictor** is the reusable score `η = Xβ`. The **link** says how the conditional mean `μ = E[Y|X]` lives on the linear-predictor scale: `g(μ)=η`. That separation is the reason one linear-looking model can handle prices, clicks, and event counts without pretending they share the same noise.

```python
x_w = np.array([1.0, 2.0])  # one feature vector with an intercept already omitted for clarity.
beta_w = np.array([0.4, -0.7])  # one coefficient per feature.
eta_w = float(x_w @ beta_w)  # the linear predictor Xβ.
print("x:", x_w, "beta:", beta_w)  # inspect the ingredients.
print("linear predictor eta:", round(eta_w, 3))  # 1*0.4 + 2*(-0.7) = -1.0.
assert round(eta_w, 3) == -1.0  # verify the worked score.
```
▶ What you'll see: a single unrestricted linear score `η=-1.0` that can be reused by different links.

```python
mu_identity_w = eta_w  # Gaussian identity link: μ = η.
mu_logit_w = 1 / (1 + np.exp(-eta_w))  # Bernoulli logit inverse link: μ is a probability.
mu_log_w = np.exp(eta_w)  # Poisson log inverse link: μ is a positive count rate.
print("identity mean:", round(mu_identity_w, 3))  # can be any real value.
print("logistic mean:", round(mu_logit_w, 3))  # must land in (0, 1).
print("log-link mean:", round(mu_log_w, 3))  # must be positive.
assert round(mu_logit_w, 3) == 0.269 and round(mu_log_w, 3) == 0.368  # verify link outputs.
```
▶ What you'll see: the same `η=-1` becomes a real-valued mean, a probability, or a positive rate depending on the link.

```python
eta_grid_w = np.linspace(-4, 4, 200)  # possible linear predictor values.
plt.figure(figsize=(5, 3))  # compact link comparison.
plt.plot(eta_grid_w, eta_grid_w, label="identity inverse")  # Gaussian mean.
plt.plot(eta_grid_w, 1 / (1 + np.exp(-eta_grid_w)), label="logit inverse")  # probability.
plt.plot(eta_grid_w, np.exp(eta_grid_w), label="log inverse")  # count rate.
plt.ylim(-1, 8)  # keep the exponential curve readable.
plt.xlabel("linear predictor η")  # x-axis is the shared score.
plt.ylabel("mean μ")  # y-axis is the outcome-scale mean.
plt.title("1: one linear score, different mean scales")  # title the diagnostic.
plt.legend()  # show curve names.
plt.show()  # display the link curves.
```
▶ What you'll see: identity stays unbounded, logistic squeezes into `[0,1]`, and the log inverse stays positive.

*Why it's done this way:* the linear predictor is allowed to be any real number because dot products naturally are. The link is the mathematical adapter that turns that unconstrained score into a valid mean for the response distribution: probabilities cannot be below 0 or above 1, and count rates cannot be negative.

### 2. Logistic GLM for Bernoulli outcomes

For a 0/1 outcome, the conditional mean is a probability: `μ = P(Y=1|X)`. The logit link uses `log(μ/(1-μ)) = Xβ`, so the inverse link is the sigmoid. We train by negative log-likelihood, which is the loss that rewards assigning high probability to the observed class and sharply penalizes confident wrong predictions.

```python
X_w2 = np.array([[1.0, -1.0], [1.0, 0.0], [1.0, 1.0], [1.0, 2.0]])  # intercept plus one feature.
y_w2 = np.array([0.0, 0.0, 1.0, 1.0])  # Bernoulli labels.
beta_w2 = np.array([-0.2, 1.1])  # intercept and slope.
eta_w2 = X_w2 @ beta_w2  # linear scores for all examples.
p_w2 = 1 / (1 + np.exp(-eta_w2))  # probabilities from the inverse-logit link.
print("eta:", np.round(eta_w2, 3))  # inspect unrestricted scores.
print("probabilities:", np.round(p_w2, 3))  # inspect valid class-1 probabilities.
assert np.all((p_w2 > 0) & (p_w2 < 1))  # probabilities stay in the legal range.
```
▶ What you'll see: increasing feature values raise `η`, and the sigmoid turns those scores into probabilities.

```python
eps_w2 = 1e-12  # numerical guard for log(0).
losses_w2 = -(y_w2 * np.log(p_w2 + eps_w2) + (1 - y_w2) * np.log(1 - p_w2 + eps_w2))  # Bernoulli NLL.
print("per-example logistic losses:", np.round(losses_w2, 3))  # inspect individual fit costs.
print("average loss:", round(float(np.mean(losses_w2)), 3))  # empirical risk for this beta.
assert round(float(np.mean(losses_w2)), 3) == 0.327  # verify the average.
```
▶ What you'll see: examples whose observed label gets high probability have smaller loss.

```python
plt.figure(figsize=(5, 3))  # create a probability curve figure.
xs_w2 = np.linspace(-2, 3, 200)  # feature grid.
X_grid_w2 = np.column_stack([np.ones_like(xs_w2), xs_w2])  # add intercept column.
plt.plot(xs_w2, 1 / (1 + np.exp(-(X_grid_w2 @ beta_w2))), color="teal")  # fitted probability curve.
plt.scatter(X_w2[:, 1], y_w2, color="black", zorder=3)  # observed binary outcomes.
plt.ylim(-0.05, 1.05)  # probability axis.
plt.xlabel("feature x")  # label feature axis.
plt.ylabel("P(Y=1|x)")  # label probability axis.
plt.title("2: logistic GLM maps a line to probabilities")  # title the plot.
plt.show()  # display the curve.
```
▶ What you'll see: the probability smoothly rises from near 0 to near 1 while observations remain binary dots.

*Why it's done this way:* the Bernoulli likelihood is the probability model for binary data. Taking its negative log gives an additive loss over examples, and the sigmoid link guarantees that every linear score produces a valid probability before the likelihood is evaluated.

### 3. Poisson GLM for count outcomes

For count data, the mean is a nonnegative event rate. The log link uses `log(μ)=Xβ`, so the inverse link is `μ=exp(Xβ)`. The Poisson negative log-likelihood, up to constants independent of the model, is `μ - y log μ`; it charges the model for predicting rates that are too high and for assigning too little rate to large observed counts.

```python
X_w3 = np.array([[1.0, 0.0], [1.0, 0.5], [1.0, 1.0], [1.0, 1.5]])  # intercept plus exposure feature.
y_w3 = np.array([1.0, 2.0, 4.0, 5.0])  # observed counts.
beta_w3 = np.array([0.1, 0.9])  # log-rate intercept and slope.
eta_w3 = X_w3 @ beta_w3  # log mean rates.
mu_w3 = np.exp(eta_w3)  # positive mean counts.
print("log rates eta:", np.round(eta_w3, 3))  # inspect the linear predictor.
print("count means mu:", np.round(mu_w3, 3))  # inspect valid positive rates.
assert np.all(mu_w3 > 0)  # count rates are never negative.
```
▶ What you'll see: the log-rate grows linearly, while the actual expected count grows multiplicatively.

```python
losses_w3 = mu_w3 - y_w3 * np.log(mu_w3)  # Poisson NLL without log(y!), which does not affect beta comparisons.
avg_w3 = float(np.mean(losses_w3))  # empirical Poisson risk.
print("Poisson losses without constants:", np.round(losses_w3, 3))  # inspect fit costs.
print("average:", round(avg_w3, 3))  # summarize the empirical risk.
assert round(avg_w3, 3) == -0.658  # constants omitted, so this can be negative.
```
▶ What you'll see: because the `log(y!)` constants are omitted, only model-dependent comparisons matter.

```python
xs_w3 = np.linspace(0, 2, 200)  # feature grid.
mu_grid_w3 = np.exp(np.column_stack([np.ones_like(xs_w3), xs_w3]) @ beta_w3)  # fitted count mean.
plt.figure(figsize=(5, 3))  # compact count-rate plot.
plt.plot(xs_w3, mu_grid_w3, color="purple")  # mean count curve.
plt.scatter(X_w3[:, 1], y_w3, color="black", zorder=3)  # observed counts.
plt.xlabel("feature x")  # label feature axis.
plt.ylabel("expected count μ")  # label response mean.
plt.title("3: Poisson GLM keeps count means positive")  # title the plot.
plt.show()  # display the curve.
```
▶ What you'll see: the expected count curve is always above zero and bends upward as `x` increases.

*Why it's done this way:* counts are asymmetric and bounded below by zero, so an identity-link linear regression can predict impossible negative rates. The log link makes multiplicative rate changes linear in coefficients while preserving positivity.

### 4. Empirical risk is the average of per-example losses

The lesson's toy arithmetic starts with three verified losses: `0.257`, `0.135`, and `0.505`. The empirical risk is not mysterious — it is just their average. Larger datasets use the same move; they only hide it behind loops and vectorized operations.

```python
losses_w4 = np.array([0.257, 0.135, 0.505])  # verified per-example losses from the lesson.
risk_w4 = float(np.mean(losses_w4))  # empirical risk R_S.
print("losses:", losses_w4)  # inspect the raw per-example terms.
print("sum:", round(float(np.sum(losses_w4)), 3), "average R_S:", round(risk_w4, 3))  # 0.897 / 3.
assert round(float(np.sum(losses_w4)), 3) == 0.897 and round(risk_w4, 3) == 0.299  # verify lesson arithmetic.
```
▶ What you'll see: `R_S = 0.897/3 = 0.299`.

```python
plt.figure(figsize=(4.5, 3))  # create a loss bar chart.
plt.bar(["ex1", "ex2", "ex3"], losses_w4, color="steelblue")  # show individual losses.
plt.axhline(risk_w4, color="crimson", linestyle="--", label="average R_S")  # show empirical risk.
plt.ylabel("loss")  # label the loss scale.
plt.title("4: empirical risk averages examples")  # title the plot.
plt.legend()  # show the average line label.
plt.show()  # display the chart.
```
▶ What you'll see: the dashed line is the mean height of the three loss bars.

*Why it's done this way:* ERM chooses parameters by minimizing an average because each example is a sampled piece of evidence about future performance. Averaging keeps the scale comparable when the dataset size changes, while summing would double just because we duplicated the dataset.

### 5. Cost, regularization, and the score used for selection

The prose warns that raw fit is not the whole decision. A model can reduce training loss by becoming too flexible, too expensive, or too unstable. So the selection score adds a cost term: `score = R_S + cost`. Here the cost is `0.090`, so the score is not `0.299`; it is `0.389`.

```python
risk_w5 = 0.299  # empirical risk from the toy calculation.
cost_w5 = 0.090  # complexity, regularization, or operational cost.
score_w5 = risk_w5 + cost_w5  # selection score.
print("raw empirical risk:", risk_w5)  # inspect fit term.
print("cost term:", cost_w5)  # inspect guardrail term.
print("decision score:", round(score_w5, 3))  # inspect full score.
assert round(score_w5, 3) == 0.389  # verify lesson number.
```
▶ What you'll see: the decision score is higher than the raw empirical risk because it includes the cost.

```python
plt.figure(figsize=(4.5, 3))  # create a stacked score figure.
plt.bar(["score"], [risk_w5], color="seagreen", label="R_S")  # fit component.
plt.bar(["score"], [cost_w5], bottom=[risk_w5], color="orange", label="cost")  # cost component.
plt.ylabel("selection score")  # label numeric scale.
plt.title("5: score = empirical risk + cost")  # title the plot.
plt.legend()  # show stack labels.
plt.show()  # display the stacked bar.
```
▶ What you'll see: the orange cost segment is part of the score, not decoration.

*Why it's done this way:* training fit estimates how well the model explains observed data, but cost encodes the price of flexibility or deployment. Adding the two makes the comparison match the actual objective rather than letting a fragile low training loss win by default.

### 6. Comparing alternatives with absolute and relative gaps

A more flexible alternative reaches score `0.429`. Since lower is better, the baseline score `0.389` wins by an absolute gap of `0.040`. The relative gap `(0.429-0.389)/0.429` is about `9.3%`, which is often a more honest reading than the raw difference because it expresses the improvement on the scale of the alternative.

```python
baseline_w6 = 0.389  # full score for the simpler GLM choice.
flex_w6 = 0.429  # full score for a tempting flexible alternative.
gap_w6 = flex_w6 - baseline_w6  # absolute advantage of the lower score.
rel_gap_w6 = gap_w6 / flex_w6  # advantage relative to the flexible score.
print("absolute gap:", round(gap_w6, 3))  # 0.040.
print("relative gap:", round(rel_gap_w6, 3))  # 0.093.
assert round(gap_w6, 3) == 0.040 and round(rel_gap_w6, 3) == 0.093  # verify lesson numbers.
```
▶ What you'll see: the simpler baseline is lower by `0.040`, or roughly `9.3%` of the flexible score.

```python
plt.figure(figsize=(4.5, 3))  # create a model-score comparison.
plt.bar(["baseline", "flexible"], [baseline_w6, flex_w6], color=["teal", "crimson"])  # compare selection scores.
plt.ylabel("full decision score")  # lower is better.
plt.title("6: compare scores on the same scale")  # title the plot.
plt.show()  # display the bars.
```
▶ What you'll see: the baseline bar is shorter, but the margin is modest.

*Why it's done this way:* comparing scores only makes sense after they include the same terms and live on the same scale. The gap is the evidence for preferring one method; if that gap is small relative to noise, validation or resampling may overturn the apparent winner.

### 7. Stabilization as an end-to-end decision

If a stabilizing knob reduces the baseline decision score by `20%`, the new score is `0.80 × 0.389 = 0.311`. The final decision compares the baseline, the flexible alternative, and the stabilized version on the same score scale, then carries forward the minimum.

```python
baseline_w7 = 0.389  # original full score.
flex_w7 = 0.429  # flexible alternative score.
stable_w7 = 0.80 * baseline_w7  # stabilized score after a 20% reduction.
scores_w7 = np.array([baseline_w7, flex_w7, stable_w7])  # collect comparable scores.
labels_w7 = np.array(["baseline", "flexible", "stabilized"])  # model names.
print("scores:", np.round(scores_w7, 3))  # inspect all options.
print("winner:", labels_w7[int(np.argmin(scores_w7))])  # choose the minimum score.
assert round(stable_w7, 3) == 0.311 and labels_w7[int(np.argmin(scores_w7))] == "stabilized"  # verify lesson decision.
```
▶ What you'll see: the stabilized score is `0.311`, the lowest of the three.

```python
plt.figure(figsize=(5, 3))  # create final decision plot.
colors_w7 = ["gray", "crimson", "seagreen"]  # color stabilized as the winner.
plt.bar(labels_w7, scores_w7, color=colors_w7)  # compare full scores.
plt.ylabel("full decision score")  # lower is better.
plt.title("7: end-to-end GLM model choice")  # title the plot.
plt.show()  # display the bars.
```
▶ What you'll see: the stabilized bar is visibly lowest, so it is the option to carry forward in this toy case.

*Why it's done this way:* stabilization is not magic; it is a constraint or penalty that trades some flexibility for less brittle future behavior. The correct decision unit is the full score implied by the method, not a raw training fragment viewed in isolation.

### ✍️ Toy 1 · One linear predictor feeds different inverse links

The same `η = Xβ` values can become an identity mean, a Bernoulli probability, or a Poisson rate depending on the GLM link.

```python
import numpy as np  # -> arrays, dot products, and inverse links.
import matplotlib.pyplot as plt  # -> one picture per toy.

t1_rng = np.random.default_rng(0)  # -> seeded generator for reproducibility.
t1_X = np.array([[1.0, -1.0], [1.0, -0.5], [1.0, 0.0], [1.0, 0.5], [1.0, 1.0], [1.0, 1.5]])  # -> 6 rows with intercept
t1_beta = np.array([-0.2, 0.8])  # -> intercept and slope
t1_eta = t1_X @ t1_beta  # -> [-1.0, -0.6, -0.2, 0.2, 0.6, 1.0]
t1_mu_identity = t1_eta  # -> [-1.0, -0.6, -0.2, 0.2, 0.6, 1.0]
t1_mu_logit = 1 / (1 + np.exp(-t1_eta))  # -> [0.269, 0.354, 0.45, 0.55, 0.646, 0.731]
t1_mu_log = np.exp(t1_eta)  # -> [0.368, 0.549, 0.819, 1.221, 1.822, 2.718]
print("eta:", np.round(t1_eta, 3).tolist())  # -> [-1.0, -0.6, -0.2, 0.2, 0.6, 1.0]
print("identity means:", np.round(t1_mu_identity, 3).tolist())  # -> [-1.0, -0.6, -0.2, 0.2, 0.6, 1.0]
print("logit means:", np.round(t1_mu_logit, 3).tolist())  # -> [0.269, 0.354, 0.45, 0.55, 0.646, 0.731]
print("log-link means:", np.round(t1_mu_log, 3).tolist())  # -> [0.368, 0.549, 0.819, 1.221, 1.822, 2.718]
assert np.allclose(np.round(t1_mu_logit, 3), [0.269, 0.354, 0.45, 0.55, 0.646, 0.731])
assert np.all(t1_mu_log > 0)

plt.figure(figsize=(4.8, 3.0))
plt.plot(t1_eta, t1_mu_identity, marker="o", label="identity")
plt.plot(t1_eta, t1_mu_logit, marker="s", label="logit inverse")
plt.plot(t1_eta, t1_mu_log, marker="^", label="log inverse")
plt.xlabel("linear predictor η")
plt.ylabel("mean μ")
plt.title("Toy 1 · one η, three mean scales")
plt.legend()
plt.show()
```
▶ What you'll see: identity stays unbounded, logit stays between `0` and `1`, and log-link means stay positive.

### ✍️ Toy 2 · Bernoulli GLM uses sigmoid probabilities and log loss

For binary outcomes, the GLM mean is a probability, and Bernoulli negative log-likelihood averages one loss per label.

```python
import numpy as np  # -> arrays, sigmoid, and logarithms.

t2_rng = np.random.default_rng(0)  # -> seeded generator for reproducibility.
t2_X = np.array([[1.0, -2.0], [1.0, -1.0], [1.0, 0.0], [1.0, 1.0], [1.0, 2.0], [1.0, 3.0]])  # -> 6 examples
t2_y = np.array([0., 0., 0., 1., 1., 1.])  # -> Bernoulli labels
t2_beta = np.array([-0.3, 0.9])  # -> logit coefficients
t2_eta = t2_X @ t2_beta  # -> [-2.1, -1.2, -0.3, 0.6, 1.5, 2.4]
t2_p = 1 / (1 + np.exp(-t2_eta))  # -> [0.109, 0.231, 0.426, 0.646, 0.818, 0.917]
t2_pos_term = t2_y * np.log(t2_p)  # -> [-0.0, -0.0, -0.0, -0.437, -0.201, -0.087]
t2_neg_term = (1 - t2_y) * np.log(1 - t2_p)  # -> [-0.116, -0.263, -0.554, -0.0, -0.0, -0.0]
t2_losses = -(t2_pos_term + t2_neg_term)  # -> [0.116, 0.263, 0.554, 0.437, 0.201, 0.087]
t2_avg = float(t2_losses.mean())  # -> 0.276
print("eta:", np.round(t2_eta, 3).tolist())  # -> [-2.1, -1.2, -0.3, 0.6, 1.5, 2.4]
print("probabilities:", np.round(t2_p, 3).tolist())  # -> [0.109, 0.231, 0.426, 0.646, 0.818, 0.917]
print("Bernoulli losses:", np.round(t2_losses, 3).tolist())  # -> [0.116, 0.263, 0.554, 0.437, 0.201, 0.087]
print("average loss:", round(t2_avg, 3))  # -> 0.276
assert round(t2_avg, 3) == 0.276
assert np.all((t2_p > 0) & (t2_p < 1))

plt.figure(figsize=(4.8, 3.0))
plt.scatter(t2_X[:, 1], t2_y, color="black", label="labels")
plt.plot(t2_X[:, 1], t2_p, marker="o", color="teal", label="P(Y=1)")
plt.xlabel("feature x")
plt.ylabel("probability / label")
plt.title("Toy 2 · Bernoulli GLM")
plt.legend()
plt.show()
```
▶ What you'll see: the sigmoid probabilities rise with `x`, and their average log loss is `0.276`.

### ✍️ Toy 3 · Poisson GLM keeps count means positive

For counts, the log link turns linear predictors into positive rates, and the Poisson loss compares those rates to observed counts.

```python
import numpy as np  # -> arrays, exponentials, and Poisson loss.

t3_rng = np.random.default_rng(0)  # -> seeded generator for reproducibility.
t3_X = np.array([[1.0, 0.0], [1.0, 0.4], [1.0, 0.8], [1.0, 1.2], [1.0, 1.6], [1.0, 2.0]])  # -> 6 rows
t3_y = np.array([1., 1., 2., 3., 5., 6.])  # -> observed counts

t3_mu = np.exp(t3_eta)  # -> [1.105, 1.462, 1.935, 2.56, 3.387, 4.482]

t3_avg = float(t3_losses.mean())  # -> -0.798
print("log rates eta:", np.round(t3_eta, 3).tolist())  # -> [0.1, 0.38, 0.66, 0.94, 1.22, 1.5]
print("positive means:", np.round(t3_mu, 3).tolist())  # -> [1.105, 1.462, 1.935, 2.56, 3.387, 4.482]
print("Poisson losses:", np.round(t3_losses, 3).tolist())  # -> [1.005, 1.082, 0.615, -0.26, -2.713, -4.518]
print("average loss:", round(t3_avg, 3))  # -> -0.798
assert np.all(t3_mu > 0)
assert round(t3_avg, 3) == -0.798

plt.figure(figsize=(4.8, 3.0))
plt.scatter(t3_X[:, 1], t3_y, color="black", label="counts")
plt.plot(t3_X[:, 1], t3_mu, marker="o", color="purple", label="mean μ")

plt.ylabel("count / mean")
plt.title("Toy 3 · log link makes positive rates")
plt.legend()
plt.show()
```
▶ What you'll see: every mean is positive, and the omitted Poisson constants let the comparison loss be negative.

### ✍️ Toy 4 · Empirical risk is the mean of GLM losses

No matter which GLM family produced them, per-example losses become empirical risk by averaging.

```python
import numpy as np  # -> arrays and averages.

assert round(t4_sum, 3) == 1.78
assert round(t4_risk, 3) == 0.297

plt.figure(figsize=(4.8, 3.0))
plt.bar(range(len(t4_losses)), t4_losses, color="steelblue")

plt.ylabel("loss")
plt.title("Toy 4 · GLM empirical risk")
plt.legend()
plt.show()
```
▶ What you'll see: the dashed mean line is `0.297`, the single training-risk number.

### Easy 1 — Fit a tiny logistic GLM by gradient descent

**Goal.** Optimize Bernoulli negative log-likelihood from scratch, because logistic GLMs learn coefficients by reducing probability loss on observed labels. We build it in 4 steps.

```python
X_e1 = np.array([[1.0, -2.0], [1.0, -1.0], [1.0, 0.5], [1.0, 1.5], [1.0, 2.5]])  # Intercept plus one feature.
y_e1 = np.array([0.0, 0.0, 1.0, 1.0, 1.0])  # Binary outcomes.
beta_e1 = np.zeros(2)  # Start with neutral coefficients.
print("initial beta:", beta_e1)  # Inspect starting point.
```
▶ What you'll see: the model starts with zero intercept and zero slope.

```python
losses_e1 = []  # Store the training loss curve.
for step_e1 in range(600):  # Run deterministic full-batch gradient descent.
    eta_e1 = X_e1 @ beta_e1  # Compute linear predictors.
    p_e1 = 1 / (1 + np.exp(-eta_e1))  # Convert scores to probabilities.
    loss_e1 = -np.mean(y_e1 * np.log(p_e1 + 1e-12) + (1 - y_e1) * np.log(1 - p_e1 + 1e-12))  # Mean Bernoulli NLL.
    grad_e1 = X_e1.T @ (p_e1 - y_e1) / len(y_e1)  # Gradient of mean NLL.
    beta_e1 -= 0.4 * grad_e1  # Take a descent step.
    losses_e1.append(float(loss_e1))  # Record the loss.
print("final beta:", np.round(beta_e1, 3), "loss:", round(losses_e1[-1], 3))  # Inspect learned coefficients.
assert losses_e1[-1] < losses_e1[0]  # Verify learning reduced the loss.
```
▶ What you'll see: the slope becomes positive because larger feature values correspond to class 1.

X_grid_e1 = np.column_stack([np.ones_like(xs_e1), xs_e1])  # Add intercept column.

### Easy 5 — Tune a ridge penalty for logistic GLM

**Goal.** Sweep regularization strengths, because the penalty term controls how much flexibility the logistic GLM is allowed to use. We build it in 4 steps.

```python
X_e5 = np.array([[1.0, -2.0], [1.0, -1.0], [1.0, 0.2], [1.0, 1.2], [1.0, 2.0], [1.0, 2.8]])  # Intercept plus feature.
y_e5 = np.array([0.0, 0.0, 0.0, 1.0, 1.0, 1.0])  # Binary outcomes.
lams_e5 = np.array([0.0, 0.01, 0.1, 1.0])  # Regularization grid.
print("lambda grid:", lams_e5)  # Inspect candidate penalties.
```
▶ What you'll see: the sweep ranges from no ridge penalty to a strong penalty.

```python
losses_e5 = []  # Store final penalized objectives.
norms_e5 = []  # Store coefficient sizes.
for lam_e5 in lams_e5:  # Train one model per penalty.
    beta_e5 = np.zeros(2)  # Reset coefficients for a fair comparison.
    for step_e5 in range(700):  # Full-batch gradient descent.
        p_e5 = 1 / (1 + np.exp(-(X_e5 @ beta_e5)))  # Current probabilities.
        grad_e5 = X_e5.T @ (p_e5 - y_e5) / len(y_e5) + lam_e5 * np.array([0.0, beta_e5[1]])  # Ridge on slope only.
        beta_e5 -= 0.35 * grad_e5  # Descent step.
    p_e5 = 1 / (1 + np.exp(-(X_e5 @ beta_e5)))  # Final probabilities.
    nll_e5 = -np.mean(y_e5 * np.log(p_e5 + 1e-12) + (1 - y_e5) * np.log(1 - p_e5 + 1e-12))  # Final NLL.
    obj_e5 = nll_e5 + 0.5 * lam_e5 * beta_e5[1] ** 2  # Penalized objective.
    losses_e5.append(float(obj_e5))  # Save objective.
    norms_e5.append(float(np.linalg.norm(beta_e5)))  # Save coefficient norm.
print("objectives:", np.round(losses_e5, 3))  # Inspect final penalized scores.
print("beta norms:", np.round(norms_e5, 3))  # Inspect shrinkage.
```
▶ What you'll see: stronger regularization shrinks coefficients, even if the fit term changes.

```python
best_idx_e5 = int(np.argmin(losses_e5))  # Pick the penalty with the lowest penalized objective.
print("best lambda by penalized objective:", lams_e5[best_idx_e5])  # Inspect selected penalty.
assert len(losses_e5) == 4 and np.all(np.isfinite(losses_e5))  # Verify the sweep produced valid scores.
```
▶ What you'll see: one λ has the lowest full objective for this tiny dataset.

```python

plt.xscale("symlog", linthresh=0.01)  # Make zero and positive lambdas readable.
plt.title("Easy 5: ridge penalty sweep")  # Title the plot.
plt.xlabel("λ")  # Label penalty axis.
plt.legend()  # Show curve labels.
plt.show()  # Display the sweep.
```
▶ What you'll see: increasing λ generally shrinks coefficient size, demonstrating the stability-flexibility tradeoff.

👀 Takeaway: regularization is a tuning knob for GLM stability, so the chosen score must include its cost.

### Advanced 2 — Use iteratively reweighted least squares for logistic GLM

**Goal.** Perform Newton-style GLM fitting from scratch, because logistic regression can be optimized by repeatedly solving a weighted least-squares system. We build it in 4 steps.

```python
X_a2 = np.array([[1.0, -2.0], [1.0, -1.0], [1.0, 0.5], [1.0, 1.0], [1.0, 2.0]])  # Intercept plus feature.
y_a2 = np.array([0.0, 0.0, 1.0, 1.0, 1.0])  # Binary labels.
beta_a2 = np.zeros(2)  # Initialize coefficients.
print("initial beta:", beta_a2)  # Inspect start.
```
▶ What you'll see: IRLS starts from the same neutral model as gradient descent.

```python
losses_a2 = []  # Store Newton losses.
for it_a2 in range(8):  # A few IRLS iterations are enough for this tiny data.
    eta_a2 = X_a2 @ beta_a2  # Current linear predictor.
    p_a2 = 1 / (1 + np.exp(-eta_a2))  # Current probabilities.
    W_a2 = np.clip(p_a2 * (1 - p_a2), 1e-6, None)  # Bernoulli variances used as weights.
    z_a2 = eta_a2 + (y_a2 - p_a2) / W_a2  # Working response from the Taylor approximation.
    XtW_a2 = X_a2.T * W_a2  # Weighted design transpose.
    beta_a2 = np.linalg.solve(XtW_a2 @ X_a2 + 0.01 * np.eye(2), XtW_a2 @ z_a2)  # Ridge-stabilized weighted least squares.
    loss_a2 = -np.mean(y_a2 * np.log(p_a2 + 1e-12) + (1 - y_a2) * np.log(1 - p_a2 + 1e-12))  # Track NLL before update.
    losses_a2.append(float(loss_a2))  # Save loss.
print("IRLS beta:", np.round(beta_a2, 3))  # Inspect fitted coefficients.
assert losses_a2[-1] < losses_a2[0]  # Verify the Newton iterations improved loss.
```
▶ What you'll see: IRLS reaches a positive slope in only a few weighted least-squares updates.

```python
p_fit_a2 = 1 / (1 + np.exp(-(X_a2 @ beta_a2)))  # Final fitted probabilities.
print("fitted probabilities:", np.round(p_fit_a2, 3))  # Inspect predictions.
assert np.all((p_fit_a2 > 0) & (p_fit_a2 < 1))  # Verify legal probabilities.
```
▶ What you'll see: fitted probabilities are low on negative features and high on positive features.

```python
plt.figure(figsize=(5, 3))  # Create IRLS convergence plot.
plt.plot(losses_a2, marker="o", color="navy")  # Plot loss by iteration.
plt.title("Advanced 2: IRLS reduces logistic NLL")  # Title the plot.
plt.xlabel("IRLS iteration")  # Label iteration axis.
plt.ylabel("NLL")  # Label loss axis.
plt.show()  # Display convergence.
```
▶ What you'll see: Newton-style weighted least squares quickly reduces the logistic objective.

👀 Takeaway: IRLS works because the GLM likelihood is locally approximated by a weighted quadratic problem.
