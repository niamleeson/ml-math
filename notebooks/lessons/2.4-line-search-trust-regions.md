# 2.4 — Line Search & Trust Regions

Line search and trust regions are the safeguards that turn a descent direction into a reliable optimizer step. A local gradient or quadratic model is useful only near the current point, so this lesson builds two safety policies: shrink the step length along a chosen direction, or shrink the region where the local model is allowed to choose a step.

## 📖 Concept walkthrough — build each idea from scratch

Before the worked examples, we build the safety logic one idea at a time. Run each cell in order and inspect the printed values: the important part is not just that a step is accepted or rejected, but why the inequality or ratio is the right mathematical test.

```python
import numpy as np
import matplotlib.pyplot as plt
np.random.seed(0)
```

### 1. Why a descent direction still needs a step-size safeguard

A descent direction points downhill infinitesimally, but it does not promise that a long jump will land downhill. We start with the one-dimensional quadratic from the lesson, where the direction points from `x=0` toward the minimizer, then deliberately try a step that is too long.

```python
def f_w1(x_w1):
    return (x_w1 - 2.0) ** 2

def grad_w1(x_w1):
    return 2.0 * (x_w1 - 2.0)

x_w1 = 0.0
p_w1 = -grad_w1(x_w1)
print("x:", x_w1, "f(x):", f_w1(x_w1), "gradient:", grad_w1(x_w1), "direction p:", p_w1)
assert p_w1 == 4.0
```
▶ What you'll see: the gradient is `-4`, so the negative-gradient direction is the positive step `p=4`.

```python
alphas_w1 = np.array([1.0, 0.5, 0.25])
trial_x_w1 = x_w1 + alphas_w1 * p_w1
trial_f_w1 = f_w1(trial_x_w1)
print("alpha:", alphas_w1)
print("trial x:", trial_x_w1)
print("trial f:", trial_f_w1)
assert np.allclose(trial_f_w1, [4.0, 0.0, 1.0])
```
▶ What you'll see: the full step goes from `x=0` to `x=4`, which has the same objective value as where we started.

```python
x_grid_w1 = np.linspace(-0.5, 4.5, 200)
plt.figure(figsize=(5, 3))
plt.plot(x_grid_w1, f_w1(x_grid_w1), color="navy")
plt.scatter(trial_x_w1, trial_f_w1, color=["crimson", "seagreen", "orange"], zorder=3)
for a_w1, tx_w1, tf_w1 in zip(alphas_w1, trial_x_w1, trial_f_w1):
    plt.text(tx_w1, tf_w1 + 0.25, f"α={a_w1}", ha="center")
plt.title("1: a downhill direction can still overshoot")
plt.xlabel("x")
plt.ylabel("f(x)")
plt.show()
```
▶ What you'll see: `α=0.5` lands at the minimum, while `α=1` jumps across the bowl and wastes the descent direction.

*Why it's done this way:* The derivative says what happens for an infinitesimal move: `g*p < 0` means the first-order change is negative near `x`. But a finite move samples the true curved function, not just its tangent. Step-size safeguards exist because local slope information becomes unreliable as the step gets longer.

### 2. Armijo backtracking line search

Line search keeps the direction fixed and shrinks only the scalar distance `α`. Armijo's rule accepts a step only when the real objective decrease is at least a fraction of the linear decrease predicted by the directional derivative:

$$f(x+\alpha p)\le f(x)+c\alpha \nabla f(x)^T p.$$

The right-hand side is lower than `f(x)` when `p` is a descent direction, so the test rejects tiny accidental improvements and asks for sufficient decrease.

```python
x_w2 = 0.0
p_w2 = 4.0
c_w2 = 0.5
g_w2 = grad_w1(x_w2)
f0_w2 = f_w1(x_w2)
dir_deriv_w2 = g_w2 * p_w2
print("f(x):", f0_w2, "g*p:", dir_deriv_w2)
assert dir_deriv_w2 == -16.0
```
▶ What you'll see: the directional derivative is `-16`, so the Armijo target drops as `α` grows.

```python
alpha_w2 = 1.0
history_w2 = []
for _ in range(6):
    left_w2 = f_w1(x_w2 + alpha_w2 * p_w2)
    right_w2 = f0_w2 + c_w2 * alpha_w2 * dir_deriv_w2
    accepted_w2 = left_w2 <= right_w2
    history_w2.append((alpha_w2, left_w2, right_w2, accepted_w2))
    print(f"alpha={alpha_w2:.3f}  f_trial={left_w2:.3f}  Armijo_bound={right_w2:.3f}  accept={accepted_w2}")
    if accepted_w2:
        break
    alpha_w2 *= 0.5
assert history_w2[0][3] == False and history_w2[1][3] == True
```
▶ What you'll see: `α=1` is rejected because `4 <= -4` is false, then `α=0.5` is accepted because `0 <= 0` is true.

```python
hist_alpha_w2 = np.array([row[0] for row in history_w2])
hist_left_w2 = np.array([row[1] for row in history_w2])
hist_right_w2 = np.array([row[2] for row in history_w2])
plt.figure(figsize=(5, 3))
plt.plot(hist_alpha_w2, hist_left_w2, marker="o", label="actual f(x+αp)")
plt.plot(hist_alpha_w2, hist_right_w2, marker="s", label="Armijo bound")
plt.gca().invert_xaxis()
plt.title("2: backtracking until sufficient decrease")
plt.xlabel("alpha tried")
plt.ylabel("value")
plt.legend()
plt.show()
```
▶ What you'll see: shrinking `α` moves the trial point from unsafe to acceptable because actual decrease finally meets the required decrease.

*Why it's done this way:* The Armijo bound uses the tangent-line prediction `f(x)+α g^T p`, then relaxes it by `c` because the tangent is only local. Backtracking by a constant factor is simple and robust: it never changes the descent direction, only asks the same direction to be trusted over a shorter interval.

### 3. Exact line search on a quadratic

For a true quadratic, the best step length along a fixed direction can be computed exactly. If

$$f(x)=\frac12 x^T Hx,$$

then along `x + αp`, the derivative with respect to `α` is `pᵀ(Hx + αHp)`. Setting it to zero gives

$$\alpha^*= -\frac{p^T Hx}{p^T H p}.$$

For steepest descent on this quadratic, `p=-g` and this becomes `α=(gᵀg)/(gᵀHg)`.

```python
H_w3 = np.diag([2.0, 8.0])
x_w3 = np.array([2.0, 1.0])
g_w3 = H_w3 @ x_w3
p_w3 = -g_w3
print("H:\n", H_w3)
print("x:", x_w3, "g=Hx:", g_w3, "p=-g:", p_w3)
assert np.allclose(g_w3, [4.0, 8.0])
```
▶ What you'll see: the steep second coordinate creates a much larger gradient component.

```python
num_w3 = float(g_w3 @ g_w3)
den_w3 = float(g_w3 @ H_w3 @ g_w3)
alpha_star_w3 = num_w3 / den_w3
print("g^T g:", num_w3)
print("g^T H g:", den_w3)
print("alpha*:", round(alpha_star_w3, 7))
assert round(alpha_star_w3, 7) == 0.1470588
```
▶ What you'll see: the best distance is about `0.147`, not `1.0`, because curvature is steep along the gradient direction.

```python
def quad_w3(x_vec_w3):
    return 0.5 * float(x_vec_w3 @ H_w3 @ x_vec_w3)

alpha_grid_w3 = np.linspace(0, 0.4, 120)
line_vals_w3 = np.array([quad_w3(x_w3 + a_w3 * p_w3) for a_w3 in alpha_grid_w3])
print("f before:", quad_w3(x_w3), "f after exact step:", round(quad_w3(x_w3 + alpha_star_w3 * p_w3), 3))
plt.figure(figsize=(5, 3))
plt.plot(alpha_grid_w3, line_vals_w3, color="purple")
plt.axvline(alpha_star_w3, color="crimson", linestyle="--", label=f"α*={alpha_star_w3:.3f}")
plt.title("3: exact line search minimizes along one direction")
plt.xlabel("alpha")
plt.ylabel("f(x + alpha p)")
plt.legend()
plt.show()
```
▶ What you'll see: the one-dimensional slice is a parabola, and the formula lands at its minimum.

*Why it's done this way:* On a quadratic, curvature along the chosen direction is exactly `pᵀHp`. Dividing gradient energy by that curvature picks the distance where the directional derivative becomes zero, so there is no need to guess or backtrack for this special model.

### 4. Trust-region steps and the actual/predicted reduction ratio

A trust-region method does not first pick a direction and then shrink it. Instead, it builds a local model and solves for the best step inside a ball `||s|| <= Δ`. After trying the step, it compares what actually happened to what the model predicted:

$$\rho=\frac{f(x)-f(x+s)}{m(0)-m(s)}.$$

Large `ρ` means the model was trustworthy; small or negative `ρ` means the local model overpromised.

```python
def f_w4(x_w4):
    return (x_w4 - 2.0) ** 2 + 0.15 * (x_w4 - 2.0) ** 4

def local_model_w4(s_w4, f0_w4, g_w4, B_w4):
    return f0_w4 + g_w4 * s_w4 + 0.5 * B_w4 * s_w4 ** 2

x_w4 = 0.0
f0_w4 = f_w4(x_w4)
g_w4 = -4.0 + 0.6 * (x_w4 - 2.0) ** 3
B_w4 = 2.0 + 1.8 * (x_w4 - 2.0) ** 2
print("f0:", round(f0_w4, 3), "g:", round(g_w4, 3), "B:", round(B_w4, 3))
```
▶ What you'll see: the local quadratic has a gradient and curvature computed at the current point.

```python
deltas_w4 = np.array([0.25, 0.75, 1.5])
steps_w4 = []
for Delta_w4 in deltas_w4:
    newton_s_w4 = -g_w4 / B_w4
    s_w4 = np.clip(newton_s_w4, -Delta_w4, Delta_w4)
    predicted_w4 = local_model_w4(0.0, f0_w4, g_w4, B_w4) - local_model_w4(s_w4, f0_w4, g_w4, B_w4)
    actual_w4 = f0_w4 - f_w4(x_w4 + s_w4)
    rho_w4 = actual_w4 / predicted_w4
    steps_w4.append((Delta_w4, s_w4, predicted_w4, actual_w4, rho_w4))
    print(f"Delta={Delta_w4:.2f}  step={s_w4:.3f}  predicted={predicted_w4:.3f}  actual={actual_w4:.3f}  rho={rho_w4:.3f}")
assert all(row[2] > 0 for row in steps_w4)
```
▶ What you'll see: each radius gives a permitted step and a ratio measuring whether the local model deserved that freedom.

```python
rho_examples_w4 = np.array([0.61 / 0.60, 0.10 / 1.00])
print("good rho:", round(rho_examples_w4[0], 3), "bad rho:", round(rho_examples_w4[1], 3))
assert round(rho_examples_w4[0], 3) == 1.017
assert round(rho_examples_w4[1], 3) == 0.1
plt.figure(figsize=(5, 3))
plt.bar(["good model", "bad model"], rho_examples_w4, color=["seagreen", "crimson"])
plt.axhline(0.75, color="black", linestyle="--", label="expand threshold")
plt.axhline(0.25, color="gray", linestyle=":", label="contract threshold")
plt.title("4: rho decides whether to trust the model more")
plt.ylabel("actual / predicted reduction")
plt.legend()
plt.show()
```
▶ What you'll see: a ratio near `1` supports expanding the radius, while a ratio near `0` argues for contraction.

*Why it's done this way:* A trust region treats the local model as a hypothesis about a neighborhood, not a global truth. The ratio `ρ` is a calibration test: if predicted and actual reductions match, the radius can grow; if the prediction was much too optimistic, the next model must be trusted only in a smaller region.

## 🟢 Basics (warm-up)

### Basic 1 — Evaluate the objective and gradient

**Goal.** Start from a tiny quadratic objective, because line search needs a current value, a slope, and a candidate direction.

```python
def f_b1(x_b1):
    return (x_b1 - 2.0) ** 2

def grad_b1(x_b1):
    return 2.0 * (x_b1 - 2.0)

x_b1 = 0.0
g_b1 = grad_b1(x_b1)
p_b1 = -g_b1
print("f(x):", f_b1(x_b1), "gradient:", g_b1, "descent direction:", p_b1)
assert g_b1 == -4.0 and p_b1 == 4.0
```
▶ What you'll see: the negative gradient points right toward the minimizer at `x=2`.

👀 Takeaway: a descent method begins by turning the gradient into a candidate direction.

### Basic 2 — Try several fixed step sizes

**Goal.** Compare trial points for different `α`, because a good direction can still be paired with a poor distance.

```python
x_b2 = 0.0
p_b2 = 4.0
alphas_b2 = np.array([1.0, 0.5, 0.25])
trial_x_b2 = x_b2 + alphas_b2 * p_b2
trial_f_b2 = (trial_x_b2 - 2.0) ** 2
print("trial x:", trial_x_b2)
print("trial f:", trial_f_b2)
assert np.allclose(trial_f_b2, [4.0, 0.0, 1.0])
```
▶ What you'll see: the half step is best, while the full step overshoots.

```python
plt.figure(figsize=(4, 3))
plt.bar(["α=1", "α=0.5", "α=0.25"], trial_f_b2, color=["crimson", "seagreen", "orange"])
plt.title("Basic 2: objective after trial steps")
plt.ylabel("f(x + αp)")
plt.show()
```
▶ What you'll see: the accepted-looking step has the smallest bar.

👀 Takeaway: step length is a modeling choice, not a detail to ignore.

### Basic 3 — Compute the directional derivative

**Goal.** Check whether `p` is locally downhill, because Armijo requires `gᵀp < 0` before line search makes sense.

```python
g_b3 = -4.0
p_b3 = 4.0
dir_b3 = g_b3 * p_b3
print("g*p:", dir_b3)
assert dir_b3 == -16.0
```
▶ What you'll see: the directional derivative is negative, so infinitesimal movement along `p` decreases the tangent model.

```python
alpha_b3 = np.linspace(0, 0.4, 5)
linear_change_b3 = alpha_b3 * dir_b3
print("linearized changes:", linear_change_b3)
plt.figure(figsize=(4, 3))
plt.plot(alpha_b3, 4.0 + linear_change_b3, marker="o")
plt.title("Basic 3: first-order prediction")
plt.xlabel("alpha")
plt.ylabel("linear model")
plt.show()
```
▶ What you'll see: the tangent model decreases linearly as `α` grows.

👀 Takeaway: `gᵀp` is the local decrease rate promised by the chosen direction.

### Basic 4 — Test one Armijo inequality

**Goal.** Evaluate both sides of Armijo for a full step, because sufficient decrease is stricter than merely not increasing.

```python
x_b4 = 0.0
p_b4 = 4.0
g_b4 = -4.0
c_b4 = 0.5
alpha_b4 = 1.0
left_b4 = (x_b4 + alpha_b4 * p_b4 - 2.0) ** 2
right_b4 = (x_b4 - 2.0) ** 2 + c_b4 * alpha_b4 * g_b4 * p_b4
print("left f_trial:", left_b4, "right Armijo bound:", right_b4, "accept:", left_b4 <= right_b4)
assert left_b4 == 4.0 and right_b4 == -4.0
```
▶ What you'll see: the full step is rejected even though it did not make the objective larger.

👀 Takeaway: Armijo rejects weak progress because it asks for enough decrease relative to the slope.

### Basic 5 — Backtrack by halving alpha

**Goal.** Implement the smallest possible backtracking loop, because practical line search repeatedly shrinks an unsafe full step.

```python
x_b5 = 0.0
p_b5 = 4.0
g_b5 = -4.0
c_b5 = 0.5
alpha_b5 = 1.0
accepted_b5 = False
for k_b5 in range(4):
    f_trial_b5 = (x_b5 + alpha_b5 * p_b5 - 2.0) ** 2
    armijo_b5 = (x_b5 - 2.0) ** 2 + c_b5 * alpha_b5 * g_b5 * p_b5
    print(k_b5, "alpha", alpha_b5, "f_trial", f_trial_b5, "bound", armijo_b5)
    if f_trial_b5 <= armijo_b5:
        accepted_b5 = True
        break
    alpha_b5 *= 0.5
assert accepted_b5 and alpha_b5 == 0.5
```
▶ What you'll see: the loop rejects `1.0`, halves it, then accepts `0.5`.

👀 Takeaway: backtracking is just a systematic way to find a safe distance along a fixed direction.

### Basic 6 — Visualize the Armijo bound

**Goal.** Plot actual trial values against the sufficient-decrease line, because the line search decision is geometric.

```python
alpha_b6 = np.linspace(0, 1, 101)
f_actual_b6 = (0.0 + alpha_b6 * 4.0 - 2.0) ** 2
f_bound_b6 = 4.0 + 0.5 * alpha_b6 * (-16.0)
accepted_mask_b6 = f_actual_b6 <= f_bound_b6
```

```python
plt.figure(figsize=(5, 3))
plt.plot(alpha_b6, f_actual_b6, label="actual")

plt.fill_between(alpha_b6, 0, 5, where=accepted_mask_b6, color="seagreen", alpha=0.15, label="accepted")

```
▶ What you'll see: accepted `α` values are where the actual curve lies below the Armijo line.

👀 Takeaway: sufficient decrease compares the real curved objective to a relaxed tangent prediction.

### Basic 7 — Compute a quadratic line-search step

**Goal.** Use the closed-form step for a quadratic, because exact line search is possible when the local model is exact.

```python
H_b7 = np.diag([2.0, 8.0])
x_b7 = np.array([2.0, 1.0])
g_b7 = H_b7 @ x_b7
num_b7 = float(g_b7 @ g_b7)
```

### Basic 8 — Clip a step to a trust radius

**Goal.** Enforce `||s|| <= Δ`, because a trust-region model is only allowed to choose steps inside its trusted neighborhood.

```python
s_unc_b8 = np.array([3.0, 4.0])
Delta_b8 = 2.0
norm_b8 = np.linalg.norm(s_unc_b8)
s_tr_b8 = s_unc_b8 * min(1.0, Delta_b8 / norm_b8)
print("unconstrained norm:", norm_b8, "trusted step:", s_tr_b8, "trusted norm:", np.linalg.norm(s_tr_b8))
assert round(float(np.linalg.norm(s_tr_b8)), 6) == 2.0
```
▶ What you'll see: the direction is preserved but the step length is clipped to the radius.

```python
plt.figure(figsize=(4, 4))
theta_b8 = np.linspace(0, 2 * np.pi, 200)
plt.plot(Delta_b8 * np.cos(theta_b8), Delta_b8 * np.sin(theta_b8), color="gray")
plt.arrow(0, 0, s_unc_b8[0], s_unc_b8[1], color="crimson", head_width=0.12, length_includes_head=True, label="unconstrained")
plt.arrow(0, 0, s_tr_b8[0], s_tr_b8[1], color="seagreen", head_width=0.12, length_includes_head=True, label="trusted")
plt.axis("equal")
plt.title("Basic 8: trust-region clipping")
plt.legend()
plt.show()
```
▶ What you'll see: the trusted arrow ends on the circle instead of outside it.

👀 Takeaway: a trust region limits model freedom in parameter space.

### Basic 9 — Compute predicted reduction

**Goal.** Evaluate `m(0)-m(s)`, because the trust-region ratio needs the model's promised improvement.

```python
g_b9 = np.array([-4.0, -2.0])
B_b9 = np.diag([2.0, 4.0])
s_b9 = np.array([1.0, 0.25])
m0_b9 = 0.0
ms_b9 = float(g_b9 @ s_b9 + 0.5 * s_b9 @ B_b9 @ s_b9)
pred_red_b9 = m0_b9 - ms_b9
print("model value at s:", round(ms_b9, 3), "predicted reduction:", round(pred_red_b9, 3))
assert round(pred_red_b9, 3) == 3.375
```
▶ What you'll see: a negative model value means the model predicts a positive reduction.

👀 Takeaway: predicted reduction is what the local model claims the step should earn.

### Basic 10 — Compute rho and update the radius

**Goal.** Convert actual and predicted reductions into `ρ`, because that ratio controls whether to expand or contract the trust radius.

```python
pred_b10 = np.array([0.60, 1.00])
actual_b10 = np.array([0.61, 0.10])
rho_b10 = actual_b10 / pred_b10
decision_b10 = np.where(rho_b10 > 0.75, "expand", np.where(rho_b10 < 0.25, "contract", "keep"))
print("rho:", np.round(rho_b10, 3))
print("decision:", decision_b10)
assert np.allclose(np.round(rho_b10, 3), [1.017, 0.1])
```
▶ What you'll see: the accurate model expands, while the overoptimistic model contracts.

```python
plt.figure(figsize=(4, 3))
plt.bar(["case 1", "case 2"], rho_b10, color=["seagreen", "crimson"])
plt.axhline(0.75, color="black", linestyle="--")
plt.axhline(0.25, color="gray", linestyle=":")
plt.title("Basic 10: trust-region ratio")
plt.ylabel("rho")
plt.show()
```
▶ What you'll see: the bars fall into the expand and contract zones.

👀 Takeaway: `ρ` measures model reliability, not just whether the objective decreased.

### Easy 1 — Implement Armijo backtracking as a reusable loop

**Goal.** Package the Armijo test into a small loop, because optimization code must choose safe steps repeatedly.

```python
def f_e1(x_e1):
    return (x_e1 - 2.0) ** 2

def grad_e1(x_e1):
    return 2.0 * (x_e1 - 2.0)

x_e1 = 0.0
p_e1 = -grad_e1(x_e1)
alpha_e1 = 1.0
c_e1 = 0.5
beta_e1 = 0.5
history_e1 = []
print("start x:", x_e1, "direction:", p_e1)
```
▶ What you'll see: the loop starts with the full negative-gradient step.

```python
for _ in range(10):
    lhs_e1 = f_e1(x_e1 + alpha_e1 * p_e1)
    rhs_e1 = f_e1(x_e1) + c_e1 * alpha_e1 * grad_e1(x_e1) * p_e1
    history_e1.append([alpha_e1, lhs_e1, rhs_e1])
    if lhs_e1 <= rhs_e1:
        break
    alpha_e1 *= beta_e1
history_e1 = np.array(history_e1)
print("history [alpha, f_trial, bound]:\n", np.round(history_e1, 3))
assert alpha_e1 == 0.5
```
▶ What you'll see: the accepted `α` is `0.5`, matching the lesson's arithmetic.

```python
x_next_e1 = x_e1 + alpha_e1 * p_e1
print("accepted x_next:", x_next_e1, "f_next:", f_e1(x_next_e1))
plt.figure(figsize=(4, 3))
plt.plot(history_e1[:, 0], history_e1[:, 1], marker="o", label="trial")
plt.plot(history_e1[:, 0], history_e1[:, 2], marker="s", label="bound")
plt.gca().invert_xaxis()
plt.title("Easy 1: Armijo backtracking history")
plt.legend()
plt.show()
```
▶ What you'll see: the first rejected trial and accepted second trial are both visible.

👀 Takeaway: Armijo backtracking turns a dangerous full step into a safe accepted step.

### Easy 2 — Compare Armijo constants

**Goal.** Change `c`, because the sufficient-decrease fraction controls how demanding line search is.

```python
c_values_e2 = np.array([0.1, 0.5, 0.9])
accepted_e2 = []
for c_e2 in c_values_e2:
    alpha_e2 = 1.0
    for _ in range(10):
        lhs_e2 = (alpha_e2 * 4.0 - 2.0) ** 2
        rhs_e2 = 4.0 + c_e2 * alpha_e2 * (-16.0)
        if lhs_e2 <= rhs_e2:
            break
        alpha_e2 *= 0.5
    accepted_e2.append(alpha_e2)
```

### Advanced 1 — Compare fixed learning rate with Armijo search

**Goal.** Optimize a non-quadratic curve with and without backtracking, because fixed steps can be unstable while line search self-corrects.

```python
def f_a1(x_a1):
    return (x_a1 - 2.0) ** 2 + 0.2 * (x_a1 + 1.0) ** 4

def grad_a1(x_a1):
    return 2.0 * (x_a1 - 2.0) + 0.8 * (x_a1 + 1.0) ** 3

x_fixed_a1 = -2.0
x_armijo_a1 = -2.0
path_fixed_a1 = [x_fixed_a1]
path_armijo_a1 = [x_armijo_a1]
print("start f:", round(f_a1(-2.0), 3))
```
▶ What you'll see: both methods begin from the same point.

```python
for _ in range(12):
    x_fixed_a1 = x_fixed_a1 - 0.05 * grad_a1(x_fixed_a1)
    path_fixed_a1.append(x_fixed_a1)
    g_a1 = grad_a1(x_armijo_a1)
    p_a1 = -g_a1
    alpha_a1 = 1.0
    while f_a1(x_armijo_a1 + alpha_a1 * p_a1) > f_a1(x_armijo_a1) + 1e-4 * alpha_a1 * g_a1 * p_a1:
        alpha_a1 *= 0.5
    x_armijo_a1 = x_armijo_a1 + alpha_a1 * p_a1
    path_armijo_a1.append(x_armijo_a1)
print("fixed final f:", round(f_a1(x_fixed_a1), 3), "Armijo final f:", round(f_a1(x_armijo_a1), 3))
```
▶ What you'll see: Armijo keeps each update decreasing without preselecting one global learning rate.


👀 Takeaway: line search replaces a fragile global learning rate with a local sufficient-decrease test.

### Advanced 2 — Use a trust region when Hessian curvature is unsafe

**Goal.** Handle negative curvature in a local quadratic model, because an unconstrained Newton step can be meaningless when the Hessian is indefinite.


### Advanced 5 — Combine line search with a Newton direction

**Goal.** Dampen a curvature-aware Newton step, because Newton's direction is powerful but still only locally reliable.

```python
def f_a5(x_a5):
    return np.log1p(np.exp(x_a5)) + 0.05 * (x_a5 - 3.0) ** 2

def grad_a5(x_a5):
    sig_a5 = 1.0 / (1.0 + np.exp(-x_a5))
    return sig_a5 + 0.1 * (x_a5 - 3.0)

def hess_a5(x_a5):
    sig_a5 = 1.0 / (1.0 + np.exp(-x_a5))
    return sig_a5 * (1.0 - sig_a5) + 0.1

x_a5 = 8.0

H_a5 = hess_a5(x_a5)
p_newton_a5 = -g_a5 / H_a5

```
▶ What you'll see: small curvature makes the raw Newton step large.

```python
alpha_a5 = 1.0

while f_a5(x_a5 + alpha_a5 * p_newton_a5) > f_a5(x_a5) + c_a5 * alpha_a5 * g_a5 * p_newton_a5:
    records_a5.append([alpha_a5, f_a5(x_a5 + alpha_a5 * p_newton_a5)])
    alpha_a5 *= 0.5

```
