# 18.1 — Exploratory Data Analysis

Exploratory data analysis (EDA) is the disciplined habit of measuring a dataset before asking a model to explain it. In this lesson, you will build EDA checks from first principles with NumPy and Matplotlib: centers, spreads, distributions, outliers, correlations, segments, and missingness patterns.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build exploratory data analysis one idea at a time. Run each cell in order and read the printed intermediate values — every statistic is computed directly so the data-quality logic is visible. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, masks, summary statistics, and synthetic data.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for any synthetic examples.
```

### 1. EDA starts with a table, a question, and visible assumptions

EDA is not "make every chart." It is a sequence of questions about whether the data is plausible enough to model: What are the rows? Which columns are numeric? Which entries are missing? Which values are labels or segments? We start by creating a tiny table as separate NumPy arrays, because that keeps each assumption explicit instead of hiding it inside a dataframe method.

```python
age_w = np.array([22., 25., 28., 35., 44., 51., 62., 70.])  # one numeric feature.
income_w = np.array([35., 42., 45., 62., 80., 95., 120., 150.])  # second numeric feature in $k.
segment_w = np.array([0, 0, 0, 0, 1, 1, 1, 1])  # 0 = A, 1 = B.
label_w = np.array([0, 0, 0, 1, 1, 1, 1, 1])  # a downstream binary target.
print("rows:", len(age_w), "numeric columns:", 2)  # inspect dataset size.
print("first three rows age/income/segment/label:", list(zip(age_w[:3], income_w[:3], segment_w[:3], label_w[:3])))
```
▶ What you'll see: eight rows with two numeric columns, one segment column, and one binary label.

```python
missing_income_w = np.array([False, False, True, False, False, False, True, False])  # pretend two incomes were blank.
observed_income_w = ~missing_income_w  # entries we are allowed to summarize.
print("observed income count:", int(observed_income_w.sum()))  # six observed values.
print("missing income rate:", round(float(missing_income_w.mean()), 3))  # 2/8 = 0.25.
assert round(float(missing_income_w.mean()), 3) == 0.25
```
▶ What you'll see: one quarter of the income field is missing, so every income summary must state whether it used six or eight rows.

```python
plt.figure(figsize=(4.4, 3))
plt.scatter(age_w[observed_income_w], income_w[observed_income_w], c=segment_w[observed_income_w], cmap="coolwarm", s=80)
plt.xlabel("age"); plt.ylabel("income ($k)"); plt.title("1: first look at rows and segments")
plt.show()
```
▶ What you'll see: older rows tend to have larger income, and the two segments occupy different parts of the plot.

*Why it's done this way:* a model sees arrays, not intentions. Writing the arrays, masks, and segment codes explicitly forces us to name what is observed, what is missing, and what population each row belongs to before any statistic can silently average across them.

### 2. Center and spread: mean, median, variance, and standard deviation

A numeric column needs a location summary and a spread summary. The mean is the arithmetic balance point, the median is the middle after sorting, and the standard deviation is the square root of average squared distance from the mean. These answer different questions: "where is the mass centered?" and "how much do rows vary around that center?"

```python
x_w = np.array([2., 3., 3., 4., 5., 20.])  # one tail value at 20.
mean_w = float(np.sum(x_w) / len(x_w))  # compute mean from the definition.
sorted_w = np.sort(x_w)  # sort before taking the middle.
median_w = float((sorted_w[2] + sorted_w[3]) / 2)  # even-length median.
print("mean:", round(mean_w, 3), "median:", round(median_w, 3))
assert round(mean_w, 3) == 6.167 and round(median_w, 3) == 3.5
```
▶ What you'll see: the mean is 6.167 while the median is 3.5, because the value 20 pulls the arithmetic average upward.

```python
dev_w = x_w - mean_w  # signed distances from center.
var_w = float(np.mean(dev_w ** 2))  # population variance: average squared distance.
std_w = float(np.sqrt(var_w))  # standard deviation returns to original units.
print("variance:", round(var_w, 3), "std:", round(std_w, 3))
assert round(std_w, 3) == 6.256
```
▶ What you'll see: the standard deviation is large relative to the median, another sign that one tail value dominates spread.

```python
plt.figure(figsize=(4.6, 3))
plt.scatter(np.arange(len(x_w)), x_w, s=80, color="teal")
plt.axhline(mean_w, color="crimson", linestyle="--", label="mean")
plt.axhline(median_w, color="black", linestyle=":", label="median")
plt.title("2: mean moves toward the tail"); plt.ylabel("value"); plt.legend(); plt.show()
```
▶ What you'll see: the mean line sits much closer to 20 than the median line does.

*Why it's done this way:* the mean minimizes squared error, so a far-away point has leverage because its distance is squared. The median minimizes absolute error, so it is less sensitive to one extreme value. EDA compares both because disagreement is evidence of skew, outliers, or mixed populations.

### 3. Distributions: histograms and box plots show shape, not just one number

A single mean and standard deviation can hide whether values are symmetric, skewed, multimodal, or capped. A histogram counts how many observations fall into value intervals, while a box plot summarizes quartiles and tails. We compute the bin counts and quartiles directly so the plot is not decorative — it is a visual version of arithmetic.

```python
rng_w = np.random.default_rng(1)
left_w = rng_w.normal(30, 4, size=60)  # first subpopulation.
right_w = rng_w.normal(55, 5, size=40)  # second subpopulation.
mix_w = np.concatenate([left_w, right_w])  # a bimodal feature.
counts_w, edges_w = np.histogram(mix_w, bins=8)  # count rows inside each interval.
print("histogram counts:", counts_w)
print("bin edges:", np.round(edges_w, 1))
assert int(counts_w.sum()) == len(mix_w)
```
▶ What you'll see: all 100 rows are assigned to bins, with mass separated into low and high value regions.

```python
q1_w, q2_w, q3_w = np.percentile(mix_w, [25, 50, 75])  # quartiles from sorted positions.
iqr_w = float(q3_w - q1_w)  # middle-50% width.
print("Q1, median, Q3:", np.round([q1_w, q2_w, q3_w], 2), "IQR:", round(iqr_w, 2))
assert iqr_w > 15
```
▶ What you'll see: the interquartile range is wide because the middle half spans the gap between two subpopulations.

```python
fig, ax = plt.subplots(1, 2, figsize=(7, 2.8))
ax[0].hist(mix_w, bins=8, color="steelblue", edgecolor="white")
ax[0].set_title("3: histogram counts"); ax[0].set_xlabel("value"); ax[0].set_ylabel("rows")
ax[1].boxplot(mix_w, vert=True); ax[1].set_title("3: quartiles and tails"); ax[1].set_ylabel("value")
plt.show()
```
▶ What you'll see: the histogram hints at two clusters, while the box plot shows a large middle spread and long whiskers.

*Why it's done this way:* histograms estimate the distribution by counting local density, and box plots summarize ordered positions. They answer questions that formulas alone miss: whether one center is meaningful, whether values are clipped, and whether downstream normalization will mix different regimes.

### 4. Outliers: z-scores and IQR fences measure tail leverage

Outliers matter because many learning algorithms use means, variances, or squared losses. A z-score measures distance from the mean in standard-deviation units. An IQR fence uses quartiles instead: values below $Q1-1.5\,IQR$ or above $Q3+1.5\,IQR$ are flagged as tail points. The two rules are not identical; EDA uses them as prompts for inspection, not automatic deletion.

```python
x_out_w = np.array([2., 3., 3., 4., 5., 20.])
mu_out_w = float(np.mean(x_out_w))
sigma_out_w = float(np.sqrt(np.mean((x_out_w - mu_out_w) ** 2)))
z_w = (x_out_w - mu_out_w) / sigma_out_w
print("z-scores:", np.round(z_w, 3))
print("largest z:", round(float(z_w[-1]), 3))
assert round(float(z_w[-1]), 3) == 2.211
```
▶ What you'll see: the value 20 is 2.211 standard deviations above the mean.

```python
q1_out_w, q3_out_w = np.percentile(x_out_w, [25, 75])
iqr_out_w = float(q3_out_w - q1_out_w)
lower_w = q1_out_w - 1.5 * iqr_out_w
upper_w = q3_out_w + 1.5 * iqr_out_w
flag_w = (x_out_w < lower_w) | (x_out_w > upper_w)
print("IQR fences:", round(lower_w, 3), round(upper_w, 3))
print("IQR outlier values:", x_out_w[flag_w])
assert np.array_equal(x_out_w[flag_w], np.array([20.]))
```
▶ What you'll see: the IQR rule flags 20 because it sits beyond the upper fence.

```python
plt.figure(figsize=(4.8, 3))
plt.boxplot(x_out_w, vert=False)
plt.scatter(x_out_w, np.ones_like(x_out_w), color=np.where(flag_w, "crimson", "teal"), zorder=3)
plt.title("4: IQR fence flags the tail point"); plt.xlabel("value"); plt.show()
```
▶ What you'll see: the point at 20 is colored red beyond the main box-and-whisker range.

*Why it's done this way:* z-scores standardize by mean and standard deviation, so they are natural when data is roughly bell-shaped. IQR fences use ranks, so they are more robust when the tail itself distorts the mean and standard deviation. Either flag means "investigate the data-generating process," not "delete blindly."

### 5. Correlation: centered co-movement normalized by both spreads

Correlation measures whether two numeric variables move together after removing their individual centers. The numerator sums paired centered deviations, and the denominator divides by each variable's length so the result is scale-free. A high correlation is useful for feature discovery, but it is not a causal claim.

```python
x_corr_w = np.array([1., 2., 3., 4., 5.])
y_corr_w = np.array([2., 4., 5., 4., 5.])
xc_w = x_corr_w - np.mean(x_corr_w)
yc_w = y_corr_w - np.mean(y_corr_w)
print("centered x:", xc_w)
print("centered y:", yc_w)
```
▶ What you'll see: each column is recentered around zero before association is measured.

```python
num_corr_w = float(np.sum(xc_w * yc_w))
den_corr_w = float(np.sqrt(np.sum(xc_w ** 2) * np.sum(yc_w ** 2)))
r_corr_w = num_corr_w / den_corr_w
print("numerator:", round(num_corr_w, 3), "denominator:", round(den_corr_w, 3), "r:", round(r_corr_w, 3))
assert round(r_corr_w, 3) == 0.775
```
▶ What you'll see: the correlation is 0.775, a strong positive association for this tiny example.

```python
plt.figure(figsize=(4.4, 3))
plt.scatter(x_corr_w, y_corr_w, s=90, color="purple")
coef_w = np.polyfit(x_corr_w, y_corr_w, 1)
plt.plot(x_corr_w, coef_w[0] * x_corr_w + coef_w[1], color="black", linestyle="--")
plt.title("5: positive association, not causation"); plt.xlabel("x"); plt.ylabel("y"); plt.show()
```
▶ What you'll see: points generally rise with x, but they are not perfectly on a line.

*Why it's done this way:* centering makes the product positive when both variables are above their means or both below their means, and negative when they move opposite ways. Normalizing by both squared lengths makes the score comparable across units. The math detects co-movement; experimental design is needed for causation.

### 6. Segments, conditional rates, and missingness patterns

Global summaries can be true but incomplete. If one segment has a much higher label rate or missingness rate than another, the overall average hides a process difference. EDA therefore computes conditional summaries by segment and asks whether the model, sampling plan, or cleaning rule must protect those slices.

```python
seg_w = np.array([0, 0, 0, 0, 1, 1, 1, 1])
y_seg_w = np.array([0, 0, 0, 1, 1, 1, 1, 0])
rate_a_w = float(np.mean(y_seg_w[seg_w == 0]))
rate_b_w = float(np.mean(y_seg_w[seg_w == 1]))
overall_w = float(np.mean(y_seg_w))
print("A rate:", round(rate_a_w, 3), "B rate:", round(rate_b_w, 3), "overall:", round(overall_w, 3))
assert round(rate_a_w, 3) == 0.25 and round(rate_b_w, 3) == 0.75 and round(overall_w, 3) == 0.5
```
▶ What you'll see: the global rate is 0.5, but segment A is 0.25 and segment B is 0.75.

```python
miss_w = np.array([False, False, False, True, True, True, False, True])
miss_a_w = float(np.mean(miss_w[seg_w == 0]))
miss_b_w = float(np.mean(miss_w[seg_w == 1]))
print("missingness A:", round(miss_a_w, 3), "missingness B:", round(miss_b_w, 3))
assert round(miss_a_w, 3) == 0.25 and round(miss_b_w, 3) == 0.75
```
▶ What you'll see: missingness is also segment-dependent, so blanks are probably a process signal.

```python
plt.figure(figsize=(4.8, 3))
xpos_w = np.arange(2)
plt.bar(xpos_w - 0.18, [rate_a_w, rate_b_w], width=0.36, label="label rate", color="teal")
plt.bar(xpos_w + 0.18, [miss_a_w, miss_b_w], width=0.36, label="missing rate", color="crimson")
plt.xticks(xpos_w, ["segment A", "segment B"]); plt.ylim(0, 1); plt.title("6: segment rates reveal hidden regimes")
plt.legend(); plt.show()
```
▶ What you'll see: segment B has both higher positive-label rate and higher missingness rate.

*Why it's done this way:* conditional rates replace one average with several averages over meaningful groups. If the groups differ, then random train/test splits, imputations, and validation metrics must preserve those groups; otherwise the model can look good globally while failing the slice that generated the hidden pattern.

## 🛠️ Setup

```python
import numpy as np  # load NumPy for arrays, masks, summary statistics, and reproducible simulations.
import matplotlib.pyplot as plt  # load Matplotlib for histograms, box plots, scatter plots, bars, and lines.
np.random.seed(0)  # make every random example reproducible across notebook runs.

def mean_from_scratch(x):  # compute the arithmetic center from its definition.
    x = np.asarray(x, dtype=float)  # ensure numeric array operations.
    return float(np.sum(x) / len(x))  # sum divided by row count.

def std_from_scratch(x):  # compute population standard deviation from squared deviations.
    x = np.asarray(x, dtype=float)  # ensure numeric array operations.
    mu = mean_from_scratch(x)  # reuse the lesson mean.
    return float(np.sqrt(np.mean((x - mu) ** 2)))  # sqrt of average squared distance.

def corr_from_scratch(x, y):  # compute Pearson correlation by centering and normalizing.
    x = np.asarray(x, dtype=float)  # convert first vector.
    y = np.asarray(y, dtype=float)  # convert second vector.
    xc = x - mean_from_scratch(x)  # remove x center.
    yc = y - mean_from_scratch(y)  # remove y center.
    denom = np.sqrt(np.sum(xc ** 2) * np.sum(yc ** 2))  # product of centered lengths.
    return 0.0 if denom == 0 else float(np.sum(xc * yc) / denom)  # guard constant columns.

def show_hist_box(x, title):  # compact helper for a distribution view.
    fig, ax = plt.subplots(1, 2, figsize=(7, 2.8))  # show counts and quartiles side by side.
    ax[0].hist(x, bins=8, color="steelblue", edgecolor="white")  # histogram for shape.
    ax[0].set_title(title + " histogram")  # label histogram.
    ax[1].boxplot(x, vert=True)  # box plot for quartiles and tails.
    ax[1].set_title(title + " box")  # label box plot.
    plt.show()  # render both plots.
```

### Basic 2 — Compute a mean from scratch

**Goal.** Compute the arithmetic average by summing and dividing, because the mean is the default center used by many models and losses. We build it in 2 steps.

```python
x_b2 = np.array([2., 3., 3., 4., 5., 20.])  # Recreate the lesson column locally.
sum_b2 = float(np.sum(x_b2))  # Add all values in the column.
count_b2 = len(x_b2)  # Count how many rows contribute.
print("sum:", sum_b2, "count:", count_b2)  # Inspect the two ingredients.
```
▶ What you'll see: the sum is 37 over 6 rows.

```python
mean_b2 = sum_b2 / count_b2  # Divide total mass by number of rows.
print("mean:", round(mean_b2, 3))  # Inspect the arithmetic center.
assert round(mean_b2, 3) == 6.167  # Verify the canonical lesson mean.
plt.figure(figsize=(4, 3))  # Create a compact plot.
plt.scatter(np.arange(len(x_b2)), x_b2, color="teal", s=80)  # Draw raw values.
plt.axhline(mean_b2, color="crimson", linestyle="--", label="mean")  # Show the mean line.
plt.title("Basic 2: mean as balance point")  # Title the plot.
plt.legend()  # Show line label.
plt.show()  # Display the plot.
```
▶ What you'll see: the mean line is pulled upward by the large value.

👀 Takeaway: the mean uses every value directly, so large tails have leverage.

### Basic 3 — Compute a median from sorted values

median_b3 = float((sorted_b3[2] + sorted_b3[3]) / 2)  # Average the two middle values for six rows.

### Basic 4 — Measure spread with squared deviations

**Goal.** Compute variance and standard deviation from deviations around the mean, because spread tells whether a feature is stable enough for modeling. We build it in 3 steps.

```python
x_b4 = np.array([2., 3., 3., 4., 5., 20.])  # Recreate the feature.
mu_b4 = mean_from_scratch(x_b4)  # Compute the center.
dev_b4 = x_b4 - mu_b4  # Compute signed deviations from the center.
print("deviations:", np.round(dev_b4, 3))  # Inspect how far each row is from the mean.
```
▶ What you'll see: the tail value has a much larger positive deviation than the other rows.

```python
sq_b4 = dev_b4 ** 2  # Square deviations so negative and positive errors both count.
var_b4 = float(np.mean(sq_b4))  # Average squared deviations.
std_b4 = float(np.sqrt(var_b4))  # Return to original units.
print("variance:", round(var_b4, 3), "std:", round(std_b4, 3))  # Inspect spread summaries.
assert round(std_b4, 3) == 6.256  # Verify the standard deviation.
```

```python
plt.figure(figsize=(4, 3))  # Create a compact bar chart.
plt.bar(range(len(x_b4)), sq_b4, color="orange")  # Show each row's contribution to variance.
plt.title("Basic 4: squared deviations")  # Title the plot.
plt.xlabel("row")  # Label rows.
plt.ylabel("(x - mean)^2")  # Label squared distance.
plt.show()  # Display the plot.
```
▶ What you'll see: one bar dominates the variance.

👀 Takeaway: standard deviation is sensitive to tail points because it is built from squared distances.

### Basic 7 — Compute z-scores

**Goal.** Standardize values into standard-deviation units, because z-scores make tail distances comparable across features. We build it in 2 steps.

```python
x_b7 = np.array([2., 3., 3., 4., 5., 20.])  # Recreate the tail example.
mu_b7 = mean_from_scratch(x_b7)  # Compute mean.
std_b7 = std_from_scratch(x_b7)  # Compute population standard deviation.
z_b7 = (x_b7 - mu_b7) / std_b7  # Standardize each row.
print("z-scores:", np.round(z_b7, 3))  # Inspect standardized distances.
```
▶ What you'll see: most values are modestly below the mean, while 20 is far above it.

```python
plt.figure(figsize=(4, 3))  # Create a compact z-score bar chart.
plt.bar(range(len(z_b7)), z_b7, color=np.where(np.abs(z_b7) > 2, "crimson", "teal"))  # Flag values beyond 2 std units.
plt.axhline(0, color="black", linewidth=0.8)  # Add zero reference.
plt.axhline(2, color="gray", linestyle="--")  # Add +2 guide.
plt.title("Basic 7: standardized tail distance")  # Title the plot.
plt.ylabel("z")  # Label z-score axis.
plt.show()  # Display the plot.
```
▶ What you'll see: only the last value crosses the +2 guide.

👀 Takeaway: z-scores measure tail distance relative to the feature's own spread.

### Basic 8 — Compute an IQR outlier fence

**Goal.** Flag values beyond quartile-based fences, because rank-based outlier checks are less distorted by the tail itself. We build it in 2 steps.

    q1_a5, q3_a5 = np.percentile(vals_a5, [25, 75])  # Quartiles for observed values.
    iqr_a5 = q3_a5 - q1_a5  # IQR.
    flags_a5 = (vals_a5 < q1_a5 - 1.5 * iqr_a5) | (vals_a5 > q3_a5 + 1.5 * iqr_a5)  # Outlier flags.
    outlier_rates_a5.append(float(np.mean(flags_a5)))  # Outlier rate among observed.
    label_corrs_a5.append(abs(corr_from_scratch(vals_a5, y_a5[obs_a5])))  # Absolute feature-label correlation.
print("missing:", np.round(missing_rates_a5, 3))  # Inspect missingness.
print("outliers:", np.round(outlier_rates_a5, 3))  # Inspect outliers.
print("abs corr to label:", np.round(label_corrs_a5, 3))  # Inspect associations.
assert round(missing_rates_a5[2], 3) == 0.1  # Verify injected missingness.
```

dashboard_a5 = np.vstack([missing_rates_a5, outlier_rates_a5, label_corrs_a5])  # Stack metrics into a dashboard matrix.
print("dashboard rows = missing/outlier/abs_corr:\n", np.round(dashboard_a5, 3))  # Inspect final diagnostic table.
assert dashboard_a5.shape == (3, 3)  # Verify 3 metrics by 3 features.
```
