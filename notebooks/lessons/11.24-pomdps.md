# 11.24 — POMDPs

A partially observable Markov decision process (POMDP) is what you get when an RL agent cannot see the true state directly. Instead of pretending a noisy sensor is the state, the agent carries a **belief state**: a probability distribution over hidden states that is updated with Bayes' rule after every action and observation.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build POMDPs one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, especially belief filtering and belief-MDP planning, is shown directly in NumPy. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, probability tables, and vectorized expectations.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for sampled observation demos.
```

### 1. Hidden state, action, observation, reward

A POMDP keeps the MDP pieces — states, actions, transitions, rewards — but adds an observation model because the agent does not see the state itself. In this toy world, the hidden state is whether the robot is in a **safe** or **dangerous** hallway. It can `wait` or `scan`, and it receives a noisy alarm observation. The reward is higher for being safe and lower for being in danger; scanning costs a little but makes the next observation more reliable.

```python
states_w = ["safe", "danger"]
actions_w = ["wait", "scan"]
observations_w = ["quiet", "alarm"]
T_w = np.array([[[0.85, 0.15], [0.25, 0.75]],
                [[0.90, 0.10], [0.35, 0.65]]])
O_w = np.array([[[0.80, 0.20], [0.30, 0.70]],
                [[0.90, 0.10], [0.15, 0.85]]])
R_w = np.array([[2.0, -4.0], [1.5, -4.5]])
print("T shape action,state,next:", T_w.shape)
print("O shape action,next_state,obs:", O_w.shape)
print("rewards action,state:\n", R_w)
```
▶ What you'll see: two actions, two hidden states, two observations, and a reward table indexed by action and hidden state.

```python
print("wait transition from safe:", T_w[0, 0])
print("scan observation if danger:", O_w[1, 1])
assert np.allclose(T_w[0, 0].sum(), 1.0)
assert np.allclose(O_w[1, 1].sum(), 1.0)
```
▶ What you'll see: each transition row and observation row is a valid probability distribution.

```python
plt.figure(figsize=(4.4, 3))
plt.imshow(R_w, cmap="coolwarm", aspect="auto")
plt.colorbar(label="reward")
plt.xticks(range(2), states_w); plt.yticks(range(2), actions_w)
plt.title("1: reward depends on hidden state")
plt.show()
```
▶ What you'll see: danger carries negative reward, and scan has a small extra cost compared with waiting.

*Why it's done this way:* a POMDP separates **what is true** (`state`) from **what is seen** (`observation`). That separation is the whole point: the transition table predicts hidden dynamics, the observation table predicts sensor evidence, and the reward table defines what the agent is trying to optimize even when the state is not directly visible.

### 2. Belief state: replacing unknown state with a distribution

Because the true state is hidden, the agent summarizes everything it knows with a belief vector $b(s)$. For two states this is just `[P(safe), P(danger)]`. The immediate expected reward of an action is the belief-weighted average $\sum_s b(s)R(a,s)$, so the same action can look good or bad depending on uncertainty.

```python
b_w = np.array([0.60, 0.40])
print("belief b(s):", b_w)
print("sum:", b_w.sum())
assert round(float(b_w.sum()), 3) == 1.000
```
▶ What you'll see: the agent currently assigns 60% probability to safe and 40% to danger.

```python
reward_wait_w = float(b_w @ R_w[0])
reward_scan_w = float(b_w @ R_w[1])
print("E[R | wait] =", round(reward_wait_w, 3))
print("E[R | scan] =", round(reward_scan_w, 3))
assert round(reward_wait_w, 3) == -0.400
assert round(reward_scan_w, 3) == -0.900
```
▶ What you'll see: waiting has higher immediate reward because scanning pays an information cost.

```python
plt.figure(figsize=(4.2, 3))
plt.bar(states_w, b_w, color=["seagreen", "crimson"])
plt.ylim(0, 1); plt.ylabel("probability")
plt.title("2: belief is the agent's state")
plt.show()
```
▶ What you'll see: the current belief is a distribution, not a single guessed hallway state.

*Why it's done this way:* a belief is sufficient because Bayes' rule can update it with all future actions and observations. Instead of storing the entire observation history, the agent stores the posterior distribution that history implies; that is what turns a partially observable problem back into a Markov problem over beliefs.

### 3. Bayesian filtering: predict, observe, normalize

The belief update has two stages. First the transition model predicts where the hidden state might move: $\bar b(s')=\sum_s P(s'\mid s,a)b(s)$. Then the observation likelihood weights that prediction: $b'(s')=\eta O(o\mid s',a)\bar b(s')$, where $\eta$ is the normalization constant that makes probabilities sum to one.

```python
a_w = 1
o_w = 1
prior_w = np.array([0.60, 0.40])
pred_w = prior_w @ T_w[a_w]
print("prior:", prior_w)
print("predicted before observation:", np.round(pred_w, 3))
assert np.allclose(np.round(pred_w, 3), [0.68, 0.32])
```
▶ What you'll see: scanning plus dynamics shifts the prior to 68% safe before looking at the alarm.

```python
likelihood_w = O_w[a_w, :, o_w]
unnormalized_w = likelihood_w * pred_w
posterior_w = unnormalized_w / unnormalized_w.sum()
print("alarm likelihood by next state:", likelihood_w)
print("unnormalized:", np.round(unnormalized_w, 3))
print("posterior:", np.round(posterior_w, 3))
assert np.allclose(np.round(posterior_w, 3), [0.200, 0.800])
```
▶ What you'll see: the alarm makes danger jump from 32% predicted probability to 80% posterior probability.

```python
plt.figure(figsize=(5, 3))
x_w = np.arange(2)
plt.bar(x_w - 0.18, pred_w, width=0.36, label="before alarm", color="gray")
plt.bar(x_w + 0.18, posterior_w, width=0.36, label="after alarm", color="orange")
plt.xticks(x_w, states_w); plt.ylim(0, 1); plt.legend()
plt.title("3: Bayes filtering after an alarm")
plt.show()
```
▶ What you'll see: probability mass moves toward danger because an alarm is much more likely in the dangerous state.

*Why it's done this way:* the prediction step accounts for hidden dynamics before evidence arrives; the likelihood step asks which hidden states would have made the observation plausible; normalization turns those unscaled scores back into a probability distribution. This is exactly Bayes' rule applied after a controlled transition.

### 4. Belief-MDP planning: value over distributions

A belief is continuous, so the exact POMDP value function lives over all probability distributions. For a two-state toy problem we can grid the single number $p=P(danger)$ and do Bellman backups on that grid. Each backup averages immediate reward plus discounted future value over possible observations, using the belief update to map each observation to a next belief.

```python
gamma_w = 0.90
grid_w = np.linspace(0, 1, 51)
V_w = np.zeros_like(grid_w)
print("belief grid points:", len(grid_w))
print("first, middle, last danger probabilities:", grid_w[[0, 25, 50]])
```
▶ What you'll see: the continuous belief line is approximated by 51 inspectable grid points.

```python
def update_belief_w(b, a, o):
    pred = b @ T_w[a]
    weights = O_w[a, :, o] * pred
    return weights / weights.sum()

def interp_value_w(b, V):
    p_danger = b[1]
    return float(np.interp(p_danger, grid_w, V))

print("example next belief after scan+alarm:", np.round(update_belief_w(np.array([0.6, 0.4]), 1, 1), 3))
```
▶ What you'll see: the helper reproduces the posterior from the filtering subsection.

```python
for it_w in range(40):
    newV_w = np.zeros_like(V_w)
    policy_w = np.zeros_like(grid_w, dtype=int)
    for i_w, p_w in enumerate(grid_w):
        b_i_w = np.array([1 - p_w, p_w])
        q_vals_w = []
        for a_i_w in range(2):
            immediate_w = float(b_i_w @ R_w[a_i_w])
            obs_probs_w = (b_i_w @ T_w[a_i_w]) @ O_w[a_i_w]
            future_w = 0.0
            for o_i_w in range(2):
                nb_w = update_belief_w(b_i_w, a_i_w, o_i_w)
                future_w += obs_probs_w[o_i_w] * interp_value_w(nb_w, V_w)
            q_vals_w.append(immediate_w + gamma_w * future_w)
        newV_w[i_w] = max(q_vals_w)
        policy_w[i_w] = int(np.argmax(q_vals_w))
    V_w = newV_w
print("value at p(danger)=0.0,0.5,1.0:", np.round(V_w[[0, 25, 50]], 3))
print("actions there:", [actions_w[i] for i in policy_w[[0, 25, 50]]])
assert V_w[0] > V_w[-1]
```
▶ What you'll see: high danger beliefs have lower value, and scanning can become worthwhile when uncertainty or danger risk is high.

```python
plt.figure(figsize=(5, 3))
plt.plot(grid_w, V_w, color="navy", label="value")
plt.scatter(grid_w, policy_w - 6, c=policy_w, cmap="coolwarm", s=12, label="policy strip")
plt.xlabel("belief p(danger)"); plt.ylabel("value")
plt.title("4: value function over belief states")
plt.legend(); plt.show()
```
▶ What you'll see: value decreases as danger becomes more likely; the colored strip shows where the best action changes.

*Why it's done this way:* the belief-MDP Bellman backup is the ordinary RL backup with one replacement: the next state is not a hidden state but a posterior belief after each possible observation. We average over observations because the agent does not control what it will see; it chooses the action that has the best expected consequence after Bayesian filtering.

### ✍️ Toy 3 · Bayesian filtering predicts, weights, then normalizes

After an action, the transition model predicts the next hidden state. The observation likelihood then reweights that prediction before normalization.

```python
import numpy as np

t3_rng = np.random.default_rng(0)
t3_prior = np.array([0.6, 0.4])                  # -> [0.6, 0.4]
t3_transition = np.array([[0.8, 0.2], [0.3, 0.7]])  # -> scan transition
t3_alarm_likelihood = np.array([0.1, 0.8])       # -> P(alarm|safe), P(alarm|danger)
t3_prediction = t3_prior @ t3_transition         # -> [0.6, 0.4]
t3_unnormalized = t3_alarm_likelihood * t3_prediction  # -> [0.06, 0.32]
t3_evidence = float(t3_unnormalized.sum())       # -> 0.38
t3_posterior = t3_unnormalized / t3_evidence     # -> [0.158, 0.842]
print("prior:", t3_prior.tolist())               # -> [0.6, 0.4]
print("prediction:", np.round(t3_prediction, 3).tolist())  # -> [0.6, 0.4]
print("likelihood:", t3_alarm_likelihood.tolist())         # -> [0.1, 0.8]
print("unnormalized:", np.round(t3_unnormalized, 3).tolist())  # -> [0.06, 0.32]
print("evidence:", round(t3_evidence, 3))         # -> 0.38
print("posterior:", np.round(t3_posterior, 3).tolist())    # -> [0.158, 0.842]
assert np.allclose(np.round(t3_posterior, 3), [0.158, 0.842])

plt.figure(figsize=(4.6, 2.8))
t3_x = np.arange(2)
plt.bar(t3_x - 0.18, t3_prediction, width=0.36, color="gray", label="before alarm")
plt.bar(t3_x + 0.18, t3_posterior, width=0.36, color="orange", label="after alarm")
plt.xticks(t3_x, ["safe", "danger"])
plt.ylim(0, 1)
plt.ylabel("probability")
plt.title("Toy 3 · alarm shifts belief to danger")
plt.legend()
plt.show()
```
▶ What you'll see: the alarm moves danger belief from 0.4 predicted probability to about 0.842 posterior probability.

### ✍️ Toy 4 · Belief-MDP backups score actions over beliefs

Planning in a POMDP backs up over possible observations. This tiny grid over `p(danger)` shows one Bellman-style backup for wait versus scan.

```python
import numpy as np

t4_rng = np.random.default_rng(0)
t4_actions = ["wait", "scan"]                   # -> ["wait", "scan"]
t4_grid = np.array([0.0, 0.5, 1.0])              # -> danger probabilities
t4_base_value = -2.0 * t4_grid                   # -> [-0.0, -1.0, -2.0]
t4_gamma = 0.8                                  # -> 0.8
t4_T = np.array([[[0.8, 0.2], [0.3, 0.7]], [[0.8, 0.2], [0.3, 0.7]]])  # -> shared dynamics
t4_O = np.array([[[0.75, 0.25], [0.35, 0.65]], [[0.9, 0.1], [0.2, 0.8]]])  # -> scan is more informative
t4_R = np.array([[2.0, -4.0], [1.4, -3.2]])      # -> scan costs less in danger but less in safe
t4_q_table = []                                  # -> collect Q values
for t4_p in t4_grid:
    t4_b = np.array([1.0 - t4_p, t4_p])
    t4_q_row = []
    for t4_a in range(2):
        t4_pred = t4_b @ t4_T[t4_a]
        t4_obs_probs = t4_pred @ t4_O[t4_a]
        t4_future = 0.0
        for t4_o in range(2):
            t4_weights = t4_O[t4_a, :, t4_o] * t4_pred
            t4_post = t4_weights / t4_weights.sum()
            t4_future = t4_future + t4_obs_probs[t4_o] * np.interp(t4_post[1], t4_grid, t4_base_value)
        t4_q = float(t4_b @ t4_R[t4_a] + t4_gamma * t4_future)
        t4_q_row.append(t4_q)
    t4_q_table.append(t4_q_row)
t4_q_table = np.array(t4_q_table)                # -> [[1.68, 1.08], [-1.72, -1.62], [-5.12, -4.32]]
t4_policy = np.argmax(t4_q_table, axis=1)        # -> [0, 1, 1]
t4_policy_names = [t4_actions[t4_i] for t4_i in t4_policy]  # -> ["wait", "scan", "scan"]
print("belief grid:", t4_grid.tolist())          # -> [0.0, 0.5, 1.0]
print("base value:", np.round(t4_base_value, 3).tolist())   # -> [-0.0, -1.0, -2.0]
print("Q table:\n", np.round(t4_q_table, 3))     # -> [[1.68, 1.08], [-1.72, -1.62], [-5.12, -4.32]]
print("best actions:", t4_policy_names)          # -> ["wait", "scan", "scan"]
assert t4_policy.tolist() == [0, 1, 1]
assert round(float(t4_q_table[2, 1]), 3) == -4.32

plt.figure(figsize=(4.8, 2.8))
plt.plot(t4_grid, t4_q_table[:, 0], marker="o", label="wait")
plt.plot(t4_grid, t4_q_table[:, 1], marker="s", label="scan")
plt.xlabel("belief p(danger)")
plt.ylabel("backup Q")
plt.title("Toy 4 · best action changes with belief")
plt.legend()
plt.show()
```
▶ What you'll see: waiting wins when danger probability is zero, while scanning wins at uncertain or dangerous beliefs.


## 🛠️ Setup

```python
import numpy as np  # load NumPy for probability vectors, Bayes updates, and Bellman backups.
import matplotlib.pyplot as plt  # load Matplotlib for belief bars, trajectories, and value plots.
np.random.seed(0)  # make all stochastic examples reproducible.

states = ["safe", "danger"]  # hidden states used in every example.
actions = ["wait", "scan"]  # action 0 is cheap, action 1 is informative but costly.
observations = ["quiet", "alarm"]  # noisy sensor readings.
T = np.array([[[0.85, 0.15], [0.25, 0.75]], [[0.90, 0.10], [0.35, 0.65]]])  # P(s'|s,a).
O = np.array([[[0.80, 0.20], [0.30, 0.70]], [[0.90, 0.10], [0.15, 0.85]]])  # P(o|s',a).
R = np.array([[2.0, -4.0], [1.5, -4.5]])  # R(a,s), including scan's information cost.

def normalize_dist(x):  # normalize a nonnegative vector into a probability distribution.
    x = np.asarray(x, dtype=float)  # ensure floating arithmetic.
    total = float(np.sum(x))  # compute the normalizing constant.
    return x / total if total > 0 else np.ones_like(x) / len(x)  # guard against zero evidence.

def predict_belief(b, a):  # transition-only prediction b_bar(s') = sum_s b(s)P(s'|s,a).
    return np.asarray(b, dtype=float) @ T[a]  # multiply row belief by transition matrix.

def update_belief(b, a, o):  # Bayes filter for one action and one observation.
    pred = predict_belief(b, a)  # first predict the hidden next-state distribution.
    return normalize_dist(O[a, :, o] * pred)  # then likelihood-weight and normalize.

def obs_probs(b, a):  # distribution over observations given current belief and action.
    return predict_belief(b, a) @ O[a]  # marginalize hidden next state out of P(o|s',a).

def expected_reward(b, a):  # immediate expected reward under a belief.
    return float(np.asarray(b, dtype=float) @ R[a])  # belief-weighted average reward.
```

## 🟢 Basics (warm-up)

### Basic 1 — Represent a hidden-state belief

**Goal.** Store uncertainty as a probability vector, because the agent cannot observe the true state directly. We build it in 2 steps.

```python
b_b1 = np.array([0.7, 0.3])  # P(safe)=0.7 and P(danger)=0.3.
print("belief:", b_b1)  # inspect the hidden-state distribution.
print("sum:", b_b1.sum())  # verify it is normalized.
assert round(float(b_b1.sum()), 3) == 1.000  # concrete probability check.
```
▶ What you'll see: one vector holds the agent's current uncertainty over hidden states.

```python
plt.figure(figsize=(4, 3))  # create a compact belief bar chart.
plt.bar(states, b_b1, color=["seagreen", "crimson"])  # visualize probability mass by state.
plt.ylim(0, 1); plt.title("Basic 1: belief over hidden state")  # keep probability scale fixed.
plt.ylabel("probability"); plt.show()  # display the belief.
```
▶ What you'll see: the safe bar is taller, but danger still has nonzero probability.

👀 Takeaway: a POMDP agent acts from a belief distribution, not from a directly observed state.

### Basic 2 — Normalize raw evidence

**Goal.** Turn unnormalized state scores into probabilities, because Bayes updates create likelihood-weighted scores before they create beliefs. We build it in 2 steps.

```python
scores_b2 = np.array([0.18, 0.42])  # two nonnegative posterior scores before normalization.
print("raw scores:", scores_b2)  # inspect evidence weights.
print("raw total:", scores_b2.sum())  # inspect the missing normalizer.
```
▶ What you'll see: the raw scores do not sum to 1, so they are not yet a belief.

```python
b_b2 = normalize_dist(scores_b2)  # divide by the evidence total.
print("normalized belief:", np.round(b_b2, 3))  # inspect posterior probabilities.
assert np.allclose(np.round(b_b2, 3), [0.300, 0.700])  # verify 0.18/0.60 and 0.42/0.60.
plt.figure(figsize=(4, 3)); plt.bar(states, b_b2, color=["seagreen", "crimson"])
plt.ylim(0, 1); plt.title("Basic 2: normalized evidence"); plt.show()
```
▶ What you'll see: the evidence becomes a 30% safe, 70% danger belief.

👀 Takeaway: the normalizer is what converts Bayesian evidence scores into a probability distribution.

### Basic 3 — Predict one step before observing

**Goal.** Apply the transition model to a belief, because hidden state can change before the next sensor reading arrives. We build it in 2 steps.

```python
b_b3 = np.array([0.6, 0.4])  # current belief before taking an action.
a_b3 = 0  # choose wait.
pred_b3 = predict_belief(b_b3, a_b3)  # compute b_bar(s').
print("prior:", b_b3)  # inspect the starting belief.
print("predicted next belief:", np.round(pred_b3, 3))  # inspect dynamics-only prediction.
assert np.allclose(np.round(pred_b3, 3), [0.610, 0.390])  # 0.6*T_safe + 0.4*T_danger.
```
▶ What you'll see: waiting leaves the belief similar but slightly changes the danger probability.

```python
plt.figure(figsize=(4, 3))
plt.bar(np.arange(2) - 0.18, b_b3, width=0.36, label="before", color="gray")
plt.bar(np.arange(2) + 0.18, pred_b3, width=0.36, label="after transition", color="steelblue")
plt.xticks(range(2), states); plt.ylim(0, 1); plt.legend(); plt.title("Basic 3: transition prediction"); plt.show()
```
▶ What you'll see: transition dynamics move probability mass even before any observation is used.

👀 Takeaway: belief filtering always predicts hidden dynamics before conditioning on new evidence.

### Basic 4 — Apply an observation likelihood

**Goal.** Weight predicted states by how likely the observed alarm is, because Bayes' rule favors states that explain the observation. We build it in 2 steps.


### Advanced 5 — Resolution tradeoff in belief-grid planning

**Goal.** Compare coarse and fine belief grids, because approximate belief-MDP planning trades speed for accuracy. We build it in 4 steps.

```python
def solve_grid_a5(n_a5):
    grid_a5 = np.linspace(0, 1, n_a5)
    V_a5 = np.zeros(n_a5)
    pi_a5 = np.zeros(n_a5, dtype=int)
    for it_a5 in range(35):
        new_a5 = np.zeros(n_a5)
        for i_a5, p_a5 in enumerate(grid_a5):
            b_a5 = np.array([1 - p_a5, p_a5])
            vals_a5 = []
            for a_a5 in range(2):
                future_a5 = sum(obs_probs(b_a5, a_a5)[o_a5] * np.interp(update_belief(b_a5, a_a5, o_a5)[1], grid_a5, V_a5) for o_a5 in range(2))
                vals_a5.append(expected_reward(b_a5, a_a5) + 0.9 * future_a5)
            new_a5[i_a5] = max(vals_a5)
            pi_a5[i_a5] = int(np.argmax(vals_a5))
        V_a5 = new_a5
    return grid_a5, V_a5, pi_a5
print("solver ready")
```
▶ What you'll see: the helper solves a gridded belief-MDP for any chosen resolution.
