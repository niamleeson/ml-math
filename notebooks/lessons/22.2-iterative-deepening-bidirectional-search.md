# 22.2 — Iterative Deepening & Bidirectional Search

BFS has the comforting depth guarantee; DFS has the comforting memory profile. Iterative deepening and bidirectional search are two ways to keep the guarantee without letting the frontier explode. In this lesson, you will implement both from scratch, count the work they do, and draw the frontiers that explain why the tricks help.

### 1. The raw materials: BFS depth order versus DFS memory

BFS and DFS already contain the two ingredients we want to combine. BFS expands by increasing depth, so the first time it reaches a unit-cost goal it has the shortest path; the price is a wide frontier. DFS keeps only a branch and a small stack; the price is that it can chase depth before checking all shallower alternatives. Iterative deepening asks: can we run DFS with a depth cap, then raise the cap until BFS's depth guarantee appears?

```python
start_w, goal_w = (0, 0), (0, 4)  # a straight five-cell row problem.
line_w = [(0, i) for i in range(5)]  # states in the tiny search space.
edges_w = {line_w[i]: [line_w[i + 1]] if i + 1 < len(line_w) else [] for i in range(len(line_w))}  # one successor to the right.
print("start:", start_w, "goal:", goal_w)  # inspect the search endpoints.
print("minimum moves by distance:", abs(goal_w[1] - start_w[1]))  # four moves in this row.
assert abs(goal_w[1] - start_w[1]) == 4  # verify the lesson distance.
```
▶ What you'll see: the goal is exactly four moves away, so any limit below 4 cannot include it.

*Why it's done this way: drawing depth explicitly separates the correctness question (which depth can contain the goal?) from the implementation question (queue, stack, or repeated stack search).* 

### 2. Iterative deepening = repeated depth-limited DFS

Depth-limited search is DFS with one extra rule: never expand children beyond limit `L`. IDDFS runs that procedure for `L = 0, 1, 2, ...` until the goal is found. This deliberately repeats shallow work, but the repeated layers are small compared with the deepest layer in a high-branching tree. The result is BFS-like depth optimality with DFS-like active memory.

```python
def successors_w(node):  # deterministic right/down/left/up grid successors.
    r, c = node  # unpack the grid coordinate.
    out = []  # collect valid neighbors.
    for dr, dc in [(0, 1), (1, 0), (0, -1), (-1, 0)]:  # fixed order for reproducible paths.
        nr, nc = r + dr, c + dc  # candidate neighbor coordinate.
        if 0 <= nr < 5 and 0 <= nc < 5:  # keep states inside a 5x5 grid.
            out.append((nr, nc))  # add the valid successor.
    return out  # return successors in fixed order.

def depth_limited_w(start, goal, limit):  # depth-limited DFS with per-path cycle checks.
    stack = [(start, [start], 0)]  # store node, path, and depth.
    touched = []  # record nodes popped for visualization.
    while stack:  # continue until the stack is empty or the goal is found.
        node, path, depth = stack.pop()  # DFS pops the newest partial path.
        touched.append(node)  # count one touch of this state.
        if node == goal:  # stop immediately on the goal.
            return path, touched  # return the successful path and work trace.
        if depth < limit:  # expand only if the cap allows deeper children.
            for nb in reversed(successors_w(node)):  # reverse so the first successor is explored first after stack push.
                if nb not in path:  # avoid cycles within the current DFS path.
                    stack.append((nb, path + [nb], depth + 1))  # push the child path.
    return None, touched  # no solution within this limit.

path3_w, touched3_w = depth_limited_w((0, 0), (0, 4), 3)  # try one limit too small.
path4_w, touched4_w = depth_limited_w((0, 0), (0, 4), 4)  # try the first sufficient limit.
print("limit 3 found:", path3_w)  # None because the goal is too deep.
print("limit 4 path length:", len(path4_w), "moves:", len(path4_w) - 1)  # five states, four moves.
assert path3_w is None and len(path4_w) - 1 == 4  # verify depth-limit arithmetic.
```
▶ What you'll see: limit 3 explores but fails; limit 4 returns a five-state path with four moves.

```python
limits_w = np.arange(5)  # limits 0 through 4.
found_depth_w = [None, None, None, None, 4]  # the first successful depth in this straight-row target.
plt.figure(figsize=(5, 3))  # create a limit diagram.
plt.bar(limits_w, [min(L, 4) + 1 for L in limits_w], color=["gray", "gray", "gray", "gray", "seagreen"])  # show how many path depths each limit can reach.
plt.axhline(5, color="crimson", linestyle="--", label="states needed")  # goal path has five states.

plt.title("2: IDDFS raises the cap until the goal fits"); plt.legend()

```
▶ What you'll see: only the bar for limit 4 reaches the dashed requirement for the goal path.

*Why it's done this way: the depth cap prevents DFS from disappearing down deep branches, while increasing the cap restores the shallow-first behavior that makes BFS optimal on unit-cost graphs.*

### 3. Counting repeated work and memory

IDDFS is honest about its tradeoff: earlier limits are recomputed. In the lesson arithmetic, the notebook touches `1, 3, 6, 8, 15` nodes for limits `0..4`, for a total of `33`, while the successful final pass touches `15`. That extra work buys a tiny active stack. BFS avoids repetition but keeps a full layer/frontier that grows roughly like `b^d`.

```python
touches_w = np.array([1, 3, 6, 8, 15])  # observed IDDFS touches from the lesson content.
limits_count_w = np.arange(len(touches_w))  # limits 0 through 4.
total_touches_w = int(touches_w.sum())  # total repeated work.
print("touches by limit:", touches_w.tolist())  # inspect the per-pass work.
print("total touches:", total_touches_w, "final pass:", int(touches_w[-1]))  # compare total to final pass.
assert total_touches_w == 33 and touches_w[-1] == 15  # verify the lesson counts.
```
▶ What you'll see: IDDFS did 33 touches total, even though the final successful pass touched 15 nodes.

```python
plt.figure(figsize=(5, 3))  # create a repeated-work chart.
plt.bar(limits_count_w, touches_w, color="steelblue")  # plot touches per limit.
plt.plot(limits_count_w, np.cumsum(touches_w), marker="o", color="crimson", label="cumulative touches")  # show accumulated repetition.
plt.xlabel("depth limit L"); plt.ylabel("nodes touched")
plt.title("3: repeated shallow work in IDDFS"); plt.legend()
plt.show()
```
▶ What you'll see: early bars are small; the cumulative curve reaches 33 after the successful limit.

*Why it's done this way: in wide trees, the deepest layer dominates, so recomputing shallow layers is often cheaper than storing every BFS frontier node.*

### 4. Bidirectional search: two waves meet in the middle

Bidirectional search attacks the same frontier problem from another angle. If the goal is known and actions can be reversed, start one BFS from the start and another from the goal. As soon as their visited sets intersect, the two half-paths can be stitched together. The branching arithmetic is the whole appeal: one frontier at depth `d` stores about `b^d`, but two frontiers to depth `d/2` store about `2b^{d/2}`.

```python
def bidirectional_path_w(start, goal):  # bidirectional BFS on the same 5x5 grid.
    front_s, front_g = {start}, {goal}  # current start-side and goal-side frontiers.
    parent_s, parent_g = {start: None}, {goal: None}  # predecessor maps for both waves.
    layers = [(set(front_s), set(front_g), None)]  # record frontiers for visualization.
    meet = None  # store the meeting node once found.
    while front_s and front_g and meet is None:  # alternate expanding the smaller frontier.
        if len(front_s) <= len(front_g):  # expand the start wave when it is no larger.
            new_front = set()  # next start-side frontier.
            for node in front_s:  # expand each frontier node.
                for nb in successors_w(node):  # inspect grid neighbors.
                    if nb not in parent_s:  # skip already-seen start-side nodes.
                        parent_s[nb] = node  # record how to reach nb from start.
                        new_front.add(nb)  # add nb to the next frontier.
                        if nb in parent_g:  # detect a meeting point by set membership.
                            meet = nb  # save the intersection.
            front_s = new_front  # advance the start wave.
        else:  # expand the goal wave otherwise.
            new_front = set()  # next goal-side frontier.
            for node in front_g:  # expand each goal frontier node.
                for nb in successors_w(node):  # predecessor equals neighbor on this undirected grid.
                    if nb not in parent_g:  # skip already-seen goal-side nodes.
                        parent_g[nb] = node  # record how to reach the goal from nb.
                        new_front.add(nb)  # add nb to next goal frontier.
                        if nb in parent_s:  # detect an intersection.
                            meet = nb  # save meeting node.
            front_g = new_front  # advance the goal wave.
        layers.append((set(front_s), set(front_g), meet))  # record the wave after the expansion.
    left = []  # reconstruct start-to-meet.
    node = meet  # begin at the meeting point.
    while node is not None:  # follow start parents backward.
        left.append(node)  # add node to left half.
        node = parent_s[node]  # step toward start.
    left = left[::-1]  # reverse into start-to-meet order.
    right = []  # reconstruct meet-to-goal.
    node = parent_g[meet]  # skip duplicated meet node.
    while node is not None:  # follow goal parents forward.
        right.append(node)  # append next state toward goal.
        node = parent_g[node]  # step toward goal.
    return left + right, meet, layers  # full path, meeting node, and recorded waves.

bipath_w, meet_w, layers_w = bidirectional_path_w((0, 0), (0, 4))  # solve the row target inside the grid.
print("meeting node:", meet_w)  # inspect the midpoint.
print("bidirectional path:", bipath_w)  # inspect the stitched path.
assert meet_w == (0, 2) and len(bipath_w) - 1 == 4  # verify meeting and path length.
```
▶ What you'll see: the two waves meet at `(0, 2)`, then stitch a four-move path.

```python
plt.figure(figsize=(5, 3))  # create a frontier meeting plot.
for r in range(5):  # draw grid rows.
    for c in range(5):  # draw grid columns.
        color = "white"  # default unvisited color.
        if (r, c) in layers_w[-1][0]: color = "lightskyblue"  # start-side current frontier.
        if (r, c) in layers_w[-1][1]: color = "navajowhite"  # goal-side current frontier.
        if (r, c) == meet_w: color = "limegreen"  # meeting node.
        plt.scatter(c, -r, s=260, color=color, edgecolor="black")  # draw the node.
for (r1, c1), (r2, c2) in zip(bipath_w[:-1], bipath_w[1:]):  # draw the final path.
    plt.plot([c1, c2], [-r1, -r2], color="crimson", linewidth=3)  # connect consecutive path states.
plt.text(0, 0.25, "start", ha="center"); plt.text(4, 0.25, "goal", ha="center"); plt.text(meet_w[1], -meet_w[0] - 0.35, "meet", ha="center")
plt.axis("equal"); plt.axis("off"); plt.title("4: two BFS waves meet in the middle")
plt.show()
```
▶ What you'll see: blue and orange frontiers meet at a green midpoint, and the red path stitches both halves.

*Why it's done this way: meeting in the middle changes the depth exponent, but only when backward successors are real and set intersection is cheap.*

Iterative deepening reruns depth-limited DFS for every cap. This buys the depth guarantee with a

### ✍️ Toy 4 · Bidirectional waves meet and stitch

Bidirectional BFS runs one wave from the start and one from the goal. On a reversible line, the

## 🛠️ Setup

```python
import numpy as np  # load NumPy for coordinates, arrays, and numerical checks.
import matplotlib.pyplot as plt  # load Matplotlib for tree, frontier, bar, and path visualizations.
from collections import deque  # load deque for FIFO queues in BFS and bidirectional BFS.
np.random.seed(0)  # make all examples reproducible.

def grid_neighbors(node, rows=5, cols=5, blocked=None):  # return legal four-neighbor grid moves.
    blocked = set() if blocked is None else set(blocked)  # normalize blocked cells to a set.
    r, c = node  # unpack the coordinate.
    out = []  # collect valid neighbors.
    for dr, dc in [(0, 1), (1, 0), (0, -1), (-1, 0)]:  # fixed order: right, down, left, up.
        nr, nc = r + dr, c + dc  # candidate neighbor coordinate.
        if 0 <= nr < rows and 0 <= nc < cols and (nr, nc) not in blocked:  # keep legal unblocked cells.
            out.append((nr, nc))  # append the neighbor.
    return out  # return deterministic neighbors.

def reconstruct(parent, node):  # rebuild a path from a parent map ending at node.
    path = []  # collect states backward first.
    while node is not None:  # stop at the root sentinel.
        path.append(node)  # add current state.
        node = parent[node]  # move to parent.
    return path[::-1]  # return start-to-node order.

def bfs_path(start, goal, rows=5, cols=5, blocked=None):  # standard BFS for comparison.
    q = deque([start])  # FIFO frontier.
    parent = {start: None}  # visited states and parents.
    expanded = []  # expansion order for visualization.
    while q:  # process until frontier is empty.
        node = q.popleft()  # BFS pops oldest frontier node.
        expanded.append(node)  # record expansion.
        if node == goal:  # goal reached.
            return reconstruct(parent, goal), expanded, parent  # path and diagnostics.
        for nb in grid_neighbors(node, rows, cols, blocked):  # expand neighbors.
            if nb not in parent:  # first visit only.
                parent[nb] = node  # store predecessor.
                q.append(nb)  # enqueue the neighbor.
    return None, expanded, parent  # no path found.

def depth_limited_search(start, goal, limit, rows=5, cols=5, blocked=None):  # DFS with a depth cap.
    stack = [(start, [start], 0)]  # stack stores node, path, and depth.
    touched = []  # nodes popped from the stack.
    max_active = len(stack)  # maximum stack size seen.
    while stack:  # continue while a branch remains.
        max_active = max(max_active, len(stack))  # track active memory.
        node, path, depth = stack.pop()  # pop the newest branch.
        touched.append(node)  # record one touch.
        if node == goal:  # success within the depth limit.
            return path, touched, max_active  # return diagnostics.
        if depth < limit:  # expand only below the limit.
            for nb in reversed(grid_neighbors(node, rows, cols, blocked)):  # reverse to preserve visual successor order.
                if nb not in path:  # avoid cycles on the current DFS path.
                    stack.append((nb, path + [nb], depth + 1))  # push child path.
    return None, touched, max_active  # no solution within the limit.

def iddfs(start, goal, max_limit, rows=5, cols=5, blocked=None):  # iterative deepening driver.
    history = []  # one record per depth limit.
    for limit in range(max_limit + 1):  # try limits from shallow to deep.
        path, touched, max_active = depth_limited_search(start, goal, limit, rows, cols, blocked)  # run capped DFS.
        history.append({"limit": limit, "path": path, "touched": touched, "max_active": max_active})  # store diagnostics.
        if path is not None:  # stop at first success.
            return path, history  # return the shallowest found path.
    return None, history  # no path within max_limit.

def bidirectional_bfs(start, goal, rows=5, cols=5, blocked=None):  # bidirectional BFS for undirected grids.
    if start == goal:  # trivial case.
        return [start], start, [(set([start]), set([goal]), start)]  # path, meet, layers.
    front_s, front_g = {start}, {goal}  # two active frontiers.
    parent_s, parent_g = {start: None}, {goal: None}  # parent maps for both directions.
    layers = [(set(front_s), set(front_g), None)]  # record frontier pairs.
    meet = None  # no intersection yet.
    prefer_start_on_tie = True  # alternate exact-size ties so neither wave starves.
    while front_s and front_g and meet is None:  # continue until a wave meets or one dies.
        expand_start = len(front_s) < len(front_g) or (len(front_s) == len(front_g) and prefer_start_on_tie)  # choose the smaller side, using the tie toggle.
        prefer_start_on_tie = not prefer_start_on_tie  # flip the tie preference for the next balanced step.
        if expand_start:  # expand the smaller side, alternating exact ties.
            new_front = set()  # next start-side frontier.
            for node in sorted(front_s):  # deterministic iteration.
                for nb in grid_neighbors(node, rows, cols, blocked):  # successors from start side.
                    if nb not in parent_s:  # unseen by start side.
                        parent_s[nb] = node  # record parent.
                        new_front.add(nb)  # add to new frontier.
                        if nb in parent_g and meet is None:  # intersection test.
                            meet = nb  # store meeting state.
            front_s = new_front  # advance side.
        else:  # expand goal side.
            new_front = set()  # next goal-side frontier.
            for node in sorted(front_g):  # deterministic iteration.
                for nb in grid_neighbors(node, rows, cols, blocked):  # predecessor logic equals neighbors in undirected grid.
                    if nb not in parent_g:  # unseen by goal side.
                        parent_g[nb] = node  # record link toward goal.
                        new_front.add(nb)  # add to frontier.
                        if nb in parent_s and meet is None:  # intersection test.
                            meet = nb  # store meeting state.
            front_g = new_front  # advance side.
        layers.append((set(front_s), set(front_g), meet))  # keep visualization state.
    if meet is None:  # no path.
        return None, None, layers  # return failure diagnostics.
    left = reconstruct(parent_s, meet)  # start to meeting point.
    right = []  # meeting successor to goal.
    node = parent_g[meet]  # skip duplicate meet.
    while node is not None:  # follow goal-side parents.
        right.append(node)  # append toward goal.
        node = parent_g[node]  # step closer to goal.
    return left + right, meet, layers  # complete path and diagnostics.

def draw_grid(rows, cols, path=None, start=None, goal=None, blocked=None, title="grid", front_a=None, front_b=None, visited=None):  # draw grid state.
    path = [] if path is None else list(path)  # normalize path.
    blocked = set() if blocked is None else set(blocked)  # normalize blocked cells.
    front_a = set() if front_a is None else set(front_a)  # start-side frontier.
    front_b = set() if front_b is None else set(front_b)  # goal-side frontier.
    visited = set() if visited is None else set(visited)  # visited cells.
    plt.figure(figsize=(4.8, 4))  # create a compact grid figure.
    for r in range(rows):  # draw rows.
        for c in range(cols):  # draw columns.
            cell = (r, c)  # current coordinate.
            color = "white"  # default empty cell.
            if cell in visited: color = "lightgray"  # visited but not frontier.
            if cell in front_a: color = "lightskyblue"  # start-side frontier.
            if cell in front_b: color = "navajowhite"  # goal-side frontier.
            if cell in blocked: color = "black"  # wall.
            if cell == start: color = "seagreen"  # start.
            if cell == goal: color = "crimson"  # goal.
            plt.scatter(c, -r, s=260, color=color, edgecolor="black")  # draw cell.
    if path:  # draw path if provided.
        for (r1, c1), (r2, c2) in zip(path[:-1], path[1:]):  # consecutive states.
            plt.plot([c1, c2], [-r1, -r2], color="purple", linewidth=3)  # path segment.
    plt.axis("equal"); plt.axis("off"); plt.title(title)  # clean grid display.

def tree_layer_counts(b, depth):  # exact layer sizes for a complete b-ary tree.
    return np.array([b ** i for i in range(depth + 1)])  # nodes at each depth.
```
