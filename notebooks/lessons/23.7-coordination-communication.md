# 23.7 — Coordination & Communication

Coordination problems are games where agents mostly want to align, but they may fail because each agent is unsure what the other will do. In this lesson, communication matters less as "extra data" and more as a way to create shared expectations: a public signal can correlate actions, select one equilibrium, and reduce costly off-diagonal mistakes.

### 1. Coordination begins with matching actions

A coordination game rewards agents for landing on the same convention. In the Stag-Hunt version, both choosing Stag gives the highest payoff, while both choosing Hare is safer. The obstacle is not disagreement about values; it is uncertainty about whether the other agent will coordinate with you.

```python
A_w1 = np.array([[4.0, 0.0], [0.0, 3.0]])  # row player's payoff: rows Stag,Hare; columns Stag,Hare.
actions_w1 = ["Stag", "Hare"]  # readable action labels.
print("row payoff matrix:\n", A_w1)  # inspect diagonal rewards and off-diagonal failures.
assert A_w1[0, 0] > A_w1[1, 1] > A_w1[0, 1]  # Stag-Stag best, Hare-Hare safe, mismatch bad.
plt.figure(figsize=(4, 3))  # compact payoff heatmap.
plt.imshow(A_w1, cmap="viridis", vmin=0, vmax=4)  # color encodes row payoff.
plt.colorbar(label="row payoff")  # show payoff scale.
plt.xticks([0, 1], actions_w1); plt.yticks([0, 1], actions_w1)  # label both players' actions.
plt.xlabel("column action"); plt.ylabel("row action")  # make strategic roles explicit.
plt.title("1: coordination payoff matrix")  # title the walkthrough figure.
plt.show()  # display the payoff matrix.
```
▶ What you'll see: the diagonal cells are bright and the off-diagonal cells are dark, so matching is the valuable event.

*Why it's done this way:* a payoff matrix makes the joint-action dependency visible; independent action values would hide the fact that Stag is good only when the other agent also chooses Stag.

### 2. Beliefs create the equilibrium-selection threshold

If the opponent chooses Stag with probability `q`, the row player compares `4q` for Stag against `3(1-q)` for Hare. The switch point is the belief threshold: above it, the high-payoff equilibrium is worth attempting; below it, the safe equilibrium is the best response.

```python
q_w2 = np.linspace(0, 1, 201)  # possible beliefs that the opponent will choose Stag.
u_stag_w2 = 4.0 * q_w2  # expected payoff from choosing Stag.
u_hare_w2 = 3.0 * (1.0 - q_w2)  # expected payoff from choosing Hare.
threshold_w2 = 3.0 / 7.0  # solve 4q = 3(1-q).
print("belief threshold:", round(threshold_w2, 6))  # inspect the exact switch point.
assert abs(threshold_w2 - 0.4285714286) < 1e-9  # verify the lesson threshold.
plt.figure(figsize=(5, 3))  # expected-payoff comparison.
plt.plot(q_w2, u_stag_w2, label="choose Stag", color="seagreen")  # payoff if trying Stag.
plt.plot(q_w2, u_hare_w2, label="choose Hare", color="darkorange")  # payoff if choosing safe Hare.
plt.axvline(threshold_w2, color="black", linestyle="--", label="threshold")  # mark best-response switch.
plt.xlabel("belief q = P(opponent Stag)"); plt.ylabel("expected payoff")  # label axes.
plt.title("2: best response changes at q = 3/7")  # title the threshold plot.
plt.legend()  # show line meanings.
plt.show()  # display the expected-payoff curves.
```
▶ What you'll see: the Stag line crosses the Hare line at about 0.429.

*Why it's done this way:* coordination failures often happen near thresholds; both agents may like Stag-Stag more, yet avoid it unless they believe the other will also try it.

### 3. Public signals correlate actions without changing payoffs

Independent randomization fails often because two private coin flips do not match. A public signal is valuable because both agents condition on the same event. Even if the signal carries no external measurement, it can select a shared action and turn randomness into coordination.

```python
p_w3 = 0.5  # probability that each independent agent chooses Stag.
independent_payoff_w3 = p_w3 ** 2 * 4.0 + (1.0 - p_w3) ** 2 * 3.0  # expected payoff from independent random actions.
public_payoff_w3 = 0.5 * 4.0 + 0.5 * 3.0  # expected payoff when a public device recommends a matching diagonal cell.
print("independent payoff:", independent_payoff_w3)  # 1.75 from only matching half the time.
print("public-signal payoff:", public_payoff_w3)  # 3.5 from always matching the recommendation.
assert public_payoff_w3 - independent_payoff_w3 == 1.75  # verify the correlation gain.
plt.figure(figsize=(4.5, 3))  # compare payoff mechanisms.
plt.bar(["independent", "public signal"], [independent_payoff_w3, public_payoff_w3], color=["gray", "teal"])  # payoff bars.
plt.ylabel("expected payoff per agent")  # label payoff axis.
plt.title("3: correlation beats private randomization")  # title the comparison.
plt.show()  # display the payoff bars.
```
▶ What you'll see: the public signal doubles the expected payoff in this toy mix.

*Why it's done this way:* communication is useful here because it correlates actions, not because it gives either agent a new action or changes the underlying payoff matrix.

### 4. Noisy messages can become another source of miscoordination

A message helps only if agents receive compatible information. If each agent receives the intended recommendation correctly with probability `a`, their actions match with probability `a² + (1-a)²`. At `a=0.5`, the message is no better than random guessing; at high accuracy, it restores common belief.

```python
acc_w4 = np.linspace(0.5, 1.0, 101)  # message accuracy from useless to perfect.
match_w4 = acc_w4 ** 2 + (1.0 - acc_w4) ** 2  # probability both received signals imply the same action.
expected_w4 = match_w4 * 3.5  # simple payoff scale: matched recommendations average 3.5.
print("match probability at a=0.8:", round(0.8 ** 2 + 0.2 ** 2, 3))  # inspect the lesson value.
assert round(0.8 ** 2 + 0.2 ** 2, 3) == 0.68  # verify noisy-message calculation.
plt.figure(figsize=(5, 3))  # message-quality curve.
plt.plot(acc_w4, match_w4, color="purple", label="P(actions match)")  # match probability by accuracy.
plt.plot(acc_w4, expected_w4 / 3.5, color="seagreen", linestyle="--", label="scaled payoff")  # same shape as payoff.
plt.xlabel("message accuracy a"); plt.ylabel("fraction")  # label axes.
plt.title("4: noisy communication erodes coordination")  # title the plot.
plt.legend()  # show curve labels.
plt.show()  # display message-accuracy effects.
```
▶ What you'll see: matching rises from 0.5 at random messages to 1.0 at perfect messages.

*Why it's done this way:* a signal must create common expectations; if agents condition on different received messages, communication itself can trigger off-diagonal outcomes.

### 5. Learning dynamics reveal equilibrium basins

Repeated interaction can settle into different conventions. A simple best-response dynamic says each agent observes the other side's current probability of Stag, then chooses the best response next. Starting above the threshold flows to Stag-Stag; starting below it flows to Hare-Hare.

```python
starts_w5 = np.linspace(0.05, 0.95, 10)  # initial beliefs or mixed Stag probabilities.
T_w5 = 8  # number of best-response iterations.
paths_w5 = []  # store probability paths.
for start_w5 in starts_w5:  # simulate each initial condition.
    path_w5 = [start_w5]  # begin from a starting Stag probability.
    p_now_w5 = start_w5  # current probability.
    for _ in range(T_w5):  # repeated best responses.
        p_now_w5 = 1.0 if p_now_w5 > 3.0 / 7.0 else 0.0  # best response to belief.
        path_w5.append(p_now_w5)  # store the new convention tendency.
    paths_w5.append(path_w5)  # save path.
finals_w5 = np.array([path_w5[-1] for path_w5 in paths_w5])  # final selected basin.
print("final Stag probabilities:", finals_w5.astype(int))  # inspect equilibrium selection.
assert np.all(finals_w5[starts_w5 > 3.0 / 7.0] == 1.0)  # above threshold goes to Stag.
plt.figure(figsize=(5, 3))  # basin visualization.
for start_w5, path_w5 in zip(starts_w5, paths_w5):  # draw each path.
    plt.plot(path_w5, alpha=0.75, color="seagreen" if path_w5[-1] == 1.0 else "darkorange")  # color by equilibrium.
plt.axhline(3.0 / 7.0, color="black", linestyle="--", label="threshold")  # mark basin boundary.
plt.xlabel("iteration"); plt.ylabel("probability of Stag")  # label axes.
plt.title("5: best-response basins select conventions")  # title dynamics plot.
plt.legend()  # show threshold label.
plt.show()  # display convergence paths.
```
▶ What you'll see: starts above the threshold jump to Stag, while starts below it collapse to Hare.

*Why it's done this way:* basins explain why coordination games need equilibrium-selection mechanisms; the same payoffs can support multiple stable outcomes.

## 🛠️ Setup

```python
import numpy as np  # numerical arrays and simulation.
import matplotlib.pyplot as plt  # all examples include a relevant visualization.
np.random.seed(0)  # reproducible examples.

A = np.array([[4.0, 0.0], [0.0, 3.0]])  # canonical Stag-Hunt payoff for both players.
actions = ["Stag", "Hare"]  # action labels used in plots.

def best_response_to_stag_prob(q):  # return a pure best response to belief q.
    return 0 if 4.0 * q >= 3.0 * (1.0 - q) else 1  # 0 means Stag, 1 means Hare.

def expected_payoffs(q):  # expected payoff from each pure action against belief q.
    return np.array([4.0 * q, 3.0 * (1.0 - q)])  # [Stag payoff, Hare payoff].

def simulate_fictitious_play(start_counts_row, start_counts_col, rounds=40):  # deterministic two-player fictitious play.
    row_counts = np.array(start_counts_row, dtype=float)  # row player's observed column-action counts.
    col_counts = np.array(start_counts_col, dtype=float)  # column player's observed row-action counts.
    row_hist, col_hist = [], []  # store chosen actions.
    for _ in range(rounds):  # iterate belief updates and best responses.
        q_col_stag = row_counts[0] / row_counts.sum()  # row belief that column plays Stag.
        q_row_stag = col_counts[0] / col_counts.sum()  # column belief that row plays Stag.
        row_action = best_response_to_stag_prob(q_col_stag)  # row best response.
        col_action = best_response_to_stag_prob(q_row_stag)  # column best response in symmetric game.
        row_hist.append(row_action); col_hist.append(col_action)  # store actions.
        col_counts[row_action] += 1.0  # column observes row action.
        row_counts[col_action] += 1.0  # row observes column action.
    return np.array(row_hist), np.array(col_hist)  # action histories.

def plot_payoff_matrix(M, title):  # heatmap helper for 2x2 payoff matrices.
    plt.figure(figsize=(4, 3))  # compact matrix plot.
    plt.imshow(M, cmap="viridis", vmin=float(np.min(M)), vmax=float(np.max(M)))  # payoff heatmap.
    plt.colorbar(label="payoff")  # numeric payoff scale.
    plt.xticks([0, 1], actions); plt.yticks([0, 1], actions)  # label actions.
    plt.xlabel("column action"); plt.ylabel("row action")  # strategic axes.
    plt.title(title)  # plot title.
    plt.show()  # display figure.
```

#### B4. Identify pure Nash equilibria

**Goal.** Check which diagonal outcomes are stable, because coordination games often have multiple Nash equilibria. We build it in 2 steps.

```python
A_b4 = np.array([[4.0, 0.0], [0.0, 3.0]])  # symmetric payoff matrix.
equilibria_b4 = []  # collect pure equilibria.
for i_b4 in range(2):  # row action.
    for j_b4 in range(2):  # column action.
        row_best_b4 = A_b4[i_b4, j_b4] >= np.max(A_b4[:, j_b4])  # row cannot improve given column.
        col_best_b4 = A_b4[i_b4, j_b4] >= np.max(A_b4[i_b4, :])  # column cannot improve given row by symmetry.
        if row_best_b4 and col_best_b4:  # mutual best responses.
            equilibria_b4.append((i_b4, j_b4))  # store equilibrium action pair.
print("pure Nash equilibria:", equilibria_b4)  # inspect stable outcomes.
assert equilibria_b4 == [(0, 0), (1, 1)]  # Stag-Stag and Hare-Hare are both equilibria.
```
▶ What you'll see: both matching outcomes are self-enforcing.

```python
eq_mask_b4 = np.zeros_like(A_b4)  # matrix marking equilibria.
```

#### A5. Couple communication with best-response learning

**Goal.** Add a temporary public signal before learning, because early communication can push agents into the high-payoff basin and then convention maintains itself. We build it in 3 steps.

```python
T_a5 = 30  # total rounds.
warmup_a5 = 5  # rounds with public Stag recommendation.
counts_with_a5 = np.array([1.0, 3.0])  # initially Hare-heavy observed column counts.
counts_without_a5 = np.array([1.0, 3.0])  # same initial counts without communication.
hist_with_a5, hist_without_a5 = [], []  # action histories.
print("initial Stag belief:", counts_with_a5[0] / counts_with_a5.sum())  # inspect below-threshold start.
assert counts_with_a5[0] / counts_with_a5.sum() < 3.0 / 7.0  # initially in Hare basin.
```
▶ What you'll see: without help, the initial belief is below the Stag threshold.

```python
for t_a5 in range(T_a5):  # simulate two learning systems.
    action_with_a5 = 0 if t_a5 < warmup_a5 else best_response_to_stag_prob(counts_with_a5[0] / counts_with_a5.sum())  # signal first, then best response.
    action_without_a5 = best_response_to_stag_prob(counts_without_a5[0] / counts_without_a5.sum())  # no signal.
    hist_with_a5.append(action_with_a5); hist_without_a5.append(action_without_a5)  # store actions.
    counts_with_a5[action_with_a5] += 1.0; counts_without_a5[action_without_a5] += 1.0  # update observed counts.
stag_with_a5 = np.cumsum(np.array(hist_with_a5) == 0) / np.arange(1, T_a5 + 1)  # running Stag share with communication.
stag_without_a5 = np.cumsum(np.array(hist_without_a5) == 0) / np.arange(1, T_a5 + 1)  # running Stag share without communication.
print("final shares:", round(stag_with_a5[-1], 3), round(stag_without_a5[-1], 3))  # compare outcomes.
assert stag_with_a5[-1] > stag_without_a5[-1]  # warmup communication improves convention.
```

```python

plt.plot(stag_with_a5, label="5-round Stag signal", color="seagreen")  # communication-assisted path.
plt.plot(stag_without_a5, label="no signal", color="darkorange")  # baseline path.
plt.axhline(3.0 / 7.0, color="black", linestyle="--", label="threshold")  # basin boundary.

plt.title("A5: early communication selects a convention")  # title plot.
plt.legend()  # show path labels.
plt.show()  # display convention paths.
```
▶ What you'll see: a short communication phase can lift beliefs into the Stag basin, while no signal stays Hare-heavy.

👀 Takeaway: communication can be transient but still durable when it creates a convention that later best-response learning preserves.
