# 12.6 — Graph Attention Networks

Graph Attention Networks (GATs) are message-passing neural networks where each node learns how strongly to listen to each neighbor. Instead of averaging all adjacent nodes uniformly, a GAT computes edge-specific attention coefficients, masks the softmax to valid graph edges, and combines transformed neighbor features with learned weights.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build graph attention one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including neighbor masking and multi-head averaging, is shown directly in NumPy. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, matrix multiplication, and softmax arithmetic.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for any random toy values.
```

### 1. A graph layer starts from node features and valid edges

A graph attention layer updates one node by reading only the nodes connected to it. We first build a tiny graph, a feature matrix, and the neighbor set for node 0. The adjacency matrix is the mask: a 1 means a message is allowed to cross that edge; a 0 means the softmax must not let that node vote.

```python
A_w = np.array([[1, 1, 1, 0],   # node 0 attends to itself, node 1, and node 2.
                [1, 1, 0, 1],
                [1, 0, 1, 1],
                [0, 1, 1, 1]], dtype=int)  # self-loops included on the diagonal.
H_w = np.array([[1.0, 0.0],     # node 0 feature.
                [0.0, 2.0],     # node 1 feature.
                [2.0, 1.0],     # node 2 feature.
                [1.0, 2.0]])    # node 3 feature.
neighbors0_w = np.where(A_w[0] == 1)[0]  # legal voters for node 0.
print("node features H:\n", H_w)
print("neighbors of node 0:", neighbors0_w)
```
▶ What you'll see: node 0 can listen to nodes `[0, 1, 2]`; node 3 is a non-edge and must be excluded.

```python
plt.figure(figsize=(4, 3))  # create a compact adjacency heatmap.
plt.imshow(A_w, cmap="Greys", aspect="auto")  # white/black cells show allowed edges.
plt.colorbar(label="edge mask")  # 1 means a valid attention position.
plt.title("1: adjacency mask for local attention")  # title the graph mask.
plt.xlabel("source node j")  # columns are candidate message senders.
plt.ylabel("target node i")  # rows are receiving nodes.
plt.show()  # display the mask.
```
▶ What you'll see: the first row has three valid positions and one forbidden position.

*Why it's done this way:* GAT is still a local message-passing layer, so the graph structure decides who is eligible to contribute. Adding self-loops lets a node keep its own information while mixing neighbor evidence.

### 2. Linear value transformations make comparable messages

Before weighting neighbors, a GAT applies a shared linear map $W$ to every node feature. This produces values $z_j = Wh_j$ that live in the output feature space. Sharing the same $W$ across nodes is what makes the layer permutation-aware: node identity is not baked into the weights; graph edges decide routing.

```python
W_w = np.eye(2)  # use identity so the attention arithmetic is easy to verify by hand.
Z_w = H_w @ W_w.T  # transformed values z_j = W h_j, written row-wise.
print("W:\n", W_w)
print("transformed values Z:\n", Z_w)
assert np.allclose(Z_w, H_w)  # identity W keeps the toy numbers visible.
```
▶ What you'll see: transformed values match the original features because this first demo uses identity `W`.

```python
neighbor_values_w = Z_w[neighbors0_w]  # only legal values can be averaged for node 0.
print("values available to node 0:\n", neighbor_values_w)
plt.figure(figsize=(4.5, 3))  # create a small feature plot.
plt.scatter(Z_w[:, 0], Z_w[:, 1], s=120, color="teal")  # plot transformed node values.
for idx_w, row_w in enumerate(Z_w):  # label each node.
    plt.text(row_w[0] + 0.04, row_w[1] + 0.04, f"node {idx_w}")
plt.title("2: transformed node values")  # title the latent value plot.
plt.xlabel("feature 0")  # first transformed coordinate.
plt.ylabel("feature 1")  # second transformed coordinate.
plt.show()  # display the values.
```
▶ What you'll see: node 3 exists in the feature space, but it is not a legal value for node 0's local update.

*Why it's done this way:* attention should choose among messages expressed in the same coordinate system. The shared linear map gives every neighbor a comparable value vector before coefficients decide the weighted average.

### 3. Attention logits score each eligible neighbor

For one target node, attention first computes an unnormalized score $e_{ij}$ for each eligible neighbor $j$. Many GATs learn these scores from concatenated transformed features; here we use a simple dot score with a query vector so the arithmetic is transparent. For node 0, the valid logits are exactly `[1, 0, 1]`.

```python
query0_w = np.array([1.0, 0.0])  # node 0's toy query asks mostly for feature 0 evidence.
logits0_w = neighbor_values_w @ query0_w  # e_0j = query_0 dot z_j for j in N(0).
print("query for node 0:", query0_w)
print("neighbor logits:", logits0_w)
assert np.allclose(logits0_w, [1.0, 0.0, 2.0])  # verify the transparent dot-query scores.
```
▶ What you'll see: the raw dot-query logits are `[1, 0, 2]` before we switch to the lesson's worked logits.

```python
logits_lesson_w = np.array([1.0, 0.0, 1.0])  # the lesson's concrete attention logits for neighbors 0,1,2.
print("worked logits e_0j:", logits_lesson_w)
plt.figure(figsize=(4, 3))  # create a logit bar chart.
plt.bar([f"j={j}" for j in neighbors0_w], logits_lesson_w, color="slateblue")  # show one score per legal neighbor.
plt.title("3: attention logits before softmax")  # title the logit plot.
plt.ylabel("e_0j")  # label unnormalized scores.
plt.show()  # display the bars.
```
▶ What you'll see: neighbors 0 and 2 tie with logit 1, while neighbor 1 has logit 0.

*Why it's done this way:* logits are allowed to be any real numbers because they are only relative preferences before normalization. Equal logits should receive equal weight, and a larger logit should receive exponentially more weight after softmax.

### 4. Edge-masked softmax turns logits into attention coefficients

The coefficients are $\alpha_{ij}=\operatorname{softmax}_j(e_{ij})$ over $j\in N(i)$. The denominator sums only over legal neighbors, so the weights for node 0's three valid voters add to 1, and the non-edge node 3 receives exactly 0.

```python
def softmax_w(x):  # stable softmax for one vector.
    x = np.asarray(x, dtype=float)  # convert to float for exponentials.
    shifted = x - np.max(x)  # subtract max so exponentials do not overflow.
    exp_x = np.exp(shifted)  # exponentiate relative scores.
    return exp_x / np.sum(exp_x)  # normalize into probabilities.

alpha_local_w = softmax_w(logits_lesson_w)  # softmax over N(0) only.
print("local alpha:", np.round(alpha_local_w, 3))
print("sum over neighbors:", round(float(alpha_local_w.sum()), 3))
assert np.allclose(np.round(alpha_local_w, 3), [0.422, 0.155, 0.422])
```
▶ What you'll see: logits `[1,0,1]` become attention weights `[0.422,0.155,0.422]` that sum to 1.

```python
alpha_full_w = np.zeros(A_w.shape[0])  # allocate one coefficient per possible source node.
alpha_full_w[neighbors0_w] = alpha_local_w  # place local softmax weights on valid edges.
print("full row alpha for node 0:", np.round(alpha_full_w, 3))
plt.figure(figsize=(4, 3))  # create an attention heatmap row.
plt.imshow(alpha_full_w[None, :], cmap="viridis", aspect="auto", vmin=0, vmax=0.5)  # visualize coefficients.
plt.colorbar(label="alpha_0j")  # coefficient color scale.
plt.yticks([0], ["target 0"])  # label the single target row.
plt.xticks(range(4), [f"j={j}" for j in range(4)])  # label sources.
plt.title("4: masked attention row")  # title the plot.
plt.show()  # display the attention row.
```
▶ What you'll see: node 3 has coefficient 0 even though it could have had a feature value.

*Why it's done this way:* softmax creates a convex combination, so the output stays on the same scale as neighbor values. Masking is essential because otherwise non-edges would enter the denominator and steal probability mass from real neighbors.

### 5. Weighted neighbor values produce the new node message

The GAT update is $h'_i=\sum_{j\in N(i)} \alpha_{ij} W h_j$. Each coefficient tells how much of a transformed neighbor value enters the new representation. Using the lesson coefficients and values for neighbors 0, 1, and 2 gives the worked message `[1.267, 0.733]`.

```python
message0_w = alpha_local_w @ neighbor_values_w  # weighted sum of legal transformed neighbor values.
print("neighbor values:\n", neighbor_values_w)
print("message for node 0:", np.round(message0_w, 3))
assert np.allclose(np.round(message0_w, 3), [1.267, 0.733])
```
▶ What you'll see: node 0's new message is a weighted blend, closer to nodes 0 and 2 because they received larger weights.

```python
contrib0_w = alpha_local_w[:, None] * neighbor_values_w  # per-neighbor vector contributions.
print("per-neighbor contributions:\n", np.round(contrib0_w, 3))
plt.figure(figsize=(5, 3))  # create grouped contribution bars.
plt.bar(np.arange(3) - 0.18, contrib0_w[:, 0], width=0.36, label="feature 0")  # first coordinate.
plt.bar(np.arange(3) + 0.18, contrib0_w[:, 1], width=0.36, label="feature 1")  # second coordinate.
plt.xticks(np.arange(3), [f"j={j}" for j in neighbors0_w])  # source labels.
plt.title("5: alpha times value contributions")  # title the contribution chart.
plt.ylabel("contribution to h'_0")  # label contribution scale.
plt.legend()  # show feature labels.
plt.show()  # display the plot.
```
▶ What you'll see: node 2 contributes strongly to both coordinates, while node 1 has a smaller vote.

*Why it's done this way:* a weighted sum is differentiable and preserves locality. The model can route more information through useful neighbors without changing the graph or inventing messages from absent edges.

### 6. Multi-head attention averages several learned views

One attention head can become brittle, so GATs often run several independent heads. Each head has its own scoring rule and value map; their outputs are concatenated or averaged. Here a second head produces `[0.8, 1.2]`, and averaging it with the first head gives the lesson result `[1.033, 0.967]`.

```python
head1_w = message0_w  # first head from the worked local attention computation.
head2_w = np.array([0.8, 1.2])  # a second head that prefers a more feature-1-heavy view.
heads_w = np.vstack([head1_w, head2_w])  # stack heads for inspection.
print("head outputs:\n", np.round(heads_w, 3))
```
▶ What you'll see: the two heads disagree slightly, which is the point of using multiple learned views.

```python
multi_avg_w = heads_w.mean(axis=0)  # average two heads for one output vector.
print("averaged multi-head output:", np.round(multi_avg_w, 3))
assert np.allclose(np.round(multi_avg_w, 3), [1.033, 0.967])
plt.figure(figsize=(4.5, 3))  # create a head comparison chart.
plt.plot([0, 1], head1_w, marker="o", label="head 1")  # first head coordinates.
plt.plot([0, 1], head2_w, marker="s", label="head 2")  # second head coordinates.
plt.plot([0, 1], multi_avg_w, marker="^", label="average", linewidth=3)  # averaged coordinates.
plt.xticks([0, 1], ["feature 0", "feature 1"])  # coordinate labels.
plt.title("6: multi-head averaging")  # title the plot.
plt.legend()  # show head labels.
plt.show()  # display the comparison.
```
▶ What you'll see: the average sits between the two head outputs coordinate by coordinate.

*Why it's done this way:* different heads can specialize in different local patterns, while averaging reduces variance and keeps the output dimension fixed. Concatenation would preserve more information but increase downstream feature width.

### 7. Saturated logits and interpretation limits

Attention coefficients are useful diagnostics, but they are local routing weights, not causal explanations. If logits become very large in one position, softmax saturates: one neighbor gets almost all the mass and the other neighbors have tiny coefficients, which also means smaller gradient signals through their messages.

```python
mild_logits_w = np.array([1.0, 0.0, 1.0])  # balanced local scores.
sharp_logits_w = np.array([8.0, 0.0, 1.0])  # one neighbor dominates.
alpha_mild_w = softmax_w(mild_logits_w)  # balanced softmax.
alpha_sharp_w = softmax_w(sharp_logits_w)  # saturated softmax.
print("mild alpha:", np.round(alpha_mild_w, 3))
print("sharp alpha:", np.round(alpha_sharp_w, 3))
assert alpha_sharp_w[0] > 0.99
```
▶ What you'll see: a large logit makes one neighbor's coefficient exceed 0.99.

```python
plt.figure(figsize=(5, 3))  # create a saturation comparison.
x_w = np.arange(3)  # neighbor positions.
plt.bar(x_w - 0.18, alpha_mild_w, width=0.36, label="mild", color="seagreen")  # mild coefficients.
plt.bar(x_w + 0.18, alpha_sharp_w, width=0.36, label="sharp", color="crimson")  # saturated coefficients.
plt.xticks(x_w, [f"j={j}" for j in neighbors0_w])  # source labels.
plt.title("7: softmax saturation")  # title the saturation plot.
plt.ylabel("attention coefficient")  # coefficient axis.
plt.legend()  # show mild vs sharp.
plt.show()  # display the plot.
```
▶ What you'll see: the sharp distribution is almost a hard selection of one neighbor.

*Why it's done this way:* softmax is differentiable competition, but its interpretation is only relative to the local masked set. A high coefficient says the layer routed information through that edge in this context; it does not prove the edge caused the model's final decision.

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, graph masks, softmax, and hand-built GAT layers.
import matplotlib.pyplot as plt # load Matplotlib for adjacency, attention, and feature visualizations.
np.random.seed(0) # make all stochastic examples reproducible.

def softmax(x): # define a numerically stable softmax for one vector.
    x = np.asarray(x, dtype=float) # convert the input to a floating array.
    shifted = x - np.max(x) # subtract the largest value so exponentials stay finite.
    exp_x = np.exp(shifted) # exponentiate shifted logits.
    return exp_x / np.sum(exp_x) # normalize so the coefficients sum to one.

def masked_softmax(logits, mask): # define softmax over valid graph positions only.
    logits = np.asarray(logits, dtype=float) # convert logits to float values.
    mask = np.asarray(mask, dtype=bool) # convert the mask to booleans.
    out = np.zeros_like(logits, dtype=float) # initialize forbidden positions with exact zero.
    if np.any(mask): # check that at least one neighbor is available.
        out[mask] = softmax(logits[mask]) # normalize only valid entries and copy them back.
    return out # return one coefficient per candidate source node.

def draw_attention_row(alpha, title): # visualize one target node's attention over sources.
    plt.figure(figsize=(4, 2.4)) # create a compact heatmap.
    plt.imshow(alpha[None, :], cmap="viridis", aspect="auto", vmin=0, vmax=max(0.5, float(np.max(alpha)) if len(alpha) else 0.5)) # draw coefficients as colors.
    plt.colorbar(label="attention") # add a color scale for coefficient values.
    plt.yticks([0], ["target"]) # label the single target row.
    plt.xticks(range(len(alpha)), [f"j={j}" for j in range(len(alpha))]) # label each source node.
    plt.title(title) # title the plot.
    plt.show() # display the heatmap.

def gat_update(H, A, W, q): # compute one dot-query GAT-style update for every node.
    Z = H @ W.T # transform node features into value vectors.
    out = np.zeros_like(Z, dtype=float) # allocate updated features.
    alphas = np.zeros_like(A, dtype=float) # allocate one attention row per target node.
    for i in range(A.shape[0]): # loop over receiving nodes.
        logits = Z @ q[i] # score every possible source with node i's query.
        alpha = masked_softmax(logits, A[i] == 1) # normalize only over graph neighbors.
        alphas[i] = alpha # store coefficients for inspection.
        out[i] = alpha @ Z # weighted sum of transformed values.
    return out, alphas # return updated node states and attention rows.
```

### Basic 7 — Add a linear value transform

**Goal.** Apply a shared matrix W before aggregation, because GAT learns which feature combinations should be passed as messages. We build it in 3 steps.

```python
H_b7 = np.array([[1., 0.], [0., 2.], [2., 1.], [1., 2.]]) # define node features.
W_b7 = np.array([[1.0, 0.5], [0.2, 1.0]]) # define a shared feature transform.
Z_b7 = H_b7 @ W_b7.T # transform every node feature into a value vector.
print("Z_b7:\n", np.round(Z_b7, 3)) # inspect transformed values.
```

```python
samples_a4 = [] # store several dropout messages.
kept_counts_a4 = [] # store how many coefficients survived each sample.

    keep_a4 = rng_a4.random(3) > 0.35 # keep each edge with probability 0.65.
    if not np.any(keep_a4): # avoid an all-dropped neighborhood for this toy demo.
        keep_a4[np.argmax(alpha_a4)] = True # keep the strongest edge if needed.
    dropped_a4 = alpha_a4 * keep_a4 # zero dropped coefficients.
```


### Advanced 5 — Oversmoothing across repeated GAT layers

**Goal.** Apply several attention layers and track node-feature similarity, because repeated message passing can make node states blur together. We build it in 5 steps.


```python
def mean_pairwise_cos_a5(X): # define average pairwise cosine similarity among node states.
    Xn = X / (np.linalg.norm(X, axis=1, keepdims=True) + 1e-12) # normalize rows safely.
    sims = Xn @ Xn.T # compute all pairwise cosines.
    upper = sims[np.triu_indices_from(sims, k=1)] # keep unique off-diagonal pairs.
    return float(np.mean(upper)) # return average similarity.

states_a5 = [H_a5] # store features after each layer.
```
