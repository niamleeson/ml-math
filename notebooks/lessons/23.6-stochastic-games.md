# 23.6 — Stochastic Games

A stochastic game is a Markov decision process with more than one decision-maker: the next state and each reward depend on the **joint action** chosen by all players. In this lesson, we build a tiny two-player zero-sum grid game from scratch, solve Bellman backups that contain stage games, and train minimax-Q values with only NumPy and Matplotlib.

## 📖 Concept walkthrough — build each idea from scratch

Before the worked examples, we build stochastic games one idea at a time. Run each cell in order and read the printed values — the state, transition, reward, discount, equilibrium backup, and learning loop are all explicit. This walkthrough is self-contained and uses a `_w` suffix so it never clashes with the examples below.

```python
import numpy as np  # arrays, tabular values, and reproducible toy dynamics.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for stochastic examples.
```

### 1. From an MDP action to a joint action

An MDP chooses one action in one state. A stochastic game chooses a **joint action**: player 0 chooses `a0`, player 1 chooses `a1`, and the pair `(a0, a1)` determines both reward and transition. That small change is the bridge from reinforcement learning to game theory.

```python
states_w = ["center", "safe"]  # two Markov states.
row_actions_w = ["push", "wait"]  # player 0 actions.
col_actions_w = ["block", "yield"]  # player 1 actions.
R_w = np.array([[[0.0, 2.0], [-1.0, 1.0]], [[0.4, 0.8], [0.2, 0.6]]])  # row rewards by state,row,col.
print("reward tensor shape:", R_w.shape)  # state x row-action x column-action.
print("center payoff matrix:\n", R_w[0])  # inspect the stage game at state 0.
assert R_w.shape == (2, 2, 2)  # two states and two actions per player.
```
▶ What you'll see: each state contains a small payoff matrix rather than a single reward vector.

```python
plt.figure(figsize=(4.2, 3.2))
plt.imshow(R_w[0], cmap="coolwarm", vmin=-2, vmax=2)
plt.colorbar(label="row reward")
plt.xticks(range(2), col_actions_w); plt.yticks(range(2), row_actions_w)
plt.title("1: stage-game payoff at center")
plt.show()
```
▶ What you'll see: player 0 prefers `push` if player 1 yields, but player 1 can block.

*Why it's done this way:* a payoff matrix makes strategic dependence visible: an action is good only relative to the other player's action.

### 2. Transitions also depend on everyone

In a stochastic game, the transition law is $P(s'\mid s,a_0,a_1)$. The same row action can be safe or risky depending on the opponent. That is why treating the other learner as stationary noise breaks: the world model changes when the opponent changes policy.

```python
P_w = np.zeros((2, 2, 2, 2))  # P[state,row-action,col-action,next-state].
P_w[0, 0, 0] = [0.8, 0.2]  # push vs block mostly stays center.
P_w[0, 0, 1] = [0.2, 0.8]  # push vs yield often reaches safe.
P_w[0, 1, 0] = [0.6, 0.4]  # wait vs block.
P_w[0, 1, 1] = [0.4, 0.6]  # wait vs yield.
P_w[1, :, :, 1] = 1.0  # safe is absorbing in this toy game.
print("row sums at center:\n", P_w[0].sum(axis=-1))  # every joint action must sum to 1.
assert np.allclose(P_w.sum(axis=-1), 1.0)  # valid probability distributions.
```
▶ What you'll see: every `(row action, column action)` pair has its own next-state distribution.

```python
plt.figure(figsize=(4.2, 3.2))
plt.imshow(P_w[0, :, :, 1], cmap="viridis", vmin=0, vmax=1)
plt.colorbar(label="Pr(next=safe)")
plt.xticks(range(2), col_actions_w); plt.yticks(range(2), row_actions_w)
plt.title("2: transition probability depends on joint action")
plt.show()
```
▶ What you'll see: `push` is valuable only when the opponent yields because it moves the game to `safe`.

*Why it's done this way:* putting the opponent's action inside the transition model forces future consequences to be strategic, not merely environmental.

### 3. Fixed-policy values are ordinary Bellman values

If both policies are fixed, a stochastic game collapses to an induced Markov reward process for each player. The value still satisfies a Bellman equation: immediate expected reward plus discounted expected continuation value.

```python
pi_row_w = np.array([[0.7, 0.3], [0.2, 0.8]])  # row policy per state.
pi_col_w = np.array([[0.4, 0.6], [0.5, 0.5]])  # column policy per state.
gamma_w = 0.9  # discount factor.
P_pi_w = np.zeros((2, 2)); r_pi_w = np.zeros(2)  # induced transition and reward.
for s_w in range(2):
    for a_w in range(2):
        for b_w in range(2):
            prob_w = pi_row_w[s_w, a_w] * pi_col_w[s_w, b_w]
            r_pi_w[s_w] += prob_w * R_w[s_w, a_w, b_w]
            P_pi_w[s_w] += prob_w * P_w[s_w, a_w, b_w]
V_pi_w = np.linalg.solve(np.eye(2) - gamma_w * P_pi_w, r_pi_w)
print("induced rewards:", np.round(r_pi_w, 3))
print("fixed-policy values:", np.round(V_pi_w, 3))
assert V_pi_w.shape == (2,)
```
▶ What you'll see: fixed policies turn joint actions into averaged rewards and averaged transitions.

```python
plt.figure(figsize=(4.2, 3.0))
plt.bar(states_w, V_pi_w, color="seagreen")
plt.title("3: value under fixed joint policies")
plt.ylabel("V_row(s)")
plt.show()
```
▶ What you'll see: the state value is long-run discounted payoff, not just immediate reward.

*Why it's done this way:* fixed policies remove the equilibrium problem so the Bellman structure can be seen before adding strategic backups.

### 4. A Bellman backup can contain a stage-game equilibrium

For a zero-sum stochastic game, a backup at state `s` forms a matrix

$$M_s(a,b)=r(s,a,b)+\gamma\sum_{s'}P(s'\mid s,a,b)V(s')$$

and then takes the value of that matrix game. The row player maximizes the guaranteed value; the column player minimizes it.

```python
def zero_sum_2x2_value_w(M_w):
    grid_w = np.linspace(0.0, 1.0, 1001)  # row probability of action 0.
    guarantees_w = []
    for p_w in grid_w:
        mix_w = np.array([p_w, 1.0 - p_w])
        guarantees_w.append(np.min(mix_w @ M_w))
    idx_w = int(np.argmax(guarantees_w))
    return float(guarantees_w[idx_w]), np.array([grid_w[idx_w], 1.0 - grid_w[idx_w]])

V_old_w = np.array([0.0, 2.0])  # continuation values from a previous iteration.
M_center_w = R_w[0] + gamma_w * np.tensordot(P_w[0], V_old_w, axes=([2], [0]))
backup_w, row_mix_w = zero_sum_2x2_value_w(M_center_w)
print("backup matrix:\n", np.round(M_center_w, 3))
print("state value:", round(backup_w, 3), "row mix:", np.round(row_mix_w, 3))
assert M_center_w.shape == (2, 2)
```
▶ What you'll see: continuation value changes the local payoff matrix before solving the stage game.

```python
plt.figure(figsize=(4.2, 3.2))
plt.imshow(M_center_w, cmap="coolwarm")
plt.colorbar(label="reward + discounted continuation")
plt.xticks(range(2), col_actions_w); plt.yticks(range(2), row_actions_w)
plt.title("4: Bellman backup matrix")
plt.show()
```
▶ What you'll see: the best action is no longer judged by immediate reward alone.

*Why it's done this way:* a stochastic-game backup must solve the strategic choice inside the state before passing a scalar value to dynamic programming.

### 5. Discounting makes future state control dominate

The discount factor decides how strongly future states matter. With small $\gamma$, the immediate payoff matrix dominates. With large $\gamma$, tiny transition differences can create large value gaps, so policy changes can destabilize learning.

```python
gammas_w = np.array([0.1, 0.5, 0.9, 0.99])
values_w = []
for g_w in gammas_w:
    V_w = np.zeros(2)
    for _ in range(80):
        new_w = np.zeros(2)
        for s_w in range(2):
            M_w = R_w[s_w] + g_w * np.tensordot(P_w[s_w], V_w, axes=([2], [0]))
            new_w[s_w], _ = zero_sum_2x2_value_w(M_w)
        V_w = new_w
    values_w.append(V_w[0])
values_w = np.array(values_w)
print("center values by gamma:", np.round(values_w, 3))
assert values_w[-1] > values_w[0]
```
▶ What you'll see: the same game receives much larger value when agents are patient.

```python
plt.figure(figsize=(4.5, 3.0))
plt.plot(gammas_w, values_w, marker="o", color="purple")
plt.title("5: discounting amplifies future state value")
plt.xlabel("discount gamma"); plt.ylabel("V(center)")
plt.show()
```
▶ What you'll see: value rises as future occupancy of better states matters more.

*Why it's done this way:* discounting turns state control into a long-horizon strategic objective rather than a one-step reward calculation.

### 6. Minimax-Q learns backups from sampled experience

Minimax-Q is the tabular learning version of the zero-sum backup. It stores $Q(s,a,b)$ for joint actions, updates one sampled joint action at a time, and uses the value of the next state's matrix game as the bootstrapped target.

```python
Q_w = np.zeros((2, 2, 2))  # Q[state,row-action,col-action].
alpha_w = 0.25; gamma_q_w = 0.9
rng_w = np.random.default_rng(1)
errors_w = []
for t_w in range(250):
    s_w = int(rng_w.integers(0, 2)); a_w = int(rng_w.integers(0, 2)); b_w = int(rng_w.integers(0, 2))
    next_s_w = int(rng_w.choice(2, p=P_w[s_w, a_w, b_w]))
    next_v_w, _ = zero_sum_2x2_value_w(Q_w[next_s_w])
    target_w = R_w[s_w, a_w, b_w] + gamma_q_w * next_v_w
    old_w = Q_w[s_w, a_w, b_w]
    Q_w[s_w, a_w, b_w] = old_w + alpha_w * (target_w - old_w)
    errors_w.append(abs(target_w - old_w))
print("learned center Q:\n", np.round(Q_w[0], 3))
assert len(errors_w) == 250
```
▶ What you'll see: sampled temporal-difference updates gradually shape the stage-game matrices.

```python
plt.figure(figsize=(4.6, 3.0))
plt.plot(errors_w, color="crimson", alpha=0.8)
plt.title("6: minimax-Q TD errors")
plt.xlabel("sample update"); plt.ylabel("|target - old Q|")
plt.show()
```
▶ What you'll see: errors are noisy because samples are random, but the stored joint-action values become structured.

*Why it's done this way:* minimax-Q keeps the Bellman equilibrium idea but replaces full model knowledge with incremental sampled backups.

## 🛠️ Setup

```python
import numpy as np  # arrays, random sampling, linear algebra, and assertions.
import matplotlib.pyplot as plt  # visual checks for payoff matrices, values, policies, and learning curves.
np.random.seed(0)  # make examples reproducible.

def zero_sum_2x2_value(M):  # solve a tiny zero-sum matrix game by row-policy grid search.
    M = np.asarray(M, dtype=float)  # ensure numeric matrix arithmetic.
    grid = np.linspace(0.0, 1.0, 1001)  # probability that row chooses action 0.
    guarantees = np.empty_like(grid)  # row's guaranteed payoff against best column response.
    for k, p in enumerate(grid):  # test each row mixture.
        mix = np.array([p, 1.0 - p])  # convert scalar probability to two-action policy.
        guarantees[k] = np.min(mix @ M)  # column player chooses the smaller column payoff.
    idx = int(np.argmax(guarantees))  # row chooses the mixture with largest guarantee.
    return float(guarantees[idx]), np.array([grid[idx], 1.0 - grid[idx]])  # value and row policy.

def make_toy_game():  # construct the lesson's two-state zero-sum stochastic game.
    R = np.array([[[0.0, 2.0], [-1.0, 1.0]], [[0.4, 0.8], [0.2, 0.6]]])  # row rewards.
    P = np.zeros((2, 2, 2, 2))  # state,row action,column action,next state.
    P[0, 0, 0] = [0.8, 0.2]; P[0, 0, 1] = [0.2, 0.8]  # center transitions for push.
    P[0, 1, 0] = [0.6, 0.4]; P[0, 1, 1] = [0.4, 0.6]  # center transitions for wait.
    P[1, :, :, 1] = 1.0  # safe is absorbing.
    return R, P  # return reward and transition tensors.

def backup_values(R, P, V, gamma):  # perform one minimax Bellman backup for every state.
    new_V = np.zeros(R.shape[0])  # scalar value per state.
    policies = np.zeros((R.shape[0], R.shape[1]))  # row equilibrium policy per state.
    for s in range(R.shape[0]):  # loop over states.
        M = R[s] + gamma * np.tensordot(P[s], V, axes=([2], [0]))  # stage game plus continuation.
        new_V[s], policies[s] = zero_sum_2x2_value(M)  # solve the matrix game backup.
    return new_V, policies  # return values and row policies.

def show_heatmap(M, title, xlabels=("block", "yield"), ylabels=("push", "wait")):  # display a small matrix.
    plt.figure(figsize=(4, 3))  # compact notebook figure.
    plt.imshow(M, cmap="coolwarm", aspect="auto")  # color matrix entries.
    plt.colorbar(label="value")  # numeric color legend.
    plt.xticks(range(len(xlabels)), xlabels)  # label column actions.
    plt.yticks(range(len(ylabels)), ylabels)  # label row actions.
    plt.title(title)  # explain the matrix.
    plt.show()  # render the visualization.
```

#### B3. Compute a fixed-policy expected reward

**Goal.** Average a payoff matrix under two policies, because fixed policies reduce the game at a state to one expected immediate reward. We build it in 2 steps.

```python
M_b3 = np.array([[0.0, 2.0], [-1.0, 1.0]])  # center payoff matrix.
pi_row_b3 = np.array([0.7, 0.3])  # row player chooses push 70% of the time.
pi_col_b3 = np.array([0.4, 0.6])  # column player chooses block 40% of the time.
joint_b3 = pi_row_b3[:, None] * pi_col_b3[None, :]  # joint action probabilities from independent policies.
```

#### B4. Compute a fixed-policy transition row

**Goal.** Average transition distributions under joint policies, because Bellman values need a state-to-state transition matrix. We build it in 2 steps.

```python
R_b4, P_b4 = make_toy_game()  # load toy game tensors.
```

#### B8. Iterate until values stabilize

**Goal.** Repeat minimax Bellman backups, because convergence means the values are consistent with their own continuation values. We build it in 3 steps.

```python
R_b8, P_b8 = make_toy_game()  # load the toy game.
V_b8 = np.zeros(2)  # initialize values.
history_b8 = []  # store values for convergence plotting.
for it_b8 in range(60):  # run enough sweeps for this tiny discounted game.
    V_b8, policies_b8 = backup_values(R_b8, P_b8, V_b8, gamma=0.9)  # minimax Bellman sweep.
    history_b8.append(V_b8.copy())  # save values.
history_b8 = np.array(history_b8)  # convert to array for plotting.
print("final values:", np.round(V_b8, 3))  # inspect converged values.
assert np.max(np.abs(history_b8[-1] - history_b8[-2])) < 1e-3  # convergence check.
```
▶ What you'll see: values settle after repeated backups.
