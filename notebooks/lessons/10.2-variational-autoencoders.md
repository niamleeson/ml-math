# 10.2 — Variational Autoencoders

Variational autoencoders (VAEs) turn the autoencoder idea into a generative model: the encoder returns a distribution over latent codes, the decoder reconstructs from sampled latent points, and the loss balances reconstruction quality against staying close to a simple prior. In this lesson, you will build the Gaussian latent, reparameterization trick, KL penalty, ELBO, and a tiny trainable VAE from first principles with only NumPy and Matplotlib.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build variational autoencoders one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including ELBO, reparameterization, and KL divergence, is derived and shown. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, random numbers, and hand-written gradients.
```

### 1. From point codes to a latent distribution

A plain autoencoder maps an input `x` to one code `z`, so it can reconstruct but has no principled way to sample new objects. A VAE changes the encoder output from a point into a Gaussian distribution $q_\phi(z\mid x)=\mathcal{N}(\mu,\sigma^2)$: each input gets a mean `mu` and log-variance `logvar`. The mean says where the code should live; the variance says how much uncertainty or spread is allowed around that code.

```python
x_w = np.array([[1.0, 0.0], [0.9, 0.1], [-1.0, 0.0], [-0.9, -0.1]])  # two tiny clusters in 2-D data space.
labels_w = np.array([0, 0, 1, 1])  # cluster labels only for coloring plots, not for VAE training.
print("data shape:", x_w.shape)  # four points with two observed coordinates.
print("first two points:\n", x_w[:2])  # inspect one cluster.
```
▶ What you'll see: four simple data points arranged as two opposite clusters; the VAE will learn a continuous latent description.

```python
mu_w = np.array([0.5])  # one encoder mean for a single example.
logvar_w = np.array([-0.7])  # encoder predicts log(sigma^2), not sigma, for numerical stability.
sigma_w = np.exp(0.5 * logvar_w)  # standard deviation = exp(1/2 log variance).
print("mu:", mu_w, "logvar:", logvar_w, "sigma:", np.round(sigma_w, 4))
assert round(float(sigma_w[0]), 4) == 0.7047  # lesson number from the source content.
```
▶ What you'll see: `logvar=-0.7` corresponds to a standard deviation of about 0.7047.

```python
samples_w = mu_w + sigma_w * np.random.randn(2000, 1)  # draw many candidate latent codes for the same input.
plt.figure(figsize=(4.4, 3))
plt.hist(samples_w[:, 0], bins=35, color="steelblue", alpha=0.85)
plt.axvline(mu_w[0], color="black", linestyle="--", label="mu")
plt.title("1: one input maps to a Gaussian over z")
plt.xlabel("latent coordinate z")
plt.ylabel("count")
plt.legend()
plt.show()
```
▶ What you'll see: a bell-shaped cloud centered at `mu`, not one deterministic code.

*Why it's done this way:* the distribution is the generative upgrade. If every input owns only a point code, random latent samples are likely to land in holes the decoder never saw. Giving each input a Gaussian patch makes nearby latent points meaningful and gives the loss a way to shape the whole latent space, not only isolated codes.

### 2. Reparameterization: sampling without blocking learning

The obstacle is that training needs gradients through the sampled latent code. Instead of sampling `z` as an opaque draw from $\mathcal{N}(\mu,\sigma^2)$, the VAE samples noise $\epsilon\sim\mathcal{N}(0,1)$ and writes

$$z=\mu+\sigma\epsilon.$$

Now the randomness lives in `epsilon`, while `mu` and `sigma` appear in ordinary differentiable arithmetic.

```python
epsilon_w = np.array([1.2])  # fixed standard-normal draw for an auditable example.
z_w = mu_w + sigma_w * epsilon_w  # reparameterized sample.
print("epsilon:", epsilon_w, "z:", np.round(z_w, 3))
assert round(float(z_w[0]), 3) == 1.346  # 0.5 + 0.7047 * 1.2.
```
▶ What you'll see: the source-content worked sample `z=1.346`.

```python
mu_grid_w = np.linspace(-1.0, 1.0, 9)  # sweep possible means with the same epsilon and sigma.
z_grid_w = mu_grid_w + sigma_w[0] * epsilon_w[0]  # z changes linearly with mu.
print("z values as mu changes:", np.round(z_grid_w, 3))
plt.figure(figsize=(4.4, 3))
plt.plot(mu_grid_w, z_grid_w, marker="o", color="purple")
plt.xlabel("mu")
plt.ylabel("z = mu + sigma epsilon")
plt.title("2: the sample is differentiable in mu")
plt.show()
```
▶ What you'll see: a straight line with slope 1, so changing the encoder mean predictably moves the sampled code.

```python
logvar_grid_w = np.linspace(-2.0, 1.0, 60)  # vary uncertainty while holding mu and epsilon fixed.
z_from_logvar_w = mu_w[0] + np.exp(0.5 * logvar_grid_w) * epsilon_w[0]
plt.figure(figsize=(4.4, 3))
plt.plot(logvar_grid_w, z_from_logvar_w, color="darkorange")
plt.xlabel("log variance")
plt.ylabel("sampled z")
plt.title("2: logvar smoothly controls sample spread")
plt.show()
```
▶ What you'll see: increasing log-variance smoothly moves `z` farther from `mu` for the same noise draw.

*Why it's done this way:* sampling is not removed; it is rewritten. The distribution of `mu + sigma * epsilon` is exactly $\mathcal{N}(\mu,\sigma^2)$, but the trainable quantities are outside the random draw. That lowers gradient variance because the optimizer can see how changing `mu` or `logvar` would have changed the sampled reconstruction.

### 3. Decoder and reconstruction likelihood

The decoder maps a latent code back to data space. For continuous toy data, a common reconstruction term is squared error, which corresponds to a Gaussian likelihood with fixed variance. Maximizing $\log p_\theta(x\mid z)$ is therefore equivalent, up to constants, to minimizing reconstruction error.

```python
W_dec_w = np.array([[1.2, -0.4]])  # one latent dimension decoded into two observed coordinates.
b_dec_w = np.array([0.05, -0.05])  # decoder bias shifts both output coordinates.
z_one_w = np.array([[1.0], [-1.0], [0.0]])  # three latent codes to decode.
x_hat_w = z_one_w @ W_dec_w + b_dec_w  # linear decoder: zW + b.
print("decoded points:\n", np.round(x_hat_w, 3))
```
▶ What you'll see: positive and negative latent codes decode to opposite-looking data points.

```python
x_target_w = np.array([1.0, 0.0])  # one observed data point.
x_recon_w = x_hat_w[0]  # reconstruction from z=1.
recon_sse_w = float(np.sum((x_target_w - x_recon_w) ** 2))  # squared reconstruction error.
print("target:", x_target_w, "reconstruction:", np.round(x_recon_w, 3))
print("reconstruction SSE:", round(recon_sse_w, 4))
assert round(recon_sse_w, 4) == 0.265
```
▶ What you'll see: the decoder output is close but not exact, producing a small reconstruction penalty.

```python
plt.figure(figsize=(4, 3.4))
plt.scatter(x_w[:, 0], x_w[:, 1], c=labels_w, cmap="coolwarm", s=80, label="data")
plt.scatter(x_hat_w[:, 0], x_hat_w[:, 1], marker="x", s=110, color="black", label="decoded z")
for k_w, zval_w in enumerate(z_one_w[:, 0]):
    plt.text(x_hat_w[k_w, 0] + 0.02, x_hat_w[k_w, 1], f"z={zval_w:g}")
plt.axhline(0, color="gray", linewidth=0.5)
plt.axvline(0, color="gray", linewidth=0.5)
plt.title("3: decoder turns latent z into data")
plt.legend()
plt.show()
```
▶ What you'll see: decoded samples trace the data direction; the decoder is the generator once training is done.

*Why it's done this way:* reconstruction pressure teaches the latent code to preserve information about `x`. The Gaussian-likelihood view matters because the VAE objective is probabilistic: squared error is not just a convenient distance; it is the negative log-likelihood for a simple continuous observation model.

### 4. KL divergence to the standard normal prior

If reconstruction were the only term, the encoder could scatter codes anywhere and generation would fail. The prior $p(z)=\mathcal{N}(0,1)$ gives the model a sampling distribution, and the KL penalty measures how far $q_\phi(z\mid x)$ drifts from that prior. For a diagonal Gaussian, one latent dimension contributes

$$D_{KL}\big(\mathcal{N}(\mu,\sigma^2)\Vert\mathcal{N}(0,1)\big)=\frac12(\mu^2+\sigma^2-1-\log\sigma^2).$$

```python
kl_w = 0.5 * (mu_w ** 2 + np.exp(logvar_w) - 1.0 - logvar_w)  # closed-form Gaussian KL.
print("KL:", np.round(kl_w, 4))
assert round(float(kl_w[0]), 4) == 0.2233  # source-content worked value.
```
▶ What you'll see: the example distribution is close to the prior but pays a nonzero KL cost.

```python
mus_grid_w = np.linspace(-2, 2, 81)  # vary mean while log variance is zero.
kl_mean_w = 0.5 * (mus_grid_w ** 2 + 1.0 - 1.0 - 0.0)  # KL = 0.5 mu^2 when sigma=1.
logvars_grid_w = np.linspace(-3, 2, 81)  # vary variance while mean is zero.
kl_var_w = 0.5 * (0.0 + np.exp(logvars_grid_w) - 1.0 - logvars_grid_w)
plt.figure(figsize=(6, 2.8))
plt.subplot(1, 2, 1); plt.plot(mus_grid_w, kl_mean_w, color="teal"); plt.title("mean cost"); plt.xlabel("mu"); plt.ylabel("KL")
plt.subplot(1, 2, 2); plt.plot(logvars_grid_w, kl_var_w, color="crimson"); plt.title("variance cost"); plt.xlabel("logvar")
plt.tight_layout(); plt.show()
```
▶ What you'll see: KL is smallest at `mu=0` and `logvar=0`, exactly the standard normal prior.

*Why it's done this way:* the prior is the address system for generation. KL charges the encoder for moving means far from zero or making variances far from one, which deliberately damages perfect reconstruction so latent space stays smooth and sampleable.

### 5. ELBO: the reconstruction-versus-KL trade

The evidence lower bound is the VAE's scalar training target:

$$\text{ELBO}=\mathbb{E}_{q(z\mid x)}[\log p(x\mid z)]-D_{KL}(q\Vert p).$$

In minimization form, we usually optimize `loss = reconstruction_loss + KL`. Lower loss means better reconstructions and/or a latent posterior closer to the prior. The key is the tradeoff: a model can improve one term while hurting the other.

```python
recon_loss_w = 0.42  # example negative log-likelihood / squared-error-style reconstruction term.
kl_term_w = float(kl_w[0])  # KL from the audited Gaussian above.
loss_w = recon_loss_w + kl_term_w  # negative ELBO up to constants.
elbo_w = -recon_loss_w - kl_term_w  # ELBO if reconstruction is stored as a positive loss.
print("recon loss:", round(recon_loss_w, 4), "KL:", round(kl_term_w, 4))
print("negative ELBO loss:", round(loss_w, 4), "ELBO:", round(elbo_w, 4))
assert round(loss_w, 4) == 0.6433
```
▶ What you'll see: the objective combines a reconstruction price and a latent-distribution price.

```python
kl_sweep_w = np.linspace(0, 1.2, 100)  # possible KL values.
recon_fixed_w = 0.42 * np.ones_like(kl_sweep_w)  # hold reconstruction fixed to isolate the trade.
loss_beta1_w = recon_fixed_w + kl_sweep_w  # ordinary VAE loss.
loss_beta4_w = recon_fixed_w + 4.0 * kl_sweep_w  # stronger KL pressure, previewing beta-VAE.
plt.figure(figsize=(4.6, 3))
plt.plot(kl_sweep_w, loss_beta1_w, label="beta=1")
plt.plot(kl_sweep_w, loss_beta4_w, label="beta=4")
plt.xlabel("KL")
plt.ylabel("recon + beta·KL")
plt.title("5: KL has an explicit price")
plt.legend()
plt.show()
```
▶ What you'll see: a larger KL weight makes the same latent drift much more expensive.

*Why it's done this way:* ELBO is a lower bound because it replaces the hard marginal likelihood $\log p(x)$ with a tractable expectation under the encoder minus an exact KL. The reconstruction term asks “can `z` explain this `x`?” while KL asks “did the encoder choose a code distribution we can sample from later?”

### 6. Train a tiny linear VAE from scratch

Now we combine the pieces into a minimal trainable VAE. To keep gradients inspectable, the encoder is linear and produces `mu` and `logvar`; the decoder is linear; the loss is mean squared reconstruction error plus the closed-form KL. This is not a production neural network, but it is the exact VAE logic in small NumPy arrays.

```python
rng_w = np.random.default_rng(0)  # local reproducibility for this training run.
n_w = 120  # number of synthetic points.
t_w = rng_w.choice([-1.0, 1.0], size=n_w)  # hidden two-mode factor.
X_w = np.column_stack([t_w + 0.12 * rng_w.normal(size=n_w), 0.45 * t_w + 0.12 * rng_w.normal(size=n_w)])  # two correlated features.
X_w = X_w - X_w.mean(axis=0, keepdims=True)  # center data for a simple linear decoder.
print("X mean:", np.round(X_w.mean(axis=0), 3), "X shape:", X_w.shape)
```
▶ What you'll see: a centered two-dimensional dataset with one dominant latent direction.

```python
Wm_w = 0.1 * rng_w.normal(size=(2, 1)); bm_w = np.zeros(1)  # encoder mean parameters.
Wl_w = 0.1 * rng_w.normal(size=(2, 1)); bl_w = np.zeros(1)  # encoder logvar parameters.
Wd_w = 0.1 * rng_w.normal(size=(1, 2)); bd_w = np.zeros(2)  # decoder parameters.
print("parameter shapes:", Wm_w.shape, Wl_w.shape, Wd_w.shape)
```
▶ What you'll see: the encoder maps 2-D data to one latent dimension, then the decoder maps back to 2-D.

```python
losses_w = []  # store total VAE loss over training.
for epoch_w in range(350):
    mu_train_w = X_w @ Wm_w + bm_w  # encoder mean.
    logvar_train_w = np.clip(X_w @ Wl_w + bl_w, -4.0, 3.0)  # encoder log variance with clipping for a stable toy demo.
    eps_train_w = rng_w.normal(size=mu_train_w.shape)  # reparameterization noise.
    sigma_train_w = np.exp(0.5 * logvar_train_w)  # standard deviation.
    z_train_w = mu_train_w + sigma_train_w * eps_train_w  # sampled latent code.
    Xhat_w = z_train_w @ Wd_w + bd_w  # decoder reconstruction.
    diff_w = Xhat_w - X_w  # reconstruction residuals.
    recon_train_w = float(np.mean(np.sum(diff_w ** 2, axis=1)))  # average squared reconstruction.
    kl_train_w = float(np.mean(0.5 * np.sum(mu_train_w ** 2 + np.exp(logvar_train_w) - 1.0 - logvar_train_w, axis=1)))  # average KL.
    losses_w.append(recon_train_w + 0.05 * kl_train_w)  # small KL weight keeps the tiny linear demo from collapsing.
    dXhat_w = (2.0 / n_w) * diff_w  # gradient of mean squared reconstruction.
    dWd_w = z_train_w.T @ dXhat_w; dbd_w = dXhat_w.sum(axis=0)  # decoder gradients.
    dz_w = dXhat_w @ Wd_w.T  # gradient back to z.
    dmu_w = dz_w + 0.05 * mu_train_w / n_w  # reparameterized path plus KL mean gradient.
    dlogvar_w = dz_w * eps_train_w * 0.5 * sigma_train_w + 0.05 * 0.5 * (np.exp(logvar_train_w) - 1.0) / n_w  # path plus KL variance gradient.
    Wd_w -= 0.04 * dWd_w; bd_w -= 0.04 * dbd_w  # update decoder.
    Wm_w -= 0.04 * (X_w.T @ dmu_w); bm_w -= 0.04 * dmu_w.sum(axis=0)  # update mean encoder.
    Wl_w -= 0.04 * (X_w.T @ dlogvar_w); bl_w -= 0.04 * dlogvar_w.sum(axis=0)  # update logvar encoder.
print("loss start -> end:", round(losses_w[0], 3), "->", round(losses_w[-1], 3))
assert losses_w[-1] < losses_w[0]
```
▶ What you'll see: the total objective decreases, confirming that reconstruction and KL gradients are wired correctly.

```python
plt.figure(figsize=(4.6, 3))
plt.plot(losses_w, color="purple")
plt.xlabel("epoch")
plt.ylabel("recon + 0.05 KL")
plt.title("6: tiny VAE training curve")
plt.show()
```
▶ What you'll see: a noisy but downward learning curve from stochastic latent samples.

*Why it's done this way:* every update follows from the ELBO ingredients. Reconstruction gradients train the decoder and push encoder samples toward useful codes; KL gradients pull means toward zero and variances toward one. The reparameterized `z` is what lets the reconstruction gradient reach encoder parameters at all.

### 7. Sampling and reading the latent space

After training, generation is simple: sample `z` from the prior $\mathcal{N}(0,1)$ and decode it. The latent plot should be smoother than a plain autoencoder's scattered point codes because KL kept encoded examples near a shared standard-normal coordinate system.

```python
mu_final_w = X_w @ Wm_w + bm_w  # encoder means after training.
logvar_final_w = np.clip(X_w @ Wl_w + bl_w, -4.0, 3.0)  # encoder log variances after training.
z_prior_w = np.linspace(-2.5, 2.5, 80)[:, None]  # ordered prior samples for visualization.
X_gen_w = z_prior_w @ Wd_w + bd_w  # decode prior samples into data space.
print("encoded mu range:", round(float(mu_final_w.min()), 3), "to", round(float(mu_final_w.max()), 3))
print("generated sample shape:", X_gen_w.shape)
```
▶ What you'll see: encoded means occupy a finite interval, and prior samples decode into synthetic 2-D points.

```python
plt.figure(figsize=(5, 3.5))
plt.scatter(mu_final_w[:, 0], np.zeros_like(mu_final_w[:, 0]), c=(t_w > 0), cmap="coolwarm", alpha=0.8, label="encoded means")
plt.hist(np.random.default_rng(1).normal(size=400), bins=30, density=True, alpha=0.25, color="gray", label="N(0,1) prior")
plt.yticks([])
plt.xlabel("latent z")
plt.title("7: encoded means live inside the prior's address system")
plt.legend()
plt.show()
```
▶ What you'll see: the two data modes separate along `z` but remain near the standard-normal prior support.

```python
plt.figure(figsize=(4.4, 3.4))
plt.scatter(X_w[:, 0], X_w[:, 1], c=(t_w > 0), cmap="coolwarm", s=28, alpha=0.65, label="training data")
plt.plot(X_gen_w[:, 0], X_gen_w[:, 1], color="black", linewidth=2, label="decoded prior path")
plt.title("7: latent-space generation")
plt.xlabel("x0")
plt.ylabel("x1")
plt.legend()
plt.show()
```
▶ What you'll see: decoding a smooth sweep of latent values traces the data manifold rather than jumping between isolated memorized examples.

*Why it's done this way:* generation uses the prior, not the training set. The KL term made that prior meaningful by forcing encoder posteriors to overlap it; the decoder then turns ordinary Gaussian samples into plausible objects.

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, random numbers, hand-written VAE math, and assertions.
import matplotlib.pyplot as plt # load Matplotlib for histograms, curves, scatters, and latent-space plots.
np.random.seed(0) # make all stochastic examples reproducible across notebook runs.

def relu(x): # define the one nonlinearity used in a few toy decoder examples.
    return np.maximum(0.0, x) # keep positive values and clamp negative values to zero.

def gaussian_kl(mu, logvar): # compute KL(q(z|x) || N(0, I)) for diagonal Gaussian latents.
    return 0.5 * np.sum(mu ** 2 + np.exp(logvar) - 1.0 - logvar, axis=-1) # closed-form diagonal Gaussian KL.

def reparameterize(mu, logvar, eps): # sample z while keeping mu and logvar in differentiable arithmetic.
    return mu + np.exp(0.5 * logvar) * eps # convert log variance to standard deviation and inject standard-normal noise.

def decode_linear(z, W, b): # decode latent vectors with a small linear decoder.
    return z @ W + b # matrix multiply latent coordinates into data coordinates.

def show_points(X, title): # visualize 2-D toy data or reconstructions.
    plt.figure(figsize=(4, 3)) # create a compact notebook figure.
    plt.scatter(X[:, 0], X[:, 1], s=70, color="teal") # draw each point in data space.
    plt.axhline(0, color="gray", linewidth=0.5) # add horizontal reference line.
    plt.axvline(0, color="gray", linewidth=0.5) # add vertical reference line.
    plt.title(title) # label the current example.
    plt.xlabel("x0") # label first data coordinate.
    plt.ylabel("x1") # label second data coordinate.
    plt.show() # display the figure.
```

### Basic 4 — Decode one latent code

**Goal.** Map a latent code back to observed coordinates, because the decoder is the generator part of a VAE. We build it in 2 steps.

```python
z_b4 = np.array([[1.346]]) # use the audited latent sample.
W_dec_b4 = np.array([[0.8, -0.3]]) # define a one-latent-to-two-output decoder matrix.
b_dec_b4 = np.array([0.1, 0.2]) # define decoder bias.
print("z shape:", z_b4.shape, "W shape:", W_dec_b4.shape) # inspect matrix multiplication shapes.
```
▶ What you'll see: one latent coordinate will produce two reconstructed coordinates.


### Easy 4 — Train a tiny linear VAE

**Goal.** Optimize encoder and decoder parameters together, because the full VAE learns where to place distributions and how to decode samples. We build it in 5 steps.

```python
rng_e4 = np.random.default_rng(4) # create a reproducible generator.
n_e4 = 100 # choose dataset size.
s_e4 = rng_e4.choice([-1.0, 1.0], size=n_e4) # hidden sign factor for two modes.
X_e4 = np.column_stack([s_e4 + 0.1 * rng_e4.normal(size=n_e4), 0.5 * s_e4 + 0.1 * rng_e4.normal(size=n_e4)]) # synthesize two-feature data.

print("data shape:", X_e4.shape) # inspect dataset shape.
```
▶ What you'll see: a centered 100×2 dataset.

```python
Wm_e4 = 0.1 * rng_e4.normal(size=(2, 1)); bm_e4 = np.zeros(1) # initialize mean encoder.
Wl_e4 = 0.1 * rng_e4.normal(size=(2, 1)); bl_e4 = np.zeros(1) # initialize logvar encoder.
Wd_e4 = 0.1 * rng_e4.normal(size=(1, 2)); bd_e4 = np.zeros(2) # initialize decoder.
losses_e4 = [] # store training losses.
print("initialized linear VAE") # confirm parameters are ready.
```

```python

    mu_e4 = X_e4 @ Wm_e4 + bm_e4 # encoder mean.
    logvar_e4 = np.clip(X_e4 @ Wl_e4 + bl_e4, -4.0, 3.0) # encoder log variance.
    eps_e4 = rng_e4.normal(size=mu_e4.shape) # stochastic noise.
    sigma_e4 = np.exp(0.5 * logvar_e4) # posterior standard deviation.
    z_e4 = mu_e4 + sigma_e4 * eps_e4 # reparameterized sample.
    Xhat_e4 = z_e4 @ Wd_e4 + bd_e4 # decoder output.
    diff_e4 = Xhat_e4 - X_e4 # reconstruction residual.
    recon_e4 = float(np.mean(np.sum(diff_e4 ** 2, axis=1))) # average reconstruction loss.
    kl_e4 = float(np.mean(gaussian_kl(mu_e4, logvar_e4))) # average KL.
    beta_e4 = 0.05 # use gentle KL pressure for this tiny linear model.
    losses_e4.append(recon_e4 + beta_e4 * kl_e4) # store negative ELBO variant.
    dXhat_e4 = (2.0 / n_e4) * diff_e4 # gradient wrt reconstruction.
    dWd_e4 = z_e4.T @ dXhat_e4; dbd_e4 = dXhat_e4.sum(axis=0) # decoder gradients.
    dz_e4 = dXhat_e4 @ Wd_e4.T # gradient through decoder to latent sample.
    dmu_e4 = dz_e4 + beta_e4 * mu_e4 / n_e4 # gradient wrt mean.
    dlog_e4 = dz_e4 * eps_e4 * 0.5 * sigma_e4 + beta_e4 * 0.5 * (np.exp(logvar_e4) - 1.0) / n_e4 # gradient wrt logvar.
    Wd_e4 -= 0.04 * dWd_e4; bd_e4 -= 0.04 * dbd_e4 # update decoder.
    Wm_e4 -= 0.04 * (X_e4.T @ dmu_e4); bm_e4 -= 0.04 * dmu_e4.sum(axis=0) # update mean encoder.
    Wl_e4 -= 0.04 * (X_e4.T @ dlog_e4); bl_e4 -= 0.04 * dlog_e4.sum(axis=0) # update logvar encoder.
print("loss start -> end:", round(losses_e4[0], 3), "->", round(losses_e4[-1], 3)) # inspect learning.
assert losses_e4[-1] < losses_e4[0] # verify the objective decreased.
```

### Advanced 1 — Sweep beta in the ELBO

**Goal.** Compare reconstruction and KL as beta changes, because increasing the KL price can smooth the latent space but reduce reconstruction detail. We build it in 5 steps.

```python

n_a1 = 90 # choose a toy dataset size.

betas_a1 = np.array([0.0, 0.02, 0.1, 0.5]) # define KL weights to compare.
print("beta grid:", betas_a1) # inspect sweep values.
```
▶ What you'll see: beta values range from no KL pressure to strong KL pressure.

```python
recons_a1 = [] # store final reconstruction losses.
kls_a1 = [] # store final KL values.
for beta_a1 in betas_a1: # train one tiny VAE per beta.
    rng_model_a1 = np.random.default_rng(12) # reset initialization for fair comparison.
    Wm_a1 = 0.1 * rng_model_a1.normal(size=(2, 1)); bm_a1 = np.zeros(1) # mean encoder.
    Wl_a1 = 0.1 * rng_model_a1.normal(size=(2, 1)); bl_a1 = np.zeros(1) # logvar encoder.
    Wd_a1 = 0.1 * rng_model_a1.normal(size=(1, 2)); bd_a1 = np.zeros(2) # decoder.
    for step_a1 in range(220): # run full-batch stochastic-gradient training.
        mu_a1 = X_a1 @ Wm_a1 + bm_a1 # means.
        logvar_a1 = np.clip(X_a1 @ Wl_a1 + bl_a1, -4, 3) # log variances.
        eps_a1 = rng_model_a1.normal(size=mu_a1.shape) # reparameterization noise.
        sig_a1 = np.exp(0.5 * logvar_a1) # standard deviations.
        z_a1 = mu_a1 + sig_a1 * eps_a1 # latent samples.
        Xhat_a1 = z_a1 @ Wd_a1 + bd_a1 # reconstructions.
        diff_a1 = Xhat_a1 - X_a1 # residuals.
        dXhat_a1 = (2.0 / n_a1) * diff_a1 # reconstruction gradient.
        dWd_a1 = z_a1.T @ dXhat_a1; dbd_a1 = dXhat_a1.sum(axis=0) # decoder gradients.
        dz_a1 = dXhat_a1 @ Wd_a1.T # backprop to z.
        dmu_a1 = dz_a1 + beta_a1 * mu_a1 / n_a1 # mean gradient with KL.
        dlog_a1 = dz_a1 * eps_a1 * 0.5 * sig_a1 + beta_a1 * 0.5 * (np.exp(logvar_a1) - 1.0) / n_a1 # logvar gradient with KL.
        Wd_a1 -= 0.04 * dWd_a1; bd_a1 -= 0.04 * dbd_a1 # update decoder.
        Wm_a1 -= 0.04 * (X_a1.T @ dmu_a1); bm_a1 -= 0.04 * dmu_a1.sum(axis=0) # update mean encoder.
        Wl_a1 -= 0.04 * (X_a1.T @ dlog_a1); bl_a1 -= 0.04 * dlog_a1.sum(axis=0) # update variance encoder.
    mu_a1 = X_a1 @ Wm_a1 + bm_a1 # final means.
    logvar_a1 = np.clip(X_a1 @ Wl_a1 + bl_a1, -4, 3) # final log variances.
    Xhat_mean_a1 = mu_a1 @ Wd_a1 + bd_a1 # deterministic mean-path reconstruction.
    recons_a1.append(float(np.mean(np.sum((Xhat_mean_a1 - X_a1) ** 2, axis=1)))) # store final recon.
    kls_a1.append(float(np.mean(gaussian_kl(mu_a1, logvar_a1)))) # store final KL.
print("recon by beta:", np.round(recons_a1, 3)) # inspect reconstruction costs.
print("KL by beta:", np.round(kls_a1, 3)) # inspect KL costs.
```

```python

print("strongest beta KL:", round(kls_a1[-1], 3)) # inspect the highest-pressure model.
```
