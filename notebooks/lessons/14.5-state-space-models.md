# 14.5 — State-Space Models

State-space models describe a noisy time series by separating the hidden thing we care about — a level, trend, or position — from the observations we actually see. In this lesson, you will build local-level and local-trend Kalman filters and smoothers from first principles, inspect the uncertainty terms that control every update, and see why the model is often smoother than raw data without ignoring real drift.

Run each cell in order and read the printed intermediate values — every piece of math, including the Kalman gain and smoother recursion, is derived and shown. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, linear algebra, and reproducible simulation.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
```

### 1. Hidden state versus noisy observation

A state-space model starts by admitting that the observed series is not the truth. The hidden state $x_t$ is the evolving quantity we would like to know, while the observation $y_t$ is a noisy measurement of it. In the simplest **local-level** model, the level drifts by small process noise and each measurement adds observation noise:

$$x_t=x_{t-1}+w_t,\qquad y_t=x_t+v_t.$$

The two variances have different jobs. Process variance $Q$ says how much the true level can move from one step to the next. Observation variance $R$ says how noisy the measurement device is.

```python
t_w = np.arange(40)  # time index for the toy series.
true_level_w = 10 + np.cumsum(np.random.normal(0, 0.18, size=len(t_w)))  # hidden random-walk level.
y_w = true_level_w + np.random.normal(0, 0.7, size=len(t_w))  # noisy observations around the hidden level.
print("first hidden states:", np.round(true_level_w[:5], 3))  # inspect the truth we normally do not see.
print("first observations:", np.round(y_w[:5], 3))  # inspect the noisy measurements.
```
▶ What you'll see: observations jump around the hidden level because measurement noise is larger than the level's step-to-step movement.

```python
plt.figure(figsize=(6, 3))  # create a compact time-series plot.
plt.plot(t_w, true_level_w, label="hidden state x", linewidth=2)  # draw the smooth latent level.
plt.scatter(t_w, y_w, label="observed y", s=18, color="darkorange")  # draw noisy measurements.
plt.title("1: hidden local level and noisy observations")  # label the story.
plt.xlabel("time")  # label horizontal axis.
plt.ylabel("value")  # label vertical axis.
plt.legend()  # show line meanings.
plt.show()  # display the figure.
```
▶ What you'll see: the orange measurements are visibly noisier than the hidden blue level.

*Why it's done this way:* the model separates **state evolution** from **measurement** because forecasting and denoising need different uncertainty assumptions. If we force one equation to explain both drift and measurement error, we cannot decide whether a jump is a real level change or just a bad reading.

### 2. The scalar Kalman update: variance decides trust

The Kalman filter alternates prediction and correction. For a scalar local-level model, the prediction is $m^-_t=m_{t-1}$ and $P^-_t=P_{t-1}+Q$. After observing $y_t$, the innovation is $e_t=y_t-m^-_t$, the innovation variance is $S_t=P^-_t+R$, and the Kalman gain is

$$K_t=\frac{P^-_t}{P^-_t+R}.$$

The gain is a trust ratio: high model uncertainty $P^-_t$ makes us move toward the observation; high measurement noise $R$ makes us resist it.

```python
m0_w, P0_w = 10.0, 4.0  # prior mean and variance before seeing the new measurement.
Q_scalar_w, R_scalar_w, obs_w = 1.0, 3.0, 13.0  # process variance, observation variance, and measurement.
m_pred_w = m0_w  # local-level prediction keeps the previous mean.
P_pred_w = P0_w + Q_scalar_w  # prediction variance grows by process uncertainty.
print("predicted mean:", m_pred_w, "predicted variance:", P_pred_w)  # inspect prior belief.
assert round(P_pred_w, 3) == 5.000  # verify the cited variance.
```
▶ What you'll see: uncertainty rises from 4 to 5 before the observation is used.

```python
innovation_w = obs_w - m_pred_w  # measurement surprise relative to the predicted observation.
S_w = P_pred_w + R_scalar_w  # total uncertainty in the innovation.
K_w = P_pred_w / S_w  # scalar Kalman gain.
print("innovation:", innovation_w, "S:", S_w, "K:", round(K_w, 3))  # inspect the update pieces.
assert round(K_w, 3) == 0.625  # verify the lesson gain.
```
▶ What you'll see: the observation is 3 units above the prediction, but the gain says to take only 62.5% of that gap.

```python
m_upd_w = m_pred_w + K_w * innovation_w  # corrected mean after seeing y.
P_upd_w = (1 - K_w) * P_pred_w  # corrected variance after conditioning on y.
print("updated mean:", round(m_upd_w, 3), "updated variance:", round(P_upd_w, 3))  # inspect posterior.
assert round(m_upd_w, 3) == 11.875  # verify the worked mean.
assert round(P_upd_w, 3) == 1.875  # verify the worked variance.
```
▶ What you'll see: the estimate moves from 10 to 11.875, not all the way to 13, and the variance shrinks.

```python
plt.figure(figsize=(4.6, 3))  # create a before-after chart.
plt.bar(["prior", "observation", "updated"], [m_pred_w, obs_w, m_upd_w], color=["gray", "orange", "seagreen"])  # compare means.
plt.title("2: Kalman update moves partway toward y")  # label the update.
plt.ylabel("value")  # label scale.
plt.show()  # display the chart.
```
▶ What you'll see: the updated estimate lands between the prior and the observation.

*Why it's done this way:* Gaussian conditioning says the posterior mean is a variance-weighted compromise. The observation does not get a fixed learning rate; it gets a **data-dependent** learning rate $K_t$ determined by the relative uncertainty of model and measurement.

### 3. Filtering a local-level time series

Filtering applies that scalar update at every time step. Each step first forecasts the next hidden level and uncertainty, then corrects with the new observation. The innovation sequence $e_t$ is especially useful: it is the one-step-ahead surprise after accounting for the model's current belief.

```python
def kalman_local_level_w(y, Q, R, m0, P0):  # implement scalar local-level filtering from scratch.
    n = len(y)  # number of observations.
    m_pred = np.zeros(n); P_pred = np.zeros(n)  # predicted means and variances.
    m_filt = np.zeros(n); P_filt = np.zeros(n)  # filtered means and variances.
    innov = np.zeros(n); gain = np.zeros(n)  # surprises and gains.
    m_prev, P_prev = m0, P0  # initialize prior belief.
    for i in range(n):  # process observations in chronological order.
        m_pred[i] = m_prev  # random-walk level prediction.
        P_pred[i] = P_prev + Q  # process noise increases uncertainty.
        innov[i] = y[i] - m_pred[i]  # one-step surprise.
        S = P_pred[i] + R  # observation-prediction variance.
        gain[i] = P_pred[i] / S  # scalar Kalman gain.
        m_filt[i] = m_pred[i] + gain[i] * innov[i]  # posterior mean.
        P_filt[i] = (1 - gain[i]) * P_pred[i]  # posterior variance.
        m_prev, P_prev = m_filt[i], P_filt[i]  # carry posterior forward.
    return m_pred, P_pred, m_filt, P_filt, innov, gain  # expose internals for inspection.

m_pred_w, P_pred_w, m_filt_w, P_filt_w, innov_w, gain_w = kalman_local_level_w(y_w, 0.03, 0.49, y_w[0], 1.0)  # filter the synthetic series.
print("first gains:", np.round(gain_w[:5], 3))  # inspect early trust in measurements.
print("last gain:", round(gain_w[-1], 3))  # inspect steady-state-like trust.
```
▶ What you'll see: the gain starts high and then settles as the filter learns a stable uncertainty balance.

```python
raw_mse_w = float(np.mean((y_w - true_level_w) ** 2))  # error from using observations as truth.
filt_mse_w = float(np.mean((m_filt_w - true_level_w) ** 2))  # error from the filtered state.
print("raw MSE:", round(raw_mse_w, 3), "filtered MSE:", round(filt_mse_w, 3))  # compare denoising.
assert filt_mse_w < raw_mse_w  # the filter should beat raw noisy observations on this seeded example.
```
▶ What you'll see: the filtered state has lower MSE than the raw observations.

```python
plt.figure(figsize=(6, 3))  # create a filtering plot.
plt.plot(t_w, true_level_w, label="hidden truth", linewidth=2)  # draw latent state.
plt.scatter(t_w, y_w, label="observed", s=16, color="orange", alpha=0.75)  # draw noisy y.
plt.plot(t_w, m_filt_w, label="filtered mean", color="seagreen", linewidth=2)  # draw filter estimate.
plt.title("3: local-level Kalman filter")  # title the plot.
plt.xlabel("time")  # label time.
plt.ylabel("value")  # label value.
plt.legend()  # show labels.
plt.show()  # display figure.
```
▶ What you'll see: the green filtered line follows the hidden level while ignoring much of the observation jitter.

*Why it's done this way:* filtering is causal: at time $t$ it only uses $y_0,\ldots,y_t$. The $Q$ term prevents the estimate from freezing, while the $R$ term prevents every noisy measurement from becoming the new state.

### 4. Local-trend models use matrices to move level and slope

A local-level model can follow drift, but it does not explicitly store velocity. A **local-trend** model uses a two-dimensional state $x_t=[\ell_t, b_t]^\top$ containing level and slope. Its transition matrix is

$$A=\begin{bmatrix}1&1\\0&1\end{bmatrix},\qquad H=\begin{bmatrix}1&0\end{bmatrix}.$$

The first row says next level equals old level plus old slope; the second row says slope persists unless process noise changes it.

```python
n_trend_w = 50  # length of the trend demo.
slope_true_w = 0.18 + np.cumsum(np.random.normal(0, 0.01, n_trend_w))  # slowly changing hidden slope.
level_true_w = 5 + np.cumsum(slope_true_w)  # hidden level is accumulated slope.
y_trend_w = level_true_w + np.random.normal(0, 0.35, n_trend_w)  # noisy level observations.
print("first true slopes:", np.round(slope_true_w[:4], 3))  # inspect hidden trend component.
print("first observations:", np.round(y_trend_w[:4], 3))  # inspect measured level.
```
▶ What you'll see: the observations measure only the level, not the slope directly.

```python
def kalman_filter_matrix_w(y, A, H, Q, R, m0, P0):  # general linear-Gaussian Kalman filter.
    n = len(y); d = len(m0)  # observations and state dimension.
    mp = np.zeros((n, d)); Pp = np.zeros((n, d, d))  # predicted states.
    mf = np.zeros((n, d)); Pf = np.zeros((n, d, d))  # filtered states.
    innov = np.zeros(n); gain = np.zeros((n, d))  # scalar observations, vector gains.
    m, P = m0.copy(), P0.copy()  # current belief.
    for i in range(n):  # chronological filtering.
        mp[i] = A @ m  # matrix transition for the predicted mean.
        Pp[i] = A @ P @ A.T + Q  # covariance prediction.
        innov[i] = y[i] - float(H @ mp[i])  # observation surprise.
        S = float(H @ Pp[i] @ H.T + R)  # innovation variance.
        K = (Pp[i] @ H.T / S).ravel()  # Kalman gain vector.
        gain[i] = K  # store gain for inspection.
        mf[i] = mp[i] + K * innov[i]  # update both level and slope.
        Pf[i] = (np.eye(d) - K[:, None] @ H) @ Pp[i]  # covariance update.
        m, P = mf[i], Pf[i]  # carry forward.
    return mp, Pp, mf, Pf, innov, gain  # return all internals.

A_w = np.array([[1., 1.], [0., 1.]])  # level plus slope transition.
H_w = np.array([[1., 0.]])  # observe only level.
Q_w = np.diag([0.02, 0.001])  # allow small level and slope process changes.
R_w = 0.35 ** 2  # measurement variance.
mp_t_w, Pp_t_w, mf_t_w, Pf_t_w, innov_t_w, gain_t_w = kalman_filter_matrix_w(y_trend_w, A_w, H_w, Q_w, R_w, np.array([y_trend_w[0], 0.0]), np.diag([1.0, 0.1]))  # run local-trend filter.
print("last filtered level/slope:", np.round(mf_t_w[-1], 3))  # inspect the two state coordinates.
```
▶ What you'll see: the filter estimates both level and slope even though only level is observed.

```python
plt.figure(figsize=(6, 3))  # create a local-trend figure.
plt.plot(level_true_w, label="hidden level", linewidth=2)  # draw true level.
plt.scatter(np.arange(n_trend_w), y_trend_w, s=14, color="orange", label="observed level")  # draw noisy observations.
plt.plot(mf_t_w[:, 0], color="seagreen", label="filtered level")  # draw estimated level.
plt.title("4: local-trend filter estimates level")  # title plot.
plt.legend()  # show labels.
plt.show()  # display figure.
```
▶ What you'll see: the filtered level tracks a sloped trajectory without copying every noisy point.

```python
plt.figure(figsize=(6, 2.8))  # create a slope diagnostic.
plt.plot(slope_true_w, label="hidden slope", linewidth=2)  # draw true slope.
plt.plot(mf_t_w[:, 1], label="filtered slope", color="purple")  # draw estimated slope.
plt.title("4: slope is inferred from level measurements")  # label slope story.
plt.xlabel("time")  # label time.
plt.legend()  # show labels.
plt.show()  # display figure.
```
▶ What you'll see: the slope estimate is smoother and lagged because slope is inferred indirectly from level changes.

*Why it's done this way:* the transition matrix encodes the physics of the state. Multiplying by $A$ is not a coding trick; it is the mathematical statement that level integrates slope, while $H$ states exactly what the sensor measures.

### 5. Kalman smoothing uses future evidence after filtering

Filtering is online; smoothing is retrospective. Once the whole series is available, the Rauch–Tung–Striebel (RTS) smoother revises each filtered state using the next smoothed state. The smoother gain is

$$J_t=P_{t|t}A^\top(P_{t+1|t})^{-1}.$$

It says how much a later correction should flow backward through the transition model.

```python
def rts_smoother_w(A, mp, Pp, mf, Pf):  # implement RTS smoothing for a linear state model.
    n, d = mf.shape  # time length and state dimension.
    ms = mf.copy(); Ps = Pf.copy()  # initialize smoothed states at filtered values.
    for i in range(n - 2, -1, -1):  # move backward from second-last state.
        J = Pf[i] @ A.T @ np.linalg.inv(Pp[i + 1])  # smoother gain linking t to t+1.
        ms[i] = mf[i] + J @ (ms[i + 1] - mp[i + 1])  # corrected mean.
        Ps[i] = Pf[i] + J @ (Ps[i + 1] - Pp[i + 1]) @ J.T  # corrected covariance.
    return ms, Ps  # return smoothed means and covariances.

ms_t_w, Ps_t_w = rts_smoother_w(A_w, mp_t_w, Pp_t_w, mf_t_w, Pf_t_w)  # smooth the local-trend states.
filt_level_mse_w = float(np.mean((mf_t_w[:, 0] - level_true_w) ** 2))  # filtered level error.
smooth_level_mse_w = float(np.mean((ms_t_w[:, 0] - level_true_w) ** 2))  # smoothed level error.
print("filtered level MSE:", round(filt_level_mse_w, 4), "smoothed level MSE:", round(smooth_level_mse_w, 4))  # compare.
assert smooth_level_mse_w < filt_level_mse_w  # future evidence should help on this seeded example.
```
▶ What you'll see: smoothing lowers level MSE because it uses future observations to refine past states.

```python
plt.figure(figsize=(6, 3))  # create smoothing comparison.
plt.plot(level_true_w, label="hidden level", linewidth=2)  # true level.
plt.plot(mf_t_w[:, 0], label="filtered", color="seagreen", alpha=0.75)  # causal estimate.
plt.plot(ms_t_w[:, 0], label="smoothed", color="crimson", linewidth=2)  # retrospective estimate.
plt.title("5: RTS smoother revises past states")  # title plot.
plt.legend()  # show labels.
plt.show()  # display figure.
```
▶ What you'll see: the smoothed line is usually closer to the true level and less phase-lagged than the filtered line.

```python
plt.figure(figsize=(6, 2.8))  # create uncertainty plot.
plt.plot(np.sqrt(Pf_t_w[:, 0, 0]), label="filtered level sd", color="seagreen")  # filtered uncertainty.
plt.plot(np.sqrt(Ps_t_w[:, 0, 0]), label="smoothed level sd", color="crimson")  # smoothed uncertainty.
plt.title("5: smoothing also reduces uncertainty")  # title plot.
plt.ylabel("state sd")  # label uncertainty scale.
plt.legend()  # show labels.
plt.show()  # display figure.
```
▶ What you'll see: smoothed uncertainty is no larger than filtered uncertainty for most time points.

*Why it's done this way:* filtering answers “what did I know then?” while smoothing answers “what do I now believe happened then?” The backward gain is mathematically careful because it propagates only corrections consistent with the state transition and covariance.

### 6. Variance tuning and innovation diagnostics

The most important knobs are not the means but the variances. If $R$ is too small, the filter believes noisy measurements and jitters. If $Q$ is too small, the filter believes the state cannot move and lags real drift. Innovations reveal the mismatch: a good one-step model leaves surprises centered and roughly as noisy as predicted.

```python
_, _, mf_lowR_w, _, innov_lowR_w, gain_lowR_w = kalman_local_level_w(y_w, 0.03, 0.05, y_w[0], 1.0)  # trust observations too much.
_, _, mf_lowQ_w, _, innov_lowQ_w, gain_lowQ_w = kalman_local_level_w(y_w, 0.001, 0.49, y_w[0], 1.0)  # trust model too much.
print("average gain low R:", round(float(np.mean(gain_lowR_w)), 3))  # high measurement trust.
print("average gain low Q:", round(float(np.mean(gain_lowQ_w)), 3))  # low movement trust.
assert np.mean(gain_lowR_w) > np.mean(gain_lowQ_w)  # smaller R creates larger gains.
```
▶ What you'll see: the low-R filter has a much larger average gain than the low-Q filter.

```python
mse_lowR_w = float(np.mean((mf_lowR_w - true_level_w) ** 2))  # error when copying observations too much.
mse_lowQ_w = float(np.mean((mf_lowQ_w - true_level_w) ** 2))  # error when lagging drift.
mse_good_w = float(np.mean((m_filt_w - true_level_w) ** 2))  # error with balanced variances.
print("MSE balanced/lowR/lowQ:", round(mse_good_w, 3), round(mse_lowR_w, 3), round(mse_lowQ_w, 3))  # compare settings.
```
▶ What you'll see: different variance choices produce visibly different accuracy.

```python
plt.figure(figsize=(6, 3))  # create variance tuning plot.
plt.scatter(t_w, y_w, s=14, color="lightgray", label="observed")  # noisy observations.
plt.plot(true_level_w, color="black", linewidth=2, label="truth")  # hidden truth.
plt.plot(m_filt_w, label="balanced Q,R", color="seagreen")  # balanced estimate.
plt.plot(mf_lowR_w, label="R too small", color="orange", alpha=0.9)  # jittery estimate.
plt.plot(mf_lowQ_w, label="Q too small", color="crimson", alpha=0.9)  # sluggish estimate.
plt.title("6: variance choices control jitter versus lag")  # title plot.
plt.legend()  # show labels.
plt.show()  # display figure.
```
▶ What you'll see: trusting observations creates jitter; trusting the model too much creates lag.

*Why it's done this way:* the Kalman gain is not a magic constant but a consequence of $Q$ and $R$. Innovation diagnostics are the practical check that those variances match the data instead of merely making a pretty smoothed line.

```python
import numpy as np

t1_rng = np.random.default_rng(0)                         # seeded generator for reproducibility.
```

### ✍️ Toy 2 · Scalar Kalman update uses a trust ratio

The scalar update first predicts, then uses the Kalman gain to move only partway toward the new
observation.

```python
import numpy as np

t2_rng = np.random.default_rng(0)                         # seeded generator for reproducibility.
t2_obs_series = np.array([7.0, 9.0, 8.0])                 # tiny observed series      # -> [7.0, 9.0, 8.0]
print("observations:", t2_obs_series.tolist())           # -> [7.0, 9.0, 8.0]
t2_m_prev = 8.0                                           # previous mean            # -> 8.0
print("previous mean:", t2_m_prev)                       # -> 8.0
t2_P_prev = 2.0                                           # previous variance        # -> 2.0
print("previous variance:", t2_P_prev)                   # -> 2.0
t2_Q = 1.0                                                # process variance         # -> 1.0
print("process variance Q:", t2_Q)                       # -> 1.0
t2_R = 3.0                                                # observation variance     # -> 3.0
print("observation variance R:", t2_R)                   # -> 3.0
t2_y = t2_obs_series[1]                                   # current measurement      # -> 9.0
print("current y:", t2_y)                                # -> 9.0
t2_m_pred = t2_m_prev                                     # local-level prediction   # -> 8.0
print("predicted mean:", t2_m_pred)                      # -> 8.0
t2_P_pred = t2_P_prev + t2_Q                              # prediction variance      # -> 3.0
print("predicted variance:", t2_P_pred)                  # -> 3.0
t2_innov = t2_y - t2_m_pred                               # observation surprise     # -> 1.0
print("innovation:", t2_innov)                           # -> 1.0
t2_S = t2_P_pred + t2_R                                   # innovation variance      # -> 6.0
print("innovation variance S:", t2_S)                    # -> 6.0
t2_K = t2_P_pred / t2_S                                   # Kalman gain              # -> 0.5
print("Kalman gain:", round(float(t2_K), 3))             # -> 0.5
t2_m_upd = t2_m_pred + t2_K * t2_innov                    # posterior mean           # -> 8.5
print("updated mean:", round(float(t2_m_upd), 3))         # -> 8.5
t2_P_upd = (1.0 - t2_K) * t2_P_pred                       # posterior variance       # -> 1.5
print("updated variance:", round(float(t2_P_upd), 3))     # -> 1.5
assert round(float(t2_m_upd), 3) == 8.5

plt.figure(figsize=(4.4, 2.8))
plt.bar(["prior", "y", "updated"], [t2_m_pred, t2_y, t2_m_upd], color=["gray", "orange", "seagreen"])
plt.title("Toy 2 · gain moves halfway")
plt.ylabel("value")
plt.show()
```
▶ What you'll see: the updated estimate lands halfway between the prior mean 8 and observation 9.

### ✍️ Toy 3 · Local-level filtering repeats predict and correct

Filtering is the scalar update looped forward through time. Watch the gain and filtered mean evolve
on four observations.

### ✍️ Toy 4 · Local-trend matrices update level and slope together

A two-state trend model predicts both the level and the slope. One level observation updates both
coordinates because the covariance couples them.

```python
import numpy as np

t4_rng = np.random.default_rng(0)                         # seeded generator for reproducibility.
t4_obs = np.array([4.0, 5.2])                             # short observed series     # -> [4.0, 5.2]
print("observations:", t4_obs.tolist())                  # -> [4.0, 5.2]
t4_A = np.array([[1.0, 1.0], [0.0, 1.0]])                 # level-plus-slope transition  # -> [[1.0, 1.0], [0.0, 1.0]]
print("transition A:", t4_A.tolist())                    # -> [[1.0, 1.0], [0.0, 1.0]]
t4_H = np.array([[1.0, 0.0]])                             # observe level only       # -> [[1.0, 0.0]]
print("observation H:", t4_H.tolist())                   # -> [[1.0, 0.0]]
t4_m_prev = np.array([4.0, 0.5])                          # prior [level, slope]     # -> [4.0, 0.5]
print("previous state mean:", t4_m_prev.tolist())         # -> [4.0, 0.5]
t4_P_prev = np.diag([1.0, 0.25])                          # prior covariance         # -> [[1.0, 0.0], [0.0, 0.25]]
print("previous covariance:", t4_P_prev.tolist())         # -> [[1.0, 0.0], [0.0, 0.25]]
t4_Q = np.diag([0.2, 0.05])                               # process covariance       # -> [[0.2, 0.0], [0.0, 0.05]]
print("process covariance Q:", t4_Q.tolist())             # -> [[0.2, 0.0], [0.0, 0.05]]
t4_R = 0.5                                                # observation variance     # -> 0.5
print("observation variance R:", t4_R)                   # -> 0.5
t4_m_pred = t4_A @ t4_m_prev                              # predicted state          # -> [4.5, 0.5]
print("predicted state:", np.round(t4_m_pred, 3).tolist())  # -> [4.5, 0.5]
t4_P_pred = t4_A @ t4_P_prev @ t4_A.T + t4_Q              # predicted covariance     # -> [[1.45, 0.25], [0.25, 0.3]]
print("predicted covariance:", np.round(t4_P_pred, 3).tolist())  # -> [[1.45, 0.25], [0.25, 0.3]]
t4_innov = t4_obs[1] - float((t4_H @ t4_m_pred)[0])       # level surprise           # -> 0.7
print("innovation:", round(float(t4_innov), 3))           # -> 0.7
t4_S = float((t4_H @ t4_P_pred @ t4_H.T)[0, 0] + t4_R)    # innovation variance      # -> 1.95
print("innovation variance S:", round(float(t4_S), 3))    # -> 1.95
t4_K = (t4_P_pred @ t4_H.T / t4_S).ravel()                # vector Kalman gain       # -> [0.744, 0.128]
print("gain vector:", np.round(t4_K, 3).tolist())         # -> [0.744, 0.128]
t4_m_upd = t4_m_pred + t4_K * t4_innov                    # updated [level, slope]   # -> [5.021, 0.59]
print("updated state:", np.round(t4_m_upd, 3).tolist())   # -> [5.021, 0.59]
t4_P_upd = (np.eye(2) - t4_K[:, None] @ t4_H) @ t4_P_pred # updated covariance       # -> [[0.372, 0.064], [0.064, 0.268]]
print("updated covariance:", np.round(t4_P_upd, 3).tolist())  # -> [[0.372, 0.064], [0.064, 0.268]]
assert np.allclose(np.round(t4_m_upd, 3), [5.021, 0.59])

plt.figure(figsize=(4.6, 2.8))
plt.bar(["level prior", "slope prior", "level upd", "slope upd"], [t4_m_pred[0], t4_m_pred[1], t4_m_upd[0], t4_m_upd[1]], color=["gray", "gray", "seagreen", "seagreen"])
plt.title("Toy 4 · one y updates two states")
plt.xticks(rotation=25)
plt.ylabel("state value")
plt.show()
```
▶ What you'll see: the level jumps upward and the slope nudges upward even though only level was observed.

### ✍️ Toy 5 · RTS smoothing sends future corrections backward

A smoother revises past filtered means after seeing later evidence. In this scalar random-walk toy,
the later high state pulls earlier smoothed estimates upward.

```python
import numpy as np

t5_rng = np.random.default_rng(0)                         # seeded generator for reproducibility.

for t5_i in range(t5_filt_mean.size - 2, -1, -1):
```

### ✍️ Toy 6 · Process variance controls lag versus movement

A larger `Q` lets the hidden level move faster. Compare a low-`Q` filter that lags a jump with a
high-`Q` filter that follows it.

```python
import numpy as np

t6_rng = np.random.default_rng(0)                         # seeded generator for reproducibility.
t6_obs = np.array([2.0, 2.2, 4.0, 4.2, 4.4])              # short observed series     # -> [2.0, 2.2, 4.0, 4.2, 4.4]
print("observations:", t6_obs.tolist())                  # -> [2.0, 2.2, 4.0, 4.2, 4.4]
t6_truth = np.array([2.0, 2.1, 3.0, 3.9, 4.3])            # hidden reference          # -> [2.0, 2.1, 3.0, 3.9, 4.3]
print("hidden reference:", t6_truth.tolist())            # -> [2.0, 2.1, 3.0, 3.9, 4.3]

def t6_filter(t6_y, t6_Q, t6_R):
    t6_m = t6_y[0]
    t6_P = 1.0
    t6_filt = []
    t6_gain = []
    for t6_value in t6_y:
        t6_m_pred = t6_m
        t6_P_pred = t6_P + t6_Q
        t6_innov = t6_value - t6_m_pred
        t6_S = t6_P_pred + t6_R
        t6_K = t6_P_pred / t6_S
        t6_m = t6_m_pred + t6_K * t6_innov
        t6_P = (1.0 - t6_K) * t6_P_pred
        t6_filt.append(t6_m)
        t6_gain.append(t6_K)
    return np.array(t6_filt), np.array(t6_gain)

t6_lowQ_filt, t6_lowQ_gain = t6_filter(t6_obs, 0.01, 0.5) # sluggish setting          # -> filtered [2.0, 2.082, 2.656, 3.03, 3.315]
t6_highQ_filt, t6_highQ_gain = t6_filter(t6_obs, 0.8, 0.5) # flexible setting          # -> filtered [2.0, 2.141, 3.437, 3.969, 4.269]
print("low-Q filtered:", np.round(t6_lowQ_filt, 3).tolist())    # -> [2.0, 2.082, 2.656, 3.03, 3.315]
print("high-Q filtered:", np.round(t6_highQ_filt, 3).tolist())  # -> [2.0, 2.141, 3.437, 3.969, 4.269]
t6_lowQ_gain_mean = float(t6_lowQ_gain.mean())             # average low-Q gain       # -> 0.365
print("average low-Q gain:", round(t6_lowQ_gain_mean, 3)) # -> 0.365
t6_highQ_gain_mean = float(t6_highQ_gain.mean())           # average high-Q gain      # -> 0.716
print("average high-Q gain:", round(t6_highQ_gain_mean, 3))  # -> 0.716
t6_lowQ_mse = float(np.mean((t6_lowQ_filt - t6_truth) ** 2))     # low-Q error          # -> 0.369
print("low-Q MSE:", round(t6_lowQ_mse, 3))                # -> 0.369
t6_highQ_mse = float(np.mean((t6_highQ_filt - t6_truth) ** 2))   # high-Q error         # -> 0.04
print("high-Q MSE:", round(t6_highQ_mse, 3))              # -> 0.04
assert t6_highQ_gain_mean > t6_lowQ_gain_mean
assert t6_highQ_mse < t6_lowQ_mse

plt.figure(figsize=(4.8, 2.8))
plt.plot(t6_truth, "o-", color="black", label="hidden")
plt.plot(t6_lowQ_filt, "o--", color="crimson", label="low Q")
plt.plot(t6_highQ_filt, "o--", color="seagreen", label="high Q")
plt.title("Toy 6 · Q controls movement")
plt.xlabel("time")
plt.ylabel("level")
plt.legend()
plt.show()
```
▶ What you'll see: high `Q` uses larger gains and follows the jump with much less lag.

### Basic 5 — Update one scalar state

**Goal.** Apply the Kalman correction to mean and variance, because filtering is prediction followed by Gaussian conditioning. We build it in 3 steps.

```python
m_pred_b5 = 10.0  # predicted mean.
```

### Easy 1 — Implement a reusable local-level filter

**Goal.** Write a compact Kalman filter function for a scalar local-level model, because many forecasting baselines reduce to this recursion. We build it in 4 steps.

```python
def local_level_filter_e1(y, Q, R, m0=None, P0=1.0):  # define scalar local-level Kalman filtering.
    y = np.asarray(y, dtype=float)  # convert observations to a numeric array.
    m = y[0] if m0 is None else float(m0)  # initialize mean.
    P = float(P0)  # initialize variance.
    mf = np.zeros(len(y)); Pf = np.zeros(len(y)); innov = np.zeros(len(y)); gains = np.zeros(len(y))  # allocate outputs.
    for i, obs in enumerate(y):  # process observations in order.
        mp = m  # local-level predicted mean.
        Pp = P + Q  # predicted variance.
        innov[i] = obs - mp  # one-step residual.
        gains[i] = Pp / (Pp + R)  # scalar Kalman gain.
        m = mp + gains[i] * innov[i]  # posterior mean.
        P = (1 - gains[i]) * Pp  # posterior variance.
        mf[i], Pf[i] = m, P  # store posterior.
    return mf, Pf, innov, gains  # return filter diagnostics.
print("local_level_filter_e1 ready")  # confirm helper creation.
```

### Easy 4 — Filter a local-trend model

**Goal.** Estimate both level and slope from level observations, because many time series have momentum that a local-level state cannot represent directly. We build it in 4 steps.

```python
def matrix_filter_e4(y, A, H, Q, R, m0, P0):  # define a linear Kalman filter for scalar observations.
    y = np.asarray(y, dtype=float); d = len(m0); n = len(y)  # capture dimensions.
    mf = np.zeros((n, d)); Pf = np.zeros((n, d, d)); mp = np.zeros((n, d)); Pp = np.zeros((n, d, d))  # allocate arrays.
    m, P = m0.copy(), P0.copy()  # initialize belief.
    for i, obs in enumerate(y):  # process time in order.
        mp[i] = A @ m; Pp[i] = A @ P @ A.T + Q  # prediction.
        S = float(H @ Pp[i] @ H.T + R)  # innovation variance.
        K = (Pp[i] @ H.T / S).ravel()  # gain vector.
        mf[i] = mp[i] + K * (obs - float(H @ mp[i]))  # mean update.
        Pf[i] = (np.eye(d) - K[:, None] @ H) @ Pp[i]  # covariance update.
        m, P = mf[i], Pf[i]  # carry forward.
    return mp, Pp, mf, Pf  # return prediction and filtering arrays.
print("matrix_filter_e4 ready")  # confirm helper creation.
```
▶ What you'll see: a reusable matrix filter is ready for local-trend examples.

### Easy 5 — Smooth filtered local-trend states

**Goal.** Apply an RTS smoother to the Easy 4 local-trend filter, because offline analysis can use future observations to improve past state estimates. We build it in 4 steps.

```python
def rts_smoother_e5(A, mp, Pp, mf, Pf):  # define Rauch-Tung-Striebel smoothing.
    ms = mf.copy(); Ps = Pf.copy()  # initialize smoothed arrays from filtered arrays.
    for i in range(len(mf) - 2, -1, -1):  # step backward through time.
        J = Pf[i] @ A.T @ np.linalg.inv(Pp[i + 1])  # smoother gain.

        Ps[i] = Pf[i] + J @ (Ps[i + 1] - Pp[i + 1]) @ J.T  # revise covariance.
    return ms, Ps  # return smoothed states.
print("rts_smoother_e5 ready")  # confirm helper creation.
```

### Advanced 4 — Handle missing observations

**Goal.** Skip Kalman updates when observations are missing, because state prediction can continue even when the sensor is silent. We build it in 4 steps.

```python
y_a4 = y_e1.copy()  # reuse the Easy 1 local-level observations.
y_a4[20:28] = np.nan  # hide a block of measurements.
missing_a4 = np.isnan(y_a4)  # mark missing observations.
print("missing count:", int(np.sum(missing_a4)))  # inspect gap length.
```
▶ What you'll see: eight consecutive observations are missing.

```python
m_a4, P_a4 = y_e1[0], 1.0  # initialize state from the original first observation.
mf_a4 = np.zeros(len(y_a4)); Pf_a4 = np.zeros(len(y_a4))  # allocate outputs.
for i_a4, obs_a4 in enumerate(y_a4):  # process series with gaps.
    mp_a4 = m_a4; Pp_a4 = P_a4 + 0.02  # prediction always happens.
    if np.isnan(obs_a4):  # if no observation arrived.
        m_a4, P_a4 = mp_a4, Pp_a4  # skip correction and keep predicted belief.
    else:  # otherwise run normal update.
        K_a4 = Pp_a4 / (Pp_a4 + 0.36)  # compute gain.
        m_a4 = mp_a4 + K_a4 * (obs_a4 - mp_a4)  # update mean.
        P_a4 = (1 - K_a4) * Pp_a4  # update variance.
    mf_a4[i_a4], Pf_a4[i_a4] = m_a4, P_a4  # store state.

assert Pf_a4[27] > Pf_a4[19]  # uncertainty grows during missing block.
```
▶ What you'll see: variance increases while measurements are missing.


### Advanced 5 — Estimate R from innovations

**Goal.** Use innovation variance as a diagnostic for observation noise, because a filter with a badly chosen R produces surprises that are too large or too small for its own uncertainty. We build it in 5 steps.

```python
y_a5 = y_e1  # reuse Easy 1 observations.
R_grid_a5 = np.array([0.05, 0.16, 0.36, 0.81, 1.44])  # candidate observation variances.
Q_a5 = 0.02  # keep process variance fixed.
print("R grid:", R_grid_a5)  # inspect candidates.
```
▶ What you'll see: the sweep ranges from over-trusting to under-trusting measurements.

```python
nll_a5 = []  # store Gaussian innovation negative log-likelihood up to constants.
for R_cand_a5 in R_grid_a5:  # evaluate each R.
    m_a5, P_a5 = y_a5[0], 1.0  # reset prior for fair comparison.
    total_a5 = 0.0  # accumulate likelihood score.
    for obs_a5 in y_a5:  # filter and score innovations.
        mp_a5 = m_a5; Pp_a5 = P_a5 + Q_a5  # prediction.
        e_a5 = obs_a5 - mp_a5  # innovation.
        S_a5 = Pp_a5 + R_cand_a5  # innovation variance under candidate R.
        total_a5 += 0.5 * (np.log(S_a5) + e_a5 ** 2 / S_a5)  # Gaussian nll without constant.
        K_a5 = Pp_a5 / S_a5  # gain.
        m_a5 = mp_a5 + K_a5 * e_a5  # update mean.
        P_a5 = (1 - K_a5) * Pp_a5  # update variance.
    nll_a5.append(total_a5)  # store candidate score.
print("innovation NLL:", np.round(nll_a5, 3))  # inspect sweep.
```
▶ What you'll see: one observation variance gives the lowest innovation score.

```python

```
▶ What you'll see: the selected R is a data-supported variance from the candidate grid.

