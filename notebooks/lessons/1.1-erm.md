# 1.1 · Empirical Risk Minimization

Empirical Risk Minimization (ERM) is the first move in learning theory: we cannot measure the true expected error, so we minimize the average loss on the training sample we actually have. This lesson builds that substitution carefully, shows why it works for a fixed model, and shows why choosing the best-looking model on the same data can overfit.

## 📖 Concept walkthrough — build it from scratch

Before the terse worked examples, we build empirical risk minimization one idea at a time. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix on its variables so it never clashes with the examples below.

### 1. Loss turns one prediction into one number

ERM starts only after we decide how to score being wrong. For classification we often use 0-1 loss: `1` for a mistake and `0` for a correct prediction. The point of this cell is not to train anything yet; it is to make the raw notion of "wrong" into numbers that can be averaged and minimized.

```python
x_w = np.array([1, 2, 3, 4, 5])  # five tiny one-dimensional inputs from the lesson.
y_w = np.array([0, 0, 1, 1, 1])  # true class labels for the five inputs.
t_w = 1.5  # choose one threshold rule h_t(x)=1 if x>t.
pred_w = (x_w > t_w).astype(int)  # compute the threshold predictions as 0/1 labels.
print("x:", x_w)  # inspect the inputs.
print("y:", y_w)  # inspect the true labels.
print("predictions at t=1.5:", pred_w)  # inspect the rule's guesses.
```
▶ What you'll see: the threshold predicts `[0,1,1,1,1]`, so only the point at x=2 is wrong.

```python
loss01_w = (pred_w != y_w).astype(int)  # 0-1 loss is 1 exactly where prediction differs from truth.
print("0-1 losses:", loss01_w)  # inspect the per-example mistake indicators.
print("mistake count:", int(loss01_w.sum()))  # count the number of wrong predictions.
assert int(loss01_w.sum()) == 1  # verify the cited one mistake for t=1.5.
```
▶ What you'll see: one `1` in the loss vector and four `0`s.

```python
plt.figure(figsize=(4.6, 3))  # create a compact loss plot.
plt.scatter(x_w, y_w, s=80, label="true y")  # draw the observed labels.
plt.scatter(x_w, pred_w, marker="x", s=90, label="prediction")  # draw predictions for comparison.
plt.axvline(t_w, color="black", linestyle="--", label="threshold")  # show the decision cutoff.
plt.title("1: 0-1 loss from a threshold rule")  # title the figure with the concept number.
plt.xlabel("x")  # label the input axis.
plt.ylabel("label")  # label the output axis.
plt.legend()  # show which markers are true labels versus predictions.
plt.show()  # display the plot.
```
▶ What you'll see: every point agrees except x=2, where prediction and truth separate.

*Why it's done this way: loss is the bridge from qualitative errors to arithmetic; once each example has a loss, learning can average those losses and compare models numerically.*

### 2. Empirical risk is the average loss on the sample

The true risk is an expectation over the population, but the empirical risk is the average over the sample we can see. For classification with 0-1 loss, that average is just the fraction of mistakes. Averaging matters because it puts samples of different sizes on the same scale and estimates the expected loss of a fixed model.

$$R_S(h)=\frac{1}{m}\sum_{i=1}^{m}\ell(h(x_i),y_i).$$

```python
thresholds_w = np.array([1.5, 2.5, 3.5])  # scan the three threshold rules from the lesson.
risks_w = []  # collect each empirical risk for comparison.
for threshold_w in thresholds_w:  # loop over candidate rules in the hypothesis class.
    preds_w = (x_w > threshold_w).astype(int)  # compute predictions for this threshold.
    risk_w = np.mean(preds_w != y_w)  # average the 0-1 losses to get empirical risk.
    risks_w.append(risk_w)  # store the risk so ERM can minimize it.
    print("t=", threshold_w, "pred=", preds_w, "R_S=", round(float(risk_w), 3))  # inspect the full calculation.
```
▶ What you'll see: risks 0.20, 0.00, and 0.20 for thresholds 1.5, 2.5, and 3.5.

```python
risks_w = np.array(risks_w)  # convert the list to an array for argmin and plotting.
best_index_w = int(np.argmin(risks_w))  # find the candidate with smallest empirical risk.
best_t_w = float(thresholds_w[best_index_w])  # recover the winning threshold value.
print("ERM threshold:", best_t_w)  # inspect the empirical-risk minimizer.
print("minimum empirical risk:", round(float(risks_w[best_index_w]), 3))  # inspect the best training error.
assert round(float(risks_w[0]), 3) == 0.2 and round(float(risks_w[1]), 3) == 0.0 and round(float(risks_w[2]), 3) == 0.2  # verify the cited risks.
```
▶ What you'll see: ERM returns t=2.5 because it makes zero training mistakes.

```python
plt.figure(figsize=(4.6, 3))  # create a compact risk curve over the finite class.
plt.bar([str(t) for t in thresholds_w], risks_w, color="seagreen")  # draw one empirical-risk bar per threshold.
plt.title("2: empirical risk chooses the smallest bar")  # title the figure with the concept number.
plt.xlabel("threshold t")  # label candidate rules.
plt.ylabel("empirical risk R_S")  # label the average training loss.
plt.ylim(0, 0.3)  # keep the small risk differences readable.
plt.show()  # display the plot.
```
▶ What you'll see: the middle bar is exactly zero while the outer two bars tie at 0.20.

*Why it's done this way: ERM turns model selection into a finite numerical search here — compute each training average, then choose the smallest one.*

### 3. Squared-loss ERM recovers the sample mean

For regression, a common loss is squared error. If the hypothesis class is all constant predictors $h_c(x)=c$, minimizing empirical squared risk chooses the sample mean. This is a reassuring first example: ERM reproduces the estimator you would already trust.

$$R_S(c)=\frac{1}{m}\sum_{i=1}^{m}(c-y_i)^2.$$

```python
targets_w = np.array([2.0, 4.0, 6.0])  # three regression targets from the lesson.
constants_w = np.array([3.0, 4.0, 5.0])  # three candidate constant predictions.
print("targets:", targets_w)  # inspect the regression sample.
print("candidates:", constants_w)  # inspect the constants we will compare.
```
▶ What you'll see: the targets are symmetric around 4.

```python
mse_w = []  # collect empirical squared risks.
for c_w in constants_w:  # scan candidate constants.
    losses_w = (c_w - targets_w) ** 2  # compute squared loss for each training point.
    risk_w = float(np.mean(losses_w))  # average squared losses into empirical risk.
    mse_w.append(risk_w)  # store this candidate's risk.
    print("c=", c_w, "squared losses=", losses_w, "R_S=", round(risk_w, 3))  # inspect the calculation.
```
▶ What you'll see: the risks are 3.667, 2.667, and 3.667.

```python
mse_w = np.array(mse_w)  # convert risks to an array for checks and plotting.
mean_w = float(np.mean(targets_w))  # compute the sample mean.
variance_w = float(np.mean((targets_w - mean_w) ** 2))  # compute the empirical variance around the mean.
print("sample mean:", round(mean_w, 3))  # inspect the ERM constant under squared loss.
print("risk at the mean:", round(variance_w, 3))  # inspect the minimum squared risk.
assert round(float(mse_w[0]), 3) == 3.667 and round(float(mse_w[1]), 3) == 2.667 and round(float(mse_w[2]), 3) == 3.667  # verify cited candidate risks.
```
▶ What you'll see: the best constant is 4, and its empirical risk equals 2.667.

```python
plt.figure(figsize=(4.6, 3))  # create a compact squared-risk plot.
plt.plot(constants_w, mse_w, marker="o", color="purple")  # draw empirical risk versus constant.
plt.axvline(mean_w, color="black", linestyle="--", label="sample mean")  # mark the minimizing constant.
plt.title("3: squared-loss ERM picks the mean")  # title the figure with the concept number.
plt.xlabel("constant c")  # label candidate constants.
plt.ylabel("empirical squared risk")  # label mean squared error.
plt.legend()  # show the sample mean marker.
plt.show()  # display the plot.
```
▶ What you'll see: the risk curve bottoms out at c=4.

*Why it's done this way: squared loss penalizes distance from the constant, and the positive and negative deviations cancel exactly at the sample mean.*

### 4. Empirical risk estimates true risk for a fixed model

For a fixed hypothesis $h$, the sample average loss is an unbiased estimate of the true expected loss. We cannot see the population in real life, so this simulation creates one known population with true error 0.2 and repeatedly samples from it. The average empirical risk bounces around, but its long-run mean lands near the true risk.

```python
true_risk_w = 0.2  # define a fixed classifier whose population mistake probability is 20%.
sample_size_w = 50  # choose the number of examples in each training sample.
trials_w = 2000  # repeat sampling many times to reveal the long-run average.
empirical_risks_w = np.random.binomial(sample_size_w, true_risk_w, size=trials_w) / sample_size_w  # simulate training-error fractions.
print("first five empirical risks:", np.round(empirical_risks_w[:5], 3))  # inspect sample-to-sample variability.
print("average empirical risk:", round(float(empirical_risks_w.mean()), 3))  # inspect the Monte Carlo mean.
assert abs(float(empirical_risks_w.mean()) - true_risk_w) < 0.02  # verify unbiasedness up to simulation tolerance.
```
▶ What you'll see: individual samples vary, but the average over many samples is close to 0.20.

```python
plt.figure(figsize=(4.8, 3))  # create a histogram figure.
plt.hist(empirical_risks_w, bins=20, color="steelblue", edgecolor="white")  # draw the distribution of sample averages.
plt.axvline(true_risk_w, color="black", linestyle="--", label="true risk")  # mark the population error.
plt.title("4: R_S(h) estimates R(h) for fixed h")  # title the figure with the concept number.
plt.xlabel("empirical risk over one sample")  # label the sample-average axis.
plt.ylabel("count")  # label the frequency axis.
plt.legend()  # show the true-risk reference.
plt.show()  # display the plot.
```
▶ What you'll see: the histogram is centered near the true risk line at 0.20.

*Why it's done this way: the law of large numbers justifies replacing an expectation by a sample average when the model was fixed before seeing the sample.*

### 5. Minimizing over many models creates downward bias

The subtle danger is that ERM does not report the risk of a fixed model; it reports the smallest sample risk after searching a class. With more hypotheses, some model will look lucky on the training sample even if its true risk is no better. That is why zero training error can be a warning rather than a trophy, especially when the Bayes floor from label noise is nonzero.

```python
rng_w = np.random.default_rng(1)  # use a separate reproducible generator for the overfitting demo.
n_models_w = 40  # define many equally-good hypotheses.
m_w = 30  # define the sample size each hypothesis is evaluated on.
true_risks_many_w = np.full(n_models_w, 0.1)  # every hypothesis has the same true 10% error floor.
sample_risks_many_w = rng_w.binomial(m_w, true_risks_many_w) / m_w  # draw empirical risks with sampling noise.
print("best empirical risk:", round(float(sample_risks_many_w.min()), 3))  # inspect the lucky winner's training error.
print("true risk of every model:", round(float(true_risks_many_w[0]), 3))  # inspect the Bayes/noise floor.
assert round(float(true_risks_many_w[0]), 3) == 0.1  # verify the cited 10% floor.
```
▶ What you'll see: at least one model often looks better than 0.10 on the sample just by luck.

```python
winner_w = int(np.argmin(sample_risks_many_w))  # find the hypothesis ERM would choose.
gap_w = float(true_risks_many_w[winner_w] - sample_risks_many_w[winner_w])  # measure optimism from choosing the lucky minimum.
print("ERM winner index:", winner_w)  # inspect which model won.
print("downward-bias gap:", round(gap_w, 3))  # inspect true risk minus training risk for the winner.
```
▶ What you'll see: the selected model's training risk can sit below its true 0.10 risk.

```python
plt.figure(figsize=(5, 3))  # create a compact overfitting visualization.
plt.scatter(np.arange(n_models_w), sample_risks_many_w, color="darkorange", label="empirical risks")  # draw sample risks for all models.
plt.axhline(0.1, color="black", linestyle="--", label="true/Bayes floor")  # show the irreducible 10% error floor.
plt.scatter([winner_w], [sample_risks_many_w[winner_w]], color="crimson", s=90, label="ERM choice")  # highlight the chosen lucky minimum.
plt.title("5: min_h R_S(h) is optimistically low")  # title the figure with the concept number.
plt.xlabel("hypothesis index")  # label the model axis.
plt.ylabel("risk")  # label risk values.
plt.legend()  # show the meaning of markers.
plt.show()  # display the plot.
```
▶ What you'll see: ERM chooses the lowest orange dot, which can fall below the dashed true-risk floor.

*Why it's done this way: the same sample is used to both score and choose the model, so the minimum sample score is biased downward even when each fixed score is unbiased.*

```python
# !pip install numpy matplotlib  # install the only packages used in this lesson when running outside Colab.
import numpy as np  # load NumPy for arrays, averages, random samples, and numerical checks.
import matplotlib.pyplot as plt  # load Matplotlib for the bars, lines, scatters, and histograms in the examples.
np.random.seed(11)  # make all example randomness reproducible across notebook runs.
def zero_one_loss(y_true, y_pred):  # define 0-1 classification loss for arrays of labels.
    return (np.asarray(y_true) != np.asarray(y_pred)).astype(int)  # return 1 for mistakes and 0 for correct predictions.
def empirical_risk(losses):  # define empirical risk as the sample average of losses.
    return float(np.mean(np.asarray(losses, dtype=float)))  # average losses after converting them to floats.
def threshold_predict(x, t):  # define the lesson's threshold classifier h_t(x)=1 if x>t.
    return (np.asarray(x) > t).astype(int)  # compare each input to the threshold and return 0/1 labels.
def squared_loss(y_true, y_pred):  # define squared loss for regression predictions.
    return (np.asarray(y_pred, dtype=float) - np.asarray(y_true, dtype=float)) ** 2  # square residuals elementwise.
def safe_mean(values):  # define a guarded mean helper for tiny arrays.
    values = np.asarray(values, dtype=float)  # convert input to a float array.
    return 0.0 if values.size == 0 else float(np.mean(values))  # avoid empty-slice warnings by returning 0 for empty input.
```
