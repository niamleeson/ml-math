# 23.8 — Regret & Counterfactual Regret Minimization

Regret minimization gives repeated games a learning rule: instead of trying to predict the opponent perfectly, we ask which action we wish we had played more often in hindsight. In this lesson, you will build regret, regret matching, average-strategy convergence, and counterfactual regret minimization (CFR) from scratch with only NumPy and Matplotlib.

## 📖 Concept walkthrough — build each idea from scratch

Before the worked examples, we build regret minimization one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including counterfactual-value weighting, is shown explicitly. This walkthrough is self-contained and uses a `_w` suffix on variables so it never clashes with examples below.

```python
import numpy as np  # arrays, random sampling, and small numerical checks.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for simulations.
```

### 1. External regret: compare against fixed actions in hindsight

The regret question is not "did every round go well?" It is "after seeing the whole sequence, how much better would the best single fixed action have done?" If the algorithm's cumulative payoff is close to the best fixed action's cumulative payoff, external regret is small. That makes regret a humble but powerful stability target for adaptive opponents.

```python
actions_w = ["H", "T"]  # two toy actions.
payoffs_w = np.array([[1, -1], [-1, 1], [1, -1], [-1, 1]], dtype=float)  # payoff of H,T each round.
played_w = np.array([0, 0, 1, 1])  # H,H,T,T.
actual_w = payoffs_w[np.arange(4), played_w]  # payoff received by the algorithm.
fixed_totals_w = payoffs_w.sum(axis=0)  # payoff from always H and always T.
regret_w = float(np.max(fixed_totals_w) - np.sum(actual_w))  # external regret.
print("actual payoffs:", actual_w, "actual total:", np.sum(actual_w))
print("fixed-action totals H,T:", fixed_totals_w, "external regret:", regret_w)
assert regret_w == 0.0
plt.figure(figsize=(4.6, 3))
plt.plot(np.cumsum(actual_w), marker="o", label="played policy")
plt.plot(np.cumsum(payoffs_w[:, 0]), marker="s", label="always H")
plt.plot(np.cumsum(payoffs_w[:, 1]), marker="^", label="always T")
plt.axhline(0, color="black", linewidth=0.7)
plt.title("1: cumulative payoff comparison")
plt.xlabel("round")
plt.ylabel("cumulative payoff")
plt.legend()
plt.show()
```
▶ What you'll see: the played policy has good and bad rounds, but neither fixed action beats it over the full sequence.

*Why it's done this way: regret is a comparison to a simple hindsight benchmark, so it can be optimized online without solving the opponent's future strategy.*

### 2. Regret matching: turn positive regret into probabilities

Regret matching accumulates one number per action: how much better that action would have been than what we actually did. Negative regrets mean "we do not miss that action," so only positive regret gets probability mass. If all cumulative regrets are nonpositive, the rule falls back to uniform play so learning can continue.

```python
regrets_w = np.array([3.0, 1.0])  # cumulative regrets for H and T.
pos_w = np.maximum(regrets_w, 0.0)  # only missed opportunities count.
probs_w = pos_w / np.sum(pos_w)  # normalize positive regret into a strategy.
print("positive regrets:", pos_w)
print("regret-matching probabilities:", probs_w)
assert np.allclose(probs_w, [0.75, 0.25])
plt.figure(figsize=(4.2, 3))
plt.bar(["H", "T"], probs_w, color=["teal", "orange"])
plt.ylim(0, 1)
plt.title("2: regret matching probabilities")
plt.ylabel("probability")
plt.show()
```
▶ What you'll see: action H receives probability 0.75 because its regret is three times T's.

*Why it's done this way: cumulative positive regret is evidence that an action deserved more play; normalizing it creates a valid mixed strategy while preserving that evidence ratio.*

### 3. Average strategy, not last strategy, is the equilibrium signal

In games such as Rock-Paper-Scissors (RPS), current regret-matching probabilities may keep moving because each player adapts to the other. The average strategy is the stabilizing object: in two-player zero-sum games, no-regret self-play drives average play toward Nash equilibrium even when current play cycles.

```python
rps_payoff_w = np.array([[0, -1, 1], [1, 0, -1], [-1, 1, 0]], dtype=float)  # row player's payoff.
def rm_w(regrets):
    pos = np.maximum(regrets, 0.0)
    return pos / pos.sum() if pos.sum() > 0 else np.ones(3) / 3
rng_w = np.random.default_rng(1)
reg0_w = np.zeros(3); reg1_w = np.zeros(3)
strat_sum0_w = np.zeros(3); avg_hist_w = []
for t_w in range(3000):
    s0_w, s1_w = rm_w(reg0_w), rm_w(reg1_w)
    a0_w = rng_w.choice(3, p=s0_w); a1_w = rng_w.choice(3, p=s1_w)
    reg0_w += rps_payoff_w[:, a1_w] - rps_payoff_w[a0_w, a1_w]
    reg1_w += (-rps_payoff_w[a0_w, :]) - (-rps_payoff_w[a0_w, a1_w])
    strat_sum0_w += s0_w
    avg_hist_w.append(strat_sum0_w / strat_sum0_w.sum())
avg_hist_w = np.array(avg_hist_w)
print("final average strategy:", np.round(avg_hist_w[-1], 3))
assert np.allclose(avg_hist_w[-1].sum(), 1.0)
plt.figure(figsize=(5, 3))
for k_w, name_w in enumerate(["Rock", "Paper", "Scissors"]):
    plt.plot(avg_hist_w[:, k_w], label=name_w)
plt.axhline(1/3, color="black", linestyle="--", linewidth=0.8)
plt.title("3: average RPS strategy approaches uniform")
plt.xlabel("iteration")
plt.ylabel("average probability")
plt.legend()
plt.show()
```
▶ What you'll see: the average probabilities drift toward one-third each, the Nash strategy for RPS.

*Why it's done this way: regret bounds control time-averaged performance, so average policies are the right object to inspect for equilibrium convergence.*

### 4. Exploitability: measure how much a best response can gain

A policy can look random but still be exploitable if a best response earns positive value against it. For zero-sum games, exploitability tracks how far a strategy profile is from equilibrium: the smaller it gets, the less either player can gain by switching to a best response.

```python
def exploit_profile_w(s0, s1):
    br0 = np.max(rps_payoff_w @ s1)  # row player's best payoff versus column strategy.
    br1 = np.max(-s0 @ rps_payoff_w)  # column player's best payoff versus row strategy.
    return float(br0 + br1)
reg0_w = np.zeros(3); reg1_w = np.zeros(3)
sum0_w = np.zeros(3); sum1_w = np.zeros(3); expl_w = []
rng_w = np.random.default_rng(2)
for t_w in range(1, 2501):
    s0_w, s1_w = rm_w(reg0_w), rm_w(reg1_w)
    a0_w = rng_w.choice(3, p=s0_w); a1_w = rng_w.choice(3, p=s1_w)
    reg0_w += rps_payoff_w[:, a1_w] - rps_payoff_w[a0_w, a1_w]
    reg1_w += (-rps_payoff_w[a0_w, :]) - (-rps_payoff_w[a0_w, a1_w])
    sum0_w += s0_w; sum1_w += s1_w
    if t_w % 25 == 0:
        expl_w.append(exploit_profile_w(sum0_w / sum0_w.sum(), sum1_w / sum1_w.sum()))
print("first exploitability:", round(expl_w[0], 3), "final:", round(expl_w[-1], 3))
assert expl_w[-1] < expl_w[0]
plt.figure(figsize=(5, 3))
plt.plot(np.arange(len(expl_w)) * 25 + 25, expl_w, color="crimson")
plt.title("4: exploitability decreases in self-play")
plt.xlabel("iteration")
plt.ylabel("best-response gain")
plt.show()
```
▶ What you'll see: exploitability trends downward as average strategies become harder to exploit.

*Why it's done this way: payoff curves can hide vulnerability; exploitability directly asks what an optimal opponent could still extract.*

### 5. Counterfactual regret: local regret weighted by reach

CFR applies regret matching separately at each information set. The key local update is counterfactual regret: action value minus node value, multiplied by the opponent/chance reach probability. The reach factor answers "how often would this local mistake matter from the whole game's perspective?"

```python
reach_w = 0.25  # probability that opponent/chance reaches this information set.
action_values_w = np.array([2.0, -1.0])  # counterfactual values of local actions A,B.
strategy_w = np.array([0.5, 0.5])  # current local policy.
node_value_w = float(strategy_w @ action_values_w)  # expected local value under current strategy.
cf_regret_w = reach_w * (action_values_w - node_value_w)  # reach-weighted regret increment.
print("node value:", node_value_w)
print("counterfactual regret increments:", cf_regret_w)
assert np.allclose(cf_regret_w, [0.375, -0.375])
plt.figure(figsize=(4.6, 3))
plt.bar(["A", "B"], cf_regret_w, color=["seagreen", "indianred"])
plt.axhline(0, color="black", linewidth=0.8)
plt.title("5: reach-weighted local regret")
plt.ylabel("counterfactual regret")
plt.show()
```
▶ What you'll see: action A gets positive regret because it beats the node value; B gets the matching negative regret.

*Why it's done this way: CFR turns one enormous strategy problem into many small regret-matching problems whose reach-weighted regrets add up to global control.*

### 6. Kuhn poker: a tiny imperfect-information tree

Kuhn poker has three cards, one private card per player, and a tiny betting tree. It is small enough to implement from scratch but rich enough to show why CFR matters: a player acts without knowing the opponent's card, so a policy is stored by information set such as "I hold Q after a bet," not by full hidden state.

```python
cards_w = np.array([0, 1, 2])  # J,Q,K encoded low to high.
infosets_w = []
for card_w in cards_w:
    for hist_w in ["", "p", "b", "pb"]:
        infosets_w.append(f"{card_w}|{hist_w}")
print("number of local information sets:", len(infosets_w))
print("sample infosets:", infosets_w[:5])
counts_w = [sum(s.startswith(str(c) + "|") for s in infosets_w) for c in cards_w]
plt.figure(figsize=(4.2, 3))
plt.bar(["J", "Q", "K"], counts_w, color="slateblue")
plt.title("6: Kuhn information sets by private card")
plt.ylabel("local decision states")
plt.show()
```
▶ What you'll see: the same betting histories repeat under each private card, creating local decision states.

*Why it's done this way: information sets group states the player cannot distinguish, so regret matching learns one local strategy for each group rather than cheating with hidden-card knowledge.*

### 7. CFR loop: regret matching at every information set

A CFR iteration traverses all card deals, computes action values at every reachable information set, updates counterfactual regrets with opponent reach weights, and accumulates average strategy with the player's own reach weight. The current strategy can fluctuate, but the average information-set strategy becomes the solver output.

```python
ACTIONS_W = ["p", "b"]
terminal_w = {"pp", "bp", "bb", "pbp", "pbb"}
regret_sum_w = {}
strategy_sum_w = {}
def strategy_for_w(info):
    r = regret_sum_w.get(info, np.zeros(2))
    pos = np.maximum(r, 0.0)
    return pos / pos.sum() if pos.sum() > 0 else np.ones(2) / 2
def terminal_utility_w(history, cards, player):
    opponent = 1 - player
    if history == "pp":
        return 1.0 if cards[player] > cards[opponent] else -1.0
    if history in ("bp", "pbp"):
        bettor = 0 if history == "bp" else 1
        return 1.0 if player == bettor else -1.0
    return 2.0 if cards[player] > cards[opponent] else -2.0
def cfr_w(cards, history, p0, p1):
    plays = len(history); player = plays % 2
    if history in terminal_w:
        return terminal_utility_w(history, cards, player)
    info = f"{cards[player]}|{history}"
    regret_sum_w.setdefault(info, np.zeros(2)); strategy_sum_w.setdefault(info, np.zeros(2))
    strat = strategy_for_w(info)
    strategy_sum_w[info] += (p0 if player == 0 else p1) * strat
    util = np.zeros(2)
    for a, label in enumerate(ACTIONS_W):
        nxt = history + label
        util[a] = -cfr_w(cards, nxt, p0 * strat[a], p1) if player == 0 else -cfr_w(cards, nxt, p0, p1 * strat[a])
    node = float(strat @ util)
    reach = p1 if player == 0 else p0
    regret_sum_w[info] += reach * (util - node)
    return node
root_values_w = []
for _ in range(250):
    value = 0.0
    for c0 in range(3):
        for c1 in range(3):
            if c0 != c1:
                value += cfr_w(np.array([c0, c1]), "", 1.0, 1.0)
    root_values_w.append(value / 6.0)
info_w = "2|"  # player holding K at root.
avg_info_w = strategy_sum_w[info_w] / strategy_sum_w[info_w].sum()
print("average root strategy with K [pass, bet]:", np.round(avg_info_w, 3))
assert np.allclose(avg_info_w.sum(), 1.0)
plt.figure(figsize=(5, 3))
plt.plot(root_values_w, color="teal")
plt.title("7: CFR root value stabilizes in Kuhn poker")
plt.xlabel("iteration")
plt.ylabel("average traversed value")
plt.show()
```
▶ What you'll see: repeated tree traversals stabilize the estimated game value and produce local average strategies.

*Why it's done this way: CFR stores and updates small local regret tables, which is the scalable trick behind solving much larger imperfect-information games.*

### ✍️ Toy 1 · External regret compares to fixed actions

Regret asks how much better the best single action would have done in hindsight.

```python
import numpy as np
import matplotlib.pyplot as plt


t1_rng = np.random.default_rng(0)
```

### ✍️ Toy 2 · Regret matching normalizes positive regret

Only positive cumulative regrets receive probability mass.

```python
import numpy as np
```

### ✍️ Toy 7 · One CFR infoset update changes regrets and averages

A CFR visit computes action values, updates opponent-reach-weighted regrets, and adds own-reach-
weighted strategy to the average table.

```python
import numpy as np
import matplotlib.pyplot as plt


t7_rng = np.random.default_rng(0)
t7_actions = np.array(["pass", "bet"])
t7_regret_sum = np.array([0.0, 0.0])
t7_strategy_sum = np.array([0.0, 0.0])
t7_strategy = np.array([0.5, 0.5])
t7_action_values = np.array([1.0, 3.0])
t7_own_reach = 0.25
t7_opp_reach = 0.5
t7_node_value = float(t7_strategy @ t7_action_values)
t7_regret_sum = t7_regret_sum + t7_opp_reach * (t7_action_values - t7_node_value)
t7_strategy_sum = t7_strategy_sum + t7_own_reach * t7_strategy
```

## 🛠️ Setup

```python
import numpy as np  # load NumPy for arrays, regret tables, and deterministic simulations.
import matplotlib.pyplot as plt  # load Matplotlib for all curves, bars, heatmaps, and simplex plots.
np.random.seed(0)  # make notebook-level examples reproducible.

ACTIONS = ["Rock", "Paper", "Scissors"]  # canonical RPS action names.
RPS = np.array([[0, -1, 1], [1, 0, -1], [-1, 1, 0]], dtype=float)  # row-player payoff matrix.

def regret_matching(regrets):  # Convert cumulative regrets into a mixed strategy.
    positive = np.maximum(np.asarray(regrets, dtype=float), 0.0)  # Ignore nonpositive regret.
    total = float(np.sum(positive))  # Measure how much positive regret exists.
    return positive / total if total > 0 else np.ones_like(positive) / len(positive)  # Fall back to uniform.

def rps_exploitability(s0, s1):  # Compute best-response gain for a two-player RPS profile.
    br0 = float(np.max(RPS @ s1))  # Best row-player payoff against column strategy.
    br1 = float(np.max(-s0 @ RPS))  # Best column-player payoff against row strategy.
    return br0 + br1  # Zero at the Nash profile.

def simplex_xy(p):  # Map a 3-action probability vector to 2-D simplex coordinates.
    vertices = np.array([[0.0, 0.0], [1.0, 0.0], [0.5, np.sqrt(3) / 2]])  # Triangle corners.
    return np.asarray(p, dtype=float) @ vertices  # Weighted average of corners.

def run_rps_regret(iterations=1000, seed=0):  # Simulate two regret-matching players in RPS.
    rng = np.random.default_rng(seed)  # Local generator for repeatability.
    reg0 = np.zeros(3); reg1 = np.zeros(3)  # Cumulative regrets for both players.
    sum0 = np.zeros(3); sum1 = np.zeros(3)  # Strategy sums used for average strategies.
    avg0_hist = []; avg1_hist = []; exploit_hist = []  # Diagnostics over time.
    for t in range(1, iterations + 1):  # Repeat online play.
        s0 = regret_matching(reg0); s1 = regret_matching(reg1)  # Current regret-matching policies.
        a0 = rng.choice(3, p=s0); a1 = rng.choice(3, p=s1)  # Sample simultaneous actions.
        reg0 += RPS[:, a1] - RPS[a0, a1]  # Row regret: each action versus actual action.
        reg1 += (-RPS[a0, :]) - (-RPS[a0, a1])  # Column regret under its payoff matrix.
        sum0 += s0; sum1 += s1  # Accumulate current strategies for averaging.
        avg0 = sum0 / np.sum(sum0); avg1 = sum1 / np.sum(sum1)  # Average strategies so far.
        avg0_hist.append(avg0.copy()); avg1_hist.append(avg1.copy())  # Store trajectory.
        exploit_hist.append(rps_exploitability(avg0, avg1))  # Store exploitability of averages.
    return np.array(avg0_hist), np.array(avg1_hist), np.array(exploit_hist), reg0, reg1  # Return diagnostics.

KUHN_ACTIONS = ["p", "b"]  # pass/check or bet/call depending on history.
KUHN_TERMINALS = {"pp", "bp", "bb", "pbp", "pbb"}  # terminal histories in this compact game.

def kuhn_terminal_utility(history, cards, player):  # Utility for the player to act at a terminal node.
    opponent = 1 - player  # Identify the other player.
    if history == "pp":  # Both checked; high card wins one chip.
        return 1.0 if cards[player] > cards[opponent] else -1.0
    if history in ("bp", "pbp"):  # Someone bet and the other folded.
        bettor = 0 if history == "bp" else 1  # Determine who made the unreplied bet.
        return 1.0 if player == bettor else -1.0
    return 2.0 if cards[player] > cards[opponent] else -2.0  # Called bet; showdown is worth two chips.

def train_kuhn_cfr(iterations=500, checkpoint=10):  # Train a minimal tabular CFR solver for Kuhn poker.
    regrets = {}; strategy_sums = {}; values = []; tracked = []  # Tables and diagnostics.
    def strategy(info):  # Regret matching at one information set.
        r = regrets.get(info, np.zeros(2))  # Missing infosets start at zero regret.
        return regret_matching(r)  # Use the shared helper.
    def cfr(cards, history, p0, p1):  # Recursive CFR traversal returning current-player value.
        plays = len(history); player = plays % 2  # Alternate players by history length.
        if history in KUHN_TERMINALS:  # Stop at terminal histories.
            return kuhn_terminal_utility(history, cards, player)  # Return terminal payoff.
        info = f"{cards[player]}|{history}"  # Information set: private card plus public history.
        regrets.setdefault(info, np.zeros(2)); strategy_sums.setdefault(info, np.zeros(2))  # Ensure tables exist.
        strat = strategy(info)  # Current local strategy from regret matching.
        strategy_sums[info] += (p0 if player == 0 else p1) * strat  # Average-strategy update with own reach.
        util = np.zeros(2)  # Action values at this information set.
        for a, label in enumerate(KUHN_ACTIONS):  # Try pass/check and bet/call.
            nxt = history + label  # Extend public history.
            util[a] = -cfr(cards, nxt, p0 * strat[a], p1) if player == 0 else -cfr(cards, nxt, p0, p1 * strat[a])  # Opponent's value negated.
        node_value = float(strat @ util)  # Expected value under current local strategy.
        reach = p1 if player == 0 else p0  # Counterfactual opponent reach weight.
        regrets[info] += reach * (util - node_value)  # Local counterfactual regret update.
        return node_value  # Return value to parent.
    for it in range(1, iterations + 1):  # Run repeated full-tree traversals.
        value = 0.0  # Expected root value over card deals.
        for c0 in range(3):  # Player 0 private card.
            for c1 in range(3):  # Player 1 private card.
                if c0 != c1:  # Deal without replacement.
                    value += cfr(np.array([c0, c1]), "", 1.0, 1.0)  # Traverse this deal.
        values.append(value / 6.0)  # Average over six ordered deals.
        if it % checkpoint == 0:  # Record a tracked average strategy periodically.
            info = "2|"  # Holding K at the root.
            ss = strategy_sums.get(info, np.ones(2))  # Guard for early iterations.
            tracked.append(ss / np.sum(ss))  # Average pass/bet probabilities.
    return regrets, strategy_sums, np.array(values), np.array(tracked)  # Return tables and diagnostics.
```

#### A1. Compare regret matching with last-round chasing

**Goal.** Contrast cumulative regret with a naive last-round rule, because chasing the latest winner overreacts to noise. We build it in 1 step.

```python
rng_a1 = np.random.default_rng(21)  # Local randomness for the opponent sequence.
opp_a1 = rng_a1.integers(0, 3, size=400)  # Generate an adaptive-looking opponent sequence.
reg_a1 = np.zeros(3); cum_pay_a1 = []; chase_pay_a1 = []  # Store regrets and payoff traces.
rm_action_a1 = 0; chase_action_a1 = 0  # Initialize both learners.
last_best_a1 = 0  # Last-round chaser's next action.
for t_a1, o_a1 in enumerate(opp_a1):  # Process rounds.
    probs_a1 = regret_matching(reg_a1)  # Cumulative-regret policy.
    rm_action_a1 = rng_a1.choice(3, p=probs_a1)  # Sample regret-matching action.
    chase_action_a1 = last_best_a1  # Chaser plays previous round's best response.
    cum_pay_a1.append(RPS[rm_action_a1, o_a1])  # Store regret-matcher payoff.
    chase_pay_a1.append(RPS[chase_action_a1, o_a1])  # Store chaser payoff.
    reg_a1 += RPS[:, o_a1] - RPS[rm_action_a1, o_a1]  # Update cumulative regret.
    last_best_a1 = int(np.argmax(RPS[:, o_a1]))  # Set next action to this round's best response.
rm_cum_a1 = np.cumsum(cum_pay_a1); chase_cum_a1 = np.cumsum(chase_pay_a1)  # Cumulative payoff curves.
print("final regret-matching payoff:", rm_cum_a1[-1], "last-round payoff:", chase_cum_a1[-1])  # Inspect totals.
assert len(rm_cum_a1) == len(chase_cum_a1) == 400  # Verify traces align.
plt.figure(figsize=(5, 3))  # Create a payoff comparison plot.
plt.plot(rm_cum_a1, label="cumulative regret matching", color="teal")  # Plot regret matcher.
plt.plot(chase_cum_a1, label="last-round chaser", color="crimson", alpha=0.8)  # Plot naive chaser.
plt.title("A1: cumulative regret vs last-round chasing")  # Title the plot.
plt.xlabel("round")  # Label round axis.
plt.ylabel("cumulative payoff")  # Label payoff.
plt.legend()  # Show labels.
plt.show()  # Display the curves.
```
▶ What you'll see: the cumulative-regret learner is smoother, while the last-round chaser can swing badly.

👀 Takeaway: regret matching accumulates evidence so it does not overreact to one fresh outcome.

#### A3. Show why counterfactual reach weights matter

**Goal.** Compare weighted and unweighted local regrets, because rare information sets should not be scaled like common ones. We build it in 1 step.

```python
reaches_a3 = np.array([1.0, 0.25, 0.05])  # Common, occasional, and rare information-set reach probabilities.
action_values_a3 = np.array([2.0, -1.0])  # Same local action values at each information set.
strategy_a3 = np.array([0.5, 0.5])  # Same local policy.
node_a3 = float(strategy_a3 @ action_values_a3)  # Local node value.
weighted_a3 = np.array([reach_a3 * (action_values_a3[0] - node_a3) for reach_a3 in reaches_a3])  # CFR-scaled regret for action A.
unweighted_a3 = np.repeat(action_values_a3[0] - node_a3, len(reaches_a3))  # Incorrect unweighted regret.
print("weighted regrets:", weighted_a3, "unweighted:", unweighted_a3)  # Inspect scaling difference.
assert weighted_a3[-1] < weighted_a3[0]  # Verify rare state receives smaller update.
x_a3 = np.arange(len(reaches_a3))  # Grouped-bar positions.
plt.figure(figsize=(5, 3))  # Create a weighting comparison plot.
plt.bar(x_a3 - 0.18, weighted_a3, width=0.36, label="CFR weighted", color="seagreen")  # Plot reach-weighted regrets.
plt.bar(x_a3 + 0.18, unweighted_a3, width=0.36, label="unweighted", color="crimson")  # Plot incorrect equal regrets.

plt.ylabel("action-A regret increment")  # Label regret increment.

```
▶ What you'll see: reach weighting shrinks updates for information sets that rarely matter globally.

👀 Takeaway: dropping reach weights mis-scales local mistakes in CFR.
