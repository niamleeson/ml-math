# 5.14 — Gaussian Processes

Gaussian Processes (GPs) are Bayesian regression models that put a probability distribution directly on functions. Instead of choosing a fixed feature map and learning only weights, we choose a kernel that says which input points should move together; conditioning that prior on data gives a posterior mean for prediction and posterior variance for calibrated uncertainty.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build Gaussian Processes one idea at a time. Run each cell in order and read the printed intermediate values — the kernel matrix, samples, posterior mean, posterior variance, length-scale behavior, and computational cost are all exposed. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, covariance matrices, random draws, and linear solves.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for sampled functions.
```

### 1. A Gaussian Process is a distribution over function values

A Gaussian Process says that any finite list of function values is jointly Gaussian. To use that statement on a computer, we choose input locations, build a covariance matrix between them, and sample a vector of possible function values. The vector is not independent noise: nearby inputs are correlated, so the sampled curve bends smoothly.

```python
X_w = np.linspace(-3, 3, 9)[:, None]  # nine input locations as a column vector.
dists_w = X_w - X_w.T  # all pairwise signed distances.
K_w = np.exp(-0.5 * (dists_w / 1.0) ** 2)  # RBF covariance with length-scale 1.
print("X shape:", X_w.shape, "K shape:", K_w.shape)  # inspect finite GP objects.
print("K first row:", np.round(K_w[0], 3))  # covariance of the leftmost input with all inputs.
```
▶ What you'll see: covariance is 1 with itself and fades toward 0 for distant inputs.

```python
L_w = np.linalg.cholesky(K_w + 1e-9 * np.eye(len(X_w)))  # stable square root of covariance.
z_w = np.random.normal(size=(len(X_w), 3))  # three independent standard-normal vectors.
f_samples_w = L_w @ z_w  # correlated function values with covariance K.
print("sample matrix shape:", f_samples_w.shape)  # one column is one sampled function.
```
▶ What you'll see: three vectors of function values, all sharing the smoothness encoded by K.

```python
plt.figure(figsize=(5, 3))
for j_w in range(3):
    plt.plot(X_w.ravel(), f_samples_w[:, j_w], marker="o", label=f"sample {j_w}")
plt.axhline(0, color="black", linewidth=0.7)
plt.title("1: GP prior samples are functions")
plt.xlabel("x"); plt.ylabel("f(x)"); plt.legend(); plt.show()
```
▶ What you'll see: each line is a different possible function drawn before seeing any data.

*Why it's done this way:* a GP is infinite in principle, but every computation reduces to a finite multivariate normal on the inputs we ask about. The Cholesky factor turns independent Gaussian noise into correlated Gaussian values because if `f = Lz`, then `cov(f)=L I Lᵀ=K`.

### 2. The kernel is the prior over smoothness

The RBF kernel is $$k(x,x')=\exp\left(-\frac{(x-x')^2}{2\ell^2}\right).$$ It gives covariance 1 at zero distance, small covariance far away, and a length-scale $\ell$ that controls how quickly similarity decays. This is the main modeling decision: we specify similarity geometry instead of hand-picking basis functions.

```python
distance_w = 2.0
ell_w = 1.0
cov_w = np.exp(-0.5 * (distance_w / ell_w) ** 2)
print("RBF covariance at distance 2:", round(cov_w, 6))
assert round(cov_w, 6) == 0.135335
```
▶ What you'll see: distance 2 has covariance 0.135335 when the length-scale is 1.

```python
dist_grid_w = np.linspace(0, 4, 80)
ells_w = np.array([0.4, 1.0, 2.0])
curves_w = [np.exp(-0.5 * (dist_grid_w / ell) ** 2) for ell in ells_w]
print("correlation at distance 1:", [round(float(np.exp(-0.5 * (1 / ell) ** 2)), 3) for ell in ells_w])
```
▶ What you'll see: correlation at distance 1 increases as length-scale moves from 0.4 to 2.0.

```python
plt.figure(figsize=(5, 3))
for ell, curve in zip(ells_w, curves_w):
    plt.plot(dist_grid_w, curve, label=f"ell={ell}")
plt.title("2: length-scale controls covariance decay")
plt.xlabel("distance |x-x'|"); plt.ylabel("k(x,x')"); plt.legend(); plt.show()
```
▶ What you'll see: short length-scales drop sharply; long length-scales keep far points tied together.

*Why it's done this way:* covariance is the language of a Gaussian prior. Larger kernel entries mean two function values are expected to move together; smaller entries mean the data can pull them apart. The squared distance and exponential make a smooth, positive-definite similarity matrix suitable for Gaussian conditioning.

### 3. Conditioning turns the prior into a posterior mean

After observing noisy targets $y$, the GP prediction at test inputs uses the Gaussian conditioning formula $$\mu_*=K_{*X}(K_{XX}+\sigma^2I)^{-1}y.$$ The term $K_{XX}+\sigma^2I$ says training observations are noisy; the cross-covariance $K_{*X}$ says how much each test point trusts each training point.

```python
X_train_w = np.array([-1.5, 0.0, 1.5])[:, None]
y_train_w = np.array([-1.0, 0.2, 1.1])
X_test_w = np.linspace(-3, 3, 80)[:, None]
noise_w = 0.1
K_xx_w = np.exp(-0.5 * ((X_train_w - X_train_w.T) / 1.0) ** 2)
K_tx_w = np.exp(-0.5 * ((X_test_w - X_train_w.T) / 1.0) ** 2)
print("K_xx:\n", np.round(K_xx_w, 3))
```
▶ What you'll see: the training covariance matrix has 1s on the diagonal and smaller off-diagonal similarities.

```python
alpha_w = np.linalg.solve(K_xx_w + noise_w * np.eye(len(X_train_w)), y_train_w)
mean_w = K_tx_w @ alpha_w
print("alpha weights:", np.round(alpha_w, 3))
print("posterior mean at x=0:", round(float(mean_w[np.argmin(np.abs(X_test_w.ravel()))]), 3))
assert mean_w.shape == (80,)
```
▶ What you'll see: the mean curve is a weighted combination of kernel bumps centered on observed data.

```python
plt.figure(figsize=(5, 3))
plt.plot(X_test_w.ravel(), mean_w, color="teal", label="posterior mean")
plt.scatter(X_train_w.ravel(), y_train_w, color="black", zorder=3, label="observed y")
plt.title("3: GP posterior mean")
plt.xlabel("x"); plt.ylabel("f(x)"); plt.legend(); plt.show()
```
▶ What you'll see: the mean passes near the observations and relaxes toward 0 away from them.

*Why it's done this way:* the solve computes how training evidence should be weighted after accounting for correlations among training points. We solve a linear system instead of inverting a matrix because it is numerically safer and represents the same formula.

### 4. Posterior variance is prior uncertainty minus explained covariance

A GP gives uncertainty, not just a fitted line. The posterior covariance is $$K_{**}-K_{*X}(K_{XX}+\sigma^2I)^{-1}K_{X*}.$$ The subtraction is the part of prior variance explained by nearby observations; far from data, little covariance is explained and the variance rises toward the prior variance.

```python
K_tt_diag_w = np.ones(len(X_test_w))  # RBF prior variance k(x,x)=1 at every test point.
v_w = np.linalg.solve(K_xx_w + noise_w * np.eye(len(X_train_w)), K_tx_w.T)
var_w = K_tt_diag_w - np.sum(K_tx_w * v_w.T, axis=1)
var_w = np.maximum(var_w, 0.0)
print("variance min/max:", round(float(var_w.min()), 3), round(float(var_w.max()), 3))
assert float(var_w.min()) < float(var_w.max())
```
▶ What you'll see: variance is smallest near training inputs and largest near the edges.

```python
std_w = np.sqrt(var_w)
plt.figure(figsize=(5, 3))
plt.plot(X_test_w.ravel(), mean_w, color="teal", label="mean")
plt.fill_between(X_test_w.ravel(), mean_w - 2 * std_w, mean_w + 2 * std_w, color="teal", alpha=0.2, label="±2 std")
plt.scatter(X_train_w.ravel(), y_train_w, color="black", zorder=3)
plt.title("4: posterior uncertainty expands away from data")
plt.xlabel("x"); plt.ylabel("f(x)"); plt.legend(); plt.show()
```
▶ What you'll see: the confidence band pinches near observations and widens between/away from them.

*Why it's done this way:* conditioning removes uncertainty only in directions correlated with the observed data. The term being subtracted is an explained-covariance term, so posterior variance reflects geometry and noise, not just residual error.

### 5. Observation noise controls interpolation versus smoothing

The noise variance $\sigma^2$ is added to the training covariance diagonal. Small noise says observations are nearly exact, so the posterior mean hugs them. Larger noise says observations are fallible, so the model smooths more and keeps more uncertainty near data.

```python
noise_grid_w = np.array([0.01, 0.1, 0.5])
means_noise_w = []
for sig2_w in noise_grid_w:
    alpha_noise_w = np.linalg.solve(K_xx_w + sig2_w * np.eye(len(X_train_w)), y_train_w)
    means_noise_w.append(K_tx_w @ alpha_noise_w)
print("mean at first training x:", [round(float(m[np.argmin(abs(X_test_w.ravel() + 1.5))]), 3) for m in means_noise_w])
```
▶ What you'll see: larger noise pulls the mean less aggressively through the observed point.

```python
plt.figure(figsize=(5, 3))
for sig2_w, m_w in zip(noise_grid_w, means_noise_w):
    plt.plot(X_test_w.ravel(), m_w, label=f"noise={sig2_w}")
plt.scatter(X_train_w.ravel(), y_train_w, color="black", zorder=3)
plt.title("5: noise smooths the posterior mean")
plt.xlabel("x"); plt.ylabel("posterior mean"); plt.legend(); plt.show()
```
▶ What you'll see: low noise nearly interpolates; high noise produces a gentler curve.

*Why it's done this way:* adding noise to the diagonal says each observed target has independent measurement error. Mathematically it prevents the solve from treating every target as a hard constraint; statistically it separates latent function uncertainty from observation noise.

### 6. Exact GP cost comes from dense linear algebra

Exact GP regression builds and solves with an $n\times n$ covariance matrix. Storage grows like $n^2$, and Cholesky factorization grows roughly like $n^3$. That cubic cost is the main reason large-scale GP systems use approximations, inducing points, structured kernels, or local methods.

```python
sizes_w = np.array([50, 100, 200, 400])
storage_w = sizes_w ** 2
relative_chol_w = (sizes_w / sizes_w[0]) ** 3
print("matrix entries:", storage_w)
print("relative cubic cost:", relative_chol_w.astype(int))
assert relative_chol_w[-1] == 512
```
▶ What you'll see: doubling n quadruples matrix entries and increases cubic work by 8×.

```python
plt.figure(figsize=(5, 3))
plt.plot(sizes_w, relative_chol_w, marker="o", color="crimson")
plt.title("6: exact GP solves scale cubically")
plt.xlabel("training points n"); plt.ylabel("relative n³ cost"); plt.show()
```
▶ What you'll see: cost rises steeply as the training set grows.

*Why it's done this way:* Gaussian conditioning is exact but dense: every point can covary with every other point. The kernel buys flexible nonparametric uncertainty, while the dense solve is the computational bill for that flexibility.

### Basic 1 — Compute one RBF covariance

**Goal.** Turn a distance into a covariance, because the kernel is the GP prior's basic building block. We build it in 2 steps.

```python
distance_b1 = 2.0 # choose two inputs separated by two units.
ell_b1 = 1.0 # choose the length-scale used in the lesson arithmetic.
print("distance:", distance_b1, "length-scale:", ell_b1) # inspect the kernel inputs.
```

```python
cov_b1 = np.exp(-0.5 * (distance_b1 / ell_b1) ** 2) # compute exp(-d^2/(2 ell^2)).
print("RBF covariance:", round(cov_b1, 6)) # inspect the worked covariance value.
assert round(cov_b1, 6) == 0.135335 # verify the lesson arithmetic e^-2.
plt.figure(figsize=(4, 3)) # create a compact diagnostic plot.
plt.bar(["k(d=2)"], [cov_b1], color="teal") # show the single covariance value.
plt.ylim(0, 1) # covariance lives between 0 and 1 for this kernel.
plt.title("Basic 1: one RBF covariance") # title the plot.
plt.show() # display the figure.
```
▶ What you'll see: the covariance is much smaller than 1 because the points are two length-scales apart.

👀 Takeaway: RBF covariance decays exponentially with squared distance.

### Basic 2 — Build a covariance matrix

**Goal.** Compute all pairwise covariances for a small input grid, because a finite GP is a multivariate Gaussian with covariance K. We build it in 2 steps.

```python
X_b2 = np.array([-1.0, 0.0, 1.0])[:, None] # define three one-dimensional inputs.
diff_b2 = X_b2 - X_b2.T # compute every pairwise signed distance.
print("pairwise differences:\n", diff_b2) # inspect the geometry before applying the kernel.
```

```python
K_b2 = np.exp(-0.5 * diff_b2 ** 2) # apply the RBF kernel with ell=1.
print("K:\n", np.round(K_b2, 3)) # inspect the covariance matrix.
assert np.allclose(np.diag(K_b2), 1.0) # verify every point has prior variance 1.
plt.figure(figsize=(4, 3)) # create a heatmap figure.
plt.imshow(K_b2, cmap="viridis", vmin=0, vmax=1) # visualize covariance strength.
plt.colorbar(label="covariance") # add a value scale.
plt.title("Basic 2: covariance matrix K") # title the heatmap.
plt.show() # display the matrix.
```
▶ What you'll see: diagonal entries are 1 and off-diagonal entries shrink with distance.

👀 Takeaway: the kernel matrix is the finite object that lets a GP run on actual inputs.

### Basic 6 — Solve for GP weights

**Goal.** Compute α = (K + σ²I)⁻¹y, because posterior means use these weights to combine kernel similarities. We build it in 2 steps.

```python
K_b6 = np.array([[1.0, 0.2], [0.2, 1.0]]) # define covariance between two training inputs.
y_b6 = np.array([1.0, -1.0]) # define two observed targets.
noise_b6 = 0.1 # define observation-noise variance.
print("system matrix:\n", K_b6 + noise_b6 * np.eye(2)) # inspect the linear system.
```

```python
alpha_b6 = np.linalg.solve(K_b6 + noise_b6 * np.eye(2), y_b6) # solve the GP conditioning weights.
print("alpha:", np.round(alpha_b6, 3)) # inspect the evidence weights.
assert np.allclose(np.round(alpha_b6, 3), np.array([1.111, -1.111])) # verify the symmetric solve.
plt.figure(figsize=(4, 3)) # create a compact bar chart.
plt.bar(["α0", "α1"], alpha_b6, color="slateblue") # show positive and negative evidence weights.
plt.axhline(0, color="black", linewidth=0.7) # add zero line.
plt.title("Basic 6: GP linear-solve weights") # title the plot.
plt.show() # display the figure.
```
▶ What you'll see: symmetric opposite targets produce symmetric opposite weights.

👀 Takeaway: GP prediction is kernel-weighted evidence after correcting for correlations among training points.

### Basic 7 — Predict one test mean

**Goal.** Apply μ* = k*X α at a single test point, because posterior prediction is a cross-covariance weighted sum. We build it in 2 steps.

```python
x_train_b7 = np.array([-1.0, 1.0])[:, None] # define two training inputs.
y_b7 = np.array([1.0, -1.0]) # define opposing targets.
x_star_b7 = np.array([[0.0]]) # choose a test input halfway between them.
K_b7 = np.exp(-0.5 * (x_train_b7 - x_train_b7.T) ** 2) # training covariance.
alpha_b7 = np.linalg.solve(K_b7 + 0.1 * np.eye(2), y_b7) # conditioning weights.
print("alpha:", np.round(alpha_b7, 3)) # inspect weights before prediction.
```

```python
k_star_b7 = np.exp(-0.5 * (x_star_b7 - x_train_b7.T) ** 2).ravel() # covariances from test point to training points.
mean_star_b7 = float(k_star_b7 @ alpha_b7) # compute posterior mean at the test point.
print("k_star:", np.round(k_star_b7, 3), "mean:", round(mean_star_b7, 3)) # inspect the weighted sum.
assert round(mean_star_b7, 3) == 0.0 # symmetry cancels the mean at the center.
plt.figure(figsize=(4, 3)) # create a tiny prediction plot.
plt.scatter(x_train_b7.ravel(), y_b7, color="black", label="train") # show observations.
plt.scatter([0], [mean_star_b7], color="teal", label="test mean") # show prediction.
plt.legend(); plt.title("Basic 7: one posterior mean"); plt.show() # display.
```
▶ What you'll see: the centered test point has equal similarity to opposite targets, so its mean is 0.

👀 Takeaway: posterior means average evidence according to kernel geometry.

### Basic 8 — Compute one posterior variance

**Goal.** Compute prior variance minus explained variance, because GP uncertainty falls when a test point is correlated with data. We build it in 2 steps.

```python
K_b8 = np.array([[1.0]]) # one training point with unit prior variance.
noise_b8 = 0.1 # observation-noise variance.
k_star_b8 = np.array([1.0]) # test at the same location as the training point.
prior_var_b8 = 1.0 # RBF prior variance at any point.
print("prior variance:", prior_var_b8) # inspect the starting uncertainty.
```

```python
explained_b8 = float(k_star_b8 @ np.linalg.solve(K_b8 + noise_b8 * np.eye(1), k_star_b8)) # compute explained covariance.
post_var_b8 = prior_var_b8 - explained_b8 # subtract explained covariance from prior variance.
print("explained:", round(explained_b8, 3), "posterior variance:", round(post_var_b8, 3)) # inspect uncertainty drop.
assert round(post_var_b8, 3) == 0.091 # verify 1 - 1/1.1.
plt.figure(figsize=(4, 3)) # create a variance comparison plot.
plt.bar(["prior", "posterior"], [prior_var_b8, post_var_b8], color=["gray", "teal"]) # compare uncertainty before and after data.
plt.title("Basic 8: variance after observing nearby data") # title the plot.
plt.show() # display the figure.
```
▶ What you'll see: observing a noisy point sharply reduces, but does not eliminate, uncertainty there.

👀 Takeaway: posterior variance is smaller where observations explain the function value.

### Basic 9 — Draw a posterior uncertainty band

**Goal.** Plot mean ±2 standard deviations, because GP regression communicates uncertainty visually as well as numerically. We build it in 3 steps.

```python
x_b9 = np.linspace(-3, 3, 60)[:, None] # define test inputs.
train_x_b9 = np.array([-1.0, 1.0])[:, None] # define two training inputs.
train_y_b9 = np.array([1.0, -0.5]) # define observed targets.
K_b9 = np.exp(-0.5 * (train_x_b9 - train_x_b9.T) ** 2) # training covariance.
Kxs_b9 = np.exp(-0.5 * (x_b9 - train_x_b9.T) ** 2) # test-to-train covariance.
print("test points:", len(x_b9)) # inspect grid size.
```

```python
A_b9 = K_b9 + 0.1 * np.eye(2) # noisy training covariance.
mean_b9 = Kxs_b9 @ np.linalg.solve(A_b9, train_y_b9) # posterior mean.
V_b9 = np.linalg.solve(A_b9, Kxs_b9.T) # helper for posterior variance.
var_b9 = 1.0 - np.sum(Kxs_b9 * V_b9.T, axis=1) # diagonal posterior variance.
std_b9 = np.sqrt(np.maximum(var_b9, 0.0)) # numerical guard before square root.
print("std range:", round(float(std_b9.min()), 3), round(float(std_b9.max()), 3)) # inspect uncertainty range.
```

```python
plt.figure(figsize=(5, 3)) # create an uncertainty-band plot.
plt.plot(x_b9.ravel(), mean_b9, color="teal", label="mean") # draw posterior mean.
plt.fill_between(x_b9.ravel(), mean_b9 - 2 * std_b9, mean_b9 + 2 * std_b9, color="teal", alpha=0.2, label="±2 std") # draw band.
plt.scatter(train_x_b9.ravel(), train_y_b9, color="black", zorder=3) # show data.
plt.title("Basic 9: GP uncertainty band") # title the plot.
plt.legend(); plt.show() # display.
```
▶ What you'll see: the band is narrow near training points and wider far away.

👀 Takeaway: GP predictions are distributions, so the uncertainty band is part of the answer.

### Basic 10 — Inspect length-scale smoothness

**Goal.** Sample with two length-scales, because ℓ directly sets how wiggly prior functions are allowed to be. We build it in 3 steps.

```python
X_b10 = np.linspace(-3, 3, 80)[:, None] # choose a dense grid for visual smoothness.
ells_b10 = [0.4, 1.5] # compare short and long length-scales.
```

```python
samples_b10 = [] # store one sample per length-scale.

    K_b10 = np.exp(-0.5 * ((X_b10 - X_b10.T) / ell_b10) ** 2) # build covariance for this ell.
```

