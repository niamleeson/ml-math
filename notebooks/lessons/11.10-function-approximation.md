# 11.10 — Function Approximation

Function approximation lets an RL agent estimate values for many states without storing one table entry per state. In this lesson, we build linear value-function approximation from raw NumPy arrays, then use semi-gradient TD to update weights from bootstrapped targets while watching why bootstrapping, off-policy learning, and approximation can become unstable.

Before the terse worked examples, we build function approximation one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including the semi-gradient TD update and the deadly triad, is spelled out so nothing is a black box. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, dot products, and small RL simulations.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
```

### 1. Replace a value table with features and weights

A tabular value function stores one independent number per state. Function approximation instead describes each state by a feature vector $\phi(s)$ and predicts with a shared rule $\hat V(s;w)=\phi(s)^\top w$. The same weight vector is reused everywhere, so changing one weight changes every state whose feature uses that weight.

```python
states_w = np.arange(6)  # six positions on a tiny line world.
features_w = np.column_stack([np.ones_like(states_w), states_w / 5])  # bias plus normalized position.
w_w = np.array([0.2, 1.4])  # shared intercept and slope.
values_w = features_w @ w_w  # linear value approximation for every state.
print("features:\n", np.round(features_w, 2))  # inspect phi(s).
print("predicted values:", np.round(values_w, 3))  # inspect V_hat(s).
assert np.allclose(np.round(values_w[[0, 5]], 3), [0.2, 1.6])
```
▶ What you'll see: each state becomes two numbers, and the last state is predicted as `0.2 + 1.4 = 1.6`.

```python
plt.figure(figsize=(4.6, 3))
plt.plot(states_w, values_w, marker="o", color="teal")
plt.title("1: V̂(s)=φ(s)ᵀw shares one line across states")
plt.xlabel("state index")
plt.ylabel("estimated value")
plt.show()
```
▶ What you'll see: a straight value line; there is no separate free parameter for each state.

*Why it's done this way:* a table with six states has six independent values, but this two-feature model has only two parameters. The compression is the generalization mechanism: nearby states share similar features, so evidence from one state updates the line and influences nearby predictions.

### 2. Discounted return is the target when you wait for the future

A complete Monte Carlo target adds rewards across time with powers of $\gamma$: $G_t=r_{t+1}+\gamma r_{t+2}+\gamma^2 r_{t+3}+\cdots$. Discounting keeps delayed rewards meaningful but smaller, which is how RL represents consequence without treating far-future rewards as equally certain.

```python
rewards_w = np.array([1.0, 0.0, 2.0])  # immediate reward, then no reward, then delayed payoff.
gamma_w = 0.9  # future rewards count, but less than immediate rewards.
discounts_w = gamma_w ** np.arange(len(rewards_w))  # 1, gamma, gamma^2.
terms_w = discounts_w * rewards_w  # contribution of each reward to return.
print("discounted terms:", np.round(terms_w, 3))
print("return G:", round(float(terms_w.sum()), 3))
assert round(float(terms_w.sum()), 3) == 2.62
```
▶ What you'll see: the reward two steps away contributes `0.9²·2 = 1.62`, so the total return is `2.62`.

```python
plt.figure(figsize=(4.6, 3))
plt.bar(["r1", "γ r2", "γ² r3"], terms_w, color="darkorange")
plt.title("2: discounted pieces of a return")
plt.ylabel("contribution to G")
plt.show()
```
▶ What you'll see: the delayed reward still dominates here, but discounting trims it from 2.0 to 1.62.

*Why it's done this way:* waiting for a full return gives an unbiased sample of long-run consequence under the current policy, but it can have high variance because every future random transition and reward enters the target.

### 3. Bootstrap with a one-step TD target

Temporal-difference learning does not wait until the episode ends. It builds the target $y=r+\gamma\hat V(s';w)$ from the observed reward plus the learner's current estimate of the next state's value. The tabular update moves toward that target by a step size $\alpha$.

```python
reward_w = 1.0  # observed one-step reward.
next_value_w = 0.8  # current estimate V_hat(s').
old_value_w = 0.4  # current estimate V_hat(s).
alpha_w = 0.5  # move halfway toward the target.
td_target_w = reward_w + gamma_w * next_value_w  # one-step bootstrap target.
td_error_w = td_target_w - old_value_w  # target minus current estimate.
new_value_w = old_value_w + alpha_w * td_error_w  # TD(0) table update.
print("target:", round(td_target_w, 3), "TD error:", round(td_error_w, 3))
print("updated value:", round(new_value_w, 3))
assert round(td_target_w, 3) == 1.72 and round(new_value_w, 3) == 1.06
```
▶ What you'll see: the target is `1.720`, the old value is `0.400`, and a half-step lands at `1.060`.

```python
plt.figure(figsize=(4.6, 3))
plt.bar(["old V", "target y", "new V"], [old_value_w, td_target_w, new_value_w], color=["gray", "black", "seagreen"])
plt.title("3: TD moves partway toward a bootstrap target")
plt.ylabel("value")
plt.show()
```
▶ What you'll see: the new value sits between the old estimate and the bootstrap target.

*Why it's done this way:* bootstrapping lowers variance and learns online, but the target contains the model's own estimate. That makes TD efficient and also makes the target move as the weights move.

### 4. Semi-gradient TD updates the weights, not just one state

For linear approximation, $\hat V(s;w)=\phi(s)^\top w$. The squared TD error target depends on $w$ through $\hat V(s';w)$ too, but semi-gradient TD treats the target as fixed for the current step and differentiates only the current prediction. The update is $w\leftarrow w+\alpha\delta\phi(s)$ where $\delta=r+\gamma\hat V(s';w)-\hat V(s;w)$.

```python
phi_s_w = np.array([1.0, 0.4])  # current state's features.
phi_next_w = np.array([1.0, 0.6])  # next state's features.
w_td_w = np.array([0.2, 1.0])  # current linear value weights.
value_s_w = float(phi_s_w @ w_td_w)  # V_hat(s).
value_next_w = float(phi_next_w @ w_td_w)  # V_hat(s').
delta_w = 0.72 + 0.9 * value_next_w - value_s_w  # TD error.
print("V(s):", round(value_s_w, 3), "V(s'):", round(value_next_w, 3), "delta:", round(delta_w, 3))
assert round(delta_w, 3) == 0.84
```
▶ What you'll see: the TD error is positive, so the current state's prediction should increase.

```python
alpha_td_w = 0.1  # semi-gradient step size.
w_new_td_w = w_td_w + alpha_td_w * delta_w * phi_s_w  # update only along current features.
print("old weights:", np.round(w_td_w, 3))
print("new weights:", np.round(w_new_td_w, 3))
assert np.allclose(np.round(w_new_td_w, 3), [0.284, 1.034])
```
▶ What you'll see: both the bias and slope move, with the slope moving less because the current feature value is 0.4.

```python
states2_w = np.linspace(0, 1, 6)
Phi2_w = np.column_stack([np.ones_like(states2_w), states2_w])
plt.figure(figsize=(4.6, 3))
plt.plot(states2_w, Phi2_w @ w_td_w, "o--", label="before")
plt.plot(states2_w, Phi2_w @ w_new_td_w, "o-", label="after")
plt.title("4: one TD step changes many states")
plt.xlabel("normalized state")
plt.ylabel("V̂")
plt.legend()
plt.show()
```
▶ What you'll see: the whole value line shifts, not only the sampled state.

*Why it's done this way:* the true gradient through the bootstrap target would include how the next-state estimate changes, but TD deliberately ignores that dependence. This semi-gradient is simple, online, and often works well, but it is not gradient descent on a fixed supervised loss.

### 5. Policy weighting and exploration change which data arrives

Function approximation in RL is not passive prediction: the policy decides which states and actions generate future data. A softmax policy turns logits into action probabilities, while an exploration bonus can temporarily favor uncertain actions even when their empirical mean is lower.

```python
logits_w = np.array([1.0, 0.0])  # preference scores for two actions.
exp_w = np.exp(logits_w - np.max(logits_w))  # stable softmax numerator.
probs_w = exp_w / exp_w.sum()  # policy probabilities.
action_rewards_w = np.array([2.0, 0.0])  # immediate rewards for the two actions.
expected_reward_w = float(probs_w @ action_rewards_w)  # policy-weighted expectation.
print("softmax probabilities:", np.round(probs_w, 3))
print("expected reward:", round(expected_reward_w, 3))
assert np.allclose(np.round(probs_w, 3), [0.731, 0.269])
assert round(expected_reward_w, 3) == 1.462
```
▶ What you'll see: action 0 gets about 73.1% probability, producing expected reward 1.462.

```python
mean_w, t_w, count_w, c_w = 0.55, 20, 5, 1.0
ucb_bonus_w = c_w * np.sqrt(2 * np.log(t_w) / count_w)
ucb_index_w = mean_w + ucb_bonus_w
print("bonus:", round(ucb_bonus_w, 3), "UCB index:", round(ucb_index_w, 3))
assert round(ucb_index_w, 3) == 1.645
```
▶ What you'll see: uncertainty adds `1.095`, making the action look worth trying despite a mean of only 0.55.

```python
plt.figure(figsize=(4.6, 3))
plt.bar(["mean", "bonus", "UCB"], [mean_w, ucb_bonus_w, ucb_index_w], color=["gray", "orange", "teal"])
plt.title("5: exploration adds value for uncertainty")
plt.ylabel("index")
plt.show()
```
▶ What you'll see: the exploration bonus is larger than the empirical mean in this small-count example.

*Why it's done this way:* in RL, predictions and data collection are coupled. A policy with no support for an action cannot evaluate that action reliably, and exploration is the deliberate pressure that prevents early estimates from freezing the data stream too soon.

### 6. The deadly triad: approximation + bootstrapping + off-policy data

The famous deadly triad is the combination of function approximation, bootstrapping, and off-policy learning. Each piece is useful alone, but together they can feed errors back through shared weights from data generated by a policy different from the one being evaluated or improved.

```python
steps_w = 40
weight_w = 1.0
history_w = []
for k_w in range(steps_w):
    current_w = 2.0 * weight_w  # off-policy sample has a large current feature.
    next_w = 2.4 * weight_w  # bootstrap next feature is larger, amplifying the same weight.
    delta_bad_w = 0.0 + 0.99 * next_w - current_w  # zero reward, bootstrapped target.
    weight_w = weight_w + 0.1 * delta_bad_w * 2.0  # semi-gradient update with current feature 2.
    history_w.append(weight_w)
print("first weight:", round(history_w[0], 3), "last weight:", round(history_w[-1], 3))
assert history_w[-1] > history_w[0]
```
▶ What you'll see: the single shared weight grows even though every reward is zero.

```python
plt.figure(figsize=(4.8, 3))
plt.plot(history_w, color="crimson")
plt.title("6: bootstrapped off-policy approximation can amplify error")
plt.xlabel("update")
plt.ylabel("shared weight")
plt.show()
```
▶ What you'll see: the curve rises because the bootstrapped next estimate is repeatedly larger than the current estimate.

*Why it's done this way:* this toy is intentionally stripped down: no reward signal is causing growth. The growth comes from a shared approximator, a bootstrapped target, and a distribution mismatch that keeps applying the same amplifying transition. Stable RL methods add target networks, small steps, on-policy constraints, replay controls, or gradient corrections to weaken one side of this triangle.

### ✍️ Toy 1 · Features and weights make one shared value rule

A linear value function predicts by multiplying each feature by its shared weight and summing the
contributions.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)
t1_states = np.array([0.0, 1.0, 2.0])
print("states:", t1_states.tolist())  # -> [0.0, 1.0, 2.0]
t1_scaled = t1_states / 2.0
print("scaled states:", t1_scaled.tolist())  # -> [0.0, 0.5, 1.0]
t1_bias = np.ones_like(t1_states)
print("bias feature:", t1_bias.tolist())  # -> [1.0, 1.0, 1.0]
t1_features = np.column_stack([t1_bias, t1_scaled])
print("feature matrix:", t1_features.tolist())  # -> [[1.0, 0.0], [1.0, 0.5], [1.0, 1.0]]
t1_weights = np.array([1.0, 2.0])
print("weights:", t1_weights.tolist())  # -> [1.0, 2.0]
t1_values = t1_features @ t1_weights
print("predicted values:", t1_values.tolist())  # -> [1.0, 2.0, 3.0]

plt.figure(figsize=(4.4, 3.0))
plt.plot(t1_states, t1_values, marker="o", color="teal")
plt.title("Toy 1 · shared linear value")
plt.xlabel("state")
plt.ylabel("V_hat")
plt.show()

assert np.allclose(t1_values, np.array([1.0, 2.0, 3.0]))
```
▶ What you'll see: the same two weights create a straight value line over all three states.

### ✍️ Toy 2 · Discounted return is a supervised target

When the full future is available, the discounted return gives a direct target for the approximator.

```python
import numpy as np

t2_rng = np.random.default_rng(0)
```

### ✍️ Toy 3 · A bootstrap target uses the next prediction

TD with approximation replaces the unknown future return with the model's current prediction for the
next state's features.

```python
import numpy as np

t3_rng = np.random.default_rng(0)
t3_phi = np.array([1.0, 0.5])
print("current features:", t3_phi.tolist())  # -> [1.0, 0.5]
t3_phi_next = np.array([1.0, 1.0])
print("next features:", t3_phi_next.tolist())  # -> [1.0, 1.0]
t3_weights = np.array([0.0, 2.0])
print("weights:", t3_weights.tolist())  # -> [0.0, 2.0]
t3_value = float(t3_phi @ t3_weights)
print("current prediction:", round(t3_value, 3))  # -> 1.0
t3_next_value = float(t3_phi_next @ t3_weights)
print("next prediction:", round(t3_next_value, 3))  # -> 2.0
t3_reward = 1.0
print("reward:", t3_reward)  # -> 1.0
t3_gamma = 0.5
print("gamma:", t3_gamma)  # -> 0.5
t3_target = t3_reward + t3_gamma * t3_next_value
print("TD target:", round(t3_target, 3))  # -> 2.0
t3_delta = t3_target - t3_value
print("TD error:", round(t3_delta, 3))  # -> 1.0
t3_alpha = 0.5
print("alpha:", t3_alpha)  # -> 0.5
t3_new_scalar = t3_value + t3_alpha * t3_delta
print("scalar TD update:", round(t3_new_scalar, 3))  # -> 1.5

plt.figure(figsize=(4.4, 3.0))
plt.bar(["old V", "target", "scalar new"], [t3_value, t3_target, t3_new_scalar], color=["gray", "black", "seagreen"])

```

### ✍️ Toy 4 · Semi-gradient TD changes shared weights

The semi-gradient step multiplies the TD error by the current feature vector, so one update shifts
predictions for multiple states.

```python
import numpy as np

t4_rng = np.random.default_rng(0)
t4_phi = np.array([1.0, 0.5])
print("current features:", t4_phi.tolist())  # -> [1.0, 0.5]
t4_phi_next = np.array([1.0, 1.0])
print("next features:", t4_phi_next.tolist())  # -> [1.0, 1.0]
t4_weights = np.array([0.0, 2.0])

t4_reward = 1.0
print("reward:", t4_reward)  # -> 1.0
```

### ✍️ Toy 5 · Policy probabilities and bonuses shape data

A softmax policy turns logits into data-collection probabilities; an uncertainty bonus can raise an
action's selection index even before its mean is high.

```python
import numpy as np

t5_rng = np.random.default_rng(0)
t5_logits = np.array([0.0, 1.0])

t5_shifted = t5_logits - np.max(t5_logits)

t5_rewards = np.array([1.0, 3.0])

t5_expected = float(t5_probs @ t5_rewards)

t5_mean = 0.4
print("observed mean:", t5_mean)  # -> 0.4
t5_time = 5.0

t5_count = 1.0
print("action count:", t5_count)  # -> 1.0
t5_bonus = 0.5 * np.sqrt(2.0 * np.log(t5_time) / t5_count)
print("UCB bonus:", round(float(t5_bonus), 3))  # -> 0.897
t5_index = t5_mean + t5_bonus
print("UCB index:", round(float(t5_index), 3))  # -> 1.297

plt.figure(figsize=(6.0, 3.0))
```

### ✍️ Toy 6 · Bootstrapped approximation can amplify itself

With shared weights and a larger next feature, a zero-reward bootstrapped target can still increase
the same weight repeatedly.

```python
import numpy as np

t6_rng = np.random.default_rng(0)
t6_weight = 1.0
print("initial weight:", t6_weight)  # -> 1.0
t6_current_feature = 2.0
print("current feature:", t6_current_feature)  # -> 2.0
t6_next_feature = 3.0
print("next feature:", t6_next_feature)  # -> 3.0
t6_gamma = 0.9
print("gamma:", t6_gamma)  # -> 0.9
t6_alpha = 0.1
print("alpha:", t6_alpha)  # -> 0.1
t6_history = []
for t6_step_index in range(5):
    t6_current_value = t6_current_feature * t6_weight
    t6_next_value = t6_next_feature * t6_weight
    t6_delta = 0.0 + t6_gamma * t6_next_value - t6_current_value
    t6_weight = t6_weight + t6_alpha * t6_delta * t6_current_feature
    t6_history.append(t6_weight)
t6_history = np.array(t6_history)
print("weight history:", np.round(t6_history, 3).tolist())  # -> [1.14, 1.3, 1.482, 1.689, 1.925]
print("final weight:", round(float(t6_weight), 3))  # -> 1.925

plt.figure(figsize=(4.6, 3.0))
plt.plot(np.arange(1, 6), t6_history, marker="o", color="crimson")
plt.title("Toy 6 · zero reward, growing weight")
plt.xlabel("update")
plt.ylabel("shared weight")
plt.show()

assert t6_history[-1] > t6_history[0]
```
▶ What you'll see: even with zero reward, the bootstrapped next estimate amplifies the shared weight.

## 🛠️ Setup

```python
import numpy as np  # Import NumPy for arrays, dot products, random simulation, and numerical checks.
import matplotlib.pyplot as plt  # Import Matplotlib for value curves, loss curves, and diagnostic plots.
np.random.seed(0)  # Fix the global random seed so every stochastic example is repeatable.

def linear_value(phi, w):  # Predict V_hat(s) = phi(s)^T w for one feature vector or a feature matrix.
    return phi @ w  # Matrix multiplication handles both single states and batches.

def discounted_return(rewards, gamma):  # Compute G = sum_t gamma^t r_t from a reward sequence.
    rewards = np.asarray(rewards, dtype=float)  # Convert rewards to a numeric array.
    powers = gamma ** np.arange(len(rewards))  # Build discount powers aligned with rewards.
    return float(np.sum(powers * rewards))  # Return the scalar discounted sum.

def softmax(logits):  # Convert action logits into probabilities.
    logits = np.asarray(logits, dtype=float)  # Convert logits to a float array.
    z = logits - np.max(logits)  # Shift for numerical stability without changing probabilities.
    e = np.exp(z)  # Exponentiate shifted logits.
    return e / np.sum(e)  # Normalize to probabilities that sum to one.

def semi_gradient_td(w, phi_s, reward, phi_next, gamma=0.9, alpha=0.1):  # One linear TD(0) update.
    v_s = float(phi_s @ w)  # Current prediction V_hat(s).
    v_next = float(phi_next @ w)  # Bootstrap prediction V_hat(s').
    delta = reward + gamma * v_next - v_s  # TD error.
    return w + alpha * delta * phi_s, delta  # Semi-gradient update and diagnostic error.
```

### Advanced 4 — Demonstrate off-policy support mismatch

**Goal.** Estimate a target policy from behavior-policy samples, because off-policy learning fails when the behavior rarely samples target actions. We build it in 4 steps.

### Advanced 5 — Visualize the deadly triad instability

**Goal.** Isolate approximation, bootstrapping, and off-policy sampling in one toy recursion, because their combination can amplify errors without reward evidence. We build it in 4 steps.

```python
steps_a5 = 50  # Number of repeated updates.
weight_a5 = 1.0  # One shared parameter.
weights_bad_a5 = []  # Store unstable history.
print("initial weight:", weight_a5)  # Inspect starting point.
```
▶ What you'll see: the toy starts from a single positive shared weight.

```python
for k_a5 in range(steps_a5):  # Repeat the same off-policy transition.
    current_feature_a5 = 2.0  # Feature for sampled current state.
    next_feature_a5 = 2.4  # Bootstrap next feature is larger.
    value_now_a5 = current_feature_a5 * weight_a5  # Current prediction.
    value_next_a5 = next_feature_a5 * weight_a5  # Bootstrapped next prediction.
    delta_a5 = 0.0 + 0.99 * value_next_a5 - value_now_a5  # Zero-reward TD error.
    weight_a5 = weight_a5 + 0.1 * delta_a5 * current_feature_a5  # Semi-gradient update.
    weights_bad_a5.append(weight_a5)  # Save history.
print("last bad weight:", round(weights_bad_a5[-1], 3))  # Inspect amplification.
assert weights_bad_a5[-1] > weights_bad_a5[0]  # Verify growth.
```

```python
weight_safe_a5 = 1.0  # Reset for a safer comparison.
weights_safe_a5 = []  # Store safer history.
for k_safe_a5 in range(steps_a5):  # Repeat with a smaller discount and step.
    current_feature_safe_a5 = 2.0  # Same current feature.
    next_feature_safe_a5 = 2.4  # Same next feature.
    delta_safe_a5 = 0.0 + 0.5 * next_feature_safe_a5 * weight_safe_a5 - current_feature_safe_a5 * weight_safe_a5  # Less bootstrapping pressure.
    weight_safe_a5 = weight_safe_a5 + 0.02 * delta_safe_a5 * current_feature_safe_a5  # Smaller step.
    weights_safe_a5.append(weight_safe_a5)  # Save history.
print("last safer weight:", round(weights_safe_a5[-1], 3))  # Inspect damped behavior.
```

```python
plt.figure(figsize=(5, 3))  # Create deadly-triad comparison plot.
plt.plot(weights_bad_a5, label="triad amplification", color="crimson")  # Plot unstable recursion.
plt.plot(weights_safe_a5, label="weakened bootstrap/step", color="teal")  # Plot safer recursion.
plt.title("Advanced 5: deadly triad toy")  # Title the plot.
plt.xlabel("update")  # Label update axis.
plt.ylabel("shared weight")  # Label weight axis.
plt.legend()  # Show labels.
plt.show()  # Display the plot.
```
▶ What you'll see: the triad curve grows while the safer curve is damped.

👀 Takeaway: instability can arise from the learning setup itself, not from positive rewards or coding mistakes.
