# 8.15 — Decoding Strategies

A language model does not directly choose words; it produces logits for the next token, and a decoder turns those scores into text. In this lesson, we build softmax, temperature, greedy decoding, beam search, top-k sampling, and nucleus sampling from scratch so the decoding rule is visible as part of the model's behavior.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build decoding one idea at a time. Run each cell in order and read the printed intermediate values — every probability, log score, truncation mask, and sample is inspectable. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, exponentials, logs, sorting, and sampling.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for any sampled token.
```

### 1. Softmax and temperature: logits become a controllable distribution

The model emits **logits**, not probabilities. Softmax exponentiates each logit and divides by the total exponential mass, producing nonnegative numbers that sum to 1. Temperature changes the scale before softmax: low temperature magnifies logit gaps, high temperature shrinks them, and temperature 1 leaves the original scale alone.

```python
tokens_w = np.array(["A", "B", "C"])  # tiny vocabulary for inspection.
logits_w = np.array([3.0, 2.0, 0.5])  # model scores before normalization.
shift_w = logits_w - np.max(logits_w)  # numerical stability: subtracting a constant preserves softmax ratios.
exp_w = np.exp(shift_w)  # unnormalized positive scores.
probs_w = exp_w / exp_w.sum()  # normalize into probabilities.
print("shifted logits:", shift_w)  # inspect stable logits.
print("softmax:", np.round(probs_w, 6))  # [0.689672, 0.253716, 0.056612].
assert np.allclose(np.round(probs_w, 6), [0.689672, 0.253716, 0.056612])
```
▶ What you'll see: token A gets about 0.69 probability, B gets 0.25, and C gets 0.057.

```python
def softmax_w(z, temperature=1.0):  # stable softmax with an explicit temperature knob.
    scaled = np.asarray(z, dtype=float) / temperature  # divide logits by T before exponentiating.
    scaled = scaled - np.max(scaled)  # shift for numerical stability without changing ratios.
    e = np.exp(scaled)  # convert scores to positive masses.
    return e / e.sum()  # normalize masses to sum to 1.

def entropy_w(p):  # Shannon entropy in nats.
    p = np.asarray(p, dtype=float)
    nz = p[p > 0]
    return float(-np.sum(nz * np.log(nz)))

temps_w = np.array([0.5, 1.0, 2.0])  # sharp, baseline, and flat settings.
entropies_w = np.array([entropy_w(softmax_w([2.0, 1.0, 0.0], T)) for T in temps_w])
print("entropies:", np.round(entropies_w, 6))  # lesson values.
assert np.allclose(np.round(entropies_w, 6), [0.441057, 0.832396, 1.020191])
```
▶ What you'll see: entropy rises as temperature rises, so the distribution becomes more exploratory.

```python
plt.figure(figsize=(5, 3))
for T_w in temps_w:
    plt.plot(tokens_w, softmax_w([2.0, 1.0, 0.0], T_w), marker="o", label=f"T={T_w}")
plt.ylim(0, 0.9); plt.ylabel("probability"); plt.title("1: temperature changes sharpness")
plt.legend(); plt.show()
```
▶ What you'll see: low temperature concentrates mass on A; high temperature spreads mass toward B and C.

*Why it's done this way:* softmax is the unique-looking normalization we need here because exponentials preserve ordering while turning additive logit gaps into probability ratios. Dividing by temperature changes those gaps before exponentiation: if $T<1$, a one-logit advantage becomes larger, so the maximum dominates; if $T>1$, the same advantage is softened, so sampling spends more probability on alternatives.

### 2. Greedy decoding: choose the best next token now

Greedy decoding takes the argmax token at every step. It is deterministic and cheap, but it optimizes a local next-token decision, not the best whole sentence.

```python
probs_greedy_w = softmax_w(np.array([3.0, 2.0, 0.5]))  # probabilities for A, B, C.
best_idx_w = int(np.argmax(probs_greedy_w))  # local best token index.
print("probabilities:", np.round(probs_greedy_w, 6))  # inspect the distribution.
print("greedy emits:", tokens_w[best_idx_w], "with p=", round(float(probs_greedy_w[best_idx_w]), 6))
assert tokens_w[best_idx_w] == "A"
```
▶ What you'll see: greedy emits A because 0.689672 is the largest probability.

```python
steps_w = [np.array([3.0, 2.0, 0.5]), np.array([0.2, 2.5, 1.0]), np.array([0.1, 0.3, 2.0])]  # three next-token logit rows.
sequence_w = []  # store greedy choices.
for z_w in steps_w:
    p_w = softmax_w(z_w)
    sequence_w.append(tokens_w[int(np.argmax(p_w))])
print("greedy sequence:", "".join(sequence_w))
assert "".join(sequence_w) == "ABC"
```
▶ What you'll see: the decoder commits to A, then B, then C, one local decision at a time.

```python
plt.figure(figsize=(5, 3))
plt.bar(tokens_w, probs_greedy_w, color=["seagreen" if i == best_idx_w else "gray" for i in range(3)])
plt.ylabel("probability"); plt.title("2: greedy takes the tallest bar"); plt.show()
```
▶ What you'll see: one highlighted bar; all other plausible tokens are discarded immediately.

*Why it's done this way:* greedy is the maximum-likelihood token under the current distribution, so it is the right rule when each step is decisive and downstream diversity is unwanted. Its weakness is the lack of lookahead: a token with slightly lower current probability can lead to much higher future probabilities, but greedy has already thrown it away.

### 3. Beam search: keep several partial sequences and score paths in log space

Beam search keeps the best `beam_width` partial strings after each step. Instead of multiplying probabilities directly, we add log probabilities, because products of many small probabilities underflow and because adding logs ranks paths exactly the same way as multiplying probabilities.

```python
first_w = {"A": 0.6, "B": 0.3, "C": 0.1}  # first-step probabilities.
second_w = {"A": {"A": 0.5, "B": 0.4, "C": 0.1},  # continuations after A.
            "B": {"A": 0.9, "B": 0.05, "C": 0.05},  # continuations after B.
            "C": {"A": 0.2, "B": 0.2, "C": 0.6}}  # continuations after C.
paths_w = [(a_w + b_w, first_w[a_w] * second_w[a_w][b_w]) for a_w in first_w for b_w in second_w[a_w]]
for name_w, prob_w in paths_w:
    print(name_w, round(prob_w, 3), round(float(np.log(prob_w)), 6))
```
▶ What you'll see: AA has probability 0.30, AB has 0.24, and BA has 0.27; their log scores preserve that order.

```python
scores_w = {name_w: float(np.log(prob_w)) for name_w, prob_w in paths_w}  # log-probability path scores.
best_path_w = max(scores_w, key=scores_w.get)  # largest log score = largest probability.
print("best path:", best_path_w, "log score:", round(scores_w[best_path_w], 6))
assert best_path_w == "AA"
assert round(scores_w["AA"], 6) == -1.203973
assert round(scores_w["BA"], 6) == -1.309333
```
▶ What you'll see: AA wins, even though BA shows why lookahead matters: B was not best first, but its continuation is strong.

```python
beam_w = [("", 0.0)]  # start with empty sequence and log probability log(1)=0.
for step_table_w in [{"A": 0.6, "B": 0.3, "C": 0.1}, None]:
    candidates_w = []
    for prefix_w, score_w in beam_w:
        table_w = step_table_w if step_table_w is not None else second_w[prefix_w[-1]]
        for tok_w, prob_w in table_w.items():
            candidates_w.append((prefix_w + tok_w, score_w + float(np.log(prob_w))))
    beam_w = sorted(candidates_w, key=lambda x: x[1], reverse=True)[:2]
    print("beam:", [(s, round(sc, 6)) for s, sc in beam_w])
assert beam_w[0][0] == "AA"
```
▶ What you'll see: only two partial paths survive at each step, so pruning is still irreversible.

```python
plt.figure(figsize=(5, 3))
plt.bar(list(scores_w.keys()), list(scores_w.values()), color="steelblue")
plt.ylabel("log probability"); plt.title("3: beam compares cumulative path scores")
plt.xticks(rotation=30); plt.show()
```
▶ What you'll see: the winning path is the least negative log score, not necessarily every locally best step.

*Why it's done this way:* a sequence probability is a product of conditional probabilities, $\prod_t p(x_t\mid x_{<t})$. Logs turn that product into $\sum_t \log p(x_t\mid x_{<t})$, which is numerically stable and easier to update one token at a time. Beam width is a compute-quality tradeoff: wider beams remember more futures, but no finite beam can recover a path once it is pruned.

### 4. Top-k sampling: keep exactly k candidates, renormalize, then sample

Top-k sampling removes all but the `k` most probable tokens. The retained probabilities must be renormalized to sum to 1 before sampling; otherwise the numbers are filtered scores, not a valid distribution.

```python
logits_k_w = np.array([4.0, 3.0, 2.0, 1.0, 0.0])  # five candidate logits.
tokens_k_w = np.array(["A", "B", "C", "D", "E"])
probs_k_w = softmax_w(logits_k_w)  # base distribution.
print("base probabilities:", np.round(probs_k_w, 6))
assert np.allclose(np.round(probs_k_w, 6), [0.636409, 0.234122, 0.086129, 0.031685, 0.011656])
```
▶ What you'll see: a long tail exists, even though A dominates.

```python
k_w = 3  # keep exactly three tokens.
keep_idx_w = np.argsort(probs_k_w)[::-1][:k_w]  # indices of the three largest probabilities.
filtered_k_w = np.zeros_like(probs_k_w)  # start with all candidates removed.
filtered_k_w[keep_idx_w] = probs_k_w[keep_idx_w]  # restore the top-k masses.
renorm_k_w = filtered_k_w / filtered_k_w.sum()  # rescale surviving mass to sum to 1.
print("top-k distribution:", np.round(renorm_k_w, 6))
print("nonzero count:", int(np.sum(renorm_k_w > 0)))
assert np.allclose(np.round(renorm_k_w, 6), [0.665241, 0.244728, 0.090031, 0.0, 0.0])
```
▶ What you'll see: D and E become impossible, while A/B/C are slightly inflated by renormalization.

```python
plt.figure(figsize=(5, 3))
width_w = 0.35; x_w = np.arange(len(tokens_k_w))
plt.bar(x_w - width_w/2, probs_k_w, width=width_w, label="before", color="gray")
plt.bar(x_w + width_w/2, renorm_k_w, width=width_w, label="after top-k", color="darkorange")
plt.xticks(x_w, tokens_k_w); plt.ylabel("probability"); plt.title("4: top-k truncates a fixed count")
plt.legend(); plt.show()
```
▶ What you'll see: exactly three bars remain after filtering, regardless of how confident the model was.

*Why it's done this way:* top-k is a hard count constraint. It blocks extremely unlikely tail tokens from injecting nonsense while preserving randomness among a small candidate set. The renormalization is mathematically required because sampling needs probabilities that sum to 1; after filtering, the surviving mass is less than 1 until we divide by that mass.

### 5. Nucleus sampling: keep the smallest set whose mass reaches p

Nucleus sampling, also called top-p sampling, sorts tokens by probability and keeps the smallest prefix whose cumulative mass reaches a threshold such as 0.9. Unlike top-k, the number of kept tokens adapts to confidence: a sharp distribution may keep few tokens, while a flat distribution may keep many.

```python
threshold_w = 0.9  # cumulative probability mass target.
order_w = np.argsort(probs_k_w)[::-1]  # sort tokens by descending probability.
sorted_probs_w = probs_k_w[order_w]  # probabilities in sorted order.
cumulative_w = np.cumsum(sorted_probs_w)  # running mass.
print("sorted cumulative:", np.round(cumulative_w, 6))
assert np.allclose(np.round(cumulative_w, 6), [0.636409, 0.870530, 0.956659, 0.988344, 1.0])
```
▶ What you'll see: A+B only reach 0.870530, so C must be included to cross 0.9.

```python
cut_w = int(np.searchsorted(cumulative_w, threshold_w) + 1)  # first prefix length reaching the threshold.
keep_nuc_w = order_w[:cut_w]  # original indices in the nucleus.
filtered_p_w = np.zeros_like(probs_k_w)
filtered_p_w[keep_nuc_w] = probs_k_w[keep_nuc_w]
renorm_p_w = filtered_p_w / filtered_p_w.sum()
print("nucleus size:", cut_w)
print("nucleus distribution:", np.round(renorm_p_w, 6))
assert cut_w == 3
assert np.allclose(renorm_p_w, renorm_k_w)
```
▶ What you'll see: for this distribution, nucleus and top-k=3 happen to keep the same tokens.

```python
sharp_w = np.array([0.86, 0.06, 0.04, 0.03, 0.01])  # confident distribution.
flat_w = np.array([0.22, 0.21, 0.20, 0.19, 0.18])  # uncertain distribution.
def nucleus_size_w(p, threshold=0.9):
    return int(np.searchsorted(np.cumsum(np.sort(p)[::-1]), threshold) + 1)
print("sharp nucleus size:", nucleus_size_w(sharp_w))
print("flat nucleus size:", nucleus_size_w(flat_w))
assert nucleus_size_w(sharp_w) == 2
assert nucleus_size_w(flat_w) == 5
```
▶ What you'll see: the same 0.9 threshold keeps 2 tokens for a sharp distribution and all 5 tokens for a flat one.

```python
plt.figure(figsize=(5, 3))
plt.plot(tokens_k_w, np.cumsum(np.sort(sharp_w)[::-1]), marker="o", label="sharp")
plt.plot(tokens_k_w, np.cumsum(np.sort(flat_w)[::-1]), marker="o", label="flat")
plt.axhline(0.9, color="black", linestyle="--", label="p=0.9")
plt.ylabel("cumulative mass"); plt.title("5: nucleus adapts candidate count")
plt.legend(); plt.show()
```
▶ What you'll see: the sharp curve crosses 0.9 quickly; the flat curve needs nearly every token.

*Why it's done this way:* nucleus sampling controls retained probability mass rather than retained count. That matches the uncertainty of the model: when the top token already explains most of the mass, few alternatives are needed; when probability is spread out, a fixed small k would cut away plausible options too aggressively.

### ✍️ Toy 1 · Temperature sharpens or flattens softmax

Softmax turns logits into probabilities. Dividing logits by a low temperature sharpens the winner,
while a high temperature spreads probability across alternatives.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)
print("rng seed:", 0)  # -> 0
t1_tokens = np.array(["A", "B", "C"])
print("tokens:", t1_tokens.tolist())  # -> ['A', 'B', 'C']
t1_logits = np.array([2.0, 1.0, 0.0])
print("logits:", t1_logits.tolist())  # -> [2.0, 1.0, 0.0]
t1_shift = t1_logits - np.max(t1_logits)
print("stable shift:", t1_shift.tolist())  # -> [0.0, -1.0, -2.0]
t1_exp = np.exp(t1_shift)
print("exp shifted:", np.round(t1_exp, 6).tolist())  # -> [1.0, 0.367879, 0.135335]
t1_probs = t1_exp / t1_exp.sum()
print("T=1 probabilities:", np.round(t1_probs, 6).tolist())  # -> [0.665241, 0.244728, 0.090031]
t1_low_logits = t1_logits / 0.5
t1_low_shift = t1_low_logits - np.max(t1_low_logits)
t1_low_exp = np.exp(t1_low_shift)
t1_low_probs = t1_low_exp / t1_low_exp.sum()
print("T=0.5 probabilities:", np.round(t1_low_probs, 6).tolist())  # -> [0.866813, 0.11731, 0.015876]
t1_high_logits = t1_logits / 2.0
t1_high_shift = t1_high_logits - np.max(t1_high_logits)
t1_high_exp = np.exp(t1_high_shift)
t1_high_probs = t1_high_exp / t1_high_exp.sum()
print("T=2 probabilities:", np.round(t1_high_probs, 6).tolist())  # -> [0.50648, 0.307196, 0.186324]
assert t1_low_probs[0] > t1_probs[0] > t1_high_probs[0]

plt.figure(figsize=(4.8, 2.8))
plt.plot(t1_tokens, t1_low_probs, marker="o", label="T=0.5")
plt.plot(t1_tokens, t1_probs, marker="o", label="T=1")
plt.plot(t1_tokens, t1_high_probs, marker="o", label="T=2")
plt.ylim(0, 1)
plt.ylabel("probability")
plt.title("Toy 1 · temperature changes sharpness")
plt.legend()
plt.show()
```
▶ What you'll see: the top token's mass moves from `0.50648` at high temperature to `0.866813` at low temperature.

### ✍️ Toy 2 · Greedy decoding takes the local argmax

Greedy decoding normalizes each step, chooses the largest probability, and never revisits that local
choice.

```python
import numpy as np

t2_rng = np.random.default_rng(0)
print("rng seed:", 0)  # -> 0
t2_tokens = np.array(["red", "blue", "green"])
print("tokens:", t2_tokens.tolist())  # -> ['red', 'blue', 'green']
t2_steps = np.array([[2.0, 1.0, 0.0], [0.0, 2.0, 1.0], [0.5, 0.2, 1.5]])
print("step logits:", t2_steps.tolist())  # -> [[2.0, 1.0, 0.0], [0.0, 2.0, 1.0], [0.5, 0.2, 1.5]]
t2_shift = t2_steps - np.max(t2_steps, axis=1, keepdims=True)
print("shifted logits:", t2_shift.tolist())  # -> [[0.0, -1.0, -2.0], [-2.0, 0.0, -1.0], [-1.0, -1.3, 0.0]]
t2_exp = np.exp(t2_shift)
print("exp shifted:", np.round(t2_exp, 6).tolist())  # -> [[1.0, 0.367879, 0.135335], [0.135335, 1.0, 0.367879], [0.367879, 0.272532, 1.0]]
t2_probs = t2_exp / t2_exp.sum(axis=1, keepdims=True)
print("step probabilities:", np.round(t2_probs, 6).tolist())  # -> [[0.665241, 0.244728, 0.090031], [0.090031, 0.665241, 0.244728], [0.22426, 0.166136, 0.609603]]
t2_choices = np.argmax(t2_probs, axis=1)
print("argmax indices:", t2_choices.tolist())  # -> [0, 1, 2]
t2_sequence = t2_tokens[t2_choices]
print("greedy sequence:", t2_sequence.tolist())  # -> ['red', 'blue', 'green']
assert t2_sequence.tolist() == ["red", "blue", "green"]

plt.figure(figsize=(4.8, 2.8))
plt.bar(t2_tokens, t2_probs[0], color=["seagreen" if t2_i == t2_choices[0] else "gray" for t2_i in range(3)])
plt.ylabel("first-step probability")
plt.title("Toy 2 · greedy keeps the tallest bar")
plt.show()
```
▶ What you'll see: the chosen sequence is `red → blue → green`, with each token selected by a row-wise argmax.

### ✍️ Toy 3 · Beam search ranks cumulative log scores

Beam search scores whole partial paths by adding log probabilities. A non-greedy first token can stay
alive if its continuation is strong.

```python
import numpy as np

t3_rng = np.random.default_rng(0)
print("rng seed:", 0)  # -> 0
t3_tokens = np.array(["A", "B", "C"])
print("tokens:", t3_tokens.tolist())  # -> ['A', 'B', 'C']
t3_first = np.array([0.5, 0.4, 0.1])
print("first-step probabilities:", t3_first.tolist())  # -> [0.5, 0.4, 0.1]
t3_second = np.array([[0.2, 0.7, 0.1], [0.9, 0.05, 0.05], [0.3, 0.3, 0.4]])
print("second-step table:", t3_second.tolist())  # -> [[0.2, 0.7, 0.1], [0.9, 0.05, 0.05], [0.3, 0.3, 0.4]]
t3_path_probs = t3_first[:, None] * t3_second
print("path probabilities:", t3_path_probs.tolist())  # -> [[0.1, 0.35, 0.05], [0.36000000000000004, 0.020000000000000004, 0.020000000000000004], [0.03, 0.03, 0.04000000000000001]]
t3_path_logs = np.log(t3_path_probs)
print("path log scores:", np.round(t3_path_logs, 6).tolist())  # -> [[-2.302585, -1.049822, -2.995732], [-1.021651, -3.912023, -3.912023], [-3.506558, -3.506558, -3.218876]]
t3_path_names = np.array([t3_a + t3_b for t3_a in t3_tokens for t3_b in t3_tokens])
print("path names:", t3_path_names.tolist())  # -> ['AA', 'AB', 'AC', 'BA', 'BB', 'BC', 'CA', 'CB', 'CC']
t3_flat_scores = t3_path_logs.ravel()
t3_order = np.argsort(t3_flat_scores)[::-1]
print("score order:", t3_order.tolist())  # -> [3, 1, 0, 2, 8, 7, 6, 5, 4]
t3_top2 = t3_order[:2]
print("beam width 2 indices:", t3_top2.tolist())  # -> [3, 1]
print("beam width 2 paths:", t3_path_names[t3_top2].tolist())  # -> ['BA', 'AB']
print("beam width 2 log scores:", np.round(t3_flat_scores[t3_top2], 6).tolist())  # -> [-1.021651, -1.049822]
assert t3_path_names[t3_top2][0] == "BA"

plt.figure(figsize=(5.2, 2.8))
plt.bar(t3_path_names, t3_flat_scores, color="steelblue")
plt.ylabel("log probability")
plt.title("Toy 3 · beam keeps top cumulative paths")
plt.xticks(rotation=30)
plt.show()
```
▶ What you'll see: `BA` beats `AB` by cumulative log score, even though `A` was the best first token.

### ✍️ Toy 4 · Top-k sampling truncates a fixed count

Top-k keeps exactly `k` tokens, renormalizes their mass, and samples only from that retained set.

```python
import numpy as np

t4_rng = np.random.default_rng(0)
print("rng seed:", 0)  # -> 0
t4_tokens = np.array(["A", "B", "C", "D"])
print("tokens:", t4_tokens.tolist())  # -> ['A', 'B', 'C', 'D']
t4_logits = np.array([2.0, 1.5, 0.5, -1.0])
print("logits:", t4_logits.tolist())  # -> [2.0, 1.5, 0.5, -1.0]
t4_shift = t4_logits - np.max(t4_logits)
print("shifted logits:", t4_shift.tolist())  # -> [0.0, -0.5, -1.5, -3.0]
t4_exp = np.exp(t4_shift)
print("exp shifted:", np.round(t4_exp, 6).tolist())  # -> [1.0, 0.606531, 0.22313, 0.049787]
t4_probs = t4_exp / t4_exp.sum()
print("base probabilities:", np.round(t4_probs, 6).tolist())  # -> [0.532071, 0.322717, 0.118721, 0.02649]
t4_order = np.argsort(t4_probs)[::-1]
print("descending order:", t4_order.tolist())  # -> [0, 1, 2, 3]
t4_keep = t4_order[:2]
print("top-k kept indices:", t4_keep.tolist())  # -> [0, 1]
t4_filtered = np.zeros_like(t4_probs)
t4_filtered[t4_keep] = t4_probs[t4_keep]
print("filtered mass:", np.round(t4_filtered, 6).tolist())  # -> [0.532071, 0.322717, 0.0, 0.0]
t4_renorm = t4_filtered / t4_filtered.sum()
print("renormalized top-k:", np.round(t4_renorm, 6).tolist())  # -> [0.622459, 0.377541, 0.0, 0.0]
t4_sample = t4_rng.choice(t4_tokens, p=t4_renorm)
print("sampled token:", str(t4_sample))  # -> B
assert int(np.sum(t4_renorm > 0)) == 2
assert t4_sample in t4_tokens[t4_keep]

plt.figure(figsize=(4.8, 2.8))
plt.bar(np.arange(4) - 0.15, t4_probs, width=0.3, label="base", color="gray")
```

## 🛠️ Setup

```python
import numpy as np  # load NumPy for logits, probabilities, sorting, logs, and small simulations.
import matplotlib.pyplot as plt  # load Matplotlib for bar charts, line charts, and heatmaps.
np.random.seed(0)  # make sampling examples reproducible.

def softmax(z, temperature=1.0):  # convert logits to probabilities with optional temperature.
    z = np.asarray(z, dtype=float) / temperature  # scale logits before exponentiation.
    z = z - np.max(z)  # subtract the maximum for numerical stability.
    e = np.exp(z)  # exponentiate shifted logits.
    return e / e.sum()  # normalize to a probability distribution.

def entropy(p):  # compute Shannon entropy in nats.
    p = np.asarray(p, dtype=float)  # ensure vector arithmetic works.
    nz = p[p > 0]  # exclude zeros so log(0) is never evaluated.
    return float(-np.sum(nz * np.log(nz)))  # return -sum p log p.

def top_k_filter(p, k):  # keep exactly k largest probabilities and renormalize.
    p = np.asarray(p, dtype=float)  # convert input to numeric probabilities.
    keep = np.argsort(p)[::-1][:k]  # indices of the largest k entries.
    out = np.zeros_like(p)  # initialize removed probabilities at zero.
    out[keep] = p[keep]  # restore the selected entries.
    return out / out.sum()  # renormalize surviving mass.

def nucleus_filter(p, threshold):  # keep the smallest sorted prefix with cumulative mass at least threshold.
    p = np.asarray(p, dtype=float)  # convert input to numeric probabilities.
    order = np.argsort(p)[::-1]  # sort indices from high probability to low.
    cut = int(np.searchsorted(np.cumsum(p[order]), threshold) + 1)  # first prefix that reaches the mass threshold.
    out = np.zeros_like(p)  # initialize removed probabilities at zero.
    out[order[:cut]] = p[order[:cut]]  # restore nucleus entries.
    return out / out.sum()  # renormalize surviving mass.

def sample_from(p):  # sample one index from an explicit distribution.
    return int(np.random.choice(len(p), p=np.asarray(p, dtype=float)))  # use NumPy's categorical sampler.
```

### Advanced 1 — Show greedy can miss the best path

**Goal.** Construct a case where the best first token is not the best two-token sequence, because local and global maximization can disagree. We build it in 3 steps.

