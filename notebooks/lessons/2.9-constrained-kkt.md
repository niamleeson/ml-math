# 2.9 — Constrained Optimization & KKT Conditions

Constrained optimization asks for the best point that is still legal. In this lesson, we build the Karush-Kuhn-Tucker (KKT) conditions from scratch: gradients as forces, equality constraints as exact balance, inequality constraints as walls, complementarity as the rule that only touched walls push back, and convexity as the reason these checks can certify a global optimum.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build constrained optimization one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math is shown with small NumPy arrays so the KKT checklist never feels like a black box. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, grids, dot products, and small numerical checks.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for any random examples.
```

### 1. A constraint can make the unconstrained optimum illegal

Start with the one-dimensional objective $f(x)=x^2$. Without constraints, the best point is $x=0$. Now add the legal region $x\ge1$. The unconstrained best point is outside the feasible set, so the constrained optimum must sit on the boundary $x=1$ even though the objective gradient there is not zero.

```python
x_w = np.linspace(-1.0, 3.0, 401)  # a dense line so we can inspect objective values.
f_w = x_w ** 2  # objective values f(x)=x^2.
feasible_w = x_w >= 1.0  # legal points for the constraint x >= 1.
print("unconstrained minimizer:", x_w[np.argmin(f_w)])  # closest grid point to 0.
print("best feasible grid point:", x_w[feasible_w][np.argmin(f_w[feasible_w])])  # boundary.
```
▶ What you'll see: the best unconstrained point is 0, but the best legal point is 1.

```python
plt.figure(figsize=(5, 3))
plt.plot(x_w, f_w, color="navy", label="f(x)=x²")
plt.axvspan(1, 3, color="seagreen", alpha=0.18, label="feasible x≥1")
plt.scatter([0, 1], [0, 1], color=["red", "black"], zorder=3)
plt.text(0, 0.25, "illegal best", ha="center")
plt.text(1, 1.25, "constrained best", ha="center")
plt.title("1: the wall moves the optimum")
plt.xlabel("x"); plt.ylabel("f(x)"); plt.legend(); plt.show()
```
▶ What you'll see: the bowl wants to bottom out at 0, but the green feasible region begins at 1.

```python
grad_f_at_boundary_w = 2 * 1.0  # derivative of x^2 at x=1.
print("∇f at constrained optimum:", grad_f_at_boundary_w)
assert grad_f_at_boundary_w == 2.0
```
▶ What you'll see: the constrained optimum has nonzero objective gradient.

*Why it's done this way:* unconstrained optima use $\nabla f=0$ because every tiny direction is legal. At a boundary, some improving directions are illegal, so the right question is not "is the gradient zero?" but "is every feasible movement non-improving?" KKT answers that by balancing the objective gradient against constraint gradients.

### 2. Equality constraints create exact gradient balance

For an equality, the legal points lie on a surface. Minimize $f(x,y)=x^2+y^2$ subject to $h(x,y)=x+y-1=0$. The optimum is the closest point on the line $x+y=1$ to the origin. At that point, $\nabla f$ points normal to the line, so it can be canceled by $\lambda\nabla h$.

```python
point_w = np.array([0.5, 0.5])  # candidate on x+y=1.
grad_f_eq_w = 2 * point_w  # gradient of x^2+y^2.
grad_h_w = np.array([1.0, 1.0])  # gradient of h=x+y-1.
lambda_w = -1.0  # equality multiplier can be positive or negative.
stationarity_eq_w = grad_f_eq_w + lambda_w * grad_h_w
print("candidate:", point_w, "h:", point_w.sum() - 1)
print("∇f:", grad_f_eq_w, "λ∇h:", lambda_w * grad_h_w)
print("stationarity residual:", stationarity_eq_w)
assert np.allclose(stationarity_eq_w, [0.0, 0.0])
```
▶ What you'll see: $(1,1)+(-1)(1,1)=(0,0)$, so stationarity holds.

```python
t_w = np.linspace(-0.2, 1.2, 200)  # parameter along the equality line.
line_w = np.column_stack([t_w, 1 - t_w])  # all points with x+y=1.
values_line_w = np.sum(line_w ** 2, axis=1)  # f along the legal line.
best_idx_w = int(np.argmin(values_line_w))
print("best line point:", np.round(line_w[best_idx_w], 3), "value:", round(values_line_w[best_idx_w], 3))
assert np.allclose(line_w[best_idx_w], [0.5, 0.5], atol=0.01)
```
▶ What you'll see: searching only legal points recovers the same point $(0.5,0.5)$.

```python
plt.figure(figsize=(4, 4))
plt.plot(line_w[:, 0], line_w[:, 1], color="seagreen", label="x+y=1")
plt.scatter([point_w[0]], [point_w[1]], color="black", zorder=3)
plt.arrow(point_w[0], point_w[1], grad_f_eq_w[0] * 0.18, grad_f_eq_w[1] * 0.18,
          head_width=0.03, color="red", length_includes_head=True, label="∇f")
plt.arrow(point_w[0], point_w[1], lambda_w * grad_h_w[0] * 0.18, lambda_w * grad_h_w[1] * 0.18,
          head_width=0.03, color="blue", length_includes_head=True, label="λ∇h")
plt.axis("equal"); plt.xlim(-0.1, 1.1); plt.ylim(-0.1, 1.1)
plt.title("2: equality force balance"); plt.legend(); plt.show()
```
▶ What you'll see: two opposite arrows normal to the equality line.

*Why it's done this way:* equality constraints remove motion in the normal direction but allow motion tangent to the surface. At the optimum, the objective gradient must have no tangent component; otherwise we could slide along the equality and improve. Therefore $\nabla f$ must be a scalar multiple of $\nabla h$, which is exactly $\nabla f+\lambda\nabla h=0$.

### 3. Inequality constraints are walls, so only active walls push

Write the constraint $x\ge1$ as $g(x)=1-x\le0$. KKT adds a multiplier $\mu\ge0$ and stationarity becomes $\nabla f+\mu\nabla g=0$. If the wall is active ($g=0$), $\mu$ may be positive. If the point is strictly inside ($g<0$), complementarity forces $\mu=0$.

```python
x_active_w = 1.0
g_active_w = 1 - x_active_w  # active wall value.
grad_f_active_w = 2 * x_active_w  # derivative of x^2.
grad_g_w = -1.0  # derivative of 1-x.
mu_active_w = 2.0  # solve 2 + mu*(-1)=0.
stationarity_active_w = grad_f_active_w + mu_active_w * grad_g_w
print("g(1):", g_active_w, "mu:", mu_active_w)
print("stationarity residual:", stationarity_active_w)
print("complementarity mu*g:", mu_active_w * g_active_w)
assert stationarity_active_w == 0.0 and mu_active_w * g_active_w == 0.0
```
▶ What you'll see: the active wall cancels the objective gradient with a positive multiplier.

```python
x_inactive_w = 2.0
g_inactive_w = 1 - x_inactive_w  # strictly negative means safely feasible.
mu_inactive_w = 0.0  # inactive wall cannot charge a price.
print("g(2):", g_inactive_w, "mu:", mu_inactive_w, "mu*g:", mu_inactive_w * g_inactive_w)
assert g_inactive_w < 0 and mu_inactive_w * g_inactive_w == 0.0
```
▶ What you'll see: a wall you are not touching has multiplier 0.

```python
xs_wall_w = np.array([1.0, 1.3, 2.0])
gs_wall_w = 1 - xs_wall_w
mus_wall_w = np.where(np.isclose(gs_wall_w, 0), 2.0, 0.0)
plt.figure(figsize=(5, 3))
plt.bar(["x=1 active", "x=1.3", "x=2"], mus_wall_w, color=["crimson", "gray", "gray"])
plt.title("3: only the touched wall pushes")
plt.ylabel("multiplier μ")
plt.show()
```
▶ What you'll see: only the boundary point has a positive multiplier.

*Why it's done this way:* an inequality wall can only prevent movement into the illegal side; it cannot pull the solution toward itself. That one-sided behavior is encoded by $\mu\ge0$ and $\mu g(x)=0$: either the wall is touched and may push, or the wall is slack and its force is exactly zero.

### 4. The KKT checklist combines feasibility, stationarity, sign, and complementarity

For a minimization problem with $g_i(x)\le0$ and $h_j(x)=0$, KKT checks four families of statements: primal feasibility, stationarity, dual feasibility, and complementarity. A candidate is not a KKT point unless all relevant checks pass.

```python
x_kkt_w = 1.0
g_kkt_w = np.array([1 - x_kkt_w])  # g(x)=1-x <= 0.
grad_f_kkt_w = np.array([2 * x_kkt_w])
grad_g_kkt_w = np.array([[-1.0]])  # one constraint gradient as a row.
mu_kkt_w = np.array([2.0])
stationarity_kkt_w = grad_f_kkt_w + mu_kkt_w @ grad_g_kkt_w
checks_kkt_w = {
    "primal feasible": bool(np.all(g_kkt_w <= 1e-12)),
    "stationary": bool(np.allclose(stationarity_kkt_w, 0.0)),
    "dual feasible": bool(np.all(mu_kkt_w >= 0)),
    "complementary": bool(np.allclose(mu_kkt_w * g_kkt_w, 0.0)),
}
print(checks_kkt_w)
assert all(checks_kkt_w.values())
```
▶ What you'll see: all four KKT checks are true for $x=1,\mu=2$.

```python
bad_mu_w = np.array([-2.0])  # would satisfy stationarity with the opposite constraint sign, but violates μ>=0.
bad_stationarity_w = grad_f_kkt_w + bad_mu_w @ grad_g_kkt_w
print("bad mu:", bad_mu_w, "stationarity residual:", bad_stationarity_w, "dual feasible:", bool(np.all(bad_mu_w >= 0)))
assert not np.all(bad_mu_w >= 0)
```
▶ What you'll see: a negative inequality multiplier fails even if it looks algebraically tempting.

```python
names_kkt_w = list(checks_kkt_w.keys())
vals_kkt_w = np.array([checks_kkt_w[k] for k in names_kkt_w], dtype=int)
plt.figure(figsize=(5, 2.6))
plt.bar(names_kkt_w, vals_kkt_w, color="seagreen")
plt.ylim(0, 1.2); plt.xticks(rotation=20); plt.title("4: KKT checklist")
plt.show()
```
▶ What you'll see: every bar is 1, meaning every required condition passed.

*Why it's done this way:* stationarity alone is not enough because it ignores whether the point is legal and whether inequality forces have the correct one-sided sign. The checklist prevents three common mistakes: optimizing an illegal point, using a negative wall force, or assigning a nonzero force to a wall that is not active.

### 5. Active-set reasoning solves small problems by guessing the touched walls

For multiple inequalities, we often reason by an active set: guess which constraints are tight, solve stationarity with those constraints, then verify the full KKT checklist. Here we minimize $(x-2)^2+(y-1)^2$ subject to $x+y\le2$. The unconstrained point $(2,1)$ is illegal because it sums to 3, so the boundary $x+y=2$ becomes active.

```python
center_w = np.array([2.0, 1.0])  # unconstrained minimizer of the shifted bowl.
normal_w = np.array([1.0, 1.0])  # gradient of g=x+y-2.
# Project center onto x+y=2: center - ((sum(center)-2)/||normal||²) normal.
projection_w = center_w - ((center_w.sum() - 2.0) / np.dot(normal_w, normal_w)) * normal_w
print("unconstrained center:", center_w, "constraint value:", center_w.sum() - 2)
print("projected constrained candidate:", projection_w, "constraint value:", projection_w.sum() - 2)
assert np.allclose(projection_w, [1.5, 0.5])
```
▶ What you'll see: the illegal center projects to the boundary point $(1.5,0.5)$.

```python
grad_f_proj_w = 2 * (projection_w - center_w)  # gradient of shifted quadratic.
grad_g_proj_w = normal_w
mu_proj_w = 1.0  # solve [-1,-1] + mu[1,1] = 0.
resid_proj_w = grad_f_proj_w + mu_proj_w * grad_g_proj_w
print("∇f at candidate:", grad_f_proj_w)
print("μ∇g:", mu_proj_w * grad_g_proj_w)
print("stationarity residual:", resid_proj_w)
assert np.allclose(resid_proj_w, [0.0, 0.0])
```
▶ What you'll see: the active constraint normal balances the objective gradient.

```python
grid_x_w = np.linspace(-0.2, 2.4, 120)
grid_y_w = np.linspace(-0.8, 2.0, 120)
X_w, Y_w = np.meshgrid(grid_x_w, grid_y_w)
Z_w = (X_w - 2) ** 2 + (Y_w - 1) ** 2
plt.figure(figsize=(4.6, 4))
plt.contour(X_w, Y_w, Z_w, levels=12, cmap="viridis")
plt.plot(grid_x_w, 2 - grid_x_w, color="crimson", label="x+y=2")
plt.fill_between(grid_x_w, grid_y_w.min(), 2 - grid_x_w, color="seagreen", alpha=0.12, label="feasible")
plt.scatter([center_w[0], projection_w[0]], [center_w[1], projection_w[1]], color=["red", "black"])
plt.xlim(-0.2, 2.4); plt.ylim(-0.8, 2.0); plt.legend(); plt.title("5: active boundary projection")
plt.show()
```
▶ What you'll see: the closest feasible contour touches the line at the projected point.

*Why it's done this way:* active-set reasoning turns inequalities into equalities only for walls that are touched. The verification step matters: if the resulting multiplier were negative or another constraint were violated, the guessed active set would be wrong.

### 6. Convexity turns KKT from necessary checks into a global certificate

KKT conditions can describe local candidates. In a convex minimization problem, they do more: any feasible point satisfying KKT is globally optimal. The reason is the first-order convex inequality $f(z)\ge f(x)+\nabla f(x)^T(z-x)$ plus the fact that active constraint gradients block every feasible improving direction.

```python
z_w = np.linspace(1.0, 4.0, 7)  # feasible points for x >= 1.
f_z_w = z_w ** 2
f_star_w = 1.0
print("feasible x values:", z_w)
print("f(x)-f(1):", np.round(f_z_w - f_star_w, 3))
assert np.all(f_z_w >= f_star_w)
```
▶ What you'll see: every feasible point has objective value at least the boundary value 1.

```python
x_nonconvex_w = np.linspace(-1.5, 2.5, 500)
f_nonconvex_w = (x_nonconvex_w ** 2 - 1) ** 2 + 0.15 * x_nonconvex_w  # nonconvex quartic.
local_idx_w = np.argmin(np.abs(x_nonconvex_w - 1.0))
global_idx_w = int(np.argmin(f_nonconvex_w))
print("value near x=1:", round(float(f_nonconvex_w[local_idx_w]), 3))
print("best grid x:", round(float(x_nonconvex_w[global_idx_w]), 3), "value:", round(float(f_nonconvex_w[global_idx_w]), 3))
```
▶ What you'll see: nonconvex landscapes can have competing basins, so stationarity-type checks need not certify global best.

```python
plt.figure(figsize=(5, 3))
plt.plot(x_nonconvex_w, f_nonconvex_w, color="purple")
plt.scatter([x_nonconvex_w[global_idx_w]], [f_nonconvex_w[global_idx_w]], color="black", label="grid global best")
plt.title("6: nonconvex problems need extra caution")
plt.xlabel("x"); plt.ylabel("objective"); plt.legend(); plt.show()
```
▶ What you'll see: a wavy objective where a local reasoning check is not the same as a global certificate.

*Why it's done this way:* convexity gives a geometry guarantee: tangent planes sit below the objective, and feasible sets have no disconnected traps. Without convexity, KKT can still be useful, but it is a candidate test rather than an automatic proof of global optimality.

### 7. Multipliers are prices, and constraint qualifications keep the math honest

A positive inequality multiplier measures how much the optimum value changes if the constraint is tightened. For $\min x^2$ subject to $x\ge b$, the solution is $x=b$ when $b>0$, the optimal value is $b^2$, and the KKT multiplier for $g(x)=b-x\le0$ is $\mu=2b$. The multiplier equals the derivative of the optimal value with respect to $b$.

```python
b_w = np.array([0.5, 1.0, 1.5, 2.0])
value_w = b_w ** 2
mu_price_w = 2 * b_w
finite_diff_w = np.diff(value_w) / np.diff(b_w)
print("b:", b_w)
print("optimal values:", value_w)
print("KKT multipliers:", mu_price_w)
print("finite-difference slopes between b's:", finite_diff_w)
assert np.allclose(mu_price_w, [1.0, 2.0, 3.0, 4.0])
```
▶ What you'll see: tighter lower bounds cost more as $b$ grows.

```python
plt.figure(figsize=(5, 3))
plt.plot(b_w, value_w, marker="o", label="optimal value b²")
plt.plot(b_w, mu_price_w, marker="s", label="multiplier 2b")
plt.title("7: μ as the price of tightening")
plt.xlabel("constraint bound b"); plt.legend(); plt.show()
```
▶ What you'll see: the multiplier follows the slope of the value curve.

```python
# Degenerate active constraints can break the usual necessity story.
x_cq_w = 0.0
g_degenerate_w = x_cq_w ** 2  # constraint x^2 <= 0 forces x=0, but its gradient is zero there.
grad_g_degenerate_w = 2 * x_cq_w
print("active g:", g_degenerate_w, "gradient of active constraint:", grad_g_degenerate_w)
assert grad_g_degenerate_w == 0.0
```
▶ What you'll see: the constraint is active, but its gradient provides no normal direction.

*Why it's done this way:* multipliers are not just algebraic tricks; they quantify sensitivity to constraints, which is why they become central in duality. Constraint qualifications are the technical assumptions that active gradients give meaningful normal directions. If those gradients degenerate, KKT may fail as a necessary condition even when an optimum exists.

### Basic 1 — Find the unconstrained minimum

**Goal.** Minimize a one-dimensional quadratic before adding constraints, because KKT modifies the familiar unconstrained condition $\nabla f=0$. We build it in 2 steps.

```python
x_b1 = np.linspace(-2, 2, 401)  # create a dense grid of candidate x values.
f_b1 = x_b1 ** 2  # evaluate f(x)=x^2 on the grid.
best_idx_b1 = int(np.argmin(f_b1))  # locate the smallest objective value.
print("best x:", x_b1[best_idx_b1], "best f:", f_b1[best_idx_b1])
assert abs(x_b1[best_idx_b1]) < 1e-12
```
▶ What you'll see: the unconstrained quadratic is minimized at x=0.

```python
plt.figure(figsize=(4, 3))
plt.plot(x_b1, f_b1, color="navy")
plt.scatter([x_b1[best_idx_b1]], [f_b1[best_idx_b1]], color="red")
plt.title("Basic 1: unconstrained bowl")
plt.xlabel("x"); plt.ylabel("x²"); plt.show()
```
▶ What you'll see: the lowest point of the bowl is exactly where the derivative is zero.

👀 Takeaway: unconstrained smooth minima happen where the objective gradient vanishes.

```python
print("number feasible:", int(np.sum(feasible_b2)), "of", x_b2.size)
```

**Goal.** Minimize $x^2$ over the legal half-line, because the wall changes the optimum. We build it in 2 steps.

```python
x_b3 = np.linspace(-1, 3, 401)  # candidate grid.
```

```python
x_b4 = 1.0  # boundary point for the constrained quadratic.
```

### Basic 5 — Compute a constraint gradient

**Goal.** Differentiate the wall $g(x)=1-x$, because the wall pushes along its normal. We build it in 2 steps.

```python
grad_g_b5 = -1.0  # derivative of g(x)=1-x.
wall_value_b5 = 1 - 1.0  # active constraint value at x=1.

```

```python
plt.figure(figsize=(4, 2.6))
plt.axvline(1, color="seagreen", label="wall x=1")
plt.arrow(1, 0, grad_g_b5 * 0.5, 0, head_width=0.06, color="blue", length_includes_head=True, label="∇g")

plt.show()
```
▶ What you'll see: $\nabla g$ points toward increasing constraint violation.

👀 Takeaway: constraint gradients provide the directions that can balance objective gradients.

### Basic 6 — Solve for one inequality multiplier

**Goal.** Find $\mu$ in $2+\mu(-1)=0$, because stationarity determines the boundary force. We build it in 2 steps.

```python
grad_f_b6 = 2.0  # objective derivative at x=1.
grad_g_b6 = -1.0  # constraint derivative for g=1-x.
mu_b6 = -grad_f_b6 / grad_g_b6  # solve grad_f + mu*grad_g = 0.
print("mu:", mu_b6)
assert mu_b6 == 2.0
```
▶ What you'll see: the active inequality multiplier is positive.

```python
residual_b6 = grad_f_b6 + mu_b6 * grad_g_b6  # stationarity residual.
print("stationarity residual:", residual_b6)
plt.figure(figsize=(4, 3))
plt.bar(["∇f", "μ∇g", "sum"], [grad_f_b6, mu_b6 * grad_g_b6, residual_b6], color=["red", "blue", "gray"])
plt.title("Basic 6: stationarity cancellation")
plt.show()
```
▶ What you'll see: the objective force and wall force sum to zero.

👀 Takeaway: stationarity is a vector balance equation, not just a derivative set to zero.

### Basic 7 — Check complementarity

**Goal.** Compute $\mu g(x)$ for active and inactive walls, because complementarity says at least one of those two factors must be zero. We build it in 2 steps.

```python

```
▶ What you'll see: both active and inactive cases satisfy $\mu g=0$ for different reasons.

```python

```
▶ What you'll see: only the active wall has a nonzero multiplier.

👀 Takeaway: complementarity does not mean every inequality is tight; it means slack walls have zero multiplier.
