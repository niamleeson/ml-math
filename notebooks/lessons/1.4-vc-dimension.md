# 1.4 · VC Dimension

VC dimension measures how many points a hypothesis class can label in every possible way. It replaces the unusable $\log|\mathcal{H}|$ count for infinite classes with a behavioral notion of capacity: what label patterns can the class actually realize on data?

## 📖 Concept walkthrough — build it from scratch

Before the terse worked examples, we build VC dimension one idea at a time. Run each cell in order and read the printed intermediate values — every combinatorial count is reproduced with tiny data, and every picture shows the labelings directly. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, combinatorics, and small numeric checks.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for any small random display choices.
```

### 1. Labelings and shattering: what must be realized?

A labeling of $m$ points is one assignment of $0/1$ labels to those points. There are $2^m$ possible labelings, and a class $\mathcal{H}$ **shatters** the points if some hypothesis in the class realizes every one of them. This is stricter than fitting one dataset: it asks whether the class can fit all possible dichotomies of the same inputs.

```python
points_w = np.array([0.2, 0.7, 1.1])  # Three fixed inputs on the line.
labelings_w = np.array([[int(b) for b in format(k, "03b")] for k in range(8)])  # All 2^3 labels.
print("m:", len(points_w))  # Number of points.
print("number of labelings:", len(labelings_w))  # Should be 2^3.
assert len(labelings_w) == 2 ** len(points_w)  # Ground the 2^m count.
```
▶ What you'll see: three points have exactly eight possible binary labelings.

```python
plt.figure(figsize=(5.2, 3.6))  # Draw all labelings as little rows.
for r_w, y_w in enumerate(labelings_w):  # One row per labeling.
    colors_w = np.where(y_w == 1, "crimson", "steelblue")  # Red = positive, blue = negative.
    plt.scatter(points_w, np.full_like(points_w, r_w), c=colors_w, s=80, edgecolor="k")  # Label points.
    plt.text(1.28, r_w, "".join(map(str, y_w)), va="center")  # Print the bit pattern.
plt.yticks([]); plt.xlabel("x"); plt.title("1: all 2^3 labelings of three points"); plt.show()
```
▶ What you'll see: eight rows, one for each possible way to color the same three points.

```python
needed_w = 2 ** 3  # A class must realize all eight patterns to shatter three points.
realized_demo_w = 6  # Pretend a toy class realizes only six of them.
print("needed to shatter:", needed_w, " realized by toy class:", realized_demo_w)  # Compare counts.
assert realized_demo_w < needed_w  # Missing even one labeling means no shattering.
```
▶ What you'll see: shattering fails unless the realized count equals the full $2^m$ count.

*Why it's done this way: VC dimension measures behavior on a fixed sample, so the first object to count is not hypotheses but the labelings those hypotheses can induce.*

### 2. Thresholds on the line have VC dimension 1

A threshold class $h_t(x)=\mathbf{1}[x>t]$ has infinitely many choices of $t$, but it is not infinitely expressive. One point can be labeled either way by placing $t$ above or below it, so $d\ge 1$. Two ordered points $a<b$ cannot get the pattern $(1,0)$, because once $a$ is positive, the larger $b$ must also be positive.

```python
x2_w = np.array([0.0, 1.0])  # Two ordered points a < b.
thresholds_w = np.array([-0.5, 0.5, 1.5])  # Representative threshold regions.
patterns_thr_w = []  # Store distinct labelings generated by thresholds.
for t_w in thresholds_w:  # Sweep thresholds across the line.
    y_w = (x2_w > t_w).astype(int)  # Threshold labels: positive to the right.
    patterns_thr_w.append(tuple(y_w))  # Save the labeling.
    print("t=", t_w, "labels=", y_w)  # Inspect each generated pattern.
patterns_thr_w = sorted(set(patterns_thr_w))  # Unique dichotomies.
print("realized:", patterns_thr_w)  # Missing (1, 0).
assert (1, 0) not in patterns_thr_w and len(patterns_thr_w) == 3  # Thresholds do not shatter two points.
```
▶ What you'll see: thresholds realize $(1,1)$, $(0,1)$, and $(0,0)$, but never $(1,0)$.

```python
plt.figure(figsize=(5, 2.6))  # Visualize the impossible labeling.
plt.scatter(x2_w, [0, 0], c=["crimson", "steelblue"], s=120, edgecolor="k")  # Want left positive, right negative.
plt.axvline(-0.25, color="gray", ls="--", label="t makes both positive")  # Left of both points.
plt.axvline(0.5, color="black", ls="--", label="t makes only right positive")  # Between points.
plt.ylim(-0.6, 0.8); plt.yticks([]); plt.xlabel("x"); plt.legend(loc="upper right")
plt.title("2: thresholds cannot make left positive and right negative"); plt.show()
```
▶ What you'll see: no vertical cut can put the left point on the positive side while leaving the right point negative.

```python
vc_threshold_w = 1  # Largest shattered set size for one-dimensional thresholds.
print("VC dimension of thresholds:", vc_threshold_w)  # Lesson result.
assert vc_threshold_w == 1  # Grounding: thresholds on the line have d = 1.
```
▶ What you'll see: an infinite threshold class still has finite VC dimension $1$.

*Why it's done this way: ordering forces monotone label patterns, and that logical constraint — not the number of parameter values — determines the VC dimension.*

### 3. Intervals on the line have VC dimension 2

An interval classifier $h_{[a,b]}(x)=\mathbf{1}[a\le x\le b]$ can shatter two points: choose an empty interval, a tiny interval around the left point, a tiny interval around the right point, or a wide interval covering both. But three ordered points $a<b<c$ break it: the labeling $(1,0,1)$ would require one interval to include both ends while excluding the middle.

```python
x_two_w = np.array([0.0, 1.0])  # Two points for the lower bound.
intervals_two_w = [(2, 3), (-0.2, 0.2), (0.8, 1.2), (-0.2, 1.2)]  # Realize 00, 10, 01, 11.
patterns_int2_w = []  # Store labels.
for a_w, b_w in intervals_two_w:  # Try four intervals.
    y_w = ((x_two_w >= a_w) & (x_two_w <= b_w)).astype(int)  # Inside interval = positive.
    patterns_int2_w.append(tuple(y_w))  # Save pattern.
    print((a_w, b_w), "->", y_w)  # Show construction.
assert set(patterns_int2_w) == {(0, 0), (1, 0), (0, 1), (1, 1)}  # Two points are shattered.
```
▶ What you'll see: all four labelings of two points are realized.

```python
x_three_w = np.array([0.0, 1.0, 2.0])  # Three ordered points.
bad_label_w = np.array([1, 0, 1])  # Ends positive, middle negative.
print("impossible interval labeling:", bad_label_w)  # The forbidden pattern.
assert bad_label_w.tolist() == [1, 0, 1]  # Ground the exact obstruction.
```
▶ What you'll see: the single-interval obstruction is the separated-positive pattern $(1,0,1)$.

```python
plt.figure(figsize=(5, 2.6))  # Draw the impossible three-point pattern.
plt.scatter(x_three_w, [0, 0, 0], c=np.where(bad_label_w == 1, "crimson", "steelblue"), s=120, edgecolor="k")  # Labels.
plt.plot([0, 2], [0.18, 0.18], color="crimson", lw=5, alpha=0.4, label="one interval covering both ends")  # Must include middle.
plt.ylim(-0.5, 0.7); plt.yticks([]); plt.xlabel("x"); plt.legend(loc="upper right")
plt.title("3: intervals cannot include both ends but exclude the middle"); plt.show()
```
▶ What you'll see: the interval segment connecting the positive endpoints necessarily passes over the negative middle point.

```python
vc_interval_w = 2  # Largest shattered set size for intervals.
print("VC dimension of intervals:", vc_interval_w)  # Lesson result.
assert vc_interval_w == 2  # Grounding: intervals have d = 2.
```
▶ What you'll see: intervals are richer than thresholds but still finite-capacity.

*Why it's done this way: intervals can carve one contiguous positive block, so two arbitrary points are possible but two separated positive blocks are not.*

### 4. Geometric classes: half-planes and rectangles

In $\mathbb{R}^2$, half-planes can shatter three points in general position but not four, so their VC dimension is $3$. Axis-aligned rectangles can shatter four points placed as top, bottom, left, and right extremes, but not every five-point set, so their VC dimension is $4$. These examples show how VC dimension grows with geometric flexibility, not just parameter count.

```python
tri_w = np.array([[0.0, 0.0], [1.0, 0.1], [0.3, 0.9]])  # Three non-collinear points.
line_normal_w = np.array([1.0, 1.0])  # A simple separator normal for one labeling.
score_w = tri_w @ line_normal_w  # Project points onto the normal.
labels_w = (score_w > 0.8).astype(int)  # One half-plane labeling.
print("triangle scores:", np.round(score_w, 2))  # Inspect side of the line.
print("one half-plane labeling:", labels_w)  # A sample realized labeling.
assert np.linalg.matrix_rank(np.c_[tri_w, np.ones(3)]) == 3  # General position: not collinear.
```
▶ What you'll see: non-collinear points give half-planes enough room to isolate label patterns.

```python
rect_pts_w = np.array([[0.0, 1.0], [1.0, 2.0], [2.0, 1.0], [1.0, 0.0]])  # Left, top, right, bottom points.
inside_w = (rect_pts_w[:, 0] >= 0.5) & (rect_pts_w[:, 0] <= 1.5) & (rect_pts_w[:, 1] >= 0.5) & (rect_pts_w[:, 1] <= 1.5)  # Center rectangle.
print("center rectangle labels:", inside_w.astype(int))  # It can pick no extreme point in this placement.
assert rect_pts_w.shape[0] == 4  # Four-point construction for rectangles.
```
▶ What you'll see: rectangles use independent $x$ and $y$ bounds, giving four degrees of geometric exclusion.

```python
plt.figure(figsize=(4.2, 4.0))  # Plot the rectangle construction.
plt.scatter(rect_pts_w[:, 0], rect_pts_w[:, 1], c="steelblue", s=110, edgecolor="k")  # Four extreme points.
plt.gca().add_patch(plt.Rectangle((0.5, 0.5), 1.0, 1.0, fill=False, lw=2, ec="crimson"))  # Example axis-aligned rectangle.
for i_w, p_w in enumerate(rect_pts_w): plt.text(p_w[0] + .04, p_w[1] + .04, f"p{i_w}")  # Label points.
plt.xlim(-.4, 2.4); plt.ylim(-.4, 2.4); plt.gca().set_aspect("equal")
plt.title("4: axis-aligned rectangles have VC dimension 4"); plt.show()
```
▶ What you'll see: four extreme points can be selected by moving the rectangle's four sides.

```python
vc_halfplane_w = 3  # Lesson result for half-planes in the plane.
vc_rectangle_w = 4  # Lesson result for axis-aligned rectangles.
print("VC half-planes:", vc_halfplane_w, " VC rectangles:", vc_rectangle_w)  # Report both.
assert vc_halfplane_w == 3 and vc_rectangle_w == 4  # Grounding: half-planes d=3, rectangles d=4.
```
▶ What you'll see: two familiar infinite geometric classes have small finite VC dimensions.

*Why it's done this way: drawing separators makes clear that VC dimension is a worst-case geometric shattering claim, with general position assumptions for half-planes.*

### 5. Growth function and Sauer's lemma

The growth function counts how many labelings a class can realize on $m$ points. If the VC dimension is $d$, Sauer's lemma says this count is at most $\sum_{i=0}^{d}\binom{m}{i}$, which grows polynomially in $m$ for fixed $d$. That polynomial ceiling is why finite VC dimension tames infinite classes and leads to sample complexity $O\big((d+\log\frac{1}{\delta})/\varepsilon\big)$ in the realizable case.

```python
def comb_w(n_w, k_w):  # Exact binomial coefficient using integer arithmetic.
    k_w = min(k_w, n_w - k_w)  # Use symmetry to keep the product short.
    out_w = 1  # Multiplicative accumulator.
    for j_w in range(1, k_w + 1):  # Build n choose k one factor at a time.
        out_w = out_w * (n_w - k_w + j_w) // j_w  # Integer division stays exact.
    return out_w  # Return C(n,k).

def sauer_w(m_w, d_w):  # Compute Sauer's lemma upper bound.
    return sum(comb_w(m_w, i_w) for i_w in range(d_w + 1))  # Sum binomial coefficients through d.

s_5_2_w = sauer_w(5, 2)  # 1 + 5 + 10.
all_5_w = 2 ** 5  # Arbitrary labelings of five points.
print("d=2, m=5: Sauer =", s_5_2_w, " all labelings =", all_5_w)  # Lesson number.
assert s_5_2_w == 16 and all_5_w == 32  # Grounding: 16 versus 32.
```
▶ What you'll see: a VC-2 class cannot realize all $32$ labelings once $m=5$; the ceiling is $16$.

```python
s_10_3_w = sauer_w(10, 3)  # 1 + 10 + 45 + 120.
all_10_w = 2 ** 10  # All possible labelings of ten points.
print("d=3, m=10: Sauer =", s_10_3_w, " all labelings =", all_10_w)  # Lesson number.
assert s_10_3_w == 176 and all_10_w == 1024  # Grounding: 176 versus 1024.
```
▶ What you'll see: $176$ grows much slower than $1024$, even though the class may contain infinitely many hypotheses.

```python
m_grid_w = np.arange(1, 16)  # Sample sizes to compare.
bound_d3_w = np.array([sauer_w(int(m_w), 3) for m_w in m_grid_w])  # Polynomial VC ceiling.
all_labels_w = 2 ** m_grid_w  # Exponential arbitrary labelings.
plt.figure(figsize=(5, 3.2)); plt.plot(m_grid_w, bound_d3_w, "o-", label="$\sum_{i=0}^{3}\binom{m}{i}$")  # Sauer curve.
plt.plot(m_grid_w, all_labels_w, "s--", label="$2^m$")  # Full labeling count.
plt.yscale("log"); plt.xlabel("m points"); plt.ylabel("labelings (log scale)"); plt.legend()
plt.title("5: Sauer ceiling vs arbitrary labels"); plt.show()
```
▶ What you'll see: the arbitrary-label curve pulls away exponentially from the VC-limited polynomial curve.

```python
eps_w, delta_w, d_w = 0.1, 0.05, 3  # A small realizable-bound illustration.
complexity_term_w = d_w + np.log(1 / max(delta_w, 1e-12))  # Guard the log and form d + log(1/delta).
print("d + log(1/delta) =", round(complexity_term_w, 3))  # Complexity term replacing log|H|.
print("scaled by 1/epsilon =", round(complexity_term_w / max(eps_w, 1e-12), 3))  # Sample-complexity scale.
assert round(complexity_term_w, 3) == 5.996  # Numerically ground the expression.
```
▶ What you'll see: $d$ steps into the role that $\log|\mathcal{H}|$ played for finite classes.

*Why it's done this way: Sauer's lemma converts shattering failure into a finite counting bound, which is exactly what PAC generalization arguments need.*

### ✍️ Toy 1 · Shattering means realizing all labelings

For `m` fixed points there are `2^m` binary labelings. Missing even one row means the points are not
shattered.

```python
import numpy as np                              # arrays + binary counting.
import matplotlib.pyplot as plt                 # one picture per toy.

t1_points = np.array([0, 1, 2])                 # three fixed inputs      # -> [0 1 2]
t1_labelings = np.array([[int(b) for b in format(t1_k, "03b")] for t1_k in range(8)])  # all labels  # -> 8 rows
t1_needed = 2 ** len(t1_points)                 # rows needed to shatter # -> 8
t1_realized = t1_labelings[:-1]                 # toy class misses 111   # -> 7 rows
t1_shattered = len(t1_realized) == t1_needed    # shattering test        # -> False
print("points:", t1_points.tolist())                            # -> [0, 1, 2]
print("needed labelings:", t1_needed)                            # -> 8
print("realized labelings:", len(t1_realized))                   # -> 7
print("shattered?:", t1_shattered)                               # -> False
assert t1_needed == 8 and not t1_shattered        # missing one labeling blocks shattering

plt.figure(figsize=(4.8, 3.0))
for t1_row, t1_y in enumerate(t1_labelings):
    plt.scatter(t1_points, np.full_like(t1_points, t1_row), c=np.where(t1_y == 1, "#e45756", "#4c78a8"), s=70, edgecolor="k")
plt.yticks([])
plt.xlabel("point index")
plt.title("Toy 1 · all 2^3 labelings")

```
▶ What you'll see: eight possible colorings, while the toy realized set has only seven.

### ✍️ Toy 2 · Thresholds miss the reversed two-point pattern

### ✍️ Toy 5 · Sauer's lemma caps the growth function

For VC dimension `d`, the realized-labeling count is bounded by a polynomial sum instead of all `2^m`
labelings.

```python
import numpy as np                              # arrays + logs.

def t5_comb(t5_n, t5_k):
    t5_out = 1                                  # accumulator            # -> starts at 1
    for t5_j in range(1, t5_k + 1):
        t5_out = t5_out * (t5_n - t5_k + t5_j) // t5_j  # exact binomial update
    return t5_out

t5_m = 6                                       # number of points        # -> 6
t5_d = 2                                       # VC dimension            # -> 2
t5_terms = np.array([t5_comb(t5_m, t5_i) for t5_i in range(t5_d + 1)])  # binomial terms  # -> [ 1  6 15]
t5_sauer = int(t5_terms.sum())                 # Sauer ceiling           # -> 22
```

```python
# !pip install numpy matplotlib  # Colab already has these; uncomment only if your runtime is missing them.
import numpy as np  # Import NumPy for arrays, combinatorics, and guarded numeric calculations.
import matplotlib.pyplot as plt  # Import Matplotlib for shattering diagrams, separator sketches, and growth curves.
np.random.seed(0)  # Fix the global random seed so every stochastic example is repeatable.
def all_labelings(m):  # Enumerate all binary labelings of m ordered points.
    return np.array([[int(b) for b in format(k, f"0{m}b")] for k in range(2 ** m)], dtype=int)  # Return a 2^m by m array.
def threshold_labels(x, t):  # Label points by a one-dimensional threshold h_t(x)=1[x>t].
    x = np.asarray(x, dtype=float)  # Convert inputs to floats for comparisons.
    return (x > t).astype(int)  # Positive labels live to the right of the threshold.
def interval_labels(x, a, b):  # Label points by membership in a closed interval [a,b].
    x = np.asarray(x, dtype=float)  # Convert inputs to floats for comparisons.
    lo, hi = min(a, b), max(a, b)  # Keep endpoints ordered even if a caller swaps them.
    return ((x >= lo) & (x <= hi)).astype(int)  # Positive labels are inside the interval.
def comb(n, k):  # Compute C(n,k) exactly without extra dependencies.
    n, k = int(n), int(k)  # Convert inputs to integers for counting.
    k = min(k, n - k)  # Use symmetry so the loop is short.
    out = 1  # Multiplicative accumulator.
    for j in range(1, k + 1):  # Multiply one factor at a time.
        out = out * (n - k + j) // j  # Integer arithmetic keeps the result exact.
    return out  # Return the binomial coefficient.
def sauer(m, d):  # Compute Sauer's lemma ceiling sum_{i=0}^d C(m,i).
    m, d = int(m), int(d)  # Convert inputs to integers for binomial coefficients.
    return sum(comb(m, i) for i in range(min(d, m) + 1))  # Cap at m and return the finite sum.
def draw_1d_labels(x, y, title):  # Draw colored one-dimensional point labels.
    plt.figure(figsize=(4.5, 1.6))  # Start a short strip figure.
    plt.scatter(x, np.zeros_like(x), c=np.where(np.asarray(y) == 1, "crimson", "steelblue"), s=110, edgecolor="k")  # Red positive, blue negative.
    plt.yticks([]); plt.xlabel("x"); plt.title(title); plt.show()  # Finish and display the strip plot.
```

#### A5. Demonstrate why infinite cardinality is not fatal

**Goal.** Compare infinitely many threshold parameters to their small realized labeling count on a finite sample. We build it in 2 steps.

```python
x_a5 = np.linspace(0, 1, 5)  # Five fixed sample points.
ts_a5 = np.linspace(-0.2, 1.2, 200)  # Many threshold values approximating a continuum.
patterns_a5 = {tuple(threshold_labels(x_a5, t)) for t in ts_a5}  # Distinct behaviors on the sample.
```

▶ What you'll see: hundreds of thresholds collapse to only six labelings on five points.

```python
plt.figure(figsize=(4.5, 3)); plt.bar(["threshold values", "behaviors"], [len(ts_a5), len(patterns_a5)], color=["gray", "seagreen"])  # Compare.
```
