# 17.2 — Domain Adaptation & Generalization

Domain adaptation asks a model to keep the label rule while the input distribution changes from a **source** domain to a **target** domain. In this lesson, we build the mechanics from scratch: measuring covariate shift, reweighting source examples to look like target examples, aligning feature distributions, and learning representations that hide domain identity without deleting label information.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build domain adaptation one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including importance weights and feature alignment, is shown directly. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, random simulation, and linear algebra for domain-shift demos.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
```

### 1. Two domains can have the same label rule but different feature distributions

A **domain** is the joint data-generating setting: what inputs appear and how labels are assigned. Domain adaptation is easiest to understand under **covariate shift**: the feature distribution changes from source to target, but the conditional label rule stays the same. Here the label is determined by the first coordinate, while the second coordinate is a nuisance coordinate whose mean shifts between domains.

```python
n_w = 80  # number of examples per domain.
rng_w = np.random.default_rng(0)  # local generator so this walkthrough is reproducible.
x1_s_w = rng_w.normal(0.0, 1.0, n_w)  # source label feature.
x2_s_w = rng_w.normal(0.0, 0.35, n_w)  # source nuisance feature.
x1_t_w = rng_w.normal(0.0, 1.0, n_w)  # target label feature uses the same distribution.
x2_t_w = rng_w.normal(1.0, 0.35, n_w)  # target nuisance feature is shifted by about +1.
X_s_w = np.column_stack([x1_s_w, x2_s_w])  # source feature matrix.
X_t_w = np.column_stack([x1_t_w, x2_t_w])  # target feature matrix.
y_s_w = (X_s_w[:, 0] > 0).astype(int)  # same label rule: positive first coordinate.
y_t_w = (X_t_w[:, 0] > 0).astype(int)  # same rule in the target domain.
print("source mean:", np.round(X_s_w.mean(axis=0), 3))  # inspect feature means.
print("target mean:", np.round(X_t_w.mean(axis=0), 3))  # inspect the shifted nuisance mean.
```
▶ What you'll see: the first-coordinate means are similar, but the second coordinate is much larger in the target domain.

```python
plt.figure(figsize=(4.6, 3.6))  # create a compact source-target scatter plot.
plt.scatter(X_s_w[:, 0], X_s_w[:, 1], c=y_s_w, cmap="coolwarm", marker="o", alpha=0.75, label="source")  # source points.
plt.scatter(X_t_w[:, 0], X_t_w[:, 1], c=y_t_w, cmap="coolwarm", marker="^", alpha=0.75, label="target")  # target points.
plt.axvline(0, color="black", linewidth=1, linestyle="--")  # the true label boundary.
plt.title("1: same label rule, shifted nuisance feature")  # title the plot.
plt.xlabel("label feature x0")  # x-axis label.
plt.ylabel("domain-shift feature x1")  # y-axis label.
plt.legend()  # show marker meanings.
plt.show()  # display the scatter.
```
▶ What you'll see: color changes at x0 = 0 in both domains, while triangle target points sit higher on the nuisance axis.

*Why it's done this way: separating a label coordinate from a nuisance coordinate lets us see the adaptation problem cleanly — not every distributional difference is task information, and the model should not confuse domain identity with the label rule.*

### 2. Mean discrepancy measures a simple domain gap

A first diagnostic is the squared distance between source and target feature means, $$\lVert\mu_S-\mu_T\rVert_2^2.$$ It is not a full distribution distance, but it exposes the lesson's core numeric example: if $\mu_S=(0,0)$ and $\mu_T=(1,-0.5)$, the discrepancy is $1^2+(-0.5)^2=1.250$.

```python
mu_s_w = np.array([0.0, 0.0])  # source feature mean from the worked example.
mu_t_w = np.array([1.0, -0.5])  # target feature mean from the worked example.
delta_w = mu_t_w - mu_s_w  # direction and size of the domain shift.
disc_w = float(np.sum(delta_w ** 2))  # squared L2 discrepancy.
print("mu_T - mu_S:", delta_w)  # inspect the shift vector.
print("squared mean discrepancy:", round(disc_w, 3))  # 1.25.
assert round(disc_w, 3) == 1.250  # concrete lesson number.
```
▶ What you'll see: the shift vector is `[1, -0.5]` and its squared length is 1.250.

```python
plt.figure(figsize=(4.4, 3.4))  # create a vector diagram.
plt.scatter([mu_s_w[0]], [mu_s_w[1]], s=100, label="μS", color="steelblue")  # source mean.
plt.scatter([mu_t_w[0]], [mu_t_w[1]], s=100, label="μT", color="darkorange")  # target mean.
plt.arrow(mu_s_w[0], mu_s_w[1], delta_w[0], delta_w[1], head_width=0.06, length_includes_head=True, color="black")  # shift arrow.
plt.xlim(-0.3, 1.3); plt.ylim(-0.8, 0.3)  # readable limits.
plt.title("2: mean-discrepancy vector")  # title.
plt.xlabel("feature 0"); plt.ylabel("feature 1")  # labels.
plt.legend(); plt.show()  # display.
```
▶ What you'll see: the discrepancy is literally the squared length of the arrow from source mean to target mean.

*Why it's done this way: the squared norm decomposes feature by feature, so it tells us exactly which directions separate domains; adaptation can then decide whether those directions are nuisance shifts to remove or label information to preserve.*

### 3. Covariate shift breaks naive source-only validation

A source-trained rule can look good on source data while failing on target data if it uses a shifted nuisance feature. The bad rule below predicts using the domain-shift coordinate; the good rule predicts using the invariant label coordinate. Both are simple thresholds, so any difference in target error comes from the feature choice, not model complexity.

```python
pred_bad_s_w = (X_s_w[:, 1] > 0.5).astype(int)  # wrong: uses the nuisance coordinate.
pred_bad_t_w = (X_t_w[:, 1] > 0.5).astype(int)  # same wrong rule applied to target.
pred_good_s_w = (X_s_w[:, 0] > 0).astype(int)  # right: uses the shared label rule.
pred_good_t_w = (X_t_w[:, 0] > 0).astype(int)  # same invariant rule on target.
err_bad_s_w = np.mean(pred_bad_s_w != y_s_w)  # source error of the nuisance rule.
err_bad_t_w = np.mean(pred_bad_t_w != y_t_w)  # target error of the nuisance rule.
err_good_t_w = np.mean(pred_good_t_w != y_t_w)  # target error of the invariant rule.
print("bad source error:", round(err_bad_s_w, 3), "bad target error:", round(err_bad_t_w, 3))  # compare domains.
print("good target error:", round(err_good_t_w, 3))  # invariant rule should be perfect here.
assert err_good_t_w == 0.0  # the synthetic label rule is exactly x0 > 0.
```
▶ What you'll see: the nuisance rule has a different error profile across domains, while the invariant rule keeps target error at 0.

```python
plt.figure(figsize=(4.5, 3))  # compact comparison chart.
plt.bar(["bad/source", "bad/target", "good/target"], [err_bad_s_w, err_bad_t_w, err_good_t_w], color=["gray", "crimson", "seagreen"])  # plot errors.
plt.ylabel("classification error")  # y-axis.
plt.title("3: source behavior does not certify target behavior")  # title.
plt.xticks(rotation=15)  # readable labels.
plt.show()  # display chart.
```
▶ What you'll see: target validation is the one that reveals whether the learned rule survives the shift.

*Why it's done this way: source risk estimates performance under the source distribution only; when $p_S(x)\ne p_T(x)$, minimizing source loss can reward features that are predictive of source quirks rather than the target task.*

### 4. Importance weighting makes source averages look like target averages

Under covariate shift, one classical correction is **importance weighting**. If labels are governed by the same conditional rule but inputs have different densities, a target expectation can be rewritten as $$\mathbb E_T[f(X)] = \mathbb E_S\left[\frac{p_T(X)}{p_S(X)} f(X)\right].$$ Points common under target and rare under source receive large weights; source-only regions receive small weights.

```python
x_w = rng_w.normal(0.0, 1.0, 4000)  # source samples from N(0,1).
target_mu_w = 1.0  # target distribution is N(1,1).
weights_w = np.exp(-0.5 * ((x_w - target_mu_w) ** 2 - x_w ** 2))  # p_T(x)/p_S(x) for equal-variance Gaussians.
plain_mean_w = float(np.mean(x_w))  # source estimate of E[X].
weighted_mean_w = float(np.sum(weights_w * x_w) / np.sum(weights_w))  # importance-weighted target estimate.
print("unweighted source mean:", round(plain_mean_w, 3))  # near 0.
print("importance-weighted mean:", round(weighted_mean_w, 3))  # near target mean 1.
assert abs(weighted_mean_w - 1.0) < 0.08  # weighted source samples recover the target mean.
```
▶ What you'll see: the unweighted source mean is near 0, while the weighted mean moves close to the target mean 1.

```python
bins_w = np.linspace(-3, 4, 45)  # shared bins for comparing histograms.
plt.figure(figsize=(5, 3))  # compact density plot.
plt.hist(x_w, bins=bins_w, density=True, alpha=0.35, label="source samples")  # source histogram.
plt.hist(x_w, bins=bins_w, weights=weights_w, density=True, alpha=0.45, label="weighted as target")  # weighted source histogram.
plt.axvline(0, color="steelblue", linestyle="--", label="source mean")  # source reference.
plt.axvline(1, color="darkorange", linestyle="--", label="target mean")  # target reference.
plt.title("4: importance weighting reshapes source mass")  # title.
plt.legend(); plt.show()  # display.
```
▶ What you'll see: weighting tilts the source histogram toward the target region around x = 1.

*Why it's done this way: the density ratio is the algebraic price of changing the measure from source to target; it corrects averages without changing labels, but it becomes high-variance when the target puts mass where the source has almost no samples.*

### 5. Feature alignment removes a nuisance shift

A simple adaptation map subtracts the estimated domain shift from target features: $$x_T' = x_T - (\mu_T-\mu_S).$$ If the shift direction is nuisance, this makes target features comparable to source features. The worked mean example has discrepancy 1.250 before alignment and 0.000 after alignment.

```python
X_demo_s_w = np.array([[0.0, 0.0], [0.2, -0.2], [-0.2, 0.2]])  # tiny source cloud centered at (0,0).
shift_w = np.array([1.0, -0.5])  # known target shift.
X_demo_t_w = X_demo_s_w + shift_w  # target cloud is the same shape but shifted.
mu_demo_s_w = X_demo_s_w.mean(axis=0)  # source mean.
mu_demo_t_w = X_demo_t_w.mean(axis=0)  # target mean.
before_w = float(np.sum((mu_demo_t_w - mu_demo_s_w) ** 2))  # discrepancy before alignment.
print("before alignment discrepancy:", round(before_w, 3))  # 1.25.
assert round(before_w, 3) == 1.250  # concrete number from the lesson.
```
▶ What you'll see: the target cloud is displaced by the same vector from concept 2.

```python
estimated_shift_w = mu_demo_t_w - mu_demo_s_w  # estimate target-source mean shift.
X_aligned_t_w = X_demo_t_w - estimated_shift_w  # subtract shift to align target to source.
after_w = float(np.sum((X_aligned_t_w.mean(axis=0) - mu_demo_s_w) ** 2))  # post-alignment discrepancy.
print("estimated shift:", np.round(estimated_shift_w, 3))  # should be [1,-0.5].
print("after alignment discrepancy:", round(after_w, 3))  # 0.
assert round(after_w, 3) == 0.000  # aligned means coincide.
```
▶ What you'll see: subtracting the shift drives the mean discrepancy to zero.

```python
plt.figure(figsize=(4.6, 3.4))  # compact alignment plot.
plt.scatter(X_demo_s_w[:, 0], X_demo_s_w[:, 1], label="source", color="steelblue")  # source cloud.
plt.scatter(X_demo_t_w[:, 0], X_demo_t_w[:, 1], label="target before", color="crimson", marker="^")  # shifted target.
plt.scatter(X_aligned_t_w[:, 0], X_aligned_t_w[:, 1], label="target aligned", color="seagreen", marker="x", s=80)  # aligned target.
plt.title("5: subtracting target-source mean shift")  # title.
plt.legend(); plt.show()  # display.
```
▶ What you'll see: green aligned target points sit on top of the blue source points.

*Why it's done this way: matching moments is the smallest possible feature-alignment objective; it works when the mismatched moment is nuisance variation, but it can harm the task if the shifted coordinate carries label information.*

### 6. Domain-adversarial intuition: keep labels, hide domains

Domain-adversarial learning asks for a representation $z=g(x)$ that supports label prediction but makes domain prediction hard. We can show the idea without neural networks: compare two candidate representations. One keeps both coordinates, so a domain classifier can read the shifted nuisance coordinate. The other keeps only the label coordinate, so domain identity is much harder to infer while label accuracy remains high.

```python
def threshold_error_w(values, labels):  # find the best one-dimensional threshold classifier error.
    thresholds = np.linspace(values.min(), values.max(), 80)  # candidate cut points.
    errs = []  # store best orientation error per threshold.
    for th in thresholds:  # sweep thresholds.
        pred = (values > th).astype(int)  # one orientation.
        errs.append(min(np.mean(pred != labels), np.mean((1 - pred) != labels)))  # allow flipped orientation.
    return float(np.min(errs))  # best achievable error.

X_all_w = np.vstack([X_s_w, X_t_w])  # combine domains.
domain_w = np.r_[np.zeros(n_w, dtype=int), np.ones(n_w, dtype=int)]  # 0=source, 1=target.
y_all_w = np.r_[y_s_w, y_t_w]  # labels from both domains.
domain_err_raw_w = threshold_error_w(X_all_w[:, 1], domain_w)  # domain classifier on nuisance coordinate.
domain_err_inv_w = threshold_error_w(X_all_w[:, 0], domain_w)  # domain classifier on invariant label coordinate.
label_err_inv_w = threshold_error_w(X_all_w[:, 0], y_all_w)  # label classifier on invariant coordinate.
print("domain error using nuisance feature:", round(domain_err_raw_w, 3))  # low = domains easy.
print("domain error using invariant feature:", round(domain_err_inv_w, 3))  # higher = domains hidden.
print("label error using invariant feature:", round(label_err_inv_w, 3))  # low = label retained.
assert label_err_inv_w < 0.02  # invariant coordinate keeps the task.
```
▶ What you'll see: the nuisance coordinate makes domain classification easy; the invariant coordinate keeps label error near zero.

```python
plt.figure(figsize=(4.8, 3))  # compact adversarial objective plot.
plt.bar(["domain from x1", "domain from x0", "label from x0"], [domain_err_raw_w, domain_err_inv_w, label_err_inv_w], color=["crimson", "seagreen", "steelblue"])  # compare errors.
plt.ylabel("best threshold error")  # y-axis.
plt.title("6: invariant features hide domain but keep label")  # title.
plt.xticks(rotation=15)  # readable labels.
plt.show()  # display.
```
▶ What you'll see: the desired representation has high domain error and low label error.

*Why it's done this way: adversarial alignment is a tug-of-war — the label predictor pushes representations to preserve task signal, while the domain predictor pushes them to erase domain-specific signal; success requires erasing nuisance variation, not useful class variation.*

### Basic 6 — Compute a Gaussian importance weight

**Goal.** Calculate one density ratio by hand, because importance weighting is just target density divided by source density at the same point. We build it in 2 steps.

```python
x_b6 = 1.0 # choose one source sample location.
mu_source_b6 = 0.0 # source is N(0,1).
mu_target_b6 = 1.0 # target is N(1,1).
log_ratio_b6 = -0.5 * ((x_b6 - mu_target_b6) ** 2 - (x_b6 - mu_source_b6) ** 2) # log p_T(x)-log p_S(x) with equal variances.
print("log density ratio:", round(log_ratio_b6, 3)) # inspect the stable log form.
```
▶ What you'll see: the log ratio is positive because x = 1 is more typical under the target.

```python
weight_b6 = float(np.exp(log_ratio_b6)) # exponentiate to get p_T(x)/p_S(x).
print("importance weight:", round(weight_b6, 3)) # inspect the multiplicative weight.
assert round(weight_b6, 3) == 1.649 # verify exp(0.5).
plt.figure(figsize=(4, 3)) # create a tiny weight plot.
plt.bar(["weight at x=1"], [weight_b6], color="purple") # plot the one ratio.
plt.axhline(1, color="gray", linestyle="--") # no-reweighting reference.
plt.title("Basic 6: target/source density ratio") # title.
plt.show() # display.
```
▶ What you'll see: the weight is above 1, so this source example counts more for target risk.

### Advanced 1 — Importance-weighted linear regression

**Goal.** Fit a linear model under covariate shift with weighted least squares, because target-like source examples should dominate the normal equations. We build it in 4 steps.

```python
rng_a1 = np.random.default_rng(21) # local reproducible randomness.
x_a1 = rng_a1.normal(0.0, 1.0, 600) # source inputs.
y_a1 = 2.0 * x_a1 + 1.0 + rng_a1.normal(0.0, 0.35, 600) # shared regression rule with noise.
w_a1 = np.exp(-0.5 * ((x_a1 - 1.5) ** 2 - x_a1 ** 2)) # target/source ratio for target N(1.5,1).
Phi_a1 = np.column_stack([np.ones_like(x_a1), x_a1]) # design matrix with intercept and slope.
print("weight range:", round(float(w_a1.min()), 3), round(float(w_a1.max()), 3)) # inspect ratio spread.
```
▶ What you'll see: weights vary substantially because the target lives to the right of the source.

```python
coef_plain_a1 = np.linalg.solve(Phi_a1.T @ Phi_a1, Phi_a1.T @ y_a1) # ordinary least squares.
Wphi_a1 = Phi_a1 * w_a1[:, None] # multiply each row by its importance weight for weighted normal equations.
coef_weighted_a1 = np.linalg.solve(Phi_a1.T @ Wphi_a1, Phi_a1.T @ (w_a1 * y_a1)) # weighted least squares.
```

### Advanced 2 — Clip extreme weights and inspect bias-variance tradeoff

**Goal.** Clip large importance weights, because unbounded density ratios can reduce effective sample size even when the formula is unbiased. We build it in 4 steps.

```python
rng_a2 = np.random.default_rng(22) # local randomness.
x_a2 = rng_a2.normal(0.0, 1.0, 5000) # source samples.
w_raw_a2 = np.exp(-0.5 * ((x_a2 - 2.0) ** 2 - x_a2 ** 2)) # large-shift target/source ratio.
clips_a2 = np.array([2.0, 5.0, 10.0, 50.0]) # clipping thresholds.
print("raw max weight:", round(float(w_raw_a2.max()), 1)) # inspect unbounded-looking weight tail.
```
▶ What you'll see: the raw maximum weight is much larger than typical weights.

```python
means_a2 = [] # store weighted mean estimates.
ess_a2 = [] # store effective sample sizes.
for clip_a2 in clips_a2: # evaluate each clipping threshold.
    w_clip_a2 = np.minimum(w_raw_a2, clip_a2) # clip extreme ratios.
    means_a2.append(float(np.sum(w_clip_a2 * x_a2) / np.sum(w_clip_a2))) # weighted mean estimate.
    ess_a2.append(float((np.sum(w_clip_a2) ** 2) / np.sum(w_clip_a2 ** 2))) # effective sample size.
print("clipped means:", np.round(means_a2, 3)) # inspect bias toward target mean 2.
print("ESS:", np.round(ess_a2)) # inspect variance proxy.
```

```python

assert means_a2[-1] > means_a2[0] # less clipping moves the estimate closer to target mean 2.

plt.legend(); plt.show() # display.
```
▶ What you'll see: heavier clipping stabilizes weights but pulls the estimate away from the true target mean.

```python
plt.figure(figsize=(5, 3)) # create ESS plot.
```

▶ What you'll see: allowing larger weights lowers the effective sample size.

### Advanced 3 — Align covariance, not just means

**Goal.** Match both mean and scale for a one-dimensional feature, because domains can differ in variance even after their means agree. We build it in 4 steps.

```python
rng_a3 = np.random.default_rng(23) # local randomness.
```


### Advanced 4 — Tune an alignment strength

**Goal.** Sweep how much of a target shift to subtract, because over-strengthening alignment can remove useful task information or under-correct a real nuisance shift. We build it in 4 steps.


▶ What you'll see: the estimated shift points mostly along feature 1.


### Advanced 5 — Multi-source invariant feature selection

**Goal.** Choose a feature that predicts labels consistently across multiple source domains, because domain generalization must learn invariants before seeing the target. We build it in 4 steps.

```python
rng_a5 = np.random.default_rng(25) # local reproducible randomness.
n_a5 = 160 # examples per source domain.
x0_d1_a5 = rng_a5.normal(0.0, 1.0, n_a5) # invariant label feature in domain 1.
x0_d2_a5 = rng_a5.normal(0.0, 1.0, n_a5) # invariant label feature in domain 2.
y_d1_a5 = (x0_d1_a5 > 0).astype(int) # labels domain 1.
y_d2_a5 = (x0_d2_a5 > 0).astype(int) # labels domain 2.
x1_d1_a5 = y_d1_a5 + rng_a5.normal(0.0, 0.25, n_a5) # spurious feature positively correlated in domain 1.
x1_d2_a5 = (1 - y_d2_a5) + rng_a5.normal(0.0, 0.25, n_a5) # spurious feature flips correlation in domain 2.
X_d1_a5 = np.column_stack([x0_d1_a5, x1_d1_a5]) # source domain 1.
X_d2_a5 = np.column_stack([x0_d2_a5, x1_d2_a5]) # source domain 2.
print("domain positive rates:", round(float(y_d1_a5.mean()), 3), round(float(y_d2_a5.mean()), 3)) # inspect label balance.
```
▶ What you'll see: both source domains have similar label rates but different spurious correlations.

```python
def stump_error_a5(values_a5, labels_a5): # best threshold-stump error for one feature.
    thresholds_a5 = np.linspace(values_a5.min(), values_a5.max(), 100) # candidate thresholds.
    best_a5 = 1.0 # initialize.
    for th_a5 in thresholds_a5: # sweep thresholds.
        pred_a5 = (values_a5 > th_a5).astype(int) # threshold prediction.
        best_a5 = min(best_a5, np.mean(pred_a5 != labels_a5), np.mean((1 - pred_a5) != labels_a5)) # allow flipped orientation.
    return float(best_a5) # return best error.

errors_d1_a5 = np.array([stump_error_a5(X_d1_a5[:, 0], y_d1_a5), stump_error_a5(X_d1_a5[:, 1], y_d1_a5)]) # feature errors in domain 1.
errors_d2_a5 = np.array([stump_error_a5(X_d2_a5[:, 0], y_d2_a5), stump_error_a5(X_d2_a5[:, 1], y_d2_a5)]) # feature errors in domain 2.
worst_source_a5 = np.maximum(errors_d1_a5, errors_d2_a5) # robust source criterion.
print("domain1 feature errors:", np.round(errors_d1_a5, 3)) # inspect d1.
print("domain2 feature errors:", np.round(errors_d2_a5, 3)) # inspect d2.
```

```python
chosen_feature_a5 = int(np.argmin(worst_source_a5)) # choose feature with best worst-domain error.
print("worst-domain errors:", np.round(worst_source_a5, 3)) # inspect robust criterion.

assert chosen_feature_a5 == 0 # verify multi-source selection picks invariant x0.
```

