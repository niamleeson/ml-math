# 10.17 — Autoregressive Generation (PixelCNN, WaveNet)

Autoregressive generation models a complicated object by choosing an order and predicting one value at a time. PixelCNN does this for images with masked convolutions, WaveNet does it for audio with causal and dilated convolutions, and both trade slower sequential sampling for an exact, auditable likelihood.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build autoregressive generation one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including masking, causality, and dilation, is shown directly in NumPy. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

import numpy as np  # arrays, probabilities, masks, and from-scratch convolutions.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for sampling demos.

### 1. Chain-rule likelihood: a joint distribution as small conditionals

Autoregressive modeling starts with the probability chain rule. Instead of assigning one giant table to a whole image or waveform, we choose an ordering and multiply simple conditional probabilities: $p(x_1,\ldots,x_D)=\prod_i p(x_i\mid x_{<i})$. In log space the product becomes a sum, which is numerically safer and exactly matches the negative log-likelihood used for training.

```python
cond_probs_w = np.array([0.5, 0.7, 0.2])  # p(x1), p(x2|x1), p(x3|x1,x2).
joint_w = float(np.prod(cond_probs_w))  # chain-rule product.
nll_w = float(-np.sum(np.log(cond_probs_w)))  # negative log-likelihood.
print("conditional probabilities:", cond_probs_w)
print("joint probability:", round(joint_w, 4))
print("negative log-likelihood:", round(nll_w, 3))
assert round(joint_w, 4) == 0.07
assert round(nll_w, 3) == 2.659
```
▶ What you'll see: the sequence probability is `0.0700`, and its negative log-likelihood is `2.659`.

```python
terms_w = -np.log(cond_probs_w)  # each time step's contribution to total NLL.
plt.figure(figsize=(4.4, 3))
plt.bar(["x1", "x2", "x3"], terms_w, color="teal")
plt.title("1: NLL is a sum of per-step surprises")
plt.ylabel("-log conditional probability")
plt.show()
```
▶ What you'll see: the smallest conditional probability, 0.2, creates the tallest loss bar.

*Why it's done this way:* multiplying conditionals is not an approximation — it is the chain rule. Training uses the log because products of many probabilities become tiny, while sums of `-log p` stay stable and reveal which step made the whole object unlikely.

### 2. Ordering and context: what is allowed to influence the next value?

The model must choose an order. For a toy image, raster order means left-to-right within a row, then top-to-bottom across rows. The conditional for one pixel can use only earlier raster positions. If a future pixel enters the computation, the likelihood is no longer $p(x_i\mid x_{<i})$; it is cheating with information unavailable during generation.

```python
img_w = np.array([[0, 1, 0],
                  [1, 1, 0],
                  [0, 0, 1]], dtype=float)  # tiny binary image.
order_w = np.arange(img_w.size).reshape(img_w.shape)  # raster position id for each pixel.
target_w = (1, 1)  # center pixel in the 3x3 image.
allowed_w = order_w < order_w[target_w]  # previous raster positions only.
print("raster order ids:\n", order_w)
print("target id:", int(order_w[target_w]))
print("allowed previous pixels:\n", allowed_w.astype(int))
```
▶ What you'll see: the center pixel may use the whole first row and the left pixel in its row, but not itself or anything after it.

```python
plt.figure(figsize=(4, 3))
plt.imshow(allowed_w, cmap="Greens", vmin=0, vmax=1)
plt.scatter([target_w[1]], [target_w[0]], c="red", s=90, label="target")
plt.title("2: context allowed by raster order")
plt.xticks(range(3)); plt.yticks(range(3)); plt.legend()
plt.show()
```
▶ What you'll see: green cells are legal context; the red target and all future cells are blocked.

*Why it's done this way:* an ordering converts a high-dimensional object into a sequence. The cost is asymmetry: dependencies that are nearby in the image but later in raster order cannot be used for the current conditional, so the model architecture must enforce the same ordering that the probability formula assumes.

### 3. PixelCNN masking: convolution without future leakage

A convolution normally looks at a full local window, including the center and future pixels. PixelCNN fixes that with a binary mask on the kernel. A type-A mask excludes the center pixel for the first layer; a type-B mask can include the center of the hidden representation but still excludes future spatial positions.

```python
kernel_w = np.ones((3, 3), dtype=float)  # inspectable all-ones kernel.
mask_a_w = np.array([[1, 1, 1],
                     [1, 0, 0],
                     [0, 0, 0]], dtype=float)  # previous rows + previous columns only.
mask_b_w = np.array([[1, 1, 1],
                     [1, 1, 0],
                     [0, 0, 0]], dtype=float)  # center allowed for hidden-to-hidden layers.
print("type-A masked kernel:\n", kernel_w * mask_a_w)
print("type-B masked kernel:\n", kernel_w * mask_b_w)
assert int(mask_a_w.sum()) == 4 and int(mask_b_w.sum()) == 5
```
▶ What you'll see: future positions in the convolution window are forced to zero.

```python
def masked_conv2d_single_w(X_w, K_w, M_w):
    pad_w = K_w.shape[0] // 2
    Xp_w = np.pad(X_w, pad_w)
    out_w = np.zeros_like(X_w, dtype=float)
    for r_w in range(X_w.shape[0]):
        for c_w in range(X_w.shape[1]):
            patch_w = Xp_w[r_w:r_w + K_w.shape[0], c_w:c_w + K_w.shape[1]]
            out_w[r_w, c_w] = np.sum(patch_w * K_w * M_w)
    return out_w

out_a_w = masked_conv2d_single_w(img_w, kernel_w, mask_a_w)
out_b_w = masked_conv2d_single_w(img_w, kernel_w, mask_b_w)
print("type-A output:\n", out_a_w)
print("type-B output:\n", out_b_w)
assert out_a_w[target_w] == 2.0 and out_b_w[target_w] == 3.0
```
▶ What you'll see: the type-B output at the center is one larger because it includes the center value itself.

```python
fig, ax = plt.subplots(1, 3, figsize=(8, 2.6))
for a_w, data_w, title_w in zip(ax, [img_w, out_a_w, out_b_w], ["image", "type-A context sum", "type-B context sum"]):
    a_w.imshow(data_w, cmap="viridis")
    a_w.set_title(title_w)
    a_w.set_xticks(range(3)); a_w.set_yticks(range(3))
plt.tight_layout(); plt.show()
```
▶ What you'll see: masked convolution produces a context summary at every pixel while respecting the generation order.

*Why it's done this way:* convolution is efficient because the same kernel scans every location, but raw convolution violates autoregressive likelihood by seeing the answer. Multiplying the kernel by a mask makes the architectural dependency graph match $x_{<i}$ exactly.

### 4. WaveNet causality and dilation: more history without peeking ahead

For audio, the sequence is one-dimensional time. A causal convolution at time $t$ can use $x_t, x_{t-1}, \ldots$ but not $x_{t+1}$. Dilation spaces the taps apart, so a small kernel can see far back: with kernel size 2 and dilations 1, 2, 4, a stack covers 8 time steps using only three layers.

```python
x_w = np.arange(8, dtype=float)  # toy waveform samples 0..7.
filter_w = np.array([0.4, 0.6])  # weight older sample and current sample.

def causal_conv1d_w(x_w, filt_w, dilation_w=1):
    y_w = np.zeros_like(x_w, dtype=float)
    for t_w in range(len(x_w)):
        total_w = 0.0
        for j_w, weight_w in enumerate(filt_w):
            idx_w = t_w - dilation_w * (len(filt_w) - 1 - j_w)
            if idx_w >= 0:
                total_w += weight_w * x_w[idx_w]
        y_w[t_w] = total_w
    return y_w

y1_w = causal_conv1d_w(x_w, filter_w, dilation_w=1)
y2_w = causal_conv1d_w(x_w, filter_w, dilation_w=2)
print("dilation 1:", np.round(y1_w, 2))
print("dilation 2:", np.round(y2_w, 2))
assert round(float(y2_w[5]), 2) == 4.2
```
▶ What you'll see: dilation 2 at time 5 mixes samples 3 and 5, skipping sample 4.

```python
layers_w = [1, 2, 4]
reachable_w = {7}
for d_w in layers_w:
    new_w = set()
    for t_w in reachable_w:
        new_w.add(t_w)
        new_w.add(t_w - d_w)
    reachable_w = {t_w for t_w in new_w if t_w >= 0}
print("times that can affect output t=7:", sorted(reachable_w))
assert sorted(reachable_w) == list(range(8))
```
▶ What you'll see: three dilated layers make every sample from 0 through 7 able to influence output time 7.

```python
plt.figure(figsize=(5, 3))
plt.stem(x_w, linefmt="gray", markerfmt="ko", basefmt=" ", label="input")
plt.plot(y2_w, marker="o", color="crimson", label="causal conv, dilation=2")
plt.title("4: causal convolution never uses future samples")
plt.xlabel("time"); plt.legend(); plt.show()
```
▶ What you'll see: each output depends only on current and past samples, so the curve is smoothed without looking rightward.

*Why it's done this way:* audio needs long context, but a wide undilated filter is expensive and many layers of dilation grow the receptive field exponentially. Causality preserves valid likelihood; dilation makes the allowed past large enough to model rhythm and phonemes.

### 5. Sequential sampling and the speed/likelihood tradeoff

Once conditionals are learned, sampling is a loop: compute the distribution for the next value, draw it, append it, and repeat. The same factorization gives exact likelihood for a completed object, but generation cannot fill all positions independently because each new variable becomes context for later variables.

```python
def sigmoid_w(z_w):
    return 1.0 / (1.0 + np.exp(-z_w))

seq_w = []
for t_w in range(6):
    prev_w = seq_w[-1] if seq_w else 0.0
    p1_w = sigmoid_w(-0.4 + 1.2 * prev_w)  # toy learned conditional p(x_t=1 | previous bit).
    bit_w = int(np.random.rand() < p1_w)
    seq_w.append(bit_w)
    print(f"t={t_w}, p(1|past)={p1_w:.3f}, sample={bit_w}")
print("sampled sequence:", seq_w)
assert len(seq_w) == 6
```
▶ What you'll see: each sampled bit changes the probability used at the next time step.

```python
seq_arr_w = np.array(seq_w)
probs_w = []
prev_w = 0.0
for bit_w in seq_arr_w:
    p1_w = sigmoid_w(-0.4 + 1.2 * prev_w)
    probs_w.append(p1_w if bit_w == 1 else 1 - p1_w)
    prev_w = bit_w
loglik_w = float(np.sum(np.log(probs_w)))
print("probabilities assigned to sampled bits:", np.round(probs_w, 3))
print("exact log-likelihood:", round(loglik_w, 3))
assert len(probs_w) == 6 and np.isfinite(loglik_w)
```
▶ What you'll see: the exact sequence log-likelihood is just the sum of the chosen-step log probabilities.

```python
positions_w = np.arange(1, 21)
parallel_cost_w = np.ones_like(positions_w)
autoregressive_cost_w = positions_w
plt.figure(figsize=(5, 3))
plt.plot(positions_w, autoregressive_cost_w, label="autoregressive sampling steps")
plt.plot(positions_w, parallel_cost_w, label="ideal parallel fill")
plt.title("5: exact likelihood, sequential sampling")
plt.xlabel("number of generated variables"); plt.ylabel("relative steps")
plt.legend(); plt.show()
```
▶ What you'll see: autoregressive sampling grows linearly with output length because later variables wait for earlier ones.

*Why it's done this way:* the model buys tractable likelihood by making each conditional easy to score. The price is sampling latency: a future pixel or audio sample is undefined until its past has actually been generated.

## 🛠️ Setup

```python
import numpy as np  # load NumPy for arrays, probabilities, masks, and toy sampling.
import matplotlib.pyplot as plt  # load Matplotlib for heatmaps, bars, stems, and line plots.
np.random.seed(0)  # make all random examples reproducible.

def softmax(logits):  # convert unnormalized scores into probabilities.
    logits = np.asarray(logits, dtype=float)  # ensure stable floating-point arithmetic.
    shifted = logits - np.max(logits)  # subtract max to avoid overflow while preserving probabilities.
    exp = np.exp(shifted)  # exponentiate nonnegative relative scores.
    return exp / np.sum(exp)  # normalize so probabilities sum to 1.

def nll_from_probs(probs):  # compute negative log-likelihood from chosen conditional probabilities.
    probs = np.asarray(probs, dtype=float)  # convert to float array for vectorized logs.
    return float(-np.sum(np.log(probs)))  # sum -log p over steps.

def masked_kernel_3x3(kind="A"):  # build the PixelCNN mask for one-channel 3x3 demos.
    mask = np.array([[1, 1, 1], [1, 1, 0], [0, 0, 0]], dtype=float)  # type-B keeps the center.
    if kind == "A":  # the first layer must not see the current pixel value.
        mask[1, 1] = 0.0  # remove the center tap.
    return mask  # return a binary kernel mask.

def masked_conv2d(X, K, mask):  # apply a same-size 2D masked convolution to one image.
    pad = K.shape[0] // 2  # use symmetric padding for 3x3 kernels.
    Xp = np.pad(np.asarray(X, dtype=float), pad)  # zero-pad the image border.
    out = np.zeros_like(X, dtype=float)  # allocate output with the same spatial size.
    for r in range(X.shape[0]):  # scan rows.
        for c in range(X.shape[1]):  # scan columns.
            patch = Xp[r:r + K.shape[0], c:c + K.shape[1]]  # local window under the kernel.
            out[r, c] = np.sum(patch * K * mask)  # sum only the allowed masked taps.
    return out  # return the context features.

def causal_conv1d(x, filt, dilation=1):  # apply a causal 1D convolution from scratch.
    x = np.asarray(x, dtype=float)  # ensure numeric input.
    filt = np.asarray(filt, dtype=float)  # ensure numeric filter.
    y = np.zeros_like(x, dtype=float)  # allocate output sequence.
    for t in range(len(x)):  # compute each output time.
        for j, weight in enumerate(filt):  # loop over filter taps.
            idx = t - dilation * (len(filt) - 1 - j)  # map tap to a current-or-past input index.
            if idx >= 0:  # ignore taps that would fall before the sequence starts.
                y[t] += weight * x[idx]  # accumulate causal evidence.
    return y  # return the filtered sequence.
```

## 🟢 Basics (warm-up)

### Basic 1 — Multiply conditionals into a joint probability

**Goal.** Compute the probability of a short sequence from conditional probabilities, because autoregressive likelihood is a product of next-step terms. We build it in 2 steps.

```python
probs_b1 = np.array([0.5, 0.7, 0.2])  # store p(x1), p(x2|x1), and p(x3|x<3).
print("conditional probabilities:", probs_b1)  # inspect the small factors before multiplying.
```
▶ What you'll see: three simple conditional probabilities that will define one joint sequence probability.

```python
joint_b1 = float(np.prod(probs_b1))  # multiply conditionals by the chain rule.
print("joint probability:", round(joint_b1, 4))  # inspect the full sequence probability.
assert round(joint_b1, 4) == 0.07  # verify the lesson's auditable chain-rule number.
plt.figure(figsize=(4, 3))  # create a compact bar chart.
plt.bar(["p1", "p2", "p3"], probs_b1, color="teal")  # show each conditional factor.
plt.title("Basic 1: chain-rule factors")  # title the probability-factor plot.
plt.ylim(0, 1)  # keep probability scale fixed.
plt.show()  # display the chart.
```
▶ What you'll see: the product is much smaller than any single factor because every step must be correct.

👀 Takeaway: autoregressive models turn one hard joint probability into a product of smaller conditional probabilities.

### Basic 2 — Convert likelihood to negative log-likelihood

**Goal.** Sum negative logs of conditional probabilities, because training minimizes an additive surprise score instead of multiplying tiny numbers. We build it in 2 steps.

```python
probs_b2 = np.array([0.5, 0.7, 0.2])  # reuse the canonical conditional probabilities.

```
▶ What you'll see: the smallest probability has the largest negative-log penalty.

```python

plt.figure(figsize=(4, 3))  # create a compact loss chart.
plt.bar(["x1", "x2", "x3"], terms_b2, color="orange")  # visualize additive loss contributions.

```
▶ What you'll see: total loss is the sum of the three bars.

👀 Takeaway: log-likelihood makes long-sequence training numerically stable and step-by-step inspectable.
