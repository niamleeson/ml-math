# 24.8 — Neuroevolution (NEAT)

Neuroevolution trains neural networks with evolutionary search instead of gradient descent. NEAT — NeuroEvolution of Augmenting Topologies — goes one step further: it evolves both the connection weights and the network graph, while using innovation numbers and species to protect new structural ideas long enough for them to improve.

## 📖 Concept walkthrough — build each idea from scratch

Before the worked examples, we build NEAT one idea at a time. Run each cell in order and read the printed values: genomes, mutations, species, crossover, and fitness are all implemented from scratch with only NumPy, Matplotlib, and the standard library. The walkthrough uses a `_w` suffix so it will not collide with the examples below.

```python
import numpy as np
import matplotlib.pyplot as plt
from dataclasses import dataclass
np.random.seed(0)
```

### 1. A neural network can be stored as a genome

A NEAT genome is a list of node genes and connection genes. The nodes say what computation units exist; the connections say which directed weighted edges are enabled. The phenotype is the neural network drawn from that graph.

```python
nodes_w = {0: "input", 1: "input", 2: "bias", 3: "output"}
connections_w = [
    {"in": 0, "out": 3, "w": 0.8, "enabled": True, "innov": 1},
    {"in": 1, "out": 3, "w": -0.5, "enabled": True, "innov": 2},
    {"in": 2, "out": 3, "w": 0.1, "enabled": True, "innov": 3},
]
print("nodes:", nodes_w)
print("connection innovations:", [c["innov"] for c in connections_w])

pos_w = {0: (0, 1), 1: (0, 0), 2: (0, -1), 3: (2, 0)}
plt.figure(figsize=(5, 3))
for c in connections_w:
    x0, y0 = pos_w[c["in"]]; x1, y1 = pos_w[c["out"]]
    plt.arrow(x0, y0, x1-x0-0.12, y1-y0, head_width=0.06, length_includes_head=True, color="seagreen")
    plt.text((x0+x1)/2, (y0+y1)/2, f'i{c["innov"]}, w={c["w"]}', fontsize=8)
for n, (x, y) in pos_w.items():
    plt.scatter([x], [y], s=550, color="white", edgecolor="black", zorder=3)
    plt.text(x, y, f"{n}\n{nodes_w[n]}", ha="center", va="center", fontsize=8)
plt.axis("off"); plt.title("1: genome as a directed neural graph"); plt.show()
```
▶ What you'll see: three input-to-output edges, each with an innovation number that identifies its historical origin.

*Why it's done this way:* storing the network as genes lets evolution mutate weights, add edges, add nodes, and align inherited structure during crossover.

### 2. Weight mutation tunes behavior before topology changes

NEAT usually starts with minimal networks. The cheapest mutation perturbs connection weights, changing predictions without changing the graph.

```python
x_w = np.array([2.0, 1.0, 1.0])
w_before_w = np.array([1.0, -0.5, 0.0])
w_after_w = np.array([1.2, -0.4, 0.0])
target_w = 1.0
pred_before_w = float(x_w @ w_before_w)
pred_after_w = float(x_w @ w_after_w)
err_before_w = (pred_before_w - target_w) ** 2
err_after_w = (pred_after_w - target_w) ** 2
print("before prediction/error:", pred_before_w, err_before_w)
print("after prediction/error:", pred_after_w, err_after_w)
assert pred_before_w == 1.5 and pred_after_w == 2.0

plt.figure(figsize=(4.5, 3))
plt.bar(["before", "after", "target"], [pred_before_w, pred_after_w, target_w], color=["gray", "orange", "seagreen"])
plt.ylabel("network output")
plt.title("2: weight mutation changes behavior")
plt.show()
```
▶ What you'll see: this mutation makes the prediction worse, which is allowed; selection will decide whether it survives.

*Why it's done this way:* mutation explores locally, and NEAT relies on population selection rather than assuming every random change is beneficial.

### 3. Add-connection mutation creates a new path

A structural mutation can connect two previously unconnected nodes. That expands the architecture while preserving the older genes.

```python
base_edges_w = [(0, 3, 1), (1, 3, 2)]
new_edge_w = (0, 4, 3)
nodes2_w = {0: "input", 1: "input", 3: "output", 4: "hidden"}
pos2_w = {0: (0, 1), 1: (0, -1), 4: (1, 0.3), 3: (2, 0)}
print("old innovations:", [e[2] for e in base_edges_w])
print("new add-connection innovation:", new_edge_w[2])

plt.figure(figsize=(5, 3))
for a, b, inn in base_edges_w + [new_edge_w]:
    x0, y0 = pos2_w[a]; x1, y1 = pos2_w[b]
    col = "crimson" if inn == 3 else "gray"
    plt.arrow(x0, y0, x1-x0-0.12, y1-y0, head_width=0.06, length_includes_head=True, color=col)
    plt.text((x0+x1)/2, (y0+y1)/2, f"i{inn}", color=col)
for n, (x, y) in pos2_w.items():
    plt.scatter([x], [y], s=520, color="white", edgecolor="black", zorder=3)
    plt.text(x, y, str(n), ha="center", va="center")
plt.axis("off"); plt.title("3: add-connection mutation"); plt.show()
```
▶ What you'll see: the red edge is new structure with its own historical label.

*Why it's done this way:* adding edges lets evolution discover shortcut computations that a fixed starting topology did not contain.

### 4. Add-node mutation splits an old connection

NEAT adds a node by disabling an existing connection and inserting two new connections around the new hidden node. The old behavior is not thrown away; it is marked disabled so history remains visible.

```python
old_conn_w = {"in": 0, "out": 3, "w": 0.8, "enabled": True, "innov": 1}
new_node_w = 4
split_w = [
    {"in": 0, "out": new_node_w, "w": 1.0, "enabled": True, "innov": 4},
    {"in": new_node_w, "out": 3, "w": old_conn_w["w"], "enabled": True, "innov": 5},
]
print("disabled old gene:", old_conn_w)
print("new split genes:", split_w)
pos4_w = {0: (0, 0), new_node_w: (1, 0.7), 3: (2, 0)}

plt.figure(figsize=(5, 3))
plt.plot([0, 2], [0, 0], "--", color="gray", label="disabled old i1")
for c in split_w:
    x0, y0 = pos4_w[c["in"]]; x1, y1 = pos4_w[c["out"]]
    plt.arrow(x0, y0, x1-x0-0.12, y1-y0, head_width=0.06, length_includes_head=True, color="seagreen")
    plt.text((x0+x1)/2, (y0+y1)/2, f'i{c["innov"]}')
for n, (x, y) in pos4_w.items():
    plt.scatter([x], [y], s=550, color="white", edgecolor="black", zorder=3)
    plt.text(x, y, str(n), ha="center", va="center")
plt.legend(); plt.axis("off"); plt.title("4: add-node mutation splits one edge"); plt.show()
```
▶ What you'll see: the dashed old edge is replaced by a two-edge path through a hidden node.

*Why it's done this way:* splitting an edge initially preserves a related signal path, so topology can complexify gradually instead of restarting from scratch.

### 5. Innovation numbers align different topologies

When two genomes have different graphs, crossover must know which genes correspond. NEAT does not match by position in the list; it matches by innovation number.

```python
A_w = {1: 0.5, 2: -1.0, 4: 0.7}
B_w = {1: 0.6, 3: 1.2, 4: 0.4}
all_innov_w = sorted(set(A_w) | set(B_w))
match_w = [i for i in all_innov_w if i in A_w and i in B_w]
disjoint_w = [i for i in all_innov_w if (i in A_w) ^ (i in B_w)]
print("matching genes:", match_w)
print("disjoint genes:", disjoint_w)
assert match_w == [1, 4] and disjoint_w == [2, 3]

plt.figure(figsize=(5, 2.6))
for row, genes, label in [(1, A_w, "A"), (0, B_w, "B")]:
    for inn in all_innov_w:
        color = "seagreen" if inn in genes else "lightgray"
        plt.scatter([inn], [row], s=520, color=color, edgecolor="black")
        txt = f"{genes[inn]:.1f}" if inn in genes else "—"
        plt.text(inn, row, txt, ha="center", va="center")
    plt.text(0.4, row, label, ha="right", va="center")
plt.xticks(all_innov_w); plt.yticks([]); plt.xlabel("innovation number")
plt.title("5: historical markings align genes"); plt.show()
```
▶ What you'll see: innovations 1 and 4 line up even though each parent has one different middle gene.

*Why it's done this way:* historical markings prevent unrelated edges from being averaged merely because they occupy the same list index.

### 6. Compatibility distance creates species

NEAT uses a distance combining excess genes, disjoint genes, and matching-weight differences. Genomes close under this distance compete in the same species.

```python
E_w, D_w, N_w, Wbar_w = 0, 2, 3, 0.2
c1_w, c2_w, c3_w = 1.0, 1.0, 0.4
delta_w = c1_w * E_w / N_w + c2_w * D_w / N_w + c3_w * Wbar_w
threshold_w = 0.8
print("compatibility distance:", round(delta_w, 3))
print("same species?", delta_w < threshold_w)
assert round(delta_w, 3) == 0.747

parts_w = np.array([c1_w * E_w / N_w, c2_w * D_w / N_w, c3_w * Wbar_w])
plt.figure(figsize=(4.8, 3))
plt.bar(["excess", "disjoint", "weight gap"], parts_w, color=["gray", "orange", "teal"])
plt.axhline(threshold_w, color="crimson", linestyle="--", label="species threshold")
plt.ylabel("distance contribution")
plt.title("6: compatibility distance ingredients")
plt.legend(); plt.show()
```
▶ What you'll see: most of the distance comes from disjoint topology, not from the weight differences.

*Why it's done this way:* species protect young structural innovations by making them compete first against similar genomes rather than mature unrelated ones.

### 7. Selection keeps fitness, species keep diversity

Fitness rewards behavior. Speciation changes who competes with whom, so a population can keep both simple high performers and more complex experiments.

```python
fitness_w = np.array([7.5, 7.0, 4.0, 3.5, 6.0])
species_w = np.array([0, 0, 1, 1, 2])
adjusted_w = np.array([fitness_w[i] / np.sum(species_w == species_w[i]) for i in range(len(fitness_w))])
print("raw fitness:", fitness_w)
print("adjusted fitness:", np.round(adjusted_w, 3))

x_w = np.arange(len(fitness_w))
plt.figure(figsize=(5, 3))
plt.bar(x_w - 0.18, fitness_w, width=0.36, label="raw", color="steelblue")
plt.bar(x_w + 0.18, adjusted_w, width=0.36, label="species-adjusted", color="darkorange")
plt.xticks(x_w, [f"g{i}\ns{species_w[i]}" for i in x_w])
plt.ylabel("fitness")
plt.title("7: fitness sharing across species")
plt.legend(); plt.show()
```
▶ What you'll see: crowded species have their raw scores shared, leaving room for smaller species.

*Why it's done this way:* fitness sharing is a simple way to balance exploitation of current winners against exploration by structurally different genomes.

### ✍️ Toy 1 · A genome stores nodes and weighted connections

NEAT keeps the neural network as genes. Node arrays say where units are, and connection arrays say which directed weighted edges are enabled.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)
t1_node_ids = np.array([0, 1, 2])
print("node ids:", t1_node_ids.tolist())  # -> [0, 1, 2]
t1_node_x = np.array([0.0, 0.0, 2.0])
print("node x positions:", t1_node_x.tolist())  # -> [0.0, 0.0, 2.0]
t1_node_y = np.array([0.6, -0.6, 0.0])
print("node y positions:", t1_node_y.tolist())  # -> [0.6, -0.6, 0.0]
t1_edge_from = np.array([0, 1])
print("edge from nodes:", t1_edge_from.tolist())  # -> [0, 1]
t1_edge_to = np.array([2, 2])
print("edge to nodes:", t1_edge_to.tolist())  # -> [2, 2]
t1_weights = np.array([0.7, -0.4])
print("edge weights:", t1_weights.tolist())  # -> [0.7, -0.4]
t1_enabled = np.array([1, 1])
print("enabled flags:", t1_enabled.tolist())  # -> [1, 1]
t1_innovations = np.array([1, 2])
print("innovation numbers:", t1_innovations.tolist())  # -> [1, 2]
assert t1_innovations.tolist() == [1, 2]

plt.figure(figsize=(4.8, 3.0))
for t1_i in range(len(t1_edge_from)):
    t1_a = int(t1_edge_from[t1_i])
    t1_b = int(t1_edge_to[t1_i])
    plt.arrow(t1_node_x[t1_a], t1_node_y[t1_a], t1_node_x[t1_b] - t1_node_x[t1_a] - 0.12, t1_node_y[t1_b] - t1_node_y[t1_a], head_width=0.06, length_includes_head=True, color="seagreen")
    plt.text((t1_node_x[t1_a] + t1_node_x[t1_b]) / 2, (t1_node_y[t1_a] + t1_node_y[t1_b]) / 2, f"i{t1_innovations[t1_i]}, w={t1_weights[t1_i]:.1f}", fontsize=8)
plt.scatter(t1_node_x, t1_node_y, s=520, color="white", edgecolor="black", zorder=3)
for t1_i in range(len(t1_node_ids)):
    plt.text(t1_node_x[t1_i], t1_node_y[t1_i], str(t1_node_ids[t1_i]), ha="center", va="center")
plt.axis("off"); plt.title("Toy 1 · genome as graph genes"); plt.show()
```
▶ What you'll see: two enabled input-to-output edges, each labeled by its innovation number.

### ✍️ Toy 2 · Weight mutation changes network behavior

A weight mutation perturbs existing numbers without changing topology. Selection later decides whether the behavioral change helped.

```python
import numpy as np

t2_rng = np.random.default_rng(0)
t2_inputs = np.array([1.0, 2.0, 1.0])
print("inputs with bias:", t2_inputs.tolist())  # -> [1.0, 2.0, 1.0]
t2_weights_before = np.array([0.5, -0.2, 0.1])
print("weights before:", t2_weights_before.tolist())  # -> [0.5, -0.2, 0.1]
t2_delta = np.array([0.1, 0.3, -0.2])
print("mutation delta:", t2_delta.tolist())  # -> [0.1, 0.3, -0.2]
t2_weights_after = t2_weights_before + t2_delta
print("weights after:", np.round(t2_weights_after, 3).tolist())  # -> [0.6, 0.1, -0.1]
t2_prediction_before = float(t2_inputs @ t2_weights_before)
print("prediction before:", round(t2_prediction_before, 3))  # -> 0.2
t2_prediction_after = float(t2_inputs @ t2_weights_after)
print("prediction after:", round(t2_prediction_after, 3))  # -> 0.7
t2_target = 1.0
print("target:", t2_target)  # -> 1.0
t2_error_before = (t2_prediction_before - t2_target) ** 2
print("squared error before:", round(float(t2_error_before), 3))  # -> 0.64
t2_error_after = (t2_prediction_after - t2_target) ** 2
print("squared error after:", round(float(t2_error_after), 3))  # -> 0.09
assert t2_error_after < t2_error_before

plt.figure(figsize=(4.6, 3.0))
plt.bar(["before", "after", "target"], [t2_prediction_before, t2_prediction_after, t2_target], color=["gray", "darkorange", "seagreen"])
plt.ylabel("output"); plt.title("Toy 2 · mutation moves prediction"); plt.show()
```
▶ What you'll see: the mutation moves the output from `0.2` toward the target `1.0`.

### ✍️ Toy 3 · Add-connection mutation creates a new directed edge

A structural mutation can insert one new edge between previously unconnected nodes while leaving older innovations intact.

```python
import numpy as np

t3_rng = np.random.default_rng(0)
t3_node_ids = np.array([0, 1, 2, 3])
print("node ids:", t3_node_ids.tolist())  # -> [0, 1, 2, 3]
t3_old_edges = np.array([[0, 2], [2, 3]])
```

### ✍️ Toy 4 · Add-node mutation splits an old connection

NEAT inserts a hidden node by disabling one old edge and replacing it with two new edges through the new node.

```python
import numpy as np

t4_rng = np.random.default_rng(0)
t4_old_connection = np.array([0.0, 2.0, 0.8, 1.0, 1.0])
print("old connection [in,out,w,enabled,innov]:", t4_old_connection.tolist())  # -> [0.0, 2.0, 0.8, 1.0, 1.0]
t4_disabled_connection = t4_old_connection.copy()
t4_disabled_connection[3] = 0.0
print("disabled old connection:", t4_disabled_connection.tolist())  # -> [0.0, 2.0, 0.8, 0.0, 1.0]
t4_new_node = 3
print("new node id:", t4_new_node)  # -> 3
t4_first_split = np.array([0.0, 3.0, 1.0, 1.0, 2.0])
print("first split gene:", t4_first_split.tolist())  # -> [0.0, 3.0, 1.0, 1.0, 2.0]
t4_second_split = np.array([3.0, 2.0, 0.8, 1.0, 3.0])
print("second split gene:", t4_second_split.tolist())  # -> [3.0, 2.0, 0.8, 1.0, 3.0]
t4_split_genes = np.vstack([t4_first_split, t4_second_split])
print("split genes:", t4_split_genes.tolist())  # -> [[0.0, 3.0, 1.0, 1.0, 2.0], [3.0, 2.0, 0.8, 1.0, 3.0]]
assert t4_disabled_connection[3] == 0.0 and t4_split_genes.shape == (2, 5)

plt.figure(figsize=(5.0, 3.0))
t4_x = np.array([0.0, 2.4, 1.2])
t4_y = np.array([0.0, 0.0, 0.8])
plt.plot([t4_x[0], t4_x[1]], [t4_y[0], t4_y[1]], "--", color="gray", label="disabled i1")
plt.arrow(t4_x[0], t4_y[0], t4_x[2] - t4_x[0] - 0.08, t4_y[2] - t4_y[0], head_width=0.06, length_includes_head=True, color="seagreen", label="new split")
plt.arrow(t4_x[2], t4_y[2], t4_x[1] - t4_x[2] - 0.08, t4_y[1] - t4_y[2], head_width=0.06, length_includes_head=True, color="seagreen")
plt.scatter(t4_x, t4_y, s=520, color="white", edgecolor="black", zorder=3)

    plt.text(t4_xi, t4_yi, str(t4_label), ha="center", va="center")
plt.legend(); plt.axis("off"); plt.title("Toy 4 · split one edge into two"); plt.show()
```
▶ What you'll see: the dashed old edge is disabled and a hidden node creates a two-edge path.

### ✍️ Toy 5 · Innovation numbers align genes during crossover

Parents with different structures can still align matching historical genes by innovation number before deciding what to inherit.

```python
import numpy as np

t5_rng = np.random.default_rng(0)
t5_A_innovations = np.array([1, 2, 4])
print("parent A innovations:", t5_A_innovations.tolist())  # -> [1, 2, 4]
t5_A_weights = np.array([0.5, -0.7, 0.3])
print("parent A weights:", t5_A_weights.tolist())  # -> [0.5, -0.7, 0.3]
t5_B_innovations = np.array([1, 3, 4])
print("parent B innovations:", t5_B_innovations.tolist())  # -> [1, 3, 4]
t5_B_weights = np.array([0.6, 1.0, 0.1])
print("parent B weights:", t5_B_weights.tolist())  # -> [0.6, 1.0, 0.1]
t5_all_innovations = np.union1d(t5_A_innovations, t5_B_innovations)
print("all innovations:", t5_all_innovations.tolist())  # -> [1, 2, 3, 4]
t5_matching = np.intersect1d(t5_A_innovations, t5_B_innovations)
print("matching innovations:", t5_matching.tolist())  # -> [1, 4]
t5_disjoint = np.setxor1d(t5_A_innovations, t5_B_innovations)
print("disjoint innovations:", t5_disjoint.tolist())  # -> [2, 3]
t5_average_matching = np.array([(t5_A_weights[t5_A_innovations == t5_i][0] + t5_B_weights[t5_B_innovations == t5_i][0]) / 2.0 for t5_i in t5_matching])
print("average matching weights:", np.round(t5_average_matching, 3).tolist())  # -> [0.55, 0.2]
assert t5_matching.tolist() == [1, 4] and t5_disjoint.tolist() == [2, 3]

plt.figure(figsize=(5.0, 2.8))
for t5_row, t5_innovs, t5_weights, t5_label in [(1, t5_A_innovations, t5_A_weights, "A"), (0, t5_B_innovations, t5_B_weights, "B")]:
    for t5_i in t5_all_innovations:
        t5_present = bool(np.any(t5_innovs == t5_i))
        t5_color = "seagreen" if t5_present else "lightgray"
        plt.scatter([t5_i], [t5_row], s=520, color=t5_color, edgecolor="black")
        t5_text = f"{t5_weights[t5_innovs == t5_i][0]:.1f}" if t5_present else "—"
        plt.text(t5_i, t5_row, t5_text, ha="center", va="center")
    plt.text(0.5, t5_row, t5_label, ha="right", va="center")
```

### ✍️ Toy 6 · Compatibility distance decides species membership

Compatibility distance adds topology differences and average matching-weight gaps. A threshold then turns that distance into a species decision.

## 🛠️ Setup

```python
import numpy as np
import matplotlib.pyplot as plt
from dataclasses import dataclass
from copy import deepcopy
np.random.seed(0)

@dataclass
class InnovationTracker:
    next_node: int = 4
    next_innov: int = 1
    conn_history: dict = None
    split_history: dict = None
    def __post_init__(self):
        self.conn_history = {} if self.conn_history is None else self.conn_history
        self.split_history = {} if self.split_history is None else self.split_history
    def connection(self, a, b):
        key = (int(a), int(b))
        if key not in self.conn_history:
            self.conn_history[key] = self.next_innov
            self.next_innov += 1
        return self.conn_history[key]
    def split(self, innov):
        if innov not in self.split_history:
            self.split_history[innov] = self.next_node
            self.next_node += 1
        return self.split_history[innov]

def make_genome(weights=(0.0, 0.0, 0.0), tracker=None):
    tracker = InnovationTracker() if tracker is None else tracker
    nodes = {0: "input", 1: "input", 2: "bias", 3: "output"}
    conns = []
    for a, w in zip([0, 1, 2], weights):
        conns.append({"in": a, "out": 3, "w": float(w), "enabled": True, "innov": tracker.connection(a, 3)})
    return {"nodes": nodes, "conns": conns, "fitness": 0.0}

def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-np.clip(x, -60, 60)))

def activate(genome, x):
    vals = {0: float(x[0]), 1: float(x[1]), 2: 1.0}
    for node in sorted(genome["nodes"]):
        if node in vals:
            continue
        incoming = [c for c in genome["conns"] if c["enabled"] and c["out"] == node]
        vals[node] = sigmoid(sum(vals.get(c["in"], 0.0) * c["w"] for c in incoming))
    return vals.get(3, 0.0), vals

def xor_fitness(genome):
    X = np.array([[0,0], [0,1], [1,0], [1,1]], dtype=float)
    y = np.array([0, 1, 1, 0], dtype=float)
    preds = np.array([activate(genome, row)[0] for row in X])
    mse = float(np.mean((preds - y) ** 2))
    return 4.0 - 4.0 * mse, preds

def draw_genome(genome, title):
    hidden = sorted([n for n, t in genome["nodes"].items() if t == "hidden"])
    pos = {0: (0, 1), 1: (0, 0), 2: (0, -1), 3: (3, 0)}
    for k, n in enumerate(hidden):
        pos[n] = (1.5, (k - (len(hidden)-1)/2) * 0.8)
    plt.figure(figsize=(5.5, 3.2))
    for c in sorted(genome["conns"], key=lambda z: z["innov"]):
        x0, y0 = pos[c["in"]]; x1, y1 = pos[c["out"]]
        color = "seagreen" if c["enabled"] else "lightgray"
        style = "-" if c["enabled"] else "--"
        plt.plot([x0, x1], [y0, y1], style, color=color, linewidth=1 + abs(c["w"]))
        plt.text((x0+x1)/2, (y0+y1)/2, f'i{c["innov"]}\n{c["w"]:.2f}', fontsize=7, ha="center")
    for n, (x0, y0) in pos.items():
        plt.scatter([x0], [y0], s=620, color="white", edgecolor="black", zorder=3)
        plt.text(x0, y0, f"{n}\n{genome['nodes'][n][0]}", ha="center", va="center", fontsize=8)
    plt.title(title); plt.axis("off")

def mutate_weights(genome, deltas):
    child = deepcopy(genome)
    for c, d in zip(child["conns"], deltas):
        c["w"] += float(d)
    return child

def mutate_add_connection(genome, tracker, a, b, w):
    child = deepcopy(genome)
    exists = any(c["in"] == a and c["out"] == b for c in child["conns"])
    assert not exists
    child["conns"].append({"in": int(a), "out": int(b), "w": float(w), "enabled": True, "innov": tracker.connection(a, b)})
    return child

def mutate_add_node(genome, tracker, innov):
    child = deepcopy(genome)
    old = [c for c in child["conns"] if c["innov"] == innov][0]
    old["enabled"] = False
    new_node = tracker.split(innov)
    child["nodes"][new_node] = "hidden"
    child["conns"].append({"in": old["in"], "out": new_node, "w": 1.0, "enabled": True, "innov": tracker.connection(old["in"], new_node)})
    child["conns"].append({"in": new_node, "out": old["out"], "w": old["w"], "enabled": True, "innov": tracker.connection(new_node, old["out"])})
    return child

def gene_map(genome):
    return {c["innov"]: c for c in genome["conns"]}

def compatibility(g1, g2, c1=1.0, c2=1.0, c3=0.4):
    m1, m2 = gene_map(g1), gene_map(g2)
    keys = sorted(set(m1) | set(m2))
    max1, max2 = max(m1), max(m2)
    matching = [k for k in keys if k in m1 and k in m2]
    disjoint = [k for k in keys if (k in m1) ^ (k in m2) and k <= min(max1, max2)]
    excess = [k for k in keys if (k in m1) ^ (k in m2) and k > min(max1, max2)]
    n = max(1, max(len(m1), len(m2)))
    wbar = float(np.mean([abs(m1[k]["w"] - m2[k]["w"]) for k in matching])) if matching else 0.0
    return c1*len(excess)/n + c2*len(disjoint)/n + c3*wbar, matching, disjoint, excess

def crossover(fit_parent, other_parent):
    m1, m2 = gene_map(fit_parent), gene_map(other_parent)
    child = {"nodes": deepcopy(fit_parent["nodes"]), "conns": [], "fitness": 0.0}
    for k in sorted(set(m1) | set(m2)):
        if k in m1 and k in m2:
            chosen = m1[k] if k % 2 else m2[k]
        elif k in m1:
            chosen = m1[k]
        else:
            continue
        child["conns"].append(deepcopy(chosen))
        child["nodes"].setdefault(chosen["in"], fit_parent["nodes"].get(chosen["in"], other_parent["nodes"].get(chosen["in"], "hidden")))
        child["nodes"].setdefault(chosen["out"], fit_parent["nodes"].get(chosen["out"], other_parent["nodes"].get(chosen["out"], "hidden")))
    return child

def species_assign(genomes, threshold=1.0):
    reps, labels = [], []
    for g in genomes:
        placed = False
        for s, rep in enumerate(reps):
            if compatibility(g, rep)[0] < threshold:
                labels.append(s); placed = True; break
        if not placed:
            reps.append(g); labels.append(len(reps)-1)
    return np.array(labels), reps
```

#### A1. Run a tiny NEAT-style loop with topology mutations

**Goal.** Combine selection, weight mutation, occasional node mutation, and species counting, because NEAT is the interaction of these pieces.

```python
rng_a1 = np.random.default_rng(7)
tracker_a1 = InnovationTracker()
pop_a1 = [make_genome(tuple(rng_a1.normal(0, 0.7, 3)), tracker_a1) for _ in range(10)]
best_a1, species_counts_a1, nodes_a1 = [], [], []
for gen_a1 in range(12):
    fits_a1 = np.array([xor_fitness(g)[0] for g in pop_a1])
    best_a1.append(float(fits_a1.max()))
    labels_a1, _ = species_assign(pop_a1, threshold=0.9)
    species_counts_a1.append(len(np.unique(labels_a1)))
    nodes_a1.append(float(np.mean([len(g["nodes"]) for g in pop_a1])))
    elites_a1 = [deepcopy(pop_a1[i]) for i in np.argsort(fits_a1)[-3:]]
    new_pop_a1 = elites_a1[:]
    while len(new_pop_a1) < 10:
        p_a1 = deepcopy(elites_a1[len(new_pop_a1) % len(elites_a1)])
        p_a1 = mutate_weights(p_a1, rng_a1.normal(0, 0.2, len(p_a1["conns"])))
        enabled_a1 = [c for c in p_a1["conns"] if c["enabled"]]
        if gen_a1 in [3, 7] and enabled_a1:
            p_a1 = mutate_add_node(p_a1, tracker_a1, enabled_a1[0]["innov"])
        new_pop_a1.append(p_a1)
    pop_a1 = new_pop_a1
print("best fitness curve:", np.round(best_a1, 3))
assert best_a1[-1] >= min(best_a1)
plt.figure(figsize=(5.5, 3))
plt.plot(best_a1, marker="o", label="best fitness")
plt.plot(species_counts_a1, marker="s", label="species count")
plt.plot(nodes_a1, marker="^", label="avg nodes")
plt.xlabel("generation")
plt.title("A1: miniature NEAT dynamics")
plt.legend(); plt.show()
```
▶ What you'll see: best fitness, species count, and average node count move together as topology enters the population.

👀 Takeaway: NEAT is not just mutation; it is fitness search plus protected structural innovation.
