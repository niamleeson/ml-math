# 12.8 — Graph Autoencoders

Graph autoencoders (GAEs) learn node embeddings without labels by asking a simple self-supervised question: can latent node vectors reconstruct the graph's observed edges? In this lesson, you will build the GCN encoder, inner-product decoder, sampled edge loss, and variational extension from scratch in NumPy so every dot product, probability, and reconstruction is inspectable.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build graph autoencoders one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including normalization, decoding, negative sampling, and the VGAE KL term, is derived and shown. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays + linear algebra for graph matrices, embeddings, and losses.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for inits, negative samples, and variational noise.
```

### 1. Edges become the supervision signal

A graph autoencoder starts with an adjacency matrix $A$, where $A_{ij}=1$ means an edge exists and $A_{ij}=0$ means no observed edge. Unlike a node-classification GNN, no labels are required: the graph supervises itself because the model will learn node vectors $Z$ that can reconstruct which pairs are connected. We keep the diagonal separate, because self-loops are useful for message passing but usually not targets for link reconstruction.

```python
A_w = np.array([[0., 1., 1., 0.],
                [1., 0., 1., 0.],
                [1., 1., 0., 1.],
                [0., 0., 1., 0.]])  # undirected toy graph: triangle 0-1-2 plus tail 2-3.
X_w = np.eye(4)  # one-hot node features so every node begins identifiable.
print("A shape:", A_w.shape, "edge count:", int(A_w.sum() / 2))
print(A_w)
assert int(A_w.sum() / 2) == 4
```
▶ What you'll see: a 4-node graph with four undirected edges; these edges are the labels the autoencoder tries to reconstruct.

```python
plt.figure(figsize=(4, 3))
plt.imshow(A_w, cmap="Greys", vmin=0, vmax=1)
plt.colorbar(label="edge present")
plt.title("1: observed adjacency A")
plt.xlabel("node j"); plt.ylabel("node i")
plt.show()
```
▶ What you'll see: white/black adjacency blocks showing the triangle among nodes 0,1,2 and the tail edge 2-3.

*Why it's done this way: a GAE turns structure into labels by treating observed edges as positives and sampled absent pairs as negatives. The diagonal is kept conceptually separate because self-loops help the encoder preserve a node's own features, while reconstructing self-edges would answer a different target question.*

### 2. A GCN encoder mixes each node with its neighbors

The encoder maps features $X$ to embeddings $Z$ with graph-aware message passing. A simple one-layer GCN uses

$$H=\tilde D^{-1/2}\tilde A\tilde D^{-1/2}XW,$$

where $\tilde A=A+I$ adds self-loops and $\tilde D$ is its degree matrix. The symmetric normalization divides messages by source and target degree, so high-degree nodes do not automatically dominate every aggregate.

```python
I_w = np.eye(A_w.shape[0])  # identity matrix for self-loops.
A_loop_w = A_w + I_w  # add self-loops before message passing.
deg_w = A_loop_w.sum(axis=1)  # degree after self-loops.
D_inv_sqrt_w = np.diag(1 / np.sqrt(deg_w))  # D^{-1/2} for symmetric normalization.
S_w = D_inv_sqrt_w @ A_loop_w @ D_inv_sqrt_w  # normalized adjacency used by the GCN.
print("self-loop degrees:", deg_w.astype(int))
print("S[0]:", np.round(S_w[0], 3))
assert np.allclose(np.round(S_w[0], 3), [0.333, 0.333, 0.289, 0.000])
```
▶ What you'll see: node 0 averages itself and node 1 with weight 0.333, and node 2 slightly less because node 2 has higher degree.

```python
W_w = np.array([[ 1.0,  0.2],
                [ 0.8, -0.1],
                [ 0.1,  0.9],
                [-0.2,  0.7]])  # fixed encoder weights for a visible 2-D embedding.
Z_w = S_w @ X_w @ W_w  # GCN encoder: normalized messages, then learned linear map.
print("Z embeddings:\n", np.round(Z_w, 3))
assert Z_w.shape == (4, 2)
```
▶ What you'll see: each node receives a 2-D vector blended from its own feature row and neighboring feature rows.

```python
plt.figure(figsize=(4, 3.4))
plt.scatter(Z_w[:, 0], Z_w[:, 1], s=120, color="teal")
for i_w in range(4):
    plt.text(Z_w[i_w, 0] + 0.01, Z_w[i_w, 1] + 0.01, f"node {i_w}")
plt.axhline(0, color="gray", linewidth=0.5); plt.axvline(0, color="gray", linewidth=0.5)
plt.title("2: GCN encoder embeddings")
plt.xlabel("latent axis 0"); plt.ylabel("latent axis 1")
plt.show()
```
▶ What you'll see: connected nodes land near related directions because their features were averaged through the graph.

*Why it's done this way: the encoder must create embeddings that know local structure, not just raw features. Adding $I$ lets a node keep its own identity; multiplying by $\tilde D^{-1/2}$ on both sides keeps message scale stable across different degrees.*

### 3. The inner-product decoder turns geometry into edge probabilities

The standard GAE decoder scores a pair $(i,j)$ by a dot product $s_{ij}=z_i^\top z_j$, then maps it through a sigmoid $\sigma(s)=1/(1+e^{-s})$. Aligned embeddings produce large positive scores and probabilities near 1; opposite embeddings produce negative scores and probabilities near 0.

```python
def sigmoid_w(x):
    return 1 / (1 + np.exp(-x))

score01_w = float(Z_w[0] @ Z_w[1])  # connected pair in the triangle.
prob01_w = float(sigmoid_w(score01_w))  # edge probability from the decoder.
print("score z0·z1:", round(score01_w, 3), "probability:", round(prob01_w, 3))
assert round(float(sigmoid_w(0.8)), 3) == 0.690
```
▶ What you'll see: the decoder converts a dot product into a bounded edge belief; the lesson's reference score 0.800 becomes probability 0.690.

```python
scores_w = Z_w @ Z_w.T  # all pairwise dot products.
A_hat_w = sigmoid_w(scores_w)  # reconstructed adjacency probabilities.
print("A_hat rounded:\n", np.round(A_hat_w, 3))
plt.figure(figsize=(4, 3))
plt.imshow(A_hat_w, cmap="viridis", vmin=0, vmax=1)
plt.colorbar(label="reconstructed probability")
plt.title("3: inner-product reconstruction σ(ZZᵀ)")
plt.xlabel("node j"); plt.ylabel("node i")
plt.show()
```
▶ What you'll see: a dense reconstructed adjacency; brighter off-diagonal cells are pairs the embeddings believe should be edges.

*Why it's done this way: $ZZ^\top$ compares every node to every other node with one matrix multiplication, and the sigmoid turns unbounded compatibility scores into probabilities usable by binary cross-entropy. The decoder is intentionally simple so the encoder must learn meaningful geometry.*

### 4. Binary cross-entropy trains positives and sampled negatives

For an observed edge we want probability near 1; for an absent sampled pair we want probability near 0. Binary cross-entropy (BCE) is

$$-\big[y\log p+(1-y)\log(1-p)\big].$$

On sparse graphs, absent pairs vastly outnumber edges, so GAEs usually sample a manageable negative set instead of summing over every non-edge.

```python
pos_score_w = 0.8  # reference positive edge score from the lesson block.
neg_score_w = -1.0  # reference negative non-edge score.
pos_loss_w = -np.log(sigmoid_w(pos_score_w))
neg_loss_w = -np.log(1 - sigmoid_w(neg_score_w))
bce_w = float((pos_loss_w + neg_loss_w) / 2)
print("positive loss:", round(float(pos_loss_w), 3), "negative loss:", round(float(neg_loss_w), 3))
print("balanced BCE:", round(bce_w, 3))
assert round(bce_w, 3) == 0.342
```
▶ What you'll see: a positive score of 0.8 and negative score of -1.0 give the lesson BCE value 0.342.

```python
pos_edges_w = np.array([(0, 1), (0, 2)])  # two observed positive edges.
neg_edges_w = np.array([(0, 3), (1, 3)])  # two sampled absent pairs.
batch_edges_w = np.vstack([pos_edges_w, neg_edges_w])
y_w = np.array([1., 1., 0., 0.])
print("balanced mini-batch size:", len(batch_edges_w), "positives:", int(y_w.sum()), "negatives:", int((1 - y_w).sum()))
assert int(y_w.sum()) == 2 and int((1 - y_w).sum()) == 2
```
▶ What you'll see: a balanced mini-batch uses 2 positives and 2 sampled negatives, matching the lesson grounding.

*Why it's done this way: BCE is the likelihood for Bernoulli edge labels, but using all non-edges would let zeros swamp positives. Negative sampling changes the training distribution deliberately, so the resulting probabilities rank links well but are not automatically calibrated to the true graph density.*

### 5. Training a tiny GAE improves adjacency reconstruction

Now we combine the GCN encoder and inner-product decoder, then update encoder weights by finite-difference gradient descent. Finite differences are slow but transparent: perturb one weight, recompute the edge loss, and estimate which direction lowers it. This keeps the lesson NumPy-only while showing the full learning loop.

```python
def gae_loss_w(W):
    Z = S_w @ X_w @ W
    score = Z @ Z.T
    edges = np.array([(0, 1), (0, 2), (1, 2), (2, 3), (0, 3), (1, 3)])
    labels = np.array([1., 1., 1., 1., 0., 0.])
    logits = np.array([score[i, j] for i, j in edges])
    probs = sigmoid_w(logits)
    return float(-np.mean(labels * np.log(probs + 1e-9) + (1 - labels) * np.log(1 - probs + 1e-9)))

rng_w = np.random.default_rng(0)
W_train_w = 0.3 * rng_w.normal(size=(4, 2))
print("initial loss:", round(gae_loss_w(W_train_w), 3))
```
▶ What you'll see: the randomly initialized GAE starts with a BCE near chance because edges and non-edges are not yet separated.

```python
losses_train_w = []
for step_w in range(45):
    base_w = gae_loss_w(W_train_w)
    grad_w = np.zeros_like(W_train_w)
    eps_w = 1e-4
    for r_w in range(W_train_w.shape[0]):
        for c_w in range(W_train_w.shape[1]):
            W_plus_w = W_train_w.copy()
            W_plus_w[r_w, c_w] += eps_w
            grad_w[r_w, c_w] = (gae_loss_w(W_plus_w) - base_w) / eps_w
    W_train_w -= 0.8 * grad_w
    losses_train_w.append(base_w)
print("loss start -> end:", round(losses_train_w[0], 3), "->", round(losses_train_w[-1], 3))
assert losses_train_w[-1] < losses_train_w[0]
```
▶ What you'll see: the reconstruction loss falls, proving the encoder weights are learning from edge supervision.

```python
Z_train_w = S_w @ X_w @ W_train_w
A_recon_w = sigmoid_w(Z_train_w @ Z_train_w.T)
print("P(edge 0-1):", round(float(A_recon_w[0, 1]), 3), "P(non-edge 0-3):", round(float(A_recon_w[0, 3]), 3))
plt.figure(figsize=(4, 3))
plt.imshow(A_recon_w, cmap="viridis", vmin=0, vmax=1)
plt.colorbar(label="probability")
plt.title("5: trained GAE reconstructed adjacency")
plt.xlabel("node j"); plt.ylabel("node i")
plt.show()
```
▶ What you'll see: reconstructed adjacency becomes brighter on observed edges than on sampled non-edges; look especially at edge (0,1) versus non-edge (0,3).

*Why it's done this way: training pushes positive endpoints to have larger dot products and sampled negative endpoints to have smaller dot products. The heatmap is the easiest sanity check: the learned geometry should recover the pattern of the original adjacency, not just lower a scalar loss.*

### 6. VGAE adds uncertainty with means, variances, and a KL penalty

A variational graph autoencoder (VGAE) does not output one embedding per node. It outputs a Gaussian distribution $q(z_i|X,A)=\mathcal N(\mu_i,\operatorname{diag}(\sigma_i^2))$, samples $z_i=\mu_i+\sigma_i\epsilon_i$, and decodes the sample. The KL term keeps those posteriors near a standard normal prior so uncertainty cannot grow without cost.

```python
Mu_w = S_w @ X_w @ np.array([[ 0.6,  0.1],
                             [ 0.5, -0.2],
                             [ 0.1,  0.7],
                             [-0.1,  0.4]])  # mean encoder output.
Logvar_w = np.clip(S_w @ X_w @ np.array([[-1.0, -0.8],
                                         [-0.9, -1.1],
                                         [-1.2, -0.7],
                                         [-0.8, -1.0]]), -3, 2)  # log variance output.
Std_w = np.exp(0.5 * Logvar_w)
print("mu[0]:", np.round(Mu_w[0], 3), "std[0]:", np.round(Std_w[0], 3))
assert Mu_w.shape == Std_w.shape == (4, 2)
```
▶ What you'll see: each node has both a latent mean and a standard deviation, not just one deterministic vector.

```python
eps_sample_w = np.array([[ 0.2, -0.4], [ 0.1, 0.3], [-0.5, 0.2], [0.4, -0.1]])
Z_sample_w = Mu_w + Std_w * eps_sample_w  # reparameterization trick sample.
kl_w = -0.5 * np.mean(np.sum(1 + Logvar_w - Mu_w ** 2 - np.exp(Logvar_w), axis=1))
print("sample z[0]:", np.round(Z_sample_w[0], 3))
print("mean KL per node:", round(float(kl_w), 3))
assert kl_w > 0
```
▶ What you'll see: a sampled embedding is the mean plus scaled noise, and the KL penalty is positive.

```python
A_vgae_w = sigmoid_w(Z_sample_w @ Z_sample_w.T)
plt.figure(figsize=(4, 3))
plt.imshow(A_vgae_w, cmap="viridis", vmin=0, vmax=1)
plt.colorbar(label="sampled edge probability")
plt.title("6: VGAE sampled reconstruction")
plt.xlabel("node j"); plt.ylabel("node i")
plt.show()
```
▶ What you'll see: one stochastic reconstruction from the VGAE; rerunning with different noise would slightly change the probabilities.

*Why it's done this way: the deterministic GAE gives one best embedding, while the VGAE represents uncertainty about each node's position. The KL term is the mathematical price for drifting away from the simple prior, and the reparameterization $\mu+\sigma\epsilon$ lets gradients flow through the sampling step in deep-learning implementations.*

## 🛠️ Setup

```python
import numpy as np # load NumPy for graph matrices, vectorized decoders, toy optimization, and numerical checks.
import matplotlib.pyplot as plt # load Matplotlib for adjacency heatmaps, embeddings, bars, and loss curves.
np.random.seed(0) # make all random examples reproducible across notebook runs.

def sigmoid(x): # define the logistic link used by the inner-product decoder.
    return 1 / (1 + np.exp(-x)) # map any real-valued score into the probability interval (0, 1).

def normalized_adjacency(A): # define the GCN normalization S = D^{-1/2}(A+I)D^{-1/2}.
    A = np.asarray(A, dtype=float) # convert input to a floating adjacency matrix.
    A_loop = A + np.eye(A.shape[0]) # add self-loops so each node keeps its own features.
    deg = A_loop.sum(axis=1) # compute self-loop degrees.
    D_inv_sqrt = np.diag(1 / np.sqrt(deg)) # build the inverse square-root degree matrix.
    return D_inv_sqrt @ A_loop @ D_inv_sqrt # return the symmetrically normalized message-passing matrix.

def gcn_encode(A, X, W): # define one GCN encoder layer for a graph autoencoder.
    return normalized_adjacency(A) @ X @ W # mix neighboring features and project them to latent dimensions.

def decode(Z): # define the standard GAE inner-product decoder.
    return sigmoid(Z @ Z.T) # score every node pair and squash to edge probabilities.

def bce(labels, probs): # define binary cross-entropy for edge and non-edge labels.
    labels = np.asarray(labels, dtype=float) # convert labels to floating point.
    probs = np.clip(np.asarray(probs, dtype=float), 1e-9, 1 - 1e-9) # avoid log(0) in tiny examples.
    return float(-np.mean(labels * np.log(probs) + (1 - labels) * np.log(1 - probs))) # return mean BCE.

def show_adj(M, title): # define a tiny heatmap helper for adjacency-like matrices.
    plt.figure(figsize=(4, 3)) # create a compact figure.
    plt.imshow(M, cmap="viridis", aspect="auto", vmin=0, vmax=1) # draw probabilities or binary edges as colors.
    plt.colorbar(label="value") # add a color scale so colors can be read numerically.
    plt.title(title) # title the current matrix.
    plt.xlabel("node j") # label columns as destination/paired nodes.
    plt.ylabel("node i") # label rows as source/paired nodes.
    plt.show() # display the heatmap.
```

### Advanced 5 — Evaluate reconstructed links with pairwise AUC

**Goal.** Rank positive edges above sampled negatives, because link prediction is often evaluated by ordering candidate pairs rather than by a fixed threshold. We build it in 4 steps.


```python

    for n_a5 in neg_scores_a5: # loop over negative scores.
```
