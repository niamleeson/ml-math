# 8.19 — Dependency & Constituency Parsing

Parsing turns a sentence from a line of tokens into grammatical structure. In this lesson, dependencies ask which word governs each other word, constituencies ask which contiguous spans form phrases, and constrained decoding keeps locally plausible scores from becoming invalid trees.

### 1. Arc scores: local evidence for heads

A dependency parser starts with a score table where row `h` is a possible head and column `m` is a possible modifier. A high entry says the arc `h → m` looks syntactically plausible, but it is only local evidence — the final output still has to be one valid tree.

```python
words_w = ["I", "saw", "her"]
S_w = np.array([[0., 2., 1.],
                [0., 0., 3.],
                [0., 1., 0.]])
print("words:", words_w)
print("arc score table rows=heads, cols=modifiers:\n", S_w)
```
▶ What you'll see: the verb row gives a strong score to `saw → her`, while other local arcs are weaker.

```python
verb_object_margin_w = S_w[1, 2] - S_w[0, 2]
print("score(saw→her):", S_w[1, 2])
print("score(I→her):", S_w[0, 2])
print("verb-object margin:", verb_object_margin_w)
assert verb_object_margin_w == 2.0
```
▶ What you'll see: the verb-to-object arc is ahead by exactly 2 points, matching the source lesson.

```python
plt.figure(figsize=(4.4, 3.2))
plt.imshow(S_w, cmap="Blues", aspect="auto")
plt.colorbar(label="arc score")
plt.xticks(range(3), words_w); plt.yticks(range(3), words_w)
plt.xlabel("modifier"); plt.ylabel("head")
plt.title("1: local dependency arc scores")
plt.show()
```
▶ What you'll see: a heatmap where bright cells are attractive arcs; look for the bright `saw → her` cell.

*Why it's done this way:* arc-factored parsing uses the additive objective $S(T)=\sum_{(h\to m)\in T}s_{h,m}$, so every candidate tree can be scored by summing table entries. The table is useful because it separates local syntactic evidence from global legality: a high cell says “choose me if possible,” not “I alone define the parse.”

### 2. Dependency trees: one head, one root, no cycles

A dependency tree stores one head per token, using `-1` for the root. The head list `[1, -1, 1]` means `I` and `her` both attach to `saw`, and `saw` is the only root. Validity is structural: each non-root token has exactly one head, the root count is exactly one, and following heads cannot loop forever.

```python
heads_w = np.array([1, -1, 1])
for m_w, h_w in enumerate(heads_w):
    label_w = "ROOT" if h_w == -1 else f"{words_w[h_w]} → {words_w[m_w]}"
    print(f"token {m_w} {words_w[m_w]}: {label_w}")
print("root count:", int(np.sum(heads_w == -1)))
assert int(np.sum(heads_w == -1)) == 1
```
▶ What you'll see: `saw` is the single root, while both other words depend on it.

```python
def is_valid_tree_w(heads):
    heads = np.asarray(heads)
    if np.sum(heads == -1) != 1:
        return False
    n = len(heads)
    for start in range(n):
        seen = set()
        cur = start
        while heads[cur] != -1:
            cur = int(heads[cur])
            if cur in seen or cur < 0 or cur >= n:
                return False
            seen.add(cur)
    return True

bad_cycle_w = np.array([1, 2, 0])
bad_roots_w = np.array([-1, -1, 1])
print("valid heads:", is_valid_tree_w(heads_w))
print("cycle heads valid?:", is_valid_tree_w(bad_cycle_w))
print("two-root heads valid?:", is_valid_tree_w(bad_roots_w))
assert is_valid_tree_w(heads_w) and not is_valid_tree_w(bad_cycle_w) and not is_valid_tree_w(bad_roots_w)
```
▶ What you'll see: local head choices can fail because they create a cycle or multiple roots.

```python
plt.figure(figsize=(4.6, 2.5))
x_w = np.arange(len(words_w))
plt.scatter(x_w, np.zeros_like(x_w), s=80, color="black")
for i_w, word_w in enumerate(words_w):
    plt.text(i_w, -0.12, word_w, ha="center")
for m_w, h_w in enumerate(heads_w):
    if h_w != -1:
        lo_w, hi_w = sorted([m_w, int(h_w)])
        xs_w = np.linspace(lo_w, hi_w, 50)
        ys_w = 0.25 * np.sin(np.pi * (xs_w - lo_w) / max(hi_w - lo_w, 1))
        plt.plot(xs_w, ys_w, color="seagreen")
        plt.text((lo_w + hi_w) / 2, ys_w.max() + 0.03, "→", ha="center")
plt.axis("off"); plt.title("2: a valid dependency tree")
plt.show()
```
▶ What you'll see: two non-crossing arcs from `saw` to its subject and object.

*Why it's done this way:* the one-head representation makes dependency parsing compact: $n$ integers describe $n-1$ arcs plus one root. The constraints are not cosmetic; without them, independently best arcs could describe a graph rather than a syntactic tree, making downstream “who governs whom?” queries ambiguous.

### 3. Constituency spans: phrases as intervals

Constituency parsing asks which contiguous intervals are phrases. A span `(i, j)` includes tokens `i` through `j-1`, so `(1, 3)` covers `saw her`. Span scores say which intervals look phrase-like before the parser chooses a nested tree.

```python
span_scores_w = {(0, 1): 1.0, (1, 3): 2.5, (0, 3): 3.0, (1, 2): 0.7, (2, 3): 0.8}
for span_w, score_w in span_scores_w.items():
    text_w = " ".join(words_w[span_w[0]:span_w[1]])
    print(span_w, repr(text_w), "score=", score_w)
assert span_scores_w[(0, 3)] == 3.0
```
▶ What you'll see: the full sentence span scores highest, but the inner `saw her` span is also strong.

```python
n_w = len(words_w)
M_w = np.full((n_w + 1, n_w + 1), np.nan)
for (i_w, j_w), score_w in span_scores_w.items():
    M_w[i_w, j_w] = score_w
print("score(1,3):", M_w[1, 3])
print("score(0,3):", M_w[0, 3])
assert M_w[1, 3] == 2.5 and M_w[0, 3] == 3.0
```
▶ What you'll see: span scores live in an upper-triangular chart because spans always satisfy `i < j`.

```python
plt.figure(figsize=(4.4, 3.4))
plt.imshow(np.nan_to_num(M_w), cmap="Oranges", aspect="auto")
plt.colorbar(label="span score")
plt.xlabel("end j"); plt.ylabel("start i")
plt.title("3: candidate constituency spans")
plt.show()
```
▶ What you'll see: bright upper-triangular cells mark phrase candidates; look for `(0,3)` and `(1,3)`.

*Why it's done this way:* spans preserve phrase nesting that a head list discards. The interval convention makes the math clean: a larger phrase `(i,j)` can be split at a boundary `k` into `(i,k)` and `(k,j)`, which is exactly the subproblem structure CKY exploits.

### 4. CKY: dynamic programming over nested spans

CKY builds a constituency parse bottom-up. It fills length-1 spans first, then combines already solved shorter spans into longer spans. For a binary grammar, the recurrence is “try every split `k`, every left label, and every right label, then keep the best score for the parent label.”

```python
tokens_w = ["I", "saw", "her"]
lex_w = {("NP", "I"): 1.0, ("V", "saw"): 1.0, ("NP", "her"): 1.0}
rules_w = {("VP", "V", "NP"): 2.0,
           ("S", "NP", "VP"): 3.0}
chart_w = [[defaultdict(lambda: -np.inf) for _ in range(len(tokens_w) + 1)] for _ in range(len(tokens_w))]
back_w = {}
for i_w, tok_w in enumerate(tokens_w):
    for (label_w, word_w), score_w in lex_w.items():
        if word_w == tok_w:
            chart_w[i_w][i_w + 1][label_w] = score_w
print("length-1 cells:", [{k: dict(chart_w[k][k+1])} for k in range(len(tokens_w))])
```
▶ What you'll see: each token receives its lexical category before longer phrases are attempted.

```python
for width_w in range(2, len(tokens_w) + 1):
    for i_w in range(0, len(tokens_w) - width_w + 1):
        j_w = i_w + width_w
        for k_w in range(i_w + 1, j_w):
            for (parent_w, left_w, right_w), rscore_w in rules_w.items():
                score_w = chart_w[i_w][k_w][left_w] + chart_w[k_w][j_w][right_w] + rscore_w
                if score_w > chart_w[i_w][j_w][parent_w]:
                    chart_w[i_w][j_w][parent_w] = score_w
                    back_w[(i_w, j_w, parent_w)] = (k_w, left_w, right_w)
print("VP score C[1,3]:", chart_w[1][3]["VP"])
print("S score C[0,3]:", chart_w[0][3]["S"])
assert chart_w[1][3]["VP"] == 4.0 and chart_w[0][3]["S"] == 8.0
```
▶ What you'll see: `V + NP → VP` is built before `NP + VP → S`, so the full sentence can reuse the verb phrase.

```python
cky_matrix_w = np.full((4, 4), np.nan)
for i_w in range(3):
    for j_w in range(i_w + 1, 4):
        best_w = max(chart_w[i_w][j_w].values()) if chart_w[i_w][j_w] else -np.inf
        if np.isfinite(best_w):
            cky_matrix_w[i_w, j_w] = best_w
plt.figure(figsize=(4.5, 3.4))
plt.imshow(np.nan_to_num(cky_matrix_w), cmap="Purples", aspect="auto")
plt.colorbar(label="best score in cell")
plt.xlabel("end j"); plt.ylabel("start i")
plt.title("4: CKY chart fills upward by span length")
plt.show()
```
▶ What you'll see: nonempty cells appear first on short spans and culminate in the full-sentence cell `(0,3)`.

*Why it's done this way:* CKY works because context-free phrase scores decompose into two child spans plus one rule score. If `C[i,k]` and `C[k,j]` are already optimal, then every candidate for `C[i,j]` can be evaluated locally; this avoids recomputing the same subphrases exponentially many times.

### 5. Transition-based parsing: actions build a tree incrementally

A transition parser keeps a stack, a buffer, and a set of arcs. `SHIFT` moves a token from buffer to stack; `LEFT-ARC` and `RIGHT-ARC` create dependencies between the top stack items. This is greedy-friendly and fast, but action constraints must prevent illegal states.

```python
state_w = {"stack": ["ROOT"], "buffer": ["I", "saw", "her"], "arcs": []}
print("initial stack:", state_w["stack"])
print("initial buffer:", state_w["buffer"])
```
▶ What you'll see: parsing starts with only ROOT on the stack and all words waiting in the buffer.

```python
def shift_w(state):
    state["stack"].append(state["buffer"].pop(0))

def left_arc_w(state):
    dep = state["stack"].pop(-2)
    head = state["stack"][-1]
    state["arcs"].append((head, dep))

def right_arc_w(state):
    dep = state["stack"].pop()
    head = state["stack"][-1]
    state["arcs"].append((head, dep))

actions_w = ["SHIFT", "SHIFT", "LEFT", "SHIFT", "RIGHT", "RIGHT"]
for action_w in actions_w:
    if action_w == "SHIFT":
        shift_w(state_w)
    elif action_w == "LEFT":
        left_arc_w(state_w)
    else:
        right_arc_w(state_w)
    print(action_w, "stack=", state_w["stack"], "buffer=", state_w["buffer"], "arcs=", state_w["arcs"])
```
▶ What you'll see: the action sequence creates `saw → I`, `saw → her`, and finally `ROOT → saw`.

```python
arc_set_w = set(state_w["arcs"])
print("final arcs:", arc_set_w)
assert ("saw", "I") in arc_set_w and ("saw", "her") in arc_set_w and ("ROOT", "saw") in arc_set_w
plt.figure(figsize=(4.8, 2.6))
plt.bar(range(len(actions_w)), [1, 1, 2, 1, 2, 2], color="steelblue")
plt.xticks(range(len(actions_w)), actions_w, rotation=30)
plt.ylabel("action type id")
plt.title("5: transition sequence constructs the parse")
plt.show()
```
▶ What you'll see: a short action program produces a complete dependency tree in linear-time style.

*Why it's done this way:* transition parsing converts structured prediction into sequential decisions. The stack summarizes built context, the buffer summarizes unread input, and each legal action changes exactly one small part of the state, so decoding can be extremely fast compared with enumerating every tree.

### 6. Projectivity: why crossing arcs matter

A projective dependency tree has no crossing arcs when drawn above the sentence. Arcs `(0,2)` and `(1,3)` cross because `0 < 1 < 2 < 3`. Projectivity is useful for dynamic programs such as Eisner, but it is a linguistic assumption, not a universal truth.

```python
def crosses_w(a, b):
    i, j = sorted(a)
    k, l = sorted(b)
    return (i < k < j < l) or (k < i < l < j)

arc1_w = (0, 2)
arc2_w = (1, 3)
print("indices satisfy 0 < 1 < 2 < 3:", 0 < 1 < 2 < 3)
print("crossing indicator:", int(crosses_w(arc1_w, arc2_w)))
assert int(crosses_w(arc1_w, arc2_w)) == 1
```
▶ What you'll see: the crossing indicator is 1 for the pattern highlighted in the source lesson.

```python
noncross_w = [(1, 0), (1, 2), (2, 3)]
crossing_w = [arc1_w, arc2_w]
print("noncrossing tree has crossing?:", any(crosses_w(a, b) for i, a in enumerate(noncross_w) for b in noncross_w[i+1:]))
print("crossing pair has crossing?:", any(crosses_w(a, b) for i, a in enumerate(crossing_w) for b in crossing_w[i+1:]))
assert not any(crosses_w(a, b) for i, a in enumerate(noncross_w) for b in noncross_w[i+1:])
```
▶ What you'll see: nested or adjacent arcs can be projective, but interleaving endpoints are not.

```python
plt.figure(figsize=(5, 2.8))
for x_w, label_w in enumerate(["w0", "w1", "w2", "w3"]):
    plt.scatter([x_w], [0], color="black")
    plt.text(x_w, -0.12, label_w, ha="center")
for a_w, b_w, col_w in [(0, 2, "crimson"), (1, 3, "navy")]:
    xs_w = np.linspace(a_w, b_w, 80)
    ys_w = 0.35 * np.sin(np.pi * (xs_w - a_w) / (b_w - a_w))
    plt.plot(xs_w, ys_w, color=col_w)
plt.axis("off"); plt.title("6: crossing arcs violate projectivity")
plt.show()
```
▶ What you'll see: the two arcs visually intersect; that intersection is what projective parsers disallow.

*Why it's done this way:* forbidding crossings makes the search space decompose by contiguous intervals, enabling dynamic programming. The price is bias: if a language or construction needs non-projective arcs, a projective parser cannot represent the correct answer no matter how good its local scores are.

### 7. Eisner decoding: best projective dependency tree

Eisner's algorithm is a dynamic program for the highest-scoring projective dependency tree. It keeps “complete” spans that are done on one side and “incomplete” spans that still expose a head-modifier arc. The four chart types are bookkeeping that lets every projective tree decompose into smaller projective pieces.

```python
labels_w = ["ROOT", "I", "saw", "her"]
A_w = np.array([[0., 0., 5., 0.],
                [0., 0., 1., 1.],
                [0., 4., 0., 3.],
                [0., 1., 1., 0.]])
print("score ROOT→saw:", A_w[0, 2])
print("score saw→I:", A_w[2, 1], "score saw→her:", A_w[2, 3])
```
▶ What you'll see: the intended projective tree has strong scores for `ROOT → saw`, `saw → I`, and `saw → her`.

```python
def eisner_score_w(scores):
    n = scores.shape[0]
    complete = np.full((n, n, 2), -np.inf)
    incomplete = np.full((n, n, 2), -np.inf)
    complete[:, :, :] = -np.inf
    for i in range(n):
        complete[i, i, 0] = 0.0
        complete[i, i, 1] = 0.0
    for width in range(1, n):
        for s in range(n - width):
            t = s + width
            left_vals = [complete[s, r, 1] + complete[r + 1, t, 0] + scores[t, s] for r in range(s, t)]
            right_vals = [complete[s, r, 1] + complete[r + 1, t, 0] + scores[s, t] for r in range(s, t)]
            incomplete[s, t, 0] = max(left_vals)
            incomplete[s, t, 1] = max(right_vals)
            complete[s, t, 0] = max(complete[s, r, 0] + incomplete[r, t, 0] for r in range(s, t))
            complete[s, t, 1] = max(incomplete[s, r + 1, 1] + complete[r + 1, t, 1] for r in range(s, t))
    return complete[0, n - 1, 1], complete, incomplete

best_eisner_w, complete_w, incomplete_w = eisner_score_w(A_w)
print("best projective score:", best_eisner_w)
assert best_eisner_w == 12.0
```
▶ What you'll see: the best score is 12, the sum `ROOT→saw` 5 + `saw→I` 4 + `saw→her` 3.

```python
complete_best_w = np.full((4, 4), np.nan)
for i_w in range(4):
    for j_w in range(i_w, 4):
        complete_best_w[i_w, j_w] = max(complete_w[i_w, j_w, 0], complete_w[i_w, j_w, 1])
plt.figure(figsize=(4.5, 3.4))
plt.imshow(np.nan_to_num(complete_best_w), cmap="Greens", aspect="auto")
plt.colorbar(label="complete-span score")
plt.xticks(range(4), labels_w); plt.yticks(range(4), labels_w)
plt.title("7: Eisner complete-span chart")
plt.show()
```
▶ What you'll see: scores accumulate over intervals until the full `ROOT..her` span contains the best projective tree.

*Why it's done this way:* Eisner splits projective dependency trees into interval subproblems just like CKY splits phrase trees. “Incomplete” items remember that an arc has been created but still needs surrounding material attached; “complete” items mark spans that can safely be used inside larger spans. That distinction is what makes the recurrence both exact and cubic-time for projective trees.

### ✍️ Toy 2 · A dependency tree needs one root and no cycles

A head vector is valid only if it has exactly one root and following heads from any token eventually
reaches that root.

```python
import numpy as np

t2_rng = np.random.default_rng(0)                         # seeded generator for reproducibility.
t2_words = np.array(["I", "saw", "her"])                # -> ['I', 'saw', 'her']
t2_heads = np.array([1, -1, 1])                           # -> [1, -1, 1]
t2_root_flags = (t2_heads == -1).astype(int)              # -> [0, 1, 0]
t2_root_count = int(np.sum(t2_root_flags))                # -> 1
t2_bad_cycle = np.array([-1, 2, 1])                       # -> [-1, 2, 1]
t2_bad_roots = np.array([-1, -1, 1])                      # -> [-1, -1, 1]

def t2_is_valid_tree(t2_candidate):
    t2_candidate = np.asarray(t2_candidate)
    if int(np.sum(t2_candidate == -1)) != 1:
        return False
    for t2_start in range(len(t2_candidate)):
        t2_seen = set()
        t2_cur = t2_start
        while t2_candidate[t2_cur] != -1:
            t2_cur = int(t2_candidate[t2_cur])
            if t2_cur in t2_seen or t2_cur < 0 or t2_cur >= len(t2_candidate):
                return False
            t2_seen.add(t2_cur)
    return True

t2_valid_ok = t2_is_valid_tree(t2_heads)                  # -> True
t2_cycle_ok = t2_is_valid_tree(t2_bad_cycle)              # -> False
t2_roots_ok = t2_is_valid_tree(t2_bad_roots)              # -> False
print("heads:", t2_heads.tolist())                       # -> [1, -1, 1]
print("root flags:", t2_root_flags.tolist())             # -> [0, 1, 0]
print("root count:", t2_root_count)                      # -> 1
print("valid tree?:", t2_valid_ok)                       # -> True
print("cycle example valid?:", t2_cycle_ok)              # -> False
print("two-root example valid?:", t2_roots_ok)           # -> False
assert t2_valid_ok and not t2_cycle_ok and not t2_roots_ok

t2_x = np.arange(len(t2_words))
plt.figure(figsize=(4.6, 2.5))
plt.scatter(t2_x, np.zeros_like(t2_x), s=80, color="black")
for t2_i, t2_word in enumerate(t2_words):
    plt.text(t2_i, -0.12, t2_word, ha="center")
for t2_mod, t2_head in enumerate(t2_heads):
    if t2_head != -1:
        t2_lo, t2_hi = sorted([t2_mod, int(t2_head)])
        t2_xs = np.linspace(t2_lo, t2_hi, 50)
        t2_ys = 0.25 * np.sin(np.pi * (t2_xs - t2_lo) / max(t2_hi - t2_lo, 1))
        plt.plot(t2_xs, t2_ys, color="seagreen")
plt.axis("off")
plt.title("Toy 2 · one-root acyclic tree")
plt.show()
```
▶ What you'll see: the valid head vector points both dependents to `saw`, while the bad vectors fail structural checks.

### ✍️ Toy 3 · Constituency spans are scored intervals

A span `(i, j)` covers a contiguous interval from token `i` up to but not including token `j`, which
lets phrase scores live in an upper-triangular chart.

```python
import numpy as np

t3_rng = np.random.default_rng(0)                         # seeded generator for reproducibility.
t3_tokens = np.array(["I", "saw", "her"])               # -> ['I', 'saw', 'her']
t3_starts = np.array([0, 1, 0])                           # -> [0, 1, 0]
t3_ends = np.array([1, 3, 3])                             # -> [1, 3, 3]

t3_lengths = t3_ends - t3_starts                          # -> [1, 2, 3]
```

### ✍️ Toy 4 · CKY combines solved child spans into larger spans

CKY fills short spans first, then tries every split and rule to build longer phrase labels from
already-solved child cells.

```python
import numpy as np

t4_rng = np.random.default_rng(0)                         # seeded generator for reproducibility.
```

### ✍️ Toy 5 · SHIFT and ARC actions build a dependency tree

A transition parser mutates a stack, a buffer, and an arc list; each action changes one small piece of
state.

```python
import numpy as np

t5_rng = np.random.default_rng(0)                         # seeded generator for reproducibility.
t5_stack = ["ROOT"]                                      # -> ['ROOT']
t5_buffer = ["I", "saw", "her"]                         # -> ['I', 'saw', 'her']
t5_arcs = []                                             # -> []
print("initial:", t5_stack, t5_buffer, t5_arcs)           # -> ['ROOT'] ['I', 'saw', 'her'] []
t5_stack.append(t5_buffer.pop(0))                        # SHIFT -> stack ['ROOT', 'I']
print("after SHIFT:", t5_stack, t5_buffer, t5_arcs)       # -> ['ROOT', 'I'] ['saw', 'her'] []
t5_stack.append(t5_buffer.pop(0))                        # SHIFT -> stack ['ROOT', 'I', 'saw']
print("after SHIFT:", t5_stack, t5_buffer, t5_arcs)       # -> ['ROOT', 'I', 'saw'] ['her'] []
t5_left_dep = t5_stack.pop(-2)                           # LEFT-ARC dependent -> I
t5_left_head = t5_stack[-1]                               # LEFT-ARC head -> saw
t5_arcs.append((t5_left_head, t5_left_dep))               # -> [('saw', 'I')]
print("after LEFT:", t5_stack, t5_buffer, t5_arcs)        # -> ['ROOT', 'saw'] ['her'] [('saw', 'I')]
t5_stack.append(t5_buffer.pop(0))                        # SHIFT -> stack ['ROOT', 'saw', 'her']
print("after SHIFT:", t5_stack, t5_buffer, t5_arcs)       # -> ['ROOT', 'saw', 'her'] [] [('saw', 'I')]
t5_right_dep = t5_stack.pop()                            # RIGHT-ARC dependent -> her
t5_right_head = t5_stack[-1]                              # RIGHT-ARC head -> saw
t5_arcs.append((t5_right_head, t5_right_dep))             # -> [('saw', 'I'), ('saw', 'her')]
print("after RIGHT:", t5_stack, t5_buffer, t5_arcs)       # -> ['ROOT', 'saw'] [] [('saw', 'I'), ('saw', 'her')]
t5_root_dep = t5_stack.pop()                              # RIGHT-ARC dependent -> saw
t5_root_head = t5_stack[-1]                               # RIGHT-ARC head -> ROOT
t5_arcs.append((t5_root_head, t5_root_dep))               # -> [('saw', 'I'), ('saw', 'her'), ('ROOT', 'saw')]
print("after RIGHT:", t5_stack, t5_buffer, t5_arcs)       # -> ['ROOT'] [] [('saw', 'I'), ('saw', 'her'), ('ROOT', 'saw')]
assert set(t5_arcs) == {("saw", "I"), ("saw", "her"), ("ROOT", "saw")}

t5_actions = np.array(["SHIFT", "SHIFT", "LEFT", "SHIFT", "RIGHT", "RIGHT"])
t5_action_ids = np.array([1, 1, 2, 1, 3, 3])              # -> [1, 1, 2, 1, 3, 3]
plt.figure(figsize=(5, 2.8))
plt.bar(np.arange(len(t5_actions)), t5_action_ids, color="steelblue")
plt.xticks(np.arange(len(t5_actions)), t5_actions, rotation=25)
plt.ylabel("action id")
plt.title("Toy 5 · transition action program")
plt.show()
```
▶ What you'll see: the action sequence creates `saw → I`, `saw → her`, and finally `ROOT → saw`.

### ✍️ Toy 7 · Eisner dynamic programming scores a projective tree

Eisner keeps complete and incomplete interval charts; the full complete span stores the best
projective dependency score.

```python
import numpy as np

t7_rng = np.random.default_rng(0)                         # seeded generator for reproducibility.
t7_labels = np.array(["ROOT", "eat", "fish"])           # -> ['ROOT', 'eat', 'fish']
t7_scores = np.array([[0.0, 4.0, 0.0], [0.0, 0.0, 3.0], [0.0, 1.0, 0.0]])  # -> ROOT→eat=4, eat→fish=3
t7_n = t7_scores.shape[0]                                # -> 3
t7_complete = np.full((t7_n, t7_n, 2), -np.inf)           # -> complete chart
t7_incomplete = np.full((t7_n, t7_n, 2), -np.inf)         # -> incomplete chart
for t7_i in range(t7_n):
    t7_complete[t7_i, t7_i, 0] = 0.0
    t7_complete[t7_i, t7_i, 1] = 0.0
for t7_width in range(1, t7_n):
    for t7_s in range(t7_n - t7_width):
        t7_t = t7_s + t7_width
        t7_left_vals = np.array([t7_complete[t7_s, t7_r, 1] + t7_complete[t7_r + 1, t7_t, 0] + t7_scores[t7_t, t7_s] for t7_r in range(t7_s, t7_t)])
        t7_right_vals = np.array([t7_complete[t7_s, t7_r, 1] + t7_complete[t7_r + 1, t7_t, 0] + t7_scores[t7_s, t7_t] for t7_r in range(t7_s, t7_t)])

assert float(t7_best_score) == 7.0

plt.figure(figsize=(4.4, 3))
plt.imshow(np.nan_to_num(t7_complete_best), cmap="Greens", aspect="auto")
plt.colorbar(label="complete score")

plt.yticks(range(t7_n), t7_labels)
```

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, score tables, dynamic-programming charts, and asserts.
import matplotlib.pyplot as plt # load Matplotlib for heatmaps, arcs, bars, and chart diagnostics.
from collections import defaultdict, deque # load small stdlib containers for grammars, parser states, and backpointers.
np.random.seed(0) # make all examples deterministic.

def has_crossing(arcs): # test whether any two dependency arcs cross when endpoints are interleaved.
    def cross(a, b):
        i, j = sorted(a); k, l = sorted(b)
        return (i < k < j < l) or (k < i < l < j)
    return any(cross(a, b) for idx, a in enumerate(arcs) for b in arcs[idx + 1:])

def draw_arcs(words, arcs, title): # draw compact dependency arcs above a sentence.
    plt.figure(figsize=(max(4, len(words)), 2.6))
    for x, word in enumerate(words):
        plt.scatter([x], [0], color="black")
        plt.text(x, -0.12, word, ha="center")
    for h, m in arcs:
        lo, hi = sorted([h, m])
        xs = np.linspace(lo, hi, 80)
        height = 0.25 + 0.08 * (hi - lo)
        ys = height * np.sin(np.pi * (xs - lo) / max(hi - lo, 1))
        plt.plot(xs, ys, color="steelblue")
        plt.text((lo + hi) / 2, ys.max() + 0.03, "→", ha="center")
    plt.axis("off")
    plt.title(title)
    plt.show()

def valid_heads(heads): # check one root and no head-following cycles.
    heads = np.asarray(heads)
    if np.sum(heads == -1) != 1:
        return False
    n = len(heads)
    for start in range(n):
        seen = set()
        cur = start
        while heads[cur] != -1:
            cur = int(heads[cur])
            if cur in seen or cur < 0 or cur >= n:
                return False
            seen.add(cur)
    return True

def best_head_assignment(scores): # enumerate tiny one-head trees for teaching, not for production parsing.
    n = scores.shape[0]
    best_score, best_heads = -np.inf, None
    def rec(m, heads):
        nonlocal best_score, best_heads
        if m == n:
            arr = np.array(heads)
            if valid_heads(arr):
                total = sum(scores[h, child] for child, h in enumerate(arr) if h != -1)
                if total > best_score:
                    best_score, best_heads = total, arr.copy()
            return
        for h in range(-1, n):
            if h != m:
                heads.append(h); rec(m + 1, heads); heads.pop()
    rec(0, [])
    return best_score, best_heads

def cky_parse(tokens, lexicon, rules): # score a tiny binary constituency grammar with CKY.
    n = len(tokens)
    chart = [[defaultdict(lambda: -np.inf) for _ in range(n + 1)] for _ in range(n)]
    back = {}
    for i, tok in enumerate(tokens):
        for (label, word), score in lexicon.items():
            if word == tok:
                chart[i][i + 1][label] = score
    for width in range(2, n + 1):
        for i in range(n - width + 1):
            j = i + width
            for k in range(i + 1, j):
                for (parent, left, right), rscore in rules.items():
                    cand = chart[i][k][left] + chart[k][j][right] + rscore
                    if cand > chart[i][j][parent]:
                        chart[i][j][parent] = cand
                        back[(i, j, parent)] = (k, left, right)
    return chart, back

def chart_heat(chart, title): # visualize best score per CKY cell.
    n = len(chart)
    M = np.full((n + 1, n + 1), np.nan)
    for i in range(n):
        for j in range(i + 1, n + 1):
            vals = list(chart[i][j].values())
            if vals:
                M[i, j] = max(vals)
    plt.figure(figsize=(4.5, 3.4))
    plt.imshow(np.nan_to_num(M), cmap="viridis", aspect="auto")
    plt.colorbar(label="best cell score")
    plt.xlabel("end j"); plt.ylabel("start i")
    plt.title(title)
    plt.show()
```

### Advanced 4 — Run Eisner scoring for a projective tree

**Goal.** Implement the score-only Eisner recurrence, because projective dependency decoding can be solved exactly with interval dynamic programming. We build it in 4 steps.

```python
A_a4 = np.array([[0., 0., 5., 0.], [0., 0., 1., 1.], [0., 4., 0., 3.], [0., 1., 1., 0.]])
labels_a4 = ["ROOT", "I", "saw", "her"]
print("intended arc scores:", A_a4[0, 2], A_a4[2, 1], A_a4[2, 3])
```
▶ What you'll see: the three intended arcs sum to 12.

```python
def eisner_score_a4(scores):
    n = scores.shape[0]
    C = np.full((n, n, 2), -np.inf)
    I = np.full((n, n, 2), -np.inf)
    for i in range(n):
        C[i, i, 0] = C[i, i, 1] = 0.0
    for width in range(1, n):
        for s in range(n - width):
            t = s + width
            I[s, t, 0] = max(C[s, r, 1] + C[r + 1, t, 0] + scores[t, s] for r in range(s, t))
            I[s, t, 1] = max(C[s, r, 1] + C[r + 1, t, 0] + scores[s, t] for r in range(s, t))
            C[s, t, 0] = max(C[s, r, 0] + I[r, t, 0] for r in range(s, t))
            C[s, t, 1] = max(I[s, r + 1, 1] + C[r + 1, t, 1] for r in range(s, t))
    return C[0, n - 1, 1], C, I
best_a4, C_a4, I_a4 = eisner_score_a4(A_a4)
print("best Eisner score:", best_a4)
assert best_a4 == 12.0
```

```python

for i_a4 in range(4):
    for j_a4 in range(i_a4, 4):
        complete_a4[i_a4, j_a4] = max(C_a4[i_a4, j_a4, 0], C_a4[i_a4, j_a4, 1])
```
