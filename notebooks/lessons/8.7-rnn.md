# 8.7 — Recurrent Neural Networks

Recurrent neural networks (RNNs) read a sequence one element at a time while carrying a hidden state forward as memory. In this lesson, you will build the recurrent update, shared parameters, sequence outputs, and backpropagation through time from scratch with NumPy, then inspect exactly why vanilla RNNs can remember short patterns but struggle with long-range gradients.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build recurrent neural networks one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including backpropagation through time, is derived and shown. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays + linear algebra for recurrent states and gradients.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for any random examples.
```

### 1. A hidden state is a running memory

A sequence is not naturally one fixed vector: token 4 should be interpreted after tokens 1, 2, and 3 have already shaped the model's memory. A vanilla RNN solves this by updating a hidden state with the same recurrence at every step,

$$h_t=\tanh(W_{hh}h_{t-1}+W_{xh}x_t+b_h).$$

For one scalar hidden unit, this becomes easy to inspect: the previous state is multiplied by a recurrence weight, the current input is multiplied by an input weight, and `tanh` keeps the memory bounded between −1 and 1.

```python
x_w = np.array([1., 0., 1., 1.])  # a binary sequence arriving one element at a time.
w_hh_w = 0.8  # how strongly the previous hidden state survives.
w_xh_w = 0.6  # how strongly the current input writes into memory.
h_w = 0.0  # initial memory before reading anything.
print("inputs:", x_w)
print("initial h:", h_w)
```
▶ What you'll see: the sequence starts with no memory, then each input will update the same scalar state.

```python
states_w = []  # store h_1, h_2, ... for inspection.
preacts_w = []  # store the value before tanh so the nonlinearity is visible.
for t_w, x_t_w in enumerate(x_w, start=1):
    a_w = w_hh_w * h_w + w_xh_w * x_t_w  # recurrence plus current input.
    h_w = np.tanh(a_w)  # bounded hidden state.
    preacts_w.append(a_w)
    states_w.append(h_w)
    print(f"t={t_w}: a={a_w:.6f}, h={h_w:.6f}")
assert np.allclose(np.round(states_w, 6), [0.537050, 0.405020, 0.727792, 0.828155])
```
▶ What you'll see: the state falls when the input is 0, then rises again when more positive evidence arrives.

```python
plt.figure(figsize=(5, 3))
plt.plot(range(1, len(states_w) + 1), states_w, marker="o", color="teal", label="hidden h_t")
plt.step(range(1, len(x_w) + 1), x_w, where="mid", color="gray", alpha=0.6, label="input x_t")
plt.title("1: hidden state carries sequence memory")
plt.xlabel("time step")
plt.ylabel("value")
plt.ylim(-0.05, 1.05)
plt.legend()
plt.show()
```
▶ What you'll see: the hidden-state line is smoother than the input steps because it blends current evidence with past memory.

*Why it's done this way: the recurrence weight creates a path for old information, the input weight creates a path for new evidence, and `tanh` prevents repeated additions from exploding; together they turn a variable-length prefix into one fixed-size state.*

### 2. The same transition is reused at every time step

The key architectural constraint is **parameter sharing**. An RNN does not learn different weights for position 1, position 2, and position 3. It learns one transition and applies it repeatedly. That is what lets the same cell read a sequence longer than anything it saw during training.

```python
T_w = 6  # compare a six-step sequence.
shared_params_w = 3  # scalar W_hh, W_xh, and b_h.
unshared_params_w = 3 * T_w  # separate scalar transition at every position.
print("shared RNN parameters:", shared_params_w)
print("unshared per-step parameters:", unshared_params_w)
print("ratio:", unshared_params_w // shared_params_w)
assert unshared_params_w / shared_params_w == 6
```
▶ What you'll see: unsharing uses 6 times as many parameters for length 6 and would keep growing with length.

```python
x_long_w = np.array([1., 0., 1., 1., 0., 1., 0., 0.])  # length 8, longer than T_w.
h_shared_w = 0.0
states_shared_w = []
for x_t_w in x_long_w:
    h_shared_w = np.tanh(w_hh_w * h_shared_w + w_xh_w * x_t_w)  # no new weights needed.
    states_shared_w.append(h_shared_w)
print("computed states for length", len(x_long_w), ":", np.round(states_shared_w, 3))
assert len(states_shared_w) == 8
```
▶ What you'll see: the same three scalars handle all 8 positions even though the parameter-count comparison used length 6.

```python
plt.figure(figsize=(5, 3))
plt.bar(["shared", "unshared T=6", "unshared T=8"], [3, 18, 24], color=["teal", "orange", "crimson"])
plt.title("2: parameter sharing controls model size")
plt.ylabel("number of scalar transition parameters")
plt.show()
```
▶ What you'll see: shared parameters stay flat while per-position parameters grow linearly with sequence length.

*Why it's done this way: language and time series patterns can appear at many positions, so reusing one transition encodes the belief that the same local update rule should work wherever a token arrives.*

### 3. Vector RNNs mix input features into multiple memory units

Real RNNs use vectors, not one scalar. If $x_t\in\mathbb{R}^{d_x}$ and $h_t\in\mathbb{R}^{d_h}$, then $W_{xh}$ maps input features into hidden units and $W_{hh}$ mixes the previous hidden units into the next memory. The formula is the same; only the shapes change.

```python
X_w = np.array([[1., 0.],
                [0., 1.],
                [1., 1.]])  # three time steps, two input features.
W_xh_vec_w = np.array([[0.7, -0.2],
                       [0.1,  0.6]])  # shape hidden_dim x input_dim.
W_hh_vec_w = np.array([[0.5, 0.1],
                       [0.0, 0.4]])  # shape hidden_dim x hidden_dim.
b_vec_w = np.array([0.0, 0.1])
h_vec_w = np.zeros(2)
print("X shape:", X_w.shape, "W_xh shape:", W_xh_vec_w.shape, "W_hh shape:", W_hh_vec_w.shape)
```
▶ What you'll see: each input vector has 2 features, and the hidden state has 2 memory coordinates.

```python
H_vec_w = []
for t_w, x_t_w in enumerate(X_w, start=1):
    a_vec_w = W_hh_vec_w @ h_vec_w + W_xh_vec_w @ x_t_w + b_vec_w
    h_vec_w = np.tanh(a_vec_w)
    H_vec_w.append(h_vec_w.copy())
    print(f"t={t_w}: preactivation={np.round(a_vec_w, 3)}, h={np.round(h_vec_w, 3)}")
H_vec_w = np.array(H_vec_w)
assert H_vec_w.shape == (3, 2)
```
▶ What you'll see: each step produces a two-number hidden state, so memory can store more than one running feature.

```python
plt.figure(figsize=(5, 3))
plt.plot(H_vec_w[:, 0], marker="o", label="hidden unit 0")
plt.plot(H_vec_w[:, 1], marker="s", label="hidden unit 1")
plt.title("3: two hidden units track different mixtures")
plt.xlabel("time index")
plt.ylabel("hidden value")
plt.legend()
plt.show()
```
▶ What you'll see: the two hidden units move differently because their rows of `W_xh` and `W_hh` encode different feature mixtures.

*Why it's done this way: matrix multiplication lets each hidden unit choose which input features and previous memory coordinates matter; the vector state is a learned summary, not a hand-written counter.*

### 4. Final-state and per-step outputs answer different tasks

Once an RNN has hidden states, it can output at the end or at every step. A final-state classifier compresses the whole sequence into $h_T$ before deciding. A next-token model uses each intermediate state $h_t$ to predict the following token, so its labels must be shifted by one position.

```python
seq_w = np.array([0., 1., 1., 0., 1.])
h_lin_w = 0.0
lin_states_w = []
for x_t_w in seq_w:
    h_lin_w = 0.7 * h_lin_w + x_t_w  # linear recurrence for transparent arithmetic.
    lin_states_w.append(h_lin_w)
print("hidden states:", np.round(lin_states_w, 3))
print("final-state class:", int(lin_states_w[-1] > 1.5))
assert np.allclose(np.round(lin_states_w, 3), [0.0, 1.0, 1.7, 1.19, 1.833])
assert int(lin_states_w[-1] > 1.5) == 1
```
▶ What you'll see: the final state is 1.833, so a threshold at 1.5 gives class 1.

```python
seq_next_w = np.array([1., 0., 1., 0., 1.])
h_next_w = 0.0
preds_w = []
states_next_w = []
for x_t_w in seq_next_w[:-1]:  # last input has no next-token target in this tiny demo.
    h_next_w = 0.5 * h_next_w + x_t_w
    states_next_w.append(h_next_w)
    preds_w.append(int(h_next_w > 0.6))
targets_w = seq_next_w[1:].astype(int)
print("states used for prediction:", np.round(states_next_w, 3))
print("predicted next labels:", preds_w)
print("next-token targets:", targets_w.tolist())
assert preds_w == [1, 0, 1, 1]
```
▶ What you'll see: there are four predictions for five tokens, and they are compared to the shifted next tokens.

```python
plt.figure(figsize=(5, 3))
plt.plot(preds_w, marker="o", label="predicted next label")
plt.plot(targets_w, marker="s", label="actual next token")
plt.title("4: autoregressive predictions use shifted targets")
plt.xlabel("prediction index")
plt.ylabel("0/1")
plt.yticks([0, 1])
plt.legend()
plt.show()
```
▶ What you'll see: predictions and targets line up by next-token position, not by the inputs that produced the states.

*Why it's done this way: sequence classification asks what the whole prefix means, so $h_T$ is natural; autoregressive modeling asks what comes next after each prefix, so every intermediate hidden state becomes a supervised example.*

### 5. Backpropagation through time unrolls the recurrence

Training an RNN means differentiating through all the reused steps. In the scalar recurrence $h_t=\tanh(a_t)$ with $a_t=w_{hh}h_{t-1}+w_{xh}x_t$, a final loss depends on old states through a chain of derivatives. The local derivative is

$$\frac{\partial h_t}{\partial h_{t-1}}=(1-h_t^2)w_{hh}.$$

Backpropagation through time (BPTT) multiplies these local Jacobian factors backward along the unrolled chain.

```python
x_bptt_w = np.array([1., 0., 1., 1.])
w_hh_bptt_w = 0.8
w_xh_bptt_w = 0.6
h_bptt_w = 0.0
states_bptt_w = []
for x_t_w in x_bptt_w:
    h_bptt_w = np.tanh(w_hh_bptt_w * h_bptt_w + w_xh_bptt_w * x_t_w)
    states_bptt_w.append(h_bptt_w)
local_factors_w = w_hh_bptt_w * (1 - np.array(states_bptt_w) ** 2)
print("hidden states:", np.round(states_bptt_w, 6))
print("local dh_t/dh_{t-1}:", np.round(local_factors_w, 6))
```
▶ What you'll see: the `tanh` derivative shrinks when hidden states get closer to saturation.

```python
prod_back_w = 1.0
back_factors_w = []
for factor_w in local_factors_w[::-1]:  # from t=4 backward toward t=0.
    prod_back_w *= factor_w
    back_factors_w.append(prod_back_w)
print("cumulative backward products from final state:", np.round(back_factors_w, 6))
assert back_factors_w[-1] < 0.2
```
▶ What you'll see: each extra step backward multiplies another factor, so the gradient reaching early time steps is smaller.

```python
plt.figure(figsize=(5, 3))
plt.plot(range(1, len(back_factors_w) + 1), back_factors_w, marker="o", color="crimson")
plt.title("5: BPTT multiplies local Jacobians")
plt.xlabel("steps backward from final state")
plt.ylabel("cumulative gradient multiplier")
plt.show()
```
▶ What you'll see: the multiplier decays as the chain reaches farther back in time.

*Why it's done this way: BPTT is ordinary chain rule applied to a reused computation graph; sharing weights means gradient contributions from every time step are summed into the same parameters, while the path to early states is a product of many Jacobians.*

### 6. Vanishing, exploding, and saturation are consequences of repeated multiplication

The same recurrence that carries memory forward carries gradients backward. If the effective multiplier is less than 1, long-range gradients vanish; if it is greater than 1, they explode. `tanh` adds another shrinkage source: near ±1 its derivative is close to zero, so even a moderate recurrence weight can lose signal.

```python
scales_w = np.array([0.2, 0.5, 0.9])
steps_w = 20
powers_w = scales_w ** steps_w
for s_w, p_w in zip(scales_w, powers_w):
    print(f"{s_w}^{steps_w} = {p_w}")
assert np.isclose(powers_w[0], 1.048576e-14)
assert np.isclose(powers_w[1], 9.5367431640625e-7)
assert np.isclose(powers_w[2], 0.12157665459056935)
```
▶ What you'll see: 0.2 and 0.5 essentially erase a 20-step signal, while 0.9 leaves a usable fraction.

```python
grid_w = np.linspace(-4, 4, 200)
tanh_deriv_w = 1 - np.tanh(grid_w) ** 2
print("derivative at 0:", round(float(1 - np.tanh(0) ** 2), 3))
print("derivative at 3:", round(float(1 - np.tanh(3) ** 2), 3))
assert round(float(1 - np.tanh(3) ** 2), 3) == 0.010
```
▶ What you'll see: `tanh` is easy to change near 0 but almost flat by input 3.

```python
plt.figure(figsize=(5, 3))
plt.plot(grid_w, tanh_deriv_w, color="purple")
plt.title("6: tanh saturation shrinks gradients")
plt.xlabel("preactivation a")
plt.ylabel("1 - tanh(a)^2")
plt.show()
```
▶ What you'll see: the derivative curve peaks at 1 near zero and collapses toward 0 in the saturated tails.

*Why it's done this way: repeated multiplication is unavoidable in a chain-structured model; vanilla RNNs expose the problem directly, which is why later LSTM and GRU cells create gated paths that can keep memory multipliers closer to one.*

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, matrix multiplication, recurrence loops, and numerical checks.
import matplotlib.pyplot as plt # load Matplotlib so hidden states, gradients, and losses can be inspected visually.
np.random.seed(0) # make all examples reproducible across notebook runs.

def rnn_forward_scalar(xs, w_hh=0.8, w_xh=0.6, b=0.0): # run a scalar tanh RNN over a 1-D sequence.
    h = 0.0 # start with no memory before the first token.
    states = [] # store every hidden state so we can inspect the full path.
    for x in xs: # read one input at a time.
        h = np.tanh(w_hh * h + w_xh * x + b) # apply the shared recurrent transition.
        states.append(h) # save the current memory.
    return np.array(states) # return h_1 through h_T as a NumPy array.

def rnn_forward_vector(X, W_xh, W_hh, b): # run a vector tanh RNN over rows of X.
    h = np.zeros(W_hh.shape[0]) # initialize a hidden vector with the correct hidden dimension.
    states = [] # collect hidden states over time.
    for x in X: # process each input vector in order.
        h = np.tanh(W_hh @ h + W_xh @ x + b) # combine previous memory and current input.
        states.append(h.copy()) # copy the state so later updates do not overwrite history.
    return np.array(states) # return a T by hidden_dim matrix.

def sigmoid(z): # define the logistic function for small output demos.
    return 1 / (1 + np.exp(-z)) # map any real number into (0, 1).

def binary_cross_entropy(p, y): # define a numerically safe binary cross-entropy helper.
    p = np.clip(p, 1e-9, 1 - 1e-9) # avoid log(0) in tiny hand-written examples.
    return -(y * np.log(p) + (1 - y) * np.log(1 - p)) # return the Bernoulli negative log-likelihood.
```

### Basic 2 — Compute one scalar recurrent update

**Goal.** Manually calculate the first hidden state, because every later RNN step repeats the same recurrence formula. We build it in 2 steps.

```python
x_b2 = 1.0 # define the first input token.
h_prev_b2 = 0.0 # define the initial hidden state.
w_hh_b2 = 0.8 # define the recurrence weight.
w_xh_b2 = 0.6 # define the input weight.
a_b2 = w_hh_b2 * h_prev_b2 + w_xh_b2 * x_b2 # compute the preactivation before tanh.
print("preactivation:", round(a_b2, 3)) # inspect the weighted sum.
```
▶ What you'll see: the first preactivation is 0.6 because there is no previous memory yet.

```python
h_b2 = np.tanh(a_b2) # squash the preactivation into the hidden state.
print("h_1:", round(h_b2, 6)) # inspect the first hidden state.
assert round(h_b2, 6) == 0.537050 # verify the lesson number.
plt.figure(figsize=(4, 3)) # create a tiny before-after plot.
plt.bar(["a_1", "tanh(a_1)"], [a_b2, h_b2], color=["orange", "teal"]) # compare linear and squashed values.
plt.title("Basic 2: one recurrent update") # title the update plot.
plt.show() # display the bar chart.
```
▶ What you'll see: `tanh` maps 0.6 to about 0.537, slightly shrinking the raw weighted sum.

👀 Takeaway: one RNN step is a weighted sum of old memory and new input followed by a nonlinearity.

### Basic 4 — Compare input and recurrent contributions

**Goal.** Split the preactivation into old-memory and new-input pieces, because RNN behavior is controlled by their balance. We build it in 3 steps.

```python
x_b4 = np.array([1., 0., 1., 1.]) # define the sequence.
h_prev_b4 = 0.0 # initialize memory.
old_parts_b4 = [] # store W_hh h_{t-1}.
new_parts_b4 = [] # store W_xh x_t.
for x_t_b4 in x_b4: # process inputs in order.
    old_b4 = 0.8 * h_prev_b4 # compute the carried memory contribution.
    new_b4 = 0.6 * x_t_b4 # compute the current input contribution.
    h_prev_b4 = np.tanh(old_b4 + new_b4) # update hidden state.
    old_parts_b4.append(old_b4) # save old contribution.
    new_parts_b4.append(new_b4) # save new contribution.
print("old-memory parts:", np.round(old_parts_b4, 3)) # inspect recurrence contributions.
```
▶ What you'll see: the old-memory part is zero at t=1, then depends on the previous hidden state.

```python
print("new-input parts:", np.round(new_parts_b4, 3)) # inspect input contributions.
print("combined preactivations:", np.round(np.array(old_parts_b4) + np.array(new_parts_b4), 3)) # inspect sums before tanh.
```

```python
idx_b4 = np.arange(len(x_b4)) # create x positions for stacked bars.
plt.figure(figsize=(5, 3)) # create a contribution plot.
plt.bar(idx_b4, old_parts_b4, label="old memory", color="gray") # plot carried memory.
plt.bar(idx_b4, new_parts_b4, bottom=old_parts_b4, label="new input", color="teal") # stack new input on top.
plt.title("Basic 4: preactivation pieces") # title the plot.

```
▶ What you'll see: zero inputs still have nonzero preactivation when old memory is present.

👀 Takeaway: the hidden state changes because old memory and current input are blended before the nonlinearity.

### Basic 7 — Produce one output at every step

**Goal.** Generate per-step scores from hidden states, because tagging and next-token tasks need an output for each prefix. We build it in 2 steps.

```python
x_b7 = np.array([1., 0., 1., 0.]) # define four inputs.
states_b7 = rnn_forward_scalar(x_b7, w_hh=0.5, w_xh=1.0) # compute one hidden state per input.
```

### Easy 4 — Hand-code BPTT for a scalar final loss

**Goal.** Backpropagate from a final squared error through a scalar RNN, because BPTT is the chain rule over the unrolled recurrence. We build it in 4 steps.

```python
x_e4 = np.array([1., 0., 1.]) # define a short sequence for hand BPTT.
w_hh_e4 = 0.7 # recurrence weight.
w_xh_e4 = 0.5 # input weight.
target_e4 = 0.8 # desired final hidden state.
hs_e4 = [0.0] # include h_0 for derivative bookkeeping.
as_e4 = [] # store preactivations.
for x_t_e4 in x_e4: # forward pass.
    a_t_e4 = w_hh_e4 * hs_e4[-1] + w_xh_e4 * x_t_e4 # compute preactivation.
    as_e4.append(a_t_e4) # save preactivation.
    hs_e4.append(np.tanh(a_t_e4)) # save hidden state.
print("hidden states h_0..h_T:", np.round(hs_e4, 3)) # inspect forward path.
```
▶ What you'll see: the list includes the initial state plus three computed states.

```python
loss_e4 = 0.5 * (hs_e4[-1] - target_e4) ** 2 # use half squared error for a clean derivative.
dh_next_e4 = hs_e4[-1] - target_e4 # dL/dh_T.
print("loss:", round(loss_e4, 4), "dL/dh_T:", round(dh_next_e4, 4)) # inspect starting gradient.
```

```python
dw_hh_e4 = 0.0 # accumulate gradient for the shared recurrence weight.
dw_xh_e4 = 0.0 # accumulate gradient for the shared input weight.
grad_h_path_e4 = [] # record gradients reaching each state.
for t_e4 in range(len(x_e4), 0, -1): # walk backward from T to 1.
    da_e4 = dh_next_e4 * (1 - hs_e4[t_e4] ** 2) # tanh derivative times upstream gradient.
    dw_hh_e4 += da_e4 * hs_e4[t_e4 - 1] # shared W_hh receives contribution from this time step.
    dw_xh_e4 += da_e4 * x_e4[t_e4 - 1] # shared W_xh receives contribution from this time step.
    dh_next_e4 = da_e4 * w_hh_e4 # pass gradient to h_{t-1}.
    grad_h_path_e4.append(dh_next_e4) # store propagated gradient.
print("dW_hh:", round(dw_hh_e4, 4), "dW_xh:", round(dw_xh_e4, 4)) # inspect shared gradients.
assert np.isfinite(dw_hh_e4) and np.isfinite(dw_xh_e4) # verify BPTT produced valid numbers.
```

```python

plt.ylabel("|gradient to earlier h|") # label gradient magnitude.
plt.show() # display the gradient path.
```
▶ What you'll see: gradients are accumulated into the same weights while the state gradient is repeatedly multiplied backward.

👀 Takeaway: BPTT sums parameter-gradient contributions from every time step because the transition parameters are shared.

### Advanced 3 — Train on variable-length sequences with shared weights

**Goal.** Fit one scalar RNN to classify several sequence lengths, because parameter sharing lets the same recurrence handle every length. We build it in 5 steps.

```python

w_xh_a3 = 0.2 # initialize input weight.
w_y_a3 = 0.5 # initialize output weight.
```

```python

        for x_t_a3 in seq_a3: # forward through this sequence length.
```
