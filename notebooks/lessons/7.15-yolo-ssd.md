# 7.15 — YOLO & SSD

YOLO and SSD are one-stage object detectors: instead of first proposing regions and then classifying cropped regions, they ask every feature-grid location to predict boxes, objectness, and class probabilities in one dense pass. In this lesson, we build the mechanics from scratch with NumPy: grid responsibility, anchor/default-box decoding, IoU assignment, confidence scoring, multi-scale SSD intuition, and non-maximum suppression.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build YOLO and SSD one idea at a time. Run each cell in order and read the printed intermediate values — every geometric and probabilistic piece is spelled out so dense detection does not feel like a black box. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, vectorized geometry, and small detector tensors.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for any random scores.
```

### 1. One-stage detection as dense grid prediction

A one-stage detector turns an image into a grid of prediction sites. Each cell emits a small bundle of numbers right away: box offsets, objectness, and class scores. The speed comes from refusing a separate proposal stage; every location proposes boxes in parallel.

```python
H_w, W_w, stride_w = 4, 4, 16  # a 4x4 feature grid over a 64x64 image.
cell_y_w, cell_x_w = np.mgrid[0:H_w, 0:W_w]  # integer row/column for every grid cell.
centers_w = np.stack([(cell_x_w + 0.5) * stride_w, (cell_y_w + 0.5) * stride_w], axis=-1)  # cell centers in pixels.
print("grid shape:", centers_w.shape)
print("top-left center:", centers_w[0, 0], "bottom-right center:", centers_w[-1, -1])
assert centers_w.shape == (4, 4, 2)
```
▶ What you'll see: a 4×4 grid where each cell has one pixel-space center.

```python
plt.figure(figsize=(4, 4))
plt.scatter(centers_w[..., 0].ravel(), centers_w[..., 1].ravel(), s=80, color="steelblue")
for y_w in range(H_w + 1):
    plt.axhline(y_w * stride_w, color="gray", linewidth=0.7)
for x_w in range(W_w + 1):
    plt.axvline(x_w * stride_w, color="gray", linewidth=0.7)
plt.xlim(0, W_w * stride_w); plt.ylim(H_w * stride_w, 0)
plt.title("1: every grid cell predicts now")
plt.xlabel("x pixels"); plt.ylabel("y pixels"); plt.show()
```
▶ What you'll see: sixteen prediction sites laid over the image; a detector head can emit boxes from all of them in one convolutional pass.

*Why it's done this way:* convolutional feature maps already preserve spatial layout, so attaching a small predictor to every cell converts detection into dense prediction. The grid index supplies coarse position; the network only needs to learn local corrections instead of arbitrary image-wide coordinates.

### 2. YOLO-style center decoding keeps responsibility local

YOLO predicts offsets inside the responsible grid cell. A sigmoid maps raw center logits into `(0, 1)`, then the cell coordinate `(j, i)` is added: `x = j + sigmoid(t_x)`, `y = i + sigmoid(t_y)`. This prevents neighboring cells from all freely chasing the same center.

```python
def sigmoid_w(z_w):
    return 1.0 / (1.0 + np.exp(-z_w))

i_w, j_w = 2, 3  # row i, column j.
tx_w = np.log(0.25 / 0.75)  # logit whose sigmoid is exactly 0.25.
ty_w = np.log(0.75 / 0.25)  # logit whose sigmoid is exactly 0.75.
offset_w = np.array([sigmoid_w(tx_w), sigmoid_w(ty_w)])
center_cells_w = np.array([j_w, i_w]) + offset_w
print("sigmoid offsets:", np.round(offset_w, 3))
print("center in grid cells:", np.round(center_cells_w, 3))
assert np.allclose(np.round(center_cells_w, 3), [3.25, 2.75])
```
▶ What you'll see: the decoded center is `(3.25, 2.75)` grid cells, matching the lesson's worked number.

```python
center_px_w = center_cells_w * stride_w
print("center in pixels:", center_px_w)
assert np.allclose(center_px_w, [52., 44.])

plt.figure(figsize=(4, 4))
plt.scatter([center_px_w[0]], [center_px_w[1]], s=120, color="crimson", label="decoded center")
plt.gca().add_patch(plt.Rectangle((j_w * stride_w, i_w * stride_w), stride_w, stride_w,
                                  fill=False, edgecolor="crimson", linewidth=2))
plt.xlim(32, 64); plt.ylim(64, 24); plt.grid(True); plt.legend()
plt.title("2: sigmoid offset stays inside its cell"); plt.show()
```
▶ What you'll see: the red center lies inside the red responsible cell, not in a global free-for-all.

*Why it's done this way:* adding the cell offset gives every predictor its own coordinate frame, while the sigmoid makes center learning bounded. Width and height can still vary, but center responsibility is localized, which stabilizes assignment and reduces duplicate competition during training.

### 3. Anchor/default-box decoding turns outputs into boxes

YOLO and SSD do not predict a box from nothing; they predict corrections to an anchor or default box. The common decode is `w = a_w exp(t_w)`, `h = a_h exp(t_h)`: zero width/height logits reproduce the anchor, positive logits enlarge it, and negative logits shrink it while keeping sizes positive.

```python
anchor_w = np.array([32., 16.])  # width, height in pixels.
twh_w = np.array([np.log(1.25), np.log(0.5)])  # enlarge width by 1.25, shrink height by 0.5.
size_w = anchor_w * np.exp(twh_w)
box_cxcywh_w = np.r_[center_px_w, size_w]
print("decoded size:", np.round(size_w, 3))
print("cx, cy, w, h:", np.round(box_cxcywh_w, 3))
assert np.allclose(size_w, [40., 8.])
```
▶ What you'll see: the anchor `(32,16)` becomes a `(40,8)` box around the decoded center.

```python
def cxcywh_to_xyxy_w(box_w):
    cx_w, cy_w, bw_w, bh_w = box_w
    return np.array([cx_w - bw_w / 2, cy_w - bh_w / 2, cx_w + bw_w / 2, cy_w + bh_w / 2])

xyxy_w = cxcywh_to_xyxy_w(box_cxcywh_w)
print("xyxy box:", np.round(xyxy_w, 3))
assert np.allclose(xyxy_w, [32., 40., 72., 48.])
```
▶ What you'll see: center-size form becomes corner form `[32, 40, 72, 48]`, which is easier for IoU and NMS.

```python
plt.figure(figsize=(5, 4))
ax_w = plt.gca()
ax_w.add_patch(plt.Rectangle((xyxy_w[0], xyxy_w[1]), xyxy_w[2]-xyxy_w[0], xyxy_w[3]-xyxy_w[1],
                             fill=False, edgecolor="darkorange", linewidth=2, label="decoded box"))
plt.scatter([center_px_w[0]], [center_px_w[1]], color="black")
plt.xlim(20, 80); plt.ylim(60, 30); plt.legend(); plt.grid(True)
plt.title("3: anchor correction becomes a real box"); plt.show()
```
▶ What you'll see: a thin wide decoded box centered at the YOLO-decoded location.

*Why it's done this way:* anchors encode a useful prior over object shapes. Exponentiating width and height is mathematically convenient because any real network output becomes a positive scale factor, so the model learns multiplicative shape corrections rather than invalid negative sizes.

### 4. IoU assigns responsibility to anchors/default boxes

Dense detectors produce many candidate boxes, so training needs a rule saying which one should learn each ground-truth object. SSD uses IoU against default boxes across locations and scales; the best-overlap default box is responsible even before the model is good.

```python
def iou_xyxy_w(a_w, b_w):
    x1_w = max(a_w[0], b_w[0]); y1_w = max(a_w[1], b_w[1])
    x2_w = min(a_w[2], b_w[2]); y2_w = min(a_w[3], b_w[3])
    inter_w = max(0.0, x2_w - x1_w) * max(0.0, y2_w - y1_w)
    area_a_w = (a_w[2] - a_w[0]) * (a_w[3] - a_w[1])
    area_b_w = (b_w[2] - b_w[0]) * (b_w[3] - b_w[1])
    return inter_w / (area_a_w + area_b_w - inter_w)

box1_w = np.array([0., 0., 3., 3.])
box2_w = np.array([1., 1., 4., 4.])
print("IoU:", round(iou_xyxy_w(box1_w, box2_w), 3))
assert round(iou_xyxy_w(box1_w, box2_w), 3) == 0.286
```
▶ What you'll see: the classic overlap example has IoU `4/14 ≈ 0.286`.

```python
gt_w = np.array([1., 1., 3., 3.])
anchors_w = np.array([[0., 0., 2., 2.], [0., 0., 3., 3.], [1., 1., 4., 4.]])
ious_w = np.array([iou_xyxy_w(a_w, gt_w) for a_w in anchors_w])
best_w = int(np.argmax(ious_w))
print("anchor IoUs:", np.round(ious_w, 3), "best index:", best_w)
assert np.allclose(np.round(ious_w, 3), [0.143, 0.444, 0.444])
assert best_w == 1
```
▶ What you'll see: anchors 1 and 2 tie at `0.444`, and NumPy's first maximum chooses index 1.

```python
plt.figure(figsize=(4, 4))
colors_w = ["gray", "seagreen", "steelblue"]
ax_w = plt.gca()
for k_w, a_w in enumerate(anchors_w):
    ax_w.add_patch(plt.Rectangle((a_w[0], a_w[1]), a_w[2]-a_w[0], a_w[3]-a_w[1],
                                 fill=False, edgecolor=colors_w[k_w], linewidth=2, label=f"anchor {k_w}"))
ax_w.add_patch(plt.Rectangle((gt_w[0], gt_w[1]), gt_w[2]-gt_w[0], gt_w[3]-gt_w[1],
                             fill=False, edgecolor="crimson", linewidth=3, label="ground truth"))
plt.xlim(-0.2, 4.2); plt.ylim(4.2, -0.2); plt.legend(); plt.grid(True)
plt.title("4: IoU chooses a responsible default box"); plt.show()
```
▶ What you'll see: the ground-truth box overlaps two larger anchors equally well, so the first best index receives responsibility.

*Why it's done this way:* IoU is scale-free overlap: it rewards intersection and penalizes union. Assignment by IoU gives each object a concrete training target among thousands of dense candidates, preventing every anchor from being treated identically.

### 5. Objectness gates class probability

A dense detector must answer two questions: is there an object here, and what class is it if there is? The class-specific confidence multiplies objectness by class probability. A high class probability alone is not enough if the box is probably background.

```python
objectness_w = np.array([0.8, 0.5, 0.9])
car_prob_w = np.array([0.6, 0.9, 0.2])
conf_w = objectness_w * car_prob_w
print("car confidences:", conf_w)
print("best box index:", int(np.argmax(conf_w)))
assert np.allclose(conf_w[:2], [0.48, 0.45])
```
▶ What you'll see: the first box ranks above the second because `0.8×0.6 = 0.48` beats `0.5×0.9 = 0.45`.

```python
plt.figure(figsize=(5, 3))
x_w = np.arange(3)
plt.bar(x_w - 0.25, objectness_w, width=0.25, label="objectness")
plt.bar(x_w, car_prob_w, width=0.25, label="p(car | object)")
plt.bar(x_w + 0.25, conf_w, width=0.25, label="product")
plt.xticks(x_w, ["box0", "box1", "box2"]); plt.ylim(0, 1)
plt.title("5: final score = objectness × class probability")
plt.legend(); plt.show()
```
▶ What you'll see: a class probability can be high while the final detection score stays lower because objectness gates it.

*Why it's done this way:* class probabilities are conditional: they say which class the box would be if it contained an object. Objectness estimates whether that condition holds, so multiplication is the probability logic that separates confident foreground from confident-looking background.

### 6. SSD's multi-scale default boxes protect small and large objects

SSD predicts from several feature maps. Fine grids have many small default boxes for small objects; coarse grids have fewer large boxes for large objects. This is the direct fix for using one feature scale for every object.

```python
levels_w = [(4, 4, 16, 16), (2, 2, 32, 32)]  # grid_h, grid_w, stride, square default size.
def make_defaults_w(levels_w):
    boxes_w = []
    for gh_w, gw_w, st_w, size_w in levels_w:
        yy_w, xx_w = np.mgrid[0:gh_w, 0:gw_w]
        cx_w = (xx_w + 0.5) * st_w; cy_w = (yy_w + 0.5) * st_w
        for cx_i_w, cy_i_w in zip(cx_w.ravel(), cy_w.ravel()):
            boxes_w.append([cx_i_w-size_w/2, cy_i_w-size_w/2, cx_i_w+size_w/2, cy_i_w+size_w/2])
    return np.array(boxes_w)

defaults_w = make_defaults_w(levels_w)
print("number of default boxes:", len(defaults_w))
assert len(defaults_w) == 20
```
▶ What you'll see: two feature levels create 20 default boxes: 16 small plus 4 large.

```python
small_gt_w = np.array([0., 0., 16., 16.])
large_gt_w = np.array([0., 0., 32., 32.])
small_best_w = np.max([iou_xyxy_w(d_w, small_gt_w) for d_w in defaults_w])
large_best_w = np.max([iou_xyxy_w(d_w, large_gt_w) for d_w in defaults_w])
print("best small-object IoU:", round(small_best_w, 3))
print("best large-object IoU:", round(large_best_w, 3))
assert small_best_w > 0.5 and large_best_w > 0.5
```
▶ What you'll see: the small object and large object both find a reasonable default box because two scales are available.

```python
plt.figure(figsize=(4, 4))
ax_w = plt.gca()
for d_w in defaults_w:
    ax_w.add_patch(plt.Rectangle((d_w[0], d_w[1]), d_w[2]-d_w[0], d_w[3]-d_w[1],
                                 fill=False, edgecolor="gray", alpha=0.35))
for g_w, c_w, name_w in [(small_gt_w, "crimson", "small"), (large_gt_w, "navy", "large")]:
    ax_w.add_patch(plt.Rectangle((g_w[0], g_w[1]), g_w[2]-g_w[0], g_w[3]-g_w[1],
                                 fill=False, edgecolor=c_w, linewidth=3, label=name_w))
plt.xlim(0, 64); plt.ylim(64, 0); plt.legend(); plt.title("6: SSD default boxes across scales"); plt.show()
```
▶ What you'll see: a field of small and large candidate boxes; different object sizes are covered by different feature levels.

*Why it's done this way:* a coarse grid cannot localize tiny objects well, and a fine grid with only tiny boxes cannot cover large objects efficiently. Multi-scale defaults spread responsibility across resolutions, matching object size to feature-map stride.

### 7. NMS removes duplicate dense predictions

Dense prediction creates nearby boxes for the same object. Non-maximum suppression keeps the highest-scoring box, then removes lower-scoring boxes whose IoU with it exceeds a threshold. Speed comes before this cleanup; one-stage detectors still need it.

```python
def nms_w(boxes_w, scores_w, thresh_w):
    order_w = np.argsort(scores_w)[::-1]
    keep_w = []
    while len(order_w) > 0:
        cur_w = int(order_w[0])
        keep_w.append(cur_w)
        rest_w = order_w[1:]
        rest_ious_w = np.array([iou_xyxy_w(boxes_w[cur_w], boxes_w[r_w]) for r_w in rest_w])
        order_w = rest_w[rest_ious_w <= thresh_w]
    return keep_w

boxes_w = np.array([[0., 0., 3., 3.], [0.5, 0.5, 3.5, 3.5], [5., 5., 7., 7.]])
scores_w = np.array([0.9, 0.8, 0.7])
keep_w = nms_w(boxes_w, scores_w, 0.3)
print("kept indices:", keep_w)
assert keep_w == [0, 2]
```
▶ What you'll see: box 1 is removed because it overlaps box 0 too much; box 2 remains separate.

```python
print("IoU box0-box1:", round(iou_xyxy_w(boxes_w[0], boxes_w[1]), 3))
plt.figure(figsize=(5, 4))
ax_w = plt.gca()
for k_w, b_w in enumerate(boxes_w):
    col_w = "seagreen" if k_w in keep_w else "crimson"
    ax_w.add_patch(plt.Rectangle((b_w[0], b_w[1]), b_w[2]-b_w[0], b_w[3]-b_w[1],
                                 fill=False, edgecolor=col_w, linewidth=2))
    plt.text(b_w[0], b_w[1]-0.15, f"{k_w}: {scores_w[k_w]}", color=col_w)
plt.xlim(-0.5, 8); plt.ylim(8, -0.8); plt.grid(True)
plt.title("7: NMS keeps green, suppresses red"); plt.show()
assert round(iou_xyxy_w(boxes_w[0], boxes_w[1]), 3) == 0.532
```
▶ What you'll see: two overlapping boxes for the same object, with the lower-score duplicate suppressed.

*Why it's done this way:* the detector scores boxes independently, so neighboring anchors often fire on the same object. NMS adds a geometric competition step: high confidence wins, and excessive overlap marks likely duplicates rather than new objects.

### Basic 2 — Decode a sigmoid center offset

**Goal.** Convert raw center logits into a cell-local center, because YOLO uses sigmoid offsets plus the cell index. We build it in 2 steps.

```python
def sigmoid_b2(z_b2):  # define the logistic function for center and objectness decoding.
    return 1.0 / (1.0 + np.exp(-z_b2))  # map any real number into (0, 1).

t_b2 = np.array([0.0, np.log(3.0)])  # choose logits whose sigmoids are 0.5 and 0.75.
offset_b2 = sigmoid_b2(t_b2)  # decode fractional offsets inside the cell.
print("offsets:", np.round(offset_b2, 3))  # inspect cell-local coordinates.
assert np.allclose(np.round(offset_b2, 3), [0.5, 0.75])
```
▶ What you'll see: raw logits become bounded offsets inside one cell.

```python
cell_b2 = np.array([2, 1])  # store (column j, row i) for the responsible cell.
center_cell_b2 = cell_b2 + offset_b2  # add the integer cell offset to get grid-coordinate center.
center_px_b2 = center_cell_b2 * 16  # multiply by stride to get pixels.
print("center cells:", np.round(center_cell_b2, 3), "center pixels:", center_px_b2)  # inspect both coordinate systems.

```
▶ What you'll see: the grid-coordinate center becomes a pixel-coordinate center by multiplying by stride.

👀 Takeaway: YOLO center decoding is local offset plus global cell position.

▶ What you'll see: the width scale is 1 and the height scale is 2.

```python
size_b3 = anchor_b3 * scale_b3  # apply corrections to the anchor dimensions.
```

### Basic 5 — Compute intersection area

**Goal.** Find the overlapping rectangle between two boxes, because IoU starts with intersection area. We build it in 2 steps.

```python
a_b5 = np.array([0.0, 0.0, 3.0, 3.0])  # define the first xyxy box.
b_b5 = np.array([1.0, 1.0, 4.0, 4.0])  # define the second xyxy box.
inter_tl_b5 = np.maximum(a_b5[:2], b_b5[:2])  # overlap starts at the larger top-left coordinates.
inter_br_b5 = np.minimum(a_b5[2:], b_b5[2:])  # overlap ends at the smaller bottom-right coordinates.
print("intersection corners:", inter_tl_b5, inter_br_b5)  # inspect the overlap box.
```
▶ What you'll see: the intersection is the square from `(1,1)` to `(3,3)`.

```python
inter_wh_b5 = np.maximum(0.0, inter_br_b5 - inter_tl_b5)  # clamp width/height to avoid negative overlap.
inter_area_b5 = float(inter_wh_b5[0] * inter_wh_b5[1])  # multiply overlap width by height.
print("intersection width/height:", inter_wh_b5, "area:", inter_area_b5)  # inspect area pieces.
assert inter_area_b5 == 4.0
plt.figure(figsize=(4, 3)); plt.bar(["w", "h", "area"], [inter_wh_b5[0], inter_wh_b5[1], inter_area_b5], color="darkorange")
plt.title("Basic 5: intersection area"); plt.show()
```
▶ What you'll see: a 2-by-2 intersection has area 4.

👀 Takeaway: intersection uses max of starts and min of ends.

### Basic 6 — Compute IoU

**Goal.** Divide intersection by union, because IoU is the localization score used for assignment and NMS. We build it in 2 steps.

```python
a_b6 = np.array([0.0, 0.0, 3.0, 3.0])  # first box.
```

### Easy 3 — Run class-aware NMS

**Goal.** Suppress duplicates within a class but not across unrelated classes, because a car should not remove a person just by overlapping. We build it in 3 steps.

### Advanced 4 — Sweep the NMS IoU threshold

**Goal.** See how the NMS threshold changes the number of kept boxes, because aggressive thresholds suppress more duplicates but can remove nearby objects. We build it in 3 steps.

```python
def iou_a4(a_a4, b_a4):
    tl_a4 = np.maximum(a_a4[:2], b_a4[:2]); br_a4 = np.minimum(a_a4[2:], b_a4[2:])
    wh_a4 = np.maximum(0.0, br_a4 - tl_a4); inter_a4 = wh_a4[0] * wh_a4[1]
    return inter_a4 / (np.prod(a_a4[2:] - a_a4[:2]) + np.prod(b_a4[2:] - b_a4[:2]) - inter_a4)

def nms_a4(boxes_a4, scores_a4, thresh_a4):
    order_a4 = np.argsort(scores_a4)[::-1]; keep_a4 = []
    while len(order_a4) > 0:
        cur_a4 = int(order_a4[0]); keep_a4.append(cur_a4); rest_a4 = order_a4[1:]
        order_a4 = rest_a4[np.array([iou_a4(boxes_a4[cur_a4], boxes_a4[r]) for r in rest_a4]) <= thresh_a4]
    return keep_a4

boxes_a4 = np.array([[0,0,3,3], [0.3,0.3,3.3,3.3], [1,1,4,4], [5,5,7,7]], dtype=float)
```
