# 8.10 — Sequence-to-Sequence

Sequence-to-sequence learning turns one variable-length stream into another: an encoder reads the source, a decoder writes the target one token at a time, and attention lets the decoder look back at the source instead of trusting one compressed vector forever. In this lesson, we build every moving part from scratch in NumPy so the conditional probability, hidden-state flow, teacher forcing shift, exposure-bias risk, and Bahdanau attention weights are visible rather than magical.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build sequence-to-sequence modeling one idea at a time. Run each cell in order and read the printed intermediate values — every state, probability, and attention score is small enough to inspect. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, matrix products, softmax math, and tiny RNN states.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for any stochastic choices.
```

### 1. A source sequence is read into encoder states

Seq2seq starts because the input and output are sequences, not one fixed feature vector. An encoder RNN reads tokens from left to right and updates a hidden state. The final state is the simplest summary: it is one vector that has been repeatedly rewritten by every source token.

```python
source_w = np.array([2., 1., 3.])  # a tiny source sequence with three numeric tokens.
h_w = 0.0  # start the scalar encoder state at zero.
states_w = []  # keep every state, not just the final summary.
for x_w in source_w:  # read tokens in source order.
    h_w = np.tanh(0.6 * h_w + 0.4 * x_w)  # combine memory with the new token.
    states_w.append(h_w)  # store the state after this token.
states_w = np.array(states_w)  # convert to an array for printing and plotting.
print("encoder states:", np.round(states_w, 6))
print("final summary:", round(float(states_w[-1]), 6))
assert round(float(states_w[0]), 6) == 0.664037
assert round(float(states_w[-1]), 6) == 0.921351
```
▶ What you'll see: three hidden states; the final summary is larger than the first because the last token is large.

```python
plt.figure(figsize=(4.4, 3))
plt.plot([1, 2, 3], states_w, marker="o", color="teal")
plt.xticks([1, 2, 3]); plt.xlabel("source position"); plt.ylabel("encoder h_t")
plt.title("1: encoder state accumulates source evidence")
plt.show()
```
▶ What you'll see: a short state trajectory, not a single lookup table; each token changes the memory.

*Why it's done this way: recurrence implements the compression \(h_t=f(h_{t-1},x_t)\). The coefficient on \(h_{t-1}\) preserves prior context, the coefficient on \(x_t\) admits new evidence, and tanh keeps the state bounded so repeated updates do not explode.*

### 2. The decoder unfolds an output distribution one step at a time

The decoder does not emit a whole sentence in one shot. It starts from the encoder summary and repeatedly produces a next-token distribution. That is the autoregressive factorization: each target probability is conditioned on the source summary and the previous target history.

```python
vocab_w = np.array(["<eos>", "A", "B", "C"])  # a tiny output vocabulary.
Wout_w = np.array([[0.2], [1.2], [-0.5], [0.7]])  # map one scalar decoder state to four logits.
bout_w = np.array([0.0, 0.1, 0.0, -0.1])  # output bias terms.
h_dec_w = float(states_w[-1])  # initialize the decoder from the final encoder state.
print("decoder starts from encoder summary:", round(h_dec_w, 6))
```
▶ What you'll see: the decoder receives the final encoder state, not the raw source list.

```python
def softmax_w(z_w):  # stable softmax for one vector of logits.
    z_w = z_w - np.max(z_w)
    exp_w = np.exp(z_w)
    return exp_w / exp_w.sum()

probs_w = []  # store next-token probabilities at each decoder step.
dec_states_w = []  # store decoder hidden states.
for t_w in range(4):  # unfold exactly four output decisions for the demo.
    h_dec_w = np.tanh(0.7 * h_dec_w)  # simple decoder recurrence.
    logits_w = (Wout_w[:, 0] * h_dec_w) + bout_w  # state -> vocabulary scores.
    probs_w.append(softmax_w(logits_w))  # normalize scores into probabilities.
    dec_states_w.append(h_dec_w)  # keep the state trajectory.
probs_w = np.array(probs_w)
print("decoder states:", np.round(dec_states_w, 6))
print("step-1 probabilities:", dict(zip(vocab_w, np.round(probs_w[0], 3))))
assert round(float(dec_states_w[0]), 6) == 0.568257
assert probs_w.shape == (4, 4)
```
▶ What you'll see: four decoder states and a full probability distribution for the first generated token.

```python
plt.figure(figsize=(5, 3))
plt.imshow(probs_w, cmap="viridis", aspect="auto")
plt.colorbar(label="next-token probability")
plt.xticks(range(len(vocab_w)), vocab_w)
plt.yticks(range(len(probs_w)), [f"step {i+1}" for i in range(len(probs_w))])
plt.xlabel("vocabulary token")
plt.ylabel("decoder step")
plt.title("2: decoder unfolds token distributions")
plt.show()
```
▶ What you'll see: every target step has its own probability row over the vocabulary.

*Why it's done this way: the model estimates \(P(y_t\mid y_{1:t-1},\operatorname{Enc}(x))\), so a vocabulary softmax is needed at every target position. Multiplying probabilities across steps gives the probability of one complete output sequence.*

### 3. Teacher forcing shifts the target by one position

During training, the decoder often receives the true previous target token. That is teacher forcing. The input side is `BOS, y1, y2, ...`; the label side is `y1, y2, ..., EOS`. Getting this shift right matters because every row of logits is supposed to predict the next token.

```python
target_w = np.array([3, 1, 2])  # desired target token ids.
decoder_inputs_w = np.r_[99, target_w[:-1]]  # BOS token id 99 then previous true tokens.
labels_w = target_w.copy()  # each position predicts the current true token.
print("decoder inputs:", decoder_inputs_w)
print("labels to predict:", labels_w)
assert decoder_inputs_w.tolist() == [99, 3, 1]
```
▶ What you'll see: the training input and training label are shifted by one position.

```python
preds_w = np.array([3, 2, 2])  # pretend model argmax predictions under teacher forcing.
correct_w = (preds_w == labels_w).astype(int)  # compare prediction at each target position.
print("correct vector:", correct_w, "sum:", int(correct_w.sum()))
assert correct_w.tolist() == [1, 0, 1]
assert int(correct_w.sum()) == 2
```
▶ What you'll see: two positions are correct and one is wrong; supervision happens at every token.

```python
shift_grid_w = np.vstack([decoder_inputs_w, labels_w])
plt.figure(figsize=(4.8, 2.4))
plt.imshow(shift_grid_w, cmap="Blues", aspect="auto")
for row_w in range(shift_grid_w.shape[0]):
    for col_w in range(shift_grid_w.shape[1]):
        plt.text(col_w, row_w, int(shift_grid_w[row_w, col_w]), ha="center", va="center")
plt.yticks([0, 1], ["decoder input", "label"])
plt.xticks(range(len(labels_w)), [f"t{t+1}" for t in range(len(labels_w))])
plt.title("3: teacher-forcing one-step shift")
plt.show()
```
▶ What you'll see: each label sits one position ahead of the previous-token decoder input.

*Why it's done this way: teacher forcing turns a long sequence target into many well-conditioned next-token classification problems. The shift is the mathematical bridge between the chain rule and a trainable table of per-position losses.*

### 4. Exposure bias compounds during free decoding

At serving time, the decoder cannot consume the true previous token; it consumes its own previous prediction. A small per-step error rate can therefore become a large sequence-level risk because one early mistake changes later decoder inputs.

```python
err_rate_w = 0.1  # per-step probability of making a wrong token.
steps_w = np.arange(1, 11)  # decode lengths from 1 to 10.
survival_w = (1 - err_rate_w) ** steps_w  # probability that no error has occurred yet.
print("survival after 1 step:", round(float(survival_w[0]), 3))
print("survival after 10 steps:", round(float(survival_w[-1]), 6))
assert round(float(survival_w[0]), 3) == 0.9
assert round(float(survival_w[-1]), 6) == 0.348678
```
▶ What you'll see: no-error probability falls from 0.9 to about 0.349 over ten steps.

```python
plt.figure(figsize=(4.6, 3))
plt.plot(steps_w, survival_w, marker="o", color="crimson")
plt.xlabel("decoded length"); plt.ylabel("P(no previous error)")
plt.title("4: exposure risk compounds")
plt.show()
```
▶ What you'll see: a downward curve; even modest token error becomes dangerous over long outputs.

*Why it's done this way: the product \((1-p)^t\) appears because the sequence is correct through step \(t\) only if all earlier next-token decisions were correct. Autoregression is powerful, but it ties later inputs to earlier model choices.*

### 5. Bahdanau attention replaces one summary with a soft lookup

A single final encoder state can bottleneck long sources. Bahdanau attention lets each decoder step score every encoder state, softmax those scores into alignment weights, and form a context vector as a weighted average of source states.

```python
enc_H_w = np.array([[0.2, 0.1], [0.6, 0.2], [0.1, 0.8], [0.7, 0.6]])  # four encoder states.
s_dec_w = np.array([0.5, 0.3])  # current decoder state.
Wa_w = np.array([[0.8, -0.2], [0.1, 0.7]])  # encoder projection.
Ua_w = np.array([[0.6, 0.1], [-0.3, 0.5]])  # decoder projection.
va_w = np.array([1.0, -0.5])  # attention scoring vector.
print("encoder state matrix shape:", enc_H_w.shape)
```
▶ What you'll see: four source positions, each represented by a 2-D state.

```python
scores_w = []  # additive attention energies e_{t,s}.
for h_src_w in enc_H_w:  # score each source position for this decoder state.
    hidden_w = np.tanh(Wa_w @ h_src_w + Ua_w @ s_dec_w)  # additive compatibility layer.
    scores_w.append(float(va_w @ hidden_w))  # scalar energy.
scores_w = np.array(scores_w)
alpha_w = softmax_w(scores_w)  # alignment weights across source positions.
context_w = alpha_w @ enc_H_w  # weighted average of encoder states.
print("attention scores:", np.round(scores_w, 3))
print("attention weights:", np.round(alpha_w, 3), "sum:", round(float(alpha_w.sum()), 3))
print("context vector:", np.round(context_w, 3))
assert round(float(alpha_w.sum()), 6) == 1.0
assert context_w.shape == (2,)
```
▶ What you'll see: weights sum to 1, so the context is a convex mixture of source states.

```python
plt.figure(figsize=(4.8, 2.6))
plt.imshow(alpha_w[None, :], cmap="magma", aspect="auto")
plt.colorbar(label="attention weight")
plt.yticks([0], ["decoder step"]); plt.xticks(range(4), ["x1", "x2", "x3", "x4"])
plt.title("5: Bahdanau attention heatmap")
plt.show()
```
▶ What you'll see: the brightest source column is the position this decoder step reads most strongly; the weights still spread across other useful positions.

*Why it's done this way: additive attention learns a compatibility function \(v^\top\tanh(W h_s+U s_t)\). The softmax makes alignments comparable and differentiable, and the weighted average gives the decoder direct access to source-specific evidence instead of only the final encoder state.*

### ✍️ Toy 1 · Encoder recurrence accumulates a source summary

An encoder hidden state is a running summary of the source prefix. Read two tiny tokens and watch the
same scalar state carry the prefix information forward.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)
t1_source = np.array([1.0, 3.0])                             # -> [1.0, 3.0]
t1_h0 = 0.0                                                  # -> 0.0
t1_pre1 = 0.5 * t1_h0 + 0.3 * t1_source[0]                  # -> 0.3
t1_h1 = np.tanh(t1_pre1)                                    # -> 0.2913
t1_pre2 = 0.5 * t1_h1 + 0.3 * t1_source[1]                  # -> 1.0457
t1_h2 = np.tanh(t1_pre2)                                    # -> 0.7801
t1_states = np.array([t1_h0, t1_h1, t1_h2])                 # -> [0.0, 0.2913, 0.7801]
print("source:", t1_source.tolist())                         # -> source: [1.0, 3.0]
print("step 1 pre:", round(float(t1_pre1), 4))               # -> step 1 pre: 0.3
print("step 1 state:", round(float(t1_h1), 4))               # -> step 1 state: 0.2913
print("step 2 pre:", round(float(t1_pre2), 4))               # -> step 2 pre: 1.0457
print("step 2 state:", round(float(t1_h2), 4))               # -> step 2 state: 0.7801
print("encoder states:", np.round(t1_states, 4).tolist())    # -> encoder states: [0.0, 0.2913, 0.7801]

plt.figure(figsize=(4.6, 2.8))
plt.plot([0, 1, 2], t1_states, marker="o", color="teal")
plt.xticks([0, 1, 2], ["start", "x1", "x2"])
plt.xlabel("source position")
plt.ylabel("encoder h")
plt.title("Toy 1 · source prefix summary")
plt.show()
assert np.allclose(np.round(t1_states, 4), [0.0, 0.2913, 0.7801])
```
▶ What you'll see: the final scalar is the compressed summary after reading both source tokens.

### ✍️ Toy 2 · Decoder softmax emits one next-token distribution per step

A decoder state becomes vocabulary logits, and softmax turns those logits into a next-token
distribution. Repeat it for two steps to see the autoregressive unfolding.

```python
import numpy as np

t2_rng = np.random.default_rng(0)
t2_h0 = 0.8                                                   # -> 0.8
t2_W = np.array([0.0, 1.0, -1.0])                             # -> [0.0, 1.0, -1.0]
t2_b = np.array([0.0, 0.1, 0.0])                              # -> [0.0, 0.1, 0.0]
t2_h1 = np.tanh(0.6 * t2_h0 + 0.2)                            # -> 0.5915
t2_logits1 = t2_W * t2_h1 + t2_b                              # -> [0.0, 0.6915, -0.5915]
t2_max1 = np.max(t2_logits1)                                  # -> 0.6915
t2_shift1 = t2_logits1 - t2_max1                              # -> [-0.6915, 0.0, -1.283]
t2_exp1 = np.exp(t2_shift1)                                   # -> [0.5008, 1.0, 0.2772]
t2_probs1 = t2_exp1 / t2_exp1.sum()                           # -> [0.2817, 0.5624, 0.1559]
t2_h2 = np.tanh(0.6 * t2_h1)                                  # -> 0.3407
t2_logits2 = t2_W * t2_h2 + t2_b                              # -> [0.0, 0.4407, -0.3407]
t2_max2 = np.max(t2_logits2)                                  # -> 0.4407
t2_shift2 = t2_logits2 - t2_max2                              # -> [-0.4407, 0.0, -0.7814]
t2_exp2 = np.exp(t2_shift2)                                   # -> [0.6436, 1.0, 0.4578]
t2_probs2 = t2_exp2 / t2_exp2.sum()                           # -> [0.3063, 0.4759, 0.2178]
t2_probs = np.vstack([t2_probs1, t2_probs2])                  # -> [[0.2817, 0.5624, 0.1559], [0.3063, 0.4759, 0.2178]]
print("decoder states:", [round(float(t2_h1), 4), round(float(t2_h2), 4)]) # -> decoder states: [0.5915, 0.3407]
print("step 1 logits:", np.round(t2_logits1, 4).tolist())     # -> step 1 logits: [0.0, 0.6915, -0.5915]
print("step 1 probabilities:", np.round(t2_probs1, 4).tolist()) # -> step 1 probabilities: [0.2817, 0.5624, 0.1559]
print("step 2 logits:", np.round(t2_logits2, 4).tolist())     # -> step 2 logits: [0.0, 0.4407, -0.3407]
print("step 2 probabilities:", np.round(t2_probs2, 4).tolist()) # -> step 2 probabilities: [0.3063, 0.4759, 0.2178]

plt.figure(figsize=(4.8, 2.8))
plt.imshow(t2_probs, cmap="viridis", aspect="auto", vmin=0, vmax=1)
plt.colorbar(label="probability")
plt.xticks([0, 1, 2], ["<eos>", "A", "B"])
plt.yticks([0, 1], ["step 1", "step 2"])
plt.title("Toy 2 · one softmax row per output step")
plt.show()
assert np.allclose(np.round(t2_probs, 4), [[0.2817, 0.5624, 0.1559], [0.3063, 0.4759, 0.2178]])
```
▶ What you'll see: each decoder step has its own probability row over the same tiny vocabulary.

### ✍️ Toy 4 · Exposure bias multiplies survival probabilities

If free decoding has a per-step error probability, the chance of staying error-free through `t` steps
is a product. Even a small error rate compounds quickly.

```python
import numpy as np

t4_rng = np.random.default_rng(0)
t4_err = 0.2                                                  # -> 0.2
t4_steps = np.arange(1, 5)                                    # -> [1, 2, 3, 4]
t4_keep = 1 - t4_err                                          # -> 0.8
t4_survival = t4_keep ** t4_steps                             # -> [0.8, 0.64, 0.512, 0.4096]
t4_failure = 1 - t4_survival                                  # -> [0.2, 0.36, 0.488, 0.5904]
print("per-step keep probability:", round(float(t4_keep), 4)) # -> per-step keep probability: 0.8
print("decode lengths:", t4_steps.tolist())                   # -> decode lengths: [1, 2, 3, 4]
print("no-error probabilities:", np.round(t4_survival, 4).tolist()) # -> no-error probabilities: [0.8, 0.64, 0.512, 0.4096]
print("at-least-one-error probabilities:", np.round(t4_failure, 4).tolist()) # -> at-least-one-error probabilities: [0.2, 0.36, 0.488, 0.5904]

plt.figure(figsize=(4.8, 2.8))
plt.plot(t4_steps, t4_survival, marker="o", color="crimson", label="no previous error")
plt.plot(t4_steps, t4_failure, marker="o", color="gray", label="some error")
plt.xlabel("decoded length")
plt.ylabel("probability")
plt.legend()
plt.title("Toy 4 · free-decoding risk compounds")
plt.show()
assert np.allclose(np.round(t4_survival, 4), [0.8, 0.64, 0.512, 0.4096])
```
▶ What you'll see: the no-error curve falls while the chance of at least one earlier mistake rises.

### ✍️ Toy 5 · Bahdanau attention softmaxes source scores into a context

Additive attention scores each source state against the decoder state, normalizes those scores, then
forms a weighted average of source states.

```python
import numpy as np

t5_rng = np.random.default_rng(0)
t5_enc = np.array([[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]])       # -> [[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]]
t5_dec = np.array([0.5, -0.5])                                # -> [0.5, -0.5]
t5_W = np.array([[0.4, 0.1], [-0.2, 0.3]])                    # -> [[0.4, 0.1], [-0.2, 0.3]]
t5_U = np.array([[0.2, -0.1], [0.1, 0.2]])                    # -> [[0.2, -0.1], [0.1, 0.2]]
t5_v = np.array([1.0, -0.5])                                  # -> [1.0, -0.5]
t5_enc_proj = t5_enc @ t5_W.T                                 # -> [[0.4, -0.2], [0.1, 0.3], [0.5, 0.1]]
t5_dec_proj = t5_dec @ t5_U.T                                 # -> [0.15, -0.05]
t5_combined = t5_enc_proj + t5_dec_proj                       # -> [[0.55, -0.25], [0.25, 0.25], [0.65, 0.05]]
t5_hidden = np.tanh(t5_combined)                              # -> [[0.5005, -0.2449], [0.2449, 0.2449], [0.5717, 0.05]]
t5_scores = t5_hidden @ t5_v                                  # -> [0.623, 0.1225, 0.5467]
t5_shift = t5_scores - np.max(t5_scores)                      # -> [0.0, -0.5005, -0.0763]
t5_exp = np.exp(t5_shift)                                     # -> [1.0, 0.6062, 0.9265]
t5_alpha = t5_exp / t5_exp.sum()                              # -> [0.3948, 0.2393, 0.3658]
t5_context = t5_alpha @ t5_enc                                # -> [0.7607, 0.6052]
print("encoder projection:", np.round(t5_enc_proj, 4).tolist()) # -> encoder projection: [[0.4, -0.2], [0.1, 0.3], [0.5, 0.1]]
print("decoder projection:", np.round(t5_dec_proj, 4).tolist()) # -> decoder projection: [0.15, -0.05]
print("attention scores:", np.round(t5_scores, 4).tolist())   # -> attention scores: [0.623, 0.1225, 0.5467]
print("attention weights:", np.round(t5_alpha, 4).tolist())   # -> attention weights: [0.3948, 0.2393, 0.3658]
print("context:", np.round(t5_context, 4).tolist())           # -> context: [0.7607, 0.6052]

plt.figure(figsize=(4.8, 2.4))
plt.imshow(t5_alpha[None, :], cmap="magma", aspect="auto", vmin=0, vmax=1)
plt.colorbar(label="attention weight")
plt.yticks([0], ["decoder"])
plt.xticks([0, 1, 2], ["src1", "src2", "src3"])
plt.title("Toy 5 · source alignment weights")
plt.show()
assert round(float(t5_alpha.sum()), 6) == 1.0 and np.allclose(np.round(t5_context, 4), [0.7607, 0.6052])
```
▶ What you'll see: attention weights sum to one, and the context is a weighted average of the three source rows.

## 🟢 Basics (warm-up)

### Basic 1 — Represent a source and target sequence

**Goal.** Store two variable-length sequences, because seq2seq maps one stream to another rather than one row to one label. We build it in 2 steps.


### Advanced 2 — Add an end-of-sequence stopping rule

**Goal.** Decode until EOS rather than a fixed length, because real outputs need a learned stopping decision. We build it in 4 steps.

```python
vocab_a2 = np.array(["<eos>", "A", "B"]) # define a vocabulary with EOS at id 0.
transition_a2 = np.array([[0.9, 0.05, 0.05], [0.1, 0.2, 0.7], [0.65, 0.25, 0.1]]) # next-token probabilities by previous token.
prev_a2 = 1 # pretend the decoder begins after token A.
max_len_a2 = 5 # set a safety cap.
print("vocab:", vocab_a2) # inspect token ids.
```
▶ What you'll see: token id 0 is the stopping token.

```python
generated_a2 = [] # store decoded token ids.
for step_a2 in range(max_len_a2): # decode with a maximum length guard.
    next_a2 = int(np.argmax(transition_a2[prev_a2])) # greedy next-token choice.
    generated_a2.append(next_a2) # save the chosen token.
    if next_a2 == 0: # stop once EOS is produced.
        break # terminate variable-length decoding.
    prev_a2 = next_a2 # otherwise feed the prediction back.
print("generated ids:", generated_a2) # inspect variable-length output.
assert generated_a2[-1] == 0 # verify EOS stopped the loop.
```

```python
generated_tokens_a2 = vocab_a2[generated_a2] # convert ids to readable tokens.

```


### Advanced 3 — Compare greedy decoding and beam search

**Goal.** Keep multiple partial hypotheses, because the best first token is not always on the best complete sequence. We build it in 5 steps.

```python
logp_a3 = np.log(np.array([[0.55, 0.45, 0.00], [0.05, 0.20, 0.75], [0.70, 0.20, 0.10]] ) + 1e-12) # transition log-probs by previous token.
start_a3 = 0 # start token id.
beam_width_a3 = 2 # keep two hypotheses.
print("beam width:", beam_width_a3) # inspect search setting.
```
▶ What you'll see: the search will compare two partial sequences at each step.

```python
greedy_a3 = [] # store greedy token ids.
prev_a3 = start_a3 # initialize previous token.
greedy_score_a3 = 0.0 # accumulate log probability.
for t_a3 in range(2): # decode two tokens.
    nxt_a3 = int(np.argmax(logp_a3[prev_a3])) # choose locally best token.
    greedy_score_a3 += float(logp_a3[prev_a3, nxt_a3]) # add its log probability.
    greedy_a3.append(nxt_a3) # save token.
    prev_a3 = nxt_a3 # feed back token.
print("greedy:", greedy_a3, "score:", round(greedy_score_a3, 3)) # inspect greedy path.
```

```python
beams_a3 = [([], start_a3, 0.0)] # each beam is sequence, previous token, log score.
for t_beam_a3 in range(2): # expand for two steps.
    candidates_a3 = [] # store all expanded beams.
    for seq_a3, prev_beam_a3, score_beam_a3 in beams_a3: # expand each current beam.
        for tok_a3 in [0, 1, 2]: # try every next token.
            candidates_a3.append((seq_a3 + [tok_a3], tok_a3, score_beam_a3 + float(logp_a3[prev_beam_a3, tok_a3]))) # append expanded sequence.
    candidates_a3 = sorted(candidates_a3, key=lambda x: x[2], reverse=True) # sort by log score.
    beams_a3 = candidates_a3[:beam_width_a3] # keep top beams.
print("beams:", [(b[0], round(b[2], 3)) for b in beams_a3]) # inspect final beam set.
```

```python
best_beam_a3 = beams_a3[0][0] # read best beam sequence.
best_score_a3 = beams_a3[0][2] # read best beam log score.
print("best beam:", best_beam_a3, "score:", round(best_score_a3, 3)) # compare with greedy.
assert best_score_a3 >= greedy_score_a3 # verify beam is at least as good as greedy here.
```

```python
plt.figure(figsize=(4, 3)) # create a score comparison chart.
plt.bar(["greedy", "beam"], [greedy_score_a3, best_score_a3], color=["gray", "teal"]) # compare log probabilities.
plt.title("Advanced 3: beam keeps alternatives") # title the plot.
plt.ylabel("log probability") # label log-score axis.
plt.show() # display the bars.
```
▶ What you'll see: beam search can retain a lower-first-step option if it leads to a stronger complete sequence.

👀 Takeaway: decoding strategy is part of seq2seq inference, not just a display choice.
