# 5.4 — Markov Random Fields

Markov Random Fields (MRFs) model variables that influence each other symmetrically: neighboring labels, adjacent pixels, or linked states that do not have a natural parent-child order. In this lesson, we build the whole idea from scratch: local compatibility scores called potentials, one global partition function that turns those scores into probabilities, and the exact-inference cost that motivates later factor graphs and belief propagation.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build Markov Random Fields one idea at a time. Run each cell in order and read the printed intermediate values — every score, normalization constant, marginal, and MAP choice is shown directly. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, enumeration, exponentials, and exact sums for tiny MRFs.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for any random draws.
```

### 1. Why undirected edges: symmetric compatibility, not a parent order

Suppose two neighboring labels can each be `-1` or `+1`. If they agree, the configuration should be more compatible; if they disagree, it should be less compatible. A directed model would force one label to be the parent and the other to be the child, but the relationship is symmetric: each neighbor encourages the other. An MRF writes this as an undirected edge potential.

```python
states_w = np.array([-1, 1])  # binary labels written as signs so agreement is x1*x2 = +1.
beta_w = 0.8  # coupling strength: positive beta rewards aligned neighbors.
assignments_w = np.array([[x1, x2] for x1 in states_w for x2 in states_w])  # enumerate all 4 joint states.
print("assignments [x1, x2]:\n", assignments_w)
```
▶ What you'll see: the four possible joint assignments for two binary variables.

```python
same_w = assignments_w[:, 0] == assignments_w[:, 1]  # True for aligned states.
raw_energy_w = beta_w * assignments_w[:, 0] * assignments_w[:, 1]  # +0.8 if aligned, -0.8 if opposed.
print("aligned flags:", same_w.astype(int))
print("compatibility log-scores:", raw_energy_w)
```
▶ What you'll see: two states receive log-score +0.8 and two receive log-score -0.8.

```python
plt.figure(figsize=(4.6, 3))
plt.bar([str(tuple(a)) for a in assignments_w], raw_energy_w, color=np.where(same_w, "seagreen", "indianred"))
plt.axhline(0, color="black", linewidth=0.8)
plt.title("1: undirected agreement log-score")
plt.ylabel(r"$\beta x_1 x_2$")
plt.show()
```
▶ What you'll see: aligned assignments have positive bars and opposed assignments have negative bars.

*Why it's done this way:* using the product $x_1x_2$ makes symmetry automatic. Swapping the two variables leaves the score unchanged, which matches the modeling idea: neither node causes the other; the pair has a mutual compatibility.

### 2. Potentials are nonnegative scores, not probabilities yet

The MRF potential turns a log-score into a nonnegative score: $\psi(x_1,x_2)=\exp(\beta x_1x_2)$. Exponentials are useful because they keep scores positive and turn additive log-compatibilities into multiplicative factors. But these numbers still do **not** sum to 1, so they are not probabilities yet.

```python
psi_pair_w = np.exp(raw_energy_w)  # convert log-scores to positive potentials.
print("pair potentials:", np.round(psi_pair_w, 6))
print("aligned score:", round(float(np.exp(0.8)), 6), "opposed score:", round(float(np.exp(-0.8)), 6))
assert round(float(np.exp(0.8)), 6) == 2.225541
assert round(float(np.exp(-0.8)), 6) == 0.449329
```
▶ What you'll see: aligned states score 2.225541; opposed states score 0.449329.

```python
print("sum of raw potentials:", round(float(psi_pair_w.sum()), 6))
print("is this already a probability distribution?", np.isclose(psi_pair_w.sum(), 1.0))
```
▶ What you'll see: the scores sum to 5.349740, not 1.

```python
plt.figure(figsize=(4.6, 3))
plt.bar([str(tuple(a)) for a in assignments_w], psi_pair_w, color=np.where(same_w, "seagreen", "indianred"))
plt.title("2: potentials are positive scores")
plt.ylabel(r"$\psi(x_1,x_2)$")
plt.show()
```
▶ What you'll see: aligned states are taller, but the bars are still unnormalized scores.

*Why it's done this way:* an MRF separates **modeling** from **normalization**. Local potentials can be any nonnegative compatibility scores; one global normalizer later makes the whole joint distribution valid.

### 3. The partition function turns scores into probabilities

The partition function $Z$ is the sum of the unnormalized score over every joint assignment. For the two-node MRF, $Z=2e^{0.8}+2e^{-0.8}$. Dividing each potential by $Z$ creates a valid joint probability distribution.

```python
Z_w = float(psi_pair_w.sum())  # exact partition function for the tiny two-node state space.
prob_w = psi_pair_w / Z_w  # normalized joint probabilities.
print("Z:", round(Z_w, 6))
print("probabilities:", np.round(prob_w, 6))
assert round(Z_w, 6) == 5.349740
assert round(float(prob_w[0]), 6) == 0.416009
```
▶ What you'll see: each aligned state has probability 0.416009 and each opposed state has probability 0.083991.

```python
print("probability sum:", round(float(prob_w.sum()), 6))
print("P(one aligned state):", round(float(prob_w[0]), 6))
print("P(one opposed state):", round(float(prob_w[1]), 6))
assert round(float(prob_w[1]), 6) == 0.083991
```
▶ What you'll see: probabilities sum to exactly 1 after normalization.

```python
plt.figure(figsize=(4.6, 3))
plt.bar([str(tuple(a)) for a in assignments_w], prob_w, color=np.where(same_w, "seagreen", "indianred"))
plt.title("3: normalized joint probabilities")
plt.ylabel("probability")
plt.ylim(0, 0.5)
plt.show()
```
▶ What you'll see: the same preference pattern as the potentials, now on the probability scale.

*Why it's done this way:* $Z$ is the price of using flexible unnormalized scores. It couples all assignments together: changing one potential changes the denominator and therefore changes every probability.

### 4. Symmetric couplings can create dependence without marginal bias

A common mistake is to think a positive edge potential makes each node more likely to be `+1`. It does not. With only a symmetric pairwise agreement term, the model prefers **same signs**, but it is equally happy with `(-1,-1)` and `(1,1)`. Dependence appears in the joint distribution even though each single-node marginal stays balanced.

```python
p_x1_pos_w = float(prob_w[assignments_w[:, 0] == 1].sum())  # marginalize x2 away.
p_x2_pos_w = float(prob_w[assignments_w[:, 1] == 1].sum())  # marginalize x1 away.
p_same_w = float(prob_w[same_w].sum())  # probability that neighbors agree.
print("P(X1=1):", round(p_x1_pos_w, 3))
print("P(X2=1):", round(p_x2_pos_w, 3))
print("P(X1=X2):", round(p_same_w, 3))
assert round(p_x1_pos_w, 3) == 0.500
assert round(p_same_w, 3) == 0.832
```
▶ What you'll see: each node is balanced at 0.5, but the pair agrees with probability 0.832.

```python
corr_w = float(np.sum(prob_w * assignments_w[:, 0] * assignments_w[:, 1]))  # E[X1 X2] because means are zero.
print("E[X1 X2] dependence:", round(corr_w, 3))
assert round(corr_w, 3) == 0.664
```
▶ What you'll see: the positive expected product shows dependence even with unbiased marginals.

```python
plt.figure(figsize=(4.2, 3))
plt.bar(["P(X1=1)", "P(same)", "E[X1X2]"], [p_x1_pos_w, p_same_w, corr_w], color=["gray", "seagreen", "purple"])
plt.title("4: dependence is not marginal bias")
plt.ylim(0, 1)
plt.show()
```
▶ What you'll see: the marginal bar is 0.5 while agreement and correlation are high.

*Why it's done this way:* pairwise potentials control relationships between variables. A unary potential is needed to prefer one value of a node; a symmetric edge alone only says neighboring values should match.

### 5. Unary evidence: local belief multiplied by pairwise compatibility

MRFs can combine evidence about individual nodes with compatibility between nodes. A unary potential $\phi_1(x_1)=\exp(hx_1)$ favors $x_1=1$ when $h>0$, while the pairwise potential still rewards agreement. The joint score is the product $\phi_1(x_1)\psi_{12}(x_1,x_2)$.

```python
h_w = 0.7  # local evidence favoring X1=+1.
unary1_w = np.exp(h_w * assignments_w[:, 0])  # larger when x1=+1.
score_with_evidence_w = unary1_w * psi_pair_w  # product of unary evidence and pairwise compatibility.
print("unary potential for X1:", np.round(unary1_w, 3))
print("combined scores:", np.round(score_with_evidence_w, 3))
```
▶ What you'll see: states with `X1=1` receive an evidence boost, especially when they also align with `X2`.

```python
Z_evidence_w = float(score_with_evidence_w.sum())
prob_evidence_w = score_with_evidence_w / Z_evidence_w
p1_evidence_w = float(prob_evidence_w[assignments_w[:, 0] == 1].sum())
p2_evidence_w = float(prob_evidence_w[assignments_w[:, 1] == 1].sum())
print("P(X1=1) with evidence:", round(p1_evidence_w, 3))
print("P(X2=1) pulled by neighbor:", round(p2_evidence_w, 3))
assert round(p1_evidence_w, 3) == 0.802
assert round(p2_evidence_w, 3) == 0.701
```
▶ What you'll see: evidence directly biases X1 and indirectly pulls X2 through the edge.

```python
plt.figure(figsize=(4.6, 3))
plt.bar([str(tuple(a)) for a in assignments_w], prob_evidence_w, color=np.where(assignments_w[:, 0] == 1, "teal", "orange"))
plt.title("5: unary evidence plus pairwise agreement")
plt.ylabel("probability")
plt.show()
```
▶ What you'll see: `(1,1)` becomes the most probable state because it satisfies both evidence and agreement.

*Why it's done this way:* multiplying potentials lets different modeling ingredients vote together. Unary evidence says what one node locally prefers; pairwise compatibility spreads that preference to neighbors when agreement is rewarded.

### 6. Exact inference by enumeration: useful, but exponentially expensive

For tiny MRFs, exact inference is just enumerate all assignments, score each one, sum to get $Z$, and sum selected probabilities to get marginals. The catch is the number of assignments: with binary variables it is $2^n$. That exponential state space is why exact inference quickly becomes expensive.

```python
def chain_scores_w(n_w, beta_w, field_w):  # score all assignments for a binary chain of length n.
    configs_w = np.array(np.meshgrid(*([states_w] * n_w))).T.reshape(-1, n_w)  # all 2^n states.
    edge_log_w = beta_w * np.sum(configs_w[:, :-1] * configs_w[:, 1:], axis=1)  # adjacent agreement terms.
    unary_log_w = field_w * np.sum(configs_w, axis=1)  # small field applied to every node.
    return configs_w, np.exp(edge_log_w + unary_log_w)  # return assignments and unnormalized scores.

configs4_w, scores4_w = chain_scores_w(4, beta_w=0.6, field_w=0.1)
print("number of assignments for n=4:", len(configs4_w))
print("first three assignments:\n", configs4_w[:3])
```
▶ What you'll see: even four binary nodes already require 16 joint assignments.

```python
Z4_w = float(scores4_w.sum())
probs4_w = scores4_w / Z4_w
marg_last_pos_w = float(probs4_w[configs4_w[:, -1] == 1].sum())
map_idx_w = int(np.argmax(probs4_w))
print("Z for 4-node chain:", round(Z4_w, 3))
print("P(last node=1):", round(marg_last_pos_w, 3))
print("MAP assignment:", configs4_w[map_idx_w])
assert len(configs4_w) == 16
```
▶ What you'll see: exact normalization gives both a marginal and the most probable full assignment.

```python
ns_w = np.arange(1, 13)
counts_w = 2 ** ns_w
plt.figure(figsize=(4.6, 3))
plt.plot(ns_w, counts_w, marker="o", color="crimson")
plt.yscale("log")
plt.title("6: exact enumeration grows as 2^n")
plt.xlabel("binary variables n")
plt.ylabel("assignments, log scale")
plt.show()
```
▶ What you'll see: the state count doubles with every added variable.

*Why it's done this way:* enumeration is the cleanest way to understand $Z$ and marginals because it literally implements the definitions. It is not the scalable solution; it is the reference calculation that later algorithms approximate or exploit structure to avoid.

### 7. Grid MRF intuition: smooth images from local compatibility

A classic MRF application is image denoising. Each pixel label should agree with its observed noisy pixel (unary evidence), but neighboring pixels should also prefer the same label (pairwise smoothness). MAP inference chooses the single assignment with the largest product of potentials.

```python
observed_grid_w = np.array([[1, 1, -1], [1, -1, -1], [1, 1, -1]])  # noisy binary image labels.
print("observed noisy grid:\n", observed_grid_w)
plt.figure(figsize=(3, 3))
plt.imshow(observed_grid_w, cmap="coolwarm", vmin=-1, vmax=1)
plt.title("7: observed noisy grid")
plt.xticks([]); plt.yticks([])
plt.show()
```
▶ What you'll see: a 3×3 image with a few boundary-disrupting labels.

```python
configs_grid_w = np.array(np.meshgrid(*([states_w] * 9))).T.reshape(-1, 9)  # all 2^9 grids.
edges_w = [(0,1),(1,2),(3,4),(4,5),(6,7),(7,8),(0,3),(3,6),(1,4),(4,7),(2,5),(5,8)]  # 4-neighbor grid edges.
obs_flat_w = observed_grid_w.ravel()
beta_grid_w, data_w = 0.5, 0.9  # smoothness strength and observed-pixel evidence strength.
edge_log_grid_w = beta_grid_w * sum(configs_grid_w[:, i] * configs_grid_w[:, j] for i, j in edges_w)
data_log_grid_w = data_w * (configs_grid_w @ obs_flat_w)
log_score_grid_w = edge_log_grid_w + data_log_grid_w
map_grid_w = configs_grid_w[int(np.argmax(log_score_grid_w))].reshape(3, 3)
print("MAP denoised grid:\n", map_grid_w)
```
▶ What you'll see: the MAP grid balances matching observations with becoming spatially smoother.

```python
plt.figure(figsize=(6, 3))
plt.subplot(1, 2, 1); plt.imshow(observed_grid_w, cmap="coolwarm", vmin=-1, vmax=1); plt.title("observed"); plt.xticks([]); plt.yticks([])
plt.subplot(1, 2, 2); plt.imshow(map_grid_w, cmap="coolwarm", vmin=-1, vmax=1); plt.title("MRF MAP"); plt.xticks([]); plt.yticks([])
plt.show()
```
▶ What you'll see: the MRF output favors coherent regions rather than independently trusting every noisy pixel.

*Why it's done this way:* local smoothness potentials encode the belief that neighboring pixels often share labels, while unary evidence prevents the model from smoothing everything blindly. MAP chooses the assignment with the best total compromise.

### Basic 2 — Score agreement with a pair potential

**Goal.** Compute $\psi(x_1,x_2)=\exp(\beta x_1x_2)$, because positive coupling rewards neighboring variables that agree. We build it in 2 steps.

```python
states_b2 = np.array([-1, 1])
assignments_b2 = np.array([[x1, x2] for x1 in states_b2 for x2 in states_b2])
beta_b2 = 0.8  # Coupling strength for the agreement potential.
log_score_b2 = beta_b2 * assignments_b2[:, 0] * assignments_b2[:, 1]  # +beta when equal, -beta when different.
print("log scores:", log_score_b2)  # Inspect before exponentiating.
```
▶ What you'll see: aligned states get +0.8 and opposed states get -0.8.

```python
psi_b2 = np.exp(log_score_b2)  # Convert log compatibility into nonnegative potential values.
print("potentials:", np.round(psi_b2, 6))  # Inspect the two unique score levels.
assert round(float(psi_b2[0]), 6) == 2.225541  # Aligned score e^0.8.
assert round(float(psi_b2[1]), 6) == 0.449329  # Opposed score e^-0.8.
plt.figure(figsize=(4, 3))
plt.bar([str(tuple(a)) for a in assignments_b2], psi_b2, color=np.where(assignments_b2[:,0] == assignments_b2[:,1], "seagreen", "crimson"))
plt.title("Basic 2: pair potential")
plt.ylabel("score")
plt.show()
```
▶ What you'll see: agreement bars are much taller than disagreement bars.

👀 Takeaway: potentials are local compatibility scores; larger means more compatible before normalization.

### Basic 3 — Normalize with the partition function

**Goal.** Divide unnormalized scores by $Z$, because potentials become probabilities only after global normalization. We build it in 3 steps.

```python
beta_b3 = 0.8
assignments_b3 = np.array([[x1, x2] for x1 in [-1, 1] for x2 in [-1, 1]])
scores_b3 = np.exp(beta_b3 * assignments_b3[:, 0] * assignments_b3[:, 1])  # Unnormalized MRF scores.
print("scores:", np.round(scores_b3, 6))
```
▶ What you'll see: the same two aligned and two opposed scores.

```python
Z_b3 = float(np.sum(scores_b3))  # Sum over every joint assignment.
prob_b3 = scores_b3 / Z_b3  # Normalize the scores into probabilities.
print("Z:", round(Z_b3, 6))
print("probabilities:", np.round(prob_b3, 6))
assert round(Z_b3, 6) == 5.349740
```

```python
print("probability sum:", round(float(prob_b3.sum()), 6))
assert np.isclose(prob_b3.sum(), 1.0)
plt.figure(figsize=(4, 3))
plt.bar([str(tuple(a)) for a in assignments_b3], prob_b3, color="purple")
plt.title("Basic 3: normalized probabilities")
plt.ylabel("probability")
plt.show()
```
▶ What you'll see: all bars sum to 1, with aligned states each at about 0.416.

👀 Takeaway: $Z$ is the global sum that turns local MRF scores into a valid distribution.

### Basic 4 — Compute one marginal probability

**Goal.** Sum joint probabilities over unwanted variables, because MRF queries often ask about one node rather than the full assignment. We build it in 2 steps.

```python
assignments_b4 = np.array([[x1, x2] for x1 in [-1, 1] for x2 in [-1, 1]])
prob_b4 = np.exp(0.8 * assignments_b4[:, 0] * assignments_b4[:, 1])
prob_b4 = prob_b4 / prob_b4.sum()  # Create the normalized two-node MRF distribution.
print("joint probabilities:", np.round(prob_b4, 6))
```
▶ What you'll see: probabilities for all complete states.

```python
p_x1_pos_b4 = float(prob_b4[assignments_b4[:, 0] == 1].sum())  # Sum over both values of X2.
```

▶ What you'll see: the marginal is balanced even though the edge encourages agreement.

👀 Takeaway: marginalization means summing probabilities of all full assignments consistent with the query.

### Basic 7 — Find the MAP assignment

**Goal.** Select the highest-scoring configuration, because MAP inference asks for the single most compatible joint assignment. We build it in 2 steps.

```python
assignments_b7 = np.array([[x1, x2] for x1 in [-1, 1] for x2 in [-1, 1]])

```

```python
map_idx_b7 = int(np.argmax(score_b7))

plt.figure(figsize=(4, 3))

plt.show()
```
▶ What you'll see: the MAP bar is the tallest score, not necessarily a marginal probability winner for each node separately.

👀 Takeaway: MAP uses argmax over joint scores, so $Z$ is unnecessary for the argmax itself.

### Basic 8 — Compare positive and negative coupling

**Goal.** Flip the sign of $\beta$, because positive coupling rewards agreement while negative coupling rewards opposition. We build it in 2 steps.

```python
assignments_b8 = np.array([[x1, x2] for x1 in [-1, 1] for x2 in [-1, 1]])
betas_b8 = np.array([0.8, -0.8])  # Ferromagnetic agreement versus anti-agreement.
print("beta values:", betas_b8)
```
▶ What you'll see: one positive and one negative coupling strength.

```python
p_same_b8 = []
for beta_b8 in betas_b8:
```
