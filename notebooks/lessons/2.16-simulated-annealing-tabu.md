# 2.16 — Simulated Annealing & Tabu Search

Simulated annealing and tabu search are metaheuristics for difficult optimization problems where greedy local search gets trapped. In this lesson, you will build both methods from first principles in NumPy, inspect every acceptance probability and memory decision, and see how controlled imperfection helps a search escape rugged landscapes.

## 📖 Concept walkthrough — build each idea from scratch

Before the worked examples, we build the ideas one at a time. Run each cell in order and read the printed intermediate values — the goal is to make every move, probability, and tabu decision inspectable instead of magical. This walkthrough is self-contained and uses a `_w` suffix so it never clashes with the examples below.

```python
import numpy as np  # arrays, random choices, and objective calculations.
import matplotlib.pyplot as plt  # plots for landscapes, paths, and diagnostics.
np.random.seed(0)  # reproducibility for the walkthrough.
```

### 1. Rugged landscapes and local neighborhoods

A local-search method needs three ingredients: a **state**, an **objective value**, and a **neighborhood** of small moves. To make the mechanics visible, we use integer states from 0 to 10 and minimize a hand-built rugged objective. The numbers are not random: they deliberately contain a tempting local minimum at state 2 and a better global minimum at state 7.

```python
states_w = np.arange(11)  # discrete states 0, 1, ..., 10.
energy_w = np.array([9.0, 6.0, 4.0, 5.0, 7.0, 6.0, 3.0, 1.0, 2.0, 4.0, 5.0])  # lower is better.
print("states:", states_w)
print("energy:", energy_w)
print("global best state:", int(states_w[np.argmin(energy_w)]), "energy:", float(np.min(energy_w)))
assert int(states_w[np.argmin(energy_w)]) == 7 and float(np.min(energy_w)) == 1.0
```
▶ What you'll see: state 7 is the true best state, but state 2 also looks good compared with its immediate neighbors.

```python
plt.figure(figsize=(6, 3))
plt.plot(states_w, energy_w, marker="o", color="purple")
plt.scatter([2, 7], energy_w[[2, 7]], color=["orange", "green"], s=90, zorder=3)
plt.text(2, energy_w[2] + 0.35, "local min")
plt.text(7, energy_w[7] + 0.35, "global min")
plt.title("1: rugged objective landscape")
plt.xlabel("state")
plt.ylabel("energy to minimize")
plt.show()
```
▶ What you'll see: the curve dips at state 2, rises, then dips lower at state 7.

```python
def neighbors_w(x_w):  # one-step left/right neighborhood on a bounded line.
    candidates_w = []
    if x_w > 0:
        candidates_w.append(x_w - 1)
    if x_w < len(energy_w) - 1:
        candidates_w.append(x_w + 1)
    return np.array(candidates_w, dtype=int)

x_w = 2
print("state:", x_w, "energy:", energy_w[x_w])
print("neighbors:", neighbors_w(x_w), "neighbor energies:", energy_w[neighbors_w(x_w)])
```
▶ What you'll see: from state 2, both one-step neighbors are worse, so a purely greedy method has no improving move.

*Why it's done this way:* Discrete neighborhoods model routing swaps, schedule edits, or feature-subset flips. The objective can be evaluated, but not differentiated. A local minimum is exactly a state whose neighbors all have higher energy, even though some distant state is better.

### 2. Greedy local search and the trap

Greedy local search always takes the best improving neighbor and stops when no neighbor improves the current state. That rule is fast and sensible on smooth landscapes, but on rugged landscapes it confuses “no better neighbor” with “best overall.” Starting at state 0, it walks downhill until it reaches the trap at state 2.

```python
path_greedy_w = [0]
while True:
    current_w = path_greedy_w[-1]
    nbrs_w = neighbors_w(current_w)
    best_nbr_w = int(nbrs_w[np.argmin(energy_w[nbrs_w])])
    print("current", current_w, "E", energy_w[current_w], "best neighbor", best_nbr_w, "E", energy_w[best_nbr_w])
    if energy_w[best_nbr_w] >= energy_w[current_w]:
        break
    path_greedy_w.append(best_nbr_w)
print("greedy path:", path_greedy_w)
assert path_greedy_w == [0, 1, 2]
```
▶ What you'll see: greedy moves 0 → 1 → 2, then stops because both neighbors of 2 are worse.

```python
plt.figure(figsize=(6, 3))
plt.plot(states_w, energy_w, marker="o", color="lightgray")
plt.plot(path_greedy_w, energy_w[path_greedy_w], marker="o", color="crimson", linewidth=3)
plt.title("2: greedy search stops at a local trap")
plt.xlabel("state")
plt.ylabel("energy")
plt.show()
```
▶ What you'll see: the red path stops at the orange local minimum and never reaches the green global minimum.

*Why it's done this way:* Greedy descent uses only the sign of each local energy difference. If every neighbor has Δ = E(neighbor) − E(current) > 0, the algorithm halts. Metaheuristics deliberately relax this rule so “temporarily worse” can be mathematically useful.

### 3. Simulated annealing: accepting uphill moves with temperature

Simulated annealing changes the greedy rule by sometimes accepting a worse move. If the proposed move raises energy by \(\Delta>0\), it is accepted with probability \(\exp(-\Delta/T)\). High temperature \(T\) makes uphill moves plausible; low temperature makes them rare. Downhill moves are still accepted automatically.

```python
deltas_w = np.array([0.5, 2.0, 5.0])  # candidate uphill costs.
temps_w = np.array([5.0, 1.0, 0.1])  # hot, moderate, cold.
for T_w in temps_w:
    probs_w = np.exp(-deltas_w / T_w)
    print("T =", T_w, "accept probs:", np.round(probs_w, 6))
print("Delta=2 at T=1:", round(float(np.exp(-2 / 1)), 6))
assert round(float(np.exp(-2 / 1)), 6) == 0.135335
assert round(float(np.exp(-2 / 5)), 6) == 0.670320
```
▶ What you'll see: the same uphill cost is often accepted when hot and almost never accepted when cold.

```python
T_curve_w = np.linspace(0.2, 8.0, 120)
prob_curve_w = np.exp(-2.0 / T_curve_w)
plt.figure(figsize=(5, 3))
plt.plot(T_curve_w, prob_curve_w, color="teal")
plt.title("3: P(accept uphill Δ=2) = exp(-Δ/T)")
plt.xlabel("temperature T")
plt.ylabel("acceptance probability")
plt.ylim(0, 1)
plt.show()
```
▶ What you'll see: acceptance rises smoothly with temperature, so temperature is an exploration dial.

```python
rng_sa_w = np.random.default_rng(0)
path_sa_w = [0]
T0_w = 5.0
cool_w = 0.92
accepted_uphill_w = 0
for step_w in range(80):
    current_w = path_sa_w[-1]
    T_w = T0_w * (cool_w ** step_w)
    nbrs_w = neighbors_w(current_w)
    proposal_w = int(rng_sa_w.choice(nbrs_w))
    delta_w = energy_w[proposal_w] - energy_w[current_w]
    accept_w = delta_w <= 0 or rng_sa_w.random() < np.exp(-delta_w / T_w)
    if accept_w:
        path_sa_w.append(proposal_w)
        accepted_uphill_w += int(delta_w > 0)
    else:
        path_sa_w.append(current_w)
print("final state:", path_sa_w[-1], "best visited:", int(path_sa_w[np.argmin(energy_w[path_sa_w])]))
print("accepted uphill moves:", accepted_uphill_w)
assert min(energy_w[path_sa_w]) == 1.0
```
▶ What you'll see: annealing accepts some uphill moves and visits the global minimum at state 7.

```python
plt.figure(figsize=(6, 3))
plt.plot(states_w, energy_w, marker="o", color="lightgray")
plt.plot(path_sa_w, energy_w[path_sa_w], color="teal", alpha=0.8)
plt.scatter(path_sa_w, energy_w[path_sa_w], s=18, color="teal")
plt.title("3: simulated annealing can cross the barrier")
plt.xlabel("state")
plt.ylabel("energy")
plt.show()
```
▶ What you'll see: the path sometimes moves uphill, which lets it cross from the local basin near 2 toward the better basin near 7.

*Why it's done this way:* The exponential form makes acceptance decrease with both larger uphill cost and lower temperature. Cooling turns the algorithm from broad exploration into near-greedy refinement, matching the intuition of hot metal settling as it cools.

### 4. Tabu search: memory prevents immediate cycling

Tabu search is deterministic in a different way: it keeps memory. After taking a move, the immediate reversal is temporarily forbidden, so the search cannot bounce between two states just because one of them is locally attractive. On our line, a move is `+1` or `-1`, and the tabu list stores forbidden reversals.

```python
moves_w = np.array([-1, 1])
start_w = 0
first_move_w = 1
forbidden_after_first_w = -first_move_w
print("move from 0 to 1:", first_move_w)
print("immediate reversal now tabu:", forbidden_after_first_w)
assert forbidden_after_first_w == -1
```
▶ What you'll see: after moving right by +1, moving left by −1 is the forbidden reversal.

```python
path_tabu_w = [0]
tabu_w = []
tenure_w = 2
for step_w in range(8):
    current_w = path_tabu_w[-1]
    candidates_w = []
    for move_w in moves_w:
        nxt_w = current_w + move_w
        if 0 <= nxt_w < len(energy_w) and move_w not in tabu_w:
            candidates_w.append((energy_w[nxt_w], nxt_w, move_w))
    best_energy_w, best_state_w, best_move_w = min(candidates_w)
    path_tabu_w.append(best_state_w)
    tabu_w.append(-best_move_w)
    tabu_w = tabu_w[-tenure_w:]
    print("step", step_w, "state", best_state_w, "move", best_move_w, "tabu", tabu_w)
print("tabu path:", path_tabu_w)
assert path_tabu_w[:5] == [0, 1, 2, 3, 4]
```
▶ What you'll see: tabu search moves through the local trap instead of immediately reversing from state 2 back to state 1.

```python
plt.figure(figsize=(6, 3))
plt.plot(states_w, energy_w, marker="o", color="lightgray")
plt.plot(path_tabu_w, energy_w[path_tabu_w], marker="o", color="darkorange", linewidth=3)
plt.title("4: tabu memory forces exploration past the trap")
plt.xlabel("state")
plt.ylabel("energy")
plt.show()
```
▶ What you'll see: the orange path is pushed across the uphill barrier because recent reversals are temporarily blocked.

*Why it's done this way:* Memory changes the feasible neighborhood, not the objective. A move can be objectively tempting but inadmissible because it undoes recent progress. Tenure controls how long that restriction lasts, trading cycling prevention against over-restricting useful moves.

### 5. Tuning escape: cooling rate versus tabu tenure

Both methods regulate escape, but with different knobs. Simulated annealing uses a cooling schedule: too fast becomes greedy, too slow wanders. Tabu search uses tenure: too short may cycle, too long may forbid useful repairs. The right knob value depends on the search budget and landscape.

```python
coolings_w = np.array([0.55, 0.85, 0.97])
sa_best_w = []
for cool_rate_w in coolings_w:
    rng_w = np.random.default_rng(3)
    path_w = [0]
    for step_w in range(35):
        current_w = path_w[-1]
        T_w = 5.0 * (cool_rate_w ** step_w)
        proposal_w = int(rng_w.choice(neighbors_w(current_w)))
        delta_w = energy_w[proposal_w] - energy_w[current_w]
        if delta_w <= 0 or rng_w.random() < np.exp(-delta_w / max(T_w, 1e-12)):
            path_w.append(proposal_w)
        else:
            path_w.append(current_w)
    sa_best_w.append(float(np.min(energy_w[path_w])))
print("cooling rates:", coolings_w)
print("best energies:", sa_best_w)
```
▶ What you'll see: different cooling rates produce different best energies even with the same starting point and budget.

```python
tenures_w = np.array([1, 2, 4])
end_states_w = []
for tenure_try_w in tenures_w:
    path_try_w = [0]
    tabu_try_w = []
    for step_w in range(8):
        current_w = path_try_w[-1]
        options_w = []
        for move_w in moves_w:
            nxt_w = current_w + move_w
            if 0 <= nxt_w < len(energy_w) and move_w not in tabu_try_w:
                options_w.append((energy_w[nxt_w], nxt_w, move_w))
        if not options_w:
            break
        _, best_state_w, best_move_w = min(options_w)
        path_try_w.append(best_state_w)
        tabu_try_w.append(-best_move_w)
        tabu_try_w = tabu_try_w[-tenure_try_w:]
    end_states_w.append(path_try_w[-1])
print("tenures:", tenures_w)
print("end states:", end_states_w)
```
▶ What you'll see: changing tenure changes the path because the admissible moves change.

```python
fig, ax_w = plt.subplots(1, 2, figsize=(8, 3))
ax_w[0].bar([str(c) for c in coolings_w], sa_best_w, color="teal")
ax_w[0].set_title("SA: cooling controls exploration")
ax_w[0].set_xlabel("cooling rate")
ax_w[0].set_ylabel("best energy")
ax_w[1].bar([str(t) for t in tenures_w], end_states_w, color="darkorange")
ax_w[1].set_title("Tabu: tenure controls memory")
ax_w[1].set_xlabel("tenure")
ax_w[1].set_ylabel("end state")
plt.tight_layout()
plt.show()
```
▶ What you'll see: both plots show that the escape mechanism is a tuning decision, not a guarantee of optimality.

*Why it's done this way:* Metaheuristics spend limited budget. The knob must allow enough non-greedy behavior to escape traps, then enough restraint to exploit good regions. That is why practical implementations monitor paths, energies, and acceptance or memory diagnostics.

### ✍️ Toy 2 · Greedy descent stops at the first trap

Greedy local search accepts only improving neighbors. Starting at `0`, it walks downhill to state `2`
and then stops because both one-step moves are worse.

```python
import numpy as np                              # arrays + greedy comparisons.
t2_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t2_energy = np.array([7.0, 4.0, 2.0, 5.0, 6.0, 3.0, 1.0, 4.0])  # -> [7,4,2,5,6,3,1,4]
print("energy:", t2_energy.tolist())            # -> [7.0, 4.0, 2.0, 5.0, 6.0, 3.0, 1.0, 4.0]
t2_path = [0]                                   # -> [0]
print("start path:", t2_path)                   # -> [0]
while True:
    t2_current = t2_path[-1]
    t2_candidates = []
    if t2_current > 0:
        t2_candidates.append(t2_current - 1)
    if t2_current < len(t2_energy) - 1:
        t2_candidates.append(t2_current + 1)
    t2_neighbors = np.array(t2_candidates, dtype=int)
    t2_best = int(t2_neighbors[np.argmin(t2_energy[t2_neighbors])])
    print("current/best neighbor:", t2_current, t2_best)  # -> 0 1; then 1 2; then 2 1
    print("energies:", float(t2_energy[t2_current]), float(t2_energy[t2_best]))  # -> 7 4; then 4 2; then 2 4
    if t2_energy[t2_best] >= t2_energy[t2_current]:
        break
    t2_path.append(t2_best)
print("greedy path:", t2_path)                  # -> [0, 1, 2]
print("ending energy:", float(t2_energy[t2_path[-1]]))   # -> 2.0
assert t2_path == [0, 1, 2]                     # greedy halts at the local minimum.

plt.figure(figsize=(5.0, 3.0))
plt.plot(np.arange(len(t2_energy)), t2_energy, marker="o", color="lightgray")
plt.plot(t2_path, t2_energy[t2_path], marker="o", color="#e45756", linewidth=3)
plt.xlabel("state")
plt.ylabel("energy")
plt.title("Toy 2 · greedy path gets trapped")
plt.show()
```
▶ What you'll see: the red path is `0 → 1 → 2`, stopping before the better basin near state `6`.

### ✍️ Toy 3 · Temperature turns uphill cost into acceptance probability

Simulated annealing accepts downhill moves automatically, but uphill moves use
`exp(-Δ/T)`. Hotter temperatures make the same cost easier to accept.

```python
import numpy as np                              # arrays + exponential probabilities.
t3_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t3_delta = np.array([0.5, 2.0, 4.0])            # -> [0.5, 2.0, 4.0]
print("uphill deltas:", t3_delta.tolist())      # -> [0.5, 2.0, 4.0]
t3_temp = np.array([4.0, 1.0, 0.25])            # -> [4.0, 1.0, 0.25]
print("temperatures:", t3_temp.tolist())        # -> [4.0, 1.0, 0.25]
t3_probs = np.exp(-t3_delta / t3_temp)          # -> [0.882497, 0.135335, 0.000000]
print("accept probabilities:", np.round(t3_probs, 6).tolist())    # -> [0.882497, 0.135335, 0.0]
t3_draws = np.array([0.70, 0.10, 0.001])        # -> [0.7, 0.1, 0.001]
print("random draws:", t3_draws.tolist())       # -> [0.7, 0.1, 0.001]
t3_accept = t3_draws < t3_probs                 # -> [True, True, False]
print("accept flags:", t3_accept.tolist())      # -> [True, True, False]
assert np.array_equal(t3_accept, np.array([True, True, False]))    # the cold, costly move is rejected.

plt.figure(figsize=(4.8, 3.0))
plt.bar(["hot", "warm", "cold"], t3_probs, color="#4c78a8", label="probability")
plt.scatter(["hot", "warm", "cold"], t3_draws, color="#e45756", zorder=3, label="draw")
plt.ylim(0, 1)
plt.ylabel("acceptance test")
plt.title("Toy 3 · draw below probability accepts")
plt.legend()
plt.show()
```
▶ What you'll see: the first two draws fall below their probabilities, while the cold move's draw does not.

### ✍️ Toy 4 · Annealing crosses a barrier by accepting uphill moves

A short annealing trace can pass through worse states before reaching a better basin. The seeded
draws accept two uphill proposals, then downhill moves finish the escape.

```python
import numpy as np                              # arrays + seeded acceptance draws.
t4_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t4_energy = np.array([7.0, 4.0, 2.0, 5.0, 6.0, 3.0, 1.0, 4.0])  # -> [7,4,2,5,6,3,1,4]
print("energy:", t4_energy.tolist())            # -> [7.0, 4.0, 2.0, 5.0, 6.0, 3.0, 1.0, 4.0]
t4_proposals = np.array([1, 2, 3, 4, 5, 6])     # -> [1, 2, 3, 4, 5, 6]
print("proposal schedule:", t4_proposals.tolist())       # -> [1, 2, 3, 4, 5, 6]
t4_draws = t4_rng.random(len(t4_proposals))     # -> [0.637, 0.27, 0.041, 0.017, 0.813, 0.913]
print("draws:", np.round(t4_draws, 3).tolist()) # -> [0.637, 0.27, 0.041, 0.017, 0.813, 0.913]
t4_T0 = 4.0                                     # -> 4.0
print("initial T:", t4_T0)                      # -> 4.0
t4_cool = 0.9                                   # -> 0.9
print("cooling rate:", t4_cool)                 # -> 0.9
t4_path = [0]                                   # -> [0]
t4_probs = []                                   # -> []
t4_accepts = []                                 # -> []
for t4_step, t4_proposal in enumerate(t4_proposals):
    t4_current = t4_path[-1]
    t4_T = t4_T0 * (t4_cool ** t4_step)
    t4_delta = t4_energy[t4_proposal] - t4_energy[t4_current]
    t4_prob = 1.0 if t4_delta <= 0 else float(np.exp(-t4_delta / t4_T))
    t4_accept = t4_delta <= 0 or t4_draws[t4_step] < t4_prob
    t4_probs.append(t4_prob)
    t4_accepts.append(t4_accept)
    t4_path.append(int(t4_proposal) if t4_accept else t4_current)
print("accept probabilities:", np.round(t4_probs, 3).tolist())     # -> [1.0, 1.0, 0.396, 0.71, 1.0, 1.0]
print("accept flags:", t4_accepts)              # -> [True, True, True, True, True, True]
print("annealing path:", t4_path)               # -> [0, 1, 2, 3, 4, 5, 6]
t4_best_state = int(t4_path[np.argmin(t4_energy[t4_path])])        # -> 6
print("best visited state:", t4_best_state)     # -> 6
assert t4_best_state == 6                       # accepted uphill moves cross the barrier to the global best.

plt.figure(figsize=(5.0, 3.0))
plt.plot(np.arange(len(t4_energy)), t4_energy, marker="o", color="lightgray")
plt.plot(t4_path, t4_energy[t4_path], marker="o", color="#4c78a8", linewidth=3)
plt.xlabel("state")
plt.ylabel("energy")
plt.title("Toy 4 · annealing crosses the hill")
plt.show()
```
▶ What you'll see: the path climbs from state `2` to `4`, then descends to the global best at state `6`.

### ✍️ Toy 5 · Tabu memory blocks immediate reversal

Tabu search stores the move that would undo the last step. That memory lets the path move through a
local trap instead of bouncing backward.

```python
import numpy as np                              # arrays + tabu-list updates.
t5_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t5_energy = np.array([7.0, 4.0, 2.0, 5.0, 6.0, 3.0, 1.0, 4.0])  # -> [7,4,2,5,6,3,1,4]
print("energy:", t5_energy.tolist())            # -> [7.0, 4.0, 2.0, 5.0, 6.0, 3.0, 1.0, 4.0]
t5_moves = np.array([-1, 1])                    # -> [-1, 1]
print("candidate moves:", t5_moves.tolist())    # -> [-1, 1]
t5_path = [0]                                   # -> [0]
```

```python
    uphill_a1 = 0
    for step_a1 in range(50):
        current_a1 = path_a1[-1]
        T_a1 = 5.0 * (cool_a1 ** step_a1)
        neighbors_a1 = np.array([n for n in [current_a1 - 1, current_a1 + 1] if 0 <= n < len(energy_a1)])
        proposal_a1 = int(rng_a1.choice(neighbors_a1))
        delta_a1 = energy_a1[proposal_a1] - energy_a1[current_a1]
        if delta_a1 <= 0 or rng_a1.random() < np.exp(-delta_a1 / max(T_a1, 1e-12)):
            path_a1.append(proposal_a1)
            uphill_a1 += int(delta_a1 > 0)
        else:
            path_a1.append(current_a1)
    best_energy_a1.append(float(np.min(energy_a1[path_a1])))
    uphill_count_a1.append(uphill_a1)
print("best energies:", best_energy_a1)
print("uphill accepts:", uphill_count_a1)
```
▶ What you'll see: schedules differ in both solution quality and number of uphill moves.


### Advanced 4 — Optimize a binary feature subset

**Goal.** Apply annealing to a binary vector, because feature subset search is a common ML-adjacent combinatorial optimization problem.

```python
weights_a4 = np.array([4.0, 2.0, 3.0, 5.0, 1.0, 2.5])
penalty_a4 = 0.8
state_a4 = np.array([1, 0, 0, 1, 0, 0])
def energy_subset_a4(bits_a4):
    score_a4 = np.sum(weights_a4 * bits_a4)
    size_penalty_a4 = penalty_a4 * (np.sum(bits_a4) ** 2)
    return float(-score_a4 + size_penalty_a4)
print("initial bits:", state_a4, "energy:", round(energy_subset_a4(state_a4), 3))
```
▶ What you'll see: the objective rewards selected features but penalizes large subsets.

```python
rng_a4 = np.random.default_rng(7)
path_energy_a4 = [energy_subset_a4(state_a4)]
best_state_a4 = state_a4.copy()
for step_a4 in range(80):
    T_a4 = 3.0 * (0.94 ** step_a4)
    idx_a4 = int(rng_a4.integers(len(state_a4)))
    proposal_a4 = state_a4.copy()
    proposal_a4[idx_a4] = 1 - proposal_a4[idx_a4]
    delta_a4 = energy_subset_a4(proposal_a4) - energy_subset_a4(state_a4)
    if delta_a4 <= 0 or rng_a4.random() < np.exp(-delta_a4 / max(T_a4, 1e-12)):
        state_a4 = proposal_a4
    if energy_subset_a4(state_a4) < energy_subset_a4(best_state_a4):
        best_state_a4 = state_a4.copy()
    path_energy_a4.append(energy_subset_a4(state_a4))
print("best bits:", best_state_a4, "best energy:", round(energy_subset_a4(best_state_a4), 3))
assert len(best_state_a4) == 6
```
▶ What you'll see: annealing flips feature bits and keeps the best subset found.

👀 Takeaway: simulated annealing applies whenever you can propose a neighbor and compute Δ.

### Advanced 5 — Optimize a small route with tabu swaps

**Goal.** Use tabu search on a route permutation, because routing and scheduling are classic settings where exact search is expensive.

```python
coords_a5 = np.array([[0.0, 0.0], [1.0, 2.0], [3.0, 1.0], [4.0, 3.0], [2.0, 4.0]])
route_a5 = np.array([0, 1, 2, 3, 4])
def route_length_a5(route_in_a5):
    total_a5 = 0.0
    for i_a5 in range(len(route_in_a5)):
        a_a5 = coords_a5[route_in_a5[i_a5]]
        b_a5 = coords_a5[route_in_a5[(i_a5 + 1) % len(route_in_a5)]]
        total_a5 += float(np.linalg.norm(a_a5 - b_a5))
    return total_a5
print("initial route length:", round(route_length_a5(route_a5), 3))
```
▶ What you'll see: a closed route length for visiting five points.

```python
tabu_pairs_a5 = []

    best_len_a5, route_a5, move_a5 = min(options_a5, key=lambda x: x[0])
    tabu_pairs_a5.append(move_a5)
    tabu_pairs_a5 = tabu_pairs_a5[-tenure_a5:]
```
