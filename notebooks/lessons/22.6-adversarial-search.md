# 22.6 — Adversarial Search

Adversarial search studies decision making when another agent is trying to undo your plan. In this lesson, we build minimax and alpha-beta pruning from scratch on tiny game trees and tic-tac-toe boards, always asking the key question: what survives after the opponent replies optimally?

```python
import numpy as np  # arrays for boards, scores, and compact bookkeeping.
```

### 1. Games turn search into strategic response

Uninformed and informed search assumed the world passively reveals successors. Games add an opponent who chooses the successor you like least. A move is not good just because it has one wonderful continuation; it is good if it remains acceptable after the opponent replies. We begin with a two-ply tree: Max chooses between moves A and B, then Min chooses the leaf under that move.

```python
leaves_w1 = {"A": [3, 5], "B": [2, 9]}  # terminal utilities from Max's point of view.
min_values_w1 = {move: min(vals) for move, vals in leaves_w1.items()}  # opponent picks the worse leaf for Max.
root_value_w1 = max(min_values_w1.values())  # Max picks the move with the best guaranteed value.
best_move_w1 = max(min_values_w1, key=min_values_w1.get)  # read off the robust move.
print("opponent values:", min_values_w1)  # A -> 3, B -> 2.
print("root value:", root_value_w1, "best move:", best_move_w1)  # Max chooses A.
assert root_value_w1 == 3 and best_move_w1 == "A"  # canonical two-ply minimax result.
```
▶ What you'll see: Max chooses A even though B contains the largest leaf 9, because Min would answer B with 2.

```python
plt.figure(figsize=(6, 3.8))
pos_w1 = {"root": (0, 2.6), "A": (-1.5, 1.4), "B": (1.5, 1.4), "A0": (-2.1, 0.2), "A1": (-0.9, 0.2), "B0": (0.9, 0.2), "B1": (2.1, 0.2)}

    x0_w1, y0_w1 = pos_w1[parent_w1]; x1_w1, y1_w1 = pos_w1[child_w1]
    plt.annotate("", xy=(x1_w1, y1_w1 + 0.18), xytext=(x0_w1, y0_w1 - 0.22), arrowprops=dict(arrowstyle="->", color="gray"))

    color_w1 = "lightgreen" if node_w1 in ["root", "A", "A0"] else "white"
    plt.text(x_w1, y_w1, labels_w1[node_w1], ha="center", va="center", bbox=dict(boxstyle="round", facecolor=color_w1, edgecolor="black"))
plt.axis("off"); plt.title("Walkthrough 1: minimax prefers the better guarantee")
plt.show()
```
▶ What you'll see: the highlighted path is root → A → 3, the outcome Max can guarantee.

*Why it's done this way:* backing up the opponent's minimum makes the value represent a strategy guarantee, not a lucky best-case leaf.

### 2. The minimax recurrence alternates max and min layers

The compact rule is simple: at a Max node, $V(s)=\max_a V(T(s,a))$; at a Min node, $V(s)=\min_a V(T(s,a))$. Terminal nodes return their utility. The alternation is the logic of turns: your layer optimizes for you, the opponent's layer optimizes against you.

```python
tree_w2 = {"root": ["L", "R"], "L": ["L0", "L1"], "R": ["R0", "R1"]}  # fixed game tree.
utility_w2 = {"L0": 4, "L1": 1, "R0": 2, "R1": 6}  # terminal utilities for Max.
def minimax_w(node_w2, maximizing_w2):
    if node_w2 in utility_w2:
        return utility_w2[node_w2]
    child_values_w2 = [minimax_w(child_w2, not maximizing_w2) for child_w2 in tree_w2[node_w2]]
    return max(child_values_w2) if maximizing_w2 else min(child_values_w2)
value_w2 = minimax_w("root", True)
print("root value:", value_w2)
assert value_w2 == 2  # L backs up 1, R backs up 2, root chooses R.
```
▶ What you'll see: the recursive rule backs up 2 because R's worst reply is better than L's worst reply.

```python
vals_w2 = {"L": 1, "R": 2, "root": value_w2, **utility_w2}
pos_w2 = {"root": (0, 2.5), "L": (-1.4, 1.35), "R": (1.4, 1.35), "L0": (-2, 0.2), "L1": (-0.8, 0.2), "R0": (0.8, 0.2), "R1": (2, 0.2)}
plt.figure(figsize=(6, 3.6))
for p_w2, children_w2 in tree_w2.items():
    for c_w2 in children_w2:
        plt.annotate("", xy=(pos_w2[c_w2][0], pos_w2[c_w2][1] + 0.18), xytext=(pos_w2[p_w2][0], pos_w2[p_w2][1] - 0.22), arrowprops=dict(arrowstyle="->", color="gray"))
for n_w2, (x_w2, y_w2) in pos_w2.items():
    label_w2 = ("MAX" if n_w2 == "root" else "MIN" if n_w2 in ["L", "R"] else "leaf") + f"\nV={vals_w2[n_w2]}"
    plt.text(x_w2, y_w2, label_w2, ha="center", va="center", bbox=dict(boxstyle="round", facecolor="lavender", edgecolor="black"))
plt.axis("off"); plt.title("Walkthrough 2: max/min recurrence backs values upward")
plt.show()
```
▶ What you'll see: leaf values rise to Min nodes first, then Max chooses the larger backed-up value.

*Why it's done this way:* recursion matches the game definition: a state value is defined by the values of reachable next states under the player to move.

### 3. Alpha-beta pruning skips branches that cannot matter

Alpha-beta pruning is exact; it changes effort, not the minimax answer. Alpha is Max's best guaranteed value so far. Beta is Min's best upper bound so far. If a node proves it cannot improve an ancestor decision, the rest of that branch is logically irrelevant and can be skipped.

```python
branches_w3 = [[3, 5], [2, 9]]  # good ordering visits A first, then B.
alpha_w3 = -np.inf
visited_w3 = []
pruned_w3 = []
for branch_idx_w3, branch_w3 in enumerate(branches_w3):
    beta_w3 = np.inf
    for leaf_idx_w3, leaf_w3 in enumerate(branch_w3):
        visited_w3.append((branch_idx_w3, leaf_idx_w3, leaf_w3))
        beta_w3 = min(beta_w3, leaf_w3)
        if beta_w3 <= alpha_w3:
            pruned_w3.extend([(branch_idx_w3, k_w3, branch_w3[k_w3]) for k_w3 in range(leaf_idx_w3 + 1, len(branch_w3))])
            break
    alpha_w3 = max(alpha_w3, beta_w3)
print("visited:", visited_w3)
print("pruned:", pruned_w3)
assert len(visited_w3) == 3 and len(pruned_w3) == 1 and alpha_w3 == 3
```
▶ What you'll see: once B shows leaf 2, Max already has A's 3, so B's remaining 9 cannot change the root choice.

```python
plt.figure(figsize=(6, 3.6))

    plt.annotate("", xy=(pos_w3[c_w3][0], pos_w3[c_w3][1] + 0.18), xytext=(pos_w3[p_w3][0], pos_w3[p_w3][1] - 0.22), arrowprops=style_w3)

plt.axis("off"); plt.title("Walkthrough 3: alpha-beta prunes impossible improvements")
plt.show()
```
▶ What you'll see: the red dashed branch is skipped even though its hidden leaf is large.

*Why it's done this way:* the cutoff follows from inequalities, not guesswork: Min can already force B to be no better than 2, and Max already has 3.

### 4. Move ordering controls how much pruning you get

Alpha-beta is exact for any move order, but ordering changes the number of nodes evaluated. Good ordering sees strong Max moves and weak Min replies early, making cutoffs happen sooner. Bad ordering delays that evidence and can visit almost the whole tree.

```python
orders_w4 = {"good": [[3, 5], [2, 9]], "bad": [[2, 9], [3, 5]]}  # same leaves, different root order.
def alphabeta_count_w(branches_w4):
    alpha_w4 = -np.inf
    visited_w4 = 0
    for branch_w4 in branches_w4:
        beta_w4 = np.inf
        for leaf_w4 in branch_w4:
            visited_w4 += 1
            beta_w4 = min(beta_w4, leaf_w4)
            if beta_w4 <= alpha_w4:
                break
        alpha_w4 = max(alpha_w4, beta_w4)
    return int(visited_w4), float(alpha_w4)
counts_w4 = {name_w4: alphabeta_count_w(order_w4)[0] for name_w4, order_w4 in orders_w4.items()}
values_w4 = {name_w4: alphabeta_count_w(order_w4)[1] for name_w4, order_w4 in orders_w4.items()}
print("visited leaves:", counts_w4)
print("values:", values_w4)
assert values_w4["good"] == values_w4["bad"] == 3
```
▶ What you'll see: both orders return value 3, but they can do different amounts of work.

```python
plt.figure(figsize=(4.8, 3.2))
plt.bar(list(counts_w4.keys()), list(counts_w4.values()), color=["seagreen", "crimson"])
plt.axhline(4, color="gray", linestyle="--", label="no pruning")
plt.ylabel("leaves evaluated")
plt.title("Walkthrough 4: ordering affects work, not value")
plt.legend()
plt.show()
```
▶ What you'll see: better ordering evaluates fewer leaves while preserving the same backed-up value.

*Why it's done this way:* alpha-beta needs evidence before it can prove irrelevance, so ordering good evidence early makes the proof arrive earlier.

### 5. Depth limits replace true utilities with evaluation functions

Exact minimax is often too expensive, so real agents stop at a depth limit and apply an evaluation function $\hat V$. In tic-tac-toe, a simple evaluation can count open lines: lines still possible for X minus lines still possible for O. The search is still minimax, but the leaves are estimates instead of terminal truth.

```python
board_w5 = np.array([['X', 'O', 'X'], [' ', 'X', ' '], ['O', ' ', ' ']])  # a nonterminal board.
lines_w5 = [[(0,0),(0,1),(0,2)], [(1,0),(1,1),(1,2)], [(2,0),(2,1),(2,2)], [(0,0),(1,0),(2,0)], [(0,1),(1,1),(2,1)], [(0,2),(1,2),(2,2)], [(0,0),(1,1),(2,2)], [(0,2),(1,1),(2,0)]]
def open_lines_w(board_w5, mark_w5):
    opp_w5 = 'O' if mark_w5 == 'X' else 'X'
    return sum(all(board_w5[r_w5, c_w5] != opp_w5 for r_w5, c_w5 in line_w5) for line_w5 in lines_w5)
score_w5 = open_lines_w(board_w5, 'X') - open_lines_w(board_w5, 'O')
print("open X lines:", open_lines_w(board_w5, 'X'), "open O lines:", open_lines_w(board_w5, 'O'))
print("evaluation score:", score_w5)
assert score_w5 == 2
```
▶ What you'll see: the heuristic says X is better because X has more still-open winning lines.

```python
plt.figure(figsize=(3.4, 3.4))
for k_w5 in range(4):
    plt.plot([-.5, 2.5], [k_w5-.5, k_w5-.5], color="black")
    plt.plot([k_w5-.5, k_w5-.5], [-.5, 2.5], color="black")
for r_w5 in range(3):
    for c_w5 in range(3):
        mark_w5 = board_w5[r_w5, c_w5]
        if mark_w5 != ' ':
            plt.text(c_w5, 2-r_w5, mark_w5, ha="center", va="center", fontsize=28)
plt.xlim(-.5, 2.5); plt.ylim(-.5, 2.5); plt.xticks([]); plt.yticks([])
plt.title(f"Walkthrough 5: depth-limit evaluation = {score_w5}")
plt.show()
```
▶ What you'll see: the board is not terminal, so the numeric score comes from structure, not a final win/loss.

*Why it's done this way:* when the full tree is unreachable, a heuristic leaf value gives minimax a principled approximation target.

### ✍️ Toy 1 · Opponent replies choose the guarantee

A tempting move is not enough in a game: Max should compare the value left after Min chooses the
worst reply.

```python
import numpy as np                              # arrays for tiny game values.
import matplotlib.pyplot as plt                 # one picture per toy section.

t1_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
```

### ✍️ Toy 2 · Minimax alternates max and min backups

At Max layers values move upward by `max`; at Min layers they move upward by `min`.

```python
import numpy as np                              # arrays for plotting backed-up values.

t2_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t2_tree = {
    "root": ["A", "B"],
    "A": ["A1", "A2"],
    "B": ["B1", "B2"],
    "A1": ["A1a", "A1b"],
    "A2": ["A2a", "A2b"],
    "B1": ["B1a", "B1b"],
    "B2": ["B2a", "B2b"],
}
t2_utilities = {"A1a": 3, "A1b": 1, "A2a": 2, "A2b": 4, "B1a": 0, "B1b": 5, "B2a": 6, "B2b": 2}

def t2_minimax(t2_node, t2_maximizing):
    if t2_node in t2_utilities:
        return t2_utilities[t2_node]
    t2_child_values = []
    for t2_child in t2_tree[t2_node]:
        t2_child_value = t2_minimax(t2_child, not t2_maximizing)
        t2_child_values.append(t2_child_value)
    if t2_maximizing:
        return max(t2_child_values)
    return min(t2_child_values)

t2_A1 = t2_minimax("A1", True)                  # Max backup from 3 and 1        # -> 3
t2_A2 = t2_minimax("A2", True)                  # Max backup from 2 and 4        # -> 4
t2_B1 = t2_minimax("B1", True)                  # Max backup from 0 and 5        # -> 5
t2_B2 = t2_minimax("B2", True)                  # Max backup from 6 and 2        # -> 6
t2_A = t2_minimax("A", False)                   # Min backup from 3 and 4        # -> 3
t2_B = t2_minimax("B", False)                   # Min backup from 5 and 6        # -> 5
t2_root = t2_minimax("root", True)              # Max backup from 3 and 5        # -> 5
print("MAX-node backups:", {"A1": t2_A1, "A2": t2_A2, "B1": t2_B1, "B2": t2_B2})  # -> {'A1': 3, 'A2': 4, 'B1': 5, 'B2': 6}
print("MIN-node backups:", {"A": t2_A, "B": t2_B})  # -> {'A': 3, 'B': 5}
print("root value:", t2_root)                   # -> 5
assert t2_root == 5 and t2_B == 5

plt.figure(figsize=(5, 2.8))
plt.bar(["A1", "A2", "A", "B1", "B2", "B", "root"], [t2_A1, t2_A2, t2_A, t2_B1, t2_B2, t2_B, t2_root], color="mediumpurple")
plt.ylabel("backed-up value")
plt.title("Toy 2 · max layers and min layers alternate")
plt.show()
```
▶ What you'll see: Max backs `B1` to `5` and `B2` to `6`; Min then backs `B` down to `5`, which root chooses.

### ✍️ Toy 3 · Alpha-beta cutoffs skip impossible improvements

After Max already has a value of `5`, a later Min branch that reveals `3` cannot improve the root,
so its remaining leaf can be pruned.

```python
import numpy as np                              # arrays for plotting visited and pruned leaves.

t3_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t3_branches = [[5, 7], [3, 9]]                  # two Min children under a Max root # -> [[5, 7], [3, 9]]
t3_alpha = -np.inf
t3_visited = []
t3_pruned = []
for t3_branch_index, t3_branch in enumerate(t3_branches):
    t3_beta = np.inf
    for t3_leaf_index, t3_leaf in enumerate(t3_branch):
        t3_visited.append((t3_branch_index, t3_leaf_index, t3_leaf))
        t3_beta = min(t3_beta, t3_leaf)
        if t3_beta <= t3_alpha:
            for t3_skip_index in range(t3_leaf_index + 1, len(t3_branch)):
                t3_pruned.append((t3_branch_index, t3_skip_index, t3_branch[t3_skip_index]))
            break
    t3_alpha = max(t3_alpha, t3_beta)
print("visited leaves:", t3_visited)            # -> [(0, 0, 5), (0, 1, 7), (1, 0, 3)]
print("pruned leaves:", t3_pruned)              # -> [(1, 1, 9)]
print("final alpha:", t3_alpha)                 # -> 5
assert t3_visited == [(0, 0, 5), (0, 1, 7), (1, 0, 3)]
assert t3_pruned == [(1, 1, 9)] and t3_alpha == 5

t3_labels = ["A0", "A1", "B0", "B1"]
t3_values = [5, 7, 3, 9]
t3_colors = ["seagreen", "seagreen", "seagreen", "lightgray"]
plt.figure(figsize=(4.8, 2.8))
plt.bar(t3_labels, t3_values, color=t3_colors, edgecolor="black")
plt.ylabel("leaf utility")
plt.title("Toy 3 · gray leaf is pruned")
plt.show()
```
▶ What you'll see: leaf `B1 = 9` is gray because `B0 = 3` already proves branch `B` cannot beat `5`.

### ✍️ Toy 4 · Move ordering changes work, not value

The same leaves can give the same minimax value while requiring different numbers of visited leaves.

```python
import numpy as np                              # arrays for comparing leaf counts.

t4_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t4_good_order = [[6, 8], [2, 7], [5, 9]]        # best branch first              # -> [[6, 8], [2, 7], [5, 9]]
t4_bad_order = [[2, 7], [5, 9], [6, 8]]         # best branch last               # -> [[2, 7], [5, 9], [6, 8]]

def t4_count_alphabeta(t4_branches):
    t4_alpha = -np.inf
    t4_visited = 0
    for t4_branch in t4_branches:
        t4_beta = np.inf
        for t4_leaf in t4_branch:
            t4_visited = t4_visited + 1
            t4_beta = min(t4_beta, t4_leaf)
            if t4_beta <= t4_alpha:
                break
        t4_alpha = max(t4_alpha, t4_beta)
    return int(t4_visited), float(t4_alpha)

t4_good_result = t4_count_alphabeta(t4_good_order)
t4_bad_result = t4_count_alphabeta(t4_bad_order)
print("good order (visited, value):", t4_good_result)  # -> (4, 6.0)
print("bad order (visited, value):", t4_bad_result)    # -> (6, 6.0)
assert t4_good_result == (4, 6.0)
assert t4_bad_result == (6, 6.0)

plt.figure(figsize=(4.6, 2.8))
plt.bar(["good order", "bad order"], [t4_good_result[0], t4_bad_result[0]], color=["seagreen", "crimson"])
plt.ylabel("visited leaves")
plt.title("Toy 4 · same value, different work")
plt.show()
```
▶ What you'll see: both orders return value `6`, but good ordering visits only `4` leaves instead of `6`.

### ✍️ Toy 5 · Depth-limited evaluation scores a nonterminal board

When search stops before a terminal result, a heuristic can count still-open winning lines for `X`
minus still-open lines for `O`.

```python
import numpy as np                              # arrays for the tiny board.

t5_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t5_board = np.array([["X", " ", "O"], [" ", "X", " "], ["O", " ", " "]])
t5_lines = [[(0, 0), (0, 1), (0, 2)], [(1, 0), (1, 1), (1, 2)], [(2, 0), (2, 1), (2, 2)], [(0, 0), (1, 0), (2, 0)], [(0, 1), (1, 1), (2, 1)], [(0, 2), (1, 2), (2, 2)], [(0, 0), (1, 1), (2, 2)], [(0, 2), (1, 1), (2, 0)]]

def t5_open_lines(t5_mark):
    t5_opp = "O" if t5_mark == "X" else "X"
    t5_count = 0
    for t5_line in t5_lines:
        t5_is_open = all(t5_board[t5_r, t5_c] != t5_opp for t5_r, t5_c in t5_line)
        t5_count = t5_count + int(t5_is_open)
    return t5_count

t5_x_open = t5_open_lines("X")                  # lines not blocked by O         # -> 3
t5_o_open = t5_open_lines("O")                  # lines not blocked by X         # -> 2
t5_score = t5_x_open - t5_o_open                # heuristic score for X          # -> 1
print("board:", t5_board.tolist())              # -> [['X', ' ', 'O'], [' ', 'X', ' '], ['O', ' ', ' ']]
print("open X lines:", t5_x_open)               # -> 3
print("open O lines:", t5_o_open)               # -> 2
print("evaluation score:", t5_score)            # -> 1
assert t5_score == 1

plt.figure(figsize=(3.2, 3.2))
for t5_grid_index in range(4):
    plt.plot([-0.5, 2.5], [t5_grid_index - 0.5, t5_grid_index - 0.5], color="black")
    plt.plot([t5_grid_index - 0.5, t5_grid_index - 0.5], [-0.5, 2.5], color="black")
```

## 🛠️ Setup

```python
import numpy as np  # arrays for game trees, toy boards, and statistics.
import matplotlib.pyplot as plt  # visual diagnostics for every example.
np.random.seed(0)  # make any stochastic ordering demonstrations reproducible.

LINES = [[(0,0),(0,1),(0,2)], [(1,0),(1,1),(1,2)], [(2,0),(2,1),(2,2)],
         [(0,0),(1,0),(2,0)], [(0,1),(1,1),(2,1)], [(0,2),(1,2),(2,2)],
         [(0,0),(1,1),(2,2)], [(0,2),(1,1),(2,0)]]  # all tic-tac-toe winning lines.

def draw_tree(levels, edges, labels, title, pruned_edges=None):
    pruned_edges = set(pruned_edges or [])
    plt.figure(figsize=(6, 3.8))
    positions = {}
    for depth, nodes in enumerate(levels):
        xs = np.linspace(-2.4, 2.4, len(nodes)) if len(nodes) > 1 else np.array([0.0])
        for x, node in zip(xs, nodes):
            positions[node] = (x, 2.7 - depth * 1.1)
    for parent, child in edges:
        x0, y0 = positions[parent]; x1, y1 = positions[child]
        style = dict(arrowstyle="->", color="red", linestyle="--") if (parent, child) in pruned_edges else dict(arrowstyle="->", color="gray")
        plt.annotate("", xy=(x1, y1 + 0.16), xytext=(x0, y0 - 0.2), arrowprops=style)
    for node, (x, y) in positions.items():
        face = "mistyrose" if any(child == node for _, child in pruned_edges) else "white"
        plt.text(x, y, labels[node], ha="center", va="center", bbox=dict(boxstyle="round", facecolor=face, edgecolor="black"))
    plt.axis("off"); plt.title(title); plt.show()

def draw_board(board, title):
    plt.figure(figsize=(3.3, 3.3))
    for k in range(4):
        plt.plot([-.5, 2.5], [k-.5, k-.5], color="black")
        plt.plot([k-.5, k-.5], [-.5, 2.5], color="black")
    for r in range(3):
        for c in range(3):
            if board[r, c] != ' ':
                plt.text(c, 2-r, board[r, c], ha="center", va="center", fontsize=28)
    plt.xlim(-.5, 2.5); plt.ylim(-.5, 2.5); plt.xticks([]); plt.yticks([]); plt.title(title); plt.show()

def winner(board):
    for line in LINES:
        marks = [board[r, c] for r, c in line]
        if marks[0] != ' ' and marks.count(marks[0]) == 3:
            return marks[0]
    if np.all(board != ' '):
        return 'draw'
    return None

def utility(board):
    w = winner(board)
    return 1 if w == 'X' else -1 if w == 'O' else 0 if w == 'draw' else None

def open_line_score(board):
    def open_count(mark):
        opp = 'O' if mark == 'X' else 'X'
        return sum(all(board[r, c] != opp for r, c in line) for line in LINES)
    return open_count('X') - open_count('O')

def minimax_tree(leaves):
    mins = [min(branch) for branch in leaves]
    return max(mins), mins

def alphabeta_two_ply(branches):
    alpha = -np.inf
    visited = []
    pruned = []
    for bi, branch in enumerate(branches):
        beta = np.inf
        for li, leaf in enumerate(branch):
            visited.append((bi, li, leaf))
            beta = min(beta, leaf)
            if beta <= alpha:
                pruned.extend((bi, k, branch[k]) for k in range(li + 1, len(branch)))
                break
        alpha = max(alpha, beta)
    return alpha, visited, pruned
```

**Goal.** Add alpha and beta bounds to recursive search, because exact pruning avoids irrelevant work. We build it in 3 steps.


```python

    if node_e2 in terminal_e2:
        visited_e2.append(node_e2)
        return terminal_e2[node_e2]

    return value_e2
```

```python
    sorted_branches_a2 = [sorted(branch_a2) for branch_a2 in sorted_branches_a2]
    _, visited_sorted_a2, _ = alphabeta_two_ply(sorted_branches_a2)
    random_counts_a2.append(len(visited_random_a2)); sorted_counts_a2.append(len(visited_sorted_a2))
print("mean random visits:", round(float(np.mean(random_counts_a2)), 2))

assert np.mean(sorted_counts_a2) <= np.mean(random_counts_a2)
```

#### A3. Depth-limited minimax on tic-tac-toe `_a3`

**Goal.** Combine recursion, terminal utility, and heuristic cutoff, because real game agents often cannot search to the end. We build it in 4 steps.

```python

print("heuristic at root:", open_line_score(board_a3))
```
▶ What you'll see: the root itself has a heuristic score, but search will look ahead.

```python
def depth_minimax_a3(board_a3, player_a3, depth_a3):
    util_a3 = utility(board_a3)
    if util_a3 is not None:
        return util_a3
    if depth_a3 == 0:
        return open_line_score(board_a3) / 8.0
    moves_a3 = [(int(r_a3), int(c_a3)) for r_a3, c_a3 in zip(*np.where(board_a3 == ' '))]
    values_a3 = []
    for move_a3 in moves_a3:
        child_a3 = board_a3.copy(); child_a3[move_a3] = player_a3
        values_a3.append(depth_minimax_a3(child_a3, 'O' if player_a3 == 'X' else 'X', depth_a3 - 1))
    return max(values_a3) if player_a3 == 'X' else min(values_a3)
print("depth-2 value:", round(depth_minimax_a3(board_a3, 'X', 2), 3))
```
