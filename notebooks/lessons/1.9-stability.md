# 1.9 · Algorithmic Stability

Algorithmic stability studies the **learning algorithm**, not the size of the whole hypothesis class. If replacing one training point barely changes the learned predictor or its loss, the learner was not clinging to that point; that insensitivity is a direct route to generalization. This lesson builds the idea from tiny arrays, then connects it to the stability guarantee behind regularization.

## 📖 Concept walkthrough — build it from scratch

### 1. Sensitivity by leave-one-out refitting

Stability asks how much the algorithm's output changes when one training example is removed or replaced. The smallest possible learner is the **sample mean**: fit one number, the average of the training values. For the data $\{2,4,6,8,10\}$, the full fit is $6.0$; dropping each point and refitting lets us measure exactly how much one example can move the output.

```python
x_w = np.array([2., 4., 6., 8., 10.])  # five tiny training values from the lesson text.
fit_w = float(np.mean(x_w))  # the learning algorithm A(S): return the sample mean.
print("training values:", x_w)  # inspect the sample before perturbing it.
print("full fit mean:", fit_w)  # the canonical fit is 6.0.
assert fit_w == 6.0  # reproduce the lesson number exactly.
```
▶ What you'll see: the learner compresses five points into one fitted number, the mean 6.0.

```python
loo_means_w = []  # store one refit after each possible deletion.
for i_w in range(len(x_w)):  # delete each training point once.
    kept_w = np.delete(x_w, i_w)  # form S without the i-th point.
    mean_i_w = float(np.mean(kept_w))  # refit the algorithm on the perturbed sample.
    loo_means_w.append(mean_i_w)  # save the leave-one-out fit for comparison.
    print(f"drop {x_w[i_w]:.0f}: mean={mean_i_w:.1f}")  # show every intermediate refit.
loo_means_w = np.array(loo_means_w)  # convert to an array for vector arithmetic.
assert np.allclose(loo_means_w, [7.0, 6.5, 6.0, 5.5, 5.0])  # reproduce the lesson list.
```
▶ What you'll see: dropping a low point raises the mean; dropping a high point lowers it.

```python
swings_w = np.abs(loo_means_w - fit_w)  # measure how far each refit moved from the full fit.
sensitivity_w = float(np.max(swings_w))  # empirical leave-one-out sensitivity on this sample.
print("absolute swings:", swings_w)  # inspect every output change.
print("max swing:", sensitivity_w)  # the lesson's 1.0 sensitivity number.
assert sensitivity_w == 1.0  # largest change is |7.0 - 6.0|.
```
▶ What you'll see: the worst deletion moves the learned mean by exactly 1.0.

```python
plt.figure(figsize=(5, 3))  # create a compact refit plot.
plt.axhline(fit_w, color="black", linestyle="--", label="full fit")  # show the original mean.
plt.plot(x_w, loo_means_w, marker="o", color="teal", label="leave-one-out fit")  # show each deletion refit.
plt.xlabel("dropped training value")  # label which point was removed.
plt.ylabel("refitted mean")  # label the algorithm output.
plt.title("1: leave-one-out sensitivity of the mean")  # title the visualization.
plt.legend()  # show which line is which.
plt.show()  # display the figure.
```
▶ What you'll see: the refitted means form a straight line around the full fit.

*Why it's done this way: perturbing one training point and measuring the output change is the most concrete version of stability; it turns the abstract question "does one example matter?" into a number we can compute.*

### 2. Uniform stability measures loss change, not just parameter change

Uniform stability $\beta$ is a worst-case guarantee: replacing one of the $m$ training points changes the loss on **any** evaluation example by at most $\beta$. The output may be a parameter such as a mean, but the theorem is about loss because generalization compares expected loss to training loss. For squared loss, changing a constant prediction from $a$ to $b$ changes the loss at a probe $z$ by $|(z-a)^2-(z-b)^2|$.

```python
S_w = np.array([0.1, 0.2, 0.4, 0.6, 0.8])  # a bounded sample in [0, 1].
S_swap_w = S_w.copy()  # copy the sample so we can replace one point.
S_swap_w[0] = 0.9  # replace 0.1 by 0.9, a one-point perturbation.
pred_w = float(np.mean(S_w))  # fit the mean on the original sample.
pred_swap_w = float(np.mean(S_swap_w))  # refit the mean after replacement.
print("original mean:", round(pred_w, 3))  # 0.42.
print("swapped mean:", round(pred_swap_w, 3))  # 0.58.
print("output change:", round(abs(pred_swap_w - pred_w), 3))  # 0.16 = 0.8/5.
assert round(abs(pred_swap_w - pred_w), 3) == 0.16  # reproduce the range/m replacement swing.
```
▶ What you'll see: replacing one point changes the mean by the replacement difference divided by $m=5$.

```python
probe_grid_w = np.linspace(0, 1, 101)  # evaluation examples where we compare losses.
loss_w = (probe_grid_w - pred_w) ** 2  # squared loss under the original fit.
loss_swap_w = (probe_grid_w - pred_swap_w) ** 2  # squared loss under the swapped fit.
loss_change_w = np.abs(loss_w - loss_swap_w)  # pointwise loss sensitivity over probes.
emp_beta_w = float(np.max(loss_change_w))  # empirical worst probe on this grid.
print("max grid loss change:", round(emp_beta_w, 3))  # largest visible loss change.
assert round(emp_beta_w, 3) == 0.16  # deterministic grid check.
```
▶ What you'll see: the largest loss change occurs near the edge of the bounded probe interval.

```python
plt.figure(figsize=(5, 3))  # create a compact loss-change plot.
plt.plot(probe_grid_w, loss_change_w, color="purple")  # show how loss sensitivity varies by probe.
plt.axhline(emp_beta_w, color="black", linestyle="--", label="empirical max")  # mark the worst grid value.
plt.xlabel("probe example z")  # label evaluation point.
plt.ylabel("absolute loss change")  # label the stability quantity.
plt.title("2: stability is loss sensitivity")  # title the plot.
plt.legend()  # display the maximum marker label.
plt.show()  # render the plot.
```
▶ What you'll see: output change becomes a curve of loss changes over possible test examples.

*Why it's done this way: uniform stability is stated on loss because generalization is a statement about loss; parameter movement matters only through how much it changes predictions and losses.*

### 3. Stability improves with data like $1/m$

For a bounded mean estimator, replacing one point can move the average by at most the data range divided by sample size: $\Delta A \le \frac{\text{range}}{m}$. That is the numerical lesson headline: with the same range, $m=5$ gives a scale of $1/5=0.20$, while $m=50$ gives $1/50=0.02$. Ten times the data makes each single point one tenth as influential.

```python
m_values_w = np.array([5, 10, 20, 50, 100])  # sample sizes to compare.
range_w = 1.0  # assume data are bounded in an interval of width one.
scales_w = range_w / m_values_w  # worst-case output movement for a one-point replacement.
print("m values:", m_values_w)  # inspect the sample-size grid.
print("range/m scales:", np.round(scales_w, 3))  # show the stability scale.
assert np.isclose(scales_w[0], 0.20) and np.isclose(scales_w[3], 0.02)  # lesson numbers.
```
▶ What you'll see: the one-point influence decays as the sample grows.

```python
ratio_w = scales_w[0] / scales_w[3]  # compare m=5 to m=50.
print("m=5 scale:", scales_w[0], "m=50 scale:", scales_w[3])  # inspect the two canonical values.
print("stability improvement factor:", round(ratio_w, 1))  # tenfold improvement.
assert round(ratio_w, 1) == 10.0  # ten times the data gives ten times less sensitivity.
```
▶ What you'll see: $0.20 / 0.02 = 10$, matching the lesson's data-size story.

```python
plt.figure(figsize=(5, 3))  # create a compact scaling plot.
plt.plot(m_values_w, scales_w, marker="o", color="seagreen")  # draw the 1/m curve.
plt.xlabel("sample size m")  # label x-axis.
plt.ylabel("one-point output scale")  # label y-axis.
plt.title("3: stability improves like 1/m")  # title the visualization.
plt.show()  # display the curve.
```
▶ What you'll see: a steep early drop that flattens as $m$ grows.

*Why it's done this way: stability is an algorithmic way to see why more data helps — a single point owns only $1/m$ of an average, so its leverage shrinks mechanically.*

### 4. Stability implies a small generalization gap

The generalization gap is $R(A(S))-R_S(A(S))$: true risk minus training risk. A stable learner cannot make training loss much smaller than test loss by exploiting quirks of individual examples, because swapping one training example barely changes the loss. The theorem says, roughly, gap $\lesssim \beta$ plus a concentration term of order $1/\sqrt{m}$.

```python
rng_w = np.random.default_rng(1)  # local generator for a reproducible simulation.
ms_w = np.array([5, 20, 80])  # sample sizes to compare.
gaps_w = []  # store average absolute train-test gaps.
for m_w in ms_w:  # run one experiment per sample size.
    trial_gaps_w = []  # collect repeated gaps for this m.
    for _ in range(400):  # repeat enough times to average randomness.
        train_w = rng_w.random(m_w)  # training data from Uniform[0, 1].
        test_w = rng_w.random(3000)  # large test sample approximates true risk.
        a_w = float(np.mean(train_w))  # stable mean learner.
        train_risk_w = float(np.mean((train_w - a_w) ** 2))  # empirical squared loss.
        test_risk_w = float(np.mean((test_w - a_w) ** 2))  # out-of-sample squared loss.
        trial_gaps_w.append(abs(test_risk_w - train_risk_w))  # absolute generalization gap.
    gaps_w.append(float(np.mean(trial_gaps_w)))  # store the average gap.
gaps_w = np.array(gaps_w)  # convert to array for checks and plotting.
print("mean |gap|:", np.round(gaps_w, 4))  # inspect the trend.
assert gaps_w[0] > gaps_w[-1]  # larger m gives a smaller average gap.
```
▶ What you'll see: the stable mean learner's train-test gap shrinks as sample size grows.

```python
plt.figure(figsize=(5, 3))  # create a compact gap plot.
plt.plot(ms_w, gaps_w, marker="o", color="darkorange")  # plot gap by sample size.
plt.xlabel("sample size m")  # label x-axis.
plt.ylabel("average |test risk - train risk|")  # label the generalization gap.
plt.title("4: stable learner gap shrinks with m")  # title the plot.
plt.show()  # display the figure.
```
▶ What you'll see: the gap is largest for tiny samples and much smaller by $m=80$.

*Why it's done this way: the simulation is not the proof, but it mirrors the proof's logic — if no one point can strongly steer the model, training performance is less likely to be a fragile accident.*

### 5. Regularization buys stability

Regularized ERM is a classic source of stability. A penalty such as $\lambda\lVert w\rVert^2$ makes the objective more curved, so one example has less power to drag the optimum around; schematically, $\beta\propto \frac{1}{\lambda m}$. In one-dimensional ridge regression, we can see this directly from the closed-form fit.

```python
xreg_w = np.array([-2., -1., 0., 1., 2.])  # tiny one-dimensional features.
yreg_w = np.array([-2.1, -0.9, 0.1, 1.1, 2.0])  # nearly linear targets.
yreg_swap_w = yreg_w.copy()  # create a perturbed dataset.
yreg_swap_w[-1] = 4.0  # replace one target by an outlier.
lams_w = np.array([0.0, 0.1, 1.0, 10.0])  # regularization strengths to sweep.
print("lambda grid:", lams_w)  # inspect the penalty values.
```
▶ What you'll see: one target is swapped to create a one-point perturbation.

```python
def ridge1d_w(x, y, lam):  # fit a one-dimensional ridge slope through the origin.
    denom = float(np.sum(x ** 2) + lam)  # regularized curvature; positive unless x is all zero and lam=0.
    return 0.0 if denom == 0 else float(np.sum(x * y) / denom)  # closed-form ridge solution.

w_full_w = np.array([ridge1d_w(xreg_w, yreg_w, lam_w) for lam_w in lams_w])  # fits on original data.
w_swap_w = np.array([ridge1d_w(xreg_w, yreg_swap_w, lam_w) for lam_w in lams_w])  # fits after one-point swap.
move_w = np.abs(w_swap_w - w_full_w)  # output sensitivity of the ridge slope.
print("original slopes:", np.round(w_full_w, 3))  # inspect regularized solutions.
print("swapped slopes:", np.round(w_swap_w, 3))  # inspect perturbed solutions.
print("slope changes:", np.round(move_w, 3))  # stability improves as lambda grows.
assert np.all(np.diff(move_w) < 0)  # larger lambda monotonically reduces this perturbation.
```
▶ What you'll see: the one-point outlier moves the unregularized slope most and the strongly regularized slope least.

```python
plt.figure(figsize=(5, 3))  # create a compact stability-vs-lambda plot.
plt.plot(lams_w, move_w, marker="o", color="crimson")  # show sensitivity as regularization grows.
plt.xscale("symlog", linthresh=0.1)  # make lambda=0 and large values readable together.
plt.xlabel("regularization λ")  # label the penalty axis.
plt.ylabel("|w_swapped - w_full|")  # label output sensitivity.
plt.title("5: regularization reduces one-point movement")  # title the plot.
plt.show()  # render the figure.
```
▶ What you'll see: the sensitivity curve falls as $\lambda$ increases.

*Why it's done this way: regularization increases the cost of moving the solution to satisfy one point, so it provides the algorithmic stability that supports generalization.*

### ✍️ Toy 1 · Leave-one-out refitting moves the mean

Stability starts by asking how much one training example can move the learner. Fit the mean, drop
one point, refit, and measure the swing.

```python
import numpy as np                              # arrays + numeric checks (safe to repeat).
import matplotlib.pyplot as plt                 # one picture per toy.

t1_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t1_train = np.array([1., 2., 4., 7., 8., 10.]) # six training values
print("training values:", t1_train.tolist())   # -> [1.0, 2.0, 4.0, 7.0, 8.0, 10.0]
t1_full = float(t1_train.mean())                # full-sample learner A(S)  # -> 5.333333333333333
print("full mean:", round(t1_full, 3))          # -> 5.333

plt.show()
```
▶ What you'll see: dropping the large point pulls the fitted mean from `5.333` down to `4.8`.

### ✍️ Toy 2 · Uniform stability is worst-case loss change

The theorem bounds loss movement, not just parameter movement. Compare two nearby constant
predictions on the same probe points and take the largest absolute loss change.

```python
import numpy as np                              # arrays + pointwise losses.

t2_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t2_probe = np.array([0., 0.25, 0.5, 0.75, 1.0, 1.25])  # six evaluation points
print("probe points:", t2_probe.tolist())       # -> [0.0, 0.25, 0.5, 0.75, 1.0, 1.25]
t2_a = 0.4                                      # original constant predictor  # -> 0.4
print("prediction a:", t2_a)                    # -> 0.4
t2_b = 0.7                                      # perturbed constant predictor # -> 0.7
print("prediction b:", t2_b)                    # -> 0.7
t2_loss_a = (t2_probe - t2_a) ** 2              # squared losses under a       # -> [0.16   0.0225 0.01   0.1225 0.36   0.7225]
print("loss under a:", np.round(t2_loss_a, 4).tolist())  # -> [0.16, 0.0225, 0.01, 0.1225, 0.36, 0.7225]
t2_loss_b = (t2_probe - t2_b) ** 2              # squared losses under b       # -> [0.49   0.2025 0.04   0.0025 0.09   0.3025]
print("loss under b:", np.round(t2_loss_b, 4).tolist())  # -> [0.49, 0.2025, 0.04, 0.0025, 0.09, 0.3025]
t2_change = np.abs(t2_loss_a - t2_loss_b)       # pointwise loss changes       # -> [0.33 0.18 0.03 0.12 0.27 0.42]
print("loss changes:", np.round(t2_change, 4).tolist())  # -> [0.33, 0.18, 0.03, 0.12, 0.27, 0.42]
t2_beta = float(t2_change.max())                # worst probe on this grid     # -> 0.42000000000000004
print("max loss change:", round(t2_beta, 4))    # -> 0.42
assert np.isclose(t2_beta, 0.42)                # beta is the largest printed loss change

plt.figure(figsize=(4.8, 2.8))
plt.plot(t2_probe, t2_change, marker="o", color="#9467bd")
plt.axhline(t2_beta, linestyle="--", color="black", label="max change")
plt.xlabel("probe z")
plt.ylabel("|loss_a - loss_b|")
plt.title("Toy 2 · stability lives in loss space")
plt.legend()
plt.show()
```
▶ What you'll see: the loss-change curve peaks at `0.42`, the toy uniform-stability value.

### ✍️ Toy 4 · Generalization gap compares train and test loss

### ✍️ Toy 5 · Regularization damps a one-point outlier

Ridge regression divides the data numerator by `sum(x²)+λ`. Increasing `λ` makes the same swapped
outlier move the fitted slope less.

```python
import numpy as np                              # arrays + ridge arithmetic.

t5_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t5_x = np.array([-2., -1., 0., 1., 2., 3.])    # one-dimensional features
print("features:", t5_x.tolist())              # -> [-2.0, -1.0, 0.0, 1.0, 2.0, 3.0]
t5_y = np.array([-3., -1., 0., 1., 2., 4.])   # original targets
print("targets:", t5_y.tolist())               # -> [-3.0, -1.0, 0.0, 1.0, 2.0, 4.0]
t5_y_swap = t5_y.copy()                        # one-point perturbed targets

t5_y_swap[-1] = 8.0                            # swap only the last label      # -> 8.0
print("swapped targets:", t5_y_swap.tolist())  # -> [-3.0, -1.0, 0.0, 1.0, 2.0, 8.0]
t5_lam = np.array([0.0, 1.0, 4.0, 10.0])       # regularization strengths
print("lambdas:", t5_lam.tolist())             # -> [0.0, 1.0, 4.0, 10.0]
t5_num = float(np.sum(t5_x * t5_y))            # original ridge numerator      # -> 24.0
print("original numerator:", round(t5_num, 3)) # -> 24.0
t5_num_swap = float(np.sum(t5_x * t5_y_swap))  # swapped ridge numerator       # -> 36.0
print("swapped numerator:", round(t5_num_swap, 3))  # -> 36.0
t5_den = np.sum(t5_x ** 2) + t5_lam            # denominator grows with λ      # -> [19. 20. 23. 29.]
print("denominators:", np.round(t5_den, 3).tolist())  # -> [19.0, 20.0, 23.0, 29.0]
t5_w = t5_num / t5_den                         # original ridge slopes        # -> [1.26315789 1.2        1.04347826 0.82758621]
print("original slopes:", np.round(t5_w, 3).tolist())  # -> [1.263, 1.2, 1.043, 0.828]
```

```python

import numpy as np  # load NumPy for arrays, simulations, closed-form fits, and assertions.
import matplotlib.pyplot as plt  # load Matplotlib for every diagnostic plot.
np.random.seed(0)  # make all examples reproducible in one shared kernel.

def safe_div(num, den):  # divide with a guard so examples never crash on empty evidence.
    return 0.0 if abs(float(den)) < 1e-12 else float(num / den)  # return 0 when the denominator is effectively zero.

def mean_fit(values):  # learning algorithm A(S): fit a constant predictor equal to the sample mean.
    values = np.asarray(values, dtype=float)  # convert inputs to a float array.
    return float(np.mean(values)) if values.size else 0.0  # guard empty arrays for completeness.

def squared_loss(z, pred):  # squared loss for a scalar target and scalar prediction.
    return float((z - pred) ** 2)  # return one nonnegative loss value.

def loo_means(values):  # compute leave-one-out mean fits for every possible deletion.
    values = np.asarray(values, dtype=float)  # normalize the input type.
    return np.array([mean_fit(np.delete(values, i)) for i in range(len(values))])  # refit after each deletion.

def ridge1d(x, y, lam):  # closed-form one-dimensional ridge regression through the origin.
    x = np.asarray(x, dtype=float)  # convert features to floats.
    y = np.asarray(y, dtype=float)  # convert targets to floats.
    denom = np.sum(x ** 2) + lam  # curvature plus regularization.
    return safe_div(np.sum(x * y), denom)  # compute the ridge slope safely.

def show_bar(labels, values, title, ylabel="value"):  # tiny bar helper used by several exercises.

    plt.ylabel(ylabel)  # label the vertical axis.
    plt.title(title)  # title the plot with the exercise id.
```

**Goal.** Estimate both one-point sensitivity and train-test gap for the same mean learner, because the theorem links small sensitivity to small gaps. We build it in 4 steps.


#### A3. Compare unregularized and regularized gradient training

**Goal.** Train a one-parameter linear model after one target is perturbed, because regularization reduces sensitivity during iterative optimization too. We build it in 5 steps.

```python
x_a3 = np.array([-2., -1., 0., 1., 2.])  # features.
y_a3 = np.array([-2., -1., 0., 1., 2.])  # clean linear targets.
y_bad_a3 = y_a3.copy()  # create perturbed targets.
y_bad_a3[-1] = 5.0  # replace one target by an outlier.
print("clean targets:", y_a3, "perturbed:", y_bad_a3)  # inspect the one-point change.
```
▶ What you'll see: only the last target differs between the two training sets.

```python
def train_slope_a3(x, y, lam, steps=300, eta=0.03):  # deterministic gradient descent for one slope.
    w_a3 = 0.0  # initialize slope at zero.
    for _ in range(steps):  # repeat full-batch updates.
        pred_a3 = w_a3 * x  # compute predictions.
        grad_a3 = -2 * np.mean(x * (y - pred_a3)) + 2 * lam * w_a3  # gradient of MSE plus L2 penalty.
        w_a3 -= eta * grad_a3  # descent update.
    return float(w_a3)  # return learned slope.

w0_a3 = train_slope_a3(x_a3, y_a3, 0.0)  # unregularized clean fit.
w0_bad_a3 = train_slope_a3(x_a3, y_bad_a3, 0.0)  # unregularized perturbed fit.
w1_a3 = train_slope_a3(x_a3, y_a3, 1.0)  # regularized clean fit.
w1_bad_a3 = train_slope_a3(x_a3, y_bad_a3, 1.0)  # regularized perturbed fit.
print("unreg slopes:", round(w0_a3, 3), round(w0_bad_a3, 3))  # inspect unregularized movement.
print("reg slopes:", round(w1_a3, 3), round(w1_bad_a3, 3))  # inspect regularized movement.
```

```python
move0_a3 = abs(w0_bad_a3 - w0_a3)  # unregularized sensitivity.
move1_a3 = abs(w1_bad_a3 - w1_a3)  # regularized sensitivity.
print("movements:", round(move0_a3, 3), round(move1_a3, 3))  # inspect movement reduction.
assert move1_a3 < move0_a3  # regularization stabilizes the iterative solution.
```

```python
probe_a3 = np.linspace(-2.5, 2.5, 100)  # probe inputs for plotting learned lines.
plt.figure(figsize=(4, 3))  # create a compact line plot.
plt.plot(probe_a3, w0_bad_a3 * probe_a3, label="unreg after perturb", color="crimson")  # show sensitive fit.
plt.plot(probe_a3, w1_bad_a3 * probe_a3, label="reg after perturb", color="seagreen")  # show stabilized fit.
plt.scatter(x_a3, y_bad_a3, color="black", s=25)  # show perturbed data.
plt.title("A3: regularized GD moves less")  # title the figure.
plt.legend()  # show line labels.
plt.show()  # display the plot.
```
▶ What you'll see: the regularized line bends less toward the outlier.

👀 Takeaway: regularization stabilizes both closed-form ERM and gradient-based training.

#### A5. Visualize a stability generalization bound
