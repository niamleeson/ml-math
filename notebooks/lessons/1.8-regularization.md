# 1.8 · Regularization in Learning Theory

Regularization replaces the discrete model-class ladder of structural risk minimization with a continuous penalty strength $\lambda$. In this lesson, you will build ridge-style penalties from scratch, watch coefficients shrink, compare $\ell_2$ and $\ell_1$ behavior, and see why $\lambda$ is the bias-variance dial.

### 1. From empirical risk to penalized risk

A learning algorithm usually minimizes training error. Regularization changes the target to **training error plus a complexity bill**: fit the data, but pay for large weights. For squared loss with an $\ell_2$ penalty, the objective is

$$J(w)=\lVert Xw-y\rVert^2+\lambda\lVert w\rVert^2=\sum_i (x_i^\top w-y_i)^2+\lambda\sum_j w_j^2.$$

The first term rewards fit; the second term rewards simplicity. The knob $\lambda$ is the exchange rate between them: $\lambda=0$ ignores simplicity, while larger $\lambda$ makes every unit of weight more expensive.

```python
X_w = np.array([[1., 1.], [1., 2.], [1., 3.]])  # Tiny design matrix: intercept column plus one feature.
y_w = np.array([1., 2., 2.])  # Three observed targets from the lesson content.
w_try_w = np.array([0.7, 0.6])  # A candidate line: prediction = 0.7 + 0.6*x.
pred_try_w = X_w @ w_try_w  # Compute fitted values for each training row.
print("predictions:", np.round(pred_try_w, 3))  # Inspect the model's fit before adding a penalty.
print("residuals:", np.round(pred_try_w - y_w, 3))  # Residuals are the training-error ingredients.
```
▶ What you'll see: a simple line's predictions and the residuals that squared loss will punish.

```python
fit_loss_w = float(np.sum((X_w @ w_try_w - y_w) ** 2))  # Sum of squared residuals.
norm_sq_w = float(np.sum(w_try_w ** 2))  # Squared L2 norm, the ridge complexity measure.
for lam_w in [0., 1., 10.]:  # Try three penalty strengths.
    obj_w = fit_loss_w + lam_w * norm_sq_w  # Penalized objective = fit cost + complexity cost.
    print(f"lambda={lam_w:>4}: fit={fit_loss_w:.3f}, penalty={lam_w*norm_sq_w:.3f}, J={obj_w:.3f}")  # Show the tradeoff.
```
▶ What you'll see: the same fit becomes less attractive as $\lambda$ makes weight size more expensive.

```python
lams_plot_w = np.array([0., 1., 2., 5., 10.])  # A small sweep of lambda values.
objectives_w = fit_loss_w + lams_plot_w * norm_sq_w  # Objective rises linearly for a fixed model.
plt.figure(figsize=(4.6, 3))  # Create a compact objective plot.
plt.plot(lams_plot_w, objectives_w, marker="o", color="purple")  # Draw the cost of this same w as lambda changes.
plt.xlabel("$\\lambda$"); plt.ylabel("penalized objective")  # Label the two pieces of the dial.
plt.title("1: same weights cost more as $\\lambda$ grows"); plt.show()  # Render the figure.
```
▶ What you'll see: when the weights are fixed, increasing $\lambda$ only raises their complexity bill.

*Why it's done this way: penalized risk keeps the optimization continuous — instead of jumping between model classes, calculus can tune a single objective with a smooth complexity price.*

### 2. Ridge has a closed form that shrinks weights

Ridge regression is least squares with an $\ell_2$ penalty. Its closed-form solution is

$$\hat w=(X^\top X+\lambda I)^{-1}X^\top y.$$

The added $\lambda I$ makes every diagonal entry of $X^\top X$ larger, so solving the linear system becomes more conservative. In plain language, the fit must now earn the right to use large weights.

```python
def ridge_w(X, y, lam):  # Closed-form ridge solver used throughout the walkthrough.
    I_w = np.eye(X.shape[1])  # Identity matrix matches the number of coefficients.
    return np.linalg.solve(X.T @ X + lam * I_w, X.T @ y)  # Solve (X^T X + lambda I) w = X^T y.

for lam_w in [0., 1., 10., 100.]:  # The exact lambda values cited in the lesson content.
    coef_w = ridge_w(X_w, y_w, lam_w)  # Fit the ridge solution for this lambda.
    print(f"lambda={lam_w:>5}: w={np.round(coef_w, 3)}, ||w||^2={np.sum(coef_w**2):.3f}")  # Inspect shrinkage.
```
▶ What you'll see: the lesson numbers $[0.667,0.500]$, $[0.375,0.583]$, $[0.196,0.409]$, and a norm near $0.011$ at $\lambda=100$.

```python
coef0_w = ridge_w(X_w, y_w, 0.)  # Plain least squares from the content.

coef100_w = ridge_w(X_w, y_w, 100.)  # Very strongly regularized solution from the content.
assert np.allclose(np.round(coef0_w, 3), [0.667, 0.500])  # Reproduce the cited lambda=0 coefficients.
assert np.allclose(np.round(coef1_w, 3), [0.375, 0.583])  # Reproduce the cited lambda=1 coefficients.
assert np.allclose(np.round(coef10_w, 3), [0.196, 0.409])  # Reproduce the cited lambda=10 coefficients.
assert round(float(np.sum(coef100_w ** 2)), 3) == 0.011  # Reproduce the cited lambda=100 norm collapse.
```
▶ What you'll see: no output if the cited numbers are reproduced exactly to three decimals.

```python

```
▶ What you'll see: the squared norm falls $0.694\to0.481\to0.206\to0.011$ as $\lambda$ grows.

*Why it's done this way: $\ell_2$ ridge shrinkage pulls weights continuously toward zero, trading a little training fit for a simpler, more stable solution.*

### 3. Coefficient paths show $\lambda$ as a bias-variance dial

The two ends of the dial are the two failure modes from the bias-complexity tradeoff. As $\lambda\to0$, ridge becomes unconstrained least squares: low bias but high variance. As $\lambda\to\infty$, weights are crushed toward zero: high bias but low variance. The useful model lives in the middle.

```python
rng_w = np.random.default_rng(1)  # Reproducible noisy data generator.

print("first y values:", np.round(y_path_w[:3], 3))  # Inspect the noisy targets.
```
▶ What you'll see: a tiny design matrix with three coefficients to shrink.

```python

coef_path_w = np.array([ridge_w(X_path_w, y_path_w, lam_w) for lam_w in lambda_grid_w])  # Fit ridge across the path.
print("lambda min coefficients:", np.round(coef_path_w[0], 3))  # Nearly unregularized fit.
```

▶ What you'll see: every coefficient is pulled smoothly toward zero as regularization strengthens.

*Why it's done this way: a coefficient path makes the bias-variance dial visible — small $\lambda$ allows flexible fits, while large $\lambda$ suppresses variance by flattening the model.*

### 4. The Lagrangian view: penalty equals a soft norm budget

Regularization can be read two ways. The penalized form minimizes $\lVert Xw-y\rVert^2+\lambda\lVert w\rVert^2$; the constrained form minimizes training error subject to $\lVert w\rVert^2\le c$. The Lagrangian idea says these are two views of the same tradeoff: $\lambda$ is the price of spending norm budget.

```python
w0_vals_w = np.linspace(-0.2, 1.2, 90)  # Candidate intercept weights.
w1_vals_w = np.linspace(-0.1, 1.0, 90)  # Candidate slope weights.
W0_w, W1_w = np.meshgrid(w0_vals_w, w1_vals_w)  # Grid for drawing objective contours.
loss_grid_w = np.zeros_like(W0_w)  # Allocate grid of squared training losses.
for i_w in range(W0_w.shape[0]):  # Loop over grid rows.
    for j_w in range(W0_w.shape[1]):  # Loop over grid columns.
        w_grid_w = np.array([W0_w[i_w, j_w], W1_w[i_w, j_w]])  # Candidate coefficient vector.
        loss_grid_w[i_w, j_w] = np.sum((X_w @ w_grid_w - y_w) ** 2)  # Training loss at this candidate.
print("grid loss min:", round(float(loss_grid_w.min()), 3))  # The grid approximates the least-squares bowl bottom.
```
▶ What you'll see: the loss surface is a bowl over possible intercept/slope pairs.

```python
ols_w = ridge_w(X_w, y_w, 0.)  # Unpenalized least-squares solution.
ridge_strong_w = ridge_w(X_w, y_w, 10.)  # Regularized solution with a smaller norm.
print("OLS norm^2:", round(float(np.sum(ols_w ** 2)), 3))  # Complexity of unpenalized fit.
print("ridge λ=10 norm^2:", round(float(np.sum(ridge_strong_w ** 2)), 3))  # Complexity after shrinking.
assert round(float(np.sum(ols_w ** 2)), 3) == 0.694  # Reproduce the cited OLS squared norm.
assert round(float(np.sum(ridge_strong_w ** 2)), 3) == 0.206  # Reproduce the cited lambda=10 squared norm.
```
▶ What you'll see: the regularized point spends far less norm budget than the unpenalized point.

```python
plt.figure(figsize=(4.8, 3.8))  # Create a contour plot of fit plus norm budget.
plt.contour(W0_w, W1_w, loss_grid_w, levels=12, cmap="Blues")  # Draw squared-error contours.
theta_w = np.linspace(0, 2 * np.pi, 200)  # Angles for a norm-budget circle.
budget_w = np.sqrt(np.sum(ridge_strong_w ** 2))  # Use the ridge norm as the budget radius.
plt.plot(budget_w * np.cos(theta_w), budget_w * np.sin(theta_w), color="seagreen", label="norm budget")  # Draw the feasible norm circle.
plt.scatter([ols_w[0], ridge_strong_w[0]], [ols_w[1], ridge_strong_w[1]], color=["crimson", "black"], zorder=3)  # Mark both solutions.
plt.text(ols_w[0], ols_w[1], " OLS"); plt.text(ridge_strong_w[0], ridge_strong_w[1], " ridge")  # Label points.
plt.xlabel("intercept"); plt.ylabel("slope"); plt.title("4: penalty as soft norm budget"); plt.legend(); plt.show()  # Render.
```
▶ What you'll see: ridge chooses a point inside a smaller norm budget instead of the unconstrained bowl minimum.

*Why it's done this way: the constrained view explains what $\lambda$ buys — a larger price forces the optimizer to spend less weight norm, just like a tighter complexity budget.*

### 5. $\ell_1$ penalties create sparsity differently from $\ell_2$

Ridge's $\ell_2$ penalty shrinks weights smoothly, but it usually does not make them exactly zero. Lasso's $\ell_1$ penalty uses $\lambda\lVert w\rVert_1=\lambda\sum_j |w_j|$, whose sharp corner at zero can set weak coefficients exactly to zero. That sparsity is useful when we believe only a few features should survive.

```python
def soft_threshold_w(z, alpha):  # One-dimensional lasso solution for objective (w-z)^2 + alpha |w|.
    return np.sign(z) * max(abs(z) - alpha / 2, 0.0)  # Shrink toward zero and clip exactly at zero.

z_vals_w = np.array([-2., -0.4, 0.2, 1.5])  # Unregularized one-feature estimates.
alpha_w = 1.0  # L1 penalty strength in this tiny separable demo.
l1_vals_w = np.array([soft_threshold_w(z_w, alpha_w) for z_w in z_vals_w])  # Apply the lasso shrinkage rule.
l2_vals_w = z_vals_w / (1 + alpha_w)  # Comparable ridge-like shrinkage for (w-z)^2 + alpha w^2.
print("unregularized z:", z_vals_w)  # Inspect original coefficients.
print("L1 soft-threshold:", l1_vals_w)  # Inspect sparse coefficients.
print("L2 shrinkage:", l2_vals_w)  # Inspect smooth shrinkage.
```
▶ What you'll see: small L1 coefficients become exactly zero, while L2 keeps nonzero remnants.

```python
assert np.allclose(l1_vals_w, [-1.5, 0.0, 0.0, 1.0])  # Verify the soft-threshold arithmetic.
assert np.allclose(l2_vals_w, [-1.0, -0.2, 0.1, 0.75])  # Verify the ridge-like shrinkage arithmetic.
plt.figure(figsize=(4.8, 3))  # Create a side-by-side coefficient comparison.
idx_w = np.arange(len(z_vals_w))  # Bar positions.
plt.bar(idx_w - 0.18, l1_vals_w, width=0.36, label="$\\ell_1$", color="darkorange")  # L1 bars.
plt.bar(idx_w + 0.18, l2_vals_w, width=0.36, label="$\\ell_2$", color="steelblue")  # L2 bars.
plt.axhline(0, color="black", linewidth=0.7); plt.xticks(idx_w, ["w0", "w1", "w2", "w3"])  # Add zero reference and names.
plt.title("5: $\\ell_1$ sparsity vs $\\ell_2$ shrinkage"); plt.legend(); plt.show()  # Display.
```
▶ What you'll see: $\ell_1$ deletes weak coefficients, whereas $\ell_2$ merely makes them smaller.

*Why it's done this way: $\ell_1$ is the right penalty when feature selection matters; $\ell_2$ is the right default when smooth, stable shrinkage is the goal.*

### 6. Regularization makes a learner less sensitive

The next lesson studies algorithmic stability, and regularization is the bridge. If a single training point changes the fitted model a lot, the algorithm is clinging to that point; a larger $\lambda$ resists that swing. On tiny data we can measure this with leave-one-out fits.

```python
lams_stab_w = np.array([0., 1., 10.])  # Compare no, mild, and strong regularization.
full_fits_w = np.array([ridge_w(X_w, y_w, lam_w) for lam_w in lams_stab_w])  # Fit on all three points.
loo_max_w = []  # Store the largest leave-one-out coefficient movement for each lambda.
for lam_w, full_w in zip(lams_stab_w, full_fits_w):  # Loop over regularization strengths.
    swings_w = []  # Store movements from dropping each point.
    for drop_w in range(len(y_w)):  # Drop one row at a time.
        keep_w = np.arange(len(y_w)) != drop_w  # Boolean mask for the remaining rows.
        loo_w = ridge_w(X_w[keep_w], y_w[keep_w], lam_w)  # Refit after dropping one point.
        swings_w.append(np.linalg.norm(loo_w - full_w))  # Measure coefficient movement.
    loo_max_w.append(max(swings_w))  # Keep the worst case swing.
    print(f"lambda={lam_w:>4}: max leave-one-out swing={max(swings_w):.3f}")  # Inspect stability.
```
▶ What you'll see: larger $\lambda$ makes the fitted coefficients less sensitive to deleting one point.

```python
assert loo_max_w[2] < loo_max_w[0]  # Strong regularization is more stable than no regularization here.
plt.figure(figsize=(4.6, 3))  # Create a stability plot.
plt.plot(lams_stab_w + 1, loo_max_w, marker="o", color="crimson")  # Plot sensitivity against lambda+1.
plt.xlabel("$\\lambda$ (plotted as $\\lambda+1$)"); plt.ylabel("max coefficient swing")  # Label axes.
plt.title("6: regularization reduces leave-one-out sensitivity"); plt.show()  # Render.
```
▶ What you'll see: the sensitivity curve drops when the penalty is strong.

*Why it's done this way: regularized ERM generalizes partly because a penalty makes the solution less dependent on any single example; that is the stability intuition behind lesson 1.9.*

```python
# !pip install numpy matplotlib  # Colab already has these; uncomment only if your runtime is missing them.
import numpy as np  # Import NumPy for arrays, linear algebra, and deterministic simulations.
import matplotlib.pyplot as plt  # Import Matplotlib for coefficient paths, contours, and diagnostics.
np.random.seed(0)  # Fix the global seed so every example is reproducible.

def ridge_closed_form(X, y, lam, penalize_intercept=True):  # Solve ridge regression with an optional intercept exemption.
    X = np.asarray(X, dtype=float)  # Convert the design matrix to float for linear algebra.
    y = np.asarray(y, dtype=float)  # Convert the target vector to float for linear algebra.
    penalty = np.eye(X.shape[1])  # Start with an identity penalty on every coefficient.
    if not penalize_intercept:  # Check whether the first column is an intercept that should not shrink.
        penalty[0, 0] = 0.0  # Leave the intercept unpenalized, the usual modeling convention.
    return np.linalg.solve(X.T @ X + lam * penalty, X.T @ y)  # Solve the ridge normal equations.

def squared_loss(X, y, w):  # Compute sum of squared residuals for a linear model.
    residuals = np.asarray(X, dtype=float) @ np.asarray(w, dtype=float) - np.asarray(y, dtype=float)  # Prediction minus target.
    return float(np.sum(residuals ** 2))  # Return the scalar squared-error sum.

def standardize_features(X):  # Standardize non-intercept columns and guard against zero variance.
    X = np.asarray(X, dtype=float)  # Convert to a float array for safe arithmetic.
    means = X.mean(axis=0)  # Compute column means.
    scales = X.std(axis=0)  # Compute column standard deviations.
    scales = np.where(scales == 0, 1.0, scales)  # Guard division by zero for constant columns.
    return (X - means) / scales, means, scales  # Return standardized values and reusable parameters.

def plot_line_data(x, y, w, title):  # Plot a one-feature line fit for quick diagnostics.
    grid = np.linspace(float(np.min(x)), float(np.max(x)), 100)  # Build a smooth x-grid.
    Xg = np.column_stack([np.ones_like(grid), grid])  # Add an intercept column for predictions.
    plt.figure(figsize=(4.5, 3))  # Start a compact figure.
    plt.scatter(x, y, color="black", label="data")  # Draw observed points.
    plt.plot(grid, Xg @ w, color="seagreen", label="fit")  # Draw the fitted line.
    plt.title(title)  # Add the example-specific title.
    plt.legend()  # Show labels.
    plt.show()  # Display the figure.
```

#### A5. Compare regularized and unregularized extrapolation

**Goal.** Inspect predictions outside the training range, because overfit coefficients often reveal themselves as unstable extrapolation. We build it in 3 steps.

```python
rng_a5 = np.random.default_rng(5)  # Reproducible data.
x_a5 = np.linspace(-1, 1, 12)  # Training inputs in a narrow range.
y_a5 = 0.5 + x_a5 - 0.3 * x_a5 ** 2 + rng_a5.normal(0, 0.12, size=x_a5.size)  # Noisy quadratic signal.
X_a5 = np.column_stack([x_a5 ** k_a5 for k_a5 in range(10)])  # High-degree polynomial features.
grid_a5 = np.linspace(-2, 2, 200)  # Wider range for extrapolation.
Xg_a5 = np.column_stack([grid_a5 ** k_a5 for k_a5 in range(10)])  # Grid features.
print("training range:", (float(x_a5.min()), float(x_a5.max())))  # Inspect the observed range.
```
▶ What you'll see: the model is trained only between -1 and 1 but evaluated more widely.

```python
w_lo_a5 = ridge_closed_form(X_a5, y_a5, 0.0, penalize_intercept=False)  # Nearly flexible/unregularized fit.
w_hi_a5 = ridge_closed_form(X_a5, y_a5, 10.0, penalize_intercept=False)  # Regularized fit.
pred_lo_a5 = Xg_a5 @ w_lo_a5  # Predict across the wider grid.
pred_hi_a5 = Xg_a5 @ w_hi_a5  # Predict across the wider grid.
print("unregularized norm:", round(float(np.linalg.norm(w_lo_a5)), 3))  # Inspect coefficient size.

assert np.linalg.norm(w_hi_a5) < np.linalg.norm(w_lo_a5)  # Ridge shrinks the coefficient vector.
```
▶ What you'll see: the regularized polynomial has a much smaller coefficient norm.

