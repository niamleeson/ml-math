# 12.11 — Community Detection

Community detection finds groups of nodes whose connections are stronger than a graph would expect by chance. In this lesson, you will build modularity, conductance, spectral splitting, label propagation, and a tiny Louvain-style greedy optimizer from scratch with NumPy, so every community assignment is inspectable rather than a black-box library call.

### 1. A graph community is not just a dense blob

A graph community is a set of nodes with many internal edges compared with its boundary. We start with the canonical four-node toy graph: nodes 0, 1, and 2 form a triangle, and node 3 is a tail attached to node 2. This is small enough to print fully, but already shows the key question: should node 2 stay with the triangle or pair with the tail?

```python
A_w = np.array([[0, 1, 1, 0],
                [1, 0, 1, 0],
                [1, 1, 0, 1],
                [0, 0, 1, 0]], dtype=float)  # undirected triangle plus tail.
d_w = A_w.sum(axis=1)  # degree of each node.
m_w = A_w.sum() / 2  # number of undirected edges.
print("adjacency:\n", A_w.astype(int))
print("degrees:", d_w.astype(int), "edges m:", int(m_w))
assert int(m_w) == 4
```
▶ What you'll see: four undirected edges; node 2 has the largest degree because it connects the triangle to the tail.


*Why it's done this way:* A matrix makes every later formula explicit: degrees are row sums, edge counts are half the adjacency sum, and a community is a label vector over rows. The fixed layout is not the algorithm; it is only a visual debugging aid so we can see whether labels match graph structure.

### 2. Modularity subtracts the degree-preserving null model

Modularity asks whether a partition has more within-community edges than expected if degrees were preserved but edges were otherwise random. The formula is

$$Q=\frac{1}{2m}\sum_{ij}\left(A_{ij}-\frac{d_i d_j}{2m}\right)\mathbf{1}[c_i=c_j].$$

The subtraction matters: high-degree nodes naturally create many edges, so raw internal edge counts can falsely reward groups that merely contain hubs. The term $d_i d_j/(2m)$ is the expected edge weight under the configuration-model null.

```python
def modularity_w(A, labels):
    labels = np.asarray(labels)
    deg = A.sum(axis=1)
    two_m = A.sum()
    same = labels[:, None] == labels[None, :]
    expected = np.outer(deg, deg) / two_m
    return float(np.sum((A - expected) * same) / two_m)

labels_012_3_w = np.array([0, 0, 0, 1])  # {0,1,2}|{3}.
labels_01_23_w = np.array([0, 0, 1, 1])  # {0,1}|{2,3}.
q1_w = modularity_w(A_w, labels_012_3_w)
q2_w = modularity_w(A_w, labels_01_23_w)
print("Q({0,1,2}|{3}) =", q1_w)
print("Q({0,1}|{2,3}) =", q2_w)
assert q1_w == -0.03125 and q2_w > q1_w
```
▶ What you'll see: the triangle-plus-singleton partition has modularity −0.03125, while the split {0,1}|{2,3} is larger on this toy graph.

```python
expected_w = np.outer(d_w, d_w) / (2 * m_w)  # expected edges from degree preservation.
print("expected edge matrix:\n", np.round(expected_w, 3))
plt.figure(figsize=(4, 3))
plt.imshow(A_w - expected_w, cmap="coolwarm", vmin=-1, vmax=1)
plt.colorbar(label="A_ij - expected")
plt.title("2: modularity residuals"); plt.xlabel("j"); plt.ylabel("i"); plt.show()
```
▶ What you'll see: blue/red residuals show where the observed graph has fewer/more edges than the degree-preserving null model expects.

*Why it's done this way:* Modularity is not saying “dense is good.” It says “denser than a degree-aware random graph is good.” Dividing by $2m$ normalizes over directed matrix entries of an undirected graph, and the same-label indicator selects only residuals inside proposed communities.

### 3. Conductance measures how leaky a proposed group is

Conductance scores a set $S$ by its boundary cut divided by the smaller side volume:

$$\phi(S)=\frac{\operatorname{cut}(S,\bar S)}{\min(\operatorname{vol}(S),\operatorname{vol}(\bar S))}.$$

A dense group with many outside edges can still be bad because information, random walks, or influence easily leak across its boundary.

```python
def conductance_w(A, S):
    S = np.asarray(S, dtype=int)
    in_S = np.zeros(A.shape[0], dtype=bool)
    in_S[S] = True
    cut = float(A[np.ix_(in_S, ~in_S)].sum())
    deg = A.sum(axis=1)
    vol_S = float(deg[in_S].sum())
    vol_T = float(deg[~in_S].sum())
    denom = min(vol_S, vol_T)
    return cut, vol_S, cut / denom if denom > 0 else 0.0

cut_w, vol_w, phi_w = conductance_w(A_w, [0, 1])
print("S={0,1}: cut=", int(cut_w), "volume=", int(vol_w), "conductance=", round(phi_w, 3))
assert int(cut_w) == 2 and int(vol_w) == 4 and round(phi_w, 3) == 0.500
```
▶ What you'll see: the set {0,1} has two edges leaving it, volume four, and conductance 0.500.

```python
sets_w = [[0, 1], [0, 1, 2], [2, 3]]
phis_w = [conductance_w(A_w, s_w)[2] for s_w in sets_w]
print("conductances:", [round(x_w, 3) for x_w in phis_w])
plt.figure(figsize=(4.8, 3))
plt.bar(["{0,1}", "{0,1,2}", "{2,3}"], phis_w, color="darkorange")
plt.ylabel("conductance (lower is tighter)"); plt.title("3: boundary leakage by candidate set"); plt.show()
```
▶ What you'll see: different candidate sets leak at different rates; lower conductance means a cleaner boundary.

*Why it's done this way:* The numerator counts boundary edges, while the volume denominator prevents tiny sets from looking perfect just because they have few possible exits. Conductance complements modularity: modularity is a global partition objective; conductance is a local set-quality diagnostic.

### 4. Label propagation copies local consensus

Label propagation starts each node with its own label, then repeatedly replaces a node’s label with the most common label in its closed neighborhood (neighbors plus itself). It is fast because it uses only local votes, but it is unstable because ties need a rule. We will make the tie rule explicit: choose the smallest tied label.

```python
A_lp_w = np.array([[0, 1, 1, 0],
                   [1, 0, 1, 1],
                   [1, 1, 0, 0],
                   [0, 1, 0, 0]], dtype=float)  # triangle with a tail on node 1.
labels0_w = np.array([0, 1, 2, 3])
print("initial labels:", labels0_w)
print("LP adjacency:\n", A_lp_w.astype(int))
```
▶ What you'll see: every node begins as its own one-node community.

```python
def one_label_step_w(A, labels):
    new = labels.copy()
    for i in range(A.shape[0]):
        neigh = np.where(A[i] > 0)[0]
        votes = labels[np.r_[i, neigh]]
        vals, counts = np.unique(votes, return_counts=True)
        new[i] = vals[np.argmax(counts)]  # np.unique sorts labels, so ties choose the smallest label.
    return new

labels1_w = one_label_step_w(A_lp_w, labels0_w)
print("after one step:", labels1_w)
assert np.array_equal(labels1_w, np.array([0, 0, 0, 1]))
```
▶ What you'll see: one synchronous label-propagation step changes labels to `[0, 0, 0, 1]`.

```python
plt.figure(figsize=(4.2, 3.4))
for i_w in range(4):
    for j_w in range(i_w + 1, 4):
        if A_lp_w[i_w, j_w] == 1:
            plt.plot([pos_w[i_w, 0], pos_w[j_w, 0]], [pos_w[i_w, 1], pos_w[j_w, 1]], color="gray", linewidth=2)
plt.scatter(pos_w[:, 0], pos_w[:, 1], s=220, c=labels1_w, cmap="tab10", edgecolor="black")
for i_w, (x_w, y_w) in enumerate(pos_w):
    plt.text(x_w, y_w, str(i_w), ha="center", va="center", color="white", weight="bold")
plt.axis("off"); plt.title("4: labels after one propagation step"); plt.show()
```
▶ What you'll see: nodes 0, 1, and 2 share label 0, while the tail keeps a different copied label.

*Why it's done this way:* Label propagation optimizes no smooth global objective here; it is a local majority heuristic. Including the node itself gives the current label a vote, which makes the update less jumpy, but ties still remain — and a different deterministic or random tie-breaker can change the final communities.

### 5. Spectral detection relaxes a discrete split into an eigenvector

A two-way community split can be encoded with signs: positive nodes on one side, negative nodes on the other. Searching all sign vectors is combinatorial, so spectral methods relax the signs to real numbers and solve an eigenvector problem. For the graph Laplacian $L=D-A$, the Fiedler vector (second-smallest eigenvector) gives a smooth direction whose signs often reveal two groups.

```python
L_w = np.diag(d_w) - A_w  # combinatorial graph Laplacian.
evals_w, evecs_w = np.linalg.eigh(L_w)  # symmetric eigen-decomposition from scratch in NumPy.
fiedler_w = evecs_w[:, 1]
spectral_labels_w = (fiedler_w >= 0).astype(int)
print("L eigenvalues:", np.round(evals_w, 3))
print("Fiedler vector:", np.round(fiedler_w, 3))
print("spectral sign labels:", spectral_labels_w)
assert len(np.unique(spectral_labels_w)) == 2
```
▶ What you'll see: the second eigenvector has both signs, so it produces two nonempty groups.

```python
plt.figure(figsize=(4.2, 3.4))
for i_w in range(4):
    for j_w in range(i_w + 1, 4):
        if A_w[i_w, j_w] == 1:
            plt.plot([pos_w[i_w, 0], pos_w[j_w, 0]], [pos_w[i_w, 1], pos_w[j_w, 1]], color="gray", linewidth=2)
plt.scatter(pos_w[:, 0], pos_w[:, 1], s=260, c=fiedler_w, cmap="coolwarm", edgecolor="black")
for i_w, (x_w, y_w) in enumerate(pos_w):
    plt.text(x_w, y_w, str(i_w), ha="center", va="center", color="white", weight="bold")
plt.colorbar(label="Fiedler coordinate")
plt.axis("off"); plt.title("5: spectral coordinates separate signs"); plt.show()
```
▶ What you'll see: nodes with similar Fiedler coordinates are drawn with similar colors; the sign boundary suggests a split.

*Why it's done this way:* The Laplacian quadratic $x^T L x=\sum_{(i,j)}(x_i-x_j)^2$ is small when connected nodes get similar coordinates. The second eigenvector is the lowest-energy nonconstant coordinate, so thresholding it turns a continuous smooth graph signal back into a discrete community proposal.

### 6. Louvain-style greedy moves climb modularity locally

The Louvain idea is to start with every node alone, repeatedly move a node into a neighboring community if modularity increases, and then coarsen communities. We will implement only the first greedy phase so the mechanics are visible: try every neighbor label, compute modularity, and keep the best improvement.

```python
def greedy_modularity_phase_w(A, labels):
    labels = labels.copy()
    improved = True
    history = []
    while improved:
        improved = False
        for node in range(A.shape[0]):
            current = labels[node]
            best_labels = labels.copy()
            best_q = modularity_w(A, labels)
            candidates = np.unique(labels[A[node] > 0])
            for cand in candidates:
                trial = labels.copy()
                trial[node] = cand
                q = modularity_w(A, trial)
                if q > best_q + 1e-12:
                    best_q, best_labels = q, trial
            if not np.array_equal(best_labels, labels):
                history.append((node, current, best_labels[node], best_q))
                labels = best_labels
                improved = True
    return labels, history

start_w = np.arange(4)
greedy_labels_w, history_w = greedy_modularity_phase_w(A_w, start_w)
print("moves:", history_w)
print("final labels:", greedy_labels_w, "Q=", round(modularity_w(A_w, greedy_labels_w), 3))
assert modularity_w(A_w, greedy_labels_w) >= modularity_w(A_w, start_w)
```
▶ What you'll see: each accepted move increases modularity until no single node move helps.

```python
plt.figure(figsize=(4.2, 3.4))
for i_w in range(4):
    for j_w in range(i_w + 1, 4):
        if A_w[i_w, j_w] == 1:
            plt.plot([pos_w[i_w, 0], pos_w[j_w, 0]], [pos_w[i_w, 1], pos_w[j_w, 1]], color="gray", linewidth=2)
plt.scatter(pos_w[:, 0], pos_w[:, 1], s=220, c=greedy_labels_w, cmap="tab10", edgecolor="black")
for i_w, (x_w, y_w) in enumerate(pos_w):
    plt.text(x_w, y_w, str(i_w), ha="center", va="center", color="white", weight="bold")
plt.axis("off"); plt.title("6: greedy modularity phase result"); plt.show()
```
▶ What you'll see: the final colors are the best partition reached by local modularity-improving moves.

*Why it's done this way:* Louvain is greedy because exact modularity maximization is hard. Checking candidate neighbor communities keeps the search cheap, and accepting only positive $\Delta Q$ gives a monotone hill-climb — powerful, but still dependent on node order and vulnerable to local optima.

### Basic 7 — Compare two modularity partitions

```python
print("nodes:", n_a2, "edges:", int(A_a2.sum() / 2)) # Inspect graph size.
```

```python
def random_label_run_a4(A, seed): # Define one randomized label-propagation run.
    rng_a4 = np.random.default_rng(seed) # Local random generator.
    labels_a4 = np.arange(A.shape[0]) # Start singleton labels.
    for _ in range(5): # Run a few synchronous rounds.
        new_a4 = labels_a4.copy() # Prepare updates.
        for i_a4 in range(A.shape[0]): # Update each node.
            neigh_a4 = np.where(A[i_a4] > 0)[0] # Neighbor list.
            vals_a4, counts_a4 = np.unique(labels_a4[neigh_a4], return_counts=True) # Vote counts.
            tied_a4 = vals_a4[counts_a4 == counts_a4.max()] # Labels tied for first.
            new_a4[i_a4] = rng_a4.choice(tied_a4) # Randomly break ties.
        labels_a4 = new_a4 # Synchronous assignment.
    return labels_a4 # Return final labels.
print("random LP helper ready") # Confirm helper.
```
