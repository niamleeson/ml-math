# 21.8 — SAT Solvers

SAT solvers industrialize the truth-table idea from propositional logic: instead of trying every Boolean assignment blindly, they represent requirements as clauses, propagate forced choices, learn from conflicts, and backtrack only when a branch is impossible. In this lesson, you will build the core mechanics from scratch in pure Python and NumPy, then use them to encode small constraint problems as SAT.

### 1. CNF and signed literals

SAT solvers normally consume **CNF**: an AND of clauses, where each clause is an OR of literals. We encode `x1` as `1`, `¬x1` as `-1`, and a formula such as $(x_1\lor \neg x_2)\land(\neg x_1\lor x_3)$ as a list of lists. That looks plain, but it is exactly what makes local clause checks cheap.

```python
cnf_w = [[1, -2], [-1, 3], [2, 3]]  # (x1 or not x2) and (not x1 or x3) and (x2 or x3).
assignment_w = {1: True, 2: False}  # x3 is not assigned yet.
print("CNF:", cnf_w)
print("partial assignment:", assignment_w)
```
▶ What you'll see: clauses are ordinary Python lists of signed integers, and assignments can be partial.

```python
def lit_value_w(lit, assignment):
    val = assignment.get(abs(lit))
    if val is None:
        return None
    return val if lit > 0 else (not val)

def clause_state_w(clause, assignment):
    vals = [lit_value_w(lit, assignment) for lit in clause]
    if True in vals:
        return "satisfied"
    if None in vals:
        return "open"
    return "conflict"

print([clause_state_w(clause, assignment_w) for clause in cnf_w])
```
▶ What you'll see: each clause is satisfied, open, or conflicting under the partial assignment.

```python
state_order_w1 = {"conflict": -1, "open": 0, "satisfied": 1}
state_scores_w1 = np.array([[state_order_w1[clause_state_w(clause, assignment_w)] for clause in cnf_w]])
plt.figure(figsize=(4.5, 1.8))
plt.imshow(state_scores_w1, cmap="RdYlGn", vmin=-1, vmax=1, aspect="auto")
plt.yticks([0], ["current assignment"])
plt.xticks(range(len(cnf_w)), [f"C{i}" for i in range(len(cnf_w))])
plt.colorbar(ticks=[-1, 0, 1], label="clause state")
plt.title("1: clause states under a partial assignment")
plt.show()
```
▶ What you'll see: a compact clause-by-clause heatmap separates satisfied, open, and conflicting clauses.

*Why it's done this way:* CNF is useful because a clause has a tiny local truth test. DPLL and CDCL repeatedly exploit that test instead of reasoning about the whole formula at once.

### 2. Unit propagation

A **unit clause** has exactly one unassigned literal and all other literals already false. That last literal is forced: any satisfying assignment must make it true. Propagation repeatedly applies those forced moves until no unit clause remains or a contradiction appears.

```python
cnf_unit_w = [[1], [-1, 2], [-2, 3], [-3, 4]]  # x1 forces x2, then x3, then x4.
assign_unit_w = {}
print("formula:", cnf_unit_w)
```
▶ What you'll see: the first one-literal clause starts a chain reaction.

```python
def unit_literal_w(cnf, assignment):
    for clause in cnf:
        vals = [lit_value_w(lit, assignment) for lit in clause]
        if True in vals:
            continue
        unknown = [lit for lit, val in zip(clause, vals) if val is None]
        if len(unknown) == 0:
            return 0
        if len(unknown) == 1:
            return unknown[0]
    return None

trail_unit_w = []
while True:
    lit_w = unit_literal_w(cnf_unit_w, assign_unit_w)
    if lit_w in (None, 0):
        break
    assign_unit_w[abs(lit_w)] = lit_w > 0
    trail_unit_w.append(lit_w)
print("forced trail:", trail_unit_w)
print("assignment:", assign_unit_w)
assert assign_unit_w == {1: True, 2: True, 3: True, 4: True}
```
▶ What you'll see: setting `x1` creates the next unit, so all four variables are forced without branching.

```python
plt.figure(figsize=(4.5, 2.8))
plt.step(range(1, len(trail_unit_w) + 1), [abs(lit) for lit in trail_unit_w], where="mid", marker="o", color="teal")
plt.xticks(range(1, len(trail_unit_w) + 1))
plt.yticks([abs(lit) for lit in trail_unit_w], [f"x{abs(lit)}" for lit in trail_unit_w])
plt.xlabel("propagation step")
plt.ylabel("forced variable")
plt.title("2: unit-propagation chain")
plt.show()
```
▶ What you'll see: each propagation step forces the next variable in the implication chain.

*Why it's done this way:* propagation is exact pruning. If logic already determines a value, branching on both values would waste half the search and delay contradictions.

### 3. Pure literals

A literal is **pure** when its variable appears with only one polarity in all active clauses. If `x4` appears only as `x4`, then setting `x4=True` can satisfy clauses but cannot falsify any clause that wanted `¬x4`, because no such active clause exists.

```python
cnf_pure_w = [[1, 2], [-1, 3], [2, 4], [3, 4]]  # x2, x3, x4 appear only positively.
print("all literals:", [lit for clause in cnf_pure_w for lit in clause])
```
▶ What you'll see: variable `x1` has both signs; the others have a single sign.

```python
def pure_literals_w(cnf, assignment):
    signs = defaultdict(set)
    for clause in cnf:
        if clause_state_w(clause, assignment) == "satisfied":
            continue
        for lit in clause:
            if abs(lit) not in assignment:
                signs[abs(lit)].add(1 if lit > 0 else -1)
    return [var * next(iter(s)) for var, s in signs.items() if len(s) == 1]

pures_w = pure_literals_w(cnf_pure_w, {})
print("pure literals:", pures_w)
assert set(pures_w) == {2, 3, 4}
```
▶ What you'll see: the solver can safely assign the pure positive literals to `True`.

```python
vars_pure_w = sorted({abs(lit) for clause in cnf_pure_w for lit in clause})
pos_counts_w = [sum(lit == v for clause in cnf_pure_w for lit in clause) for v in vars_pure_w]
neg_counts_w = [sum(lit == -v for clause in cnf_pure_w for lit in clause) for v in vars_pure_w]
x_pure_w = np.arange(len(vars_pure_w))
plt.figure(figsize=(4.8, 3))
plt.bar(x_pure_w - 0.18, pos_counts_w, width=0.36, label="positive", color="seagreen")
plt.bar(x_pure_w + 0.18, neg_counts_w, width=0.36, label="negative", color="indianred")
plt.xticks(x_pure_w, [f"x{v}" for v in vars_pure_w])
plt.ylabel("appearances")
plt.title("3: polarity counts reveal pure literals")
plt.legend()
plt.show()
```
▶ What you'll see: pure variables have bars on only one side of the polarity count chart.

*Why it's done this way:* pure-literal elimination is a one-way simplification. It removes clauses that are easy to satisfy while never creating a new demand for the opposite sign.

### 4. DPLL backtracking search

DPLL combines propagation with search: simplify first, stop if all clauses are satisfied, stop if one clause conflicts, otherwise branch on an unassigned variable. It is still complete, but it avoids exploring branches that propagation has already proved impossible.

```python
def vars_w(cnf):
    return sorted({abs(lit) for clause in cnf for lit in clause})

def formula_state_w(cnf, assignment):
    states = [clause_state_w(c, assignment) for c in cnf]
    if "conflict" in states:
        return "conflict"
    if all(s == "satisfied" for s in states):
        return "satisfied"
    return "open"

def propagate_w(cnf, assignment):
    assignment = dict(assignment)
    trail = []
    while True:
        lit = unit_literal_w(cnf, assignment)
        if lit == 0:
            return assignment, trail, True
        if lit is None:
            return assignment, trail, False
        assignment[abs(lit)] = lit > 0
        trail.append(lit)

cnf_dpll_w = [[1, 2], [-1, 3], [-2, 3], [-3, 4], [-4, 5]]
print("variables:", vars_w(cnf_dpll_w))
```
▶ What you'll see: a small formula whose branches will be simplified by unit propagation.

```python
edges_w = []
def dpll_w(cnf, assignment=None):
    assignment = {} if assignment is None else dict(assignment)
    assignment, trail, conflict = propagate_w(cnf, assignment)
    if conflict or formula_state_w(cnf, assignment) == "conflict":
        return False, assignment
    if formula_state_w(cnf, assignment) == "satisfied":
        return True, assignment
    var = next(v for v in vars_w(cnf) if v not in assignment)
    parent = tuple(sorted(assignment.items()))
    for val in [True, False]:
        child = dict(assignment); child[var] = val
        edges_w.append((parent, tuple(sorted(child.items())), f"x{var}={val}"))
        ok, sol = dpll_w(cnf, child)
        if ok:
            return True, sol
    return False, assignment

sat_w, sol_w = dpll_w(cnf_dpll_w)
print("SAT?", sat_w, "solution:", sol_w)
assert sat_w and all(clause_state_w(c, sol_w) == "satisfied" for c in cnf_dpll_w)
```
▶ What you'll see: DPLL returns a satisfying assignment and records the decision edges it explored.

```python
vars_dpll_w = vars_w(cnf_dpll_w)
plt.figure(figsize=(5, 2.8))
plt.bar([f"x{v}" for v in vars_dpll_w], [1 if sol_w.get(v, False) else 0 for v in vars_dpll_w], color="teal")
plt.yticks([0, 1], ["False", "True"])
plt.title("4: satisfying assignment found by DPLL")
plt.xlabel("variable")
plt.show()
```
▶ What you'll see: the final model is a concrete Boolean value for each variable.

*Why it's done this way:* DPLL guesses only when the formula has no forced move. That keeps the branching tree focused on genuine uncertainty rather than obvious consequences.

### 5. The DPLL search tree

A DPLL tree contains decision edges, not every variable assignment. Propagation happens between those edges, so one node can represent several forced assignments. Drawing the tree makes it clear why pruning is the whole point.

```python
nodes_w = sorted({e[0] for e in edges_w} | {e[1] for e in edges_w}, key=lambda n: (len(n), n))
pos_w = {}
for depth_w in sorted({len(n) for n in nodes_w}):
    row_w = [n for n in nodes_w if len(n) == depth_w]
    for j_w, node_w in enumerate(row_w):
        pos_w[node_w] = (j_w - (len(row_w) - 1) / 2, -depth_w)
print("decision edges:", len(edges_w))
```
▶ What you'll see: the explored tree is much smaller than a full truth table.

```python
plt.figure(figsize=(6, 4))
for parent_w, child_w, label_w in edges_w:
    x0_w, y0_w = pos_w[parent_w]; x1_w, y1_w = pos_w[child_w]
    plt.plot([x0_w, x1_w], [y0_w, y1_w], color="gray")
    plt.text((x0_w+x1_w)/2, (y0_w+y1_w)/2, label_w, fontsize=8)
for node_w, (x_w, y_w) in pos_w.items():
    plt.scatter([x_w], [y_w], s=120, color="teal")
    plt.text(x_w, y_w + 0.08, "{}" if not node_w else str(dict(node_w)), ha="center", fontsize=7)
plt.axis("off"); plt.title("DPLL decision tree"); plt.show()
```
▶ What you'll see: each edge is a choice; propagation is compressed into the node reached after that choice.

*Why it's done this way:* visualizing only decisions separates search from deduction. The solver branches on choices, then lets propagation fill in what the choices imply.

### 6. CDCL and clause learning idea

CDCL asks what a conflict teaches. Full CDCL builds an implication graph and resolves clauses, but the core idea is simple: if decisions `x1=True` and `x2=True` led to a contradiction, add `(¬x1 ∨ ¬x2)` so that combination is never repeated.

```python
cnf_cdcl_w = [[-1, 3], [-2, 3], [-3]]  # x1 and x2 together force x3, but x3 is forbidden.
decisions_cdcl_w = {1: True, 2: True}
prop_cdcl_w, trail_cdcl_w, conflict_cdcl_w = propagate_w(cnf_cdcl_w, decisions_cdcl_w)
print("propagated:", prop_cdcl_w, "trail:", trail_cdcl_w, "conflict:", conflict_cdcl_w)
```
▶ What you'll see: the decision pair forces a value that contradicts the unit clause `¬x3`.

```python
learned_cdcl_w = [-1, -2]
cnf_learned_w = cnf_cdcl_w + [learned_cdcl_w]
print("learned clause:", learned_cdcl_w)
print("old decisions now give:", clause_state_w(learned_cdcl_w, decisions_cdcl_w))
assert clause_state_w(learned_cdcl_w, decisions_cdcl_w) == "conflict"
```
▶ What you'll see: the learned clause immediately blocks the same bad decision pair.

```python
state_order_cdcl_w = {"conflict": -1, "open": 0, "satisfied": 1}
states_before_cdcl_w = [state_order_cdcl_w[clause_state_w(c, decisions_cdcl_w)] for c in cnf_cdcl_w]
states_after_cdcl_w = [state_order_cdcl_w[clause_state_w(c, decisions_cdcl_w)] for c in cnf_learned_w]
M_cdcl_w = np.full((2, len(cnf_learned_w)), np.nan)
M_cdcl_w[0, :len(states_before_cdcl_w)] = states_before_cdcl_w
M_cdcl_w[1, :len(states_after_cdcl_w)] = states_after_cdcl_w
plt.figure(figsize=(5, 2.5))
plt.imshow(M_cdcl_w, cmap="RdYlGn", vmin=-1, vmax=1, aspect="auto")
plt.yticks([0, 1], ["before learning", "after learning"])
plt.xticks(range(len(cnf_learned_w)), [f"C{i}" for i in range(len(cnf_learned_w))])
plt.colorbar(ticks=[-1, 0, 1], label="state")
plt.title("6: learned clause blocks the conflict cube")
plt.show()
```
▶ What you'll see: the added clause appears as a new conflicting row for the repeated bad decisions.

*Why it's done this way:* learning converts one failed branch into reusable memory. The added clause is still ordinary CNF, so the same propagation engine can use it later.

### 7. Watched literals

Naive propagation scans every literal in every clause after every assignment. **Watched literals** keep two representatives per clause; a clause wakes only when one watched literal becomes false. If another non-false literal can be watched, the clause goes quiet again.

```python
clause_watch_w = [1, -2, 3, 4]
watches_w = [0, 1]  # watch x1 and not x2.
assign_watch_w = {1: False}
print("watched literals:", [clause_watch_w[i] for i in watches_w])
```
▶ What you'll see: only two literal positions are being monitored.

```python
def update_watch_w(clause, watches, assignment, false_watch_index):
    other = watches[1 - false_watch_index]
    for idx, lit in enumerate(clause):
        if idx in watches:
            continue
        if lit_value_w(lit, assignment) is not False:
            new_watches = watches.copy(); new_watches[false_watch_index] = idx
            return new_watches, "moved"
    other_val = lit_value_w(clause[other], assignment)
    if other_val is None:
        return watches, "unit"
    return watches, "satisfied" if other_val else "conflict"

new_watches_w, state_watch_w = update_watch_w(clause_watch_w, watches_w, assign_watch_w, 0)
print("new watched literals:", [clause_watch_w[i] for i in new_watches_w], "state:", state_watch_w)
```
▶ What you'll see: the watch moves away from the falsified literal instead of scanning the formula globally.

```python
watch_grid_w = np.array([[1 if i in watches_w else 0 for i in range(len(clause_watch_w))],
                         [1 if i in new_watches_w else 0 for i in range(len(clause_watch_w))]])
plt.figure(figsize=(4.8, 2.5))
plt.imshow(watch_grid_w, cmap="Blues", vmin=0, vmax=1, aspect="auto")
plt.yticks([0, 1], ["before", "after"])
plt.xticks(range(len(clause_watch_w)), [str(lit) for lit in clause_watch_w])
plt.title("7: watched literals before and after update")
plt.xlabel("literal position")
plt.show()
```
▶ What you'll see: only the two watched positions are highlighted, and one moves to a safe literal.

*Why it's done this way:* watched literals preserve the same logic while changing the cost model. Propagation work becomes tied to clauses affected by the newest assignment, not all clauses.

### 8. Phase saving and encoding problems to SAT

**Phase saving** remembers the last polarity used for a variable, so after backtracking or restart the solver rebuilds a promising assignment instead of choosing randomly. Separately, domain problems must be encoded into SAT variables and clauses; for graph coloring, variable `v_color` means vertex `v` has a particular color.

```python
phase_w = {1: True, 2: False}
choice_var_w = 2
choice_w = phase_w.get(choice_var_w, True)
print("saved branch for x2:", choice_w)
assert choice_w is False
```
▶ What you'll see: the solver reuses the last known useful polarity for `x2`.

```python
colors_w = [0, 1, 2]
edges_color_w = [(0, 1), (1, 2), (0, 2)]
def color_var_w(v, c):
    return 1 + 3 * v + c
cnf_color_w = []
for v_w in range(3):
    cnf_color_w.append([color_var_w(v_w, c_w) for c_w in colors_w])
    for c1_w, c2_w in combinations(colors_w, 2):
        cnf_color_w.append([-color_var_w(v_w, c1_w), -color_var_w(v_w, c2_w)])
for u_w, v_w in edges_color_w:
    for c_w in colors_w:
        cnf_color_w.append([-color_var_w(u_w, c_w), -color_var_w(v_w, c_w)])
sat_color_w, sol_color_w = dpll_w(cnf_color_w)
coloring_w = {v_w: [c_w for c_w in colors_w if sol_color_w.get(color_var_w(v_w, c_w), False)][0] for v_w in range(3)}
print("triangle coloring:", coloring_w)
assert sat_color_w and all(coloring_w[u] != coloring_w[v] for u, v in edges_color_w)
```
▶ What you'll see: a graph-coloring problem becomes SAT clauses, and the solver returns a valid coloring.

```python
coords_color_w = np.array([[0, 1], [-1, 0], [1, 0]])
plt.figure(figsize=(4, 3))
for u_w, v_w in edges_color_w:
    plt.plot([coords_color_w[u_w, 0], coords_color_w[v_w, 0]], [coords_color_w[u_w, 1], coords_color_w[v_w, 1]], color="gray")
plt.scatter(coords_color_w[:, 0], coords_color_w[:, 1], c=[coloring_w[v_w] for v_w in range(3)], cmap="Set1", s=320)
for v_w, (x_w, y_w) in enumerate(coords_color_w):
    plt.text(x_w, y_w, f"v{v_w}", ha="center", va="center", color="white")
plt.axis("off")
plt.title("8: SAT-decoded triangle coloring")
plt.show()
```
▶ What you'll see: adjacent triangle vertices receive different colors from the SAT model.

*Why it's done this way:* SAT solvers are general engines. The modeling step exposes a domain's constraints as Boolean clauses; phase saving and learned clauses then accelerate the generic search.

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, random CNF generation, and compact numerical checks.
import matplotlib.pyplot as plt # load Matplotlib for clause matrices, trees, bars, and phase-transition plots.
from itertools import product, combinations # use standard-library iterators for truth tables and pairwise constraints.
from collections import defaultdict # use standard dictionaries of lists/sets for polarity and watch tables.
np.random.seed(0) # make all random examples reproducible.

def lit_value(lit, assignment): # Evaluate a signed literal under a partial assignment.
    val = assignment.get(abs(lit)) # Look up the underlying variable.
    if val is None: # The variable may be unassigned.
        return None # Unknown is different from false.
    return bool(val) if lit > 0 else (not bool(val)) # Negative literals flip the variable truth value.

def clause_value(clause, assignment): # Evaluate a clause as True, False, or None.
    vals = [lit_value(lit, assignment) for lit in clause] # Evaluate all literals.
    if True in vals: # OR is true as soon as one literal is true.
        return True # Clause satisfied.
    if None in vals: # Some literal might still become true later.
        return None # Clause undecided.
    return False # All literals are false, so this is a conflict.

def cnf_vars(cnf): # Collect variable ids from signed literals.
    return sorted({abs(lit) for clause in cnf for lit in clause}) # Absolute values remove polarity.

def cnf_satisfied(cnf, assignment): # Check whether every clause is true.
    return all(clause_value(clause, assignment) is True for clause in cnf) # CNF is conjunction.

def unit_literal(cnf, assignment): # Return one forced literal, 0 for conflict, or None for no unit.
    for clause in cnf: # Inspect each clause.
        vals = [lit_value(lit, assignment) for lit in clause] # Evaluate literals.
        if True in vals: # Satisfied clauses impose no requirement.
            continue # Move on.
        unknown = [lit for lit, val in zip(clause, vals) if val is None] # Gather unassigned literals.
        if len(unknown) == 0: # No way to satisfy this clause.
            return 0 # Conflict marker.
        if len(unknown) == 1: # Exactly one possible literal remains.
            return unknown[0] # Forced literal.
    return None # No unit clause.

def pure_literals(cnf, assignment): # Find pure literals in unsatisfied clauses.
    signs = defaultdict(set) # Map variable to seen polarities.
    for clause in cnf: # Scan clauses.
        if clause_value(clause, assignment) is True: # Ignore already satisfied clauses.
            continue # They need no more help.
        for lit in clause: # Scan literals.
            if abs(lit) not in assignment: # Only unassigned variables can be chosen.
                signs[abs(lit)].add(1 if lit > 0 else -1) # Store polarity.
    return [v * next(iter(s)) for v, s in signs.items() if len(s) == 1] # Keep one-polarity variables.

def propagate(cnf, assignment, use_pure=True): # Apply unit propagation and optional pure literals.
    assignment = dict(assignment) # Copy branch state.
    trail = [] # Store explanatory assignments.
    while True: # Repeat to a fixed point.
        unit = unit_literal(cnf, assignment) # Look for forced literal.
        if unit == 0: # A clause is false.
            return assignment, trail, True # Report conflict.
        if unit is not None: # A unit clause exists.
            assignment[abs(unit)] = unit > 0 # Satisfy it.
            trail.append((unit, "unit")) # Record why.
            continue # More units may appear.
        if use_pure: # Pure literals are optional simplifications.
            pures = [lit for lit in pure_literals(cnf, assignment) if abs(lit) not in assignment] # Find active pures.
            if pures: # Assign all pures.
                for lit in pures: # Process each pure literal.
                    assignment[abs(lit)] = lit > 0 # Choose satisfying polarity.
                    trail.append((lit, "pure")) # Record why.
                continue # More simplification may appear.
        return assignment, trail, False # Fixed point reached.

def dpll(cnf, assignment=None, use_pure=True, trace=None): # Recursive DPLL solver.
    assignment = {} if assignment is None else dict(assignment) # Initialize or copy state.
    trace = [] if trace is None else trace # Optional trace accumulator.
    assignment, trail, conflict = propagate(cnf, assignment, use_pure=use_pure) # Simplify first.
    node = tuple(sorted(assignment.items())) # Freeze state for tracing.
    if conflict: # Contradiction found.
        trace.append((node, "conflict", trail)) # Record dead leaf.
        return False, assignment, trace # Branch failed.
    if cnf_satisfied(cnf, assignment): # All clauses are true.
        trace.append((node, "sat", trail)) # Record success.
        return True, assignment, trace # Return model.
    var = next(v for v in cnf_vars(cnf) if v not in assignment) # Choose first unassigned variable.
    trace.append((node, f"branch x{var}", trail)) # Record branch point.
    for val in [True, False]: # Deterministic polarity order.
        child = dict(assignment) # Copy current propagated state.
        child[var] = val # Add decision.
        trace.append((node, f"try x{var}={val}", [])) # Record decision.
        ok, sol, trace = dpll(cnf, child, use_pure=use_pure, trace=trace) # Recurse.
        if ok: # Stop at first model.
            return True, sol, trace # Return model upward.
    return False, assignment, trace # Both branches failed.

def brute_force_sat(cnf): # Exhaustive SAT solver for tiny formulas.
    vars_ = cnf_vars(cnf) # Truth-table variables.
    for bits in product([False, True], repeat=len(vars_)): # Enumerate every row.
        assignment = dict(zip(vars_, bits)) # Build assignment.
        if cnf_satisfied(cnf, assignment): # Check all clauses.
            return True, assignment # Return first model.
    return False, {} # No model exists.

def random_k_cnf(n_vars, n_clauses, k=3, rng=None): # Generate a random k-CNF formula.
    rng = np.random.default_rng(0) if rng is None else rng # Default reproducibility.
    cnf = [] # Store clauses.
    for _ in range(n_clauses): # Build clauses.
        variables = rng.choice(np.arange(1, n_vars + 1), size=k, replace=False) # Choose distinct vars.
        signs = rng.choice([-1, 1], size=k) # Choose polarities.
        cnf.append(list((variables * signs).astype(int))) # Store signed literals.
    return cnf # Return formula.

def plot_clause_matrix(cnf, title): # Visualize clause-variable polarity.
    vars_ = cnf_vars(cnf) # Columns are variables.
    M = np.zeros((len(cnf), len(vars_))) # 0 means absent.
    idx = {v: j for j, v in enumerate(vars_)} # Variable-to-column map.
    for i, clause in enumerate(cnf): # Fill rows.
        for lit in clause: # Fill literal signs.
            M[i, idx[abs(lit)]] = 1 if lit > 0 else -1 # Positive or negative.
    plt.figure(figsize=(4.5, 3)) # Compact heatmap.
    plt.imshow(M, cmap="coolwarm", vmin=-1, vmax=1, aspect="auto") # Draw polarity.
    plt.colorbar(label="literal sign") # Color legend.
    plt.title(title) # Plot title.
    plt.xlabel("variable") # Column label.
    plt.ylabel("clause") # Row label.
    plt.show() # Display.
```

### Easy 2 — Draw a DPLL search tree

**Goal.** Record decision edges and plot them, because the tree shows where backtracking search spends effort. We build it in 4 steps.


```python

    assignment = {} if assignment is None else dict(assignment)
    assignment, trail, conflict = propagate(cnf, assignment, use_pure=False)
    parent = tuple(sorted(assignment.items()))
    if conflict:
        return False, assignment
    if cnf_satisfied(cnf, assignment):
        return True, assignment
    var = next(v for v in cnf_vars(cnf) if v not in assignment)

        child_key = tuple(sorted(child.items()))

        ok, sol = dpll_edges_e2(cnf, child)
        if ok:
            return True, sol
    return False, assignment
sat_e2, sol_e2 = dpll_edges_e2(cnf_e2) # Solve while recording edges.
print("SAT?", sat_e2, "edges:", len(edges_e2)) # Inspect tree size.
```


### Advanced 1 — Simplified CDCL with learning

**Goal.** Restart after conflicts while adding learned blocking clauses, because CDCL uses conflicts as memory. We build it in 5 steps.

```python
cnf_a1 = [[1, 2], [-1, 3], [-2, 3], [-3, 4], [-4]] # Branches can force x4, which is forbidden.

```
▶ What you'll see: the initial clause database is small.

```python
def cdcl_toy_a1(cnf, max_rounds=8):
    learned = []
    phase = {}
    for round_a1 in range(max_rounds):
        formula = cnf + learned
        assignment, trail, conflict = propagate(formula, {}, use_pure=False)
        decisions = []
        while not conflict and not cnf_satisfied(formula, assignment):
            var = next(v for v in cnf_vars(formula) if v not in assignment)
            val = phase.get(var, True)
            assignment[var] = val; phase[var] = val; decisions.append((var, val))
            assignment, more_trail, conflict = propagate(formula, assignment, use_pure=False)
            trail.extend(more_trail)
        if not conflict and cnf_satisfied(formula, assignment):
            return True, assignment, learned, phase
        if not decisions:
            return False, assignment, learned, phase
        learned.append([(-v if val else v) for v, val in decisions])
    return False, assignment, learned, phase
sat_a1, sol_a1, learned_a1, phase_a1 = cdcl_toy_a1(cnf_a1) # Run toy CDCL.
```

```python
def dpll_count_a3(cnf, assignment=None, counter=None):
    assignment = {} if assignment is None else dict(assignment)
    counter = {"calls": 0} if counter is None else counter
    counter["calls"] += 1
    assignment, trail, conflict = propagate(cnf, assignment, use_pure=False)
```
