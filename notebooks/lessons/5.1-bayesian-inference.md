# 5.1 — Bayesian Inference

Bayesian inference turns uncertainty into an object we can compute with: start with a prior belief, score how compatible each hypothesis is with the data through a likelihood, normalize those scores into a posterior distribution, and then make predictions or decisions while keeping uncertainty visible.

Run each cell in order and read the printed intermediate values — every piece of math is spelled out so Bayes' rule is not a black box. ### 1. Hypotheses as a grid: probability is distributed belief

Bayesian inference starts by treating an unknown parameter as uncertain, not as one hidden number we must immediately guess. For a coin or click-rate problem, the parameter is a success probability \(\theta\), so it must live between 0 and 1. We begin with a small grid of possible \(\theta\) values and assign each one a prior probability. That prior is not decoration: it is the amount of belief each hypothesis receives before seeing the new data.

```python
theta_w = np.linspace(0.05, 0.95, 19)  # possible success probabilities on a simple grid.
prior_w = np.ones_like(theta_w) / len(theta_w)  # a uniform prior: every grid point starts equally plausible.
print("theta grid:", np.round(theta_w[:5], 2), "...", np.round(theta_w[-5:], 2))  # inspect endpoints.
print("prior sums to:", round(float(prior_w.sum()), 3))  # probabilities must add to 1.
assert round(float(prior_w.sum()), 3) == 1.000  # concrete probability check.
```
▶ What you'll see: a list of candidate success probabilities and a prior mass that sums to exactly 1.

```python
plt.figure(figsize=(5, 3))  # create a compact prior plot.
plt.stem(theta_w, prior_w, basefmt=" ")  # draw one prior probability per hypothesis.
plt.title("1: uniform prior over possible θ")  # title the prior visualization.
plt.xlabel("θ = success probability")  # label the unknown parameter axis.
plt.ylabel("prior probability")  # label belief before data.
plt.show()  # display the prior mass function.
```
▶ What you'll see: every candidate θ has the same height, meaning the data will be allowed to speak evenly.

*Why it's done this way:* a probability distribution forces our beliefs to obey bookkeeping. If the prior mass sums to 1, then increasing belief in one region must decrease belief somewhere else, which is exactly the tradeoff uncertainty should represent.

### 2. Likelihood: data reweights the hypotheses

The likelihood asks: if a candidate \(\theta\) were true, how compatible would the observed data be? For Bernoulli data with \(s\) successes and \(f\) failures, the likelihood is proportional to \(\theta^s(1-\theta)^f\). The proportionality is enough for comparing hypotheses because the missing combinatorial constant is the same for every \(\theta\) on this fixed dataset.

```python
successes_w, failures_w = 7, 3  # the worked dataset: 7 successes and 3 failures.
likelihood_w = theta_w ** successes_w * (1 - theta_w) ** failures_w  # Bernoulli likelihood over the grid.
best_idx_w = int(np.argmax(likelihood_w))  # locate the maximum-likelihood hypothesis.
print("MLE grid θ:", round(float(theta_w[best_idx_w]), 2))  # should land near 7/10.
print("max likelihood score:", round(float(likelihood_w[best_idx_w]), 6))  # unnormalized compatibility.
assert round(float(theta_w[best_idx_w]), 2) == 0.70  # data fraction 7/10 is the peak.
```
▶ What you'll see: θ = 0.70 gets the largest likelihood score because 7 of 10 observations were successes.

```python
plt.figure(figsize=(5, 3))  # create a likelihood curve.
plt.plot(theta_w, likelihood_w, marker="o", color="darkorange")  # draw likelihood across candidate θ values.
plt.axvline(0.7, color="black", linestyle="--", label="7/10")  # mark the empirical success rate.
plt.title("2: likelihood from 7 successes, 3 failures")  # title the data-compatibility plot.
plt.xlabel("θ")  # parameter axis.
plt.ylabel("likelihood score")  # score is not yet a probability distribution.
plt.legend()  # show the 7/10 reference.
plt.show()  # display the likelihood.
```
▶ What you'll see: the curve peaks near 0.7 and falls for hypotheses that make the data less plausible.

*Why it's done this way:* the powers count repeated evidence. Each success multiplies by \(\theta\), each failure multiplies by \(1-\theta\), so a hypothesis must explain every observation, not just match the average loosely.

### 3. Bayes' rule: multiply, then normalize with evidence

Bayes' rule says posterior belief is proportional to prior belief times likelihood. The product is only an unnormalized score; it does not necessarily sum to 1. The evidence \(p(D)\) is the sum or integral of those scores, and dividing by it turns local compatibility scores into a valid posterior distribution.

```python
score_w = prior_w * likelihood_w  # unnormalized posterior score = prior times likelihood.
evidence_grid_w = float(score_w.sum())  # grid evidence: total mass before normalization.
posterior_w = score_w / evidence_grid_w  # normalized posterior probabilities.
print("unnormalized score sum:", round(evidence_grid_w, 8))  # evidence on this grid.
print("posterior sum:", round(float(posterior_w.sum()), 3))  # must be 1 after normalization.
assert round(float(posterior_w.sum()), 3) == 1.000  # concrete normalization check.
```
▶ What you'll see: the raw score sum is not 1, but the posterior sum is exactly 1 after dividing by evidence.

```python
plt.figure(figsize=(5, 3))  # create a posterior plot.
plt.stem(theta_w, posterior_w, basefmt=" ")  # show normalized posterior mass at each θ.
plt.title("3: posterior = normalized prior × likelihood")  # title the Bayes update.
plt.xlabel("θ")  # parameter axis.
plt.ylabel("posterior probability")  # belief after data.
plt.show()  # display the posterior distribution.
```
▶ What you'll see: posterior mass is concentrated near the hypotheses that both the prior and data support.

*Why it's done this way:* multiplication performs the logical AND: a hypothesis should score highly only when it was plausible before and it explains the data. Normalization is what makes those scores comparable probabilities rather than arbitrary units.

### 4. Beta-Bernoulli conjugacy: update by adding counts

A Beta distribution is a natural prior for a Bernoulli probability because it has two positive shape parameters: \(\alpha\) behaves like prior successes and \(\beta\) behaves like prior failures. After observing \(s\) successes and \(f\) failures, the posterior is \(\mathrm{Beta}(\alpha+s,\beta+f)\). This is conjugacy: the posterior stays in the same family as the prior.

```python
alpha0_w, beta0_w = 2, 3  # prior pseudo-counts from the lesson block.
alpha_post_w = alpha0_w + successes_w  # add observed successes to alpha.
beta_post_w = beta0_w + failures_w  # add observed failures to beta.
print("posterior alpha:", alpha_post_w, "posterior beta:", beta_post_w)  # inspect updated pseudo-counts.
assert (alpha_post_w, beta_post_w) == (9, 6)  # concrete worked arithmetic from the lesson block.
```
▶ What you'll see: Beta(2,3) plus 7 successes and 3 failures becomes Beta(9,6).

```python
def beta_pdf_int_w(x, a, b):  # beta density for integer a,b using products instead of SciPy.
    coeff = np.prod(np.arange(1, a + b)) / (np.prod(np.arange(1, a)) * np.prod(np.arange(1, b)))  # Γ(a+b)/(Γ(a)Γ(b)).
    return coeff * (x ** (a - 1)) * ((1 - x) ** (b - 1))  # normalized beta density.

fine_w = np.linspace(0.001, 0.999, 600)  # fine grid for smooth density plots.
prior_pdf_w = beta_pdf_int_w(fine_w, alpha0_w, beta0_w)  # prior density.
post_pdf_w = beta_pdf_int_w(fine_w, alpha_post_w, beta_post_w)  # posterior density.
print("prior mode approx:", round(float(fine_w[np.argmax(prior_pdf_w)]), 3))  # where the prior peaks.
print("posterior mode approx:", round(float(fine_w[np.argmax(post_pdf_w)]), 3))  # where the posterior peaks.
```
▶ What you'll see: the posterior peak shifts toward the observed success rate while still remembering the prior.

```python
plt.figure(figsize=(5, 3))  # create a prior/posterior comparison.
plt.plot(fine_w, prior_pdf_w, label="prior Beta(2,3)", color="gray")  # prior density.
plt.plot(fine_w, post_pdf_w, label="posterior Beta(9,6)", color="seagreen")  # posterior density.
plt.axvline(0.7, color="black", linestyle="--", label="data rate 7/10")  # data reference.
plt.title("4: Beta-Bernoulli update adds counts")  # title the conjugate update.
plt.xlabel("θ")  # success probability.
plt.ylabel("density")  # beta density.
plt.legend()  # show labels.
plt.show()  # display the densities.
```
▶ What you'll see: the posterior is tighter and moved toward 0.7, but not all the way there.

*Why it's done this way:* the Beta exponents are \(\theta^{\alpha-1}(1-\theta)^{\beta-1}\). Multiplying by \(\theta^s(1-\theta)^f\) simply adds exponents, so the update becomes count addition rather than a new optimization problem.

### 5. Posterior summaries: prediction and uncertainty

The posterior is the full answer, but we often summarize it. For \(\mathrm{Beta}(\alpha,\beta)\), the posterior predictive probability of the next success is the mean \(\alpha/(\alpha+\beta)\), and the variance is \(\alpha\beta/((\alpha+\beta)^2(\alpha+\beta+1))\). The mean gives a forecast; the variance says how much uncertainty remains around that forecast.

```python
pred_success_w = alpha_post_w / (alpha_post_w + beta_post_w)  # posterior predictive success probability.
var_post_w = alpha_post_w * beta_post_w / ((alpha_post_w + beta_post_w) ** 2 * (alpha_post_w + beta_post_w + 1))  # beta variance.
print("posterior predictive success:", round(float(pred_success_w), 3))  # 9/15.
print("posterior variance:", round(float(var_post_w), 3))  # 54/3600.
assert round(float(pred_success_w), 3) == 0.600  # lesson number.
assert round(float(var_post_w), 3) == 0.015  # lesson number.
```
▶ What you'll see: the next-success probability is 0.600 and the posterior variance is 0.015.

```python
samples_w = np.random.beta(alpha_post_w, beta_post_w, size=4000)  # draw from the posterior using NumPy.
ci_w = np.percentile(samples_w, [5, 50, 95])  # summarize uncertainty with a central interval.
print("5%, 50%, 95% posterior θ:", np.round(ci_w, 3))  # inspect credible interval values.
plt.figure(figsize=(5, 3))  # create a posterior sample histogram.
plt.hist(samples_w, bins=35, density=True, color="steelblue", alpha=0.75)  # visualize sampled posterior uncertainty.
plt.axvline(pred_success_w, color="black", linestyle="--", label="posterior mean")  # show predictive mean.
plt.title("5: posterior samples show remaining uncertainty")  # title uncertainty plot.
plt.xlabel("θ")  # success probability.
plt.ylabel("density")  # histogram density.
plt.legend()  # show mean label.
plt.show()  # display histogram.
```
▶ What you'll see: most samples sit near 0.6, but the spread reminds us that θ is not known exactly.

*Why it's done this way:* replacing the posterior with only one point would hide how much evidence supports the forecast. The mean and variance together preserve both the prediction and the confidence behind it.

### 6. Evidence as model comparison: normalizing across priors

The evidence \(p(D)\) also lets us compare models or priors. A very concentrated prior can look confident, but if it places mass far from the data, the integrated likelihood will be small. For the Beta-Bernoulli model, the beta-binomial evidence for \(s\) successes and \(f\) failures is \(\binom{n}{s} B(\alpha+s,\beta+f)/B(\alpha,\beta)\).

```python
def comb_int_w(n, k):  # integer combination n choose k without importing math.
    return int(np.prod(np.arange(n - k + 1, n + 1)) / np.prod(np.arange(1, k + 1)))  # product formula.

def beta_func_int_w(a, b):  # beta function for positive integers.
    return np.prod(np.arange(1, a, dtype=float)) * np.prod(np.arange(1, b, dtype=float)) / np.prod(np.arange(1, a + b, dtype=float))  # Γ(a)Γ(b)/Γ(a+b).

n_w = successes_w + failures_w  # total trials.
evidence_w = comb_int_w(n_w, successes_w) * beta_func_int_w(alpha_post_w, beta_post_w) / beta_func_int_w(alpha0_w, beta0_w)  # marginal likelihood.
print("beta-binomial evidence:", round(float(evidence_w), 6))  # lesson evidence value.
assert round(float(evidence_w), 6) == 0.079920  # concrete evidence check from the lesson block.
```
▶ What you'll see: the evidence for 7 successes in 10 trials under Beta(2,3) is 0.079920.

```python
priors_w = [(1, 1), (2, 3), (12, 3)]  # weak, lesson, and strong-high priors.
evidences_w = []  # store evidence under each prior.
for a_w, b_w in priors_w:  # evaluate each prior.
    ev_w = comb_int_w(n_w, successes_w) * beta_func_int_w(a_w + successes_w, b_w + failures_w) / beta_func_int_w(a_w, b_w)  # evidence.
    evidences_w.append(ev_w)  # collect value.
print("evidences:", [round(float(x), 6) for x in evidences_w])  # compare model support.
plt.figure(figsize=(5, 3))  # create evidence comparison chart.
plt.bar(["Beta(1,1)", "Beta(2,3)", "Beta(12,3)"], evidences_w, color=["gray", "seagreen", "orange"])  # show evidence by prior.
plt.title("6: evidence compares prior-data fit")  # title model comparison plot.
plt.ylabel("p(D) under prior")  # evidence axis.
plt.xticks(rotation=15)  # improve label readability.
plt.show()  # display bar chart.
```
▶ What you'll see: different priors receive different marginal likelihoods for the same data.

*Why it's done this way:* evidence rewards a model for assigning probability to what actually happened before seeing it. That is why it is the normalizer inside one posterior and the score for comparing multiple Bayesian models.

### 7. Decisions under loss: posterior belief becomes action

Bayesian inference often ends with a decision. The posterior tells us what is plausible; a loss function tells us what mistakes cost. Under squared error, the best point estimate is the posterior mean. Under absolute error, it is the posterior median. Under asymmetric business costs, the best action can move away from both because false positives and false negatives do not hurt equally.

```python
mean_decision_w = float(np.mean(samples_w))  # squared-loss optimal estimate.
median_decision_w = float(np.median(samples_w))  # absolute-loss optimal estimate.
threshold_w = 0.55  # action threshold for launching a hypothetical treatment.
prob_above_w = float(np.mean(samples_w > threshold_w))  # posterior probability that θ exceeds threshold.
print("mean:", round(mean_decision_w, 3), "median:", round(median_decision_w, 3))  # compare summaries.
print("P(θ > 0.55):", round(prob_above_w, 3))  # action-relevant probability.
```
▶ What you'll see: the mean and median are close, and the posterior probability above 0.55 quantifies launch confidence.

```python
false_launch_cost_w = 4.0  # cost if we launch while θ is not actually above threshold.
missed_launch_cost_w = 1.0  # cost if we do not launch while θ is above threshold.
launch_loss_w = false_launch_cost_w * (1 - prob_above_w)  # expected cost of launching.
wait_loss_w = missed_launch_cost_w * prob_above_w  # expected cost of waiting.
action_w = "launch" if launch_loss_w < wait_loss_w else "wait"  # choose smaller posterior expected loss.
print("expected launch loss:", round(launch_loss_w, 3))  # inspect launch risk.
print("expected wait loss:", round(wait_loss_w, 3), "-> decision:", action_w)  # inspect wait risk and action.
plt.figure(figsize=(4.8, 3))  # create loss comparison.
plt.bar(["launch", "wait"], [launch_loss_w, wait_loss_w], color=["seagreen", "gray"])  # compare expected losses.
plt.title("7: choose the action with lower expected loss")  # title decision plot.
plt.ylabel("posterior expected loss")  # loss scale.
plt.show()  # display decision chart.
```
▶ What you'll see: the cheaper action is the one with lower posterior expected loss, not necessarily the one with the highest raw probability.

*Why it's done this way:* probability alone answers what we believe; loss translates belief into consequences. Bayesian decisions minimize average loss under the posterior, so uncertainty and cost enter the final action together.

### ✍️ Toy 1 · A prior grid spreads belief over hypotheses

A Bayesian prior is a probability distribution over candidate hypotheses. Normalize six raw weights
so the bookkeeping sums to one.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)                  # seeded generator for reproducibility
t1_theta = np.array([0.10, 0.25, 0.40, 0.55, 0.70, 0.85])  # -> [0.10, 0.25, 0.40, 0.55, 0.70, 0.85]
print("theta grid:", t1_theta.tolist())            # -> [0.1, 0.25, 0.4, 0.55, 0.7, 0.85]
t1_raw = np.array([1, 1, 2, 2, 1, 1])              # raw prior weights  # -> [1, 1, 2, 2, 1, 1]
print("raw prior weights:", t1_raw.tolist())       # -> [1, 1, 2, 2, 1, 1]
t1_total = t1_raw.sum()                            # normalizing constant  # -> 8
print("raw total:", int(t1_total))                 # -> 8
t1_prior = t1_raw / t1_total                       # normalized prior  # -> [0.125, 0.125, 0.25, 0.25, 0.125, 0.125]
print("prior:", np.round(t1_prior, 3).tolist())    # -> [0.125, 0.125, 0.25, 0.25, 0.125, 0.125]
t1_sum = t1_prior.sum()                            # probability check  # -> 1.0
print("prior sum:", round(float(t1_sum), 3))       # -> 1.0
assert np.isclose(t1_sum, 1.0)                     # normalized belief must sum to one

plt.figure(figsize=(4.8, 2.8))
plt.bar([f"{v:.2f}" for v in t1_theta], t1_prior, color="#4c78a8")
plt.xlabel("candidate θ")
plt.ylabel("prior probability")
plt.title("Toy 1 · normalized prior grid")
plt.show()
```
▶ What you'll see: the two middle hypotheses get twice as much prior mass, and all six bars sum to `1.0`.

### ✍️ Toy 2 · Likelihood reweights hypotheses by data compatibility

For Bernoulli observations, each success contributes a factor of `θ` and each failure contributes
`1−θ`. Six observations make the grid point near the sample rate score highest.

```python
import numpy as np

t2_rng = np.random.default_rng(0)                  # seeded generator for reproducibility
t2_obs = np.array([1, 1, 0, 1, 0, 1])              # 6 Bernoulli observations  # -> [1, 1, 0, 1, 0, 1]
print("observations:", t2_obs.tolist())            # -> [1, 1, 0, 1, 0, 1]
t2_successes = int(t2_obs.sum())                   # successes  # -> 4
print("successes:", t2_successes)                 # -> 4
t2_failures = int(t2_obs.size - t2_successes)      # failures  # -> 2
print("failures:", t2_failures)                   # -> 2
t2_theta = np.array([0.20, 0.40, 0.60, 0.80])      # candidate success probabilities  # -> [0.2, 0.4, 0.6, 0.8]
print("theta grid:", t2_theta.tolist())            # -> [0.2, 0.4, 0.6, 0.8]
t2_likelihood = t2_theta ** t2_successes * (1 - t2_theta) ** t2_failures  # -> [0.001024, 0.009216, 0.020736, 0.016384]
print("likelihood:", np.round(t2_likelihood, 6).tolist())  # -> [0.001024, 0.009216, 0.020736, 0.016384]
t2_best = float(t2_theta[int(np.argmax(t2_likelihood))])   # highest likelihood grid point  # -> 0.6
print("best likelihood θ:", t2_best)              # -> 0.6
assert t2_best == 0.60                             # 4 successes out of 6 points toward 0.6 on this grid

plt.figure(figsize=(4.8, 2.8))
plt.plot(t2_theta, t2_likelihood, marker="o", color="#f58518")
plt.axvline(t2_successes / t2_obs.size, color="black", linestyle="--", label="4/6")

```

### ✍️ Toy 3 · Posterior equals prior times likelihood, normalized

Bayes' rule first multiplies prior mass by likelihood, then divides by the total evidence so the
posterior is a probability distribution again.

```python
import numpy as np

t3_rng = np.random.default_rng(0)                  # seeded generator for reproducibility
t3_theta = np.array([0.20, 0.35, 0.50, 0.65, 0.80, 0.95])  # -> [0.2, 0.35, 0.5, 0.65, 0.8, 0.95]
print("theta grid:", t3_theta.tolist())            # -> [0.2, 0.35, 0.5, 0.65, 0.8, 0.95]
t3_prior = np.array([0.25, 0.25, 0.125, 0.125, 0.125, 0.125])  # -> [0.25, 0.25, 0.125, 0.125, 0.125, 0.125]
print("prior:", t3_prior.tolist())                 # -> [0.25, 0.25, 0.125, 0.125, 0.125, 0.125]
t3_successes = 5                                   # successes  # -> 5
t3_failures = 1                                    # failures  # -> 1
print("successes, failures:", t3_successes, t3_failures)  # -> 5 1
t3_likelihood = t3_theta ** t3_successes * (1 - t3_theta) ** t3_failures  # likelihood scores
print("likelihood:", np.round(t3_likelihood, 6).tolist())  # -> [0.000256, 0.003414, 0.015625, 0.04061, 0.065536, 0.038689]
t3_score = t3_prior * t3_likelihood                # unnormalized posterior score
print("prior × likelihood:", np.round(t3_score, 8).tolist())  # -> [6.4e-05, 0.00085348, 0.00195312, 0.00507627, 0.008192, 0.00483613]

print("posterior:", np.round(t3_posterior, 3).tolist())  # -> [0.003, 0.041, 0.093, 0.242, 0.391, 0.231]
t3_best = float(t3_theta[int(np.argmax(t3_posterior))])  # posterior mode  # -> 0.8

assert t3_best == 0.80                              # the posterior mode is 0.8 for this tiny grid

plt.figure(figsize=(4.8, 2.8))
plt.plot(t3_theta, t3_prior, marker="o", label="prior", color="gray")
plt.plot(t3_theta, t3_posterior, marker="o", label="posterior", color="#54a24b")
plt.xlabel("candidate θ")
plt.ylabel("probability mass")
plt.title("Toy 3 · multiply then normalize")
plt.legend()
plt.show()
```
▶ What you'll see: the posterior bars still sum to one, but mass shifts toward high-θ hypotheses.

### ✍️ Toy 4 · Beta-Bernoulli conjugacy adds counts

A Beta prior stores pseudo-successes and pseudo-failures. Bernoulli data updates those two numbers
by simple addition.

```python
import numpy as np

t4_rng = np.random.default_rng(0)                  # seeded generator for reproducibility
t4_obs = np.array([1, 0, 1, 1, 1, 0, 1, 1])        # 8 Bernoulli observations  # -> [1, 0, 1, 1, 1, 0, 1, 1]
print("observations:", t4_obs.tolist())            # -> [1, 0, 1, 1, 1, 0, 1, 1]
t4_successes = int(t4_obs.sum())                   # observed successes  # -> 6
print("successes:", t4_successes)                 # -> 6
t4_failures = int(t4_obs.size - t4_successes)      # observed failures  # -> 2
print("failures:", t4_failures)                   # -> 2
t4_alpha0 = 2                                      # prior successes plus one  # -> 2
t4_beta0 = 4                                       # prior failures plus one  # -> 4
print("prior alpha, beta:", t4_alpha0, t4_beta0)   # -> 2 4
t4_alpha_post = t4_alpha0 + t4_successes           # posterior alpha  # -> 8
print("posterior alpha:", t4_alpha_post)           # -> 8
t4_beta_post = t4_beta0 + t4_failures              # posterior beta  # -> 6
print("posterior beta:", t4_beta_post)             # -> 6

def t4_beta_pdf_int(t4_x, t4_a, t4_b):
    t4_coeff = np.prod(np.arange(1, t4_a + t4_b, dtype=float)) / (np.prod(np.arange(1, t4_a, dtype=float)) * np.prod(np.arange(1, t4_b, dtype=float)))
    return t4_coeff * (t4_x ** (t4_a - 1)) * ((1 - t4_x) ** (t4_b - 1))

t4_grid = np.linspace(0.1, 0.9, 9)                 # 9 θ locations for drawing densities
t4_prior_pdf = t4_beta_pdf_int(t4_grid, t4_alpha0, t4_beta0)  # prior density on the grid
print("prior density:", np.round(t4_prior_pdf, 3).tolist())  # -> [1.458, 2.048, 2.058, 1.728, 1.25, 0.768, 0.378, 0.128, 0.018]
t4_post_pdf = t4_beta_pdf_int(t4_grid, t4_alpha_post, t4_beta_post)  # posterior density on the grid
print("posterior density:", np.round(t4_post_pdf, 3).tolist())  # -> [0.001, 0.043, 0.378, 1.312, 2.514, 2.951, 2.06, 0.691, 0.049]
assert (t4_alpha_post, t4_beta_post) == (8, 6)      # counts were added exactly

plt.figure(figsize=(4.8, 2.8))
```

### ✍️ Toy 6 · Evidence scores how well a prior predicted the data

The same data can have different marginal likelihoods under different priors. The evidence rewards
priors that placed mass near what happened before seeing it.

```python
import numpy as np

t6_rng = np.random.default_rng(0)                  # seeded generator for reproducibility
t6_obs = np.array([1, 0, 1, 1, 0, 1, 0, 1])        # 8 Bernoulli observations  # -> [1, 0, 1, 1, 0, 1, 0, 1]
print("observations:", t6_obs.tolist())            # -> [1, 0, 1, 1, 0, 1, 0, 1]
t6_successes = int(t6_obs.sum())                   # successes  # -> 5
print("successes:", t6_successes)                 # -> 5
t6_failures = int(t6_obs.size - t6_successes)      # failures  # -> 3
print("failures:", t6_failures)                   # -> 3
t6_priors = np.array([[1, 1], [2, 2], [6, 2]])     # three (alpha,beta) priors  # -> [[1, 1], [2, 2], [6, 2]]
print("candidate priors:", t6_priors.tolist())     # -> [[1, 1], [2, 2], [6, 2]]

def t6_comb_int(t6_n, t6_k):
    return int(np.prod(np.arange(t6_n - t6_k + 1, t6_n + 1, dtype=float)) / np.prod(np.arange(1, t6_k + 1, dtype=float)))

def t6_beta_func_int(t6_a, t6_b):
    return np.prod(np.arange(1, t6_a, dtype=float)) * np.prod(np.arange(1, t6_b, dtype=float)) / np.prod(np.arange(1, t6_a + t6_b, dtype=float))

t6_n = int(t6_obs.size)                            # total trials  # -> 8
print("trial count:", t6_n)                        # -> 8
t6_choose = t6_comb_int(t6_n, t6_successes)        # binomial coefficient  # -> 56
print("n choose successes:", t6_choose)            # -> 56
t6_evidences = []                                  # marginal likelihoods under each prior
for t6_alpha, t6_beta in t6_priors:
    t6_ev = t6_choose * t6_beta_func_int(int(t6_alpha + t6_successes), int(t6_beta + t6_failures)) / t6_beta_func_int(int(t6_alpha), int(t6_beta))
    t6_evidences.append(t6_ev)
t6_evidences = np.array(t6_evidences)              # -> [0.111111, 0.145455, 0.156643]
print("evidences:", np.round(t6_evidences, 6).tolist())  # -> [0.111111, 0.145455, 0.156643]
t6_best_idx = int(np.argmax(t6_evidences))         # best-supported prior index  # -> 2
print("best prior:", t6_priors[t6_best_idx].tolist())  # -> [6, 2]
assert t6_best_idx == 2                             # the high-success prior fits 5/8 successes best here

plt.figure(figsize=(4.8, 2.8))
plt.bar(["Beta(1,1)", "Beta(2,2)", "Beta(6,2)"], t6_evidences, color=["gray", "#4c78a8", "#f58518"])
plt.ylabel("evidence p(D)")
plt.title("Toy 6 · evidence compares priors")
plt.xticks(rotation=12)
plt.show()
```
▶ What you'll see: `Beta(6,2)` has the largest evidence because it expected a success-heavy sample.

### Basic 9 — Compute beta-binomial evidence

**Goal.** Calculate the marginal likelihood of the data, because evidence is both Bayes' normalizer and a model-comparison score. We build it in 3 steps.

```python
def comb_b9(n_b9, k_b9): # compute n choose k with NumPy products.
    return int(np.prod(np.arange(n_b9 - k_b9 + 1, n_b9 + 1)) / np.prod(np.arange(1, k_b9 + 1))) # product formula for combinations.

def beta_func_b9(a_b9, b_b9): # beta function for integer arguments.
```


### Advanced 1 — Approximate a continuous posterior by numerical integration

**Goal.** Compute posterior normalization on a fine grid, because continuous Bayes' rule uses an integral for evidence rather than a finite sum. We build it in 4 steps.

```python
theta_a1 = np.linspace(0.001, 0.999, 2000) # fine grid over the continuous parameter interval.
dtheta_a1 = theta_a1[1] - theta_a1[0] # grid spacing for numerical integration.
prior_a1 = 6 * theta_a1 * (1 - theta_a1) # Beta(2,2) density, already normalized analytically.
print("prior integral approx:", round(float(np.sum(prior_a1) * dtheta_a1), 3)) # check density integration.
```
▶ What you'll see: the prior density integrates to approximately 1 on the grid.

```python
s_a1, f_a1 = 9, 1 # observe nine successes and one failure.
lik_a1 = theta_a1 ** s_a1 * (1 - theta_a1) ** f_a1 # continuous likelihood curve.
score_a1 = prior_a1 * lik_a1 # unnormalized posterior density.
evidence_a1 = float(np.sum(score_a1) * dtheta_a1) # numerical integral of prior times likelihood.
post_density_a1 = score_a1 / evidence_a1 # normalized posterior density.
print("evidence integral:", round(evidence_a1, 6)) # inspect continuous normalizer.
```

```python
post_integral_a1 = float(np.sum(post_density_a1) * dtheta_a1) # verify posterior density integrates to one.
post_mean_a1 = float(np.sum(theta_a1 * post_density_a1) * dtheta_a1) # approximate posterior mean by integration.

```


### Advanced 3 — Evidence rewards calibrated priors

**Goal.** Compare marginal likelihoods for several priors, because evidence measures how well a prior expected the data before seeing it. We build it in 4 steps.

```python
def comb_a3(n_a3, k_a3): # compute combinations with products.
    return int(np.prod(np.arange(n_a3 - k_a3 + 1, n_a3 + 1)) / np.prod(np.arange(1, k_a3 + 1))) # n choose k.

def beta_func_a3(a_a3, b_a3): # beta function for integer parameters.
    return np.prod(np.arange(1, a_a3, dtype=float)) * np.prod(np.arange(1, b_a3, dtype=float)) / np.prod(np.arange(1, a_a3 + b_a3, dtype=float)) # beta function.
print("helpers ready") # confirm helper definitions.
```
▶ What you'll see: the integer beta-binomial helpers are defined without SciPy.

```python
s_a3, f_a3 = 7, 3 # observed data.
priors_a3 = np.array([[1, 1], [2, 3], [8, 2], [20, 20]]) # candidate priors with different beliefs and strengths.
labels_a3 = ["Beta(1,1)", "Beta(2,3)", "Beta(8,2)", "Beta(20,20)"] # plot labels.
evidence_a3 = [] # store marginal likelihoods.
for a_a3, b_a3 in priors_a3: # loop over priors.
    ev_a3 = comb_a3(s_a3 + f_a3, s_a3) * beta_func_a3(int(a_a3 + s_a3), int(b_a3 + f_a3)) / beta_func_a3(int(a_a3), int(b_a3)) # beta-binomial evidence.
    evidence_a3.append(ev_a3) # save evidence.
print("evidence:", [round(float(x), 6) for x in evidence_a3]) # inspect comparison values.
```

