# 10.15 — ControlNet & Conditioning

ControlNet adds a trainable conditioning path to a frozen diffusion-style generator so edges, poses, depth, or layouts can steer the sample without erasing what the base model already knows. In this lesson, we build the idea from scratch with NumPy: a toy denoising step, residual spatial conditioning, zero-initialized gates, and a copied trainable branch that learns control safely.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build ControlNet one idea at a time. Run each cell in order and inspect every printed shape, residual, and plot — the model is tiny, but the math mirrors the real design: preserve a base generator, inject a spatial condition as a residual, and start that residual at exactly zero.

```python
import numpy as np  # arrays, linear algebra, and toy convolutions.
import matplotlib.pyplot as plt  # heatmaps and learning curves.
np.random.seed(0)  # reproducibility for toy images and training.
```

### 1. A frozen toy denoiser is the base model

A diffusion U-Net can be reduced to one local denoising rule for teaching: take a noisy image and replace each pixel by a weighted average of its neighbors. The important ControlNet assumption is that this base model is already useful, so we freeze it instead of retraining it whenever a new edge map or pose map arrives.

```python
def conv2d_same_w(x_w, k_w):
    pad_w = k_w.shape[0] // 2
    xp_w = np.pad(x_w, pad_w, mode="edge")
    out_w = np.zeros_like(x_w, dtype=float)
    for i_w in range(x_w.shape[0]):
        for j_w in range(x_w.shape[1]):
            out_w[i_w, j_w] = np.sum(xp_w[i_w:i_w+3, j_w:j_w+3] * k_w)
    return out_w

base_kernel_w = np.array([[0.05, 0.10, 0.05],
                          [0.10, 0.40, 0.10],
                          [0.05, 0.10, 0.05]])
noisy_w = np.zeros((8, 8), dtype=float)
noisy_w[2:6, 2:6] = 1.0
noisy_w += 0.15 * np.random.randn(8, 8)
base_w = conv2d_same_w(noisy_w, base_kernel_w)
print("base kernel sums to:", round(float(base_kernel_w.sum()), 3))
print("noisy mean -> base mean:", round(float(noisy_w.mean()), 3), "->", round(float(base_w.mean()), 3))
assert round(float(base_kernel_w.sum()), 3) == 1.0
```
▶ What you'll see: the kernel preserves average scale because its weights sum to 1.0, while local noise is smoothed.

```python
fig_w, ax_w = plt.subplots(1, 2, figsize=(6, 3))
ax_w[0].imshow(noisy_w, cmap="gray", vmin=0, vmax=1); ax_w[0].set_title("noisy input")
ax_w[1].imshow(base_w, cmap="gray", vmin=0, vmax=1); ax_w[1].set_title("frozen base output")
for a_w in ax_w:
    a_w.axis("off")
plt.suptitle("1: a frozen toy denoiser"); plt.show()
```
▶ What you'll see: the square remains recognizable, but the output is smoother than the noisy input.

*Why it's done this way:* Freezing means the learned prior is treated as a trusted function $f_{base}(x_t,t,\text{text})$. Conditioning should add a correction, not rewrite the function. The normalized smoothing kernel is a tiny stand-in for a trained denoiser whose output already lives on the right numerical scale.

### 2. Spatial conditioning is a residual map, not a new image

Text guidance says what should appear, but edges, poses, and depth say where structure should be. In ControlNet form, the condition creates a residual feature map $r_{cond}(c)$ and the layer output becomes $h_{out}=h_{base}+r_{cond}(c)$. The residual is spatial: every pixel can receive a different correction.

```python
condition_w = np.zeros((8, 8), dtype=float)
condition_w[2, 2:6] = 1.0; condition_w[5, 2:6] = 1.0
condition_w[2:6, 2] = 1.0; condition_w[2:6, 5] = 1.0
edge_kernel_w = np.array([[0.0, 0.25, 0.0],
                          [0.25, 0.0, 0.25],
                          [0.0, 0.25, 0.0]])
residual_w = 0.35 * conv2d_same_w(condition_w, edge_kernel_w)
controlled_w = base_w + residual_w
print("condition pixels:", int(condition_w.sum()))
print("residual norm:", round(float(np.linalg.norm(residual_w)), 3))
assert int(condition_w.sum()) == 12
```
▶ What you'll see: the condition is a thin square outline, and the residual has nonzero values near that outline.

```python
fig_w, ax_w = plt.subplots(1, 3, figsize=(8, 3))
ax_w[0].imshow(condition_w, cmap="gray", vmin=0, vmax=1); ax_w[0].set_title("condition c")
ax_w[1].imshow(residual_w, cmap="magma"); ax_w[1].set_title("r_cond(c)")
ax_w[2].imshow(controlled_w, cmap="gray"); ax_w[2].set_title("base + residual")
for a_w in ax_w:
    a_w.axis("off")
plt.suptitle("2: residual spatial conditioning"); plt.show()
```
▶ What you'll see: the conditioned output brightens where the outline says structure should be.

*Why it's done this way:* Addition is the residual-network trick: if the condition has nothing useful to say, the residual can be zero and the base path remains intact. Because $c$ is an image-shaped map, $r_{cond}(c)$ is also image-shaped, so the correction can target local geometry instead of applying one global prompt weight everywhere.

### 3. Zero-conv starts as exactly no change

A zero convolution is a learnable linear map whose weights and bias start at zero. At initialization, its output is exactly zero for every condition, so the combined model produces the same output as the frozen base. Training can then grow the residual gradually.

```python
features_w = np.stack([condition_w, conv2d_same_w(condition_w, edge_kernel_w)], axis=0)
zero_weights_w = np.zeros(features_w.shape[0])
zero_bias_w = 0.0
zero_residual_w = np.tensordot(zero_weights_w, features_w, axes=(0, 0)) + zero_bias_w
unchanged_w = base_w + zero_residual_w
print("zero residual max abs:", float(np.max(np.abs(zero_residual_w))))
print("base/control difference:", float(np.max(np.abs(unchanged_w - base_w))))
assert np.max(np.abs(zero_residual_w)) == 0.0
assert np.max(np.abs(unchanged_w - base_w)) == 0.0
```
▶ What you'll see: the residual and the base/control difference are exactly 0.0.

```python
fig_w, ax_w = plt.subplots(1, 2, figsize=(6, 3))
ax_w[0].imshow(base_w, cmap="gray"); ax_w[0].set_title("frozen base")
ax_w[1].imshow(unchanged_w, cmap="gray"); ax_w[1].set_title("after zero-conv")
for a_w in ax_w:
    a_w.axis("off")
plt.suptitle("3: zero-conv preserves the generator at step 0"); plt.show()
```
▶ What you'll see: the two images match because the conditioning branch initially injects nothing.

*Why it's done this way:* The safety math is simple: $h_{out}=h_{base}+0=h_{base}$. A randomly initialized residual branch would add arbitrary spatial artifacts before learning. Zero initialization makes the new branch an identity-preserving extension, which is why ControlNet can be attached to a powerful pretrained model without immediately damaging it.

### 4. A trainable copy learns while the base stays frozen

ControlNet copies blocks of the base network into a conditioning branch, trains that copy, and keeps the original locked. In the toy version, we freeze the base smoothing kernel and train only two residual weights that mix condition features. This separates preservation from adaptation.

```python
target_w = base_w + residual_w
train_w = np.zeros(features_w.shape[0])
lr_w = 0.8
losses_w = []
for step_w in range(40):
    pred_res_w = np.tensordot(train_w, features_w, axes=(0, 0))
    pred_w = base_w + pred_res_w
    err_w = pred_w - target_w
    grad_w = np.array([2 * np.mean(err_w * features_w[k_w]) for k_w in range(features_w.shape[0])])
    train_w -= lr_w * grad_w
    losses_w.append(float(np.mean(err_w ** 2)))
print("learned residual weights:", np.round(train_w, 3))
print("loss start -> end:", round(losses_w[0], 5), "->", round(losses_w[-1], 5))
assert losses_w[-1] < losses_w[0]
```
▶ What you'll see: only the residual weights change, and the loss falls as the conditioning branch learns the target correction.

```python
learned_res_w = np.tensordot(train_w, features_w, axes=(0, 0))
learned_out_w = base_w + learned_res_w
fig_w, ax_w = plt.subplots(1, 3, figsize=(8, 3))
ax_w[0].imshow(target_w, cmap="gray"); ax_w[0].set_title("target")
ax_w[1].imshow(learned_out_w, cmap="gray"); ax_w[1].set_title("learned control")
ax_w[2].plot(losses_w, color="purple"); ax_w[2].set_title("residual loss")
for a_w in ax_w[:2]:
    a_w.axis("off")
plt.suptitle("4: train the copy, not the base"); plt.show()
```
▶ What you'll see: the learned controlled output approaches the target while the learning curve drops.

*Why it's done this way:* The frozen path protects general image knowledge; the copied path supplies degrees of freedom for the new condition. Mathematically, optimization only changes parameters inside $r_{cond}$, so gradients cannot corrupt $h_{base}$. This is the core compromise: adapt to spatial control while preserving the pretrained generator.

### 5. Control strength trades prompt freedom for spatial obedience

Once a residual is learned, we can scale it: $h_{out}=h_{base}+s\,r_{cond}(c)$. Small $s$ leaves the base mostly free; large $s$ forces the geometry harder. This is the same modeling tension as classifier-free guidance, but applied to spatial structure.

```python
strengths_w = np.array([0.0, 0.5, 1.0, 1.5])
outs_w = np.array([base_w + s_w * learned_res_w for s_w in strengths_w])
edge_scores_w = np.array([float(np.mean(out_w[condition_w > 0])) for out_w in outs_w])
print("strengths:", strengths_w)
print("mean value on condition edge:", np.round(edge_scores_w, 3))
assert edge_scores_w[-1] > edge_scores_w[0]
```
▶ What you'll see: the average value on the conditioned edge rises as control strength increases.

```python
fig_w, ax_w = plt.subplots(1, 4, figsize=(9, 2.5))
for idx_w, s_w in enumerate(strengths_w):
    ax_w[idx_w].imshow(outs_w[idx_w], cmap="gray")
    ax_w[idx_w].set_title(f"s={s_w}")
    ax_w[idx_w].axis("off")
plt.suptitle("5: residual scale controls obedience"); plt.show()
```
▶ What you'll see: higher scales make the outline increasingly dominate the denoised image.

*Why it's done this way:* The residual scale is a Lagrange-multiplier-like knob between two objectives: preserve the base model's natural sample and satisfy the condition. Because the correction is additive, scaling it is predictable: doubling $s$ doubles the learned residual before any later nonlinearities.

### 6. Multi-scale injection keeps layout from arriving too late

If a condition is injected only at the end, early layers may have already lost coarse layout. ControlNet-style conditioning is often added at multiple resolutions. In the toy model, we inject a downsampled condition into a coarse map and a full-resolution condition into a fine map.

```python
def down2_w(x_w):
    return x_w.reshape(4, 2, 4, 2).mean(axis=(1, 3))

def up2_w(x_w):
    return np.repeat(np.repeat(x_w, 2, axis=0), 2, axis=1)

coarse_base_w = down2_w(base_w)
coarse_cond_w = down2_w(condition_w)
coarse_res_w = 0.25 * coarse_cond_w
fine_res_w = 0.15 * condition_w
multi_w = up2_w(coarse_base_w + coarse_res_w) + fine_res_w
late_only_w = base_w + fine_res_w
print("coarse shape:", coarse_base_w.shape, "fine shape:", base_w.shape)
print("multi mean:", round(float(multi_w.mean()), 3), "late mean:", round(float(late_only_w.mean()), 3))
assert coarse_base_w.shape == (4, 4)
```
▶ What you'll see: the coarse path is 4×4 while the fine path is 8×8, matching two spatial scales.

```python
fig_w, ax_w = plt.subplots(1, 3, figsize=(8, 3))
ax_w[0].imshow(up2_w(coarse_cond_w), cmap="gray"); ax_w[0].set_title("coarse condition")
ax_w[1].imshow(late_only_w, cmap="gray"); ax_w[1].set_title("late only")
ax_w[2].imshow(multi_w, cmap="gray"); ax_w[2].set_title("multi-scale")
for a_w in ax_w:
    a_w.axis("off")
plt.suptitle("6: inject condition before layout is lost"); plt.show()
```
▶ What you'll see: multi-scale injection changes broad regions and edges, while late-only injection mostly changes thin pixels.

*Why it's done this way:* Spatial structure has frequencies. Coarse maps carry pose and layout; fine maps carry edges and local detail. Injecting only at high resolution can repair texture but may not move the object-level arrangement, so ControlNet distributes residuals across scales.

### ✍️ Toy 1 · A frozen denoiser smooths with a fixed kernel

A frozen base path can be represented by a fixed smoothing kernel: the weights sum to one, so the output stays on the same scale.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)
def t1_conv2d_same(t1_x, t1_k):
    t1_pad = t1_k.shape[0] // 2
    t1_xp = np.pad(t1_x, t1_pad, mode="edge")
    t1_out = np.zeros_like(t1_x, dtype=float)
    for t1_i in range(t1_x.shape[0]):
        for t1_j in range(t1_x.shape[1]):
            t1_patch = t1_xp[t1_i:t1_i+3, t1_j:t1_j+3]
            t1_out[t1_i, t1_j] = np.sum(t1_patch * t1_k)
    return t1_out

t1_img = np.array([[0.0, 0.0, 0.0], [0.0, 2.0, 0.0], [0.0, 0.0, 0.0]])
t1_kernel = np.array([[0.0, 0.125, 0.0], [0.125, 0.5, 0.125], [0.0, 0.125, 0.0]])
t1_out = t1_conv2d_same(t1_img, t1_kernel)  # -> [[0.0, 0.25, 0.0], [0.25, 1.0, 0.25], [0.0, 0.25, 0.0]]
print("kernel sum:", round(float(t1_kernel.sum()), 3))  # -> 1.0
print("input center:", round(float(t1_img[1, 1]), 3))  # -> 2.0
print("smoothed image:", np.round(t1_out, 3).tolist())  # -> [[0.0, 0.25, 0.0], [0.25, 1.0, 0.25], [0.0, 0.25, 0.0]]
print("output center:", round(float(t1_out[1, 1]), 3))  # -> 1.0
assert round(float(t1_kernel.sum()), 3) == 1.0

t1_fig, t1_ax = plt.subplots(1, 2, figsize=(5.2, 2.6))
t1_ax[0].imshow(t1_img, cmap="gray", vmin=0, vmax=2)
t1_ax[0].set_title("input")
t1_ax[1].imshow(t1_out, cmap="gray", vmin=0, vmax=2)
t1_ax[1].set_title("frozen output")
for t1_a in t1_ax:
    t1_a.axis("off")
plt.suptitle("Toy 1 · fixed base smoothing")
plt.show()
```
▶ What you'll see: the bright center pixel is spread to its neighbors without changing the kernel's total scale.

```python
t3_rng = np.random.default_rng(0)
```

### ✍️ Toy 4 · The copied branch learns while the base stays frozen

Train only residual weights against a controlled target; the base array never changes.

```python
import numpy as np

t4_rng = np.random.default_rng(0)
t4_base = np.full((2, 2), 0.5)
t4_feature0 = np.array([[1.0, 0.0], [0.0, 1.0]])
t4_feature1 = 1.0 - t4_feature0
t4_features = np.stack([t4_feature0, t4_feature1], axis=0)
t4_true_weights = np.array([0.4, 0.2])
t4_target_res = np.tensordot(t4_true_weights, t4_features, axes=(0, 0))  # -> [[0.4, 0.2], [0.2, 0.4]]
t4_target = t4_base + t4_target_res
t4_train = np.zeros(2)
t4_lr = 1.0
t4_losses = []
for t4_step in range(3):
    t4_pred_res = np.tensordot(t4_train, t4_features, axes=(0, 0))
    t4_pred = t4_base + t4_pred_res
    t4_err = t4_pred - t4_target
    t4_loss = np.mean(t4_err ** 2)
    t4_losses.append(float(t4_loss))
    t4_grad = np.array([2 * np.mean(t4_err * t4_features[t4_k]) for t4_k in range(2)])
    t4_train = t4_train - t4_lr * t4_grad
t4_learned_res = np.tensordot(t4_train, t4_features, axes=(0, 0))
t4_learned = t4_base + t4_learned_res
t4_base_change = np.max(np.abs(t4_base - np.full((2, 2), 0.5)))  # -> 0.0
print("target residual:", np.round(t4_target_res, 3).tolist())  # -> [[0.4, 0.2], [0.2, 0.4]]
print("learned weights:", np.round(t4_train, 3).tolist())  # -> [0.4, 0.2]
print("losses:", [round(t4_loss, 5) for t4_loss in t4_losses])  # -> [0.1, 0.0, 0.0]
print("base change:", round(float(t4_base_change), 3))  # -> 0.0
assert t4_losses[-1] < t4_losses[0]

t4_fig, t4_ax = plt.subplots(1, 3, figsize=(7.2, 2.6))
t4_ax[0].imshow(t4_target, cmap="gray", vmin=0.5, vmax=0.9)
t4_ax[0].set_title("target")
t4_ax[1].imshow(t4_learned, cmap="gray", vmin=0.5, vmax=0.9)
t4_ax[1].set_title("learned")
t4_ax[2].plot(t4_losses, marker="o", color="purple")
t4_ax[2].set_title("loss")
for t4_a in t4_ax[:2]:
    t4_a.axis("off")
plt.suptitle("Toy 4 · train residual weights only")
plt.show()
```
▶ What you'll see: the learned residual matches the target while the loss drops to zero and the base remains unchanged.

### ✍️ Toy 6 · Multi-scale injection adds coarse and fine control

A downsampled condition changes broad regions, while the full-resolution condition adds fine detail.

```python
import numpy as np

t6_rng = np.random.default_rng(0)
def t6_down2(t6_x):
    return t6_x.reshape(2, 2, 2, 2).mean(axis=(1, 3))

def t6_up2(t6_x):
    return np.repeat(np.repeat(t6_x, 2, axis=0), 2, axis=1)

t6_base = np.zeros((4, 4))
t6_condition = np.zeros((4, 4))
t6_condition[1:3, 1:3] = 1.0
t6_coarse_base = t6_down2(t6_base)
t6_coarse_cond = t6_down2(t6_condition)  # -> [[0.25, 0.25], [0.25, 0.25]]
t6_coarse_res = 0.4 * t6_coarse_cond
t6_fine_res = 0.1 * t6_condition
t6_multi = t6_up2(t6_coarse_base + t6_coarse_res) + t6_fine_res
t6_late = t6_base + t6_fine_res
t6_multi_mean = t6_multi.mean()  # -> 0.125
t6_late_mean = t6_late.mean()  # -> 0.025
```

## 🛠️ Setup

```python
import numpy as np  # load NumPy for arrays, toy convolutions, and numerical checks.
import matplotlib.pyplot as plt  # load Matplotlib for every heatmap, bar chart, and line plot.
np.random.seed(0)  # make all examples reproducible.

def conv2d_same(x, k):  # compute a tiny same-size 3x3 convolution using edge padding.
    pad = k.shape[0] // 2  # infer the one-pixel padding for a 3x3 kernel.
    xp = np.pad(x, pad, mode="edge")  # pad with edge values so output size matches input size.
    out = np.zeros_like(x, dtype=float)  # allocate the output image.
    for i in range(x.shape[0]):  # loop over image rows.
        for j in range(x.shape[1]):  # loop over image columns.
            out[i, j] = np.sum(xp[i:i+3, j:j+3] * k)  # multiply the local patch by the kernel and sum.
    return out  # return the filtered image.

def show_img(x, title, cmap="gray"):  # show one compact image-like array.
    plt.figure(figsize=(3.5, 3))  # create a compact figure.
    plt.imshow(x, cmap=cmap)  # display array values as colors.
    plt.colorbar(label="value")  # add a numeric color scale.
    plt.title(title)  # title the image.
    plt.axis("off")  # hide pixel ticks.
    plt.show()  # display the plot.
```

### Advanced 1 — Fit a tiny controlled denoising step

**Goal.** Train a small conditioning branch on several synthetic examples, because ControlNet learns a mapping from condition maps to residual corrections. We build it in 5 steps.


