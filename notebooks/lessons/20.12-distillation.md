# 20.12 — Distillation

Distillation trains a compact student model to imitate a stronger teacher, so deployment gets much of the teacher's decision structure at a fraction of the parameters and latency. In this lesson, we build temperature softmax, soft-target KL loss, hard-label loss, logit matching, feature matching, and a tiny NumPy teacher/student MLP from scratch so every production tradeoff is inspectable.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build distillation one idea at a time. Run each cell in order and read the printed intermediate values — every probability, loss, gradient, and deployment ratio is exposed. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

### 1. The production reason: teacher quality versus student budget

Distillation starts from a production mismatch: the best teacher may be too large or slow to serve, while a small student fits the budget but loses accuracy if it only sees hard labels. The compression target is not magic — it is a ratio calculation. If the student has 12M parameters instead of 120M and answers in 18ms instead of 90ms, the serving win is easy to quantify before we even train.

```python
teacher_params_w = 120.0  # teacher size in millions of parameters.
student_params_w = 12.0  # student size in millions of parameters.
teacher_latency_w = 90.0  # teacher latency in milliseconds.
student_latency_w = 18.0  # student latency in milliseconds.
size_ratio_w = student_params_w / teacher_params_w  # fraction of teacher size kept by the student.
speedup_w = teacher_latency_w / student_latency_w  # serving speedup from using the student.
print("student size ratio:", round(size_ratio_w, 2))
print("latency speedup:", round(speedup_w, 1), "x")
assert round(size_ratio_w, 2) == 0.10
assert round(speedup_w, 1) == 5.0
```
▶ What you'll see: the student is 10% of the teacher size and 5× faster in this deployment arithmetic.

```python
plt.figure(figsize=(4.8, 3))
plt.bar(["teacher", "student"], [teacher_latency_w, student_latency_w], color=["gray", "teal"])
plt.ylabel("latency (ms)")
plt.title("1: distillation is motivated by serving budget")
plt.show()
```
▶ What you'll see: the student bar is much shorter, making the production motivation visible.

*Why it's done this way:* Distillation is useful only if the smaller model preserves enough behavior to justify the budget savings. Writing the ratios first keeps the ML objective tied to the deployment constraint: the student must be cheaper, and the loss must teach it more than hard labels alone.

### 2. Temperature softmax and soft targets

A one-hot label says only "class 0 is correct." A teacher distribution says "class 0 is most likely, class 1 is a near miss, class 2 is far away." Temperature softmax exposes that ranking by dividing logits by $T$ before exponentiating: $p_i^T=\exp(z_i/T)/\sum_j\exp(z_j/T)$. Higher $T$ makes the distribution softer; too high makes every class nearly equal.

```python
logits_w = np.array([2.0, 1.0, 0.0])  # teacher logits for three classes.
def softmax_temp_w(z_w, T_w):
    shifted_w = z_w / T_w - np.max(z_w / T_w)  # subtract max for numerical stability.
    exp_w = np.exp(shifted_w)
    return exp_w / np.sum(exp_w)

for T_w in [1.0, 2.0, 5.0]:
    p_w = softmax_temp_w(logits_w, T_w)
    print(f"T={T_w}:", np.round(p_w, 3))
assert np.allclose(np.round(softmax_temp_w(logits_w, 2.0), 3), [0.506, 0.307, 0.186])
```
▶ What you'll see: at T=2 the top class is 0.506 instead of an almost-one one-hot target, and lower classes remain meaningfully ordered.

```python
Ts_w = [1.0, 2.0, 5.0]
probs_by_T_w = np.vstack([softmax_temp_w(logits_w, T_w) for T_w in Ts_w])
plt.figure(figsize=(5.2, 3))
for row_w, T_w in zip(probs_by_T_w, Ts_w):
    plt.plot([0, 1, 2], row_w, marker="o", label=f"T={T_w}")
plt.xticks([0, 1, 2])
plt.xlabel("class")
plt.ylabel("probability")
plt.title("2: temperature reveals soft targets")
plt.legend()
plt.show()
```
▶ What you'll see: increasing temperature lowers the winner and lifts the losing classes, exposing the teacher's class ranking.

*Why it's done this way:* Dividing logits by $T$ shrinks their gaps before exponentiation. Since exponentials amplify gaps, temperature controls how much the teacher distribution says "winner only" versus "winner plus near-miss structure." That near-miss structure is the soft target the student could never infer from a one-hot label.

### 3. KL-divergence soft loss

To imitate the teacher, the student minimizes cross-entropy from teacher probabilities to student probabilities, equivalently KL divergence up to the teacher entropy constant: $KL(p_T^T\Vert p_S^T)=\sum_i p_{T,i}^T\log(p_{T,i}^T/p_{S,i}^T)$. The teacher weights each class's penalty, so mismatching a near-miss class matters more than mismatching a class the teacher considers impossible.

```python
teacher_soft_w = softmax_temp_w(np.array([2.0, 1.0, 0.0]), 2.0)
student_soft_w = softmax_temp_w(np.array([1.2, 0.7, -0.2]), 2.0)
kl_terms_w = teacher_soft_w * (np.log(teacher_soft_w + 1e-12) - np.log(student_soft_w + 1e-12))
kl_w = float(np.sum(kl_terms_w))
print("teacher:", np.round(teacher_soft_w, 3))
print("student:", np.round(student_soft_w, 3))
print("KL terms:", np.round(kl_terms_w, 4), "KL:", round(kl_w, 4))
assert round(kl_w, 4) == 0.0092
```
▶ What you'll see: the total KL is small but nonzero because the student distribution is close, not identical, to the teacher.

```python
plt.figure(figsize=(5, 3))
x_w = np.arange(3)
plt.bar(x_w - 0.18, teacher_soft_w, width=0.36, label="teacher", color="gray")
plt.bar(x_w + 0.18, student_soft_w, width=0.36, label="student", color="teal")
plt.xticks(x_w, ["class0", "class1", "class2"])
plt.ylabel("probability at T=2")
plt.title("3: KL compares full distributions")
plt.legend()
plt.show()
```
▶ What you'll see: KL sees all three bars, not only whether the top class matches.

*Why it's done this way:* Cross-entropy with a one-hot target has gradient $p_S-y$, so only the true class receives direct positive target mass. Distillation uses $p_S^T-p_T^T$, giving every class a target. The student therefore learns the teacher's relative uncertainty, not merely its argmax.

### 4. Dark knowledge in softened wrong classes

"Dark knowledge" is the teacher's information about wrong classes. If class 1 is much more plausible than class 2, both are wrong under the hard label, but they should not be treated equally. Soft targets preserve that ranking, which helps a smaller student shape smoother decision boundaries.

```python
teacher_logits_dark_w = np.array([6.0, 4.8, 0.2, -1.0])  # class 1 is a near miss; classes 2-3 are far.
hard_label_dark_w = np.array([1.0, 0.0, 0.0, 0.0])
soft_dark_w = softmax_temp_w(teacher_logits_dark_w, 3.0)
wrong_ratio_w = soft_dark_w[1] / soft_dark_w[2]
print("hard label:", hard_label_dark_w)
print("soft target:", np.round(soft_dark_w, 3))
print("near/far wrong-class ratio:", round(float(wrong_ratio_w), 2))
assert round(float(wrong_ratio_w), 2) == 4.63
```
▶ What you'll see: the hard label gives every wrong class 0, while the teacher says class 1 is about 4.63× more plausible than class 2.

```python
plt.figure(figsize=(5, 3))
plt.bar(np.arange(4) - 0.18, hard_label_dark_w, width=0.36, label="hard label", color="black")
plt.bar(np.arange(4) + 0.18, soft_dark_w, width=0.36, label="teacher T=3", color="orange")
plt.xticks(range(4), ["true", "near", "far", "very far"])
plt.ylabel("target mass")
plt.title("4: softened logits carry dark knowledge")
plt.legend()
plt.show()
```
▶ What you'll see: only the soft target shows that the near-miss class deserves more probability than the far classes.

*Why it's done this way:* The wrong-class probabilities are not noise; they encode class similarity learned by the teacher. Matching them gives the student a richer geometry: move probability from far classes first, then decide among plausible classes, instead of learning from a single hard spike.

### 5. Blending hard and soft losses, including the $T^2$ scale

Production distillation usually blends two signals: the hard-label cross-entropy for correctness and the teacher KL for behavior transfer. A common objective is $L=\alpha T^2 KL(p_T^T\Vert p_S^T)+(1-\alpha)CE(y,p_S)$. The $T^2$ factor offsets the gradient shrinkage caused by dividing logits by $T$, keeping the soft loss comparable across temperatures.

```python
def ce_hard_w(y_idx_w, logits_w):
    p_w = softmax_temp_w(logits_w, 1.0)
    return float(-np.log(p_w[y_idx_w] + 1e-12)), p_w

def kd_loss_w(teacher_logits_w, student_logits_w, y_idx_w, T_w=2.0, alpha_w=0.7):
    pt_w = softmax_temp_w(teacher_logits_w, T_w)
    psT_w = softmax_temp_w(student_logits_w, T_w)
    soft_w = float(np.sum(pt_w * (np.log(pt_w + 1e-12) - np.log(psT_w + 1e-12))))
    hard_w, ps_w = ce_hard_w(y_idx_w, student_logits_w)
    return alpha_w * (T_w ** 2) * soft_w + (1 - alpha_w) * hard_w, soft_w, hard_w, ps_w

loss_w, soft_part_w, hard_part_w, ps_w = kd_loss_w(np.array([2.0, 1.0, 0.0]), np.array([0.8, 0.9, 0.1]), 0)
print("soft KL:", round(soft_part_w, 3), "hard CE:", round(hard_part_w, 3), "blended:", round(loss_w, 3))
assert round(loss_w, 3) == 0.408
```
▶ What you'll see: the blended loss combines teacher imitation and true-label correction in one scalar.

```python
alpha_grid_w = np.linspace(0, 1, 6)
blend_grid_w = alpha_grid_w * (2.0 ** 2) * soft_part_w + (1 - alpha_grid_w) * hard_part_w
print("blend losses:", np.round(blend_grid_w, 3))
plt.figure(figsize=(5, 3))
plt.plot(alpha_grid_w, blend_grid_w, marker="o", color="purple")
plt.xlabel("alpha: weight on soft teacher loss")
plt.ylabel("combined loss")
plt.title("5: alpha trades correctness and imitation")
plt.show()
```
▶ What you'll see: changing alpha moves the objective between hard-label CE and temperature-scaled teacher KL.

*Why it's done this way:* The hard term prevents the student from copying teacher mistakes blindly; the soft term transfers the teacher's probability structure. Temperature softmax makes gradients roughly scale like $1/T^2$, so multiplying the KL term by $T^2$ keeps the soft signal from disappearing when $T$ increases.

### 6. Training a teacher and two students from scratch

Now we train a larger NumPy MLP teacher, then train two smaller students: one only on hard labels and one with KD. The dataset is synthetic but deliberately nonlinear, so the teacher can learn smoother class structure than a tiny student would get from hard labels alone.

```python
rng_w = np.random.default_rng(0)
n_per_class_w = 80
centers_w = np.array([[0.0, 0.0], [2.0, 0.4], [0.8, 1.9]])
X_parts_w = [centers_w[i] + 0.45 * rng_w.normal(size=(n_per_class_w, 2)) for i in range(3)]
X_w = np.vstack(X_parts_w)
y_w = np.repeat(np.arange(3), n_per_class_w)
perm_w = rng_w.permutation(len(y_w))
X_w, y_w = X_w[perm_w], y_w[perm_w]
Y_w = np.eye(3)[y_w]
X_w = (X_w - X_w.mean(axis=0)) / X_w.std(axis=0)
print("X shape:", X_w.shape, "class counts:", np.bincount(y_w))
```
▶ What you'll see: 240 two-dimensional examples balanced across three classes.

```python
def init_mlp_w(rng_w, hidden_w):
    return {"W1": 0.6 * rng_w.normal(size=(2, hidden_w)), "b1": np.zeros(hidden_w),
            "W2": 0.6 * rng_w.normal(size=(hidden_w, 3)), "b2": np.zeros(3)}

def forward_w(params_w, X_in_w):
    h_pre_w = X_in_w @ params_w["W1"] + params_w["b1"]
    h_w = np.tanh(h_pre_w)
    logits_out_w = h_w @ params_w["W2"] + params_w["b2"]
    return h_w, logits_out_w

def train_hard_w(params_w, X_in_w, y_in_w, steps_w=700, lr_w=0.08):
    losses_w, accs_w = [], []
    Y_in_w = np.eye(3)[y_in_w]
    for step_w in range(steps_w):
        h_w, z_w = forward_w(params_w, X_in_w)
        p_w = softmax_temp_w(z_w, 1.0)
        dz_w = (p_w - Y_in_w) / len(y_in_w)
        params_w["W2"] -= lr_w * (h_w.T @ dz_w)
        params_w["b2"] -= lr_w * dz_w.sum(axis=0)
        dh_w = dz_w @ params_w["W2"].T * (1 - h_w ** 2)
        params_w["W1"] -= lr_w * (X_in_w.T @ dh_w)
        params_w["b1"] -= lr_w * dh_w.sum(axis=0)
        if step_w % 50 == 0:
            losses_w.append(float(-np.mean(np.log(p_w[np.arange(len(y_in_w)), y_in_w] + 1e-12))))
            accs_w.append(float(np.mean(np.argmax(p_w, axis=1) == y_in_w)))
    return losses_w, accs_w

teacher_w = init_mlp_w(rng_w, 16)
teacher_losses_w, teacher_accs_w = train_hard_w(teacher_w, X_w, y_w, steps_w=900, lr_w=0.09)
_, teacher_logits_w = forward_w(teacher_w, X_w)
teacher_acc_w = float(np.mean(np.argmax(teacher_logits_w, axis=1) == y_w))
print("teacher accuracy:", round(teacher_acc_w, 3))
assert teacher_acc_w > 0.90
```
▶ What you'll see: the larger teacher reaches high accuracy on the toy nonlinear task.

```python
def train_student_w(params_w, X_in_w, y_in_w, teacher_logits_in_w=None, steps_w=700, lr_w=0.08, T_w=3.0, alpha_w=0.7):
    Y_in_w = np.eye(3)[y_in_w]
    pt_w = softmax_temp_w(teacher_logits_in_w, T_w) if teacher_logits_in_w is not None else None
    losses_w, accs_w = [], []
    for step_w in range(steps_w):
        h_w, z_w = forward_w(params_w, X_in_w)
        p_w = softmax_temp_w(z_w, 1.0)
        if pt_w is None:
            dz_w = (p_w - Y_in_w) / len(y_in_w)
            loss_w = float(-np.mean(np.log(p_w[np.arange(len(y_in_w)), y_in_w] + 1e-12)))
        else:
            psT_w = softmax_temp_w(z_w, T_w)
            dz_hard_w = (p_w - Y_in_w) / len(y_in_w)
            dz_soft_w = (alpha_w * T_w) * (psT_w - pt_w) / len(y_in_w)
            dz_w = (1 - alpha_w) * dz_hard_w + dz_soft_w
            hard_w = float(-np.mean(np.log(p_w[np.arange(len(y_in_w)), y_in_w] + 1e-12)))
            soft_w = float(np.mean(np.sum(pt_w * (np.log(pt_w + 1e-12) - np.log(psT_w + 1e-12)), axis=1)))
            loss_w = alpha_w * T_w ** 2 * soft_w + (1 - alpha_w) * hard_w
        old_W2_w = params_w["W2"].copy()
        params_w["W2"] -= lr_w * (h_w.T @ dz_w)
        params_w["b2"] -= lr_w * dz_w.sum(axis=0)
        dh_w = dz_w @ old_W2_w.T * (1 - h_w ** 2)
        params_w["W1"] -= lr_w * (X_in_w.T @ dh_w)
        params_w["b1"] -= lr_w * dh_w.sum(axis=0)
        if step_w % 50 == 0:
            losses_w.append(loss_w)
            accs_w.append(float(np.mean(np.argmax(p_w, axis=1) == y_in_w)))
    return losses_w, accs_w

student_hard_w = init_mlp_w(np.random.default_rng(1), 4)
student_kd_w = init_mlp_w(np.random.default_rng(1), 4)
hard_losses_w, hard_accs_w = train_student_w(student_hard_w, X_w, y_w, None, steps_w=650, lr_w=0.07)
kd_losses_w, kd_accs_w = train_student_w(student_kd_w, X_w, y_w, teacher_logits_w, steps_w=650, lr_w=0.07, T_w=3.0, alpha_w=0.7)
_, z_hard_w = forward_w(student_hard_w, X_w)
_, z_kd_w = forward_w(student_kd_w, X_w)
acc_hard_w = float(np.mean(np.argmax(z_hard_w, axis=1) == y_w))
acc_kd_w = float(np.mean(np.argmax(z_kd_w, axis=1) == y_w))
print("student hard accuracy:", round(acc_hard_w, 3), "student KD accuracy:", round(acc_kd_w, 3))
assert acc_kd_w >= acc_hard_w - 0.02
```
▶ What you'll see: the KD student is competitive with, and often slightly better than, the hard-label student despite the same small hidden size.

```python
plt.figure(figsize=(5.2, 3))
plt.plot(np.arange(len(hard_accs_w)) * 50, hard_accs_w, marker="o", label="hard-label student")
plt.plot(np.arange(len(kd_accs_w)) * 50, kd_accs_w, marker="o", label="KD student")
plt.axhline(teacher_acc_w, color="gray", linestyle="--", label="teacher")
plt.xlabel("training step")
plt.ylabel("accuracy")
plt.title("6: student accuracy with and without KD")
plt.legend()
plt.show()
```
▶ What you'll see: compare the two student curves against the teacher reference; KD should track or beat hard-only learning on this toy run.

*Why it's done this way:* The teacher first converts finite labels into a smoother function over the input space. The KD student then trains on both labels and that function's full probability vector. Backprop is ordinary MLP calculus; the only new part is replacing part of the output gradient with a teacher-distribution gradient.

### 7. Logit matching and feature matching

Distillation can match more than probabilities. Logit matching directly pulls the student's pre-softmax scores toward the teacher's scores, while feature matching aligns hidden representations through a projection. These terms are useful when we care about behavior before the final softmax or when the teacher's intermediate geometry is valuable.

```python
teacher_logits_match_w = np.array([[2.4, 1.1, -0.5], [0.2, 2.0, 0.1]])
student_logits_match_w = np.array([[1.8, 0.9, -0.2], [0.4, 1.4, 0.3]])
logit_mse_w = float(np.mean((student_logits_match_w - teacher_logits_match_w) ** 2))
logit_grad_w = 2 * (student_logits_match_w - teacher_logits_match_w) / student_logits_match_w.size
print("logit MSE:", round(logit_mse_w, 3))
print("logit gradient first row:", np.round(logit_grad_w[0], 3))
assert round(logit_mse_w, 3) == 0.155
```
▶ What you'll see: logit matching has a simple squared-error gradient that moves each student logit toward its teacher counterpart.

```python
teacher_feat_w = np.array([[1.0, 0.2, -0.4, 0.7], [0.1, 0.9, 0.3, -0.2]])
student_feat_w = np.array([[0.8, -0.1], [0.0, 0.7]])
proj_w = np.array([[1.0, 0.2, -0.3, 0.4], [0.1, 0.8, 0.5, -0.2]])
student_projected_w = student_feat_w @ proj_w
feature_mse_w = float(np.mean((student_projected_w - teacher_feat_w) ** 2))
print("projected student features:\n", np.round(student_projected_w, 3))
print("feature MSE:", round(feature_mse_w, 3))
assert round(feature_mse_w, 3) == 0.04
```
▶ What you'll see: a projection lets a smaller two-dimensional student hidden state align with a four-dimensional teacher hidden state.

```python
plt.figure(figsize=(5, 3))
plt.plot(teacher_feat_w[0], marker="o", label="teacher feature", color="gray")
plt.plot(student_projected_w[0], marker="o", label="projected student", color="teal")
plt.title("7: feature matching after projection")
plt.xlabel("teacher feature coordinate")
plt.ylabel("activation")
plt.legend()
plt.show()
```
▶ What you'll see: the projected student feature follows the teacher's hidden pattern coordinate by coordinate.

*Why it's done this way:* Softmax discards information: adding the same constant to every logit changes no probabilities, and hidden features are invisible to output-only losses. Logit and feature matching add auxiliary constraints, helping the student imitate the teacher's margins and representation geometry when probability matching alone is too weak.

### Basic 3 — Apply temperature softmax

**Goal.** Soften a teacher distribution with temperature, because near-miss classes are easier to see when logits are divided by T. We build it in 2 steps.

```python
logits_b3 = np.array([2.0, 1.0, 0.0])
T_b3 = 2.0
scaled_b3 = logits_b3 / T_b3
print("scaled logits:", scaled_b3)
```
▶ What you'll see: temperature halves the gaps between logits.


### Basic 7 — Compute KL soft loss

**Goal.** Compare teacher and student distributions at temperature, because distillation imitates the full teacher probability vector. We build it in 2 steps.

```python
teacher_logits_b7 = np.array([2.0, 1.0, 0.0])
student_logits_b7 = np.array([0.8, 0.9, 0.1])
T_b7 = 2.0
def sm_b7(z_b7):
    e_b7 = np.exp(z_b7 / T_b7 - np.max(z_b7 / T_b7))
    return e_b7 / np.sum(e_b7)
pt_b7 = sm_b7(teacher_logits_b7)
ps_b7 = sm_b7(student_logits_b7)
print("teacher/student T=2:", np.round(pt_b7, 3), np.round(ps_b7, 3))
```
▶ What you'll see: the two softened distributions are comparable class by class.

```python
kl_b7 = np.sum(pt_b7 * (np.log(pt_b7 + 1e-12) - np.log(ps_b7 + 1e-12)))
print("KL:", round(float(kl_b7), 3))
assert round(float(kl_b7), 3) == 0.043
```
▶ What you'll see: KL penalizes the student for putting too much probability on class 1 and too little on class 0.

```python
plt.figure(figsize=(5, 3))
x_b7 = np.arange(3)
plt.bar(x_b7 - 0.18, pt_b7, width=0.36, label="teacher T=2", color="gray")

plt.xticks(x_b7, ["class 0", "class 1", "class 2"])
plt.ylabel("probability")
plt.title("B7: KL matches full distributions")
plt.legend()
plt.show()
```
▶ What you'll see: the student overweights class 1 and underweights class 0 relative to the teacher.

👀 Takeaway: KL is a distribution-matching loss, not merely an accuracy loss.

### Basic 9 — Inspect the KD output gradient


### Easy 5 — Compare accuracy with and without KD

**Goal.** Train two same-size students from the same initialization, because a fair KD comparison changes only the loss. We build it in 4 steps.

```python
rng_e5 = np.random.default_rng(50)

print("comparison dataset:", X_e5.shape)
```
▶ What you'll see: both students will train on the same examples.

```python

    Ht_e5 = np.tanh(X_e5 @ Wt1_e5 + bt1_e5); Zt_e5 = Ht_e5 @ Wt2_e5 + bt2_e5

    Wt2_e5 -= 0.08 * (Ht_e5.T @ dZt_e5); bt2_e5 -= 0.08 * dZt_e5.sum(axis=0)

```

### Advanced 1 — Sweep temperature values

**Goal.** Measure how T changes soft-target entropy and KD loss, because too-low T is one-hot-like and too-high T becomes flat. We build it in 3 steps.

```python
teacher_logits_a1 = np.array([4.0, 2.5, 0.0, -1.0])
student_logits_a1 = np.array([2.0, 1.7, 0.2, -0.4])
Ts_a1 = np.array([1.0, 2.0, 4.0, 8.0])
print("temperatures:", Ts_a1)
```
▶ What you'll see: the sweep covers sharp through very soft distributions.

```python
entropy_a1 = []
kl_scaled_a1 = []
for T_a1 in Ts_a1:
    pt_a1 = np.exp(teacher_logits_a1 / T_a1 - np.max(teacher_logits_a1 / T_a1)); pt_a1 = pt_a1 / pt_a1.sum()
    ps_a1 = np.exp(student_logits_a1 / T_a1 - np.max(student_logits_a1 / T_a1)); ps_a1 = ps_a1 / ps_a1.sum()
    entropy_a1.append(float(-np.sum(pt_a1 * np.log(pt_a1 + 1e-12))))
    kl_scaled_a1.append(float(T_a1 ** 2 * np.sum(pt_a1 * (np.log(pt_a1 + 1e-12) - np.log(ps_a1 + 1e-12)))))
print("teacher entropy:", np.round(entropy_a1, 3))
print("T^2 KL:", np.round(kl_scaled_a1, 3))
assert entropy_a1[-1] > entropy_a1[0]
```
▶ What you'll see: entropy increases with temperature, while the scaled KL stays in a comparable numeric range.

```python
plt.figure(figsize=(5, 3))
plt.plot(Ts_a1, entropy_a1, marker="o", label="teacher entropy")
plt.plot(Ts_a1, kl_scaled_a1, marker="s", label="T² KL")
plt.xlabel("temperature T")
plt.title("A1: temperature sweep")
plt.legend()
plt.show()
```
▶ What you'll see: temperature makes targets more uniform, so useful T is a middle-ground choice.

👀 Takeaway: choose temperature by validation behavior, not by assuming higher is always better.

### Advanced 2 — Sweep alpha values

**Goal.** Track hard CE and teacher KL as alpha changes, because alpha controls the risk of copying versus ignoring the teacher. We build it in 3 steps.
