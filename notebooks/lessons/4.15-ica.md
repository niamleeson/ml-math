# 4.15 — Independent Component Analysis

Independent Component Analysis (ICA) is an unsupervised method for separating mixed observations into hidden signals by looking for directions that are statistically independent, not just uncorrelated. In this lesson, we build the whole pipeline from scratch: center the data, whiten it with SVD geometry, rotate the whitened cloud toward maximum non-Gaussianity, and remember that the recovered components are only identifiable up to order, sign, and scale.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build Independent Component Analysis one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math is visible enough to audit by hand. This walkthrough is self-contained and uses a `_w` suffix on variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, linear algebra, random signals, and SVD.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for signals and optimization.
```

### 1. Mixed observations: the problem ICA is trying to undo

ICA starts with the opposite of a labeled dataset: we observe only mixtures. Imagine two hidden sources — a smooth wave and a blocky pulse — recorded by two sensors. Each sensor hears a different linear combination, so the data matrix is $X = SA^\top$: rows are time points, columns are sensors, and the source matrix $S$ is hidden.

```python
t_w = np.linspace(0, 8, 500)  # time axis for a tiny two-source signal demo.
s1_w = np.sin(2 * np.pi * 0.7 * t_w)  # smooth source.
s2_w = np.sign(np.sin(2 * np.pi * 1.3 * t_w + 0.4))  # blocky non-Gaussian source.
S_w = np.c_[s1_w, s2_w]  # hidden sources as columns.
S_w = (S_w - S_w.mean(axis=0)) / S_w.std(axis=0)  # standardize so neither source dominates by units.
print("S shape:", S_w.shape)  # 500 time points x 2 sources.
print("source means:", np.round(S_w.mean(axis=0), 3))  # centered.
assert S_w.shape == (500, 2)
```
▶ What you'll see: two standardized hidden signals arranged as a 500×2 matrix.

```python
A_w = np.array([[1.0, 0.6], [0.4, 1.2]])  # unknown mixing matrix: each sensor is a source blend.
X_w = S_w @ A_w.T  # observed sensor readings.
print("mixing matrix A:\n", A_w)  # inspect the blend coefficients.
print("X shape:", X_w.shape)  # same rows, observed sensor columns.
assert round(float(np.linalg.det(A_w)), 2) == 0.96
```
▶ What you'll see: the determinant is nonzero, so the mixing can be inverted in principle.

```python
fig, ax = plt.subplots(1, 2, figsize=(7, 2.8))
ax[0].plot(t_w[:120], S_w[:120, 0], label="source 0")
ax[0].plot(t_w[:120], S_w[:120, 1], label="source 1", alpha=0.8)
ax[0].set_title("hidden sources"); ax[0].legend()
ax[1].plot(t_w[:120], X_w[:120, 0], label="sensor 0")
ax[1].plot(t_w[:120], X_w[:120, 1], label="sensor 1", alpha=0.8)
ax[1].set_title("observed mixtures"); ax[1].legend()
plt.suptitle("1: sources are cleaner than sensors"); plt.show()
```
▶ What you'll see: each sensor trace combines both source shapes, so visual inspection alone no longer gives the clean signals.

*Why it's done this way:* the linear mixing model is the smallest setting where source separation is meaningful. If $A$ is invertible, some unmixing matrix exists; ICA's job is to find it without seeing $S$ by using a statistical criterion rather than labels.

### 2. Centering and covariance: remove offsets before searching for structure

The first preprocessing step is centering. ICA cares about the shape and orientation of the cloud, not about an arbitrary sensor baseline. Subtracting column means turns the second-moment calculation into covariance, so later rotations describe variation around the origin.

```python
mean_w = X_w.mean(axis=0)  # one mean per sensor column.
Xc_w = X_w - mean_w  # centered observations.
print("sensor means before:", np.round(mean_w, 3))
print("sensor means after:", np.round(Xc_w.mean(axis=0), 3))
assert np.allclose(Xc_w.mean(axis=0), [0, 0], atol=1e-12)
```
▶ What you'll see: the centered data has mean zero in both sensor coordinates.

```python
cov_w = (Xc_w.T @ Xc_w) / Xc_w.shape[0]  # population covariance for this demonstration.
print("covariance:\n", np.round(cov_w, 3))
print("off-diagonal covariance:", round(float(cov_w[0, 1]), 3))
assert cov_w.shape == (2, 2)
```
▶ What you'll see: a nonzero off-diagonal entry, meaning the two sensor columns are correlated mixtures.

```python
plt.figure(figsize=(4, 3.4))
plt.scatter(Xc_w[:, 0], Xc_w[:, 1], s=8, alpha=0.35, color="steelblue")
plt.axhline(0, color="black", linewidth=0.6); plt.axvline(0, color="black", linewidth=0.6)
plt.title("2: centered sensor cloud"); plt.xlabel("sensor 0"); plt.ylabel("sensor 1"); plt.show()
```
▶ What you'll see: an elongated, tilted cloud; the tilt is covariance caused by mixing.

*Why it's done this way:* covariance is $E[(x-\mu)(x-\mu)^\top]$, so centering is not cosmetic. Without it, a large offset would look like structure and contaminate the directions chosen by SVD and whitening.

### 3. Whitening with SVD: make directions uncorrelated and unit variance

Whitening is the bridge from PCA geometry to ICA. SVD gives orthogonal directions and singular values. Dividing by the square roots of covariance eigenvalues rescales the centered cloud so its covariance becomes the identity. After whitening, every remaining orthogonal rotation has the same covariance, so ICA must use a stronger criterion than variance.

```python
U_w, sing_w, Vt_w = np.linalg.svd(Xc_w, full_matrices=False)  # Xc = U Sigma V^T.
energies_w = sing_w ** 2
print("singular values:", np.round(sing_w, 3))
print("energy fractions:", np.round(energies_w / energies_w.sum(), 3))
assert len(sing_w) == 2
```
▶ What you'll see: the first singular value explains more variance, but variance alone is not ICA's final target.

```python
eigvals_w = (sing_w ** 2) / Xc_w.shape[0]  # covariance eigenvalues.
whitener_w = Vt_w.T @ np.diag(1.0 / np.sqrt(eigvals_w)) @ Vt_w  # covariance^{-1/2}.
Xwhite_w = Xc_w @ whitener_w  # whitened observations.
white_cov_w = (Xwhite_w.T @ Xwhite_w) / Xwhite_w.shape[0]
print("whitened covariance:\n", np.round(white_cov_w, 3))
assert np.allclose(np.round(white_cov_w, 3), np.eye(2))
```
▶ What you'll see: the whitened covariance is approximately the identity matrix.

```python
fig, ax = plt.subplots(1, 2, figsize=(7, 3))
ax[0].scatter(Xc_w[:, 0], Xc_w[:, 1], s=8, alpha=0.35, color="steelblue")
ax[0].set_title("centered mixtures")
ax[1].scatter(Xwhite_w[:, 0], Xwhite_w[:, 1], s=8, alpha=0.35, color="seagreen")
ax[1].set_title("whitened data")
for a_w in ax:
    a_w.axhline(0, color="black", linewidth=0.5); a_w.axvline(0, color="black", linewidth=0.5)
plt.suptitle("3: whitening removes covariance scale and tilt"); plt.show()
```
▶ What you'll see: the whitened cloud has balanced axes, but its non-Gaussian shape still contains source information.

*Why it's done this way:* decorrelation is necessary but not sufficient. PCA would stop after choosing high-variance axes; ICA whitens first so variance cannot decide anymore, then searches rotations using independence or non-Gaussianity.

### 4. Non-Gaussianity: the criterion that separates ICA from PCA

The central ICA idea is that mixtures of independent non-Gaussian sources tend to look more Gaussian than the sources themselves. A simple computable proxy is absolute kurtosis: $E[z^4]-3$ is near zero for a Gaussian and far from zero for heavy-tailed or flat/blocky signals. In whitened data, we scan unit directions and look for projections with large absolute kurtosis.

```python
def kurtosis_w(z):
    z = (z - z.mean()) / z.std()  # standardize so the fourth moment is comparable.
    return float(np.mean(z ** 4) - 3.0)  # excess kurtosis: Gaussian is about 0.

angles_w = np.linspace(0, np.pi, 181)  # directions on the unit circle; sign repeats after pi.
kurt_w = []
for theta_w in angles_w:
    direction_w = np.array([np.cos(theta_w), np.sin(theta_w)])
    kurt_w.append(kurtosis_w(Xwhite_w @ direction_w))
kurt_w = np.array(kurt_w)
best_angle_w = float(angles_w[np.argmax(np.abs(kurt_w))])
print("best angle degrees:", round(best_angle_w * 180 / np.pi, 1))
print("best excess kurtosis:", round(float(kurt_w[np.argmax(np.abs(kurt_w))]), 3))
assert abs(kurt_w[np.argmax(np.abs(kurt_w))]) > 1.0
```
▶ What you'll see: one rotation direction has a much stronger non-Gaussian score than nearby directions.

```python
plt.figure(figsize=(5, 3))
plt.plot(angles_w * 180 / np.pi, np.abs(kurt_w), color="purple")
plt.axvline(best_angle_w * 180 / np.pi, color="red", linestyle="--", label="best direction")
plt.title("4: scan rotations by absolute kurtosis")
plt.xlabel("angle in degrees"); plt.ylabel("|excess kurtosis|"); plt.legend(); plt.show()
```
▶ What you'll see: peaks mark candidate independent-component directions; ICA chooses a criterion-defined lens, not a human-drawn axis.

*Why it's done this way:* covariance cannot distinguish any two rotations after whitening. Non-Gaussianity supplies the missing decision rule: an independent source should be statistically surprising compared with a Gaussianized mixture.

### 5. Recovering multiple components: rotate, deflate, and compare

In two dimensions, once we find one unit direction, the other independent direction must be its orthogonal companion. Projecting whitened data onto these directions gives recovered component signals. ICA cannot know the original order or sign, so we compare with absolute correlations rather than exact column equality.

```python
w1_w = np.array([np.cos(best_angle_w), np.sin(best_angle_w)])  # first recovered direction.
w2_w = np.array([-w1_w[1], w1_w[0]])  # orthogonal companion in 2-D.
Wrot_w = np.vstack([w1_w, w2_w])  # rows are unmixing directions in whitened coordinates.
Y_w = Xwhite_w @ Wrot_w.T  # recovered components.
Y_w = (Y_w - Y_w.mean(axis=0)) / Y_w.std(axis=0)  # normalize for comparison only.
print("component covariance:\n", np.round((Y_w.T @ Y_w) / Y_w.shape[0], 3))
assert Y_w.shape == S_w.shape
```
▶ What you'll see: the recovered components are uncorrelated because they are orthogonal projections of whitened data.

```python
corr_w = np.corrcoef(S_w.T, Y_w.T)[:2, 2:]  # source-vs-recovered correlation matrix.
print("absolute source/recovery correlations:\n", np.round(np.abs(corr_w), 3))
assert np.max(np.abs(corr_w), axis=1).min() > 0.9
```
▶ What you'll see: each true source has a recovered component with high absolute correlation, but the columns may be swapped or sign-flipped.

```python
fig, ax = plt.subplots(2, 1, figsize=(7, 4), sharex=True)
ax[0].plot(t_w[:160], S_w[:160, 0], label="true source 0")
ax[0].plot(t_w[:160], Y_w[:160, np.argmax(np.abs(corr_w[0]))], "--", label="matched recovered")
ax[0].legend(); ax[0].set_title("source 0 match")
ax[1].plot(t_w[:160], S_w[:160, 1], label="true source 1")
ax[1].plot(t_w[:160], Y_w[:160, np.argmax(np.abs(corr_w[1]))], "--", label="matched recovered")
ax[1].legend(); ax[1].set_title("source 1 match")
plt.suptitle("5: ICA recovers signals up to sign and order"); plt.show()
```
▶ What you'll see: dashed recovered curves trace the true sources closely, even if their signs or order differ.

*Why it's done this way:* the data distribution is unchanged if an independent source is multiplied by −1 or if components are listed in a different order. Those ambiguities are not bugs; they are mathematical limits of the information in unlabeled mixtures.

### 6. Scaling and stability checks: treating ICA as a lens, not an oracle

The source block warns that unsupervised outputs are criterion-dependent. ICA is no exception: scaling a sensor changes covariance and can distort the whitening step; changing the non-Gaussianity criterion or sample can change the recovered rotation. A responsible workflow checks preprocessing and stability instead of treating one run as ground truth.

```python
X_scaled_w = X_w.copy()
X_scaled_w[:, 0] *= 8.0  # one sensor uses a much larger unit.
raw_cov_w = (X_scaled_w.T @ X_scaled_w) / X_scaled_w.shape[0]
std_scaled_w = (X_scaled_w - X_scaled_w.mean(axis=0)) / X_scaled_w.std(axis=0)
std_cov_w = (std_scaled_w.T @ std_scaled_w) / std_scaled_w.shape[0]
print("raw scaled covariance diagonal:", np.round(np.diag(raw_cov_w), 3))
print("standardized covariance diagonal:", np.round(np.diag(std_cov_w), 3))
assert round(float(np.diag(raw_cov_w)[0] / np.diag(raw_cov_w)[1]), 1) > 20
```
▶ What you'll see: the large-unit sensor dominates raw scale, while standardization restores comparable variances.

```python
rng_w = np.random.default_rng(4)
idx1_w = rng_w.choice(Xwhite_w.shape[0], size=350, replace=True)
idx2_w = rng_w.choice(Xwhite_w.shape[0], size=350, replace=True)
def best_kurt_angle_w(Xin_w):
    scores_w = []
    for theta_w in angles_w:
        d_w = np.array([np.cos(theta_w), np.sin(theta_w)])
        scores_w.append(abs(kurtosis_w(Xin_w @ d_w)))
    return float(angles_w[int(np.argmax(scores_w))])
a1_w = best_kurt_angle_w(Xwhite_w[idx1_w])
a2_w = best_kurt_angle_w(Xwhite_w[idx2_w])
print("bootstrap best angles:", round(a1_w * 180 / np.pi, 1), round(a2_w * 180 / np.pi, 1))
assert abs(a1_w - a2_w) < 0.35
```
▶ What you'll see: nearby resamples produce similar directions on this clean toy problem; fragile data would jump more.

```python
plt.figure(figsize=(4, 3))
plt.bar(["raw var 0", "raw var 1", "std var 0", "std var 1"],
        [raw_cov_w[0, 0], raw_cov_w[1, 1], std_cov_w[0, 0], std_cov_w[1, 1]],
        color=["crimson", "crimson", "seagreen", "seagreen"])
plt.xticks(rotation=20); plt.title("6: scaling changes the numeric lens"); plt.ylabel("variance"); plt.show()
```
▶ What you'll see: the raw feature scale overwhelms the calculation until standardization makes the coordinates comparable.

*Why it's done this way:* an unsupervised algorithm optimizes the criterion it is given. Scaling, whitening choices, non-Gaussianity measures, and sampling all define that criterion, so stability checks are part of the method rather than afterthoughts.

### Basic 7 — Whiten a tiny dataset

**Goal.** Transform centered data so covariance becomes identity, because ICA wants rotations that are not decided by variance scale. We build it in 3 steps.

```python
X_b7 = np.array([[0.0, 0.0], [2.0, 1.0], [4.0, 3.0], [6.0, 4.0], [8.0, 5.0]]) # create correlated observations.
Xc_b7 = X_b7 - X_b7.mean(axis=0) # center observations.
U_b7, s_b7, Vt_b7 = np.linalg.svd(Xc_b7, full_matrices=False) # compute SVD.
print("before covariance:\n", np.round((Xc_b7.T @ Xc_b7) / Xc_b7.shape[0], 3)) # inspect correlated covariance.
```
▶ What you'll see: the original covariance has unequal variances and nonzero off-diagonal covariance.

```python
eig_b7 = (s_b7 ** 2) / Xc_b7.shape[0] # convert singular values to covariance eigenvalues.
white_b7 = Vt_b7.T @ np.diag(1 / np.sqrt(eig_b7)) @ Vt_b7 # build covariance inverse square root.
Xw_b7 = Xc_b7 @ white_b7 # whiten the data.
print("after covariance:\n", np.round((Xw_b7.T @ Xw_b7) / Xw_b7.shape[0], 3)) # inspect whitened covariance.
assert np.allclose(np.round((Xw_b7.T @ Xw_b7) / Xw_b7.shape[0], 3), np.eye(2))
```

### Advanced 1 — Use a fixed-point ICA update

**Goal.** Replace brute-force angle scanning with a FastICA-style fixed-point update, because optimization usually searches the criterion directly. We build it in 5 steps.

```python

for step_a1 in range(30): # run fixed-point iterations.
    y_a1 = Xw_a1 @ w_a1 # project data onto current direction.
    g_a1 = np.tanh(y_a1) # nonlinearity that rewards non-Gaussian projections.
    gp_a1 = 1.0 - g_a1 ** 2 # derivative of tanh for the correction term.

```

```python

W_a2 = [] # store recovered orthonormal directions.
for comp_a2 in range(3): # find one direction at a time.
    w_a2 = rng_a2.normal(size=3) # random initial direction.
    w_a2 = w_a2 / np.linalg.norm(w_a2) # normalize initialization.
    for step_a2 in range(80): # fixed-point iterations.
        y_a2 = Xw_a2 @ w_a2 # project onto direction.
        g_a2 = np.tanh(y_a2) # non-Gaussian nonlinearity.
        gp_a2 = 1.0 - g_a2 ** 2 # derivative.
        w_new_a2 = (Xw_a2.T @ g_a2) / Xw_a2.shape[0] - gp_a2.mean() * w_a2 # update direction.
        for prev_a2 in W_a2: # deflate by removing already found directions.
            w_new_a2 = w_new_a2 - np.dot(w_new_a2, prev_a2) * prev_a2 # Gram-Schmidt orthogonalization.
        w_new_a2 = w_new_a2 / np.linalg.norm(w_new_a2) # renormalize.
        if abs(abs(float(w_new_a2 @ w_a2)) - 1.0) < 1e-7: # check convergence up to sign.
            w_a2 = w_new_a2 # save converged direction.
            break
        w_a2 = w_new_a2 # continue.
    W_a2.append(w_a2) # store component direction.
W_a2 = np.vstack(W_a2) # rows are unmixing directions.
print("W W^T:\n", np.round(W_a2 @ W_a2.T, 3)) # inspect orthonormality.
assert np.allclose(np.round(W_a2 @ W_a2.T, 3), np.eye(3))
```

```python

Y_a2 = (Y_a2 - Y_a2.mean(axis=0)) / Y_a2.std(axis=0) # standardize for comparison.
match_a2 = np.abs(np.corrcoef(S_a2.T, Y_a2.T)[:3, 3:]) # source/recovery matches.

```

### Advanced 5 — Compare two non-Gaussian criteria

**Goal.** Compare kurtosis and negentropy-like log-cosh scores, because changing the criterion can change what structure an unsupervised lens sees. We build it in 4 steps.

```python

print("prepared:", Xw_a5.shape) # inspect whitened shape.
```

▶ What you'll see: a whitened two-sensor dataset is ready for criterion comparison.

```python
def kurt_a5(z_a5):
    z_a5 = (z_a5 - z_a5.mean()) / z_a5.std() # standardize projection.
    return abs(float(np.mean(z_a5 ** 4) - 3.0)) # absolute excess kurtosis.
def logcosh_a5(z_a5):

    gaussian_ref_a5 = np.random.default_rng(55).normal(size=z_a5.size) # fixed Gaussian reference.
    return abs(float(np.mean(np.log(np.cosh(z_a5))) - np.mean(np.log(np.cosh(gaussian_ref_a5))))) # negentropy-like contrast.
```
