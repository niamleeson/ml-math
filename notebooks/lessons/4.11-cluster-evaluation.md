# 4.11 — Cluster Evaluation

Cluster evaluation turns unlabeled points into auditable evidence: are points close to their own cluster, far from other clusters, and surprisingly aligned with any external labels we trust? In this lesson, we build silhouette, Davies–Bouldin, and adjusted Rand index from scratch with NumPy so every distance, average, count, and normalization is visible.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build cluster evaluation one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math is spelled out so no score is a black box. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, pairwise distances, and counting.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for any jittered examples.
```

### 1. Distances and labels are the raw evidence

Cluster evaluation starts with two objects: a data matrix $X\in\mathbb{R}^{m\times n}$ and a proposed label vector in $\{0,1,\dots\}^m$. The evaluator does not know whether the labels are “true.” It only asks whether points with the same label are geometrically close and points with different labels are far apart.

```python
X_w = np.array([[0.0, 0.0], [0.4, 0.1], [0.2, -0.3],
                [3.0, 3.0], [3.4, 3.1], [2.9, 2.7]])  # two visible groups.
labels_w = np.array([0, 0, 0, 1, 1, 1])  # proposed clustering.
print("X shape:", X_w.shape)  # 6 points by 2 measured coordinates.
print("labels:", labels_w)  # one cluster id per point.
```
▶ What you'll see: six 2-D points and a length-6 label vector assigning the first three to cluster 0 and the last three to cluster 1.

```python
diff_w = X_w[:, None, :] - X_w[None, :, :]  # all pairwise coordinate differences.
D_w = np.sqrt(np.sum(diff_w ** 2, axis=2))  # Euclidean distance matrix.
print("pairwise distance matrix:\n", np.round(D_w, 2))  # inspect every point-to-point distance.
assert D_w.shape == (6, 6)  # one distance for every ordered pair of points.
```
▶ What you'll see: a 6×6 matrix with small within-cluster distances and large cross-cluster distances.

```python
plt.figure(figsize=(4.4, 3.6))
plt.scatter(X_w[:, 0], X_w[:, 1], c=labels_w, cmap="viridis", s=80)
for i_w, (x_w, y_w) in enumerate(X_w):
    plt.text(x_w + 0.03, y_w + 0.03, str(i_w))
plt.title("1: proposed clusters"); plt.xlabel("feature 0"); plt.ylabel("feature 1"); plt.show()
```
▶ What you'll see: two separated blobs; the numbers identify the rows used in the distance matrix.

*Why it's done this way:* evaluation metrics cannot inspect “meaning” directly. They reduce the question to geometry and counting: a distance matrix says what is close, and labels say which distances are supposed to be within-cluster evidence.

### 2. Silhouette: compare own-cluster distance to nearest-other distance

For point $i$, silhouette uses $a(i)$ for the average distance to points in its own cluster and $b(i)$ for the smallest average distance to any other cluster. The score

$$s(i)=\frac{b(i)-a(i)}{\max(a(i),b(i))}$$

is near $1$ when the point is much closer to its own cluster, near $0$ on a boundary, and negative when another cluster is closer.

```python
i_w = 0  # audit point 0 by hand.
same_w = (labels_w == labels_w[i_w]) & (np.arange(len(labels_w)) != i_w)  # own cluster except itself.
other_clusters_w = [c_w for c_w in np.unique(labels_w) if c_w != labels_w[i_w]]  # candidate rival clusters.
a_w = float(np.mean(D_w[i_w, same_w]))  # average distance to same-label neighbors.
print("same-cluster distances:", np.round(D_w[i_w, same_w], 3))
print("a(0):", round(a_w, 3))
```
▶ What you'll see: point 0 is close to points 1 and 2, so its within-cluster distance is small.

```python
b_candidates_w = []
for c_w in other_clusters_w:
    mask_w = labels_w == c_w
    b_candidates_w.append(float(np.mean(D_w[i_w, mask_w])))  # average distance to that other cluster.
b_w = min(b_candidates_w)  # nearest other cluster average.
sil0_w = (b_w - a_w) / max(a_w, b_w)  # silhouette for point 0.
print("other-cluster averages:", np.round(b_candidates_w, 3))
print("s(0):", round(sil0_w, 3))
assert round(sil0_w, 3) == 0.909
```
▶ What you'll see: the other cluster is far away, giving point 0 a high silhouette score.

```python
sil_w = []
for i2_w in range(len(X_w)):
    same2_w = (labels_w == labels_w[i2_w]) & (np.arange(len(labels_w)) != i2_w)
    a2_w = np.mean(D_w[i2_w, same2_w]) if np.any(same2_w) else 0.0
    b2_w = min(np.mean(D_w[i2_w, labels_w == c_w]) for c_w in np.unique(labels_w) if c_w != labels_w[i2_w])
    sil_w.append((b2_w - a2_w) / max(a2_w, b2_w))
sil_w = np.array(sil_w)
print("silhouettes:", np.round(sil_w, 3), "mean:", round(float(np.mean(sil_w)), 3))
plt.figure(figsize=(4.6, 3)); plt.bar(np.arange(len(sil_w)), sil_w, color="seagreen")
plt.axhline(np.mean(sil_w), color="black", linestyle="--", label="mean")
plt.title("2: silhouette by point"); plt.xlabel("point"); plt.ylabel("s(i)"); plt.legend(); plt.show()
```
▶ What you'll see: all bars are high and positive; no point appears closer to the rival cluster.

*Why it's done this way:* the numerator $b-a$ asks “how much safer is my assigned cluster than the nearest alternative?” Dividing by the larger of $a$ and $b$ normalizes the answer into a comparable scale from −1 to 1.

### 3. Davies–Bouldin: scatter divided by centroid separation

Davies–Bouldin evaluates whole clusters rather than individual points. For cluster $k$, $S_k$ is its average distance to its centroid. For two clusters, $M_{12}$ is the centroid distance, and the comparison ratio is

$$DB=\frac{S_1+S_2}{M_{12}}.$$

Lower is better: compact clusters make the numerator small; separated centroids make the denominator large.

```python
centroids_w = np.array([X_w[labels_w == c_w].mean(axis=0) for c_w in np.unique(labels_w)])  # one mean point per cluster.
print("centroids:\n", np.round(centroids_w, 3))
plt.figure(figsize=(4.4, 3.6))
plt.scatter(X_w[:, 0], X_w[:, 1], c=labels_w, cmap="viridis", s=70)
plt.scatter(centroids_w[:, 0], centroids_w[:, 1], marker="X", s=180, color="red")
plt.title("3: centroids summarize clusters"); plt.show()
```
▶ What you'll see: each red X sits near the middle of its cluster.

```python
scatters_w = []
for c_w in np.unique(labels_w):
    pts_w = X_w[labels_w == c_w]
    center_w = pts_w.mean(axis=0)
    scatters_w.append(float(np.mean(np.sqrt(np.sum((pts_w - center_w) ** 2, axis=1)))))
scatters_w = np.array(scatters_w)
sep_w = float(np.linalg.norm(centroids_w[0] - centroids_w[1]))
db_w = float((scatters_w[0] + scatters_w[1]) / sep_w)
print("scatters:", np.round(scatters_w, 3), "separation:", round(sep_w, 3), "DB:", round(db_w, 3))
assert round(db_w, 3) == 0.118
```
▶ What you'll see: scatter is tiny compared with centroid separation, so Davies–Bouldin is small.

```python
bad_labels_w = np.array([0, 0, 1, 1, 0, 1])  # mix far-apart points into the same clusters.
bad_centroids_w = np.array([X_w[bad_labels_w == c_w].mean(axis=0) for c_w in np.unique(bad_labels_w)])
bad_scatters_w = np.array([np.mean(np.linalg.norm(X_w[bad_labels_w == c_w] - bad_centroids_w[c_w], axis=1)) for c_w in np.unique(bad_labels_w)])
bad_sep_w = float(np.linalg.norm(bad_centroids_w[0] - bad_centroids_w[1]))
bad_db_w = float((bad_scatters_w[0] + bad_scatters_w[1]) / bad_sep_w)
print("good DB:", round(db_w, 3), "bad DB:", round(bad_db_w, 3))
plt.figure(figsize=(4.4, 3)); plt.bar(["good labels", "mixed labels"], [db_w, bad_db_w], color=["seagreen", "crimson"])
plt.ylabel("Davies-Bouldin (lower better)"); plt.title("3: DB punishes scatter"); plt.show()
```
▶ What you'll see: the mixed clustering has a much larger DB score because clusters are spread out and not cleanly separated.

*Why it's done this way:* DB is a compactness/separation ratio. Ratios are useful because they compare two effects in the same unit of distance, so doubling all coordinates does not change the score.

### 4. Adjusted Rand index: agreement beyond chance

Sometimes we have external labels, such as hand-labeled categories, and want to ask whether a clustering agrees with them. Rand-style scores count pairs of points: two clusterings agree on a pair if both put the pair together or both keep it apart. Adjusted Rand index (ARI) corrects that agreement for what random clusterings with the same group sizes would achieve.

```python
true_w = np.array([0, 0, 0, 1, 1, 1])  # external reference labels.
pred_w = np.array([0, 0, 0, 1, 1, 1])  # proposed clustering.
cont_w = np.zeros((2, 2), dtype=int)
for t_w, p_w in zip(true_w, pred_w):
    cont_w[t_w, p_w] += 1
print("contingency table:\n", cont_w)
```
▶ What you'll see: all mass is on the diagonal, meaning predicted groups match the reference groups exactly.

```python
def choose2_w(n_w):
    return n_w * (n_w - 1) / 2
sum_cells_w = sum(choose2_w(n_w) for n_w in cont_w.ravel())
row_pairs_w = sum(choose2_w(n_w) for n_w in cont_w.sum(axis=1))
col_pairs_w = sum(choose2_w(n_w) for n_w in cont_w.sum(axis=0))
total_pairs_w = choose2_w(len(true_w))
expected_w = row_pairs_w * col_pairs_w / total_pairs_w
max_index_w = 0.5 * (row_pairs_w + col_pairs_w)
ari_w = (sum_cells_w - expected_w) / (max_index_w - expected_w)
print("ARI pieces:", round(sum_cells_w, 3), round(expected_w, 3), round(max_index_w, 3))
print("ARI:", round(ari_w, 3))
assert round(ari_w, 3) == 1.0
```
▶ What you'll see: perfect agreement gives ARI = 1 after chance correction.

```python
bad_pred_w = np.array([0, 0, 1, 1, 0, 1])
cont_bad_w = np.zeros((2, 2), dtype=int)
for t_w, p_w in zip(true_w, bad_pred_w):
    cont_bad_w[t_w, p_w] += 1
sum_bad_w = sum(choose2_w(n_w) for n_w in cont_bad_w.ravel())
row_bad_w = sum(choose2_w(n_w) for n_w in cont_bad_w.sum(axis=1))
col_bad_w = sum(choose2_w(n_w) for n_w in cont_bad_w.sum(axis=0))
expected_bad_w = row_bad_w * col_bad_w / total_pairs_w
ari_bad_w = (sum_bad_w - expected_bad_w) / (0.5 * (row_bad_w + col_bad_w) - expected_bad_w)
print("mixed contingency:\n", cont_bad_w)
print("mixed ARI:", round(ari_bad_w, 3))
assert round(ari_bad_w, 3) == -0.111
```
▶ What you'll see: the mixed labels score slightly below zero, meaning worse than chance under the fixed-size correction.

*Why it's done this way:* raw agreement can look high just because many pairs are separated in both clusterings. ARI subtracts expected random agreement, so the remaining number measures surprise alignment rather than easy pair-count coincidence.

### 5. Scaling and stability decide what the metrics can see

All internal cluster metrics depend on distances. If one feature is measured in huge units, it can dominate every distance and silently redefine “close.” A wise workflow therefore standardizes features when units are arbitrary and checks whether scores remain stable under small perturbations.

```python
X_scale_w = X_w.copy()
X_scale_w[:, 1] *= 20.0  # make feature 1 use a much larger numeric scale.
D_scale_w = np.sqrt(np.sum((X_scale_w[:, None, :] - X_scale_w[None, :, :]) ** 2, axis=2))
print("original d(0,1):", round(D_w[0, 1], 3), "scaled d(0,1):", round(D_scale_w[0, 1], 3))
```
▶ What you'll see: the same two points become much farther apart because one coordinate was rescaled.

```python
mean_scale_w = X_scale_w.mean(axis=0)
std_scale_w = X_scale_w.std(axis=0)
Z_scale_w = (X_scale_w - mean_scale_w) / std_scale_w
print("standardized means:", np.round(Z_scale_w.mean(axis=0), 3))
print("standardized stds:", np.round(Z_scale_w.std(axis=0), 3))
assert np.allclose(np.round(Z_scale_w.std(axis=0), 3), [1.0, 1.0])
```
▶ What you'll see: standardization restores comparable feature scales.

```python
rng_w = np.random.default_rng(0)
mean_scores_w = []
for run_w in range(20):
    noisy_w = X_w + 0.08 * rng_w.normal(size=X_w.shape)
    d_noisy_w = np.sqrt(np.sum((noisy_w[:, None, :] - noisy_w[None, :, :]) ** 2, axis=2))
    vals_w = []
    for i3_w in range(len(noisy_w)):
        same3_w = (labels_w == labels_w[i3_w]) & (np.arange(len(labels_w)) != i3_w)
        a3_w = np.mean(d_noisy_w[i3_w, same3_w])
        b3_w = min(np.mean(d_noisy_w[i3_w, labels_w == c_w]) for c_w in np.unique(labels_w) if c_w != labels_w[i3_w])
        vals_w.append((b3_w - a3_w) / max(a3_w, b3_w))
    mean_scores_w.append(np.mean(vals_w))
print("mean silhouette range:", round(float(np.min(mean_scores_w)), 3), "to", round(float(np.max(mean_scores_w)), 3))
plt.figure(figsize=(4.6, 3)); plt.plot(mean_scores_w, marker="o", color="navy")
plt.title("5: stability under small noise"); plt.xlabel("rerun"); plt.ylabel("mean silhouette"); plt.show()
```
▶ What you'll see: the scores wiggle only a little for this clean structure; fragile clusters would swing much more.

*Why it's done this way:* the metric optimizes the numbers we feed it, not the story in our head. Scaling makes the geometry match our intended units, and stability checks keep us from trusting a pattern that vanishes under tiny changes.

### Basic 1 — Plot a labeled clustering

**Goal.** Create a tiny data matrix and a proposed clustering, because every evaluation score starts from points plus labels. We build it in 2 steps.

```python
X_b1 = np.array([[0.0, 0.0], [0.4, 0.1], [0.2, -0.3], [3.0, 3.0], [3.4, 3.1], [2.9, 2.7]])  # store six 2-D points.
labels_b1 = np.array([0, 0, 0, 1, 1, 1])  # assign one cluster id to each point.
print("shape:", X_b1.shape, "labels:", labels_b1)  # inspect the evaluation inputs.
assert X_b1.shape == (6, 2)
```
▶ What you'll see: a small matrix and one label per row.

```python
plt.figure(figsize=(4, 3))
plt.scatter(X_b1[:, 0], X_b1[:, 1], c=labels_b1, cmap="viridis", s=80)
plt.title("Basic 1: proposed clustering"); plt.xlabel("x0"); plt.ylabel("x1"); plt.show()
```
▶ What you'll see: two visibly separated groups.

👀 Takeaway: cluster evaluation needs a proposed label for every row of the data matrix.

### Basic 2 — Build a pairwise distance matrix

**Goal.** Compute all point-to-point Euclidean distances, because silhouette and many internal scores are built from these distances. We build it in 2 steps.

```python
X_b2 = X_b1.copy()  # reuse the warm-up points from Basic 1.
diff_b2 = X_b2[:, None, :] - X_b2[None, :, :]  # broadcast every point against every other point.
print("difference tensor shape:", diff_b2.shape)  # inspect m by m by feature dimensions.
assert diff_b2.shape == (6, 6, 2)
```
▶ What you'll see: broadcasting creates one 2-D difference vector for every ordered pair.

```python
D_b2 = np.sqrt(np.sum(diff_b2 ** 2, axis=2))  # convert coordinate differences to Euclidean distances.
print("D_b2:\n", np.round(D_b2, 2))  # inspect the full distance matrix.
assert np.allclose(np.diag(D_b2), 0.0)
plt.figure(figsize=(4, 3)); plt.imshow(D_b2, cmap="magma"); plt.colorbar(label="distance")
plt.title("Basic 2: pairwise distances"); plt.show()
```
▶ What you'll see: dark diagonal zeros and bright cross-cluster distances.

👀 Takeaway: the distance matrix is the geometric evidence used by internal cluster scores.

### Basic 3 — Compute within-cluster distance a(i)

**Goal.** Measure one point's average distance to its own cluster, because silhouette calls that quantity $a(i)$. We build it in 2 steps.

```python
i_b3 = 0  # choose point 0 for a hand audit.
same_b3 = (labels_b1 == labels_b1[i_b3]) & (np.arange(len(labels_b1)) != i_b3)  # own-cluster neighbors only.
print("same-cluster indices:", np.where(same_b3)[0])  # inspect which points count toward a(i).
```
▶ What you'll see: point 0 compares to points 1 and 2, not to itself.

```python
a_b3 = float(np.mean(D_b2[i_b3, same_b3]))  # average own-cluster distance.
print("a(0):", round(a_b3, 3))  # inspect the within-cluster distance.
assert round(a_b3, 3) == 0.386
plt.figure(figsize=(4, 3)); plt.bar(["to 1", "to 2"], D_b2[i_b3, same_b3], color="teal")
plt.title("Basic 3: distances inside point 0's cluster"); plt.ylabel("distance"); plt.show()
```
▶ What you'll see: two small bars whose mean is $a(0)$.

👀 Takeaway: $a(i)$ is small when a point is embedded tightly inside its assigned cluster.

### Basic 4 — Compute nearest-other distance b(i)

**Goal.** Measure the average distance to the nearest rival cluster, because silhouette compares own-cluster distance against this alternative. We build it in 2 steps.

```python
other_clusters_b4 = [c for c in np.unique(labels_b1) if c != labels_b1[i_b3]]  # list rival cluster ids.
other_means_b4 = np.array([np.mean(D_b2[i_b3, labels_b1 == c]) for c in other_clusters_b4])  # average distance to each rival.
print("rival cluster means:", np.round(other_means_b4, 3))  # inspect candidate b values.
```
▶ What you'll see: with two clusters, there is one rival-cluster average.

```python
b_b4 = float(np.min(other_means_b4))  # nearest other-cluster average.
print("b(0):", round(b_b4, 3))  # inspect b(i).
assert round(b_b4, 3) == 4.269
plt.figure(figsize=(4, 3)); plt.bar(["a(0)", "b(0)"], [a_b3, b_b4], color=["teal", "orange"])
plt.title("Basic 4: own vs rival distance"); plt.ylabel("average distance"); plt.show()
```
▶ What you'll see: the rival average is much larger than the own-cluster average.

👀 Takeaway: $b(i)$ is the best alternative cluster's average distance, not necessarily the distance to a single nearest point.

### Basic 5 — Compute one silhouette value

**Goal.** Combine $a(i)$ and $b(i)$ into one bounded score, because silhouette needs a normalized separation margin. We build it in 2 steps.

```python
sil_b5 = (b_b4 - a_b3) / max(a_b3, b_b4)  # silhouette formula for point 0.
print("silhouette for point 0:", round(sil_b5, 3))  # inspect the normalized margin.
assert round(sil_b5, 3) == 0.909
```
▶ What you'll see: point 0 has a high positive silhouette.

```python
plt.figure(figsize=(4, 3)); plt.bar(["b-a", "max(a,b)", "s"], [b_b4 - a_b3, max(a_b3, b_b4), sil_b5], color="seagreen")
plt.title("Basic 5: silhouette pieces"); plt.show()
```
▶ What you'll see: the raw margin is divided by the larger distance scale to produce a value below 1.

👀 Takeaway: silhouette is high when own-cluster distance is much smaller than nearest-rival distance.

### Basic 6 — Average silhouette over all points

**Goal.** Compute a dataset-level silhouette score, because model selection usually compares one number per clustering. We build it in 3 steps.

```python
sil_values_b6 = []  # store one silhouette per point.
for i_b6 in range(len(X_b1)):
    same_b6 = (labels_b1 == labels_b1[i_b6]) & (np.arange(len(labels_b1)) != i_b6)
    a_b6 = np.mean(D_b2[i_b6, same_b6]) if np.any(same_b6) else 0.0
    b_b6 = min(np.mean(D_b2[i_b6, labels_b1 == c]) for c in np.unique(labels_b1) if c != labels_b1[i_b6])
    sil_values_b6.append((b_b6 - a_b6) / max(a_b6, b_b6))
sil_values_b6 = np.array(sil_values_b6)
print("silhouettes:", np.round(sil_values_b6, 3))
```
▶ What you'll see: one score for each row of the data matrix.

```python
mean_sil_b6 = float(np.mean(sil_values_b6))  # summarize point scores.
print("mean silhouette:", round(mean_sil_b6, 3))
assert round(mean_sil_b6, 3) == 0.896
```

```python
plt.figure(figsize=(4.5, 3)); plt.bar(np.arange(len(sil_values_b6)), sil_values_b6, color="slateblue")
plt.axhline(mean_sil_b6, color="black", linestyle="--")
plt.title("Basic 6: mean silhouette"); plt.xlabel("point"); plt.ylabel("s(i)"); plt.show()
```
▶ What you'll see: every point contributes to the mean; outliers would appear as low bars.

👀 Takeaway: mean silhouette summarizes local cluster fit but still lets you inspect point-level failures.

### Basic 7 — Compute cluster centroids

**Goal.** Summarize each cluster by its mean point, because Davies–Bouldin compares scatter around centroids to centroid separation. We build it in 2 steps.

```python
clusters_b7 = np.unique(labels_b1)  # find cluster ids in sorted order.
centroids_b7 = np.array([X_b1[labels_b1 == c].mean(axis=0) for c in clusters_b7])  # compute one centroid per cluster.
print("centroids:\n", np.round(centroids_b7, 3))

```
▶ What you'll see: two centroid coordinates, one for each proposed cluster.

```python
plt.figure(figsize=(4, 3)); plt.scatter(X_b1[:, 0], X_b1[:, 1], c=labels_b1, cmap="viridis", s=70)
plt.scatter(centroids_b7[:, 0], centroids_b7[:, 1], marker="X", s=180, color="red")

```
▶ What you'll see: red X markers near the centers of the two blobs.

👀 Takeaway: a centroid is a compact representative, but it is only meaningful for distance-shaped clusters.

### Basic 8 — Compute cluster scatter S_k

**Goal.** Measure average distance from points to their centroid, because Davies–Bouldin calls this cluster scatter. We build it in 2 steps.

```python
scatter_b8 = []  # store S_k values.
for idx_b8, c_b8 in enumerate(clusters_b7):
    pts_b8 = X_b1[labels_b1 == c_b8]
    scatter_b8.append(float(np.mean(np.linalg.norm(pts_b8 - centroids_b7[idx_b8], axis=1))))
scatter_b8 = np.array(scatter_b8)
print("scatter values:", np.round(scatter_b8, 3))
assert np.allclose(np.round(scatter_b8, 3), [0.235, 0.257])
```
▶ What you'll see: both clusters have small average radius.

```python
plt.figure(figsize=(4, 3)); plt.bar(["cluster 0", "cluster 1"], scatter_b8, color="darkcyan")
plt.title("Basic 8: cluster scatter S_k"); plt.ylabel("mean distance to centroid"); plt.show()
```
▶ What you'll see: compact clusters produce short bars.

👀 Takeaway: scatter is the within-cluster part of the Davies–Bouldin compactness/separation ratio.

### Basic 9 — Compute Davies–Bouldin for two clusters

**Goal.** Divide total scatter by centroid separation, because a good clustering should be compact relative to the distance between centers. We build it in 2 steps.

```python
sep_b9 = float(np.linalg.norm(centroids_b7[0] - centroids_b7[1]))  # centroid distance M_12.
db_b9 = float((scatter_b8[0] + scatter_b8[1]) / sep_b9)  # two-cluster Davies-Bouldin score.
```

### Easy 1 — Compare two clusterings with silhouette

**Goal.** Score a good and a mixed clustering with mean silhouette, because internal evaluation can choose between unlabeled alternatives. We build it in 3 steps.

```python
def mean_sil_e1(X_e1, y_e1):
    D_e1 = np.sqrt(np.sum((X_e1[:, None, :] - X_e1[None, :, :]) ** 2, axis=2))
    vals_e1 = []
    for i_e1 in range(len(X_e1)):
        same_e1 = (y_e1 == y_e1[i_e1]) & (np.arange(len(y_e1)) != i_e1)
        a_e1 = np.mean(D_e1[i_e1, same_e1]) if np.any(same_e1) else 0.0
        b_e1 = min(np.mean(D_e1[i_e1, y_e1 == c]) for c in np.unique(y_e1) if c != y_e1[i_e1])
        vals_e1.append((b_e1 - a_e1) / max(a_e1, b_e1))
    return float(np.mean(vals_e1))
```

### Easy 3 — Compute ARI from scratch

**Goal.** Implement adjusted Rand index with NumPy counting, because external cluster validation should correct raw pair agreement for chance. We build it in 3 steps.

```python
true_e3 = np.array([0, 0, 0, 1, 1, 1])
pred_e3 = np.array([0, 0, 1, 1, 0, 1])
cont_e3 = np.zeros((2, 2), dtype=int)
for t_e3, p_e3 in zip(true_e3, pred_e3):
    cont_e3[t_e3, p_e3] += 1
print("contingency:\n", cont_e3)
```
▶ What you'll see: off-diagonal counts show disagreements between labels and clusters.

```python
def c2_e3(n_e3):
    return n_e3 * (n_e3 - 1) / 2
index_e3 = sum(c2_e3(n_e3) for n_e3 in cont_e3.ravel())
row_e3 = sum(c2_e3(n_e3) for n_e3 in cont_e3.sum(axis=1))
col_e3 = sum(c2_e3(n_e3) for n_e3 in cont_e3.sum(axis=0))
total_e3 = c2_e3(len(true_e3))
expected_e3 = row_e3 * col_e3 / total_e3
ari_e3 = (index_e3 - expected_e3) / (0.5 * (row_e3 + col_e3) - expected_e3)

```


👀 Takeaway: ARI can be negative when a clustering agrees with reference labels less than chance would predict.

### Advanced 4 — ARI is insensitive to label names

**Goal.** Show that permuting cluster ids leaves ARI unchanged, because cluster labels are arbitrary names rather than ordered class numbers. We build it in 3 steps.

▶ What you'll see: 0 and 1 are swapped, but the grouping of pairs is identical.

```python
def ari_from_labels_a4(a_a4, b_a4):
    ua_a4 = np.unique(a_a4)
    ub_a4 = np.unique(b_a4)
    table_a4 = np.zeros((len(ua_a4), len(ub_a4)), dtype=int)
    for i_a4, va_a4 in enumerate(ua_a4):
        for j_a4, vb_a4 in enumerate(ub_a4):
            table_a4[i_a4, j_a4] = np.sum((a_a4 == va_a4) & (b_a4 == vb_a4))
    c2_a4 = lambda n: n * (n - 1) / 2
    idx_a4 = sum(c2_a4(n) for n in table_a4.ravel())
    rows_a4 = sum(c2_a4(n) for n in table_a4.sum(axis=1))
    cols_a4 = sum(c2_a4(n) for n in table_a4.sum(axis=0))
    expected_a4 = rows_a4 * cols_a4 / c2_a4(len(a_a4))
    return float((idx_a4 - expected_a4) / (0.5 * (rows_a4 + cols_a4) - expected_a4))
ari_swap_a4 = ari_from_labels_a4(true_a4, pred_a4)
```
