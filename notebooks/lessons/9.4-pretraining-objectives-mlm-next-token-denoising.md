# 9.4 — Pretraining Objectives (MLM, Next-Token, Denoising)

Pretraining objectives turn raw text into supervised learning signals by deciding which tokens the model may see, which tokens receive loss, and what reconstruction problem the Transformer must solve. In this lesson, you will build masked language modeling, next-token prediction, and denoising from first principles with tiny NumPy arrays, then inspect why changing the mask or label set changes the behavior the model can learn.

### 1. Cross-entropy turns token probabilities into loss

Every objective in this lesson eventually asks the same question: what probability did the model assign to the correct token? The negative log-probability, or cross-entropy for one token, is $-\\log p(\\text{correct})$. A confident correct prediction gives a small loss; a tiny probability gives a large loss. That logarithm is why multiplying many probabilities becomes adding losses, which is numerically stable and makes each supervised token contribute one inspectable term.

```python
probs_w = np.array([0.8, 0.6, 0.5])  # model probabilities assigned to three correct labels.
loss_terms_w = -np.log(probs_w)  # one negative-log-probability per supervised token.
print("probabilities:", probs_w)  # inspect the inputs to cross-entropy.
print("loss terms:", np.round(loss_terms_w, 3))  # inspect each token's penalty.
```
▶ What you'll see: probabilities 0.8, 0.6, and 0.5 become losses about 0.223, 0.511, and 0.693.

```python
loss_w = float(np.sum(loss_terms_w))  # total loss for the three supervised tokens.
mean_loss_w = float(np.mean(loss_terms_w))  # mean loss makes different label counts comparable.
print("sum loss:", round(loss_w, 3))  # -log .8 -log .6 -log .5 = 1.427.
print("mean loss:", round(mean_loss_w, 3))  # average per predicted token.
assert round(loss_w, 3) == 1.427  # canonical MLM arithmetic from the lesson text.
```
▶ What you'll see: the summed loss is 1.427, matching the worked mechanics.

```python
p_grid_w = np.linspace(0.05, 1.0, 80)  # possible correct-token probabilities.
ce_grid_w = -np.log(p_grid_w)  # loss for each probability.
plt.figure(figsize=(4.4, 3))  # compact diagnostic curve.
plt.plot(p_grid_w, ce_grid_w, color="purple")  # show how loss reacts to confidence.
plt.scatter(probs_w, loss_terms_w, color="black")  # mark the three toy probabilities.
plt.xlabel("probability assigned to correct token")  # probability axis.
plt.ylabel("-log(probability)")  # cross-entropy axis.
plt.title("1: token probability → loss"); plt.show()  # render the curve.
```
▶ What you'll see: loss falls slowly near high probabilities but explodes as probability approaches zero.

*Why it's done this way:* log loss directly rewards assigning probability mass to the correct label while preserving uncertainty: improving a low probability from 0.05 to 0.10 matters a lot because it halves surprise, while improving 0.90 to 0.95 matters less. Summing $-\\log p$ over supervised tokens is equivalent to maximizing the product of their probabilities, but the sum is easier and stable to compute.

### 2. Masked language modeling predicts only hidden positions

Masked language modeling (MLM) corrupts a small subset $M$ of positions, gives the model the surrounding unmasked context, and computes loss only on the hidden original tokens: $\\mathcal{L}_{MLM}=-\\sum_{t\\in M}\\log p(x_t\\mid x_{\\setminus M})$. The crucial detail is the set $M$: unmasked tokens are evidence, not labels. If we count all tokens in the loss, we reward copying visible tokens and change the objective.

```python
tokens_w = np.array(["the", "cat", "sat", "on", "the", "mat"], dtype=object)  # original sentence.
mask_positions_w = np.array([1, 4])  # hide two positions: cat and the.
visible_w = tokens_w.copy()  # start from the original tokens.
visible_w[mask_positions_w] = "[MASK]"  # replace selected positions by a mask symbol.
print("original:", " ".join(tokens_w))  # inspect true sequence.
print("visible :", " ".join(visible_w))  # inspect model input.
```
▶ What you'll see: only positions 1 and 4 are hidden, while the other words remain as context.

```python
mlm_probs_w = np.array([0.8, 0.6])  # probabilities assigned to the two original hidden tokens.
mlm_loss_w = float(np.sum(-np.log(mlm_probs_w)))  # loss over masked positions only.
label_count_w = len(mask_positions_w)  # number of supervised labels.
print("masked labels:", tokens_w[mask_positions_w])  # labels are the original hidden tokens.
print("MLM loss:", round(mlm_loss_w, 3), "over", label_count_w, "labels")  # inspect objective size.
assert round(mlm_loss_w, 3) == 0.734  # -log .8 -log .6.
```
▶ What you'll see: the model is penalized only for recovering `cat` and `the`, not for repeating visible words.

```python
plt.figure(figsize=(4.6, 3))  # show which positions contribute loss.
colors_w = ["crimson" if i in mask_positions_w else "lightgray" for i in range(len(tokens_w))]  # red = supervised.
plt.bar(np.arange(len(tokens_w)), [1] * len(tokens_w), color=colors_w)  # one bar per token position.
plt.xticks(np.arange(len(tokens_w)), tokens_w, rotation=20)  # label tokens.
plt.yticks([]); plt.title("2: MLM loss is sparse over positions"); plt.show()  # render.
```
▶ What you'll see: only the red masked positions receive objective terms.

*Why it's done this way:* MLM forces bidirectional context use because the model can look left and right of a blank, but the loss mask prevents trivial copying of tokens that were never hidden. The 15% masking rule is a label-budget choice: enough hidden tokens to train, but enough visible tokens to reconstruct from evidence.

### 3. Next-token prediction shifts labels under a causal mask

Next-token training uses every position after the first as a label, but each label may only depend on earlier tokens. For tokens $x_0,\\dots,x_T$, the loss is $-\\sum_t \\log p(x_t\\mid x_{<t})$. Unlike MLM, there is no random hidden set; supervision is dense across the sequence, and the mask is causal rather than bidirectional.

```python
seq_w = np.array(["I", "like", "small", "models"])  # a tiny token sequence.
inputs_w = seq_w[:-1]  # prefixes positions: I, like, small.
labels_w = seq_w[1:]  # shifted targets: like, small, models.
print("inputs:", inputs_w)  # inspect tokens supplied at each step.
print("labels:", labels_w)  # inspect next-token targets.
```
▶ What you'll see: every input token is paired with the following token as its label.

```python
next_probs_w = np.array([0.7, 0.5, 0.2])  # probabilities assigned to the three next-token labels.
next_losses_w = -np.log(next_probs_w)  # per-position next-token penalties.
next_loss_w = float(np.sum(next_losses_w))  # total sequence loss.
print("loss terms:", np.round(next_losses_w, 3))  # 0.357, 0.693, 1.609.
print("next-token loss:", round(next_loss_w, 3))  # total from worked mechanics.
assert round(next_loss_w, 3) == 2.659  # canonical next-token arithmetic.
```
▶ What you'll see: the low 0.2 probability creates the largest loss term.

```python
causal_mask_w = np.tril(np.ones((4, 4), dtype=int))  # token i can attend to positions <= i.
print("causal attention mask:\n", causal_mask_w)  # inspect allowed attention.
plt.figure(figsize=(3.6, 3.2))  # compact mask heatmap.
plt.imshow(causal_mask_w, cmap="Greens", vmin=0, vmax=1)  # green means visible.
plt.title("3: causal mask"); plt.xlabel("key position"); plt.ylabel("query position"); plt.show()  # render.
```
▶ What you'll see: a lower-triangular matrix; future positions are blocked.

*Why it's done this way:* shifting labels creates a self-supervised task from plain text, and the causal mask prevents peeking at the answer. Because nearly every token becomes a label, next-token pretraining has a dense training signal and naturally matches left-to-right generation.

### 4. Denoising reconstructs corrupted spans, often with sentinels

Denoising objectives corrupt a broader input and train the model to reconstruct the missing content. A common span-corruption version replaces a contiguous span with one sentinel token, then asks the decoder to generate the removed span. This is different from single-token MLM: the model must recover multiple tokens from a compressed hint and surrounding context.

```python
long_tokens_w = np.array(["t0", "t1", "t2", "t3", "t4", "t5", "t6", "t7", "t8", "t9",
                          "t10", "t11", "t12", "t13", "t14", "t15", "t16", "t17", "t18", "t19"])  # 20 tokens.
span_start_w, span_len_w = 7, 5  # remove five contiguous tokens.
removed_w = long_tokens_w[span_start_w:span_start_w + span_len_w]  # target span.
corrupted_w = np.concatenate([long_tokens_w[:span_start_w], np.array(["<extra_id_0>"]), long_tokens_w[span_start_w + span_len_w:]])  # replace span by one sentinel.
print("removed span:", removed_w)  # inspect denoising target.
print("corrupted length:", len(corrupted_w), "from original length:", len(long_tokens_w))  # inspect compression.
assert len(corrupted_w) == 16  # 20 - 5 + 1 sentinel.
```
▶ What you'll see: five tokens are removed and represented by one sentinel, reducing length from 20 to 16.

```python
denoise_probs_w = np.array([0.5, 0.4, 0.8, 0.7, 0.6])  # probabilities for reconstructing the five removed tokens.
denoise_terms_w = -np.log(denoise_probs_w)  # one reconstruction loss per removed token.
denoise_loss_w = float(np.sum(denoise_terms_w))  # total denoising loss.
print("denoising loss terms:", np.round(denoise_terms_w, 3))  # inspect target-token penalties.
print("denoising loss:", round(denoise_loss_w, 3))  # total loss for the span.
assert round(denoise_loss_w, 3) == 2.700  # fixed numerical check.
```
▶ What you'll see: the span loss is the sum of reconstruction surprises for all removed tokens.

```python
plt.figure(figsize=(5, 2.8))  # visualize original versus compressed input length.
plt.bar(["original", "corrupted"], [len(long_tokens_w), len(corrupted_w)], color=["gray", "darkorange"])  # compare lengths.
plt.ylabel("token count")  # length axis.
plt.title("4: span corruption compresses input"); plt.show()  # render.
```
▶ What you'll see: the corrupted input is shorter because one sentinel stands for a whole missing span.

*Why it's done this way:* replacing spans rather than isolated tokens teaches the model to bridge larger gaps and generate coherent missing chunks. The sentinel marks where reconstruction belongs, while compression makes the encoder focus on useful context instead of carrying placeholder tokens for every missing word.

### 5. Objective choice changes label count, evidence, and comparisons

MLM, next-token, and denoising can all use cross-entropy, but they supervise different token sets under different visibility rules. That means raw losses are not automatically comparable: a next-token objective may have many more labels, while MLM may have fewer but bidirectional labels. When objectives are mixed, the formula must state the weights explicitly.

```python
sequence_length_w = 20  # toy document length.
mask_rate_w = 0.15  # common MLM corruption rate.
masked_count_w = int(sequence_length_w * mask_rate_w)  # 20 tokens × 15% = 3 labels.
next_count_w = sequence_length_w - 1  # next-token labels for a length-20 sequence.
print("MLM labels:", masked_count_w)  # sparse supervised positions.
print("next-token labels:", next_count_w)  # dense shifted labels.
assert masked_count_w == 3  # canonical worked mechanic.
```
▶ What you'll see: the same 20-token text creates 3 MLM labels but 19 next-token labels.

```python
mlm_component_w = 1.4  # toy MLM loss.
denoise_component_w = 2.0  # toy denoising loss.
weights_w = np.array([0.75, 0.25])  # explicit mixture weights.
mixed_loss_w = float(weights_w @ np.array([mlm_component_w, denoise_component_w]))  # weighted objective.
print("mixed loss:", round(mixed_loss_w, 3))  # 0.75*1.4 + 0.25*2.0.
assert round(mixed_loss_w, 3) == 1.55  # canonical mixed-objective arithmetic.
```
▶ What you'll see: the mixed objective is 1.55, exactly determined by the stated weights.

```python
plt.figure(figsize=(5, 3))  # compare objective label density.
plt.bar(["MLM", "next-token", "denoise span"], [masked_count_w, next_count_w, span_len_w], color=["crimson", "seagreen", "darkorange"])  # label counts.
plt.ylabel("supervised token count")  # what is being compared.
plt.title("5: objectives supervise different token sets"); plt.show()  # render.
```
▶ What you'll see: label counts differ sharply, so summed losses answer different questions.

*Why it's done this way:* the objective is the behavioral contract. If a term is not in the loss, the model is not directly trained for it; if extra tokens are counted, the incentive changes. Mean losses, held-out evaluations, and explicit mixture weights keep comparisons honest.

### Easy 1 — Implement MLM with vocabulary logits

**Goal.** Compute MLM loss from logits at masked positions, because real models output a distribution over the vocabulary for each hidden token. We build it in 3 steps.

```python
vocab_e1 = np.array(["cat", "dog", "sat", "the"])  # Tiny vocabulary.
masked_targets_e1 = np.array([0, 3])  # Correct labels: cat and the.
logits_e1 = np.array([[2.0, 0.0, 0.5, 1.0], [0.2, 0.1, -0.2, 1.4]])  # Model logits for two masked positions.
```
