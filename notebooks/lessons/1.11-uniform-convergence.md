# 1.11 · Uniform Convergence

Uniform convergence is the reason empirical risk minimization (ERM) can trust training error. A fixed model can look good by concentration, but ERM chooses after seeing data, so we need training error close to true error **simultaneously for every** $h\in\mathcal{H}$.

## 📖 Concept walkthrough — build it from scratch

Before the exercises, we build the theorem one piece at a time. Run each cell in order and inspect the printed numbers: one-hypothesis concentration, the union bound over a class, the ERM guarantee, sample-size thresholds, and a simulation of the maximum empirical/true gap. This walkthrough is self-contained and uses a `_w` suffix so it never collides with the examples below.

```python
import numpy as np  # arrays, random samples, and numerical checks.
import matplotlib.pyplot as plt  # visual diagnostics for every concept.
np.random.seed(0)  # reproducibility for the stochastic cells.
```

### 1. One fixed hypothesis concentrates

For a single fixed hypothesis $h$, the empirical risk $R_S(h)$ is an average of i.i.d. bounded losses. Hoeffding's inequality says that average is unlikely to be far from the true risk $R(h)$:

$$\Pr\big(|R_S(h)-R(h)|>\epsilon\big)\le 2e^{-2m\epsilon^2}.$$

The word **fixed** matters: this bound covers one hypothesis chosen before the sample is seen. It does not yet cover ERM, because ERM chooses whichever hypothesis looks best on the same sample.

```python
m_w = 500  # sample size from the lesson text.
eps_w = 0.1  # allowed train-vs-true risk gap.
exponent_w = -2 * m_w * eps_w ** 2  # Hoeffding exponent for one bounded-loss average.
one_bound_w = 2 * np.exp(exponent_w)  # failure probability for one fixed hypothesis.
print("exponent:", round(exponent_w, 3))  # -10.
print("one-hypothesis bound:", round(one_bound_w, 6))  # about 0.000091.
assert round(exponent_w, 3) == -10.0  # cited arithmetic.
assert abs(one_bound_w - 0.0000907999) < 1e-8  # cited number with tolerance.
```
▶ What you'll see: at $m=500$ and $\epsilon=0.1$, one fixed model is pinned down to about $9.08\times10^{-5}$ failure probability.

```python
ms_w = np.arange(25, 501, 25)  # increasing training-set sizes.
one_curve_w = 2 * np.exp(-2 * ms_w * eps_w ** 2)  # Hoeffding bound for each size.
print("first three bounds:", np.round(one_curve_w[:3], 3))  # big at small m.
plt.figure(figsize=(4.4, 3))  # compact curve.
plt.plot(ms_w, np.minimum(one_curve_w, 1), marker="o", color="teal")  # clip to probability scale for display.
plt.xlabel("sample size m")  # horizontal axis.
plt.ylabel("failure bound, clipped at 1")  # vertical axis.
plt.title("1: fixed-hypothesis concentration")  # required concept figure.
plt.show()  # display.
```
▶ What you'll see: the bound decays exponentially as the sample size grows.

*Why it's done this way: a loss average is noisy at small $m$ but stabilizes like $e^{-m}$; this is the one-model engine that the full uniform-convergence proof will reuse.*

### 2. Uniform convergence means all hypotheses at once

Uniform convergence is the event

$$\sup_{h\in\mathcal{H}} |R_S(h)-R(h)|\le\epsilon,$$

meaning the training error is close to the true error **simultaneously for every** $h$ in the class. For a finite class, the union bound pays for this by summing the failure probability over all hypotheses:

$$\Pr\Big(\sup_{h\in\mathcal{H}} |R_S(h)-R(h)|>\epsilon\Big)\le |\mathcal{H}|\cdot 2e^{-2m\epsilon^2}.$$

```python
H_size_w = 100  # finite class size from the lesson text.
uniform_bound_w = H_size_w * one_bound_w  # union-bound multiplier.
print("single h:", round(one_bound_w, 6))  # one model.
print("all 100 h:", round(uniform_bound_w, 4))  # class-wide failure.
assert abs(uniform_bound_w - 0.00907998595) < 1e-8  # cited 0.0091 number.
```
▶ What you'll see: multiplying by 100 still gives a failure bound under 1%.

```python
H_grid_w = np.array([1, 10, 100, 1000, 10000])  # increasingly rich finite classes.
class_bounds_w = H_grid_w * one_bound_w  # union-bound failure for each class size.
print("bounds by |H|:", np.round(class_bounds_w, 4))  # see linear price for class size.
plt.figure(figsize=(4.5, 3))  # compact plot.
plt.semilogx(H_grid_w, np.minimum(class_bounds_w, 1), marker="o", color="purple")  # log x for class sizes.
plt.xlabel("$|\\mathcal{H}|$")  # class size.
plt.ylabel("uniform failure bound, clipped")  # probability.
plt.title("2: union bound pays for all h")  # required title.
plt.show()  # display.
```
▶ What you'll see: a linear-in-$|\mathcal{H}|$ price on a log x-axis; very large classes can make the statement vacuous.

*Why it's done this way: the union bound is deliberately simple and safe — if any hypothesis fails, at least one individual failure happened, so summing individual probabilities upper-bounds the bad event.*

### 3. Why this justifies ERM

ERM picks $\hat h=\arg\min_h R_S(h)$, so a one-hypothesis bound cannot protect it. If the uniform event holds, however, every training error is close to every true error at the same time. Then the empirical minimizer cannot be much worse than the best true-risk hypothesis: roughly, $R(\hat h)\le R(h^*)+2\epsilon$.

```python
true_risk_w = np.array([0.30, 0.24, 0.18, 0.22, 0.28])  # true risks for five hypotheses.
emp_risk_w = np.array([0.29, 0.20, 0.19, 0.21, 0.31])  # sample risks observed by ERM.
gaps_w = np.abs(emp_risk_w - true_risk_w)  # train-vs-true gaps for every h.
erm_idx_w = int(np.argmin(emp_risk_w))  # ERM's sample-based choice.
best_idx_w = int(np.argmin(true_risk_w))  # oracle best true-risk choice.
print("gaps:", np.round(gaps_w, 3))  # inspect simultaneous closeness.
print("ERM index:", erm_idx_w, "oracle index:", best_idx_w)  # compare choices.
assert erm_idx_w == 2 and best_idx_w == 2  # here ERM finds the oracle.
```
▶ What you'll see: ERM chooses the hypothesis with the smallest empirical risk, and the gaps are small for all five hypotheses.

```python
eps_event_w = float(np.max(gaps_w))  # empirical uniform-convergence radius for this toy class.
erm_true_w = float(true_risk_w[erm_idx_w])  # true risk of ERM choice.
best_true_w = float(true_risk_w[best_idx_w])  # best true risk in class.
cert_w = best_true_w + 2 * eps_event_w  # standard ERM comparison certificate.
print("sup gap:", round(eps_event_w, 3))  # max_h |R_S-R|.
print("R(ERM):", round(erm_true_w, 3), "<=", round(cert_w, 3))  # certificate.
assert erm_true_w <= cert_w + 1e-12  # uniform convergence implies the ERM guarantee.
```
▶ What you'll see: once the maximum gap is small, ERM's true risk is certified close to the class optimum.

```python
x_w = np.arange(len(true_risk_w))  # hypothesis indices.
plt.figure(figsize=(5, 3))  # compact comparison.
plt.plot(x_w, true_risk_w, marker="o", label="true risk")  # true risks.
plt.plot(x_w, emp_risk_w, marker="s", label="empirical risk")  # sample risks.
plt.scatter([erm_idx_w], [emp_risk_w[erm_idx_w]], s=100, color="red", label="ERM pick")  # highlight ERM.
plt.xlabel("hypothesis index")  # x axis.
plt.ylabel("risk")  # y axis.
plt.title("3: ERM is safe when all gaps are small")  # required title.
plt.legend()  # labels.
plt.show()  # display.
```
▶ What you'll see: the empirical curve tracks the true curve everywhere, so the sample minimizer is meaningful.

*Why it's done this way: ERM is data-dependent, so the proof must cover the model it will choose before knowing which one that is; the $\sup$ event gives exactly that coverage.*

### 4. Vacuous bounds and the sample-size threshold

A probability upper bound above 1 is true but useless. With $|\mathcal{H}|=100$ and $\epsilon=0.1$, small sample sizes make the union-bound statement vacuous. Solving the bound for a target $\delta$ gives the needed sample size:

$$m\ge \frac{\ln |\mathcal{H}|+\ln(2/\delta)}{2\epsilon^2}.$$

```python
m_values_w = np.array([100, 150, 230, 300, 500])  # lesson sample sizes.
raw_bounds_w = H_size_w * 2 * np.exp(-2 * m_values_w * eps_w ** 2)  # finite-class failure bounds.
print("raw bounds:", np.round(raw_bounds_w, 3))  # first three exceed 1, m=300 is 0.496.
assert np.all(raw_bounds_w[:3] >= 1.0)  # cited vacuous rows.
assert abs(raw_bounds_w[3] - 0.495750) < 1e-6  # cited m=300 value.
```
▶ What you'll see: $m=100,150,230$ are vacuous, while $m=300$ finally drops below 1.

```python
delta_w = 0.05  # target failure probability.
needed_w = (np.log(H_size_w) + np.log(2 / delta_w)) / (2 * eps_w ** 2)  # solve for m.
ceil_needed_w = int(np.ceil(needed_w))  # samples are integers.
print("needed m:", round(needed_w, 1), "ceil:", ceil_needed_w)  # 414.7 -> 415.
assert round(needed_w, 1) == 414.7 and ceil_needed_w == 415  # cited sample size.
```
▶ What you'll see: 415 samples are enough to make the whole 100-model class trustworthy at $\epsilon=0.1$, $\delta=0.05$.

```python
plt.figure(figsize=(4.5, 3))  # compact plot.
plt.plot(m_values_w, np.minimum(raw_bounds_w, 1), marker="o", color="darkorange")  # clipped bound.
plt.axhline(delta_w, color="black", linestyle="--", label="$\\delta=0.05$")  # target confidence.
plt.axvline(ceil_needed_w, color="gray", linestyle=":", label="m=415")  # threshold.
plt.xlabel("sample size m")  # x axis.
plt.ylabel("bound, clipped at 1")  # y axis.
plt.title("4: finite-class bound becomes useful")  # required title.
plt.legend()  # show threshold labels.
plt.show()  # display.
```
▶ What you'll see: the curve is flat at the vacuous ceiling until enough samples arrive.

*Why it's done this way: sample complexity is the theorem read backward — choose the confidence and accuracy you want, then solve for how much data makes the uniform event likely.*

### 5. Simulating the maximum gap across a class

A direct demo is to create many threshold classifiers, estimate their true risks on a huge reference set, estimate empirical risks on smaller samples, and plot

$$\max_{h\in\mathcal{H}} |R_S(h)-R(h)|.$$

As $m$ grows, this maximum gap shrinks: not just one hypothesis converges, but the whole finite class moves together.

```python
rng_w = np.random.default_rng(1)  # local reproducible generator.
thresholds_w = np.linspace(0.05, 0.95, 25)  # finite hypothesis class h_t(x)=1[x>t].
ref_x_w = rng_w.random(200_000)  # large reference sample for near-true risks.
ref_y_w = (ref_x_w > 0.5).astype(int)  # noiseless label rule.
true_risks_w = np.array([np.mean((ref_x_w > t) != ref_y_w) for t in thresholds_w])  # near-true risk for each threshold.
print("best threshold:", thresholds_w[np.argmin(true_risks_w)])  # closest to 0.5.
print("best true risk:", round(float(true_risks_w.min()), 4))  # about 0.0125 because grid misses 0.5.
```
▶ What you'll see: the best grid threshold is near 0.5, with nearly zero true risk.

```python
sample_sizes_w = np.array([25, 50, 100, 200, 500, 1000])  # growing m.
max_gaps_w = []  # store sup_h |R_S-R|.
for m_cur_w in sample_sizes_w:  # run one reproducible sample per size.
    x_w = rng_w.random(m_cur_w)  # training inputs.
    y_w = (x_w > 0.5).astype(int)  # labels.
    emp_w = np.array([np.mean((x_w > t) != y_w) for t in thresholds_w])  # empirical risks.
    max_gaps_w.append(float(np.max(np.abs(emp_w - true_risks_w))))  # class-wide max gap.
max_gaps_w = np.array(max_gaps_w)  # convert for plotting.
print("max gaps:", np.round(max_gaps_w, 3))  # generally shrinks with m.
assert max_gaps_w[-1] < 0.08  # stochastic but reproducible: large m has small uniform gap.
```
▶ What you'll see: the maximum gap is much smaller for $m=1000$ than for tiny samples.

```python
bound_eps_w = np.sqrt((np.log(len(thresholds_w)) + np.log(2 / 0.05)) / (2 * sample_sizes_w))  # inverted finite-class bound.
plt.figure(figsize=(4.7, 3))  # compact curve.
plt.plot(sample_sizes_w, max_gaps_w, marker="o", label="simulated sup gap")  # observed gap.
plt.plot(sample_sizes_w, bound_eps_w, marker="s", label="bound radius")  # theoretical safe radius.
plt.xlabel("sample size m")  # x axis.
plt.ylabel("gap")  # y axis.
plt.title("5: max train-true gap shrinks")  # required title.
plt.legend()  # labels.
plt.show()  # display.
```
▶ What you'll see: the empirical maximum gap falls with $m$, and the formal bound is conservative but has the same downward shape.

*Why it's done this way: uniform convergence is a statement about the worst hypothesis in the class, so simulating the maximum gap makes the $\sup$ in the theorem visible.*

### 6. The bound as a generalization penalty

Solving the finite-class bound for $\epsilon$ gives a high-probability penalty:

$$\epsilon(m,\delta,|\mathcal{H}|)=\sqrt{\frac{\ln |\mathcal{H}|+\ln(2/\delta)}{2m}}.$$

This is the generalization-bound shape from earlier Part 1 lessons: bigger classes and higher confidence cost more; more data costs less.

```python
m_pen_w = 500  # fixed data size.
delta_pen_w = 0.05  # fixed failure probability.
H_pen_w = np.array([10, 100, 1000, 10000])  # class sizes.
eps_pen_w = np.sqrt((np.log(H_pen_w) + np.log(2 / delta_pen_w)) / (2 * m_pen_w))  # penalty radius.
print("epsilon penalties:", np.round(eps_pen_w, 3))  # grows slowly with log |H|.
assert np.all(np.diff(eps_pen_w) > 0)  # larger classes pay a larger penalty.
```
▶ What you'll see: each tenfold increase in class size adds only a logarithmic amount to the penalty.

```python
m_grid_w = np.array([100, 200, 500, 1000, 2000])  # data sizes.
eps_grid_w = np.sqrt((np.log(100) + np.log(2 / delta_pen_w)) / (2 * m_grid_w))  # penalty for |H|=100.
print("epsilon vs m:", np.round(eps_grid_w, 3))  # shrinks like 1/sqrt(m).
plt.figure(figsize=(4.5, 3))  # compact figure.
plt.plot(m_grid_w, eps_grid_w, marker="o", color="seagreen")  # penalty curve.
plt.xlabel("sample size m")  # x axis.
plt.ylabel("$\\epsilon$ bound")  # y axis.
plt.title("6: uniform-convergence penalty")  # required title.
plt.show()  # display.
```
▶ What you'll see: doubling data reduces the penalty, but with diminishing returns because it scales as $1/\sqrt{m}$.

*Why it's done this way: this rearranged theorem is what practitioners use as a complexity penalty — empirical risk plus a term for class size, confidence, and data volume.*

### ✍️ Toy 1 · One fixed hypothesis concentrates

For one pre-chosen hypothesis, Hoeffding bounds how far the empirical loss average can drift from
its true risk. Here the printed loss sample lands exactly on the true risk.

```python
import numpy as np                              # arrays + Hoeffding arithmetic.
import matplotlib.pyplot as plt                 # one picture per toy.

t1_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t1_m = 12                                       # sample size                 # -> 12
print("sample size m:", t1_m)                   # -> 12
t1_eps = 0.25                                   # allowed deviation           # -> 0.25
print("epsilon:", t1_eps)                       # -> 0.25
t1_exponent = -2 * t1_m * t1_eps ** 2           # Hoeffding exponent          # -> -1.5
print("Hoeffding exponent:", round(t1_exponent, 3))  # -> -1.5
t1_bound = 2 * np.exp(t1_exponent)              # one-hypothesis failure bound # -> 0.44626032029685964
print("failure bound:", round(float(t1_bound), 4))  # -> 0.4463
t1_losses = np.array([0, 1, 0, 0, 1, 0, 0, 0, 1, 0, 0, 0])  # twelve bounded losses
print("loss sample:", t1_losses.tolist())       # -> [0, 1, 0, 0, 1, 0, 0, 0, 1, 0, 0, 0]
t1_emp = float(t1_losses.mean())                # empirical risk              # -> 0.25
print("empirical risk:", round(t1_emp, 3))      # -> 0.25
t1_true = 0.25                                  # fixed hypothesis true risk  # -> 0.25
print("true risk:", t1_true)                    # -> 0.25
t1_gap = abs(t1_emp - t1_true)                  # absolute train-true gap     # -> 0.0
print("absolute gap:", round(t1_gap, 3))        # -> 0.0
assert np.isclose(t1_emp, t1_true)              # this particular sample has zero gap

plt.figure(figsize=(4.4, 2.8))
plt.bar(["empirical", "true"], [t1_emp, t1_true], color=["#4c78a8", "#54a24b"])
plt.ylabel("risk")
plt.title("Toy 1 · one fixed h has one average")
plt.show()
```
▶ What you'll see: empirical and true risk both equal `0.25`, while the bound says larger gaps are unlikely.

### ✍️ Toy 2 · Union bound pays once per hypothesis

Uniform convergence asks all hypotheses to be good at once. The finite-class union bound multiplies
the one-hypothesis failure probability by the class size.

```python
import numpy as np                              # arrays + union-bound arithmetic.

t2_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t2_one_bound = 0.08                             # failure bound for one fixed h  # -> 0.08
print("one-hypothesis bound:", t2_one_bound)    # -> 0.08
t2_H = np.array([1, 2, 4, 8])                   # four finite class sizes
print("class sizes:", t2_H.tolist())            # -> [1, 2, 4, 8]
t2_uniform = t2_H * t2_one_bound                # union-bound failure values     # -> [0.08 0.16 0.32 0.64]
print("union bounds:", np.round(t2_uniform, 3).tolist())  # -> [0.08, 0.16, 0.32, 0.64]
t2_clipped = np.minimum(t2_uniform, 1.0)        # probabilities clipped for plotting # -> [0.08 0.16 0.32 0.64]
print("clipped bounds:", np.round(t2_clipped, 3).tolist())  # -> [0.08, 0.16, 0.32, 0.64]
t2_price = float(t2_uniform[-1] / t2_uniform[0])  # price from |H|=1 to |H|=8      # -> 8.0
print("largest/smallest price:", round(t2_price, 1))  # -> 8.0
assert np.isclose(t2_uniform[2], 0.32)          # four hypotheses cost 4 * 0.08

plt.figure(figsize=(4.6, 2.8))
plt.plot(t2_H, t2_clipped, marker="o", color="#9467bd")
plt.xlabel("|H|")
plt.ylabel("failure bound")
plt.title("Toy 2 · union bound multiplies by |H|")
plt.show()
```
▶ What you'll see: doubling the class size doubles the bound: `0.08, 0.16, 0.32, 0.64`.

### ✍️ Toy 3 · ERM is certified by the sup gap

ERM chooses from empirical risks, but the guarantee uses the largest train-true gap across the whole
class. Once that sup gap is small, ERM's true risk is bounded near the oracle's.

```python
import numpy as np                              # arrays + ERM comparison.

t3_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t3_true = np.array([0.32, 0.20, 0.27, 0.24])    # true risks for four hypotheses
print("true risks:", t3_true.tolist())          # -> [0.32, 0.2, 0.27, 0.24]
t3_emp = np.array([0.28, 0.23, 0.22, 0.26])     # empirical risks seen by ERM
print("empirical risks:", t3_emp.tolist())      # -> [0.28, 0.23, 0.22, 0.26]
t3_gaps = np.abs(t3_emp - t3_true)              # simultaneous train-true gaps  # -> [0.04 0.03 0.05 0.02]
print("absolute gaps:", np.round(t3_gaps, 3).tolist())  # -> [0.04, 0.03, 0.05, 0.02]
t3_erm = int(np.argmin(t3_emp))                 # empirical minimizer index     # -> 2
print("ERM index:", t3_erm)                     # -> 2
t3_oracle = int(np.argmin(t3_true))             # true-risk oracle index        # -> 1
print("oracle index:", t3_oracle)               # -> 1
t3_sup_gap = float(t3_gaps.max())               # max_h |R_S - R|              # -> 0.05000000000000002
print("sup gap:", round(t3_sup_gap, 3))         # -> 0.05
t3_certificate = float(t3_true[t3_oracle] + 2 * t3_sup_gap)  # oracle + 2ε        # -> 0.30000000000000004
print("certificate:", round(t3_certificate, 3)) # -> 0.3
t3_erm_true = float(t3_true[t3_erm])            # true risk of ERM choice       # -> 0.27
print("ERM true risk:", round(t3_erm_true, 3))  # -> 0.27
assert t3_erm_true <= t3_certificate            # uniform event certifies ERM

plt.figure(figsize=(4.8, 2.8))
plt.plot(t3_true, marker="o", label="true")
plt.plot(t3_emp, marker="s", label="empirical")
plt.scatter([t3_erm], [t3_emp[t3_erm]], color="red", s=80, label="ERM")
plt.xlabel("hypothesis index")
plt.ylabel("risk")
plt.title("Toy 3 · sup gap protects ERM")
plt.legend()
plt.show()
```
▶ What you'll see: ERM picks index `2`, and its true risk `0.27` is below the `0.30` certificate.

### ✍️ Toy 4 · Vacuous bounds need enough samples

A probability upper bound above one is technically true but useless. Solve the same formula backward
to find the first useful sample size for a target `δ`.

```python
import numpy as np                              # arrays + sample-size algebra.

t4_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t4_H = 8                                        # finite class size            # -> 8
print("class size:", t4_H)                      # -> 8
t4_eps = 0.3                                    # target accuracy radius      # -> 0.3
print("epsilon:", t4_eps)                       # -> 0.3
t4_delta = 0.2                                  # target failure probability  # -> 0.2
print("delta:", t4_delta)                       # -> 0.2
t4_m = np.array([4, 8, 12, 20])                 # candidate sample sizes
print("sample sizes:", t4_m.tolist())           # -> [4, 8, 12, 20]
t4_bounds = t4_H * 2 * np.exp(-2 * t4_m * t4_eps ** 2)  # raw finite-class bounds # -> [7.7880361  3.79084414 1.84520194 0.43717956]
print("raw bounds:", np.round(t4_bounds, 3).tolist())  # -> [7.788, 3.791, 1.845, 0.437]
t4_clipped = np.minimum(t4_bounds, 1.0)         # displayable probabilities    # -> [1.         1.         1.         0.43717956]
print("clipped bounds:", np.round(t4_clipped, 3).tolist())  # -> [1.0, 1.0, 1.0, 0.437]
t4_needed = (np.log(t4_H) + np.log(2 / t4_delta)) / (2 * t4_eps ** 2)  # solve for m # -> 24.344592414854898
print("needed m:", round(float(t4_needed), 2))  # -> 24.34
t4_ceil = int(np.ceil(t4_needed))               # integer sample threshold     # -> 25
print("ceil needed:", t4_ceil)                  # -> 25
assert t4_bounds[0] > 1                         # small-m bound is vacuous
assert t4_ceil == 25                            # 25 samples meet the δ target

plt.figure(figsize=(4.6, 2.8))
plt.plot(t4_m, t4_clipped, marker="o", color="#f58518")
plt.axhline(t4_delta, linestyle="--", color="black", label="δ=0.2")
plt.xlabel("sample size m")
plt.ylabel("bound clipped at 1")
plt.title("Toy 4 · enough samples un-vacuate it")
plt.legend()
plt.show()
```
▶ What you'll see: the first three displayed bounds are stuck at `1.0`, and the formula asks for `25` samples.

### ✍️ Toy 5 · The sup gap scans the whole class

Uniform convergence watches the worst hypothesis. For three threshold classifiers, compute empirical
risk, compare to reference true risk, and take the maximum absolute gap.

```python
import numpy as np                              # arrays + threshold risks.

t5_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t5_x = np.array([0.05, 0.20, 0.35, 0.55, 0.70, 0.90])  # six inputs
print("x sample:", t5_x.tolist())               # -> [0.05, 0.2, 0.35, 0.55, 0.7, 0.9]
t5_y = (t5_x > 0.5).astype(int)                 # noiseless labels            # -> [0 0 0 1 1 1]
print("labels:", t5_y.tolist())                 # -> [0, 0, 0, 1, 1, 1]
t5_thresholds = np.array([0.25, 0.50, 0.75])    # three hypotheses
print("thresholds:", t5_thresholds.tolist())    # -> [0.25, 0.5, 0.75]
t5_true = np.array([0.25, 0.00, 0.25])          # reference true risks under Uniform[0,1]
```

## Setup

```python
# !pip install numpy matplotlib  # Colab already includes these; uncomment only if your runtime is missing them.
import numpy as np  # Use NumPy for arrays, random simulations, masks, and numerical assertions.
import matplotlib.pyplot as plt  # Use Matplotlib for every small diagnostic visualization.
np.random.seed(0)  # Fix global randomness so all examples are reproducible.

def hoeffding_one(m, eps):  # Bound one fixed bounded-loss hypothesis.
    m = max(float(m), 1.0)  # Guard against division-by-zero style invalid sample sizes.
    eps = max(float(eps), 0.0)  # Accuracy radii are nonnegative.
    return float(2 * np.exp(-2 * m * eps ** 2))  # Return 2 exp(-2 m eps^2).

def uniform_bound(H_size, m, eps):  # Finite-class union-bound failure probability.
    return float(H_size * hoeffding_one(m, eps))  # Multiply one-hypothesis failure by |H|.

def epsilon_bound(H_size, m, delta):  # Solve the finite-class bound for epsilon.
    H_size = max(float(H_size), 1.0)  # Keep log defined.
    m = max(float(m), 1.0)  # Keep denominator nonzero.
    delta = min(max(float(delta), 1e-12), 1.0)  # Keep confidence in a valid numeric range.
    return float(np.sqrt((np.log(H_size) + np.log(2 / delta)) / (2 * m)))  # Return the safe radius.

def sample_needed(H_size, eps, delta):  # Solve the finite-class bound for m.
    eps = max(float(eps), 1e-12)  # Guard against division by zero.
    delta = min(max(float(delta), 1e-12), 1.0)  # Keep log finite.
    return float((np.log(H_size) + np.log(2 / delta)) / (2 * eps ** 2))  # Required real-valued sample size.

def true_risk_threshold(t):  # True 0-1 risk for h_t(x)=1[x>t] against y=1[x>0.5], X uniform on [0,1].
    return float(abs(t - 0.5))  # Errors occur exactly on the interval between t and 0.5.

def empirical_risk_threshold(x, t):  # Empirical 0-1 risk for the same threshold rule.
    y = (x > 0.5).astype(int)  # Generate noiseless labels from the true threshold.
    pred = (x > t).astype(int)  # Predict with candidate threshold t.
    return float(np.mean(pred != y))  # Average 0-1 loss.

def max_threshold_gap(x, thresholds):  # Compute sup_h |R_S(h)-R(h)| over a finite threshold grid.
    emp = np.array([empirical_risk_threshold(x, t) for t in thresholds])  # Empirical risks over the grid.
    tru = np.array([true_risk_threshold(t) for t in thresholds])  # Analytic true risks over the grid.
    return float(np.max(np.abs(emp - tru)))  # Return the maximum absolute gap.

def show_bar(labels, values, title):  # Small reusable bar-plot helper.
    plt.figure(figsize=(4.6, 3))  # Create a compact figure.
    plt.bar(labels, values, color="steelblue")  # Draw values as bars.
    plt.title(title)  # Add the requested example title.
    plt.xticks(rotation=20)  # Keep labels readable.
    plt.show()  # Display the figure.
```

```python
show_bar(["R(ERM)", "R(best)+2eps"], [lhs_e4, rhs_e4], "E4: ERM certificate")  # Visualize.
```
▶ What you'll see: the certificate upper-bounds the true risk of ERM.

👀 Takeaway: uniform convergence converts sample optimality into near-true optimality.
