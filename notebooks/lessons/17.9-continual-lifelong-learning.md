# 17.9 — Continual & Lifelong Learning

Continual learning studies models that face tasks in sequence instead of receiving one frozen dataset. In this lesson, we build a tiny learner from scratch, watch task B overwrite task A (**catastrophic forgetting**), then add two core defenses: **Elastic Weight Consolidation (EWC)**, which protects parameters that mattered for the old task, and **rehearsal/replay**, which keeps a small memory of old examples in the new-task stream.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build continual learning one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including forgetting curves, EWC penalties, old-task importance, and replay batches, is exposed. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, toy data, gradients, and numerical checks.
import matplotlib.pyplot as plt  # compact plots for boundaries and forgetting curves.
np.random.seed(0)  # reproducibility for the synthetic task sequence.
```

### 1. Catastrophic forgetting: one set of weights, two shifting tasks

A continual learner receives task A, updates its weights, then receives task B. The same parameter vector must now serve a new distribution. If task B's gradients point in a direction that changes weights task A relied on, task A accuracy can collapse even while task B accuracy improves. That collapse is **catastrophic forgetting**: not because the model is too small for either task alone, but because sequential optimization overwrites old solutions.

```python
def sigmoid_w(z_w):  # logistic probability for a binary classifier.
    return 1.0 / (1.0 + np.exp(-np.clip(z_w, -30, 30)))  # clip for numerical stability.

def add_bias_w(X_w):  # append a constant feature so the model learns an intercept.
    return np.c_[X_w, np.ones(len(X_w))]  # shape: n examples by 3 parameters.

rng_w = np.random.default_rng(0)  # local generator for the walkthrough.
X_base_w = rng_w.normal(size=(240, 2))  # one shared input cloud for both tasks.
yA_w = (X_base_w[:, 0] + 0.25 * X_base_w[:, 1] > 0).astype(float)  # task A boundary: mostly x0.
yB_w = (X_base_w[:, 1] - 0.25 * X_base_w[:, 0] > 0).astype(float)  # task B boundary: mostly x1.
X_w = add_bias_w(X_base_w)  # include an intercept parameter.
print("X shape:", X_w.shape, "task A positives:", int(yA_w.sum()), "task B positives:", int(yB_w.sum()))
```
▶ What you'll see: the same 240 inputs carry two different label rules, so the data order really matters.

```python
plt.figure(figsize=(5, 3))
plt.scatter(X_base_w[:, 0], X_base_w[:, 1], c=yA_w, cmap="coolwarm", s=18, alpha=0.75)
plt.title("1: task A labels (mostly x0)"); plt.xlabel("x0"); plt.ylabel("x1"); plt.show()
```
▶ What you'll see: task A splits the cloud mostly left-versus-right.

```python
plt.figure(figsize=(5, 3))
plt.scatter(X_base_w[:, 0], X_base_w[:, 1], c=yB_w, cmap="coolwarm", s=18, alpha=0.75)
plt.title("1: task B labels (mostly x1)"); plt.xlabel("x0"); plt.ylabel("x1"); plt.show()
```
▶ What you'll see: task B splits the same cloud mostly bottom-versus-top, asking the classifier to rotate its decision boundary.

```python
def loss_grad_w(theta_w, Xbatch_w, ybatch_w, l2_w=0.0):  # binary cross-entropy gradient.
    p_w = sigmoid_w(Xbatch_w @ theta_w)  # predicted probability for class 1.
    grad_w = Xbatch_w.T @ (p_w - ybatch_w) / len(ybatch_w) + l2_w * theta_w  # mean gradient.
    loss_w = -np.mean(ybatch_w * np.log(p_w + 1e-9) + (1 - ybatch_w) * np.log(1 - p_w + 1e-9))  # BCE.
    return loss_w, grad_w  # return both so training can inspect learning.

def acc_w(theta_w, Xeval_w, yeval_w):  # accuracy for a logistic classifier.
    return float(np.mean((sigmoid_w(Xeval_w @ theta_w) >= 0.5) == yeval_w))  # threshold probabilities at 0.5.

def train_plain_w(theta_w, Xtrain_w, ytrain_w, steps_w=400, lr_w=0.4):  # full-batch gradient descent.
    theta_w = theta_w.copy()  # avoid mutating caller weights.
    for _ in range(steps_w):
        _, grad_w = loss_grad_w(theta_w, Xtrain_w, ytrain_w)  # current task gradient.
        theta_w -= lr_w * grad_w  # ordinary gradient descent update.
    return theta_w
print("helpers ready")
```
▶ What you'll see: a tiny logistic learner is enough to demonstrate forgetting without any ML framework.

```python
theta0_w = np.zeros(3)  # start from no preference and no intercept.
thetaA_w = train_plain_w(theta0_w, X_w, yA_w, steps_w=500, lr_w=0.4)  # learn task A first.
print("theta after A:", np.round(thetaA_w, 3))
print("A acc after A:", round(acc_w(thetaA_w, X_w, yA_w), 3), "B acc after A:", round(acc_w(thetaA_w, X_w, yB_w), 3))
assert acc_w(thetaA_w, X_w, yA_w) > 0.97
```
▶ What you'll see: after task A, the first coordinate of θ is large and A accuracy is near perfect.

```python
thetaB_plain_w = train_plain_w(thetaA_w, X_w, yB_w, steps_w=500, lr_w=0.4)  # continue on task B only.
print("theta after B-only training:", np.round(thetaB_plain_w, 3))
print("A acc after B:", round(acc_w(thetaB_plain_w, X_w, yA_w), 3), "B acc after B:", round(acc_w(thetaB_plain_w, X_w, yB_w), 3))
assert acc_w(thetaB_plain_w, X_w, yB_w) > 0.97
```
▶ What you'll see: task B becomes accurate, but the weight vector rotates toward x1 and task A accuracy drops sharply.

```python
curve_A_plain_w, curve_B_plain_w = [], []  # store accuracies during sequential B training.
theta_curve_w = thetaA_w.copy()  # start from the task-A solution.
for step_w in range(121):
    curve_A_plain_w.append(acc_w(theta_curve_w, X_w, yA_w))  # old-task accuracy at this time.
    curve_B_plain_w.append(acc_w(theta_curve_w, X_w, yB_w))  # new-task accuracy at this time.
    _, grad_w = loss_grad_w(theta_curve_w, X_w, yB_w)  # B-only gradient.
    theta_curve_w -= 0.4 * grad_w  # update toward B.
plt.figure(figsize=(5, 3))
plt.plot(curve_A_plain_w, label="task A accuracy")
plt.plot(curve_B_plain_w, label="task B accuracy")
plt.title("1: forgetting curve under B-only training"); plt.xlabel("B update"); plt.ylabel("accuracy"); plt.legend(); plt.show()
```
▶ What you'll see: B accuracy rises while A accuracy falls — the classic stability-plasticity conflict.

*Why it's done this way:* logistic regression makes the overwriting geometry visible. Task A needs a large x0 weight; task B needs a large x1 weight and a different rotation. Gradient descent does not remember which coordinates were useful before; it only follows the current loss. Forgetting is therefore a property of sequential optimization, not a mysterious neural-network-only failure.

### 2. Elastic Weight Consolidation: protect important old parameters

Elastic Weight Consolidation (EWC) adds a quadratic spring around the old solution: $$L_B(\theta)+\frac{\lambda}{2}\sum_i F_i(\theta_i-\theta_{A,i})^2.$$ The saved vector $\theta_A$ says where task A ended. The importance vector $F$ says which parameters task A was sensitive to. Moving an important parameter is expensive; moving an unimportant one is cheap. This turns continual learning into a weighted compromise between plasticity for task B and stability for task A.

```python
F_w = thetaA_w ** 2  # toy diagonal importance: parameters with larger old-task weights matter more.
F_w = F_w / (F_w.max() + 1e-12)  # scale for readable penalties.
print("scaled importance F:", np.round(F_w, 3))
assert F_w[0] > F_w[1]
```
▶ What you'll see: the x0 parameter is most important for task A, because task A's boundary mostly used x0.

```python
candidate_w = np.array([0.0, thetaA_w[1], thetaA_w[2]])  # erase the important x0 weight but keep others.
move_w = candidate_w - thetaA_w  # parameter movement away from the saved A solution.
penalty_w = 0.5 * np.sum(F_w * move_w ** 2)  # EWC penalty with lambda=1.
print("movement:", np.round(move_w, 3))
print("EWC penalty with λ=1:", round(float(penalty_w), 3))
assert penalty_w > 3.0
```
▶ What you'll see: erasing the important x0 coordinate receives a large penalty.

```python
candidate2_w = thetaA_w + np.array([0.0, 2.0, 0.0])  # move mostly along the less important x1 coordinate.
move2_w = candidate2_w - thetaA_w  # compare to the task-A anchor.
penalty2_w = 0.5 * np.sum(F_w * move2_w ** 2)  # weighted squared movement.
print("less-important movement penalty:", round(float(penalty2_w), 3))
assert penalty2_w < penalty_w
```
▶ What you'll see: movement along a less important coordinate is cheaper than destroying x0.

```python
def train_ewc_w(theta_start_w, Xtrain_w, ytrain_w, theta_old_w, F_old_w, lam_w=20.0, steps_w=500, lr_w=0.25):
    theta_w = theta_start_w.copy()  # begin from the old solution.
    for _ in range(steps_w):
        _, grad_task_w = loss_grad_w(theta_w, Xtrain_w, ytrain_w)  # gradient for new task B.
        grad_ewc_w = lam_w * F_old_w * (theta_w - theta_old_w)  # derivative of the quadratic spring.
        theta_w -= lr_w * (grad_task_w + grad_ewc_w)  # descend the combined objective.
        theta_w = np.clip(theta_w, -12, 12)  # keep the tiny demo numerically finite under strong springs.
    return theta_w

thetaB_ewc_w = train_ewc_w(thetaA_w, X_w, yB_w, thetaA_w, F_w, lam_w=18.0, steps_w=500, lr_w=0.25)
print("theta with EWC:", np.round(thetaB_ewc_w, 3))
print("A acc:", round(acc_w(thetaB_ewc_w, X_w, yA_w), 3), "B acc:", round(acc_w(thetaB_ewc_w, X_w, yB_w), 3))
assert acc_w(thetaB_ewc_w, X_w, yA_w) > acc_w(thetaB_plain_w, X_w, yA_w)
```
▶ What you'll see: EWC preserves more old-task accuracy than B-only training, usually at some cost to B accuracy.

```python
curve_A_ewc_w, curve_B_ewc_w = [], []  # accuracies during EWC training on B.
theta_curve_ewc_w = thetaA_w.copy()
for step_w in range(121):
    curve_A_ewc_w.append(acc_w(theta_curve_ewc_w, X_w, yA_w))
    curve_B_ewc_w.append(acc_w(theta_curve_ewc_w, X_w, yB_w))
    _, grad_task_w = loss_grad_w(theta_curve_ewc_w, X_w, yB_w)
    theta_curve_ewc_w -= 0.25 * (grad_task_w + 18.0 * F_w * (theta_curve_ewc_w - thetaA_w))
plt.figure(figsize=(5, 3))
plt.plot(curve_A_plain_w, "--", label="A plain")
plt.plot(curve_A_ewc_w, label="A with EWC")
plt.plot(curve_B_ewc_w, label="B with EWC")
plt.title("2: EWC slows old-task forgetting"); plt.xlabel("B update"); plt.ylabel("accuracy"); plt.legend(); plt.show()
```
▶ What you'll see: the EWC A curve stays higher than the plain A curve because important movement is penalized.

*Why it's done this way:* the diagonal Fisher approximation is a cheap sensitivity estimate: if changing parameter $i$ would strongly change old-task predictions, $F_i$ is large. The quadratic penalty is exactly a coordinate-wise spring, so it does not freeze the whole model; it freezes important directions more than unimportant directions. The price is that too-large $\lambda$ can prevent useful adaptation to task B.

### 3. Rehearsal and replay: mix a small memory with the new task

Rehearsal attacks forgetting from the data side. Instead of protecting weights directly, it stores a small buffer of old examples and replays them while learning task B. The new gradient is then an average of B examples and remembered A examples, so updates are continually reminded what old decisions should still look like.

```python
memory_idx_w = rng_w.choice(len(X_w), size=32, replace=False)  # a small memory buffer from task A.
Xmem_w = X_w[memory_idx_w]  # remembered inputs.
ymem_w = yA_w[memory_idx_w]  # remembered old labels.
print("memory size:", len(memory_idx_w), "of", len(X_w), "examples")
print("memory A positive rate:", round(float(ymem_w.mean()), 3))
```
▶ What you'll see: replay keeps only a small fraction of the old task, not the full dataset.

```python
def train_replay_w(theta_start_w, XB_w, yB_w, Xmem_w, ymem_w, steps_w=500, lr_w=0.25, replay_weight_w=1.0):
    theta_w = theta_start_w.copy()  # start from task A.
    for _ in range(steps_w):
        _, gradB_w = loss_grad_w(theta_w, XB_w, yB_w)  # gradient for the new task.
        _, gradM_w = loss_grad_w(theta_w, Xmem_w, ymem_w)  # gradient for remembered old examples.
        theta_w -= lr_w * (gradB_w + replay_weight_w * gradM_w) / (1.0 + replay_weight_w)  # blend the two objectives.
    return theta_w

thetaB_replay_w = train_replay_w(thetaA_w, X_w, yB_w, Xmem_w, ymem_w, steps_w=500, lr_w=0.25, replay_weight_w=1.0)
print("theta with replay:", np.round(thetaB_replay_w, 3))
print("A acc:", round(acc_w(thetaB_replay_w, X_w, yA_w), 3), "B acc:", round(acc_w(thetaB_replay_w, X_w, yB_w), 3))
assert acc_w(thetaB_replay_w, X_w, yA_w) > acc_w(thetaB_plain_w, X_w, yA_w)
```
▶ What you'll see: replay also improves old-task retention compared with B-only training.

```python
methods_w = ["plain", "EWC", "replay"]
A_scores_w = [acc_w(thetaB_plain_w, X_w, yA_w), acc_w(thetaB_ewc_w, X_w, yA_w), acc_w(thetaB_replay_w, X_w, yA_w)]
B_scores_w = [acc_w(thetaB_plain_w, X_w, yB_w), acc_w(thetaB_ewc_w, X_w, yB_w), acc_w(thetaB_replay_w, X_w, yB_w)]
xpos_w = np.arange(len(methods_w))
plt.figure(figsize=(5.5, 3))
plt.bar(xpos_w - 0.18, A_scores_w, width=0.36, label="task A")
plt.bar(xpos_w + 0.18, B_scores_w, width=0.36, label="task B")
plt.xticks(xpos_w, methods_w); plt.ylim(0, 1.05); plt.ylabel("accuracy")
plt.title("3: retention-plasticity comparison"); plt.legend(); plt.show()
```
▶ What you'll see: plain training is most plastic for B, while EWC and replay retain more of A.

*Why it's done this way:* replay changes the gradient itself. A B-only gradient says, “move wherever improves B.” A replay gradient says, “move only if the average of B and remembered A approves.” The buffer is an empirical approximation to the old data distribution; it is simple and powerful, but biased if the memory is unrepresentative or impossible when storage/privacy forbids examples.

### ✍️ Toy 1 · Sequential training overwrites an old solution

Task A wants one parameter vector; task B wants a different one. Training on B after A moves the
same weights away from A.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)
print("rng seed:", 0)  # -> 0
t1_X = np.eye(2)
print("X:", t1_X.tolist())  # -> [[1.0, 0.0], [0.0, 1.0]]
t1_yA = np.array([2.0, 0.0])
print("task A targets:", t1_yA.tolist())  # -> [2.0, 0.0]
t1_yB = np.array([0.0, 2.0])
print("task B targets:", t1_yB.tolist())  # -> [0.0, 2.0]
t1_theta0 = np.array([0.0, 0.0])
print("start theta:", t1_theta0.tolist())  # -> [0.0, 0.0]
t1_grad_A = t1_X.T @ (t1_X @ t1_theta0 - t1_yA)
print("task A gradient:", t1_grad_A.tolist())  # -> [-2.0, 0.0]
t1_thetaA = t1_theta0 - t1_grad_A
print("theta after A:", t1_thetaA.tolist())  # -> [2.0, 0.0]
t1_A_loss_after_A = 0.5 * np.mean((t1_X @ t1_thetaA - t1_yA) ** 2)
print("A loss after A:", round(float(t1_A_loss_after_A), 3))  # -> 0.0
t1_B_loss_after_A = 0.5 * np.mean((t1_X @ t1_thetaA - t1_yB) ** 2)
print("B loss after A:", round(float(t1_B_loss_after_A), 3))  # -> 2.0
t1_grad_B = t1_X.T @ (t1_X @ t1_thetaA - t1_yB)
print("task B gradient:", t1_grad_B.tolist())  # -> [2.0, -2.0]
t1_thetaB = t1_thetaA - t1_grad_B
print("theta after B:", t1_thetaB.tolist())  # -> [0.0, 2.0]
t1_A_loss_after_B = 0.5 * np.mean((t1_X @ t1_thetaB - t1_yA) ** 2)
print("A loss after B:", round(float(t1_A_loss_after_B), 3))  # -> 2.0
t1_B_loss_after_B = 0.5 * np.mean((t1_X @ t1_thetaB - t1_yB) ** 2)
print("B loss after B:", round(float(t1_B_loss_after_B), 3))  # -> 0.0
assert t1_A_loss_after_B > t1_A_loss_after_A and t1_B_loss_after_B == 0.0

plt.figure(figsize=(4.6, 2.8))
plt.bar(["A after A", "A after B", "B after B"], [t1_A_loss_after_A, t1_A_loss_after_B, t1_B_loss_after_B], color=["seagreen", "crimson", "steelblue"])
plt.ylabel("loss")
plt.title("Toy 1 · B training forgets A")
plt.show()
```
▶ What you'll see: task B loss falls to zero while task A loss jumps from zero to 2.0.

### ✍️ Toy 2 · EWC charges important movement

EWC adds a weighted quadratic spring around the old solution. Moving the important coordinate is
expensive even if it helps the new task.

```python
import numpy as np

t2_rng = np.random.default_rng(0)
print("rng seed:", 0)  # -> 0
t2_theta_old = np.array([2.0, 0.0])
print("old theta:", t2_theta_old.tolist())  # -> [2.0, 0.0]
t2_theta_B_star = np.array([0.0, 2.0])
print("task B optimum:", t2_theta_B_star.tolist())  # -> [0.0, 2.0]
t2_F = np.array([1.0, 0.1])
print("importance F:", t2_F.tolist())  # -> [1.0, 0.1]
t2_plain = np.array([0.0, 2.0])
print("plain B candidate:", t2_plain.tolist())  # -> [0.0, 2.0]
t2_plain_move = t2_plain - t2_theta_old
print("plain movement:", t2_plain_move.tolist())  # -> [-2.0, 2.0]
t2_plain_penalty = 0.5 * np.sum(t2_F * t2_plain_move ** 2)
print("plain EWC penalty:", round(float(t2_plain_penalty), 3))  # -> 2.2
t2_keep = np.array([1.5, 2.0])
print("protected candidate:", t2_keep.tolist())  # -> [1.5, 2.0]
t2_keep_move = t2_keep - t2_theta_old
print("protected movement:", t2_keep_move.tolist())  # -> [-0.5, 2.0]
t2_keep_penalty = 0.5 * np.sum(t2_F * t2_keep_move ** 2)
print("protected EWC penalty:", round(float(t2_keep_penalty), 3))  # -> 0.325
t2_plain_B_loss = 0.5 * np.mean((t2_plain - t2_theta_B_star) ** 2)
print("plain B loss:", round(float(t2_plain_B_loss), 3))  # -> 0.0
t2_keep_B_loss = 0.5 * np.mean((t2_keep - t2_theta_B_star) ** 2)
print("protected B loss:", round(float(t2_keep_B_loss), 3))  # -> 0.562
t2_plain_obj = t2_plain_B_loss + t2_plain_penalty
print("plain combined objective:", round(float(t2_plain_obj), 3))  # -> 2.2
t2_keep_obj = t2_keep_B_loss + t2_keep_penalty
print("protected combined objective:", round(float(t2_keep_obj), 3))  # -> 0.887
assert t2_keep_obj < t2_plain_obj and t2_keep[0] > t2_plain[0]

plt.figure(figsize=(4.6, 2.8))
plt.bar(["plain", "protected"], [t2_plain_obj, t2_keep_obj], color=["crimson", "seagreen"])
plt.ylabel("B loss + EWC penalty")
plt.title("Toy 2 · spring favors retention")
plt.show()
```
▶ What you'll see: the protected candidate has worse B loss but a much lower combined EWC objective.

### ✍️ Toy 3 · Replay blends new and memory gradients

Replay changes the update direction by averaging the new-task gradient with a memory gradient from
old examples.

```python
import numpy as np

t3_rng = np.random.default_rng(0)
print("rng seed:", 0)  # -> 0
t3_theta = np.array([1.0, 1.0])
print("current theta:", t3_theta.tolist())  # -> [1.0, 1.0]
t3_yA = np.array([2.0, 0.0])
print("memory A target:", t3_yA.tolist())  # -> [2.0, 0.0]
t3_yB = np.array([0.0, 2.0])
print("new B target:", t3_yB.tolist())  # -> [0.0, 2.0]
t3_grad_B = t3_theta - t3_yB
print("new-task gradient:", t3_grad_B.tolist())  # -> [1.0, -1.0]
t3_grad_mem = t3_theta - t3_yA
print("memory gradient:", t3_grad_mem.tolist())  # -> [-1.0, 1.0]
t3_replay_weight = 0.5
print("replay weight:", t3_replay_weight)  # -> 0.5
t3_grad_mix = (t3_grad_B + t3_replay_weight * t3_grad_mem) / (1.0 + t3_replay_weight)
print("mixed gradient:", np.round(t3_grad_mix, 3).tolist())  # -> [0.333, -0.333]
t3_lr = 0.5
print("learning rate:", t3_lr)  # -> 0.5
t3_theta_bonly = t3_theta - t3_lr * t3_grad_B
print("theta B-only:", t3_theta_bonly.tolist())  # -> [0.5, 1.5]
t3_theta_replay = t3_theta - t3_lr * t3_grad_mix
print("theta replay:", np.round(t3_theta_replay, 3).tolist())  # -> [0.833, 1.167]
t3_A_loss_bonly = 0.5 * np.mean((t3_theta_bonly - t3_yA) ** 2)
print("A loss B-only:", round(float(t3_A_loss_bonly), 3))  # -> 1.125
t3_A_loss_replay = 0.5 * np.mean((t3_theta_replay - t3_yA) ** 2)
print("A loss replay:", round(float(t3_A_loss_replay), 3))  # -> 0.681
t3_B_loss_before = 0.5 * np.mean((t3_theta - t3_yB) ** 2)
print("B loss before:", round(float(t3_B_loss_before), 3))  # -> 0.5
t3_B_loss_replay = 0.5 * np.mean((t3_theta_replay - t3_yB) ** 2)
print("B loss replay:", round(float(t3_B_loss_replay), 3))  # -> 0.347
assert t3_A_loss_replay < t3_A_loss_bonly and t3_B_loss_replay < t3_B_loss_before

plt.figure(figsize=(4.8, 2.8))
t3_xpos = np.arange(2)
plt.bar(t3_xpos - 0.17, [t3_A_loss_bonly, t3_B_loss_before], width=0.34, label="B-only / before")
plt.bar(t3_xpos + 0.17, [t3_A_loss_replay, t3_B_loss_replay], width=0.34, label="replay")
plt.xticks(t3_xpos, ["A loss", "B loss"])
plt.ylabel("loss")
plt.title("Toy 3 · replay trades plasticity for retention")
plt.legend()
plt.show()
```
▶ What you'll see: replay keeps old-task loss lower than B-only while still improving B from its starting loss.

## 🛠️ Setup

```python
import numpy as np # load NumPy for toy task sequences, vectorized logistic regression, and numerical checks.
import matplotlib.pyplot as plt # load Matplotlib for scatter plots, parameter bars, and forgetting curves.
np.random.seed(0) # make all examples deterministic across notebook runs.

def sigmoid(z): # Convert logits to probabilities for binary logistic regression.
    return 1.0 / (1.0 + np.exp(-np.clip(z, -30, 30))) # Clip logits so exponentials stay finite.

def add_bias(X): # Append a bias column to a two-dimensional feature matrix.
    return np.c_[X, np.ones(len(X))] # The final model parameter is the intercept.

def make_tasks(seed=0, n=240, angle_shift=True): # Build two sequential binary classification tasks.
    rng = np.random.default_rng(seed) # Use a local generator so examples do not disturb each other.
    X2 = rng.normal(size=(n, 2)) # Draw a shared Gaussian input cloud.
    yA = (X2[:, 0] + 0.25 * X2[:, 1] > 0).astype(float) # Task A labels mostly depend on x0.
    yB = (X2[:, 1] - 0.25 * X2[:, 0] > 0).astype(float) if angle_shift else (X2[:, 0] - 0.25 * X2[:, 1] > 0).astype(float) # Task B can rotate the boundary.
    return add_bias(X2), X2, yA, yB # Return biased and raw features plus both labelings.

def loss_grad(theta, X, y, l2=0.0): # Compute binary cross-entropy and its gradient.
    p = sigmoid(X @ theta) # Predict probabilities for the current weights.
    loss = -np.mean(y * np.log(p + 1e-9) + (1 - y) * np.log(1 - p + 1e-9)) + 0.5 * l2 * float(theta @ theta) # Average BCE plus optional L2.
    grad = X.T @ (p - y) / len(y) + l2 * theta # Gradient of the same objective.
    return loss, grad # Return both for training curves and updates.

def accuracy(theta, X, y): # Compute classification accuracy from logistic probabilities.
    return float(np.mean((sigmoid(X @ theta) >= 0.5) == y)) # Threshold at 0.5.

def train_plain(theta, X, y, steps=400, lr=0.4): # Train on one task with full-batch gradient descent.
    theta = theta.copy() # Avoid mutating the input vector.
    for _ in range(steps): # Repeat small deterministic updates.
        _, grad = loss_grad(theta, X, y) # Get current-task gradient.
        theta -= lr * grad # Descend the current-task objective.
    return theta # Return learned weights.

def fisher_diag(theta, X): # Estimate diagonal old-task parameter importance for this tiny linear model.
    F = theta ** 2 # In this toy, large learned old-task weights identify coordinates the old decision rule used.
    return F / (F.max() + 1e-12) # Scale so lambda values are readable.

def train_ewc(theta_start, X, y, theta_old, F_old, lam=20.0, steps=400, lr=0.25): # Train new task with EWC regularization.
    theta = theta_start.copy() # Start from the old solution.
    for _ in range(steps): # Repeat combined-objective updates.
        _, grad = loss_grad(theta, X, y) # New-task gradient.
        theta -= lr * (grad + lam * F_old * (theta - theta_old)) # Add the EWC spring gradient.
        theta = np.clip(theta, -12, 12) # Keep strong regularizers finite in this small educational demo.
    return theta # Return the compromise weights.

def train_replay(theta_start, XB, yB, Xmem, ymem, steps=400, lr=0.25, replay_weight=1.0): # Train B while replaying old examples.
    theta = theta_start.copy() # Start from task A weights.
    for _ in range(steps): # Repeat blended-gradient updates.
        _, gradB = loss_grad(theta, XB, yB) # New-task gradient.
        _, gradM = loss_grad(theta, Xmem, ymem) # Memory gradient for old task labels.
        theta -= lr * (gradB + replay_weight * gradM) / (1.0 + replay_weight) # Weighted average gradient.
    return theta # Return replay-trained weights.
```

### Advanced 2 — Combine EWC and replay

**Goal.** Use both a parameter spring and old examples, because practical continual learners often combine complementary defenses. We build it in 5 steps.

```python
X_a2, X2_a2, yA_a2, yB_a2 = make_tasks(seed=32, n=260) # Create a task sequence.

rng_a2 = np.random.default_rng(32) # Create a memory sampler.
mem_a2 = rng_a2.choice(len(X_a2), size=36, replace=False) # Select replay examples.

```
▶ What you'll see: the combined method starts from the same old-task solution.

```python
def train_ewc_replay_a2(theta_start_a2, XB_a2, yB_a2, Xmem_a2, ymem_a2, theta_old_a2, F_old_a2, lam_a2=12.0, steps_a2=500, lr_a2=0.22): # Define a local combined trainer.
    theta_a2 = theta_start_a2.copy() # Start from task A.
    for _ in range(steps_a2): # Repeat combined updates.
        _, gradB_a2 = loss_grad(theta_a2, XB_a2, yB_a2) # New-task gradient.
        _, gradM_a2 = loss_grad(theta_a2, Xmem_a2, ymem_a2) # Replay gradient.
        gradE_a2 = lam_a2 * F_old_a2 * (theta_a2 - theta_old_a2) # EWC spring gradient.
        theta_a2 -= lr_a2 * ((gradB_a2 + gradM_a2) / 2.0 + gradE_a2) # Blend data replay with parameter protection.
        theta_a2 = np.clip(theta_a2, -12, 12) # Keep the combined demo finite under strong protection.
    return theta_a2 # Return combined-method weights.
print("combined trainer ready") # Confirm the helper exists.
```
