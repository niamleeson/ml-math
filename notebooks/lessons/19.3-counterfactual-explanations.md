# 19.3 — Counterfactual Explanations

Counterfactual explanations ask a practical question: what is the smallest actionable change to an input that would have changed a model's decision? In this lesson we build that idea from scratch with NumPy, using a tiny loan-style classifier so the geometry, objective, constraints, sparsity, and counterfactual path are all visible instead of hidden behind an explanation library.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build counterfactual explanations one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math is shown in small steps so the final explanation is not a black box. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, vector math, and tiny optimization loops.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for toy data and search paths.
```

### 1. A decision boundary is the region a counterfactual must cross

A counterfactual only makes sense after we name the model decision we want to change. We use a tiny linear classifier with two features: normalized income and normalized savings. The model score is `w·x + b`; the decision is approved when the score is at least zero. The counterfactual task is therefore not vague: move the original point just far enough to cross the line `w·z + b = 0`.

```python
w_w = np.array([1.0, 0.8])  # income and savings both raise the approval score.
b_w = -0.9  # negative intercept makes low-income/low-savings applicants denied.
x_w = np.array([0.30, 0.40])  # the person we want to explain.
score_w = float(w_w @ x_w + b_w)  # linear model score before thresholding.
print("score:", round(score_w, 3), "decision:", "approve" if score_w >= 0 else "deny")
assert round(score_w, 3) == -0.280
```
▶ What you'll see: the applicant is denied because the score is −0.280, below the zero threshold.

```python
xs_w = np.linspace(0, 1, 100)  # income grid for drawing the boundary.
ys_w = (-b_w - w_w[0] * xs_w) / w_w[1]  # solve w0*x + w1*y + b = 0 for savings.
plt.figure(figsize=(4.5, 3.5))
plt.plot(xs_w, ys_w, color="black", label="decision boundary")
plt.scatter([x_w[0]], [x_w[1]], color="crimson", s=80, label="original x")
plt.fill_between(xs_w, ys_w, 1, color="seagreen", alpha=0.12, label="approved side")
plt.xlim(0, 1); plt.ylim(0, 1); plt.xlabel("income"); plt.ylabel("savings")
plt.title("1: counterfactuals cross the boundary"); plt.legend(); plt.show()
```
▶ What you'll see: the red point sits below the black boundary; a counterfactual must land on or above the green side.

*Why it's done this way:* the threshold converts a score into a decision, so the mathematical target is the boundary, not a vague explanation sentence. For a linear classifier, crossing means changing `z` until `w·z + b >= 0`; every later objective and constraint is just a disciplined way to choose which crossing point is most useful.

### 2. Proximity: the nearest counterfactual solves a minimal-perturbation objective

The core formula is `x_cf = argmin_z d(z, x) subject to f(z)=target`. With Euclidean distance and a linear boundary, the nearest point is the orthogonal projection of `x` onto the boundary. If the score is negative, the signed amount to add in the normal direction is `-score / ||w||²`, because adding `alpha*w` changes the score by `alpha*(w·w)`.

```python
norm2_w = float(w_w @ w_w)  # ||w||^2 controls how score changes along the normal direction.
alpha_w = -score_w / norm2_w  # exact step to make w·(x + alpha*w) + b equal zero.
cf_w = x_w + alpha_w * w_w  # nearest point on the boundary in L2 distance.
print("||w||^2:", round(norm2_w, 3), "alpha:", round(alpha_w, 3))
print("counterfactual:", np.round(cf_w, 3), "score:", round(float(w_w @ cf_w + b_w), 6))
assert np.allclose(np.round(cf_w, 3), np.array([0.471, 0.537]))
```
▶ What you'll see: adding `[0.171, 0.137]` lands exactly on the boundary with score 0.

```python
path_w = np.vstack([x_w, cf_w])  # a two-point path from original to nearest boundary point.
plt.figure(figsize=(4.5, 3.5))
plt.plot(xs_w, ys_w, color="black")
plt.plot(path_w[:, 0], path_w[:, 1], marker="o", color="steelblue", label="minimal L2 path")
plt.scatter([x_w[0]], [x_w[1]], color="crimson", s=70, label="x")
plt.scatter([cf_w[0]], [cf_w[1]], color="seagreen", s=70, label="x_cf")
plt.xlim(0, 1); plt.ylim(0, 1); plt.xlabel("income"); plt.ylabel("savings")
plt.title("2: shortest Euclidean move"); plt.legend(); plt.show()
```
▶ What you'll see: the blue segment hits the boundary at a right angle, which is the shortest L2 route.

*Why it's done this way:* the squared distance `||z-x||²` grows like a bowl around the original point, and the linear constraint is a line. The closest feasible point must move along the normal vector `w`, because any sideways motion along the boundary spends distance without increasing the score toward the target.

### 3. Feature scaling changes what “nearest” means

Distance is not neutral when features have different units. If one feature is measured in dollars and another in years, raw Euclidean distance can accidentally say that a one-dollar change matters like a one-year change. We therefore define proximity in standardized units: divide each coordinate change by a feature scale before measuring length.

```python
scale_w = np.array([0.20, 0.10])  # income is allowed to vary twice as much as savings in typical data.
raw_delta_w = cf_w - x_w  # unscaled counterfactual change from concept 2.
standard_delta_w = raw_delta_w / scale_w  # measure the same change in feature-scale units.
print("raw delta:", np.round(raw_delta_w, 3))
print("standardized delta:", np.round(standard_delta_w, 3))
```
▶ What you'll see: the savings move looks larger after scaling because savings has the smaller typical scale.

```python
Dinv2_w = np.diag(1 / (scale_w ** 2))  # metric for weighted squared distance.
weighted_denom_w = float(w_w @ np.diag(scale_w ** 2) @ w_w)  # score gain per weighted-distance step.
cf_scaled_w = x_w + (-score_w / weighted_denom_w) * (scale_w ** 2) * w_w  # closest point in scaled metric.
print("scaled-metric cf:", np.round(cf_scaled_w, 3))
print("score:", round(float(w_w @ cf_scaled_w + b_w), 6))
assert np.allclose(np.round(cf_scaled_w, 3), np.array([0.541, 0.448]))
```
▶ What you'll see: the scaled-metric counterfactual changes income more and savings less than the raw L2 answer.

```python
plt.figure(figsize=(4.5, 3.5))
plt.plot(xs_w, ys_w, color="black", label="boundary")
plt.plot([x_w[0], cf_w[0]], [x_w[1], cf_w[1]], marker="o", label="raw L2")
plt.plot([x_w[0], cf_scaled_w[0]], [x_w[1], cf_scaled_w[1]], marker="o", label="scaled distance")
plt.xlim(0, 1); plt.ylim(0, 1); plt.xlabel("income"); plt.ylabel("savings")
plt.title("3: scaling changes the nearest point"); plt.legend(); plt.show()
```
▶ What you'll see: both endpoints cross the same boundary, but the scaled metric chooses a different explanation.

*Why it's done this way:* proximity should represent user burden, not arbitrary measurement units. Weighting by feature scales means the objective is really `sum_j ((z_j-x_j)/scale_j)^2`, so a coordinate with small normal variation is expensive to move and the optimizer prefers a more realistic direction.

### 4. Actionability: impossible or immutable changes must be constrained

A tiny counterfactual can still be useless if it changes something the person cannot change. We add an immutable feature — age — and only allow income and savings to move upward. The unconstrained projection may alter age because age helps the model score; the actionable search forbids that and looks for the nearest feasible change on the allowed features.

```python
w3_w = np.array([1.0, 0.8, 0.5])  # age also affects the model, but age is not actionable.
b3_w = -1.25
x3_w = np.array([0.30, 0.40, 0.20])  # income, savings, normalized age.
score3_w = float(w3_w @ x3_w + b3_w)
cf_uncon3_w = x3_w + (-score3_w / float(w3_w @ w3_w)) * w3_w
print("unconstrained cf:", np.round(cf_uncon3_w, 3))
print("age changed by:", round(float(cf_uncon3_w[2] - x3_w[2]), 3))
assert round(score3_w, 3) == -0.530
```
▶ What you'll see: the mathematically nearest point changes age, which is not an actionable explanation.

```python
best_cf_w, best_dist_w = None, 10**9  # track the best feasible candidate found by grid search.
for inc_w in np.linspace(x3_w[0], 1.0, 141):  # income can only increase.
    for sav_w in np.linspace(x3_w[1], 1.0, 121):  # savings can only increase.
        z_w = np.array([inc_w, sav_w, x3_w[2]])  # keep age fixed.
        if w3_w @ z_w + b3_w >= 0:  # candidate reaches approval.
            dist_w = float(np.linalg.norm(z_w - x3_w))
            if dist_w < best_dist_w:
                best_dist_w, best_cf_w = dist_w, z_w.copy()
print("actionable cf:", np.round(best_cf_w, 3), "distance:", round(best_dist_w, 3))
assert best_cf_w[2] == x3_w[2]
```
▶ What you'll see: the actionable counterfactual holds age fixed and pays a larger distance cost.

```python
plt.figure(figsize=(4.5, 3.5))
bound3_w = (-b3_w - w3_w[2] * x3_w[2] - w3_w[0] * xs_w) / w3_w[1]
plt.plot(xs_w, bound3_w, color="black", label="boundary at fixed age")
plt.plot([x3_w[0], best_cf_w[0]], [x3_w[1], best_cf_w[1]], marker="o", color="seagreen", label="actionable path")
plt.scatter([x3_w[0]], [x3_w[1]], color="crimson", s=70, label="x")
plt.xlim(0, 1); plt.ylim(0, 1); plt.xlabel("income"); plt.ylabel("savings")
plt.title("4: immutable age stays fixed"); plt.legend(); plt.show()
```
▶ What you'll see: the path moves only through actionable coordinates, so it may be longer than the unconstrained shortcut.

*Why it's done this way:* counterfactual explanations are recommendations for change, so constraints are part of the math, not an afterthought. The feasible set encodes immutable features, monotone features, budgets, and policy rules; without it, the nearest point may be numerically elegant but humanly impossible.

### 5. Sparsity: prefer a small number of changed features when explanations are read by people

Two counterfactuals can have similar distance but very different readability. A dense explanation says “change a little bit of everything,” while a sparse explanation says “change these one or two things.” We can encourage sparsity by charging a fixed penalty for every feature that changes, then choosing the subset of features with the best total objective.

```python
x4_w = np.array([0.30, 0.40, 0.20, 0.60])  # income, savings, age, education.
w4_w = np.array([1.0, 0.8, 0.5, 0.4])
b4_w = -1.49
mutable_w = np.array([0, 1, 3])  # age index 2 is immutable.
score4_w = float(w4_w @ x4_w + b4_w)
print("initial score:", round(score4_w, 3), "mutable features:", mutable_w)
assert round(score4_w, 3) == -0.530
```
▶ What you'll see: the person is denied, and three features are allowed to move.

```python
best_sparse_w = []  # store candidate records for each subset.
for mask_int_w in range(1, 2 ** len(mutable_w)):  # enumerate non-empty mutable-feature subsets.
    subset_w = mutable_w[[bool(mask_int_w & (1 << k)) for k in range(len(mutable_w))]]
    z_w = x4_w.copy()
    subw_w = w4_w[subset_w]
    step_w = -score4_w / float(subw_w @ subw_w)  # minimum L2 move restricted to this subset.
    z_w[subset_w] = z_w[subset_w] + step_w * subw_w
    if np.all((z_w >= 0) & (z_w <= 1)) and w4_w @ z_w + b4_w >= -1e-9:
        dist_w = float(np.linalg.norm(z_w - x4_w))
        obj_w = dist_w + 0.08 * len(subset_w)  # proximity plus sparsity penalty.
        best_sparse_w.append((obj_w, dist_w, len(subset_w), subset_w, z_w))
best_sparse_w = sorted(best_sparse_w, key=lambda t: t[0])
print("best subset:", best_sparse_w[0][3], "distance:", round(best_sparse_w[0][1], 3), "objective:", round(best_sparse_w[0][0], 3))
```
▶ What you'll see: the chosen explanation balances distance against the number of changed features.

```python
labels_w = [str(tuple(r[3])) for r in best_sparse_w]
objs_w = [r[0] for r in best_sparse_w]
plt.figure(figsize=(5, 3))
plt.bar(labels_w, objs_w, color="mediumpurple")
plt.xticks(rotation=25); plt.ylabel("distance + sparsity penalty")
plt.title("5: sparse subset objective"); plt.show()
```
▶ What you'll see: not every feasible subset is equally interpretable; the lowest bar is the sparse objective winner.

*Why it's done this way:* proximity alone often spreads change across many coordinates because many small squared changes can be cheaper than one large change. A sparsity term, even a simple per-changed-feature penalty, expresses the human need for a compact instruction rather than a mathematically tiny but diffuse edit.

### 6. Search-based counterfactuals for nonlinear models and path inspection

Real models are often nonlinear, so we may not have a closed-form projection. We can still optimize a counterfactual from scratch by minimizing a loss with two terms: a target loss that pushes the model score above the threshold, and a proximity loss that keeps `z` near `x`. The path matters: it lets us inspect whether the optimizer takes a sensible route or exploits strange model geometry.

```python
def sigmoid_w(t_w):
    return 1 / (1 + np.exp(-t_w))

def score_nl_w(z_w):
    return 1.6 * z_w[0] + 1.1 * z_w[1] - 1.2 * z_w[0] * z_w[1] - 0.72

def prob_nl_w(z_w):
    return sigmoid_w(score_nl_w(z_w))

z_w = np.array([0.25, 0.35])  # denied starting point for nonlinear search.
print("initial probability:", round(float(prob_nl_w(z_w)), 3))
assert round(float(prob_nl_w(z_w)), 3) == 0.490
```
▶ What you'll see: the starting probability is near but below a stricter approval target of 0.65.

```python
target_prob_w = 0.65
lr_w = 0.08
lam_path_w = 0.05
path_nl_w = [z_w.copy()]
for step_nl_w in range(80):
    s_w = score_nl_w(z_w)
    p_w = sigmoid_w(s_w)
    margin_loss_grad_s_w = -2 * max(0.0, target_prob_w - p_w) * p_w * (1 - p_w)  # d(max(0,t-p)^2)/ds.
    grad_s_w = np.array([1.6 - 1.2 * z_w[1], 1.1 - 1.2 * z_w[0]])  # gradient of nonlinear score.
    grad_w = margin_loss_grad_s_w * grad_s_w + 2 * lam_path_w * (z_w - path_nl_w[0])  # target + proximity gradient.
    z_w = np.clip(z_w - lr_w * grad_w, 0, 1)
    path_nl_w.append(z_w.copy())
cf_nl_w = path_nl_w[-1]
print("final probability:", round(float(prob_nl_w(cf_nl_w)), 3), "cf:", np.round(cf_nl_w, 3))
assert prob_nl_w(cf_nl_w) > 0.57
```
▶ What you'll see: the optimized point reaches the target region while staying close to the original point.

```python
path_nl_w = np.array(path_nl_w)
gx_w, gy_w = np.meshgrid(np.linspace(0, 1, 80), np.linspace(0, 1, 80))
gp_w = sigmoid_w(1.6 * gx_w + 1.1 * gy_w - 1.2 * gx_w * gy_w - 0.72)
plt.figure(figsize=(4.8, 3.8))
plt.contourf(gx_w, gy_w, gp_w, levels=12, cmap="viridis", alpha=0.75)
plt.colorbar(label="approval probability")
plt.contour(gx_w, gy_w, gp_w, levels=[target_prob_w], colors="white", linewidths=2)
plt.plot(path_nl_w[:, 0], path_nl_w[:, 1], marker=".", color="red", label="optimization path")
plt.xlabel("income"); plt.ylabel("savings"); plt.title("6: nonlinear counterfactual path")
plt.legend(); plt.show()
```
▶ What you'll see: the red path climbs toward the white target contour, then slows because proximity resists unnecessary movement.

*Why it's done this way:* the optimization loss separates “make the decision flip” from “do not move too far.” The target term vanishes once the desired probability is reached, while the proximity term keeps pulling the solution back toward the original point; this tension is the practical counterfactual objective for models without a closed-form boundary.

### ✍️ Toy 2 · The nearest L2 counterfactual is a projection

For a linear boundary, the shortest Euclidean move points along the model-weight vector.

```python
import numpy as np

t2_rng = np.random.default_rng(0)  # -> seeded generator for reproducibility
t2_x = np.array([0.2, 0.4])  # -> original point
t2_w = np.array([1.0, 0.5])  # -> boundary normal
t2_b = -0.6  # -> intercept
t2_score = t2_w @ t2_x + t2_b  # -> -0.2
t2_norm2 = t2_w @ t2_w  # -> 1.25
t2_alpha = -t2_score / t2_norm2  # -> 0.16
t2_delta = t2_alpha * t2_w  # -> [0.16, 0.08]
t2_cf = t2_x + t2_delta  # -> [0.36, 0.48]
t2_cf_score = t2_w @ t2_cf + t2_b  # -> 0.0
print("norm squared:", round(float(t2_norm2), 3))  # -> 1.25
print("alpha:", round(float(t2_alpha), 3))  # -> 0.16
print("delta:", np.round(t2_delta, 3).tolist())  # -> [0.16, 0.08]
print("counterfactual score:", round(float(t2_cf_score), 6))  # -> 0.0
assert np.allclose(t2_cf, np.array([0.36, 0.48]))  # projection lands on the boundary

t2_grid = np.linspace(0.0, 1.0, 50)
t2_boundary = (-t2_b - t2_w[0] * t2_grid) / t2_w[1]
plt.figure(figsize=(4.4, 3.2))

```
▶ What you'll see: the segment moves straight to the boundary at `[0.36, 0.48]`.

### ✍️ Toy 4 · Actionability keeps immutable features fixed

A feasible counterfactual may need a grid search when some features cannot change and others can only move upward.

```python
import numpy as np

t4_rng = np.random.default_rng(0)  # -> seeded generator for reproducibility
t4_x = np.array([0.2, 0.3, 0.5])  # -> income, savings, immutable age
t4_w = np.array([1.0, 0.8, 0.6])  # -> model weights
t4_b = -1.1  # -> intercept
t4_score = t4_w @ t4_x + t4_b  # -> -0.36
t4_best_cf = None  # -> no feasible point yet
t4_best_dist = 999.0  # -> large initial distance
for t4_income in np.linspace(t4_x[0], 1.0, 9):
    for t4_savings in np.linspace(t4_x[1], 1.0, 8):
        t4_z = np.array([t4_income, t4_savings, t4_x[2]])
        t4_z_score = t4_w @ t4_z + t4_b
        if t4_z_score >= 0.0:
            t4_dist = np.linalg.norm(t4_z - t4_x)
            if t4_dist < t4_best_dist:
                t4_best_dist = t4_dist
                t4_best_cf = t4_z.copy()
t4_best_score = t4_w @ t4_best_cf + t4_b  # -> 0.0
print("initial score:", round(float(t4_score), 3))  # -> -0.36
print("actionable cf:", np.round(t4_best_cf, 3).tolist())  # -> [0.4, 0.5, 0.5]
print("distance:", round(float(t4_best_dist), 3))  # -> 0.283
print("age change:", round(float(t4_best_cf[2] - t4_x[2]), 3))  # -> 0.0
```

### ✍️ Toy 5 · Sparsity charges for each changed feature

A sparsity penalty can make a slightly longer but simpler counterfactual preferable to a dense one.

```python
import numpy as np

t5_rng = np.random.default_rng(0)  # -> seeded generator for reproducibility
t5_x = np.array([0.2, 0.3, 0.4])  # -> three mutable features

t5_records = []  # -> candidate records
for t5_mask in range(1, 2 ** 3):

    t5_z = t5_x.copy()

    t5_step = -t5_score / (t5_subw @ t5_subw)

    if np.all((t5_z >= 0.0) & (t5_z <= 1.0)):
        t5_dist = np.linalg.norm(t5_z - t5_x)
        t5_objective = t5_dist + 0.06 * len(t5_subset)
        t5_records.append((t5_objective, t5_dist, len(t5_subset), t5_subset, t5_z))
t5_records = sorted(t5_records, key=lambda t5_row: t5_row[0])  # -> best objective first
t5_best = t5_records[0]  # -> subset [0, 1]
```

### ✍️ Toy 6 · Nonlinear counterfactual search follows a path

Without a closed-form projection, a small gradient loop can push a point across a nonlinear decision boundary while penalizing unnecessary movement.

```python
import numpy as np

t6_rng = np.random.default_rng(0)  # -> seeded generator for reproducibility
t6_z = np.array([0.2, 0.2])  # -> starting point
t6_start = t6_z.copy()  # -> fixed proximity anchor
t6_target_prob = 0.58  # -> desired probability pressure
t6_lr = 0.12  # -> gradient step size
t6_lam = 0.02  # -> proximity weight
t6_path = [t6_z.copy()]  # -> optimization path
for t6_step_i in range(90):
    t6_score = 1.2 * t6_z[0] + 1.0 * t6_z[1] - 0.8 * t6_z[0] * t6_z[1] - 0.6
    t6_prob = 1.0 / (1.0 + np.exp(-t6_score))
    t6_margin_grad = -2.0 * max(0.0, t6_target_prob - t6_prob) * t6_prob * (1.0 - t6_prob)
    t6_score_grad = np.array([1.2 - 0.8 * t6_z[1], 1.0 - 0.8 * t6_z[0]])
    t6_grad = t6_margin_grad * t6_score_grad + 2.0 * t6_lam * (t6_z - t6_start)
    t6_z = np.clip(t6_z - t6_lr * t6_grad, 0.0, 1.0)
    t6_path.append(t6_z.copy())
t6_path = np.array(t6_path)  # -> 91 points
t6_initial_score = 1.2 * t6_start[0] + 1.0 * t6_start[1] - 0.8 * t6_start[0] * t6_start[1] - 0.6  # -> -0.192
t6_initial_prob = 1.0 / (1.0 + np.exp(-t6_initial_score))  # -> 0.452147
t6_final_score = 1.2 * t6_z[0] + 1.0 * t6_z[1] - 0.8 * t6_z[0] * t6_z[1] - 0.6  # -> 0.182654
t6_final_prob = 1.0 / (1.0 + np.exp(-t6_final_score))  # -> 0.545537
print("initial probability:", round(float(t6_initial_prob), 3))  # -> 0.452
print("final point:", np.round(t6_z, 3).tolist())  # -> [0.445, 0.386]
print("final probability:", round(float(t6_final_prob), 3))  # -> 0.546
print("path length:", len(t6_path))  # -> 91
assert float(t6_final_prob) > 0.5 and float(t6_final_prob) > float(t6_initial_prob)  # the search flips the side

t6_gx, t6_gy = np.meshgrid(np.linspace(0, 1, 60), np.linspace(0, 1, 60))
t6_gp = 1.0 / (1.0 + np.exp(-(1.2 * t6_gx + 1.0 * t6_gy - 0.8 * t6_gx * t6_gy - 0.6)))
plt.figure(figsize=(4.6, 3.4))
plt.contourf(t6_gx, t6_gy, t6_gp, levels=12, cmap="viridis", alpha=0.75)
plt.contour(t6_gx, t6_gy, t6_gp, levels=[0.5], colors="white")
plt.plot(t6_path[:, 0], t6_path[:, 1], color="red", marker=".", markersize=3)
plt.xlabel("feature 0"); plt.ylabel("feature 1"); plt.title("Toy 6 · nonlinear CF path"); plt.show()
```
▶ What you'll see: the red path crosses the white `0.5` probability contour and then slows.


## 🛠️ Setup

```python
import numpy as np  # load NumPy for arrays, norms, masks, toy classifiers, and optimization loops.
import matplotlib.pyplot as plt  # load Matplotlib for boundary plots, paths, heatmaps, and bar charts.
np.random.seed(0)  # make every random example reproducible.

def lin_score(x, w=np.array([1.0, 0.8]), b=-0.9):  # compute a default linear model score.
    return float(np.asarray(x, dtype=float) @ w + b)  # return w dot x plus intercept as one scalar.

def decision(x, w=np.array([1.0, 0.8]), b=-0.9):  # threshold a linear score into a label.
    return int(lin_score(x, w, b) >= 0)  # return 1 for approval and 0 for denial.

def nearest_l2_cf(x, w=np.array([1.0, 0.8]), b=-0.9):  # nearest boundary point for a denied linear example.
    x = np.asarray(x, dtype=float)  # convert input to a float vector.
    s = float(x @ w + b)  # compute the current signed score.
    return x if s >= 0 else x + (-s / float(w @ w)) * w  # project to the boundary only when denied.

def show_boundary(w, b, title):  # draw a 2-D linear decision boundary.
    xs = np.linspace(0, 1, 100)  # create x-coordinates for the boundary line.
    ys = (-b - w[0] * xs) / w[1]  # solve the boundary equation for y.
    plt.figure(figsize=(4, 3))  # create a compact figure.
    plt.plot(xs, ys, color="black")  # draw the decision boundary.
    plt.xlim(0, 1); plt.ylim(0, 1)  # keep the toy feature space visible.
    plt.xlabel("feature 0")  # label the first feature.
    plt.ylabel("feature 1")  # label the second feature.
    plt.title(title)  # add the requested title.
```

### Easy 1 — Generate a counterfactual by grid search

**Goal.** Search a small feature grid for the nearest valid counterfactual, because brute force is the most transparent optimizer. We build it in 3 steps.


```python

for inc_e1 in np.linspace(0, 1, 101):  # search income values.
    for sav_e1 in np.linspace(0, 1, 101):  # search savings values.
        z_e1 = np.array([inc_e1, sav_e1])  # build a candidate point.

                best_dist_e1, best_e1 = d_e1, z_e1.copy()  # save candidate and distance.
```

### Advanced 1 — Optimize a nonlinear counterfactual with gradients

**Goal.** Use gradient descent to find a counterfactual for a nonlinear score, because many models do not have closed-form projections. We build it in 4 steps.

```python

    return 1 / (1 + np.exp(-t_a1))  # map real scores into (0, 1).

def score_a1(z_a1):  # define a nonlinear two-feature model.
    return 1.6 * z_a1[0] + 1.1 * z_a1[1] - 1.2 * z_a1[0] * z_a1[1] - 0.72  # include an interaction term.

x_a1 = np.array([0.25, 0.35])  # choose a starting point.
print("initial probability:", round(float(sigmoid_a1(score_a1(x_a1))), 3))  # inspect model output.
```

```python

target_a1 = 0.55  # define the desired approval probability.
path_a1 = [z_a1.copy()]  # store the optimization path.
print("target probability:", target_a1)  # inspect the target.
```

```python
for step_a1 in range(400):  # run small gradient steps.
    p_a1 = sigmoid_a1(score_a1(z_a1))  # compute current probability.
    grad_score_a1 = np.array([1.6 - 1.2 * z_a1[1], 1.1 - 1.2 * z_a1[0]])  # gradient of nonlinear score.
    grad_target_a1 = -2 * max(0.0, target_a1 - p_a1) * p_a1 * (1 - p_a1) * grad_score_a1  # target-loss gradient.
    grad_prox_a1 = 0.01 * (z_a1 - x_a1)  # proximity gradient from 0.8*||z-x||^2.

    path_a1.append(z_a1.copy())  # save the path.

```
