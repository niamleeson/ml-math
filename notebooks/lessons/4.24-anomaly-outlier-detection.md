# 4.24 — Anomaly & Outlier Detection

Anomaly and outlier detection turns unlabeled data into a ranked list of “surprising” points. In this lesson, we build the core lenses from scratch: distance from a reference center, isolation by repeated splits, margin-style one-class scoring, and local density comparison. The theme is not that one score is universally correct; it is that each algorithm defines what “normal” means, then marks points that violate that definition.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build anomaly detection one idea at a time. Run each cell in order and inspect every printed value: the same point can look normal under a global center, isolated under random cuts, outside a learned boundary, or sparse relative to its neighbors. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, distances, random draws, and small linear algebra.
import matplotlib.pyplot as plt  # compact plots for every anomaly score.
np.random.seed(0)  # reproducibility for toy data, random projections, and isolation splits.
```

### 1. Outliers as large distance from a learned reference

The simplest anomaly score learns one reference point for the normal cloud — usually the mean or median — and measures Euclidean distance from it. If most observations cluster near a center $c$, then $s(x)=\lVert x-c\rVert_2$ is small for typical points and large for points that do not behave like the cluster. This is the arithmetic in the lesson block: the score is a decision, not decoration.

```python
X_w = np.array([[0.0, 0.0], [0.2, 0.0], [0.0, 0.1], [4.0, 4.0]])  # three normal points plus one far point.
center_w = X_w[:3].mean(axis=0)  # estimate the normal reference from the known-looking cloud.
print("normal center:", np.round(center_w, 3))  # [0.067, 0.033].
assert np.allclose(np.round(center_w, 3), [0.067, 0.033])  # verify the lesson arithmetic.
```
▶ What you'll see: the normal center is near the origin because the first three points are tiny perturbations around (0,0).

```python
scores_w = np.linalg.norm(X_w - center_w, axis=1)  # Euclidean distance from each point to the center.
print("distance scores:", np.round(scores_w, 3))  # the outlier should dominate.
print("outlier score:", round(float(scores_w[-1]), 3))  # 5.586.
assert round(float(scores_w[-1]), 3) == 5.586  # verify the lesson number.
```
▶ What you'll see: the first three scores stay below 0.14, while [4,4] scores 5.586.

```python
plt.figure(figsize=(4.4, 3.4))
plt.scatter(X_w[:-1, 0], X_w[:-1, 1], s=80, label="normal-looking", color="teal")
plt.scatter(X_w[-1:, 0], X_w[-1:, 1], s=100, label="candidate outlier", color="crimson")
plt.scatter(center_w[0], center_w[1], s=120, marker="x", color="black", label="center c")
for idx_w, row_w in enumerate(X_w):
    plt.plot([center_w[0], row_w[0]], [center_w[1], row_w[1]], color="gray", linewidth=0.8)
plt.title("1: distance from a normal reference")
plt.xlabel("feature 0"); plt.ylabel("feature 1"); plt.legend(); plt.show()
```
▶ What you'll see: three short gray segments and one very long segment — the score is literally that segment length.

*Why it's done this way: Euclidean distance is the Pythagorean length of the residual vector $x-c$. Subtracting the center removes the baseline location, squaring coordinates makes positive and negative deviations both count, and the square root returns the distance to the original feature scale.*

### 2. Thresholding scores is a modeling choice

An anomaly detector produces scores before it produces labels. To turn scores into labels, we choose a threshold: perhaps the top $10\%$, perhaps anything above a domain limit, or perhaps anything above a percentile of training scores. This is where unsupervised detection becomes a decision policy.

```python
normal_scores_w = scores_w[:3]  # pretend the first three scores summarize normal behavior.
threshold_w = float(normal_scores_w.max() + 0.5)  # choose a deliberately conservative cutoff above normal scores.
labels_w = scores_w > threshold_w  # True means flagged as unusual.
print("threshold:", round(threshold_w, 3))
print("flagged labels:", labels_w.astype(int))
assert labels_w.tolist() == [False, False, False, True]
```
▶ What you'll see: only the far point crosses the threshold.

```python
plt.figure(figsize=(4.6, 3))
plt.bar(range(len(scores_w)), scores_w, color=np.where(labels_w, "crimson", "teal"))
plt.axhline(threshold_w, color="black", linestyle="--", label="threshold")
plt.title("2: scores become labels only after a cutoff")
plt.xlabel("point index"); plt.ylabel("distance score"); plt.legend(); plt.show()
```
▶ What you'll see: the cutoff line separates one tall red bar from three short teal bars.

*Why it's done this way: score ranking and label assignment answer different questions. The score estimates surprise under the chosen lens; the threshold encodes tolerance for false alarms, investigation budget, or expected contamination.*

### 3. Scaling controls which feature dominates distance

Distance-based anomaly detection only sees numeric scale. A feature measured in thousands can dominate a feature measured in units even if it is less meaningful. Standardizing features to zero mean and unit standard deviation makes each coordinate contribute in comparable units.

```python
X_scale_w = np.array([[0.0, 1000.0], [0.2, 1010.0], [0.0, 990.0], [0.3, 3000.0]])  # feature 1 has huge units.
center_scale_w = X_scale_w[:3].mean(axis=0)
raw_scores_w = np.linalg.norm(X_scale_w - center_scale_w, axis=1)
print("raw scores:", np.round(raw_scores_w, 3))
```
▶ What you'll see: the large-unit feature makes the last point look overwhelmingly anomalous.

```python
mu_scale_w = X_scale_w[:3].mean(axis=0)  # normal mean for each feature.
sigma_scale_w = X_scale_w[:3].std(axis=0)  # normal standard deviation for each feature.
sigma_scale_w = np.where(sigma_scale_w == 0, 1.0, sigma_scale_w)  # guard constant features.
Z_scale_w = (X_scale_w - mu_scale_w) / sigma_scale_w  # z-score standardization.
z_scores_w = np.linalg.norm(Z_scale_w, axis=1)
print("z-scored points:\n", np.round(Z_scale_w, 3))
print("standardized scores:", np.round(z_scores_w, 3))
```
▶ What you'll see: after scaling, both features are measured in “number of normal standard deviations.”

```python
plt.figure(figsize=(5, 3))
plt.bar(np.arange(4) - 0.18, raw_scores_w / raw_scores_w.max(), width=0.36, label="raw scaled")
plt.bar(np.arange(4) + 0.18, z_scores_w / z_scores_w.max(), width=0.36, label="standardized")
plt.title("3: scaling changes distance scores")
plt.xlabel("point index"); plt.ylabel("score divided by max"); plt.legend(); plt.show()
```
▶ What you'll see: the relative bar heights change because the metric has changed.

*Why it's done this way: Euclidean distance is a sum of squared coordinate differences. Standardization changes each difference from “raw unit gap” to “gap measured in typical variability,” preventing a large-unit feature from silently becoming the whole detector.*

### 4. Isolation by repeated random splits

Isolation Forest uses a different notion of surprise: anomalous points are easier to isolate with random axis-aligned cuts because they sit in sparse regions. We can mimic one isolation tree by repeatedly choosing a feature and a split between the current minimum and maximum until a point is alone. Shorter path length means more isolated, hence more anomalous.

```python
X_iso_w = np.vstack([np.random.normal(0, 0.35, size=(12, 2)), np.array([[3.0, 3.0]])])  # compact cloud plus far point.
targets_iso_w = [0, 12]  # compare a typical point and the far point.
print("typical point:", np.round(X_iso_w[0], 3), "far point:", X_iso_w[12])
```
▶ What you'll see: one point lives in the cloud and one sits far away at (3,3).

```python
def isolation_depth_w(X, target, seed, max_depth=20):
    rng = np.random.default_rng(seed)
    active = np.arange(X.shape[0])
    depth = 0
    while len(active) > 1 and depth < max_depth:
        feature = rng.integers(0, X.shape[1])
        lo, hi = X[active, feature].min(), X[active, feature].max()
        if lo == hi:
            break
        split = rng.uniform(lo, hi)
        if X[target, feature] <= split:
            active = active[X[active, feature] <= split]
        else:
            active = active[X[active, feature] > split]
        depth += 1
    return depth

depths_iso_w = np.array([[isolation_depth_w(X_iso_w, t, seed_w) for seed_w in range(60)] for t in targets_iso_w])
print("mean depths [typical, far]:", np.round(depths_iso_w.mean(axis=1), 2))
assert depths_iso_w.mean(axis=1)[1] < depths_iso_w.mean(axis=1)[0]
```
▶ What you'll see: the far point has a smaller average path length because random cuts separate it sooner.

```python
plt.figure(figsize=(4.6, 3))
plt.hist(depths_iso_w[0], bins=np.arange(1, 12) - 0.5, alpha=0.65, label="typical")
plt.hist(depths_iso_w[1], bins=np.arange(1, 12) - 0.5, alpha=0.65, label="far")
plt.title("4: isolation depth over random trees")
plt.xlabel("path length until isolated"); plt.ylabel("count"); plt.legend(); plt.show()
```
▶ What you'll see: the far point's histogram is shifted left toward shorter paths.

*Why it's done this way: a random split is unlikely to carve a dense cluster down to one point quickly, but a point alone in open space can be separated by many possible cuts. Isolation therefore scores “how easy it is to separate,” not “how far from the mean.”*

### 5. One-class margin scoring with a center and radius

One-Class SVM learns a boundary around normal data. We build the radial idea without a library: choose a center, choose a radius that contains most training points, then score new points by signed distance to the boundary. Negative signed distance is inside the normal region; positive signed distance is outside.

```python
X_oc_w = np.random.normal(0, 0.45, size=(80, 2))  # normal training cloud.
center_oc_w = X_oc_w.mean(axis=0)  # simple center for a radial one-class boundary.
radii_oc_w = np.linalg.norm(X_oc_w - center_oc_w, axis=1)  # distance of each training point from center.
radius_oc_w = float(np.percentile(radii_oc_w, 90))  # keep about 90% inside.
print("center:", np.round(center_oc_w, 3), "radius:", round(radius_oc_w, 3))
assert radius_oc_w > 0
```
▶ What you'll see: the boundary is a circle centered near the normal cloud.

```python
query_oc_w = np.array([[0.1, 0.1], [1.8, 1.8], [-0.8, 0.2]])  # two likely normal-ish, one far.
signed_oc_w = np.linalg.norm(query_oc_w - center_oc_w, axis=1) - radius_oc_w  # outside distance minus radius.
print("signed boundary scores:", np.round(signed_oc_w, 3))
print("outside flags:", (signed_oc_w > 0).astype(int))
assert signed_oc_w[1] > 0
```
▶ What you'll see: the far query has positive signed distance and is flagged outside the learned region.

```python
theta_oc_w = np.linspace(0, 2 * np.pi, 200)
circle_oc_w = center_oc_w + radius_oc_w * np.c_[np.cos(theta_oc_w), np.sin(theta_oc_w)]
plt.figure(figsize=(4.4, 3.8))
plt.scatter(X_oc_w[:, 0], X_oc_w[:, 1], s=20, color="lightgray", label="training normals")
plt.plot(circle_oc_w[:, 0], circle_oc_w[:, 1], color="black", label="90% boundary")
plt.scatter(query_oc_w[:, 0], query_oc_w[:, 1], c=np.where(signed_oc_w > 0, "crimson", "teal"), s=80, label="queries")
plt.title("5: one-class radial boundary")
plt.xlabel("feature 0"); plt.ylabel("feature 1"); plt.legend(); plt.axis("equal"); plt.show()
```
▶ What you'll see: points inside the circle are normal under this lens; the red point outside is anomalous.

*Why it's done this way: a one-class boundary defines normality as a region containing most training data. The radius percentile is a contamination assumption: it decides how much training data we are willing to place outside the boundary to leave room for future anomalies.*

### 6. Local Outlier Factor compares neighborhood density

Local Outlier Factor (LOF) flags a point whose neighborhood is much sparser than its neighbors' neighborhoods. The useful idea is local comparison: a point near a sparse cluster should not be punished just because a dense cluster exists elsewhere. We build a simplified LOF with k-nearest-neighbor distances and local reachability density.

```python
cluster_dense_w = np.random.normal([0, 0], [0.15, 0.15], size=(10, 2))
cluster_sparse_w = np.random.normal([3, 3], [0.45, 0.45], size=(10, 2))
probe_w = np.array([[0.05, 0.05], [3.2, 3.1], [1.5, 1.5]])  # dense normal, sparse normal, between-cluster outlier.
X_lof_w = np.vstack([cluster_dense_w, cluster_sparse_w, probe_w])
print("data shape:", X_lof_w.shape)
```
▶ What you'll see: the data contains one dense group, one sparse group, and a point between them.

```python
def pairwise_dist_w(X):
    diff = X[:, None, :] - X[None, :, :]
    return np.sqrt(np.sum(diff ** 2, axis=2))

def simple_lof_w(X, k=4):
    D = pairwise_dist_w(X)
    order = np.argsort(D, axis=1)[:, 1:k+1]
    kdist = D[np.arange(X.shape[0]), order[:, -1]]
    reach = np.maximum(D[np.arange(X.shape[0])[:, None], order], kdist[order])
    lrd = 1.0 / (reach.mean(axis=1) + 1e-12)
    lof = np.array([np.mean(lrd[order[i]]) / lrd[i] for i in range(X.shape[0])])
    return lof, order, lrd

lof_w, neigh_w, lrd_w = simple_lof_w(X_lof_w, k=4)
print("probe LOF scores:", np.round(lof_w[-3:], 3))
assert lof_w[-1] > lof_w[-2]
```
▶ What you'll see: the between-cluster point has a larger LOF because its local density is lower than its neighbors'.

```python
plt.figure(figsize=(4.5, 3.8))
plt.scatter(X_lof_w[:, 0], X_lof_w[:, 1], c=lof_w, cmap="magma", s=70)
plt.colorbar(label="LOF score")
plt.title("6: LOF compares local density")
plt.xlabel("feature 0"); plt.ylabel("feature 1"); plt.axis("equal"); plt.show()
```
▶ What you'll see: the between-cluster probe is brightest; points inside either cluster are less surprising relative to nearby density.

*Why it's done this way: global distance would call the sparse cluster unusual merely because it is spread out. LOF divides neighbors' density by the point's own density, so the score asks whether the point is sparse compared with its local reference group.*

## 🛠️ Setup

```python
import numpy as np  # load NumPy for arrays, distances, percentiles, and small simulations.
import matplotlib.pyplot as plt  # load Matplotlib for scatter plots, histograms, bars, and boundaries.
np.random.seed(0)  # make all stochastic examples reproducible.

def pairwise_distances(X):  # compute all Euclidean distances inside a matrix of points.
    X = np.asarray(X, dtype=float)  # ensure arithmetic uses floating point.
    diff = X[:, None, :] - X[None, :, :]  # broadcast every point against every other point.
    return np.sqrt(np.sum(diff ** 2, axis=2))  # return the Euclidean distance matrix.

def zscore_with_reference(X, ref):  # standardize data using a reference sample.
    mu = ref.mean(axis=0)  # compute reference feature means.
    sigma = ref.std(axis=0)  # compute reference feature standard deviations.
    sigma = np.where(sigma == 0, 1.0, sigma)  # avoid division by zero for constant features.
    return (X - mu) / sigma, mu, sigma  # return standardized data and reusable parameters.

def distance_scores(X, center):  # score points by Euclidean distance from a center.
    return np.linalg.norm(np.asarray(X, dtype=float) - center, axis=1)  # one score per row.

def knn_indices(X, k):  # return indices of k nearest neighbors for every point.
    D = pairwise_distances(X)  # compute pairwise distances once.
    return np.argsort(D, axis=1)[:, 1:k+1]  # skip self at column 0.

def simple_lof(X, k=4):  # compute a compact Local Outlier Factor score.
    D = pairwise_distances(X)  # all pairwise Euclidean distances.
    neigh = np.argsort(D, axis=1)[:, 1:k+1]  # k nearest neighbors for each point.
    kdist = D[np.arange(X.shape[0]), neigh[:, -1]]  # each point's kth-neighbor distance.
    reach = np.maximum(D[np.arange(X.shape[0])[:, None], neigh], kdist[neigh])  # reachability distances to neighbors.
    lrd = 1.0 / (reach.mean(axis=1) + 1e-12)  # local reachability density.
    lof = np.array([np.mean(lrd[neigh[i]]) / lrd[i] for i in range(X.shape[0])])  # neighbor density divided by own density.
    return lof, neigh, lrd  # return scores and debug pieces.

def isolation_depth(X, target, seed, max_depth=25):  # one simple isolation-tree path length.
    rng = np.random.default_rng(seed)  # local random generator for reproducible splits.
    active = np.arange(X.shape[0])  # start with all points in the current node.
    depth = 0  # count how many cuts are needed to isolate target.
    while len(active) > 1 and depth < max_depth:  # stop when target is alone or tree is capped.
        feature = rng.integers(0, X.shape[1])  # randomly select a feature.
        lo, hi = X[active, feature].min(), X[active, feature].max()  # possible split range.
        if lo == hi:  # no useful split on this active set.
            break  # stop if every active point has the same value.
        split = rng.uniform(lo, hi)  # choose a random split point.
        if X[target, feature] <= split:  # keep the side containing the target.
            active = active[X[active, feature] <= split]
        else:
            active = active[X[active, feature] > split]
        depth += 1  # record one more cut.
    return depth  # shorter depth means easier isolation.
```

### Advanced 1 — Use a covariance-aware distance

**Goal.** Compare Euclidean and Mahalanobis distance, because correlated features make diagonal distance overstate unusualness along common directions. We build it in 4 steps.

### Advanced 5 — Check threshold stability under resampling

**Goal.** Bootstrap a distance threshold, because fragile anomaly decisions can flip when the reference sample changes slightly. We build it in 5 steps.

```python

normal_a5 = rng_a5.normal(0, 0.5, size=(80, 2))  # trusted normal pool.
```


