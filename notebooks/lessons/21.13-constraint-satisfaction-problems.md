# 21.13 — Constraint Satisfaction Problems

Constraint satisfaction problems (CSPs) make search explicit: choose one value for each variable from its domain while constraints prune impossible partial worlds before we waste time completing them. In this lesson, we build a small CSP toolkit from scratch, then use map coloring, Sudoku, and N-queens to see how backtracking, propagation, heuristics, and local repair turn brute force into disciplined narrowing.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build constraint satisfaction one idea at a time. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays for boards, counts, and reproducible random choices.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
from collections import deque  # queue for AC-3 arcs.
np.random.seed(0)  # reproducibility for any random tie breaks.
```

### 1. Variables, domains, and constraints

A CSP is a triple $(X,D,C)$. The variables $X$ are the slots to fill, each domain $D_i$ is the finite set of values still possible for variable $i$, and each constraint in $C$ says which joint assignments are legal. A tiny triangle map is the cleanest first example: variables are regions `A`, `B`, `C`; domains are colors; and every edge says neighboring regions must have different colors.

```python
vars_w = ["A", "B", "C"]  # the three regions in a triangle map.
colors_w = ["R", "G", "B"]  # every region starts with the same three-color domain.
domains_w = {v: colors_w[:] for v in vars_w}  # copy the domain list for each variable.
edges_w = [("A", "B"), ("A", "C"), ("B", "C")]  # every pair of regions touches.
print("variables:", vars_w)
print("domain(A):", domains_w["A"])
print("constraints:", edges_w)
```
▶ What you'll see: three variables, each with three candidate colors, plus three inequality constraints.

```python
def consistent_w(assign, edges):  # check every fully-known edge in a partial assignment.
    for left, right in edges:
        if left in assign and right in assign and assign[left] == assign[right]:
            return False
    return True

partial_w = {"A": "R", "B": "R"}  # a deliberately bad partial coloring.
print("partial assignment:", partial_w)
print("still legal?", consistent_w(partial_w, edges_w))
```
▶ What you'll see: `A=R, B=R` is rejected immediately because A and B are neighbors.

```python
pos_w = {"A": (0, 1), "B": (-0.9, -0.5), "C": (0.9, -0.5)}  # fixed triangle layout.
plt.figure(figsize=(4, 3))
for u_w, v_w in edges_w:
    plt.plot([pos_w[u_w][0], pos_w[v_w][0]], [pos_w[u_w][1], pos_w[v_w][1]], color="gray")
for v_w in vars_w:
    plt.scatter(*pos_w[v_w], s=600, color="white", edgecolor="black")
    plt.text(pos_w[v_w][0], pos_w[v_w][1], v_w, ha="center", va="center", fontsize=14)
plt.axis("off"); plt.title("1: constraint graph for triangle coloring"); plt.show()
```
▶ What you'll see: a triangle constraint graph; each edge is an inequality rule that can prune colors.

*Why it's done this way:* Separating variables, domains, and constraints lets the solver reason locally. The drawing is not decoration: graph edges identify exactly which assignments can invalidate each other, so later pruning does not need to inspect unrelated variables.

### 2. Backtracking search with early rejection

Brute force waits until every variable has a value, then checks the assignment. Backtracking does the same depth-first enumeration but checks constraints after each choice. If a partial assignment already violates a rule, the whole subtree below it is impossible and can be skipped.

```python
count_w = {"nodes": 0}  # count partial assignments visited by backtracking.

def backtrack_w(assign):
    count_w["nodes"] += 1
    if len(assign) == len(vars_w):
        return assign.copy()
    var = next(v for v in vars_w if v not in assign)  # simple left-to-right variable order.
    for value in domains_w[var]:
        trial = assign.copy(); trial[var] = value
        if consistent_w(trial, edges_w):
            result = backtrack_w(trial)
            if result is not None:
                return result
    return None

solution_w = backtrack_w({})
print("solution:", solution_w)
print("nodes visited:", count_w["nodes"])
```
▶ What you'll see: one valid coloring is found after visiting far fewer partial assignments than the full tree.

```python
all_assignments_w = len(colors_w) ** len(vars_w)  # brute-force complete assignments only.
valid_count_w = 0
for a_w in colors_w:
    for b_w in colors_w:
        for c_w in colors_w:
            valid_count_w += consistent_w({"A": a_w, "B": b_w, "C": c_w}, edges_w)
print("complete assignments:", all_assignments_w)
print("valid complete assignments:", valid_count_w)
assert valid_count_w == 6  # 3 choices for A, then 2 for B, then 1 for C.
```
▶ What you'll see: only 6 of the 27 complete triangle colorings satisfy all constraints.

```python
plt.figure(figsize=(4, 3))
plt.bar(["valid", "all complete", "backtrack nodes"], [valid_count_w, all_assignments_w, count_w["nodes"]],
        color=["seagreen", "gray", "steelblue"])
plt.ylabel("count"); plt.title("2: search space vs early rejection"); plt.show()
```
▶ What you'll see: valid solutions are a small slice of the complete space, and backtracking avoids many doomed branches.

*Why it's done this way:* Backtracking is still systematic search, not magic. The key logic is that constraints are monotone for partial assignments: once `A` and `B` already clash, adding `C` can never repair that clash, so pruning the subtree is sound.

### 3. Forward checking: prune neighbor domains after a choice

Backtracking asks, "is my current partial assignment legal?" Forward checking asks a stronger question: "after this assignment, do unassigned neighbors still have at least one legal value?" For inequality constraints, assigning `A=R` removes `R` from every unassigned neighbor of `A`.

```python
def neighbors_w(edges):
    nbrs = {v: [] for v in vars_w}
    for u, v in edges:
        nbrs[u].append(v); nbrs[v].append(u)
    return nbrs

nbrs_w = neighbors_w(edges_w)
print("neighbors:", nbrs_w)
```
▶ What you'll see: each triangle variable has the other two variables as neighbors.

```python
def forward_check_w(domains, var, value, assign):
    new_domains = {x: list(vals) for x, vals in domains.items()}
    new_domains[var] = [value]
    for nb in nbrs_w[var]:
        if nb not in assign and value in new_domains[nb]:
            new_domains[nb].remove(value)
            if len(new_domains[nb]) == 0:
                return None
    return new_domains

pruned_w = forward_check_w(domains_w, "A", "R", {"A": "R"})
print("after A=R:", pruned_w)
```
▶ What you'll see: `B` and `C` shrink from three colors to two colors before either is assigned.

```python
before_sizes_w = [len(domains_w[v]) for v in vars_w]
after_sizes_w = [len(pruned_w[v]) for v in vars_w]
plt.figure(figsize=(4, 3))
plt.bar(np.arange(3) - 0.18, before_sizes_w, width=0.36, label="before", color="gray")
plt.bar(np.arange(3) + 0.18, after_sizes_w, width=0.36, label="after A=R", color="seagreen")
plt.xticks(range(3), vars_w); plt.ylabel("domain size"); plt.title("3: forward checking shrinks domains")
plt.legend(); plt.show()
```
▶ What you'll see: A is fixed to one value, and its two neighbors lose the incompatible color.

*Why it's done this way:* Forward checking turns one assignment into immediate information about adjacent variables. It is cheap because it only touches neighbors, and it prevents the solver from walking into branches where an unassigned variable already has no legal value left.

### 4. Arc consistency with AC-3

Forward checking only propagates from the newest assignment. Arc consistency keeps propagating until every directed edge `(Xi, Xj)` has support: for each value in `Xi`'s domain, there must be at least one compatible value in `Xj`'s domain. AC-3 is the queue algorithm that repeatedly revises arcs and re-enqueues affected neighbors when a domain shrinks.

```python
def revise_w(domains, xi, xj):
    removed = []
    kept = []
    for x in domains[xi]:
        has_support = any(x != y for y in domains[xj])  # inequality constraint support.
        (kept if has_support else removed).append(x)
    domains[xi] = kept
    return removed

ac_domains_w = {"A": ["R"], "B": ["R", "G"], "C": ["R", "G", "B"]}
removed_w = revise_w(ac_domains_w, "B", "A")
print("removed from B because A is fixed:", removed_w)
print("domains now:", ac_domains_w)
```
▶ What you'll see: `R` is removed from `B` because no different value exists in fixed neighbor `A`'s domain.

```python
def ac3_w(domains, edges):
    nbrs = {v: [] for v in domains}
    queue = deque()
    for u, v in edges:
        nbrs[u].append(v); nbrs[v].append(u)
        queue.append((u, v)); queue.append((v, u))
    dom = {v: list(vals) for v, vals in domains.items()}
    revisions = 0
    while queue:
        xi, xj = queue.popleft()
        removed = revise_w(dom, xi, xj)
        if removed:
            revisions += 1
            if len(dom[xi]) == 0:
                return None, revisions
            for xk in nbrs[xi]:
                if xk != xj:
                    queue.append((xk, xi))
    return dom, revisions

start_ac_w = {"A": ["R"], "B": colors_w[:], "C": colors_w[:]}
arc_domains_w, revisions_w = ac3_w(start_ac_w, edges_w)
print("AC-3 domains:", arc_domains_w)
print("revisions:", revisions_w)
```
▶ What you'll see: fixing `A=R` removes `R` from both neighbors and reaches a stable arc-consistent state.

```python
ac_sizes_w = np.array([[len(start_ac_w[v]) for v in vars_w], [len(arc_domains_w[v]) for v in vars_w]])
plt.figure(figsize=(4, 2.6))
plt.imshow(ac_sizes_w, cmap="YlGnBu", vmin=0, vmax=3)
plt.colorbar(label="domain size")
plt.xticks(range(len(vars_w)), vars_w); plt.yticks([0, 1], ["before", "after AC-3"])
plt.title("4: domain sizes after arc consistency"); plt.show()
```
▶ What you'll see: A stays fixed while AC-3 removes the unsupported red value from B and C.

*Why it's done this way:* AC-3 is stricter than one-step pruning because a domain reduction can make another arc newly unsupported. The queue is the reasoning mechanism: only arcs that might be affected are reconsidered, so propagation is systematic without rechecking everything forever.

### 5. MRV, degree, and LCV heuristics

Heuristics do not change which assignments are solutions; they change the order in which search discovers contradictions. MRV chooses the unassigned variable with the fewest remaining values, degree breaks ties by choosing the variable connected to more unassigned neighbors, and LCV tries values that rule out the fewest neighbor options first.

```python
map_vars_w = ["WA", "NT", "SA", "Q", "NSW", "V", "T"]
map_edges_w = [("WA", "NT"), ("WA", "SA"), ("NT", "SA"), ("NT", "Q"), ("SA", "Q"),
               ("SA", "NSW"), ("SA", "V"), ("Q", "NSW"), ("NSW", "V")]
map_domains_w = {v: ["red", "green", "blue"] for v in map_vars_w}
map_domains_w["WA"] = ["red"]  # pretend an earlier choice fixed WA.
map_domains_w["NT"] = ["green", "blue"]  # NT was already pruned.
print("domain sizes:", {v: len(map_domains_w[v]) for v in map_vars_w})
```
▶ What you'll see: `WA` has the smallest domain because it is fixed, while `NT` is already tighter than most regions.

```python
def mrv_degree_choice_w(domains, assignment, edges):
    unassigned = [v for v in domains if v not in assignment]
    degrees = {v: sum(v in e and (e[0] not in assignment or e[1] not in assignment) for e in edges) for v in unassigned}
    return min(unassigned, key=lambda v: (len(domains[v]), -degrees[v], v))

choice_w = mrv_degree_choice_w(map_domains_w, {"WA": "red"}, map_edges_w)
print("MRV/degree chooses:", choice_w)
```
▶ What you'll see: the heuristic chooses the tightest unassigned variable, using graph degree to break ties.

```python
def lcv_order_w(var, domains, assignment, edges):
    nbrs = {v: set() for v in domains}
    for u, v in edges:
        nbrs[u].add(v); nbrs[v].add(u)
    scores = []
    for val in domains[var]:
        ruled_out = sum(val in domains[nb] for nb in nbrs[var] if nb not in assignment)
        scores.append((ruled_out, val))
    return [val for _, val in sorted(scores)]

print("LCV order for NT:", lcv_order_w("NT", map_domains_w, {"WA": "red"}, map_edges_w))
```
▶ What you'll see: values are sorted by how few neighbor-domain entries they remove.

```python
candidate_w = [v for v in map_vars_w if v != "WA"]
degree_w = {v: sum(v in edge for edge in map_edges_w) for v in candidate_w}
plt.figure(figsize=(5, 3))
plt.scatter([len(map_domains_w[v]) for v in candidate_w], [degree_w[v] for v in candidate_w], s=90, color="steelblue")
for v in candidate_w:
    plt.text(len(map_domains_w[v]) + 0.02, degree_w[v], v, va="center")
plt.xlabel("remaining domain size"); plt.ylabel("constraint degree")
plt.title(f"5: MRV/degree picks {choice_w}"); plt.show()
```
▶ What you'll see: the selected variable sits at the smallest remaining-domain size, with degree as the tie-breaker.

*Why it's done this way:* MRV fails early by attacking the most constrained variable first; degree prefers variables whose assignment will create the most pruning; LCV delays failure by trying gentle values before destructive ones. Together they make the same exact search tree much smaller in practice.

### 6. Min-conflicts local search

Backtracking builds a partial assignment that is always legal so far. Min-conflicts takes the opposite stance: start with a complete assignment, count violations, then repeatedly repair one conflicted variable by giving it the value that minimizes remaining conflicts. It is incomplete in the strict proof sense, but it is extremely effective for large problems like N-queens.

```python
def nqueen_conflicts_w(cols):
    n = len(cols)
    conflicts = 0
    for r1 in range(n):
        for r2 in range(r1 + 1, n):
            same_col = cols[r1] == cols[r2]
            same_diag = abs(cols[r1] - cols[r2]) == abs(r1 - r2)
            conflicts += int(same_col or same_diag)
    return conflicts

start_cols_w = np.array([0, 0, 0, 0])  # one queen per row, all in the same column.
print("start board columns:", start_cols_w)
print("conflicting queen pairs:", nqueen_conflicts_w(start_cols_w))
```
▶ What you'll see: a complete but very illegal four-queen assignment.

```python
def min_conflicts_w(n, max_steps=200, seed=0):
    rng = np.random.default_rng(seed)
    cols = rng.integers(0, n, size=n)
    for step in range(max_steps):
        if nqueen_conflicts_w(cols) == 0:
            return cols, step
        conflicted = []
        for r in range(n):
            old = cols[r]
            if any(r != rr and (cols[rr] == old or abs(cols[rr] - old) == abs(rr - r)) for rr in range(n)):
                conflicted.append(r)
        row = int(rng.choice(conflicted))
        scores = []
        for col in range(n):
            trial = cols.copy(); trial[row] = col
            scores.append(nqueen_conflicts_w(trial))
        best = np.where(np.array(scores) == np.min(scores))[0]
        cols[row] = int(rng.choice(best))
    return cols, max_steps

cols_w, steps_w = min_conflicts_w(8, seed=2)
print("solution columns:", cols_w)
print("steps:", steps_w, "conflicts:", nqueen_conflicts_w(cols_w))
assert nqueen_conflicts_w(cols_w) == 0
```
▶ What you'll see: an 8-queen solution appears after a small number of repairs, with zero conflicts.

```python
board_w = np.zeros((8, 8))
board_w[np.arange(8), cols_w] = 1
plt.figure(figsize=(4, 4))
plt.imshow(board_w, cmap="Greys", vmin=0, vmax=1)
plt.xticks(range(8)); plt.yticks(range(8)); plt.grid(color="lightgray")
plt.title("6: solved N-queens board by min-conflicts"); plt.show()
```
▶ What you'll see: one queen per row and column, with no two queens sharing a diagonal.

*Why it's done this way:* Local repair is powerful when a complete assignment is easy to make but global consistency is hard. Each move greedily reduces violations, so the algorithm spends effort on the small set of currently broken variables instead of rebuilding the entire board from scratch.

### ✍️ Toy 1 · Variables, domains, and constraints reject bad partials

A CSP starts with slots to fill, possible values for each slot, and local rules that can reject a
partial assignment before it is complete.

```python
import numpy as np
```

### ✍️ Toy 2 · Backtracking prunes as soon as a choice conflicts

Backtracking builds one partial assignment at a time. A conflicting value is skipped before the
solver recurses below it.

```python
import numpy as np

t2_rng = np.random.default_rng(0)
t2_vars = ["A", "B", "C"]
t2_colors = ["R", "G"]
t2_domains = {t2_var: t2_colors[:] for t2_var in t2_vars}
t2_edges = [("A", "B"), ("B", "C")]
print("variables:", t2_vars)  # -> ['A', 'B', 'C']
print("domains:", t2_domains)  # -> {'A': ['R', 'G'], 'B': ['R', 'G'], 'C': ['R', 'G']}

def t2_consistent(t2_assign):
    for t2_u, t2_v in t2_edges:
        if t2_u in t2_assign and t2_v in t2_assign and t2_assign[t2_u] == t2_assign[t2_v]:
            return False
    return True

t2_count = {"nodes": 0}

def t2_backtrack(t2_assign):
    t2_count["nodes"] += 1
    if len(t2_assign) == len(t2_vars):
        return dict(t2_assign)
    t2_var = next(t2_var for t2_var in t2_vars if t2_var not in t2_assign)
    for t2_value in t2_domains[t2_var]:
        t2_trial = dict(t2_assign)
        t2_trial[t2_var] = t2_value
        if t2_consistent(t2_trial):
            t2_result = t2_backtrack(t2_trial)
            if t2_result is not None:
                return t2_result
    return None

t2_solution = t2_backtrack({})
print("solution:", t2_solution)  # -> {'A': 'R', 'B': 'G', 'C': 'R'}
print("nodes visited:", t2_count["nodes"])  # -> 4
t2_all_complete = len(t2_colors) ** len(t2_vars)
print("complete assignments:", t2_all_complete)  # -> 8
t2_valid = 0
for t2_a in t2_colors:
    for t2_b in t2_colors:
        for t2_c in t2_colors:
            t2_valid += int(t2_consistent({"A": t2_a, "B": t2_b, "C": t2_c}))
print("valid complete assignments:", t2_valid)  # -> 2
assert t2_solution == {"A": "R", "B": "G", "C": "R"}

plt.figure(figsize=(4.6, 2.8))
plt.bar(["valid", "all", "visited"], [t2_valid, t2_all_complete, t2_count["nodes"]], color=["seagreen", "gray", "steelblue"])
plt.ylabel("count")
plt.title("Toy 2 · early rejection saves nodes")
plt.show()
```
▶ What you'll see: the solver visits four partial assignments instead of enumerating all eight completions.

### ✍️ Toy 4 · AC-3 propagates arc consistency through a queue

Arc consistency revisits affected arcs when a domain shrinks, so one fixed value can propagate
through neighboring variables.

```python
import numpy as np

t4_rng = np.random.default_rng(0)
t4_vars = ["A", "B", "C"]
t4_edges = [("A", "B"), ("B", "C")]
t4_start = {"A": ["R"], "B": ["R", "G"], "C": ["R", "G"]}
print("start domains:", t4_start)  # -> {'A': ['R'], 'B': ['R', 'G'], 'C': ['R', 'G']}

def t4_revise(t4_domains, t4_xi, t4_xj):
    t4_removed = []
    t4_kept = []
    for t4_x in t4_domains[t4_xi]:
        t4_supported = any(t4_x != t4_y for t4_y in t4_domains[t4_xj])
        if t4_supported:
            t4_kept.append(t4_x)
        else:
            t4_removed.append(t4_x)
    t4_domains[t4_xi] = t4_kept
    return t4_removed

def t4_ac3(t4_domains):
    t4_nbrs = {t4_var: [] for t4_var in t4_domains}
    t4_queue = []
    for t4_u, t4_v in t4_edges:
        t4_nbrs[t4_u].append(t4_v)
        t4_nbrs[t4_v].append(t4_u)
        t4_queue.append((t4_u, t4_v))
        t4_queue.append((t4_v, t4_u))
    t4_dom = {t4_var: list(t4_vals) for t4_var, t4_vals in t4_domains.items()}
    t4_revisions = 0
    while t4_queue:
        t4_xi, t4_xj = t4_queue.pop(0)
        t4_removed = t4_revise(t4_dom, t4_xi, t4_xj)
        if t4_removed:
            t4_revisions += 1
            for t4_xk in t4_nbrs[t4_xi]:
                if t4_xk != t4_xj:
                    t4_queue.append((t4_xk, t4_xi))
    return t4_dom, t4_revisions

t4_final, t4_revisions = t4_ac3(t4_start)
print("final domains:", t4_final)  # -> {'A': ['R'], 'B': ['G'], 'C': ['R']}
print("revisions:", t4_revisions)  # -> 2
t4_sizes = np.array([[len(t4_start[t4_var]) for t4_var in t4_vars], [len(t4_final[t4_var]) for t4_var in t4_vars]])
print("domain-size table:", t4_sizes.tolist())  # -> [[1, 2, 2], [1, 1, 1]]
assert t4_final == {"A": ["R"], "B": ["G"], "C": ["R"]}

plt.figure(figsize=(4.4, 2.8))
plt.imshow(t4_sizes, cmap="YlGnBu", vmin=0, vmax=2)
plt.colorbar(label="domain size")
plt.xticks(range(3), t4_vars)
plt.yticks([0, 1], ["before", "after"])
plt.title("Toy 4 · AC-3 propagation")
plt.show()
```
▶ What you'll see: `A=R` forces `B=G`, which then forces `C=R`.

## 🛠️ Setup

```python
import numpy as np  # load NumPy for arrays, domain summaries, and deterministic random choices.
import matplotlib.pyplot as plt  # load Matplotlib for constraint graphs, boards, and diagnostic bars.
from collections import deque  # load deque for the AC-3 queue.
np.random.seed(0)  # make all stochastic examples reproducible.

def make_neighbors(variables, edges):  # build an adjacency map from undirected constraint edges.
    nbrs = {v: [] for v in variables}  # start every variable with no listed neighbors.
    for u, v in edges:  # read each undirected constraint edge.
        nbrs[u].append(v); nbrs[v].append(u)  # add both directions for local pruning.
    return nbrs  # return variable -> neighboring variables.

def is_consistent(assignment, edges):  # check inequality constraints in a partial assignment.
    for u, v in edges:  # inspect each neighboring pair.
        if u in assignment and v in assignment and assignment[u] == assignment[v]:  # both assigned and equal violates map coloring.
            return False  # reject the partial world immediately.
    return True  # no known edge currently violates the rules.

def draw_graph(variables, edges, positions, assignment=None, title="constraint graph"):  # draw a small constraint graph.
    assignment = assignment or {}  # default to no coloring if no assignment is provided.
    palette = {"red": "tomato", "green": "mediumseagreen", "blue": "cornflowerblue", "R": "tomato", "G": "mediumseagreen", "B": "cornflowerblue"}  # map values to colors.
    plt.figure(figsize=(4.6, 3.6))  # create a compact figure.
    for u, v in edges:  # draw constraint edges first.
        plt.plot([positions[u][0], positions[v][0]], [positions[u][1], positions[v][1]], color="gray", zorder=1)  # edge line.
    for v in variables:  # draw variables as labeled nodes.
        color = palette.get(assignment.get(v), "white")  # fill solved variables; leave others white.
        plt.scatter(*positions[v], s=700, color=color, edgecolor="black", zorder=2)  # node marker.
        plt.text(positions[v][0], positions[v][1], v, ha="center", va="center", fontsize=10, zorder=3)  # node label.
    plt.title(title); plt.axis("off"); plt.show()  # finish the graph.

def forward_check(domains, variable, value, assignment, neighbors):  # prune neighbor domains after one assignment.
    new_domains = {v: list(vals) for v, vals in domains.items()}  # copy so callers can backtrack safely.
    new_domains[variable] = [value]  # assigned variable is now fixed to one value.
    for nb in neighbors[variable]:  # inspect only adjacent variables.
        if nb not in assignment and value in new_domains[nb]:  # unassigned neighbor cannot use the same value.
            new_domains[nb].remove(value)  # remove the incompatible value.
            if len(new_domains[nb]) == 0:  # an empty domain means this branch is impossible.
                return None  # signal failure.
    return new_domains  # return the pruned domains.

def ac3(domains, variables, edges):  # enforce arc consistency for inequality constraints.
    neighbors = make_neighbors(variables, edges)  # adjacency tells which arcs are connected.
    dom = {v: list(vals) for v, vals in domains.items()}  # copy domains so AC-3 is side-effect safe.
    queue = deque([(u, v) for u, v in edges] + [(v, u) for u, v in edges])  # every undirected edge becomes two directed arcs.
    revisions = 0  # count successful domain reductions.
    while queue:  # continue until no arc can shrink a domain.
        xi, xj = queue.popleft()  # pop one directed arc.
        kept = []  # values of xi that still have support in xj.
        removed_any = False  # track whether xi's domain shrank.
        for x in dom[xi]:  # test each value in xi.
            if any(x != y for y in dom[xj]):  # inequality has support if xj can take a different value.
                kept.append(x)  # keep supported values.
            else:
                removed_any = True  # unsupported value is pruned.
        if removed_any:  # if xi changed, neighbors of xi may need reconsideration.
            dom[xi] = kept; revisions += 1  # commit the revision.
            if len(dom[xi]) == 0:  # no values left means inconsistency.
                return None, revisions  # report failure.
            for xk in neighbors[xi]:  # revisit arcs pointing into the changed variable.
                if xk != xj:
                    queue.append((xk, xi))  # neighbor xk may lose support because xi shrank.
    return dom, revisions  # return arc-consistent domains and count.

def select_unassigned(domains, assignment, variables, edges, use_mrv=True, use_degree=True):  # choose next variable.
    unassigned = [v for v in variables if v not in assignment]  # candidate variables not assigned yet.
    if not use_mrv:  # simple left-to-right search.
        return unassigned[0]  # choose first remaining variable.
    degree = {v: sum((v == u and w not in assignment) or (v == w and u not in assignment) for u, w in edges) for v in unassigned}  # unassigned-neighbor degree.
    return min(unassigned, key=lambda v: (len(domains[v]), -degree[v] if use_degree else 0, v))  # MRV, then highest degree.

def order_values(var, domains, assignment, neighbors, use_lcv=True):  # choose value order.
    if not use_lcv:  # preserve the domain order if LCV is disabled.
        return list(domains[var])  # return values unchanged.
    scores = []  # store (damage, value) pairs.
    for value in domains[var]:  # inspect each candidate value.
        damage = sum(value in domains[nb] for nb in neighbors[var] if nb not in assignment)  # count neighbor values ruled out.
        scores.append((damage, value))  # lower damage is less constraining.
    return [value for damage, value in sorted(scores)]  # least-constraining values first.

def solve_csp(variables, domains, edges, use_forward=False, use_mrv=False, use_degree=False, use_lcv=False):  # backtracking CSP solver.
    neighbors = make_neighbors(variables, edges)  # adjacency for forward checking and LCV.
    nodes = {"count": 0}  # mutable counter for visited recursive nodes.
    def search(assignment, cur_domains):  # recursive depth-first search.
        nodes["count"] += 1  # count each partial assignment state.
        if len(assignment) == len(variables):  # all variables assigned.
            return assignment.copy()  # return a full solution.
        var = select_unassigned(cur_domains, assignment, variables, edges, use_mrv, use_degree)  # choose next variable.
        for value in order_values(var, cur_domains, assignment, neighbors, use_lcv):  # try values in selected order.
            trial = assignment.copy(); trial[var] = value  # extend the partial assignment.
            if is_consistent(trial, edges):  # keep only locally legal partial assignments.
                next_domains = cur_domains  # default: no extra pruning.
                if use_forward:  # optionally prune neighbor domains.
                    next_domains = forward_check(cur_domains, var, value, trial, neighbors)  # prune domains from this choice.
                if next_domains is not None:  # skip branches that emptied a domain.
                    result = search(trial, next_domains)  # continue recursively.
                    if result is not None:  # stop after first solution.
                        return result  # return the found assignment.
        return None  # no value worked here.
    return search({}, {v: list(vals) for v, vals in domains.items()}), nodes["count"]  # solve from scratch.

def nqueen_edges(n):  # create binary attack constraints between queen rows.
    return [(i, j) for i in range(n) for j in range(i + 1, n)]  # every pair of rows must be non-attacking.

def nqueen_consistent(assignment, n):  # check N-queens partial assignment row -> column.
    rows = list(assignment)  # assigned rows.
    for i in range(len(rows)):  # compare pairs of assigned queens.
        for j in range(i + 1, len(rows)):
            r1, r2 = rows[i], rows[j]  # two rows.
            c1, c2 = assignment[r1], assignment[r2]  # their columns.
            if c1 == c2 or abs(c1 - c2) == abs(r1 - r2):  # same column or diagonal attacks.
                return False  # conflict.
    return True  # no attacks among assigned queens.

def solve_nqueens_backtracking(n, use_mrv=False):  # small N-queens backtracking solver.
    variables = list(range(n)); domains = {r: list(range(n)) for r in variables}; nodes = {"count": 0}  # setup.
    def search(assign):  # recursive search.
        nodes["count"] += 1  # count node.
        if len(assign) == n:  # all rows assigned.
            return assign.copy()  # return solution.
        remaining = [r for r in variables if r not in assign]  # unassigned rows.
        if use_mrv:  # estimate remaining legal columns for each row.
            row = min(remaining, key=lambda r: sum(nqueen_consistent({**assign, r: c}, n) for c in domains[r]))  # tightest row first.
        else:
            row = remaining[0]  # natural row order.
        legal_cols = [c for c in domains[row] if nqueen_consistent({**assign, row: c}, n)]  # legal values now.
        for col in legal_cols:  # try columns.
            result = search({**assign, row: col})  # recurse.
            if result is not None:
                return result  # stop at first solution.
        return None  # fail.
    return search({}), nodes["count"]  # solve.

def nqueen_conflicts(cols):  # count attacking queen pairs in a complete row -> column vector.
    n = len(cols); conflicts = 0  # initialize count.
    for r1 in range(n):  # compare every pair of rows.
        for r2 in range(r1 + 1, n):
            conflicts += int(cols[r1] == cols[r2] or abs(cols[r1] - cols[r2]) == abs(r1 - r2))  # column or diagonal attack.
    return conflicts  # return pair count.

def min_conflicts_nqueens(n, max_steps=1000, seed=0):  # local search for N-queens.
    rng = np.random.default_rng(seed)  # deterministic random generator.
    cols = rng.integers(0, n, size=n)  # complete initial assignment: one column per row.
    history = [nqueen_conflicts(cols)]  # track conflict count.
    for step in range(max_steps):  # repair loop.
        if history[-1] == 0:  # solved.
            return cols, step, history  # return solution and trace.
        conflicted = [r for r in range(n) if any(r != rr and (cols[rr] == cols[r] or abs(cols[rr] - cols[r]) == abs(rr - r)) for rr in range(n))]  # rows in conflict.
        row = int(rng.choice(conflicted))  # repair one conflicted row.
        scores = []  # conflict score per candidate column.
        for col in range(n):  # test all columns for that row.
            trial = cols.copy(); trial[row] = col  # move queen.
            scores.append(nqueen_conflicts(trial))  # count conflicts.
        best = np.where(np.array(scores) == np.min(scores))[0]  # best columns may tie.
        cols[row] = int(rng.choice(best))  # choose one best repair.
        history.append(nqueen_conflicts(cols))  # record new conflicts.
    return cols, max_steps, history  # return best effort.

def plot_nqueen(cols, title):  # draw a queen board from row -> column vector.
    n = len(cols); board = np.zeros((n, n))  # empty board.
    board[np.arange(n), cols] = 1  # place queens.
    plt.figure(figsize=(4, 4)); plt.imshow(board, cmap="Greys", vmin=0, vmax=1)  # draw board.
    plt.xticks(range(n)); plt.yticks(range(n)); plt.grid(color="lightgray")  # grid for squares.
    plt.title(title); plt.show()  # render.
```

### Advanced 5 — Build a compact Sudoku constraint graph summary

**Goal.** Inspect graph degree in Sudoku, because degree heuristics prefer variables that constrain many still-unassigned neighbors. We build it in 3 steps.

```python
n_a5 = 4  # 4x4 Sudoku.
variables_a5 = [(r, c) for r in range(n_a5) for c in range(n_a5)]  # one cell variable.
edges_a5 = set()  # store unique binary inequality edges.
for a_a5 in variables_a5:
    for b_a5 in variables_a5:
        if a_a5 < b_a5:
            related_a5 = a_a5[0] == b_a5[0] or a_a5[1] == b_a5[1] or (a_a5[0] // 2, a_a5[1] // 2) == (b_a5[0] // 2, b_a5[1] // 2)
            if related_a5:
                edges_a5.add((a_a5, b_a5))
edges_a5 = list(edges_a5)  # list for helper functions.
print("variables:", len(variables_a5), "edges:", len(edges_a5))  # inspect graph size.
```
▶ What you'll see: 16 cell variables connected by many row, column, and box constraints.

```python
neighbors_a5 = make_neighbors(variables_a5, edges_a5)  # build Sudoku constraint graph adjacency.
degrees_a5 = np.array([len(neighbors_a5[v]) for v in variables_a5])  # degree for each cell.
print("degree min/mean/max:", degrees_a5.min(), round(float(degrees_a5.mean()), 2), degrees_a5.max())  # inspect graph density.
assert degrees_a5.min() == degrees_a5.max() == 7  # each 4x4 Sudoku cell sees 7 peers.
```
▶ What you'll see: every 4×4 Sudoku cell has seven distinct peer cells.
