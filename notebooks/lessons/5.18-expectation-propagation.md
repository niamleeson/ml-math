# 5.18 — Expectation Propagation

Expectation Propagation (EP) approximates a hard posterior by replacing difficult factors with simple local site approximations, then refining one site at a time. The key move is cavity → tilted → moment match: remove one approximate site, put the true factor back locally, match moments, and convert those matched moments into a new site.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build expectation propagation one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math is shown with tiny one-dimensional grids so the approximation never feels like a black box. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, grids, and moment calculations.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for toy experiments.
```
▶ What you'll see: the only imports used in this lesson: NumPy and Matplotlib.

### 1. Approximate a difficult product with simple local sites

EP starts from a posterior that is proportional to a product of factors. Some factors may be awkward, but we can replace each one by a simple approximate site. In a Gaussian EP toy model, a site is easiest to store in natural parameters: precision \(\tau=1/\sigma^2\) and precision-times-mean \(\nu=\mu/\sigma^2\). Products are simple because natural parameters add.

```python
site_tau_w = np.array([1/2, 1/3])  # two approximate Gaussian-site precisions.
site_nu_w = np.array([0.0, 1/3])  # second site prefers mean 1 with variance 3.
global_tau_w = np.sum(site_tau_w)  # precisions add under multiplication.
global_nu_w = np.sum(site_nu_w)  # precision-times-mean terms add too.
print("site precisions:", np.round(site_tau_w, 6))
print("global precision:", round(global_tau_w, 6))
assert round(global_tau_w, 6) == 0.833333
```
▶ What you'll see: the two local precisions add to `0.833333`.

```python
global_var_w = 1 / global_tau_w  # variance is inverse precision.
global_mean_w = global_nu_w / global_tau_w  # mean is nu divided by tau.
print("global mean:", round(global_mean_w, 3))
print("global variance:", round(global_var_w, 3))
assert round(global_mean_w, 3) == 0.4
assert round(global_var_w, 3) == 1.2
```
▶ What you'll see: the approximate global distribution has mean `0.400` and variance `1.200`.

```python
x_w = np.linspace(-5, 5, 400)  # grid for a one-dimensional density picture.
q_w = np.exp(-0.5 * global_tau_w * (x_w - global_mean_w) ** 2)  # unnormalized Gaussian q.
q_w = q_w / np.trapz(q_w, x_w)  # normalize on the grid for plotting.
plt.figure(figsize=(4.6, 3))
plt.plot(x_w, q_w, color="teal")
plt.title("1: product of approximate sites")
plt.xlabel("x"); plt.ylabel("q(x)")
plt.show()
```
▶ What you'll see: one smooth Gaussian curve representing the current EP approximation.

*Why it's done this way:* EP chooses a tractable family so global updates stay cheap. Natural parameters make the product rule algebraic: multiplying Gaussian-shaped terms adds precisions, so local evidence can be inserted and removed without redoing a hard integral from scratch.

### 2. Build the cavity by removing one old site

To update site 2, EP first removes site 2 from the current approximation. The result is the cavity distribution \(q_{\setminus i}(x) \propto q(x)/\tilde f_i(x)\). This matters because matching moments while the old site is still present would count the same evidence twice.

```python
remove_idx_w = 1  # update the second site.
cav_tau_w = global_tau_w - site_tau_w[remove_idx_w]  # divide by a Gaussian site by subtracting natural parameters.
cav_nu_w = global_nu_w - site_nu_w[remove_idx_w]
cav_var_w = 1 / cav_tau_w
cav_mean_w = cav_nu_w / cav_tau_w
print("cavity precision:", round(cav_tau_w, 3))
print("cavity mean, variance:", round(cav_mean_w, 3), round(cav_var_w, 3))
assert round(cav_mean_w, 3) == 0.0
assert round(cav_var_w, 3) == 2.0
```
▶ What you'll see: after removing site 2, the cavity returns to mean `0.000` and variance `2.000`.

```python
cavity_w = np.exp(-0.5 * cav_tau_w * (x_w - cav_mean_w) ** 2)
cavity_w = cavity_w / np.trapz(cavity_w, x_w)
plt.figure(figsize=(4.6, 3))
plt.plot(x_w, q_w, label="q with old site", color="gray")
plt.plot(x_w, cavity_w, label="cavity", color="purple")
plt.title("2: removing a site creates the cavity")
plt.xlabel("x"); plt.ylabel("density")
plt.legend(); plt.show()
```
▶ What you'll see: the cavity is wider and centered at zero because the second site's pull has been removed.

*Why it's done this way:* The cavity is a leave-one-factor-out distribution. It carries all current beliefs except the factor being repaired, so the next step can ask, “what would the true factor add to the rest of the model?” rather than “what would the true factor add on top of its own old approximation?”

### 3. Form the tilted distribution with the true local factor

The tilted distribution is proportional to the true factor times the cavity: \(p_i^\text{tilt}(x) \propto f_i(x) q_{\setminus i}(x)\). In this toy, the true factor is a soft likelihood centered near 1, and the cavity is a broad Gaussian prior-like belief.

```python
true_factor_w = 1 / (1 + np.exp(-4 * (x_w - 0.55)))  # a non-Gaussian increasing likelihood factor.
tilted_unnorm_w = true_factor_w * cavity_w  # combine true local evidence with the rest of the model.
Z_tilt_w = np.trapz(tilted_unnorm_w, x_w)  # normalizing constant on the grid.
tilted_w = tilted_unnorm_w / Z_tilt_w
print("tilted normalizer:", round(Z_tilt_w, 3))
print("tilted mass check:", round(np.trapz(tilted_w, x_w), 3))
assert round(np.trapz(tilted_w, x_w), 3) == 1.0
```
▶ What you'll see: the tilted curve is normalized to integrate to one.

```python
plt.figure(figsize=(4.8, 3))
plt.plot(x_w, cavity_w, label="cavity", color="purple")
plt.plot(x_w, true_factor_w / np.trapz(true_factor_w, x_w), label="scaled true factor", color="orange")
plt.plot(x_w, tilted_w, label="tilted", color="teal")
plt.title("3: tilted = true factor × cavity")
plt.xlabel("x"); plt.ylabel("density / scaled score")
plt.legend(); plt.show()
```
▶ What you'll see: the tilted distribution shifts right because the true factor rewards larger `x` values.

*Why it's done this way:* The cavity supplies the current context and the true factor supplies the local exact evidence. Normalizing turns their product from “relative scores” into a probability distribution whose moments can be matched by a tractable approximation.

### 4. Match tilted moments with a Gaussian approximation

EP projects the tilted distribution back into the tractable family by matching moments. For a Gaussian approximation, that means choose the Gaussian with the same mean and variance as the tilted distribution.

```python
tilt_mean_w = np.trapz(x_w * tilted_w, x_w)  # first moment.
tilt_second_w = np.trapz((x_w ** 2) * tilted_w, x_w)  # second raw moment.
tilt_var_w = tilt_second_w - tilt_mean_w ** 2  # variance = E[x^2] - E[x]^2.
print("tilted mean:", round(tilt_mean_w, 3))
print("tilted variance:", round(tilt_var_w, 3))
assert 1.2 < tilt_mean_w < 1.6
assert 0.45 < tilt_var_w < 0.75
```
▶ What you'll see: the non-Gaussian tilted distribution has a mean near the right-shifted mass and a finite variance.

```python
matched_tau_w = 1 / tilt_var_w
matched_nu_w = tilt_mean_w / tilt_var_w
matched_w = np.exp(-0.5 * matched_tau_w * (x_w - tilt_mean_w) ** 2)
matched_w = matched_w / np.trapz(matched_w, x_w)
plt.figure(figsize=(4.8, 3))
plt.plot(x_w, tilted_w, label="tilted", color="teal")
plt.plot(x_w, matched_w, label="moment-matched Gaussian", color="crimson", linestyle="--")
plt.title("4: projection by moment matching")
plt.xlabel("x"); plt.ylabel("density")
plt.legend(); plt.show()
```
▶ What you'll see: the Gaussian approximation matches the tilted distribution's center and spread, not every skewed detail.

*Why it's done this way:* Moment matching preserves the expectations EP is designed to keep accurate. The projection is local: rather than optimize one global KL objective, EP asks each true factor to leave behind a simple site whose product with the cavity has the same low-order moments as the tilted distribution.

### 5. Convert matched moments into a new site

After matching the tilted distribution, EP must isolate what the updated site contributed. Since global natural parameters equal cavity plus site, the new site is matched minus cavity.

```python
toy_tilt_mean_w = 0.8  # worked arithmetic from the lesson block.
toy_tilt_var_w = 0.5
toy_matched_tau_w = 1 / toy_tilt_var_w
toy_matched_nu_w = toy_tilt_mean_w / toy_tilt_var_w
print("matched natural params:", round(toy_matched_tau_w, 3), round(toy_matched_nu_w, 3))
assert round(toy_matched_tau_w, 3) == 2.0
assert round(toy_matched_nu_w, 3) == 1.6
```
▶ What you'll see: tilted moments `(0.8, 0.5)` become matched natural parameters `[2.0, 1.6]`.

```python
toy_cav_tau_w = 0.5
toy_cav_nu_w = 0.0
new_site_tau_w = toy_matched_tau_w - toy_cav_tau_w
new_site_nu_w = toy_matched_nu_w - toy_cav_nu_w
print("new site natural params:", round(new_site_tau_w, 3), round(new_site_nu_w, 3))
assert round(new_site_tau_w, 3) == 1.5
assert round(new_site_nu_w, 3) == 1.6
```
▶ What you'll see: subtracting the cavity gives the lesson's new site `[1.5, 1.6]`.

```python
old_site_pair_w = np.array([site_tau_w[1], site_nu_w[1]])
new_site_pair_w = np.array([new_site_tau_w, new_site_nu_w])
plt.figure(figsize=(4.6, 3))
plt.bar(["old τ", "old ν", "new τ", "new ν"], np.r_[old_site_pair_w, new_site_pair_w], color=["gray", "gray", "teal", "teal"])
plt.title("5: old site replaced by matched site")
plt.ylabel("natural parameter value")
plt.show()
```
▶ What you'll see: the updated site has much stronger precision and a strong positive mean-pull.

*Why it's done this way:* Moment matching gives a new approximation for cavity × true factor. Subtracting the cavity extracts only the local factor's replacement, so when the site is multiplied back into the global approximation, the global distribution has the matched moments.

### 6. Damping and convergence checks

EP updates can jump too far, especially when sites are sharp or tilted moments change a lot. Damping blends the old and new site natural parameters before insertion. This makes each iteration less aggressive and can turn oscillation into convergence.

```python
old_site_w = np.array([site_tau_w[1], site_nu_w[1]])
raw_new_site_w = np.array([new_site_tau_w, new_site_nu_w])
damp_w = 0.4
damped_site_w = (1 - damp_w) * old_site_w + damp_w * raw_new_site_w
print("old site:", np.round(old_site_w, 3))
print("damped site:", np.round(damped_site_w, 3))
assert np.all(damped_site_w > old_site_w)
```
▶ What you'll see: the damped site moves toward the raw update without taking the whole jump.

```python
jump_sizes_w = []
site_path_w = old_site_w.copy()
for step_w in range(8):
    proposal_w = raw_new_site_w + 0.15 * ((-1) ** step_w) * np.array([1.0, -0.5])  # deliberately oscillating proposal.
    new_path_w = 0.6 * site_path_w + 0.4 * proposal_w
    jump_sizes_w.append(float(np.linalg.norm(new_path_w - site_path_w)))
    site_path_w = new_path_w
print("jump sizes:", np.round(jump_sizes_w, 3))
assert jump_sizes_w[-1] < jump_sizes_w[0]
```
▶ What you'll see: damped jumps shrink even when raw proposals alternate slightly.

```python
plt.figure(figsize=(4.8, 3))
plt.plot(jump_sizes_w, marker="o", color="crimson")
plt.title("6: damping reduces update jumps")
plt.xlabel("EP update"); plt.ylabel("site-parameter jump")
plt.show()
```
▶ What you'll see: a downward trend in update size, which is the convergence signal we want to monitor.

*Why it's done this way:* EP is not guaranteed to converge, because each local projection changes the context seen by later factors. Damping is a numerical safety valve: it preserves the direction of the moment-matched update while reducing the chance that one site overreacts and destabilizes the product.

### ✍️ Toy 1 · Gaussian site products add natural parameters

For Gaussian-shaped EP sites, multiplying sites means adding precision `tau` and precision-times-mean `nu`.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)
t1_site_tau = np.array([0.50, 0.25, 0.25])
print("site tau:", t1_site_tau.tolist())  # -> [0.5, 0.25, 0.25]
t1_site_nu = np.array([0.00, 0.50, -0.25])
print("site nu:", t1_site_nu.tolist())  # -> [0.0, 0.5, -0.25]
t1_global_tau = float(t1_site_tau.sum())
print("global tau:", round(t1_global_tau, 3))  # -> 1.0
t1_global_nu = float(t1_site_nu.sum())
print("global nu:", round(t1_global_nu, 3))  # -> 0.25
t1_global_var = 1.0 / t1_global_tau
print("global variance:", round(t1_global_var, 3))  # -> 1.0
t1_global_mean = t1_global_nu / t1_global_tau
print("global mean:", round(t1_global_mean, 3))  # -> 0.25
t1_grid = np.arange(-3, 4, dtype=float)
print("grid:", t1_grid.tolist())  # -> [-3.0, -2.0, -1.0, 0.0, 1.0, 2.0, 3.0]
t1_q = np.exp(-0.5 * t1_global_tau * (t1_grid - t1_global_mean) ** 2)
t1_q = t1_q / t1_q.sum()
print("normalized q on grid:", np.round(t1_q, 3).tolist())  # -> [0.002, 0.032, 0.183, 0.387, 0.301, 0.086, 0.009]
assert round(t1_global_mean, 3) == 0.25

plt.figure(figsize=(4.8, 2.8))
plt.plot(t1_grid, t1_q, marker="o", color="teal")
plt.xlabel("x")
plt.ylabel("grid mass")
plt.title("Toy 1 · product of Gaussian sites")
plt.show()
```
▶ What you'll see: three local sites combine into one Gaussian-like curve with mean `0.25`.

### ✍️ Toy 2 · The cavity subtracts one old site

EP removes the site being repaired by subtracting its natural parameters from the current global approximation.

```python
import numpy as np

t2_rng = np.random.default_rng(0)
t2_site_tau = np.array([0.75, 0.25, 0.25])

print("site nu:", t2_site_nu.tolist())  # -> [0.0, 0.5, 0.0]
t2_global_tau = float(t2_site_tau.sum())
print("global tau:", round(t2_global_tau, 3))  # -> 1.25
t2_global_nu = float(t2_site_nu.sum())
print("global nu:", round(t2_global_nu, 3))  # -> 0.5
t2_remove = 1
print("removed site index:", t2_remove)  # -> 1
t2_cavity_tau = t2_global_tau - t2_site_tau[t2_remove]

t2_cavity_var = 1.0 / t2_cavity_tau
print("cavity variance:", round(float(t2_cavity_var), 3))  # -> 1.0
t2_cavity_mean = t2_cavity_nu / t2_cavity_tau

t2_grid = np.arange(-3, 4, dtype=float)
print("grid:", t2_grid.tolist())  # -> [-3.0, -2.0, -1.0, 0.0, 1.0, 2.0, 3.0]
t2_global_mean = t2_global_nu / t2_global_tau
t2_global_var = 1.0 / t2_global_tau
t2_q = np.exp(-0.5 * (t2_grid - t2_global_mean) ** 2 / t2_global_var)

t2_cavity = np.exp(-0.5 * (t2_grid - t2_cavity_mean) ** 2 / t2_cavity_var)
t2_cavity = t2_cavity / t2_cavity.sum()
print("cavity mass:", np.round(t2_cavity, 3).tolist())  # -> [0.004, 0.054, 0.242, 0.399, 0.242, 0.054, 0.004]
assert round(float(t2_cavity_mean), 3) == 0.0

plt.figure(figsize=(4.8, 2.8))

plt.ylabel("grid mass")
plt.title("Toy 2 · removing a site widens context")
plt.legend()
plt.show()
```
▶ What you'll see: subtracting site 1 returns the cavity to mean `0.0` and changes the curve.

### ✍️ Toy 3 · Tilted distribution multiplies cavity by the true factor

The tilted distribution is the normalized product of the cavity and the exact local factor.

```python
import numpy as np

t3_rng = np.random.default_rng(0)
t3_grid = np.arange(-3, 4, dtype=float)
print("grid:", t3_grid.tolist())  # -> [-3.0, -2.0, -1.0, 0.0, 1.0, 2.0, 3.0]
t3_cavity_scores = np.exp(-0.5 * (t3_grid ** 2) / 2.0)
t3_cavity = t3_cavity_scores / t3_cavity_scores.sum()
print("cavity mass:", np.round(t3_cavity, 3).tolist())  # -> [0.03, 0.105, 0.222, 0.285, 0.222, 0.105, 0.03]
t3_true_factor = np.array([0.10, 0.20, 0.40, 0.80, 1.00, 1.00, 1.00])

print("unnormalized tilted:", np.round(t3_unnormalized, 3).tolist())  # -> [0.003, 0.021, 0.089, 0.228, 0.222, 0.105, 0.03]
t3_Z = float(t3_unnormalized.sum())

assert round(float(t3_tilted.sum()), 3) == 1.0

plt.figure(figsize=(4.8, 2.8))
```

### ✍️ Toy 4 · Moment matching turns tilted moments into Gaussian natural parameters

EP projects the tilted distribution back to a Gaussian by matching its mean and variance.

```python
import numpy as np

t4_rng = np.random.default_rng(0)
t4_grid = np.array([-2.0, -1.0, 0.0, 1.0, 2.0, 3.0])
print("grid:", t4_grid.tolist())  # -> [-2.0, -1.0, 0.0, 1.0, 2.0, 3.0]
t4_tilted = np.array([0.05, 0.10, 0.15, 0.30, 0.25, 0.15])
print("tilted mass:", t4_tilted.tolist())  # -> [0.05, 0.1, 0.15, 0.3, 0.25, 0.15]
t4_mean = float(np.sum(t4_grid * t4_tilted))
print("matched mean:", round(t4_mean, 3))  # -> 1.05
t4_second = float(np.sum((t4_grid ** 2) * t4_tilted))
print("second raw moment:", round(t4_second, 3))  # -> 2.95
t4_var = t4_second - t4_mean ** 2
print("matched variance:", round(t4_var, 3))  # -> 1.848
t4_tau = 1.0 / t4_var
print("matched tau:", round(t4_tau, 3))  # -> 0.541
t4_nu = t4_mean / t4_var
print("matched nu:", round(t4_nu, 3))  # -> 0.568
t4_matched_scores = np.exp(-0.5 * (t4_grid - t4_mean) ** 2 / t4_var)
t4_matched = t4_matched_scores / t4_matched_scores.sum()
print("matched Gaussian mass:", np.round(t4_matched, 3).tolist())  # -> [0.025, 0.098, 0.226, 0.304, 0.239, 0.109]
assert round(t4_mean, 3) == 1.05
assert round(t4_var, 3) == 1.848

plt.figure(figsize=(4.8, 2.8))
plt.bar(t4_grid - 0.12, t4_tilted, width=0.24, color="teal", label="tilted")
plt.bar(t4_grid + 0.12, t4_matched, width=0.24, color="crimson", label="matched Gaussian")
plt.xlabel("x")
plt.ylabel("grid mass")
plt.title("Toy 4 · match mean and variance")
plt.legend()
plt.show()
```
▶ What you'll see: the Gaussian approximation preserves the tilted mean `1.05` and variance `1.848`.

### ✍️ Toy 5 · New site equals matched approximation minus cavity

Once the tilted moments define the matched global approximation, the local site is the matched natural parameters minus the cavity parameters.

```python
import numpy as np

t5_rng = np.random.default_rng(0)
t5_matched_mean = 1.0
print("matched mean:", t5_matched_mean)  # -> 1.0
t5_matched_var = 0.5

t5_matched_tau = 1.0 / t5_matched_var

t5_cavity_tau = 0.75
print("cavity tau:", t5_cavity_tau)  # -> 0.75
t5_cavity_nu = 0.25
print("cavity nu:", t5_cavity_nu)  # -> 0.25

print("new site mean-pull:", round(t5_site_mean, 3))  # -> 1.4
assert np.allclose(np.array([t5_site_tau, t5_site_nu]), np.array([1.25, 1.75]))

plt.ylabel("natural parameter")
plt.title("Toy 5 · subtract cavity to isolate the site")
plt.show()
```
▶ What you'll see: matched `[2,2]` minus cavity `[0.75,0.25]` leaves site `[1.25,1.75]`.

### ✍️ Toy 6 · Damping shrinks EP update jumps

Damping blends the old site with the raw proposal so repeated updates move less abruptly.

```python
import numpy as np

t6_rng = np.random.default_rng(0)
t6_old_site = np.array([0.40, 0.20])
print("old site:", t6_old_site.tolist())  # -> [0.4, 0.2]
t6_raw_site = np.array([1.20, 1.00])
print("raw new site:", t6_raw_site.tolist())  # -> [1.2, 1.0]
t6_damping = 0.5
print("damping:", t6_damping)  # -> 0.5
t6_damped_site = (1.0 - t6_damping) * t6_old_site + t6_damping * t6_raw_site
print("one damped update:", t6_damped_site.tolist())  # -> [0.8, 0.6]
t6_proposals = np.array([[1.20, 1.00], [0.90, 1.20], [1.10, 0.90], [1.00, 1.00], [1.05, 0.95], [1.02, 1.00]])
print("raw proposal path:", t6_proposals.tolist())  # -> [[1.2, 1.0], [0.9, 1.2], [1.1, 0.9], [1.0, 1.0], [1.05, 0.95], [1.02, 1.0]]
t6_site_path = t6_old_site.copy()
t6_jumps = []
for t6_proposal in t6_proposals:
    t6_next_site = (1.0 - t6_damping) * t6_site_path + t6_damping * t6_proposal
    t6_jump = float(np.linalg.norm(t6_next_site - t6_site_path))
    t6_jumps.append(t6_jump)
    t6_site_path = t6_next_site
print("damped jump sizes:", np.round(t6_jumps, 3).tolist())  # -> [0.566, 0.304, 0.125, 0.052, 0.031, 0.025]
print("final damped site:", np.round(t6_site_path, 3).tolist())  # -> [1.019, 0.975]
assert t6_jumps[-1] < t6_jumps[0]

plt.figure(figsize=(4.8, 2.8))
plt.plot(np.arange(1, len(t6_jumps) + 1), t6_jumps, marker="o", color="crimson")
plt.xlabel("update")
plt.ylabel("jump size")
plt.title("Toy 6 · damped jumps get smaller")
plt.show()
```
▶ What you'll see: the jump sizes shrink from `0.566` to `0.025` as damping stabilizes the site path.

## 🛠️ Setup

```python
import numpy as np
import matplotlib.pyplot as plt
np.random.seed(0)

def gaussian_pdf(x, mean, var):
    return np.exp(-0.5 * (x - mean) ** 2 / var) / np.sqrt(2 * np.pi * var)

def normalize_grid(y, x):
    area = np.trapz(y, x)
    return y / area, area

def grid_moments(x, p):
    mean = np.trapz(x * p, x)
    second = np.trapz((x ** 2) * p, x)
    return mean, second - mean ** 2

def to_natural(mean, var):
    return 1 / var, mean / var

def from_natural(tau, nu):
    return nu / tau, 1 / tau
```

### Advanced 1 — Run several EP sweeps over two non-Gaussian sites

**Goal.** Implement a small multi-sweep EP loop, because real EP repeatedly revisits sites until changes are small. We build it in 4 steps.

```python
x_a1 = np.linspace(-6, 6, 1000)
centers_a1 = np.array([-0.7, 0.8])
site_tau_a1 = np.array([0.3, 0.3])
site_nu_a1 = np.array([-0.1, 0.1])
max_jumps_a1 = []
print("initial sites:", np.round(site_tau_a1, 3), np.round(site_nu_a1, 3))
```
▶ What you'll see: two weak initial sites for the two true factors.

```python
for sweep_a1 in range(8):
    sweep_jumps_a1 = []
    for i_a1 in range(2):
        old_pair_a1 = np.array([site_tau_a1[i_a1], site_nu_a1[i_a1]])
        cav_tau_a1 = np.sum(site_tau_a1) - site_tau_a1[i_a1]
        cav_nu_a1 = np.sum(site_nu_a1) - site_nu_a1[i_a1]
        cav_mean_a1, cav_var_a1 = from_natural(cav_tau_a1, cav_nu_a1)
        cavity_a1 = gaussian_pdf(x_a1, cav_mean_a1, cav_var_a1)
        factor_a1 = 1 / (1 + np.exp(-4 * (x_a1 - centers_a1[i_a1])))
        tilted_a1, _ = normalize_grid(cavity_a1 * factor_a1, x_a1)
        mean_a1, var_a1 = grid_moments(x_a1, tilted_a1)
        mtau_a1, mnu_a1 = to_natural(mean_a1, var_a1)
        proposal_a1 = np.array([max(mtau_a1 - cav_tau_a1, 1e-5), mnu_a1 - cav_nu_a1])
        damped_a1 = 0.6 * old_pair_a1 + 0.4 * proposal_a1
        site_tau_a1[i_a1], site_nu_a1[i_a1] = damped_a1
        sweep_jumps_a1.append(float(np.linalg.norm(damped_a1 - old_pair_a1)))
    max_jumps_a1.append(max(sweep_jumps_a1))
print("max jumps:", np.round(max_jumps_a1, 4))
assert max_jumps_a1[-1] < max_jumps_a1[0]
```
▶ What you'll see: the largest site change generally shrinks across sweeps.

```python
q_mean_a1, q_var_a1 = from_natural(np.sum(site_tau_a1), np.sum(site_nu_a1))
print("final q mean/var:", round(q_mean_a1, 3), round(q_var_a1, 3))
assert q_var_a1 > 0
```
▶ What you'll see: the final approximate posterior remains a valid Gaussian.

```python
plt.figure(figsize=(5, 3))
plt.plot(max_jumps_a1, marker="o", color="purple")
plt.title("Advanced 1: EP sweep convergence")
plt.xlabel("sweep"); plt.ylabel("max site jump")
plt.show()
```
▶ What you'll see: a convergence diagnostic curve for repeated EP sweeps.

👀 Takeaway: practical EP is an iterative schedule with diagnostics, not a one-shot formula.
