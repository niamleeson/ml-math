# 12.9 — Graph Transformers

Graph transformers keep the transformer's global attention but add graph structure back into the score. In this lesson, we build attention, graph-distance bias, degree features, Laplacian positional encodings, and graph-token readout from scratch so the model can jump across the graph without forgetting the graph's roads.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build graph transformers one idea at a time. Run each cell in order and read the printed intermediate values — every piece of graph math is spelled out so global attention never feels like a black box. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays + linear algebra for graphs, encodings, and attention.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for any random-looking examples.
```

### 1. A graph is nodes plus roads, not a sequence

A transformer normally receives tokens in a sequence, where position 3 comes after position 2. A graph has no such natural order: node labels can be permuted without changing the graph. We start with a tiny path graph 0—1—2, store its roads in an adjacency matrix, and compute shortest-path distances by repeated relaxation. Those distances are the structural coordinates attention will use later.

```python
A_w = np.array([[0., 1., 0.],
                [1., 0., 1.],
                [0., 1., 0.]])  # adjacency for path graph 0--1--2.
X_w = np.array([[1.0, 0.0],
                [0.8, 0.6],
                [0.0, 1.0]])  # two node features per node.
print("adjacency:\n", A_w.astype(int))
print("node features:\n", X_w)
```
▶ What you'll see: a 3-node path graph and one 2-D feature vector per node.

```python
def all_pairs_dist_w(A):
    n = A.shape[0]
    D = np.where(A > 0, 1.0, np.inf)  # one edge means distance 1; missing edge starts as infinity.
    np.fill_diagonal(D, 0.0)  # every node is distance 0 from itself.
    for k in range(n):
        D = np.minimum(D, D[:, [k]] + D[[k], :])  # allow paths that travel through k.
    return D

D_w = all_pairs_dist_w(A_w)
print("shortest-path distances:\n", D_w.astype(int))
assert D_w[0, 2] == 2
```
▶ What you'll see: node 0 is one hop from node 1 and two hops from node 2.

```python
plt.figure(figsize=(4, 3))
plt.imshow(D_w, cmap="magma_r")
plt.colorbar(label="shortest-path distance")
plt.xticks(range(3)); plt.yticks(range(3))
plt.title("1: graph distances, not token positions")
plt.show()
```
▶ What you'll see: the diagonal is distance 0, adjacent nodes are 1, and the graph endpoints are 2 apart.

*Why it's done this way:* A graph transformer needs a structure signal that survives node relabeling. Shortest-path distance depends only on the roads in the graph, not on arbitrary row order, so it is a useful bias for attention.

### 2. Vanilla global attention can look everywhere

Self-attention builds a query, key, and value for each node. The score from node $i$ to node $j$ is $q_i^\top k_j / \sqrt d$, then softmax turns scores into weights that sum to 1. This is global: node 0 can attend to node 2 even though there is no edge 0—2.

```python
def softmax_w(z):
    z = z - np.max(z, axis=-1, keepdims=True)  # stabilize exponentials.
    e = np.exp(z)
    return e / e.sum(axis=-1, keepdims=True)

def attention_w(X, B=None):
    Q = X.copy(); K = X.copy(); V = X.copy()  # identity projections for inspectable math.
    scores = Q @ K.T / np.sqrt(X.shape[1])
    if B is not None:
        scores = scores + B
    W = softmax_w(scores)
    return scores, W, W @ V

scores_plain_w, W_plain_w, H_plain_w = attention_w(X_w)
print("plain scores from node 0:", np.round(scores_plain_w[0], 3))
print("plain weights from node 0:", np.round(W_plain_w[0], 3))
assert round(float(W_plain_w[0].sum()), 6) == 1.0
```
▶ What you'll see: node 0 gives nonzero attention to all three nodes, including the far endpoint.

```python
plt.figure(figsize=(4, 3))
plt.bar(["to 0", "to 1", "to 2"], W_plain_w[0], color="steelblue")
plt.ylim(0, 0.6)
plt.title("2: vanilla attention from node 0")
plt.ylabel("attention weight")
plt.show()
```
▶ What you'll see: self-attention is largest, but the far node still receives probability mass.

*Why it's done this way:* The dot product measures content similarity, while softmax makes the weights comparable and normalized. The benefit is long-range communication in one layer; the danger is that content scores alone do not know which nodes are graph-close.

### 3. Structural bias prices graph distance

A graph transformer adds a bias matrix $B$ before softmax: $\operatorname{softmax}(QK^\top/\sqrt d + B)$. Here we use $B_{ij}=-0.5\,\operatorname{dist}(i,j)$, so nearby nodes get a smaller penalty than far nodes. The model still sees every node, but far nodes must overcome a structural cost.

```python
B_dist_w = -0.5 * D_w  # each extra hop subtracts 0.5 from the attention logit.
scores_bias_w, W_bias_w, H_bias_w = attention_w(X_w, B_dist_w)
print("distance bias from node 0:", B_dist_w[0])
print("biased weights from node 0:", np.round(W_bias_w[0], 3))
assert W_bias_w[0, 0] > W_bias_w[0, 2]
```
▶ What you'll see: node 0's self weight is larger than its far-node weight after the distance penalty.

```python
gap_plain_w = W_plain_w[0, 1] - W_plain_w[0, 2]
gap_bias_w = W_bias_w[0, 1] - W_bias_w[0, 2]
print("close-minus-far gap, plain:", round(float(gap_plain_w), 3))
print("close-minus-far gap, biased:", round(float(gap_bias_w), 3))
assert gap_bias_w > gap_plain_w
```
▶ What you'll see: the mass gap between the one-hop node and two-hop node increases.

```python
plt.figure(figsize=(5, 3))
x_w = np.arange(3)
plt.bar(x_w - 0.18, W_plain_w[0], width=0.36, label="plain", color="gray")
plt.bar(x_w + 0.18, W_bias_w[0], width=0.36, label="distance-biased", color="seagreen")
plt.xticks(x_w, ["to 0", "to 1", "to 2"])
plt.title("3: structural bias changes attention")
plt.ylabel("attention weight")
plt.legend()
plt.show()
```
▶ What you'll see: the biased bars lean more toward close nodes while keeping global support.

*Why it's done this way:* Adding bias before softmax is equivalent to changing the log-odds of attention. A penalty of −0.5 per hop multiplies that pair's unnormalized attention by $e^{-0.5}$ per hop, so distance changes probabilities without deleting far nodes entirely.

### 4. Degree encodings add local structural identity

Two nodes can have similar features but different roles. Degree is the simplest structural role: how many roads touch a node. Concatenating degree to the feature vector changes this toy graph from shape $3\times2$ to $3\times3$, and node 1 receives degree 2 because it is the middle of the path.

```python
deg_w = A_w.sum(axis=1)
X_deg_w = np.c_[X_w, deg_w]
print("degrees:", deg_w.astype(int))
print("encoded feature shape:", X_deg_w.shape)
assert X_deg_w.shape == (3, 3)
assert deg_w[1] == 2
```
▶ What you'll see: node 1 has degree 2 while endpoints have degree 1.

```python
plt.figure(figsize=(4.5, 3))
plt.imshow(X_deg_w, cmap="viridis", aspect="auto")
plt.colorbar(label="feature value")
plt.xticks([0, 1, 2], ["x0", "x1", "degree"])
plt.yticks(range(3), ["node 0", "node 1", "node 2"])
plt.title("4: degree becomes an extra feature")
plt.show()
```
▶ What you'll see: the added degree column highlights the middle node's special structural role.

*Why it's done this way:* Attention computes from node features, so structural facts must be represented as features or biases. Degree is cheap, permutation-invariant, and tells the model whether a node is a hub, endpoint, or middle-like node.

### 5. Laplacian positional encodings give graph coordinates

Shortest-path bias is pairwise, but nodes also benefit from their own graph-position coordinates. The normalized Laplacian $L=I-D^{-1/2}AD^{-1/2}$ has eigenvectors that vary smoothly over the graph. The smallest nonconstant eigenvectors act like graph Fourier coordinates: nearby connected nodes tend to have related values.

```python
def lap_posenc_w(A, k=2):
    deg = A.sum(axis=1)
    inv_sqrt = np.where(deg > 0, 1.0 / np.sqrt(deg), 0.0)
    L = np.eye(A.shape[0]) - (inv_sqrt[:, None] * A * inv_sqrt[None, :])
    vals, vecs = np.linalg.eigh(L)
    return vals, vecs[:, 1:1 + k]

vals_w, PE_w = lap_posenc_w(A_w, k=2)
print("Laplacian eigenvalues:", np.round(vals_w, 3))
print("positional encodings:\n", np.round(PE_w, 3))
assert np.allclose(np.round(vals_w, 3), [0.0, 1.0, 2.0])
```
▶ What you'll see: one zero eigenvalue plus two nonconstant graph-coordinate directions.

```python
plt.figure(figsize=(4.5, 3))
plt.plot(range(3), PE_w[:, 0], marker="o", label="PE 1")
plt.plot(range(3), PE_w[:, 1], marker="s", label="PE 2")
plt.axhline(0, color="black", linewidth=0.6)
plt.xticks(range(3))
plt.title("5: Laplacian positional encodings")
plt.xlabel("node id on the path")
plt.legend()
plt.show()
```
▶ What you'll see: eigenvector values give each node coordinates tied to path structure, not token order.

*Why it's done this way:* Laplacian eigenvectors solve a smoothness problem on the graph: changing rapidly across edges costs energy. Low-frequency eigenvectors therefore summarize coarse graph position, which helps attention distinguish nodes that otherwise share features.

### 6. A graph token reads out the whole graph

For graph-level prediction, many graph transformers add a learned graph token that attends to every node and becomes the readout. We implement a transparent version: a query vector attends to node keys, averages node values, and returns a graph embedding. With symmetric node features here, the readout is $[0.726,0.726]$.

```python
X_read_w = np.array([[1.0, 0.0], [0.9614, 0.9614], [0.0, 1.0]])  # symmetric features chosen for a readable readout.
graph_query_w = np.array([[1.0, 1.0]])
node_scores_w = graph_query_w @ X_read_w.T / np.sqrt(2)
graph_attn_w = softmax_w(node_scores_w)
graph_readout_w = graph_attn_w @ X_read_w
print("graph-token attention:", np.round(graph_attn_w[0], 3))
print("graph readout:", np.round(graph_readout_w[0], 3))
assert np.allclose(np.round(graph_readout_w[0], 3), [0.726, 0.726])
```
▶ What you'll see: the graph token gives most weight to the middle node and returns a two-number graph summary.

```python
plt.figure(figsize=(4.5, 3))
plt.bar(["node 0", "node 1", "node 2"], graph_attn_w[0], color="darkorange")
plt.ylim(0, 0.5)
plt.title("6: graph-token readout weights")
plt.ylabel("attention weight")
plt.show()
```
▶ What you'll see: the readout is a weighted pooling operation, not a simple unweighted average.

*Why it's done this way:* A graph token lets the same attention machinery produce graph-level embeddings. Instead of manually summing nodes, the model learns which nodes should dominate the summary for the task.

### ✍️ Toy 1 · Shortest-path distance is graph position

A graph transformer can bias attention with graph distance. On a 4-node path, repeated relaxation
turns immediate edges into all-pairs shortest-path coordinates.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)
t1_A = np.array([[0, 1, 0, 0],
                 [1, 0, 1, 0],
                 [0, 1, 0, 1],
                 [0, 0, 1, 0]], dtype=float)
print("adjacency:", t1_A.astype(int).tolist())  # -> [[0, 1, 0, 0], [1, 0, 1, 0], [0, 1, 0, 1], [0, 0, 1, 0]]
t1_D = np.where(t1_A > 0, 1.0, np.inf)
np.fill_diagonal(t1_D, 0.0)
t1_initial = np.where(np.isinf(t1_D), 99, t1_D).astype(int)
print("initial distances (99 = missing):", t1_initial.tolist())  # -> [[0, 1, 99, 99], [1, 0, 1, 99], [99, 1, 0, 1], [99, 99, 1, 0]]
for t1_k in range(t1_A.shape[0]):
    t1_D = np.minimum(t1_D, t1_D[:, [t1_k]] + t1_D[[t1_k], :])
print("final shortest-path distances:", t1_D.astype(int).tolist())  # -> [[0, 1, 2, 3], [1, 0, 1, 2], [2, 1, 0, 1], [3, 2, 1, 0]]
t1_far_hops = int(t1_D[0, 3])
print("0 to 3 hops:", t1_far_hops)  # -> 3
assert t1_far_hops == 3

plt.figure(figsize=(4.2, 3.2))
plt.imshow(t1_D, cmap="magma_r")
plt.colorbar(label="hops")
plt.xticks(range(4))
plt.yticks(range(4))
plt.title("Toy 1 · shortest-path coordinates")
plt.show()
```
▶ What you'll see: the path endpoints are three hops apart, so graph distance is not the same as row order.

### ✍️ Toy 2 · Global attention normalizes every node-to-node score

Vanilla self-attention compares every node feature vector with every other one. Softmax then turns
one score row into probabilities that sum to one, including nonzero mass on a non-neighbor.

```python
import numpy as np

t2_rng = np.random.default_rng(0)
t2_A = np.array([[0, 1, 0],
                 [1, 0, 1],
                 [0, 1, 0]], dtype=float)
t2_X = np.array([[1.0, 0.0],
                 [0.5, 0.5],
                 [0.0, 1.0]])
print("adjacency:", t2_A.astype(int).tolist())  # -> [[0, 1, 0], [1, 0, 1], [0, 1, 0]]
print("features:", t2_X.tolist())  # -> [[1.0, 0.0], [0.5, 0.5], [0.0, 1.0]]
t2_Q = t2_X.copy()
t2_K = t2_X.copy()
t2_V = t2_X.copy()
t2_scores = t2_Q @ t2_K.T / np.sqrt(t2_X.shape[1])
print("node 0 scores:", np.round(t2_scores[0], 3).tolist())  # -> [0.707, 0.354, 0.0]
t2_shifted = t2_scores[0] - np.max(t2_scores[0])
print("shifted scores:", np.round(t2_shifted, 3).tolist())  # -> [0.0, -0.354, -0.707]
t2_exp = np.exp(t2_shifted)
print("exp shifted:", np.round(t2_exp, 3).tolist())  # -> [1.0, 0.702, 0.493]
t2_weights0 = t2_exp / t2_exp.sum()
print("attention weights from node 0:", np.round(t2_weights0, 3).tolist())  # -> [0.456, 0.32, 0.225]
t2_all_exp = np.exp(t2_scores - np.max(t2_scores, axis=1, keepdims=True))
t2_W = t2_all_exp / t2_all_exp.sum(axis=1, keepdims=True)
t2_out = t2_W @ t2_V
print("node 0 output:", np.round(t2_out[0], 3).tolist())  # -> [0.615, 0.385]
assert abs(float(t2_weights0.sum()) - 1.0) < 1e-12
assert t2_weights0[2] > 0.0

plt.figure(figsize=(4.4, 2.8))
plt.bar(["to 0", "to 1", "to 2"], t2_weights0, color="steelblue")
plt.ylim(0, 0.55)
plt.ylabel("attention weight")
plt.title("Toy 2 · global attention from node 0")
plt.show()
```
▶ What you'll see: node 0 attends to all three nodes, even though node 2 is not adjacent in the graph.

### ✍️ Toy 3 · Distance bias prices far attention

A structural bias is added before softmax. Penalizing each hop by `0.75` leaves global support in
place but pushes probability away from far pairs.

```python
import numpy as np

t3_rng = np.random.default_rng(0)
t3_A = np.array([[0, 1, 0],
                 [1, 0, 1],
                 [0, 1, 0]], dtype=float)
t3_X = np.array([[1.0, 0.0],
                 [0.5, 0.5],
                 [0.0, 1.0]])
t3_D = np.where(t3_A > 0, 1.0, np.inf)
np.fill_diagonal(t3_D, 0.0)
for t3_k in range(t3_A.shape[0]):
    t3_D = np.minimum(t3_D, t3_D[:, [t3_k]] + t3_D[[t3_k], :])
print("distances:", t3_D.astype(int).tolist())  # -> [[0, 1, 2], [1, 0, 1], [2, 1, 0]]
t3_scores = t3_X @ t3_X.T / np.sqrt(t3_X.shape[1])
print("plain scores from node 0:", np.round(t3_scores[0], 3).tolist())  # -> [0.707, 0.354, 0.0]
t3_plain_exp = np.exp(t3_scores - np.max(t3_scores, axis=1, keepdims=True))
t3_plain_W = t3_plain_exp / t3_plain_exp.sum(axis=1, keepdims=True)
print("plain weights from node 0:", np.round(t3_plain_W[0], 3).tolist())  # -> [0.456, 0.32, 0.225]
t3_bias = -0.75 * t3_D
print("distance bias from node 0:", np.round(t3_bias[0], 3).tolist())  # -> [-0.0, -0.75, -1.5]
t3_biased_scores = t3_scores + t3_bias
t3_biased_exp = np.exp(t3_biased_scores - np.max(t3_biased_scores, axis=1, keepdims=True))
t3_biased_W = t3_biased_exp / t3_biased_exp.sum(axis=1, keepdims=True)
print("biased weights from node 0:", np.round(t3_biased_W[0], 3).tolist())  # -> [0.694, 0.23, 0.076]
t3_plain_gap = float(t3_plain_W[0, 1] - t3_plain_W[0, 2])
t3_biased_gap = float(t3_biased_W[0, 1] - t3_biased_W[0, 2])
print("close-minus-far gap plain:", round(t3_plain_gap, 3))  # -> 0.095
print("close-minus-far gap biased:", round(t3_biased_gap, 3))  # -> 0.154
assert t3_biased_W[0, 2] < t3_plain_W[0, 2]
assert t3_biased_gap > t3_plain_gap

plt.figure(figsize=(4.8, 2.8))
t3_x = np.arange(3)
plt.bar(t3_x - 0.18, t3_plain_W[0], width=0.36, label="plain", color="gray")
plt.bar(t3_x + 0.18, t3_biased_W[0], width=0.36, label="biased", color="seagreen")
plt.xticks(t3_x, ["to 0", "to 1", "to 2"])
plt.ylabel("attention weight")
plt.title("Toy 3 · hop penalty changes softmax")
plt.legend()
plt.show()
```
▶ What you'll see: the two-hop node keeps a nonzero weight, but its bar shrinks after the distance penalty.

### ✍️ Toy 5 · Laplacian eigenvectors give graph coordinates

The Laplacian turns graph smoothness into linear algebra. The Fiedler vector is the lowest-energy
nonconstant coordinate, so its signs locate opposite ends of the path.

```python
import numpy as np

t5_rng = np.random.default_rng(0)
t5_A = np.array([[0, 1, 0],
                 [1, 0, 1],
                 [0, 1, 0]], dtype=float)
print("adjacency:", t5_A.astype(int).tolist())  # -> [[0, 1, 0], [1, 0, 1], [0, 1, 0]]
t5_deg = t5_A.sum(axis=1)
print("degrees:", t5_deg.astype(int).tolist())  # -> [1, 2, 1]
t5_L = np.diag(t5_deg) - t5_A
print("Laplacian:", t5_L.astype(int).tolist())  # -> [[1, -1, 0], [-1, 2, -1], [0, -1, 1]]
t5_evals, t5_evecs = np.linalg.eigh(t5_L)
print("eigenvalues:", np.round(t5_evals, 3).tolist())  # -> [0.0, 1.0, 3.0]
t5_fiedler = t5_evecs[:, 1]
if t5_fiedler[0] > 0:
    t5_fiedler = -t5_fiedler
print("Fiedler vector:", np.round(t5_fiedler, 3).tolist())  # -> [-0.707, 0.0, 0.707]
t5_sign_labels = (t5_fiedler >= 0).astype(int)
print("sign labels:", t5_sign_labels.tolist())  # -> [0, 1, 1]
assert np.allclose(np.round(t5_evals, 3), [0.0, 1.0, 3.0])
assert t5_sign_labels[0] != t5_sign_labels[2]

plt.figure(figsize=(4.4, 2.8))
plt.plot(range(3), t5_fiedler, marker="o", color="crimson")
plt.axhline(0, color="black", linewidth=0.7)
plt.xticks(range(3))
plt.xlabel("node on path")
plt.ylabel("Fiedler coordinate")
plt.title("Toy 5 · one graph-coordinate axis")
plt.show()
```
▶ What you'll see: the coordinate moves smoothly from one endpoint through the middle to the other endpoint.

### ✍️ Toy 6 · A graph token is learned weighted pooling

A graph token uses its query to score all node keys. The weighted sum of node values becomes a
small graph-level readout vector.

```python
import numpy as np

t6_rng = np.random.default_rng(0)
t6_X = np.array([[1.0, 0.0],
                 [0.6, 0.6],
                 [0.0, 1.0]])
t6_query = np.array([[1.0, 1.0]])
print("node values:", t6_X.tolist())  # -> [[1.0, 0.0], [0.6, 0.6], [0.0, 1.0]]
print("graph query:", t6_query.tolist())  # -> [[1.0, 1.0]]
t6_scores = t6_query @ t6_X.T / np.sqrt(t6_X.shape[1])
print("graph-token scores:", np.round(t6_scores[0], 3).tolist())  # -> [0.707, 0.849, 0.707]
t6_exp = np.exp(t6_scores - np.max(t6_scores, axis=1, keepdims=True))
t6_attn = t6_exp / t6_exp.sum(axis=1, keepdims=True)
print("graph-token attention:", np.round(t6_attn[0], 3).tolist())  # -> [0.317, 0.365, 0.317]
t6_readout = t6_attn @ t6_X
print("graph readout:", np.round(t6_readout[0], 3).tolist())  # -> [0.537, 0.537]
assert np.allclose(np.round(t6_readout[0], 3), [0.537, 0.537])
assert abs(float(t6_attn.sum()) - 1.0) < 1e-12
```

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, graph matrices, eigendecompositions, and attention math.
import matplotlib.pyplot as plt # load Matplotlib for the heatmaps, bars, curves, and scatter plots used below.
np.random.seed(0) # make every random example reproducible.

def softmax(z): # define row-wise stable softmax for attention weights.
    z = np.asarray(z, dtype=float) # convert input to floats so exponentials are predictable.
    z = z - np.max(z, axis=-1, keepdims=True) # subtract each row maximum for numerical stability.
    e = np.exp(z) # exponentiate stabilized logits.
    return e / e.sum(axis=-1, keepdims=True) # normalize each row so weights sum to one.

def shortest_paths(A): # compute all-pairs shortest-path distances for a small unweighted graph.
    A = np.asarray(A, dtype=float) # convert adjacency to floats for infinity arithmetic.
    n = A.shape[0] # read the node count.
    D = np.where(A > 0, 1.0, np.inf) # initialize edge distances and non-edge infinities.
    np.fill_diagonal(D, 0.0) # set self-distance to zero.
    for k in range(n): # allow each node to be an intermediate stop.
        D = np.minimum(D, D[:, [k]] + D[[k], :]) # relax paths through k.
    return D # return the distance matrix.

def graph_attention(X, bias=None): # implement single-head graph-biased attention with identity projections.
    X = np.asarray(X, dtype=float) # ensure node features are floats.
    scores = X @ X.T / np.sqrt(X.shape[1]) # compute QK^T/sqrt(d) with Q=K=X.
    if bias is not None: # optionally add structural bias before softmax.
        scores = scores + bias # add graph-distance or other structural logits.
    W = softmax(scores) # convert logits into attention weights.
    return scores, W, W @ X # return logits, weights, and weighted node features.

def laplacian_positional_encoding(A, k=2): # compute normalized-Laplian eigenvector positions.
    A = np.asarray(A, dtype=float) # convert adjacency to floats.
    deg = A.sum(axis=1) # compute node degrees.
    inv_sqrt = np.where(deg > 0, 1.0 / np.sqrt(deg), 0.0) # compute D^{-1/2}, with zero for isolated nodes.
    L = np.eye(A.shape[0]) - inv_sqrt[:, None] * A * inv_sqrt[None, :] # normalized Laplacian.
    vals, vecs = np.linalg.eigh(L) # eigendecompose symmetric L.
    return vals, vecs[:, 1:1 + k] # skip the constant first eigenvector and return k coordinates.
```
