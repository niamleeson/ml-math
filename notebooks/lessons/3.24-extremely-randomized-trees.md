# 3.24 — Extremely Randomized Trees

Extremely Randomized Trees (Extra Trees) are decision-tree ensembles that deliberately inject randomness into split thresholds. Instead of searching every possible cut like a standard tree, each tree samples candidate features and random thresholds, keeps the candidate with the best impurity gain, and then the forest averages many decorrelated trees so unstable single-tree choices become a stable prediction.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build Extremely Randomized Trees one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math is small enough to inspect by hand. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, random sampling, and small numerical checks.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for the sampled thresholds.
```

### 1. Impurity: what a split is trying to reduce

For regression trees, impurity is usually the mean squared deviation from a node's own average target value. A node is pure when its targets are nearly equal, because one constant prediction explains them well. A split is useful only if the two child nodes have lower weighted impurity than the parent.

```python
x_w = np.array([0.05, 0.12, 0.20, 0.35, 0.52, 0.68, 0.80, 0.95])  # one feature.
y_w = np.array([1.0, 1.2, 1.1, 1.4, 3.7, 3.9, 4.2, 4.0])  # target jumps near x=0.5.
parent_mean_w = np.mean(y_w)  # the one-number prediction before any split.
parent_imp_w = np.mean((y_w - parent_mean_w) ** 2)  # MSE impurity inside the parent node.
print("parent mean:", round(parent_mean_w, 3))
print("parent impurity:", round(parent_imp_w, 3))
assert round(parent_imp_w, 3) == 1.952
```
▶ What you'll see: the unsplit node has high impurity because low targets near 1 and high targets near 4 are forced into one average.

```python
s_w = 0.50  # try a threshold between the low and high groups.
left_w = y_w[x_w <= s_w]  # child targets sent left.
right_w = y_w[x_w > s_w]  # child targets sent right.
left_imp_w = np.mean((left_w - np.mean(left_w)) ** 2)  # left-child MSE impurity.
right_imp_w = np.mean((right_w - np.mean(right_w)) ** 2)  # right-child MSE impurity.
weighted_child_w = (len(left_w) * left_imp_w + len(right_w) * right_imp_w) / len(y_w)  # weighted child impurity.
gain_w = parent_imp_w - weighted_child_w  # impurity decrease from this threshold.
print("left/right means:", round(np.mean(left_w), 3), round(np.mean(right_w), 3))
print("weighted child impurity:", round(weighted_child_w, 3))
print("gain:", round(gain_w, 3))
assert round(gain_w, 3) == 1.925
```
▶ What you'll see: the threshold near 0.5 almost separates the two target levels, so the gain is almost the whole parent impurity.

```python
plt.figure(figsize=(4.6, 3))
plt.scatter(x_w, y_w, color="black")
plt.axvline(s_w, color="crimson", linestyle="--", label="threshold")
plt.hlines([np.mean(left_w), np.mean(right_w)], [x_w.min(), s_w], [s_w, x_w.max()], colors="seagreen", linewidth=3, label="child means")
plt.title("1: a split lowers within-child variation")
plt.xlabel("feature x"); plt.ylabel("target y"); plt.legend(); plt.show()
```
▶ What you'll see: two green horizontal predictions fit the data much better than one global average.

*Why it's done this way:* A regression tree predicts a constant inside each leaf, so the mathematically correct split score is the drop in squared error from replacing one constant by two constants. The child impurities are weighted by child sizes because a low-error split on one example should not dominate the error on many examples.

### 2. Extra random thresholds instead of exhaustive thresholds

A standard tree tests many legal thresholds and chooses the best. Extra Trees sample thresholds uniformly inside the feature range, then score only those candidates. This is the defining extra randomness: the tree can only optimize among thresholds it happened to draw.

```python
candidates_w = np.array([0.18, 0.33, 0.50, 0.74])  # fixed random-looking thresholds for inspection.
gains_w = []  # store the impurity gain for each candidate.
for s2_w in candidates_w:
    left_mask_w = x_w <= s2_w
    right_mask_w = ~left_mask_w
    child_w = (np.sum(left_mask_w) * np.mean((y_w[left_mask_w] - np.mean(y_w[left_mask_w])) ** 2) +
               np.sum(right_mask_w) * np.mean((y_w[right_mask_w] - np.mean(y_w[right_mask_w])) ** 2)) / len(y_w)
    gains_w.append(parent_imp_w - child_w)
gains_w = np.array(gains_w)
print("candidate thresholds:", candidates_w)
print("candidate gains:", np.round(gains_w, 3))
assert round(float(gains_w[2]), 3) == 1.925
```
▶ What you'll see: only the sampled threshold near the true jump receives the large impurity gain.

```python
best_idx_w = int(np.argmax(gains_w))  # choose the best sampled threshold, not the best possible threshold.
best_s_w = candidates_w[best_idx_w]
print("best sampled threshold:", best_s_w)
print("best sampled gain:", round(float(gains_w[best_idx_w]), 3))
```
▶ What you'll see: the selected split is the best of a small random menu.

```python
plt.figure(figsize=(5, 3))
plt.bar([str(v) for v in candidates_w], gains_w, color="steelblue")
plt.axhline(0, color="black", linewidth=0.7)
plt.title("2: random threshold candidates and gains")
plt.xlabel("sampled threshold"); plt.ylabel("impurity gain"); plt.show()
```
▶ What you'll see: the bar chart makes the random search menu visible; Extra Trees optimize inside that menu only.

*Why it's done this way:* Random thresholds deliberately add bias to each individual tree, but they greatly reduce correlation between trees. In an ensemble, many slightly biased but different trees can average to a lower-variance predictor than many nearly identical greedily optimized trees.

### 3. Random candidate pairs \((j,s)\): feature plus threshold

With multiple features, Extra Trees sample candidate pairs: a feature index \(j\) and a threshold \(s\) drawn inside that feature's observed range. The chosen split is the random candidate that maximizes impurity gain, \(\Delta(j,s)\).

```python
X_w = np.column_stack([x_w, np.array([0.90, 0.15, 0.85, 0.10, 0.70, 0.30, 0.65, 0.25])])  # feature 0 is strong; feature 1 is weaker/noisier.
pairs_w = [(0, 0.50), (0, 0.30), (1, 0.50), (1, 0.75)]  # sampled (feature, threshold) candidates.
print("X shape:", X_w.shape)
print("candidate (feature, threshold) pairs:", pairs_w)
```
▶ What you'll see: each candidate tells the tree which feature to cut and where to cut it.

```python
def gain_for_pair_w(X, y, feature, threshold):  # compute regression impurity gain for one candidate pair.
    parent = np.mean((y - np.mean(y)) ** 2)
    left = X[:, feature] <= threshold
    right = ~left
    if np.sum(left) == 0 or np.sum(right) == 0:
        return 0.0
    l_imp = np.mean((y[left] - np.mean(y[left])) ** 2)
    r_imp = np.mean((y[right] - np.mean(y[right])) ** 2)
    child = (np.sum(left) * l_imp + np.sum(right) * r_imp) / len(y)
    return float(parent - child)

pair_gains_w = np.array([gain_for_pair_w(X_w, y_w, j_w, t_w) for j_w, t_w in pairs_w])
print("pair gains:", np.round(pair_gains_w, 3))
assert round(float(pair_gains_w[0]), 3) == 1.925
```
▶ What you'll see: the good feature-threshold pair wins because it creates the cleanest child means.

```python
winner_w = int(np.argmax(pair_gains_w))
print("chosen pair:", pairs_w[winner_w])
plt.figure(figsize=(5, 3))
plt.bar([f"x{j}≤{t}" for j, t in pairs_w], pair_gains_w, color="darkorange")
plt.title("3: choose the best random (j, s)")
plt.ylabel("gain Δ(j,s)"); plt.xticks(rotation=20); plt.show()
```
▶ What you'll see: Extra Trees still use the impurity formula, but the search space is a random subset.

*Why it's done this way:* Sampling both feature and threshold prevents every tree from repeatedly selecting the same dominant split. The gain calculation keeps each random choice honest: randomness proposes candidates, but impurity reduction decides which candidate enters the tree.

### 4. Averaging randomized trees reduces variance

One randomized tree can make a rough prediction because its thresholds were partly luck. A forest averages many such trees. If their errors are not perfectly correlated, averaging cancels a large part of the random fluctuation.

```python
query_w = np.linspace(0, 1, 80)  # x-locations where we will compare tree predictions.
true_curve_w = np.where(query_w <= 0.5, 1.2, 4.0)  # the ideal piecewise-constant target.
thresholds_w = np.array([0.42, 0.47, 0.53, 0.61, 0.49])  # five different random tree thresholds.
print("tree thresholds:", thresholds_w)
```
▶ What you'll see: each tree puts the jump in a slightly different place.

```python
tree_preds_w = []
for thr_w in thresholds_w:
    l_mean_w = np.mean(y_w[x_w <= thr_w])
    r_mean_w = np.mean(y_w[x_w > thr_w])
    tree_preds_w.append(np.where(query_w <= thr_w, l_mean_w, r_mean_w))
tree_preds_w = np.array(tree_preds_w)
forest_pred_w = np.mean(tree_preds_w, axis=0)
print("single tree at x≈0.5:", round(float(tree_preds_w[0, 40]), 3))
print("forest at x≈0.5:", round(float(forest_pred_w[40]), 3))
```
▶ What you'll see: individual trees disagree near the split boundary, while the forest smooths their disagreement.

```python
single_mse_w = np.mean((tree_preds_w[0] - true_curve_w) ** 2)
forest_mse_w = np.mean((forest_pred_w - true_curve_w) ** 2)
print("single-tree MSE:", round(single_mse_w, 3))
print("forest MSE:", round(forest_mse_w, 3))
assert forest_mse_w < single_mse_w
plt.figure(figsize=(5.4, 3))
for k_w in range(tree_preds_w.shape[0]):
    plt.plot(query_w, tree_preds_w[k_w], color="gray", alpha=0.35)
plt.plot(query_w, forest_pred_w, color="crimson", linewidth=3, label="forest average")
plt.plot(query_w, true_curve_w, color="black", linestyle="--", label="true pattern")
plt.title("4: averaging decorrelated random trees")
plt.xlabel("x"); plt.ylabel("prediction"); plt.legend(); plt.show()
```
▶ What you'll see: gray individual trees vary, but the red average is steadier and closer to the dashed target.

*Why it's done this way:* Variance reduction is the ensemble bargain. If each tree's random threshold error points in a different direction, the average error shrinks roughly with the number of independent trees; if trees are identical, averaging does nothing. Extra randomness is useful because it makes the trees less identical.

### 5. Model selection: raw fit, cost, gap, and stability

The lesson's content frames Extra Trees inside empirical risk and validation. We do not choose a model from raw training fit alone. We compute the average loss, add the method's cost or complexity guardrail, compare alternatives on the same scale, and prefer a stable score only when the gap is meaningful.

```python
losses_w = np.array([0.246, 0.148, 0.505])  # verified toy losses from the lesson content.
R_S_w = np.mean(losses_w)  # empirical risk: average loss over examples.
cost_w = 0.050  # complexity/regularization/operational cost for this setting.
score_w = R_S_w + cost_w  # decision score, not just raw fit.
print("empirical risk:", round(R_S_w, 3))
print("score with cost:", round(score_w, 3))
assert round(R_S_w, 3) == 0.300
assert round(score_w, 3) == 0.350
```
▶ What you'll see: the raw average is 0.300, but the decision score is 0.350 after the cost is included.

```python
alternative_w = 0.402  # a more flexible alternative's decision score.
gap_w = alternative_w - score_w
relative_gap_w = gap_w / alternative_w
stable_w = 0.80 * score_w
print("gap:", round(gap_w, 3))
print("relative gap:", round(relative_gap_w, 3))
print("stabilized score:", round(stable_w, 3))
assert round(gap_w, 3) == 0.052
assert round(stable_w, 3) == 0.280
```
▶ What you'll see: the stabilized score is lower than both the baseline and the tempting flexible alternative.

```python
scores_w = np.array([score_w, alternative_w, stable_w])
labels_w = ["baseline", "flexible", "stabilized"]
print("winner:", labels_w[int(np.argmin(scores_w))])
plt.figure(figsize=(5, 3))
plt.bar(labels_w, scores_w, color=["steelblue", "gray", "seagreen"])
plt.title("5: compare full decision scores")
plt.ylabel("lower is better"); plt.show()
```
▶ What you'll see: the green stabilized bar is the lowest, so it is the model to carry forward in this toy decision.

*Why it's done this way:* Empirical risk is only the fit term. Extra Trees can be very flexible, so the honest unit of comparison is the full decision score after costs, uncertainty, or validation gaps are included. The same arithmetic protects us from mistaking a lucky random split for durable structure.

## 🟢 Basics (warm-up)

### Basic 1 — Measure parent impurity

**Goal.** Compute the variance-like impurity of one node, because a regression tree split is valuable only if it reduces this quantity. We build it in 2 steps.

```python
y_b1 = np.array([1.0, 1.2, 1.1, 1.4, 3.7, 3.9, 4.2, 4.0])  # Store targets inside one unsplit node.
mean_b1 = np.mean(y_b1)  # Compute the constant prediction used by the parent node.
print("parent mean:", round(mean_b1, 3))  # Inspect the one-number prediction before splitting.
```
▶ What you'll see: the parent prediction is the average of low and high target groups.

```python
impurity_b1 = np.mean((y_b1 - mean_b1) ** 2)  # Compute mean squared deviation from the node mean.
print("parent impurity:", round(impurity_b1, 3))  # Inspect the node's squared-error impurity.
assert round(impurity_b1, 3) == 1.952  # Verify the canonical impurity for this toy node.
plt.figure(figsize=(4, 3))
plt.scatter(np.arange(len(y_b1)), y_b1, color="black")
plt.axhline(mean_b1, color="crimson", linestyle="--")
plt.title("Basic 1: parent node impurity")
plt.ylabel("target"); plt.show()
```
▶ What you'll see: points far from the red mean create high impurity.

👀 Takeaway: impurity is the training loss a node pays when it predicts one constant for all examples.

### Basic 2 — Split a node with one threshold

**Goal.** Send examples left or right with a threshold, because trees make local decisions of the form `feature <= threshold`. We build it in 2 steps.

```python
x_b2 = np.array([0.05, 0.12, 0.20, 0.35, 0.52, 0.68, 0.80, 0.95])  # One feature used for splitting.
y_b2 = np.array([1.0, 1.2, 1.1, 1.4, 3.7, 3.9, 4.2, 4.0])  # Targets paired with the feature.
threshold_b2 = 0.50  # Choose a threshold near the visible jump.
left_b2 = x_b2 <= threshold_b2  # Mark examples routed to the left child.
print("left count:", int(np.sum(left_b2)), "right count:", int(np.sum(~left_b2)))  # Inspect child sizes.
```
▶ What you'll see: the threshold divides the data into four low-x and four high-x examples.

```python
plt.figure(figsize=(4, 3))
plt.scatter(x_b2[left_b2], y_b2[left_b2], color="seagreen", label="left")
plt.scatter(x_b2[~left_b2], y_b2[~left_b2], color="darkorange", label="right")
plt.axvline(threshold_b2, color="black", linestyle="--")
plt.title("Basic 2: threshold routing")
plt.xlabel("x"); plt.ylabel("y"); plt.legend(); plt.show()
```
▶ What you'll see: examples on each side of the dashed line form much more homogeneous target groups.

👀 Takeaway: a tree split is a simple routing rule that creates two smaller prediction problems.

### Basic 3 — Compute impurity gain

**Goal.** Compare parent impurity with weighted child impurity, because Extra Trees still choose among random candidates by impurity gain. We build it in 3 steps.

```python
x_b3 = np.array([0.05, 0.12, 0.20, 0.35, 0.52, 0.68, 0.80, 0.95])  # Feature values.
y_b3 = np.array([1.0, 1.2, 1.1, 1.4, 3.7, 3.9, 4.2, 4.0])  # Regression targets.
s_b3 = 0.50  # Candidate split threshold.
parent_b3 = np.mean((y_b3 - np.mean(y_b3)) ** 2)  # Parent impurity before splitting.
print("parent impurity:", round(parent_b3, 3))  # Inspect the baseline loss.
```
▶ What you'll see: the unsplit node has the same high impurity as Basic 1.

```python
left_b3 = x_b3 <= s_b3  # Route examples left.
left_imp_b3 = np.mean((y_b3[left_b3] - np.mean(y_b3[left_b3])) ** 2)  # Left child impurity.
right_imp_b3 = np.mean((y_b3[~left_b3] - np.mean(y_b3[~left_b3])) ** 2)  # Right child impurity.
child_b3 = (np.sum(left_b3) * left_imp_b3 + np.sum(~left_b3) * right_imp_b3) / len(y_b3)  # Size-weighted child impurity.
print("child impurity:", round(child_b3, 3))  # Inspect post-split loss.
```

```python
gain_b3 = parent_b3 - child_b3  # Impurity decrease from this threshold.
print("gain:", round(gain_b3, 3))  # Inspect how much squared error the split removes.
assert round(gain_b3, 3) == 1.925  # Verify the split nearly removes all parent impurity.
plt.figure(figsize=(4, 3))
plt.bar(["parent", "children"], [parent_b3, child_b3], color=["gray", "seagreen"])
plt.title("Basic 3: impurity reduction")
plt.ylabel("MSE impurity"); plt.show()
```
▶ What you'll see: the weighted child impurity is tiny compared with the parent impurity.

👀 Takeaway: gain is the amount of training loss removed by a proposed split.

### Basic 4 — Sample random thresholds

**Goal.** Draw possible thresholds uniformly from the feature range, because Extra Trees randomize threshold proposals instead of testing every midpoint. We build it in 2 steps.

```python
x_b4 = np.array([0.05, 0.12, 0.20, 0.35, 0.52, 0.68, 0.80, 0.95])  # Feature values that define the legal threshold range.
rng_b4 = np.random.default_rng(4)  # Use a local generator so the example is repeatable.
thresholds_b4 = rng_b4.uniform(np.min(x_b4), np.max(x_b4), size=5)  # Sample five random thresholds inside the feature range.
print("thresholds:", np.round(thresholds_b4, 3))  # Inspect the random candidate menu.
```
▶ What you'll see: the tree receives a small set of random thresholds to score.

```python
plt.figure(figsize=(4, 3))
plt.scatter(x_b4, np.zeros_like(x_b4), color="black", label="data")
plt.scatter(thresholds_b4, np.ones_like(thresholds_b4), color="crimson", label="sampled thresholds")
plt.yticks([0, 1], ["data x", "candidates"])

plt.xlabel("feature value"); plt.legend(); plt.show()
```
▶ What you'll see: candidate thresholds can land anywhere in the feature interval, not only between sorted samples.

👀 Takeaway: Extra Trees inject randomness before scoring, by limiting the threshold choices a tree can consider.

### Basic 5 — Score a random threshold menu

**Goal.** Evaluate several sampled thresholds and keep the one with the largest gain, because randomness proposes but impurity still disposes. We build it in 3 steps.

```python
x_b5 = np.array([0.05, 0.12, 0.20, 0.35, 0.52, 0.68, 0.80, 0.95])  # Feature values.
y_b5 = np.array([1.0, 1.2, 1.1, 1.4, 3.7, 3.9, 4.2, 4.0])  # Targets.
thresholds_b5 = np.array([0.18, 0.33, 0.50, 0.74])  # Candidate thresholds from a random menu.
parent_b5 = np.mean((y_b5 - np.mean(y_b5)) ** 2)  # Parent impurity used by all candidates.
print("candidates:", thresholds_b5)  # Inspect the menu.
```
▶ What you'll see: a small list of possible cut points.

```python
gains_b5 = []  # Store one gain per threshold.
for s_b5 in thresholds_b5:
    mask_b5 = x_b5 <= s_b5
    child_b5 = (np.sum(mask_b5) * np.mean((y_b5[mask_b5] - np.mean(y_b5[mask_b5])) ** 2) + np.sum(~mask_b5) * np.mean((y_b5[~mask_b5] - np.mean(y_b5[~mask_b5])) ** 2)) / len(y_b5)
    gains_b5.append(parent_b5 - child_b5)
gains_b5 = np.array(gains_b5)
print("gains:", np.round(gains_b5, 3))
```

```python
best_b5 = int(np.argmax(gains_b5))  # Find the best threshold inside the sampled menu.
print("chosen threshold:", thresholds_b5[best_b5], "gain:", round(float(gains_b5[best_b5]), 3))
assert thresholds_b5[best_b5] == 0.50  # Verify the best candidate is the near-boundary split.
plt.figure(figsize=(4, 3))
plt.bar([str(v) for v in thresholds_b5], gains_b5, color="steelblue")
plt.title("Basic 5: gain for sampled thresholds")
plt.xlabel("threshold"); plt.ylabel("gain"); plt.show()
```
▶ What you'll see: the threshold near the target jump has the tallest gain bar.

👀 Takeaway: Extra Trees are random in candidate generation, not random in the final gain comparison.

### Basic 7 — Choose a random feature-threshold pair

**Goal.** Score candidate \((j,s)\) pairs, because the core Extra Trees split rule is to maximize gain over random feature-threshold candidates. We build it in 3 steps.

```python
print("pairs:", pairs_b7)  # Inspect candidate split rules.
```

▶ What you'll see: the best random pair is selected by the largest impurity drop.

```python
    thresholds_a4 = rng_a4.uniform(np.min(x_a4), np.max(x_a4), size=count_a4)
    gains_a4 = []
    for s_a4 in thresholds_a4:
        m_a4 = x_a4 <= s_a4
        if np.sum(m_a4) == 0 or np.sum(~m_a4) == 0:
            gains_a4.append(-1.0)
        else:
            parent_a4 = np.mean((y_a4 - np.mean(y_a4)) ** 2)
            child_a4 = (np.sum(m_a4) * np.mean((y_a4[m_a4] - np.mean(y_a4[m_a4])) ** 2) + np.sum(~m_a4) * np.mean((y_a4[~m_a4] - np.mean(y_a4[~m_a4])) ** 2)) / len(y_a4)
            gains_a4.append(parent_a4 - child_a4)
    best_s_a4 = thresholds_a4[int(np.argmax(gains_a4))]
    lm_a4 = np.mean(y_a4[x_a4 <= best_s_a4])
    rm_a4 = np.mean(y_a4[x_a4 > best_s_a4])
    pred_val_a4 = np.where(x_val_a4 <= best_s_a4, lm_a4, rm_a4)
    val_mse_a4.append(np.mean((pred_val_a4 - y_val_a4) ** 2))
val_mse_a4 = np.array(val_mse_a4)
print("validation MSE:", np.round(val_mse_a4, 3))
```

```python
best_count_a4 = int(counts_a4[np.argmin(val_mse_a4)])
print("best count by validation:", best_count_a4)
assert best_count_a4 in counts_a4
```

```python
plt.xscale("log", base=2)
plt.title("Advanced 4: validation chooses randomness level")
plt.xlabel("candidate thresholds"); plt.ylabel("validation MSE"); plt.show()
```

👀 Takeaway: the amount of Extra Trees randomness is a hyperparameter that should be judged on held-out performance.

### Advanced 5 — Stability decision with repeated random forests

**Goal.** Run repeated randomized forests and compare their score spread, because stability means the result survives different random seeds rather than winning once by luck. We build it in 4 steps.

```python
x_a5 = np.array([0.05, 0.12, 0.20, 0.35, 0.52, 0.68, 0.80, 0.95])  # Training feature.
y_a5 = np.array([1.0, 1.2, 1.1, 1.4, 3.7, 3.9, 4.2, 4.0])  # Training target.
grid_a5 = np.linspace(0, 1, 80)  # Future points to score.
truth_a5 = np.where(grid_a5 <= 0.5, 1.2, 4.0)  # Future target pattern.
print("repeats:", 12)
```
▶ What you'll see: we will evaluate many forests generated by different seeds.

```python
mse_scores_a5 = []
for seed_a5 in range(12):
    rng_a5 = np.random.default_rng(seed_a5)
    thresholds_a5 = rng_a5.uniform(np.min(x_a5), np.max(x_a5), size=15)
    curves_a5 = []
    for t_a5 in thresholds_a5:
        m_a5 = x_a5 <= t_a5
        if np.sum(m_a5) == 0 or np.sum(~m_a5) == 0:
            curves_a5.append(np.full_like(grid_a5, np.mean(y_a5)))
        else:
            curves_a5.append(np.where(grid_a5 <= t_a5, np.mean(y_a5[m_a5]), np.mean(y_a5[~m_a5])))
    forest_a5 = np.mean(np.array(curves_a5), axis=0)
    mse_scores_a5.append(np.mean((forest_a5 - truth_a5) ** 2))
mse_scores_a5 = np.array(mse_scores_a5)
print("MSE scores:", np.round(mse_scores_a5, 3))
```

```python
mean_score_a5 = np.mean(mse_scores_a5)
spread_a5 = np.std(mse_scores_a5)
final_score_a5 = mean_score_a5 + spread_a5  # Penalize unstable repeated outcomes.
print("mean:", round(float(mean_score_a5), 3), "std:", round(float(spread_a5), 3), "mean+std:", round(float(final_score_a5), 3))
assert spread_a5 > 0
```

```python
plt.figure(figsize=(5, 3))
plt.hist(mse_scores_a5, bins=6, color="seagreen", edgecolor="black")
plt.axvline(mean_score_a5, color="crimson", linestyle="--", label="mean")
plt.title("Advanced 5: repeated-forest score stability")
plt.xlabel("future MSE"); plt.ylabel("count"); plt.legend(); plt.show()
```
▶ What you'll see: repeated random forests produce a distribution of scores, not one guaranteed number.

👀 Takeaway: Extra Trees should be evaluated with validation and repeated randomness checks when the decision gap is small.
