# 22.8 — Automated Planning (STRIPS/PDDL)

Automated planning asks an agent to reach a goal by choosing actions whose logical requirements and consequences are known. In this lesson, a state is a set of facts, an action has preconditions plus add/delete effects, and search turns those pieces into a plan.

## 📖 Concept walkthrough — build each idea from scratch

Before the worked examples, we build STRIPS planning one idea at a time. Run each cell in order and read the printed intermediate values: every state is a `frozenset`, every action is plain Python data, and every transition is visualized.

```python
import numpy as np  # arrays for tables, simple heuristics, and visualization coordinates.
import matplotlib.pyplot as plt  # all lesson visualizations.
from collections import deque  # FIFO frontier for breadth-first search.
np.random.seed(0)  # keep tiny layout choices reproducible.
```

### 1. States are sets of facts, not coordinates

A classical planner does not need a grid cell or a neural embedding. It needs a list of facts that are true right now, such as `AtA` or `RoadAB`. Using a set matters because the order of facts is irrelevant: `{AtA, RoadAB}` and `{RoadAB, AtA}` describe the same world.

```python
S_w1 = frozenset(["AtA", "RoadAB"])  # the current world: robot at A and the A-B road exists.
S_same_w1 = frozenset(["RoadAB", "AtA"])  # the same facts in a different order.
print("state:", sorted(S_w1))  # inspect the canonical readable ordering.
print("same state despite order?", S_w1 == S_same_w1)  # sets ignore order.
assert S_w1 == S_same_w1  # verify the representation is order-invariant.

facts_w1 = ["AtA", "AtB", "RoadAB", "RoadBC"]  # a small fact universe for visualization.
values_w1 = np.array([1 if f in S_w1 else 0 for f in facts_w1])  # 1 means true in the state.
plt.figure(figsize=(5, 2.6))  # create a compact fact-vector plot.
plt.imshow(values_w1[None, :], cmap="Greens", vmin=0, vmax=1, aspect="auto")  # show true facts as filled cells.
plt.xticks(range(len(facts_w1)), facts_w1, rotation=25)  # label each possible fact.
plt.yticks([0], ["S"])  # label the single state row.
plt.title("1: a STRIPS state as a set of true facts")  # title the visualization.
plt.colorbar(label="truth value")  # add a 0/1 legend.
plt.show()  # display the fact-set heatmap.
```
▶ What you'll see: only `AtA` and `RoadAB` are true, and changing fact order does not create a new state.

*Why it's done this way:* set states make equality, goal tests, and precondition checks simple subset operations instead of fragile string or list comparisons.

### 2. A STRIPS action has preconditions, add effects, and delete effects

An action schema says three things: what must already be true, what becomes true, and what stops being true. For `MoveAB`, the robot must be at A and the road must exist; after moving, `AtB` becomes true and `AtA` becomes false.

```python
move_ab_w2 = {"name": "MoveAB", "pre": frozenset(["AtA", "RoadAB"]), "add": frozenset(["AtB"]), "delete": frozenset(["AtA"])}  # one STRIPS operator.
print("action:", move_ab_w2["name"])  # inspect the operator name.
print("pre/add/delete:", sorted(move_ab_w2["pre"]), sorted(move_ab_w2["add"]), sorted(move_ab_w2["delete"]))  # inspect its lists.
assert "AtA" in move_ab_w2["pre"] and "AtA" in move_ab_w2["delete"]  # the old location must be removed.

facts_w2 = ["AtA", "RoadAB", "AtB"]  # facts touched by the action.
mat_w2 = np.array([[1 if f in move_ab_w2[k] else 0 for f in facts_w2] for k in ["pre", "add", "delete"]])  # action table.
plt.figure(figsize=(5, 2.8))  # create a compact table figure.
plt.imshow(mat_w2, cmap="Blues", vmin=0, vmax=1, aspect="auto")  # visualize membership in each list.
plt.xticks(range(len(facts_w2)), facts_w2)  # label fact columns.
plt.yticks(range(3), ["Pre", "Add", "Del"])  # label STRIPS rows.
plt.title("2: MoveAB precondition/effect table")  # title the action table.
plt.colorbar(label="listed?")  # add a binary legend.
plt.show()  # display the table.
```
▶ What you'll see: `AtA` appears both as a precondition and a delete effect, while `AtB` appears as an add effect.

*Why it's done this way:* separating add and delete lists prevents stale facts from surviving after the world changes.

### 3. Applicability is a subset test

An action is legal only when every precondition is already true. This is the STRIPS version of asking whether an edge exists before graph search follows it.

```python
S_ok_w3 = frozenset(["AtA", "RoadAB", "RoadBC"])  # a state that can use MoveAB.
S_bad_w3 = frozenset(["AtA", "RoadBC"])  # a state missing RoadAB.
pre_w3 = move_ab_w2["pre"]  # reuse MoveAB's preconditions.
app_ok_w3 = pre_w3.issubset(S_ok_w3)  # legal because both required facts are present.
app_bad_w3 = pre_w3.issubset(S_bad_w3)  # illegal because RoadAB is missing.
print("MoveAB legal in S_ok?", app_ok_w3)  # inspect the legal case.
print("MoveAB legal in S_bad?", app_bad_w3)  # inspect the illegal case.
assert app_ok_w3 and not app_bad_w3  # verify applicability behavior.

labels_w3 = ["AtA", "RoadAB"]  # preconditions to check.
mat_w3 = np.array([[1 if f in S_ok_w3 else 0 for f in labels_w3], [1 if f in S_bad_w3 else 0 for f in labels_w3]])  # presence table.
plt.figure(figsize=(4.6, 2.8))  # create a compact heatmap.
plt.imshow(mat_w3, cmap="YlGn", vmin=0, vmax=1, aspect="auto")  # show which preconditions are present.
plt.xticks(range(len(labels_w3)), labels_w3)  # label precondition columns.
plt.yticks([0, 1], ["S_ok", "S_bad"])  # label the two states.
plt.title("3: preconditions must be a subset of the state")  # title the subset check.
plt.colorbar(label="present?")  # add a 0/1 legend.
plt.show()  # display the applicability table.
```
▶ What you'll see: the state missing `RoadAB` fails the subset test and cannot legally apply `MoveAB`.

*Why it's done this way:* the subset test is exact, cheap, and prevents search from inventing transitions that the domain rules do not allow.

### 4. The successor formula deletes first, then adds

When an applicable action fires, the successor is $(S \setminus Del(a)) \cup Add(a)$. Delete first removes facts that stopped being true; add then inserts the new facts.

```python
def apply_action_w4(state, action):  # apply one STRIPS action to one fact-set state.
    if not action["pre"].issubset(state):  # refuse illegal actions.
        return None  # no successor exists.
    return frozenset((state - action["delete"]) | action["add"])  # delete stale facts, then add new facts.

S_before_w4 = frozenset(["AtA", "RoadAB"])  # initial state from the lesson math.
S_after_w4 = apply_action_w4(S_before_w4, move_ab_w2)  # apply MoveAB.
print("before:", sorted(S_before_w4))  # inspect the old state.
print("after:", sorted(S_after_w4))  # inspect the successor.
assert S_after_w4 == frozenset(["RoadAB", "AtB"])  # matches (S \ Del) union Add.

states_w4 = [S_before_w4, S_after_w4]  # before/after states for visualization.
facts_w4 = ["AtA", "AtB", "RoadAB"]  # relevant facts.
mat_w4 = np.array([[1 if f in s else 0 for f in facts_w4] for s in states_w4])  # truth table across the transition.
plt.figure(figsize=(5, 2.8))  # create a transition heatmap.
plt.imshow(mat_w4, cmap="Purples", vmin=0, vmax=1, aspect="auto")  # show truth before and after.
plt.xticks(range(len(facts_w4)), facts_w4)  # label facts.
plt.yticks([0, 1], ["before", "after"])  # label time steps.
plt.title("4: applying MoveAB updates the fact set")  # title the successor plot.
plt.colorbar(label="true?")  # add a 0/1 legend.
plt.show()  # display the before/after table.
```
▶ What you'll see: `AtA` disappears and `AtB` appears; the road fact persists because no delete effect removed it.

*Why it's done this way:* action semantics are local, so the successor keeps every unaffected fact while changing only the facts named by effects.

### 5. Forward planning is graph search over symbolic states

Once actions define successors, planning can use ordinary BFS. The nodes are fact sets, and an edge is labeled by the action that transforms one fact set into the next.

```python
move_bc_w5 = {"name": "MoveBC", "pre": frozenset(["AtB", "RoadBC"]), "add": frozenset(["AtC"]), "delete": frozenset(["AtB"])}  # second movement action.
actions_w5 = [move_ab_w2, move_bc_w5]  # available actions.
start_w5 = frozenset(["AtA", "RoadAB", "RoadBC"])  # initial planning state.
goal_w5 = frozenset(["AtC"])  # desired facts.
frontier_w5 = deque([(start_w5, [])])  # BFS queue of (state, plan).
seen_w5 = {start_w5}  # visited states.
edges_w5 = []  # record explored transitions for visualization.
plan_w5 = None  # will store the first shortest plan found.
while frontier_w5:  # run BFS until a goal is found.
    state_w5, plan_so_far_w5 = frontier_w5.popleft()  # pop the oldest state.
    if goal_w5.issubset(state_w5):  # test whether all goal facts are true.
        plan_w5 = plan_so_far_w5  # store the solution plan.
        break  # BFS found a shortest plan.
    for action_w5 in actions_w5:  # try every action.
        nxt_w5 = apply_action_w4(state_w5, action_w5)  # compute a legal successor or None.
        if nxt_w5 is not None:  # only follow legal transitions.
            edges_w5.append((state_w5, nxt_w5, action_w5["name"]))  # remember the transition.
            if nxt_w5 not in seen_w5:  # avoid revisiting states.
                seen_w5.add(nxt_w5)  # mark visited.
                frontier_w5.append((nxt_w5, plan_so_far_w5 + [action_w5["name"]]))  # enqueue with extended plan.
print("plan:", plan_w5)  # inspect the discovered action sequence.
assert plan_w5 == ["MoveAB", "MoveBC"]  # shortest route to AtC.

state_names_w5 = {start_w5: "AtA", frozenset(["AtB", "RoadAB", "RoadBC"]): "AtB", frozenset(["AtC", "RoadAB", "RoadBC"]): "AtC"}  # readable labels.
xs_w5 = [0, 1, 2]  # x positions for the state-transition graph.
plt.figure(figsize=(6, 2.8))  # create graph-like visualization.
plt.scatter(xs_w5, [0, 0, 0], s=650, color="lightblue", edgecolor="black")  # draw state nodes.
for x_w5, label_w5 in zip(xs_w5, ["AtA", "AtB", "AtC"]):  # label states.
    plt.text(x_w5, 0, label_w5, ha="center", va="center")  # put labels inside nodes.
plt.annotate("MoveAB", xy=(1, 0), xytext=(0.25, 0.18), arrowprops=dict(arrowstyle="->"))  # edge A to B.
plt.annotate("MoveBC", xy=(2, 0), xytext=(1.25, 0.18), arrowprops=dict(arrowstyle="->"))  # edge B to C.
plt.axis("off")  # hide decorative axes.
plt.title("5: BFS over STRIPS states finds a two-action plan")  # title the transition graph.
plt.show()  # display the state-transition graph.
```
▶ What you'll see: BFS expands symbolic states in order and returns `MoveAB, MoveBC` for the goal `AtC`.

*Why it's done this way:* STRIPS supplies the successor function, while graph search supplies completeness and shortest-plan behavior for unit-cost actions.

### 6. Regression asks what had to be true before the last action

Forward search starts at the initial state. Regression works backward from the goal: if the last action adds a goal fact, remove the achieved goal and add that action's preconditions.

```python
def regress_w6(goal, action):  # regress a goal set through one action.
    if goal & action["delete"]:  # an action deleting a goal cannot be the final achiever without repair.
        return None  # reject destructive final action in this simple demo.
    return frozenset((goal - action["add"]) | action["pre"])  # replace achieved goals with action preconditions.

G_w6 = frozenset(["AtC"])  # final goal.
subgoal_w6 = regress_w6(G_w6, move_bc_w5)  # work backward through MoveBC.
print("goal:", sorted(G_w6))  # inspect final goal.
print("regressed subgoal:", sorted(subgoal_w6))  # inspect what must hold before MoveBC.
assert subgoal_w6 == frozenset(["AtB", "RoadBC"])  # matches the lesson derivation.

facts_w6 = ["AtB", "AtC", "RoadBC"]  # facts involved in regression.
mat_w6 = np.array([[1 if f in G_w6 else 0 for f in facts_w6], [1 if f in subgoal_w6 else 0 for f in facts_w6]])  # goal before/after regression.
plt.figure(figsize=(5, 2.8))  # create a regression heatmap.
plt.imshow(mat_w6, cmap="Oranges", vmin=0, vmax=1, aspect="auto")  # show how the goal set changes.
plt.xticks(range(len(facts_w6)), facts_w6)  # label facts.
plt.yticks([0, 1], ["after MoveBC", "before MoveBC"])  # label goal levels.
plt.title("6: regression replaces an achieved goal with preconditions")  # title the backward step.
plt.colorbar(label="required?")  # add a 0/1 legend.
plt.show()  # display the regression table.
```
▶ What you'll see: `AtC` is replaced by the requirements `AtB` and `RoadBC`.

*Why it's done this way:* regression can focus search on actions relevant to the goal rather than all actions available from the start.

### 7. Heuristics estimate remaining goal work, but interactions matter

A simple planning heuristic counts unsatisfied goal facts. That can guide search, but it is only an estimate: one action may achieve multiple goals, and another may delete a goal already achieved.

```python
states_w7 = [frozenset(["AtA", "RoadAB", "RoadBC"]), frozenset(["AtB", "RoadAB", "RoadBC"]), frozenset(["AtC", "RoadAB", "RoadBC"])]  # three states along the route.
goal_w7 = frozenset(["AtC", "RoadBC"])  # two desired facts.
h_w7 = np.array([len(goal_w7 - s) for s in states_w7])  # count unsatisfied goal facts.
print("heuristic values:", h_w7.tolist())  # inspect h from start to goal.
assert h_w7[-1] == 0 and h_w7[0] > h_w7[-1]  # goal distance reaches zero at the goal.

plt.figure(figsize=(5, 3))  # create a heuristic plot.
plt.plot(["start", "after MoveAB", "after MoveBC"], h_w7, marker="o", color="crimson")  # show h along the plan.
plt.title("7: unsatisfied-goal heuristic along a plan")  # title the goal-distance plot.
plt.ylabel("number of unsatisfied goal facts")  # label heuristic axis.
plt.ylim(-0.1, max(h_w7) + 0.5)  # keep zero visible.
plt.show()  # display the heuristic curve.
```
▶ What you'll see: the count falls to zero as the plan reaches a state satisfying every goal fact.

*Why it's done this way:* a cheap heuristic can prioritize promising states, but delete effects and interacting goals mean the count is guidance, not proof.

### ✍️ Toy 1 · Fact sets ignore ordering

A STRIPS state is the set of facts that are true. Reordering those facts should not create a new
world state.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)
t1_facts = ["AtKitchen", "HasCup", "CleanCup", "WaterOn"]
t1_state = frozenset(["AtKitchen", "HasCup"])
t1_same_state = frozenset(["HasCup", "AtKitchen"])
t1_equal = t1_state == t1_same_state  # -> True
t1_truth = np.array([1 if t1_fact in t1_state else 0 for t1_fact in t1_facts])  # -> [1 1 0 0]
print("state facts:", sorted(t1_state))  # -> ['AtKitchen', 'HasCup']
print("same after reordering?:", t1_equal)  # -> True
print("truth vector:", t1_truth.tolist())  # -> [1, 1, 0, 0]
assert t1_equal and t1_truth.tolist() == [1, 1, 0, 0]

plt.figure(figsize=(5, 2.4))
plt.imshow(t1_truth[None, :], cmap="Greens", vmin=0, vmax=1, aspect="auto")
plt.xticks(range(len(t1_facts)), t1_facts, rotation=25, ha="right")
plt.yticks([0], ["state"])
plt.colorbar(label="true?")
plt.title("Toy 1 · a state is a set of true facts")
plt.tight_layout()
plt.show()
```
▶ What you'll see: the two differently ordered fact lists are the same state, with only two true facts.

### ✍️ Toy 2 · STRIPS operators split preconditions, adds, and deletes

A planner reads an action as three separate lists: what must already hold, what becomes true, and
what stops being true.

```python
import numpy as np

t2_rng = np.random.default_rng(0)
t2_facts = ["AtSink", "HasCup", "CupEmpty", "CupFull"]
```

### ✍️ Toy 4 · Successors delete stale facts before adding new ones

The STRIPS successor formula is `(state − delete) ∪ add`: remove facts that stopped being true, then
insert new facts.

```python
import numpy as np

t4_rng = np.random.default_rng(0)
t4_before = frozenset(["AtSink", "HasCup", "CupEmpty"])
t4_add = frozenset(["CupFull"])
t4_delete = frozenset(["CupEmpty"])
t4_removed = t4_before - t4_delete  # -> frozenset({'AtSink', 'HasCup'})
t4_after = frozenset(t4_removed | t4_add)  # -> frozenset({'AtSink', 'HasCup', 'CupFull'})
t4_facts = ["AtSink", "HasCup", "CupEmpty", "CupFull"]
t4_matrix = np.array([[1 if t4_fact in t4_state else 0 for t4_fact in t4_facts] for t4_state in [t4_before, t4_after]])  # -> [[1 1 1 0], [1 1 0 1]]
print("before:", sorted(t4_before))  # -> ['AtSink', 'CupEmpty', 'HasCup']
print("after deleting stale facts:", sorted(t4_removed))  # -> ['AtSink', 'HasCup']
print("after adding new facts:", sorted(t4_after))  # -> ['AtSink', 'CupFull', 'HasCup']
print("truth table:", t4_matrix.tolist())  # -> [[1, 1, 1, 0], [1, 1, 0, 1]]
assert t4_after == frozenset(["AtSink", "HasCup", "CupFull"])

plt.figure(figsize=(5, 2.8))
plt.imshow(t4_matrix, cmap="Purples", vmin=0, vmax=1, aspect="auto")
plt.xticks(range(len(t4_facts)), t4_facts, rotation=25, ha="right")
plt.yticks([0, 1], ["before", "after"])
plt.colorbar(label="true?")
plt.title("Toy 4 · CupEmpty off, CupFull on")
plt.tight_layout()
plt.show()
```
▶ What you'll see: `CupEmpty` turns off and `CupFull` turns on, while untouched facts persist.

### ✍️ Toy 6 · Regression replaces achieved goals with preconditions

Backward planning asks what must have been true before the chosen last action.

## 🛠️ Setup

```python
import numpy as np  # load NumPy for arrays, tables, and deterministic checks.
import matplotlib.pyplot as plt  # load Matplotlib so every example has an explanatory visualization.
from collections import deque  # use a FIFO queue for breadth-first symbolic search.
np.random.seed(0)  # make all examples reproducible.

def make_action(name, pre, add, delete):  # create a small STRIPS action dictionary.
    return {"name": name, "pre": frozenset(pre), "add": frozenset(add), "delete": frozenset(delete)}  # freeze fact lists for set algebra.

def applicable(state, action):  # test whether an action can legally fire in a state.
    return action["pre"].issubset(state)  # STRIPS applicability is precondition subset state.

def apply_action(state, action):  # compute the STRIPS successor for one action.
    if not applicable(state, action):  # reject illegal actions instead of inventing an edge.
        return None  # no successor exists.
    return frozenset((state - action["delete"]) | action["add"])  # S' = (S \ Del) union Add.

def goal_reached(state, goal):  # test whether a state satisfies every goal fact.
    return frozenset(goal).issubset(state)  # goals are also represented as fact sets.

def bfs_plan(start, goal, actions):  # find a shortest unit-cost plan by forward search.
    start = frozenset(start)  # freeze the initial fact set so it can be stored in sets.
    goal = frozenset(goal)  # freeze the goal facts.
    frontier = deque([(start, [])])  # each frontier item stores a state and the action names used to reach it.
    seen = {start}  # remember visited fact sets.
    expanded = []  # record expansion order for debugging and plots.
    edges = []  # record state-transition edges.
    while frontier:  # continue until no reachable states remain.
        state, plan = frontier.popleft()  # pop the oldest state for BFS.
        expanded.append(state)  # track that this node was expanded.
        if goal_reached(state, goal):  # stop when the current state satisfies the goal.
            return plan, expanded, edges  # return the discovered shortest plan and traces.
        for action in actions:  # try every domain action.
            nxt = apply_action(state, action)  # compute legal successor.
            if nxt is not None:  # only legal actions create graph edges.
                edges.append((state, nxt, action["name"]))  # store the transition.
                if nxt not in seen:  # avoid repeated states.
                    seen.add(nxt)  # mark the successor as discovered.
                    frontier.append((nxt, plan + [action["name"]]))  # enqueue with the extended plan.
    return None, expanded, edges  # report failure if BFS exhausts the graph.

def unsatisfied_count(state, goal):  # simple planning heuristic h(s).
    return len(frozenset(goal) - frozenset(state))  # count goal facts not yet true.

def show_fact_table(states, facts, labels, title):  # visualize which facts are true in each state.
    mat = np.array([[1 if f in s else 0 for f in facts] for s in states])  # convert fact sets to a 0/1 matrix.
    plt.figure(figsize=(max(4, 0.75 * len(facts)), 0.6 * len(states) + 2.2))  # size the table to labels.
    plt.imshow(mat, cmap="viridis", vmin=0, vmax=1, aspect="auto")  # draw truth values as colors.
    plt.xticks(range(len(facts)), facts, rotation=30, ha="right")  # label fact columns.
    plt.yticks(range(len(labels)), labels)  # label state rows.
    plt.colorbar(label="true?")  # add a binary legend.
    plt.title(title)  # title the current visualization.
    plt.tight_layout()  # keep labels visible.

def show_action_table(actions, facts, title):  # visualize pre/add/delete membership for actions.
    rows = []  # collect table rows.
    labels = []  # collect row labels.
    for action in actions:  # add three rows per action.
        for key in ["pre", "add", "delete"]:  # inspect each STRIPS list.
            rows.append([1 if f in action[key] else 0 for f in facts])  # membership row.
            labels.append(action["name"] + ":" + key)  # readable row label.
    plt.figure(figsize=(max(4, 0.7 * len(facts)), 0.35 * len(rows) + 2.2))  # size by table dimensions.
    plt.imshow(np.array(rows), cmap="Blues", vmin=0, vmax=1, aspect="auto")  # draw the binary table.
    plt.xticks(range(len(facts)), facts, rotation=30, ha="right")  # label fact columns.
    plt.yticks(range(len(labels)), labels)  # label action rows.
    plt.colorbar(label="listed?")  # add a 0/1 legend.
    plt.title(title)  # title the action table.
    plt.tight_layout()  # avoid label clipping.

def show_plan_sequence(plan, title):  # visualize an ordered plan as action slots.
    y = np.zeros(len(plan))  # all actions lie on one sequence line.
    x = np.arange(len(plan))  # positions in plan order.
    plt.figure(figsize=(max(4, len(plan) + 2), 2.4))  # create a compact sequence plot.
    plt.scatter(x, y, s=700, color="lightgreen", edgecolor="black")  # draw action nodes.
    for i, name in enumerate(plan):  # label each action.
        plt.text(i, 0, name, ha="center", va="center")  # put name in node.
        if i < len(plan) - 1:  # draw arrows between adjacent plan steps.
            plt.annotate("", xy=(i + 0.72, 0), xytext=(i + 0.28, 0), arrowprops=dict(arrowstyle="->"))  # action order arrow.
    plt.xlim(-0.8, len(plan) - 0.2 if plan else 1)  # keep endpoints visible.
    plt.ylim(-0.5, 0.5)  # compress unused vertical space.
    plt.axis("off")  # hide decorative axes.
    plt.title(title)  # title the sequence.
```

#### A1. Compare BFS and greedy best-first search effort

**Goal.** Measure nodes expanded by two search strategies, because heuristics are valuable when symbolic state spaces grow. We build it in 5 steps.

