# 10.5 — Generative Adversarial Networks

Generative adversarial networks (GANs) learn a generator by making it play a game against a discriminator: the discriminator learns to separate real samples from generated samples, while the generator learns to make fakes that the discriminator cannot reject. In this lesson, we build that game from scratch with NumPy on tiny 1-D and 2-D toy distributions, inspect the minimax objective, and see why unstable gradients, mode collapse, and critic balance matter.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build generative adversarial networks one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including the minimax loss and the generator/discriminator gradients, is derived and shown. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, random sampling, and hand-written neural-network math.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for the toy game.
```

### 1. Real data, latent noise, and generator samples

A GAN begins with two distributions. The real distribution $p_{data}(x)$ is the data we want to imitate; the latent distribution $p(z)$ is an easy source of noise we can sample. The generator $G(z)$ maps noise into the data space, so learning means moving the generated distribution until it overlaps the real one.

```python
real_w = np.r_[np.random.normal(-1.5, 0.25, 80), np.random.normal(1.5, 0.25, 80)]  # two real 1-D modes.
z_w = np.random.normal(0, 1, 160)  # easy latent noise source.
fake_start_w = 0.35 * z_w + 0.2  # a weak initial generator: affine map z -> x.
print("real mean/std:", round(real_w.mean(), 3), round(real_w.std(), 3))
print("fake mean/std:", round(fake_start_w.mean(), 3), round(fake_start_w.std(), 3))
assert real_w.shape == fake_start_w.shape == (160,)
```
▶ What you'll see: real samples are wide and bimodal, while the initial fake samples are narrow and centered.

```python
plt.figure(figsize=(5, 3))
plt.hist(real_w, bins=24, alpha=0.6, density=True, label="real", color="seagreen")
plt.hist(fake_start_w, bins=24, alpha=0.6, density=True, label="fake start", color="crimson")
plt.title("1: real vs initial generated distribution")
plt.xlabel("x"); plt.ylabel("density"); plt.legend(); plt.show()
```
▶ What you'll see: the green distribution has two peaks near -1.5 and 1.5, while the red distribution misses both modes.

*Why it's done this way:* GANs avoid writing an explicit likelihood $p(x)$ by learning a sampler. The generator only needs a differentiable path from simple noise to samples; the discriminator will provide the training pressure that says which generated samples look believable.

### 2. The discriminator is logistic classification

The discriminator returns $D(x)\in(0,1)$, interpreted as “probability this sample is real.” For one real sample it receives label 1; for one generated sample it receives label 0. Its maximization objective is the binary-classification log score

$$\max_D\;\log D(x_{real})+\log(1-D(x_{fake})).$$

```python
def sigmoid_w(t):
    return 1.0 / (1.0 + np.exp(-np.clip(t, -40, 40)))

x_pair_w = np.array([1.0, -0.5])  # one real-looking point and one fake-looking point.
wD_w, bD_w = 1.2, -0.1  # scalar logistic discriminator parameters.
D_pair_w = sigmoid_w(wD_w * x_pair_w + bD_w)
print("D(real-ish):", round(float(D_pair_w[0]), 3), "D(fake-ish):", round(float(D_pair_w[1]), 3))
assert round(float(sigmoid_w(1.1)), 3) == 0.750
```
▶ What you'll see: the larger input receives a larger real probability under this toy discriminator.

```python
real_term_w = np.log(D_pair_w[0])
fake_term_w = np.log(1 - D_pair_w[1])
D_objective_w = real_term_w + fake_term_w
print("log D(real):", round(float(real_term_w), 4))
print("log(1-D(fake)):", round(float(fake_term_w), 4))
print("discriminator objective:", round(float(D_objective_w), 4))
assert round(float(D_objective_w), 4) == -0.6905
```
▶ What you'll see: the objective is less negative when the discriminator gives high probability to real and low probability to fake.

*Why it's done this way:* logistic loss is a proper scoring rule for binary labels. Maximizing the real term pushes $D(x_{real})$ toward 1; maximizing the fake term pushes $D(G(z))$ toward 0, creating exactly the signal the generator will later try to undo.

### 3. The minimax game and generator gradients

The original GAN objective is

$$\min_G\max_D\;\mathbb{E}_{x\sim p_{data}}\log D(x)+\mathbb{E}_{z\sim p(z)}\log(1-D(G(z))).$$

The discriminator maximizes both terms. The generator only controls the fake term, so in the minimax version it minimizes $\log(1-D(G(z)))$. In practice, many implementations use the non-saturating generator loss $-\log D(G(z))$, which has the same optimum but gives stronger gradients when $D(G(z))$ is near 0.

```python
Dfake_grid_w = np.array([0.01, 0.10, 0.50, 0.90])
minimax_loss_w = np.log(1 - Dfake_grid_w)  # generator minimizes this original fake term.
non_sat_loss_w = -np.log(Dfake_grid_w)  # generator minimizes this practical alternative.
print("D(fake):", Dfake_grid_w)
print("minimax fake term:", np.round(minimax_loss_w, 3))
print("non-saturating loss:", np.round(non_sat_loss_w, 3))
assert round(float(non_sat_loss_w[0]), 3) == 4.605
```
▶ What you'll see: when D(fake)=0.01, the non-saturating loss is large, loudly telling the generator to improve.

```python
# For a sigmoid discriminator logit a, d/da log(1-sigmoid(a)) = -sigmoid(a).
# For the non-saturating loss -log(sigmoid(a)), d/da = -(1-sigmoid(a)).
grad_minimax_logit_w = -Dfake_grid_w
grad_non_sat_logit_w = -(1 - Dfake_grid_w)
print("minimax logit gradients:", np.round(grad_minimax_logit_w, 3))
print("non-saturating logit gradients:", np.round(grad_non_sat_logit_w, 3))
```
▶ What you'll see: the minimax gradient is tiny when D confidently rejects fakes, while the non-saturating gradient is near -1.

```python
plt.figure(figsize=(5, 3))
plt.plot(Dfake_grid_w, np.abs(grad_minimax_logit_w), marker="o", label="|minimax grad|")
plt.plot(Dfake_grid_w, np.abs(grad_non_sat_logit_w), marker="s", label="|non-sat grad|")
plt.title("3: generator gradient strength")
plt.xlabel("D(G(z))"); plt.ylabel("absolute logit-gradient"); plt.legend(); plt.show()
```
▶ What you'll see: the non-saturating curve stays large when the discriminator is winning.

*Why it's done this way:* the minimax objective defines the game, but the chain rule decides whether learning is usable. If $D(G(z))\approx0$, minimizing $\log(1-D(G(z)))$ barely changes with the discriminator logit, so the generator gets a weak signal; $-\log D(G(z))$ preserves pressure to move fakes toward regions the discriminator calls real.

### 4. Backpropagating through a tiny generator and discriminator

Now make the game differentiable end to end. Let $G(z)=a_G z+b_G$ and $D(x)=\sigma(w_Dx+b_D)$. For a fake sample, the non-saturating generator loss is $L_G=-\log D(G(z))$. The chain rule gives

$$\frac{\partial L_G}{\partial a_G}=-(1-D(G(z)))w_Dz,\qquad \frac{\partial L_G}{\partial b_G}=-(1-D(G(z)))w_D.$$

```python
z_one_w = 0.7
aG_w, bG_w = 0.4, -0.2
wD2_w, bD2_w = 1.5, 0.1
x_fake_w = aG_w * z_one_w + bG_w
D_fake_w = float(sigmoid_w(wD2_w * x_fake_w + bD2_w))
lossG_w = -np.log(D_fake_w)
print("G(z):", round(x_fake_w, 3), "D(G(z)):", round(D_fake_w, 3), "L_G:", round(float(lossG_w), 3))
assert round(x_fake_w, 3) == 0.080
```
▶ What you'll see: the generated point is small, the discriminator is uncertain, and the generator loss is positive.

```python
dL_dlogit_w = -(1 - D_fake_w)
dL_dx_w = dL_dlogit_w * wD2_w
dL_daG_w = dL_dx_w * z_one_w
dL_dbG_w = dL_dx_w
print("dL/dlogit:", round(dL_dlogit_w, 3))
print("dL/daG:", round(dL_daG_w, 3), "dL/dbG:", round(dL_dbG_w, 3))
assert round(dL_daG_w, 3) == -0.467
```
▶ What you'll see: both gradients are negative, so gradient descent increases `aG` and `bG` in this setup.

```python
eta_w = 0.2
aG_new_w = aG_w - eta_w * dL_daG_w
bG_new_w = bG_w - eta_w * dL_dbG_w
new_D_fake_w = float(sigmoid_w(wD2_w * (aG_new_w * z_one_w + bG_new_w) + bD2_w))
print("updated aG,bG:", round(aG_new_w, 3), round(bG_new_w, 3))
print("D(G(z)) before -> after:", round(D_fake_w, 3), "->", round(new_D_fake_w, 3))
assert new_D_fake_w > D_fake_w
```
▶ What you'll see: one generator step makes this fake look more real to the fixed discriminator.

*Why it's done this way:* the generator never sees labels directly; it receives a gradient through $D$. The discriminator slope $w_D$ and the fake's latent coordinate $z$ multiply the loss gradient, so the critic's geometry literally shapes the direction in which generated samples move.

### 5. Alternating training on a 1-D toy GAN

GAN optimization alternates: update $D$ to classify current real/fake samples, then update $G$ through the frozen discriminator. We use a tiny affine generator and logistic discriminator so every gradient is visible, and we train on a single Gaussian real distribution where an affine generator is expressive enough.

```python
rng_w = np.random.default_rng(0)
mu_real_w, sig_real_w = 1.2, 0.45
a_w, b_w = 0.25, -0.6  # generator parameters.
wd_w, bd_w = -0.2, 0.0  # discriminator parameters.
history_w = []
print("initial generator mean/std:", round(b_w, 3), round(abs(a_w), 3))
```
▶ What you'll see: the generator starts far from the real mean and too narrow.

```python
for step_w in range(900):
    xr_w = rng_w.normal(mu_real_w, sig_real_w, 64)
    z_w = rng_w.normal(0, 1, 64)
    xf_w = a_w * z_w + b_w
    Dr_w = sigmoid_w(wd_w * xr_w + bd_w)
    Df_w = sigmoid_w(wd_w * xf_w + bd_w)
    grad_wd_w = np.mean((Dr_w - 1) * xr_w + Df_w * xf_w)
    grad_bd_w = np.mean((Dr_w - 1) + Df_w)
    wd_w -= 0.05 * grad_wd_w; bd_w -= 0.05 * grad_bd_w
    z2_w = rng_w.normal(0, 1, 64)
    xf2_w = a_w * z2_w + b_w
    Df2_w = sigmoid_w(wd_w * xf2_w + bd_w)
    dL_dx_w = -(1 - Df2_w) * wd_w
    a_w -= 0.03 * np.mean(dL_dx_w * z2_w)
    b_w -= 0.03 * np.mean(dL_dx_w)
    if step_w % 50 == 0:
        history_w.append([step_w, a_w, b_w, wd_w, bd_w, float(np.mean(Df2_w))])
print("final generator mean/std:", round(b_w, 3), round(abs(a_w), 3))
assert abs(b_w - mu_real_w) < 0.35
```
▶ What you'll see: the learned generator mean moves near the real mean, while the scale grows from the weak start.

```python
hist_w = np.array(history_w)
plt.figure(figsize=(5, 3))
plt.plot(hist_w[:, 0], hist_w[:, 2], label="generator mean b")
plt.axhline(mu_real_w, color="black", linestyle="--", label="real mean")
plt.plot(hist_w[:, 0], np.abs(hist_w[:, 1]), label="generator std |a|")
plt.axhline(sig_real_w, color="gray", linestyle=":", label="real std")
plt.title("5: tiny GAN parameters move toward data")
plt.xlabel("step"); plt.legend(); plt.show()
```
▶ What you'll see: the generator mean approaches the dashed real mean and the scale approaches the dotted real std.

```python
real_final_w = rng_w.normal(mu_real_w, sig_real_w, 400)
fake_final_w = a_w * rng_w.normal(0, 1, 400) + b_w
plt.figure(figsize=(5, 3))
plt.hist(real_final_w, bins=28, alpha=0.6, density=True, label="real", color="seagreen")
plt.hist(fake_final_w, bins=28, alpha=0.6, density=True, label="fake trained", color="steelblue")
plt.title("5: trained fake distribution overlaps real")
plt.xlabel("x"); plt.ylabel("density"); plt.legend(); plt.show()
```
▶ What you'll see: the trained blue histogram is much closer to the green histogram than the initial fake distribution.

*Why it's done this way:* alternating steps keep the game coupled. If $D$ is never updated, $G$ chases a stale signal; if $D$ is updated too far, $G$ can receive saturated gradients. Small alternating steps approximate the moving equilibrium where fake samples become hard to distinguish from real samples.

### 6. Mode collapse and distribution coverage

Matching one discriminator can hide a failure: the generator may produce realistic samples from only one mode. This is mode collapse. The discriminator can be confused locally, but the generated distribution fails to cover the full data distribution.

```python
real_modes_w = np.r_[np.random.normal(-2, 0.18, 120), np.random.normal(2, 0.18, 120)]
fake_collapsed_w = np.random.normal(2, 0.18, 240)
fake_covered_w = np.r_[np.random.normal(-2, 0.18, 120), np.random.normal(2, 0.18, 120)]
left_real_w = np.mean(real_modes_w < 0)
left_collapsed_w = np.mean(fake_collapsed_w < 0)
left_covered_w = np.mean(fake_covered_w < 0)
print("left-mode mass real/collapsed/covered:", round(left_real_w, 2), round(left_collapsed_w, 2), round(left_covered_w, 2))
assert round(left_collapsed_w, 2) == 0.0
```
▶ What you'll see: the collapsed generator puts essentially no mass on the left mode.

```python
plt.figure(figsize=(5, 3))
plt.hist(real_modes_w, bins=34, alpha=0.45, density=True, label="real two modes", color="seagreen")
plt.hist(fake_collapsed_w, bins=34, alpha=0.45, density=True, label="fake collapsed", color="crimson")
plt.hist(fake_covered_w, bins=34, alpha=0.35, density=True, label="fake covered", color="steelblue")
plt.title("6: realism is not the same as coverage")
plt.xlabel("x"); plt.ylabel("density"); plt.legend(); plt.show()
```
▶ What you'll see: collapsed red samples look plausible near the right mode but completely miss the left mode.

*Why it's done this way:* the adversarial objective compares distributions through a learned classifier, not by explicitly counting every mode. A generator can improve the game value by exploiting the critic's current weaknesses, so visualizing real-vs-fake coverage and using distributional diagnostics are essential.

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, random sampling, vectorized loss computations, and hand-written backprop.
import matplotlib.pyplot as plt # load Matplotlib for histograms, curves, scatters, and training diagnostics.
np.random.seed(0) # make all examples reproducible across notebook runs.

def sigmoid(x): # define a numerically guarded logistic function used by discriminators.
    return 1.0 / (1.0 + np.exp(-np.clip(x, -40, 40))) # clipping prevents overflow without changing visible probabilities.

def bce_loss(prob, label): # define binary cross-entropy for one probability and one label.
    prob = np.clip(prob, 1e-8, 1 - 1e-8) # avoid log(0) so loss values remain finite.
    return float(-(label * np.log(prob) + (1 - label) * np.log(1 - prob))) # return the scalar BCE loss.

def sample_real_1d(n, rng, mean=1.2, std=0.45): # sample a simple one-mode real distribution.
    return rng.normal(mean, std, n) # return Gaussian data for tiny GAN experiments.

def show_hist(real, fake, title): # compare real and fake 1-D distributions.
    plt.figure(figsize=(5, 3)) # create a compact histogram figure.
    plt.hist(real, bins=28, alpha=0.6, density=True, label="real", color="seagreen") # plot the target density estimate.
    plt.hist(fake, bins=28, alpha=0.6, density=True, label="fake", color="crimson") # plot the generated density estimate.
    plt.title(title) # label the comparison.
    plt.xlabel("x") # label sample values.
    plt.ylabel("density") # label normalized histogram height.
    plt.legend() # show real/fake labels.
    plt.show() # display the plot.
```

## 🟢 Basics (warm-up)

### Basic 1 — Sample real data and latent noise

**Goal.** Create real samples and latent noise, because a GAN learns a map from an easy distribution to a target distribution. We build it in 2 steps.

```python
rng_b1 = np.random.default_rng(1) # create a local random generator for this example.
real_b1 = rng_b1.normal(1.2, 0.45, 200) # sample the target 1-D real distribution.

print("real mean/std:", round(float(real_b1.mean()), 3), round(float(real_b1.std()), 3)) # inspect real sample statistics.

```
▶ What you'll see: real samples are centered near 1.2, while latent noise is centered near 0.

```python
plt.figure(figsize=(5, 3)) # create one histogram comparison.
plt.hist(real_b1, bins=25, alpha=0.6, density=True, label="real", color="seagreen") # show target data samples.
```

### Basic 3 — Score samples with a discriminator

**Goal.** Compute $D(x)=\sigma(wx+b)$, because the discriminator is a binary classifier over real versus fake. We build it in 2 steps.

```python
x_b3 = np.array([-1.0, 0.0, 1.0, 2.0]) # choose four candidate samples.
w_b3, c_b3 = 1.1, -0.2 # define discriminator weight and bias.
prob_b3 = sigmoid(w_b3 * x_b3 + c_b3) # compute real probabilities.
print("D(x):", np.round(prob_b3, 3)) # inspect discriminator scores.
assert round(float(prob_b3[2]), 3) == 0.711 # verify sigmoid(0.9).
```
▶ What you'll see: larger x values receive larger real probabilities with this positive weight.

```python
plt.figure(figsize=(5, 3)) # create a discriminator curve.
grid_b3 = np.linspace(-3, 3, 100) # make points for a smooth sigmoid curve.
plt.plot(grid_b3, sigmoid(w_b3 * grid_b3 + c_b3), color="navy") # plot D(x).
plt.scatter(x_b3, prob_b3, color="red") # mark the evaluated samples.
plt.title("Basic 3: logistic discriminator") # title the plot.
plt.xlabel("x"); plt.ylabel("D(x)"); plt.show() # label and display.
```
▶ What you'll see: the S-shaped curve converts sample position into a probability.

👀 Takeaway: the discriminator supplies a differentiable realness score.

### Basic 4 — Compute discriminator BCE on real and fake

**Goal.** Evaluate binary cross-entropy for one real and one fake score, because the discriminator trains as a classifier. We build it in 2 steps.

```python
D_real_b4 = 0.73 # choose the lesson's real probability.
D_fake_b4 = 0.41 # choose the lesson's fake probability.
loss_real_b4 = bce_loss(D_real_b4, 1) # loss for labeling real data as 1.
loss_fake_b4 = bce_loss(D_fake_b4, 0) # loss for labeling fake data as 0.
print("real BCE:", round(loss_real_b4, 4), "fake BCE:", round(loss_fake_b4, 4)) # inspect loss pieces.
assert round(loss_real_b4, 4) == 0.3147 # verify -log(0.73).
```
▶ What you'll see: confident correct probabilities produce smaller losses.

```python
D_loss_b4 = loss_real_b4 + loss_fake_b4 # add real and fake classification losses.
D_objective_b4 = -D_loss_b4 # discriminator maximization objective is the negative BCE sum.
print("D loss:", round(D_loss_b4, 4), "D objective:", round(D_objective_b4, 4)) # compare minimization and maximization signs.
assert round(D_objective_b4, 4) == -0.8423 # verify the content-block number.
```
▶ What you'll see: the discriminator objective contribution matches log(0.73)+log(1-0.41).

👀 Takeaway: the minimax expression is binary-classification log score written as a game.

### Basic 7 — Derive one discriminator gradient

**Goal.** Compute the logistic gradient for one labeled sample, because discriminator updates are ordinary classifier backprop. We build it in 2 steps.

```python
x_b7 = 1.5 # choose one real sample.
y_b7 = 1.0 # real label.
w_b7, b0_b7 = 0.4, -0.3 # current discriminator parameters.
p_b7 = float(sigmoid(w_b7 * x_b7 + b0_b7)) # compute D(x).
grad_logit_b7 = p_b7 - y_b7 # BCE derivative with respect to the logit.
print("D(x):", round(p_b7, 3), "dL/dlogit:", round(grad_logit_b7, 3)) # inspect classification error signal.
```
▶ What you'll see: since the real sample is under-scored, the gradient is negative.

```python
grad_w_b7 = grad_logit_b7 * x_b7 # chain the logit gradient to weight w.
grad_b_b7 = grad_logit_b7 # chain the logit gradient to bias b.
print("grad w:", round(grad_w_b7, 3), "grad b:", round(grad_b_b7, 3)) # inspect parameter gradients.
assert grad_w_b7 < 0 # gradient descent will increase w for this positive real sample.
```
▶ What you'll see: descending the negative gradient makes the discriminator call this real point more real.

👀 Takeaway: discriminator learning is just logistic regression on a changing fake class.

### Basic 8 — Derive one generator gradient

**Goal.** Backpropagate $-\log D(G(z))$ through $G(z)=az+b$, because the generator learns only through the discriminator. We build it in 3 steps.

```python
z_b8 = 0.8 # choose one latent input.
a_b8, b_b8 = 0.5, -0.1 # current generator parameters.
wD_b8, cD_b8 = 1.4, 0.0 # fixed discriminator parameters for the generator step.
x_fake_b8 = a_b8 * z_b8 + b_b8 # generate one fake sample.
D_fake_b8 = float(sigmoid(wD_b8 * x_fake_b8 + cD_b8)) # score the fake sample.
print("x_fake:", round(x_fake_b8, 3), "D_fake:", round(D_fake_b8, 3)) # inspect forward pass.
```
▶ What you'll see: the fake sample receives a discriminator probability between 0 and 1.

```python
dL_dx_b8 = -(1 - D_fake_b8) * wD_b8 # chain non-saturating loss through discriminator logit to x_fake.
grad_a_b8 = dL_dx_b8 * z_b8 # chain x_fake to generator scale a.
grad_b_b8 = dL_dx_b8 # chain x_fake to generator shift b.
print("grad a:", round(grad_a_b8, 3), "grad b:", round(grad_b_b8, 3)) # inspect generator gradients.
assert round(float(grad_a_b8), 3) == -0.444 # verify the hand-computed gradient.
```
▶ What you'll see: negative gradients mean gradient descent will increase both generator parameters here.

```python
eta_b8 = 0.1 # choose a small generator learning rate.
a_new_b8 = a_b8 - eta_b8 * grad_a_b8 # update generator scale.
b_new_b8 = b_b8 - eta_b8 * grad_b_b8 # update generator shift.
D_new_b8 = float(sigmoid(wD_b8 * (a_new_b8 * z_b8 + b_new_b8) + cD_b8)) # score after the update.
print("D_fake before -> after:", round(D_fake_b8, 3), "->", round(D_new_b8, 3)) # verify improvement.
assert D_new_b8 > D_fake_b8 # the fixed discriminator is more fooled after the update.
```
▶ What you'll see: one generator step raises the discriminator's probability for the fake sample.

👀 Takeaway: generator gradients are discriminator gradients pulled backward through the sample path.

### Basic 9 — Alternate one discriminator step and one generator step

**Goal.** Perform the smallest GAN training cycle, because the two players must update against each other's current behavior. We build it in 3 steps.

▶ What you'll see: both players start weak and nearly untrained.

```python

Df_b9 = sigmoid(w_b9 * xf_b9 + c_b9) # discriminator scores on fake samples.
```

▶ What you'll see: the discriminator moves first, then the generator responds to the new critic.

👀 Takeaway: GAN training is not one static loss; it is an alternating game.

```python
z_a2 = np.array([[0.2], [-1.0], [1.5]]) # create a tiny latent batch with one latent dimension.
W1_a2 = np.array([[0.5], [-0.3]]) # hidden-layer weights, shape 2x1.
b1_a2 = np.array([0.1, -0.2]) # hidden-layer biases.
W2_a2 = np.array([[1.0, -0.7]]) # output-layer weights, shape 1x2.
b2_a2 = np.array([0.05]) # output bias.
wD_a2, cD_a2 = 1.2, -0.1 # fixed discriminator for this generator step.
print("batch shape:", z_a2.shape) # inspect the mini-batch shape.
```

```python
hpre_a2 = z_a2 @ W1_a2.T + b1_a2 # compute hidden pre-activations.
h_a2 = np.tanh(hpre_a2) # apply tanh nonlinearity.
x_a2 = h_a2 @ W2_a2.T + b2_a2 # compute generated samples.
D_a2 = sigmoid(wD_a2 * x_a2[:, 0] + cD_a2) # discriminator probabilities for fakes.
loss_a2 = float(np.mean(-np.log(np.clip(D_a2, 1e-8, 1)))) # mean non-saturating generator loss.
print("x_fake:", np.round(x_a2[:, 0], 3), "loss:", round(loss_a2, 3)) # inspect forward pass.
```

```python
dL_dx_a2 = (-(1 - D_a2) * wD_a2 / len(z_a2))[:, None] # gradient wrt generator outputs, averaged over batch.
grad_W2_a2 = dL_dx_a2.T @ h_a2 # output-layer weight gradient.
grad_b2_a2 = np.sum(dL_dx_a2, axis=0) # output-layer bias gradient.
dh_a2 = dL_dx_a2 @ W2_a2 # gradient wrt tanh activations.
dhpre_a2 = dh_a2 * (1 - h_a2 ** 2) # tanh derivative.
grad_W1_a2 = dhpre_a2.T @ z_a2 # hidden-layer weight gradient.
grad_b1_a2 = np.sum(dhpre_a2, axis=0) # hidden-layer bias gradient.
print("grad W2:", np.round(grad_W2_a2, 3)) # inspect output-layer gradient.
print("grad W1:", np.round(grad_W1_a2, 3)) # inspect hidden-layer gradient.
assert grad_W1_a2.shape == W1_a2.shape and grad_W2_a2.shape == W2_a2.shape # verify backprop shapes.
```

```python
eta_a2 = 0.1 # choose a small update.
W1_new_a2 = W1_a2 - eta_a2 * grad_W1_a2 # update hidden weights.
b1_new_a2 = b1_a2 - eta_a2 * grad_b1_a2 # update hidden biases.
W2_new_a2 = W2_a2 - eta_a2 * grad_W2_a2 # update output weights.
b2_new_a2 = b2_a2 - eta_a2 * grad_b2_a2 # update output bias.
h_new_a2 = np.tanh(z_a2 @ W1_new_a2.T + b1_new_a2) # recompute hidden activations.
x_new_a2 = h_new_a2 @ W2_new_a2.T + b2_new_a2 # recompute fake samples.
new_loss_a2 = float(np.mean(-np.log(np.clip(sigmoid(wD_a2 * x_new_a2[:, 0] + cD_a2), 1e-8, 1)))) # recompute generator loss.
print("loss before -> after:", round(loss_a2, 3), "->", round(new_loss_a2, 3)) # inspect improvement.
assert new_loss_a2 < loss_a2 # one generator descent step should reduce the fixed-D loss.
```
▶ What you'll see: a hand-written backprop step lowers the generator loss against the fixed discriminator.

👀 Takeaway: deep GANs use the same chain rule; the graph is larger, but the logic is unchanged.

### Advanced 5 — Train a tiny GAN and inspect generated quantiles

**Goal.** Compare quantiles of real and generated samples after training, because quantiles reveal tail and spread mismatch beyond the mean. We build it in 4 steps.

```python
rng_a5 = np.random.default_rng(505) # create reproducible randomness.
a_a5, b_a5, w_a5, c_a5 = 0.2, -0.7, -0.2, 0.0 # initialize a tiny GAN.
quant_trace_a5 = [] # store occasional quantile gaps.
print("initial fake mean:", b_a5) # inspect starting generator center.
```

```python
for step_a5 in range(850): # train a small 1-D GAN.
    xr_a5 = rng_a5.normal(1.2, 0.45, 64) # real batch.
    z_a5 = rng_a5.normal(0, 1, 64) # latent batch.
    xf_a5 = a_a5 * z_a5 + b_a5 # fake batch.
    Dr_a5 = sigmoid(w_a5 * xr_a5 + c_a5) # score real batch.
    Df_a5 = sigmoid(w_a5 * xf_a5 + c_a5) # score fake batch.
    w_a5 -= 0.05 * np.mean((Dr_a5 - 1) * xr_a5 + Df_a5 * xf_a5) # update discriminator weight.
    c_a5 -= 0.05 * np.mean((Dr_a5 - 1) + Df_a5) # update discriminator bias.
    z2_a5 = rng_a5.normal(0, 1, 64) # fresh generator batch.
    Df2_a5 = sigmoid(w_a5 * (a_a5 * z2_a5 + b_a5) + c_a5) # score fake batch.
    dL_dx_a5 = -(1 - Df2_a5) * w_a5 # compute generator gradient wrt fake samples.
    a_a5 -= 0.03 * np.mean(dL_dx_a5 * z2_a5) # update generator scale.
    b_a5 -= 0.03 * np.mean(dL_dx_a5) # update generator shift.
    if step_a5 % 100 == 0: # periodically compare quantiles.
        real_q_a5 = np.quantile(rng_a5.normal(1.2, 0.45, 300), [0.1, 0.5, 0.9]) # real quantiles.
        fake_q_a5 = np.quantile(a_a5 * rng_a5.normal(0, 1, 300) + b_a5, [0.1, 0.5, 0.9]) # fake quantiles.
        quant_trace_a5.append(np.mean(np.abs(real_q_a5 - fake_q_a5))) # store average quantile gap.
print("final a,b:", round(a_a5, 3), round(b_a5, 3)) # inspect final generator.
assert abs(b_a5 - 1.2) < 0.4 # verify mean movement toward real data.
```
