# 19.9 — Adversarial Robustness & Certification

Adversarial robustness asks whether a prediction survives small, worst-case input changes; certification asks for a proof that it must survive within a stated radius. In this lesson, you will build toy attacks, adversarial training, Lipschitz margin certificates, and randomized-smoothing certificates from first principles with only NumPy and Matplotlib.

### 1. A tiny classifier, a margin, and a perturbation ball

A robustness question starts with a normal prediction. We use a linear score $g(x)=w^\top x+b$ and classify by its sign: class $+1$ if the score is nonnegative, class $-1$ otherwise. The **margin** is the signed score in the true-label direction, $y g(x)$. A positive margin means correct; a larger positive margin means the point is farther from the boundary. A perturbation ball then asks which nearby inputs $x+\delta$ are allowed, usually $\lVert\delta\rVert\le \varepsilon$.

```python
X_w = np.array([[-2.0, -1.0], [-1.5, -1.4], [-1.0, -0.4], [0.7, 0.8], [1.4, 0.9], [2.0, 1.5]])  # six toy points.
y_w = np.array([-1, -1, -1, 1, 1, 1])  # labels are separated by a diagonal line.
w_w = np.array([1.2, 0.8])  # linear classifier weights.
b_w = -0.1  # bias shifts the boundary.
scores_w = X_w @ w_w + b_w  # one signed score per point.
print("scores:", np.round(scores_w, 3))
print("predictions:", np.where(scores_w >= 0, 1, -1))
assert np.array_equal(np.where(scores_w >= 0, 1, -1), y_w)
```
▶ What you'll see: all six clean points are classified correctly, so any failure below comes from perturbations rather than clean accuracy.

```python
margins_w = y_w * scores_w  # positive means correct, magnitude means distance in score units.
idx_w = 2  # inspect the weakest negative-class point.
eps_w = 0.5  # allowed L2 perturbation radius for the local audit.
print("margins:", np.round(margins_w, 3))
print("chosen margin:", round(float(margins_w[idx_w]), 3), "epsilon:", eps_w)
assert round(float(margins_w[idx_w]), 3) == 1.620
```
▶ What you'll see: point 2 is correct but has the smallest margin, making it a natural attack target.

```python
plt.figure(figsize=(4.6, 3.6))
plt.scatter(X_w[y_w == -1, 0], X_w[y_w == -1, 1], color="crimson", label="class -1")
plt.scatter(X_w[y_w == 1, 0], X_w[y_w == 1, 1], color="teal", label="class +1")
xx_w = np.linspace(-2.4, 2.4, 100)
plt.plot(xx_w, -(w_w[0] * xx_w + b_w) / w_w[1], color="black", label="decision boundary")
circle_w = plt.Circle(X_w[idx_w], eps_w, fill=False, color="orange", linewidth=2)
plt.gca().add_patch(circle_w)
plt.axis("equal"); plt.legend(); plt.title("1: clean classifier and ε-ball"); plt.show()
```
▶ What you'll see: the orange ball is the set an adversary may search; certification asks whether the boundary can enter that ball.

*Why it's done this way:* a margin turns correctness into a signed distance-like number. The perturbation ball makes the adversary's power explicit, so every later claim is tied to one norm and one radius instead of a vague idea of “small change.”

### 2. A worst-case linear attack

For a linear score, the strongest L2 attack is not mysterious. To reduce the true-label margin $y(w^\top x+b)$ as fast as possible, move opposite the gradient $y w$. With an L2 budget $\varepsilon$, the steepest unit direction is $-y w/\lVert w\rVert_2$, so the adversarial point is $x_{adv}=x-\varepsilon y w/\lVert w\rVert_2$.

```python
x0_w = X_w[idx_w]  # point to attack.
y0_w = y_w[idx_w]  # its true label.
dir_w = -y0_w * w_w / np.linalg.norm(w_w)  # L2 steepest margin-reducing direction.
x_adv_w = x0_w + eps_w * dir_w  # use the whole allowed budget.
print("attack direction:", np.round(dir_w, 3))
print("clean x:", x0_w, "adversarial x:", np.round(x_adv_w, 3))
assert round(float(np.linalg.norm(x_adv_w - x0_w)), 3) == 0.500
```
▶ What you'll see: the perturbation has exactly length 0.5 and points toward the decision boundary.

```python
clean_score_w = float(w_w @ x0_w + b_w)
adv_score_w = float(w_w @ x_adv_w + b_w)
print("clean score:", round(clean_score_w, 3), "adv score:", round(adv_score_w, 3))
print("clean pred:", 1 if clean_score_w >= 0 else -1, "adv pred:", 1 if adv_score_w >= 0 else -1)
assert round(adv_score_w, 3) == -0.899
```
▶ What you'll see: the attack weakens the score but does not flip this point at ε = 0.5.

```python
eps_grid_w = np.linspace(0, 1.4, 60)
adv_scores_w = clean_score_w + eps_grid_w * float(w_w @ dir_w)
plt.figure(figsize=(4.8, 3))
plt.plot(eps_grid_w, adv_scores_w, color="purple")
plt.axhline(0, color="black", linewidth=1)
plt.axvline(eps_w, color="orange", linestyle="--", label="ε=0.5")
plt.xlabel("attack radius ε"); plt.ylabel("attacked score")
plt.title("2: score movement under worst-case L2 attack"); plt.legend(); plt.show()
```
▶ What you'll see: the score decreases linearly with ε; the crossing point is the exact radius needed to flip this linear classifier.

*Why it's done this way:* linear functions change most in the direction of their gradient. Under an L2 budget, Cauchy–Schwarz says the largest possible score decrease is $\varepsilon\lVert w\rVert_2$, so the attack direction above is not just a heuristic; it is optimal for this model and norm.

### 3. Adversarial training as a min-max update

Standard training minimizes loss on clean points. Adversarial training changes the objective to “minimize the loss after the worst allowed perturbation.” For our linear logistic model, each step first constructs an adversarial version of the current example, then updates weights on that harder point. This is a tiny min-max loop: the inner maximization finds a damaging $\delta$, and the outer minimization adapts the classifier.

```python
def logistic_loss_grad_w(w, b, x, y):
    z = y * (w @ x + b)
    coeff = -y / (1.0 + np.exp(z))
    return coeff * x, coeff

w_clean_w = np.zeros(2); b_clean_w = 0.0
w_rob_w = np.zeros(2); b_rob_w = 0.0
eta_train_w = 0.2; eps_train_w = 0.35
print("initial clean weights:", w_clean_w, "robust weights:", w_rob_w)
```
▶ What you'll see: both models start from the same zero classifier, so the only difference will be the training rule.

```python
for epoch_w in range(80):
    for i_w in range(len(X_w)):
        gc_w, gb_w = logistic_loss_grad_w(w_clean_w, b_clean_w, X_w[i_w], y_w[i_w])
        w_clean_w -= eta_train_w * gc_w; b_clean_w -= eta_train_w * gb_w
        direction_w = -y_w[i_w] * w_rob_w / (np.linalg.norm(w_rob_w) + 1e-12)
        x_hard_w = X_w[i_w] + eps_train_w * direction_w
        gr_w, grb_w = logistic_loss_grad_w(w_rob_w, b_rob_w, x_hard_w, y_w[i_w])
        w_rob_w -= eta_train_w * gr_w; b_rob_w -= eta_train_w * grb_w
print("clean weights:", np.round(w_clean_w, 3), "bias:", round(b_clean_w, 3))
print("robust weights:", np.round(w_rob_w, 3), "bias:", round(b_rob_w, 3))
assert np.linalg.norm(w_rob_w) > 0 and np.linalg.norm(w_clean_w) > 0
```
▶ What you'll see: the adversarially trained model ends at different weights, because it has repeatedly seen harder, boundary-pushing examples.

```python
def robust_accuracy_w(w, b, X, y, eps):
    margins = y * (X @ w + b)
    worst = margins - eps * np.linalg.norm(w)
    return float(np.mean(worst > 0)), worst

acc_clean_w, worst_clean_w = robust_accuracy_w(w_clean_w, b_clean_w, X_w, y_w, eps_train_w)
acc_rob_w, worst_rob_w = robust_accuracy_w(w_rob_w, b_rob_w, X_w, y_w, eps_train_w)
print("clean robust accuracy:", round(acc_clean_w, 3), "robust-trained robust accuracy:", round(acc_rob_w, 3))
plt.figure(figsize=(5, 3))
plt.bar(np.arange(len(X_w)) - 0.18, worst_clean_w, width=0.36, label="clean training", color="gray")
plt.bar(np.arange(len(X_w)) + 0.18, worst_rob_w, width=0.36, label="adversarial training", color="teal")
plt.axhline(0, color="black", linewidth=1); plt.title("3: worst-case margins after training")
plt.xlabel("point"); plt.ylabel("margin − ε||w||"); plt.legend(); plt.show()
```
▶ What you'll see: adversarial training improves the weakest worst-case margins, even if it does not make every toy point equally safe.

*Why it's done this way:* adversarial training optimizes the quantity deployment cares about: loss after allowed input changes. The inner attack makes the training example harder; the outer gradient step then increases margins where the current classifier is brittle.

### 4. Lipschitz margin certificates

A certificate is a proof with assumptions. If every class score can move by at most $L\lVert\delta\rVert$, then the gap between the predicted class and any rival can shrink by at most $2L\varepsilon$. Therefore a sufficient certificate is $f_y(x)-\max_{k\ne y}f_k(x) > 2L\varepsilon$. For binary linear scores written as two class scores $[0, g(x)]$, the relevant score gap is $|g(x)|$ and a safe L2 Lipschitz bound is $L=\lVert w\rVert_2$.

```python
L_w = float(np.linalg.norm(w_rob_w))
gaps_w = np.abs(X_w @ w_rob_w + b_rob_w)
radii_lip_w = gaps_w / (2 * L_w)
print("Lipschitz L:", round(L_w, 3))
print("certified radii:", np.round(radii_lip_w, 3))
assert np.all(radii_lip_w >= 0)
```
▶ What you'll see: each example receives its own certified radius; smaller score gaps get smaller certificates.

```python
eps_cert_w = 0.35
certified_w = gaps_w > 2 * L_w * eps_cert_w
print("certified at ε=0.35:", certified_w.astype(int))
print("count certified:", int(certified_w.sum()), "of", len(certified_w))
```
▶ What you'll see: only examples whose score gap beats the worst-case movement bound are certified.

```python
plt.figure(figsize=(5, 3))
plt.bar(range(len(radii_lip_w)), radii_lip_w, color=np.where(certified_w, "teal", "crimson"))
plt.axhline(eps_cert_w, color="black", linestyle="--", label="target ε")
plt.title("4: deterministic certified radius by point")
plt.xlabel("point"); plt.ylabel("certified L2 radius"); plt.legend(); plt.show()
```
▶ What you'll see: bars above the dashed line are certified safe for every perturbation of radius 0.35 under the stated bound.

*Why it's done this way:* empirical attacks can miss a stronger adversary, but a Lipschitz bound controls all perturbations in the ball. The factor of 2 appears because the winning score can go down while the rival score can go up, so the gap can close from both sides.

### 5. Randomized smoothing certificates

Randomized smoothing certifies a new classifier: add Gaussian noise to the input many times, classify each noisy copy with a base classifier, and predict the most frequent class. If class A wins with probability $p_A$ and the runner-up has probability $p_B$, the smoothed classifier is certifiably constant inside radius $R=\frac{\sigma}{2}(\Phi^{-1}(p_A)-\Phi^{-1}(p_B))$. We approximate probabilities by Monte Carlo and compute $\Phi^{-1}$ by a small bisection routine.

```python
def normal_cdf_w(z):
    return 0.5 * (1.0 + erf(z / sqrt(2.0)))

def normal_ppf_w(p):
    lo, hi = -8.0, 8.0
    for _ in range(70):
        mid = (lo + hi) / 2.0
        if normal_cdf_w(mid) < p:
            lo = mid
        else:
            hi = mid
    return (lo + hi) / 2.0

print("Φ⁻¹(0.975):", round(normal_ppf_w(0.975), 3))
assert abs(normal_ppf_w(0.975) - 1.96) < 0.01
```
▶ What you'll see: the bisection inverse CDF reproduces the familiar 1.96 normal quantile without SciPy.

```python
sigma_w = 0.6
x_smooth_w = np.array([0.7, 0.8])
rng_smooth_w = np.random.default_rng(1)
noise_w = rng_smooth_w.normal(0, sigma_w, size=(4000, 2))
noisy_scores_w = (x_smooth_w + noise_w) @ w_rob_w + b_rob_w
votes_pos_w = int(np.sum(noisy_scores_w >= 0))
pA_w = votes_pos_w / len(noisy_scores_w)
pB_w = 1.0 - pA_w
radius_smooth_w = 0.5 * sigma_w * (normal_ppf_w(pA_w) - normal_ppf_w(pB_w))
print("positive votes:", votes_pos_w, "of", len(noisy_scores_w))
print("pA:", round(pA_w, 3), "pB:", round(pB_w, 3), "radius:", round(radius_smooth_w, 3))
assert pA_w > 0.8 and radius_smooth_w > 0.4
```
▶ What you'll see: most noisy copies vote positive, producing a nonzero certified radius for the smoothed classifier.

```python
plt.figure(figsize=(4.8, 3.4))
plt.hist(noisy_scores_w, bins=35, color="steelblue", alpha=0.8)
plt.axvline(0, color="black", linewidth=1, label="decision threshold")
plt.title("5: noisy votes behind smoothing")
plt.xlabel("base-classifier score on x + noise"); plt.ylabel("count"); plt.legend(); plt.show()
```
▶ What you'll see: most noisy scores land on the positive side; the margin in vote probability becomes the certificate.

*Why it's done this way:* smoothing converts local geometric robustness into a probability gap under Gaussian noise. A perturbation shifts the noise distribution; the normal quantiles measure how far it can shift before the winning class can lose its probability advantage.

### ✍️ Toy 1 · Signed margins reveal the nearest fragile point

A linear classifier is correct when the signed margin `y * score` is positive. The smallest
positive margin is the point an adversary should inspect first.

```python
import numpy as np  # arrays and small numerical checks.
import matplotlib.pyplot as plt  # one picture per toy.

t1_rng = np.random.default_rng(0)  # seeded generator for reproducible toys.
t1_X = np.array([[-2.0, 0.0], [-1.0, 1.0], [2.0, 1.0]])  # three tiny points.
t1_y = np.array([-1, -1, 1])  # true labels.
t1_w = np.array([1.0, 0.5])  # linear weights.
t1_b = -0.5  # bias term.
t1_scores = t1_X @ t1_w + t1_b  # -> [-2.5 -1.   2. ]
print("scores:", np.round(t1_scores, 3).tolist())  # -> [-2.5, -1.0, 2.0]
t1_pred = np.where(t1_scores >= 0, 1, -1)  # -> [-1 -1  1]
print("predictions:", t1_pred.tolist())  # -> [-1, -1, 1]
t1_margins = t1_y * t1_scores  # -> [2.5 1.  2. ]
print("signed margins:", np.round(t1_margins, 3).tolist())  # -> [2.5, 1.0, 2.0]
t1_min_margin = float(t1_margins.min())  # -> 1.0
print("smallest margin:", round(t1_min_margin, 3))  # -> 1.0
assert np.all(t1_margins > 0)

plt.figure(figsize=(4.6, 3.2))
plt.scatter(t1_X[:, 0], t1_X[:, 1], c=t1_y, cmap="coolwarm", s=80, edgecolor="black")
t1_xs = np.linspace(-2.4, 2.4, 60)
t1_ys = -(t1_w[0] * t1_xs + t1_b) / t1_w[1]
plt.plot(t1_xs, t1_ys, color="black", label="score = 0")
plt.title("Toy 1 · margins are all positive")
plt.xlabel("x0")
plt.ylabel("x1")
plt.legend()
plt.show()
```
▶ What you'll see: all three margins are positive, and the middle negative point has the smallest safety cushion.

### ✍️ Toy 2 · L2 worst-case attack spends the whole budget

For a linear score, the strongest L2 perturbation points opposite the true-label gradient. Its
score decrease is exactly `epsilon * ||w||`.

```python
import numpy as np  # arrays and linear algebra.

t2_rng = np.random.default_rng(0)  # seeded generator for reproducible toys.
t2_x = np.array([0.0, 2.0])  # one clean point.
t2_y = 1  # true label.
t2_w = np.array([3.0, 4.0])  # weight vector with norm 5.
t2_b = -2.0  # bias term.
t2_eps = 0.5  # L2 attack budget.
t2_norm = float(np.linalg.norm(t2_w))  # -> 5.0
print("weight norm:", round(t2_norm, 3))  # -> 5.0
t2_direction = -t2_y * t2_w / t2_norm  # -> [-0.6 -0.8]
print("attack direction:", np.round(t2_direction, 3).tolist())  # -> [-0.6, -0.8]
t2_delta = t2_eps * t2_direction  # -> [-0.3 -0.4]
print("delta:", np.round(t2_delta, 3).tolist())  # -> [-0.3, -0.4]
t2_adv_x = t2_x + t2_delta  # -> [-0.3  1.6]
print("adversarial x:", np.round(t2_adv_x, 3).tolist())  # -> [-0.3, 1.6]
t2_clean_score = float(t2_w @ t2_x + t2_b)  # -> 6.0
print("clean score:", round(t2_clean_score, 3))  # -> 6.0
t2_adv_score = float(t2_w @ t2_adv_x + t2_b)  # -> 3.5
print("attacked score:", round(t2_adv_score, 3))  # -> 3.5
t2_decrease = t2_clean_score - t2_adv_score  # -> 2.5
print("score decrease:", round(t2_decrease, 3))  # -> 2.5
assert abs(t2_decrease - t2_eps * t2_norm) < 1e-9

plt.figure(figsize=(4.6, 2.8))
t2_eps_grid = np.linspace(0.0, 0.8, 50)
t2_scores_grid = t2_clean_score - t2_eps_grid * t2_norm
plt.plot(t2_eps_grid, t2_scores_grid, color="purple")
plt.scatter([t2_eps], [t2_adv_score], color="crimson", zorder=3)
plt.axhline(0.0, color="black", linewidth=1)
plt.title("Toy 2 · linear score drops with ε")
plt.xlabel("ε")
plt.ylabel("worst-case score")
plt.show()
```
▶ What you'll see: the score falls linearly by `2.5`, exactly the L2 budget times the weight norm.

### ✍️ Toy 3 · Flip radii become empirical robust accuracy

A point flips only after the attack radius reaches `margin / ||w||`. Counting points whose flip
radius beats the requested epsilon gives empirical robust accuracy.

```python
import numpy as np  # arrays and means.

t3_rng = np.random.default_rng(0)  # seeded generator for reproducible toys.
t3_margins = np.array([0.4, 1.2, 2.4])  # clean signed margins.
print("margins:", t3_margins.tolist())  # -> [0.4, 1.2, 2.4]
t3_norm = 2.0  # classifier weight norm.
print("weight norm:", round(t3_norm, 3))  # -> 2.0
t3_flip_radii = t3_margins / t3_norm  # -> [0.2 0.6 1.2]
print("flip radii:", np.round(t3_flip_radii, 3).tolist())  # -> [0.2, 0.6, 1.2]
t3_eps = 0.5  # audit radius.
print("audit epsilon:", round(t3_eps, 3))  # -> 0.5
t3_robust = t3_flip_radii > t3_eps  # -> [False  True  True]
print("robust flags:", t3_robust.astype(int).tolist())  # -> [0, 1, 1]
t3_acc = float(t3_robust.mean())  # -> 0.6666666666666666
print("empirical robust accuracy:", round(t3_acc, 3))  # -> 0.667
assert abs(t3_acc - 2 / 3) < 1e-9

plt.figure(figsize=(4.6, 2.8))
plt.bar(["point 0", "point 1", "point 2"], t3_flip_radii, color=["crimson", "teal", "teal"])

```

### ✍️ Toy 4 · Adversarial training updates on the hard point

A min-max step first moves the input in the damaging direction, then takes the logistic gradient
on that harder example.

```python
import numpy as np  # arrays, exponentials, and gradients.

t4_rng = np.random.default_rng(0)  # seeded generator for reproducible toys.
t4_x = np.array([1.0, 2.0])  # clean training point.
t4_y = 1  # true label.
t4_w = np.array([0.6, 0.8])  # current weights.
t4_b = 0.0  # current bias.
t4_eps = 0.5  # adversarial-training radius.
t4_eta = 0.1  # learning rate.
t4_norm = float(np.linalg.norm(t4_w))  # -> 1.0
print("weight norm:", round(t4_norm, 3))  # -> 1.0
t4_direction = -t4_y * t4_w / t4_norm  # -> [-0.6 -0.8]
print("inner attack direction:", np.round(t4_direction, 3).tolist())  # -> [-0.6, -0.8]
t4_x_adv = t4_x + t4_eps * t4_direction  # -> [0.7 1.6]
print("hard example:", np.round(t4_x_adv, 3).tolist())  # -> [0.7, 1.6]
t4_clean_margin = float(t4_y * (t4_w @ t4_x + t4_b))  # -> 2.2
print("clean margin:", round(t4_clean_margin, 3))  # -> 2.2
t4_adv_margin = float(t4_y * (t4_w @ t4_x_adv + t4_b))  # -> 1.7000000000000002
print("hard-example margin:", round(t4_adv_margin, 3))  # -> 1.7
t4_coeff = -t4_y / (1.0 + np.exp(t4_adv_margin))  # -> -0.1544652650835347
print("logistic coeff:", round(float(t4_coeff), 3))  # -> -0.154
t4_grad_w = t4_coeff * t4_x_adv  # -> [-0.10812569 -0.24714442]
print("weight gradient:", np.round(t4_grad_w, 3).tolist())  # -> [-0.108, -0.247]
t4_grad_b = t4_coeff  # -> -0.1544652650835347
print("bias gradient:", round(float(t4_grad_b), 3))  # -> -0.154
t4_w_next = t4_w - t4_eta * t4_grad_w  # -> [0.61081257 0.82471444]
print("updated weights:", np.round(t4_w_next, 3).tolist())  # -> [0.611, 0.825]
t4_b_next = t4_b - t4_eta * t4_grad_b  # -> 0.01544652650835347
print("updated bias:", round(float(t4_b_next), 3))  # -> 0.015
assert t4_adv_margin < t4_clean_margin

plt.figure(figsize=(4.4, 3.0))
plt.scatter([t4_x[0]], [t4_x[1]], s=90, label="clean")
plt.scatter([t4_x_adv[0]], [t4_x_adv[1]], s=90, label="hard")
plt.arrow(t4_x[0], t4_x[1], t4_x_adv[0] - t4_x[0], t4_x_adv[1] - t4_x[1], head_width=0.05, length_includes_head=True)
plt.title("Toy 4 · update uses the adversarial point")
plt.xlabel("x0")
plt.ylabel("x1")
plt.legend()
plt.show()
```
▶ What you'll see: the adversarial point has a smaller margin, so the gradient is computed on the harder example.

### ✍️ Toy 5 · Lipschitz gaps turn into certified radii

If a score gap is larger than the worst possible score movement, the label is certified. The toy
radius is `gap / (2L)` for each example.

```python
import numpy as np  # arrays and norms.

t5_rng = np.random.default_rng(0)  # seeded generator for reproducible toys.
```

## 🛠️ Setup

```python
import numpy as np  # load NumPy for arrays, attacks, training loops, simulation, and numerical checks.
import matplotlib.pyplot as plt  # load Matplotlib for heatmaps, scatter plots, bars, and certificate curves.
from math import erf, sqrt  # use standard-library functions to implement the normal CDF for smoothing.
np.random.seed(0)  # make all random examples reproducible across notebook runs.

def lin_score(X, w, b):  # Compute linear scores for one point or a batch.
    return np.asarray(X) @ np.asarray(w) + b  # Return w dot x plus bias.

def lin_pred(X, w, b):  # Convert linear scores into {-1, +1} labels.
    return np.where(lin_score(X, w, b) >= 0, 1, -1)  # Use zero as the decision boundary.

def l2_attack(x, y, w, eps):  # Build the exact worst-case L2 attack for a linear binary classifier.
    return np.asarray(x) - eps * y * np.asarray(w) / (np.linalg.norm(w) + 1e-12)  # Move opposite the true-label gradient.

def worst_margin(X, y, w, b, eps):  # Compute certified worst-case binary margins under an L2 ball.
    return y * lin_score(X, w, b) - eps * np.linalg.norm(w)  # Cauchy-Schwarz bound for all perturbations.

def normal_cdf(z):  # Standard normal CDF using only the standard library.
    return 0.5 * (1.0 + erf(z / sqrt(2.0)))  # Convert erf into Φ(z).

def normal_ppf(p):  # Invert the standard normal CDF by bisection.
    lo, hi = -8.0, 8.0  # This range covers probabilities extremely close to 0 and 1.
    for _ in range(70):  # Enough iterations for stable lesson-level decimals.
        mid = (lo + hi) / 2.0  # Test the middle quantile.
        if normal_cdf(mid) < p:  # If CDF is too small, move right.
            lo = mid
        else:  # Otherwise move left.
            hi = mid
    return (lo + hi) / 2.0  # Return the final quantile estimate.

def show_boundary(X, y, w, b, title):  # Draw a 2-D linear decision boundary with labeled points.
    plt.figure(figsize=(4.5, 3.5))  # Create a compact plot.
    plt.scatter(X[y == -1, 0], X[y == -1, 1], color="crimson", label="-1")  # Plot negative points.
    plt.scatter(X[y == 1, 0], X[y == 1, 1], color="teal", label="+1")  # Plot positive points.
    xs = np.linspace(np.min(X[:, 0]) - 0.5, np.max(X[:, 0]) + 0.5, 100)  # Boundary x-grid.
    plt.plot(xs, -(w[0] * xs + b) / w[1], color="black", label="boundary")  # Draw w dot x + b = 0.
    plt.title(title); plt.xlabel("x1"); plt.ylabel("x2"); plt.legend(); plt.show()  # Label and display.
```
