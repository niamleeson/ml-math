# 20.10 — Pruning

Pruning removes parameters whose contribution is small enough that we prefer a smaller, faster, or simpler model over unused capacity. In this lesson, we build magnitude pruning, masks, structured pruning, iterative prune-and-fine-tune, sparsity/accuracy tradeoffs, and the lottery-ticket idea from scratch with NumPy.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build pruning one idea at a time. Run each cell in order and read the printed intermediate values — every threshold, mask, sparsity number, and accuracy tradeoff is made visible. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import matplotlib.pyplot as plt  # all walkthrough visualizations.
```

### 1. Magnitude pruning: remove the smallest weights

Magnitude pruning starts with the simplest useful assumption: if a learned weight is very close to zero, then deleting it usually changes the model output less than deleting a large weight. The pruning mask is a binary matrix: `1` means keep the weight, `0` means prune it.

```python
W_w = np.array([[0.02, -0.50, 0.10, 0.80],
                [0.00,  0.04, -0.30, 0.12]])  # toy learned weights.
threshold_w = 0.10  # prune only weights with magnitude strictly below this value.
mask_w = (np.abs(W_w) >= threshold_w).astype(float)  # 1 = kept, 0 = pruned.
W_pruned_w = W_w * mask_w  # zero-out pruned weights while keeping the original shape.
print("mask:\n", mask_w.astype(int))
print("pruned weights:\n", W_pruned_w)
```
▶ What you'll see: the 0.02, 0.00, and 0.04 weights become zero, while weights with magnitude at least 0.10 survive.

```python
n_total_w = W_w.size  # total parameter count.
n_pruned_w = int((mask_w == 0).sum())  # number removed by the threshold.
sparsity_w = n_pruned_w / n_total_w  # removed fraction.
density_w = 1 - sparsity_w  # kept fraction.
print("pruned / total:", n_pruned_w, "/", n_total_w)
print("sparsity:", round(sparsity_w, 3), "density:", round(density_w, 3))
assert round(sparsity_w, 3) == 0.375
```
▶ What you'll see: pruning 3 of 8 weights gives 37.5% sparsity and 62.5% density.

```python
plt.figure(figsize=(5, 3))
plt.hist(W_w.ravel(), bins=np.linspace(-0.6, 0.9, 11), color="steelblue", edgecolor="black")
plt.axvline(-threshold_w, color="crimson", linestyle="--", label="±threshold")
plt.axvline(threshold_w, color="crimson", linestyle="--")
plt.title("1: magnitude pruning keeps weights outside the band")
plt.xlabel("weight value")
plt.ylabel("count")
plt.legend()
plt.show()
```
▶ What you'll see: the red band around zero marks weights whose absolute value is too small to keep.

*Why it's done this way:* a linear layer computes sums like $y=\sum_j w_jx_j$. If $|w_j|$ is tiny, then $|w_jx_j|$ is also tiny for bounded inputs, so the first-order output change from deleting that term is small. Magnitude is not a perfect importance score, but it is cheap, local, and often a strong first approximation.

### 2. Unstructured versus structured pruning

Unstructured pruning removes individual weights wherever they occur. Structured pruning removes whole units such as rows, columns, channels, or blocks. Random zeros can save storage, but hardware often runs faster only when whole slices disappear.

```python
W2_w = np.array([[0.01, -0.02, 0.03, 0.04],
                 [0.80, -0.60, 0.70, 0.90],
                 [0.05,  0.04, -0.02, 0.01]])  # rows can be interpreted as output channels.
unstructured_mask_w = (np.abs(W2_w) >= 0.05).astype(float)  # individual-weight mask.
row_scores_w = np.linalg.norm(W2_w, axis=1)  # channel importance by row L2 norm.
print("row L2 scores:", np.round(row_scores_w, 3))
print("unstructured sparsity:", round(float((unstructured_mask_w == 0).mean()), 3))
```
▶ What you'll see: individual zeros are scattered, while row norms reveal one strong channel and two weak channels.

```python
keep_rows_w = row_scores_w >= 0.10  # structured rule: keep channels with enough total energy.
structured_mask_w = keep_rows_w[:, None].astype(float) * np.ones_like(W2_w)  # broadcast row keep/drop.
W_structured_w = W2_w * structured_mask_w
print("keep rows:", keep_rows_w.astype(int))
print("structured-pruned weights:\n", W_structured_w)
assert int((~keep_rows_w).sum()) == 2
```
▶ What you'll see: two whole rows disappear, leaving one dense row rather than many scattered zeros.

```python
fig, ax = plt.subplots(1, 2, figsize=(7, 3))
ax[0].imshow(unstructured_mask_w, cmap="Greys", vmin=0, vmax=1)
ax[0].set_title("unstructured mask")
ax[1].imshow(structured_mask_w, cmap="Greys", vmin=0, vmax=1)
ax[1].set_title("structured row mask")
for a in ax:
    a.set_xlabel("input weight")
    a.set_ylabel("output channel")
plt.suptitle("2: random zeros vs removable channels")
plt.show()
```
▶ What you'll see: the unstructured mask has holes; the structured mask removes entire rows that a dense runtime can skip.

*Why it's done this way:* sparsity changes arithmetic only when the implementation can avoid multiplying by zero. Unstructured masks minimize parameter count for a chosen accuracy loss, but structured masks match matrix shapes and hardware kernels, so they are more likely to reduce latency.

### 3. Iterative pruning plus fine-tuning

A single aggressive prune can damage accuracy because weights interact. Iterative pruning removes a little at a time, then fine-tunes the surviving weights so the network can redistribute responsibility before the next cut.

```python
def sigmoid_w(z):
    return 1 / (1 + np.exp(-z))

def mlp_forward_w(X, params, masks):
    W1, b1, W2, b2 = params
    M1, M2 = masks
    H = np.tanh(X @ (W1 * M1) + b1)
    P = sigmoid_w(H @ (W2 * M2) + b2)
    return H, P

X_w = np.array([[-1., -1.], [-1., 1.], [1., -1.], [1., 1.]])
y_w = np.array([[0.], [1.], [1.], [0.]])  # XOR labels.
rng_w = np.random.default_rng(0)
params_w = [rng_w.normal(scale=0.7, size=(2, 6)), np.zeros((1, 6)), rng_w.normal(scale=0.7, size=(6, 1)), np.zeros((1, 1))]
masks_w = [np.ones_like(params_w[0]), np.ones_like(params_w[2])]
print("tiny MLP weights:", params_w[0].shape, params_w[2].shape)
```
▶ What you'll see: a two-layer NumPy MLP with 18 prunable weights and tiny XOR data.

```python
def train_steps_w(params, masks, steps=1200, lr=0.25):
    W1, b1, W2, b2 = params
    M1, M2 = masks
    for _ in range(steps):
        H, P = mlp_forward_w(X_w, params, masks)
        dZ2 = (P - y_w) / len(y_w)
        dW2 = H.T @ dZ2
        db2 = np.sum(dZ2, axis=0, keepdims=True)
        dH = dZ2 @ (W2 * M2).T
        dZ1 = dH * (1 - H ** 2)
        dW1 = X_w.T @ dZ1
        db1 = np.sum(dZ1, axis=0, keepdims=True)
        W1 -= lr * dW1 * M1
        b1 -= lr * db1
        W2 -= lr * dW2 * M2
        b2 -= lr * db2
    return [W1, b1, W2, b2]

def accuracy_w(params, masks):
    return float(np.mean((mlp_forward_w(X_w, params, masks)[1] >= 0.5) == y_w))

params_w = train_steps_w(params_w, masks_w, steps=2500, lr=0.25)
base_acc_w = accuracy_w(params_w, masks_w)
print("baseline accuracy:", base_acc_w)
assert base_acc_w == 1.0
```
▶ What you'll see: the small network fits XOR perfectly before pruning.

```python
def prune_fraction_w(params, masks, frac):
    W1, b1, W2, b2 = params
    M1, M2 = masks
    alive = np.concatenate([np.abs(W1[M1 == 1]), np.abs(W2[M2 == 1])])
    k = int(np.floor(frac * alive.size))
    if k > 0:
        cutoff = np.sort(alive)[k - 1]
        M1 = M1 * (np.abs(W1) > cutoff)
        M2 = M2 * (np.abs(W2) > cutoff)
    return [M1, M2]

sparsities_w, accuracies_w = [0.0], [base_acc_w]
for round_w in range(3):
    masks_w = prune_fraction_w(params_w, masks_w, 0.25)
    before_ft_w = accuracy_w(params_w, masks_w)
    params_w = train_steps_w(params_w, masks_w, steps=700, lr=0.18)
    after_ft_w = accuracy_w(params_w, masks_w)
    sparsities_w.append(float(1 - (masks_w[0].sum() + masks_w[1].sum()) / (masks_w[0].size + masks_w[1].size)))
    accuracies_w.append(after_ft_w)
    print(f"round {round_w+1}: acc before fine-tune={before_ft_w:.2f}, after={after_ft_w:.2f}")
```
▶ What you'll see: pruning may hurt immediately, and fine-tuning often recovers some or all performance.

```python
plt.figure(figsize=(5, 3))
plt.plot(sparsities_w, accuracies_w, marker="o", color="seagreen")
plt.xlabel("sparsity")
plt.ylabel("XOR accuracy")
plt.ylim(0, 1.05)
plt.title("3: iterative prune + fine-tune")
plt.show()
```
▶ What you'll see: accuracy stays high for early pruning rounds, then can drop when too few weights remain.

*Why it's done this way:* pruning changes the function, while fine-tuning re-optimizes the remaining subnetwork under the new constraint. Iteration is safer because each step asks the model to solve a nearby problem instead of jumping from dense to heavily sparse in one shock.

### 4. Sparsity-accuracy-cost curves

Pruning is a production decision, so the key plot is not just “how many zeros?” It is accuracy versus sparsity, often with a cost proxy such as dense cost multiplied by density before sparse overhead.

```python
base_acc4_w = 0.820
prune_loss_w = 0.012
fine_tune_gain_w = 0.007
pruned_acc_w = base_acc4_w - prune_loss_w
recovered_acc_w = pruned_acc_w + fine_tune_gain_w
print("base:", base_acc4_w, "after prune:", pruned_acc_w, "after fine-tune:", recovered_acc_w)
print("gap from baseline:", round(base_acc4_w - recovered_acc_w, 3))
assert round(recovered_acc_w, 3) == 0.815
```
▶ What you'll see: accuracy drops from 0.820 to 0.808, then fine-tuning recovers to 0.815.

```python
sparsity_grid_w = np.array([0.00, 0.20, 0.35, 0.50, 0.70, 0.85])
accuracy_grid_w = np.array([0.820, 0.820, 0.815, 0.807, 0.770, 0.610])
dense_cost_w = 100
cost_proxy_w = dense_cost_w * (1 - sparsity_grid_w)
print("cost proxy at 35% sparsity:", cost_proxy_w[2])
assert cost_proxy_w[2] == 65
```
▶ What you'll see: 35% sparsity means 65% density, so the ideal multiply-add proxy is 65 before overhead.

```python
fig, ax1 = plt.subplots(figsize=(5, 3))
ax1.plot(sparsity_grid_w, accuracy_grid_w, marker="o", color="seagreen", label="accuracy")
ax1.set_xlabel("sparsity")
ax1.set_ylabel("accuracy", color="seagreen")
ax2 = ax1.twinx()
ax2.plot(sparsity_grid_w, cost_proxy_w, marker="s", color="purple", label="cost proxy")
ax2.set_ylabel("ideal cost", color="purple")
plt.title("4: sparsity vs accuracy and cost")
plt.show()
```
▶ What you'll see: the useful region is the elbow where cost falls a lot before accuracy collapses.

*Why it's done this way:* sparsity is a constraint, not the final objective. A pruning plan is attractive only if the accuracy loss is acceptable and the deployment stack converts density reduction into real memory, bandwidth, or latency gains.

### 5. Lottery-ticket hypothesis

The lottery-ticket hypothesis says that inside an overparameterized random network there may be a sparse subnetwork whose original initialization can train well when isolated. The “ticket” is not just the final sparse mask; it is the mask paired with the lucky initial weights.

```python
rng5_w = np.random.default_rng(5)
initial_w = rng5_w.normal(scale=0.4, size=20)  # pretend these are initial weights.
trained_w = initial_w + rng5_w.normal(scale=0.15, size=20)  # pretend training moved them.
keep_mask5_w = (np.abs(trained_w) >= np.quantile(np.abs(trained_w), 0.60)).astype(float)  # keep top 40% by final magnitude.
print("kept weights:", int(keep_mask5_w.sum()), "of", keep_mask5_w.size)
print("ticket sparsity:", round(float((keep_mask5_w == 0).mean()), 2))
assert int(keep_mask5_w.sum()) == 8
```
▶ What you'll see: the mask keeps 8 of 20 weights, a 60% sparse subnetwork.

```python
rewound_ticket_w = initial_w * keep_mask5_w  # reset kept weights to their original values.
random_reinit_w = rng5_w.normal(scale=0.4, size=20) * keep_mask5_w  # same sparse shape, different initial values.
print("ticket norm:", round(float(np.linalg.norm(rewound_ticket_w)), 3))
print("random sparse norm:", round(float(np.linalg.norm(random_reinit_w)), 3))
```
▶ What you'll see: both subnetworks have the same number of weights, but different starting coordinates.

```python
plt.figure(figsize=(5, 3))
plt.scatter(initial_w, trained_w, c=keep_mask5_w, cmap="coolwarm", s=60)
plt.axhline(0, color="gray", linewidth=0.5)
plt.axvline(0, color="gray", linewidth=0.5)
plt.title("5: final mask selects a sparse ticket")
plt.xlabel("initial weight")
plt.ylabel("trained weight")
plt.show()
```
▶ What you'll see: highlighted kept points are the weights whose trained magnitudes caused them to survive.

*Why it's done this way:* the hypothesis separates architecture search from optimization. If the original initialization matters, then pruning after training can reveal a sparse trainable subnetwork, not merely a compressed final model. This explains why “same mask, random reinit” can behave worse than “same mask, rewound weights.”

### Basic 1 — Count sparsity from a mask

**Goal.** Compute sparsity from kept and pruned weights, because pruning decisions are tracked as ratios rather than only raw counts. We build it in 2 steps.

```python
weights_b1 = np.array([0.02, -0.50, 0.10, 0.80]) # define the four worked weights from the lesson arithmetic.
threshold_b1 = 0.10 # choose the magnitude threshold used in the production calculation.
mask_b1 = (np.abs(weights_b1) >= threshold_b1).astype(int) # keep weights whose absolute value is at least the threshold.
print("weights:", weights_b1) # inspect the candidate parameters.
print("keep mask:", mask_b1) # inspect 1 for kept and 0 for pruned.
```
▶ What you'll see: only the 0.02 weight is pruned because 0.10 is kept by the >= rule.

```python
sparsity_b1 = float(np.mean(mask_b1 == 0)) # compute the fraction of weights removed.
density_b1 = 1 - sparsity_b1 # compute the fraction that remains active.
print("sparsity:", round(sparsity_b1, 2), "density:", round(density_b1, 2)) # inspect both ratios.
assert density_b1 == 0.75 # verify the lesson number: 3 of 4 weights survive.
plt.figure(figsize=(4, 3)) # create a compact mask plot.
plt.bar(np.arange(len(weights_b1)), np.abs(weights_b1), color=np.where(mask_b1, "seagreen", "crimson")) # show kept and pruned magnitudes.
plt.axhline(threshold_b1, color="black", linestyle="--") # mark the threshold.
plt.title("Basic 1: magnitude threshold") # title the plot.
plt.ylabel("|weight|") # label the magnitude axis.
plt.show() # display the bar chart.
```
▶ What you'll see: the red bar below the dashed line is the only pruned parameter.

👀 Takeaway: sparsity is the removed fraction, while density is the active fraction used in cost estimates.

### Basic 2 — Apply a binary pruning mask

**Goal.** Zero out pruned weights without changing tensor shape, because most pruning implementations store a dense tensor plus a mask during training. We build it in 2 steps.

```python
W_b2 = np.array([[0.2, -0.03, 0.5], [0.01, -0.4, 0.08]]) # create a small weight matrix.
mask_b2 = (np.abs(W_b2) >= 0.05).astype(float) # define a magnitude mask with threshold 0.05.
print("mask:\n", mask_b2.astype(int)) # inspect which weights survive.
```
▶ What you'll see: entries below 0.05 in absolute value are marked with zeros.

```python
W_pruned_b2 = W_b2 * mask_b2 # multiply by the mask so pruned coordinates become exactly zero.
print("pruned W:\n", W_pruned_b2) # inspect the masked matrix.
assert int((W_pruned_b2 == 0).sum()) == 2 # verify exactly two weights were removed.
plt.figure(figsize=(4, 3)) # create a heatmap figure.
plt.imshow(mask_b2, cmap="Greys", vmin=0, vmax=1) # visualize the binary mask.

plt.show() # display the mask.
```
▶ What you'll see: the mask heatmap shows the sparse pattern applied to the matrix.

👀 Takeaway: pruning is usually implemented as `W * mask`, which preserves shapes while disabling selected weights.

### Basic 5 — Compare output before and after pruning

**Goal.** Measure the output perturbation from pruning, because a mask is acceptable only if it changes predictions little enough. We build it in 2 steps.

```python
x_b5 = np.array([1.0, -2.0, 0.5]) # define one input vector.
w_b5 = np.array([0.6, 0.02, -0.4]) # define a linear model with one tiny weight.
mask_b5 = (np.abs(w_b5) >= 0.05).astype(float) # prune the tiny middle weight.
y_dense_b5 = float(x_b5 @ w_b5) # compute the original output.
y_pruned_b5 = float(x_b5 @ (w_b5 * mask_b5)) # compute the masked output.
print("dense output:", round(y_dense_b5, 3), "pruned output:", round(y_pruned_b5, 3)) # compare predictions.
```
▶ What you'll see: deleting the tiny weight changes the output by only 0.04 for this input.

```python
delta_b5 = y_pruned_b5 - y_dense_b5 # compute the signed prediction change.
print("output change:", round(delta_b5, 3)) # inspect perturbation from the mask.
assert round(abs(delta_b5), 3) == 0.04 # verify the exact small change.
plt.figure(figsize=(4, 3)) # create a comparison figure.
plt.bar(["dense", "pruned"], [y_dense_b5, y_pruned_b5], color=["gray", "seagreen"]) # compare outputs.
plt.title("Basic 5: pruning perturbs outputs") # title the plot.
plt.ylabel("linear output") # label the output axis.
plt.show() # display the bar chart.
```
▶ What you'll see: the bars are nearly equal because the removed contribution was small.

👀 Takeaway: pruning is justified by small function change, not by small parameter values alone.

### Basic 6 — Keep the top-k magnitudes

**Goal.** Prune to a target density, because production constraints often specify how many weights may remain. We build it in 2 steps.

```python
weights_b6 = np.array([0.01, -0.7, 0.3, 0.02, -0.4, 0.9]) # define six candidate weights.
keep_b6 = 3 # choose exactly three survivors.
order_b6 = np.argsort(np.abs(weights_b6))[::-1] # sort indices from largest magnitude to smallest.
print("largest-magnitude order:", order_b6) # inspect ranking used by top-k pruning.
```
▶ What you'll see: the largest weights are selected before any threshold is formed.

```python
mask_b6 = np.zeros_like(weights_b6, dtype=float) # initialize all weights as pruned.
mask_b6[order_b6[:keep_b6]] = 1.0 # keep the top-k magnitudes.
print("top-k mask:", mask_b6.astype(int)) # inspect the exact survivors.
assert int(mask_b6.sum()) == 3 # verify target density count.
plt.figure(figsize=(4, 3)) # create a rank plot.
plt.bar(np.arange(len(weights_b6)), np.abs(weights_b6), color=np.where(mask_b6, "seagreen", "crimson")) # color kept and pruned weights.
plt.title("Basic 6: keep top-k magnitudes") # title the plot.
plt.ylabel("|weight|") # label magnitude axis.
plt.show() # display the bar chart.
```
▶ What you'll see: exactly three bars are green, regardless of the absolute threshold value.

👀 Takeaway: top-k pruning controls density directly, while threshold pruning controls a magnitude cutoff.

### Basic 7 — Row-wise structured pruning

**Goal.** Remove an entire output channel by row norm, because structured pruning changes layer shape in hardware-friendly chunks. We build it in 2 steps.

```python
W_b7 = np.array([[0.02, 0.01, -0.02], [0.8, -0.6, 0.7], [0.04, 0.03, 0.02]]) # define three output rows.
row_norm_b7 = np.linalg.norm(W_b7, axis=1) # compute each row's L2 energy.
print("row norms:", np.round(row_norm_b7, 3)) # inspect channel importance.
```
▶ What you'll see: the middle row has far more energy than the others.

```python
keep_rows_b7 = row_norm_b7 >= 0.08 # keep only rows whose total magnitude is large enough.
W_struct_b7 = W_b7[keep_rows_b7] # physically remove pruned rows for the structured demo.
print("kept rows:", keep_rows_b7.astype(int)) # inspect row mask.
print("new shape:", W_struct_b7.shape) # inspect the smaller layer shape.
assert W_struct_b7.shape == (1, 3) # verify only one output channel remains.
plt.figure(figsize=(4, 3)) # create a row-score chart.
plt.bar(["row0", "row1", "row2"], row_norm_b7, color=np.where(keep_rows_b7, "seagreen", "crimson")) # show kept/pruned rows.
plt.title("Basic 7: structured row pruning") # title the plot.
plt.ylabel("row L2 norm") # label the score axis.
plt.show() # display the chart.
```
▶ What you'll see: two rows are removed as complete channels.

### Advanced 1 — Iterative prune-and-fine-tune a tiny MLP

**Goal.** Train a tiny XOR MLP, prune repeatedly, and fine-tune under masks, because iterative pruning is safer than one large deletion. We build it in 5 steps.

```python

y_a1 = np.array([[0.], [1.], [1.], [0.]]) # XOR labels.
rng_a1 = np.random.default_rng(11) # reproducible initialization.
W1_a1 = rng_a1.normal(scale=0.7, size=(2, 8)) # input-to-hidden weights.
b1_a1 = np.zeros((1, 8)) # hidden bias.
W2_a1 = rng_a1.normal(scale=0.7, size=(8, 1)) # hidden-to-output weights.
b2_a1 = np.zeros((1, 1)) # output bias.
M1_a1 = np.ones_like(W1_a1) # dense first-layer mask.
M2_a1 = np.ones_like(W2_a1) # dense second-layer mask.
print("prunable weights:", W1_a1.size + W2_a1.size) # inspect model size.
```
▶ What you'll see: the MLP has 24 prunable weights before masks remove any.

```python
def sig_a1(z):
    return 1 / (1 + np.exp(-z))

def forward_a1(W1, b1, W2, b2, M1, M2):
    H = np.tanh(X_a1 @ (W1 * M1) + b1) # hidden activations with masked first layer.
    P = sig_a1(H @ (W2 * M2) + b2) # output probabilities with masked second layer.
    return H, P

def train_a1(W1, b1, W2, b2, M1, M2, steps, lr):
    for _ in range(steps):
        H, P = forward_a1(W1, b1, W2, b2, M1, M2) # forward pass.
        dZ2 = (P - y_a1) / len(y_a1) # binary-cross-entropy sigmoid gradient.
        dW2 = H.T @ dZ2 # second-layer weight gradient.
        db2 = np.sum(dZ2, axis=0, keepdims=True) # output-bias gradient.
        dH = dZ2 @ (W2 * M2).T # backpropagate through masked second layer.
        dZ1 = dH * (1 - H ** 2) # tanh derivative.
        dW1 = X_a1.T @ dZ1 # first-layer weight gradient.
        db1 = np.sum(dZ1, axis=0, keepdims=True) # hidden-bias gradient.
        W1 -= lr * dW1 * M1 # update only live first-layer weights.
        b1 -= lr * db1 # update hidden bias.
        W2 -= lr * dW2 * M2 # update only live second-layer weights.
        b2 -= lr * db2 # update output bias.
    return W1, b1, W2, b2

W1_a1, b1_a1, W2_a1, b2_a1 = train_a1(W1_a1, b1_a1, W2_a1, b2_a1, M1_a1, M2_a1, 3000, 0.22) # dense pretraining.
acc_a1 = float(np.mean((forward_a1(W1_a1, b1_a1, W2_a1, b2_a1, M1_a1, M2_a1)[1] >= 0.5) == y_a1)) # baseline accuracy.
print("dense accuracy:", acc_a1) # inspect fit before pruning.
assert acc_a1 == 1.0 # verify dense model solved XOR.
```
▶ What you'll see: the printed or plotted values expose the intermediate pruning calculation for this step.

### Advanced 2 — One-shot versus iterative pruning

**Goal.** Compare one large prune with several smaller prune-and-recover steps on the same toy model, because gradual compression can preserve accuracy better. We build it in 5 steps.

```python
base_b1_a2 = np.zeros((1, 8)) # base hidden bias.

base_b2_a2 = np.zeros((1, 1)) # base output bias.

```
▶ What you'll see: both pruning strategies will start from the same trained dense model.

```python
def sig_a2(z):
    return 1 / (1 + np.exp(-z))

def train_model_a2(W1, b1, W2, b2, M1, M2, steps, lr):
    for _ in range(steps):
        H = np.tanh(X_a2 @ (W1 * M1) + b1); P = sig_a2(H @ (W2 * M2) + b2) # forward.
        dZ2 = (P - y_a2) / len(y_a2); dW2 = H.T @ dZ2; db2 = np.sum(dZ2, axis=0, keepdims=True) # output gradients.
        dZ1 = (dZ2 @ (W2 * M2).T) * (1 - H ** 2); dW1 = X_a2.T @ dZ1; db1 = np.sum(dZ1, axis=0, keepdims=True) # hidden gradients.
        W1 -= lr * dW1 * M1; b1 -= lr * db1; W2 -= lr * dW2 * M2; b2 -= lr * db2 # masked update.
    return W1, b1, W2, b2

def acc_model_a2(W1, b1, W2, b2, M1, M2):
    H = np.tanh(X_a2 @ (W1 * M1) + b1); P = sig_a2(H @ (W2 * M2) + b2) # forward.
    return float(np.mean((P >= 0.5) == y_a2)) # classification accuracy.
```

```python
    k = int(np.floor(target * flat.size)) # number to remove.

    return (np.abs(W1) > cutoff).astype(float), (np.abs(W2) > cutoff).astype(float) # masks.
```
