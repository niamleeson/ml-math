# 24.7 — Ant Colony Optimization

Ant colony optimization (ACO) is swarm intelligence for discrete construction problems: paths, schedules, assignments, and tours assembled one choice at a time. In this lesson, you will implement ACO for a tiny traveling-salesperson problem from scratch, inspect the transition-probability math, and visualize how pheromone memory is reinforced, evaporated, and converted into better tours.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build ant colony optimization one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including transition probabilities and pheromone updates, is spelled out. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, distances, probabilities, and small numerical checks.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for stochastic ant choices.
```

### 1. Graph representations: edges are where memory lives

ACO starts by turning the problem into a graph. For the traveling-salesperson problem (TSP), each city is a node and each possible move is an edge. The important modeling decision is that pheromone is stored on **edges**, not inside an ant. That edge memory is why later ants can reuse good pieces of earlier tours.

```python
coords_w = np.array([[0.0, 0.0], [1.0, 0.2], [1.3, 1.2], [0.2, 1.0], [0.6, 0.55]])  # five city coordinates.
n_w = len(coords_w)  # number of cities in the toy TSP graph.
dist_w = np.linalg.norm(coords_w[:, None, :] - coords_w[None, :, :], axis=2)  # pairwise Euclidean distances.
np.fill_diagonal(dist_w, np.inf)  # self-moves are forbidden, so their distance is infinite.
pher_w = np.ones((n_w, n_w))  # start every directed edge with equal pheromone.
np.fill_diagonal(pher_w, 0.0)  # self-edges have no pheromone.
print("distance matrix:\n", np.round(dist_w, 2))  # inspect geometry available to ants.
print("initial pheromone off-diagonal mean:", round(float(pher_w[pher_w > 0].mean()), 2))  # all equal.
```
▶ What you'll see: a complete graph of five cities, with equal starting pheromone on every non-self edge.

```python
plt.figure(figsize=(4.4, 3.6))  # create the first graph visualization.
for i_w in range(n_w):  # draw every undirected edge with uniform initial thickness.
    for j_w in range(i_w + 1, n_w):
        plt.plot([coords_w[i_w, 0], coords_w[j_w, 0]], [coords_w[i_w, 1], coords_w[j_w, 1]], color="gray", alpha=0.35, linewidth=1.0)
plt.scatter(coords_w[:, 0], coords_w[:, 1], s=80, color="crimson", zorder=3)  # draw cities.
for i_w, (x_w, y_w) in enumerate(coords_w):
    plt.text(x_w + 0.03, y_w + 0.03, str(i_w))  # label each city.
plt.title("1: complete TSP graph with equal pheromone")
plt.axis("equal"); plt.show()
```
▶ What you'll see: every city can connect to every other city, and no edge is preferred yet.

*Why it's done this way: ACO stores learned information on solution components. For TSP, the reusable components are edges, so pheromone belongs in an edge matrix.*

### 2. Probability distributions: pheromone and heuristic desirability vote together

From the current city $i$, an ant chooses an unvisited city $j$ with

$$P(i\to j)=\frac{\tau_{ij}^{\alpha}\eta_{ij}^{\beta}}{\sum_{k\in A_i}\tau_{ik}^{\alpha}\eta_{ik}^{\beta}},\qquad \eta_{ij}=1/d_{ij}.$$ 

The numerator is a score: pheromone says what worked historically, and heuristic desirability says what looks locally short right now. The denominator normalizes those scores into a probability distribution over available moves.

```python
current_w = 0  # start at city 0.
available_w = np.array([1, 2, 3, 4])  # unvisited cities.
alpha_w, beta_w = 1.0, 2.0  # let distance matter strongly while pheromone is still equal.
eta_w = 1.0 / dist_w  # inverse distance heuristic; shorter edges have larger eta.
scores_w = (pher_w[current_w, available_w] ** alpha_w) * (eta_w[current_w, available_w] ** beta_w)  # transition scores.
probs_w = scores_w / scores_w.sum()  # normalized probabilities.
print("available:", available_w)  # inspect candidate cities.
print("scores:", np.round(scores_w, 3))  # inspect unnormalized votes.
print("probabilities:", np.round(probs_w, 3), "sum=", round(float(probs_w.sum()), 3))  # verify distribution.
assert abs(float(probs_w.sum()) - 1.0) < 1e-12  # probabilities must sum to one.
```
▶ What you'll see: city 4 is closest to city 0, so it receives the largest transition probability.

```python
plt.figure(figsize=(4.5, 3.2))  # create a probability bar chart.
plt.bar([f"0→{j}" for j in available_w], probs_w, color="teal")  # visualize next-step probabilities.
plt.ylabel("P(next city)")
plt.title("2: normalized ACO transition probabilities")
plt.ylim(0, 1); plt.show()
```
▶ What you'll see: all moves remain possible, but shorter edges get more probability when pheromone is tied.

*Why it's done this way: probabilistic choice balances exploitation and exploration — the best-looking edge is favored without making the algorithm greedily deterministic.*

### 3. Constructing full tours: simple ants build complete solutions

An ant repeats the transition rule until every city is visited, then returns to the start. A full tour is scored by total length. The ant itself is simple; useful intelligence emerges because many tours deposit pheromone on their edges afterward.

```python
def pick_next_w(rng, probs, choices):  # sample one available city from a probability vector.
    return int(rng.choice(choices, p=probs))

def tour_length_w(tour, distances):  # compute closed-tour length.
    return float(sum(distances[tour[k], tour[(k + 1) % len(tour)]] for k in range(len(tour))))

rng_w = np.random.default_rng(2)  # local generator for one reproducible ant.
tour_w = [0]  # start the tour at city 0.
while len(tour_w) < n_w:  # keep choosing until every city has appeared once.
    avail_w = np.array([j for j in range(n_w) if j not in tour_w])  # remaining cities.
    score_w = (pher_w[tour_w[-1], avail_w] ** alpha_w) * (eta_w[tour_w[-1], avail_w] ** beta_w)  # ACO scores.
    prob_w = score_w / score_w.sum()  # probabilities over remaining cities.
    tour_w.append(pick_next_w(rng_w, prob_w, avail_w))  # stochastic next city.
length_w = tour_length_w(tour_w, dist_w)  # closed-loop tour length.
print("sample ant tour:", tour_w, "length:", round(length_w, 3))  # inspect built solution.
assert sorted(tour_w) == list(range(n_w))  # every city appears exactly once.
```
▶ What you'll see: one ant constructs a valid tour without backtracking or exhaustive search.

```python
plt.figure(figsize=(4.4, 3.6))  # create a tour visualization.
for k_w in range(n_w):  # draw the selected tour edges.
    a_w, b_w = tour_w[k_w], tour_w[(k_w + 1) % n_w]
    plt.plot([coords_w[a_w, 0], coords_w[b_w, 0]], [coords_w[a_w, 1], coords_w[b_w, 1]], color="darkorange", linewidth=3)
plt.scatter(coords_w[:, 0], coords_w[:, 1], s=80, color="crimson", zorder=3)
for i_w, (x_w, y_w) in enumerate(coords_w):
    plt.text(x_w + 0.03, y_w + 0.03, str(i_w))
plt.title(f"3: one stochastic ant tour, length={length_w:.3f}")
plt.axis("equal"); plt.show()
```
▶ What you'll see: the ant produces a complete loop through all cities, not just a single edge choice.

*Why it's done this way: combinatorial optimization needs whole feasible solutions; edge probabilities are only useful because repeated choices assemble a complete tour to evaluate.*

### 4. Reinforcement: good tours deposit more pheromone

After tours are scored, good tours reinforce their edges. A common deposit is $Q/L$, where $L$ is tour length, so shorter tours add more pheromone. The update is symmetric for undirected TSP because traveling $i\to j$ and $j\to i$ uses the same road.

```python
Q_w = 1.0  # deposit scale.
deposit_w = np.zeros_like(pher_w)  # start with no deposits.
for k_w in range(n_w):  # add Q / length to every edge in the sampled tour.
    a_w, b_w = tour_w[k_w], tour_w[(k_w + 1) % n_w]
    deposit_w[a_w, b_w] += Q_w / length_w
    deposit_w[b_w, a_w] += Q_w / length_w
print("deposit per used edge:", round(Q_w / length_w, 3))  # shorter tours deposit more.
print("nonzero deposit edges:", int(np.sum(deposit_w > 0)))  # two directions for each selected edge.
assert int(np.sum(deposit_w > 0)) == 2 * n_w  # undirected tour stored symmetrically.
```
▶ What you'll see: exactly the tour edges receive deposit, and shorter length means larger reward per edge.

```python
plt.figure(figsize=(4.4, 3.4))  # create a deposit heatmap.
plt.imshow(deposit_w, cmap="magma")  # visualize which edge pairs received pheromone.
plt.colorbar(label="deposit Δτ")
plt.title("4: pheromone deposited on the tour edges")
plt.xlabel("to city"); plt.ylabel("from city")
plt.show()
```
▶ What you'll see: a sparse heatmap where only the selected tour edges light up.

*Why it's done this way: tying deposit to inverse tour length makes pheromone represent solution quality rather than mere frequency of use.*

### 5. Evaporation: forgetful memory prevents early lock-in

The full pheromone update is

$$\tau_{ij}\leftarrow(1-\rho)\tau_{ij}+\Delta\tau_{ij}.$$ 

Evaporation multiplies every edge by $(1-\rho)$ before deposits are added. Without evaporation, the first lucky route can dominate forever. With evaporation, old evidence fades unless it keeps being supported by good tours.

```python
rho_w = 0.25  # evaporate 25% of existing pheromone.
old_edge_w = float(pher_w[0, 1])  # inspect one edge before update.
updated_w = (1 - rho_w) * pher_w + deposit_w  # evaporate all edges, then add tour deposits.
np.fill_diagonal(updated_w, 0.0)  # keep self-edges forbidden.
print("edge 0→1 before:", old_edge_w, "after:", round(float(updated_w[0, 1]), 3))  # either evaporated only or reinforced.
print("min/max off-diagonal:", round(float(updated_w[updated_w > 0].min()), 3), round(float(updated_w.max()), 3))  # inspect spread.
assert np.all(updated_w >= 0)  # pheromone stays nonnegative.
```
▶ What you'll see: unused edges shrink, while used tour edges can remain larger after deposit.

```python
fig, ax_w = plt.subplots(1, 2, figsize=(7.2, 3))  # compare before and after update.
ax_w[0].imshow(pher_w, cmap="viridis", vmin=0, vmax=updated_w.max()); ax_w[0].set_title("before")
img_w = ax_w[1].imshow(updated_w, cmap="viridis", vmin=0, vmax=updated_w.max()); ax_w[1].set_title("after evaporation + deposit")
for a_w in ax_w:
    a_w.set_xlabel("to city"); a_w.set_ylabel("from city")
fig.colorbar(img_w, ax=ax_w, label="pheromone")
plt.suptitle("5: pheromone matrix update")
plt.show()
```
▶ What you'll see: pheromone memory becomes uneven but does not erase unused edges to zero.

*Why it's done this way: evaporation makes the colony's memory adaptive, so new evidence can overturn old luck while reinforced edges remain attractive.*

### 6. Iteration: many ants turn local choices into global search

One ACO iteration builds several tours, evaporates the matrix, and deposits pheromone from the better tours. Repeating that loop creates feedback: good edges become more likely, but stochastic sampling still probes alternatives.

```python
def build_tour_w(rng, pheromone, eta, alpha, beta, start=0):  # build one TSP tour by ACO probabilities.
    tour = [start]
    while len(tour) < len(pheromone):
        avail = np.array([j for j in range(len(pheromone)) if j not in tour])
        scores = (pheromone[tour[-1], avail] ** alpha) * (eta[tour[-1], avail] ** beta)
        probs = scores / scores.sum()
        tour.append(int(rng.choice(avail, p=probs)))
    return tour

rng_loop_w = np.random.default_rng(3)  # reproducible colony.
pher_loop_w = np.ones((n_w, n_w)) - np.eye(n_w)  # reset pheromone.
best_lengths_w = []  # record best-so-far length.
best_tour_w = None  # track best tour.
best_len_w = np.inf  # initialize best length.
for it_w in range(20):  # run a small colony for 20 iterations.
    deposits_loop_w = np.zeros_like(pher_loop_w)
    for ant_w in range(8):
        t_w = build_tour_w(rng_loop_w, pher_loop_w, eta_w, 1.0, 2.0, start=0)
        L_w = tour_length_w(t_w, dist_w)
        if L_w < best_len_w:
            best_len_w, best_tour_w = L_w, t_w
        for k_w in range(n_w):
            a_w, b_w = t_w[k_w], t_w[(k_w + 1) % n_w]
            deposits_loop_w[a_w, b_w] += 1.0 / L_w
            deposits_loop_w[b_w, a_w] += 1.0 / L_w
    pher_loop_w = 0.8 * pher_loop_w + deposits_loop_w
    np.fill_diagonal(pher_loop_w, 0.0)
    best_lengths_w.append(best_len_w)
print("best tour:", best_tour_w, "best length:", round(best_len_w, 3))
assert best_lengths_w[-1] <= best_lengths_w[0]  # best-so-far never worsens.
```
▶ What you'll see: repeated sampling and updating finds a short tour and remembers it.

```python
plt.figure(figsize=(4.8, 3.2))  # convergence visualization.
plt.plot(best_lengths_w, marker="o", color="purple")
plt.xlabel("iteration"); plt.ylabel("best-so-far tour length")
plt.title("6: ACO convergence curve")
plt.show()
```
▶ What you'll see: the best-so-far curve steps downward or stays flat as better tours are discovered.

*Why it's done this way: ACO converts many cheap stochastic local decisions into a population search over complete tours, with pheromone acting as shared memory between iterations.*

### 7. Pitfalls: α, β, evaporation, and bad deposits

The main ACO knobs decide what kind of search you get. Large $\alpha$ over-amplifies early pheromone and can freeze the colony. Large $\beta$ makes the method nearly greedy. No evaporation makes old deposits permanent. Depositing on bad tours breaks the meaning of pheromone as quality memory.

```python
alphas_w = np.array([0.0, 1.0, 3.0])  # compare no pheromone influence, moderate influence, and over-amplification.
custom_pher_w = np.ones((n_w, n_w))
np.fill_diagonal(custom_pher_w, 0.0)
custom_pher_w[0, 2] = custom_pher_w[2, 0] = 5.0  # simulate an early strong pheromone edge.
prob_by_alpha_w = []
for a_val_w in alphas_w:
    s_w = (custom_pher_w[0, available_w] ** a_val_w) * (eta_w[0, available_w] ** 1.0)
    prob_by_alpha_w.append(s_w / s_w.sum())
prob_by_alpha_w = np.array(prob_by_alpha_w)
print("probabilities by alpha rows:\n", np.round(prob_by_alpha_w, 3))  # inspect how alpha sharpens memory.
assert np.allclose(prob_by_alpha_w.sum(axis=1), 1.0)  # each row is a distribution.
```
▶ What you'll see: as α grows, the high-pheromone edge receives more probability even if it is not the closest edge.

```python
plt.figure(figsize=(5.2, 3.2))  # plot alpha sensitivity.
for row_w, a_val_w in zip(prob_by_alpha_w, alphas_w):
    plt.plot(available_w, row_w, marker="o", label=f"α={a_val_w:g}")
plt.xlabel("candidate next city from 0"); plt.ylabel("transition probability")
plt.title("7: α can over-amplify early pheromone")
plt.legend(); plt.show()
```
▶ What you'll see: high α concentrates probability on the already-rich edge, reducing exploration.

*Why it's done this way: hyperparameters are not cosmetic — they control whether ACO behaves like random search, greedy nearest-neighbor search, or brittle pheromone lock-in.*

### ✍️ Toy 1 · Distances and pheromones live on graph edges

ACO first builds an edge table: distances describe the problem geometry, and pheromone stores learned memory on those same edges.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)
t1_coords = np.array([[0.0, 0.0], [2.0, 0.0], [2.0, 1.0], [0.0, 1.0]])
print("city coordinates:", t1_coords.tolist())  # -> [[0.0, 0.0], [2.0, 0.0], [2.0, 1.0], [0.0, 1.0]]
t1_delta = t1_coords[:, None, :] - t1_coords[None, :, :]
print("delta shape:", list(t1_delta.shape))  # -> [4, 4, 2]
t1_squared = t1_delta ** 2
print("squared delta shape:", list(t1_squared.shape))  # -> [4, 4, 2]
t1_dist = np.sqrt(t1_squared.sum(axis=2))
np.fill_diagonal(t1_dist, np.inf)
print("distance matrix:", np.round(t1_dist, 3).tolist())  # -> [[inf, 2.0, 2.236, 1.0], [2.0, inf, 1.0, 2.236], [2.236, 1.0, inf, 2.0], [1.0, 2.236, 2.0, inf]]
t1_pheromone = np.ones((4, 4))
np.fill_diagonal(t1_pheromone, 0.0)
print("initial pheromone:", t1_pheromone.tolist())  # -> [[0.0, 1.0, 1.0, 1.0], [1.0, 0.0, 1.0, 1.0], [1.0, 1.0, 0.0, 1.0], [1.0, 1.0, 1.0, 0.0]]
assert t1_pheromone[0, 1] == 1.0 and np.isinf(t1_dist[0, 0])

plt.figure(figsize=(4.6, 3.4))
for t1_i in range(4):
    for t1_j in range(t1_i + 1, 4):
        plt.plot([t1_coords[t1_i, 0], t1_coords[t1_j, 0]], [t1_coords[t1_i, 1], t1_coords[t1_j, 1]], color="gray", alpha=0.35)
plt.scatter(t1_coords[:, 0], t1_coords[:, 1], s=90, color="crimson", zorder=3)
for t1_i, t1_xy in enumerate(t1_coords):
    plt.text(t1_xy[0] + 0.04, t1_xy[1] + 0.04, str(t1_i))
plt.axis("equal"); plt.title("Toy 1 · graph edges hold memory"); plt.show()
```
▶ What you'll see: a four-city complete graph whose off-diagonal pheromone entries all start at `1`.

### ✍️ Toy 2 · Transition probabilities normalize pheromone and distance votes

From one city, pheromone and inverse distance form scores. Dividing by the sum turns those scores into a probability distribution.

```python
import numpy as np

t2_rng = np.random.default_rng(0)
t2_available = np.array([1, 2, 3])
print("available cities:", t2_available.tolist())  # -> [1, 2, 3]
t2_pheromone = np.array([1.0, 2.0, 1.0])
print("edge pheromone:", t2_pheromone.tolist())  # -> [1.0, 2.0, 1.0]
t2_distances = np.array([2.0, np.sqrt(5.0), 1.0])
print("edge distances:", np.round(t2_distances, 3).tolist())  # -> [2.0, 2.236, 1.0]
t2_eta = 1.0 / t2_distances
print("inverse distances:", np.round(t2_eta, 3).tolist())  # -> [0.5, 0.447, 1.0]
t2_alpha = 1.0
t2_beta = 2.0
print("alpha beta:", [t2_alpha, t2_beta])  # -> [1.0, 2.0]
t2_scores = (t2_pheromone ** t2_alpha) * (t2_eta ** t2_beta)
print("unnormalized scores:", np.round(t2_scores, 3).tolist())  # -> [0.25, 0.4, 1.0]
t2_probabilities = t2_scores / t2_scores.sum()
print("probabilities:", np.round(t2_probabilities, 3).tolist())  # -> [0.152, 0.242, 0.606]
print("probability sum:", round(float(t2_probabilities.sum()), 3))  # -> 1.0
assert np.isclose(t2_probabilities.sum(), 1.0)

plt.figure(figsize=(4.6, 3.0))
plt.bar([f"0→{t2_city}" for t2_city in t2_available], t2_probabilities, color="teal")
plt.ylim(0, 1); plt.ylabel("probability"); plt.title("Toy 2 · normalized next-city votes"); plt.show()
```
▶ What you'll see: city `3` gets the largest bar because it is closest after the score normalization.

### ✍️ Toy 3 · One ant samples a complete tour

An ant repeatedly samples from the current transition distribution until every city appears once, then the tour closes back to the start.

```python
import numpy as np

t3_rng = np.random.default_rng(0)
t3_dist = np.array([[np.inf, 1.0, 2.0, 1.0], [1.0, np.inf, 1.0, 2.0], [2.0, 1.0, np.inf, 1.0], [1.0, 2.0, 1.0, np.inf]])
print("distance matrix:", t3_dist.tolist())  # -> [[inf, 1.0, 2.0, 1.0], [1.0, inf, 1.0, 2.0], [2.0, 1.0, inf, 1.0], [1.0, 2.0, 1.0, inf]]
t3_eta = 1.0 / t3_dist
print("inverse-distance row 0:", np.round(t3_eta[0], 3).tolist())  # -> [0.0, 1.0, 0.5, 1.0]
t3_pheromone = np.ones((4, 4))
np.fill_diagonal(t3_pheromone, 0.0)
print("pheromone row 0:", t3_pheromone[0].tolist())  # -> [0.0, 1.0, 1.0, 1.0]
t3_available1 = np.array([1, 2, 3])
t3_scores1 = t3_pheromone[0, t3_available1] * t3_eta[0, t3_available1]
print("step 1 scores:", t3_scores1.tolist())  # -> [1.0, 0.5, 1.0]
t3_probs1 = t3_scores1 / t3_scores1.sum()
print("step 1 probs:", np.round(t3_probs1, 3).tolist())  # -> [0.4, 0.2, 0.4]
t3_cum1 = np.cumsum(t3_probs1)
print("step 1 cumulative:", np.round(t3_cum1, 3).tolist())  # -> [0.4, 0.6, 1.0]
t3_draw1 = float(t3_rng.random())
print("step 1 draw:", round(t3_draw1, 3))  # -> 0.637
t3_next1 = int(t3_available1[int(np.searchsorted(t3_cum1, t3_draw1, side="right"))])
print("step 1 chosen city:", t3_next1)  # -> 3
t3_available2 = np.array([1, 2])
t3_scores2 = t3_pheromone[t3_next1, t3_available2] * t3_eta[t3_next1, t3_available2]
print("step 2 scores:", t3_scores2.tolist())  # -> [0.5, 1.0]
t3_probs2 = t3_scores2 / t3_scores2.sum()
print("step 2 probs:", np.round(t3_probs2, 3).tolist())  # -> [0.333, 0.667]
t3_cum2 = np.cumsum(t3_probs2)
print("step 2 cumulative:", np.round(t3_cum2, 3).tolist())  # -> [0.333, 1.0]
t3_draw2 = float(t3_rng.random())
print("step 2 draw:", round(t3_draw2, 3))  # -> 0.27
t3_next2 = int(t3_available2[int(np.searchsorted(t3_cum2, t3_draw2, side="right"))])
print("step 2 chosen city:", t3_next2)  # -> 1
t3_available3 = np.array([2])
t3_scores3 = t3_pheromone[t3_next2, t3_available3] * t3_eta[t3_next2, t3_available3]
print("step 3 scores:", t3_scores3.tolist())  # -> [1.0]
t3_probs3 = t3_scores3 / t3_scores3.sum()
print("step 3 probs:", t3_probs3.tolist())  # -> [1.0]
t3_draw3 = float(t3_rng.random())
print("step 3 draw:", round(t3_draw3, 3))  # -> 0.041
t3_next3 = int(t3_available3[0])
print("step 3 chosen city:", t3_next3)  # -> 2
t3_tour = np.array([0, t3_next1, t3_next2, t3_next3])
print("tour:", t3_tour.tolist())  # -> [0, 3, 1, 2]
t3_edges_from = t3_tour
t3_edges_to = np.roll(t3_tour, -1)
t3_edge_lengths = t3_dist[t3_edges_from, t3_edges_to]
print("closed-tour edge lengths:", t3_edge_lengths.tolist())  # -> [1.0, 2.0, 1.0, 2.0]
t3_length = float(t3_edge_lengths.sum())
print("closed-tour length:", t3_length)  # -> 6.0
assert sorted(t3_tour.tolist()) == [0, 1, 2, 3]

plt.figure(figsize=(4.4, 3.4))
```

## 🛠️ Setup

```python
import numpy as np # load NumPy for graph matrices, probability vectors, and reproducible simulation.
import matplotlib.pyplot as plt # load Matplotlib for graph, heatmap, and convergence visualizations.
np.random.seed(0) # make any global-random examples reproducible.

coords = np.array([[0.0, 0.0], [1.0, 0.2], [1.3, 1.2], [0.2, 1.0], [0.6, 0.55]]) # define a small five-city TSP instance.

def distance_matrix(points): # compute pairwise Euclidean distances for a complete TSP graph.
    D = np.linalg.norm(points[:, None, :] - points[None, :, :], axis=2) # pairwise coordinate distances.
    np.fill_diagonal(D, np.inf) # forbid self-moves by giving them infinite distance.
    return D # return the distance matrix.

def heuristic_matrix(D): # compute ACO heuristic desirability eta = 1 / distance.
    eta = 1.0 / D # short edges get larger desirability.
    eta[~np.isfinite(eta)] = 0.0 # replace self-edge infinities with zero desirability.
    return eta # return eta.

def tour_length(tour, D): # compute the closed-loop length of a TSP tour.
    return float(sum(D[tour[k], tour[(k + 1) % len(tour)]] for k in range(len(tour)))) # add each edge including the return edge.

def transition_probs(current, available, pheromone, eta, alpha=1.0, beta=2.0): # compute ACO next-city probabilities.
    available = np.asarray(available, dtype=int) # ensure candidates are integer indices.
    scores = (pheromone[current, available] ** alpha) * (eta[current, available] ** beta) # tau^alpha times eta^beta.
    total = float(scores.sum()) # denominator of the probability rule.
    return np.ones_like(scores, dtype=float) / len(scores) if total == 0 else scores / total # normalize or fall back to uniform.

def build_tour(rng, pheromone, eta, alpha=1.0, beta=2.0, start=0): # construct one full TSP tour.
    tour = [int(start)] # begin at a fixed city for easier comparisons.
    n = pheromone.shape[0] # number of cities.
    while len(tour) < n: # continue until every city has been visited once.
        available = np.array([j for j in range(n) if j not in tour]) # unvisited cities.
        probs = transition_probs(tour[-1], available, pheromone, eta, alpha, beta) # next-step probabilities.
        tour.append(int(rng.choice(available, p=probs))) # sample one city according to ACO probabilities.
    return tour # return the complete city order.

def pheromone_update(pheromone, tours, lengths, rho=0.2, Q=1.0, elite_only=False): # evaporate and deposit pheromone.
    new_pheromone = (1.0 - rho) * pheromone.copy() # evaporate every edge before adding new evidence.
    selected = [int(np.argmin(lengths))] if elite_only else range(len(tours)) # choose all ants or only the best ant.
    for idx in selected: # deposit from each selected tour.
        amount = Q / lengths[idx] # shorter tours deposit more pheromone.
        tour = tours[idx] # read this ant's tour.
        for k in range(len(tour)): # visit every closed-tour edge.
            a, b = tour[k], tour[(k + 1) % len(tour)] # current edge.
            new_pheromone[a, b] += amount # add pheromone in one direction.
            new_pheromone[b, a] += amount # mirror for undirected TSP.
    np.fill_diagonal(new_pheromone, 0.0) # keep self-edges forbidden.
    return new_pheromone # return updated matrix.

def draw_tsp(points, pheromone=None, tour=None, title="TSP graph"): # visualize cities, pheromone, and optional best tour.
    plt.figure(figsize=(4.6, 3.8)) # start a compact graph figure.
    n = len(points) # number of cities.
    max_pher = float(np.max(pheromone)) if pheromone is not None and np.max(pheromone) > 0 else 1.0 # scale edge widths.
    for i in range(n): # draw all undirected graph edges.
        for j in range(i + 1, n):
            weight = 1.0 if pheromone is None else pheromone[i, j] / max_pher # relative pheromone.
            plt.plot([points[i, 0], points[j, 0]], [points[i, 1], points[j, 1]], color=plt.cm.viridis(weight), alpha=0.35 + 0.45 * weight, linewidth=0.7 + 4.0 * weight) # thickness/color shows pheromone.
    if tour is not None: # overlay a selected tour when provided.
        for k in range(len(tour)):
            a, b = tour[k], tour[(k + 1) % len(tour)]
            plt.plot([points[a, 0], points[b, 0]], [points[a, 1], points[b, 1]], color="crimson", linewidth=2.8, zorder=2) # best-tour overlay.
    plt.scatter(points[:, 0], points[:, 1], s=90, color="black", zorder=3) # draw cities above edges.
    for i, (x, y) in enumerate(points):
        plt.text(x + 0.03, y + 0.03, str(i), color="black") # city labels.
    plt.title(title) # title the plot.
    plt.axis("equal") # preserve geometry.
    plt.show() # display the graph.

def run_aco(points, iterations=25, ants=8, alpha=1.0, beta=2.0, rho=0.2, Q=1.0, seed=0, elite_only=False): # run a compact ACO loop.
    D = distance_matrix(points) # compute distances.
    eta = heuristic_matrix(D) # compute inverse-distance heuristic.
    n = len(points) # number of cities.
    pheromone = np.ones((n, n)) - np.eye(n) # initialize equal non-self pheromone.
    rng = np.random.default_rng(seed) # local reproducible random generator.
    best_tour, best_len = None, np.inf # track best-so-far solution.
    history = [] # record best-so-far length per iteration.
    snapshots = [] # store pheromone snapshots for visualization.
    for it in range(iterations): # repeated colony iterations.
        tours = [build_tour(rng, pheromone, eta, alpha, beta, start=0) for _ in range(ants)] # construct ant tours.
        lengths = np.array([tour_length(t, D) for t in tours]) # score each tour.
        idx = int(np.argmin(lengths)) # find this iteration's best ant.
        if lengths[idx] < best_len: # update best-so-far when improved.
            best_len = float(lengths[idx]) # store best length.
            best_tour = tours[idx] # store best tour.
        pheromone = pheromone_update(pheromone, tours, lengths, rho=rho, Q=Q, elite_only=elite_only) # evaporate and deposit.
        history.append(best_len) # record convergence.
        snapshots.append(pheromone.copy()) # keep matrix snapshot.
    return {"D": D, "eta": eta, "pheromone": pheromone, "best_tour": best_tour, "best_len": best_len, "history": np.array(history), "snapshots": snapshots} # return run state.
```

#### A5. Balance exploration and exploitation with entropy

**Goal.** Track transition entropy as pheromone sharpens, because decreasing entropy means the colony is exploiting a smaller set of edges. We build it in 5 steps.

```python

pher_a5 = np.ones((len(coords), len(coords))) - np.eye(len(coords)) # equal initial pheromone.
entropy_a5 = [] # store entropy from city 0 each iteration.
best_hist_a5 = [] # store best-so-far tour lengths.
best_len_a5 = np.inf # initialize best length.
print("tracking entropy from city 0") # describe diagnostic.
```

```python

    avail_a5 = np.array([1, 2, 3, 4]) # available moves from city 0 at the start.
    probs_a5 = transition_probs(0, avail_a5, pher_a5, eta_a5, alpha=1.0, beta=2.0) # current start-edge probabilities.
```
