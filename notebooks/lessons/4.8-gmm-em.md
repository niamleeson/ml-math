# 4.8 — Gaussian Mixture Models & EM

Gaussian Mixture Models (GMMs) explain unlabeled data as several Gaussian components that overlap, so a point can belong partly to more than one group. Expectation–Maximization (EM) is the repeated recipe: compute soft responsibilities from probability scores, then update each component with responsibility-weighted averages until the data likelihood stops improving.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build Gaussian mixtures and EM one idea at a time. Run each cell in order and read the printed intermediate values — every probability normalization, weighted update, and likelihood check is spelled out so nothing is a black box. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, exponentials, matrix algebra, and random samples.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for sampled toy data and EM initialization.
```

### 1. A mixture is a density model, not a hard label table

A Gaussian Mixture Model assumes each point was generated by first choosing a hidden component, then sampling from that component's Gaussian density. Because the component is hidden, the model stores a probability for every possible explanation instead of a single early label. That is the core change from hard clustering: overlap is not an error; overlap is exactly why soft membership exists.

```python
x_left_w = np.random.normal(loc=-2.0, scale=0.45, size=35)  # samples from component 0.
x_right_w = np.random.normal(loc=2.0, scale=0.65, size=45)  # samples from component 1.
x_w = np.concatenate([x_left_w, x_right_w])  # observed data; component identities are hidden.
print("data shape:", x_w.shape)  # one-dimensional data with 80 unlabeled points.
print("min/mean/max:", np.round([x_w.min(), x_w.mean(), x_w.max()], 3))  # inspect scale.
```
▶ What you'll see: one vector of unlabeled numbers whose mean sits between two visible groups.

```python
plt.figure(figsize=(5, 2.8))  # compact histogram for the observed data.
plt.hist(x_w, bins=18, density=True, alpha=0.65, color="gray")  # density-scaled counts.
plt.title("1: unlabeled samples from two overlapping Gaussians")
plt.xlabel("x"); plt.ylabel("density"); plt.show()
```
▶ What you'll see: two humps with some middle overlap; a hard boundary would throw away uncertainty near the overlap.

*Why it's done this way:* a mixture treats the observed data as coming from several reusable probability mechanisms. We do not force a point near the boundary to commit immediately because the likelihood of that point can be explained partly by both components.

### 2. Gaussian scores say how plausible a point is under each component

For one-dimensional data, a Gaussian component with mean $\mu$ and standard deviation $\sigma$ assigns density

$$\mathcal{N}(x\mid\mu,\sigma^2)=\frac{1}{\sqrt{2\pi}\sigma}\exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right).$$

The exponential term punishes squared distance from the mean, while the $1/\sigma$ term spreads probability over a wider range when the component is broad. In a mixture, this density becomes the unnormalized score $q_{ik}$ before normalization.

```python
def gaussian_pdf_w(x, mu, sigma):  # one-dimensional Gaussian density.
    x = np.asarray(x, dtype=float)  # support scalars or arrays.
    return np.exp(-0.5 * ((x - mu) / sigma) ** 2) / (np.sqrt(2 * np.pi) * sigma)  # density.

probe_w = np.array([-2.0, 0.0, 2.0])  # left center, overlap, right center.
left_score_w = gaussian_pdf_w(probe_w, -2.0, 0.6)  # plausibility under left component.
right_score_w = gaussian_pdf_w(probe_w, 2.0, 0.8)  # plausibility under right component.
print("left scores:", np.round(left_score_w, 4))
print("right scores:", np.round(right_score_w, 4))
assert round(float(left_score_w[0]), 3) == 0.665  # concrete density at its own mean.
```
▶ What you'll see: each component gives its largest density near its own mean and tiny density far away.

```python
grid_w = np.linspace(-5, 5, 300)  # x-values for plotting the two densities.
plt.figure(figsize=(5, 3))
plt.plot(grid_w, gaussian_pdf_w(grid_w, -2.0, 0.6), label="left Gaussian", color="teal")
plt.plot(grid_w, gaussian_pdf_w(grid_w, 2.0, 0.8), label="right Gaussian", color="orange")
plt.scatter(probe_w, gaussian_pdf_w(probe_w, -2.0, 0.6), color="teal")
plt.title("2: Gaussian density scores"); plt.xlabel("x"); plt.ylabel("density"); plt.legend(); plt.show()
```
▶ What you'll see: the same point has different heights under different bell curves; those heights become competing explanations.

*Why it's done this way:* EM cannot update components until it knows which component plausibly explains each point. The Gaussian density converts geometric distance and spread into a probability score that is comparable across components.

### 3. Responsibilities normalize competing explanations

A mixture component also has a mixing weight $\pi_k$, the prior chance that a random point came from component $k$. For point $x_i$, the unnormalized score is $q_{ik}=\pi_k\mathcal{N}(x_i\mid\mu_k,\sigma_k^2)$. The responsibility is the normalized score

$$r_{ik}=\frac{q_{ik}}{\sum_j q_{ij}},$$

so the responsibilities across components sum to 1 for every point.

```python
pis_w = np.array([0.4, 0.6])  # prior component weights; they sum to 1.
mu_w = np.array([-2.0, 2.0])  # component centers.
sigma_w = np.array([0.6, 0.8])  # component spreads.
x0_w = 0.0  # an ambiguous point in the middle.
q_w = pis_w * np.array([gaussian_pdf_w(x0_w, mu_w[k], sigma_w[k]) for k in range(2)])  # unnormalized scores.
print("unnormalized q:", np.round(q_w, 5))
print("sum q:", round(float(q_w.sum()), 5))
```
▶ What you'll see: both components get small but nonzero scores for a middle point.

```python
r_w = q_w / q_w.sum()  # normalize scores into responsibilities.
print("responsibilities:", np.round(r_w, 3))
print("sum responsibilities:", round(float(r_w.sum()), 3))
assert round(float(r_w.sum()), 3) == 1.0  # every point's memberships form a probability vector.
```
▶ What you'll see: the middle point is split between components, with the broader/right component receiving more responsibility here.

```python
plt.figure(figsize=(4.5, 3))
plt.bar(["left", "right"], r_w, color=["teal", "orange"])
plt.ylim(0, 1); plt.ylabel("responsibility")
plt.title("3: one point's soft membership"); plt.show()
```
▶ What you'll see: two bars that add to 1 rather than one hard winner-take-all assignment.

*Why it's done this way:* normalization turns arbitrary density scores into comparable shares of responsibility. The denominator is Bayes-style evidence: it asks, among all explanations available to the model, what fraction belongs to each component?

### 4. The M-step is a weighted average update

Once every point has responsibilities, each component updates its parameters using those responsibilities as fractional counts. The effective count is $N_k=\sum_i r_{ik}$, and the mean update is

$$\mu_k=\frac{\sum_i r_{ik}x_i}{\sum_i r_{ik}}.$$

This is the same arithmetic as the lesson's tiny pass: high-responsibility points pull the mean strongly; low-responsibility points barely move it.

```python
x_tiny_w = np.array([0.0, 1.0, 4.0])  # tiny data vector from the source lesson.
weights_tiny_w = np.array([0.8, 0.6, 0.1])  # fractional responsibility for one component.
weighted_num_w = float(np.sum(weights_tiny_w * x_tiny_w))  # numerator of weighted mean.
weighted_den_w = float(np.sum(weights_tiny_w))  # effective component count.
print("weighted numerator:", round(weighted_num_w, 3))
print("effective count:", round(weighted_den_w, 3))
```
▶ What you'll see: the numerator is not a simple sum of points; each point is scaled by ownership.

```python
mu_update_w = weighted_num_w / weighted_den_w  # responsibility-weighted mean.
print("updated mean:", round(mu_update_w, 3))
assert round(mu_update_w, 3) == 0.667  # matches the content block's hand calculation.
```
▶ What you'll see: the updated center is 0.667, close to the heavily owned low-valued points.

```python
plt.figure(figsize=(5, 2.8))
plt.scatter(x_tiny_w, np.zeros_like(x_tiny_w), s=250 * weights_tiny_w + 20, color="slateblue", alpha=0.75)
plt.axvline(mu_update_w, color="crimson", linestyle="--", label=f"weighted mean={mu_update_w:.3f}")
plt.yticks([]); plt.xlabel("x"); plt.title("4: responsibilities act like fractional counts"); plt.legend(); plt.show()
```
▶ What you'll see: the largest markers pull the dashed mean toward them.

*Why it's done this way:* a component should learn from the points it probably generated, not from all points equally. Responsibilities are fractional evidence, so the maximum-likelihood mean is the average under those fractional counts.

### 5. EM alternates E-steps and M-steps until likelihood improves no more

The E-step computes responsibilities using the current parameters. The M-step updates parameters using those responsibilities. EM repeats because either step alone is incomplete: responsibilities need parameters, and parameters need responsibilities. We track log-likelihood

$$\sum_i \log\left(\sum_k \pi_k\mathcal{N}(x_i\mid\mu_k,\sigma_k^2)\right)$$

to verify that the fit is improving.

```python
def e_step_1d_w(x, pis, mus, sigmas):  # responsibilities for a 1-D diagonal GMM.
    scores = np.column_stack([pis[k] * gaussian_pdf_w(x, mus[k], sigmas[k]) for k in range(len(pis))])
    return scores / scores.sum(axis=1, keepdims=True)  # normalize each point's row.

def m_step_1d_w(x, resp):  # weighted updates for pi, mu, and sigma.
    Nk = resp.sum(axis=0)  # effective counts.
    pis = Nk / len(x)  # component fractions.
    mus = (resp * x[:, None]).sum(axis=0) / Nk  # weighted means.
    vars_ = (resp * (x[:, None] - mus) ** 2).sum(axis=0) / Nk  # weighted variances.
    return pis, mus, np.sqrt(vars_ + 1e-9)  # small guard for zero variance.
```
▶ What you'll see: no output yet; these two functions are the EM loop written directly from the formulas.

```python
pis_em_w = np.array([0.5, 0.5])  # start with equal prior weights.
mus_em_w = np.array([-1.0, 1.0])  # rough initial centers.
sigmas_em_w = np.array([1.0, 1.0])  # rough initial spreads.
resp0_w = e_step_1d_w(x_w, pis_em_w, mus_em_w, sigmas_em_w)  # first E-step.
print("first three responsibility rows:\n", np.round(resp0_w[:3], 3))
assert np.allclose(resp0_w[:3].sum(axis=1), 1.0)  # row-wise normalization.
```
▶ What you'll see: each data point owns two probabilities that sum to 1.

```python
losses_w = []  # store log-likelihoods.
for epoch_w in range(25):  # repeat E then M.
    resp_em_w = e_step_1d_w(x_w, pis_em_w, mus_em_w, sigmas_em_w)  # E-step.
    pis_em_w, mus_em_w, sigmas_em_w = m_step_1d_w(x_w, resp_em_w)  # M-step.
    mix_density_w = sum(pis_em_w[k] * gaussian_pdf_w(x_w, mus_em_w[k], sigmas_em_w[k]) for k in range(2))
    losses_w.append(float(np.sum(np.log(mix_density_w + 1e-12))))  # observed log-likelihood.
print("final pis:", np.round(pis_em_w, 3))
print("final mus:", np.round(mus_em_w, 3))
print("log-likelihood start -> end:", round(losses_w[0], 2), "->", round(losses_w[-1], 2))
assert losses_w[-1] > losses_w[0]  # EM improved the data likelihood.
```
▶ What you'll see: the means move toward the two humps and log-likelihood increases.

```python
plt.figure(figsize=(5, 3))
plt.plot(losses_w, marker="o", color="purple")
plt.title("5: EM log-likelihood rises")
plt.xlabel("iteration"); plt.ylabel("log-likelihood"); plt.show()
```
▶ What you'll see: the curve climbs and then flattens as EM converges.

*Why it's done this way:* EM is coordinate ascent on a likelihood lower bound. The E-step improves the hidden-membership explanation for fixed parameters, and the M-step improves parameters for fixed memberships; alternating them makes the observed data more probable.

### 6. Covariance shape, scaling, and model trust

A full GMM can learn covariance matrices, not just one-dimensional spreads. Covariance controls ellipses: diagonal entries are variances along axes, and off-diagonal entries tilt the ellipse. This power is useful, but it also makes GMMs sensitive to scaling and initialization, so we inspect shapes and rerun logic rather than treating the output as ground truth.

```python
rng_cov_w = np.random.default_rng(3)  # reproducible 2-D sample.
mean2_w = np.array([0.0, 0.0])  # center of a tilted cloud.
cov2_w = np.array([[2.0, 1.2], [1.2, 1.0]])  # positive covariance tilts the cloud upward.
X2_w = rng_cov_w.multivariate_normal(mean2_w, cov2_w, size=120)  # synthetic correlated data.
emp_cov_w = np.cov(X2_w.T)  # empirical covariance uses columns as variables.
print("X shape:", X2_w.shape)
print("empirical covariance:\n", np.round(emp_cov_w, 2))
assert emp_cov_w.shape == (2, 2)  # shape bookkeeping: two measured coordinates.
```
▶ What you'll see: a 120×2 data matrix and a 2×2 covariance matrix.

```python
vals_w, vecs_w = np.linalg.eigh(emp_cov_w)  # eigenvectors give ellipse axes.
order_w = np.argsort(vals_w)[::-1]  # largest variance first.
vals_w, vecs_w = vals_w[order_w], vecs_w[:, order_w]
print("variance along ellipse axes:", np.round(vals_w, 3))
print("top direction:", np.round(vecs_w[:, 0], 3))
```
▶ What you'll see: one larger variance direction dominates, identifying the long axis of the tilted cluster.

```python
plt.figure(figsize=(4.5, 4))
plt.scatter(X2_w[:, 0], X2_w[:, 1], s=18, alpha=0.55, color="steelblue")
for j_w in range(2):
    v_w = vecs_w[:, j_w] * np.sqrt(vals_w[j_w]) * 2
    plt.arrow(0, 0, v_w[0], v_w[1], color="crimson", width=0.02, length_includes_head=True)
plt.axis("equal"); plt.title("6: covariance controls ellipse shape"); plt.xlabel("x1"); plt.ylabel("x2"); plt.show()
```
▶ What you'll see: arrows align with the cloud's long and short directions, showing what a full covariance component can learn.

*Why it's done this way:* Gaussian components are geometric objects. Means locate them, covariances shape them, and scaling decides which coordinates dominate the density. That is why a clean-looking GMM can still be misaligned with the structure you actually care about.

### ✍️ Toy 1 · A mixture density adds component densities

A GMM does not first make hard labels. It scores each point under every component and adds the
weighted component densities.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)
t1_x = np.array([-3.0, -2.0, -1.0, 0.0, 1.0, 2.0, 3.0])
t1_pi = np.array([0.4, 0.6])
t1_mu = np.array([-1.0, 2.0])
t1_sigma = np.array([0.7, 0.8])
print("x grid:", t1_x.tolist())  # -> [-3.0, -2.0, -1.0, 0.0, 1.0, 2.0, 3.0]
print("mixing weights:", t1_pi.tolist())  # -> [0.4, 0.6]
t1_left_pdf = np.exp(-0.5 * ((t1_x - t1_mu[0]) / t1_sigma[0]) ** 2) / (np.sqrt(2 * np.pi) * t1_sigma[0])
t1_right_pdf = np.exp(-0.5 * ((t1_x - t1_mu[1]) / t1_sigma[1]) ** 2) / (np.sqrt(2 * np.pi) * t1_sigma[1])
t1_left = t1_pi[0] * t1_left_pdf
t1_right = t1_pi[1] * t1_right_pdf
t1_mix = t1_left + t1_right
print("weighted left density:", np.round(t1_left, 4).tolist())  # -> [0.0038, 0.0822, 0.228, 0.0822, 0.0038, 0.0, 0.0]
print("weighted right density:", np.round(t1_right, 4).tolist())  # -> [0.0, 0.0, 0.0003, 0.0131, 0.137, 0.2992, 0.137]
print("mixture density:", np.round(t1_mix, 4).tolist())  # -> [0.0038, 0.0822, 0.2282, 0.0953, 0.1408, 0.2992, 0.137]
assert np.allclose(t1_mix, t1_left + t1_right)

plt.figure(figsize=(5.0, 3.0))
plt.plot(t1_x, t1_left, marker="o", label="weighted left")
plt.plot(t1_x, t1_right, marker="o", label="weighted right")
plt.plot(t1_x, t1_mix, marker="o", color="black", label="sum")
plt.xlabel("x")
plt.ylabel("density")
plt.title("Toy 1 · mixture = weighted sum")
plt.legend()
plt.show()
```
▶ What you'll see: the black mixture curve is exactly the pointwise sum of the two weighted curves.

### ✍️ Toy 2 · Gaussian scores come from z-scores

The normal density turns distance from the mean into an exponential penalty. Points two standard
deviations away get much smaller density than the mean.

```python
import numpy as np

t2_rng = np.random.default_rng(0)
t2_x = np.array([-2.0, 0.0, 2.0])
t2_mu = 0.0
t2_sigma = 1.0
print("probe x:", t2_x.tolist())  # -> [-2.0, 0.0, 2.0]
t2_z = (t2_x - t2_mu) / t2_sigma
t2_exponent = -0.5 * t2_z ** 2
t2_coeff = 1.0 / (np.sqrt(2 * np.pi) * t2_sigma)
t2_pdf = t2_coeff * np.exp(t2_exponent)
print("z-scores:", t2_z.tolist())  # -> [-2.0, 0.0, 2.0]
print("exponents:", t2_exponent.tolist())  # -> [-2.0, -0.0, -2.0]
print("coefficient:", round(float(t2_coeff), 4))  # -> 0.3989
print("pdf values:", np.round(t2_pdf, 4).tolist())  # -> [0.054, 0.3989, 0.054]
assert t2_pdf[1] > t2_pdf[0] and np.allclose(t2_pdf[0], t2_pdf[2])

plt.figure(figsize=(4.8, 3.0))
plt.bar(["x=-2", "x=0", "x=2"], t2_pdf, color="slateblue")
plt.ylabel("Gaussian density")
plt.title("Toy 2 · center gets highest score")
plt.show()
```
▶ What you'll see: the center point has density `0.3989`, while the symmetric tail points have density `0.054`.

### ✍️ Toy 3 · Responsibilities normalize weighted scores

For one ambiguous point, multiply each Gaussian score by its mixture weight, then normalize those
competing explanations to sum to one.

```python
import numpy as np

t3_rng = np.random.default_rng(0)
t3_x = 0.5
```

### ✍️ Toy 4 · The M-step updates weighted parameters

Responsibilities are fractional counts. The M-step uses them to update mixture weights, means, and
variances.

```python
import numpy as np

t4_rng = np.random.default_rng(0)
t4_x = np.array([0.0, 1.0, 2.0, 5.0, 6.0, 7.0])
t4_left = np.array([0.9, 0.8, 0.6, 0.2, 0.1, 0.05])
t4_resp = np.column_stack([t4_left, 1.0 - t4_left])
print("x values:", t4_x.tolist())  # -> [0.0, 1.0, 2.0, 5.0, 6.0, 7.0]
print("responsibilities:", np.round(t4_resp, 3).tolist())  # -> [[0.9, 0.1], [0.8, 0.2], [0.6, 0.4], [0.2, 0.8], [0.1, 0.9], [0.05, 0.95]]
t4_Nk = t4_resp.sum(axis=0)
t4_pi = t4_Nk / t4_x.size
t4_num = t4_resp.T @ t4_x
t4_mu = t4_num / t4_Nk
t4_var = (t4_resp * (t4_x[:, None] - t4_mu) ** 2).sum(axis=0) / t4_Nk
t4_sigma = np.sqrt(t4_var)
print("effective counts:", np.round(t4_Nk, 3).tolist())  # -> [2.65, 3.35]
print("new pi:", np.round(t4_pi, 3).tolist())  # -> [0.442, 0.558]
print("weighted numerators:", np.round(t4_num, 3).tolist())  # -> [3.95, 17.05]
print("new means:", np.round(t4_mu, 3).tolist())  # -> [1.491, 5.09]
print("new variances:", np.round(t4_var, 3).tolist())  # -> [3.156, 4.171]
print("new sigmas:", np.round(t4_sigma, 3).tolist())  # -> [1.776, 2.042]
assert np.allclose(t4_pi.sum(), 1.0) and t4_mu[0] < t4_mu[1]

plt.figure(figsize=(5.0, 2.8))
plt.scatter(t4_x, np.zeros_like(t4_x), s=250 * t4_resp[:, 0] + 20, color="teal", alpha=0.65, label="component 0 ownership")
plt.axvline(t4_mu[0], color="teal", linestyle="--", label="mu0")
plt.axvline(t4_mu[1], color="orange", linestyle="--", label="mu1")
plt.yticks([])
plt.xlabel("x")
plt.title("Toy 4 · weighted M-step means")
plt.legend()
plt.show()
```
▶ What you'll see: component 0 moves near `1.491`, while component 1 moves near `5.090`.

### ✍️ Toy 5 · One EM pass improves log-likelihood

An E-step computes responsibilities from current parameters, then an M-step updates the parameters.
The observed-data log-likelihood should increase.

```python
import numpy as np

t5_rng = np.random.default_rng(0)
t5_x = np.array([-2.2, -1.8, -1.2, -0.8, 1.0, 1.4, 2.0, 2.4])
t5_pi = np.array([0.5, 0.5])
t5_mu = np.array([-1.5, 1.5])
t5_sigma = np.array([1.0, 1.0])
print("x values:", t5_x.tolist())  # -> [-2.2, -1.8, -1.2, -0.8, 1.0, 1.4, 2.0, 2.4]
t5_scores0 = np.column_stack([t5_pi[k] * np.exp(-0.5 * ((t5_x - t5_mu[k]) / t5_sigma[k]) ** 2) / (np.sqrt(2 * np.pi) * t5_sigma[k]) for k in range(2)])
t5_ll0 = float(np.sum(np.log(t5_scores0.sum(axis=1) + 1e-12)))
t5_resp = t5_scores0 / t5_scores0.sum(axis=1, keepdims=True)
t5_Nk = t5_resp.sum(axis=0)
t5_pi_new = t5_Nk / t5_x.size
t5_mu_new = (t5_resp * t5_x[:, None]).sum(axis=0) / t5_Nk
t5_var_new = (t5_resp * (t5_x[:, None] - t5_mu_new) ** 2).sum(axis=0) / t5_Nk
t5_sigma_new = np.sqrt(t5_var_new + 1e-9)
t5_scores1 = np.column_stack([t5_pi_new[k] * np.exp(-0.5 * ((t5_x - t5_mu_new[k]) / t5_sigma_new[k]) ** 2) / (np.sqrt(2 * np.pi) * t5_sigma_new[k]) for k in range(2)])
t5_ll1 = float(np.sum(np.log(t5_scores1.sum(axis=1) + 1e-12)))
print("initial log-likelihood:", round(t5_ll0, 3))  # -> -13.95
```

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, exponentials, probability normalization, and EM updates.
import matplotlib.pyplot as plt # load Matplotlib so every probability, responsibility, and convergence curve is visible.
np.random.seed(0) # make all examples reproducible across notebook runs.

def normal_pdf_1d(x, mu, sigma): # compute a one-dimensional Gaussian density.
    x = np.asarray(x, dtype=float) # convert scalars or arrays to predictable float arrays.
    return np.exp(-0.5 * ((x - mu) / sigma) ** 2) / (np.sqrt(2 * np.pi) * sigma) # apply the closed-form normal density.

def responsibilities_1d(x, pis, mus, sigmas): # compute GMM responsibilities for a 1-D mixture.
    scores = np.column_stack([pis[k] * normal_pdf_1d(x, mus[k], sigmas[k]) for k in range(len(pis))]) # unnormalized q_ik scores.
    return scores / scores.sum(axis=1, keepdims=True) # normalize each point so responsibilities sum to 1.

def weighted_mean(x, w): # compute a responsibility-weighted average.
    return float(np.sum(w * x) / np.sum(w)) # divide weighted evidence by effective count.

def log_likelihood_1d(x, pis, mus, sigmas): # compute observed-data log-likelihood for a 1-D GMM.
    density = sum(pis[k] * normal_pdf_1d(x, mus[k], sigmas[k]) for k in range(len(pis))) # mixture density at every point.
    return float(np.sum(np.log(density + 1e-12))) # sum logs with a tiny numerical guard.

def show_points_1d(x, title): # draw a compact 1-D scatter strip for mixture examples.
    plt.figure(figsize=(5, 1.8)) # create a short strip figure.
    plt.scatter(x, np.zeros_like(x), s=35, alpha=0.7) # draw points on one horizontal line.
    plt.yticks([]) # hide the meaningless vertical axis.
    plt.title(title) # label the diagnostic plot.
    plt.xlabel("x") # label the measured coordinate.
    plt.show() # display the plot.
```

### Advanced 1 — Fit a diagonal 2-D GMM

**Goal.** Extend EM to two measured coordinates with diagonal covariance, because real GMMs often model vector data while keeping updates inspectable. We build it in 4 steps.

```python
rng_a1 = np.random.default_rng(11) # reproducible 2-D data.
X_a1 = np.vstack([rng_a1.normal([-2, 0], [0.45, 0.7], size=(45, 2)), rng_a1.normal([2, 1], [0.6, 0.4], size=(55, 2))]) # two diagonal Gaussian clouds.
pis_a1 = np.array([0.5, 0.5]) # initialize component priors.
mus_a1 = np.array([[-1.0, -0.5], [1.0, 0.5]]) # initialize means.
vars_a1 = np.ones((2, 2)) # initialize diagonal variances for two components and two features.
print("X shape:", X_a1.shape, "vars shape:", vars_a1.shape) # inspect shape bookkeeping.
```
▶ What you'll see: 100 points with two features and two diagonal variance vectors.

```python
lls_a1 = [] # store likelihood progress.
for step_a1 in range(25): # run diagonal-covariance EM.
    scores_a1 = [] # collect component scores.
    for k_a1 in range(2): # score each component.
        norm_a1 = 1 / (2 * np.pi * np.sqrt(np.prod(vars_a1[k_a1]))) # diagonal 2-D normal constant.
        expo_a1 = np.exp(-0.5 * np.sum((X_a1 - mus_a1[k_a1]) ** 2 / vars_a1[k_a1], axis=1)) # exponent term.
        scores_a1.append(pis_a1[k_a1] * norm_a1 * expo_a1) # weighted density.
    scores_a1 = np.column_stack(scores_a1) # shape n by k.
    resp_a1 = scores_a1 / scores_a1.sum(axis=1, keepdims=True) # E-step normalization.
    Nk_a1 = resp_a1.sum(axis=0) # effective counts.
    pis_a1 = Nk_a1 / len(X_a1) # update priors.
    mus_a1 = (resp_a1.T @ X_a1) / Nk_a1[:, None] # update means.
    vars_a1 = np.array([(resp_a1[:, k][:, None] * (X_a1 - mus_a1[k]) ** 2).sum(axis=0) / Nk_a1[k] for k in range(2)]) + 1e-6 # update diagonal variances.
    lls_a1.append(float(np.sum(np.log(scores_a1.sum(axis=1) + 1e-12)))) # record likelihood.
print("learned means:\n", np.round(mus_a1, 2)) # inspect fitted centers.
assert lls_a1[-1] > lls_a1[0] # verify EM improved likelihood.
```

▶ What you'll see: color changes smoothly between two 2-D clouds, with learned centers near the cloud centers.


```python
def diag_resp_a2(X, mus, vars_, pis): # small diagonal-Gaussian responsibility helper.
```

### Advanced 4 — Select the number of components with BIC

**Goal.** Compare K values using BIC, because more components always fit training density better but can overfit. We build it in 4 steps.

```python
rng_a4 = np.random.default_rng(14) # reproducible data.
x_a4 = np.concatenate([rng_a4.normal(-2.0, 0.35, 40), rng_a4.normal(1.8, 0.5, 50)]) # two-component data.

lls_a4 = [] # store best likelihood per K.
bics_a4 = [] # store BIC per K.
print("candidate K values:", Ks_a4) # inspect model sizes.
```
▶ What you'll see: the sweep will compare one through four components.

```python
for K_a4 in Ks_a4: # fit each candidate K.
    pis_a4 = np.ones(K_a4) / K_a4 # equal priors.
    mus_a4 = np.linspace(x_a4.min(), x_a4.max(), K_a4) # spread initial means across data range.
    sigmas_a4 = np.ones(K_a4) * np.std(x_a4) # broad initial spreads.
    for step_a4 in range(40): # run EM.
        resp_a4 = responsibilities_1d(x_a4, pis_a4, mus_a4, sigmas_a4) # E-step.
        Nk_a4 = resp_a4.sum(axis=0) + 1e-9 # effective counts with guard.
        pis_a4 = Nk_a4 / len(x_a4) # update priors.
        mus_a4 = (resp_a4 * x_a4[:, None]).sum(axis=0) / Nk_a4 # update means.
        sigmas_a4 = np.sqrt((resp_a4 * (x_a4[:, None] - mus_a4) ** 2).sum(axis=0) / Nk_a4 + 1e-6) # update spreads.
    ll_a4 = log_likelihood_1d(x_a4, pis_a4, mus_a4, sigmas_a4) # final likelihood.
    params_a4 = (K_a4 - 1) + K_a4 + K_a4 # weights plus means plus variances in 1-D.
    bic_a4 = -2 * ll_a4 + params_a4 * np.log(len(x_a4)) # BIC: lower is better.
    lls_a4.append(ll_a4); bics_a4.append(bic_a4) # store metrics.
print("log-likelihoods:", np.round(lls_a4, 1)) # inspect fit quality.
print("BIC:", np.round(bics_a4, 1)) # inspect penalized quality.
```

```python

```

👀 Takeaway: component count is a modeling choice that should be checked with a penalty or validation criterion.
