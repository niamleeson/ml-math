# 22.4 — Local Search

Local search stops storing a frontier of partial paths and instead edits one complete candidate solution at a time. That makes it useful when the path does not matter — only the final schedule, route, board, or assignment does. The tradeoff is that local evidence can be misleading: greedy steps can get trapped, while controlled randomness and short memory can help escape.

## 📖 Concept walkthrough — build each idea from scratch

Before the worked examples, we build local search one idea at a time. Run each cell in order and read the printed intermediate values: every score, neighbor comparison, and annealing probability is shown directly. This walkthrough is self-contained and uses a `_w` suffix so it will not collide with the examples below.

```python
import numpy as np  # arrays, random numbers, and small numerical checks.
import matplotlib.pyplot as plt  # objective landscapes, trajectories, schedules, and state diagrams.
import math  # exp() for simulated-annealing acceptance probabilities.
np.random.seed(0)  # reproducibility for any random choices.
```

### 1. Complete states, neighbors, and an objective landscape

In local search, a **state is already a complete candidate**. If we are choosing an integer position on a line, state `x=4` is not a partial path to a solution; it is the current full answer. The objective function `F(x)` gives that answer a score, and the neighborhood `N(x)` lists small edits we are willing to consider next. Search becomes repeated local repair: inspect nearby complete candidates, move if the rule says to move, and forget most of the path history.

```python
xs_w = np.arange(0, 11)  # complete candidate states: choose one integer location.
scores_w = np.array([1, 2, 4, 6, 8, 10, 12, 14, 13, 11, 9], dtype=float)  # objective F(x).
state_w = 4  # current complete candidate.
neighbors_w = np.array([state_w - 1, state_w + 1])  # small one-step edits around x=4.
print("current state:", state_w, "score:", scores_w[state_w])  # inspect the candidate we already have.
print("neighbors:", neighbors_w, "scores:", scores_w[neighbors_w])  # inspect local alternatives only.
assert np.array_equal(neighbors_w, np.array([3, 5]))  # the one-dimensional neighborhood is left/right.
plt.figure(figsize=(5, 3))  # create the landscape figure.
plt.plot(xs_w, scores_w, marker="o", color="steelblue")  # draw the objective value for every complete state.
plt.scatter([state_w], [scores_w[state_w]], s=90, color="crimson", label="current")  # mark the current state.
plt.scatter(neighbors_w, scores_w[neighbors_w], s=80, color="darkorange", label="neighbors")  # mark allowed edits.
plt.title("1: complete candidates and local neighbors")  # title the figure.
plt.xlabel("state x")  # label candidate states.
plt.ylabel("score F(x)")  # label the objective.
plt.legend()  # explain markers.
plt.show()
```
▶ What you'll see: one current state and its two neighbors highlighted on a full objective landscape.

*Why it's done this way:* local search saves memory by ranking complete candidates with `F(x)` instead of storing every partial route that could have led there.

### 2. Hill climbing: move only to a better neighbor

Hill climbing is the greedy local-search rule. At state `x`, evaluate neighbors and move to the one with the highest score only if it improves the current score. Formally, choose `x' = argmax_y in N(x) F(y)` and move when `F(x') > F(x)`. This is fast and easy to debug because every step has a local justification, but it proves only local optimality.

```python
scores_w2 = np.array([1, 2, 4, 6, 8, 10, 12, 14, 13, 11, 9], dtype=float)  # same single-peak landscape.
def neighbors_line_w(x, n):  # list valid left/right neighbors on a line.
    out = []  # collect valid edits.
    if x > 0:
        out.append(x - 1)  # left edit.
    if x < n - 1:
        out.append(x + 1)  # right edit.
    return np.array(out, dtype=int)  # return integer neighbor indices.
path_w2 = [0]  # start at the far left.
while True:  # repeat greedy improvement until no neighbor is better.
    x = path_w2[-1]  # current state.
    nb = neighbors_line_w(x, len(scores_w2))  # local candidates.
    best = int(nb[np.argmax(scores_w2[nb])])  # best local candidate.
    if scores_w2[best] <= scores_w2[x]:  # stop when even the best neighbor fails to improve.
        break
    path_w2.append(best)  # accept the uphill move.
print("hill-climb path:", path_w2)  # inspect the local decisions.
print("states visited:", len(path_w2), "final local optimum:", path_w2[-1])  # match lesson math.
assert path_w2 == [0, 1, 2, 3, 4, 5, 6, 7]  # the worked path climbs to x=7.
plt.figure(figsize=(5, 3))  # create trajectory figure.
plt.plot(np.arange(len(scores_w2)), scores_w2, marker="o", color="lightgray")  # draw full landscape.
plt.plot(path_w2, scores_w2[path_w2], marker="o", color="seagreen", linewidth=2)  # draw accepted steps.
plt.title("2: hill climbing follows improving neighbors")  # title the figure.
plt.xlabel("state x")  # label states.
plt.ylabel("score F(x)")  # label objective.
plt.show()
```
▶ What you'll see: the trajectory climbs monotonically from `0` to the local/global peak at `7`.

*Why it's done this way:* greed is cheap because it needs only neighbor scores, not a frontier or a global proof.

### 3. Local optima can be traps

A **local optimum** is a state that has no better neighbor. A **global optimum** is the best state anywhere. Hill climbing can stop at a local optimum even when a better peak is far away, because reaching that better peak may require a temporary downhill move. The failure is not bad luck; it is built into the rule that forbids downhill steps.

```python
trap_scores_w = np.array([1, 3, 6, 9, 7, 5, 6, 8, 12, 10], dtype=float)  # two-peak landscape.
trap_path_w = [0]  # start near the smaller peak.
while True:  # greedy climb.
    x = trap_path_w[-1]  # current state.
    nb = neighbors_line_w(x, len(trap_scores_w))  # local edits.
    best = int(nb[np.argmax(trap_scores_w[nb])])  # best neighbor.
    if trap_scores_w[best] <= trap_scores_w[x]:  # no improving neighbor means local optimum.
        break
    trap_path_w.append(best)  # accept improvement.
local_w = trap_path_w[-1]  # local optimum reached from 0.
global_w = int(np.argmax(trap_scores_w))  # true best state by exhaustive inspection for teaching.
print("local-climb final:", local_w, "global peak:", global_w)  # compare local and global.
print("missed distance:", global_w - local_w, "states")  # lesson's trap gap.
assert local_w == 3 and global_w == 8 and global_w - local_w == 5  # verify the trap example.
plt.figure(figsize=(5, 3))  # create trap figure.
plt.plot(np.arange(len(trap_scores_w)), trap_scores_w, marker="o", color="gray")  # draw landscape.
plt.plot(trap_path_w, trap_scores_w[trap_path_w], marker="o", color="crimson", linewidth=2, label="hill climb")  # draw trapped path.
plt.scatter([global_w], [trap_scores_w[global_w]], s=120, color="gold", edgecolor="black", label="global peak")  # mark better peak.
plt.title("3: a local optimum can hide a better peak")  # title the figure.
plt.xlabel("state x")  # label states.
plt.ylabel("score F(x)")  # label objective.
plt.legend()  # show marker meanings.
plt.show()
```
▶ What you'll see: hill climbing stops at `x=3` even though the taller peak is at `x=8`.

*Why it's done this way:* the plot separates what the algorithm can prove locally from what an all-seeing evaluator could know globally.

### 4. Simulated annealing: sometimes accept worse moves

Simulated annealing modifies the greedy rule: always accept an improving move, but accept a worse move with probability `exp(delta / T)`, where `delta = F(candidate) - F(current) < 0` and `T` is temperature. The math matters. Because `delta` is negative, `exp(delta/T)` lies between 0 and 1. High `T` makes `delta/T` close to 0, so `exp(delta/T)` is near 1 and exploration is tolerant. Low `T` makes `delta/T` very negative, so acceptance becomes rare and the search behaves like hill climbing.

```python
bridge_scores_w = np.array([1, 3, 6, 9, 7, 5, 6, 8, 12], dtype=float)  # route from small peak to better peak.
route_w = np.arange(0, 9)  # deliberately inspect the bridge 0->...->8.
deltas_w = np.diff(bridge_scores_w[route_w])  # score changes for each move.
T_hi_w, T_lo_w = 5.0, 0.5  # compare hot and cold temperatures.
down_delta_w = -2.0  # a representative downhill step, such as 9->7.
p_hi_w = math.exp(down_delta_w / T_hi_w)  # hot acceptance probability.
p_lo_w = math.exp(down_delta_w / T_lo_w)  # cold acceptance probability.
print("route states:", route_w.tolist(), "moves:", len(route_w) - 1)  # route length.
print("score deltas:", deltas_w.tolist(), "has downhill:", bool(np.any(deltas_w < 0)))  # find negative bridge steps.
print("P(accept delta=-2, T=5):", round(p_hi_w, 3), "T=0.5:", round(p_lo_w, 3))  # show the exponential effect.
assert len(route_w) == 9 and len(deltas_w) == 8 and np.any(deltas_w < 0)  # verify lesson bridge facts.
plt.figure(figsize=(5, 3))  # create route figure.
plt.plot(np.arange(len(bridge_scores_w)), bridge_scores_w, marker="o", color="gray")  # landscape.
plt.plot(route_w, bridge_scores_w[route_w], marker="o", color="darkorange", linewidth=2)  # route containing downhill moves.
for i in range(len(route_w) - 1):  # annotate accepted move directions.
    plt.annotate("", xy=(route_w[i+1], bridge_scores_w[route_w[i+1]]), xytext=(route_w[i], bridge_scores_w[route_w[i]]), arrowprops=dict(arrowstyle="->", color="darkorange"))
plt.title("4: annealing can cross a downhill bridge")  # title the figure.
plt.xlabel("state x")  # label state axis.
plt.ylabel("score F(x)")  # label objective.
plt.show()
```
▶ What you'll see: the route includes negative `delta` steps that hill climbing would reject, but annealing may accept early.

*Why it's done this way:* `exp(delta/T)` turns controlled bad moves into a temperature-dependent escape mechanism rather than unrestricted wandering.

### 5. Cooling schedule and acceptance over time

Temperature must usually cool. Early search benefits from exploration; late search should settle. A geometric schedule such as `T_t = T0 * alpha^t` is simple: each step keeps a fixed fraction of the previous temperature. For a fixed downhill loss, the acceptance probability falls smoothly as the temperature falls.

```python
steps_w5 = np.arange(30)  # annealing iteration numbers.
T0_w5, alpha_w5 = 6.0, 0.88  # starting temperature and cooling multiplier.
temps_w5 = T0_w5 * (alpha_w5 ** steps_w5)  # geometric cooling schedule.
delta_w5 = -1.5  # fixed downhill move size.
accept_w5 = np.exp(delta_w5 / temps_w5)  # acceptance probability for that fixed loss.
print("first temperature:", round(float(temps_w5[0]), 3), "last:", round(float(temps_w5[-1]), 3))  # inspect cooling.
print("first accept prob:", round(float(accept_w5[0]), 3), "last:", round(float(accept_w5[-1]), 3))  # inspect probability decay.
assert accept_w5[0] > accept_w5[-1]  # cooling makes the same bad move less likely.
fig, ax1 = plt.subplots(figsize=(5, 3))  # create dual-axis schedule figure.
ax1.plot(steps_w5, temps_w5, color="steelblue", label="temperature")  # plot T.
ax1.set_xlabel("iteration")  # label time.
ax1.set_ylabel("temperature", color="steelblue")  # label T axis.
ax2 = ax1.twinx()  # second y-axis for probabilities.
ax2.plot(steps_w5, accept_w5, color="crimson", label="accept prob")  # plot acceptance.
ax2.set_ylabel("P(accept delta=-1.5)", color="crimson")  # label probability axis.
plt.title("5: cooling lowers downhill acceptance")  # title the figure.
plt.show()
```
▶ What you'll see: both temperature and the probability of accepting the same worse move decrease over iterations.

*Why it's done this way:* annealing is useful only if its randomness is scheduled — hot enough to escape early, cool enough to commit later.

### 6. Random restarts and tabu memory

Random restarts run local search from multiple starting points and keep the best result. They do not change the hill-climbing rule; they reduce dependence on a single unlucky start. Tabu search adds short memory: recently visited states are temporarily forbidden so the search does not bounce between the same candidates. Both ideas spend a little extra work to buy robustness.

```python
restart_starts_w = np.array([0, 4, 6, 9])  # several independent starting points.
finals_w = []  # collect final local optima.
paths_w6 = []  # collect trajectories for plotting.
for start_w in restart_starts_w:  # run a separate hill climb from each start.
    p = [int(start_w)]  # path for this restart.
    while True:
        x = p[-1]  # current state.
        nb = neighbors_line_w(x, len(trap_scores_w))  # local edits.
        best = int(nb[np.argmax(trap_scores_w[nb])])  # best neighbor.
        if trap_scores_w[best] <= trap_scores_w[x]:  # stop at local optimum.
            break
        p.append(best)  # accept uphill move.
    paths_w6.append(p)  # save path.
    finals_w.append(p[-1])  # save final state.
best_final_w = int(finals_w[np.argmax(trap_scores_w[finals_w])])  # choose best restart result.
tabu_demo_w = [2, 3, 2, 3]  # no-memory bounce that a tabu list would block.
print("restart finals:", finals_w, "best final:", best_final_w)  # inspect restart spread.
print("tabu blocks immediate bounce like:", tabu_demo_w)  # show memory motivation.
assert best_final_w == 8  # one restart reaches the better peak.
plt.figure(figsize=(5, 3))  # create restart figure.
plt.plot(np.arange(len(trap_scores_w)), trap_scores_w, color="lightgray", marker="o")  # landscape.
for p in paths_w6:  # draw every restart trajectory.
    plt.plot(p, trap_scores_w[p], marker="o", linewidth=2)  # path overlay.
plt.scatter(finals_w, trap_scores_w[finals_w], s=100, color="black", label="restart finals")  # final states.
plt.title("6: random restarts spread search effort")  # title the figure.
plt.xlabel("state x")  # label candidate axis.
plt.ylabel("score F(x)")  # label objective.
plt.legend()  # explain black markers.
plt.show()
```
▶ What you'll see: different starts end at different peaks, and the best restart finds the global peak in this toy landscape.

*Why it's done this way:* restarts fight bad initialization, while tabu memory fights short cycles; both add robustness without storing a full search tree.

```python
import numpy as np

t1_rng = np.random.default_rng(0)
```

### ✍️ Toy 2 · Hill climbing accepts only improving neighbors

Hill climbing evaluates the local neighbors and moves only when the best neighbor improves the
score. On this small landscape, every accepted step goes uphill.

```python
import numpy as np

t2_rng = np.random.default_rng(0)
t2_scores = np.array([1.0, 3.0, 6.0, 8.0, 7.0, 5.0])
t2_path = [0]
while True:
    t2_x = t2_path[-1]
    t2_neighbors = []
    if t2_x > 0:
        t2_neighbors.append(t2_x - 1)
    if t2_x < len(t2_scores) - 1:
        t2_neighbors.append(t2_x + 1)
    t2_best = int(t2_neighbors[int(np.argmax(t2_scores[t2_neighbors]))])
    if t2_scores[t2_best] <= t2_scores[t2_x]:
        break
    t2_path.append(t2_best)
t2_path_scores = t2_scores[t2_path]
print("hill-climb path:", t2_path)  # -> [0, 1, 2, 3]
print("path scores:", t2_path_scores.tolist())  # -> [1.0, 3.0, 6.0, 8.0]
print("final state:", t2_path[-1])  # -> 3
assert t2_path == [0, 1, 2, 3] and np.all(np.diff(t2_path_scores) > 0)

plt.figure(figsize=(4.8, 2.8))
plt.plot(np.arange(len(t2_scores)), t2_scores, marker="o", color="lightgray")
plt.plot(t2_path, t2_path_scores, marker="o", color="seagreen", linewidth=2)
plt.xlabel("state x")
plt.ylabel("score")
plt.title("Toy 2 · greedy uphill moves")
plt.show()
```
▶ What you'll see: the accepted path climbs from score `1` to `8` and then stops.

### ✍️ Toy 4 · Annealing may accept a worse move when hot

Simulated annealing accepts all improvements, but a worse move with score change `delta < 0` is
accepted with probability `exp(delta/T)`. A fixed random draw can pass when hot and fail when cold.

```python
import numpy as np

t4_rng = np.random.default_rng(0)
t4_current = 7.0
t4_candidate = 5.0
t4_delta = t4_candidate - t4_current
t4_hot_T = 5.0
t4_cold_T = 0.5
t4_hot_prob = float(np.exp(t4_delta / t4_hot_T))
t4_cold_prob = float(np.exp(t4_delta / t4_cold_T))
t4_draw = float(t4_rng.random())
t4_hot_accept = t4_draw < t4_hot_prob
t4_cold_accept = t4_draw < t4_cold_prob
print("delta:", t4_delta)  # -> -2.0
print("hot accept prob:", round(t4_hot_prob, 3))  # -> 0.67
print("cold accept prob:", round(t4_cold_prob, 3))  # -> 0.018
print("random draw:", round(t4_draw, 3))  # -> 0.637
print("hot accepts, cold accepts:", t4_hot_accept, t4_cold_accept)  # -> True False
assert t4_hot_accept is True and t4_cold_accept is False

plt.figure(figsize=(4.8, 2.8))
plt.bar(["T=5", "T=0.5"], [t4_hot_prob, t4_cold_prob], color=["darkorange", "steelblue"])
plt.axhline(t4_draw, color="crimson", linestyle="--", label="draw")
plt.ylabel("P(accept worse move)")
plt.title("Toy 4 · heat makes downhill moves possible")
plt.legend()
plt.show()
```
▶ What you'll see: the same draw is below the hot probability but above the cold probability.

### ✍️ Toy 5 · Cooling lowers worse-move probability

A cooling schedule makes the same downhill move less likely over time. The temperature shrinks
geometrically, so the exponential acceptance probability shrinks too.

```python
import numpy as np

t5_rng = np.random.default_rng(0)
t5_steps = np.arange(5)
t5_T0 = 4.0
t5_alpha = 0.5
t5_delta = -1.0
t5_temps = t5_T0 * (t5_alpha ** t5_steps)
t5_probs = np.exp(t5_delta / t5_temps)
print("temperatures:", t5_temps.tolist())  # -> [4.0, 2.0, 1.0, 0.5, 0.25]
print("accept probs:", np.round(t5_probs, 3).tolist())  # -> [0.779, 0.607, 0.368, 0.135, 0.018]
print("first > last:", bool(t5_probs[0] > t5_probs[-1]))  # -> True
assert np.all(np.diff(t5_temps) < 0) and np.all(np.diff(t5_probs) < 0)

plt.figure(figsize=(4.8, 2.8))
plt.plot(t5_steps, t5_temps, "o-", label="temperature")
plt.plot(t5_steps, t5_probs, "o-", label="accept prob")
plt.xlabel("step")
plt.title("Toy 5 · cooling reduces exploration")
plt.legend()
plt.show()
```
▶ What you'll see: both the temperature curve and the acceptance-probability curve descend together.

### ✍️ Toy 6 · Restarts find better basins; tabu blocks bounces

Random restarts run the same local rule from several starts and keep the best final state. A tabu
list is short memory: if a candidate was just visited, block the immediate bounce.

```python
import numpy as np

t6_rng = np.random.default_rng(0)
t6_scores = np.array([1.0, 5.0, 4.0, 2.0, 6.0, 9.0, 7.0])

def t6_climb(t6_start):
    t6_path = [int(t6_start)]
    while True:
        t6_x = t6_path[-1]
        t6_neighbors = []
        if t6_x > 0:
            t6_neighbors.append(t6_x - 1)
        if t6_x < len(t6_scores) - 1:
            t6_neighbors.append(t6_x + 1)
        t6_best = int(t6_neighbors[int(np.argmax(t6_scores[t6_neighbors]))])
        if t6_scores[t6_best] <= t6_scores[t6_x]:
            break
        t6_path.append(t6_best)
    return t6_path

t6_starts = np.array([0, 3, 6])
t6_paths = [t6_climb(t6_start) for t6_start in t6_starts]
t6_finals = [t6_path[-1] for t6_path in t6_paths]
t6_best_final = int(t6_finals[int(np.argmax(t6_scores[t6_finals]))])
t6_recent = [2, 3]
t6_candidate = 2
t6_tabu_blocks = t6_candidate in t6_recent
print("restart paths:", t6_paths)  # -> [[0, 1], [3, 4, 5], [6, 5]]
```

## 🛠️ Setup

```python
import numpy as np  # numerical arrays, random choices, and assertions.
import matplotlib.pyplot as plt  # required visualizations for landscapes, paths, and states.
import math  # exponential acceptance math for simulated annealing.
np.random.seed(0)  # reproducible examples.

def line_neighbors(x, n):  # return valid one-step neighbors on a 1-D landscape.
    out = []  # collect neighbors.
    if x > 0:
        out.append(x - 1)  # left neighbor.
    if x < n - 1:
        out.append(x + 1)  # right neighbor.
    return np.array(out, dtype=int)  # integer indices.

def hill_climb_1d(scores, start):  # greedy ascent on a discrete one-dimensional objective.
    scores = np.asarray(scores, dtype=float)  # normalize input type.
    path = [int(start)]  # store visited states for visualization.
    while True:  # repeat until no improvement exists.
        x = path[-1]  # current state.
        nb = line_neighbors(x, len(scores))  # local edits.
        best = int(nb[np.argmax(scores[nb])])  # best-scoring neighbor.
        if scores[best] <= scores[x]:  # stop at local optimum.
            break
        path.append(best)  # move uphill.
    return np.array(path, dtype=int)  # return trajectory.

def objective_2d(x, y):  # smooth two-dimensional maximization landscape.
    return 3 * np.exp(-((x - 1.2) ** 2 + (y - 1.0) ** 2)) + 2 * np.exp(-((x + 1.4) ** 2 + (y + 1.1) ** 2) / 0.7) - 0.15 * (x ** 2 + y ** 2)  # two hills plus mild penalty.

def nqueen_conflicts(cols):  # count attacking queen pairs for one queen per row.
    cols = np.asarray(cols, dtype=int)  # ensure integer columns.
    c = 0  # conflict counter.
    for i in range(len(cols)):  # first queen row.
        for j in range(i + 1, len(cols)):  # second queen row.
            same_col = cols[i] == cols[j]  # vertical attack.
            same_diag = abs(cols[i] - cols[j]) == abs(i - j)  # diagonal attack.
            c += int(same_col or same_diag)  # add one attacking pair if either condition holds.
    return c  # lower is better.

def tsp_length(route, points):  # compute closed-tour length for a TSP route.
    route = np.asarray(route, dtype=int)  # ensure index array.
    total = 0.0  # accumulate edge lengths.
    for k in range(len(route)):  # each city in tour order.
        a = points[route[k]]  # current point.
        b = points[route[(k + 1) % len(route)]]  # next point, wrapping to start.
        total += float(np.linalg.norm(a - b))  # Euclidean edge length.
    return total  # lower is better.
```

#### A5. Combine annealing with TSP 2-opt proposals

**Goal.** Apply annealing to TSP segment reversals, because accepting a longer tour early can help route search avoid poor local structure. We build it in 5 steps.


▶ What you'll see: the TSP state is a complete closed tour.

```python

alpha_a5 = 0.85  # cooling rate.
```

```python

    cand_a5 = current_a5.copy()  # candidate tour.
    cand_a5[i_a5:j_a5 + 1] = cand_a5[i_a5:j_a5 + 1][::-1]  # reverse segment.

        path_routes_a5.append(current_a5.copy())  # record route.
        lengths_a5.append(tsp_length(current_a5, points_a5))  # record cost.
```
