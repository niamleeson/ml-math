# 22.10 — Planning Under Uncertainty

Classical planning assumes an action has one known effect. Planning under uncertainty replaces that brittle picture with probabilities: in an MDP, actions lead to distributions over next states; in a POMDP, even the current state is uncertain, so the planner maintains a belief distribution. The central habit is Bellman reasoning: value now equals reward now plus discounted expected value later.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build stochastic planning one idea at a time. Run each cell in order and read the printed intermediate values — every probability, expectation, Bellman backup, and belief update is made explicit. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, probabilities, value tables, and linear algebra.
```

### 1. From deterministic plans to stochastic transitions

A deterministic planner says: "if I take action `right`, I move right." An MDP says: "if I take action `right`, I usually move right, but sometimes I slip up or down." That small change is the whole reason we need expected value. A state-action pair no longer has one successor; it has a probability distribution $P(s'\mid s,a)$ over possible successors, and the probabilities must sum to 1.

```python
states_w = ["left", "middle", "right"]  # three positions in a tiny corridor.
P_right_w = np.array([[0.20, 0.80, 0.00],  # from left: mostly reaches middle.
                      [0.10, 0.20, 0.70],  # from middle: mostly reaches right.
                      [0.00, 0.20, 0.80]]) # from right: mostly stays near right.
print("transition row sums:", P_right_w.sum(axis=1))  # every row is a distribution.
assert np.allclose(P_right_w.sum(axis=1), 1.0)  # probabilities must normalize.
```
▶ What you'll see: every row sums to 1, so each current state has a valid next-state distribution.

```python
plt.figure(figsize=(4.6, 3.2))  # compact transition-matrix heatmap.
plt.imshow(P_right_w, cmap="Blues", vmin=0, vmax=1)  # color = transition probability.
plt.colorbar(label="P(next state | state, right)")  # interpret colors numerically.
plt.xticks(range(3), states_w); plt.yticks(range(3), states_w)  # label current and next states.
plt.xlabel("next state s'"); plt.ylabel("current state s")  # make orientation explicit.
plt.title("1: stochastic action model for 'right'"); plt.show()  # render the MDP dynamics.
```
▶ What you'll see: most probability mass sits near the intended rightward move, but failure states still matter.

*Why it's done this way:* stochastic transitions prevent the planner from pretending the best successor is guaranteed; every later Bellman backup must average over this matrix.

### 2. One Bellman backup: reward now plus expected future value

The MDP Bellman optimality equation is

$$V^*(s)=\max_a\left[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^*(s')\right].$$

Read it in three pieces. $R(s,a)$ is immediate reward. The sum $\sum_{s'}P(s'\mid s,a)V(s')$ is the expected next value under the action's transition distribution. The discount $\gamma$ says how much that future value counts today. Then the max chooses the action with the largest backed-up value.

```python
reward_w = 1.0  # immediate reward for taking the action.
gamma_w = 0.9  # discount factor for one step of future value.
probs_w = np.array([0.2, 0.8])  # two possible next-state probabilities.
next_values_w = np.array([0.0, 10.0])  # values of those possible next states.
expected_next_w = float(np.dot(probs_w, next_values_w))  # 0.2*0 + 0.8*10.
q_w = reward_w + gamma_w * expected_next_w  # Bellman backup for this action.
print("expected next value:", expected_next_w)  # inspect the expectation.
print("Bellman Q:", q_w)  # reward + discounted expected future.
assert q_w == 8.2  # matches the source worked example.
```
▶ What you'll see: the action's value is 8.2 because most probability mass points to the valuable next state.

```python
plt.figure(figsize=(4.4, 3))  # show how next-state values are weighted.
plt.bar(["low next", "high next"], probs_w * next_values_w, color="seagreen")  # each probability-weighted contribution.
plt.axhline(expected_next_w, color="black", linestyle="--", label="expected next value")  # summary expectation.
plt.ylabel("P(s') × V(s')"); plt.title("2: Bellman expectation pieces"); plt.legend(); plt.show()
```
▶ What you'll see: the high-value successor dominates the expectation because it has both high value and high probability.

*Why it's done this way:* Bellman backups are recursive accounting: immediate reward is known now, while future reward is uncertain and must be probability-weighted before discounting.

### 3. Discounting turns time into value

A reward far in the future is worth $\gamma^t$ times its face value after $t$ steps. With a small $\gamma$, the planner is myopic; with a large $\gamma$, it is patient. The source example makes the scale clear: a reward of 10 three steps later ranges from almost worthless at $\gamma=0.1$ to almost full value at $\gamma=0.99$.

```python
gammas_w = np.array([0.1, 0.9, 0.99])  # short-, medium-, and long-horizon planners.
delayed_reward_w = 10.0  # reward arriving later.
steps_later_w = 3  # number of discount steps.
present_values_w = delayed_reward_w * gammas_w ** steps_later_w  # 10*gamma^3.
print("present values:", np.round(present_values_w, 3))  # [0.010, 7.290, 9.703].
assert np.allclose(np.round(present_values_w, 3), [0.010, 7.290, 9.703])  # source numbers.
```
▶ What you'll see: the same delayed reward has radically different present value under different discounts.

```python
plt.figure(figsize=(4.6, 3))  # visualize the horizon effect.
plt.bar(["γ=0.1", "γ=0.9", "γ=0.99"], present_values_w, color=["crimson", "orange", "teal"])  # discounted values.
plt.ylabel("10 × γ³"); plt.title("3: discount factor controls planning horizon"); plt.show()
```
▶ What you'll see: patient planners preserve delayed reward; myopic planners nearly erase it.

*Why it's done this way:* discounting is not decoration; it is a mathematical statement about how much future consequences should influence today's action.

### 4. Value iteration: repeat Bellman backups until values stabilize

Value iteration applies the Bellman optimality equation to every state again and again. At first all values are crude; each sweep backs terminal rewards and future possibilities one step farther through the grid. Convergence means additional sweeps change the value table very little.

```python
H_w, W_w = 3, 4  # grid shape.
terminal_w = (0, 3)  # rewarding goal state.
wall_w = (1, 1)  # blocked cell.
actions_w = {"U": (-1, 0), "D": (1, 0), "L": (0, -1), "R": (0, 1)}  # four moves.
V_w = np.zeros((H_w, W_w))  # initial value estimate.
rewards_w = -0.04 * np.ones((H_w, W_w))  # small step cost.
rewards_w[terminal_w] = 1.0  # goal reward.
rewards_w[wall_w] = 0.0  # wall is not updated.
print("initial values:\n", V_w)  # inspect the starting table.
```
▶ What you'll see: value iteration starts from zeros before reward information has propagated.

```python
def step_w(s, a):  # deterministic helper used inside a stochastic transition model.
    r, c = s  # unpack the row and column.
    dr, dc = actions_w[a]  # intended move direction.
    nr, nc = r + dr, c + dc  # proposed successor.
    if nr < 0 or nr >= H_w or nc < 0 or nc >= W_w or (nr, nc) == wall_w:  # invalid move.
        return s  # bounce back to the same state.
    return (nr, nc)  # valid successor.

def backup_grid_w(V, s, gamma=0.9):  # one Bellman optimality backup for a grid state.
    if s == terminal_w or s == wall_w:  # terminal and wall stay fixed in this toy grid.
        return rewards_w[s]
    q_vals = []  # collect action values.
    for a in actions_w:  # evaluate each intended action.
        main = step_w(s, a)  # intended successor.
        slips = [step_w(s, x) for x in actions_w if x != a]  # possible accidental moves.
        expected = 0.8 * V_w[main] + sum((0.2 / 3) * V_w[x] for x in slips)  # stochastic expectation.
        q_vals.append(rewards_w[s] + gamma * expected)  # immediate reward plus discounted future.
    return max(q_vals)  # optimal state value.

errors_w = []  # max change per sweep.
for sweep_w in range(35):  # repeated Bellman sweeps.
    old_w = V_w.copy()  # previous value table.
    for r_w in range(H_w):  # loop rows.
        for c_w in range(W_w):  # loop columns.
            V_w[r_w, c_w] = backup_grid_w(old_w, (r_w, c_w))  # synchronous-style update.
    errors_w.append(float(np.max(np.abs(V_w - old_w))))  # convergence diagnostic.
print("final values:\n", np.round(V_w, 3))  # inspect converged values.
assert errors_w[-1] < errors_w[0]  # sweeps reduce the maximum update size.
```
▶ What you'll see: values are highest near the goal and lower farther away or near the wall.

```python
fig, ax = plt.subplots(1, 2, figsize=(7.2, 3))  # values plus convergence.
im = ax[0].imshow(V_w, cmap="viridis")  # state-value heatmap.
ax[0].set_title("4: state values after value iteration"); ax[0].set_xticks(range(W_w)); ax[0].set_yticks(range(H_w))
fig.colorbar(im, ax=ax[0], fraction=0.046)  # value colorbar.
ax[1].plot(errors_w, color="purple")  # convergence curve.
ax[1].set_title("max Bellman change"); ax[1].set_xlabel("sweep"); ax[1].set_ylabel("max |ΔV|")
plt.tight_layout(); plt.show()
```
▶ What you'll see: the value heatmap slopes toward the goal, and the Bellman changes shrink toward zero.

*Why it's done this way:* repeated backups solve the recursive equation by fixed-point iteration; the convergence curve verifies the recursion has mostly stabilized.

### 5. A policy chooses the action with the best backed-up value

Once values are known, the greedy policy is easy: for each state, compute every action's Bellman $Q(s,a)$ and choose the largest. The policy is not merely a shortest path; it accounts for slipping, walls, step costs, terminal reward, and discounting.

```python
def q_grid_w(V, s, a, gamma=0.9):  # action-value under the same stochastic grid dynamics.
    main = step_w(s, a)  # intended successor.
    slips = [step_w(s, x) for x in actions_w if x != a]  # accidental successors.
    expected = 0.8 * V[main] + sum((0.2 / 3) * V[x] for x in slips)  # expected next value.
    return float(rewards_w[s] + gamma * expected)  # Bellman Q.

arrow_w = {"U": "↑", "D": "↓", "L": "←", "R": "→"}  # readable policy symbols.
policy_w = np.full((H_w, W_w), " ", dtype=object)  # table of greedy actions.
for r_w in range(H_w):  # loop grid rows.
    for c_w in range(W_w):  # loop grid columns.
        s_w = (r_w, c_w)  # current state.
        if s_w == terminal_w:
            policy_w[s_w] = "G"  # goal marker.
        elif s_w == wall_w:
            policy_w[s_w] = "■"  # wall marker.
        else:
            qs_w = {a: q_grid_w(V_w, s_w, a) for a in actions_w}  # evaluate each action.
            policy_w[s_w] = arrow_w[max(qs_w, key=qs_w.get)]  # choose best action.
print(policy_w)  # inspect the greedy policy table.
assert policy_w[terminal_w] == "G"  # terminal is labeled, not moved from.
```
▶ What you'll see: arrows generally point toward the goal while respecting the wall and stochastic risk.

```python
plt.figure(figsize=(4.8, 3.4))  # policy overlay figure.
plt.imshow(V_w, cmap="viridis")  # value heatmap background.
plt.colorbar(label="V(s)")  # value scale.
for r_w in range(H_w):  # annotate every cell.
    for c_w in range(W_w):
        plt.text(c_w, r_w, policy_w[r_w, c_w], ha="center", va="center", color="white", fontsize=16, fontweight="bold")
plt.xticks(range(W_w)); plt.yticks(range(H_w)); plt.title("5: greedy policy arrows over values"); plt.show()
```
▶ What you'll see: the policy is the actionable plan extracted from the value table.

*Why it's done this way:* values answer "how good is this state?"; the greedy policy converts those numbers into "what should I do here?" by comparing backed-up action values.

### 6. POMDP belief updates: plan over distributions when state is hidden

A POMDP adds a harder uncertainty: the agent may not know which state it is in. Instead of a single state, it keeps a belief vector $b(s)$ whose entries sum to 1. After an action, the transition model predicts a new belief; after an observation, Bayes' rule multiplies by observation likelihoods and normalizes.

```python
belief_w = np.array([0.6, 0.4])  # prior belief over hidden states [safe, risky].
T_wait_w = np.array([[0.90, 0.10],  # if safe, usually remains safe.
                     [0.30, 0.70]]) # if risky, sometimes recovers.
obs_likelihood_w = np.array([0.2, 0.9])  # likelihood of seeing an alarm in each hidden state.
pred_belief_w = belief_w @ T_wait_w  # transition prediction b'(s') = sum_s b(s)P(s'|s,a).
unnorm_w = pred_belief_w * obs_likelihood_w  # multiply by observation likelihood.
posterior_w = unnorm_w / unnorm_w.sum()  # normalize into a belief distribution.
print("predicted belief:", np.round(pred_belief_w, 3))  # transition-only belief.
print("posterior after alarm:", np.round(posterior_w, 3))  # updated hidden-state belief.
assert np.isclose(posterior_w.sum(), 1.0)  # beliefs must sum to one.
```
▶ What you'll see: the alarm shifts belief toward the risky state because it is much more likely there.

```python
x_w = np.arange(2)  # hidden-state positions.
plt.figure(figsize=(5, 3))  # grouped belief bars.
plt.bar(x_w - 0.2, belief_w, width=0.2, label="prior", color="gray")  # before action.
plt.bar(x_w, pred_belief_w, width=0.2, label="after transition", color="orange")  # prediction step.
plt.bar(x_w + 0.2, posterior_w, width=0.2, label="after observation", color="teal")  # correction step.
plt.xticks(x_w, ["safe", "risky"]); plt.ylim(0, 1); plt.ylabel("belief probability")
plt.title("6: POMDP belief update"); plt.legend(); plt.show()
```
▶ What you'll see: transition and observation each reshape the probability distribution over hidden states.

*Why it's done this way:* when the true state is hidden, the belief is the planner's sufficient state summary; failing to normalize would leave numbers that cannot be interpreted as probabilities.

### 7. Common pitfalls: best-successor shortcuts, casual γ, and unnormalized beliefs

Three mistakes break uncertainty-aware planning. First, replacing the expectation with the best successor acts as if luck is guaranteed. Second, changing $\gamma$ casually changes the planning horizon. Third, forgetting belief normalization turns Bayesian weights into non-probabilities.

```python
stochastic_q_w = 1.0 + 0.9 * np.dot(np.array([0.2, 0.8]), np.array([0.0, 10.0]))  # correct expected backup.
best_successor_q_w = 1.0 + 0.9 * np.max(np.array([0.0, 10.0]))  # wrong deterministic optimism.
raw_belief_w = np.array([0.12, 0.36])  # unnormalized posterior weights from the source example.
normalized_belief_w = raw_belief_w / raw_belief_w.sum()  # valid belief distribution.
print("correct Q:", stochastic_q_w, "best-successor Q:", best_successor_q_w)  # compare planning assumptions.
print("raw sum:", raw_belief_w.sum(), "normalized sum:", normalized_belief_w.sum())  # check belief validity.
assert best_successor_q_w > stochastic_q_w  # shortcut overstates reliability.
assert np.isclose(normalized_belief_w.sum(), 1.0)  # only normalized weights are a belief.
```
▶ What you'll see: the deterministic shortcut is too optimistic, and raw posterior weights do not sum to 1.

```python
fig, ax = plt.subplots(1, 2, figsize=(7.4, 3))  # pitfalls side by side.
ax[0].bar(["expected", "best successor"], [stochastic_q_w, best_successor_q_w], color=["seagreen", "crimson"])  # Bellman pitfall.
ax[0].set_title("shortcut overstates Q"); ax[0].set_ylabel("backup value")
ax[1].bar(["safe raw", "risky raw", "safe norm", "risky norm"], [raw_belief_w[0], raw_belief_w[1], normalized_belief_w[0], normalized_belief_w[1]], color=["gray", "gray", "teal", "teal"])  # belief pitfall.
ax[1].set_title("normalize belief weights"); ax[1].tick_params(axis="x", rotation=25)
plt.tight_layout(); plt.show()
```
▶ What you'll see: uncertainty-aware planning is more conservative than best-case planning, and normalized beliefs are interpretable probabilities.

*Why it's done this way:* the source lesson's warnings are operational checks: use expectation, tune $\gamma$ deliberately, and normalize every belief update.

## 🛠️ Setup

```python
import numpy as np  # load NumPy for arrays, probabilities, and value iteration.
import matplotlib.pyplot as plt  # load Matplotlib for heatmaps, arrows, bars, and convergence curves.
np.random.seed(0)  # make examples reproducible.

ACTIONS = {"U": (-1, 0), "D": (1, 0), "L": (0, -1), "R": (0, 1)}  # grid moves used in many examples.
ARROWS = {"U": "↑", "D": "↓", "L": "←", "R": "→"}  # readable policy symbols.

def expected_value(probs, values):  # compute sum_s' P(s') V(s') for a distribution.
    probs = np.asarray(probs, dtype=float)  # ensure probability vector arithmetic is numeric.
    values = np.asarray(values, dtype=float)  # ensure value vector arithmetic is numeric.
    assert np.isclose(np.sum(probs), 1.0)  # guard that probabilities form a distribution.
    return float(np.dot(probs, values))  # return the expectation.

def bellman_q(reward, gamma, probs, next_values):  # one action-value Bellman backup.
    return float(reward + gamma * expected_value(probs, next_values))  # immediate reward plus discounted expected future.

def move(state, action, shape, walls=()):  # deterministic grid move with boundary and wall bounce-back.
    r, c = state  # unpack row and column.
    dr, dc = ACTIONS[action]  # get movement direction.
    nr, nc = r + dr, c + dc  # proposed next state.
    if nr < 0 or nr >= shape[0] or nc < 0 or nc >= shape[1] or (nr, nc) in walls:  # invalid move.
        return state  # stay in place after bumping into boundary or wall.
    return (nr, nc)  # valid next state.

def transition_distribution(state, action, shape, walls=(), intended=0.8):  # stochastic grid transition as a dict.
    probs = {}  # map successor states to probabilities.
    slip = (1.0 - intended) / (len(ACTIONS) - 1)  # split remaining probability across other actions.
    for a in ACTIONS:  # consider intended action plus slips.
        p = intended if a == action else slip  # choose the probability for this realized move.
        nxt = move(state, a, shape, walls)  # find resulting state.
        probs[nxt] = probs.get(nxt, 0.0) + p  # accumulate if multiple moves bounce to same state.
    assert np.isclose(sum(probs.values()), 1.0)  # transition distribution must normalize.
    return probs  # return successor probabilities.

def grid_q(V, rewards, state, action, gamma=0.9, walls=(), terminals=()):  # Bellman Q for a grid action.
    dist = transition_distribution(state, action, V.shape, walls)  # get P(s'|s,a).
    future = sum(p * V[s2] for s2, p in dist.items())  # expected next value.
    return float(rewards[state] + gamma * future)  # immediate reward plus discounted future.

def value_iteration(rewards, gamma=0.9, walls=(), terminals=(), sweeps=60):  # tabular MDP value iteration.
    V = np.zeros_like(rewards, dtype=float)  # initialize all state values to zero.
    errors = []  # store max value change after each sweep.
    for _ in range(sweeps):  # repeat Bellman updates.
        old = V.copy()  # synchronous reference values.
        for r in range(V.shape[0]):  # loop over rows.
            for c in range(V.shape[1]):  # loop over columns.
                s = (r, c)  # current state.
                if s in walls:  # walls are not decision states.
                    V[s] = 0.0  # keep wall value neutral.
                elif s in terminals:  # terminal states keep their terminal reward.
                    V[s] = rewards[s]  # fixed terminal value.
                else:
                    V[s] = max(grid_q(old, rewards, s, a, gamma, walls, terminals) for a in ACTIONS)  # optimal backup.
        errors.append(float(np.max(np.abs(V - old))))  # convergence diagnostic.
    return V, np.array(errors)  # return values and learning curve.

def greedy_policy(V, rewards, gamma=0.9, walls=(), terminals=()):  # extract greedy arrows from a value table.
    policy = np.full(V.shape, " ", dtype=object)  # initialize policy labels.
    for r in range(V.shape[0]):  # loop rows.
        for c in range(V.shape[1]):  # loop columns.
            s = (r, c)  # current state.
            if s in walls:
                policy[s] = "■"  # wall marker.
            elif s in terminals:
                policy[s] = "G"  # goal marker.
            else:
                qs = {a: grid_q(V, rewards, s, a, gamma, walls, terminals) for a in ACTIONS}  # evaluate actions.
                policy[s] = ARROWS[max(qs, key=qs.get)]  # best action arrow.
    return policy  # return arrow table.

def belief_update(prior, transition, likelihood):  # one POMDP predict-correct update.
    prior = np.asarray(prior, dtype=float)  # current belief distribution.
    transition = np.asarray(transition, dtype=float)  # row-stochastic transition matrix.
    likelihood = np.asarray(likelihood, dtype=float)  # observation likelihood by state.
    assert np.isclose(prior.sum(), 1.0)  # prior must be a belief.
    assert np.allclose(transition.sum(axis=1), 1.0)  # each transition row must normalize.
    predicted = prior @ transition  # prediction step.
    unnorm = predicted * likelihood  # correction weights.
    posterior = unnorm / unnorm.sum()  # normalize.
    assert np.isclose(posterior.sum(), 1.0)  # posterior must be a belief.
    return predicted, unnorm, posterior  # return all pieces for teaching.

def show_grid_values(V, title):  # small value heatmap helper.
    plt.figure(figsize=(4.5, 3.2))  # compact figure.
    plt.imshow(V, cmap="viridis")  # draw state values.
    plt.colorbar(label="V(s)")  # numeric color scale.
    plt.title(title)  # label the plot.
    plt.xlabel("column")  # grid column axis.
    plt.ylabel("row")  # grid row axis.
    plt.show()  # display.
```


```python
row_sums_b1 = P_b1.sum(axis=1)  # sum each row to check valid probability distributions.
```

▶ What you'll see: the high-value successor contributes 8 because it is likely and valuable.

```python
exp_b2 = expected_value(probs_b2, values_b2)  # compute sum P(s')V(s').

assert exp_b2 == 8.0  # verify the source example's expectation.
plt.figure(figsize=(4, 3))  # create contribution chart.
plt.bar(["s0", "s1"], products_b2, color="seagreen")  # show each weighted contribution.
plt.axhline(exp_b2, color="black", linestyle="--", label="sum = 8")  # mark total expectation.
```

#### B3. Perform one Bellman backup

```python
    for a in ACTIONS:  # realized directions.

        nxt = move(state, a, shape, walls)  # successor.
        probs[nxt] = probs.get(nxt, 0.0) + p  # accumulate bounce-backs.
    return probs  # distribution.

def value_iteration_noise_a1(noise):  # value iteration using the noise-specific transition.
    V = np.zeros_like(rewards_b6)  # initialize values.
    for _ in range(60):  # Bellman sweeps.
        old = V.copy()  # previous values.
        for r in range(3):  # rows.
            for c in range(4):  # columns.
                s = (r, c)  # state.
                if s == wall_b6:
                    V[s] = 0.0  # wall.
                elif s == goal_b6:
                    V[s] = rewards_b6[s]  # goal.
                else:
                    qs = []  # action values.
                    for a in ACTIONS:  # actions.
                        dist = transition_distribution_noise_a1(s, a, (3, 4), walls=(wall_b6,), noise=noise)  # transition.
                        qs.append(rewards_b6[s] + 0.9 * sum(p * old[s2] for s2, p in dist.items()))  # Bellman Q.
                    V[s] = max(qs)  # optimal backup.
    return V  # converged values.

for noise_a1 in noise_levels_a1:  # sweep noise.
    V_noise_a1 = value_iteration_noise_a1(float(noise_a1))  # solve MDP.
    start_values_a1.append(V_noise_a1[start_a1])  # record start value.
print("start values:", np.round(start_values_a1, 3))  # inspect degradation.
```

```python
def rollout_return_a5(start, max_steps=25):  # simulate one stochastic trajectory.
    s = start  # current state.
    total = 0.0  # discounted return accumulator.
    discount = 1.0  # gamma^t accumulator.
    for _ in range(max_steps):  # finite cap to keep simulation bounded.
        total += discount * rewards_b6[s]  # collect reward at current state.
        if s == goal_b6:  # stop at terminal goal.
            break
        symbol = policy_a5[s]  # greedy arrow symbol.

        dist = transition_distribution(s, action, rewards_b6.shape, walls=(wall_b6,))  # stochastic transition.
        next_states = list(dist.keys())  # possible successors.
        probs = np.array(list(dist.values()))  # successor probabilities.
        idx = rng_a5.choice(len(next_states), p=probs)  # sample next state.
        s = next_states[idx]  # advance.
        discount *= 0.9  # update discount.
    return total  # sampled discounted return.
```
