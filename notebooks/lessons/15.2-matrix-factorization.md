# 15.2 · Matrix Factorization

Matrix factorization (MF) explains a sparse user-item rating table by giving each user and item a short latent vector, then scoring a pair with a dot product. In this lesson, you will build MF from first principles, inspect every intermediate value, and see why the low-rank bottleneck helps recommenders generalize instead of memorizing cells.

## Setup

```python
# !pip install numpy matplotlib # install the only packages used in this lesson when running outside Colab.
import numpy as np # load NumPy for arrays, linear algebra, random numbers, and small numerical checks.
import matplotlib.pyplot as plt # load Matplotlib so every concept can be inspected visually.
np.random.seed(0) # make all random examples reproducible across Colab runs.

def predict(P, Q): # define the MF prediction rule R_hat = P Q^T.
    return P @ Q.T # multiply user factors by item factors to score every user-item pair.

def observed_mask(R): # define a helper that marks which entries are observed ratings.
    return R > 0 # treat positive ratings as observed and zeros as blanks in most recommender demos.

def show_matrix(M, title): # define a tiny heatmap helper for matrices.
    plt.figure(figsize=(4, 3)) # create one compact figure for the current matrix.

    plt.colorbar(label="value") # add a color scale so colors can be read as numbers.
    plt.title(title) # label the plot with the example name and concept.
    plt.xlabel("item") # label columns as items.
    plt.ylabel("user") # label rows as users.
    plt.show() # display the heatmap.
```

▶ What you'll see: the first two users like the first items, the last two users like the last items, and zeros are blanks rather than dislikes.

👀 Takeaway: MF models only observed entries Ω unless we intentionally redefine zeros as negative exposure signals.

#### B3. Score a rating with a dot product

**Goal.** Turn one user factor and one item factor into a predicted rating, because MF scores affinity as p·q. We build it in 2 steps.

```python
p0_b3 = np.array([1.2, 0.2]) # user 0's latent factors on two hidden axes.

print("p0:", p0_b3, "q0:", q0_b3) # inspect the two vectors we will align.
```

```python
r_hat_b3 = float(p0_b3 @ q0_b3) # compute the dot product as the predicted rating.
print("predicted rating:", round(r_hat_b3, 3)) # inspect the worked score.
assert round(r_hat_b3, 3) == 4.84 # verify the lesson number 1.2*4.0 + 0.2*0.2 = 4.840.
plt.figure(figsize=(4, 3)) # create a bar chart for contribution debugging.
plt.bar(["axis0", "axis1"], p0_b3 * q0_b3, color="teal") # plot each per-axis product that sums to p dot q.

plt.ylabel("contribution") # label the contribution scale.
plt.show() # display the bar chart.
```
▶ What you'll see: axis 0 contributes 4.8, axis 1 only 0.04, so the score is dominated by the shared strong axis.

👀 Takeaway: a rating is high when user and item point the same way in latent space.

#### B5. Measure one prediction error

```python
p_b5 = np.array([0.8, 0.2]) # choose a current user factor before learning.

```

```python
pred_b5 = float(p_b5 @ q_b5) # compute the current predicted rating.
```

#### B7. Penalize large factors with regularization

**Goal.** Compute λ(||p||² + ||q||²), because regularization limits capacity and discourages huge latent factors that memorize ratings. We build it in 3 steps.

```python
p_b7 = np.array([0.8, 0.2]) # choose a user factor to penalize.
q_b7 = np.array([3.0, 0.4]) # choose an item factor to penalize.
lam_b7 = 0.1 # set the regularization strength lambda.
print("p:", p_b7, "q:", q_b7, "lambda:", lam_b7) # inspect the ingredients.
```

```python
p_penalty_b7 = float(np.sum(p_b7 ** 2)) # compute the user factor squared norm.
q_penalty_b7 = float(np.sum(q_b7 ** 2)) # compute the item factor squared norm.
reg_b7 = lam_b7 * (p_penalty_b7 + q_penalty_b7) # scale the total size penalty by lambda.
print("p norm^2:", round(p_penalty_b7, 3), "q norm^2:", round(q_penalty_b7, 3), "regularization:", round(reg_b7, 3)) # inspect regularization pieces.
```

```python
plt.figure(figsize=(4, 3)) # create a regularization breakdown plot.
plt.bar(["||p||²", "||q||²", "λ total"], [p_penalty_b7, q_penalty_b7, reg_b7], color=["teal", "orange", "gray"]) # compare raw norms and scaled penalty.
plt.title("B7: factor-size penalty") # title the plot.
plt.ylabel("penalty component") # label the numeric scale.
plt.show() # display the bar chart.
```
▶ What you'll see: the item factor dominates the penalty because q has much larger coordinates.

👀 Takeaway: λ controls the bias-complexity tradeoff by charging the model for large factor magnitudes.

#### B8. Compute the gradient for p

**Goal.** Calculate ∂/∂p = −2 e q + 2λp for one cell, because gradients tell us which direction reduces observed loss plus regularization. We build it in 3 steps.

```python
p_b8 = np.array([0.8, 0.2]) # define the current user factor.
q_b8 = np.array([3.0, 0.4]) # define the current item factor.
r_b8 = 5.0 # define the observed rating.
lam_b8 = 0.1 # define regularization strength.
print("p:", p_b8, "q:", q_b8, "r:", r_b8) # inspect the gradient inputs.
```

```python
pred_b8 = float(p_b8 @ q_b8) # compute the current prediction.
e_b8 = r_b8 - pred_b8 # compute the residual used by the gradient.
grad_p_b8 = -2 * e_b8 * q_b8 + 2 * lam_b8 * p_b8 # compute the gradient with respect to p.
print("prediction:", round(pred_b8, 3), "error:", round(e_b8, 3), "grad_p:", np.round(grad_p_b8, 3)) # inspect the direction of steepest increase.
```

```python
plt.figure(figsize=(4, 3)) # create a vector plot for the factor and negative gradient.
plt.quiver([0], [0], [p_b8[0]], [p_b8[1]], angles="xy", scale_units="xy", scale=1, color="teal", label="p") # draw the current user vector.
plt.quiver([p_b8[0]], [p_b8[1]], [-0.05 * grad_p_b8[0]], [-0.05 * grad_p_b8[1]], angles="xy", scale_units="xy", scale=1, color="red", label="-gradient step") # draw a scaled descent step.
plt.xlim(0, 1.4) # set x limits so both arrows are visible.
plt.ylim(0, 0.5) # set y limits so both arrows are visible.
plt.title("B8: p update direction") # title the gradient plot.
plt.xlabel("latent axis 0") # label the first axis.
plt.ylabel("latent axis 1") # label the second axis.
plt.legend() # show arrow labels.
plt.show() # display the quiver plot.
```
▶ What you'll see: the descent direction moves p toward q because the prediction is too low.

👀 Takeaway: gradients translate one observed error into a concrete movement in latent space.

#### B9. Take one full SGD step

**Goal.** Update p and q once using the worked SGD equations, because MF learns by nudging both sides of an observed pair after each error. We build it in 3 steps.

```python
p_b9 = np.array([0.8, 0.2]) # initialize the user factor from the worked example.
q_b9 = np.array([3.0, 0.4]) # initialize the item factor from the worked example.
r_b9 = 5.0 # set the observed rating.
eta_b9 = 0.05 # set the learning rate.
lam_b9 = 0.1 # set the regularization strength.
print("before p:", p_b9, "q:", q_b9) # inspect factors before the update.
```

```python
pred_b9 = float(p_b9 @ q_b9) # compute the current prediction.
e_b9 = r_b9 - pred_b9 # compute the residual.
p_step_b9 = e_b9 * q_b9 - lam_b9 * p_b9 # compute the p update direction without the learning-rate scale.
q_step_b9 = e_b9 * p_b9 - lam_b9 * q_b9 # compute the q update direction without the learning-rate scale.
print("prediction:", round(pred_b9, 3), "error:", round(e_b9, 3)) # inspect the worked prediction and error.
assert round(pred_b9, 3) == 2.48 # verify the lesson prediction number.
assert round(e_b9, 3) == 2.52 # verify the lesson error number.
```

```python
p_new_b9 = p_b9 + eta_b9 * p_step_b9 # update p using the old q and the regularized step.
q_new_b9 = q_b9 + eta_b9 * q_step_b9 # update q using the old p and the regularized step.
new_pred_b9 = float(p_new_b9 @ q_new_b9) # compute the post-update prediction.
print("p step:", np.round(p_step_b9, 3), "q step:", np.round(q_step_b9, 3)) # inspect the unscaled update directions.
print("after p:", np.round(p_new_b9, 3), "q:", np.round(q_new_b9, 3), "new prediction:", round(new_pred_b9, 3)) # inspect the updated factors and score.
assert np.allclose(np.round(p_new_b9, 3), np.array([1.174, 0.249])) # verify the lesson p' number.
assert np.allclose(np.round(q_new_b9, 3), np.array([3.086, 0.423])) # verify the lesson q' number.
assert abs(round(new_pred_b9, 3) - 3.728) <= 0.001 # verify the lesson new prediction number within rounding tolerance.
plt.figure(figsize=(5, 3)) # create a before-after prediction plot.
plt.bar(["before", "after", "target"], [pred_b9, new_pred_b9, r_b9], color=["orange", "teal", "green"]) # compare the prediction before and after one SGD step.
plt.title("B9: one SGD step moves prediction toward 5") # title the update plot.
plt.ylabel("rating") # label the rating scale.
plt.show() # display the bar chart.
```
▶ What you'll see: the prediction jumps from 2.48 to about 3.728, moving toward the observed rating 5.

👀 Takeaway: SGD uses each observed error immediately to update both the user and item factors.

## 🟡 Easy

#### E1. Train MF with observed-only SGD

**Goal.** Fit P and Q on only observed entries Ω, because blank cells are unknown rather than automatic zeros. We build it in 4 steps.

```python
R_e1 = np.array([[5, 4, 0, 1], [4, 5, 0, 1], [1, 1, 5, 4], [0, 1, 4, 5]], dtype=float) # define the sparse toy matrix.
mask_e1 = observed_mask(R_e1) # identify the observed training entries.
rng_e1 = np.random.default_rng(1) # create a local seeded generator for reproducible factors.
P_e1 = 0.1 * rng_e1.normal(size=(4, 2)) # initialize user factors with small random values.
Q_e1 = 0.1 * rng_e1.normal(size=(4, 2)) # initialize item factors with small random values.
print("observed entries:", int(mask_e1.sum())) # inspect how many ratings drive training.
```

```python
eta_e1 = 0.03 # choose a modest learning rate for stable SGD.
lam_e1 = 0.02 # choose a small regularization strength.
steps_e1 = 800 # choose enough passes for the tiny toy problem.
losses_e1 = [] # prepare a list to store objective values.
print("eta:", eta_e1, "lambda:", lam_e1, "steps:", steps_e1) # inspect training hyperparameters.
```

```python
for step_e1 in range(steps_e1): # repeat many stochastic updates.
    users_e1, items_e1 = np.where(mask_e1) # list observed coordinates for this pass.
    k_e1 = step_e1 % len(users_e1) # cycle deterministically through observed cells.
    u_e1 = users_e1[k_e1] # choose the current observed user.
    i_e1 = items_e1[k_e1] # choose the current observed item.
    pred_e1 = float(P_e1[u_e1] @ Q_e1[i_e1]) # predict the current observed rating.
    err_e1 = R_e1[u_e1, i_e1] - pred_e1 # compute the observed residual.
    old_p_e1 = P_e1[u_e1].copy() # save old p so q update uses simultaneous-style values.
    old_q_e1 = Q_e1[i_e1].copy() # save old q so p update uses simultaneous-style values.
    P_e1[u_e1] = old_p_e1 + eta_e1 * (err_e1 * old_q_e1 - lam_e1 * old_p_e1) # update the selected user factor.
    Q_e1[i_e1] = old_q_e1 + eta_e1 * (err_e1 * old_p_e1 - lam_e1 * old_q_e1) # update the selected item factor.
    if step_e1 % 20 == 0: # record the objective periodically for plotting.
        pred_all_e1 = predict(P_e1, Q_e1) # compute current predictions for all cells.
        sse_e1 = float(np.sum(((R_e1 - pred_all_e1)[mask_e1]) ** 2)) # sum squared errors on observed ratings only.
        reg_e1 = lam_e1 * (float(np.sum(P_e1 ** 2)) + float(np.sum(Q_e1 ** 2))) # compute the L2 regularization term.
        losses_e1.append(sse_e1 + reg_e1) # store the observed-only objective value.
print("final observed objective:", round(losses_e1[-1], 3)) # inspect the final training loss.
```

```python
plt.figure(figsize=(5, 3)) # create a training-curve figure.
plt.plot(np.arange(len(losses_e1)) * 20, losses_e1, color="teal") # plot objective against SGD steps.
plt.title("E1: observed-only SGD loss curve") # title the convergence plot.
plt.xlabel("SGD step") # label the step axis.
plt.ylabel("observed SSE + regularization") # label the objective axis.
plt.show() # display the line chart.
```
▶ What you'll see: the loss falls as factors adapt to observed ratings without treating blanks as targets.

👀 Takeaway: the MF objective is defined over Ω, the set of observed user-item ratings.

#### E3. Sweep reconstruction rank with SVD

**Goal.** Quantify how rank controls reconstruction, because a lower rank is a stronger bottleneck and a higher rank can memorize more detail. We build it in 3 steps.


#### A1. Sweep regularization strength

**Goal.** Compare train and validation RMSE across λ values, because too little regularization can overfit and too much can underfit. We build it in 5 steps.

```python
R_a1 = np.array([[5, 4, 0, 1], [4, 5, 0, 1], [1, 1, 5, 4], [0, 1, 4, 5]], dtype=float) # define the toy matrix.
val_cells_a1 = [(0, 1), (2, 3)] # choose two observed ratings to hold out.
train_mask_a1 = observed_mask(R_a1) # start from all observed entries.
for cell_a1 in val_cells_a1: # remove validation entries from training.
    train_mask_a1[cell_a1] = False # mark the current validation cell as not trained.
print("validation cells:", val_cells_a1) # inspect the held-out coordinates.
```

```python
lams_a1 = np.array([0.0, 0.01, 0.05, 0.2, 0.8]) # choose regularization strengths from low to high.
train_rmse_a1 = [] # prepare storage for training errors.
val_rmse_a1 = [] # prepare storage for validation errors.
print("lambda grid:", lams_a1) # inspect the sweep values.
```

```python
for lam_a1 in lams_a1: # train one model per lambda.
    rng_a1 = np.random.default_rng(10) # reset initialization so lambda is the changed variable.
    P_a1 = 0.1 * rng_a1.normal(size=(4, 2)) # initialize user factors.
    Q_a1 = 0.1 * rng_a1.normal(size=(4, 2)) # initialize item factors.
    for step_a1 in range(1800): # run observed-only SGD for this lambda.
        users_a1, items_a1 = np.where(train_mask_a1) # list training entries.
        k_a1 = step_a1 % len(users_a1) # cycle through entries deterministically.
        u_a1 = users_a1[k_a1] # select the current user.
        i_a1 = items_a1[k_a1] # select the current item.
        err_a1 = R_a1[u_a1, i_a1] - float(P_a1[u_a1] @ Q_a1[i_a1]) # compute residual.
        old_p_a1 = P_a1[u_a1].copy() # save old user vector.
        old_q_a1 = Q_a1[i_a1].copy() # save old item vector.
        P_a1[u_a1] = old_p_a1 + 0.03 * (err_a1 * old_q_a1 - lam_a1 * old_p_a1) # update user factors.
        Q_a1[i_a1] = old_q_a1 + 0.03 * (err_a1 * old_p_a1 - lam_a1 * old_q_a1) # update item factors.
    pred_a1 = predict(P_a1, Q_a1) # compute predictions for this trained model.
    train_rmse_a1.append(float(np.sqrt(np.mean(((R_a1 - pred_a1)[train_mask_a1]) ** 2)))) # store train RMSE.
    val_rmse_a1.append(float(np.sqrt(np.mean([(R_a1[c_a1] - pred_a1[c_a1]) ** 2 for c_a1 in val_cells_a1])))) # store validation RMSE.

print("validation RMSE:", np.round(val_rmse_a1, 3)) # inspect validation errors.
```


#### A2. Compare learning rates

**Goal.** Show stable versus unstable SGD behavior, because the learning rate controls whether factor updates converge or overshoot. We build it in 4 steps.

```python
R_a2 = np.array([[5, 4, 0, 1], [4, 5, 0, 1], [1, 1, 5, 4], [0, 1, 4, 5]], dtype=float) # define the toy matrix.

rates_a2 = [0.03, 0.5] # compare a stable and an intentionally too-large learning rate.

```

```python
for eta_a2 in rates_a2: # run one training loop per learning rate.
    rng_a2 = np.random.default_rng(20) # reset initialization for fair comparison.
    P_a2 = 0.1 * rng_a2.normal(size=(4, 2)) # initialize user factors.
    Q_a2 = 0.1 * rng_a2.normal(size=(4, 2)) # initialize item factors.
    losses_a2 = [] # store this learning rate's losses.
    for step_a2 in range(160): # run a short training sequence.
        users_a2, items_a2 = np.where(mask_a2) # list observed entries.
        k_a2 = step_a2 % len(users_a2) # cycle through entries.
        u_a2 = users_a2[k_a2] # choose user.
        i_a2 = items_a2[k_a2] # choose item.
        pred_cell_a2 = float(P_a2[u_a2] @ Q_a2[i_a2]) # compute current cell prediction.
        err_a2 = R_a2[u_a2, i_a2] - pred_cell_a2 # compute current residual.
        old_p_a2 = P_a2[u_a2].copy() # save old user vector.
        old_q_a2 = Q_a2[i_a2].copy() # save old item vector.

        Q_a2[i_a2] = np.clip(old_q_a2 + eta_a2 * (err_a2 * old_p_a2 - 0.02 * old_q_a2), -20, 20) # update and clip q to keep the demo finite.
        if step_a2 % 4 == 0: # record losses at a readable cadence.
            pred_all_a2 = predict(P_a2, Q_a2) # compute all predictions.
            losses_a2.append(float(np.mean(((R_a2 - pred_all_a2)[mask_a2]) ** 2))) # store observed mean squared error.

print("final losses:", [round(c[-1], 3) for c in curves_a2]) # inspect where each rate ended.
```

```python
    old_p_obs_a4 = P_obs_a4[u_obs_a4].copy() # save old user vector.
    old_q_obs_a4 = Q_obs_a4[i_obs_a4].copy() # save old item vector.
    P_obs_a4[u_obs_a4] = old_p_obs_a4 + 0.03 * (err_obs_a4 * old_q_obs_a4 - 0.04 * old_p_obs_a4) # update observed-only user factor.
    Q_obs_a4[i_obs_a4] = old_q_obs_a4 + 0.03 * (err_obs_a4 * old_p_obs_a4 - 0.04 * old_q_obs_a4) # update observed-only item factor.

```

```python
full_target_a4 = R_a4.copy() # keep zeros as literal zero targets for the pitfall model.
```

#### A5. Handle a cold-start item

**Goal.** Score a brand-new item with no ratings and compare a fallback, because an untrained random item factor gives unreliable personalized predictions. We build it in 4 steps.

```python
R_a5 = np.array([[5, 4, 0, 1], [4, 5, 0, 1], [1, 1, 5, 4], [0, 1, 4, 5]], dtype=float) # define the training matrix.
mask_a5 = observed_mask(R_a5) # mark observed entries.
mu_a5 = float(np.mean(R_a5[mask_a5])) # compute the global mean fallback.
rng_a5 = np.random.default_rng(50) # create reproducible randomness.
P_a5 = 0.1 * rng_a5.normal(size=(4, 2)) # initialize user factors.
Q_a5 = 0.1 * rng_a5.normal(size=(4, 2)) # initialize item factors.
print("global mean fallback:", round(mu_a5, 3)) # inspect the fallback value.
```

```python
for step_a5 in range(1500): # train factors for existing users and items.
    users_a5, items_a5 = np.where(mask_a5) # list observed ratings.
    k_a5 = step_a5 % len(users_a5) # cycle through observed examples.
    u_a5 = users_a5[k_a5] # select the current user.
    i_a5 = items_a5[k_a5] # select the current item.
    err_a5 = R_a5[u_a5, i_a5] - float(P_a5[u_a5] @ Q_a5[i_a5]) # compute residual for the existing item.
    old_p_a5 = P_a5[u_a5].copy() # save old user vector.
    old_q_a5 = Q_a5[i_a5].copy() # save old item vector.
    P_a5[u_a5] = old_p_a5 + 0.03 * (err_a5 * old_q_a5 - 0.04 * old_p_a5) # update user vector.
    Q_a5[i_a5] = old_q_a5 + 0.03 * (err_a5 * old_p_a5 - 0.04 * old_q_a5) # update item vector.
print("trained existing catalog factors") # confirm training completed.
```

```python
new_item_q_a5 = 0.1 * rng_a5.normal(size=2) # create a random factor for an item with no observations.
user_idx_a5 = 0 # choose one existing user to score the cold item.
random_score_a5 = float(P_a5[user_idx_a5] @ new_item_q_a5) # compute the unreliable random-factor score.
fallback_score_a5 = mu_a5 # use the global mean as a safer no-evidence fallback.
print("new item q:", np.round(new_item_q_a5, 3)) # inspect the untrained item factor.
print("random-factor score:", round(random_score_a5, 3), "fallback score:", round(fallback_score_a5, 3)) # compare cold-start scores.
```

```python
plt.figure(figsize=(5, 3)) # create a cold-start comparison plot.
plt.bar(["random q_new", "global mean fallback"], [random_score_a5, fallback_score_a5], color=["red", "teal"]) # compare unreliable and fallback scores.

plt.show() # display the bar chart.
```
▶ What you'll see: the random cold-start factor can produce an arbitrary score, while the fallback is stable and evidence-based.

👀 Takeaway: MF needs interactions to learn item factors, so cold-start items should use metadata, bias terms, or global/popularity fallbacks until data arrives.
