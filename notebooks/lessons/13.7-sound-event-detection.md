# 13.7 — Sound Event Detection

Sound event detection (SED) asks both **what happened** and **when it happened** in an audio clip. Instead of assigning one mutually exclusive class to a whole recording, SED predicts independent event probabilities over short time frames, then turns those frame decisions into onset/offset segments that can overlap.

### 1. Toy spectrogram evidence: events leave different time-frequency shapes

A real SED model usually starts from a spectrogram: rows are frequency bands, columns are short time frames, and color is energy. We can synthesize the idea without audio libraries. A clap becomes a short broadband burst; a siren becomes a longer narrow band. The model's job is not magic listening — it is learning that certain spectrogram shapes line up with event labels.

```python
T_w, F_w = 60, 32  # 60 time frames and 32 frequency bins.
time_w = np.arange(T_w)  # frame indices for plotting and label construction.
freq_w = np.arange(F_w)[:, None]  # frequency indices as a column vector.
S_w = 0.05 * np.random.rand(F_w, T_w)  # low background energy.
print("spectrogram shape:", S_w.shape)
```
▶ What you'll see: the toy spectrogram has 32 frequency bands across 60 frames.

```python
clap_frames_w = np.arange(12, 16)  # a brief event lasting four frames.
siren_frames_w = np.arange(34, 50)  # a sustained event lasting sixteen frames.
S_w[:, clap_frames_w] += 1.0  # broadband burst: every frequency lights up briefly.
S_w += 0.9 * np.exp(-0.5 * ((freq_w - 21) / 2.5) ** 2) * ((time_w >= 34) & (time_w < 50))  # narrow siren band.
print("clap frames:", clap_frames_w[0], "to", clap_frames_w[-1])
print("siren frames:", siren_frames_w[0], "to", siren_frames_w[-1])
```
▶ What you'll see: the clap is short and the siren is much longer.

```python

plt.xlabel("time frame")
plt.ylabel("frequency bin")
plt.show()
```
▶ What you'll see: a vertical bright stripe for the clap and a horizontal bright band for the siren.

*Why it's done this way:* SED is a time-localized problem, so a frame grid is the natural coordinate system. The spectrogram lets short transients and sustained tones occupy different shapes; later formulas simply attach labels and probabilities to these time frames.

### 2. Frame-level multi-label targets and binary cross-entropy

At each frame, more than one event can be active. That makes SED **multi-label**, not multi-class: clap and speech, or siren and engine, can overlap. The right output is one sigmoid probability per event, and the right loss is binary cross-entropy (BCE) applied independently to each event label.

```python
events_w = ["clap", "siren"]  # two independent labels, not two softmax classes.
Y_w = np.zeros((T_w, len(events_w)))  # frame-level target matrix: time by event.
Y_w[12:16, 0] = 1  # clap is active on frames 12..15.
Y_w[34:50, 1] = 1  # siren is active on frames 34..49.
Y_w[14:16, 1] = 1  # overlap: siren also starts weakly while clap is active.
print("labels at frame 14:", Y_w[14])
print("frames with any event:", int(np.any(Y_w == 1, axis=1).sum()))
```
▶ What you'll see: frame 14 has both labels active, proving softmax would be the wrong shape.

```python
logits_w = np.stack([0.15 * S_w.mean(axis=0) - 0.1, 4.0 * S_w[19:24].mean(axis=0) - 0.6], axis=1)  # simple hand-built evidence scores.
P_w = 1 / (1 + np.exp(-logits_w))  # sigmoid turns each event score into an independent probability.
eps_w = 1e-9  # numerical guard for log.
bce_w = -(Y_w * np.log(P_w + eps_w) + (1 - Y_w) * np.log(1 - P_w + eps_w))  # BCE per frame and event.
print("probabilities at frame 14:", np.round(P_w[14], 3))
print("mean BCE:", round(float(bce_w.mean()), 3))
assert P_w.shape == Y_w.shape
```
▶ What you'll see: two probabilities per frame and one averaged BCE value over all frame-event decisions.

```python
plt.figure(figsize=(6, 3))
plt.plot(P_w[:, 0], label="p(clap)")
plt.plot(P_w[:, 1], label="p(siren)")
plt.imshow(Y_w.T, extent=[0, T_w - 1, -0.08, 0.08], aspect="auto", cmap="Greens", alpha=0.35)
plt.title("2: independent frame probabilities")
plt.xlabel("time frame")
plt.ylabel("probability")
plt.ylim(-0.1, 1.05)
plt.legend()
plt.show()
```
▶ What you'll see: each event has its own probability curve, and the curves can be high at the same time.

*Why it's done this way:* BCE is the Bernoulli negative log-likelihood for each event being on or off. Summing it over frame-event pairs matches the assumption that each label has its own yes/no decision; a softmax would force probabilities to compete and would make overlapping events mathematically impossible.

### 3. Thresholding, smoothing, and grouping frame decisions into events

Frame probabilities are useful, but users need intervals: "siren from frame 34 to 50." We threshold probabilities into 0/1 frame decisions, smooth away short flickers, then group consecutive positive frames into onset/offset segments.

```python
raw_pred_w = (P_w[:, 1] >= 0.5).astype(int)  # threshold siren probabilities at 0.5.
print("raw positive siren frames:", np.where(raw_pred_w == 1)[0][:10], "...")
print("raw count:", int(raw_pred_w.sum()))
```
▶ What you'll see: thresholding creates a binary timeline for the siren class.

```python
def smooth_binary_w(x, width=3):
    padded = np.pad(x, (width // 2, width // 2), mode="edge")
    votes = np.array([padded[i:i + width].mean() for i in range(len(x))])
    return (votes >= 0.5).astype(int)

smooth_pred_w = smooth_binary_w(raw_pred_w, width=3)  # majority filter over nearby frames.
print("changed frames after smoothing:", np.where(raw_pred_w != smooth_pred_w)[0])
```
▶ What you'll see: isolated frame flips are removed or filled depending on their neighbors.

```python
def segments_from_frames_w(x):
    padded = np.r_[0, x.astype(int), 0]
    changes = np.diff(padded)
    starts = np.where(changes == 1)[0]
    ends = np.where(changes == -1)[0]
    return list(zip(starts.tolist(), ends.tolist()))

segments_w = segments_from_frames_w(smooth_pred_w)
print("siren segments:", segments_w)
assert all(start < end for start, end in segments_w)
```
▶ What you'll see: consecutive positive frames collapse into one or more onset/offset intervals.

```python
plt.figure(figsize=(6, 2.4))
plt.step(time_w, raw_pred_w, where="post", label="raw threshold", alpha=0.55)
plt.step(time_w, smooth_pred_w, where="post", label="smoothed", linewidth=2)
plt.axvspan(34, 50, color="green", alpha=0.15, label="true siren")
plt.title("3: frame decisions become an event timeline")
plt.xlabel("time frame")
plt.yticks([0, 1])
plt.legend(loc="upper right")
plt.show()
```
▶ What you'll see: a timeline where a contiguous positive region lines up with the true siren span.

*Why it's done this way:* The threshold chooses an operating point for precision versus recall; smoothing encodes the prior that real acoustic events usually persist for more than one frame; grouping converts frame classification into detection by defining the boundaries users care about.

### 4. Weak clip labels and multiple-instance pooling

Many datasets only say a clip contains "siren" without giving the exact frames. Multiple-instance learning (MIL) handles this by pooling frame probabilities into one clip probability. Max pooling asks whether **any** frame is confident; noisy-OR asks whether at least one independent frame is positive.

```python
clip_label_w = 1.0  # weak label: the clip contains a siren somewhere.
siren_probs_w = P_w[:, 1]  # frame probabilities for siren.
max_pool_w = float(np.max(siren_probs_w))  # any-frame evidence.
noisy_or_w = float(1 - np.prod(1 - siren_probs_w))  # probability at least one frame is positive.
print("max-pooled clip probability:", round(max_pool_w, 3))
print("noisy-OR clip probability:", round(noisy_or_w, 3))
assert noisy_or_w >= max_pool_w
```
▶ What you'll see: noisy-OR is at least as large as max pooling because it accumulates evidence across frames.

```python
def bce_scalar_w(y, p):
    p = np.clip(p, 1e-9, 1 - 1e-9)
    return float(-(y * np.log(p) + (1 - y) * np.log(1 - p)))

loss_max_w = bce_scalar_w(clip_label_w, max_pool_w)
loss_or_w = bce_scalar_w(clip_label_w, noisy_or_w)
print("weak-label BCE using max:", round(loss_max_w, 3))
print("weak-label BCE using noisy-OR:", round(loss_or_w, 3))
```
▶ What you'll see: both losses train from a clip label, even though no frame-level annotation was provided.

```python
plt.figure(figsize=(6, 2.7))
plt.plot(siren_probs_w, color="darkorange", label="frame p(siren)")
plt.axhline(max_pool_w, color="purple", linestyle="--", label="max pool")
plt.title("4: weak labels pool frame evidence")
plt.xlabel("time frame")
plt.ylabel("probability")
plt.ylim(0, 1.05)
plt.legend()
plt.show()
```
▶ What you'll see: the clip-level decision is driven by the strongest or accumulated frame evidence.

*Why it's done this way:* Weak labels do not identify which instance frame caused the clip label. MIL bridges that gap by defining a differentiable clip probability from frame probabilities; the math says a positive bag needs at least one convincing positive frame, not every frame positive.

### 5. Event-based precision, recall, and F1

Frame accuracy can be misleading: a detector may mark many correct frames but split one event into fragments. Event-based F1 compares predicted segments with reference segments, so onset and offset quality matter. Here we use an intersection-over-union (IoU) match rule from scratch.

```python
true_events_w = [(12, 16, "clap"), (34, 50, "siren")]  # half-open intervals [start, end).
pred_events_w = [(12, 15, "clap"), (33, 48, "siren"), (52, 55, "siren")]  # one false extra siren.
print("true events:", true_events_w)
print("predicted events:", pred_events_w)
```
▶ What you'll see: predictions include two good detections and one extra false alarm.

```python
def interval_iou_w(a, b):
    inter = max(0, min(a[1], b[1]) - max(a[0], b[0]))
    union = max(a[1], b[1]) - min(a[0], b[0])
    return inter / union if union else 0.0

print("clap IoU:", round(interval_iou_w(true_events_w[0], pred_events_w[0]), 3))
print("siren IoU:", round(interval_iou_w(true_events_w[1], pred_events_w[1]), 3))
assert round(interval_iou_w(true_events_w[1], pred_events_w[1]), 3) == 0.824
```
▶ What you'll see: overlap quality becomes a number between 0 and 1 for each candidate match.

```python
def event_f1_w(true_events, pred_events, iou_threshold=0.5):
    matched_true = set()
    tp = 0
    for pred_idx, pred in enumerate(pred_events):
        best_iou, best_true = 0.0, None
        for true_idx, truth in enumerate(true_events):
            if truth[2] == pred[2] and true_idx not in matched_true:
                score = interval_iou_w(truth, pred)
                if score > best_iou:
                    best_iou, best_true = score, true_idx
        if best_iou >= iou_threshold:
            tp += 1
            matched_true.add(best_true)
    fp = len(pred_events) - tp
    fn = len(true_events) - tp
    precision = tp / (tp + fp) if tp + fp else 0.0
    recall = tp / (tp + fn) if tp + fn else 0.0
    f1 = 2 * precision * recall / (precision + recall) if precision + recall else 0.0
    return tp, fp, fn, precision, recall, f1

counts_w = event_f1_w(true_events_w, pred_events_w)
print("TP, FP, FN:", counts_w[:3])
print("precision, recall, F1:", np.round(counts_w[3:], 3))
assert counts_w[:3] == (2, 1, 0)
```
▶ What you'll see: two matched events, one false positive, and an event F1 below 1.

```python
plt.figure(figsize=(6, 2.5))
for start, end, name in true_events_w:
    plt.plot([start, end], [1, 1], linewidth=8, solid_capstyle="butt", label="true" if start == 12 else None)
for start, end, name in pred_events_w:
    plt.plot([start, end], [0, 0], linewidth=8, solid_capstyle="butt", label="pred" if start == 12 else None)
    plt.text((start + end) / 2, -0.18, name, ha="center")
plt.yticks([0, 1], ["pred", "true"])
plt.xlabel("time frame")
plt.title("5: event timeline for F1 matching")
plt.legend(loc="upper right")
plt.show()
```
▶ What you'll see: matched segments overlap the truth, while the late siren has no matching reference event.

*Why it's done this way:* Event-based F1 counts complete detections, not just individual frames. The IoU threshold forces a prediction to be close enough in time and class before it earns a true positive, so boundary mistakes and duplicate false alarms affect the score users actually care about.

## 🛠️ Setup

```python
import numpy as np  # load NumPy for synthetic spectrograms, labels, probabilities, and metrics.
import matplotlib.pyplot as plt  # load Matplotlib for spectrograms, probability curves, and event timelines.
np.random.seed(0)  # make all stochastic toy examples repeatable.

def sigmoid(x):  # convert scores into independent Bernoulli probabilities.
    return 1 / (1 + np.exp(-x))

def binary_cross_entropy(y, p):  # compute mean BCE for matching arrays of labels and probabilities.
    p = np.clip(p, 1e-9, 1 - 1e-9)
    return float(np.mean(-(y * np.log(p) + (1 - y) * np.log(1 - p))))

def segments_from_binary(x):  # convert a binary frame timeline into half-open [start, end) segments.
    x = np.asarray(x, dtype=int)
    padded = np.r_[0, x, 0]
    changes = np.diff(padded)
    starts = np.where(changes == 1)[0]
    ends = np.where(changes == -1)[0]
    return list(zip(starts.tolist(), ends.tolist()))

def interval_iou(a, b):  # measure temporal overlap quality between two half-open intervals.
    inter = max(0, min(a[1], b[1]) - max(a[0], b[0]))
    union = max(a[1], b[1]) - min(a[0], b[0])
    return inter / union if union else 0.0
```
▶ What you'll see: no printed output; the helpers define the small SED operations used below.

### Basic 9 — Smooth a flickering prediction
