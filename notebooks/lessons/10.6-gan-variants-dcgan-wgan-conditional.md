# 10.6 — GAN Variants (DCGAN, WGAN, Conditional)

GAN variants keep the adversarial idea from vanilla GANs but change the pieces that make the game trainable and useful. DCGAN changes the **architecture** so image-like structure is easier to learn, WGAN changes the **distance signal** so the critic gives smoother gradients, and conditional GANs change the **inputs** so the same generator can be steered toward a chosen class or attribute.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build the three major variants one idea at a time. Run each cell in order and inspect the arrays, curves, and toy samples — every moving part is small enough to audit by hand. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix on variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, random numbers, small neural-network pieces, and numerical checks.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for toy GAN samples and parameter initialization.
```

### 1. DCGAN: convolutional bias for image-like data

A vanilla MLP can generate pixels, but it has no built-in belief that nearby pixels are related or that the same edge pattern can appear in many places. DCGAN fixes that by using convolution-like weight sharing: the same small kernel is applied across locations. Here we build the idea in 1-D so the operation is transparent: a latent vector is upsampled, then a shared kernel smooths and shapes it into a local pattern.

```python
z_w = np.array([0.2, -0.5, 1.0, 0.3])  # a tiny latent code standing in for generator features.
upsampled_w = np.repeat(z_w, 2)  # nearest-neighbor upsampling doubles spatial resolution.
kernel_w = np.array([0.25, 0.50, 0.25])  # a shared local smoothing kernel.
print("latent z:", z_w)
print("upsampled features:", upsampled_w)
```
▶ What you'll see: four latent positions become eight feature positions, the simplest version of a generator increasing resolution.

```python
padded_w = np.pad(upsampled_w, 1, mode="edge")  # keep endpoints stable for the tiny demo.
dcgan_signal_w = np.array([np.sum(padded_w[i:i+3] * kernel_w) for i in range(len(upsampled_w))])  # shared local filter.
print("after shared-kernel filtering:", np.round(dcgan_signal_w, 3))
assert np.allclose(np.round(dcgan_signal_w[:3], 3), [0.2, 0.025, -0.325])  # lesson numbers.
plt.figure(figsize=(5, 3))
plt.plot(upsampled_w, marker="o", label="upsampled")
plt.plot(dcgan_signal_w, marker="s", label="shared filter")
plt.title("1: DCGAN-style upsample + shared local filter")
plt.xlabel("position")
plt.ylabel("feature value")
plt.legend()
plt.show()
```
▶ What you'll see: the filtered curve is smoother and locally coherent because each output mixes nearby positions with the same kernel.

*Why it's done this way:* convolution is not decoration; it is an inductive bias. A full dense layer learns a separate parameter for every input-output pixel pair, while a convolution reuses the same few parameters across positions. That reduces sample complexity and encodes the mathematical assumption of local stationarity: an edge detector or texture primitive should mean the same thing wherever it appears.

### 2. WGAN: replace classification confidence with transport distance

The vanilla discriminator can saturate: once real and fake are easy to separate, its probability output may give the generator weak gradients. WGAN replaces the classifier with a **critic** that scores samples with real numbers. The objective estimates a Wasserstein-1 transport gap: how much mass must be moved, times how far, to turn the generated distribution into the data distribution.

```python
real_w = np.array([0.0, 1.0, 2.0])  # tiny 1-D data samples.
fake_w = np.array([0.5, 1.5, 2.5])  # generated samples shifted right by 0.5.
mean_gap_w = float(np.mean(real_w) - np.mean(fake_w))  # critic f(x)=x gives a mean-score difference.
transport_gap_w = abs(0.2 - 1.1)  # lesson's one-dimensional mean transport example.
print("critic mean difference E[f(real)] - E[f(fake)]:", round(mean_gap_w, 3))
print("transport gap |0.2 - 1.1|:", round(transport_gap_w, 3))
assert round(mean_gap_w, 3) == -0.500 and round(transport_gap_w, 3) == 0.900
```
▶ What you'll see: the mean-score difference is −0.5 for the shifted samples, and the hand-auditable transport gap is 0.9.

```python
xs_w = np.linspace(-0.25, 2.75, 80)
plt.figure(figsize=(5, 3))
plt.scatter(real_w, np.zeros_like(real_w), s=80, label="real", color="seagreen")
plt.scatter(fake_w, np.zeros_like(fake_w) + 0.08, s=80, label="fake", color="crimson")
for r_w, f_w in zip(real_w, fake_w):
    plt.arrow(f_w, 0.05, r_w - f_w, 0, length_includes_head=True, head_width=0.025, color="gray")
plt.yticks([])
plt.title("2: WGAN thinks in transport, not just classification")
plt.xlabel("sample value")
plt.legend()
plt.show()
```
▶ What you'll see: every fake point must move left by 0.5 to match the real point, so distance remains informative even when supports do not overlap.

*Why it's done this way:* Wasserstein distance is sensitive to geometry. If fake samples are on the wrong side of the line, the critic can still say which direction moves them closer. The WGAN objective $\min_G\max_{\lVert f\rVert_L\le1}\mathbb{E}f(x)-\mathbb{E}f(G(z))$ only works because the critic is constrained to be 1-Lipschitz; otherwise it could inflate scores arbitrarily instead of measuring distance.

### 3. Enforcing the Lipschitz constraint: clipping and gradient penalty

A WGAN critic must not change faster than one unit of score per one unit of input distance. Weight clipping is the original crude method: keep parameters in a small box. Gradient penalty is the smoother modern method: penalize slopes whose norm differs from 1 on points between real and fake samples.

```python
weights_w = np.array([-0.8, -0.2, 0.1, 0.7])  # pretend critic parameters before clipping.
clipped_w = np.clip(weights_w, -0.3, 0.3)  # original WGAN's simple constraint proxy.
print("before clipping:", weights_w)
print("after clipping:", clipped_w)
assert np.allclose(clipped_w, [-0.3, -0.2, 0.1, 0.3])
```
▶ What you'll see: large-magnitude weights are forced into a narrow range, limiting how steep the critic can become.

```python
grad_norms_w = np.array([0.6, 0.9, 1.0, 1.4])  # toy slopes on interpolated real/fake points.
lambda_gp_w = 10.0
gp_terms_w = lambda_gp_w * (grad_norms_w - 1.0) ** 2
gp_loss_w = float(np.mean(gp_terms_w))
print("gradient penalty terms:", np.round(gp_terms_w, 3))
print("mean gradient penalty:", round(gp_loss_w, 3))
assert round(gp_loss_w, 3) == 0.825
plt.figure(figsize=(5, 3))
plt.bar(["0.6", "0.9", "1.0", "1.4"], gp_terms_w, color="darkorange")
plt.title("3: gradient penalty charges slopes away from 1")
plt.xlabel("critic gradient norm")
plt.ylabel("10 · (||∇f|| - 1)²")
plt.show()
```
▶ What you'll see: the slope exactly at 1 pays no penalty, while slopes too small or too large pay a quadratic cost.

*Why it's done this way:* the Kantorovich-Rubinstein dual form of Wasserstein-1 requires the critic to be 1-Lipschitz. Weight clipping indirectly reduces slope but can underuse critic capacity. Gradient penalty targets the actual mathematical condition — gradient norm near 1 along the real-to-fake path — so the critic stays informative without becoming arbitrarily steep.

### 4. Conditional GANs: steer both generator and discriminator with labels

A conditional GAN adds a label or attribute $y$ to both sides: the generator becomes $G(z,y)$ and the discriminator/critic becomes $D(x,y)$. The same noise can therefore decode into different modes, and the discriminator can reject a correct-looking sample if it is paired with the wrong label.

```python
z_w = np.array([-1.0, 0.0, 1.0])  # the same noise coordinates for every class.
class_offsets_w = {0: -2.0, 1: 2.0}  # class 0 lives left, class 1 lives right.
def G_cond_w(z, y):
    return z + class_offsets_w[int(y)]  # toy conditional generator: noise plus label-specific offset.
print("G(z, class 0):", G_cond_w(z_w, 0))
print("G(z, class 1):", G_cond_w(z_w, 1))
assert np.allclose(G_cond_w(z_w, 1) - G_cond_w(z_w, 0), 4.0)
```
▶ What you'll see: the same three noise values become a left cluster for class 0 and a right cluster for class 1.

```python
def D_cond_score_w(x, y):
    target = class_offsets_w[int(y)]  # discriminator knows which class center it should expect.
    return -np.abs(x - target)  # higher score means the sample matches that label's region.
right_pair_w = D_cond_score_w(2.2, 1)
wrong_pair_w = D_cond_score_w(2.2, 0)
print("score for x=2.2 with correct label 1:", round(float(right_pair_w), 3))
print("score for x=2.2 with wrong label 0:", round(float(wrong_pair_w), 3))
assert round(float(right_pair_w), 3) == -0.200 and round(float(wrong_pair_w), 3) == -4.200
plt.figure(figsize=(5, 3))
plt.scatter(G_cond_w(z_w, 0), np.zeros_like(z_w), label="class 0 samples", color="steelblue")
plt.scatter(G_cond_w(z_w, 1), np.ones_like(z_w), label="class 1 samples", color="crimson")
plt.yticks([0, 1], ["y=0", "y=1"])
plt.title("4: conditioning chooses the target mode")
plt.xlabel("sample value")
plt.legend()
plt.show()
```
▶ What you'll see: label 0 and label 1 occupy different modes; the discriminator must see the label to punish mismatches.

*Why it's done this way:* conditioning changes the modeled distribution from $p(x)$ to $p(x\mid y)$. If only $G$ sees $y$, it may ignore the label because $D$ only checks realism. Giving $D$ the same $y$ lets the game optimize realism **and** label consistency: a sample must look real for the requested condition, not merely real in aggregate.

### ✍️ Toy 1 · DCGAN upsampling plus one shared filter

A DCGAN-style generator grows spatial resolution and then reuses the same local kernel everywhere.
This 1-D version makes both steps visible.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)
t1_z = np.array([-1.0, 0.0, 2.0])
print("latent features:", t1_z.tolist())  # -> latent features: [-1.0, 0.0, 2.0]
t1_up = np.repeat(t1_z, 2)
print("upsampled features:", t1_up.tolist())  # -> upsampled features: [-1.0, -1.0, 0.0, 0.0, 2.0, 2.0]
t1_kernel = np.array([0.25, 0.50, 0.25])
print("shared kernel:", t1_kernel.tolist())  # -> shared kernel: [0.25, 0.5, 0.25]
t1_padded = np.pad(t1_up, 1, mode="edge")
print("edge-padded features:", t1_padded.tolist())  # -> edge-padded features: [-1.0, -1.0, -1.0, 0.0, 0.0, 2.0, 2.0, 2.0]
t1_filtered = np.array([np.sum(t1_padded[t1_i:t1_i + 3] * t1_kernel) for t1_i in range(len(t1_up))])
print("filtered features:", np.round(t1_filtered, 3).tolist())  # -> filtered features: [-1.0, -0.75, -0.25, 0.5, 1.5, 2.0]
assert np.allclose(np.round(t1_filtered, 3), [-1.0, -0.75, -0.25, 0.5, 1.5, 2.0])

plt.figure(figsize=(4.8, 2.8))
plt.plot(t1_up, marker="o", label="upsampled")
plt.plot(t1_filtered, marker="s", label="shared filter")
plt.title("Toy 1 · upsample + shared kernel")
plt.xlabel("position")
plt.ylabel("feature")
plt.legend()
plt.show()
```
▶ What you'll see: repeated features become a smoother signal after the same 3-weight kernel is applied at every position.

### ✍️ Toy 3 · Vanilla discriminator probability can saturate

The vanilla GAN discriminator squashes logits through a sigmoid. Large logits become probabilities
near 0 or 1, which can leave the generator with weak minimax gradients.

```python
import numpy as np

t3_rng = np.random.default_rng(0)
t3_scores = np.array([-2.0, 0.0, 2.0])
print("discriminator logits:", t3_scores.tolist())  # -> discriminator logits: [-2.0, 0.0, 2.0]
t3_probs = 1.0 / (1.0 + np.exp(-t3_scores))
print("sigmoid probabilities:", np.round(t3_probs, 3).tolist())  # -> sigmoid probabilities: [0.119, 0.5, 0.881]
t3_real_term = np.log(t3_probs[2])
print("log D(real-ish):", round(float(t3_real_term), 3))  # -> log D(real-ish): -0.127
t3_fake_term = np.log(1.0 - t3_probs[0])
print("log(1-D(fake-ish)):", round(float(t3_fake_term), 3))  # -> log(1-D(fake-ish)): -0.127
t3_objective = t3_real_term + t3_fake_term
print("vanilla discriminator objective:", round(float(t3_objective), 3))  # -> vanilla discriminator objective: -0.254
assert round(float(t3_objective), 3) == -0.254

plt.figure(figsize=(4.4, 2.8))
plt.bar(["fake-ish", "uncertain", "real-ish"], t3_probs, color="purple")
plt.ylim(0, 1)
plt.ylabel("D(x)")
plt.title("Toy 3 · sigmoid confidence")
plt.show()
```
▶ What you'll see: logits `-2` and `2` already push the classifier close to the probability extremes.

### ✍️ Toy 4 · WGAN critic gap gives a transport direction

A WGAN critic emits real-valued scores. On the line, a mean-score gap points out how far fake mass
must move.

```python
import numpy as np

t4_rng = np.random.default_rng(0)
t4_real = np.array([0.0, 1.0])
print("real samples:", t4_real.tolist())  # -> real samples: [0.0, 1.0]
t4_fake = np.array([2.0, 3.0])
print("fake samples:", t4_fake.tolist())  # -> fake samples: [2.0, 3.0]
t4_crit_real = t4_real
print("critic scores real:", t4_crit_real.tolist())  # -> critic scores real: [0.0, 1.0]
t4_crit_fake = t4_fake
print("critic scores fake:", t4_crit_fake.tolist())  # -> critic scores fake: [2.0, 3.0]
t4_gap = np.mean(t4_crit_real) - np.mean(t4_crit_fake)
print("E[f(real)] - E[f(fake)]:", round(float(t4_gap), 3))  # -> E[f(real)] - E[f(fake)]: -2.0
t4_transport = abs(np.mean(t4_real) - np.mean(t4_fake))
print("mean transport distance:", round(float(t4_transport), 3))  # -> mean transport distance: 2.0
t4_fake_moved = t4_fake - 1.0
print("fake after one left move:", t4_fake_moved.tolist())  # -> fake after one left move: [1.0, 2.0]
t4_transport_after = abs(np.mean(t4_real) - np.mean(t4_fake_moved))
print("transport after move:", round(float(t4_transport_after), 3))  # -> transport after move: 1.0
assert t4_transport_after < t4_transport

plt.figure(figsize=(4.8, 2.6))
plt.scatter(t4_real, np.zeros_like(t4_real), color="seagreen", label="real")
plt.scatter(t4_fake, np.ones_like(t4_fake), color="crimson", label="fake before")
plt.scatter(t4_fake_moved, np.ones_like(t4_fake_moved) * 0.5, color="steelblue", label="fake moved")
plt.yticks([0, 0.5, 1], ["real", "moved", "fake"])
plt.title("Toy 4 · WGAN transport signal")
plt.xlabel("sample value")
plt.legend()
plt.show()
```
▶ What you'll see: moving fake samples one unit left halves the mean transport distance from `2.0` to `1.0`.

### ✍️ Toy 5 · Lipschitz control: clipping and gradient penalty

WGAN critics must be slope-limited. Weight clipping constrains parameters directly; gradient penalty
charges slopes that drift away from norm 1.

```python
import numpy as np

t5_rng = np.random.default_rng(0)
```

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, toy optimization, and reproducible random examples.
import matplotlib.pyplot as plt # load Matplotlib for all visual debugging plots.
np.random.seed(0) # make stochastic cells reproducible across notebook runs.

def sigmoid(x): # define a small sigmoid helper for discriminator probabilities.
    return 1.0 / (1.0 + np.exp(-x)) # map scores to probabilities in (0, 1).

def conv1d_same(x, kernel): # define a tiny same-length 1-D convolution helper.
    pad = len(kernel) // 2 # compute symmetric padding width for odd kernels.
    padded = np.pad(np.asarray(x, dtype=float), pad, mode="edge") # pad endpoints so length is preserved.
    return np.array([np.sum(padded[i:i+len(kernel)] * kernel) for i in range(len(x))]) # apply one shared kernel at every position.

def critic_linear(x, w=1.0, b=0.0): # define a simple WGAN critic f(x)=wx+b.
    return w * np.asarray(x, dtype=float) + b # return real-valued scores rather than probabilities.

def gradient_penalty(norms, lam=10.0): # define the WGAN-GP penalty for toy gradient norms.
    norms = np.asarray(norms, dtype=float) # ensure vectorized arithmetic.
    return lam * (norms - 1.0) ** 2 # penalize slopes away from the 1-Lipschitz target.
```

## 🟢 Basics (warm-up)

### Basic 1 — Upsample a latent vector for DCGAN

**Goal.** Increase a tiny latent feature map's resolution, because DCGAN generators gradually turn compact noise into spatial samples. We build it in 2 steps.

```python
z_b1 = np.array([0.2, -0.5, 1.0, 0.3]) # define four latent feature values.
print("z_b1:", z_b1) # inspect the compact representation before spatial growth.
```
▶ What you'll see: the generator starts from only four coarse feature positions.

```python
up_b1 = np.repeat(z_b1, 2) # double the resolution by repeating each feature value.
print("upsampled:", up_b1) # inspect the expanded feature map.
assert len(up_b1) == 8 # verify the resolution doubled.
plt.figure(figsize=(5, 3)) # create a compact line plot.
plt.step(np.arange(len(up_b1)), up_b1, where="mid", color="teal") # draw repeated values as a step signal.
plt.title("Basic 1: nearest-neighbor upsampling") # title the plot.
plt.xlabel("position") # label spatial position.
```

### Advanced 4 — Train a conditional toy generator with label offsets

**Goal.** Learn class offsets from labeled data, because conditional GANs should map label y to the correct target distribution. We build it in 5 steps.

```python

offsets_a4 = np.array([0.0, 0.0]) # initialize generator class offsets incorrectly.
eta_a4 = 0.1 # choose learning rate for mean matching.
print("real class means:", np.round([np.mean(real_a4[y_a4 == c]) for c in [0, 1]], 3)) # inspect targets.
```

```python

    for c_a4 in [0, 1]: # update each label-specific offset.
        target_a4 = float(np.mean(real_a4[y_a4 == c_a4])) # compute the real class mean.
        pred_a4 = offsets_a4[c_a4] # generated mean when noise has zero mean.
```

▶ What you'll see: the class-conditional mean loss falls toward zero.

