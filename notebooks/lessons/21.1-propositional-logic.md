# 21.1 — Propositional Logic

Propositional logic is the smallest useful language for symbolic AI: whole statements are either true or false, and connectives such as NOT, AND, OR, and IMPLIES tell us which possible worlds survive. In this lesson, you will build formulas as plain Python data structures, evaluate truth tables, test equivalence and entailment, convert rules to CNF, and run resolution from scratch so every inference is inspectable.

### 1. Propositions, syntax, and possible worlds

A proposition is a whole statement that can be true or false: `P` might mean "it is raining" and `Q` might mean "the ground is wet." Logic separates **syntax** (the formula shape we write down) from **semantics** (the truth value it has in one possible world). We will represent formulas as tuples: `('var','P')` for an atom, `('not', f)` for negation, and binary tuples such as `('and', left, right)`.

```python
P_w = ('var', 'P')  # atomic proposition P.
Q_w = ('var', 'Q')  # atomic proposition Q.
formula_w = ('and', P_w, ('not', Q_w))  # syntax tree for P AND (NOT Q).
world_w = {'P': True, 'Q': False}  # one possible world: P true, Q false.
print("formula syntax:", formula_w)
print("one world:", world_w)
```
▶ What you'll see: a nested tuple for the formula and a dictionary assigning truth values to proposition names.

```python
def vars_in_w(f):  # collect proposition names appearing in a formula.
    if f[0] == 'var':
        return {f[1]}
    if f[0] == 'not':
        return vars_in_w(f[1])
    return vars_in_w(f[1]) | vars_in_w(f[2])

def worlds_w(names):  # enumerate all possible truth assignments for selected names.
    names = sorted(names)
    return [dict(zip(names, vals)) for vals in itertools.product([False, True], repeat=len(names))]

print("variables:", sorted(vars_in_w(formula_w)))
print("all worlds:", worlds_w(vars_in_w(formula_w)))
```
▶ What you'll see: two proposition names create four possible worlds, the tiny search space behind a truth table.

```python

mat_w = np.array([[int(w['P']), int(w['Q'])] for w in worlds2_w])
plt.figure(figsize=(4, 2.8))
plt.imshow(mat_w, cmap="Greys", aspect="auto")
plt.xticks([0, 1], ['P', 'Q']); plt.yticks(range(4), [str(i) for i in range(4)])
plt.colorbar(label="truth value")
plt.title("1: four possible worlds")
plt.show()
```
▶ What you'll see: a 4-row heatmap; each row is one complete assignment of truth values to P and Q.

*Why it's done this way:* a syntax tree keeps formulas mechanical rather than English-dependent, while dictionaries make semantics local to one world. Enumerating worlds is brute-force search, but for propositional logic it is the cleanest way to see that every inference is about sets of truth assignments.

### 2. Connectives and truth-table semantics

The connectives define the meaning of a formula. NOT flips one value, AND requires both, OR requires at least one, and material implication `P -> Q` is false only when the promise is triggered (`P=True`) and then broken (`Q=False`). This is not causation or time order; it is just the truth condition `not P or Q`.

```python
def eval_w(f, world):  # recursively evaluate a formula in one world.
    op = f[0]
    if op == 'var':
        return bool(world[f[1]])
    if op == 'not':
        return not eval_w(f[1], world)
    if op == 'and':
        return eval_w(f[1], world) and eval_w(f[2], world)
    if op == 'or':
        return eval_w(f[1], world) or eval_w(f[2], world)
    if op == 'imp':
        return (not eval_w(f[1], world)) or eval_w(f[2], world)
    if op == 'iff':
        return eval_w(f[1], world) == eval_w(f[2], world)
    raise ValueError(op)

imp_w = ('imp', P_w, Q_w)
for row_w in worlds_w({'P', 'Q'}):
    print(row_w, "P->Q =", eval_w(imp_w, row_w))
```
▶ What you'll see: implication is false in exactly one row: `P=True, Q=False`.

```python
headers_w = ['P', 'Q', 'not P', 'P and Q', 'P or Q', 'P->Q']
rows_w = []
for row_w in worlds_w({'P', 'Q'}):
    rows_w.append([row_w['P'], row_w['Q'], eval_w(('not', P_w), row_w),
                   eval_w(('and', P_w, Q_w), row_w), eval_w(('or', P_w, Q_w), row_w),
                   eval_w(imp_w, row_w)])
table_w = np.array(rows_w, dtype=int)
print(headers_w)
print(table_w)
assert table_w[:, -1].tolist() == [1, 1, 0, 1]
```
▶ What you'll see: the full connective table, with the implication column `[1, 1, 0, 1]`.


*Why it's done this way:* recursion mirrors the formula tree, so the evaluator is a direct semantics definition. The heatmap makes the set-thinking view visible: every formula is exactly the set of rows where its column is bright.

### 3. Logical equivalence, tautology, and satisfiability

Two formulas are **logically equivalent** when they have the same truth value in every possible world. A formula is a **tautology** if every row is true, **satisfiable** if at least one row is true, and **contradictory** if no row is true. These are not new algorithms yet — they are summaries of truth-table columns.

```python
def truth_column_w(f):  # truth values over all variables mentioned by f.
    names = vars_in_w(f)
    ws = worlds_w(names)
    return ws, np.array([eval_w(f, w) for w in ws], dtype=bool)

def equivalent_w(f, g):  # compare formulas over the union of variables.
    names = vars_in_w(f) | vars_in_w(g)
    return all(eval_w(f, w) == eval_w(g, w) for w in worlds_w(names))

notp_or_q_w = ('or', ('not', P_w), Q_w)
print("P->Q equivalent to not P or Q?", equivalent_w(imp_w, notp_or_q_w))
assert equivalent_w(imp_w, notp_or_q_w)
```
▶ What you'll see: implication and `not P or Q` agree in every row.

```python
taut_w = ('or', P_w, ('not', P_w))
contr_w = ('and', P_w, ('not', P_w))
for name_w, f_w in [('P or not P', taut_w), ('P and not P', contr_w), ('P and Q', ('and', P_w, Q_w))]:
    _, col_w = truth_column_w(f_w)
    print(name_w, "truth column", col_w.astype(int), "all?", col_w.all(), "any?", col_w.any())
assert truth_column_w(taut_w)[1].all()
assert not truth_column_w(contr_w)[1].any()
```
▶ What you'll see: a tautology has all 1s, a contradiction has all 0s, and `P and Q` has one satisfying row.

```python
summary_labels_w = ['tautology', 'contradiction', 'P and Q']
summary_cols_w = [truth_column_w(taut_w)[1], truth_column_w(contr_w)[1], truth_column_w(('and', P_w, Q_w))[1]]
plt.figure(figsize=(5, 2.8))
plt.bar(summary_labels_w, [int(col.sum()) for col in summary_cols_w], color=['seagreen', 'crimson', 'steelblue'])

```
▶ What you'll see: the tautology fills all rows, the contradiction fills none, and `P and Q` lands in between.

*Why it's done this way:* equivalence, validity, and satisfiability sound abstract, but each is a simple quantifier over rows: same rows, all rows, or some row. Making those quantifiers explicit prevents the common mistake of proving a rule from one convenient example.

### 4. Entailment as set containment

A knowledge base entails a query, written `KB ⊨ q`, when every world satisfying the knowledge base also satisfies the query. For `KB = {P, P -> Q}`, only one world survives: `P=True, Q=True`, and in that world `Q` is true. That is modus ponens as table inspection.

```python
def kb_holds_w(kb, world):  # a KB is a conjunction of its sentences.
    return all(eval_w(sentence, world) for sentence in kb)

def entails_w(kb, query):  # every KB model must also satisfy the query.
    names = set().union(*(vars_in_w(s) for s in kb), vars_in_w(query))
    models = [w for w in worlds_w(names) if kb_holds_w(kb, w)]
    return models, all(eval_w(query, w) for w in models)

kb_w = [P_w, ('imp', P_w, Q_w)]
models_w, entails_q_w = entails_w(kb_w, Q_w)
print("KB models:", models_w)
print("KB entails Q?", entails_q_w)
assert entails_q_w and models_w == [{'P': True, 'Q': True}]
```
▶ What you'll see: the only model of the knowledge base has `Q=True`, so the entailment holds.

```python
all_worlds_w = worlds_w({'P', 'Q'})
kb_col_w = np.array([kb_holds_w(kb_w, w) for w in all_worlds_w], dtype=int)
q_col_w = np.array([eval_w(Q_w, w) for w in all_worlds_w], dtype=int)
plt.figure(figsize=(4, 2.8))
plt.imshow(np.c_[kb_col_w, q_col_w], cmap="viridis", aspect="auto")
plt.xticks([0, 1], ['KB true', 'Q true']); plt.yticks(range(4), [str(w) for w in all_worlds_w])
plt.title("4: entailment as KB rows inside query rows")
plt.colorbar(label="truth")
plt.tight_layout(); plt.show()
```
▶ What you'll see: every bright KB row is also bright in the Q column; that containment is entailment.

*Why it's done this way:* entailment is stronger than finding one good example. The code first filters to the possible worlds that obey the facts, then checks the query on all remaining worlds, matching the mathematical definition exactly.

### 5. CNF conversion: making formulas clause-shaped

Resolution works on CNF: an AND of OR-clauses of literals. To convert a formula, we eliminate implications, push NOT inward with De Morgan's laws, and distribute OR over AND. Each rewrite preserves truth values, so the final clause set is equivalent to the original formula but easier for a mechanical proof rule.

```python
def eliminate_imp_w(f):  # rewrite implication and biconditional away.
    op = f[0]
    if op in ('var',):
        return f
    if op == 'not':
        return ('not', eliminate_imp_w(f[1]))
    if op == 'imp':
        return ('or', ('not', eliminate_imp_w(f[1])), eliminate_imp_w(f[2]))
    if op == 'iff':
        a, b = eliminate_imp_w(f[1]), eliminate_imp_w(f[2])
        return ('and', ('or', ('not', a), b), ('or', ('not', b), a))
    return (op, eliminate_imp_w(f[1]), eliminate_imp_w(f[2]))

compound_w = ('imp', ('and', P_w, Q_w), ('var', 'R'))
noimp_w = eliminate_imp_w(compound_w)
print("after implication removal:", noimp_w)
assert equivalent_w(compound_w, noimp_w)
```
▶ What you'll see: `(P and Q) -> R` becomes `not(P and Q) or R`, an equivalent implication-free formula.

```python
def push_not_w(f):  # move negations to literals.
    op = f[0]
    if op == 'var':
        return f
    if op == 'not':
        g = f[1]
        if g[0] == 'var':
            return f
        if g[0] == 'not':
            return push_not_w(g[1])
        if g[0] == 'and':
            return ('or', push_not_w(('not', g[1])), push_not_w(('not', g[2])))
        if g[0] == 'or':
            return ('and', push_not_w(('not', g[1])), push_not_w(('not', g[2])))
    return (op, push_not_w(f[1]), push_not_w(f[2]))

nnf_w = push_not_w(noimp_w)
print("negations pushed inward:", nnf_w)
assert equivalent_w(compound_w, nnf_w)
```
▶ What you'll see: `not(P and Q)` becomes `not P or not Q`, putting NOT directly on atoms.

```python
def distribute_w(f):  # distribute OR over AND until CNF-shaped.
    op = f[0]
    if op in ('var', 'not'):
        return f
    a, b = distribute_w(f[1]), distribute_w(f[2])
    if op == 'and':
        return ('and', a, b)
    if op == 'or' and a[0] == 'and':
        return ('and', distribute_w(('or', a[1], b)), distribute_w(('or', a[2], b)))
    if op == 'or' and b[0] == 'and':
        return ('and', distribute_w(('or', a, b[1])), distribute_w(('or', a, b[2])))
    return ('or', a, b)

cnf_formula_w = distribute_w(nnf_w)
print("CNF formula:", cnf_formula_w)
assert equivalent_w(compound_w, cnf_formula_w)
```
▶ What you'll see: the rule becomes a single disjunction `not P or not Q or R`, already a CNF clause.

```python
stages_w = [compound_w, noimp_w, nnf_w, cnf_formula_w]
stage_labels_w = ['original', 'no imp', 'NNF', 'CNF']
stage_worlds_w = worlds_w(vars_in_w(compound_w))
stage_table_w = np.array([[eval_w(f, w) for f in stages_w] for w in stage_worlds_w], dtype=int)
plt.figure(figsize=(5, 2.8))
plt.imshow(stage_table_w, cmap="viridis", aspect="auto")
plt.xticks(range(len(stage_labels_w)), stage_labels_w, rotation=20, ha="right")
plt.yticks(range(len(stage_worlds_w)), [str(i) for i in range(len(stage_worlds_w))])
plt.colorbar(label="truth")
plt.title("5: CNF rewrites preserve truth rows")
plt.tight_layout(); plt.show()
```
▶ What you'll see: every rewrite stage has the same truth pattern, showing that CNF conversion changed shape but not meaning.

*Why it's done this way:* CNF conversion is not algebra for its own sake. It normalizes many surface forms into clauses so one simple proof operation can apply everywhere, while equivalence asserts protect us from changing the meaning during rewrites.

### 6. Resolution: proving by contradiction

Resolution says that from `(A or X)` and `(not A or Y)` we may infer `(X or Y)`: one of `A` or `not A` must be false, so any satisfying world needs the leftovers. To prove `KB ⊨ q`, add `not q` to the KB; if resolution derives the empty clause, the combined assumptions are unsatisfiable, so the original KB entails `q`.

```python
def lit_w(name, neg=False):  # literals are (name, is_negated).
    return (name, bool(neg))

def resolve_pair_w(c1, c2):  # all resolvents from two frozenset clauses.
    out = set()
    for name, neg in c1:
        comp = (name, not neg)
        if comp in c2:
            resolvent = (set(c1) - {(name, neg)}) | (set(c2) - {comp})
            out.add(frozenset(resolvent))
    return out

c1_w = frozenset([lit_w('P', True), lit_w('Q')])  # not P or Q.
c2_w = frozenset([lit_w('P')])  # P.
print("resolvents:", resolve_pair_w(c1_w, c2_w))
```
▶ What you'll see: resolving `P` with `not P or Q` leaves the unit clause `{Q}`.

```python
def resolution_w(clauses):  # return whether empty clause is derived.
    clauses = set(clauses)
    history = []
    while True:
        new = set()
        pairs = list(itertools.combinations(sorted(clauses, key=lambda c: sorted(c)), 2))
        for c1, c2 in pairs:
            for r in resolve_pair_w(c1, c2):
                history.append((c1, c2, r))
                if len(r) == 0:
                    return True, history
                new.add(r)
        if new <= clauses:
            return False, history
        clauses |= new

clauses_w = {frozenset([lit_w('P')]), frozenset([lit_w('P', True), lit_w('Q')]), frozenset([lit_w('Q', True)])}
proved_w, history_w = resolution_w(clauses_w)
print("derived contradiction?", proved_w)
print("last step:", history_w[-1])
assert proved_w
```
▶ What you'll see: adding `not Q` to `{P, P->Q}` eventually derives the empty clause.

```python
resolvent_sizes_w = [len(step[2]) for step in history_w]
plt.figure(figsize=(4.5, 2.8))
plt.step(range(1, len(resolvent_sizes_w) + 1), resolvent_sizes_w, where="mid", marker="o", color="crimson")
plt.xlabel("resolution step")
plt.ylabel("resolvent size")
plt.title("6: resolution reaches the empty clause")
plt.ylim(-0.2, max(resolvent_sizes_w) + 0.5)
plt.tight_layout(); plt.show()
```
▶ What you'll see: the proof progress drops to a size-0 resolvent, the empty clause contradiction.

*Why it's done this way:* resolution turns entailment into an unsatisfiability test. The empty clause means no possible world can satisfy all clauses, so the negated query was impossible under the KB; that is exactly proof by contradiction in clause form.

## 🛠️ Setup

```python
import numpy as np  # load NumPy for arrays, truth-table matrices, and numerical checks.
import matplotlib.pyplot as plt  # load Matplotlib for heatmaps, bars, and proof visualizations.
import itertools  # load Cartesian products and combinations for world enumeration and resolution.
np.random.seed(0)  # make every stochastic demonstration reproducible.

TRUE = ('const', True)  # represent a true constant when examples need it.
FALSE = ('const', False)  # represent a false constant when examples need it.

def Var(name):  # build an atomic proposition node.
    return ('var', name)

def Not(f):  # build a negation node.
    return ('not', f)

def And(a, b):  # build a conjunction node.
    return ('and', a, b)

def Or(a, b):  # build a disjunction node.
    return ('or', a, b)

def Imp(a, b):  # build an implication node.
    return ('imp', a, b)

def Iff(a, b):  # build a biconditional node.
    return ('iff', a, b)

def vars_in(f):  # collect proposition names from a formula tree.
    if f[0] == 'const':
        return set()
    if f[0] == 'var':
        return {f[1]}
    if f[0] == 'not':
        return vars_in(f[1])
    return vars_in(f[1]) | vars_in(f[2])

def all_worlds(names):  # enumerate all truth assignments for a set/list of variable names.
    names = sorted(names)
    return [dict(zip(names, vals)) for vals in itertools.product([False, True], repeat=len(names))]

def eval_formula(f, world):  # evaluate one formula in one possible world.
    op = f[0]
    if op == 'const':
        return bool(f[1])
    if op == 'var':
        return bool(world[f[1]])
    if op == 'not':
        return not eval_formula(f[1], world)
    if op == 'and':
        return eval_formula(f[1], world) and eval_formula(f[2], world)
    if op == 'or':
        return eval_formula(f[1], world) or eval_formula(f[2], world)
    if op == 'imp':
        return (not eval_formula(f[1], world)) or eval_formula(f[2], world)
    if op == 'iff':
        return eval_formula(f[1], world) == eval_formula(f[2], world)
    raise ValueError(op)

def truth_table(formulas, names=None):  # compute a matrix of truth values for formulas.
    if names is None:
        names = set().union(*(vars_in(f) for f in formulas))
    worlds = all_worlds(names)
    table = np.array([[eval_formula(f, w) for f in formulas] for w in worlds], dtype=bool)
    return worlds, table

def is_tautology(f):  # test whether a formula is true in all worlds.
    return bool(truth_table([f])[1].all())

def is_satisfiable(f):  # test whether a formula is true in at least one world.
    return bool(truth_table([f])[1].any())

def equivalent(f, g):  # test whether two formulas agree in every world.
    worlds, tab = truth_table([f, g], vars_in(f) | vars_in(g))
    return bool(np.all(tab[:, 0] == tab[:, 1]))

def entails(kb, query):  # test KB entailment by model checking.
    names = set(vars_in(query))
    for sentence in kb:
        names |= vars_in(sentence)
    worlds = all_worlds(names)
    kb_mask = np.array([all(eval_formula(s, w) for s in kb) for w in worlds], dtype=bool)
    q_mask = np.array([eval_formula(query, w) for w in worlds], dtype=bool)
    return bool(np.all(q_mask[kb_mask])), worlds, kb_mask, q_mask

def eliminate_imp(f):  # remove implication and biconditional while preserving truth values.
    op = f[0]
    if op in ('const', 'var'):
        return f
    if op == 'not':
        return Not(eliminate_imp(f[1]))
    if op == 'imp':
        return Or(Not(eliminate_imp(f[1])), eliminate_imp(f[2]))
    if op == 'iff':
        a, b = eliminate_imp(f[1]), eliminate_imp(f[2])
        return And(Or(Not(a), b), Or(Not(b), a))
    return (op, eliminate_imp(f[1]), eliminate_imp(f[2]))

def push_not(f):  # convert to negation normal form.
    op = f[0]
    if op in ('const', 'var'):
        return f
    if op == 'not':
        g = f[1]
        if g[0] == 'const':
            return ('const', not g[1])
        if g[0] == 'var':
            return f
        if g[0] == 'not':
            return push_not(g[1])
        if g[0] == 'and':
            return Or(push_not(Not(g[1])), push_not(Not(g[2])))
        if g[0] == 'or':
            return And(push_not(Not(g[1])), push_not(Not(g[2])))
    return (op, push_not(f[1]), push_not(f[2]))

def distribute_or(f):  # distribute OR over AND to produce a CNF-shaped tree.
    op = f[0]
    if op in ('const', 'var', 'not'):
        return f
    left, right = distribute_or(f[1]), distribute_or(f[2])
    if op == 'and':
        return And(left, right)
    if op == 'or' and left[0] == 'and':
        return And(distribute_or(Or(left[1], right)), distribute_or(Or(left[2], right)))
    if op == 'or' and right[0] == 'and':
        return And(distribute_or(Or(left, right[1])), distribute_or(Or(left, right[2])))
    return Or(left, right)

def to_cnf_formula(f):  # compose the three CNF conversion stages.
    return distribute_or(push_not(eliminate_imp(f)))

def flatten_or(f):  # collect literals from one OR clause.
    if f[0] == 'or':
        return flatten_or(f[1]) | flatten_or(f[2])
    if f[0] == 'var':
        return {(f[1], False)}
    if f[0] == 'not' and f[1][0] == 'var':
        return {(f[1][1], True)}
    if f[0] == 'const' and f[1] is True:
        return {('__TRUE__', False)}
    return {str(f)}

def clauses_from_cnf(f):  # convert a CNF tree into a list of frozenset clauses.
    f = to_cnf_formula(f)
    if f[0] == 'and':
        return clauses_from_cnf(f[1]) + clauses_from_cnf(f[2])
    clause = frozenset(flatten_or(f))
    if ('__TRUE__', False) in clause:
        return []
    return [clause]

def resolve_pair(c1, c2):  # compute all resolvents from two clauses.
    out = set()
    for lit in c1:
        comp = (lit[0], not lit[1])
        if comp in c2:
            out.add(frozenset((set(c1) - {lit}) | (set(c2) - {comp})))
    return out

def resolution(clauses, max_steps=100):  # derive clauses until contradiction or saturation.
    clauses = set(clauses)
    history = []
    for _ in range(max_steps):
        new = set()
        for c1, c2 in itertools.combinations(list(clauses), 2):
            for r in resolve_pair(c1, c2):
                history.append((c1, c2, r))
                if len(r) == 0:
                    return True, history, clauses | {r}
                new.add(r)
        if new <= clauses:
            return False, history, clauses
        clauses |= new
    return False, history, clauses

def show_truth_heatmap(table, labels, title):  # draw a compact truth-table heatmap.
    plt.figure(figsize=(max(4, 0.7 * len(labels)), 3))

    plt.tight_layout(); plt.show()
```

### Advanced 5 — Resolution detects satisfiable versus unsatisfiable clause sets

**Goal.** Compare two clause sets, because resolution derives the empty clause only for unsatisfiable assumptions. We build it in 5 steps.

```python
P_a5, Q_a5 = Var('P'), Var('Q')  # Define propositions.
unsat_a5 = [P_a5, Imp(P_a5, Q_a5), Not(Q_a5)]  # Inconsistent assumptions.
sat_a5 = [Imp(P_a5, Q_a5), Not(P_a5)]  # Satisfiable assumptions.
print("prepared two clause sets")  # Confirm setup.
```
▶ What you'll see: one set should contradict itself and the other should not.

```python
clauses_unsat_a5 = []  # Prepare unsatisfiable clauses.
for f_a5 in unsat_a5:
    clauses_unsat_a5.extend(clauses_from_cnf(f_a5))  # Convert each formula.
clauses_sat_a5 = []  # Prepare satisfiable clauses.
for f_a5 in sat_a5:
    clauses_sat_a5.extend(clauses_from_cnf(f_a5))  # Convert each formula.
print("unsat clauses:", clauses_unsat_a5)  # Inspect first set.
print("sat clauses:", clauses_sat_a5)  # Inspect second set.
```
▶ What you'll see: the unsat set contains `P`, `not P or Q`, and `not Q`.

```python
unsat_proved_a5, hist_unsat_a5, _ = resolution(clauses_unsat_a5)  # Run resolution on inconsistent set.
sat_proved_a5, hist_sat_a5, _ = resolution(clauses_sat_a5)  # Run resolution on satisfiable set.

print("empty clause for sat set?", sat_proved_a5)  # Inspect second result.
assert unsat_proved_a5 and not sat_proved_a5  # Confirm contrast.
```
▶ What you'll see: only the inconsistent assumptions derive the empty clause.

```python
checks_a5 = [is_satisfiable(And(And(P_a5, Imp(P_a5, Q_a5)), Not(Q_a5))), is_satisfiable(And(Imp(P_a5, Q_a5), Not(P_a5)))]  # Cross-check by truth table.
```
