# 22.1 — Uninformed Search

Uninformed search solves graph problems when the algorithm knows only the start state, a successor function, edge costs, and a goal test. In this lesson, the same small grids and graphs show how the **frontier rule** changes behavior: BFS uses a queue, DFS uses a stack, and UCS uses a priority queue by accumulated cost.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build uninformed search one idea at a time. Run each cell in order and read the printed intermediate values — every path, frontier update, and cost is explicit. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays for grids, visit maps, and numeric checks.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
from collections import deque  # FIFO frontier for BFS.
import heapq  # priority frontier for uniform-cost search.
np.random.seed(0)  # reproducibility for any small random choices.
```

### 1. States, actions, paths, and the frontier

A search problem is a graph in disguise. A **state** is a node, an **action** is an outgoing edge, and a **path** is the chain of states already chosen. The frontier is the waiting room of partial paths that have been discovered but not expanded. Uninformed search does not score states with a heuristic; its only intelligence is the rule for which frontier path gets popped next.

```python
pos_w = {"S": (0, 0), "A": (1, 1), "B": (1, -1), "C": (2, 1), "G": (3, 0)}  # node coordinates for drawing.
edges_w = {"S": ["A", "B"], "A": ["C"], "B": ["G"], "C": ["G"], "G": []}  # successor lists.
frontier_w = [["S"]]  # store complete paths, not just endpoints, so a solution is ready when found.
print("start path:", frontier_w[0])  # inspect the one discovered path before any expansion.
print("successors of S:", edges_w["S"])  # inspect the actions available from the start.
```
▶ What you'll see: the frontier begins with one path ending at `S`, and expansion reveals two next choices.

```python
plt.figure(figsize=(4.6, 3.2))  # create a compact graph figure.
for u_w, nbrs_w in edges_w.items():  # draw every directed edge.
    for v_w in nbrs_w:  # draw one arrow per successor.
        x0_w, y0_w = pos_w[u_w]; x1_w, y1_w = pos_w[v_w]  # read endpoint coordinates.
        plt.arrow(x0_w, y0_w, x1_w - x0_w, y1_w - y0_w, length_includes_head=True, head_width=0.06, color="gray")  # show the action.
for name_w, (x_w, y_w) in pos_w.items():  # draw every state.
    color_w = "seagreen" if name_w == "S" else "crimson" if name_w == "G" else "steelblue"  # highlight start and goal.
    plt.scatter([x_w], [y_w], s=180, color=color_w)  # plot node.
    plt.text(x_w, y_w + 0.12, name_w, ha="center")  # label node.
plt.axis("off"); plt.title("1: a search problem is a graph plus a frontier"); plt.show()
```
▶ What you'll see: `S` is the start, `G` is the goal, and edges are the only information an uninformed algorithm can use.

*Why it's done this way: storing paths on the frontier makes the algorithm mechanical — pop one path, test its last state, append successor paths — while the frontier discipline decides the search strategy.*

### 2. BFS: FIFO frontier means shallowest first

Breadth-first search uses a FIFO queue: the path that entered earliest leaves earliest. Because all paths of depth $d$ enter before paths of depth $d+1$, BFS expands the graph by layers. On unit-cost edges this is exactly what we want: the first time BFS reaches the goal, no shallower path exists, so the returned path has the fewest moves.

```python
grid_w = np.zeros((5, 5), dtype=int)  # 0 means open cell.
start_w, goal_w = (0, 0), (4, 4)  # solve the lesson's 5x5 grid from corner to corner.
frontier_bfs_w = deque([(start_w, [start_w])])  # FIFO queue of (state, path).
seen_bfs_w = {start_w}  # mark on entry so the same cell is not queued twice.
order_bfs_w = []  # record expansion order for inspection.
print("Manhattan lower bound:", abs(goal_w[0] - start_w[0]) + abs(goal_w[1] - start_w[1]))  # unit-grid lower bound.
```
▶ What you'll see: the corner-to-corner lower bound is 8 moves.

```python
while frontier_bfs_w:  # continue until a path reaches the goal.
    state_w, path_bfs_w = frontier_bfs_w.popleft()  # FIFO pop gives the oldest, shallowest path.
    order_bfs_w.append(state_w)  # record that this state was expanded.
    if state_w == goal_w:  # stop immediately on first goal pop.
        break
    r_w, c_w = state_w  # unpack the grid cell.
    for nb_w in [(r_w + 1, c_w), (r_w, c_w + 1), (r_w - 1, c_w), (r_w, c_w - 1)]:  # deterministic four-neighbor order.
        if 0 <= nb_w[0] < 5 and 0 <= nb_w[1] < 5 and nb_w not in seen_bfs_w:  # keep legal new cells.
            seen_bfs_w.add(nb_w)  # close on entry to prevent duplicates.
            frontier_bfs_w.append((nb_w, path_bfs_w + [nb_w]))  # enqueue the extended path.
print("BFS states in path:", len(path_bfs_w), "moves:", len(path_bfs_w) - 1)  # inspect path length.
assert len(path_bfs_w) - 1 == 8  # BFS finds the 8-move shortest path on this unit grid.
```
▶ What you'll see: BFS returns 9 states, which means 8 moves.

```python
visit_bfs_w = np.full((5, 5), -1, dtype=int)  # prepare a grid of visit-order numbers.
for k_w, cell_w in enumerate(order_bfs_w):  # assign expansion index to each expanded cell.
    visit_bfs_w[cell_w] = k_w  # store visit order at that cell.
plt.figure(figsize=(4, 4))  # create a grid visualization.
plt.imshow(visit_bfs_w, cmap="viridis")  # color cells by expansion order.
for r_w, c_w in path_bfs_w:  # highlight the found path.
    plt.scatter([c_w], [r_w], s=80, facecolors="none", edgecolors="white", linewidths=2)  # draw path rings.
plt.title("2: BFS expands layers and returns 8 moves"); plt.xticks(range(5)); plt.yticks(range(5)); plt.show()
```
▶ What you'll see: colors spread outward in shallow layers, and the highlighted path has the minimum possible number of moves.

*Why it's done this way: FIFO order makes depth the priority without explicitly sorting by depth, so BFS is optimal exactly when every edge has the same cost.*

### 3. DFS: LIFO frontier follows one branch

Depth-first search uses a LIFO stack: the newest path is expanded first. That makes DFS memory-light and direct, but not shortest-path aware. It may find a goal quickly, or it may dive down a long corridor before trying a shallow alternative. In cyclic graphs, DFS also needs a visited set; otherwise the stack can keep re-adding the states it just left.

```python
neighbors_dfs_w = lambda cell_w: [(cell_w[0] + 1, cell_w[1]), (cell_w[0] - 1, cell_w[1]), (cell_w[0], cell_w[1] + 1), (cell_w[0], cell_w[1] - 1)]  # down/up/right/left order creates a long deterministic branch.
stack_w = [(start_w, [start_w])]  # LIFO frontier of paths.
seen_dfs_w = {start_w}  # visited set prevents cycles.
order_dfs_w = []  # record expansion order.
print("initial stack size:", len(stack_w))  # inspect DFS frontier before expansion.
```
▶ What you'll see: DFS starts with the same one-path frontier as BFS.

```python
while stack_w:  # continue until a goal path is popped.
    state_w, path_dfs_w = stack_w.pop()  # LIFO pop chooses the newest path.
    order_dfs_w.append(state_w)  # record expansion order.
    if state_w == goal_w:  # stop at the first goal found by this branch order.
        break
    for nb_w in reversed(neighbors_dfs_w(state_w)):  # reverse push order so down/up/right/left is the pop preference.
        if 0 <= nb_w[0] < 5 and 0 <= nb_w[1] < 5 and nb_w not in seen_dfs_w:  # keep legal unvisited cells.
            seen_dfs_w.add(nb_w)  # close on entry to avoid cycles.
            stack_w.append((nb_w, path_dfs_w + [nb_w]))  # push the extended path.
print("DFS states in path:", len(path_dfs_w), "moves:", len(path_dfs_w) - 1)  # inspect DFS route length.
assert len(path_dfs_w) - 1 == 16  # this successor order reaches the goal by a longer route.
```
▶ What you'll see: DFS returns a 16-move route, 8 moves longer than BFS.

```python
visit_dfs_w = np.full((5, 5), -1, dtype=int)  # prepare expansion-order grid.
for k_w, cell_w in enumerate(order_dfs_w):  # write expansion indices.
    visit_dfs_w[cell_w] = k_w  # store visit order.
plt.figure(figsize=(4, 4))  # create a grid visualization.
plt.imshow(visit_dfs_w, cmap="magma")  # color by DFS expansion order.
for r_w, c_w in path_dfs_w:  # draw the DFS path.
    plt.scatter([c_w], [r_w], s=70, facecolors="none", edgecolors="white", linewidths=2)  # highlight path cells.
plt.title("3: DFS follows one long branch"); plt.xticks(range(5)); plt.yticks(range(5)); plt.show()
```
▶ What you'll see: DFS snakes through a branch instead of balancing shallow alternatives.

*Why it's done this way: LIFO order is cheap because it remembers the current branch, but that same commitment means DFS solves reachability, not shortest path, unless extra limits or ordering assumptions are added.*

### 4. UCS: priority frontier means cheapest path first

Uniform-cost search generalizes BFS from equal costs to arbitrary nonnegative costs. Instead of choosing the shallowest path, UCS chooses the path with the smallest accumulated cost $C(p)=\sum_e c(e)$. A priority queue makes that rule explicit. When entering some cells is expensive, UCS may prefer a longer route with lower total cost.

```python
cost_w = np.ones((5, 5), dtype=float)  # entering most cells costs 1.
cost_w[2, 2] = 9.0; cost_w[2, 3] = 9.0  # two expensive cells make shallow-looking routes costly.
straight_cost_w = 1 + 1 + 9 + 9 + 1 + 1 + 1 + 1  # one route through both expensive cells.
around_cost_w = 8 * 1  # an eight-move route that avoids expensive cells.
print("straight-through cost:", straight_cost_w, "around cost:", around_cost_w)  # inspect the cost contrast.
assert straight_cost_w == 24 and around_cost_w == 8  # lesson arithmetic.
```
▶ What you'll see: a route can have the same move count but a much larger cost.

```python
pq_w = [(0.0, start_w, [start_w])]  # priority queue stores (cost so far, state, path).
best_w = {start_w: 0.0}  # best known cost to each state.
order_ucs_w = []  # record expansion order.
while pq_w:  # continue until the cheapest frontier path reaches the goal.
    g_w, state_w, path_ucs_w = heapq.heappop(pq_w)  # pop cheapest path so far.
    if g_w != best_w[state_w]:  # skip stale entries superseded by a cheaper path.
        continue
    order_ucs_w.append(state_w)  # record a real expansion.
    if state_w == goal_w:  # first goal pop is optimal under nonnegative costs.
        break
    r_w, c_w = state_w  # unpack cell.
    for nb_w in [(r_w + 1, c_w), (r_w, c_w + 1), (r_w - 1, c_w), (r_w, c_w - 1)]:  # four-neighbor moves.
        if 0 <= nb_w[0] < 5 and 0 <= nb_w[1] < 5:  # keep legal cells.
            new_g_w = g_w + cost_w[nb_w]  # add the cost of entering the neighbor.
            if new_g_w < best_w.get(nb_w, float("inf")):  # improve only if cheaper.
                best_w[nb_w] = new_g_w  # remember best cost.
                heapq.heappush(pq_w, (new_g_w, nb_w, path_ucs_w + [nb_w]))  # push updated path.
print("UCS path cost:", g_w, "moves:", len(path_ucs_w) - 1)  # inspect optimal cost and moves.
assert g_w == 8.0  # UCS avoids the expensive cells.
```
▶ What you'll see: UCS chooses total cost 8, not the expensive cost-24 route.

```python
plt.figure(figsize=(4, 4))  # create a grid cost visualization.
plt.imshow(cost_w, cmap="Oranges")  # show expensive cells by color.
for r_w, c_w in path_ucs_w:  # overlay UCS path.
    plt.scatter([c_w], [r_w], s=80, facecolors="none", edgecolors="navy", linewidths=2)  # path rings.
plt.colorbar(label="entering cost")  # label cost scale.
plt.title("4: UCS routes around expensive cells"); plt.xticks(range(5)); plt.yticks(range(5)); plt.show()
```
▶ What you'll see: the highlighted path goes around the high-cost cells instead of through them.

*Why it's done this way: a priority queue makes accumulated cost the frontier discipline, so UCS is the right replacement for BFS whenever one move is not always worth one unit.*

### 5. Closed sets: mark states early to prevent duplicate work

The same state can be reached by many paths. If we wait too long to mark a state as seen, a small cyclic graph can keep queuing duplicate paths. Marking states when they enter the frontier is a conservative way to avoid repeated work in unweighted BFS; for UCS, we keep the best cost instead because a later path may be cheaper.

```python
cycle_edges_w = {"S": ["A", "B"], "A": ["S", "C"], "B": ["S", "C"], "C": ["G"], "G": []}  # tiny graph with cycles and duplicate routes.
q_bad_w = deque([["S"]])  # queue paths without early marking.
pops_bad_w = []  # record popped endpoints.
for _ in range(8):  # limit the demo so the cycle cannot run forever.
    p_w = q_bad_w.popleft()  # pop a path.
    pops_bad_w.append(p_w[-1])  # record endpoint.
    for nb_w in cycle_edges_w[p_w[-1]]:  # append every successor, including repeats.
        q_bad_w.append(p_w + [nb_w])  # no duplicate filter.
print("without early seen, first popped endpoints:", pops_bad_w)  # inspect repeated states.
```
▶ What you'll see: `S` reappears because cycles put it back in the queue.

```python
q_good_w = deque([["S"]])  # queue paths with early marking.
seen_good_w = {"S"}  # mark start immediately.
pops_good_w = []  # record real expansions.
while q_good_w:  # run until all reachable states are expanded once.
    p_w = q_good_w.popleft()  # FIFO pop.
    pops_good_w.append(p_w[-1])  # record endpoint.
    for nb_w in cycle_edges_w[p_w[-1]]:  # inspect successors.
        if nb_w not in seen_good_w:  # only queue unseen states.
            seen_good_w.add(nb_w)  # mark on entry.
            q_good_w.append(p_w + [nb_w])  # enqueue new path.
print("with early seen:", pops_good_w)  # inspect each state once.
assert len(pops_good_w) == 5  # S, A, B, C, G each expands once.
```
▶ What you'll see: early marking expands each reachable state once.

```python
plt.figure(figsize=(4.6, 3))  # create duplicate-work comparison.
plt.bar(["no early seen\n(first 8 pops)", "early seen"], [len(pops_bad_w), len(pops_good_w)], color=["crimson", "seagreen"])  # compare pop counts.
plt.title("5: visited timing controls duplicate work")  # title the plot.
plt.ylabel("popped paths")  # label effort scale.
plt.show()  # display the comparison.
```
▶ What you'll see: the no-filter version spends its limited pops revisiting states, while early marking finishes the reachable graph.

*Why it's done this way: closed-state bookkeeping is not an implementation detail; it is what turns a graph with cycles from repeated path enumeration into finite state search.*

## 🛠️ Setup

```python
import numpy as np  # load NumPy for grids, arrays, masks, and numeric checks.
import matplotlib.pyplot as plt  # load Matplotlib so every search trace can be inspected visually.
from collections import deque  # load the standard-library FIFO queue building block for BFS.
import heapq  # load the standard-library priority queue building block for UCS.
np.random.seed(0)  # make all stochastic examples reproducible across notebook runs.

def grid_neighbors(cell, shape):  # define legal four-neighbor moves for a rectangular grid.
    r, c = cell  # unpack the current row and column.
    for nr, nc in [(r + 1, c), (r, c + 1), (r - 1, c), (r, c - 1)]:  # try down, right, up, left.
        if 0 <= nr < shape[0] and 0 <= nc < shape[1]:  # keep only in-bounds neighbors.
            yield (nr, nc)  # emit the legal neighboring cell.

def draw_grid_values(values, title, path=None, cmap="viridis", colorbar_label="value"):  # draw a grid and optionally overlay a path.
    plt.figure(figsize=(4, 4))  # create a compact square figure.
    plt.imshow(values, cmap=cmap, aspect="equal")  # show cell values as colors.
    plt.colorbar(label=colorbar_label)  # add a readable color scale.
    if path is not None:  # optionally overlay the solution path.
        for r, c in path:  # draw a ring around each path cell.
            plt.scatter([c], [r], s=80, facecolors="none", edgecolors="white", linewidths=2)  # highlight the path.
    plt.xticks(range(values.shape[1]))  # show grid columns.
    plt.yticks(range(values.shape[0]))  # show grid rows.
    plt.title(title)  # title the plot with the example id.
    plt.show()  # display the figure.

def bfs_grid(start, goal, shape, blocked=()):  # run BFS on a grid with optional blocked cells.
    blocked = set(blocked)  # convert blocked cells to a set for fast membership.
    q = deque([(start, [start])])  # initialize FIFO frontier with one path.
    seen = {start}  # mark the start when it enters the frontier.
    order = []  # record expansion order.
    widths = []  # record frontier size over time.
    while q:  # continue until frontier is empty or goal is found.
        widths.append(len(q))  # store current memory pressure before popping.
        state, path = q.popleft()  # pop the oldest path.
        order.append(state)  # record expansion.
        if state == goal:  # stop when the goal is popped.
            return path, order, widths  # return solution and diagnostics.
        for nb in grid_neighbors(state, shape):  # examine legal neighbors.
            if nb not in blocked and nb not in seen:  # skip walls and duplicates.
                seen.add(nb)  # mark on entry.
                q.append((nb, path + [nb]))  # enqueue the extended path.
    return None, order, widths  # report failure if no path exists.

def dfs_grid(start, goal, shape, blocked=()):  # run DFS on a grid with optional blocked cells.
    blocked = set(blocked)  # convert blocked cells to a set.
    stack = [(start, [start])]  # initialize LIFO frontier.
    seen = {start}  # mark the start on entry.
    order = []  # record expansion order.
    widths = []  # record stack size over time.
    while stack:  # continue until stack is empty or goal appears.
        widths.append(len(stack))  # store current stack size.
        state, path = stack.pop()  # pop the newest path.
        order.append(state)  # record expansion.
        if state == goal:  # stop at first found goal.
            return path, order, widths  # return solution and diagnostics.
        nbrs = list(grid_neighbors(state, shape))  # materialize neighbors so we can reverse push order.
        preferred = [(state[0] + 1, state[1]), (state[0] - 1, state[1]), (state[0], state[1] + 1), (state[0], state[1] - 1)]  # prefer down/up/right/left for a deterministic branch.
        for nb in reversed(preferred):  # push reversed order so the first preferred neighbor is explored first.
            if 0 <= nb[0] < shape[0] and 0 <= nb[1] < shape[1] and nb not in blocked and nb not in seen:  # avoid invalid cells, walls, and repeats.
                seen.add(nb)  # mark on entry.
                stack.append((nb, path + [nb]))  # push the extended path.
    return None, order, widths  # report failure.

def ucs_grid(start, goal, costs, blocked=()):  # run uniform-cost search where costs are paid on entry.
    blocked = set(blocked)  # convert blocked cells to a set.
    pq = [(0.0, start, [start])]  # initialize priority queue with zero cost at start.
    best = {start: 0.0}  # best known cost to each state.
    order = []  # record expansion order.
    widths = []  # record priority-queue size over time.
    while pq:  # continue until frontier is empty or goal is popped.
        widths.append(len(pq))  # store memory pressure.
        g, state, path = heapq.heappop(pq)  # pop cheapest path.
        if g != best[state]:  # ignore stale worse entries.
            continue
        order.append(state)  # record true expansion.
        if state == goal:  # first goal pop is optimal with nonnegative costs.
            return path, g, order, widths  # return solution and diagnostics.
        for nb in grid_neighbors(state, costs.shape):  # examine neighbors.
            if nb not in blocked:  # skip blocked cells.
                ng = g + float(costs[nb])  # add entering cost.
                if ng < best.get(nb, float("inf")):  # keep only cheaper paths.
                    best[nb] = ng  # update best cost.
                    heapq.heappush(pq, (ng, nb, path + [nb]))  # push the improved path.
    return None, float("inf"), order, widths  # report failure.

def order_grid(order, shape):  # convert an expansion-order list into a grid of indices.
    out = np.full(shape, -1, dtype=int)  # initialize unseen cells as -1.
    for k, cell in enumerate(order):  # loop over expanded cells.
        out[cell] = k  # store expansion index.
    return out  # return the diagnostic grid.
```

### Basic 3 — FIFO queue behavior

**Goal.** Use a queue operation, because BFS depends on first-in, first-out path selection. We build it in 2 steps.


```python
remaining_b3 = list(q_b3)  # save the queue after the pop.

plt.bar([oldest_b3] + remaining_b3, [3, 2, 1], color=["seagreen", "gray", "gray"])  # highlight the popped path.
```

### Advanced 3 — Reopen a state when UCS finds a cheaper path

**Goal.** Keep best costs instead of a simple seen set, because weighted graphs can discover a state first by an expensive path and later by a cheaper one. We build it in 5 steps.
