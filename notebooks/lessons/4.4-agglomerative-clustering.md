# 4.4 — Agglomerative Clustering

Agglomerative clustering is a bottom-up way to discover structure in unlabeled data: start with every point as its own cluster, repeatedly merge the two closest clusters, and read the resulting merge history as a hierarchy. In this lesson, the important object is not a learned classifier but the criterion that decides **what counts as close** — Euclidean distance, linkage, centroid compression, Ward's increase in squared error, and the cut height that turns a tree into flat labels.

### 1. Points, distances, and the shape of the unsupervised problem

Agglomerative clustering starts with an unlabeled matrix $X\in\mathbb{R}^{m\times n}$: rows are examples, columns are measured coordinates, and no row comes with a target label. The only raw evidence the algorithm can use is geometry. For two points $x_i,x_j\in\mathbb{R}^2$, Euclidean distance is

$$d(x_i,x_j)=\lVert x_i-x_j\rVert_2=\sqrt{(x_{i1}-x_{j1})^2+(x_{i2}-x_{j2})^2}.$$

Squaring coordinate differences makes left/right and up/down misses positive; taking the square root returns the result to the original coordinate units. Those distances are the first "numbers that decide" which points are close enough to merge.

```python
X_w = np.array([[1.0, 2.0], [1.0, 1.5], [4.5, 4.0], [4.5, 4.5]])  # four unlabeled 2-D points.
names_w = np.array(["A", "B", "C", "D"])  # readable point names.
print("X shape:", X_w.shape)  # m=4 examples, n=2 features.
print(X_w)  # inspect the data the algorithm sees.
```
▶ What you'll see: a 4×2 matrix with two points near (1,2) and two points near (4.5,4).

```python
diff_ab_w = X_w[0] - X_w[1]  # coordinate-wise displacement from B to A.
sq_ab_w = diff_ab_w ** 2  # squared coordinate differences.

print("A-B difference:", diff_ab_w)  # [0, 0.5].

assert round(d_ab_w, 3) == 0.500  # concrete hand-check.
```
▶ What you'll see: A and B are only 0.5 units apart.

*Why it's done this way: without labels, the only defensible first step is to convert geometry into auditable numbers; Euclidean distance is the simplest rule that says nearby coordinates are similar while keeping the result in the same units as the data.*

### 2. The pairwise distance matrix

A bottom-up hierarchy needs to know which pair is closest at each step, so we compute every pairwise distance and store it in a matrix $D\in\mathbb{R}^{m\times m}$. The diagonal is zero because each point is distance zero from itself. The matrix is symmetric because $d(x_i,x_j)=d(x_j,x_i)$. In implementation, this matrix is also a debugging tool: if a merge surprises you, inspect the distances before blaming the clustering.

```python
diffs_w = X_w[:, None, :] - X_w[None, :, :]  # broadcast to all pairwise coordinate differences.
D_w = np.sqrt(np.sum(diffs_w ** 2, axis=2))  # reduce feature differences to Euclidean distances.
print("pairwise distance matrix:\n", np.round(D_w, 3))  # inspect all distances at once.
assert D_w.shape == (4, 4)  # shape bookkeeping: one row/column per point.
assert np.allclose(D_w, D_w.T)  # distances are symmetric.
```
▶ What you'll see: zeros on the diagonal, 0.5 for A-B and C-D, and much larger cross-pair distances.

```python
masked_D_w = D_w + np.eye(len(D_w)) * 999.0  # hide diagonal zeros so they cannot win the nearest-pair search.
flat_idx_w = int(np.argmin(masked_D_w))  # index of the smallest off-diagonal entry.
i_w, j_w = np.unravel_index(flat_idx_w, D_w.shape)  # convert flat index to row/column.
print("nearest pair:", names_w[i_w], names_w[j_w], "distance", round(D_w[i_w, j_w], 3))  # one closest pair.
assert round(float(D_w[i_w, j_w]), 3) == 0.500  # concrete nearest-pair value.
```
▶ What you'll see: the nearest off-diagonal distance is 0.5, tying the two obvious local pairs.

```python

plt.colorbar(label="Euclidean distance")  # numeric color scale.
plt.xticks(range(4), names_w); plt.yticks(range(4), names_w)  # label rows and columns.
plt.title("2: pairwise distance matrix"); plt.show()
```
▶ What you'll see: two dark off-diagonal blocks (A-B and C-D) and bright cross-block distances.

*Why it's done this way: a pairwise matrix turns vague visual closeness into a finite search problem — find the smallest permitted distance, merge, update the matrix, and repeat.*

### 3. Clusters need a linkage rule, not just point distances

After the first merge, the algorithm compares **clusters**, not just individual points. A linkage rule converts many point-to-point distances into one cluster-to-cluster distance. Single linkage uses the minimum pair distance, complete linkage uses the maximum, average linkage uses the mean, and centroid linkage compares cluster means.

This is the first major modeling choice. Single linkage likes chains, complete linkage demands compact groups, average linkage smooths over all pair relationships, and centroid linkage compresses a cluster to a representative. The same data can produce a different hierarchy when this rule changes.

```python
left_w = np.array([0, 1])  # cluster {A,B}.
right_w = np.array([2, 3])  # cluster {C,D}.
block_w = D_w[np.ix_(left_w, right_w)]  # all cross-distances between the two clusters.
print("cross-distance block {A,B} vs {C,D}:\n", np.round(block_w, 3))  # four pair distances.
```
▶ What you'll see: the four distances connecting the left pair to the right pair.

```python
single_w = float(np.min(block_w))  # nearest cross pair.
complete_w = float(np.max(block_w))  # farthest cross pair.
average_w = float(np.mean(block_w))  # average cross distance.
centroid_w = float(np.linalg.norm(X_w[left_w].mean(axis=0) - X_w[right_w].mean(axis=0)))  # representative distance.
print("single:", round(single_w, 3), "complete:", round(complete_w, 3))  # inspect extreme linkages.
print("average:", round(average_w, 3), "centroid:", round(centroid_w, 3))  # inspect smoothed/compressed linkages.
assert round(single_w, 3) == 4.031 and round(complete_w, 3) == 4.610  # concrete linkage checks.
```
▶ What you'll see: one pair of clusters has several legitimate distances depending on the linkage rule.

```python

plt.xticks(rotation=15); plt.show()
```
▶ What you'll see: complete linkage is largest because it protects against the worst within-merge separation; single is smallest because it only needs one bridge.

*Why it's done this way: once points become clusters, there is no single automatic distance left; linkage defines the geometry the hierarchy can see, so it is a modeling assumption rather than a coding detail.*

### 4. The agglomerative merge loop

The agglomerative algorithm is short: initialize one singleton cluster per point, compute distances between all cluster pairs, merge the closest pair, record the merge height, and repeat until one cluster remains. The recorded heights form the information a dendrogram would display.

```python
def cluster_distance_w(X, c1, c2, linkage="average"):  # cluster-to-cluster distance from scratch.
    c1 = np.array(c1, dtype=int); c2 = np.array(c2, dtype=int)  # integer point indices.
    d = np.sqrt(np.sum((X[c1][:, None, :] - X[c2][None, :, :]) ** 2, axis=2))  # all cross distances.
    if linkage == "single":
        return float(np.min(d))  # nearest bridge.
    if linkage == "complete":
        return float(np.max(d))  # worst separation.
    if linkage == "centroid":
        return float(np.linalg.norm(X[c1].mean(axis=0) - X[c2].mean(axis=0)))  # representative means.
    return float(np.mean(d))  # average linkage default.

clusters_w = [[i] for i in range(len(X_w))]  # each point starts alone.
print("initial clusters:", clusters_w)  # four singleton clusters.
```
▶ What you'll see: the hierarchy begins with `[0]`, `[1]`, `[2]`, `[3]`.

```python
history_w = []  # record (left cluster, right cluster, merge distance, new cluster).
while len(clusters_w) > 1:  # repeat until one root cluster remains.
    best_w = None  # store the closest pair found in this pass.
    for a_w in range(len(clusters_w)):  # scan current clusters.
        for b_w in range(a_w + 1, len(clusters_w)):  # scan each unordered pair once.
            dist_w = cluster_distance_w(X_w, clusters_w[a_w], clusters_w[b_w], "average")  # average-link distance.
            if best_w is None or dist_w < best_w[0]:  # keep the minimum distance.
                best_w = (dist_w, a_w, b_w)  # distance plus cluster positions.
    dist_w, a_w, b_w = best_w  # unpack the winning merge.
    new_cluster_w = sorted(clusters_w[a_w] + clusters_w[b_w])  # combine point indices.
    history_w.append((clusters_w[a_w].copy(), clusters_w[b_w].copy(), dist_w, new_cluster_w.copy()))  # record merge.
    clusters_w = [c for k_w, c in enumerate(clusters_w) if k_w not in (a_w, b_w)] + [new_cluster_w]  # replace two clusters with one.
    print("merge", history_w[-1][0], "+", history_w[-1][1], "at", round(dist_w, 3), "->", new_cluster_w)  # inspect step.
assert len(history_w) == 3  # four points require exactly three merges.
```
▶ What you'll see: two small merges at height 0.5, then one larger merge between the two pairs.

```python
heights_w = np.array([h_w[2] for h_w in history_w])  # merge distances in order.
print("merge heights:", np.round(heights_w, 3))  # the hierarchy's vertical scale.
assert np.allclose(np.round(heights_w[:2], 3), [0.5, 0.5])  # first two merges are the local pairs.
plt.figure(figsize=(4.5, 3))
plt.plot(np.arange(1, len(heights_w) + 1), heights_w, marker="o", color="purple")
plt.xlabel("merge step"); plt.ylabel("merge distance"); plt.title("4: agglomerative merge heights")
plt.xticks([1, 2, 3]); plt.show()
```
▶ What you'll see: a big jump after the two local merges, suggesting two stable clusters.

*Why it's done this way: the greedy loop is simple because each merge is locally justified by the current linkage criterion; the full hierarchy is useful because we postpone the final number of clusters until we inspect the merge heights.*

### 5. Cutting the hierarchy into flat labels

A hierarchy is a nested tree, but most downstream workflows need one label per point. We get flat clusters by cutting the tree: either stop when exactly $K$ clusters remain, or cut at a distance threshold and keep all merges below it. A large jump in merge heights often marks a natural cut.

```python
def agglomerate_w(X, k=1, linkage="average"):  # return clusters after stopping at k groups.
    clusters = [[i] for i in range(len(X))]  # singleton start.
    merges = []  # record merge heights.
    while len(clusters) > k:  # stop early for flat clustering.
        best = None  # closest pair placeholder.
        for a in range(len(clusters)):
            for b in range(a + 1, len(clusters)):
                dist = cluster_distance_w(X, clusters[a], clusters[b], linkage)  # chosen linkage.
                if best is None or dist < best[0]:
                    best = (dist, a, b)
        dist, a, b = best  # winning pair.
        merged = sorted(clusters[a] + clusters[b])  # new group.
        merges.append((clusters[a].copy(), clusters[b].copy(), dist, merged.copy()))  # record.
        clusters = [c for idx, c in enumerate(clusters) if idx not in (a, b)] + [merged]  # update active set.
    return clusters, merges  # final flat clusters plus history.

clusters2_w, merges2_w = agglomerate_w(X_w, k=2, linkage="average")  # stop at two clusters.
print("two-cluster cut:", clusters2_w)  # inspect flat groups.
```
▶ What you'll see: the cut keeps `{A,B}` and `{C,D}` as separate clusters.

```python
labels_w = np.empty(len(X_w), dtype=int)  # one label per point.
for label_w, cluster_w in enumerate(clusters2_w):  # assign label numbers to final clusters.
    labels_w[cluster_w] = label_w  # fill point labels.
print("labels:", labels_w)  # flat representation in {0,1}^4.
assert set(map(tuple, [sorted(c) for c in clusters2_w])) == {(0, 1), (2, 3)}  # concrete cluster check.
```
▶ What you'll see: four points become a length-4 label vector.

```python
plt.figure(figsize=(4.2, 3.4))
plt.scatter(X_w[:, 0], X_w[:, 1], c=labels_w, cmap="viridis", s=100)  # color by flat cluster label.
for name_w, point_w in zip(names_w, X_w):
    plt.text(point_w[0] + 0.05, point_w[1] + 0.05, name_w)  # point labels.
plt.title("5: cutting the hierarchy at K=2"); plt.xlabel("feature 0"); plt.ylabel("feature 1")
plt.axis("equal"); plt.show()
```
▶ What you'll see: the left pair and right pair receive different colors.

*Why it's done this way: the merge tree preserves every resolution, while the cut turns that tree into the practical output shape labels $\in\{0,1\}^m$; choosing the cut is a decision, not a fact revealed by the data.*

### 6. Ward linkage and the squared-error cost

The content block writes the representative cost

$$J=\sum_{i=1}^{m}\min_k\lVert x_i-\mu_k\rVert_2^2.$$

For a fixed partition, $\mu_k$ is the mean of cluster $k$, and $J$ is the within-cluster sum of squared errors. Ward linkage chooses the merge that increases this cost the least. That makes agglomerative clustering behave like a bottom-up compression method: each merge asks, "which two clusters can share one representative with the least extra squared error?"

```python
def sse_cluster_w(X, cluster):  # within-cluster squared error around the cluster mean.
    pts = X[np.array(cluster, dtype=int)]  # selected points.
    mu = pts.mean(axis=0)  # representative mean.
    return float(np.sum((pts - mu) ** 2))  # squared deviations from representative.

def ward_increase_w(X, c1, c2):  # cost increase caused by merging two clusters.
    before = sse_cluster_w(X, c1) + sse_cluster_w(X, c2)  # current compression cost.
    after = sse_cluster_w(X, sorted(c1 + c2))  # cost after using one representative.
    return float(after - before)  # incremental penalty.

print("SSE {A,B}:", round(sse_cluster_w(X_w, [0, 1]), 3))  # two points around their mean.
print("SSE {C,D}:", round(sse_cluster_w(X_w, [2, 3]), 3))  # symmetric pair.
assert round(sse_cluster_w(X_w, [0, 1]), 3) == 0.125  # each point is 0.25 from mean in y, squared total 0.125.
```
▶ What you'll see: a tight two-point cluster has small but nonzero squared error around its centroid.

```python
pairs_w = [([0], [1]), ([2], [3]), ([0, 1], [2, 3])]  # candidate Ward merges.
inc_w = np.array([ward_increase_w(X_w, a_w, b_w) for a_w, b_w in pairs_w])  # compute merge penalties.
print("Ward increases:", np.round(inc_w, 3))  # small local merges, big final merge.
assert np.allclose(np.round(inc_w[:2], 3), [0.125, 0.125])  # concrete local penalties.
```
▶ What you'll see: merging within a visible pair is cheap; merging both pairs into one representative is expensive.

```python
plt.figure(figsize=(4.8, 3))
plt.bar(["A+B", "C+D", "AB+CD"], inc_w, color=["seagreen", "seagreen", "crimson"])
plt.ylabel("increase in J"); plt.title("6: Ward linkage minimizes SSE increase")
plt.show()
```
▶ What you'll see: the cross-cluster merge has a much larger squared-error penalty.

*Why it's done this way: Ward's rule connects hierarchical clustering to the objective $J$ — a merge is good when replacing two representatives by one loses little information, so the hierarchy becomes a record of increasingly coarse compression.*

### 7. Scaling, stability, and the algorithm-as-lens warning

Distances only see the numeric coordinates we feed them. If one feature is measured in huge units, it can dominate every linkage decision. A responsible unsupervised workflow therefore standardizes features, checks whether small perturbations change the merge order, and remembers that the output is optimized structure under a criterion — not ground-truth labels.

```python
X_scale_w = np.array([[1.0, 2.0], [1.0, 1.5], [4.5, 4.0], [4.5, 4.5]])  # original coordinates.
X_bad_w = X_scale_w.copy()  # create a version with feature 0 in oversized units.
X_bad_w[:, 0] *= 100.0  # scale only the first feature.
print("original first row:", X_scale_w[0], "scaled first row:", X_bad_w[0])  # inspect distortion.
```
▶ What you'll see: feature 0 is now hundreds of units while feature 1 is still around 1–5.

```python
orig_d_w = np.linalg.norm(X_scale_w[0] - X_scale_w[2])  # cross-cluster distance before scaling.
bad_d_w = np.linalg.norm(X_bad_w[0] - X_bad_w[2])  # same pair after scaling x-coordinate.
print("A-C original distance:", round(float(orig_d_w), 3))  # balanced units.
print("A-C scaled distance:", round(float(bad_d_w), 3))  # dominated by feature 0.
assert round(float(orig_d_w), 3) == 4.031  # concrete original distance.
```
▶ What you'll see: the same two points become about 350 units apart after one feature is rescaled.

```python
mean_w = X_bad_w.mean(axis=0)  # feature means.
std_w = X_bad_w.std(axis=0)  # feature standard deviations.
X_std_w = (X_bad_w - mean_w) / std_w  # standardize each feature to comparable units.

print("standardized clusters:", clusters_std_w)  # inspect repaired geometry.
assert set(map(tuple, [sorted(c) for c in clusters_std_w])) == {(0, 1), (2, 3)}  # stable intended grouping.
```
▶ What you'll see: after standardization, the natural two-pair structure is recovered.

```python
plt.figure(figsize=(7, 3))
plt.subplot(1, 2, 1); plt.scatter(X_bad_w[:, 0], X_bad_w[:, 1], s=90, color="indianred"); plt.title("unscaled feature units")
plt.xlabel("feature 0 ×100"); plt.ylabel("feature 1")
plt.subplot(1, 2, 2); plt.scatter(X_std_w[:, 0], X_std_w[:, 1], s=90, color="seagreen"); plt.title("standardized units")

```
▶ What you'll see: the left plot is stretched by units; the right plot restores comparable axes.

*Why it's done this way: agglomerative clustering is a lens built from distances and linkage, so preprocessing and stability checks are part of the model; otherwise a unit conversion can masquerade as discovered structure.*

## 🛠️ Setup

```python
import numpy as np  # Import NumPy for arrays, distances, means, masks, and numerical checks.
import matplotlib.pyplot as plt  # Import Matplotlib for scatterplots, heatmaps, bar charts, and merge curves.
np.random.seed(0)  # Fix the global random seed so every stochastic example is reproducible.

def pairwise_distances(X):  # Compute a full Euclidean distance matrix for rows of X.
    X = np.asarray(X, dtype=float)  # Ensure predictable floating-point arithmetic.
    diffs = X[:, None, :] - X[None, :, :]  # Broadcast all pairwise coordinate differences.
    return np.sqrt(np.sum(diffs ** 2, axis=2))  # Convert squared differences into Euclidean distances.

def cluster_distance(X, c1, c2, linkage="average"):  # Compute one cluster-to-cluster distance.
    X = np.asarray(X, dtype=float)  # Ensure rows can be indexed and averaged.
    c1 = np.asarray(c1, dtype=int)  # Convert the first cluster to integer indices.
    c2 = np.asarray(c2, dtype=int)  # Convert the second cluster to integer indices.
    d = np.sqrt(np.sum((X[c1][:, None, :] - X[c2][None, :, :]) ** 2, axis=2))  # All cross distances.
    if linkage == "single":  # Single linkage uses the nearest bridge.
        return float(np.min(d))  # Return the minimum point-to-point distance.
    if linkage == "complete":  # Complete linkage protects against the farthest separation.
        return float(np.max(d))  # Return the maximum point-to-point distance.
    if linkage == "centroid":  # Centroid linkage compresses each cluster to its mean.
        return float(np.linalg.norm(X[c1].mean(axis=0) - X[c2].mean(axis=0)))  # Return representative distance.
    if linkage == "ward":  # Ward linkage is the increase in within-cluster squared error.
        return ward_increase(X, list(c1), list(c2))  # Return the merge penalty.
    return float(np.mean(d))  # Average linkage averages all cross pair distances.

def sse_cluster(X, cluster):  # Compute within-cluster sum of squared errors around the mean.
    pts = np.asarray(X, dtype=float)[np.asarray(cluster, dtype=int)]  # Select cluster rows.
    mu = pts.mean(axis=0)  # The mean minimizes squared error for a fixed cluster.
    return float(np.sum((pts - mu) ** 2))  # Sum squared deviations from the mean.

def ward_increase(X, c1, c2):  # Compute Ward's merge cost increase.
    before = sse_cluster(X, c1) + sse_cluster(X, c2)  # Cost with two representatives.
    after = sse_cluster(X, sorted(list(c1) + list(c2)))  # Cost with one representative.
    return float(after - before)  # Extra squared error caused by the merge.

def agglomerate(X, k=1, linkage="average"):  # Bottom-up agglomerative clustering from scratch.
    clusters = [[i] for i in range(len(X))]  # Start with one singleton per point.
    history = []  # Store merge records for inspection.
    while len(clusters) > k:  # Stop when the requested number of clusters remains.
        best = None  # Closest pair found so far.
        for a in range(len(clusters)):  # Scan active clusters.
            for b in range(a + 1, len(clusters)):  # Scan each unordered pair once.
                dist = cluster_distance(X, clusters[a], clusters[b], linkage)  # Linkage distance.
                if best is None or dist < best[0]:  # Keep the smallest distance.
                    best = (dist, a, b)  # Store distance and positions.
        dist, a, b = best  # Unpack the winning merge.
        merged = sorted(clusters[a] + clusters[b])  # Combine point indices.
        history.append((clusters[a].copy(), clusters[b].copy(), dist, merged.copy()))  # Record the merge.
        clusters = [c for idx, c in enumerate(clusters) if idx not in (a, b)] + [merged]  # Replace two clusters by one.
    labels = np.empty(len(X), dtype=int)  # Prepare flat labels for current clusters.
    for label, cluster in enumerate(clusters):  # Assign each active cluster a label.
        labels[cluster] = label  # Fill labels for member points.
    return clusters, labels, history  # Return flat clusters, labels, and merge history.

def plot_points(X, labels, title):  # Draw a compact labeled scatterplot.
    plt.figure(figsize=(4, 3))  # Create one small figure.
    plt.scatter(X[:, 0], X[:, 1], c=labels, cmap="viridis", s=80)  # Color points by cluster label.
    plt.title(title)  # Label the plot with the current example.
    plt.xlabel("feature 0")  # Label the first coordinate.
    plt.ylabel("feature 1")  # Label the second coordinate.
    plt.axis("equal")  # Preserve geometry so distances look honest.
    plt.show()  # Display the scatterplot.
```

```python
    rid_a1 = tuple(right_a1) if len(right_a1) > 1 else right_a1[0]  # Child key for right cluster.
    lx_a1, rx_a1 = positions_a1[lid_a1], positions_a1[rid_a1]  # Child x-positions.
    lh_a1, rh_a1 = heights_a1[lid_a1], heights_a1[rid_a1]  # Child heights.
    segments_a1 += [([lx_a1, lx_a1], [lh_a1, height_a1]), ([rx_a1, rx_a1], [rh_a1, height_a1]), ([lx_a1, rx_a1], [height_a1, height_a1])]  # Vertical and horizontal branches.
    key_a1 = tuple(merged_a1)  # New internal cluster key.
    positions_a1[key_a1] = (lx_a1 + rx_a1) / 2  # Parent x-position is midpoint.
    heights_a1[key_a1] = height_a1  # Parent height is merge distance.
print("segments drawn:", len(segments_a1))  # Inspect the number of plotted branches.
assert len(segments_a1) == 9  # Three line segments per merge for three merges.
```
▶ What you'll see: the dendrogram is represented by nine simple line segments.


### Advanced 4 — Sweep K and plot the squared-error objective J

**Goal.** Compute $J=\sum_i \min_k\lVert x_i-\mu_k\rVert^2$ for different cuts, because the training objective alone always improves as K grows. We build it in 4 steps.

```python

```
▶ What you'll see: the objective will be measured from one cluster to six singleton clusters.

```python

for K_a4 in Ks_a4:  # Evaluate each cut size.
    clusters_a4, labels_a4, _ = agglomerate(X_a4, k=int(K_a4), linkage="ward")  # Ward cut at K.
    cost_a4 = sum(sse_cluster(X_a4, c_a4) for c_a4 in clusters_a4)  # Compute J for that partition.
    J_a4.append(cost_a4)  # Save cost.

```
