# 19.16 — Uncertainty Calibration

Uncertainty calibration asks whether model scores behave like real probabilities: among examples assigned confidence 0.8, about 80% should be correct. In this lesson, you will build reliability diagrams, expected calibration error, temperature scaling, Platt scaling, isotonic regression, and uncertainty decompositions from scratch with only NumPy and Matplotlib.

### 1. Confidence is a frequency claim, not just a large score

A classifier usually emits logits, then softmax turns those logits into class probabilities. Calibration asks a group question: if we collect all predictions with confidence near 0.7, are about 70% of them correct? A model can have useful accuracy while still being overconfident, so we must inspect confidence and correctness side by side.

```python
logits_w = np.array([[2.2, 0.1], [1.8, 0.3], [1.4, 0.5], [0.7, 1.2], [0.2, 1.5], [1.6, 0.4]])
y_w = np.array([0, 0, 1, 1, 1, 0])
shift_w = logits_w - logits_w.max(axis=1, keepdims=True)
probs_w = np.exp(shift_w) / np.exp(shift_w).sum(axis=1, keepdims=True)
pred_w = np.argmax(probs_w, axis=1)
conf_w = probs_w.max(axis=1)
correct_w = (pred_w == y_w).astype(float)
print("predictions:", pred_w)
print("confidence:", np.round(conf_w, 3))
print("correct?:", correct_w.astype(int))
```
▶ What you'll see: confidence is high for most examples, but one high-confidence prediction is wrong.

```python
acc_w = float(correct_w.mean())
avg_conf_w = float(conf_w.mean())
print("accuracy:", round(acc_w, 3), "average confidence:", round(avg_conf_w, 3))
assert round(acc_w, 3) == 0.833
assert round(avg_conf_w, 3) == 0.766
plt.figure(figsize=(4.6, 3))
plt.bar(np.arange(len(conf_w)), conf_w, color=np.where(correct_w == 1, "seagreen", "indianred"))
plt.axhline(acc_w, color="black", linestyle="--", label="accuracy")
plt.ylim(0, 1); plt.title("1: confidence bars, red = wrong"); plt.ylabel("confidence"); plt.legend(); plt.show()
```
▶ What you'll see: the dashed accuracy line and confidence bars are related but not the same quantity.

*Why it's done this way:* softmax normalizes logits into numbers that sum to one, but the normalization alone does not guarantee frequency meaning. Calibration tests that meaning empirically: confidence is a promise about many similar predictions, while correctness is observed one example at a time.

### 2. Reliability diagrams and expected calibration error (ECE)

A reliability diagram bins predictions by confidence. For each bin $b$, it compares $acc(b)$, the fraction correct, with $conf(b)$, the average confidence. Expected calibration error summarizes the weighted gaps:

$$ECE=\sum_b \frac{n_b}{n}\lvert acc(b)-conf(b)\rvert.$$

The weight $n_b/n$ matters because a large bin should affect the audit more than a tiny bin. The absolute value matters because overconfidence and underconfidence are both calibration errors.

```python
conf2_w = np.array([0.15, 0.35, 0.55, 0.65, 0.82, 0.93, 0.88, 0.42, 0.76, 0.61])
correct2_w = np.array([0, 0, 1, 0, 1, 1, 0, 1, 1, 1], dtype=float)
edges_w = np.linspace(0, 1, 6)
bin_id_w = np.minimum(np.digitize(conf2_w, edges_w[1:-1], right=False), 4)
print("bin ids:", bin_id_w)
print("edges:", edges_w)
```
▶ What you'll see: each prediction is assigned to one of five confidence intervals.

```python
acc_bins_w, conf_bins_w, counts_w = [], [], []
for b_w in range(5):
    m_w = bin_id_w == b_w
    counts_w.append(int(m_w.sum()))
    acc_bins_w.append(float(correct2_w[m_w].mean()) if m_w.any() else 0.0)
    conf_bins_w.append(float(conf2_w[m_w].mean()) if m_w.any() else 0.0)
acc_bins_w = np.array(acc_bins_w); conf_bins_w = np.array(conf_bins_w); counts_w = np.array(counts_w)
gaps_w = np.abs(acc_bins_w - conf_bins_w)
ece_w = float(np.sum((counts_w / len(conf2_w)) * gaps_w))
print("counts:", counts_w)
print("acc:", np.round(acc_bins_w, 3), "conf:", np.round(conf_bins_w, 3))
print("ECE:", round(ece_w, 3))
assert round(ece_w, 3) == 0.218
```
▶ What you'll see: bins with different sizes contribute different amounts to the final ECE.

```python
centers_w = 0.5 * (edges_w[:-1] + edges_w[1:])
plt.figure(figsize=(4.8, 3.6))
plt.bar(centers_w, acc_bins_w, width=0.17, alpha=0.75, label="bin accuracy", color="steelblue")
plt.plot([0, 1], [0, 1], "k--", label="perfect calibration")
plt.scatter(conf_bins_w, acc_bins_w, color="crimson", zorder=3, label="(conf, acc)")
plt.xlim(0, 1); plt.ylim(0, 1); plt.xlabel("confidence"); plt.ylabel("accuracy")
plt.title("2: reliability diagram"); plt.legend(); plt.show()
```
▶ What you'll see: points below the diagonal are overconfident; points above it are underconfident.

*Why it's done this way:* calibration is not a per-example property because one binary outcome cannot prove whether 0.8 was honest. Binning creates repeated trials with similar stated probabilities, and ECE turns the visual reliability gaps into one weighted scalar audit.

### 3. Bin choice changes what the audit can see

The design decision in calibration is binning or smoothing. Too few bins hide local failures; too many bins make each $acc(b)$ noisy because a bin may contain only one or two examples. The math is the same ECE formula, but the diagnostic resolution and variance change.

```python
rng_w = np.random.default_rng(1)
conf3_w = rng_w.uniform(0.05, 0.95, size=80)
true_prob3_w = np.clip(conf3_w - 0.18 * (conf3_w > 0.65), 0.02, 0.98)
correct3_w = (rng_w.random(80) < true_prob3_w).astype(float)
print("mean confidence:", round(float(conf3_w.mean()), 3))
print("mean accuracy:", round(float(correct3_w.mean()), 3))
```
▶ What you'll see: the synthetic model is slightly overconfident on average.

```python
def ece_bins_w(conf, correct, n_bins):
    edges = np.linspace(0, 1, n_bins + 1)
    ids = np.minimum(np.digitize(conf, edges[1:-1], right=False), n_bins - 1)
    ece = 0.0; nonempty = 0
    for b in range(n_bins):
        m = ids == b
        if m.any():
            nonempty += 1
            ece += (m.sum() / len(conf)) * abs(correct[m].mean() - conf[m].mean())
    return float(ece), nonempty
for nb_w in [4, 8, 20]:
    e_w, ne_w = ece_bins_w(conf3_w, correct3_w, nb_w)
    print(f"bins={nb_w}: ECE={e_w:.3f}, nonempty={ne_w}")
```
▶ What you'll see: ECE changes as bins become finer, even though the predictions are unchanged.

```python
bin_grid_w = np.array([3, 4, 5, 8, 10, 16, 20, 40])
eces_grid_w = np.array([ece_bins_w(conf3_w, correct3_w, int(k))[0] for k in bin_grid_w])
plt.figure(figsize=(4.8, 3))
plt.plot(bin_grid_w, eces_grid_w, marker="o", color="purple")
plt.xlabel("number of bins"); plt.ylabel("ECE"); plt.title("3: ECE depends on bin resolution"); plt.show()
```
▶ What you'll see: the curve moves because coarse and fine audits emphasize different evidence.

*Why it's done this way:* binning is a bias-variance tradeoff. Wide bins have stable averages but can wash out sharp miscalibration; narrow bins localize failures but estimate accuracy from fewer Bernoulli trials, so the audit itself becomes noisy.

### 4. Temperature scaling fixes softmax overconfidence with one number

Temperature scaling divides logits by $T$ before softmax. If $T>1$, logits shrink toward each other and confidence falls; if $T<1$, logits spread apart and confidence rises. We choose $T$ on validation data by minimizing negative log-likelihood, leaving class order unchanged because dividing all logits by the same positive number does not change the argmax.

```python
rng_w = np.random.default_rng(2)
y4_w = rng_w.integers(0, 3, size=90)
logits4_w = rng_w.normal(0, 0.8, size=(90, 3))
logits4_w[np.arange(90), y4_w] += rng_w.normal(1.2, 0.8, size=90)
logits4_w *= 1.9
def softmax_temp_w(logits, T):
    z = logits / T
    z = z - z.max(axis=1, keepdims=True)
    ez = np.exp(z)
    return ez / ez.sum(axis=1, keepdims=True)
def nll_w(probs, y):
    return float(-np.mean(np.log(probs[np.arange(len(y)), y] + 1e-12)))
base_probs4_w = softmax_temp_w(logits4_w, 1.0)
print("base NLL:", round(nll_w(base_probs4_w, y4_w), 3), "base confidence:", round(float(base_probs4_w.max(axis=1).mean()), 3))
```
▶ What you'll see: scaled-up logits produce confident predictions with a measurable NLL.

```python
Ts_w = np.linspace(0.5, 4.0, 71)
nlls_w = np.array([nll_w(softmax_temp_w(logits4_w, T_w), y4_w) for T_w in Ts_w])
best_T_w = float(Ts_w[np.argmin(nlls_w)])
cal_probs4_w = softmax_temp_w(logits4_w, best_T_w)
print("best T:", round(best_T_w, 2), "calibrated NLL:", round(nll_w(cal_probs4_w, y4_w), 3))
assert best_T_w > 1.0
assert nll_w(cal_probs4_w, y4_w) < nll_w(base_probs4_w, y4_w)
```
▶ What you'll see: the best temperature is greater than 1, so it softens overconfident logits.

```python
plt.figure(figsize=(4.8, 3))
plt.plot(Ts_w, nlls_w, color="navy")
plt.axvline(best_T_w, color="crimson", linestyle="--", label=f"best T={best_T_w:.2f}")
plt.xlabel("temperature T"); plt.ylabel("validation NLL"); plt.title("4: choose T by validation NLL"); plt.legend(); plt.show()
```
▶ What you'll see: NLL forms a curve with a best softening temperature.

*Why it's done this way:* NLL is a proper scoring rule, so it rewards honest probabilities rather than just correct argmaxes. Temperature scaling is deliberately low-capacity: it can repair global overconfidence without changing which class is predicted.

### 5. Platt scaling and isotonic regression calibrate scores directly

For binary classification, Platt scaling fits a sigmoid $\sigma(as+b)$ to raw scores. It is smooth and low-variance but assumes an S-shaped calibration curve. Isotonic regression instead fits a nondecreasing step function, which is more flexible but needs enough validation data. We implement both from scratch.

```python
scores5_w = np.array([-2.2, -1.4, -0.8, -0.3, 0.1, 0.4, 0.9, 1.2, 1.8, 2.4])
y5_w = np.array([0, 0, 0, 1, 0, 1, 1, 0, 1, 1], dtype=float)
a5_w, b5_w, lr5_w = 0.0, 0.0, 0.25
for step5_w in range(800):
    p5_w = 1 / (1 + np.exp(-(a5_w * scores5_w + b5_w)))
    a5_w -= lr5_w * np.mean((p5_w - y5_w) * scores5_w)
    b5_w -= lr5_w * np.mean(p5_w - y5_w)
platt5_w = 1 / (1 + np.exp(-(a5_w * scores5_w + b5_w)))
print("a,b:", round(a5_w, 3), round(b5_w, 3))
print("Platt probs:", np.round(platt5_w, 3))
assert a5_w > 0
```
▶ What you'll see: larger scores receive larger calibrated probabilities through a learned sigmoid.

```python
def isotonic_pava_w(scores, y):
    order = np.argsort(scores)
    levels = list(y[order].astype(float))
    weights = [1.0] * len(levels)
    i = 0
    while i < len(levels) - 1:
        if levels[i] > levels[i + 1]:
            new_w = weights[i] + weights[i + 1]
            new_level = (levels[i] * weights[i] + levels[i + 1] * weights[i + 1]) / new_w
            levels[i:i+2] = [new_level]
            weights[i:i+2] = [new_w]
            i = max(i - 1, 0)
        else:
            i += 1
    fitted_sorted = np.repeat(levels, np.array(weights, dtype=int))
    fitted = np.empty_like(fitted_sorted)
    fitted[order] = fitted_sorted
    return fitted
iso5_w = isotonic_pava_w(scores5_w, y5_w)
print("isotonic probs:", np.round(iso5_w, 3))
assert np.all(np.diff(iso5_w[np.argsort(scores5_w)]) >= -1e-12)
```
▶ What you'll see: isotonic probabilities are flat steps that never decrease as the score increases.

```python
plt.figure(figsize=(5, 3))
plt.scatter(scores5_w, y5_w, color="black", label="labels")
plt.plot(scores5_w, platt5_w, marker="o", label="Platt sigmoid", color="seagreen")
plt.step(scores5_w, iso5_w, where="mid", label="isotonic", color="darkorange")
plt.ylim(-0.05, 1.05); plt.xlabel("raw score"); plt.ylabel("calibrated probability")
plt.title("5: parametric vs monotone calibration"); plt.legend(); plt.show()
```
▶ What you'll see: Platt is a smooth S-curve, while isotonic is a monotone staircase.

*Why it's done this way:* Platt scaling encodes the belief that score reliability changes smoothly with one slope and intercept. Isotonic encodes only monotonicity: a higher score should not mean lower risk. The price of flexibility is variance, especially when adjacent score regions have few labels.

### 6. Aleatoric versus epistemic uncertainty

Aleatoric uncertainty is irreducible noise in the data, such as overlapping classes or ambiguous labels. Epistemic uncertainty is uncertainty from limited knowledge, such as models disagreeing because training data are scarce. A useful uncertainty audit separates these: collecting more data can reduce epistemic uncertainty, but not irreducible aleatoric noise.

```python
x6_w = np.linspace(-3, 3, 80)
true_p6_w = 1 / (1 + np.exp(-1.5 * x6_w))
aleatoric6_w = true_p6_w * (1 - true_p6_w)
ensemble6_w = []
for slope6_w, bias6_w in [(1.0, -0.2), (1.4, 0.0), (1.9, 0.2), (1.2, 0.25), (1.7, -0.15)]:
    ensemble6_w.append(1 / (1 + np.exp(-(slope6_w * x6_w + bias6_w))))
ensemble6_w = np.array(ensemble6_w)
epistemic6_w = ensemble6_w.var(axis=0)
print("max aleatoric:", round(float(aleatoric6_w.max()), 3))
print("max epistemic:", round(float(epistemic6_w.max()), 3))
assert round(float(aleatoric6_w.max()), 3) == 0.25
```
▶ What you'll see: aleatoric uncertainty peaks near probability 0.5, while epistemic uncertainty comes from ensemble disagreement.

```python
plt.figure(figsize=(5, 3))
plt.plot(x6_w, true_p6_w, color="black", label="mean probability")
plt.fill_between(x6_w, true_p6_w - np.sqrt(aleatoric6_w), true_p6_w + np.sqrt(aleatoric6_w), alpha=0.18, label="aleatoric band")
plt.fill_between(x6_w, ensemble6_w.mean(axis=0) - 2*np.sqrt(epistemic6_w), ensemble6_w.mean(axis=0) + 2*np.sqrt(epistemic6_w), alpha=0.25, label="epistemic band")
plt.ylim(-0.2, 1.2); plt.xlabel("x"); plt.ylabel("probability"); plt.title("6: two uncertainty sources"); plt.legend(); plt.show()
```
▶ What you'll see: the irreducible band is largest near the decision boundary; model disagreement is a separate band.

*Why it's done this way:* calibration asks whether stated probabilities are reliable, but uncertainty quantification asks why the model is unsure. The Bernoulli variance $p(1-p)$ captures outcome randomness, while ensemble variance captures sensitivity to the learned model.

### Basic 1 — Convert logits to probabilities

**Goal.** Turn logits into probabilities with a stable softmax, because calibration audits probabilities rather than raw scores. We build it in 2 steps.

```python
logits_b1 = np.array([[2.0, 0.5, -1.0], [0.2, 1.1, 0.4]])  # store two examples with three class logits.

```
▶ What you'll see: each row has maximum shifted logit 0, but class ordering is unchanged.


### Basic 6 — Compute ECE from three bins

**Goal.** Combine bin gaps into expected calibration error, because larger bins should count more in the final scalar. We build it in 2 steps.

```python
counts_b6 = np.array([2, 3, 5])  # number of predictions in each bin.
acc_b6 = np.array([0.50, 0.67, 0.80])  # empirical accuracy in each bin.
conf_b6 = np.array([0.35, 0.70, 0.90])  # average confidence in each bin.
gaps_b6 = np.abs(acc_b6 - conf_b6)  # absolute reliability gap per bin.
print("gaps:", np.round(gaps_b6, 3))  # inspect local calibration errors.
```
▶ What you'll see: each bin has its own reliability gap.

```python
weights_b6 = counts_b6 / counts_b6.sum()  # convert bin counts into n_b/n weights.
ece_b6 = float(np.sum(weights_b6 * gaps_b6))  # compute weighted average absolute gap.
print("weights:", weights_b6, "ECE:", round(ece_b6, 3))  # inspect weighting and final ECE.
assert round(ece_b6, 3) == 0.089  # verify the concrete ECE value.
plt.figure(figsize=(4, 3))
plt.bar(["bin0", "bin1", "bin2"], weights_b6 * gaps_b6, color="teal")
```

### Basic 8 — Soften logits with temperature

**Goal.** Apply one temperature to logits, because $T>1$ reduces overconfident softmax probabilities without changing the predicted class. We build it in 2 steps.

```python

    a_a2 -= 0.2 * np.mean((pl_a2 - y_a2) * score_a2)
    b_a2 -= 0.2 * np.mean(pl_a2 - y_a2)
platt_p_a2 = 1 / (1 + np.exp(-(a_a2 * score_a2 + b_a2)))
levels_a2 = list(y_a2.astype(float)); weights_a2 = [1.0] * len(levels_a2); i_a2 = 0
while i_a2 < len(levels_a2) - 1:
    if levels_a2[i_a2] > levels_a2[i_a2 + 1]:
        w_a2 = weights_a2[i_a2] + weights_a2[i_a2 + 1]
        avg_a2 = (levels_a2[i_a2] * weights_a2[i_a2] + levels_a2[i_a2 + 1] * weights_a2[i_a2 + 1]) / w_a2
        levels_a2[i_a2:i_a2+2] = [avg_a2]; weights_a2[i_a2:i_a2+2] = [w_a2]
        i_a2 = max(i_a2 - 1, 0)
    else:
        i_a2 += 1
iso_p_a2 = np.repeat(levels_a2, np.array(weights_a2, dtype=int))
print("Platt slope/intercept:", round(a_a2, 3), round(b_a2, 3))
assert np.all(np.diff(iso_p_a2) >= -1e-12)
```
▶ What you'll see: Platt learns a smooth sigmoid; isotonic learns a monotone staircase.


### Advanced 5 — Decompose predictive uncertainty with an ensemble

**Goal.** Estimate predictive, aleatoric, and epistemic uncertainty for probabilistic classifiers, because different uncertainty sources imply different interventions. We build it in 4 steps.

```python
x_a5 = np.linspace(-3, 3, 120)  # input grid.
params_a5 = [(1.0, -0.4), (1.4, -0.1), (1.8, 0.2), (1.2, 0.35), (1.6, -0.25)]  # ensemble parameter samples.
probs_a5 = np.array([1 / (1 + np.exp(-(a_a5 * x_a5 + b_a5))) for a_a5, b_a5 in params_a5])  # model probabilities.
mean_p_a5 = probs_a5.mean(axis=0)  # predictive mean probability.
print("ensemble members:", probs_a5.shape[0])  # inspect ensemble size.
```
▶ What you'll see: five plausible classifiers produce probabilities on the same grid.

```python
predictive_var_a5 = mean_p_a5 * (1 - mean_p_a5)  # total Bernoulli uncertainty of the averaged prediction.
aleatoric_a5 = np.mean(probs_a5 * (1 - probs_a5), axis=0)  # expected within-model Bernoulli variance.
epistemic_a5 = np.var(probs_a5, axis=0)  # between-model variance.
print("max predictive:", round(float(predictive_var_a5.max()), 3))
print("max aleatoric:", round(float(aleatoric_a5.max()), 3), "max epistemic:", round(float(epistemic_a5.max()), 3))
assert np.allclose(predictive_var_a5, aleatoric_a5 + epistemic_a5, atol=0.03)
```
▶ What you'll see: predictive uncertainty is approximately the sum of aleatoric and epistemic terms.

```python

print("highest-disagreement x:", round(float(x_a5[idx_a5]), 3), "epistemic:", round(float(epistemic_a5[idx_a5]), 3))
```
▶ What you'll see: the largest epistemic uncertainty occurs where ensemble members disagree most.


👀 Takeaway: uncertainty quantification is more useful when it separates irreducible noise from reducible model uncertainty.
