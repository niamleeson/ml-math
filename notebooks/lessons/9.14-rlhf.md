# 9.14 — RLHF

RLHF (reinforcement learning from human feedback) improves a pretrained language policy by rewarding preferred responses while a KL leash keeps the new policy near the reference model. We will use a tiny three-response “text” bandit, but the same quantities appear in real RLHF: preference rewards, advantages, PPO ratios, clipping, and the KL-regularized objective.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build RLHF one idea at a time. Run each cell in order and inspect the printed values — every term in the objective is visible. This walkthrough is self-contained and uses a `_w` suffix so it never clashes with the examples below.

```python
import numpy as np
import matplotlib.pyplot as plt
np.random.seed(0)
```

### 1. A policy is a probability distribution over responses

RLHF starts with a reference policy, not a blank slate. In the toy setting, one prompt has three possible responses: evasive, concise, and overconfident. Logits are unnormalized preferences; softmax turns them into probabilities.

```python
def softmax_w(z_w):
    z_w = np.asarray(z_w, dtype=float)
    e_w = np.exp(z_w - np.max(z_w))
    return e_w / e_w.sum()

responses_w = np.array(["evasive", "concise", "overconfident"])
ref_logits_w = np.array([0.0, 1.0, -0.5])
pi0_w = softmax_w(ref_logits_w)
print(list(zip(responses_w, np.round(pi0_w, 3))))
assert np.allclose(np.round(pi0_w, 3), [0.231, 0.629, 0.140])
```
▶ What you'll see: the reference already prefers concise, but keeps probability on weaker answers.

```python
plt.figure(figsize=(5, 3))
plt.bar(responses_w, pi0_w, color="gray")
plt.ylabel("probability")
plt.ylim(0, 1)
plt.title("1: reference policy π₀")
plt.show()
```
▶ What you'll see: the concise bar is tallest, while evasive and overconfident remain possible.

*Why it's done this way:* Softmax is used because policy learning reallocates probability mass. Raising one response's logit raises its probability and lowers the others through normalization, matching the “choose one continuation” structure of language generation.

### 2. Preferences become a scalar reward model

Humans often compare answers rather than write exact rewards. A reward model can learn from pairs using the Bradley–Terry idea: the probability that A beats B is σ(r(A)−r(B)).

```python
features_w = np.array([[0.1, 0.1], [1.0, 0.2], [0.8, 0.9]])
pairs_w = [(1, 0), (1, 2), (2, 0)]
w_reward_w = np.zeros(2)
print("features: helpfulness, risk")
print(features_w)
```
▶ What you'll see: three responses represented by helpfulness/risk features.

```python
def sigmoid_w(x_w):
    return 1 / (1 + np.exp(-x_w))

losses_rm_w = []
for epoch_w in range(160):
    total_w = 0.0
    for win_w, lose_w in pairs_w:
        diff_w = features_w[win_w] - features_w[lose_w]
        p_w = sigmoid_w(w_reward_w @ diff_w)
        w_reward_w -= 0.3 * (p_w - 1) * diff_w
        total_w += -np.log(p_w + 1e-12)
    losses_rm_w.append(total_w)
rewards_w = features_w @ w_reward_w
print("weights:", np.round(w_reward_w, 3))
print("rewards:", np.round(rewards_w, 3))
assert rewards_w[1] > rewards_w[2] > rewards_w[0]
```
▶ What you'll see: the learned rewards rank concise highest, then overconfident, then evasive.

```python
plt.figure(figsize=(5, 3))
plt.plot(losses_rm_w, color="purple")
plt.xlabel("epoch")
plt.ylabel("pairwise loss")
plt.title("2: reward model learns preferences")
plt.show()
```
▶ What you'll see: the pairwise preference loss decreases.

*Why it's done this way:* The model learns reward gaps, not absolute moral truth. The sigmoid likelihood pushes winner scores above loser scores; later RL will optimize this learned proxy, so reward validation matters.

### 3. The KL-regularized RLHF objective

The core formula is J(θ)=E[r(y)]−β KL(πθ||π0). Reward pulls toward preferred answers; KL charges the policy for moving away from the reference.

```python
def kl_w(p_w, q_w):
    return float(np.sum(p_w * (np.log(p_w + 1e-12) - np.log(q_w + 1e-12))))

new_logits_w = ref_logits_w + np.array([-0.5, 0.4, 1.2])
pi_w = softmax_w(new_logits_w)
exp_reward_w = float(pi_w @ rewards_w)
kl_ref_w = kl_w(pi_w, pi0_w)
print("πθ:", np.round(pi_w, 3))
print("E reward:", round(exp_reward_w, 3), "KL:", round(kl_ref_w, 3))
assert kl_ref_w > 0
```
▶ What you'll see: the new policy gets reward but pays positive KL for drift.

```python
betas_w = np.array([0.0, 0.2, 0.8, 2.0])
objectives_w = exp_reward_w - betas_w * kl_ref_w
print("objectives:", np.round(objectives_w, 3))
plt.figure(figsize=(5, 3))
plt.plot(betas_w, objectives_w, marker="o", color="teal")
plt.xlabel("β")
plt.ylabel("E[r] - βKL")
plt.title("3: beta prices drift")
plt.show()
```
▶ What you'll see: the same policy is less attractive as β increases.

*Why it's done this way:* KL is asymmetric: πθ log(πθ/π0) especially penalizes putting new mass where the reference assigned little. β is therefore a price on behavioral drift: too low invites loopholes, too high freezes learning.

### 4. Advantages center the learning signal

A policy update should reinforce an answer only when it beats the policy's current average. The advantage A=r−b subtracts a baseline b, reducing variance and preventing every positive reward from being treated as equally good.

```python
baseline_w = float(pi_w @ rewards_w)
advantages_w = rewards_w - baseline_w
print("baseline:", round(baseline_w, 3))
print("advantages:", np.round(advantages_w, 3))
assert abs(float(pi_w @ advantages_w)) < 1e-10
```
▶ What you'll see: advantages are positive for above-average responses and policy-weighted mean zero.

```python
chosen_w = 1
grad_logp_w = np.eye(3)[chosen_w] - pi_w
policy_grad_w = advantages_w[chosen_w] * grad_logp_w
print("grad logπ:", np.round(grad_logp_w, 3))
print("advantage-scaled update:", np.round(policy_grad_w, 3))
```
▶ What you'll see: the chosen response logit rises and the alternatives fall.

*Why it's done this way:* For softmax logits, ∇logπ(a)=onehot(a)−π. Multiplying by advantage means better-than-baseline samples increase their probability; worse-than-baseline samples would push the opposite way.

### 5. PPO clipping limits one-step policy movement

PPO compares new and old probabilities with ρ=πθ(a)/πold(a). The clipped term prevents a high-advantage sample from receiving unlimited extra credit after its probability has already moved too far.

```python
old_prob_w = 0.30
new_probs_w = np.array([0.24, 0.30, 0.36, 0.42])
adv_w = 0.5
eps_w = 0.2
ratios_w = new_probs_w / old_prob_w
unclipped_w = ratios_w * adv_w
clipped_w = np.minimum(unclipped_w, np.clip(ratios_w, 1-eps_w, 1+eps_w) * adv_w)
print("ratios:", np.round(ratios_w, 2))
print("clipped terms:", np.round(clipped_w, 3))
assert clipped_w[-1] == 0.6
```
▶ What you'll see: ratio 1.4 receives the same credit as the clipped ratio 1.2.

```python
plt.figure(figsize=(5, 3))
plt.plot(ratios_w, unclipped_w, marker="o", label="ρA")
plt.plot(ratios_w, clipped_w, marker="s", label="clipped")
plt.axvline(1+eps_w, color="gray", linestyle="--")
plt.xlabel("ratio ρ")
plt.ylabel("surrogate term")
plt.title("5: PPO clipping")
plt.legend()
plt.show()
```
▶ What you'll see: the clipped curve flattens beyond the trust-region boundary.

*Why it's done this way:* Clipping is a conservative trust-region approximation. It does not say the response is bad; it says the policy should not get extra objective reward for moving that probability too far in one batch.

### 6. A tiny RLHF loop balances reward and KL

Finally we combine reward, KL shaping, a baseline, and a softmax policy-gradient loop. This is a bandit rather than a language model, but the control loop is the same: improve reward while watching KL.

```python
logits_loop_w = ref_logits_w.copy()
beta_loop_w = 0.8
reward_hist_w, kl_hist_w = [], []
for step_w in range(80):
    p_loop_w = softmax_w(logits_loop_w)
    shaped_w = rewards_w - beta_loop_w * (np.log(p_loop_w + 1e-12) - np.log(pi0_w + 1e-12))
    base_w = float(p_loop_w @ shaped_w)
    grad_w = sum(p_loop_w[a_w] * (shaped_w[a_w] - base_w) * (np.eye(3)[a_w] - p_loop_w) for a_w in range(3))
    logits_loop_w += 0.25 * grad_w
    reward_hist_w.append(float(p_loop_w @ rewards_w))
    kl_hist_w.append(kl_w(p_loop_w, pi0_w))
final_policy_w = softmax_w(logits_loop_w)
print("final policy:", np.round(final_policy_w, 3))
print("reward:", round(reward_hist_w[0], 3), "->", round(reward_hist_w[-1], 3))
assert reward_hist_w[-1] > reward_hist_w[0]
```
▶ What you'll see: reward rises while the policy remains distributed.

```python
fig, ax_w = plt.subplots(1, 2, figsize=(8, 3))
ax_w[0].plot(reward_hist_w, color="seagreen")
ax_w[0].set_title("expected reward")
ax_w[1].plot(kl_hist_w, color="crimson")
ax_w[1].set_title("KL to π₀")
plt.suptitle("6: tiny RLHF dynamics")
plt.show()
```
▶ What you'll see: reward and KL both rise, showing the tradeoff.

*Why it's done this way:* The shaped reward subtracts the local KL price before computing advantages. Monitoring both curves is necessary because reward-only success can hide runaway distribution shift or reward hacking.

## 🛠️ Setup

```python
import numpy as np
import matplotlib.pyplot as plt
np.random.seed(0)

def softmax(z):
    z = np.asarray(z, dtype=float)
    e = np.exp(z - np.max(z))
    return e / e.sum()

def kl_div(p, q):
    p = np.asarray(p, dtype=float)
    q = np.asarray(q, dtype=float)
    return float(np.sum(p * (np.log(p + 1e-12) - np.log(q + 1e-12))))

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def expected_value(p, values):
    return float(np.sum(np.asarray(p) * np.asarray(values)))

def ppo_clip_term(ratio, advantage, eps=0.2):
    unclipped = ratio * advantage
    clipped = np.clip(ratio, 1 - eps, 1 + eps) * advantage
    return float(np.minimum(unclipped, clipped) if advantage >= 0 else np.maximum(unclipped, clipped))
```

## 🟢 Basics (warm-up)

### Basic 1 — Turn logits into a response policy

**Goal.** Convert logits into probabilities, because RLHF changes a policy distribution, not a single label. We build it in 2 steps.

```python
responses_b1 = np.array(["evasive", "concise", "overconfident"])
logits_b1 = np.array([0.0, 1.0, -0.5])
print("logits:", logits_b1)
```
▶ What you'll see: logits are real-valued scores before normalization.

```python
probs_b1 = softmax(logits_b1)
print(list(zip(responses_b1, np.round(probs_b1, 3))))
assert np.allclose(np.round(probs_b1, 3), [0.231, 0.629, 0.140])
plt.figure(figsize=(5,3)); plt.bar(responses_b1, probs_b1, color="steelblue"); plt.ylim(0,1); plt.title("Basic 1: softmax policy"); plt.show()
```
▶ What you'll see: concise has the largest probability but not all the mass.

👀 Takeaway: Softmax makes policy improvement a redistribution of probability mass.

### Basic 2 — Compute expected reward

**Goal.** Average rewards under a policy, because the RL objective scores behavior in expectation. We build it in 2 steps.

```python
probs_b2 = np.array([0.2, 0.6, 0.2])
rewards_b2 = np.array([0.0, 2.0, 1.0])
print("policy:", probs_b2, "rewards:", rewards_b2)
```
▶ What you'll see: the highest-reward answer also has high probability.

▶ What you'll see: the concise response dominates the expected-reward contribution.

👀 Takeaway: Expected reward rises by moving probability toward higher-reward responses.

### Basic 3 — Measure KL drift from a reference

**Goal.** Compute KL(π||π0), because RLHF prices movement away from pretrained behavior. We build it in 2 steps.

```python
pi0_b3 = np.array([0.231, 0.629, 0.140])
pi_b3 = np.array([0.120, 0.500, 0.380])
print("reference:", pi0_b3)
print("new policy:", pi_b3)
```
▶ What you'll see: the new policy puts much more mass on overconfident.

```python

x_b3=np.arange(3); plt.figure(figsize=(5,3)); plt.bar(x_b3-.18, pi0_b3, .36, label="π0", color="gray"); plt.bar(x_b3+.18, pi_b3, .36, label="π", color="crimson"); plt.xticks(x_b3,["evasive","concise","overconfident"]); plt.legend(); plt.title("Basic 3: policy drift"); plt.show()
```
▶ What you'll see: the shifted distribution creates a positive KL cost.

👀 Takeaway: KL is the numeric leash connecting the updated policy to the reference.

### Basic 4 — Price KL with beta

**Goal.** Combine reward and KL, because β decides how expensive policy drift is. We build it in 2 steps.

```python
reward_b4 = 2.0
kl_b4 = 3.0
beta_b4 = 0.1
print("reward, KL, beta:", reward_b4, kl_b4, beta_b4)
```
▶ What you'll see: the objective has a benefit and a drift cost.

```python
betas_b4=np.array([0.0,0.1,0.2,0.4]); plt.figure(figsize=(5,3)); plt.plot(betas_b4, reward_b4-betas_b4*kl_b4, marker="o"); plt.title("Basic 4: beta prices KL"); plt.xlabel("β"); plt.ylabel("reward - βKL"); plt.show()
```
▶ What you'll see: the same reward is worth less as β increases.

👀 Takeaway: β is a behavior knob: low β chases reward; high β preserves the reference.

### Basic 5 — Center rewards into advantages

**Goal.** Subtract a baseline, because policy gradients should reinforce better-than-average samples. We build it in 2 steps.

```python
probs_b5 = np.array([0.2, 0.6, 0.2])
rewards_b5 = np.array([0.0, 2.0, 1.0])
```

### Basic 6 — Compute a policy-gradient direction

**Goal.** Use ∇logπ(a), because logits move according to sampled response advantage. We build it in 2 steps.

```python
probs_b6 = np.array([0.2, 0.6, 0.2])
chosen_b6 = 1
adv_b6 = 0.6
print("chosen:", chosen_b6, "advantage:", adv_b6)
```
▶ What you'll see: the concise sample is better than baseline.

```python

plt.figure(figsize=(5,3)); plt.bar(["evasive","concise","overconfident"], update_b6, color=["gray","green","gray"]); plt.axhline(0,color="black"); plt.title("Basic 6: advantage × ∇logπ"); plt.show()
```
▶ What you'll see: the chosen logit rises and alternatives fall.

👀 Takeaway: A positive advantage raises the sampled response relative to the rest of the distribution.

### Basic 7 — Clip a PPO ratio

**Goal.** Apply PPO clipping, because a single update should not get extra credit after moving too far. We build it in 2 steps.

### Basic 8 — Add a per-action KL penalty

**Goal.** Subtract β(logπ−logπ0), because KL can be shaped into the reward signal. We build it in 2 steps.

```python
pi0_b8 = np.array([0.231, 0.629, 0.140])
```

### Basic 9 — Compare low and high beta policies

**Goal.** Run the same update with two β values, because β controls drift. We build it in 2 steps.

```python
ref_logits_b9 = np.array([0.0, 1.0, -0.5])
pi0_b9 = softmax(ref_logits_b9)
rewards_b9 = np.array([0.0, 2.0, 1.0])
betas_b9 = [0.05, 2.0]

```
▶ What you'll see: both runs start from the same policy.

```python
finals_b9=[]
for beta_loop_b9 in betas_b9:
    logits_loop_b9 = ref_logits_b9.copy()
```

👀 Takeaway: The KL coefficient is a first-order RLHF hyperparameter.

### Easy 2 — Optimize the KL-regularized objective exactly

**Goal.** Build a slightly larger RLHF calculation from the warm-up pieces. We build it in 2 steps.

```python
ref_logits_e2=np.array([0.0,1.0,-0.5])
pi0_e2=softmax(ref_logits_e2)
rewards_e2=np.array([0.0,2.0,1.0])
```
