# 4.21 — Manifold Learning

Manifold learning turns high-dimensional unlabeled data into lower-dimensional coordinates by replacing “what label is this?” with “which points are close, connected, or locally explainable?” In this lesson, you will build neighborhood graphs, Laplacians, Isomap, MDS, LLE, and Laplacian eigenmaps from scratch with NumPy, while treating every embedding as a lens whose behavior depends on distances, scaling, and graph choices.

### 1. Neighborhood graphs: turning geometry into edges

Manifold methods usually start by deciding which points are allowed to influence each other. Raw Euclidean distance sees every pair, but a manifold method often keeps only **local neighbors** so the graph follows the curved surface rather than cutting straight across it. The first object is therefore an affinity matrix $A$: $A_{ij}>0$ means point $i$ is connected to point $j$, and $A_{ij}=0$ means the method pretends those points are not directly comparable.

```python
X_w = np.array([[0.0, 0.0], [0.2, 0.1], [1.0, 0.0], [1.2, 0.1], [4.0, 0.0], [4.2, 0.1]])  # two nearby pairs plus a far pair.
labels_w = [f"p{i}" for i in range(len(X_w))]  # readable point names.
diff_w = X_w[:, None, :] - X_w[None, :, :]  # all pairwise coordinate differences.
D_w = np.sqrt(np.sum(diff_w ** 2, axis=2))  # Euclidean distance matrix.
print("distance matrix:\n", np.round(D_w, 3))  # inspect the geometry before graph construction.
assert D_w.shape == (6, 6)  # six points produce a 6x6 pairwise matrix.
```
▶ What you'll see: within-pair distances are about 0.224, while the gap between the middle and right groups is much larger.

```python
k_w = 1  # keep the single nearest neighbor of each point.
A_directed_w = np.zeros_like(D_w)  # start with no directed edges.
for i_w in range(len(X_w)):  # choose neighbors for each point independently.
    order_w = np.argsort(D_w[i_w] + np.eye(len(X_w))[i_w] * 999)  # put self last by adding a huge self distance.
    A_directed_w[i_w, order_w[:k_w]] = 1.0  # connect to the nearest non-self point.
A_w = np.maximum(A_directed_w, A_directed_w.T)  # symmetrize so the graph is undirected.
print("1-neighbor affinity A:\n", A_w.astype(int))  # inspect graph edges as 0/1.
assert int(A_w.sum() / 2) == 3  # three undirected edges: (0,1), (2,3), (4,5).
```
▶ What you'll see: each close pair becomes an edge, but the three pairs are disconnected from one another.

```python
plt.figure(figsize=(5, 2.8))  # compact geometry plot.
plt.scatter(X_w[:, 0], X_w[:, 1], s=80, color="teal")  # draw points.
for i_w, name_w in enumerate(labels_w):  # label each point.
    plt.text(X_w[i_w, 0] + 0.03, X_w[i_w, 1] + 0.03, name_w)  # point labels.
for i_w in range(len(X_w)):  # draw each undirected edge once.
    for j_w in range(i_w + 1, len(X_w)):
        if A_w[i_w, j_w] > 0:
            plt.plot([X_w[i_w, 0], X_w[j_w, 0]], [X_w[i_w, 1], X_w[j_w, 1]], color="gray", linewidth=2)
plt.title("1: local edges define the manifold lens"); plt.axis("equal"); plt.show()
```
▶ What you'll see: the graph follows only local pair links; it deliberately ignores long straight-line jumps.

*Why it's done this way:* local edges are the modeling assumption. If the manifold is curved, a far Euclidean shortcut can jump across empty space and destroy the intrinsic geometry. Keeping only nearest neighbors says “trust tiny moves, then build global structure from many tiny moves.”

### 2. The graph Laplacian: connected components and smooth coordinates

Once we have an affinity graph, we summarize it with the degree matrix $D$ and Laplacian $L=D-A$. The degree $D_{ii}=\sum_j A_{ij}$ counts how much point $i$ is connected. The Laplacian quadratic form $z^\top Lz=\frac12\sum_{ij}A_{ij}(z_i-z_j)^2$ is small when connected points receive similar coordinates, so its eigenvectors become smooth graph coordinates. A zero eigenvalue means a coordinate can be constant on a connected component without paying any edge penalty.

```python
deg_w = A_w.sum(axis=1)  # degree of every node.
Deg_w = np.diag(deg_w)  # diagonal degree matrix.
L_w = Deg_w - A_w  # unnormalized graph Laplacian.
print("degrees:", deg_w.astype(int))  # each node has one neighbor in this toy graph.
print("L:\n", L_w.astype(int))  # inspect D - A.
assert np.all(deg_w == 1)  # matches the lesson's tiny numeric pass.
```
▶ What you'll see: degrees are `[1, 1, 1, 1, 1, 1]`, and each edge creates a `[[1,-1],[-1,1]]` block.

```python
evals_w, evecs_w = np.linalg.eigh(L_w)  # symmetric eigendecomposition.
print("eigenvalues:", np.round(evals_w, 3))  # inspect graph frequencies.
zero_count_w = int(np.sum(np.isclose(evals_w, 0.0)))  # number of connected components.
print("zero eigenvalues:", zero_count_w)  # disconnected pairs each contribute one zero.
assert zero_count_w == 3  # this graph has three components.
```
▶ What you'll see: three eigenvalues are zero, exactly matching the three disconnected components.

```python
z_w = np.array([0., 0., 1., 1., 3., 3.])  # a coordinate that is constant inside each connected pair.
energy_w = float(z_w @ L_w @ z_w)  # graph smoothness penalty.
print("smoothness energy:", round(energy_w, 3))  # no edge connects different values.
assert round(energy_w, 3) == 0.0  # constant-on-component coordinates are free.
plt.figure(figsize=(5, 2.8)); plt.scatter(X_w[:, 0], X_w[:, 1], c=z_w, s=100, cmap="viridis")
plt.colorbar(label="coordinate z"); plt.title("2: Laplacian allows constants on components"); plt.axis("equal"); plt.show()
```
▶ What you'll see: each connected pair has one color, and the graph pays zero smoothness cost for differences across missing edges.

*Why it's done this way:* $L=D-A$ encodes “neighbors should not be assigned wildly different coordinates.” Eigenvectors with the smallest nonzero eigenvalues are the smoothest nontrivial coordinates, while the multiplicity of zero eigenvalues audits graph connectivity before any embedding is trusted.

### 3. Isomap: replace straight distances with graph geodesics

Isomap keeps the local-neighbor graph but changes the distance used for embedding. Instead of the straight Euclidean distance between far points, it uses the **shortest path distance through the graph** — an approximation to distance along the manifold. The key idea is: local Euclidean distances are reliable, global Euclidean distances may cut across the curve, so global distance should be assembled from local steps.

```python
t_w = np.linspace(0, np.pi, 8)  # parameter along a curved half-circle.
curve_w = np.c_[np.cos(t_w), np.sin(t_w)]  # 2D curved manifold sample.
E_w = np.sqrt(np.sum((curve_w[:, None, :] - curve_w[None, :, :]) ** 2, axis=2))  # straight distances.
G_w = np.full_like(E_w, np.inf)  # graph distances start as infinity.
np.fill_diagonal(G_w, 0.0)  # zero distance from a point to itself.
for i_w in range(len(curve_w) - 1):  # connect only consecutive curve samples.
    G_w[i_w, i_w + 1] = E_w[i_w, i_w + 1]  # local edge length.
    G_w[i_w + 1, i_w] = E_w[i_w, i_w + 1]  # undirected edge.
print("straight end-to-end:", round(E_w[0, -1], 3))  # chord length across the semicircle.
print("one local step:", round(G_w[0, 1], 3))  # trusted neighbor distance.
assert round(E_w[0, -1], 3) == 2.0  # chord across unit semicircle.
```
▶ What you'll see: the two ends are only distance 2 by chord, even though the path along the arc is about π.

```python
Geo_w = G_w.copy()  # Floyd-Warshall shortest paths over local edges.
for k2_w in range(len(curve_w)):  # allow each node as an intermediate waypoint.
    Geo_w = np.minimum(Geo_w, Geo_w[:, [k2_w]] + Geo_w[[k2_w], :])  # vectorized relaxation.
print("geodesic end-to-end:", round(Geo_w[0, -1], 3))  # sum of local chords along the curve.
assert round(Geo_w[0, -1], 3) == 3.115  # close to pi with 7 chord steps.
```
▶ What you'll see: graph distance from one end to the other is about 3.115, much closer to arc length than the chord.

```python
n_w = len(curve_w)  # number of points.
J_w = np.eye(n_w) - np.ones((n_w, n_w)) / n_w  # centering matrix for classical MDS.
B_w = -0.5 * J_w @ (Geo_w ** 2) @ J_w  # inner-product matrix implied by distances.
evals_iso_w, evecs_iso_w = np.linalg.eigh(B_w)  # recover coordinates from distances.
idx_w = np.argsort(evals_iso_w)[::-1]  # largest eigenvalues first.
z_iso_w = evecs_iso_w[:, idx_w[0]] * np.sqrt(evals_iso_w[idx_w[0]])  # 1D Isomap coordinate.
print("Isomap coordinate order:", np.round(z_iso_w, 3))  # should progress along the curve.
plt.figure(figsize=(5, 2.8)); plt.scatter(z_iso_w, np.zeros_like(z_iso_w), c=t_w, cmap="plasma", s=90)
plt.title("3: Isomap unwraps the curve into one coordinate"); plt.yticks([]); plt.show()
```
▶ What you'll see: points arrange in a line in the same order as their position along the semicircle.

*Why it's done this way:* shortest paths turn many trustworthy local measurements into one global intrinsic distance. Classical MDS then finds coordinates whose squared distances best match those graph geodesics, so the final embedding preserves “distance along the manifold,” not the shortcut through ambient space.

### 4. Locally Linear Embedding: preserve reconstruction weights

LLE uses a different invariant: a point should be reconstructable from its local neighbors with the same weights before and after embedding. For one point $x_i$, it solves weights $w$ so $x_i\approx\sum_j w_jx_j$ and $\sum_jw_j=1$. The sum-to-one constraint makes the weights translation-invariant: shifting every coordinate by the same vector does not change the local recipe.

```python
X_lle_w = np.array([[0.0, 0.0], [1.0, 0.0], [0.5, 0.8], [0.5, 0.25]])  # triangle plus an interior point.
target_w = X_lle_w[3]  # interior point to reconstruct.
neigh_w = X_lle_w[:3]  # use the triangle vertices as neighbors.
Z_lle_w = neigh_w - target_w  # local coordinates relative to target.
C_w = Z_lle_w @ Z_lle_w.T  # local covariance Gram matrix.
C_w += 1e-3 * np.trace(C_w) * np.eye(3)  # tiny ridge for stable inverse.
ones_w = np.ones(3)  # sum-to-one constraint vector.
w_raw_w = np.linalg.solve(C_w, ones_w)  # unconstrained solve proportional to weights.
w_lle_w = w_raw_w / w_raw_w.sum()  # normalize weights to sum to one.
print("LLE weights:", np.round(w_lle_w, 3), "sum:", round(w_lle_w.sum(), 3))  # inspect local recipe.
assert round(float(w_lle_w.sum()), 3) == 1.0  # affine weights must sum to one.
```
▶ What you'll see: the weights add to 1 and express the interior point as a local mixture of triangle vertices.

```python
recon_w = w_lle_w @ neigh_w  # reconstruct target from neighbor weights.
err_lle_w = float(np.linalg.norm(target_w - recon_w))  # reconstruction error.
print("reconstruction:", np.round(recon_w, 3), "target:", target_w)  # compare predicted point to target.
print("reconstruction error:", round(err_lle_w, 4))  # tiny when local linearity holds.
assert err_lle_w < 0.02  # local triangle explains the interior point well.
```
▶ What you'll see: the reconstructed point is almost the same as the target.

```python
shift_w = np.array([10.0, -3.0])  # translate the whole neighborhood.
neigh_shift_w = neigh_w + shift_w  # shifted neighbors.
target_shift_w = target_w + shift_w  # shifted target.
recon_shift_w = w_lle_w @ neigh_shift_w  # same weights after translation.
print("shifted reconstruction error:", round(float(np.linalg.norm(target_shift_w - recon_shift_w)), 4))
plt.figure(figsize=(4, 3)); plt.scatter(neigh_w[:, 0], neigh_w[:, 1], s=90, color="gray", label="neighbors")
plt.scatter([target_w[0]], [target_w[1]], s=100, color="crimson", label="target")
plt.scatter([recon_w[0]], [recon_w[1]], s=80, color="teal", marker="x", label="recon")
plt.legend(); plt.axis("equal"); plt.title("4: LLE preserves a local recipe"); plt.show()
```
▶ What you'll see: the target and reconstruction nearly overlap; translation would not change the recipe.

*Why it's done this way:* LLE assumes small neighborhoods are almost flat even if the whole manifold is curved. Preserving affine reconstruction weights keeps those local flat patches stitched together in the low-dimensional embedding without directly preserving every pairwise distance.

### 5. Laplacian eigenmaps: coordinates that vary slowly over the graph

Laplacian eigenmaps choose coordinates by minimizing $\sum_{ij}A_{ij}(z_i-z_j)^2$ subject to constraints that prevent the trivial all-constant answer. The smallest eigenvector is constant; the next eigenvectors are the smoothest nonconstant ways to color the graph. On a connected chain, the first nontrivial eigenvector behaves like a gentle left-to-right coordinate.

```python
n_chain_w = 8  # points in a simple path graph.
A_chain_w = np.zeros((n_chain_w, n_chain_w))  # adjacency matrix for a chain.
for i_w in range(n_chain_w - 1):  # connect consecutive nodes.
    A_chain_w[i_w, i_w + 1] = 1.0  # edge forward.
    A_chain_w[i_w + 1, i_w] = 1.0  # edge backward.
D_chain_w = np.diag(A_chain_w.sum(axis=1))  # degree matrix.
L_chain_w = D_chain_w - A_chain_w  # graph Laplacian.
evals_chain_w, evecs_chain_w = np.linalg.eigh(L_chain_w)  # Laplacian spectrum.
print("first eigenvalues:", np.round(evals_chain_w[:4], 3))  # graph frequencies from smooth to wiggly.
assert round(float(evals_chain_w[0]), 3) == 0.0  # connected graph has one zero eigenvalue.
```
▶ What you'll see: one zero eigenvalue, then increasing graph frequencies.

```python
coord_chain_w = evecs_chain_w[:, 1]  # first nonconstant smooth coordinate.
if coord_chain_w[0] > coord_chain_w[-1]:  # flip sign for readable left-to-right order.
    coord_chain_w = -coord_chain_w
energy_chain_w = float(coord_chain_w @ L_chain_w @ coord_chain_w)  # smoothness of this coordinate.
print("embedding coordinate:", np.round(coord_chain_w, 3))  # slowly varying over the chain.
print("energy equals eigenvalue:", round(energy_chain_w, 3), round(float(evals_chain_w[1]), 3))  # eigenvector property.
assert abs(energy_chain_w - evals_chain_w[1]) < 1e-10  # normalized eigenvector energy equals lambda.
```
▶ What you'll see: the coordinate changes gradually from one end of the chain to the other.

```python
plt.figure(figsize=(5, 2.8))  # plot the graph embedding.
plt.plot(np.arange(n_chain_w), coord_chain_w, marker="o", color="seagreen")  # coordinate by graph position.
plt.title("5: first nontrivial Laplacian eigenmap coordinate")
plt.xlabel("node along chain"); plt.ylabel("embedding z"); plt.show()
```
▶ What you'll see: a smooth wave rather than arbitrary labels; nearby graph nodes get nearby coordinate values.

*Why it's done this way:* the eigenproblem converts “make neighbors close” into linear algebra. The constant eigenvector is useless for embedding because it gives every point the same coordinate, so the first nonzero eigenvectors are the lowest-energy nontrivial summaries of graph geometry.

### 6. Scaling and stability: the lens is not an oracle

Every manifold method depends on the numeric geometry it receives. If one feature has a much larger unit, Euclidean distances and neighbor graphs can be dominated by that feature. Scaling is therefore not cosmetic; it changes the graph, the Laplacian, and the embedding. Stability checks ask whether small choices like neighbor count or feature scale change the story.

```python
X_scale_w = np.array([[0.0, 0.0], [0.1, 100.0], [0.2, 200.0], [2.0, 210.0]])  # second feature has huge units.
D_raw_w = np.sqrt(np.sum((X_scale_w[:, None, :] - X_scale_w[None, :, :]) ** 2, axis=2))  # raw distances.
X_std_w = (X_scale_w - X_scale_w.mean(axis=0)) / X_scale_w.std(axis=0)  # standardize columns.
D_std_w = np.sqrt(np.sum((X_std_w[:, None, :] - X_std_w[None, :, :]) ** 2, axis=2))  # scaled distances.
print("raw nearest to p0:", int(np.argsort(D_raw_w[0] + np.array([999,0,0,0]))[0]))  # neighbor by raw units.
print("scaled nearest to p0:", int(np.argsort(D_std_w[0] + np.array([999,0,0,0]))[0]))  # neighbor after scaling.
```
▶ What you'll see: nearest-neighbor choices can change once each feature has comparable scale.

```python
raw_span_w = float(D_raw_w[0, 2] / D_raw_w[0, 1])  # how raw distances grow along giant feature.
std_span_w = float(D_std_w[0, 2] / D_std_w[0, 1])  # same comparison after scaling.
print("distance ratio raw:", round(raw_span_w, 3), "scaled:", round(std_span_w, 3))  # inspect scale effect.
assert raw_span_w > 1.9  # raw units are dominated by the large second coordinate.
```
▶ What you'll see: the raw ratio mostly mirrors the 100-vs-200 unit jump, while scaled geometry balances both columns.

```python
plt.figure(figsize=(5, 2.8))
plt.subplot(1, 2, 1); plt.imshow(D_raw_w, cmap="magma"); plt.title("raw distances"); plt.colorbar(fraction=0.046)
plt.subplot(1, 2, 2); plt.imshow(D_std_w, cmap="magma"); plt.title("standardized distances"); plt.colorbar(fraction=0.046)
plt.suptitle("6: scaling changes the graph lens"); plt.tight_layout(); plt.show()
```
▶ What you'll see: the distance heatmaps have different contrast patterns, meaning the downstream graph would also differ.

*Why it's done this way:* unsupervised methods optimize their own criterion, not a hidden truth. Scaling, neighbor count, and graph construction define that criterion, so a responsible workflow audits whether the discovered structure survives reasonable changes to the lens.

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, distances, eigendecompositions, and numerical checks.
import matplotlib.pyplot as plt # load Matplotlib for heatmaps, scatter plots, graph drawings, and learning curves.
np.random.seed(0) # make all random examples reproducible across notebook runs.

def pairwise_dist(X): # compute a Euclidean distance matrix for rows of X.
    X = np.asarray(X, dtype=float) # ensure predictable floating-point arithmetic.
    diff = X[:, None, :] - X[None, :, :] # subtract every point from every other point.
    return np.sqrt(np.sum(diff ** 2, axis=2)) # convert squared coordinate gaps into Euclidean distances.

def knn_affinity(X, k=2, weighted=False, sigma=1.0): # build a symmetric k-nearest-neighbor affinity graph.
    D = pairwise_dist(X) # compute all pairwise distances.
    n = D.shape[0] # number of points.
    A = np.zeros((n, n), dtype=float) # start with no edges.
    for i in range(n): # choose neighbors separately for each point.
        order = np.argsort(D[i] + np.eye(n)[i] * 1e9) # sort non-self points by distance.
        for j in order[:k]: # keep k nearest non-self neighbors.
            A[i, j] = np.exp(-(D[i, j] ** 2) / (2 * sigma ** 2)) if weighted else 1.0 # binary or heat-kernel edge.
    return np.maximum(A, A.T) # symmetrize so influence is mutual.

def laplacian(A): # compute the unnormalized graph Laplacian L = D - A.
    degrees = A.sum(axis=1) # degree is total affinity touching each point.
    return np.diag(degrees) - A # subtract affinities from the degree matrix.

def shortest_paths(W): # Floyd-Warshall shortest paths for a dense weighted graph with inf for missing edges.
    G = W.copy() # avoid modifying the caller's matrix.
    for k in range(G.shape[0]): # try every node as an intermediate waypoint.
        G = np.minimum(G, G[:, [k]] + G[[k], :]) # relax all i->j paths through k.
    return G # return graph geodesic distances.

def classical_mds(D, r=2): # recover r-dimensional coordinates from a distance matrix.
    n = D.shape[0] # number of objects.
    J = np.eye(n) - np.ones((n, n)) / n # centering matrix removes translation.
    B = -0.5 * J @ (D ** 2) @ J # convert squared distances into centered inner products.
    vals, vecs = np.linalg.eigh(B) # symmetric eigendecomposition.
    idx = np.argsort(vals)[::-1] # sort from largest variance to smallest.
    vals = np.maximum(vals[idx[:r]], 0) # keep nonnegative leading eigenvalues.
    vecs = vecs[:, idx[:r]] # keep matching eigenvectors.
    return vecs * np.sqrt(vals) # scale eigenvectors to coordinates.

def standardize(X): # z-score columns so distance is not dominated by units.
    X = np.asarray(X, dtype=float) # ensure float arithmetic.
    return (X - X.mean(axis=0)) / X.std(axis=0) # subtract mean and divide by column standard deviation.
```
▶ What you'll see: the printed values expose the current calculation, and any plot makes the geometry or matrix pattern visible for inspection.

### Basic 3 — Convert distances into heat-kernel affinities

**Goal.** Use soft edge weights instead of only 0/1 edges, because closer neighbors can be allowed to influence each other more strongly. We build it in 2 steps.

```python
X_b3 = np.array([[0.0], [0.5], [1.5]]) # three points on a line.
sigma_b3 = 1.0 # heat-kernel width controlling how fast affinity decays.
D_b3 = pairwise_dist(X_b3) # compute distances before weighting.
print("distances from p0:", np.round(D_b3[0], 3)) # inspect distance scale.
```
▶ What you'll see: the printed values expose the current calculation, and any plot makes the geometry or matrix pattern visible for inspection.

```python
A_b3 = np.exp(-(D_b3 ** 2) / (2 * sigma_b3 ** 2)) # compute Gaussian affinities for every pair.
np.fill_diagonal(A_b3, 0.0) # remove self-loops for graph learning.
print("A_b3:\n", np.round(A_b3, 3)) # inspect soft similarities.
```
