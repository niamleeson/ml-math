# 5.23 — Latent Dirichlet Allocation

Latent Dirichlet Allocation (LDA) discovers hidden themes in discrete documents by assuming each document mixes topics and each topic mixes words. In this lesson, we build the model from scratch with NumPy: Dirichlet priors, document-topic mixtures, topic-word mixtures, topic assignments, Gibbs-style local updates, and predictive word probabilities.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build LDA one idea at a time. Run each cell in order and read the printed intermediate values — every probability is normalized in the open so the latent-variable story is never a black box. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, random draws, counts, and normalization.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for Dirichlet and categorical draws.
```

### 1. Documents as bags of words

LDA starts by making a deliberate simplification: a document is represented by word counts, not word order. This is the exchangeability assumption. It says that `bank loan bank` and `loan bank bank` carry the same topic evidence because the co-occurrence pattern matters more than position for this model.

```python
vocab_w = np.array(["loan", "bank", "team", "score", "recipe", "flour"])  # six-word toy vocabulary.
docs_tokens_w = [["loan", "bank", "loan", "bank", "score"],
                 ["team", "score", "team", "score", "bank"],
                 ["recipe", "flour", "recipe", "flour", "bank"]]  # three short documents.
word_to_id_w = {word: i for i, word in enumerate(vocab_w)}  # map words to columns.
print("vocabulary:", vocab_w)  # inspect the fixed vocabulary.
print("doc 0 tokens:", docs_tokens_w[0])  # inspect one ordered document before bagging.
```
▶ What you'll see: a tiny corpus where finance, sports, and cooking words co-occur but order has not yet been used.

```python
X_w = np.zeros((len(docs_tokens_w), len(vocab_w)), dtype=int)  # rows are documents, columns are vocabulary words.
for d_w, tokens_w in enumerate(docs_tokens_w):  # loop over documents.
    for token_w in tokens_w:  # loop over tokens inside the document.
        X_w[d_w, word_to_id_w[token_w]] += 1  # add one count to the token's column.
print("document-word counts:\n", X_w)  # inspect the bag-of-words representation.
assert X_w[0, word_to_id_w["loan"]] == 2 and X_w[2, word_to_id_w["flour"]] == 2  # concrete counts.
```
▶ What you'll see: each document becomes one count vector; repeated words increase evidence for their columns.

```python
plt.figure(figsize=(5, 3))  # create a compact count heatmap.
plt.imshow(X_w, cmap="viridis", aspect="auto")  # visualize count strength by color.
plt.colorbar(label="count")  # add a count scale.
plt.xticks(range(len(vocab_w)), vocab_w, rotation=35)  # label word columns.
plt.yticks(range(3), ["doc0", "doc1", "doc2"])  # label documents.
plt.title("1: bag-of-words document matrix"); plt.show()  # show the matrix.
```
▶ What you'll see: co-occurrence blocks appear as brighter word columns within each document.

*Why it's done this way:* LDA is a model for discrete counts. Ignoring order turns a variable-length sentence into a fixed vocabulary vector, so the inference problem can focus on which words tend to appear together rather than where they appear.

### 2. Dirichlet priors create probability mixtures

A topic mixture must be nonnegative and sum to 1, so LDA uses a Dirichlet prior. The parameter `alpha` acts like pseudocounts before observing words: small values prefer sparse documents dominated by one topic, while large values prefer diffuse documents that spread mass across topics.

```python
alpha_sparse_w = np.array([0.2, 0.2, 0.2])  # small concentration: peaky mixtures.
alpha_diffuse_w = np.array([5.0, 5.0, 5.0])  # large concentration: balanced mixtures.
sparse_draws_w = np.random.dirichlet(alpha_sparse_w, size=5)  # sample five sparse topic mixtures.
diffuse_draws_w = np.random.dirichlet(alpha_diffuse_w, size=5)  # sample five diffuse topic mixtures.
print("sparse draws:\n", np.round(sparse_draws_w, 3))  # inspect peaky mixtures.
print("diffuse draws:\n", np.round(diffuse_draws_w, 3))  # inspect balanced mixtures.
assert np.allclose(sparse_draws_w.sum(axis=1), 1.0) and np.allclose(diffuse_draws_w.sum(axis=1), 1.0)  # mixtures sum to one.
```
▶ What you'll see: both rows sum to 1, but small-alpha rows usually put most mass on one topic.

```python
plt.figure(figsize=(5, 3))  # create a side-by-side bar view.
plt.bar(np.arange(3) - 0.18, sparse_draws_w[0], width=0.36, label="alpha=0.2")  # plot one sparse draw.
plt.bar(np.arange(3) + 0.18, diffuse_draws_w[0], width=0.36, label="alpha=5")  # plot one diffuse draw.
plt.xticks(range(3), ["topic0", "topic1", "topic2"])  # label topics.
plt.ylabel("probability"); plt.title("2: Dirichlet topic-mixture draws"); plt.legend(); plt.show()  # render.
```
▶ What you'll see: the sparse mixture usually has one tall bar; the diffuse mixture is more even.

*Why it's done this way:* The Dirichlet is conjugate to categorical counts. Adding observed topic counts to `alpha` gives a posterior-like normalized mixture, so prior belief and data evidence combine as simple count addition.

### 3. Topic-word distributions are Dirichlet rows

Each topic is also a probability distribution, now over words. LDA draws each topic row `phi_k` from a Dirichlet with parameter `eta`; after observing topic-word counts, counts plus `eta` normalize into a word distribution for that topic.

```python
topic_word_counts_w = np.array([[7, 5, 1, 1, 0, 0],
                                [0, 1, 6, 7, 0, 0],
                                [0, 1, 0, 0, 6, 7]], dtype=float)  # K x V counts.
eta_w = 0.1  # symmetric word pseudocount.
phi_w = (topic_word_counts_w + eta_w) / (topic_word_counts_w + eta_w).sum(axis=1, keepdims=True)  # normalize rows.
print("topic-word probabilities:\n", np.round(phi_w, 3))  # inspect word probabilities per topic.
assert np.allclose(phi_w.sum(axis=1), 1.0)  # each topic is a distribution over words.
```
▶ What you'll see: topic 0 favors loan/bank, topic 1 favors team/score, and topic 2 favors recipe/flour.

```python
plt.figure(figsize=(6, 3))  # create one heatmap for all topic rows.
plt.imshow(phi_w, cmap="magma", aspect="auto")  # color = word probability.
plt.colorbar(label="p(word | topic)")  # probability scale.
plt.xticks(range(len(vocab_w)), vocab_w, rotation=35)  # word labels.
plt.yticks(range(3), ["topic0", "topic1", "topic2"])  # topic labels.
plt.title("3: topics are word distributions"); plt.show()  # render.
```
▶ What you'll see: each row has a few bright words, making topics readable as probability vectors.

*Why it's done this way:* Counts alone would assign zero probability to unseen words. The `eta` pseudocount smooths every word so future documents can still generate words not yet seen under a topic.

### 4. Document-topic mixtures come from counts plus alpha

If a document currently assigns 8 tokens to topic 0 and 2 tokens to topic 1, the document-topic mean is counts plus `alpha`, normalized. With `alpha=[0.5,0.5]`, the arithmetic is `[8.5, 2.5] / 11 = [0.772727, 0.227273]`.

```python
doc_topic_counts_w = np.array([8.0, 2.0])  # current topic counts in one document.
alpha_w = np.array([0.5, 0.5])  # symmetric document-topic pseudocounts.
theta_mean_w = (doc_topic_counts_w + alpha_w) / np.sum(doc_topic_counts_w + alpha_w)  # normalize counts plus prior.
print("theta mean:", np.round(theta_mean_w, 6))  # inspect the worked arithmetic.
assert np.allclose(theta_mean_w, [0.77272727, 0.22727273])  # exact lesson number.
```
▶ What you'll see: the first topic dominates but the second topic keeps nonzero mass because of the prior.

```python
plt.figure(figsize=(4, 3))  # create a compact mixture chart.
plt.bar(["topic0", "topic1"], theta_mean_w, color=["steelblue", "orange"])  # show normalized topic probabilities.
plt.ylim(0, 1); plt.ylabel("p(topic | document)")  # probability scale.
plt.title("4: counts + alpha -> theta"); plt.show()  # render.
```
▶ What you'll see: topic 0 gets about 77% of the document, topic 1 about 23%.

*Why it's done this way:* Normalization turns local evidence into a probability statement. Adding `alpha` before normalizing prevents a document from becoming absolutely certain just because a small sample currently lacks a topic.

### 5. The LDA generative story and joint probability

The model says: draw topic-word rows `phi`, draw a document mixture `theta_d`, choose a topic `z_dn` for each token, then choose a word `w_dn` from that topic's word row. The joint probability factorizes into those local choices.

```python
theta_demo_w = np.array([0.7, 0.3])  # one document's topic mixture.
phi_demo_w = np.array([[0.6, 0.3, 0.1],
                       [0.1, 0.2, 0.7]])  # two topics over three words.
z_seq_w = np.array([0, 0, 1, 1])  # chosen latent topics for four tokens.
w_seq_w = np.array([0, 1, 2, 2])  # observed word ids for four tokens.
local_probs_w = np.array([theta_demo_w[z_seq_w[n]] * phi_demo_w[z_seq_w[n], w_seq_w[n]] for n in range(len(z_seq_w))])  # token factors.
print("local p(z)*p(w|z):", np.round(local_probs_w, 3))  # inspect each token contribution.
print("token joint product:", round(float(np.prod(local_probs_w)), 6))  # multiply local factors.
assert round(float(np.prod(local_probs_w)), 6) == 0.00389  # concrete joint contribution.
```
▶ What you'll see: each token contributes one topic-choice probability times one word-choice probability.

```python
plt.figure(figsize=(5, 3))  # create a diagnostic bar chart.
plt.bar(range(len(local_probs_w)), local_probs_w, color="teal")  # one factor per token.
plt.xlabel("token position"); plt.ylabel("local probability")  # label factor scale.
plt.title("5: token factors in the LDA joint"); plt.show()  # render.
```
▶ What you'll see: the joint product is small because probabilities multiply across tokens.

*Why it's done this way:* The factorization encodes conditional independence: once the topic assignment is known, the word depends on the topic-word row, not directly on neighboring token positions.

### 6. Gibbs-style reassignment uses document and topic evidence

Collapsed Gibbs sampling updates one token's topic by comparing local scores. The score for topic `k` is proportional to `(document-topic count + alpha_k) × (topic-word probability for the token word)`. The first term asks whether this document likes topic `k`; the second asks whether topic `k` likes this word.

```python
doc_counts_minus_w = np.array([3.0, 1.0, 0.0])  # topic counts in the document excluding the current token.
phi_word_w = np.array([0.05, 0.60, 0.10])  # p(current word | each topic).
alpha_gibbs_w = np.array([0.5, 0.5, 0.5])  # document-topic prior.
raw_scores_w = (doc_counts_minus_w + alpha_gibbs_w) * phi_word_w  # local Gibbs scores.
cond_w = raw_scores_w / raw_scores_w.sum()  # normalize scores into probabilities.
print("raw scores:", np.round(raw_scores_w, 3))  # inspect unnormalized evidence.
print("conditional:", np.round(cond_w, 3))  # inspect normalized assignment probabilities.
assert np.allclose(np.round(cond_w, 3), [0.156, 0.800, 0.044])  # lesson-style local numbers.
```
▶ What you'll see: topic 1 wins because it strongly explains the current word despite fewer document counts.

```python
plt.figure(figsize=(4.5, 3))  # create a topic-reassignment chart.
plt.bar(["topic0", "topic1", "topic2"], cond_w, color="purple")  # show normalized Gibbs probabilities.
plt.ylabel("p(z=current topic | rest)"); plt.title("6: Gibbs conditional"); plt.show()  # render.
```
▶ What you'll see: the tallest bar is the topic with the best product of document evidence and word evidence.

*Why it's done this way:* Multiplication forces agreement between two explanations. A topic should be plausible for the document and plausible for the word; normalization then converts comparable scores into a categorical distribution.

### 7. Prediction averages topics into word probabilities

After estimating a document mixture `theta_d` and topic-word rows `phi`, LDA predicts the next word by averaging topic word distributions: `p(w | d) = theta_d^T phi`. This is the visible mixture implied by hidden topics.

```python
theta_pred_w = np.array([0.77272727, 0.22727273])  # document-topic mixture from concept 4.
phi_pred_w = np.array([[0.55, 0.35, 0.10],
                       [0.10, 0.20, 0.70]])  # two topic-word rows over three words.
word_pred_w = theta_pred_w @ phi_pred_w  # predictive word distribution.
print("predictive word distribution:", np.round(word_pred_w, 6))  # inspect theta^T phi.
assert np.allclose(word_pred_w.sum(), 1.0) and round(float(word_pred_w[0]), 6) == 0.447727  # sums to one and first number.
```
▶ What you'll see: the first topic dominates the prediction, but topic 1 still contributes probability to its favorite word.

```python
plt.figure(figsize=(4.5, 3))  # create a predictive distribution plot.
plt.bar(["word0", "word1", "word2"], word_pred_w, color="seagreen")  # plot final word probabilities.
plt.ylabel("p(word | document)"); plt.title("7: thetaᵀ phi predicts words"); plt.show()  # render.
```
▶ What you'll see: the bars sum to 1; the document mixture blends the two topic rows into one word distribution.

*Why it's done this way:* Prediction marginalizes over the unknown topic. Instead of choosing one topic first, we weight every topic's word distribution by how likely that topic is in the document.

### ✍️ Toy 1 · Bag-of-words counts ignore order

LDA turns a token sequence into vocabulary counts. Once we count words, only how many times each word
appears matters, not where it appeared.

```python
import numpy as np                              # arrays + checks (safe to repeat).

t1_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
```

### ✍️ Toy 2 · Dirichlet draws make mixtures

A Dirichlet draw is a probability vector. Small concentration often makes one component dominate,
while larger concentration makes rows more balanced.

```python
import numpy as np                              # arrays + checks (safe to repeat).

t2_rng = np.random.default_rng(0)               # seeded Dirichlet draws.
t2_alpha_sparse = np.array([0.3, 0.3, 0.3])     # small concentration
print("sparse alpha:", t2_alpha_sparse.tolist())  # -> [0.3, 0.3, 0.3]
t2_alpha_diffuse = np.array([5.0, 5.0, 5.0])    # large concentration
print("diffuse alpha:", t2_alpha_diffuse.tolist())  # -> [5.0, 5.0, 5.0]
t2_sparse = t2_rng.dirichlet(t2_alpha_sparse, size=6)  # 6 sparse mixtures
t2_diffuse = t2_rng.dirichlet(t2_alpha_diffuse, size=6)  # 6 diffuse mixtures
t2_sparse_first = t2_sparse[0]                  # first sparse row              # -> [0.283 0.    0.717]
print("first sparse draw:", np.round(t2_sparse_first, 3).tolist())  # -> [0.283, 0.0, 0.717]
t2_diffuse_first = t2_diffuse[0]                # first diffuse row             # -> [0.153 0.516 0.33 ]
print("first diffuse draw:", np.round(t2_diffuse_first, 3).tolist())  # -> [0.153, 0.516, 0.33]
t2_sparse_max = t2_sparse.max(axis=1)           # largest topic mass per sparse draw # -> [0.717 0.705 0.684 0.571 0.502 0.886]
print("sparse row maxima:", np.round(t2_sparse_max, 3).tolist())  # -> [0.717, 0.705, 0.684, 0.571, 0.502, 0.886]
t2_diffuse_max = t2_diffuse.max(axis=1)         # largest topic mass per diffuse draw # -> [0.516 0.409 0.445 0.601 0.437 0.468]
print("diffuse row maxima:", np.round(t2_diffuse_max, 3).tolist())  # -> [0.516, 0.409, 0.445, 0.601, 0.437, 0.468]
assert np.allclose(t2_sparse.sum(axis=1), 1.0) and np.allclose(t2_diffuse.sum(axis=1), 1.0)

plt.figure(figsize=(4.8, 2.8))
plt.bar(np.arange(3) - 0.18, t2_sparse_first, width=0.36, label="alpha=0.3", color="#e45756")

plt.xticks(range(3), ["topic0", "topic1", "topic2"])
plt.ylim(0, 1)

plt.show()
```
▶ What you'll see: both rows are valid mixtures, but the small-alpha row is much peakier.

### ✍️ Toy 3 · η smoothing turns counts into word probabilities

Topic-word rows are counts plus an `eta` pseudocount, normalized so every topic row sums to 1 and no
word has exactly zero probability.

```python
import numpy as np                              # arrays + checks (safe to repeat).

t3_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t3_counts = np.array([[5, 3, 0, 0, 0, 0], [0, 1, 4, 3, 0, 0], [0, 0, 0, 1, 3, 4]], dtype=float)  # 3 topics x 6 words
print("topic-word counts:\n", t3_counts.astype(int))  # -> [[5 3 0 0 0 0] [0 1 4 3 0 0] [0 0 0 1 3 4]]
t3_eta = 0.2                                    # symmetric word pseudocount    # -> 0.2
print("eta:", t3_eta)                           # -> 0.2
t3_smoothed = t3_counts + t3_eta                # add eta everywhere            # -> first row [5.2 3.2 0.2 0.2 0.2 0.2]
print("smoothed first row:", t3_smoothed[0].tolist())  # -> [5.2, 3.2, 0.2, 0.2, 0.2, 0.2]
t3_phi = t3_smoothed / t3_smoothed.sum(axis=1, keepdims=True)  # normalize rows # -> rows sum to 1
print("phi rows:", np.round(t3_phi, 3).tolist())  # -> [[0.565, 0.348, 0.022, 0.022, 0.022, 0.022], [0.022, 0.13, 0.457, 0.348, 0.022, 0.022], [0.022, 0.022, 0.022, 0.13, 0.348, 0.457]]
t3_row_sums = t3_phi.sum(axis=1)                # each topic distribution sum   # -> [1. 1. 1.]
print("row sums:", np.round(t3_row_sums, 3).tolist())  # -> [1.0, 1.0, 1.0]
assert np.allclose(t3_row_sums, 1.0) and np.all(t3_phi > 0.0)  # smoothing removes zeros

plt.figure(figsize=(5.4, 2.8))
plt.imshow(t3_phi, cmap="magma", aspect="auto")
plt.colorbar(label="p(word | topic)")
plt.xlabel("word id")
plt.ylabel("topic")
plt.title("Toy 3 · eta-smoothed topic-word rows")
plt.show()
```
▶ What you'll see: the high-count words are brightest, but every word receives a small positive mass.

### ✍️ Toy 4 · α turns document-topic counts into θ

Document-topic probabilities come from adding `alpha` to topic counts and normalizing the result.

```python
import numpy as np                              # arrays + checks (safe to repeat).

t4_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t4_counts = np.array([5., 1., 0.])              # topic counts in one document
print("doc-topic counts:", t4_counts.tolist())  # -> [5.0, 1.0, 0.0]
t4_alpha = np.array([0.5, 0.5, 0.5])            # topic pseudocounts
print("alpha:", t4_alpha.tolist())              # -> [0.5, 0.5, 0.5]

```
▶ What you'll see: topic 0 dominates, but topic 2 still has nonzero probability because of `alpha`.

### ✍️ Toy 5 · The joint is a product of local token factors

Given topic assignments, each token contributes `p(topic | document) × p(word | topic)`. The joint
factor is the product of those local numbers.

```python
import numpy as np                              # arrays + checks (safe to repeat).

t5_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t5_theta = np.array([0.6, 0.4])                 # document topic mixture
print("theta:", t5_theta.tolist())              # -> [0.6, 0.4]
t5_phi = np.array([[0.5, 0.3, 0.2], [0.1, 0.2, 0.7]])  # topic-word rows
print("phi:\n", t5_phi)                         # -> [[0.5 0.3 0.2] [0.1 0.2 0.7]]
t5_z = np.array([0, 1, 0, 1, 1, 0])             # 6 latent topic assignments
print("topics z:", t5_z.tolist())               # -> [0, 1, 0, 1, 1, 0]
t5_w = np.array([0, 2, 1, 2, 0, 0])             # 6 observed word ids
print("words w:", t5_w.tolist())                # -> [0, 2, 1, 2, 0, 0]
t5_topic_probs = t5_theta[t5_z]                 # p(z_n | theta) per token      # -> [0.6 0.4 0.6 0.4 0.4 0.6]
print("topic probabilities:", t5_topic_probs.tolist())  # -> [0.6, 0.4, 0.6, 0.4, 0.4, 0.6]
t5_word_probs = t5_phi[t5_z, t5_w]              # p(w_n | z_n, phi) per token   # -> [0.5 0.7 0.3 0.7 0.1 0.5]
print("word probabilities:", t5_word_probs.tolist())  # -> [0.5, 0.7, 0.3, 0.7, 0.1, 0.5]
t5_local = t5_topic_probs * t5_word_probs       # local token factors           # -> [0.3  0.28 0.18 0.28 0.04 0.3 ]
print("local factors:", np.round(t5_local, 3).tolist())  # -> [0.3, 0.28, 0.18, 0.28, 0.04, 0.3]
t5_joint = float(np.prod(t5_local))             # product over tokens           # -> 0.000051
print("joint product:", round(t5_joint, 6))     # -> 5.1e-05
assert round(t5_joint, 6) == 0.000051           # tiny because six probabilities multiply

plt.figure(figsize=(5.0, 2.8))
plt.bar(np.arange(t5_local.size), t5_local, color="#4c78a8")
plt.xlabel("token position")
plt.ylabel("local factor")
plt.title("Toy 5 · LDA joint multiplies local factors")
plt.show()
```
▶ What you'll see: six modest local probabilities multiply into a very small joint score.

### ✍️ Toy 6 · Gibbs scores multiply document and word evidence

A collapsed Gibbs reassignment gives each topic a score from document-topic evidence times how well
that topic explains the current word.

```python
import numpy as np                              # arrays + checks (safe to repeat).

t6_rng = np.random.default_rng(0)               # seeded generator for reproducibility.
t6_doc_counts = np.array([2., 1., 0.])          # counts excluding current token
print("doc counts minus token:", t6_doc_counts.tolist())  # -> [2.0, 1.0, 0.0]
t6_alpha = np.array([0.5, 0.5, 0.5])            # document-topic prior
print("alpha:", t6_alpha.tolist())              # -> [0.5, 0.5, 0.5]
```

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, random draws, counts, categorical probabilities, and checks.
import matplotlib.pyplot as plt # load Matplotlib so topic mixtures, count tables, and diagnostics can be inspected visually.
np.random.seed(0) # make every random example reproducible across notebook runs.

def normalize(x): # define a small helper that converts nonnegative scores into probabilities.
    x = np.asarray(x, dtype=float) # convert input to float so division behaves predictably.
    total = np.sum(x) # compute the denominator for probability normalization.
    return x / total if total > 0 else np.ones_like(x) / len(x) # return uniform probabilities if all scores vanish.

def sample_categorical(probs): # define one categorical sampler using only NumPy.
    probs = normalize(probs) # ensure probabilities sum to one before sampling.
    return int(np.searchsorted(np.cumsum(probs), np.random.rand())) # inverse-CDF sample from the cumulative probabilities.

def doc_word_matrix(token_docs, vocab): # define a bag-of-words builder for small tokenized documents.
    index = {word: i for i, word in enumerate(vocab)} # map vocabulary words to matrix columns.
    X = np.zeros((len(token_docs), len(vocab)), dtype=int) # allocate a document-word count matrix.
    for d, tokens in enumerate(token_docs): # loop over documents.
        for token in tokens: # loop over tokens in the document.
            X[d, index[token]] += 1 # increment the count for that token.
    return X # return the completed count matrix.

def show_heatmap(M, title, xticklabels=None, yticklabels=None): # define a compact matrix visualization helper.
    plt.figure(figsize=(5, 3)) # create a notebook-friendly figure.
    plt.imshow(M, cmap="viridis", aspect="auto") # draw matrix values as color.
    plt.colorbar(label="value") # add a numeric color scale.
    if xticklabels is not None: # optionally label columns.
        plt.xticks(range(len(xticklabels)), xticklabels, rotation=35) # show column labels at an angle.
    if yticklabels is not None: # optionally label rows.
        plt.yticks(range(len(yticklabels)), yticklabels) # show row labels.
    plt.title(title) # title the figure.
    plt.show() # display it.
```

## 🔴 Advanced

### Advanced 1 — Run a tiny collapsed Gibbs sampler

**Goal.** Iteratively reassign topic labels for a small corpus, because LDA inference alternates local topic choices using count evidence. We build it in 5 steps.

```python
vocab_a1 = np.array(["loan", "bank", "team", "score", "recipe", "flour"]) # define vocabulary.
docs_ids_a1 = [[0, 1, 0, 1, 3], [2, 3, 2, 3, 1], [4, 5, 4, 5, 1]] # encode tokenized documents as word ids.
K_a1 = 3 # choose three latent topics.
V_a1 = len(vocab_a1) # record vocabulary size.
alpha_a1 = 0.5 # document-topic smoothing.
eta_a1 = 0.1 # topic-word smoothing.
print("documents:", docs_ids_a1) # inspect encoded corpus.
```
▶ What you'll see: each document contains repeated co-occurring word ids.

```python
np.random.seed(2) # make initialization reproducible.
z_a1 = [np.random.randint(K_a1, size=len(doc)) for doc in docs_ids_a1] # initialize random topic labels for every token.
ndk_a1 = np.zeros((len(docs_ids_a1), K_a1), dtype=int) # document-topic counts.
nkv_a1 = np.zeros((K_a1, V_a1), dtype=int) # topic-word counts.
nk_a1 = np.zeros(K_a1, dtype=int) # total tokens assigned to each topic.
for d_a1, doc_a1 in enumerate(docs_ids_a1): # fill counts from initial labels.
    for n_a1, word_a1 in enumerate(doc_a1): # loop over tokens.
        topic_a1 = z_a1[d_a1][n_a1] # read initial label.
        ndk_a1[d_a1, topic_a1] += 1; nkv_a1[topic_a1, word_a1] += 1; nk_a1[topic_a1] += 1 # update all count tables.
print("initial document-topic counts:\n", ndk_a1) # inspect initialized counts.
```

```python
for sweep_a1 in range(40): # run a small number of Gibbs sweeps.
    for d_a1, doc_a1 in enumerate(docs_ids_a1): # loop over documents.
        for n_a1, word_a1 in enumerate(doc_a1): # loop over tokens.
            old_a1 = z_a1[d_a1][n_a1] # current topic label.
            ndk_a1[d_a1, old_a1] -= 1; nkv_a1[old_a1, word_a1] -= 1; nk_a1[old_a1] -= 1 # remove token from counts.
            left_a1 = ndk_a1[d_a1] + alpha_a1 # document-topic evidence.
            right_a1 = (nkv_a1[:, word_a1] + eta_a1) / (nk_a1 + V_a1 * eta_a1) # topic-word evidence for this word.
            probs_a1 = normalize(left_a1 * right_a1) # conditional topic probabilities.
            new_a1 = sample_categorical(probs_a1) # sample a new topic.
            z_a1[d_a1][n_a1] = new_a1 # store new label.
            ndk_a1[d_a1, new_a1] += 1; nkv_a1[new_a1, word_a1] += 1; nk_a1[new_a1] += 1 # add token back to counts.
print("final document-topic counts:\n", ndk_a1) # inspect counts after inference.
```

```python
theta_a1 = (ndk_a1 + alpha_a1) / np.sum(ndk_a1 + alpha_a1, axis=1, keepdims=True) # estimate document-topic mixtures.
phi_a1 = (nkv_a1 + eta_a1) / np.sum(nkv_a1 + eta_a1, axis=1, keepdims=True) # estimate topic-word distributions.
print("theta:\n", np.round(theta_a1, 3)) # inspect learned document mixtures.
print("top words:", [vocab_a1[np.argmax(phi_a1[k])] for k in range(K_a1)]) # inspect the top word per topic.
assert np.allclose(theta_a1.sum(axis=1), 1.0) and np.allclose(phi_a1.sum(axis=1), 1.0) # verify normalized estimates.
```

```python
show_heatmap(phi_a1, "Advanced 1: learned topic-word rows", vocab_a1, [f"topic{k}" for k in range(K_a1)]) # visualize learned topics.
```
▶ What you'll see: after repeated local reassignments, topic rows specialize around recurring word groups.

👀 Takeaway: collapsed Gibbs sampling repeatedly applies the same local conditional until global count structure emerges.

### Advanced 2 — Track pseudo log score during sampling

**Goal.** Monitor a simple token predictive score over sweeps, because inference should make observed words more probable under the estimated mixtures. We build it in 4 steps.

```python
vocab_a2 = np.array(["loan", "bank", "team", "score"]) # define a small vocabulary.
docs_ids_a2 = [[0, 1, 0, 1], [2, 3, 2, 3], [0, 1, 2, 3]] # define two pure docs and one mixed doc.
K_a2 = 2 # choose two topics.
alpha_a2 = 0.4 # document smoothing.
eta_a2 = 0.2 # word smoothing.
print("corpus token count:", sum(len(doc) for doc in docs_ids_a2)) # inspect problem size.
```
▶ What you'll see: a tiny corpus where two topics should separate finance and sports words.

```python
np.random.seed(3) # make the sampler reproducible.
z_a2 = [np.random.randint(K_a2, size=len(doc)) for doc in docs_ids_a2] # random initial labels.
ndk_a2 = np.zeros((len(docs_ids_a2), K_a2), dtype=int); nkv_a2 = np.zeros((K_a2, len(vocab_a2)), dtype=int); nk_a2 = np.zeros(K_a2, dtype=int) # allocate count tables.
for d_a2, doc_a2 in enumerate(docs_ids_a2): # initialize counts.
    for n_a2, word_a2 in enumerate(doc_a2): # loop tokens.
        k_a2 = z_a2[d_a2][n_a2]; ndk_a2[d_a2, k_a2] += 1; nkv_a2[k_a2, word_a2] += 1; nk_a2[k_a2] += 1 # add initial assignment.
print("initial topic totals:", nk_a2) # inspect starting totals.
```

```python
scores_a2 = [] # store a pseudo predictive log score after each sweep.
for sweep_a2 in range(50): # run several Gibbs sweeps.
    for d_a2, doc_a2 in enumerate(docs_ids_a2): # loop documents.
        for n_a2, word_a2 in enumerate(doc_a2): # loop tokens.
            old_a2 = z_a2[d_a2][n_a2]; ndk_a2[d_a2, old_a2] -= 1; nkv_a2[old_a2, word_a2] -= 1; nk_a2[old_a2] -= 1 # remove old label.
            probs_a2 = normalize((ndk_a2[d_a2] + alpha_a2) * (nkv_a2[:, word_a2] + eta_a2) / (nk_a2 + len(vocab_a2) * eta_a2)) # compute conditional.
            new_a2 = sample_categorical(probs_a2); z_a2[d_a2][n_a2] = new_a2 # sample and store new label.
            ndk_a2[d_a2, new_a2] += 1; nkv_a2[new_a2, word_a2] += 1; nk_a2[new_a2] += 1 # add new label.
    theta_a2 = (ndk_a2 + alpha_a2) / np.sum(ndk_a2 + alpha_a2, axis=1, keepdims=True) # estimate theta.
    phi_a2 = (nkv_a2 + eta_a2) / np.sum(nkv_a2 + eta_a2, axis=1, keepdims=True) # estimate phi.
    score_a2 = 0.0 # initialize pseudo log score.
    for d_a2, doc_a2 in enumerate(docs_ids_a2): # score observed tokens.
        for word_a2 in doc_a2: # loop words.
            score_a2 += np.log(theta_a2[d_a2] @ phi_a2[:, word_a2] + 1e-12) # add log predictive probability.
    scores_a2.append(score_a2) # store the sweep score.
print("score start -> end:", round(scores_a2[0], 3), "->", round(scores_a2[-1], 3)) # inspect progress.
assert np.isfinite(scores_a2[-1]) # verify the diagnostic is numeric.
```

```python
plt.figure(figsize=(5, 3)) # create a score trace.
plt.plot(scores_a2, color="crimson") # plot pseudo log score by sweep.
plt.title("Advanced 2: predictive score trace"); plt.xlabel("sweep"); plt.ylabel("pseudo log score"); plt.show() # display plot.
```
▶ What you'll see: the trace may wiggle because sampling is stochastic, but better assignments usually improve the predictive score.

👀 Takeaway: sampler diagnostics should be inspected because LDA inference is approximate, not a single closed-form fit.
