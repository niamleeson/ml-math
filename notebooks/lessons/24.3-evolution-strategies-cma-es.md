# 24.3 — Evolution Strategies & CMA-ES

Evolution strategies optimize real-valued vectors when gradients are missing, noisy, unavailable, or too expensive. The core idea is simple: sample a population around a current mean, evaluate every candidate with a black-box objective, keep the best candidates, and use them to steer the next search distribution. CMA-ES adds the important geometric step: it learns the covariance of successful moves so the population stretches along promising directions instead of staying round forever.

### 1. Black-box continuous optimization

An evolution strategy is for problems where a candidate is a real vector, such as `x = [x0, x1]`, and the only thing we can do is ask an objective function for a score. We do not ask for a derivative. We just evaluate many candidates and prefer the ones with lower loss. This makes ES useful when the function is noisy, discontinuous, simulated, or otherwise unfriendly to ordinary gradient descent.

```python
def sphere_w(x):  # A black-box objective: lower is better and the optimum is at the origin.
    x = np.asarray(x, dtype=float)  # Convert candidates to arrays so vector operations are predictable.
    return float(np.sum(x ** 2))  # Return squared distance from the origin.

grid_w = np.linspace(-3, 3, 120)  # Create a 2-D plotting grid.
X_w, Y_w = np.meshgrid(grid_w, grid_w)  # Turn x and y coordinates into a contour grid.
Z_w = X_w ** 2 + Y_w ** 2  # Evaluate the sphere objective on the grid.
points_w = np.array([[2.5, 2.0], [1.0, -1.5], [-2.0, 0.5]])  # Example candidates.
values_w = np.array([sphere_w(p) for p in points_w])  # Black-box evaluations only.
print("candidate losses:", np.round(values_w, 3))  # Inspect objective values.
assert values_w.argmin() == 1  # The middle candidate is closest to the optimum.
plt.figure(figsize=(4.5, 3.8))  # Create a contour visualization of the objective.
plt.contour(X_w, Y_w, Z_w, levels=18, cmap="viridis")  # Show equal-loss curves.
plt.scatter(points_w[:, 0], points_w[:, 1], c=values_w, cmap="magma", s=80, edgecolor="black")  # Draw evaluated candidates.
plt.colorbar(label="loss")  # Add a color scale for candidate losses.
plt.title("1: black-box scores for real vectors")  # Title the diagnostic plot.
plt.xlabel("x0"); plt.ylabel("x1")  # Label vector coordinates.
plt.show()  # Display the contour and candidates.
```
▶ What you'll see: candidates closer to the center have lower loss, even though the algorithm only sees function values.

*Why it's done this way:* ES treats the objective as an evaluator, not as a formula to differentiate, so the whole algorithm is built around sampling, scoring, and selection.

### 2. Sampling from a Gaussian search distribution

Instead of mutating arbitrary encodings, evolution strategies sample numeric candidates from a multivariate Gaussian. The mean `m` is the current best guess, the global step size `sigma` controls overall radius, and the covariance matrix `C` controls the shape and orientation of the sampling cloud:

$$x_k \sim \mathcal{N}(m_t,\sigma_t^2 C_t).$$

If `C` is the identity, the cloud is round. If `C` has unequal eigenvalues, the cloud becomes an ellipse. If `C` has rotated eigenvectors, the ellipse points along a diagonal direction.

```python
rng_w = np.random.default_rng(1)  # Local generator for reproducible sampling.
m_w = np.array([1.8, 1.2])  # Current search mean.
sigma_w = 0.7  # Global radius multiplier.
C_w = np.array([[1.0, 0.75], [0.75, 1.6]])  # Positive definite covariance that tilts the cloud.
samples_w = rng_w.multivariate_normal(m_w, sigma_w ** 2 * C_w, size=80)  # Draw a population.
eigvals_w, eigvecs_w = np.linalg.eigh(sigma_w ** 2 * C_w)  # Decompose covariance for plotting.
theta_w = np.linspace(0, 2 * np.pi, 200)  # Angles for an ellipse.
ellipse_w = m_w + (eigvecs_w @ (np.sqrt(eigvals_w)[:, None] * np.vstack([np.cos(theta_w), np.sin(theta_w)]))).T  # One-standard-deviation ellipse.
print("sample mean:", np.round(samples_w.mean(axis=0), 3))  # Inspect empirical center.
print("target mean:", m_w)  # Compare with configured center.
assert samples_w.shape == (80, 2)  # Verify population shape.
plt.figure(figsize=(4.5, 3.8))  # Create the sampling plot.
plt.scatter(samples_w[:, 0], samples_w[:, 1], s=18, alpha=0.65, label="samples")  # Draw sampled candidates.
plt.plot(ellipse_w[:, 0], ellipse_w[:, 1], color="crimson", lw=2, label="search covariance")  # Draw covariance ellipse.
plt.scatter([m_w[0]], [m_w[1]], color="black", marker="x", s=90, label="mean")  # Mark current mean.
plt.axis("equal"); plt.title("2: Gaussian population around a mean")  # Keep geometry honest.
plt.xlabel("x0"); plt.ylabel("x1"); plt.legend()  # Label the plot.
plt.show()  # Display the population and ellipse.
```
▶ What you'll see: samples form a tilted ellipse around the mean, not a fixed coordinate-axis box.

*Why it's done this way:* a Gaussian gives ES a compact, controllable search distribution; `sigma` says how far to search, while `C` says which directions deserve more or less exploration.

### 3. Elite recombination moves the mean

A basic $(\mu,\lambda)$-ES samples `lambda` candidates, sorts them by fitness, and recombines the best `mu` elites into the next mean:

$$m_{t+1}=\sum_{k=1}^{\mu} w_k x_{k:\lambda}.$$

The notation $x_{k:\lambda}$ means the $k$th best candidate after sorting. Equal weights are easy to understand; CMA-ES often uses larger weights for better elites.

```python
rng_w = np.random.default_rng(2)  # Reproducible population.
def shifted_bowl_w(x):  # A simple black-box loss with optimum near (0.5, -0.5).
    x = np.asarray(x, dtype=float)  # Convert one candidate or many candidates.
    return np.sum((x - np.array([0.5, -0.5])) ** 2, axis=-1)  # Squared distance to the target.

m0_w = np.array([2.4, 1.8])  # Start far from the optimum.
pop_w = rng_w.normal(m0_w, 0.8, size=(24, 2))  # Sample lambda=24 candidates from a round cloud.
fit_w = shifted_bowl_w(pop_w)  # Evaluate all candidates.
elite_idx_w = np.argsort(fit_w)[:6]  # Keep mu=6 best candidates.
elites_w = pop_w[elite_idx_w]  # Gather elite vectors.
m1_w = elites_w.mean(axis=0)  # Equal-weight recombination.
print("old mean:", np.round(m0_w, 3), "new mean:", np.round(m1_w, 3))  # Inspect movement.
assert shifted_bowl_w(m1_w) < shifted_bowl_w(m0_w)  # Recombined mean should improve on this toy draw.
plt.figure(figsize=(4.5, 3.8))  # Create an optimization contour plot.
xx_w = np.linspace(-1.5, 3.2, 120); yy_w = np.linspace(-2.2, 3.0, 120)  # Grid ranges.
X_w, Y_w = np.meshgrid(xx_w, yy_w); Z_w = (X_w - 0.5) ** 2 + (Y_w + 0.5) ** 2  # Objective contours.
plt.contour(X_w, Y_w, Z_w, levels=18, cmap="viridis")  # Show loss surface.
plt.scatter(pop_w[:, 0], pop_w[:, 1], s=20, alpha=0.35, label="population")  # Draw all candidates.
plt.scatter(elites_w[:, 0], elites_w[:, 1], s=65, color="orange", edgecolor="black", label="elites")  # Highlight elites.
plt.arrow(m0_w[0], m0_w[1], m1_w[0]-m0_w[0], m1_w[1]-m0_w[1], color="crimson", width=0.025, length_includes_head=True)  # Show mean move.
plt.scatter([0.5], [-0.5], marker="*", s=120, color="black", label="optimum")  # Mark target.
plt.title("3: elites pull the mean downhill"); plt.xlabel("x0"); plt.ylabel("x1"); plt.legend()  # Label plot.
plt.show()  # Display the recombination step.
```
▶ What you'll see: the new mean moves toward the cluster of best samples without using a gradient.

*Why it's done this way:* recombination converts several noisy evaluations into one steadier direction of travel; it is a derivative-free estimate of where good regions seem to be.

### 4. Covariance is memory of successful directions

CMA-ES is powerful because it does not only move the mean. It also measures how the successful steps are arranged around the old mean. If elite displacements stretch along a diagonal valley, the covariance update should stretch future sampling along that same diagonal.

For centered elite steps $y_k=(x_k-m_t)/\sigma_t$, a simple rank-$\mu$ covariance estimate is

$$C_{\text{elite}}=\sum_{k=1}^{\mu} w_k y_k y_k^\top,$$

where $y_k y_k^\top$ is an outer product. Diagonal entries are variances; off-diagonal entries are coordinate co-movements. A positive off-diagonal means successful moves tend to increase or decrease the two coordinates together; a negative one means they trade off.

```python
rng_w = np.random.default_rng(3)  # Reproducible elite cloud.
angle_w = np.deg2rad(35)  # Desired diagonal orientation.
Rrot_w = np.array([[np.cos(angle_w), -np.sin(angle_w)], [np.sin(angle_w), np.cos(angle_w)]])  # Rotation matrix.
scales_w = np.array([1.2, 0.18])  # Long and short axis scales for successful steps.
steps_w = rng_w.normal(size=(40, 2)) @ np.diag(scales_w) @ Rrot_w.T  # Simulate successful centered steps.
C_elite_w = steps_w.T @ steps_w / len(steps_w)  # Average outer products to estimate covariance.
eigvals_w, eigvecs_w = np.linalg.eigh(C_elite_w)  # Decompose for ellipse plotting.
theta_w = np.linspace(0, 2 * np.pi, 200)  # Ellipse angles.
ellipse_w = (eigvecs_w @ (np.sqrt(eigvals_w)[:, None] * np.vstack([np.cos(theta_w), np.sin(theta_w)]))).T  # One-std covariance ellipse.
print("elite covariance:\n", np.round(C_elite_w, 3))  # Inspect variances and covariance.
assert C_elite_w[0, 0] > 0 and C_elite_w[1, 1] > 0  # Variances must be positive.
fig, ax = plt.subplots(1, 2, figsize=(7.2, 3.2))  # Compare geometry and matrix entries.
ax[0].scatter(steps_w[:, 0], steps_w[:, 1], s=18, alpha=0.55)  # Plot successful steps.
ax[0].plot(ellipse_w[:, 0], ellipse_w[:, 1], color="crimson", lw=2)  # Plot covariance ellipse.
ax[0].axis("equal"); ax[0].set_title("successful-step ellipse")  # Preserve orientation.
im_w = ax[1].imshow(C_elite_w, cmap="coolwarm")  # Show covariance matrix as heatmap.
ax[1].set_xticks([0, 1]); ax[1].set_yticks([0, 1]); ax[1].set_title("C from elites")  # Label entries.
fig.colorbar(im_w, ax=ax[1], fraction=0.046)  # Add colorbar for covariance values.
plt.suptitle("4: covariance records useful geometry")  # Overall title.
plt.show()  # Display both views.
```
▶ What you'll see: the heatmap's off-diagonal terms correspond to a rotated ellipse of successful steps.

*Why it's done this way:* covariance adaptation stores directional evidence from past elites, turning individual evaluations into a reusable search geometry.

### 5. Global step size controls exploration radius

The covariance matrix controls shape, but the scalar `sigma` controls scale. Large `sigma` explores broadly; small `sigma` refines locally. A simple practical rule is to shrink `sigma` when progress stalls and grow or keep it when selection improves the mean. Full CMA-ES uses evolution paths for a more principled step-size update, but the lesson's simplified version still separates scale from shape.

```python
rng_w = np.random.default_rng(4)  # Reproducible ES run.
def run_es_sigma_w(start, generations=28):  # Tiny sigma-adapting ES for demonstration.
    m = np.array(start, dtype=float)  # Current mean.
    sigma = 1.2  # Initial global step size.
    C = np.eye(2)  # Round shape so only sigma changes here.
    best_hist, sigma_hist, means = [], [], [m.copy()]  # Diagnostics.
    for _ in range(generations):  # Repeat sampling and selection.
        pop = rng_w.multivariate_normal(m, sigma ** 2 * C, size=30)  # Sample lambda candidates.
        fit = np.sum(pop ** 2, axis=1)  # Minimize the sphere.
        elites = pop[np.argsort(fit)[:8]]  # Select mu elites.
        old = np.sum(m ** 2)  # Loss at old mean.
        m_new = elites.mean(axis=0)  # Recombine elites.
        new = np.sum(m_new ** 2)  # Loss at new mean.
        sigma *= 1.04 if new < old else 0.82  # Simple success-based scale adaptation.
        m = m_new  # Accept the recombined mean.
        best_hist.append(float(np.min(fit))); sigma_hist.append(float(sigma)); means.append(m.copy())  # Record diagnostics.
    return np.array(means), np.array(best_hist), np.array(sigma_hist)  # Return run traces.

means_w, best_w, sigmas_w = run_es_sigma_w([3.0, -2.4])  # Run the optimizer.
print("final mean:", np.round(means_w[-1], 3), "final sigma:", round(sigmas_w[-1], 3))  # Inspect outcome.
assert best_w[-1] < best_w[0]  # Best sampled fitness should improve.
fig, ax = plt.subplots(1, 2, figsize=(7.4, 3.2))  # Plot trajectory and sigma.
ax[0].plot(means_w[:, 0], means_w[:, 1], marker="o", ms=3, color="teal")  # Mean path.
ax[0].scatter([0], [0], marker="*", s=120, color="black")  # Optimum.
ax[0].set_title("mean path toward optimum"); ax[0].set_xlabel("x0"); ax[0].set_ylabel("x1")  # Labels.
ax[1].plot(sigmas_w, color="crimson", marker="o", ms=3)  # Sigma trace.
ax[1].set_title("step size over generations"); ax[1].set_xlabel("generation"); ax[1].set_ylabel("sigma")  # Labels.
plt.suptitle("5: sigma controls search radius")  # Overall title.
plt.show()  # Display diagnostics.
```
▶ What you'll see: the mean moves toward the optimum while sigma changes as the run alternates between exploration and refinement.

*Why it's done this way:* ES needs a scalar knob for overall distance and a matrix knob for direction; mixing them up makes it hard to tell whether failure is due to wrong scale or wrong geometry.

### 6. A simplified CMA-ES loop

A simplified CMA-ES loop combines the pieces: sample from $\mathcal{N}(m,\sigma^2C)$, keep elites, recombine their mean, update covariance from elite steps, regularize the matrix with a small diagonal term, and update `sigma` from progress. The covariance update below uses an exponential moving average:

$$C_{t+1}=(1-c_{\text{cov}})C_t+c_{\text{cov}}\sum_k w_k y_k y_k^\top+\epsilon I.$$

The old covariance is retained so one lucky generation does not overwrite all memory. The elite covariance is added so future samples stretch along successful directions. The tiny $\epsilon I$ keeps the matrix positive definite enough for stable sampling.

```python
rng_w = np.random.default_rng(5)  # Reproducible simplified CMA-ES.
def valley_w(X):  # Rotated elongated valley; lower is better.
    X = np.asarray(X, dtype=float)  # Accept a single candidate or a batch.
    u = (X[..., 0] + X[..., 1]) / np.sqrt(2)  # Diagonal coordinate along the valley.
    v = (X[..., 0] - X[..., 1]) / np.sqrt(2)  # Diagonal coordinate across the valley.
    return 0.08 * u ** 2 + 3.0 * v ** 2  # Long valley: cheap along u, expensive along v.

m_w = np.array([3.0, -2.5])  # Initial mean.
sigma_w = 1.0  # Initial global scale.
C_w = np.eye(2)  # Initial round covariance.
weights_w = np.ones(6) / 6  # Equal recombination weights for mu=6 elites.
means_w, covs_w, best_w, sigmas_w = [m_w.copy()], [C_w.copy()], [], []  # Diagnostics.
for gen_w in range(35):  # Run simplified CMA-ES.
    pop_w = rng_w.multivariate_normal(m_w, sigma_w ** 2 * C_w, size=28)  # Sample lambda candidates.
    fit_w = valley_w(pop_w)  # Evaluate black-box objective.
    elites_w = pop_w[np.argsort(fit_w)[:6]]  # Keep best mu candidates.
    old_fit_w = valley_w(m_w)  # Current mean fitness.
    m_new_w = np.sum(weights_w[:, None] * elites_w, axis=0)  # Recombine elite mean.
    steps_w = (elites_w - m_w) / max(sigma_w, 1e-12)  # Normalize elite displacements.
    C_elite_w = sum(weights_w[k] * np.outer(steps_w[k], steps_w[k]) for k in range(len(weights_w)))  # Rank-mu covariance estimate.
    C_w = 0.82 * C_w + 0.18 * C_elite_w + 1e-5 * np.eye(2)  # Smooth covariance update plus regularization.
    C_w = 0.5 * (C_w + C_w.T)  # Symmetrize to remove numerical asymmetry.
    sigma_w *= 1.03 if valley_w(m_new_w) < old_fit_w else 0.82  # Simple success-based sigma adaptation.
    m_w = m_new_w  # Accept the new mean.
    means_w.append(m_w.copy()); covs_w.append(C_w.copy()); best_w.append(float(np.min(fit_w))); sigmas_w.append(float(sigma_w))  # Record traces.
means_w = np.array(means_w); best_w = np.array(best_w); sigmas_w = np.array(sigmas_w)  # Convert traces to arrays.
print("final mean:", np.round(means_w[-1], 3), "best fitness:", round(best_w[-1], 5))  # Inspect result.
assert best_w[-1] < best_w[0]  # Confirm improvement.
fig, ax = plt.subplots(1, 2, figsize=(7.6, 3.4))  # Plot path and final covariance.
grid_w = np.linspace(-4, 4, 130); X_w, Y_w = np.meshgrid(grid_w, grid_w); Z_w = valley_w(np.dstack([X_w, Y_w]))  # Objective contours.
ax[0].contour(X_w, Y_w, Z_w, levels=22, cmap="viridis")  # Valley contours.
ax[0].plot(means_w[:, 0], means_w[:, 1], marker="o", ms=3, color="crimson")  # Mean path.
ax[0].scatter([0], [0], marker="*", color="black", s=110)  # Optimum.
ax[0].set_title("mean path in rotated valley"); ax[0].set_xlabel("x0"); ax[0].set_ylabel("x1")  # Labels.
im_w = ax[1].imshow(covs_w[-1], cmap="coolwarm")  # Final covariance heatmap.
ax[1].set_title("final learned covariance C"); ax[1].set_xticks([0, 1]); ax[1].set_yticks([0, 1])  # Labels.
fig.colorbar(im_w, ax=ax[1], fraction=0.046)  # Color scale.
plt.suptitle("6: simplified CMA-ES learns shape and location")  # Overall title.
plt.show()  # Display CMA-ES diagnostics.
```
▶ What you'll see: the mean follows the diagonal valley and the learned covariance is no longer the identity matrix.

*Why it's done this way:* the moving-average covariance update balances stability and adaptation; it remembers useful geometry while avoiding singular matrices from too few elites.

### 7. Evaluation budget, noise, and population size

CMA-ES spends `lambda` objective calls every generation. Larger populations can estimate covariance more reliably, but they also burn budget faster. With noisy objectives, the best-looking elite can be lucky rather than truly good, so using several elites and monitoring best fitness over time is safer than trusting one winner.

```python
rng_w = np.random.default_rng(6)  # Reproducible noisy comparison.
def noisy_sphere_w(pop, noise=0.4):  # Noisy black-box evaluation.
    return np.sum(pop ** 2, axis=1) + rng_w.normal(0, noise, size=len(pop))  # True loss plus noise.

lambdas_w = np.array([8, 20, 50])  # Population sizes to compare.
budget_w = 600  # Fixed evaluation budget.
finals_w = []  # Store final best true fitness for each lambda.
for lam_w in lambdas_w:  # Run one ES per population size.
    m_w = np.array([2.8, 2.2])  # Same start.
    sigma_w = 0.8  # Same scale.
    mu_w = max(2, lam_w // 4)  # Keep a quarter as elites.
    for _ in range(budget_w // lam_w):  # Spend the same total budget.
        pop_w = rng_w.normal(m_w, sigma_w, size=(lam_w, 2))  # Sample candidates.
        fit_w = noisy_sphere_w(pop_w)  # Noisy ranking signal.
        elites_w = pop_w[np.argsort(fit_w)[:mu_w]]  # Select noisy elites.
        m_w = elites_w.mean(axis=0)  # Recombine mean.
        sigma_w *= 0.96  # Gradual refinement.
    finals_w.append(float(np.sum(m_w ** 2)))  # True final mean fitness without noise.
print("true final fitness by lambda:", np.round(finals_w, 4))  # Inspect budget tradeoff.
assert len(finals_w) == len(lambdas_w)  # Verify one result per population size.
plt.figure(figsize=(4.8, 3.2))  # Create budget comparison plot.
plt.plot(lambdas_w, finals_w, marker="o", color="purple")  # Plot final quality versus lambda.
plt.title("7: population size under fixed budget")  # Title the plot.
plt.xlabel("population size λ")  # Label population axis.
plt.ylabel("final true f(mean)")  # Label quality axis.
plt.show()  # Display the budget tradeoff.
```
▶ What you'll see: population size changes final quality because it trades covariance/selection reliability against the number of generations.

*Why it's done this way:* ES is evaluation-limited; every design choice must be judged by how much information it extracts per objective call.

## 🛠️ Setup

```python
import numpy as np  # NumPy provides arrays, random sampling, eigendecompositions, and assertions.
import matplotlib.pyplot as plt  # Matplotlib provides contour plots, ellipses, heatmaps, and fitness curves.
np.random.seed(0)  # Keep any legacy NumPy randomness reproducible.

def sphere(x):  # Standard minimization benchmark with optimum at the origin.
    x = np.asarray(x, dtype=float)  # Accept one vector or a batch of vectors.
    return np.sum(x ** 2, axis=-1)  # Return squared Euclidean distance.

def rotated_valley(x):  # Elongated rotated bowl used to show why covariance matters.
    x = np.asarray(x, dtype=float)  # Accept one candidate or a batch.
    u = (x[..., 0] + x[..., 1]) / np.sqrt(2)  # Coordinate along the valley.
    v = (x[..., 0] - x[..., 1]) / np.sqrt(2)  # Coordinate across the valley.
    return 0.08 * u ** 2 + 3.0 * v ** 2  # Penalize cross-valley movement much more.

def covariance_ellipse(mean, cov, scale=1.0, n=200):  # Convert a 2x2 covariance into ellipse coordinates.
    vals, vecs = np.linalg.eigh(cov)  # Eigenvectors set orientation and eigenvalues set squared radii.
    vals = np.maximum(vals, 1e-12)  # Guard against tiny negative roundoff before square roots.
    theta = np.linspace(0, 2 * np.pi, n)  # Parameterize the ellipse.
    circle = np.vstack([np.cos(theta), np.sin(theta)])  # Unit circle points.
    ellipse = np.asarray(mean)[:, None] + scale * vecs @ (np.sqrt(vals)[:, None] * circle)  # Transform circle by covariance.
    return ellipse.T  # Return rows as (x0, x1) coordinates.

def run_mu_lambda_es(objective, start, sigma=0.8, lam=30, mu=8, generations=30, seed=0):  # Basic (mu,lambda)-ES.
    rng = np.random.default_rng(seed)  # Local randomness for reproducibility.
    m = np.array(start, dtype=float)  # Current search mean.
    means, bests, sigmas = [m.copy()], [], []  # Diagnostics.
    for _ in range(generations):  # Repeat generations.
        pop = rng.normal(m, sigma, size=(lam, len(m)))  # Sample an isotropic Gaussian population.
        fit = objective(pop)  # Evaluate all candidates.
        elites = pop[np.argsort(fit)[:mu]]  # Keep the best mu candidates.
        old = float(objective(m))  # Fitness at old mean.
        m_new = elites.mean(axis=0)  # Recombine elites with equal weights.
        sigma *= 1.04 if float(objective(m_new)) < old else 0.82  # Simple success-based scale rule.
        m = m_new  # Update mean.
        means.append(m.copy()); bests.append(float(np.min(fit))); sigmas.append(float(sigma))  # Record diagnostics.
    return np.array(means), np.array(bests), np.array(sigmas)  # Return traces.

def run_simple_cma(objective, start, sigma=1.0, lam=32, mu=8, generations=35, seed=0):  # Simplified CMA-ES from scratch.
    rng = np.random.default_rng(seed)  # Local randomness.
    m = np.array(start, dtype=float)  # Current mean.
    d = len(m)  # Dimension.
    C = np.eye(d)  # Start with round covariance.
    weights = np.ones(mu) / mu  # Equal elite weights.
    means, covs, bests, sigmas = [m.copy()], [C.copy()], [], []  # Diagnostics.
    for _ in range(generations):  # Repeat CMA generations.
        pop = rng.multivariate_normal(m, sigma ** 2 * C, size=lam)  # Sample from N(m, sigma^2 C).
        fit = objective(pop)  # Evaluate candidates.
        elites = pop[np.argsort(fit)[:mu]]  # Select best elites.
        old_fit = float(objective(m))  # Old mean fitness.
        m_new = np.sum(weights[:, None] * elites, axis=0)  # Weighted recombination.
        steps = (elites - m) / max(sigma, 1e-12)  # Normalize by global step size.
        C_elite = sum(weights[k] * np.outer(steps[k], steps[k]) for k in range(mu))  # Rank-mu covariance estimate.
        C = 0.84 * C + 0.16 * C_elite + 1e-5 * np.eye(d)  # Smooth covariance update plus regularization.
        C = 0.5 * (C + C.T)  # Force symmetry for stable multivariate sampling.
        sigma *= 1.03 if float(objective(m_new)) < old_fit else 0.84  # Simple step-size adaptation.
        m = m_new  # Accept mean.
        means.append(m.copy()); covs.append(C.copy()); bests.append(float(np.min(fit))); sigmas.append(float(sigma))  # Record traces.
    return np.array(means), np.array(covs), np.array(bests), np.array(sigmas)  # Return diagnostics.

def plot_contours(objective, title, xlim=(-4, 4), ylim=(-4, 4)):  # Reusable 2-D contour helper.
    xs = np.linspace(xlim[0], xlim[1], 140)  # x-grid.
    ys = np.linspace(ylim[0], ylim[1], 140)  # y-grid.
    X, Y = np.meshgrid(xs, ys)  # 2-D mesh.
    Z = objective(np.dstack([X, Y]))  # Evaluate objective on the grid.
    plt.contour(X, Y, Z, levels=22, cmap="viridis")  # Draw equal-loss curves.
    plt.title(title)  # Add plot title.
    plt.xlabel("x0")  # Label first coordinate.
    plt.ylabel("x1")  # Label second coordinate.
```

#### A2. Inspect covariance-update math in detail (`_a2`)

**Goal.** Compute one CMA covariance update by hand, because the matrix formula is the heart of CMA-ES. We build it in 4 steps.

```python
C_old_a2 = np.array([[1.0, 0.0], [0.0, 1.0]])  # Start from identity covariance.
sigma_a2 = 0.5  # Current global step size.
mean_a2 = np.array([1.0, 1.0])  # Old mean used to measure steps.
elites_a2 = np.array([[1.5, 1.4], [1.4, 1.3], [1.6, 1.5]])  # Successful candidates.
weights_a2 = np.array([0.5, 0.3, 0.2])  # Recombination weights.
steps_a2 = (elites_a2 - mean_a2) / sigma_a2  # Normalize elite displacements y_k.
print("normalized steps:\n", np.round(steps_a2, 3))  # Inspect y_k values.
assert steps_a2.shape == elites_a2.shape  # Verify normalized steps match candidate shape.
```
▶ What you'll see: each elite displacement is measured in units of sigma.

```python
outer_sum_a2 = sum(weights_a2[k] * np.outer(steps_a2[k], steps_a2[k]) for k in range(len(weights_a2)))  # Weighted rank-mu update.
c_cov_a2 = 0.25  # Covariance learning rate.
C_new_a2 = (1 - c_cov_a2) * C_old_a2 + c_cov_a2 * outer_sum_a2 + 1e-5 * np.eye(2)  # Moving-average covariance update.
print("elite outer-product covariance:\n", np.round(outer_sum_a2, 3))  # Inspect new evidence.
print("updated C:\n", np.round(C_new_a2, 3))  # Inspect smoothed covariance.
assert C_new_a2[0, 1] > 0  # Elite steps move coordinates together.
fig, ax = plt.subplots(1, 2, figsize=(7, 3.2))  # Create geometry and heatmap.
ax[0].scatter(steps_a2[:, 0], steps_a2[:, 1], s=90, c=weights_a2, cmap="viridis", edgecolor="black")  # Plot weighted steps.
ax[0].plot(*covariance_ellipse([0, 0], C_new_a2).T, color="crimson")  # Updated covariance ellipse.
ax[0].axis("equal"); ax[0].set_title("weighted steps y_k")  # Label geometry.
im_a2 = ax[1].imshow(C_new_a2, cmap="coolwarm")  # Updated covariance heatmap.
ax[1].set_title("(1-c)C + cΣwyyᵀ"); ax[1].set_xticks([0, 1]); ax[1].set_yticks([0, 1])  # Label matrix.
fig.colorbar(im_a2, ax=ax[1], fraction=0.046)  # Colorbar.
plt.suptitle("A2: one covariance update")  # Overall title.
plt.show()  # Display update.
```
▶ What you'll see: the update blends old identity memory with a positive-correlation elite covariance.

👀 Takeaway: CMA-ES updates `C` by averaging old geometry with weighted outer products of successful normalized steps.
