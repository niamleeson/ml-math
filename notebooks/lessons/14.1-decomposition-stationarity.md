# 14.1 — Decomposition & Stationarity

Time series become easier to forecast when we stop treating the raw line as one mystery. In this lesson, you will synthesize a series from trend, seasonality, and residual noise; estimate those pieces with NumPy; and check whether the leftover behavior is stable enough for lag-based forecasting.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build decomposition and stationarity one idea at a time. Run each cell in order and read the printed intermediate values — every trend fit, seasonal average, residual, and stationarity diagnostic is computed directly from arrays. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, least squares, and synthetic time series.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for synthetic residual noise.
```

### 1. A time series is an ordered signal, not a shuffled table

A time series is a vector whose index matters. We start by building one from three visible causes: a slow upward trend, a repeating seasonal offset, and small residual noise. The additive story is

$$y_t = T_t + S_t + e_t.$$

That equation is not a forecasting model yet; it is a bookkeeping identity that says each observed value can be read as level plus cycle plus leftover.

```python
n_w = 48  # four years of monthly observations.
t_w = np.arange(n_w)  # ordered time index: 0, 1, ..., 47.
trend_true_w = 20 + 0.12 * t_w  # slow linear drift upward.
season_pattern_w = np.array([0.0, 1.5, 2.6, 2.0, 0.7, -0.8, -2.0, -2.6, -1.6, -0.3, 0.8, 1.7])  # one 12-step cycle.
season_true_w = season_pattern_w[t_w % 12]  # repeat the seasonal pattern four times.
noise_w = np.random.normal(0, 0.35, n_w)  # residual shocks around zero.
y_w = trend_true_w + season_true_w + noise_w  # additive observed series.
print("first five y values:", np.round(y_w[:5], 3))
assert len(y_w) == 48
```
▶ What you'll see: the first values mix a rising baseline with early positive seasonal months.

```python
plt.figure(figsize=(7, 3))
plt.plot(t_w, y_w, marker="o", ms=3, label="observed y")
plt.plot(t_w, trend_true_w, lw=2, label="true trend")
plt.title("1: observed series = trend + season + residual")
plt.xlabel("time step")
plt.ylabel("value")
plt.legend()
plt.show()
```
▶ What you'll see: a wavy line that rises over time; the trend alone misses the repeating ups and downs.

*Why it's done this way:* ordering is the feature. If we shuffled `y_w`, the same values would keep their histogram but lose the meaning of slope, period, and lag. The additive construction makes the math inspectable: trend explains low-frequency level, seasonality explains repeated within-period offsets, and the residual is what remains after those systematic parts are removed.

### 2. Fit the slow trend with least squares

A linear trend is just regression on time. We build a design matrix with a constant column and a time column, then solve

$$\hat\beta=(X^\top X)^{-1}X^\top y,$$

so the fitted trend is $\hat T_t=\hat\beta_0+\hat\beta_1 t$. This is deliberately simple: before looking for cycles, we remove the slowest moving component.

```python
y_small_w = np.array([10.0, 12.5, 11.0, 9.5, 12.0, 14.5])  # six-point worked example from the lesson text.
t_small_w = np.arange(len(y_small_w))
X_small_w = np.column_stack([np.ones_like(t_small_w), t_small_w])  # intercept and time.
beta_small_w = np.linalg.inv(X_small_w.T @ X_small_w) @ X_small_w.T @ y_small_w
trend_small_w = X_small_w @ beta_small_w
resid_small_w = y_small_w - trend_small_w
print("beta:", np.round(beta_small_w, 3))
print("trend at t=3:", round(float(trend_small_w[3]), 3), "residual at t=3:", round(float(resid_small_w[3]), 3))
assert np.allclose(np.round(beta_small_w, 3), [10.190, 0.557])
assert round(float(resid_small_w[3]), 3) == -2.362
```
▶ What you'll see: the fitted line is `10.190 + 0.557 t`, and the fourth point is 2.362 units below it.

```python
X_w = np.column_stack([np.ones(n_w), t_w])  # full-series intercept and time columns.
beta_w = np.linalg.inv(X_w.T @ X_w) @ X_w.T @ y_w  # least-squares trend coefficients.
trend_hat_w = X_w @ beta_w  # fitted slow-moving component.
print("estimated slope:", round(float(beta_w[1]), 3))
assert abs(float(beta_w[1]) - 0.12) < 0.03
```
▶ What you'll see: the estimated slope is close to the true 0.12 despite seasonality and noise.

```python
plt.figure(figsize=(7, 3))
plt.plot(t_w, y_w, color="gray", alpha=0.7, label="observed")
plt.plot(t_w, trend_hat_w, color="crimson", lw=2, label="least-squares trend")
plt.title("2: least squares extracts slow drift")
plt.xlabel("time step")
plt.ylabel("value")
plt.legend()
plt.show()
```
▶ What you'll see: the red line follows the overall climb, not the month-to-month wiggles.

*Why it's done this way:* least squares chooses the line whose residual squares are smallest, so the slope estimates the average linear drift. Removing trend first prevents slow level change from masquerading as temporal dependence; otherwise a lag plot would look correlated simply because early values are low and late values are high.

### 3. Estimate seasonality as repeated within-period averages

After subtracting trend, values at the same seasonal position should share a typical offset. For monthly data, all Januaries estimate one seasonal slot, all Februaries another, and so on. We average detrended values by slot, then force the seasonal pattern to have mean zero so it does not steal level from the trend.

```python
detrended_w = y_w - trend_hat_w  # remove the slow line before reading seasonality.
period_w = 12
season_est_w = np.zeros(period_w)
for m_w in range(period_w):
    season_est_w[m_w] = np.mean(detrended_w[t_w % period_w == m_w])  # average same-month residuals.
season_est_w = season_est_w - np.mean(season_est_w)  # center one full cycle at zero.
season_hat_w = season_est_w[t_w % period_w]  # repeat the estimated cycle across time.
print("estimated seasonal cycle:", np.round(season_est_w, 2))
assert abs(float(np.mean(season_est_w))) < 1e-12
```
▶ What you'll see: a 12-number seasonal pattern with positive early-year offsets and negative late-summer offsets.

```python
plt.figure(figsize=(7, 3))
plt.plot(np.arange(period_w), season_pattern_w, marker="o", label="true seasonal pattern")
plt.plot(np.arange(period_w), season_est_w, marker="s", label="estimated from detrended data")
plt.axhline(0, color="black", lw=0.8)
plt.title("3: one seasonal offset per position in the cycle")
plt.xlabel("seasonal position")
plt.ylabel("offset")
plt.legend()
plt.show()
```
▶ What you'll see: the estimated cycle tracks the true cycle closely, with small errors from noise and trend-estimation uncertainty.

*Why it's done this way:* averaging the same seasonal position reduces random residual noise because shocks cancel, while centering the cycle enforces identifiability: without centering, adding 1 to every seasonal value and subtracting 1 from the trend would produce the same fitted series. The zero-mean seasonal constraint gives each component a distinct job.

### 4. Moving-average decomposition smooths trend without assuming a line

A line is not the only trend estimate. A centered moving average estimates the slow component by replacing each point with nearby averages. With a full seasonal window, the positive and negative seasonal offsets mostly cancel, leaving a smooth local level.

```python
def moving_average_w(x_w, window_w):
    half_w = window_w // 2
    out_w = np.full(len(x_w), np.nan)
    for i_w in range(half_w, len(x_w) - half_w):
        out_w[i_w] = np.mean(x_w[i_w - half_w:i_w + half_w + 1])
    return out_w

trend_ma_w = moving_average_w(y_w, 13)  # odd 13-step window gives a centered local trend.
valid_ma_w = ~np.isnan(trend_ma_w)
print("first valid moving-average trend:", round(float(trend_ma_w[valid_ma_w][0]), 3))
assert int(valid_ma_w.sum()) == 36
```
▶ What you'll see: the first and last six points are undefined because a centered window needs neighbors on both sides.

```python
resid_ma_w = y_w - trend_ma_w - season_hat_w  # residual after moving-average trend and estimated season.
print("residual mean on valid window:", round(float(np.nanmean(resid_ma_w)), 3))
assert abs(float(np.nanmean(resid_ma_w))) < 0.2
```
▶ What you'll see: the valid-window residual mean is near zero after removing smooth level and cycle.

```python
fig, ax_w = plt.subplots(3, 1, figsize=(7, 6), sharex=True)
ax_w[0].plot(t_w, y_w, color="gray", label="observed")
ax_w[0].plot(t_w, trend_ma_w, color="crimson", label="moving-average trend")
ax_w[0].legend(); ax_w[0].set_title("4: decomposition panels")
ax_w[1].plot(t_w, season_hat_w, color="darkorange"); ax_w[1].set_ylabel("season")
ax_w[2].plot(t_w, resid_ma_w, color="teal"); ax_w[2].axhline(0, color="black", lw=0.8); ax_w[2].set_ylabel("residual")
ax_w[2].set_xlabel("time step")
plt.show()
```
▶ What you'll see: the top panel keeps slow drift, the middle repeats the same seasonal curve, and the bottom is much smaller random-looking leftover variation.

*Why it's done this way:* a moving average is a low-pass filter: it preserves slow changes and cancels faster oscillations. The odd centered window keeps the estimate aligned with the original timestamp. The edge `nan` values are honest — using future or missing neighbors silently would change the meaning of the trend estimate.

### 5. Stationarity asks whether mean, variance, and lag behavior stay stable

Weak stationarity means the mean, variance, and covariance at a given lag do not depend on calendar time. We cannot prove that from one finite sample, but we can run practical diagnostics: compare rolling means, rolling variances, and lag-1 autocorrelation in early versus late windows.

```python
def rolling_mean_w(x_w, window_w):
    return np.array([np.mean(x_w[i_w:i_w + window_w]) for i_w in range(len(x_w) - window_w + 1)])

def rolling_var_w(x_w, window_w):
    return np.array([np.var(x_w[i_w:i_w + window_w]) for i_w in range(len(x_w) - window_w + 1)])

roll_raw_w = rolling_mean_w(y_w, 12)
roll_resid_w = rolling_mean_w(resid_small_w, 3)
print("raw rolling-mean drift:", round(float(roll_raw_w[-1] - roll_raw_w[0]), 3))
print("small residual rolling means:", np.round(roll_resid_w, 3))
assert float(roll_raw_w[-1] - roll_raw_w[0]) > 3.5
```
▶ What you'll see: the raw level's rolling mean drifts upward, while residual summaries are centered much more tightly.

```python
valid_resid_w = resid_ma_w[valid_ma_w]
roll_resid_ma_w = rolling_mean_w(valid_resid_w, 12)
roll_var_resid_w = rolling_var_w(valid_resid_w, 12)
print("decomposed residual mean drift:", round(float(roll_resid_ma_w[-1] - roll_resid_ma_w[0]), 3))
print("residual variance range:", round(float(np.max(roll_var_resid_w) - np.min(roll_var_resid_w)), 3))
assert abs(float(roll_resid_ma_w[-1] - roll_resid_ma_w[0])) < 0.5
```
▶ What you'll see: residual rolling mean and variance vary far less than the raw series level.

```python
plt.figure(figsize=(7, 3))
plt.plot(roll_raw_w, label="raw 12-step rolling mean")
plt.plot(np.arange(len(roll_resid_ma_w)) + 6, roll_resid_ma_w + np.mean(y_w), label="residual rolling mean shifted for display")
plt.title("5: rolling means reveal nonstationary level")
plt.xlabel("window start")
plt.ylabel("mean")
plt.legend()
plt.show()
```
▶ What you'll see: the raw rolling mean slopes upward; the residual mean is almost flat once shifted onto the same display scale.

*Why it's done this way:* stationarity is a stability claim about the data-generating rules, not a visual preference. Rolling windows approximate “if I estimate the mean or variance here versus later, do I get the same answer?” A trended level fails that test, while a well-decomposed residual should be much closer.

### 6. Differencing removes level drift by modeling increments

First differencing replaces levels with changes:

$$\Delta y_t = y_t - y_{t-1}.$$

For a linear trend $a + bt$, the difference is $(a+bt)-(a+b(t-1))=b$, so the changing level becomes a roughly constant increment. This is why ARIMA uses differencing before fitting lag equations to nonstationary levels.

```python
diff_w = y_w[1:] - y_w[:-1]  # first difference.
roll_diff_w = rolling_mean_w(diff_w, 12)
print("first five differences:", np.round(diff_w[:5], 3))
print("differenced rolling-mean drift:", round(float(roll_diff_w[-1] - roll_diff_w[0]), 3))
assert abs(float(roll_diff_w[-1] - roll_diff_w[0])) < abs(float(roll_raw_w[-1] - roll_raw_w[0]))
```
▶ What you'll see: differences fluctuate around a much steadier average than raw levels.

```python
seasonal_diff_w = y_w[period_w:] - y_w[:-period_w]  # subtract same month last year.
print("seasonal difference mean:", round(float(np.mean(seasonal_diff_w)), 3))
print("expected annual trend gain:", round(0.12 * period_w, 3))
assert abs(float(np.mean(seasonal_diff_w)) - 1.44) < 0.35
```
▶ What you'll see: subtracting the same season cancels most seasonality and leaves roughly one year's trend gain.

```python
fig, ax_w = plt.subplots(2, 1, figsize=(7, 5), sharex=False)
ax_w[0].plot(t_w, y_w, color="gray"); ax_w[0].set_title("6: raw nonstationary level")
ax_w[1].plot(t_w[1:], diff_w, color="seagreen"); ax_w[1].axhline(np.mean(diff_w), color="black", lw=0.8); ax_w[1].set_title("first differences: local increments")
plt.tight_layout(); plt.show()
```
▶ What you'll see: the raw plot climbs, while the differenced plot oscillates around a relatively stable center.

*Why it's done this way:* differencing changes the target from “what is the level?” to “how much did it move?” That destroys a linear deterministic trend because adjacent levels share almost the same trend value. The cost is that we lose one observation and amplify high-frequency noise, so differencing is a remedy for nonstationary levels, not a decoration to apply blindly.

### ✍️ Toy 1 · Ordered additive components make the series

A decomposition starts by keeping time order visible: trend, season, and residual add point-by-point.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)                  # -> seeded generator for reproducible toys
t1_t = np.arange(8)                                # -> [0, 1, 2, 3, 4, 5, 6, 7]
print("time index:", t1_t.tolist())                # -> [0, 1, 2, 3, 4, 5, 6, 7]
t1_trend = 10 + 0.5 * t1_t                         # -> [10.0, 10.5, 11.0, 11.5, 12.0, 12.5, 13.0, 13.5]
print("trend:", t1_trend.tolist())                 # -> [10.0, 10.5, 11.0, 11.5, 12.0, 12.5, 13.0, 13.5]
t1_pattern = np.array([1.0, -1.0, 0.5, -0.5])       # -> [1.0, -1.0, 0.5, -0.5]
print("one seasonal cycle:", t1_pattern.tolist())  # -> [1.0, -1.0, 0.5, -0.5]
t1_season = t1_pattern[t1_t % 4]                   # -> [1.0, -1.0, 0.5, -0.5, 1.0, -1.0, 0.5, -0.5]
print("repeated season:", t1_season.tolist())      # -> [1.0, -1.0, 0.5, -0.5, 1.0, -1.0, 0.5, -0.5]
t1_resid = np.array([0.0, 0.2, -0.1, 0.0, 0.1, -0.2, 0.0, 0.2])  # -> [0.0, 0.2, -0.1, 0.0, 0.1, -0.2, 0.0, 0.2]
print("residual:", t1_resid.tolist())              # -> [0.0, 0.2, -0.1, 0.0, 0.1, -0.2, 0.0, 0.2]
t1_y = t1_trend + t1_season                        # -> [11.0, 9.5, 11.5, 11.0, 13.0, 11.5, 13.5, 13.0]
t1_y = t1_y + t1_resid                             # -> [11.0, 9.7, 11.4, 11.0, 13.1, 11.3, 13.5, 13.2]
print("observed y:", np.round(t1_y, 1).tolist())   # -> [11.0, 9.7, 11.4, 11.0, 13.1, 11.3, 13.5, 13.2]
assert np.allclose(t1_y, [11.0, 9.7, 11.4, 11.0, 13.1, 11.3, 13.5, 13.2])

plt.figure(figsize=(5.2, 2.8))
plt.plot(t1_t, t1_y, "o-", label="observed")
plt.plot(t1_t, t1_trend, "--", label="trend")
plt.plot(t1_t, t1_trend + t1_season, ":", label="trend + season")
plt.xlabel("time")
plt.ylabel("value")
plt.title("Toy 1 · ordered components add up")
plt.legend()
plt.show()
```
▶ What you'll see: the observed line follows the trend but wiggles by the repeated seasonal offsets.

### ✍️ Toy 2 · Least-squares trend solves a two-column system

A linear trend fit is ordinary least squares with an intercept column and a time column.

```python
import numpy as np

t2_rng = np.random.default_rng(0)                  # -> seeded generator for reproducible toys
t2_y = np.array([3.0, 4.0, 5.0, 5.0, 6.0, 7.0, 8.0, 8.0])  # -> [3.0, 4.0, 5.0, 5.0, 6.0, 7.0, 8.0, 8.0]
print("series:", t2_y.tolist())                   # -> [3.0, 4.0, 5.0, 5.0, 6.0, 7.0, 8.0, 8.0]
t2_t = np.arange(t2_y.size)                        # -> [0, 1, 2, 3, 4, 5, 6, 7]
print("time:", t2_t.tolist())                     # -> [0, 1, 2, 3, 4, 5, 6, 7]
t2_X = np.column_stack([np.ones_like(t2_t), t2_t]) # -> [[1, 0], [1, 1], ..., [1, 7]]
print("design rows:", t2_X.tolist())              # -> [[1, 0], [1, 1], [1, 2], [1, 3], [1, 4], [1, 5], [1, 6], [1, 7]]
t2_xtx = t2_X.T @ t2_X                             # -> [[8, 28], [28, 140]]
print("X^T X:", t2_xtx.tolist())                  # -> [[8, 28], [28, 140]]
t2_xty = t2_X.T @ t2_y                             # -> [46.0, 192.0]
print("X^T y:", t2_xty.tolist())                  # -> [46.0, 192.0]
t2_beta = np.linalg.inv(t2_xtx) @ t2_xty           # -> [3.167, 0.738]
print("beta:", np.round(t2_beta, 3).tolist())      # -> [3.167, 0.738]
t2_fit = t2_X @ t2_beta                            # -> [3.167, 3.905, 4.643, 5.381, 6.119, 6.857, 7.595, 8.333]
print("fitted trend:", np.round(t2_fit, 3).tolist())  # -> [3.167, 3.905, 4.643, 5.381, 6.119, 6.857, 7.595, 8.333]
t2_resid = t2_y - t2_fit                           # -> [-0.167, 0.095, 0.357, -0.381, -0.119, 0.143, 0.405, -0.333]
print("residuals:", np.round(t2_resid, 3).tolist())  # -> [-0.167, 0.095, 0.357, -0.381, -0.119, 0.143, 0.405, -0.333]
assert np.allclose(np.round(t2_beta, 3), [3.167, 0.738])

plt.figure(figsize=(5.2, 2.8))
plt.plot(t2_t, t2_y, "o", label="data")
plt.plot(t2_t, t2_fit, "-", label="least-squares trend")
plt.xlabel("time")
plt.ylabel("value")
plt.title("Toy 2 · trend from XᵀX beta = Xᵀy")
plt.legend()
plt.show()
```
▶ What you'll see: the fitted line has intercept about `3.167` and slope about `0.738`.

### ✍️ Toy 3 · Seasonal slots are averaged then centered

After removing trend, average all matching cycle positions and subtract the cycle mean so seasonality does not steal level.

```python
import numpy as np

t3_rng = np.random.default_rng(0)                  # -> seeded generator for reproducible toys
t3_y = np.array([11.0, 9.0, 10.0, 8.0, 13.0, 11.0, 12.0, 10.0])  # -> [11.0, 9.0, 10.0, 8.0, 13.0, 11.0, 12.0, 10.0]
print("series:", t3_y.tolist())                   # -> [11.0, 9.0, 10.0, 8.0, 13.0, 11.0, 12.0, 10.0]
t3_t = np.arange(t3_y.size)                        # -> [0, 1, 2, 3, 4, 5, 6, 7]
print("time:", t3_t.tolist())                     # -> [0, 1, 2, 3, 4, 5, 6, 7]
t3_trend = 10 + 0.5 * t3_t                         # -> [10.0, 10.5, 11.0, 11.5, 12.0, 12.5, 13.0, 13.5]
print("trend:", t3_trend.tolist())                # -> [10.0, 10.5, 11.0, 11.5, 12.0, 12.5, 13.0, 13.5]
t3_detrended = t3_y - t3_trend                     # -> [1.0, -1.5, -1.0, -3.5, 1.0, -1.5, -1.0, -3.5]
print("detrended:", t3_detrended.tolist())         # -> [1.0, -1.5, -1.0, -3.5, 1.0, -1.5, -1.0, -3.5]
t3_period = 4                                      # -> 4
t3_slot0 = t3_detrended[t3_t % t3_period == 0]     # -> [1.0, 1.0]
print("slot 0 values:", t3_slot0.tolist())         # -> [1.0, 1.0]
t3_slot1 = t3_detrended[t3_t % t3_period == 1]     # -> [-1.5, -1.5]
print("slot 1 values:", t3_slot1.tolist())         # -> [-1.5, -1.5]
t3_slot2 = t3_detrended[t3_t % t3_period == 2]     # -> [-1.0, -1.0]
print("slot 2 values:", t3_slot2.tolist())         # -> [-1.0, -1.0]
t3_slot3 = t3_detrended[t3_t % t3_period == 3]     # -> [-3.5, -3.5]
print("slot 3 values:", t3_slot3.tolist())         # -> [-3.5, -3.5]
t3_raw_cycle = np.array([t3_slot0.mean(), t3_slot1.mean(), t3_slot2.mean(), t3_slot3.mean()])  # -> [1.0, -1.5, -1.0, -3.5]
print("raw cycle means:", t3_raw_cycle.tolist())   # -> [1.0, -1.5, -1.0, -3.5]
t3_centered_cycle = t3_raw_cycle - t3_raw_cycle.mean()  # -> [2.25, -0.25, 0.25, -2.25]
print("centered cycle:", t3_centered_cycle.tolist())   # -> [2.25, -0.25, 0.25, -2.25]
t3_season = t3_centered_cycle[t3_t % t3_period]    # -> [2.25, -0.25, 0.25, -2.25, 2.25, -0.25, 0.25, -2.25]
print("repeated season:", t3_season.tolist())      # -> [2.25, -0.25, 0.25, -2.25, 2.25, -0.25, 0.25, -2.25]
assert abs(float(t3_centered_cycle.mean())) < 1e-12

plt.figure(figsize=(5.2, 2.8))
plt.bar(np.arange(t3_period), t3_centered_cycle, color="darkorange")
plt.axhline(0, color="black", linewidth=0.8)
plt.xlabel("seasonal slot")
plt.ylabel("offset")
plt.title("Toy 3 · centered seasonal offsets")
plt.show()
```
▶ What you'll see: the centered cycle sums to zero, separating seasonal shape from overall level.

### ✍️ Toy 4 · Centered moving averages leave honest edges

A centered moving average can estimate trend without a line, but it cannot fill edge points without neighbors.

```python
import numpy as np

t4_rng = np.random.default_rng(0)                  # -> seeded generator for reproducible toys
t4_y = np.array([5.0, 7.0, 8.0, 12.0, 13.0, 15.0, 18.0, 18.0, 22.0])  # -> [5.0, 7.0, 8.0, 12.0, 13.0, 15.0, 18.0, 18.0, 22.0]
```

### ✍️ Toy 5 · Rolling diagnostics expose nonstationary drift

Rolling means, variances, and lag-1 scores are quick checks for changing time-series behavior.

```python

t5_lag1_early = t5_lag1(t5_y[:5])                 # -> 0.275

plt.show()
```

```python
season_pattern_a5 = np.array([0.5, 1.5, 2.5, 1.8, 0.7, -0.5, -1.8, -2.4, -1.5, -0.3, 0.6, 1.4]) # annual offsets.
season_pattern_a5 = season_pattern_a5 - np.mean(season_pattern_a5) # center cycle.
y_a5 = trend_a5 + season_pattern_a5[t_a5 % period_a5] + np.random.normal(0, 0.3, len(t_a5)) # observed data.
train_end_a5 = 60 # hold out final year.
print("train/test sizes:", train_end_a5, len(y_a5) - train_end_a5) # inspect split.
assert len(y_a5) - train_end_a5 == 12
```
▶ What you'll see: the last 12 points are reserved for chronological testing.

```python
t_train_a5 = t_a5[:train_end_a5] # training timestamps.
y_train_a5 = y_a5[:train_end_a5] # training observations only.
X_train_a5 = np.column_stack([np.ones_like(t_train_a5), t_train_a5]) # trend design on history.
beta_a5 = np.linalg.inv(X_train_a5.T @ X_train_a5) @ X_train_a5.T @ y_train_a5 # fit trend using no future data.
trend_train_a5 = X_train_a5 @ beta_a5 # fitted training trend.
print("trained slope:", round(float(beta_a5[1]), 3))
assert abs(float(beta_a5[1]) - 0.18) < 0.04
```
▶ What you'll see: the historical slope estimate is close to the data-generating slope.

```python
detrended_train_a5 = y_train_a5 - trend_train_a5 # remove fitted historical trend.
season_est_a5 = np.array([np.mean(detrended_train_a5[t_train_a5 % period_a5 == j_a5]) for j_a5 in range(period_a5)]) # estimate season from training only.
season_est_a5 = season_est_a5 - np.mean(season_est_a5) # center estimated season.
print("estimated season mean:", round(float(np.mean(season_est_a5)), 6))
assert abs(float(np.mean(season_est_a5))) < 1e-10
```
▶ What you'll see: the seasonal pattern is learned without touching the held-out year.

```python
t_test_a5 = t_a5[train_end_a5:] # future timestamps.
X_test_a5 = np.column_stack([np.ones_like(t_test_a5), t_test_a5]) # future trend design.
forecast_a5 = X_test_a5 @ beta_a5 + season_est_a5[t_test_a5 % period_a5] # extend trend and repeat season.
rmse_a5 = float(np.sqrt(np.mean((y_a5[train_end_a5:] - forecast_a5) ** 2))) # evaluate holdout error.
naive_a5 = y_a5[train_end_a5 - period_a5:train_end_a5] # seasonal naive forecast from last year.
rmse_naive_a5 = float(np.sqrt(np.mean((y_a5[train_end_a5:] - naive_a5) ** 2))) # naive benchmark.
print("decomposition RMSE:", round(rmse_a5, 3), "seasonal naive RMSE:", round(rmse_naive_a5, 3))
assert rmse_a5 < rmse_naive_a5
```
▶ What you'll see: decomposition beats copying last year's values because it extends the upward trend.
