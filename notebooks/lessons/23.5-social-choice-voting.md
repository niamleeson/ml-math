# 23.5 — Social Choice & Voting

Social choice studies how a group turns many individual rankings into one collective outcome. In ML systems, the same problem appears in ensemble voting, preference aggregation for RLHF, committee decisions, and multi-agent platforms: every voting rule preserves some evidence, discards other evidence, and creates incentives.

## 📖 Concept walkthrough — build each idea from scratch

Before the worked examples, we build social choice one idea at a time. Run each cell in order and read the printed intermediate values — every piece of logic is explicit. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix so it never clashes with the examples below.

```python
import numpy as np  # arrays for ballots, scores, and pairwise counts.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
from itertools import permutations  # standard-library enumeration of possible rankings.
np.random.seed(0)  # reproducibility for any randomized tie demonstrations.
```

### 1. Rankings and preference profiles

A voting problem starts with candidates and voters. Each voter submits a **ranking**, meaning a permutation of the candidates from favorite to least favorite. A whole table of rankings is called a **preference profile**. The key modeling choice is that the ballot is ordinal: it says A is above B, but not how many utility points separate them.

```python
cands_w = ["A", "B", "C"]  # three alternatives.
profile_w = np.array([[0, 1, 2],  # voter 0: A > B > C
                      [0, 1, 2],  # voter 1: A > B > C
                      [1, 0, 2],  # voter 2: B > A > C
                      [2, 1, 0],  # voter 3: C > B > A
                      [2, 1, 0]]) # voter 4: C > B > A
rank_matrix_w = np.zeros_like(profile_w)  # rank_matrix[v, candidate] = position in voter v's ranking.
for v_w, ballot_w in enumerate(profile_w):
    for pos_w, cand_w in enumerate(ballot_w):
        rank_matrix_w[v_w, cand_w] = pos_w
print("ballots as candidate ids:\n", profile_w)
print("rank positions (0 = top):\n", rank_matrix_w)
assert rank_matrix_w.shape == (5, 3)
plt.figure(figsize=(4.6, 3.2))
plt.imshow(rank_matrix_w, cmap="viridis_r", aspect="auto")
plt.colorbar(label="rank position (0 = best)")
plt.xticks(range(3), cands_w); plt.yticks(range(5), [f"v{v}" for v in range(5)])
plt.title("1: preference-profile matrix")
plt.xlabel("candidate"); plt.ylabel("voter")
plt.show()
```
▶ What you'll see: a voter-by-candidate heatmap where darker/top-rank positions reveal each voter's favorite.

*Why it's done this way:* storing rankings as positions makes every later rule a transparent transformation of the same ordinal evidence.

### 2. Plurality counts only first-place evidence

The simplest rule is **plurality**: each voter gives one point to the candidate ranked first. This is easy to explain, but it throws away every lower rank. That loss of information is not a bug in the code; it is the definition of the mechanism.

```python
top_choices_w = profile_w[:, 0]  # first column is each voter's favorite.
plurality_scores_w = np.bincount(top_choices_w, minlength=len(cands_w))  # one point per first-place vote.
winners_w = np.flatnonzero(plurality_scores_w == plurality_scores_w.max())
print("first-place votes:", plurality_scores_w)
print("plurality winners by id:", winners_w)
assert plurality_scores_w.tolist() == [2, 1, 2]
plt.figure(figsize=(4.2, 3.0))
plt.bar(cands_w, plurality_scores_w, color=["steelblue", "gray", "steelblue"])
plt.ylabel("first-place votes")
plt.title("2: plurality can tie A and C")
plt.ylim(0, 3)
plt.show()
```
▶ What you'll see: A and C tie with two top votes each, while B has one.

*Why it's done this way:* plurality measures concentrated first-place support, so a candidate with broad second-place support can be invisible.

### 3. Borda uses the full ranking

**Borda count** gives points by position. With three candidates, first place gets 2, second gets 1, and last gets 0. The rule now uses every rank, so a candidate who is rarely first but often acceptable can win.

```python
n_cands_w = len(cands_w)
borda_scores_w = np.zeros(n_cands_w)  # accumulate points by candidate.
for ballot_w in profile_w:
    for pos_w, cand_w in enumerate(ballot_w):
        borda_scores_w[cand_w] += n_cands_w - 1 - pos_w  # 2, 1, 0 for three candidates.
print("Borda scores:", borda_scores_w)
print("Borda winner:", cands_w[int(np.argmax(borda_scores_w))])
assert borda_scores_w.tolist() == [5.0, 6.0, 4.0]
plt.figure(figsize=(4.2, 3.0))
plt.bar(cands_w, borda_scores_w, color=["gray", "seagreen", "gray"])
plt.ylabel("Borda points")
plt.title("3: Borda rewards broad acceptability")
plt.show()
```
▶ What you'll see: B wins by Borda even though B is not the plurality winner.

*Why it's done this way:* Borda treats lower ranks as meaningful evidence instead of discarding them after first place.

### 4. Pairwise majority builds a Condorcet tournament

A **pairwise majority** comparison asks whether more voters rank candidate X above candidate Y than the reverse. Doing this for every pair creates a majority tournament. A **Condorcet winner**, if it exists, beats every other candidate head-to-head.

```python
pairwise_w = np.zeros((n_cands_w, n_cands_w), dtype=int)  # pairwise_w[i,j] = voters preferring i over j.
for i_w in range(n_cands_w):
    for j_w in range(n_cands_w):
        if i_w != j_w:
            pairwise_w[i_w, j_w] = int(np.sum(rank_matrix_w[:, i_w] < rank_matrix_w[:, j_w]))
wins_w = pairwise_w > pairwise_w.T
condorcet_w = [i for i in range(n_cands_w) if np.all(wins_w[i, np.arange(n_cands_w) != i])]
print("pairwise counts i over j:\n", pairwise_w)
print("pairwise win matrix:\n", wins_w.astype(int))
print("Condorcet winners:", [cands_w[i] for i in condorcet_w])
assert pairwise_w[1, 0] == 3 and pairwise_w[1, 2] == 3
plt.figure(figsize=(4.0, 3.2))
plt.imshow(pairwise_w, cmap="Blues", vmin=0, vmax=len(profile_w))
plt.colorbar(label="voters preferring row over column")
plt.xticks(range(3), cands_w); plt.yticks(range(3), cands_w)
plt.title("4: pairwise-majority matrix")
plt.xlabel("opponent"); plt.ylabel("candidate")
plt.show()
```
▶ What you'll see: B beats both A and C head-to-head, so B is the Condorcet winner in this profile.

*Why it's done this way:* pairwise comparison preserves majority evidence between every two alternatives, not only position scores.

### 5. Majority preference can cycle

Majority rule does not guarantee transitivity. With three voters ranking A>B>C, B>C>A, and C>A>B, the group majority says A beats B, B beats C, and C beats A. That is a **Condorcet cycle**, so no candidate beats all others.

```python
cycle_profile_w = np.array([[0, 1, 2], [1, 2, 0], [2, 0, 1]])
cycle_rank_w = np.zeros_like(cycle_profile_w)
for v_w, ballot_w in enumerate(cycle_profile_w):
    for pos_w, cand_w in enumerate(ballot_w):
        cycle_rank_w[v_w, cand_w] = pos_w
cycle_pair_w = np.zeros((3, 3), dtype=int)
for i_w in range(3):
    for j_w in range(3):
        if i_w != j_w:
            cycle_pair_w[i_w, j_w] = int(np.sum(cycle_rank_w[:, i_w] < cycle_rank_w[:, j_w]))
cycle_wins_w = cycle_pair_w > cycle_pair_w.T
print("cycle pairwise counts:\n", cycle_pair_w)
print("A beats B, B beats C, C beats A:", cycle_wins_w[0,1], cycle_wins_w[1,2], cycle_wins_w[2,0])
assert cycle_wins_w[0, 1] and cycle_wins_w[1, 2] and cycle_wins_w[2, 0]
angles_w = np.linspace(0, 2*np.pi, 4)[:-1] + np.pi/2
xy_w = np.c_[np.cos(angles_w), np.sin(angles_w)]
plt.figure(figsize=(4.0, 3.6))
plt.scatter(xy_w[:,0], xy_w[:,1], s=500, color="white", edgecolor="black")
for i_w, lab_w in enumerate(cands_w):
    plt.text(xy_w[i_w,0], xy_w[i_w,1], lab_w, ha="center", va="center", fontsize=14)
for a_w, b_w in [(0,1), (1,2), (2,0)]:
    plt.annotate("", xy=xy_w[b_w], xytext=xy_w[a_w], arrowprops=dict(arrowstyle="->", lw=2, color="crimson"))
plt.axis("off"); plt.title("5: Condorcet cycle A→B→C→A")
plt.show()
```
▶ What you'll see: arrows form a directed loop, proving pairwise majority has no top candidate here.

*Why it's done this way:* the graph makes the impossibility visible — majority comparisons can be locally decisive but globally circular.

### 6. Agenda order is part of the mechanism

If pairwise votes are held sequentially, the **agenda** decides which comparison happens first. In a cycle, different agendas can select different final winners. The schedule is therefore not a clerical detail; it changes the voting rule.

```python
def agenda_winner_w(order_w, wins_w):
    current_w = order_w[0]
    for challenger_w in order_w[1:]:
        current_w = current_w if wins_w[current_w, challenger_w] else challenger_w
    return current_w
agendas_w = [(0, 1, 2), (1, 2, 0), (2, 0, 1)]
agenda_winners_w = [agenda_winner_w(list(a_w), cycle_wins_w) for a_w in agendas_w]
print("agendas:", [[cands_w[i] for i in a] for a in agendas_w])
print("winners:", [cands_w[i] for i in agenda_winners_w])
assert agenda_winners_w == [2, 0, 1]
plt.figure(figsize=(5.0, 3.0))
plt.bar(["A then B then C", "B then C then A", "C then A then B"], agenda_winners_w, color="darkorange")
plt.yticks(range(3), cands_w)
plt.xticks(rotation=20, ha="right")
plt.title("6: agenda order changes the winner")
plt.ylabel("final winner")
plt.show()
```
▶ What you'll see: each agenda in the cycle produces a different final winner.

*Why it's done this way:* sequential majority voting needs an agenda, and in cyclic profiles the agenda effectively controls the outcome.

### 7. Strategy-proofness and Arrow-style criteria

Voting rules are mechanisms, so voters may gain by misreporting. We can test simple criteria from scratch: unanimity, independence of irrelevant alternatives (IIA) on a constructed pair, and manipulability. These checks are small, but they show the same lesson as Arrow/Gibbard-Satterthwaite style results: desirable fairness and incentive properties pull against each other.

```python
def borda_winner_w(profile_w, m_w):
    scores_w = np.zeros(m_w)
    for ballot_w in profile_w:
        for pos_w, cand_w in enumerate(ballot_w):
            scores_w[cand_w] += m_w - 1 - pos_w
    return int(np.argmax(scores_w)), scores_w
truth_w = np.array([[0, 1, 2], [1, 0, 2], [1, 0, 2]])  # voter 0 prefers A over B, but B wins honestly.
misreport_w = truth_w.copy(); misreport_w[0] = np.array([0, 2, 1])  # voter 0 buries B below C.
honest_win_w, honest_scores_w = borda_winner_w(truth_w, 3)
strategic_win_w, strategic_scores_w = borda_winner_w(misreport_w, 3)
print("honest Borda scores:", honest_scores_w, "winner", cands_w[honest_win_w])
print("after voter 0 misreports:", strategic_scores_w, "winner", cands_w[strategic_win_w])
print("manipulation helped voter 0:", rank_matrix_w.shape[1] == 3 and strategic_win_w == 0 and honest_win_w == 1)
assert honest_win_w == 1 and strategic_win_w == 0
x_w = np.arange(3)
plt.figure(figsize=(4.6, 3.0))
plt.bar(x_w - 0.18, honest_scores_w, width=0.36, label="honest", color="gray")
plt.bar(x_w + 0.18, strategic_scores_w, width=0.36, label="strategic", color="crimson")
plt.xticks(x_w, cands_w); plt.ylabel("Borda score")
plt.title("7: a Borda manipulation by burying B")
plt.legend()
plt.show()
```
▶ What you'll see: the strategic ballot changes the Borda winner from B to A, helping voter 0.

*Why it's done this way:* testing one explicit manipulation makes incentive compatibility concrete before naming the impossibility theorem.

### ✍️ Toy 1 · Rankings become rank-position matrices

A ballot lists candidates from favorite to least favorite. The rank-position matrix flips that view so
`rank[voter, candidate]` is easy to compare.

```python
import numpy as np
import matplotlib.pyplot as plt


t1_rng = np.random.default_rng(0)
t1_cands = np.array(["A", "B", "C"])
t1_profile = np.array([[0, 2, 1], [1, 0, 2], [2, 1, 0], [1, 2, 0]])
t1_rank = np.zeros_like(t1_profile)
for t1_voter in range(t1_profile.shape[0]):
    t1_ballot = t1_profile[t1_voter]
    for t1_pos in range(t1_ballot.size):
        t1_cand = t1_ballot[t1_pos]
        t1_rank[t1_voter, t1_cand] = t1_pos
print("candidates:", t1_cands.tolist())  # -> ['A', 'B', 'C']
print("ballots as ids:", t1_profile.tolist())  # -> [[0, 2, 1], [1, 0, 2], [2, 1, 0], [1, 2, 0]]
print("rank positions:", t1_rank.tolist())  # -> [[0, 2, 1], [1, 0, 2], [2, 1, 0], [2, 0, 1]]
plt.figure(figsize=(4.2, 2.8))
plt.imshow(t1_rank, cmap="viridis_r", vmin=0, vmax=2)
plt.colorbar(label="rank position")
plt.xticks(np.arange(3), t1_cands)
plt.yticks(np.arange(4), ["v0", "v1", "v2", "v3"])
plt.title("Toy 1 · rank positions")
plt.show()
assert t1_rank.tolist() == [[0, 2, 1], [1, 0, 2], [2, 1, 0], [2, 0, 1]]
```
▶ What you'll see: every ballot row has been inverted so lower numbers mean stronger preference.

### ✍️ Toy 6 · Agenda order selects a path through a cycle

Sequential majority voting needs an agenda; in a cycle, different paths produce different winners.

```python
import numpy as np
import matplotlib.pyplot as plt


t6_rng = np.random.default_rng(0)
t6_cands = np.array(["A", "B", "C"])
t6_wins = np.array([[False, False, True], [True, False, False], [False, True, False]])
t6_agendas = np.array([[0, 2, 1], [2, 1, 0], [1, 0, 2]])
t6_winners = []
for t6_agenda in t6_agendas:

t6_winners = np.array(t6_winners)
print("win matrix:", t6_wins.astype(int).tolist())  # -> [[0, 0, 1], [1, 0, 0], [0, 1, 0]]

```
▶ What you'll see: the same majority cycle lets the agenda pick B, A, or C.

### ✍️ Toy 7 · Strategic burial can change a Borda winner

A voter who prefers A to B may bury B below C, changing the deterministic Borda tie-break winner.

```python
import numpy as np
import matplotlib.pyplot as plt


t7_rng = np.random.default_rng(0)
t7_cands = np.array(["A", "B", "C"])
t7_truth = np.array([[0, 1, 2], [1, 0, 2], [1, 0, 2], [2, 0, 1], [2, 1, 0]])
t7_misreport = t7_truth.copy()
t7_misreport[0] = np.array([0, 2, 1])
t7_points = np.array([2, 1, 0])
t7_honest = np.zeros(3)
t7_strategic = np.zeros(3)
for t7_ballot in t7_truth:
    for t7_pos in range(3):
        t7_honest[t7_ballot[t7_pos]] += t7_points[t7_pos]
for t7_ballot in t7_misreport:
    for t7_pos in range(3):
        t7_strategic[t7_ballot[t7_pos]] += t7_points[t7_pos]
```

## 🛠️ Setup

```python
import numpy as np  # arrays, ranking matrices, and numerical checks.
import matplotlib.pyplot as plt  # visualizations for every example.
from itertools import permutations  # standard-library enumeration of rankings.
np.random.seed(0)  # reproducible tie and profile demonstrations.

CANDS = ["A", "B", "C", "D"]  # shared labels; examples often use the first three.

def rank_positions(profile, m=None):  # convert ballots into rank positions: lower means preferred.
    profile = np.asarray(profile, dtype=int)
    if m is None:
        m = int(profile.max()) + 1
    ranks = np.zeros((profile.shape[0], m), dtype=int)
    for v, ballot in enumerate(profile):
        for pos, cand in enumerate(ballot):
            ranks[v, cand] = pos
    return ranks

def plurality_scores(profile, m=None):  # count first-place votes from scratch.
    profile = np.asarray(profile, dtype=int)
    if m is None:
        m = int(profile.max()) + 1
    return np.bincount(profile[:, 0], minlength=m).astype(float)

def borda_scores(profile, m=None):  # assign m-1, m-2, ..., 0 points down each ballot.
    profile = np.asarray(profile, dtype=int)
    if m is None:
        m = int(profile.max()) + 1
    scores = np.zeros(m, dtype=float)
    for ballot in profile:
        for pos, cand in enumerate(ballot):
            scores[cand] += m - 1 - pos
    return scores

def pairwise_counts(profile, m=None):  # count voters preferring row candidate over column candidate.
    ranks = rank_positions(profile, m)
    m = ranks.shape[1]
    counts = np.zeros((m, m), dtype=int)
    for i in range(m):
        for j in range(m):
            if i != j:
                counts[i, j] = int(np.sum(ranks[:, i] < ranks[:, j]))
    return counts

def condorcet_winners(profile, m=None):  # return all candidates beating every opponent head-to-head.
    counts = pairwise_counts(profile, m)
    wins = counts > counts.T
    m = counts.shape[0]
    return [i for i in range(m) if np.all(wins[i, np.arange(m) != i])]

def irv_winner(profile, m=None):  # instant-runoff voting with deterministic lowest-id tie-breaking.
    profile = np.asarray(profile, dtype=int)
    if m is None:
        m = int(profile.max()) + 1
    active = list(range(m))
    rounds = []
    while len(active) > 1:
        counts = np.zeros(m, dtype=int)
        for ballot in profile:
            for cand in ballot:
                if cand in active:
                    counts[cand] += 1
                    break
        rounds.append(counts.copy())
        active_counts = counts[active]
        if active_counts.max() > profile.shape[0] / 2:
            return int(active[int(np.argmax(active_counts))]), rounds
        loser = active[int(np.argmin(active_counts))]
        active.remove(loser)
    return int(active[0]), rounds

def majority_graph_xy(m):  # positions for a small tournament diagram.
    angles = np.linspace(0, 2*np.pi, m, endpoint=False) + np.pi/2
    return np.c_[np.cos(angles), np.sin(angles)]
```

**Goal.** Compare A versus B before and after moving only C, because IIA says the social choice between A and B should not depend on an irrelevant candidate's position. We build it in 1 step.

```python
profile_e5 = np.array([[0, 2, 1], [1, 0, 2], [2, 1, 0]])
changed_e5 = np.array([[0, 1, 2], [1, 2, 0], [1, 0, 2]])  # each voter's A-vs-B order is unchanged.
rank_e5 = rank_positions(profile_e5, 3); changed_rank_e5 = rank_positions(changed_e5, 3)
ab_same_e5 = np.all((rank_e5[:,0] < rank_e5[:,1]) == (changed_rank_e5[:,0] < changed_rank_e5[:,1]))
borda_e5 = int(np.argmax(borda_scores(profile_e5, 3)))
changed_borda_e5 = int(np.argmax(borda_scores(changed_e5, 3)))
print("A-vs-B orders unchanged:", ab_same_e5)
print("Borda winners before/after:", CANDS[borda_e5], CANDS[changed_borda_e5])
assert ab_same_e5 and borda_e5 != changed_borda_e5

plt.bar(["before", "after moving C"], [borda_e5, changed_borda_e5], color=["purple", "orange"])
```

#### A1. Enumerate all rankings and find manipulable profiles

**Goal.** Brute-force small Borda elections, because exhaustive search makes strategy vulnerability concrete. We build it in 1 step.

```python
rankings_a1 = list(permutations(range(3)))
manipulable_a1 = 0
checked_a1 = 0
for b0_a1 in rankings_a1:
    for b1_a1 in rankings_a1:
        for b2_a1 in rankings_a1:
            profile_a1 = np.array([b0_a1, b1_a1, b2_a1])
            honest_scores_a1 = borda_scores(profile_a1, 3)
            honest_win_a1 = int(np.argmax(honest_scores_a1))
            ranks_a1 = rank_positions(profile_a1, 3)
            for voter_a1 in range(3):
                for alt_ballot_a1 in rankings_a1:
                    alt_profile_a1 = profile_a1.copy(); alt_profile_a1[voter_a1] = np.array(alt_ballot_a1)
                    alt_win_a1 = int(np.argmax(borda_scores(alt_profile_a1, 3)))
                    if ranks_a1[voter_a1, alt_win_a1] < ranks_a1[voter_a1, honest_win_a1]:
                        manipulable_a1 += 1
                        break
                else:
                    continue
                break
            checked_a1 += 1
print("profiles checked:", checked_a1, "manipulable profiles found:", manipulable_a1)
assert checked_a1 == 216 and manipulable_a1 > 0
plt.figure(figsize=(4.2, 3.0))
plt.bar(["manipulable", "not found"], [manipulable_a1, checked_a1 - manipulable_a1], color=["crimson", "gray"])
plt.title("A1: brute-force Borda manipulation search")
plt.ylabel("profiles")
plt.show()
```
▶ What you'll see: many small profiles admit at least one beneficial misreport under Borda.

👀 Takeaway: manipulability is not rare edge-case behavior in unrestricted preference domains.
