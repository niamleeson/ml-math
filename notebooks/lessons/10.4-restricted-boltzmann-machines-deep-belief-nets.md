# 10.4 — Restricted Boltzmann Machines & Deep Belief Nets

Restricted Boltzmann Machines (RBMs) are small binary energy models: they do not decode inputs directly, but assign low energy to compatible visible-hidden configurations and then sample from that landscape. In this lesson, you will build RBM energy, conditional Bernoulli updates, Gibbs sampling, contrastive divergence, and a tiny deep belief net pretraining stack from scratch with NumPy.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build restricted Boltzmann machines one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including energy, factorized conditionals, Gibbs sampling, and contrastive divergence, is shown so the model is not a black box. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, logits, Bernoulli sampling, and small linear algebra.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for samples and toy training.

def sigmoid_w(x):
    return 1 / (1 + np.exp(-x))
```

### 1. Energy: scoring visible-hidden compatibility

An RBM has binary visible units `v` (data bits) and binary hidden units `h` (latent causes). Instead of producing a reconstruction in one deterministic pass, it gives every joint configuration an **energy**

$$E(v,h)=-b^\top v-c^\top h-v^\top W h.$$

Low energy means the visible bits, hidden bits, biases, and pairwise visible-hidden weights agree. The unnormalized probability weight is `exp(-E)`, so lowering energy exponentially raises probability mass.

```python
v_w = np.array([1., 0.])  # two visible bits, matching the lesson's hand-auditable case.
h_w = np.array([1., 1.])  # two hidden bits switched on.
b_w = np.array([0.2, -0.1])  # visible biases: bit 0 is slightly encouraged, bit 1 discouraged.
c_w = np.array([0.1, 0.2])  # hidden biases: both hidden causes are mildly encouraged.
W_w = np.array([[0.3, -0.1], [0.4, 0.2]])  # visible-hidden interactions only.
energy_w = -float(b_w @ v_w + c_w @ h_w + v_w @ W_w @ h_w)  # RBM energy formula.
print("energy E(v,h):", round(energy_w, 4))
assert round(energy_w, 4) == -0.7000
```
▶ What you'll see: the chosen visible-hidden pair has energy `-0.7000`, exactly the small number from the lesson block.

```python
weight_w = np.exp(-energy_w)  # unnormalized probability weight.
print("unnormalized exp(-E):", round(float(weight_w), 3))
assert round(float(weight_w), 3) == 2.014
plt.figure(figsize=(4, 3))
plt.bar(["energy E", "weight exp(-E)"], [energy_w, weight_w], color=["crimson", "seagreen"])
plt.title("1: low energy becomes high weight")
plt.show()
```
▶ What you'll see: negative energy turns into a probability weight above 1 before normalization.

*Why it's done this way:* energy models separate **compatibility scoring** from normalization. The bilinear term `vᵀWh` is a sum of all active visible-hidden pair agreements; the negative sign means agreement lowers energy. `exp(-E)` makes energy differences multiplicative: reducing energy by 1 multiplies unnormalized probability by `e`. The missing piece is the partition function `Z`, because weights become probabilities only after dividing by the sum over all binary configurations.

### 2. The partition function: probabilities require summing all states

The joint probability is `p(v,h)=exp(-E(v,h))/Z`, where `Z` is the sum of `exp(-E)` over every possible visible-hidden state. For realistic RBMs that sum is impossible, but with two visible and two hidden units we can enumerate all 16 states and see exactly why normalization matters.

```python
states_w = []
weights_w = []
for v0_w in [0., 1.]:
    for v1_w in [0., 1.]:
        for h0_w in [0., 1.]:
            for h1_w in [0., 1.]:
                vv_w = np.array([v0_w, v1_w])
                hh_w = np.array([h0_w, h1_w])
                e_w = -float(b_w @ vv_w + c_w @ hh_w + vv_w @ W_w @ hh_w)
                states_w.append((vv_w.copy(), hh_w.copy(), e_w))
                weights_w.append(np.exp(-e_w))
Z_w = float(np.sum(weights_w))
print("number of joint states:", len(states_w))
print("partition function Z:", round(Z_w, 3))
```
▶ What you'll see: the tiny RBM has 16 joint states and a finite normalizer `Z`.

```python
target_weight_w = np.exp(-energy_w)
prob_target_w = float(target_weight_w / Z_w)
print("p(v=[1,0], h=[1,1]):", round(prob_target_w, 4))
print("sum of all probabilities:", round(float(np.sum(np.array(weights_w) / Z_w)), 6))
assert abs(np.sum(np.array(weights_w) / Z_w) - 1) < 1e-12
plt.figure(figsize=(5, 3))
plt.bar(np.arange(len(weights_w)), np.array(weights_w) / Z_w, color="steelblue")
plt.title("2: normalized probabilities over 16 states")
plt.xlabel("state index")
plt.ylabel("probability")
plt.show()
```
▶ What you'll see: probabilities over all states sum to 1, and the target state is only one slice of the mass.

*Why it's done this way:* `exp(-E)` alone is not a probability because its values do not add to 1. Dividing by `Z` converts relative preferences into calibrated probabilities. The catch is computational: with `D` visible and `K` hidden bits, `Z` sums `2^(D+K)` states, so training needs sampling approximations instead of exact normalization.

### 3. Conditional factorization: why the R in RBM matters

The word **restricted** means there are no visible-visible edges and no hidden-hidden edges. Because hidden units do not directly interact with each other, the conditional distribution `p(h|v)` factorizes into independent Bernoulli probabilities:

$$p(h_j=1\mid v)=\sigma(c_j+W_{:j}^\top v).$$

The same logic gives `p(v_i=1|h)=σ(b_i+W_{i:}h)`. This is the design decision that makes alternating Gibbs updates cheap.

```python
hidden_logits_w = c_w + v_w @ W_w  # one logit per hidden unit.
hidden_probs_w = sigmoid_w(hidden_logits_w)  # independent Bernoulli parameters p(h_j=1|v).
print("hidden logits:", np.round(hidden_logits_w, 3))
print("p(h=1 | v):", np.round(hidden_probs_w, 3))
assert np.allclose(np.round(hidden_probs_w, 3), [0.599, 0.525])
```
▶ What you'll see: each hidden unit receives its own scalar logit from the same visible vector.

```python
visible_logits_w = b_w + W_w @ h_w  # one logit per visible unit.
visible_probs_w = sigmoid_w(visible_logits_w)  # independent Bernoulli parameters p(v_i=1|h).
print("visible logits:", np.round(visible_logits_w, 3))
print("p(v=1 | h):", np.round(visible_probs_w, 3))
plt.figure(figsize=(5, 3))
plt.bar(["h0", "h1", "v0", "v1"], np.r_[hidden_probs_w, visible_probs_w], color="darkorange")
plt.ylim(0, 1)
plt.title("3: conditional Bernoulli probabilities")
plt.ylabel("probability of bit = 1")
plt.show()
```
▶ What you'll see: four probabilities, each between 0 and 1, ready for independent Bernoulli sampling.

*Why it's done this way:* conditioning on one layer turns every cross-layer term involving a unit into a linear logit, and the lack of same-layer edges removes coupling among units inside the updated layer. If hidden-hidden edges existed, `h0`'s probability would depend on `h1`, so the hidden layer could not be updated in parallel with one sigmoid vector.

### 4. Gibbs sampling: walking through the learned landscape

A Gibbs chain alternates `h ~ p(h|v)` and `v ~ p(v|h)`. Each half-step is simple because of conditional factorization, but the repeated alternation is a Markov chain that gradually explores the model distribution. Generation in an RBM is therefore not a direct decoder call; it is sampling from a learned energy landscape.

```python
def sample_bernoulli_w(probs_w, rng_w):
    return (rng_w.random(probs_w.shape) < probs_w).astype(float)

rng_gibbs_w = np.random.default_rng(3)
v_chain_w = np.array([1., 0.])
trajectory_w = [v_chain_w.copy()]
for step_w in range(8):
    ph_w = sigmoid_w(c_w + v_chain_w @ W_w)
    h_chain_w = sample_bernoulli_w(ph_w, rng_gibbs_w)
    pv_w = sigmoid_w(b_w + W_w @ h_chain_w)
    v_chain_w = sample_bernoulli_w(pv_w, rng_gibbs_w)
    trajectory_w.append(v_chain_w.copy())
trajectory_w = np.array(trajectory_w)
print("visible trajectory:\n", trajectory_w.astype(int))
```
▶ What you'll see: the visible bits change over alternating hidden and visible Bernoulli draws.

```python
plt.figure(figsize=(5, 3))
plt.imshow(trajectory_w.T, cmap="Greys", aspect="auto")
plt.yticks([0, 1], ["v0", "v1"])
plt.xlabel("Gibbs step")
plt.title("4: visible states along a Gibbs chain")
plt.show()
```
▶ What you'll see: a two-row binary heatmap where columns are successive samples from the Markov chain.

*Why it's done this way:* exact independent samples from `p(v)` would require marginalizing hidden states and the partition function. Gibbs sampling avoids `Z` by using local conditional distributions whose normalizers are just sigmoids. Short chains are cheap and useful for learning, but they are biased if they have not mixed across the energy landscape.

### 5. Contrastive divergence: positive phase minus negative phase

Maximum likelihood wants the model to lower energy on data configurations and raise energy on configurations it currently generates too easily. The RBM weight gradient has a simple difference-of-correlations form:

$$\Delta W \propto \langle v h^\top\rangle_{data} - \langle v h^\top\rangle_{model}.$$

Contrastive divergence CD-k approximates the expensive model expectation by starting a short Gibbs chain at the data and taking the chain endpoint as the negative phase.

```python
X_w = np.array([[1., 1., 0., 0.], [1., 0., 0., 0.], [0., 0., 1., 1.], [0., 0., 1., 0.]])
D_w, K_w = X_w.shape[1], 2
rng_cd_w = np.random.default_rng(4)
W_cd_w = 0.05 * rng_cd_w.normal(size=(D_w, K_w))
b_cd_w = np.zeros(D_w)
c_cd_w = np.zeros(K_w)
v0_w = X_w[:2]
ph0_w = sigmoid_w(c_cd_w + v0_w @ W_cd_w)
pos_w = v0_w.T @ ph0_w / len(v0_w)
print("positive associations shape:", pos_w.shape)
print(np.round(pos_w, 3))
```
▶ What you'll see: the positive phase is a visible×hidden association matrix measured on real data.

```python
h0_w = sample_bernoulli_w(ph0_w, rng_cd_w)
pv1_w = sigmoid_w(b_cd_w + h0_w @ W_cd_w.T)
v1_w = sample_bernoulli_w(pv1_w, rng_cd_w)
ph1_w = sigmoid_w(c_cd_w + v1_w @ W_cd_w)
neg_w = v1_w.T @ ph1_w / len(v1_w)
eta_cd_w = 0.5
update_w = eta_cd_w * (pos_w - neg_w)
print("negative visible samples:\n", v1_w.astype(int))
print("mean |W update|:", round(float(np.mean(np.abs(update_w))), 4))
assert update_w.shape == W_cd_w.shape
```
▶ What you'll see: CD-1 produces a negative sample and an update matrix with the same shape as `W`.

```python
plt.figure(figsize=(6, 2.8))
plt.subplot(1, 2, 1); plt.imshow(pos_w, cmap="viridis", aspect="auto"); plt.title("positive vh")
plt.subplot(1, 2, 2); plt.imshow(neg_w, cmap="viridis", aspect="auto"); plt.title("negative vh")
plt.suptitle("5: contrastive divergence compares associations")
plt.show()
```
▶ What you'll see: two small heatmaps; the update is driven by where data associations exceed model-sample associations.

*Why it's done this way:* the positive phase uses hidden probabilities under real data, so it strengthens features that explain observations. The negative phase uses samples from the model's current landscape, so it weakens features that make the model hallucinate the wrong patterns. CD-k is not exact maximum likelihood because a short chain is not the true model distribution, but it is often a useful biased gradient estimate.

### 6. Deep belief nets: stacking RBMs into hierarchical features

A Deep Belief Net historically stacked RBMs greedily. Train the first RBM on visible data, use its hidden probabilities as a new representation, then train another RBM on those hidden features. The result is a hierarchy: lower units model raw bits, higher units model co-occurring hidden causes.

```python
X_dbn_w = np.array([[1., 1., 0., 0.], [1., 0., 0., 0.], [0., 0., 1., 1.], [0., 0., 1., 0.], [1., 1., 0., 0.], [0., 0., 1., 1.]])
W1_w = np.array([[2.0, -1.0], [1.5, -0.8], [-1.0, 2.0], [-0.8, 1.5]])
c1_w = np.array([-0.5, -0.5])
H1_probs_w = sigmoid_w(c1_w + X_dbn_w @ W1_w)
print("first-layer hidden probabilities:\n", np.round(H1_probs_w, 3))
assert H1_probs_w.shape == (6, 2)
```
▶ What you'll see: examples with the first two bits on activate hidden feature 0, while examples with the last two bits on activate feature 1.

```python
W2_w = np.array([[1.2], [1.2]])
c2_w = np.array([-0.7])
H2_probs_w = sigmoid_w(c2_w + H1_probs_w @ W2_w)
print("second-layer probability:", np.round(H2_probs_w.ravel(), 3))
plt.figure(figsize=(5, 3))
plt.scatter(H1_probs_w[:, 0], H1_probs_w[:, 1], c=H2_probs_w.ravel(), cmap="viridis", s=120)
plt.colorbar(label="top hidden probability")
plt.xlabel("h1 feature 0")
plt.ylabel("h1 feature 1")
plt.title("6: stacked RBM representation")
plt.show()
```
▶ What you'll see: first-layer features separate two pattern families, and the top unit summarizes their higher-level activation.

*Why it's done this way:* greedy stacking makes a hard joint deep generative model manageable: each RBM learns a distribution over the representation produced by the layer below. The hierarchy is useful because higher layers can model combinations of lower-level causes rather than raw bits directly.

## 🛠️ Setup

```python
import numpy as np  # load NumPy for binary arrays, logits, sampling, and from-scratch RBM math.
import matplotlib.pyplot as plt  # load Matplotlib for the heatmaps, bars, and learning curves used below.
np.random.seed(0)  # make all stochastic examples reproducible.

def sigmoid(x):  # convert RBM logits into Bernoulli probabilities.
    return 1 / (1 + np.exp(-x))

def sample_binary(probs, rng):  # draw Bernoulli bits from probabilities.
    return (rng.random(probs.shape) < probs).astype(float)

def rbm_energy(v, h, b, c, W):  # compute E(v,h) = -b^T v - c^T h - v^T W h.
    return -float(b @ v + c @ h + v @ W @ h)
```

### Basic 2 — Compute one RBM energy

**Goal.** Score one visible-hidden pair with the energy formula, because energy is the compatibility number behind RBM probability. We build it in 2 steps.

```python
v_b2 = np.array([1., 0.])
h_b2 = np.array([1., 1.])
b_b2 = np.array([0.2, -0.1])
c_b2 = np.array([0.1, 0.2])
W_b2 = np.array([[0.3, -0.1], [0.4, 0.2]])
terms_b2 = np.array([b_b2 @ v_b2, c_b2 @ h_b2, v_b2 @ W_b2 @ h_b2])
print("bias and interaction terms:", np.round(terms_b2, 3))
```
▶ What you'll see: the energy is built from visible bias, hidden bias, and pairwise interaction pieces.

```python
E_b2 = rbm_energy(v_b2, h_b2, b_b2, c_b2, W_b2)
print("energy:", round(E_b2, 4))
assert round(E_b2, 4) == -0.7
plt.figure(figsize=(4, 3))
plt.bar(["b·v", "c·h", "vWh", "E"], [terms_b2[0], terms_b2[1], terms_b2[2], E_b2], color="teal")
plt.title("Basic 2: energy ingredients")
plt.show()
```
▶ What you'll see: positive compatibility terms become a negative energy because of the leading minus sign.

👀 Takeaway: lower energy means the visible and hidden choices are more compatible under the model.

### Basic 4 — Enumerate a tiny partition function

**Goal.** Normalize all weights in a two-visible, one-hidden RBM, because unnormalized weights are not probabilities. We build it in 2 steps.

```python
b_b4 = np.array([0.2, -0.1])
c_b4 = np.array([0.3])
W_b4 = np.array([[0.4], [-0.2]])
weights_b4 = []
for i_b4 in [0., 1.]:
    for j_b4 in [0., 1.]:
        for k_b4 in [0., 1.]:

Z_b4 = float(weights_b4.sum())
print("Z:", round(Z_b4, 3), "states:", len(weights_b4))
```
▶ What you'll see: a tiny RBM can be normalized by summing eight states.

```python
probs_b4 = weights_b4 / Z_b4

plt.figure(figsize=(4, 3))

plt.title("Basic 4: normalized joint probabilities")
plt.show()
```
▶ What you'll see: the bars form a valid probability distribution over all tiny states.

👀 Takeaway: `Z` is what turns RBM weights into probabilities, but it grows exponentially with units.

### Basic 9 — Positive associations from data

**Goal.** Compute `vᵀp(h|v)`, because the positive phase strengthens visible-hidden correlations present in the data. We build it in 2 steps.

```python
X_b9 = np.array([[1., 1., 0.], [1., 0., 0.]])
W_b9 = np.array([[0.2, -0.1], [0.3, 0.1], [-0.2, 0.4]])

recon_a2, pseudo_a2 = [], []

    pv2_a5 = sigmoid(b2_a5 + h2_a5 @ W2_a5.T)
    v2_a5 = sample_binary(pv2_a5, rng_a5)
    ph2n_a5 = sigmoid(c2_a5 + v2_a5 @ W2_a5)
    W2_a5 += 0.08 * ((Hbin_a5.T @ ph2_a5 - v2_a5.T @ ph2n_a5) / len(Hbin_a5))
    b2_a5 += 0.08 * np.mean(Hbin_a5 - v2_a5, axis=0)
    c2_a5 += 0.08 * np.mean(ph2_a5 - ph2n_a5, axis=0)
Top_a5 = sigmoid(c2_a5 + Hbin_a5 @ W2_a5)
print("top representation shape:", Top_a5.shape)
assert Top_a5.shape == (60, 2)
```
▶ What you'll see: the second RBM learns a distribution over first-layer feature bits.
