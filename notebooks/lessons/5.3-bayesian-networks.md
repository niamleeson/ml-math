# 5.3 — Bayesian Networks

Bayesian networks represent a joint distribution with a directed acyclic graph and one local conditional probability table per node. Instead of listing every possible assignment of all variables at once, we multiply small terms like `p(A)`, `p(B|A)`, and `p(C|B)`, then sum or condition those local pieces to answer probability questions.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build Bayesian networks one idea at a time. Run each cell in order and read the printed intermediate values — every product, hidden summation, and normalization step is shown. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays for probability tables, enumeration, and exact sums.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for any simulated checks.
```

### 1. Why a graph saves us from the full joint table

Start with three binary variables `A`, `B`, and `C`. A full joint table must store one probability for every assignment `(A,B,C)`, then satisfy one sum-to-one constraint. A Bayesian network instead says: choose a parent set for each variable and store only the local distribution needed after those parents are known.

```python
n_vars_w = 3  # A, B, and C are binary variables.
full_entries_w = 2 ** n_vars_w  # every complete assignment in a full joint table.
full_free_w = full_entries_w - 1  # one probability is determined by the sum-to-one constraint.
bn_free_w = 1 + 2 + 2  # p(A) has 1 free number, p(B|A) has 2, p(C|B) has 2.
print("full joint entries:", full_entries_w)  # 8 assignments for 3 binary variables.
print("full free parameters:", full_free_w)  # 7 after normalization.
print("BN free parameters:", bn_free_w)  # 5 local conditional numbers.
assert full_free_w == 7 and bn_free_w == 5  # matches the lesson arithmetic.
```
▶ What you'll see: the full table needs 7 free numbers, while the chain BN uses 5.

```python
plt.figure(figsize=(4.4, 3))
plt.bar(["full joint", "BN factors"], [full_free_w, bn_free_w], color=["indianred", "seagreen"])
plt.ylabel("free parameters")
plt.title("1: local factors reduce the table")
plt.show()
```
▶ What you'll see: the BN bar is smaller because it reuses local conditional tables instead of memorizing every global assignment.

*Why it's done this way:* a full table treats every configuration as unrelated, so binary variables cost `2^n - 1` free parameters. The graph claims a conditional-independence structure: once `B` is known, `C` does not need a separate table for every value of `A`. That claim is the compression.

### 2. Local conditional probability tables (CPTs)

For the chain `A → B → C`, the local tables are `p(A)`, `p(B|A)`, and `p(C|B)`. Each row of a CPT must sum to 1 because it is a complete distribution over the child after the parent value is fixed.

```python
pA_w = np.array([0.4, 0.6])  # p(A=0), p(A=1).
pB_given_A_w = np.array([[0.8, 0.2],  # row A=0: p(B=0|A=0), p(B=1|A=0)
                         [0.3, 0.7]]) # row A=1: p(B=0|A=1), p(B=1|A=1)
pC_given_B_w = np.array([[0.9, 0.1],  # row B=0: p(C=0|B=0), p(C=1|B=0)
                         [0.2, 0.8]]) # row B=1: p(C=0|B=1), p(C=1|B=1)
print("p(A):", pA_w)
print("row sums B|A:", pB_given_A_w.sum(axis=1))
print("row sums C|B:", pC_given_B_w.sum(axis=1))
assert np.allclose(pB_given_A_w.sum(axis=1), 1) and np.allclose(pC_given_B_w.sum(axis=1), 1)
```
▶ What you'll see: each conditional row sums to 1, so each parent setting defines a valid distribution for the child.

```python
fig, ax = plt.subplots(1, 2, figsize=(7, 2.8))
ax[0].imshow(pB_given_A_w, cmap="Blues", vmin=0, vmax=1)
ax[0].set_title("p(B|A)"); ax[0].set_xlabel("B"); ax[0].set_ylabel("A")
ax[1].imshow(pC_given_B_w, cmap="Greens", vmin=0, vmax=1)
ax[1].set_title("p(C|B)"); ax[1].set_xlabel("C"); ax[1].set_ylabel("B")
plt.suptitle("2: local CPT rows")
plt.show()
```
▶ What you'll see: each row is a small conditional distribution that can be inspected independently.

*Why it's done this way:* the parent value selects one row, and the child value selects one column. This row/column lookup is exactly the computational meaning of an arrow: not causality by itself, but the local conditioning context for that factor.

### 3. Factorizing one joint assignment

The Bayesian-network rule is `p(A,B,C)=p(A)p(B|A)p(C|B)`. For the assignment `A=1, B=1, C=1`, each factor is just one lookup from its local table.

```python
a_w, b_w, c_w = 1, 1, 1  # target assignment.
fA_w = pA_w[a_w]  # p(A=1).
fB_w = pB_given_A_w[a_w, b_w]  # p(B=1 | A=1).
fC_w = pC_given_B_w[b_w, c_w]  # p(C=1 | B=1).
print("factors:", fA_w, fB_w, fC_w)
```
▶ What you'll see: the three local factors are `0.6`, `0.7`, and `0.8`.

```python
joint111_w = fA_w * fB_w * fC_w  # product rule for the BN chain.
print("p(A=1,B=1,C=1):", round(joint111_w, 3))
assert round(joint111_w, 3) == 0.336  # 0.6 * 0.7 * 0.8.
```
▶ What you'll see: the joint assignment probability is `0.336`.

```python
plt.figure(figsize=(4.6, 3))
plt.bar(["p(A=1)", "p(B=1|A=1)", "p(C=1|B=1)", "product"], [fA_w, fB_w, fC_w, joint111_w], color=["gray", "steelblue", "seagreen", "purple"])
plt.ylim(0, 1)
plt.xticks(rotation=18)
plt.title("3: one joint assignment from local factors")
plt.show()
```
▶ What you'll see: multiplying local probabilities makes the final joint probability smaller than any single factor.

*Why it's done this way:* the chain rule would allow `p(A)p(B|A)p(C|A,B)`. The network asserts that `C` only needs `B`, replacing `p(C|A,B)` with `p(C|B)`. That is the conditional-independence assumption written as code.

### 4. Building the full joint by enumeration

Even when we do not store a full joint table, we can construct it for a tiny example by enumerating all assignments and multiplying local factors. This is useful for checking normalization and for learning how marginalization will work.

```python
joint_w = np.zeros((2, 2, 2))  # axes are A, B, C.
for a in range(2):
    for b in range(2):
        for c in range(2):
            joint_w[a, b, c] = pA_w[a] * pB_given_A_w[a, b] * pC_given_B_w[b, c]
print("joint table shape:", joint_w.shape)
print("sum of all assignments:", round(float(joint_w.sum()), 6))
assert np.allclose(joint_w.sum(), 1.0)
```
▶ What you'll see: the enumerated 2×2×2 table sums to 1, confirming the local factors define a valid joint.

```python
plt.figure(figsize=(4.8, 3))
plt.bar(["000", "001", "010", "011", "100", "101", "110", "111"], joint_w.reshape(-1), color="teal")
plt.ylabel("joint probability")
plt.title("4: all assignments from BN factors")
plt.show()
```
▶ What you'll see: eight bars, one per assignment, generated from only the small CPTs.

*Why it's done this way:* enumeration is not the scalable inference algorithm, but it makes the semantics unambiguous: a BN is a recipe for every joint probability. The product gives each complete assignment a score, and the CPT normalization makes the whole table normalize automatically.

### 5. Marginalizing hidden ancestors

A marginal like `p(C=1)` must sum over the unobserved variables `A` and `B`. The hidden summation is where many Bayesian-network mistakes happen: evidence about `C` flows through every possible upstream route, not just the most likely one.

```python
terms_C1_w = []
for a in range(2):
    for b in range(2):
        term = pA_w[a] * pB_given_A_w[a, b] * pC_given_B_w[b, 1]
        terms_C1_w.append(term)
        print(f"A={a}, B={b} contribution:", round(term, 3))
```
▶ What you'll see: four route contributions into `C=1`, one for each hidden `(A,B)` pair.

```python
pC1_w = float(np.sum(terms_C1_w))
print("p(C=1):", round(pC1_w, 3))
assert round(pC1_w, 3) == 0.45  # lesson marginal.
```
▶ What you'll see: summing all hidden routes gives `p(C=1)=0.450`.

```python
plt.figure(figsize=(4.8, 3))
plt.bar(["A0B0", "A0B1", "A1B0", "A1B1"], terms_C1_w, color="darkorange")
plt.ylabel("contribution to p(C=1)")
plt.title("5: marginal = sum over hidden routes")
plt.show()
```
▶ What you'll see: the `A=1,B=1` route contributes most, but every hidden route is included.

*Why it's done this way:* marginal probability means “probability of `C=1` no matter what the hidden variables were.” The only mathematically legal way to remove hidden discrete variables is summation over their mutually exclusive assignments.

### 6. Posterior inference by normalization

To compute `p(A=1 | C=1)`, first score the compatible worlds with `A=1` and `C=1`, summing out hidden `B`. Then divide by the total probability of the evidence `p(C=1)` so the answer becomes a probability rather than an unnormalized score.

```python
score_A1_C1_w = 0.0
for b in range(2):
    term = pA_w[1] * pB_given_A_w[1, b] * pC_given_B_w[b, 1]
    score_A1_C1_w += term
    print(f"A=1, B={b}, C=1 contribution:", round(term, 3))
print("unnormalized score p(A=1,C=1):", round(score_A1_C1_w, 3))
assert round(score_A1_C1_w, 3) == 0.354
```
▶ What you'll see: `p(A=1,C=1)=0.354` after summing the two possible values of `B`.

```python
posterior_A1_given_C1_w = score_A1_C1_w / pC1_w
print("p(A=1 | C=1):", round(posterior_A1_given_C1_w, 3))
assert round(posterior_A1_given_C1_w, 3) == 0.787  # 0.354 / 0.450.
```
▶ What you'll see: observing `C=1` raises belief in `A=1` to about `0.787`.

```python
plt.figure(figsize=(4.2, 3))
plt.bar(["prior p(A=1)", "posterior p(A=1|C=1)"], [pA_w[1], posterior_A1_given_C1_w], color=["gray", "seagreen"])
plt.ylim(0, 1)
plt.title("6: evidence updates belief upstream")
plt.show()
```
▶ What you'll see: the posterior bar is higher than the prior because `C=1` is more likely through the `A=1 → B=1` route.

*Why it's done this way:* Bayes' rule is normalization of compatible worlds. The numerator keeps worlds where both the hypothesis and evidence are true; the denominator keeps all worlds where the evidence is true, ensuring the posterior alternatives sum to 1.

### 7. Observing is not intervening

An observation `C=1` conditions on worlds where `C` happened. An intervention `do(B=1)` replaces the local mechanism for `B` with a fixed value, cutting the usual incoming dependence from `A` into `B`. This distinction is why arrows can look causal, yet factorization alone is not proof of causality.

```python
pC1_observe_B1_w = pC_given_B_w[1, 1]  # p(C=1 | B=1) by observing B=1.
pC1_do_B1_w = sum(pA_w[a] * pC_given_B_w[1, 1] for a in range(2))  # set B=1, then average over A.
print("p(C=1 | B=1):", round(pC1_observe_B1_w, 3))
print("p(C=1 | do(B=1)):", round(pC1_do_B1_w, 3))
assert round(pC1_do_B1_w, 3) == 0.8
```
▶ What you'll see: in this simple chain both values are `0.8`, because `C` depends directly only on `B`.

```python
pA1_given_B1_w = pA_w[1] * pB_given_A_w[1, 1] / (pA_w[0] * pB_given_A_w[0, 1] + pA_w[1] * pB_given_A_w[1, 1])
pA1_under_do_B1_w = pA_w[1]  # intervening on B does not change A's prior in this graph.
print("p(A=1 | B=1):", round(pA1_given_B1_w, 3))
print("p(A=1 | do(B=1)):", round(pA1_under_do_B1_w, 3))
```
▶ What you'll see: observing `B=1` changes belief about its parent `A`, but forcing `B=1` leaves `A` at its prior.

```python
plt.figure(figsize=(4.6, 3))
plt.bar(["observe B=1", "do(B=1)"], [pA1_given_B1_w, pA1_under_do_B1_w], color=["purple", "orange"])
plt.ylim(0, 1)
plt.ylabel("belief in A=1")
plt.title("7: conditioning vs intervention")
plt.show()
```
▶ What you'll see: the two bars differ because observation carries diagnostic information upstream, while intervention breaks that diagnostic link.

*Why it's done this way:* conditioning filters the existing joint distribution. Intervention edits the model by replacing a conditional distribution. Those are different mathematical operations, so causal claims require more than drawing directed arrows.

### ✍️ Toy 1 · A graph reduces free parameters

A full binary joint over six variables needs one number per assignment minus one. A Bayesian network
only stores one local row per parent setting.

```python
import numpy as np
import matplotlib.pyplot as plt

t1_rng = np.random.default_rng(0)                  # seeded generator for reproducibility
t1_parent_counts = np.array([0, 1, 1, 2, 1, 0])    # parents per binary node  # -> [0, 1, 1, 2, 1, 0]
print("parent counts:", t1_parent_counts.tolist()) # -> [0, 1, 1, 2, 1, 0]
t1_n_vars = int(t1_parent_counts.size)             # variable count  # -> 6
print("binary variables:", t1_n_vars)              # -> 6
t1_full_entries = 2 ** t1_n_vars                   # full joint assignments  # -> 64
print("full joint entries:", t1_full_entries)      # -> 64
t1_full_free = t1_full_entries - 1                 # free parameters after normalization  # -> 63
print("full free parameters:", t1_full_free)       # -> 63
t1_local_free = 2 ** t1_parent_counts              # binary child needs one free number per parent row
print("local free parameters:", t1_local_free.tolist())  # -> [1, 2, 2, 4, 2, 1]
t1_bn_free = int(t1_local_free.sum())              # total BN free parameters  # -> 12
print("BN free parameters:", t1_bn_free)           # -> 12
assert t1_full_free == 63 and t1_bn_free == 12     # local factors are far smaller here

plt.figure(figsize=(4.8, 2.8))
plt.bar(["full joint", "BN factors"], [t1_full_free, t1_bn_free], color=["#e45756", "#54a24b"])
plt.ylabel("free parameters")
plt.title("Toy 1 · local graph compression")
plt.show()
```
▶ What you'll see: the BN stores `12` local free numbers instead of `63` full-joint free numbers.

### ✍️ Toy 2 · CPT rows must sum to one

Each parent setting selects a row of a conditional probability table. Every selected row must be a
valid distribution over the child.

```python
import numpy as np

t2_rng = np.random.default_rng(0)                  # seeded generator for reproducibility
t2_pA = np.array([0.3, 0.7])                       # root prior p(A)
print("p(A):", t2_pA.tolist())                     # -> [0.3, 0.7]
t2_pB_given_A = np.array([[0.6, 0.4], [0.2, 0.8]]) # rows A=0,A=1; columns B=0,B=1
print("p(B|A):", t2_pB_given_A.tolist())           # -> [[0.6, 0.4], [0.2, 0.8]]
t2_pC_given_B = np.array([[0.9, 0.1], [0.3, 0.7]]) # rows B=0,B=1; columns C=0,C=1
print("p(C|B):", t2_pC_given_B.tolist())           # -> [[0.9, 0.1], [0.3, 0.7]]
t2_row_sums_B = t2_pB_given_A.sum(axis=1)          # row sums for B|A  # -> [1.0, 1.0]
print("row sums B|A:", t2_row_sums_B.tolist())     # -> [1.0, 1.0]
t2_row_sums_C = t2_pC_given_B.sum(axis=1)          # row sums for C|B  # -> [1.0, 1.0]
print("row sums C|B:", t2_row_sums_C.tolist())     # -> [1.0, 1.0]
assert np.allclose(t2_row_sums_B, 1.0) and np.allclose(t2_row_sums_C, 1.0)  # each CPT row normalizes

plt.figure(figsize=(4.2, 3))
plt.imshow(t2_pB_given_A, cmap="Blues", vmin=0, vmax=1)
plt.colorbar(label="probability")
plt.xticks([0, 1], ["B=0", "B=1"])
plt.yticks([0, 1], ["A=0", "A=1"])
plt.title("Toy 2 · rows of p(B|A)")
plt.show()
```
▶ What you'll see: each row of the heatmap is a complete distribution over `B` for one value of `A`.

### ✍️ Toy 3 · One joint assignment is a product of local factors

For a chain `A → B → C`, the probability of a complete assignment is one lookup from each local table
multiplied together.

```python
import numpy as np

t3_rng = np.random.default_rng(0)                  # seeded generator for reproducibility
t3_pA = np.array([0.3, 0.7])                       # p(A=0), p(A=1)
t3_pB_given_A = np.array([[0.6, 0.4], [0.2, 0.8]]) # p(B|A)
t3_pC_given_B = np.array([[0.9, 0.1], [0.3, 0.7]]) # p(C|B)
t3_a = 1                                           # chosen A value  # -> 1
t3_b = 1                                           # chosen B value  # -> 1
t3_c = 1                                           # chosen C value  # -> 1
print("assignment A,B,C:", t3_a, t3_b, t3_c)       # -> 1 1 1
t3_fA = t3_pA[t3_a]                                # p(A=1)  # -> 0.7
print("p(A=1):", float(t3_fA))                     # -> 0.7
t3_fB = t3_pB_given_A[t3_a, t3_b]                  # p(B=1|A=1)  # -> 0.8
print("p(B=1|A=1):", float(t3_fB))                 # -> 0.8
t3_fC = t3_pC_given_B[t3_b, t3_c]                  # p(C=1|B=1)  # -> 0.7
print("p(C=1|B=1):", float(t3_fC))                 # -> 0.7
t3_joint = t3_fA * t3_fB * t3_fC                   # product factorization  # -> 0.392
print("joint probability:", round(float(t3_joint), 3))  # -> 0.392
assert round(float(t3_joint), 3) == 0.392          # 0.7 × 0.8 × 0.7

plt.figure(figsize=(4.8, 2.8))
plt.bar(["p(A)", "p(B|A)", "p(C|B)", "product"], [t3_fA, t3_fB, t3_fC, t3_joint], color=["gray", "#4c78a8", "#54a24b", "#b279a2"])
plt.ylim(0, 1)
plt.ylabel("probability")
plt.title("Toy 3 · joint = local product")
plt.show()
```
▶ What you'll see: multiplying `0.7 × 0.8 × 0.7` gives the joint assignment probability `0.392`.

### ✍️ Toy 4 · Enumeration builds the full joint table

Even when the BN stores only local tables, enumerating all assignments reconstructs the full joint for
a tiny three-node graph.

```python
import numpy as np

t4_rng = np.random.default_rng(0)                  # seeded generator for reproducibility
t4_pA = np.array([0.4, 0.6])

t4_pC_given_B = np.array([[0.9, 0.1], [0.25, 0.75]])

assert np.isclose(t4_total, 1.0)                   # local CPTs define a normalized joint

plt.figure(figsize=(5, 2.8))
```

### ✍️ Toy 5 · Marginals sum over hidden routes

To find `P(C=1)`, remove hidden variables `A` and `B` by summing every compatible route into `C=1`.

```python
import numpy as np

t5_rng = np.random.default_rng(0)                  # seeded generator for reproducibility
t5_pA = np.array([0.4, 0.6])
t5_pB_given_A = np.array([[0.7, 0.3], [0.2, 0.8]])
t5_pC_given_B = np.array([[0.9, 0.1], [0.25, 0.75]])
t5_terms = []                                      # contributions to P(C=1)
t5_labels = []                                     # route labels
for t5_a in range(2):
    for t5_b in range(2):
        t5_term = t5_pA[t5_a] * t5_pB_given_A[t5_a, t5_b] * t5_pC_given_B[t5_b, 1]
        t5_terms.append(t5_term)
        t5_labels.append(f"A{t5_a}B{t5_b}")
t5_terms = np.array(t5_terms)                      # -> [0.028, 0.09, 0.012, 0.36]
print("route labels:", t5_labels)                  # -> ['A0B0', 'A0B1', 'A1B0', 'A1B1']
print("C=1 route terms:", np.round(t5_terms, 3).tolist())  # -> [0.028, 0.09, 0.012, 0.36]
t5_pC1 = t5_terms.sum()                            # marginal P(C=1)  # -> 0.49
print("P(C=1):", round(float(t5_pC1), 3))          # -> 0.49
assert round(float(t5_pC1), 3) == 0.49             # sum all hidden A,B routes

plt.figure(figsize=(4.8, 2.8))
plt.bar(t5_labels, t5_terms, color="#f58518")
plt.ylabel("contribution")
plt.title("Toy 5 · marginal sums hidden routes")
plt.show()
```
▶ What you'll see: the four route contributions add to `P(C=1)=0.49`.

### ✍️ Toy 6 · Posterior inference normalizes compatible scores

For `P(A=1 | C=1)`, score the worlds where both are true, then divide by the evidence `P(C=1)`.

```python
import numpy as np

t6_rng = np.random.default_rng(0)                  # seeded generator for reproducibility
t6_pA = np.array([0.4, 0.6])
t6_pB_given_A = np.array([[0.7, 0.3], [0.2, 0.8]])
t6_pC_given_B = np.array([[0.9, 0.1], [0.25, 0.75]])
t6_A1_terms = np.array([t6_pA[1] * t6_pB_given_A[1, 0] * t6_pC_given_B[0, 1], t6_pA[1] * t6_pB_given_A[1, 1] * t6_pC_given_B[1, 1]])
print("A=1,C=1 terms:", np.round(t6_A1_terms, 3).tolist())  # -> [0.012, 0.36]
t6_score_A1_C1 = t6_A1_terms.sum()                # numerator p(A=1,C=1)  # -> 0.372
print("p(A=1,C=1):", round(float(t6_score_A1_C1), 3))  # -> 0.372

t6_pC1 = t6_C1_terms.sum()                         # evidence p(C=1)  # -> 0.49
print("p(C=1):", round(float(t6_pC1), 3))          # -> 0.49
t6_posterior = t6_score_A1_C1 / t6_pC1             # normalized posterior  # -> 0.759184
print("p(A=1|C=1):", round(float(t6_posterior), 6))  # -> 0.759184

assert round(float(t6_posterior), 3) == 0.759      # posterior after observing C=1

plt.ylabel("probability")
plt.title("Toy 6 · normalize compatible worlds")
```

▶ What you'll see: observing `C=1` raises belief in `A=1` from `0.6` to about `0.759`.

### ✍️ Toy 7 · Observing a child is not intervening on it

Conditioning on `B=1` updates belief about its parent `A`; forcing `do(B=1)` leaves the parent prior
alone because the incoming mechanism is cut.

```python
t7_A1_given_B1 = t7_num_A1_B1 / t7_pB1             # observation posterior  # -> 0.890909
print("p(A=1|B=1):", round(float(t7_A1_given_B1), 6))  # -> 0.890909
t7_A1_under_do_B1 = t7_pA[1]                       # intervention leaves A prior  # -> 0.7
```

### Advanced 1 — Variable elimination for p(C)

**Goal.** Sum out `A` first, then `B`, because variable elimination avoids explicitly materializing the full joint table. We build it in 4 steps.

```python
pA_a1 = np.array([0.4, 0.6])
pB_A_a1 = np.array([[0.8, 0.2], [0.3, 0.7]])
pC_B_a1 = np.array([[0.9, 0.1], [0.2, 0.8]])
print("eliminate A, then combine with C|B")
```
▶ What you'll see: the computation will form a smaller intermediate factor over `B`.

```python
pB_a1 = pA_a1 @ pB_A_a1  # sum_A p(A)p(B|A), producing p(B).

assert np.allclose(np.round(pB_a1, 3), np.array([0.5, 0.5]))
```
▶ What you'll see: in this toy setup, `B` is evenly split after averaging over `A`.

```python
pC_a1 = pB_a1 @ pC_B_a1  # sum_B p(B)p(C|B), producing p(C).
print("p(C):", np.round(pC_a1, 3))
assert np.allclose(np.round(pC_a1, 3), np.array([0.55, 0.45]))
```
▶ What you'll see: `p(C=1)` is again `0.450`, but computed through smaller intermediate factors.


▶ What you'll see: the final marginal distribution over `C` is normalized.

### Advanced 2 — Diagnose explaining away

**Goal.** Build a collider `Cloudy → WetGrass ← Sprinkler`, because observing a common effect can make independent causes dependent. We build it in 4 steps.

```python
pC_a2 = np.array([0.5, 0.5])  # Cloudy prior.
pS_a2 = np.array([0.5, 0.5])  # Sprinkler prior, independent of Cloudy before observing WetGrass.
pW_CS_a2 = np.array([[[0.99, 0.01], [0.10, 0.90]],  # C=0 rows over S: p(W=0/1|C,S)
                     [[0.20, 0.80], [0.01, 0.99]]]) # C=1 rows over S.
print("prior p(C=1):", pC_a2[1], "prior p(S=1):", pS_a2[1])
```
▶ What you'll see: the two causes start independent with equal prior probabilities.

```python
joint_CSW_a2 = np.zeros((2, 2, 2))
for c_a2 in range(2):
    for s_a2 in range(2):
        for w_a2 in range(2):
            joint_CSW_a2[c_a2, s_a2, w_a2] = pC_a2[c_a2] * pS_a2[s_a2] * pW_CS_a2[c_a2, s_a2, w_a2]
print("joint sum:", round(float(joint_CSW_a2.sum()), 6))
assert np.allclose(joint_CSW_a2.sum(), 1.0)
```
▶ What you'll see: the collider CPT still defines a normalized joint distribution.

```python
pC1_W1_a2 = joint_CSW_a2[1, :, 1].sum() / joint_CSW_a2[:, :, 1].sum()
pC1_W1_S1_a2 = joint_CSW_a2[1, 1, 1] / joint_CSW_a2[:, 1, 1].sum()
print("p(Cloudy=1 | Wet=1):", round(pC1_W1_a2, 3))
print("p(Cloudy=1 | Wet=1, Sprinkler=1):", round(pC1_W1_S1_a2, 3))
assert pC1_W1_S1_a2 < pC1_W1_a2
```
▶ What you'll see: knowing the sprinkler was on lowers the need to explain wet grass by cloudiness.

```python
plt.figure(figsize=(5, 3))
plt.bar(["Wet observed", "Wet + Sprinkler"], [pC1_W1_a2, pC1_W1_S1_a2], color=["purple", "orange"])
plt.ylim(0, 1)
plt.ylabel("belief Cloudy=1")
plt.title("Advanced 2: explaining away")
plt.show()
```
▶ What you'll see: the second bar is lower, showing dependence between causes after observing their effect.

👀 Takeaway: colliders are blocked until their effect is observed, then causes can explain each other away.

### Advanced 3 — Detect a directed cycle

**Goal.** Test a graph for acyclicity, because a BN with a directed cycle has no valid parent-before-child factor order. We build it in 4 steps.

```python
edges_a3 = [(0, 1), (1, 2), (2, 0)]  # A->B, B->C, C->A creates a directed cycle.
nodes_a3 = 3
adj_a3 = np.zeros((nodes_a3, nodes_a3), dtype=int)
for u_a3, v_a3 in edges_a3:
    adj_a3[u_a3, v_a3] = 1
print("adjacency matrix:\n", adj_a3)
```
▶ What you'll see: the adjacency matrix has arrows around a 3-node loop.

```python
reach_a3 = adj_a3.copy()
for _a3 in range(nodes_a3):
    reach_a3 = ((reach_a3 + reach_a3 @ adj_a3) > 0).astype(int)
has_cycle_a3 = bool(np.any(np.diag(reach_a3) > 0))
print("has directed cycle:", has_cycle_a3)
assert has_cycle_a3
```
▶ What you'll see: a node can reach itself, so the graph is cyclic.

```python
plt.figure(figsize=(3.6, 3.2))
angles_a3 = np.linspace(0, 2 * np.pi, nodes_a3, endpoint=False)
xy_a3 = np.c_[np.cos(angles_a3), np.sin(angles_a3)]
plt.scatter(xy_a3[:, 0], xy_a3[:, 1], s=220, color="lightcoral", edgecolor="black")
for i_a3, name_a3 in enumerate(["A", "B", "C"]):
    plt.text(xy_a3[i_a3, 0], xy_a3[i_a3, 1] + 0.12, name_a3, ha="center")
for u_a3, v_a3 in edges_a3:
    dx_a3, dy_a3 = xy_a3[v_a3] - xy_a3[u_a3]
    plt.arrow(xy_a3[u_a3, 0], xy_a3[u_a3, 1], 0.75 * dx_a3, 0.75 * dy_a3, head_width=0.08, length_includes_head=True)
plt.axis("off")
plt.title("Advanced 3: invalid BN cycle")
plt.show()
```
▶ What you'll see: the arrows form a closed directed loop.

👀 Takeaway: cycles break the BN factorization because no node in the loop can be evaluated after all its parents.

### Advanced 4 — Compare observation and intervention

**Goal.** Quantify `p(A=1|B=1)` versus `p(A=1|do(B=1))`, because intervention replaces a conditional instead of conditioning on the old joint. We build it in 4 steps.

```python
pA_a4 = np.array([0.4, 0.6])
pB_A_a4 = np.array([[0.8, 0.2], [0.3, 0.7]])
print("prior p(A=1):", pA_a4[1])
```
▶ What you'll see: before any information, `A=1` has probability `0.6`.

```python
pB1_a4 = pA_a4[0] * pB_A_a4[0, 1] + pA_a4[1] * pB_A_a4[1, 1]
pA1_given_B1_a4 = pA_a4[1] * pB_A_a4[1, 1] / pB1_a4
print("p(B=1):", round(pB1_a4, 3))
print("p(A=1|B=1):", round(pA1_given_B1_a4, 3))
```
▶ What you'll see: observing `B=1` raises belief in `A=1` because `B=1` is more likely under `A=1`.

```python
pA1_do_B1_a4 = pA_a4[1]  # setting B does not provide diagnostic evidence about A.
print("p(A=1|do(B=1)):", round(pA1_do_B1_a4, 3))
assert round(pA1_given_B1_a4, 3) == 0.84 and round(pA1_do_B1_a4, 3) == 0.6
```
▶ What you'll see: the intervention leaves belief in `A` at its prior.

```python
plt.figure(figsize=(4.8, 3))
plt.bar(["observe B=1", "do(B=1)"], [pA1_given_B1_a4, pA1_do_B1_a4], color=["seagreen", "crimson"])

plt.ylabel("p(A=1)")
plt.title("Advanced 4: observation vs intervention")
plt.show()
```
▶ What you'll see: observation and intervention produce different beliefs about the parent.

👀 Takeaway: conditioning updates beliefs inside the original model; intervention edits the model first.

### Advanced 5 — Estimate a CPT from complete data

**Goal.** Learn `p(B|A)` by counting complete observations with smoothing, because CPTs are often estimated from data rather than hand-written. We build it in 4 steps.

```python
rng_a5 = np.random.default_rng(5)
n_a5 = 2000
pA_a5 = np.array([0.4, 0.6])
pB_A_a5_true = np.array([[0.8, 0.2], [0.3, 0.7]])
A_a5 = (rng_a5.random(n_a5) < pA_a5[1]).astype(int)
B_a5 = np.array([int(rng_a5.random() < pB_A_a5_true[a_a5, 1]) for a_a5 in A_a5])
print("simulated rows:", n_a5)
```
▶ What you'll see: complete `(A,B)` observations have been generated from the true CPT.

```python
counts_a5 = np.zeros((2, 2))
for a_a5, b_a5 in zip(A_a5, B_a5):
    counts_a5[a_a5, b_a5] += 1
print("counts B by A:\n", counts_a5.astype(int))
```
▶ What you'll see: each row counts how often `B=0` or `B=1` occurred for a fixed value of `A`.

```python
alpha_a5 = 1.0  # Laplace smoothing avoids zero probabilities in small samples.
est_a5 = (counts_a5 + alpha_a5) / (counts_a5.sum(axis=1, keepdims=True) + 2 * alpha_a5)
print("estimated p(B|A):\n", np.round(est_a5, 3))
assert np.max(np.abs(est_a5 - pB_A_a5_true)) < 0.05
```
▶ What you'll see: the estimated CPT is close to the true table used to generate the data.

```python
x_a5 = np.arange(2)
plt.figure(figsize=(5, 3))
plt.bar(x_a5 - 0.18, pB_A_a5_true[:, 1], width=0.36, label="true", color="gray")
plt.bar(x_a5 + 0.18, est_a5[:, 1], width=0.36, label="estimated", color="teal")
plt.xticks(x_a5, ["A=0", "A=1"])
plt.ylabel("p(B=1|A)")
plt.title("Advanced 5: CPT estimation")
plt.legend()
plt.show()
```
▶ What you'll see: estimated bars nearly match the true conditional probabilities.

👀 Takeaway: with complete data, learning a discrete CPT is normalized counting plus smoothing.
