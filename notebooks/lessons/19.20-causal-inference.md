# 19.20 — Causal Inference

Causal inference asks a harder question than prediction: not "who has a high outcome?" but "what would change if we intervened?" In this lesson, we build the potential-outcomes view, show how confounding breaks naive comparisons, and implement backdoor adjustment, propensity-score inverse probability weighting, and doubly-robust estimation from scratch with NumPy.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build causal inference one idea at a time. Run each cell in order and read the printed intermediate values — every estimate is compared against a known synthetic data-generating process, so association and causation never get blurred. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, simulation, and hand-built estimators.
import matplotlib.pyplot as plt  # visual checks for bias, weights, and adjustment.
np.random.seed(0)  # reproducibility for the walkthrough.
```

### 1. Potential outcomes: one unit has two possible worlds

A causal effect compares two outcomes for the same unit: $Y_i(1)$ if treated and $Y_i(0)$ if untreated. We only observe one of them, because a unit cannot both receive and not receive the same treatment at the same time. To learn the math without mystery, we first simulate both potential outcomes from a structural causal model (SCM), then hide one the way real data would.

```python
n_w = 8000  # many units so sampling noise is small.
rng_w = np.random.default_rng(0)  # local reproducible generator.
X_w = rng_w.normal(0, 1, n_w)  # pre-treatment covariate that affects outcomes.
noise_w = rng_w.normal(0, 0.4, n_w)  # individual outcome noise shared by both worlds.
Y0_w = 1.0 + 0.7 * X_w + noise_w  # potential outcome if untreated.
Y1_w = Y0_w + 2.0  # potential outcome if treated; the individual treatment effect is exactly 2.
tau_i_w = Y1_w - Y0_w  # individual treatment effects.
print("first three Y(0):", np.round(Y0_w[:3], 3))
print("first three Y(1):", np.round(Y1_w[:3], 3))
print("true ATE:", round(float(np.mean(tau_i_w)), 3))
assert round(float(np.mean(tau_i_w)), 3) == 2.0
```
▶ What you'll see: every unit has two possible outcomes in the simulation, and the true average treatment effect is exactly 2.

```python
T_rand_w = rng_w.binomial(1, 0.5, n_w)  # randomized treatment assignment.
Y_obs_rand_w = T_rand_w * Y1_w + (1 - T_rand_w) * Y0_w  # only one potential outcome is observed.
print("observed treated mean:", round(float(Y_obs_rand_w[T_rand_w == 1].mean()), 3))
print("observed control mean:", round(float(Y_obs_rand_w[T_rand_w == 0].mean()), 3))
```
▶ What you'll see: with random assignment, the observed treated-minus-control difference lands near the true effect of 2.

*Why it's done this way:* causal estimands live in the table of potential outcomes, not just in the observed column. The SCM lets us know the answer while still enforcing the real-world rule that only $Y=T Y(1)+(1-T)Y(0)$ is observed. Random assignment makes $T$ independent of both potential outcomes, so treated and untreated units are exchangeable copies except for treatment.

### 2. Confounding: association mixes treatment with selection

Confounding happens when a pre-treatment variable affects both treatment assignment and the outcome. Here high-$X$ units are more likely to be treated and also have higher baseline outcomes. A naive treated-minus-control comparison then estimates a mix of the treatment effect and the pre-existing advantage of treated units.

```python
logit_w = -0.2 + 1.3 * X_w  # treatment is more likely when X is high.
e_w = 1 / (1 + np.exp(-logit_w))  # true propensity P(T=1|X).
T_conf_w = rng_w.binomial(1, e_w)  # confounded observational treatment.
Y_obs_conf_w = T_conf_w * Y1_w + (1 - T_conf_w) * Y0_w  # observed outcome under confounding.
naive_w = float(Y_obs_conf_w[T_conf_w == 1].mean() - Y_obs_conf_w[T_conf_w == 0].mean())
print("mean X treated:", round(float(X_w[T_conf_w == 1].mean()), 3))
print("mean X control:", round(float(X_w[T_conf_w == 0].mean()), 3))
print("naive difference:", round(naive_w, 3))
assert round(naive_w, 3) > 2.6
```
▶ What you'll see: treated units have larger $X$, so the naive difference is much larger than the true ATE of 2.

```python
plt.figure(figsize=(5, 3))
plt.hist(X_w[T_conf_w == 1], bins=30, alpha=0.6, label="treated", color="teal")
plt.hist(X_w[T_conf_w == 0], bins=30, alpha=0.6, label="control", color="orange")
plt.title("2: confounding means groups differ before treatment")
plt.xlabel("pre-treatment X")
plt.ylabel("count")
plt.legend()
plt.show()
```
▶ What you'll see: the treated histogram is shifted right; this imbalance is the source of bias.

*Why it's done this way:* $E[Y\mid T=1]-E[Y\mid T=0]$ is an association. It equals a causal effect only when the untreated potential outcomes would have been comparable across treatment groups. Confounding violates that by making $E[Y(0)\mid T=1] \ne E[Y(0)\mid T=0]$.

### 3. Backdoor adjustment: compare like with like

If all confounders are observed, the backdoor idea says treatment becomes as-good-as-random after conditioning on them: $(Y(1),Y(0))\perp T\mid X$. We estimate the effect inside small $X$ strata, then average the stratum effects using the population distribution of $X$.

```python
bins_w = np.quantile(X_w, np.linspace(0, 1, 7))  # six strata with similar counts.
bins_w[0] -= 1e-6
bins_w[-1] += 1e-6
strata_w = np.digitize(X_w, bins_w[1:-1])  # stratum index 0..5.
print("stratum counts:", np.bincount(strata_w))
```
▶ What you'll see: the population is split into balanced bins of the confounder.

```python
stratum_effects_w = []
stratum_weights_w = []
for s_w in range(6):
    m_w = strata_w == s_w
    treated_mean_w = Y_obs_conf_w[m_w & (T_conf_w == 1)].mean()
    control_mean_w = Y_obs_conf_w[m_w & (T_conf_w == 0)].mean()
    stratum_effects_w.append(treated_mean_w - control_mean_w)
    stratum_weights_w.append(m_w.mean())
adjusted_w = float(np.sum(np.array(stratum_effects_w) * np.array(stratum_weights_w)))
print("stratum effects:", np.round(stratum_effects_w, 3))
print("backdoor adjusted ATE:", round(adjusted_w, 3))
assert abs(adjusted_w - 2.0) < 0.08
```
▶ What you'll see: within-stratum effects cluster near 2, and the weighted average recovers the true ATE.

```python
plt.figure(figsize=(5, 3))
plt.bar(np.arange(6), stratum_effects_w, color="slateblue")
plt.axhline(2.0, color="black", linestyle="--", label="true ATE")
plt.title("3: effects after conditioning on X")
plt.xlabel("X stratum")
plt.ylabel("treated mean - control mean")
plt.legend()
plt.show()
```
▶ What you'll see: each adjusted comparison is close to the horizontal true-effect line.

*Why it's done this way:* adjustment blocks the backdoor path $T \leftarrow X \rightarrow Y$. We do not average treated/control sample sizes equally; we average by the full population's $X$ distribution, because the estimand is the population ATE, not the effect in whichever strata happened to receive more treatment.

### 4. Propensity scores and IPW: rebuild a randomized population

The propensity score $e(X)=P(T=1\mid X)$ compresses confounders into the probability of treatment. Inverse probability weighting (IPW) gives treated units weight $1/e(X)$ and controls weight $1/(1-e(X))$. Units who were unlikely to receive what they actually received stand in for many similar units, creating a pseudo-population where treatment is balanced.

```python
w_treat_w = T_conf_w / e_w  # treated contribution TY/e(X).
w_control_w = (1 - T_conf_w) / (1 - e_w)  # control contribution (1-T)Y/(1-e(X)).
ipw_w = float(np.mean(w_treat_w * Y_obs_conf_w - w_control_w * Y_obs_conf_w))
print("mean treated weight:", round(float(w_treat_w[T_conf_w == 1].mean()), 3))
print("mean control weight:", round(float(w_control_w[T_conf_w == 0].mean()), 3))
print("IPW ATE:", round(ipw_w, 3))
assert abs(ipw_w - 2.0) < 0.12
```
▶ What you'll see: IPW recovers the true ATE by reweighting outcomes with propensity denominators.

```python
weighted_x_t_w = np.sum(w_treat_w * X_w) / np.sum(w_treat_w)
weighted_x_c_w = np.sum(w_control_w * X_w) / np.sum(w_control_w)
print("raw mean X gap:", round(float(X_w[T_conf_w == 1].mean() - X_w[T_conf_w == 0].mean()), 3))
print("weighted mean X gap:", round(float(weighted_x_t_w - weighted_x_c_w), 3))
plt.figure(figsize=(5, 3))
plt.bar(["raw gap", "IPW gap"], [X_w[T_conf_w == 1].mean() - X_w[T_conf_w == 0].mean(), weighted_x_t_w - weighted_x_c_w], color=["crimson", "seagreen"])
plt.title("4: IPW balances the confounder")
plt.ylabel("treated mean X - control mean X")
plt.show()
```
▶ What you'll see: the raw confounder gap is large, while the weighted gap is near zero.

*Why it's done this way:* IPW estimates $E[T Y/e(X)]-E[(1-T)Y/(1-e(X))]$. The denominators undo the non-random sampling induced by treatment assignment: a treated unit with $e=0.2$ represents about five units from that covariate region, while a treated unit with $e=0.9$ represents only about 1.11.

### 5. Doubly-robust estimation: outcome model plus propensity model

A doubly-robust estimator combines an outcome regression $\mu_t(X)=E[Y\mid T=t,X]$ with a propensity score. Its correction terms add weighted residuals to the predicted potential outcomes. The remarkable property is that the estimator is consistent if either the outcome model or the propensity model is correct, not necessarily both.

```python
Phi_w = np.column_stack([np.ones(n_w), X_w])  # linear features for outcome regression.
beta0_w = np.linalg.lstsq(Phi_w[T_conf_w == 0], Y_obs_conf_w[T_conf_w == 0], rcond=None)[0]
beta1_w = np.linalg.lstsq(Phi_w[T_conf_w == 1], Y_obs_conf_w[T_conf_w == 1], rcond=None)[0]
mu0_w = Phi_w @ beta0_w
mu1_w = Phi_w @ beta1_w
plug_in_w = float(np.mean(mu1_w - mu0_w))
print("outcome-model ATE:", round(plug_in_w, 3))
assert abs(plug_in_w - 2.0) < 0.06
```
▶ What you'll see: a correctly specified linear outcome model already estimates the true effect well.

```python
dr_terms_w = (mu1_w - mu0_w
              + T_conf_w * (Y_obs_conf_w - mu1_w) / e_w
              - (1 - T_conf_w) * (Y_obs_conf_w - mu0_w) / (1 - e_w))
dr_w = float(np.mean(dr_terms_w))
print("doubly-robust ATE:", round(dr_w, 3))
assert abs(dr_w - 2.0) < 0.06
```
▶ What you'll see: the doubly-robust estimate is also near 2, using both predictions and residual reweighting.

*Why it's done this way:* the plug-in part averages the two modeled potential outcomes for every unit. The residual terms then repair mistakes using the observed arm only, scaled by the inverse probability of observing that arm. Algebraically, if $\mu_t$ is correct the residuals average to zero; if $e(X)$ is correct, the residuals correct the outcome model's bias.

### 6. Positivity and bad adjustment: denominators and colliders matter

Causal estimates need overlap: every covariate region must have some chance of treatment and control. If propensities approach 0 or 1, IPW weights explode. Adjustment can also fail by conditioning on a collider, a variable caused by both treatment and outcome-related factors, which can create a fake path instead of blocking one.

```python
extreme_e_w = 1 / (1 + np.exp(-4.0 * X_w))  # near-deterministic treatment for large |X|.
T_ext_w = rng_w.binomial(1, extreme_e_w)
weights_ext_w = T_ext_w / np.clip(extreme_e_w, 1e-6, 1) + (1 - T_ext_w) / np.clip(1 - extreme_e_w, 1e-6, 1)
print("95th percentile weight:", round(float(np.percentile(weights_ext_w, 95)), 3))
print("max weight:", round(float(weights_ext_w.max()), 3))
assert weights_ext_w.max() > 20
```
▶ What you'll see: a few units receive very large weights because their observed treatment was unlikely.

```python
C_w = 0.8 * T_rand_w + 0.8 * Y_obs_rand_w + rng_w.normal(0, 1, n_w)  # collider-style post-treatment variable.
median_c_w = np.median(C_w)
low_c_w = C_w <= median_c_w
high_c_w = C_w > median_c_w
naive_rand_w = float(Y_obs_rand_w[T_rand_w == 1].mean() - Y_obs_rand_w[T_rand_w == 0].mean())
collider_low_w = float(Y_obs_rand_w[low_c_w & (T_rand_w == 1)].mean() - Y_obs_rand_w[low_c_w & (T_rand_w == 0)].mean())
collider_high_w = float(Y_obs_rand_w[high_c_w & (T_rand_w == 1)].mean() - Y_obs_rand_w[high_c_w & (T_rand_w == 0)].mean())
print("randomized unadjusted:", round(naive_rand_w, 3))
print("within low collider stratum:", round(collider_low_w, 3))
print("within high collider stratum:", round(collider_high_w, 3))
```
▶ What you'll see: randomization works unadjusted, but slicing on a post-treatment collider distorts the comparison.

```python
plt.figure(figsize=(5, 3))
plt.hist(weights_ext_w, bins=40, color="darkorange")
plt.title("6: positivity problems create extreme weights")
plt.xlabel("IPW weight")
plt.ylabel("count")
plt.show()
```
▶ What you'll see: most weights are modest, but a long right tail warns that a few units can dominate the estimate.

*Why it's done this way:* causal adjustment is a design choice, not a recipe to condition on everything. Confounders are pre-treatment common causes to block; colliders and mediators are often not safe adjustment variables. Positivity is the denominator version of the same design requirement: without comparable treated and untreated units, the missing counterfactual is extrapolation.

## 🟢 Basics (warm-up)

### Basic 1 — Simulate potential outcomes

**Goal.** Create both $Y(0)$ and $Y(1)$ in a toy SCM, because causal effects are defined before treatment assignment hides one world. We build it in 2 steps.

```python
rng_b1 = np.random.default_rng(1) # Create reproducible randomness for this basic example.
n_b1 = 1000 # Use enough units that averages are stable.
X_b1 = rng_b1.normal(size=n_b1) # Draw a pre-treatment covariate.
Y0_b1 = 1 + 0.5 * X_b1 + rng_b1.normal(0, 0.2, n_b1) # Define the untreated potential outcome.
Y1_b1 = Y0_b1 + 1.5 # Define the treated potential outcome with a known constant effect.
print("Y0 first 3:", np.round(Y0_b1[:3], 3)) # Inspect untreated worlds for a few units.
print("Y1 first 3:", np.round(Y1_b1[:3], 3)) # Inspect treated worlds for the same units.
```
▶ What you'll see: the treated potential outcome is exactly 1.5 higher for each unit.

```python
ate_b1 = float(np.mean(Y1_b1 - Y0_b1)) # Average individual causal effects over the population.
print("true ATE:", round(ate_b1, 3)) # Inspect the estimand we will try to recover later.
assert round(ate_b1, 3) == 1.5 # Verify the known SCM effect.
plt.figure(figsize=(4, 3)) # Create a small comparison figure.
plt.scatter(Y0_b1[:80], Y1_b1[:80], s=12, alpha=0.7, color="teal") # Plot paired potential outcomes for visible units.
plt.title("Basic 1: paired potential outcomes") # Title the plot.
plt.xlabel("Y(0)") # Label untreated potential outcome.
plt.ylabel("Y(1)") # Label treated potential outcome.
plt.show() # Display the scatter.
```
▶ What you'll see: points lie on a line shifted upward by the treatment effect.

👀 Takeaway: the ATE is an average over missing-world comparisons, not a prediction accuracy score.

### Basic 2 — Observe only one potential outcome

**Goal.** Apply treatment assignment and construct the observed outcome $Y=TY(1)+(1-T)Y(0)$, because real data never contains both worlds for the same unit. We build it in 2 steps.

```python
rng_b2 = np.random.default_rng(2) # Create reproducible randomness.
n_b2 = 1000 # Choose a small population.
X_b2 = rng_b2.normal(size=n_b2) # Draw a covariate.
Y0_b2 = 2 + 0.4 * X_b2 + rng_b2.normal(0, 0.3, n_b2) # Define untreated potential outcomes.
Y1_b2 = Y0_b2 + 2.0 # Define treated potential outcomes with known effect 2.
T_b2 = rng_b2.binomial(1, 0.5, n_b2) # Randomly assign treatment.
print("treated count:", int(T_b2.sum()), "control count:", int((1 - T_b2).sum())) # Inspect assignment balance.
```
▶ What you'll see: roughly half the units are treated.

```python
Y_b2 = T_b2 * Y1_b2 + (1 - T_b2) * Y0_b2 # Reveal only the potential outcome matching the assigned treatment.
missing_world_b2 = T_b2 * Y0_b2 + (1 - T_b2) * Y1_b2 # Keep the unobserved counterfactual only for teaching.
print("observed Y first 3:", np.round(Y_b2[:3], 3)) # Inspect observed outcomes.
print("counterfactual first 3:", np.round(missing_world_b2[:3], 3)) # Inspect hidden worlds in the simulation.
plt.figure(figsize=(4, 3)) # Create a compact observed-vs-hidden plot.
plt.scatter(Y_b2[:80], missing_world_b2[:80], s=12, color="purple", alpha=0.7) # Compare observed and hidden values.
plt.title("Basic 2: observed vs counterfactual") # Title the plot.
plt.xlabel("observed outcome") # Label observed axis.
plt.ylabel("unobserved counterfactual") # Label hidden axis.
plt.show() # Display the scatter.
```
▶ What you'll see: every unit has one observed value and one counterfactual that ordinary data would not reveal.

👀 Takeaway: causal inference is hard because the comparison we want is partly missing by design.

### Basic 3 — Randomization makes the difference unbiased

**Goal.** Estimate the ATE by a treated-minus-control difference under random assignment, because randomization breaks links between treatment and potential outcomes. We build it in 3 steps.

```python
rng_b3 = np.random.default_rng(3) # Create reproducible randomness.
n_b3 = 4000 # Use many units for a stable randomized estimate.
X_b3 = rng_b3.normal(size=n_b3) # Draw a covariate that affects outcomes.
Y0_b3 = 1 + X_b3 + rng_b3.normal(0, 0.5, n_b3) # Define baseline outcomes.
Y1_b3 = Y0_b3 + 1.2 # Add a known treatment effect.
T_b3 = rng_b3.binomial(1, 0.5, n_b3) # Randomize treatment independent of X and outcomes.
print("mean X treated:", round(float(X_b3[T_b3 == 1].mean()), 3)) # Inspect covariate balance.
print("mean X control:", round(float(X_b3[T_b3 == 0].mean()), 3)) # Inspect covariate balance.
```
▶ What you'll see: treatment and control have similar average covariates.

```python
Y_b3 = T_b3 * Y1_b3 + (1 - T_b3) * Y0_b3 # Construct observed outcomes.
diff_b3 = float(Y_b3[T_b3 == 1].mean() - Y_b3[T_b3 == 0].mean()) # Compute the randomized difference in means.
true_b3 = float(np.mean(Y1_b3 - Y0_b3)) # Compute the true ATE from the SCM.
print("randomized estimate:", round(diff_b3, 3), "true ATE:", round(true_b3, 3)) # Compare estimate and truth.
assert abs(diff_b3 - true_b3) < 0.08 # Verify randomization recovers the effect up to sampling noise.
```
▶ What you'll see: the printed values and/or plot expose the current causal quantity before the next step.

```python
plt.figure(figsize=(4, 3)) # Create an estimator comparison plot.
plt.bar(["estimate", "truth"], [diff_b3, true_b3], color=["seagreen", "black"]) # Compare estimate with true ATE.
plt.title("Basic 3: randomized difference") # Title the plot.
plt.ylabel("ATE") # Label the effect scale.
plt.show() # Display the comparison.
```
▶ What you'll see: the estimate bar nearly matches the truth bar.

👀 Takeaway: randomization makes treated and untreated groups comparable before treatment.

### Basic 4 — Show confounding bias

**Goal.** Make treatment depend on a prognostic covariate, because observational treatment often selects people who would already have different outcomes. We build it in 3 steps.

```python
rng_b4 = np.random.default_rng(4) # Create reproducible randomness.
n_b4 = 4000 # Use enough samples for a clear bias demonstration.
X_b4 = rng_b4.normal(size=n_b4) # Draw a confounder.
Y0_b4 = 1 + 0.8 * X_b4 + rng_b4.normal(0, 0.3, n_b4) # Let X raise untreated outcomes.
Y1_b4 = Y0_b4 + 1.0 # Define the true treatment effect.
e_b4 = 1 / (1 + np.exp(-1.5 * X_b4)) # Let X also raise treatment probability.
T_b4 = rng_b4.binomial(1, e_b4) # Draw confounded treatment.
print("treatment rate:", round(float(T_b4.mean()), 3)) # Inspect treatment prevalence.
```
▶ What you'll see: treatment is common but not randomized.

```python
Y_b4 = T_b4 * Y1_b4 + (1 - T_b4) * Y0_b4 # Construct observed outcomes.
naive_b4 = float(Y_b4[T_b4 == 1].mean() - Y_b4[T_b4 == 0].mean()) # Compute the observational association.
true_b4 = float(np.mean(Y1_b4 - Y0_b4)) # Compute the true ATE.
print("naive difference:", round(naive_b4, 3), "true ATE:", round(true_b4, 3)) # Compare association and effect.
assert naive_b4 > true_b4 + 0.5 # Verify confounding inflated the naive estimate.
```
▶ What you'll see: the printed values and/or plot expose the current causal quantity before the next step.

```python
plt.figure(figsize=(4, 3)) # Create a bias visualization.
plt.bar(["naive", "true"], [naive_b4, true_b4], color=["crimson", "black"]) # Compare biased association with causal truth.
plt.title("Basic 4: confounding inflates association") # Title the plot.
plt.ylabel("effect estimate") # Label the y-axis.
plt.show() # Display the plot.
```
▶ What you'll see: the naive bar is much taller than the true-effect bar.

👀 Takeaway: association is not causation when treatment groups differ before treatment.

### Basic 6 — Adjust with two strata

**Goal.** Estimate separate treated-control differences for low and high $X$, because adjustment compares units within similar covariate regions. We build it in 3 steps.

```python
rng_b6 = np.random.default_rng(6) # Create reproducible randomness.
n_b6 = 5000 # Use enough samples in both strata.
X_b6 = rng_b6.normal(size=n_b6) # Draw a confounder.
Y0_b6 = 1 + 0.3 * X_b6 + rng_b6.normal(0, 0.4, n_b6) # Baseline depends on X.
Y1_b6 = Y0_b6 + 1.4 # Known treatment effect.
e_b6 = 1 / (1 + np.exp(-0.6 * X_b6)) # Treatment depends on X.
T_b6 = rng_b6.binomial(1, e_b6) # Confounded assignment.
Y_b6 = T_b6 * Y1_b6 + (1 - T_b6) * Y0_b6 # Observed outcome.
high_b6 = X_b6 > np.median(X_b6) # Split the confounder into two strata.
print("low stratum count:", int((~high_b6).sum()), "high stratum count:", int(high_b6.sum())) # Inspect stratum sizes.
```
▶ What you'll see: the median split makes two equal-size strata.

```python
effects_b6 = [] # Store within-stratum effects.
```

### Advanced 4 — Doubly robust survives a wrong propensity

**Goal.** Deliberately use a poor constant propensity while keeping the outcome model correct, because double robustness means one correct nuisance model can still save the ATE. We build it in 4 steps.

```python

n_a4 = 5000 # Use a stable sample.

true_e_a4 = 1 / (1 + np.exp(-1.2 * X_a4)) # True confounded treatment probability.

Y_a4 = T_a4 * Y1_a4 + (1 - T_a4) * Y0_a4 # Observe factual outcomes.
```

### Advanced 5 — Confounded versus adjusted estimates in one audit

**Goal.** Build a small causal audit that reports naive, backdoor, IPW, and doubly-robust estimates together, because real analyses compare estimators and look for agreement. We build it in 5 steps.

```python
rng_a5 = np.random.default_rng(25) # Create reproducible randomness.
n_a5 = 7000 # Use a stable sample.
X_a5 = rng_a5.normal(size=n_a5) # Draw confounder.
Y0_a5 = 0.5 + 0.6 * X_a5 + rng_a5.normal(0, 0.4, n_a5) # Define untreated outcomes.
Y1_a5 = Y0_a5 + 1.1 # Define known treatment effect.
e_true_a5 = 1 / (1 + np.exp(-(-0.1 + 1.0 * X_a5))) # True propensity.
T_a5 = rng_a5.binomial(1, e_true_a5) # Draw confounded treatment.
Y_a5 = T_a5 * Y1_a5 + (1 - T_a5) * Y0_a5 # Observe outcomes.
naive_a5 = float(Y_a5[T_a5 == 1].mean() - Y_a5[T_a5 == 0].mean()) # Compute naive association.
print("naive:", round(naive_a5, 3)) # Inspect biased estimate.
```
▶ What you'll see: the naive association is larger than the true effect of 1.1.

```python

edges_a5[0] -= 1e-6 # Include minimum.
edges_a5[-1] += 1e-6 # Include maximum.
S_a5 = np.digitize(X_a5, edges_a5[1:-1]) # Assign strata.
strat_eff_a5 = [] # Store stratum effects.
strat_w_a5 = [] # Store population weights.
for s_a5 in range(5): # Loop over strata.
    m_a5 = S_a5 == s_a5 # Select stratum.
    strat_eff_a5.append(Y_a5[m_a5 & (T_a5 == 1)].mean() - Y_a5[m_a5 & (T_a5 == 0)].mean()) # Within-stratum contrast.
    strat_w_a5.append(m_a5.mean()) # Population stratum weight.
backdoor_a5 = float(np.dot(strat_eff_a5, strat_w_a5)) # Backdoor-adjusted ATE.
print("backdoor:", round(backdoor_a5, 3)) # Inspect adjusted estimate.
```
▶ What you'll see: the printed values and/or plot expose the current causal quantity before the next step.

```python
Z_a5 = np.column_stack([np.ones(n_a5), X_a5]) # Build nuisance-model design.
beta_a5 = np.zeros(2) # Initialize propensity coefficients.
for step_a5 in range(900): # Fit propensity by gradient descent.
    p_a5 = 1 / (1 + np.exp(-(Z_a5 @ beta_a5))) # Predict treatment probabilities.
    beta_a5 -= 0.7 * (Z_a5.T @ (p_a5 - T_a5) / n_a5) # Update coefficients.
ehat_a5 = np.clip(1 / (1 + np.exp(-(Z_a5 @ beta_a5))), 0.03, 0.97) # Clip estimated propensities.

print("IPW:", round(ipw_a5, 3)) # Inspect IPW estimate.
```
▶ What you'll see: the printed values and/or plot expose the current causal quantity before the next step.

```python

b1_a5 = np.linalg.lstsq(Z_a5[T_a5 == 1], Y_a5[T_a5 == 1], rcond=None)[0] # Fit treated outcome regression.
mu0_a5 = Z_a5 @ b0_a5 # Predict untreated outcomes.
```
