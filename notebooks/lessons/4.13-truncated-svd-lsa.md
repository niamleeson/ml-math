# 4.13 — Truncated SVD & LSA

Truncated SVD finds a low-dimensional structure inside a matrix by keeping only the strongest singular directions. In Latent Semantic Analysis (LSA), that matrix is usually term×document counts or weights, so the kept directions behave like hidden topics: words and documents that never exactly match can become close because they share the same latent geometry.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build Truncated SVD and LSA one idea at a time. Run each cell in order and read the printed intermediate values — every shape, singular value, projection, and reconstruction is exposed so the method is not a black box. This walkthrough is self-contained and uses a `_w` suffix on variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, matrix multiplication, SVD, norms, and small numerical checks.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for any randomized checks.
```

### 1. Build the matrix and choose what the numbers mean

Truncated SVD only sees a matrix. For LSA, rows can be terms and columns can be documents, and each entry says how strongly a term appears in a document. The algorithm has no language understanding by itself; the meaning comes from how we encode text as numbers. Here we create two themes — pets and vehicles — with a small bridge word so the low-rank structure has something real to discover.

```python
terms_w = np.array(["cat", "dog", "pet", "car", "truck", "road"])  # six vocabulary terms.
docs_w = np.array(["pet-1", "pet-2", "mixed", "vehicle-1", "vehicle-2"])  # five documents.
X_w = np.array([[4., 3., 1., 0., 0.],   # cat
                [3., 4., 1., 0., 0.],   # dog
                [5., 4., 2., 0., 0.],   # pet
                [0., 0., 1., 4., 5.],   # car
                [0., 0., 1., 5., 4.],   # truck
                [0., 0., 0., 3., 4.]])  # road
print("X shape terms×docs:", X_w.shape)
print(X_w)
```
▶ What you'll see: a 6×5 term-document matrix with two visible blocks and one mixed document.

```python
plt.figure(figsize=(4.8, 3.2))
plt.imshow(X_w, cmap="viridis", aspect="auto")
plt.colorbar(label="term count")
plt.xticks(range(len(docs_w)), docs_w, rotation=25)
plt.yticks(range(len(terms_w)), terms_w)
plt.title("1: term-document matrix")
plt.show()
```
▶ What you'll see: pet words are bright in the first columns, vehicle words are bright in the last columns, and the mixed column touches both.

*Why it's done this way:* SVD optimizes numerical reconstruction, not semantics. If the matrix entries are raw counts, long documents and common words can dominate; if they are centered or reweighted, different structure becomes visible. The first modeling decision is therefore not the factorization — it is what each entry of `X` is allowed to mean.

### 2. Center columns before asking for directions of variation

The lesson formula uses $X_c$, a centered matrix. Centering subtracts each column's mean so SVD finds directions of variation around a baseline instead of spending the first component on the fact that some documents simply contain more total counts. In data matrices, this is the same habit as PCA: remove the offset, then study directions.

```python
col_means_w = X_w.mean(axis=0)  # average term count inside each document column.
Xc_w = X_w - col_means_w  # subtract the document baseline from every term in that document.
print("column means:", np.round(col_means_w, 3))
print("centered column sums:", np.round(Xc_w.sum(axis=0), 6))
assert np.allclose(Xc_w.sum(axis=0), 0.0)
```
▶ What you'll see: every centered column sums to zero, so the column baseline has been removed.

```python
fig, ax = plt.subplots(1, 2, figsize=(8, 3))
ax[0].imshow(X_w, cmap="viridis", aspect="auto")
ax[0].set_title("raw counts")
ax[1].imshow(Xc_w, cmap="coolwarm", aspect="auto")
ax[1].set_title("centered deviations")
for a_w in ax:
    a_w.set_xticks(range(len(docs_w))); a_w.set_xticklabels(docs_w, rotation=25)
    a_w.set_yticks(range(len(terms_w))); a_w.set_yticklabels(terms_w)
plt.suptitle("2: centering changes the matrix SVD sees")
plt.show()
```
▶ What you'll see: the raw matrix is nonnegative counts, while the centered matrix shows above- and below-baseline deviations.

*Why it's done this way:* Without centering, a component can waste capacity explaining document length or overall frequency. Subtracting means forces the singular directions to explain contrast: which terms are high relative to a document's own baseline and which are low. That is the geometry behind $X_c=U\Sigma V^\top$.

### 3. Compute SVD and read the factors

The singular value decomposition writes $X_c=U\Sigma V^\top$. The columns of $U$ are orthonormal term directions, the rows of $V^\top$ are orthonormal document directions, and the singular values in $\Sigma$ say how much energy each paired direction carries. Large singular values are directions the matrix uses strongly; small ones are details or noise.

```python
U_w, s_w, Vt_w = np.linalg.svd(Xc_w, full_matrices=False)  # compact SVD.
print("U shape:", U_w.shape, "s shape:", s_w.shape, "Vt shape:", Vt_w.shape)
print("singular values:", np.round(s_w, 3))
assert U_w.shape == (6, 5) and Vt_w.shape == (5, 5)
```
▶ What you'll see: the matrix is split into term directions, five singular values, and document directions.

```python
energy_w = s_w ** 2  # squared singular values are reconstruction energy.
explained_w = energy_w / energy_w.sum()
print("explained energy:", np.round(explained_w, 3))
print("cumulative:", np.round(np.cumsum(explained_w), 3))
plt.figure(figsize=(4.5, 3))
plt.bar(np.arange(1, len(s_w) + 1), explained_w, color="teal")
plt.plot(np.arange(1, len(s_w) + 1), np.cumsum(explained_w), marker="o", color="black")
plt.title("3: singular-value energy")
plt.xlabel("component")
plt.ylabel("fraction of energy")
plt.show()
```
▶ What you'll see: the first few components carry most of the energy, which is why truncation can work.

*Why it's done this way:* SVD orders directions by decreasing squared error reduction. Keeping component 1 before component 2 is not arbitrary; the first singular vector pair is the rank-1 matrix with the largest possible Frobenius-norm payoff, the second is the best remaining orthogonal correction, and so on.

### 4. Truncate, project, and reconstruct

Truncated SVD keeps only the first $r$ singular directions. The low-dimensional representation in the lesson is $Z=X_cV_r$, where $V_r$ keeps the first $r$ right singular vectors. Multiplying by $V_r$ projects each row into the retained coordinates; reconstructing with $U_r\Sigma_rV_r^\top$ shows exactly what information the bottleneck preserved.

```python
r_w = 2  # keep two latent dimensions.
U_r_w = U_w[:, :r_w]
s_r_w = s_w[:r_w]
Vt_r_w = Vt_w[:r_w, :]
Z_terms_w = Xc_w @ Vt_r_w.T  # term embeddings in the document-direction basis.
print("Z_terms shape:", Z_terms_w.shape)
print(np.round(Z_terms_w, 3))
assert Z_terms_w.shape == (6, 2)
```
▶ What you'll see: each term is now two coordinates instead of five document counts.

```python
X2_w = U_r_w @ np.diag(s_r_w) @ Vt_r_w  # rank-2 reconstruction.
err2_w = np.linalg.norm(Xc_w - X2_w)
err0_w = np.linalg.norm(Xc_w)
print("rank-2 error:", round(err2_w, 3))
print("relative error:", round(err2_w / err0_w, 3))
assert err2_w < err0_w
```
▶ What you'll see: rank 2 loses some detail but is much closer than reconstructing everything as zero.

```python
plt.figure(figsize=(4.6, 3.4))
plt.scatter(Z_terms_w[:, 0], Z_terms_w[:, 1], s=80, color="purple")
for i_w, term_w in enumerate(terms_w):
    plt.text(Z_terms_w[i_w, 0] + 0.05, Z_terms_w[i_w, 1], term_w)
plt.axhline(0, color="gray", linewidth=0.6)
plt.axvline(0, color="gray", linewidth=0.6)
plt.title("4: terms in rank-2 SVD space")
plt.xlabel("latent component 1")
plt.ylabel("latent component 2")
plt.show()
```
▶ What you'll see: related terms tend to occupy nearby regions of the low-dimensional map.

*Why it's done this way:* Truncation is compression with a guarantee: among all rank-`r` matrices, the kept SVD pieces give the smallest Frobenius reconstruction error. Projection gives compact coordinates; reconstruction checks what those coordinates still explain.

### 5. Use LSA for similarity beyond exact word overlap

LSA becomes useful when similarity is computed in the latent space rather than on raw term overlap. A query about `cat` can become close to documents that also use `dog` or `pet`, because the shared singular directions encode co-occurrence structure. The query is projected with the same $V_r$ directions so it lives in the same coordinate system as the terms.

```python
def cos_w(a, b):
    denom_w = np.linalg.norm(a) * np.linalg.norm(b)
    return 0.0 if denom_w == 0 else float(np.dot(a, b) / denom_w)

doc_coords_w = (np.diag(s_r_w) @ Vt_r_w).T  # document embeddings: columns of V scaled by singular values.
query_counts_w = np.array([1., 1., 1., 0., 0., 0.])  # query: cat dog pet.
query_centered_w = query_counts_w - query_counts_w.mean()
query_coord_w = query_centered_w @ U_r_w  # project query terms into same rank-2 coordinates.
print("doc coords shape:", doc_coords_w.shape)
print("query coord:", np.round(query_coord_w, 3))
```
▶ What you'll see: every document and the query are represented by two latent numbers.

```python
scores_w = np.array([cos_w(query_coord_w, doc_coords_w[j_w]) for j_w in range(len(docs_w))])
order_w = np.argsort(scores_w)[::-1]
print("LSA scores:", dict(zip(docs_w, np.round(scores_w, 3))))
print("best document:", docs_w[order_w[0]])
assert scores_w[0] > scores_w[-1]
```
▶ What you'll see: pet documents score higher than vehicle documents even though the comparison is low-dimensional.

```python
plt.figure(figsize=(5, 3))
plt.bar(docs_w, scores_w, color="seagreen")
plt.axhline(0, color="black", linewidth=0.6)
plt.title("5: LSA query-document cosine")
plt.ylabel("cosine in latent space")
plt.xticks(rotation=25)
plt.show()
```
▶ What you'll see: the highest bars are documents aligned with the query's latent topic.

*Why it's done this way:* Exact matching treats words as independent coordinates. LSA rotates the space into directions of co-occurrence, so two documents can be similar because they load on the same hidden component, not because they share every literal term.

### 6. Check rank, scaling, and stability before trusting structure

Truncated SVD is a lens, not an oracle. The rank decides how much detail survives; scaling decides which rows or columns dominate; and small data changes can rotate or flip components. Good practice is to rerun nearby ranks and perturbations, then ask whether the same qualitative structure remains.

```python
ranks_w = np.arange(1, min(Xc_w.shape) + 1)
errors_w = []
for rank_w in ranks_w:
    Xk_w = U_w[:, :rank_w] @ np.diag(s_w[:rank_w]) @ Vt_w[:rank_w, :]
    errors_w.append(float(np.linalg.norm(Xc_w - Xk_w)))
print("errors by rank:", np.round(errors_w, 3))
assert np.all(np.diff(errors_w) <= 1e-10)
```
▶ What you'll see: reconstruction error never increases as rank grows.

```python
X_scaled_w = X_w.copy()
X_scaled_w[2] *= 10  # make the word "pet" artificially huge.
Xsc_w = X_scaled_w - X_scaled_w.mean(axis=0)
_, s_scaled_w, _ = np.linalg.svd(Xsc_w, full_matrices=False)
print("original first energy:", round((s_w[0] ** 2) / np.sum(s_w ** 2), 3))
print("scaled first energy:", round((s_scaled_w[0] ** 2) / np.sum(s_scaled_w ** 2), 3))
```
▶ What you'll see: changing one row's scale changes the singular-value story.

```python
plt.figure(figsize=(5, 3))
plt.plot(ranks_w, errors_w, marker="o", color="navy")
plt.title("6: rank controls reconstruction error")
plt.xlabel("rank kept")
plt.ylabel("Frobenius error")
plt.xticks(ranks_w)
plt.show()
```
▶ What you'll see: the curve falls with rank, but the right rank is a modeling decision rather than a theorem.

*Why it's done this way:* The arithmetic is deterministic for a fixed matrix, but the matrix is a modeling artifact. Scaling a term, centering a column, or choosing rank changes what counts as explanatory, so the responsible workflow audits those choices instead of treating the first plot as ground truth.

### Basic 3 — Run the SVD

**Goal.** Factor a centered matrix into U, singular values, and Vᵀ, because these are the pieces Truncated SVD keeps or drops. We build it in 2 steps.

```python
X_b3 = np.array([[1., 2.], [2., 1.], [3., 4.], [4., 3.]])  # Recreate the toy matrix.
Xc_b3 = X_b3 - X_b3.mean(axis=0)  # Center before SVD.

```
▶ What you'll see: two singular values because the centered matrix has two feature directions.

```python
reconstructed_b3 = U_b3 @ np.diag(s_b3) @ Vt_b3  # Rebuild the centered matrix from all SVD pieces.
print("max reconstruction error:", np.max(np.abs(Xc_b3 - reconstructed_b3)))  # Check exact reconstruction.
assert np.allclose(Xc_b3, reconstructed_b3)
```
▶ What you'll see: full SVD reconstructs the centered matrix up to tiny floating-point error.

```python
plt.figure(figsize=(4, 3))
```

👀 Takeaway: SVD is an exact factorization until we deliberately truncate it.

### Basic 5 — Keep only rank 1

**Goal.** Reconstruct a matrix with only the strongest component, because Truncated SVD is full SVD plus deletion. We build it in 3 steps.

```python
X_b5 = np.array([[1., 2.], [2., 1.], [3., 4.], [4., 3.]])  # Recreate the toy matrix.
```

### Basic 6 — Project rows into latent coordinates

**Goal.** Compute `Z = Xc V_r`, because the lower-dimensional representation stores each row's coordinates in kept singular directions. We build it in 2 steps.

```python
X_b6 = np.array([[1., 2.], [2., 1.], [3., 4.], [4., 3.]])  # Recreate the toy matrix.
```
