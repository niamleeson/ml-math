# 10.13 — Classifier-Free Guidance

Classifier-free guidance (CFG) is the sampling-time trick that lets one diffusion model balance realism against prompt fidelity. In this lesson, we build the score arithmetic from scratch with NumPy: an unconditional denoising direction says what looks generally data-like, a conditional direction says what matches the prompt, and guidance extrapolates from the first toward (and often beyond) the second.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build classifier-free guidance one idea at a time. Run each cell in order and read the printed intermediate values — every vector, score, and denoising step is small enough to audit by hand. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, vector arithmetic, and reproducible toy diffusion math.
import matplotlib.pyplot as plt  # all walkthrough visualizations.

plt.rcParams["figure.max_open_warning"] = 0  # keep headless validation quiet when many lesson figures open.
```

### 1. Scores as denoising directions

A diffusion sampler holds a noisy point and asks the model which way to move to make it less noisy. We will use a tiny 2-D toy: one coordinate behaves like a generic image manifold direction, and the other behaves like a prompt-specific feature. A **score** is just a vector direction; stepping along it is a simplified denoising update.

```python
x_w = np.array([-1.0, 0.5])  # current noisy sample in a tiny 2-D latent space.
s_uncond_w = np.array([0.4, -0.2])  # generic denoising direction: move toward plausible data.
s_cond_w = np.array([0.9, 0.6])  # prompt-aware denoising direction: plausible and prompt-matching.
print("x:", x_w)  # inspect the noisy point.
print("unconditional score:", s_uncond_w, "conditional score:", s_cond_w)  # inspect the two model predictions.
```
▶ What you'll see: two different denoising vectors for the same noisy point — one ignores the prompt, the other uses it.

```python
plt.figure(figsize=(4.5, 3.5))  # create a compact vector plot.
plt.scatter([x_w[0]], [x_w[1]], color="black", label="current x")  # mark the current sample.
plt.quiver([x_w[0], x_w[0]], [x_w[1], x_w[1]], [s_uncond_w[0], s_cond_w[0]], [s_uncond_w[1], s_cond_w[1]],
           angles="xy", scale_units="xy", scale=1, color=["gray", "teal"], width=0.008)  # draw the two score arrows.
plt.text(x_w[0] + s_uncond_w[0], x_w[1] + s_uncond_w[1], "uncond")  # label generic direction.
plt.text(x_w[0] + s_cond_w[0], x_w[1] + s_cond_w[1], "cond")  # label prompt direction.
plt.xlim(-1.3, 0.2); plt.ylim(0.0, 1.4); plt.xlabel("latent axis 0"); plt.ylabel("latent axis 1")  # readable axes.
plt.title("1: two denoising directions"); plt.legend(); plt.show()  # display the plot.
```
▶ What you'll see: the conditional arrow has a much stronger upward component, representing the prompt-specific feature.

*Why it's done this way: diffusion sampling is local vector arithmetic. The unconditional score estimates “what direction makes this look like data,” while the conditional score estimates “what direction makes this look like data matching the condition.” CFG works because those two directions live in the same vector space and can be subtracted.*

### 2. The conditional-minus-unconditional difference

CFG isolates the prompt pressure by subtracting the unconditional score from the conditional score. The difference vector $s_{cond}-s_{uncond}$ is the part of the denoising direction that appears only when the condition is present. If that difference points upward, the prompt is asking the sampler to add more of the upward feature.

```python
delta_w = s_cond_w - s_uncond_w  # prompt-only direction: what conditioning changes.
print("delta = cond - uncond:", delta_w)  # inspect the prompt pressure.
assert np.allclose(delta_w, [0.5, 0.8])  # verify the hand-computable difference.
```
▶ What you'll see: the prompt adds `[0.5, 0.8]` to the generic denoising direction.

```python
parts_w = np.vstack([s_uncond_w, delta_w, s_cond_w])  # stack vectors for a component chart.
plt.figure(figsize=(5, 3))  # create a grouped component plot.
plt.bar(np.arange(2) - 0.25, parts_w[0], width=0.25, label="uncond", color="gray")  # plot generic components.
plt.bar(np.arange(2), parts_w[1], width=0.25, label="cond - uncond", color="orange")  # plot prompt-only components.
plt.bar(np.arange(2) + 0.25, parts_w[2], width=0.25, label="cond", color="teal")  # plot conditional components.
plt.xticks([0, 1], ["axis 0", "axis 1"]); plt.axhline(0, color="black", linewidth=0.7)  # axis labels and baseline.
plt.title("2: conditioning is a vector difference"); plt.legend(); plt.show()  # display the comparison.
```
▶ What you'll see: the conditional score equals the unconditional score plus the orange prompt-only difference.

*Why it's done this way: subtracting removes the shared “looks like data” part and leaves the condition-specific pressure. That is why the guidance formula can amplify prompt adherence without training a separate classifier gradient.*

### 3. Guidance scale as interpolation and extrapolation

The CFG formula is

$$s_{guided}=s_{uncond}+w(s_{cond}-s_{uncond}).$$

When $w=0$, we ignore the prompt. When $w=1$, we use the conditional prediction exactly. When $w>1$, we extrapolate **past** the conditional prediction, making prompt features stronger than the model originally predicted. The scalar example from the lesson block makes the arithmetic visible.

```python
su_scalar_w = -0.4  # unconditional scalar score from the lesson block.
sc_scalar_w = 0.9  # conditional scalar score from the lesson block.
w_scalar_w = 3.0  # guidance scale.
guided_scalar_w = su_scalar_w + w_scalar_w * (sc_scalar_w - su_scalar_w)  # CFG mixing formula.
print("difference:", round(sc_scalar_w - su_scalar_w, 3))  # 0.9 - (-0.4) = 1.3.
print("guided score:", round(guided_scalar_w, 3))  # -0.4 + 3*1.3 = 3.5.
assert round(sc_scalar_w - su_scalar_w, 3) == 1.3  # verify lesson number.
assert round(guided_scalar_w, 3) == 3.5  # verify lesson number.
```
▶ What you'll see: with `w=3`, the guided score is `3.5`, far beyond the conditional score `0.9`.

```python
scales_w = np.array([0.0, 0.5, 1.0, 2.0, 3.0])  # guidance scales to compare.
guided_scalar_grid_w = su_scalar_w + scales_w * (sc_scalar_w - su_scalar_w)  # compute guided score for each scale.
print("guided scores by w:", np.round(guided_scalar_grid_w, 3))  # inspect interpolation/extrapolation.
plt.figure(figsize=(5, 3))  # create a line plot over guidance scale.
plt.plot(scales_w, guided_scalar_grid_w, marker="o", color="purple")  # draw score versus scale.
plt.axhline(sc_scalar_w, color="teal", linestyle="--", label="conditional score")  # mark w=1 target.
plt.axhline(su_scalar_w, color="gray", linestyle="--", label="unconditional score")  # mark w=0 target.
plt.title("3: guidance scale extrapolates"); plt.xlabel("guidance scale w"); plt.ylabel("guided scalar score"); plt.legend(); plt.show()  # display.
```
▶ What you'll see: the curve passes through the unconditional score at `w=0`, the conditional score at `w=1`, then keeps rising beyond it.

*Why it's done this way: $w$ is not a probability or a softmax temperature; it is an extrapolation coefficient. Values above 1 intentionally over-emphasize the condition, which can improve prompt fidelity but also push samples away from the learned data manifold.*

### 4. Guided denoising steps in a toy sampler

A sampler turns a score into a small update, here `x_next = x + step_size * score`. This is not a full DDPM update, but it captures the CFG logic: the only difference between samples is the score used inside the same stepping rule.

```python
step_w = 0.4  # small denoising step size.
scales_step_w = np.array([0.0, 1.0, 3.0])  # unconditional, conditional, strong CFG.
paths_w = []  # store short trajectories for each scale.
for scale_w in scales_step_w:  # simulate several denoising steps.
    x_path_w = [x_w.copy()]  # start at the same noisy point.
    for t_w in range(5):  # take five toy denoising steps.
        score_w = s_uncond_w + scale_w * (s_cond_w - s_uncond_w)  # guided score for this scale.
        x_path_w.append(x_path_w[-1] + step_w * score_w)  # update the sample.
    paths_w.append(np.array(x_path_w))  # store this trajectory.
print("final points:", [np.round(p[-1], 3).tolist() for p in paths_w])  # inspect endpoints.
```
▶ What you'll see: all trajectories start at the same point, but higher guidance ends farther in the prompt direction.

```python
plt.figure(figsize=(5, 4))  # create trajectory plot.
for scale_w, path_w, color_w in zip(scales_step_w, paths_w, ["gray", "teal", "crimson"]):  # draw each CFG path.
    plt.plot(path_w[:, 0], path_w[:, 1], marker="o", color=color_w, label=f"w={scale_w:g}")  # trajectory.
plt.scatter([x_w[0]], [x_w[1]], color="black", zorder=3, label="start")  # starting point.
plt.xlabel("latent axis 0"); plt.ylabel("latent axis 1"); plt.title("4: guidance changes the sampling path"); plt.legend(); plt.show()  # display.
```
▶ What you'll see: the `w=3` path climbs fastest along the prompt-specific direction; look for the red path overshooting the teal path.

*Why it's done this way: a diffusion sampler repeatedly applies denoising updates. CFG does not require changing the sampler’s mechanics; it changes the vector inserted into each step, so the same step rule follows a different path through latent space.*

### 5. Training one model to be conditional and unconditional

Classifier-free guidance needs both predictions from the same network family. During training, the condition is randomly dropped, so the model sees conditional examples and unconditional examples. In this toy version, a dropout mask decides whether each training row keeps its label feature.

```python
labels_w = np.array([1, 1, 0, 1, 0, 0, 1, 0])  # toy conditions: 1 means prompt/label is present.
drop_prob_w = 0.25  # probability of hiding the condition during training.
rng_w = np.random.default_rng(0)  # local reproducible generator.
keep_condition_w = rng_w.random(labels_w.shape) > drop_prob_w  # True means train conditionally.
condition_seen_w = labels_w * keep_condition_w  # dropped labels become 0-like null conditioning.
print("labels:", labels_w)  # inspect true labels.
print("keep condition:", keep_condition_w.astype(int))  # inspect condition dropout mask.
print("condition sent to model:", condition_seen_w)  # inspect mixed conditional/unconditional batch.
```
▶ What you'll see: some originally conditional examples are converted to null-condition examples.

```python
n_cond_w = int(keep_condition_w.sum())  # count conditional training cases.
n_uncond_w = int((~keep_condition_w).sum())  # count unconditional training cases.
plt.figure(figsize=(4, 3))  # create count plot.
plt.bar(["conditional", "unconditional"], [n_cond_w, n_uncond_w], color=["teal", "gray"])  # show batch mix.
plt.title("5: condition dropout creates both tasks"); plt.ylabel("examples"); plt.show()  # display.
```
▶ What you'll see: the batch contains both kept-condition and dropped-condition cases, so one model can learn both predictions.

*Why it's done this way: CFG sampling asks for two outputs at the same noisy input: one with the condition and one with the null condition. Randomly dropping conditions during training teaches the null branch without requiring a separate unconditional model.*

### 6. The high-guidance pitfall

Because $w>1$ extrapolates, very high guidance can leave the region where the model's score estimates are reliable. We can make that concrete with a toy “realism band”: values near the conditional score are plausible, while extreme extrapolated values are marked as artifact risk.

```python
scale_grid_w = np.linspace(0, 8, 17)  # sweep guidance from off to very high.
guided_grid_w = su_scalar_w + scale_grid_w * (sc_scalar_w - su_scalar_w)  # scalar guided scores.
realism_penalty_w = np.maximum(0.0, np.abs(guided_grid_w - sc_scalar_w) - 1.5)  # toy penalty beyond a safe band.
print("first risky scale:", scale_grid_w[np.argmax(realism_penalty_w > 0)])  # inspect when penalty starts.
assert round(float(guided_grid_w[6]), 3) == 3.5  # at w=3, the lesson guided score appears in the grid.
```
▶ What you'll see: as scale grows, the score moves farther from the conditional prediction and eventually enters the risk band.

```python
fig, ax1 = plt.subplots(figsize=(5, 3))  # create dual-axis diagnostic plot.
ax1.plot(scale_grid_w, guided_grid_w, marker="o", color="purple", label="guided score")  # score curve.
ax1.axhline(sc_scalar_w, color="teal", linestyle="--", label="conditional")  # reference.
ax1.set_xlabel("guidance scale w"); ax1.set_ylabel("guided score")  # axis labels.
ax2 = ax1.twinx()  # second axis for risk.
ax2.plot(scale_grid_w, realism_penalty_w, color="crimson", label="artifact risk")  # risk curve.
ax2.set_ylabel("toy artifact risk")  # risk label.
fig.legend(loc="upper left", bbox_to_anchor=(0.12, 0.88)); plt.title("6: too much guidance can overshoot"); plt.show()  # display.
```
▶ What you'll see: prompt pressure keeps increasing with `w`, but the red risk curve rises once extrapolation becomes extreme.

*Why it's done this way: the formula is linear, but image quality is not. A higher score toward the prompt can sharpen semantics, yet the sampler may sacrifice diversity, texture, or realism when the extrapolated direction no longer matches the data distribution.*

## 🛠️ Setup

```python
import numpy as np  # Import NumPy for vectors, tiny diffusion updates, and numerical checks.
import matplotlib.pyplot as plt  # Import Matplotlib for the score, path, and scale visualizations.
np.random.seed(0)  # Fix the global seed so all stochastic toy examples are reproducible.
plt.rcParams["figure.max_open_warning"] = 0  # Avoid open-figure warnings during full-notebook headless checks.

def cfg_mix(s_uncond, s_cond, w):  # Define classifier-free guidance score mixing.
    return np.asarray(s_uncond, dtype=float) + w * (np.asarray(s_cond, dtype=float) - np.asarray(s_uncond, dtype=float))  # Apply s_u + w(s_c-s_u).

def toy_step(x, score, step_size=0.25):  # Define one simplified denoising update.
    return np.asarray(x, dtype=float) + step_size * np.asarray(score, dtype=float)  # Move the sample along the chosen score.
```
▶ What you'll see: two small helpers are available: `cfg_mix` for score mixing and `toy_step` for simple denoising updates.

### Basic 1 — Compute the prompt direction

**Goal.** Subtract unconditional from conditional scores, because CFG amplifies exactly the part of the denoising prediction caused by the condition. We build it in 2 steps.

```python
s_uncond_b1 = np.array([-0.4])  # Store the unconditional scalar score from the lesson block.

```
▶ What you'll see: the conditional score is larger than the unconditional score.

```python
delta_b1 = s_cond_b1 - s_uncond_b1  # Compute the condition-only direction.
```

▶ What you'll see: the orange delta bar is `1.3`, the amount CFG will scale.

👀 Takeaway: CFG starts by identifying the condition-specific score difference.

### Basic 8 — Simulate condition dropout

**Goal.** Randomly hide some labels, because classifier-free training must teach the model a null-condition prediction. We build it in 2 steps.

```python
labels_b8 = np.array([1, 0, 1, 1, 0, 1])  # Toy condition labels.
rng_b8 = np.random.default_rng(8)  # Local reproducible generator.
keep_b8 = rng_b8.random(labels_b8.shape) > 0.33  # Decide which labels remain visible.
print("keep mask:", keep_b8.astype(int))  # Inspect conditional versus dropped examples.
```
▶ What you'll see: some entries are kept and some are dropped.

```python
sent_b8 = labels_b8 * keep_b8  # Dropped conditions become null labels.
print("sent to model:", sent_b8)  # Inspect the training conditioning signal.
assert sent_b8.shape == labels_b8.shape  # Verify dropout preserves batch shape.
plt.figure(figsize=(4, 3))  # Create count plot.

plt.title("Basic 8: condition dropout"); plt.ylabel("examples"); plt.show()  # Display.
```

### Advanced 5 — Build a tiny CFG sampler function

**Goal.** Wrap the logic into a reusable sampler, because real pipelines repeatedly compute unconditional and conditional scores inside a loop. We build it in 4 steps.

```python
def score_model_a5(x, condition):  # Define a tiny deterministic two-branch score model.
    base_target_a5 = np.array([0.0, 0.0])  # Generic data target.
    prompt_target_a5 = np.array([1.0, 1.5]) if condition else np.array([0.0, 0.0])  # Prompt target when condition is present.
    return base_target_a5 + prompt_target_a5 - x  # Score points from x toward the selected target.

x0_a5 = np.array([-0.8, 0.4])  # Starting sample.
print("start:", x0_a5)  # Inspect start.
```
▶ What you'll see: the sampler starts from a noisy 2-D point.

```python
def sample_cfg_a5(x_start, w, n_steps=8, step_size=0.2):  # Define a tiny CFG sampling loop.
    path_a5 = [np.asarray(x_start, dtype=float).copy()]  # Store trajectory.
    for _ in range(n_steps):  # Repeat denoising updates.
        x_now_a5 = path_a5[-1]  # Current sample.
        su_a5 = score_model_a5(x_now_a5, False)  # Unconditional score call.
        sc_a5 = score_model_a5(x_now_a5, True)  # Conditional score call.
        sg_a5 = cfg_mix(su_a5, sc_a5, w)  # CFG mixing.
        path_a5.append(toy_step(x_now_a5, sg_a5, step_size=step_size))  # Update sample.
    return np.array(path_a5)  # Return full path.

path_low_a5 = sample_cfg_a5(x0_a5, w=1.0)  # Conditional sampler.
path_high_a5 = sample_cfg_a5(x0_a5, w=3.0)  # Strong-guidance sampler.
print("end low/high:", np.round(path_low_a5[-1], 3), np.round(path_high_a5[-1], 3))  # Inspect endpoints.
```

```python
prompt_target_a5 = np.array([1.0, 1.5])  # Target associated with the condition.
prompt_projection_low_a5 = float(path_low_a5[-1] @ prompt_target_a5 / np.linalg.norm(prompt_target_a5))  # Projection along prompt direction.
prompt_projection_high_a5 = float(path_high_a5[-1] @ prompt_target_a5 / np.linalg.norm(prompt_target_a5))  # Projection for high guidance.
print("prompt-axis projection low/high:", round(prompt_projection_low_a5, 3), round(prompt_projection_high_a5, 3))  # Inspect prompt pressure.
assert prompt_projection_high_a5 > prompt_projection_low_a5  # Verify stronger guidance moves farther along the prompt axis.
```
