# 21.10 — Automated Theorem Proving

Automated theorem proving turns symbolic reasoning into proof search: represent facts and rules as logic, add the negation of a goal, and ask whether a mechanical sequence of sound steps derives contradiction. In this lesson, we build the core machinery from scratch — clauses, resolution, first-order unification, a given-clause loop, pruning tricks, proof DAGs, and the proof-system intuitions that explain why deriving the empty clause is meaningful.

Before the terse worked examples, we build automated theorem proving one idea at a time. Run each cell in order and read the printed intermediate values — every step is deliberately small, inspectable, and written in pure Python/NumPy so the proof search never hides behind a solver. ### 1. Proof by refutation: prove a goal by making its negation impossible

The core move in resolution proving is indirect. Instead of trying to construct the goal directly, we add the **negation of the goal** to the knowledge base. If the combined set collapses to contradiction, the negated goal could not coexist with the facts and rules, so the original goal follows. At the clause level, contradiction is represented by the **empty clause**: a disjunction with zero literals, meaning there is no remaining way to make the clause true.

```python
clauses_w = [frozenset(["P"]), frozenset(["~P", "Q"]), frozenset(["~Q"])]  # fact P, rule P→Q, negated goal ¬Q.
print("clauses:", [sorted(c) for c in clauses_w])  # inspect the refutation set.
print("empty clause means:", "no literal left to satisfy")  # contradiction target.
```
▶ What you'll see: the knowledge base plus `~Q` is encoded as three small clauses.

```python
def neg_lit_w(lit_w):  # flip propositional polarity.
    return lit_w[1:] if lit_w.startswith("~") else "~" + lit_w  # remove or add the negation mark.

def resolve_prop_w(c1_w, c2_w):  # all one-step propositional resolvents.
    out_w = []  # collect derived clauses.
    for lit_w in c1_w:  # choose a literal from the first parent.
        if neg_lit_w(lit_w) in c2_w:  # find the complementary literal in the second parent.
            out_w.append(frozenset((c1_w - {lit_w}) | (c2_w - {neg_lit_w(lit_w)})))  # cancel the pair.
    return out_w  # possibly empty if no complementary pair exists.

step1_w = resolve_prop_w(clauses_w[0], clauses_w[1])[0]  # P with ¬P∨Q gives Q.
step2_w = resolve_prop_w(step1_w, clauses_w[2])[0]  # Q with ¬Q gives empty.
print("after first resolution:", sorted(step1_w))  # inspect Q.
print("after second resolution:", sorted(step2_w), "size", len(step2_w))  # inspect contradiction.
assert step2_w == frozenset()  # deriving the empty clause proves Q by refutation.
```
▶ What you'll see: the proof trace derives `Q`, then derives `[]` with size 0.

```python
sizes_w = [len(c) for c in clauses_w] + [len(step1_w), len(step2_w)]  # clause sizes along the tiny trace.
plt.figure(figsize=(4.6, 3))  # compact trace plot.
plt.plot(range(len(sizes_w)), sizes_w, marker="o", color="purple")  # show collapse toward zero literals.
plt.xticks(range(len(sizes_w)), ["P", "~P∨Q", "~Q", "Q", "□"], rotation=20)  # label proof milestones.
plt.ylabel("number of literals")  # clause length is the vertical axis.
plt.title("1: refutation shrinks to the empty clause")  # title the plot.
plt.show()  # display the trace.
```
▶ What you'll see: the final point is at 0 literals; that zero-length clause is the contradiction marker.

*Why it's done this way:* proving by refutation turns theorem proving into a uniform failure search. The solver does not need a special rule for every goal shape; it only needs to show that the world containing the knowledge base and the negated goal has no model. Resolution is useful because each step preserves unsatisfiability: if the parents cannot both be satisfied without satisfying the resolvent, then reaching the empty resolvent is a checkable certificate that the original assumptions were inconsistent.

### 2. Propositional resolution: one repeatable rule over clauses

Resolution works on clauses, which are ORs of literals. Resolving `(P ∨ R)` with `(¬P ∨ S)` cancels the complementary pair `P` and `¬P`, then unions everything left, yielding `(R ∨ S)`. This is powerful because many logical rules can be rewritten into clauses, after which the prover repeats this one small operation.

```python
c_left_w = frozenset(["P", "R"])  # P ∨ R.
c_right_w = frozenset(["~P", "S"])  # ¬P ∨ S.
res_w = resolve_prop_w(c_left_w, c_right_w)[0]  # cancel P against ¬P.
print("parent 1:", sorted(c_left_w))  # inspect first parent.
print("parent 2:", sorted(c_right_w))  # inspect second parent.
print("resolvent:", sorted(res_w))  # inspect R ∨ S.
assert res_w == frozenset(["R", "S"])  # concrete resolution result.
```
▶ What you'll see: the complementary literals disappear and the side literals remain.

```python
pairs_w = [("P", "~P"), ("A", "B"), ("~R", "R")]  # candidate pairs to inspect.
flags_w = [int(neg_lit_w(a_w) == b_w) for a_w, b_w in pairs_w]  # 1 if complementary.
print("complementary flags:", flags_w)  # inspect which pairs can resolve.
plt.figure(figsize=(4.4, 3))  # compact diagnostic chart.
plt.bar([f"{a}/{b}" for a, b in pairs_w], flags_w, color=["seagreen" if f else "gray" for f in flags_w])  # show valid cancellations.
plt.ylim(0, 1.2)  # binary scale.
plt.title("2: resolution needs opposite polarity")  # title the plot.
plt.show()  # display the bars.
```
▶ What you'll see: only exact opposite-polarity pairs can be cancelled.

*Why it's done this way:* a clause is false only when all its literals are false. If one parent says “at least `P` or `R`” and the other says “at least not-`P` or `S`,” then whichever truth value `P` has, one of the side literals must carry the burden. The resolvent `(R ∨ S)` records exactly that unavoidable side condition, which is why the rule is sound.

### 3. First-order unification: make predicates match by solving substitutions

First-order logic adds variables and structured terms, so complementary literals do not need to be textually identical. `Human(?x)` can cancel with `¬Human(socrates)` after the substitution `?x = socrates`. The unifier is the smallest set of bindings that makes two expressions equal; resolution then applies the substitution before cancelling.

```python
def is_var_w(x_w):  # variables start with a question mark.
    return isinstance(x_w, str) and x_w.startswith("?")  # True for ?x, ?y, ...

def walk_w(x_w, subst_w):  # follow substitution links until stable.
    while is_var_w(x_w) and x_w in subst_w:  # chase ?x -> ?y -> term chains.
        x_w = subst_w[x_w]  # replace by the current binding.
    return x_w  # return the representative term.

def occurs_w(v_w, x_w, subst_w):  # prevent ?x = f(?x) cycles.
    x_w = walk_w(x_w, subst_w)  # inspect the current representative.
    if v_w == x_w:  # direct occurrence.
        return True  # cycle detected.
    if isinstance(x_w, tuple):  # structured term or predicate.
        return any(occurs_w(v_w, part_w, subst_w) for part_w in x_w[1:])  # scan arguments.
    return False  # constants do not contain variables.

def unify_w(a_w, b_w, subst_w=None):  # Robinson-style unification.
    subst_w = {} if subst_w is None else dict(subst_w)  # copy so callers stay unchanged.
    a_w, b_w = walk_w(a_w, subst_w), walk_w(b_w, subst_w)  # normalize both sides.
    if a_w == b_w:  # already equal.
        return subst_w  # no new binding.
    if is_var_w(a_w):  # bind left variable if safe.
        if occurs_w(a_w, b_w, subst_w):
            return None  # reject cyclic binding.
        subst_w[a_w] = b_w; return subst_w  # extend substitution.
    if is_var_w(b_w):  # bind right variable symmetrically.
        return unify_w(b_w, a_w, subst_w)  # reuse the left-variable case.
    if isinstance(a_w, tuple) and isinstance(b_w, tuple) and len(a_w) == len(b_w) and a_w[0] == b_w[0]:  # same functor/predicate.
        for x_w, y_w in zip(a_w[1:], b_w[1:]):  # unify arguments one by one.
            subst_w = unify_w(x_w, y_w, subst_w)  # extend substitution.
            if subst_w is None:  # any mismatch kills the whole unifier.
                return None  # failure.
        return subst_w  # all arguments matched.
    return None  # constants or functors conflict.

sigma_w = unify_w(("Human", "?x"), ("Human", "socrates"))  # match a variable predicate to a ground fact.
print("substitution:", sigma_w)  # inspect ?x -> socrates.
assert sigma_w == {"?x": "socrates"}  # concrete unifier.
```
▶ What you'll see: unification finds the binding that makes the two `Human` atoms identical.

```python
def subst_term_w(x_w, subst_w):  # apply a substitution recursively.
    x_w = walk_w(x_w, subst_w)  # replace variable by its bound representative.
    if isinstance(x_w, tuple):  # structured expression.
        return tuple([x_w[0]] + [subst_term_w(arg_w, subst_w) for arg_w in x_w[1:]])  # rebuild with substituted args.
    return x_w  # constants remain unchanged.

atom_w = ("Mortal", "?x")  # conclusion with a variable.
print("before:", atom_w)  # inspect symbolic conclusion.
print("after:", subst_term_w(atom_w, sigma_w))  # inspect grounded conclusion.
assert subst_term_w(atom_w, sigma_w) == ("Mortal", "socrates")  # substitution application.
```
▶ What you'll see: the same binding turns `Mortal(?x)` into `Mortal(socrates)`.

```python
def var_count_w(x_w):  # count variables remaining in a term or atom.
    if is_var_w(x_w):
        return 1
    if isinstance(x_w, tuple):
        return sum(var_count_w(part_w) for part_w in x_w[1:])
    return 0

terms_before_after_w = [atom_w, subst_term_w(atom_w, sigma_w)]  # compare symbolic and grounded forms.
plt.figure(figsize=(4.2, 3))  # compact substitution effect plot.
plt.bar(["before\nsubstitution", "after\nsubstitution"], [var_count_w(t_w) for t_w in terms_before_after_w], color=["gray", "seagreen"])  # variables disappear.
plt.title("3: unification grounds the atom")  # title the plot.
plt.ylabel("variables remaining")  # vertical quantity.
plt.show()  # display the grounding effect.
```
▶ What you'll see: applying the unifier reduces the remaining variable count from 1 to 0.

*Why it's done this way:* first-order resolution must know when two literals are the “same pattern” under variable names. Unification is the minimal agreement step: it delays commitment until needed, binds variables only as tightly as required, and rejects cyclic terms so substitutions remain finite and checkable.

### 4. First-order resolution: cancel complementary predicates after unification

A first-order literal has polarity plus an atom. To resolve, we need opposite polarity, the same predicate symbol, and a unifier for the arguments. After unifying, we remove the two complementary literals and apply the substitution to the remaining side literals.

```python
def Lit_w(sign_w, atom_w):  # tiny literal constructor.
    return (sign_w, atom_w)  # sign is True for positive, False for negated.

def lit_text_w(lit_w):  # readable literal formatting.
    sign_w, atom_w = lit_w  # unpack polarity and atom.
    args_w = ",".join(map(str, atom_w[1:]))  # format arguments.
    return ("" if sign_w else "¬") + f"{atom_w[0]}({args_w})"  # combine sign and atom.

def complementary_unifier_w(l1_w, l2_w):  # find a unifier for opposite-polarity atoms.
    if l1_w[0] == l2_w[0] or l1_w[1][0] != l2_w[1][0]:  # same sign or different predicate cannot cancel.
        return None  # no resolution pair.
    return unify_w(l1_w[1], l2_w[1])  # unify the atoms.

def apply_lit_w(lit_w, subst_w):  # substitute inside a literal.
    return (lit_w[0], subst_term_w(lit_w[1], subst_w))  # keep polarity, update atom.

def resolve_fol_w(c1_w, c2_w):  # one-step first-order resolvents.
    outs_w = []  # collect (resolvent, substitution, cancelled literals).
    for l1_w in c1_w:  # choose a literal from parent 1.
        for l2_w in c2_w:  # choose a literal from parent 2.
            sigma_w = complementary_unifier_w(l1_w, l2_w)  # can these cancel after unification?
            if sigma_w is not None:  # resolution is possible.
                rest_w = [apply_lit_w(l_w, sigma_w) for l_w in (c1_w | c2_w) if l_w not in {l1_w, l2_w}]  # side literals.
                outs_w.append((frozenset(rest_w), sigma_w, (l1_w, l2_w)))  # save proof data.
    return outs_w  # all resolvents.

rule_w = frozenset([Lit_w(False, ("Human", "?x")), Lit_w(True, ("Mortal", "?x"))])  # ¬Human(?x) ∨ Mortal(?x).
fact_w = frozenset([Lit_w(True, ("Human", "socrates"))])  # Human(socrates).
resolvent_w, sigma2_w, _ = resolve_fol_w(rule_w, fact_w)[0]  # derive Mortal(socrates).
print("sigma:", sigma2_w)  # inspect substitution.
print("resolvent:", [lit_text_w(l_w) for l_w in resolvent_w])  # inspect derived clause.
assert list(resolvent_w)[0] == Lit_w(True, ("Mortal", "socrates"))  # concrete first-order result.
```
▶ What you'll see: the universal rule and the ground fact derive `Mortal(socrates)`.

```python
goal_neg_w = frozenset([Lit_w(False, ("Mortal", "socrates"))])  # negated goal.
empty_w = resolve_fol_w(resolvent_w, goal_neg_w)[0][0]  # cancel Mortal(socrates) with ¬Mortal(socrates).
print("final resolvent:", [lit_text_w(l_w) for l_w in empty_w], "size", len(empty_w))  # inspect contradiction.
assert empty_w == frozenset()  # theorem proved.
```
▶ What you'll see: the first-order proof reaches the empty clause after applying unification.

```python
labels_w4 = ["rule", "fact", "Mortal", "¬Mortal", "□"]  # proof milestones.
sizes_w4 = [len(rule_w), len(fact_w), len(resolvent_w), len(goal_neg_w), len(empty_w)]  # clause sizes.
plt.figure(figsize=(4.8, 3))  # compact first-order proof trace.
plt.plot(sizes_w4, marker="o", color="teal")  # show resolution steps ending at contradiction.
plt.xticks(range(len(labels_w4)), labels_w4, rotation=20)  # label milestones.
plt.ylabel("literal count")  # clause-size axis.
plt.title("4: first-order resolution reaches □")  # title the plot.
plt.show()  # display the trace.
```
▶ What you'll see: the instantiated conclusion and its negation resolve to a zero-literal clause.

*Why it's done this way:* the resolution rule itself remains simple, but unification makes it schema-aware. Universal rules are not instantiated for every possible object up front; instead, the needed instance is created exactly when a complementary literal is found. That is what keeps first-order proof search symbolic rather than brute-force enumeration.

### 5. The given-clause loop: organize proof search so it can make progress

A prover needs a search strategy. The classic given-clause loop keeps two sets: **usable** clauses already selected for inference, and **support** clauses waiting to be selected. Each iteration picks one given clause from support, resolves it against usable clauses, adds genuinely new resolvents to support, then moves the given clause to usable. If any new resolvent is empty, the proof is found.

```python
class Node_w:  # tiny proof node for the walkthrough prover.
    def __init__(self, clause_w, parents_w=None, rule_w="input"):
        self.clause = clause_w  # a frozenset of literals.
        self.parents = parents_w or ()  # parent node ids.
        self.rule = rule_w  # input or resolution.

def clause_key_w(clause_w):  # canonical key for duplicate detection.
    return tuple(sorted(lit_text_w(l_w) for l_w in clause_w))  # readable deterministic tuple.

nodes_w = {0: Node_w(fact_w), 1: Node_w(rule_w), 2: Node_w(goal_neg_w)}  # inputs.
support_w = deque([0, 1, 2])  # clauses waiting to become given.
usable_w = []  # processed given clauses.
seen_w = {clause_key_w(n.clause) for n in nodes_w.values()}  # known clauses.
next_id_w = count(3)  # new node ids.
print("initial support size:", len(support_w), "usable size:", len(usable_w))  # inspect starting state.
```
▶ What you'll see: all input clauses start in support, and usable is initially empty.

```python
found_w = None  # store the empty-clause node id if found.
trace_sizes_w = []  # record support size over time.
while support_w and found_w is None:  # stop on proof or exhaustion.
    given_id_w = support_w.popleft()  # choose the next given clause.
    given_w = nodes_w[given_id_w].clause  # read its clause.
    for old_id_w in usable_w:  # resolve against already selected clauses.
        for new_clause_w, sigma_w, _ in resolve_fol_w(given_w, nodes_w[old_id_w].clause):  # generate resolvents.
            key_w = clause_key_w(new_clause_w)  # canonical duplicate key.
            if key_w not in seen_w:  # keep only new clauses.
                nid_w = next(next_id_w)  # allocate proof id.
                nodes_w[nid_w] = Node_w(new_clause_w, (given_id_w, old_id_w), "resolution")  # store proof node.
                seen_w.add(key_w); support_w.append(nid_w)  # enqueue for future inference.
                if len(new_clause_w) == 0:  # contradiction found.
                    found_w = nid_w  # save empty-clause node.
    usable_w.append(given_id_w)  # mark given as processed.
    trace_sizes_w.append((len(usable_w), len(support_w)))  # record loop state.
print("found empty node:", found_w)  # inspect proof result.
assert found_w is not None and nodes_w[found_w].clause == frozenset()  # theorem proved by the loop.
```
▶ What you'll see: the loop discovers a node whose clause has zero literals.

```python
usable_counts_w = [u_w for u_w, s_w in trace_sizes_w]  # processed count over iterations.
support_counts_w = [s_w for u_w, s_w in trace_sizes_w]  # waiting count over iterations.
plt.figure(figsize=(4.8, 3))  # compact search-state plot.
plt.plot(usable_counts_w, label="usable", marker="o")  # processed clauses.
plt.plot(support_counts_w, label="support", marker="s")  # waiting clauses.
plt.title("5: given-clause loop state")  # title the plot.
plt.xlabel("iteration")  # iteration axis.
plt.ylabel("clause count")  # count axis.
plt.legend()  # show labels.
plt.show()  # display the search trace.
```
▶ What you'll see: clauses move from support to usable while new resolvents are generated.

*Why it's done this way:* unrestricted pairwise resolution quickly repeats work. The given-clause loop creates discipline: every inference is made when one parent becomes “given,” and duplicate checking prevents the same clause from flooding the search. This does not make the problem easy, but it turns a chaotic closure computation into a controllable loop.

### 6. Subsumption and deletion: prune clauses that are weaker than ones you already have

A clause with fewer literals can be stronger than a clause with more literals. For example, `P` **subsumes** `P ∨ Q` because anything satisfying `P` already satisfies `P ∨ Q`; keeping the larger clause is usually redundant. Provers use deletion rules such as duplicate removal, tautology deletion, and subsumption to shrink the search space without losing possible refutations.

```python
def tautology_prop_w(clause_w):  # detect P ∨ ¬P.
    return any(neg_lit_w(l_w) in clause_w for l_w in clause_w)  # complementary pair inside one clause.

def subsumes_prop_w(small_w, large_w):  # propositional subset subsumption.
    return small_w.issubset(large_w)  # every model of small also satisfies large.

candidate_clauses_w = [frozenset(["P"]), frozenset(["P", "Q"]), frozenset(["R", "~R"]), frozenset(["Q"])]  # mixed clauses.
print("tautologies:", [tautology_prop_w(c_w) for c_w in candidate_clauses_w])  # inspect deletable tautology.
print("P subsumes P∨Q:", subsumes_prop_w(candidate_clauses_w[0], candidate_clauses_w[1]))  # inspect redundancy.
```
▶ What you'll see: `R∨¬R` is a tautology, and `P` makes `P∨Q` redundant.

```python
kept_w = []  # pruned clause set.
for c_w in candidate_clauses_w:  # scan in order.
    if tautology_prop_w(c_w):  # tautologies add no constraint.
        continue  # delete.
    if any(subsumes_prop_w(k_w, c_w) for k_w in kept_w):  # existing stronger clause covers it.
        continue  # delete.
    kept_w = [k_w for k_w in kept_w if not subsumes_prop_w(c_w, k_w)]  # remove old clauses made redundant by c.
    kept_w.append(c_w)  # keep the useful clause.
print("kept clauses:", [sorted(c_w) for c_w in kept_w])  # inspect pruned set.
assert frozenset(["P", "Q"]) not in kept_w and frozenset(["R", "~R"]) not in kept_w  # pruning worked.
```
▶ What you'll see: the redundant and tautological clauses disappear.

```python
removed_taut_w = sum(tautology_prop_w(c_w) for c_w in candidate_clauses_w)  # tautologies deleted.
removed_subsumed_w = len(candidate_clauses_w) - len(kept_w) - removed_taut_w  # remaining deletions are subsumed clauses.
plt.figure(figsize=(4.2, 3))  # compact pruning accounting chart.
plt.bar(["kept", "tautology\ndeleted", "subsumed\ndeleted"], [len(kept_w), removed_taut_w, removed_subsumed_w], color=["seagreen", "gray", "purple"])  # classify outcomes.
plt.title("6: where clauses went")  # title the plot.
plt.ylabel("clause count")  # count axis.
plt.show()  # display pruning breakdown.
```
▶ What you'll see: each input clause is accounted for as kept, tautological, or subsumed.

*Why it's done this way:* proof search is usually limited by the number of clauses, not by the cost of one inference. Deletion rules are safe when they remove clauses that cannot contribute anything stronger than what remains. Subsumption preserves refutational power because a smaller clause is harder to satisfy; if it is already available, the larger clause is unnecessary baggage.

### 7. Proof systems and guarantees: natural deduction, sequents, soundness, completeness

Resolution is not the only proof format. **Natural deduction** resembles human line-by-line reasoning with introduction and elimination rules. **Sequent calculus** rewrites judgments of the form assumptions ⟹ conclusions and exposes proof search structure. Resolution is more machine-oriented: normalize formulas to clauses, then search for a refutation. Soundness says every derived result is logically valid; completeness says that if a clause set is unsatisfiable, resolution can eventually derive the empty clause under a fair search strategy.

```python
systems_w = ["natural\ndeduction", "sequent\ncalculus", "resolution"]  # three proof styles.

print("systems:", systems_w)  # inspect labels.

```
▶ What you'll see: the proof styles emphasize different tradeoffs between human readability and automation.

▶ What you'll see: resolution is drawn as search-friendly, while natural deduction is drawn as more human-shaped.

*Why it's done this way:* soundness is the safety contract: every proof step must be locally checkable, so the final theorem is trustworthy. Completeness is the search contract: if contradiction is really there, a fair resolution strategy is not missing a needed inference forever. Natural deduction and sequent calculus help explain proof structure, but resolution’s uniform clause rule is why it became a practical automated-theorem-proving workhorse.

### ✍️ Toy 5 · Given-clause search moves support into usable

resolving it with usable clauses, and queuing only new results.


### ✍️ Toy 6 · Tautology and subsumption deletion prune clauses

A tautology is always true, and a larger clause is redundant when a smaller kept clause already
subsumes it.

```python
import numpy as np
```

## 🛠️ Setup

```python
import numpy as np  # load NumPy for arrays, traces, and reproducible synthetic examples.
import matplotlib.pyplot as plt  # load Matplotlib for proof traces, clause counts, and proof DAG visualizations.
from collections import deque  # use a queue for breadth-first and given-clause loops.
from itertools import count  # use deterministic counters for proof node ids.
np.random.seed(0)  # make random examples reproducible.

def prop_neg(lit):  # flip a propositional literal represented as a string.
    return lit[1:] if lit.startswith("~") else "~" + lit  # remove or add the negation prefix.

def prop_resolve(c1, c2):  # return all propositional resolvents of two clauses.
    outs = []  # collect derived clauses.
    for lit in c1:  # choose a literal from c1.
        if prop_neg(lit) in c2:  # check whether c2 has the complementary literal.
            outs.append(frozenset((c1 - {lit}) | (c2 - {prop_neg(lit)})))  # cancel the pair and union the sides.
    return outs  # possibly empty.

def is_var(x):  # identify first-order variables.
    return isinstance(x, str) and x.startswith("?")  # variables are strings like ?x.

def walk(x, subst):  # follow substitution bindings until fixed.
    while is_var(x) and x in subst:  # chase variable links.
        x = subst[x]  # replace with current binding.
    return x  # final representative.

def occurs(v, x, subst):  # occurs check for finite substitutions.
    x = walk(x, subst)  # normalize first.
    if v == x:  # direct cycle.
        return True  # reject.
    if isinstance(x, tuple):  # structured expression.
        return any(occurs(v, a, subst) for a in x[1:])  # scan arguments.
    return False  # constants are safe.

def unify(a, b, subst=None):  # unify two first-order terms or atoms.
    subst = {} if subst is None else dict(subst)  # copy input substitution.
    a, b = walk(a, subst), walk(b, subst)  # normalize both sides.
    if a == b:  # already equal.
        return subst  # success with no change.
    if is_var(a):  # bind variable a.
        if occurs(a, b, subst):  # avoid ?x = f(?x).
            return None  # failure.
        subst[a] = b; return subst  # extend substitution.
    if is_var(b):  # bind variable b symmetrically.
        return unify(b, a, subst)  # reuse variable case.
    if isinstance(a, tuple) and isinstance(b, tuple) and len(a) == len(b) and a[0] == b[0]:  # same functor or predicate.
        for x, y in zip(a[1:], b[1:]):  # unify all arguments.
            subst = unify(x, y, subst)  # extend substitution.
            if subst is None:  # mismatch.
                return None  # failure.
        return subst  # success.
    return None  # incompatible constants or functors.

def subst_term(x, subst):  # apply a substitution recursively.
    x = walk(x, subst)  # replace variables.
    if isinstance(x, tuple):  # structured expression.
        return tuple([x[0]] + [subst_term(a, subst) for a in x[1:]])  # rebuild expression.
    return x  # constant.

def Lit(sign, atom):  # construct a first-order literal.
    return (bool(sign), atom)  # True means positive, False means negated.

def lit_text(lit):  # render a literal for printing and keys.
    sign, atom = lit  # unpack literal.
    args = ",".join(map(str, atom[1:]))  # render arguments.
    return ("" if sign else "¬") + f"{atom[0]}({args})"  # include polarity.

def clause_text(clause):  # render a whole clause.
    return "□" if len(clause) == 0 else " ∨ ".join(sorted(lit_text(l) for l in clause))  # empty or disjunction.

def apply_lit(lit, subst):  # substitute inside a literal.
    return (lit[0], subst_term(lit[1], subst))  # polarity unchanged.

def fol_resolve(c1, c2):  # return first-order resolvents with metadata.
    outs = []  # collect triples.
    for l1 in c1:  # first parent literal.
        for l2 in c2:  # second parent literal.
            if l1[0] == l2[0] or l1[1][0] != l2[1][0]:  # need opposite signs and same predicate.
                continue  # cannot resolve.
            sigma = unify(l1[1], l2[1])  # try to unify atoms.
            if sigma is None:  # no common instance.
                continue  # skip.
            rest = [apply_lit(l, sigma) for l in (c1 | c2) if l not in {l1, l2}]  # apply substitution to side literals.
            outs.append((frozenset(rest), sigma, (l1, l2)))  # save resolvent, substitution, and cancelled pair.
    return outs  # list of possible resolvents.

def tautology_prop(clause):  # detect propositional P ∨ ¬P.
    return any(prop_neg(l) in clause for l in clause)  # true if complementary pair exists.

def subsumes_prop(a, b):  # propositional subsumption.
    return a.issubset(b)  # smaller clause is stronger.

def draw_dag(edges, labels, title):  # draw a small proof DAG without networkx.
    nodes = sorted(labels)  # deterministic node order.
    levels = {}  # y-levels by distance from inputs.
    for n in nodes:  # initialize.
        parents = [u for u, v in edges if v == n]  # incoming parents.
        levels[n] = 0 if not parents else 1 + max(levels.get(p, 0) for p in parents)  # simple topological level.
    xs = {n: i for i, n in enumerate(nodes)}  # x positions.
    ys = {n: -levels[n] for n in nodes}  # y positions.
    plt.figure(figsize=(6, 3.5))  # create compact DAG figure.
    for u, v in edges:  # draw arrows.
        plt.annotate("", xy=(xs[v], ys[v]), xytext=(xs[u], ys[u]), arrowprops=dict(arrowstyle="->", lw=1))  # parent to child.
    for n in nodes:  # draw node labels.
        plt.scatter([xs[n]], [ys[n]], s=500, color="white", edgecolor="black", zorder=3)  # node circle.
        plt.text(xs[n], ys[n], labels[n], ha="center", va="center", fontsize=8, zorder=4)  # node text.
    plt.axis("off")  # hide axes.
    plt.title(title)  # title the DAG.
    plt.show()  # display.
```

### Advanced 2 — Compare breadth-first and given-clause search effort

**Goal.** Count generated clauses under two simple strategies, because proof search behavior depends strongly on organization even when the inference rule is the same. We build it in 4 steps.

```python
                generated_naive_a2 += 1  # count candidate.
                if r_a2 not in known_a2:  # new clause.
                    known_a2.append(r_a2); changed_a2 = True  # add.
    if frozenset() in known_a2 or not changed_a2:  # stop if done.
```

### Advanced 4 — Explore soundness and completeness with a finite truth table

**Goal.** Check a propositional resolution step against all truth assignments, because soundness means the resolvent is true whenever both parents are true. We build it in 3 steps.

```python
parent1_a4 = frozenset(["P", "R"])  # P ∨ R.
parent2_a4 = frozenset(["~P", "S"])  # ¬P ∨ S.
resolvent_a4 = prop_resolve(parent1_a4, parent2_a4)[0]  # R ∨ S.
vars_a4 = ["P", "R", "S"]  # variables in the example.
print("resolvent:", sorted(resolvent_a4))  # inspect derived clause.
```
▶ What you'll see: resolution derives `R∨S` from the two parents.

```python
def eval_lit_a4(lit_a4, env_a4):  # evaluate one literal under a truth assignment.
    return (not env_a4[lit_a4[1:]]) if lit_a4.startswith("~") else env_a4[lit_a4]  # handle negation.

def eval_clause_a4(clause_a4, env_a4):  # evaluate a disjunction.
    return any(eval_lit_a4(lit_a4, env_a4) for lit_a4 in clause_a4)  # OR over literals.

violations_a4 = []  # assignments where parents true but resolvent false.
for bits_a4 in range(8):  # all assignments for three variables.
    env_a4 = {v_a4: bool((bits_a4 >> k_a4) & 1) for k_a4, v_a4 in enumerate(vars_a4)}  # build assignment.
    if eval_clause_a4(parent1_a4, env_a4) and eval_clause_a4(parent2_a4, env_a4) and not eval_clause_a4(resolvent_a4, env_a4):  # soundness violation.
        violations_a4.append(env_a4)  # store bad assignment.
```

### Advanced 5 — Prove a two-step ancestor theorem with first-order resolution

**Goal.** Use multiple first-order rules and a negated goal, because real theorem proving chains several unification-driven inferences. We build it in 4 steps.
