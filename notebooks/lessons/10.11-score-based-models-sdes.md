# 10.11 — Score-Based Models & SDEs

Score-based models learn a vector field that points noisy samples back toward higher data density, then use small stochastic steps to turn noise into samples. In this lesson, we build the score function, denoising score matching, Langevin sampling, and the SDE view from scratch with NumPy only, using tiny distributions where every formula can be audited by hand.

Before the terse worked examples, we build score-based modeling one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including the score function and denoising target, is shown from first principles. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, random numbers, and small linear algebra checks.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for noise, toy data, and sampling paths.
```

### 1. The score is a direction, not a probability

A density tells us how much probability mass lives near a point. A **score** tells us which way the log-density increases:

$$s(x)=\nabla_x \log p(x).$$

In one dimension this is just the slope of `log p(x)`. If the score is positive, moving right increases density; if it is negative, moving left increases density. That makes the score the local denoising arrow: it points back toward typical data.

```python
x_w = np.linspace(-3, 3, 301)  # inspect a one-dimensional coordinate grid.
sigma_w = 1.0  # standard deviation of a standard Gaussian.
density_w = np.exp(-0.5 * (x_w / sigma_w) ** 2) / np.sqrt(2 * np.pi * sigma_w ** 2)  # exact N(0,1) density.
log_density_w = np.log(density_w)  # log density is easier to differentiate and stable up to constants.
score_w = -x_w / sigma_w ** 2  # exact score for N(0, sigma^2).
print("score at x=-1:", score_w[np.argmin(np.abs(x_w + 1))])
print("score at x= 1:", score_w[np.argmin(np.abs(x_w - 1))])
assert score_w[np.argmin(np.abs(x_w + 1))] == 1.0
assert score_w[np.argmin(np.abs(x_w - 1))] == -1.0
```
▶ What you'll see: the score is positive at −1 and negative at +1, so both arrows point inward toward the Gaussian peak.

```python
plt.figure(figsize=(5, 3))
plt.plot(x_w, density_w, label="density p(x)", color="steelblue")
plt.twinx()
plt.plot(x_w, score_w, label="score ∇log p(x)", color="crimson")
plt.axhline(0, color="black", linewidth=0.8)
plt.title("1: density height versus score direction")
plt.show()
```
▶ What you'll see: the density curve is highest at 0, while the score line crosses 0 there and points toward it from both sides.

*Why it's done this way:* differentiating `log p` turns a density into a vector field. The log removes irrelevant normalization constants, and the gradient keeps only the local direction of increasing probability; generation can follow directions even when it never knows the normalized density value.

### 2. Gaussian scores are exactly computable

For a Gaussian $p(x)=\mathcal N(\mu,\sigma^2)$,

$$\log p(x)=C-\frac{(x-\mu)^2}{2\sigma^2},\qquad \nabla_x\log p(x)=-\frac{x-\mu}{\sigma^2}.$$

The numerator says how far the point is from the center; the denominator says narrow distributions pull back harder because the same displacement is more surprising.

```python
mu_w = 2.0  # Gaussian center.
sigma_w = 0.5  # narrow Gaussian, so scores have large magnitude.
points_w = np.array([1.0, 2.0, 3.0])  # left of mean, at mean, right of mean.
scores_exact_w = -(points_w - mu_w) / sigma_w ** 2  # closed-form Gaussian score.
print("points:", points_w)
print("exact scores:", scores_exact_w)
assert np.allclose(scores_exact_w, [4.0, -0.0, -4.0])
```
▶ What you'll see: a point one unit left of the mean has score +4, while one unit right has score −4.

```python
x2_w = np.linspace(0, 4, 200)
density2_w = np.exp(-0.5 * ((x2_w - mu_w) / sigma_w) ** 2) / np.sqrt(2 * np.pi * sigma_w ** 2)
score2_w = -(x2_w - mu_w) / sigma_w ** 2
plt.figure(figsize=(5, 3))
plt.plot(x2_w, density2_w, color="steelblue", label="N(2, 0.5²)")
plt.quiver(points_w, np.zeros_like(points_w), scores_exact_w, np.zeros_like(points_w), angles="xy", scale_units="xy", scale=8, color="crimson")
plt.title("2: exact Gaussian score arrows")
plt.xlabel("x")
plt.legend()
plt.show()
```
▶ What you'll see: arrows on both tails point back toward the mean, and the center has zero score.

*Why it's done this way:* the Gaussian example is the calibration case for score models. If the model cannot learn `-(x-μ)/σ²` for a blurred Gaussian, then it cannot be trusted to learn harder multimodal score fields.

### 3. Adding noise creates a smoother score field

Real data may live on thin manifolds or be a mixture of clusters. At exactly zero noise, the score can be sharp or undefined between clusters. Score models therefore train on noisy data $x_t=x_0+\sigma_t\epsilon$, so every noise level has a smooth density $p_t$ and a learnable score.

```python
rng_w = np.random.default_rng(0)
clean_w = rng_w.choice([-2.0, 2.0], size=400)  # two-point toy data distribution.
noise_small_w = clean_w + 0.25 * rng_w.normal(size=clean_w.size)  # low-noise observations.
noise_large_w = clean_w + 1.00 * rng_w.normal(size=clean_w.size)  # high-noise observations.
print("clean mean:", round(float(clean_w.mean()), 3))
print("small-noise std:", round(float(noise_small_w.std()), 3))
print("large-noise std:", round(float(noise_large_w.std()), 3))
assert clean_w.shape == noise_small_w.shape == noise_large_w.shape
```
▶ What you'll see: the high-noise sample has a larger standard deviation and more overlap between the two clusters.

```python
plt.figure(figsize=(6, 3))
plt.hist(noise_small_w, bins=30, alpha=0.6, density=True, label="σ=0.25")
plt.hist(noise_large_w, bins=30, alpha=0.6, density=True, label="σ=1.00")
plt.title("3: noising smooths a two-cluster distribution")
plt.xlabel("x")
plt.ylabel("density estimate")
plt.legend()
plt.show()
```
▶ What you'll see: low noise leaves two sharp modes; high noise blurs them into a smoother bridge.

*Why it's done this way:* training across noise levels gives a path from easy, smooth, high-noise densities down to detailed data densities. Without noise, the model would see almost no training signal away from the data points it must eventually denoise from.

### 4. Denoising score matching gives a supervised target

The miracle is that we can train scores without knowing the data density. If we corrupt a clean point by $x_t=x_0+\sigma\epsilon$, then the conditional density $p(x_t\mid x_0)$ is Gaussian, so its score is known:

$$\nabla_{x_t}\log p(x_t\mid x_0)=-\frac{x_t-x_0}{\sigma^2}=-\frac{\epsilon}{\sigma}.$$

Denoising score matching trains the model to predict that target from noisy examples. Averaged over many clean points, the conditional target estimates the score of the noisy marginal distribution.

```python
x0_w = np.array([-2.0, 2.0, -2.0, 2.0])  # four clean toy samples.
eps_w = np.array([0.5, -1.0, 1.5, -0.5])  # chosen noise for hand-auditable arithmetic.
sigma_dsm_w = 0.5  # noise scale.
xt_w = x0_w + sigma_dsm_w * eps_w  # corrupt clean data.
target_score_w = -(xt_w - x0_w) / sigma_dsm_w ** 2  # exact conditional score.
print("x_t:", xt_w)
print("DSM targets:", target_score_w)
assert np.allclose(target_score_w, [-1.0, 2.0, -3.0, 1.0])
```
▶ What you'll see: the target is exactly `-epsilon / sigma`, so larger corruption gets a larger restoring arrow.

```python
model_score_guess_w = -0.8 * xt_w  # a deliberately simple linear score model guess.
loss_w = np.mean((model_score_guess_w - target_score_w) ** 2)  # score matching MSE.
print("model guesses:", np.round(model_score_guess_w, 3))
print("DSM loss:", round(float(loss_w), 3))
assert round(float(loss_w), 3) == 9.44
```
▶ What you'll see: the loss compares predicted arrows to known denoising arrows, not predicted pixels to clean pixels.

*Why it's done this way:* direct maximum likelihood would require the normalized data density. DSM avoids that by manufacturing noisy pairs where the Gaussian corruption score is known exactly, turning density-gradient learning into ordinary squared-error regression on vector targets.

### 5. A tiny score model can be fit with NumPy gradients

To keep the model inspectable, use a linear score $s_\theta(x,\sigma)=a_\sigma x+b_\sigma$ at each noise level. This is not a neural network, but it has the same training principle: minimize squared error to DSM targets. For a batch, the gradients are

$$\frac{\partial L}{\partial a}=\frac{2}{n}\sum_i (a x_i+b-y_i)x_i,\qquad \frac{\partial L}{\partial b}=\frac{2}{n}\sum_i (a x_i+b-y_i).$$

```python
rng_w = np.random.default_rng(1)
x0_fit_w = rng_w.choice([-2.0, 2.0], size=600)
sigma_fit_w = 0.7
eps_fit_w = rng_w.normal(size=x0_fit_w.size)
xt_fit_w = x0_fit_w + sigma_fit_w * eps_fit_w
y_fit_w = -(xt_fit_w - x0_fit_w) / sigma_fit_w ** 2
print("training pairs:", xt_fit_w.shape[0])
print("target mean:", round(float(y_fit_w.mean()), 3))
assert xt_fit_w.shape[0] == 600
```
▶ What you'll see: every noisy scalar has a supervised score target from its known corruption noise.

```python
a_w, b_w = 0.0, 0.0
losses_fit_w = []
for step_w in range(300):
    pred_w = a_w * xt_fit_w + b_w
    err_w = pred_w - y_fit_w
    grad_a_w = 2 * np.mean(err_w * xt_fit_w)
    grad_b_w = 2 * np.mean(err_w)
    a_w -= 0.02 * grad_a_w
    b_w -= 0.02 * grad_b_w
    if step_w % 10 == 0:
        losses_fit_w.append(float(np.mean(err_w ** 2)))
print("learned a,b:", round(a_w, 3), round(b_w, 3))
print("loss start -> end:", round(losses_fit_w[0], 3), "->", round(losses_fit_w[-1], 3))
assert losses_fit_w[-1] < losses_fit_w[0]
```
▶ What you'll see: the DSM loss falls, and the learned linear score slope becomes negative because tails should be pushed inward.

```python
plt.figure(figsize=(5, 3))
plt.plot(np.arange(len(losses_fit_w)) * 10, losses_fit_w, color="purple")
plt.title("5: denoising score matching loss decreases")
plt.xlabel("gradient step")
plt.ylabel("MSE to score targets")
plt.show()
```
▶ What you'll see: the loss curve drops quickly and then flattens as the simple linear model reaches its best fit.

*Why it's done this way:* even a tiny parametric score model learns by matching arrows. The gradients are ordinary least-squares gradients because DSM has converted the generative problem into regression on a vector field.

### 6. Langevin sampling follows the learned score plus noise

Once we have a score field, we can sample with Langevin dynamics:

$$x_{k+1}=x_k+\eta s_\theta(x_k)+\sqrt{2\eta}\,z_k,\qquad z_k\sim\mathcal N(0,1).$$

The score term drifts toward high density; the noise term prevents all samples from collapsing to the mode and makes the chain explore the distribution.

```python
rng_w = np.random.default_rng(2)
def mixture_score_w(x, sigma=0.5):
    means = np.array([-2.0, 2.0])
    weights = np.exp(-0.5 * ((x[:, None] - means[None, :]) / sigma) ** 2)
    component_scores = -(x[:, None] - means[None, :]) / sigma ** 2
    return np.sum(weights * component_scores, axis=1) / np.sum(weights, axis=1)

x_langevin_w = rng_w.normal(0, 3, size=500)
print("initial mean/std:", round(float(x_langevin_w.mean()), 3), round(float(x_langevin_w.std()), 3))
assert x_langevin_w.shape == (500,)
```
▶ What you'll see: samples start as broad Gaussian noise, not as two clean data clusters.

```python
eta_w = 0.02
for step_w in range(250):
    score_step_w = mixture_score_w(x_langevin_w, sigma=0.5)
    x_langevin_w = x_langevin_w + eta_w * score_step_w + np.sqrt(2 * eta_w) * rng_w.normal(size=x_langevin_w.size)
print("final mean/std:", round(float(x_langevin_w.mean()), 3), round(float(x_langevin_w.std()), 3))
print("fraction near modes:", round(float(np.mean(np.abs(np.abs(x_langevin_w) - 2) < 0.75)), 3))
assert np.mean(np.abs(np.abs(x_langevin_w) - 2) < 0.75) > 0.4
```
▶ What you'll see: many samples migrate toward neighborhoods around −2 and +2, the high-density modes.

```python
plt.figure(figsize=(6, 3))
plt.hist(x_langevin_w, bins=35, density=True, color="seagreen", alpha=0.75)
plt.axvline(-2, color="black", linestyle="--")
plt.axvline(2, color="black", linestyle="--")
plt.title("6: Langevin samples gather near score-field modes")
plt.xlabel("x")
plt.ylabel("sample density")
plt.show()
```
▶ What you'll see: the histogram becomes bimodal, with peaks near the two dashed data modes.

*Why it's done this way:* the deterministic score alone would climb density and stop; the stochastic term keeps the process a sampler rather than an optimizer. The step size must be small because this is a discretized stochastic differential equation.

### 7. The SDE view connects noise schedules to reverse generation

A forward SDE gradually adds noise, for example $dx=\sqrt{\beta(t)}\,dw$. The reverse-time SDE removes noise using the score:

$$dx=-\beta(t)s_\theta(x,t)\,dt+\sqrt{\beta(t)}\,d\bar w,$$

when stepping backward in time. In discrete code, this becomes many small denoising steps from large noise to small noise. The score must be conditioned on the noise level because the correct arrow changes with $t$.

```python
rng_w = np.random.default_rng(3)
x_reverse_w = rng_w.normal(0, 2.5, size=400)
sigmas_w = np.linspace(1.5, 0.35, 8)  # high noise down to low noise.
print("schedule:", np.round(sigmas_w, 2))
print("start std:", round(float(x_reverse_w.std()), 3))
assert len(sigmas_w) == 8
```
▶ What you'll see: sampling begins at a high noise level and plans to step toward lower noise levels.

```python
std_path_w = []
for sigma_w in sigmas_w:
    for inner_w in range(40):
        sc_w = mixture_score_w(x_reverse_w, sigma=float(sigma_w))
        step_w = 0.01 * sigma_w ** 2
        x_reverse_w = x_reverse_w + step_w * sc_w + np.sqrt(2 * step_w) * rng_w.normal(size=x_reverse_w.size)
    std_path_w.append(float(x_reverse_w.std()))
print("std path:", np.round(std_path_w, 3))
assert len(std_path_w) == len(sigmas_w)
```
▶ What you'll see: the sample cloud changes gradually rather than jumping directly from noise to data.

```python
plt.figure(figsize=(5, 3))
plt.plot(sigmas_w, std_path_w, marker="o", color="darkorange")
plt.gca().invert_xaxis()
plt.title("7: annealed reverse-SDE-style sampling")
plt.xlabel("noise level σ, high → low")
plt.ylabel("sample standard deviation")
plt.show()
```
▶ What you'll see: the diagnostic changes smoothly along the noise schedule, illustrating why diffusion samplers use many small steps.

*Why it's done this way:* the SDE formulation says generation is not one denoise operation; it is a path through related noisy distributions. Conditioning the score on noise level lets the model know whether to make broad global corrections or fine local corrections.

### Basic 1 — Compute a Gaussian score

**Goal.** Evaluate the closed-form score of a one-dimensional Gaussian, because this is the simplest density-gradient field. We build it in 2 steps.

```python
mu_b1 = 0.0 # set the Gaussian center.
sigma_b1 = 0.5 # set a narrow standard deviation so score magnitudes are easy to see.
x_b1 = np.array([-1.0, 0.0, 1.0]) # choose left tail, mode, and right tail points.
print("x values:", x_b1) # inspect the audit points.
```
▶ What you'll see: the three points sit left of the mode, at the mode, and right of the mode.

```python
score_b1 = -(x_b1 - mu_b1) / sigma_b1 ** 2 # compute ∇ log N(mu, sigma²).
print("scores:", score_b1) # inspect the restoring directions.
assert np.allclose(score_b1, [4.0, -0.0, -4.0]) # verify the concrete lesson numbers.
plt.figure(figsize=(4, 3)) # create a compact score plot.
plt.bar(["x=-1", "x=0", "x=1"], score_b1, color="teal") # show the signed score at each point.
plt.axhline(0, color="black", linewidth=0.8) # mark zero score at the density peak.
plt.title("Basic 1: Gaussian score") # title the figure.
plt.ylabel("∇ log p(x)") # label the score axis.
plt.show() # display the bars.
```
▶ What you'll see: the two tail scores point back toward zero, while the center has no restoring direction.

👀 Takeaway: the score is a signed direction toward higher density, not a probability value.

### Basic 3 — Estimate a score by finite differences

**Goal.** Approximate a score numerically, because in harder distributions the gradient is the local slope of log-density. We build it in 2 steps.

```python
x0_b3 = 1.0 # choose a point where the standard Gaussian score should be -1.
h_b3 = 1e-3 # choose a tiny finite-difference step.
def logp_standard_b3(x):
    return -0.5 * x ** 2 - 0.5 * np.log(2 * np.pi)
print("log p(x+h):", round(float(logp_standard_b3(x0_b3 + h_b3)), 6)) # inspect one side of the difference.
```
▶ What you'll see: the log-density changes slightly when x moves by a tiny amount.

```python
score_fd_b3 = (logp_standard_b3(x0_b3 + h_b3) - logp_standard_b3(x0_b3 - h_b3)) / (2 * h_b3) # central finite difference.
score_exact_b3 = -x0_b3 # exact standard Gaussian score.
print("finite-difference score:", round(float(score_fd_b3), 6)) # inspect the numerical slope.
print("exact score:", score_exact_b3) # inspect the analytic answer.
assert abs(score_fd_b3 - score_exact_b3) < 1e-6 # verify the approximation.
plt.figure(figsize=(4, 3)) # create a small comparison chart.
plt.bar(["finite diff", "exact"], [score_fd_b3, score_exact_b3], color=["orange", "teal"]) # compare scores.
plt.title("Basic 3: numerical score check") # title the plot.
plt.show() # display the chart.
```
▶ What you'll see: the finite-difference score matches the exact value −1.

👀 Takeaway: a score is just the local derivative of log-density.

### Basic 7 — Take one linear score gradient step

**Goal.** Update a tiny linear score model once, because even neural score models use the same regression logic. We build it in 3 steps.

```python
x_b7 = np.array([-1.0, 0.0, 1.0]) # define tiny noisy inputs.
y_b7 = np.array([1.0, 0.0, -1.0]) # define ideal inward scores for N(0,1).
a_b7 = 0.0 # initialize slope of s(x)=a*x.
print("initial slope:", a_b7) # inspect the starting model.
```
▶ What you'll see: the initial model predicts zero score everywhere.

```python
pred_b7 = a_b7 * x_b7 # compute current score predictions.
err_b7 = pred_b7 - y_b7 # compute regression errors.
grad_a_b7 = 2 * np.mean(err_b7 * x_b7) # derivative of mean squared error with respect to slope.
print("gradient:", grad_a_b7) # inspect the slope direction.
```

```python
xrev_a3 = rng_a3.normal(0, forward_stds_a3[-1], size=1000) # initialize reverse process from high noise.
```

**Goal.** Build a two-dimensional score field and run Langevin sampling, because image score models learn high-dimensional vector fields. We build it in 4 steps.

### Advanced 5 — Compare one-step denoising with iterative sampling

**Goal.** Show that a single denoising jump is not the same as a sampler, because generation needs many small stochastic corrections. We build it in 4 steps.

```python
rng_a5 = np.random.default_rng(25) # create reproducible randomness.
x_start_a5 = rng_a5.normal(0, 3, size=600) # initialize broad noise.
def mix_score_a5(x, sigma):
    means = np.array([-2.0, 2.0])
    w = np.exp(-0.5 * ((x[:, None] - means[None, :]) / sigma) ** 2)
    cs = -(x[:, None] - means[None, :]) / sigma ** 2
    return np.sum(w * cs, axis=1) / np.sum(w, axis=1)
print("start std:", round(float(x_start_a5.std()), 3)) # inspect initial noise.
```
▶ What you'll see: both methods start from the same noisy distribution.

```python

print("one-step std:", round(float(one_step_a5.std()), 3)) # inspect the single jump result.
```
▶ What you'll see: one big score move changes the cloud abruptly and can over-concentrate or distort samples.

