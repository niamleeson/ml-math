# 2.14 — Bayesian Optimization

Bayesian optimization chooses the next expensive experiment by maintaining a probabilistic surrogate of the unknown objective, then sampling where high predicted value and high uncertainty make the observation most useful.

## 📖 Concept walkthrough — build each idea from scratch

Before the worked examples, we build Bayesian optimization one idea at a time. Run each cell in order and inspect the printed arrays, shapes, and plots. The walkthrough uses only NumPy and Matplotlib, and all walkthrough variables end in `_w` so they do not collide with the examples.

### 1. Expensive black-box search needs a budget-aware objective

Bayesian optimization starts with a black-box function: we can ask for `f(x)`, but we do not get gradients and each call is treated as costly. The toy objective below is cheap to evaluate, but we pretend each point is an expensive experiment so the algorithm must learn from a small table of observations.

```python
def objective_w(x_w):
    x_w = np.asarray(x_w, dtype=float)
    return np.sin(3 * x_w) + 0.35 * np.cos(7 * x_w) - 0.08 * (x_w - 1.0) ** 2

grid_w = np.linspace(0, 2, 301)
y_grid_w = objective_w(grid_w)
print("grid shape:", grid_w.shape)
print("true best x,y:", round(float(grid_w[np.argmax(y_grid_w)]), 3), round(float(np.max(y_grid_w)), 3))
```
▶ What you'll see: a one-dimensional landscape with a best value near the right side, but the optimizer will not be allowed to inspect all 301 values.

```python
X_obs_w = np.array([0.10, 0.75, 1.60])
y_obs_w = objective_w(X_obs_w)
print("observed x:", X_obs_w)
print("observed y:", np.round(y_obs_w, 3))
assert X_obs_w.shape == y_obs_w.shape == (3,)
```
▶ What you'll see: only three experiments are known, which is far too little for a reliable greedy decision.

### 2. RBF kernels encode smoothness as similarity

The surrogate needs a way to say nearby inputs should have related function values. An RBF kernel does exactly that: $k(x,x')=\exp(-\frac{(x-x')^2}{2\ell^2})$. The length scale $\ell$ is the smoothness assumption: small $\ell$ says values change quickly; large $\ell$ says distant points remain correlated.

```python
def rbf_kernel_w(a_w, b_w, length_w=0.35, scale_w=1.0):
    a_w = np.asarray(a_w, dtype=float)[:, None]
    b_w = np.asarray(b_w, dtype=float)[None, :]
    sqdist_w = (a_w - b_w) ** 2
    return scale_w ** 2 * np.exp(-0.5 * sqdist_w / length_w ** 2)

K_obs_w = rbf_kernel_w(X_obs_w, X_obs_w, length_w=0.35)
print("kernel matrix shape:", K_obs_w.shape)
print(np.round(K_obs_w, 3))
assert np.allclose(np.diag(K_obs_w), 1.0)
```
▶ What you'll see: diagonal entries are 1 because every point is perfectly similar to itself; off-diagonal entries shrink with distance.

```python
lengths_w = np.array([0.15, 0.35, 0.80])
probe_w = np.array([0.75])
for ell_w in lengths_w:
    sims_w = rbf_kernel_w(probe_w, grid_w, length_w=ell_w).ravel()
    print("ell", ell_w, "similarity at x=0.10:", round(float(sims_w[np.argmin(np.abs(grid_w - 0.10))]), 3))
```
▶ What you'll see: the same distant point becomes more similar as the length scale grows.

```python
plt.figure(figsize=(5, 3))
for ell_w in lengths_w:
    plt.plot(grid_w, rbf_kernel_w(probe_w, grid_w, length_w=ell_w).ravel(), label=f"ell={ell_w}")
plt.axvline(float(probe_w[0]), color="black", linestyle="--", linewidth=1)
plt.title("2: RBF similarity around one observation")
plt.xlabel("x")
plt.ylabel("k(0.75, x)")
plt.legend()
plt.show()
```
▶ What you'll see: short length scales create narrow similarity bumps; long length scales spread influence over more of the domain.

*Why it's done this way:* Gaussian-process conditioning is built from covariance matrices. The RBF kernel supplies those covariances by translating geometric distance into statistical dependence, so the posterior can interpolate smoothly while still expressing uncertainty far from data.

### 3. Gaussian conditioning gives posterior mean and uncertainty

A Gaussian-process posterior conditions the prior on observed data. For test grid $X_*$, the mean and covariance are
$\mu_* = K_{*X}(K_{XX}+\sigma_n^2I)^{-1}y$ and
$\Sigma_* = K_{**}-K_{*X}(K_{XX}+\sigma_n^2I)^{-1}K_{X*}$.
The mean is the surrogate's best guess; the diagonal of $\Sigma_*$ gives uncertainty.

```python
def gp_posterior_w(X_train_w, y_train_w, X_test_w, length_w=0.35, noise_w=1e-6):
    K_w = rbf_kernel_w(X_train_w, X_train_w, length_w) + noise_w * np.eye(len(X_train_w))
    Ks_w = rbf_kernel_w(X_test_w, X_train_w, length_w)
    Kss_w = rbf_kernel_w(X_test_w, X_test_w, length_w)
    alpha_w = np.linalg.solve(K_w, y_train_w)
    mean_w = Ks_w @ alpha_w
    v_w = np.linalg.solve(K_w, Ks_w.T)
    cov_w = Kss_w - Ks_w @ v_w
    std_w = np.sqrt(np.maximum(np.diag(cov_w), 0.0))
    return mean_w, std_w

mu_w, std_w = gp_posterior_w(X_obs_w, y_obs_w, grid_w)
print("posterior arrays:", mu_w.shape, std_w.shape)
print("mean near x=0.75:", round(float(mu_w[np.argmin(np.abs(grid_w - 0.75))]), 3))
```
▶ What you'll see: the posterior mean is a full curve, and near an observed point it matches the observed value closely.

```python
idx_obs1_w = int(np.argmin(np.abs(grid_w - X_obs_w[1])))
print("observed y at x=0.75:", round(float(y_obs_w[1]), 3))
print("posterior mu/std there:", round(float(mu_w[idx_obs1_w]), 3), round(float(std_w[idx_obs1_w]), 5))
assert abs(float(mu_w[idx_obs1_w] - y_obs_w[1])) < 5e-3
```
▶ What you'll see: the surrogate nearly interpolates the observation and reports almost zero uncertainty there.

```python
plt.figure(figsize=(5, 3))
plt.plot(grid_w, mu_w, color="navy", label="posterior mean")
plt.fill_between(grid_w, mu_w - 2 * std_w, mu_w + 2 * std_w, color="skyblue", alpha=0.35, label="±2 std")
plt.scatter(X_obs_w, y_obs_w, color="crimson", zorder=3, label="observed")
plt.title("3: GP posterior mean and uncertainty")
plt.xlabel("x")
plt.ylabel("surrogate")
plt.legend()
plt.show()
```
▶ What you'll see: uncertainty pinches at observed points and widens in gaps, while the mean smoothly connects evidence.

*Why it's done this way:* Solving the linear system with $K_{XX}+\sigma_n^2I$ weighs observations by kernel similarity while the noise term stabilizes inversion. The variance formula subtracts what the observations explain from the prior variance, so uncertainty is low where data strongly constrain the function and high where they do not.

### 4. UCB turns mean and uncertainty into an explore-exploit score

The posterior mean alone would greedily pick the point that currently looks best. Upper confidence bound instead scores $a(x)=\mu(x)+\kappa\sigma(x)$ for maximization. The parameter $\kappa$ is a knob: larger values buy more uncertainty and therefore explore more aggressively.

```python
kappa_w = 1.8
ucb_w = mu_w + kappa_w * std_w
next_idx_w = int(np.argmax(ucb_w))
print("best observed so far:", round(float(np.max(y_obs_w)), 3))
print("next x by UCB:", round(float(grid_w[next_idx_w]), 3))
print("mu,std,ucb:", round(float(mu_w[next_idx_w]), 3), round(float(std_w[next_idx_w]), 3), round(float(ucb_w[next_idx_w]), 3))
```
▶ What you'll see: UCB can prefer a point that is not the highest mean if its uncertainty creates enough upside.

```python
candidate_w = np.array([0.6])
sigma_demo_w = 0.2
for kappa_demo_w in [0.5, 2.0]:
    acq_demo_w = 0.6 + kappa_demo_w * sigma_demo_w
    print("kappa", kappa_demo_w, "score", round(acq_demo_w, 3))
assert 0.6 + 0.5 * 0.2 == 0.7
assert 0.6 + 2.0 * 0.2 == 1.0
```
▶ What you'll see: increasing $\kappa$ raises the value of the same uncertain candidate from 0.7 to 1.0.

```python
plt.figure(figsize=(5, 3))
plt.plot(grid_w, mu_w, label="mean", color="navy")
plt.plot(grid_w, ucb_w, label="UCB", color="darkorange")
plt.scatter([grid_w[next_idx_w]], [ucb_w[next_idx_w]], color="red", zorder=3)
plt.title("4: acquisition = mean + kappa·std")
plt.xlabel("x")
plt.ylabel("score")
plt.legend()
plt.show()
```
▶ What you'll see: the UCB curve rises above the mean most strongly in uncertain regions; the red point is the proposed next experiment.

*Why it's done this way:* The acquisition function is the decision rule, not the surrogate itself. Adding $\kappa\sigma(x)$ gives uncertainty explicit value, preventing the optimizer from overcommitting to early lucky observations and making the exploration-exploitation tradeoff visible as one parameter.

### 5. Expected improvement values probabilistic upside

Expected improvement asks how much a candidate is expected to beat the current best. For maximization, $EI=(\mu-y^*)\Phi(z)+\sigma\phi(z)$ where $z=(\mu-y^*)/\sigma$. The first term rewards candidates whose mean already exceeds the best; the second term rewards uncertainty that could produce an improvement.

```python
def normal_pdf_w(z_w):
    return np.exp(-0.5 * z_w ** 2) / np.sqrt(2 * np.pi)

def normal_cdf_approx_w(z_w):
    z_w = np.asarray(z_w, dtype=float)
    sign_w = np.where(z_w >= 0, 1.0, -1.0)
    x_w = np.abs(z_w) / np.sqrt(2.0)
    t_w = 1.0 / (1.0 + 0.3275911 * x_w)
    erf_w = sign_w * (1.0 - (((((1.061405429 * t_w - 1.453152027) * t_w) + 1.421413741) * t_w - 0.284496736) * t_w + 0.254829592) * t_w * np.exp(-x_w * x_w))
    return 0.5 * (1.0 + erf_w)

def expected_improvement_w(mu_in_w, std_in_w, best_w):
    safe_std_w = np.maximum(std_in_w, 1e-12)
    z_w = (mu_in_w - best_w) / safe_std_w
    return (mu_in_w - best_w) * normal_cdf_approx_w(z_w) + safe_std_w * normal_pdf_w(z_w)

mu_demo_w, std_demo_w, best_demo_w = 0.8, 0.3, 1.0
z_demo_w = (mu_demo_w - best_demo_w) / std_demo_w
ei_demo_w = expected_improvement_w(mu_demo_w, std_demo_w, best_demo_w)
print("z:", round(float(z_demo_w), 4), "Phi:", round(float(normal_cdf_approx_w(z_demo_w)), 4), "phi:", round(float(normal_pdf_w(z_demo_w)), 4))
print("EI:", round(float(ei_demo_w), 4))
assert abs(float(ei_demo_w) - 0.0453) < 0.001
```
▶ What you'll see: even with mean below the current best, uncertainty gives a positive expected improvement.

```python
best_y_w = float(np.max(y_obs_w))
ei_w = expected_improvement_w(mu_w, std_w, best_y_w)
ei_idx_w = int(np.argmax(ei_w))
print("current best y:", round(best_y_w, 3))
print("next x by EI:", round(float(grid_w[ei_idx_w]), 3), "EI:", round(float(ei_w[ei_idx_w]), 4))
assert np.all(ei_w >= -1e-10)
```
▶ What you'll see: EI produces a nonnegative acquisition curve and a next point based on expected upside.

```python
plt.figure(figsize=(5, 3))
plt.plot(grid_w, ei_w, color="purple", label="expected improvement")
plt.scatter([grid_w[ei_idx_w]], [ei_w[ei_idx_w]], color="red", zorder=3)
plt.title("5: EI rewards plausible improvement")
plt.xlabel("x")
plt.ylabel("EI")
plt.legend()
plt.show()
```
▶ What you'll see: EI is high where either the mean is competitive or uncertainty leaves enough probability of beating the incumbent.

*Why it's done this way:* EI integrates improvement under the surrogate's predictive normal distribution. That is why below-best means can still matter: the right tail can beat the incumbent, and the $\sigma\phi(z)$ term is exactly the expected tail contribution.

### 6. The Bayesian optimization loop updates after each experiment

A Bayesian optimization iteration fits the surrogate, scores candidates with an acquisition, evaluates the chosen point, and appends the result. The loop is sequential because the next posterior depends on the newest experiment.

```python
X_loop_w = X_obs_w.copy()
y_loop_w = y_obs_w.copy()
chosen_w = []
for step_w in range(4):
    mu_loop_w, std_loop_w = gp_posterior_w(X_loop_w, y_loop_w, grid_w, length_w=0.35, noise_w=1e-6)
    acq_loop_w = mu_loop_w + 1.5 * std_loop_w
    acq_loop_w[np.isin(np.round(grid_w, 6), np.round(X_loop_w, 6))] = -np.inf
    idx_loop_w = int(np.argmax(acq_loop_w))
    x_next_w = float(grid_w[idx_loop_w])
    y_next_w = float(objective_w(x_next_w))
    chosen_w.append(x_next_w)
    X_loop_w = np.append(X_loop_w, x_next_w)
    y_loop_w = np.append(y_loop_w, y_next_w)
    print(step_w + 1, "x_next", round(x_next_w, 3), "y_next", round(y_next_w, 3), "best", round(float(np.max(y_loop_w)), 3))
assert len(X_loop_w) == 7
```
▶ What you'll see: each iteration adds one experiment and updates the best observed value.

```python
mu_final_w, std_final_w = gp_posterior_w(X_loop_w, y_loop_w, grid_w, length_w=0.35, noise_w=1e-6)
print("chosen sequence:", np.round(chosen_w, 3))
print("final best x,y:", round(float(X_loop_w[np.argmax(y_loop_w)]), 3), round(float(np.max(y_loop_w)), 3))
```
▶ What you'll see: the selected sequence balances inspecting uncertain gaps and refining promising regions.

```python
plt.figure(figsize=(5, 3))
plt.plot(grid_w, y_grid_w, color="lightgray", label="hidden true objective")
plt.plot(grid_w, mu_final_w, color="navy", label="final posterior mean")
plt.scatter(X_loop_w, y_loop_w, color="crimson", zorder=3, label="evaluations")
plt.title("6: BO after several acquisition-guided evaluations")
plt.xlabel("x")
plt.ylabel("value")
plt.legend()
plt.show()
```
▶ What you'll see: the final surrogate has more support near useful regions than a uniformly spaced design with the same tiny budget.

*Why it's done this way:* Bayesian optimization spends evaluations adaptively. Re-fitting after every observation is mathematically necessary because the posterior covariance and mean change when the data set changes, and the acquisition should be optimized under the most current uncertainty.

### Basic 3 — Compute RBF similarity

**Goal.** Convert distance into covariance, because a GP surrogate needs a kernel to express smoothness.

```python
x1_b3 = np.array([0.75])
x2_b3 = np.array([0.10, 0.75, 1.60])
ell_b3 = 0.35
sqdist_b3 = (x1_b3[:, None] - x2_b3[None, :]) ** 2

```
▶ What you'll see: the observation at 0.75 has similarity 1 to itself and lower similarity to distant points.

👀 Takeaway: the RBF kernel is the smoothness prior written as a covariance number.

### Basic 4 — Build the training covariance matrix

**Goal.** Assemble `K(X, X)`, because GP conditioning is linear algebra on the observed inputs.

### Basic 5 — Predict one posterior mean by hand


```python
x_star_b5 = np.array([0.75])
```

### Basic 6 — Compute posterior uncertainty

**Goal.** Inspect the posterior standard deviation, because uncertainty is the part that drives exploration.

```python
X_b6 = np.array([0.10, 0.75, 1.60])
x_test_b6 = np.array([0.75, 1.15])
ell_b6 = 0.35
K_b6 = np.exp(-0.5 * (X_b6[:, None] - X_b6[None, :]) ** 2 / ell_b6 ** 2) + 1e-6 * np.eye(3)
Ks_b6 = np.exp(-0.5 * (x_test_b6[:, None] - X_b6[None, :]) ** 2 / ell_b6 ** 2)
Kss_b6 = np.exp(-0.5 * (x_test_b6[:, None] - x_test_b6[None, :]) ** 2 / ell_b6 ** 2)
V_b6 = np.linalg.solve(K_b6, Ks_b6.T)
cov_b6 = Kss_b6 - Ks_b6 @ V_b6
std_b6 = np.sqrt(np.maximum(np.diag(cov_b6), 0.0))
print("test x:", x_test_b6)
print("posterior std:", np.round(std_b6, 5))
assert std_b6[0] < std_b6[1]
```
▶ What you'll see: uncertainty is almost zero at the observed point and larger at an unobserved point.

👀 Takeaway: posterior variance measures what the current data do not yet constrain.

### Basic 9 — Compute expected improvement ingredients

**Goal.** Calculate `z`, `phi`, and an approximate `Phi`, because EI is built from normal-tail improvement.

```python
mu_b9 = 0.8
std_b9 = 0.3
best_b9 = 1.0
z_b9 = (mu_b9 - best_b9) / std_b9
phi_b9 = np.exp(-0.5 * z_b9 ** 2) / np.sqrt(2 * np.pi)
Phi_b9 = 1.0 / (1.0 + np.exp(-1.702 * z_b9))
ei_b9 = (mu_b9 - best_b9) * Phi_b9 + std_b9 * phi_b9

```
▶ What you'll see: EI remains positive because uncertainty leaves some chance of beating the current best.

👀 Takeaway: expected improvement values upside, not just current predicted mean.

### Basic 10 — Mask already-sampled candidates

**Goal.** Prevent duplicate experiments, because evaluating the exact same deterministic point wastes budget.

```python
grid_b10 = np.linspace(0, 1, 6)
acq_b10 = np.array([0.2, 0.8, 0.5, 0.9, 0.7, 0.1])
observed_b10 = np.array([0.2, 0.6])
mask_seen_b10 = np.isin(np.round(grid_b10, 6), np.round(observed_b10, 6))
acq_masked_b10 = acq_b10.copy()
acq_masked_b10[mask_seen_b10] = -np.inf
```
