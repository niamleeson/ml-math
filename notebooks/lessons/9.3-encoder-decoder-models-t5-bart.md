# 9.3 — Encoder-Decoder Models (T5, BART)

Encoder-decoder models split sequence modeling into two jobs: an encoder reads the source text with full bidirectional attention, and a decoder writes the target text one token at a time while cross-attending to the encoded source. In this lesson, you will build that split from tiny NumPy arrays, inspect the masks and attention weights, and see why T5/BART-style denoising and conditional generation are different from both encoder-only classification and decoder-only continuation.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build encoder-decoder modeling one idea at a time. Run each cell in order and read the printed intermediate values — every mask, attention score, probability, and reconstruction choice is spelled out so nothing is a black box. This walkthrough is self-contained (it imports what it needs) and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, masks, softmaxes, and tiny linear algebra.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for toy vectors.
```

### 1. Conditional sequence generation: two sequences, two lengths

Encoder-decoder models solve **conditional** generation: generate an output sequence $y_{1:U}$ given an input sequence $x_{1:T}$. The encoder can read all $T$ source tokens at once because the source is already known. The decoder must generate the $U$ target tokens causally because future target tokens do not exist yet during generation. That is why the lesson formula is

$$p(y_{1:U}\mid x_{1:T})=\prod_{u=1}^{U}p(y_u\mid y_{<u},\mathrm{Enc}(x_{1:T})).$$

```python
source_w = ["translate:", "cats", "sleep"]  # source tokens x_1:T.
target_w = ["chats", "dorment"]              # target tokens y_1:U.
T_w, U_w = len(source_w), len(target_w)        # source and target lengths can differ.
print("source length T:", T_w, "target length U:", U_w)
print("source:", source_w)
print("target:", target_w)
```
▶ What you'll see: the source has 3 tokens and the target has 2 tokens, so the model is not copying positions one-for-one.

```python
enc_pairs_w = T_w * T_w                  # full bidirectional source attention.
dec_pairs_w = U_w * (U_w + 1) // 2       # causal target self-attention pairs.
cross_pairs_w = U_w * T_w                # every target query can inspect every source key.
print("encoder self-attention pairs:", enc_pairs_w)
print("decoder causal pairs:", dec_pairs_w)
print("cross-attention pairs:", cross_pairs_w)
assert (enc_pairs_w, dec_pairs_w, cross_pairs_w) == (9, 3, 6)
```
▶ What you'll see: the canonical counts are `9`, `3`, and `6` for T=3 and U=2.

```python
plt.figure(figsize=(4.6, 3))
plt.bar(["encoder", "decoder", "cross"], [enc_pairs_w, dec_pairs_w, cross_pairs_w], color=["teal", "orange", "purple"])
plt.ylabel("visible query-key pairs")
plt.title("1: three attention budgets")
plt.show()
```
▶ What you'll see: encoder attention is full over the source, decoder attention is triangular over the target, and cross-attention is rectangular from target to source.

*Why it's done this way:* The model needs different visibility rules for different information. Source tokens are already observed, so bidirectional reading is legal. Target tokens are being generated, so future target tokens must be hidden. Cross-attention is the bridge: it lets every current decoder state condition on the whole encoded source without violating the left-to-right target factorization.

### 2. Encoder self-attention reads the source bidirectionally

The encoder turns source token embeddings into contextual states. In a full Transformer this happens through query-key-value attention. In the tiny version below, each source token gets to score every other source token, softmax the row of scores, and take a weighted average of source value vectors. Because no causal mask is used in the encoder, a middle source token can use both its left and right neighbors.

```python
X_w = np.array([[1.0, 0.0, 0.2, 0.1],   # "translate:"
                [0.2, 1.0, 0.0, 0.1],   # "cats"
                [0.1, 0.3, 1.0, 0.0]])  # "sleep"
print("X shape:", X_w.shape)
print(X_w)
```
▶ What you'll see: three 4-dimensional source token vectors.

```python
def softmax_w(z):
    z = np.asarray(z, dtype=float)
    e = np.exp(z - np.max(z, axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)

scores_enc_w = X_w @ X_w.T / np.sqrt(X_w.shape[1])  # scaled dot-product scores.
weights_enc_w = softmax_w(scores_enc_w)             # row-wise attention distributions.
print("encoder score matrix:\n", np.round(scores_enc_w, 3))
print("encoder attention rows sum to:", np.round(weights_enc_w.sum(axis=1), 3))
assert scores_enc_w.shape == (3, 3)
```
▶ What you'll see: a 3×3 score matrix and attention rows that each sum to 1.

```python
H_w = weights_enc_w @ X_w  # contextual encoder states.
print("encoder states H shape:", H_w.shape)
print(np.round(H_w, 3))
plt.figure(figsize=(4, 3))
plt.imshow(weights_enc_w, cmap="Blues", vmin=0, vmax=1)
plt.colorbar(label="attention weight")
plt.xticks(range(T_w), source_w, rotation=25)
plt.yticks(range(T_w), source_w)
plt.title("2: encoder sees all source tokens")
plt.show()
```
▶ What you'll see: every source row assigns nonzero weight across the full source sequence.

*Why it's done this way:* Scaled dot-product attention compares each query to all source keys, then normalizes with softmax so the values are averaged rather than summed. Dividing by $\sqrt d$ keeps dot products from growing too large as dimensionality grows, which prevents the softmax from becoming needlessly sharp. No causal mask appears here because the source is not being predicted left-to-right; it is evidence.

### 3. Decoder self-attention writes causally

The decoder also uses self-attention, but with a triangular mask. At target position $u$, the decoder may use target tokens $\le u$ and must not use target tokens $>u$. During training, the true previous target tokens are shifted in (teacher forcing); during generation, the model's own previous outputs are shifted in. Either way, the mask preserves the factorization.

```python
Y_w = np.array([[0.9, 0.1, 0.0, 0.2],   # decoder input for first target position.
                [0.1, 0.8, 0.2, 0.0]])  # decoder input for second target position.
raw_dec_w = Y_w @ Y_w.T / np.sqrt(Y_w.shape[1])
causal_mask_w = np.triu(np.ones((U_w, U_w), dtype=bool), k=1)
print("raw decoder scores:\n", np.round(raw_dec_w, 3))
print("future-token mask:\n", causal_mask_w.astype(int))
```
▶ What you'll see: the mask has a 1 above the diagonal, marking the future cell that must be hidden.

```python
masked_dec_w = raw_dec_w.copy()
masked_dec_w[causal_mask_w] = -1e9
weights_dec_w = softmax_w(masked_dec_w)
print("decoder attention weights:\n", np.round(weights_dec_w, 3))
assert np.allclose(weights_dec_w[0], [1.0, 0.0])
```
▶ What you'll see: the first target position attends only to itself; the second can attend to both earlier target inputs.

```python
D_self_w = weights_dec_w @ Y_w
print("decoder self-attended states shape:", D_self_w.shape)
plt.figure(figsize=(3.8, 3))
plt.imshow(weights_dec_w, cmap="Oranges", vmin=0, vmax=1)
plt.colorbar(label="attention weight")
plt.xticks(range(U_w), ["y0", "y1"])
plt.yticks(range(U_w), ["y0", "y1"])
plt.title("3: decoder causal self-attention")
plt.show()
```
▶ What you'll see: the upper-right future cell is zeroed out after masking.

*Why it's done this way:* The decoder is an autoregressive model inside a conditional model. If position 0 could look at position 1 during training, the loss would reward cheating: the model would learn with information unavailable at generation time. The triangular mask makes training and inference obey the same causal dependency pattern.

### 4. Cross-attention: target queries read source memory

Cross-attention is the defining encoder-decoder operation. The decoder provides **queries**: what the current output position needs. The encoder provides **keys and values**: where each source token's information lives and what content can be copied or transformed. Scores have shape $U\times T$, weights also have shape $U\times T$, and the output has shape $U\times d$ because each target position receives one source-conditioned vector.

```python
Q_cross_w = D_self_w                         # decoder states ask questions.
K_cross_w = H_w                              # encoder states provide addresses.
V_cross_w = H_w                              # encoder states provide content.
scores_cross_w = Q_cross_w @ K_cross_w.T / np.sqrt(H_w.shape[1])
weights_cross_w = softmax_w(scores_cross_w)
print("cross scores shape:", scores_cross_w.shape)
print("cross weights:\n", np.round(weights_cross_w, 3))
assert weights_cross_w.shape == (2, 3)
```
▶ What you'll see: a 2×3 matrix — two target positions attending over three source tokens.

```python
context_w = weights_cross_w @ V_cross_w
print("cross-attention output shape:", context_w.shape)
print(np.round(context_w, 3))
assert context_w.shape == (2, 4)
```
▶ What you'll see: each target position now has a 4-dimensional source-conditioned context vector.

```python
plt.figure(figsize=(4.6, 3))
plt.imshow(weights_cross_w, cmap="Purples", vmin=0, vmax=1)
plt.colorbar(label="source weight")
plt.xticks(range(T_w), source_w, rotation=25)
plt.yticks(range(U_w), ["target 0", "target 1"])
plt.title("4: cross-attention aligns target to source")
plt.show()
```
▶ What you'll see: each decoder row distributes its probability mass across source tokens.

*Why it's done this way:* Self-attention inside the decoder can only summarize the partial target prefix. Cross-attention injects source evidence at every generation step. Mathematically, softmax turns source-token scores into a probability distribution; multiplying by values computes the expectation of source content under that distribution. This is why a decoder can translate, summarize, or answer a question instead of behaving like an unconditional language model.

### 5. Conditional probabilities and teacher forcing loss

Once the decoder state is source-conditioned, a vocabulary projection turns it into logits and a softmax turns logits into next-token probabilities. Training usually uses teacher forcing: feed the true previous target tokens, then apply cross-entropy to the true next tokens. For a target sequence, the conditional probability is the product of the target-token probabilities given the same encoded source.

```python
W_vocab_w = np.array([[ 1.5, -0.2,  0.1],
                      [ 0.1,  1.3, -0.4],
                      [ 0.2, -0.1,  1.0],
                      [ 0.0,  0.4,  0.2]])  # maps d=4 states to a 3-token toy vocabulary.
logits_w = context_w @ W_vocab_w
probs_w = softmax_w(logits_w)
print("vocab probabilities:\n", np.round(probs_w, 3))
print("rows sum to:", np.round(probs_w.sum(axis=1), 3))
```
▶ What you'll see: each target position has a probability distribution over three toy output tokens.

```python
true_ids_w = np.array([0, 1])
token_probs_w = probs_w[np.arange(U_w), true_ids_w]
loss_w = -np.log(token_probs_w).sum()
print("true-token probabilities:", np.round(token_probs_w, 3))
print("negative log-likelihood:", round(float(loss_w), 3))
assert token_probs_w.shape == (2,)
```
▶ What you'll see: the loss is the sum of `-log(probability assigned to the correct target token)`.

```python
manual_probs_w = np.array([0.6, 0.5, 0.4])
cond_prob_w = float(np.prod(manual_probs_w))
print("conditional sequence probability:", round(cond_prob_w, 3))
assert round(cond_prob_w, 3) == 0.120
plt.figure(figsize=(4, 3))
plt.bar(["p(y1)", "p(y2)", "p(y3)", "product"], list(manual_probs_w) + [cond_prob_w], color="seagreen")
plt.title("5: sequence probability multiplies steps")
plt.show()
```
▶ What you'll see: three reasonable token probabilities multiply to a much smaller whole-sequence probability.

*Why it's done this way:* Cross-entropy trains the model to put probability mass on the observed target at each causal step. Multiplying probabilities is not arbitrary; it follows the chain rule factorization. In practice we sum negative log-probabilities because products of many small numbers underflow and logs turn products into stable sums.

### 6. T5/BART denoising: reconstruct missing text, not every input token

T5 and BART are often trained by corrupting an input and asking the decoder to reconstruct the missing or original content. The important idea is that the encoder reads a damaged source, while the decoder learns a conditional repair distribution. In span corruption, several missing input tokens can be replaced by one sentinel token, so the decoder's target is shorter and more focused than copying the whole input.

```python
clean_w = ["the", "small", "cat", "slept", "on", "the", "blue", "mat"]
corrupted_w = ["the", "<extra_id_0>", "slept", "on", "the", "<extra_id_1>", "mat"]
repair_target_w = ["<extra_id_0>", "small", "cat", "<extra_id_1>", "blue"]
print("clean length:", len(clean_w))
print("corrupted source length:", len(corrupted_w))
print("repair target length:", len(repair_target_w))
```
▶ What you'll see: the corrupted source is shorter than the clean text because spans are replaced by sentinels.

```python
n_corrupted_spans_w = 2
n_source_tokens_w = len(clean_w)
span_fraction_w = n_corrupted_spans_w / n_source_tokens_w
print("corrupted spans:", n_corrupted_spans_w, "out of", n_source_tokens_w, "tokens")
print("span fraction:", round(span_fraction_w, 3))
assert round(span_fraction_w, 3) == 0.250
```
▶ What you'll see: two corrupted spans out of eight tokens gives the lesson's 0.25 span-per-token count.

```python
lengths_w = [len(clean_w), len(corrupted_w), len(repair_target_w)]
plt.figure(figsize=(4.6, 3))
plt.bar(["clean", "corrupted source", "decoder target"], lengths_w, color=["gray", "orange", "teal"])
plt.ylabel("tokens")
plt.title("6: denoising changes source and target")
plt.xticks(rotation=15)
plt.show()
```
▶ What you'll see: the decoder target is the repair text, not a full unconditional continuation.

*Why it's done this way:* Denoising makes the model learn conditional reconstruction. The encoder must use both left and right context around the corrupted spans; the decoder must generate the missing content causally. This matches the encoder-decoder split exactly: bidirectional understanding of damaged evidence plus left-to-right production of the repaired answer.

### ✍️ Toy 2 · Encoder self-attention reads all source tokens

Source tokens are evidence, so every encoder row softmaxes across the full source instead of using a
causal wall.

```python
import numpy as np

t2_seed = 0  # -> 0
t2_rng = np.random.default_rng(0)  # -> reproducible generator
print("seed:", t2_seed)  # -> 0
t2_X = np.array([[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]])  # -> 3 source vectors
print("source vectors:", t2_X.tolist())  # -> [[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]]
t2_scale = np.sqrt(t2_X.shape[1])  # -> 1.4142135623730951
print("scale:", round(float(t2_scale), 3))  # -> 1.414
t2_scores = t2_X @ t2_X.T  # -> dot products
t2_scores = t2_scores / t2_scale  # -> scaled scores
print("encoder scores:", np.round(t2_scores, 3).tolist())  # -> [[0.707, 0.0, 0.707], [0.0, 0.707, 0.707], [0.707, 0.707, 1.414]]
t2_shifted = t2_scores - np.max(t2_scores, axis=1, keepdims=True)  # -> row-shifted scores
print("shifted scores:", np.round(t2_shifted, 3).tolist())  # -> [[0.0, -0.707, 0.0], [-0.707, 0.0, 0.0], [-0.707, -0.707, 0.0]]
t2_exp = np.exp(t2_shifted)  # -> exponentials
print("exp scores:", np.round(t2_exp, 3).tolist())  # -> [[1.0, 0.493, 1.0], [0.493, 1.0, 1.0], [0.493, 0.493, 1.0]]
t2_weights = t2_exp / np.sum(t2_exp, axis=1, keepdims=True)  # -> row probabilities
print("attention weights:", np.round(t2_weights, 3).tolist())  # -> [[0.401, 0.198, 0.401], [0.198, 0.401, 0.401], [0.248, 0.248, 0.503]]
t2_H = t2_weights @ t2_X  # -> contextual source states
print("encoder states:", np.round(t2_H, 3).tolist())  # -> [[0.802, 0.599], [0.599, 0.802], [0.752, 0.752]]

plt.figure(figsize=(3.8, 3.0))
plt.imshow(t2_weights, cmap="Blues", vmin=0, vmax=1)
plt.colorbar(label="weight")
plt.xlabel("source key")
plt.ylabel("source query")
plt.title("Toy 2 · full encoder attention")
plt.show()
assert np.all(t2_weights > 0.0)
assert t2_H.shape == (3, 2)
```
▶ What you'll see: every source row has three nonzero weights, so it can mix left, self, and right evidence.

### ✍️ Toy 3 · Decoder self-attention writes causally

The decoder uses the same scoring idea but zeros out future target positions before softmax.

```python
import numpy as np

t3_seed = 0  # -> 0
t3_rng = np.random.default_rng(0)  # -> reproducible generator
print("seed:", t3_seed)  # -> 0
t3_Y = np.array([[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]])  # -> 3 decoder input vectors
print("decoder vectors:", t3_Y.tolist())  # -> [[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]]
t3_scores = t3_Y @ t3_Y.T  # -> dot products
t3_scores = t3_scores / np.sqrt(t3_Y.shape[1])  # -> scaled scores
print("raw decoder scores:", np.round(t3_scores, 3).tolist())  # -> [[0.707, 0.0, 0.707], [0.0, 0.707, 0.707], [0.707, 0.707, 1.414]]
t3_future_mask = np.triu(np.ones((3, 3), dtype=bool), k=1)  # -> upper triangle
print("future mask:", t3_future_mask.astype(int).tolist())  # -> [[0, 1, 1], [0, 0, 1], [0, 0, 0]]
t3_masked_scores = t3_scores.copy()  # -> copy before blocking
t3_masked_scores[t3_future_mask] = -1e9  # -> future scores are impossible
print("masked scores:", np.round(t3_masked_scores, 3).tolist())  # -> [[0.707, -1000000000.0, -1000000000.0], [0.0, 0.707, -1000000000.0], [0.707, 0.707, 1.414]]
t3_shifted = t3_masked_scores - np.max(t3_masked_scores, axis=1, keepdims=True)  # -> shifted rows
print("shifted scores:", np.round(t3_shifted, 3).tolist())  # -> [[0.0, -1000000000.707, -1000000000.707], [-0.707, 0.0, -1000000000.707], [-0.707, -0.707, 0.0]]
t3_exp = np.exp(t3_shifted)  # -> exponentials
t3_exp[t3_future_mask] = 0.0  # -> exact zero future mass
print("exp scores:", np.round(t3_exp, 3).tolist())  # -> [[1.0, 0.0, 0.0], [0.493, 1.0, 0.0], [0.493, 0.493, 1.0]]
t3_weights = t3_exp / np.sum(t3_exp, axis=1, keepdims=True)  # -> causal weights
print("decoder weights:", np.round(t3_weights, 3).tolist())  # -> [[1.0, 0.0, 0.0], [0.33, 0.67, 0.0], [0.248, 0.248, 0.503]]

plt.figure(figsize=(3.8, 3.0))
plt.imshow(t3_weights, cmap="Oranges", vmin=0, vmax=1)
plt.colorbar(label="weight")
plt.xlabel("target key")
plt.ylabel("target query")
plt.title("Toy 3 · causal decoder attention")
plt.show()
assert np.allclose(t3_weights[0], np.array([1.0, 0.0, 0.0]))
assert float(t3_weights[1, 2]) == 0.0
```
▶ What you'll see: target row 0 can only see itself, while later rows keep only their prefixes.

### ✍️ Toy 4 · Cross-attention reads source memory from target queries

Cross-attention has target rows and source columns. Each decoder query forms a distribution over encoder
states and averages source values.

▶ What you'll see: each target row chooses a different source-weighted summary.

### ✍️ Toy 5 · Teacher forcing multiplies conditional token probabilities

With teacher forcing, the true previous targets are inputs and the shifted targets receive loss. Sequence
probability is the product of those conditional step probabilities.

```python
import numpy as np

t5_seed = 0  # -> 0
t5_rng = np.random.default_rng(0)  # -> reproducible generator
print("seed:", t5_seed)  # -> 0
t5_target_ids = np.array([0, 1, 2, 3])  # -> [0, 1, 2, 3]
print("target ids:", t5_target_ids.tolist())  # -> [0, 1, 2, 3]
```

## 🛠️ Setup

```python
import numpy as np  # load NumPy for arrays, masks, softmaxes, and small numerical checks.
import matplotlib.pyplot as plt  # load Matplotlib so attention weights and losses can be inspected visually.
np.random.seed(0)  # make all random examples reproducible across runs.

def softmax(z, axis=-1):  # define a numerically stable softmax helper.
    z = np.asarray(z, dtype=float)  # convert input to a float array for exponentials.
    shifted = z - np.max(z, axis=axis, keepdims=True)  # subtract the row max to avoid overflow.
    e = np.exp(shifted)  # exponentiate shifted scores.
    return e / np.sum(e, axis=axis, keepdims=True)  # normalize each row into probabilities.

def causal_mask(n):  # define a True mask for future positions in a decoder sequence.
    return np.triu(np.ones((n, n), dtype=bool), k=1)  # mark cells above the diagonal as future tokens.

def scaled_dot_attention(Q, K, V, mask=None):  # implement attention from scratch using NumPy only.
    scores = Q @ K.T / np.sqrt(Q.shape[-1])  # compute scaled query-key dot products.
    if mask is not None:  # optionally hide disallowed key positions.
        scores = scores.copy()  # avoid mutating caller-owned arrays.
        scores[mask] = -1e9  # make masked logits effectively impossible after softmax.
    weights = softmax(scores, axis=-1)  # normalize over keys for each query.
    return weights @ V, weights  # return weighted value averages plus attention weights.
```
