# 6.30 — Spiking Neural Networks

Spiking neural networks (SNNs) replace continuous activations with threshold events: a neuron accumulates input current in a leaky membrane, fires a spike when the voltage crosses a threshold, and then resets. In this lesson, you will build that mechanism from scratch in NumPy, inspect every intermediate value, and see why timing, leakage, surrogate gradients, and scale bookkeeping matter for stable learning.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build spiking neural networks one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math, including the membrane rule and a surrogate-gradient update, is shown directly. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, linear algebra, and small simulations for spiking neurons.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for random currents and weights.
```

### 1. Input current: turning features into drive

A spiking neuron still starts with the familiar affine score from deep learning: $I_t=w^\top x_t+b$. The difference is what happens next. Instead of immediately passing a smooth activation to the next layer, the score becomes **current** that charges a membrane over time. We first reproduce the lesson's two-input scratch pass so the arithmetic is visible before adding time.

```python
x_w = np.array([1.5, -0.5])  # two visible input features.
w_w = np.array([1.0, -0.1])  # weights that convert features into current.
b_w = 0.300                  # bias current from the lesson block.
I_w = float(w_w @ x_w + b_w)  # affine current: 1.0*1.5 + -0.1*(-0.5) + 0.3.
gated_w = max(0.0, I_w)       # a ReLU-style gate used in the source content for comparison.
print("affine current:", round(I_w, 3))
print("gated current:", round(gated_w, 3))
assert round(I_w, 3) == 1.850 and round(gated_w, 3) == 1.850
```
▶ What you'll see: the raw score is 1.850, so a nonnegative gate leaves it unchanged.

```python
parts_w = np.array([w_w[0] * x_w[0], w_w[1] * x_w[1], b_w])
plt.figure(figsize=(4.4, 3))
plt.bar(["w0 x0", "w1 x1", "bias"], parts_w, color=["teal", "orange", "gray"])
plt.axhline(0, color="black", linewidth=0.7)
plt.title("1: pieces of input current")
plt.ylabel("current contribution")
plt.show()
```
▶ What you'll see: the positive feature contribution dominates; the second weight-feature product adds a small positive 0.050.

*Why it's done this way:* $w^\top x+b$ is the simplest local rule that mixes evidence from several inputs into one scalar drive. In an SNN, that scalar is not the final communication value; it is the amount of charge injected into a dynamical state, so the same affine map becomes a time-dependent current source.

### 2. Leaky membrane accumulation

The core SNN state is membrane voltage $v_t$. At every time step, old voltage partly remains and new current is added:

$$v_t=\alpha v_{t-1}+I_t.$$

The leak parameter $\alpha$ is a memory knob. If $\alpha=0$, the neuron forgets everything each step. If $\alpha$ is close to 1, current from earlier time steps persists and can combine with later current to reach threshold.

```python
I_seq_w = np.array([0.4, 0.4, 0.4, 0.4, 0.4])  # repeated weak inputs that are individually subthreshold.
alpha_w = 0.8                                  # keep 80% of the previous voltage each step.
v_w = np.zeros_like(I_seq_w)                    # store membrane voltage over time.
for t_w in range(len(I_seq_w)):
    prev_w = 0.0 if t_w == 0 else v_w[t_w - 1]
    v_w[t_w] = alpha_w * prev_w + I_seq_w[t_w]
print("voltages:", np.round(v_w, 3))
assert np.allclose(np.round(v_w, 3), [0.4, 0.72, 0.976, 1.181, 1.345])
```
▶ What you'll see: five small currents accumulate into a voltage that eventually exceeds 1.

```python
plt.figure(figsize=(4.6, 3))
plt.plot(np.arange(len(v_w)), v_w, marker="o", color="purple", label="v_t")
plt.axhline(1.0, color="red", linestyle="--", label="threshold τ=1")
plt.title("2: leaky integration over time")
plt.xlabel("time step")
plt.ylabel("membrane voltage")
plt.legend()
plt.show()
```
▶ What you'll see: the curve rises but bends because each old voltage is multiplied by 0.8 before the new current is added.

*Why it's done this way:* the recurrence is a discrete-time memory equation. Multiplying by $\alpha$ prevents unbounded accumulation while preserving useful recent evidence; adding $I_t$ lets multiple weak inputs cooperate across time, which is the temporal computation missing from a one-shot ReLU.

### 3. Threshold spike and reset

Voltage becomes communication only when it crosses a threshold $\tau$. The spike is a binary event, $spike_t=\mathbf{1}[v_t\ge\tau]$. After firing, many simple neuron models reset the membrane so the same accumulated charge is not counted twice.

```python
I_seq_w = np.array([0.4, 0.4, 0.4, 0.4, 0.4])
alpha_w, tau_w = 0.8, 1.0
v_reset_w = np.zeros_like(I_seq_w)
spikes_w = np.zeros_like(I_seq_w)
v_prev_w = 0.0
for t_w, I_t_w in enumerate(I_seq_w):
    v_now_w = alpha_w * v_prev_w + I_t_w
    spikes_w[t_w] = 1.0 if v_now_w >= tau_w else 0.0
    v_reset_w[t_w] = v_now_w
    v_prev_w = 0.0 if spikes_w[t_w] == 1.0 else v_now_w
print("pre-reset voltages:", np.round(v_reset_w, 3))
print("spikes:", spikes_w.astype(int))
assert spikes_w.astype(int).tolist() == [0, 0, 0, 1, 0]
```
▶ What you'll see: the neuron fires once at time step 3, then starts accumulating again from reset.

```python
plt.figure(figsize=(4.8, 3))
plt.plot(v_reset_w, marker="o", label="voltage before reset", color="teal")
plt.vlines(np.arange(len(spikes_w)), 0, spikes_w, color="crimson", linewidth=3, label="spike")
plt.axhline(tau_w, color="black", linestyle="--", label="τ")
plt.title("3: threshold creates a discrete event")
plt.xlabel("time step")
plt.legend()
plt.show()
```
▶ What you'll see: a red event appears exactly when the voltage first crosses the threshold line.

*Why it's done this way:* thresholding turns accumulated analog evidence into sparse binary communication. Reset enforces causality: once the neuron has spent its stored charge to fire, the next spike must be earned by new input rather than by reusing the same voltage.

### 4. Spike trains encode intensity through time

A spike is binary at one time step, but a spike train can still represent a graded signal. Stronger current tends to produce more frequent spikes (rate coding) and earlier threshold crossings (temporal coding). We can see both by feeding the same neuron different constant currents.

```python
currents_w = np.array([0.35, 0.55, 0.75])  # weak, medium, strong current levels.
T_w, alpha_w, tau_w = 12, 0.7, 1.0
spike_trains_w = []
for current_w in currents_w:
    v_prev_w = 0.0
    spikes_one_w = []
    for t_w in range(T_w):
        v_now_w = alpha_w * v_prev_w + current_w
        spike_w = 1.0 if v_now_w >= tau_w else 0.0
        spikes_one_w.append(spike_w)
        v_prev_w = 0.0 if spike_w else v_now_w
    spike_trains_w.append(spikes_one_w)
spike_trains_w = np.array(spike_trains_w)
print("spike counts:", spike_trains_w.sum(axis=1).astype(int))
assert spike_trains_w.sum(axis=1).astype(int).tolist() == [2, 4, 6]
```
▶ What you'll see: stronger current creates more spikes in the same 12-step window.

```python
plt.figure(figsize=(5, 3))
for row_w, current_w in enumerate(currents_w):
    times_w = np.where(spike_trains_w[row_w] > 0)[0]
    plt.vlines(times_w, row_w + 0.15, row_w + 0.85, linewidth=3, label=f"I={current_w}")
plt.yticks(np.arange(len(currents_w)) + 0.5, ["0.35", "0.55", "0.75"])
plt.xlabel("time step")
plt.ylabel("constant current")
plt.title("4: spike trains carry graded intensity")
plt.show()
```
▶ What you'll see: higher-current rows have denser and earlier event marks.

*Why it's done this way:* the binary spike avoids sending a continuous value at every time step, but information is not lost; it moves into event timing and event count. This is why SNNs can be sparse and still approximate analog computation over a time window.

### 5. Surrogate gradient for a hard threshold

The threshold function is not differentiable in the useful way: it is flat almost everywhere and jumps at $\tau$. Training therefore often uses a **surrogate gradient**: forward pass uses the hard spike, while backward pass pretends the threshold has a narrow smooth slope near $\tau$.

```python
v_grid_w = np.linspace(-0.5, 1.5, 101)
tau_w = 1.0
spike_grid_w = (v_grid_w >= tau_w).astype(float)
slope_w = 10.0
surrogate_grad_w = 1.0 / (1.0 + slope_w * np.abs(v_grid_w - tau_w)) ** 2
print("hard spike at v=0.9,1.0,1.1:", (np.array([0.9, 1.0, 1.1]) >= tau_w).astype(int))
print("surrogate grad near threshold:", np.round(1.0 / (1.0 + slope_w * np.abs(np.array([0.9, 1.0, 1.1]) - tau_w)) ** 2, 3))
```
▶ What you'll see: the forward spike jumps from 0 to 1, while the surrogate gives its largest learning signal at the threshold.

```python
plt.figure(figsize=(5, 3))
plt.plot(v_grid_w, spike_grid_w, label="hard spike", color="black")
plt.plot(v_grid_w, surrogate_grad_w, label="surrogate gradient", color="crimson")
plt.axvline(tau_w, linestyle="--", color="gray")
plt.title("5: train through a threshold with a surrogate")
plt.xlabel("voltage")
plt.legend()
plt.show()
```
▶ What you'll see: a step function for communication and a peaked smooth curve for learning.

*Why it's done this way:* gradient descent needs a direction. The hard threshold says almost every voltage change has zero local effect, which would block learning. The surrogate keeps the forward model event-based but assigns credit to voltages near firing, where a small weight change could actually change the spike decision.

### 6. One parameter update from spike error

The source content emphasizes the training knob: with learning rate $\eta=0.050$ and gradient $g=1.500$, a scalar parameter moves from 2.000 to 1.925. In an SNN, that gradient can be read as an error signal times a surrogate threshold slope times the input that created voltage.

```python
weight_w = 2.000
eta_w = 0.050
grad_w = 1.500
new_weight_w = weight_w - eta_w * grad_w
print("new weight:", round(new_weight_w, 3))
assert round(new_weight_w, 3) == 1.925
```
▶ What you'll see: one reliable nudge moves the parameter by only 0.075.

```python
v_near_w = 0.95
x_in_w = 1.5
target_spike_w = 0.0
actual_spike_w = 1.0 if v_near_w >= 0.9 else 0.0
sur_slope_w = 1.0 / (1.0 + 10.0 * abs(v_near_w - 1.0)) ** 2
local_grad_w = (actual_spike_w - target_spike_w) * sur_slope_w * x_in_w
print("surrogate slope:", round(sur_slope_w, 3))
print("local gradient:", round(local_grad_w, 3))
assert round(local_grad_w, 3) == 0.667
```
▶ What you'll see: a voltage near threshold produces a nonzero local gradient, so the input weight can be adjusted.

*Why it's done this way:* the update remains ordinary gradient descent, but the gradient is assembled from spiking-specific pieces: spike error says the direction, surrogate slope says whether the neuron was close enough to threshold to deserve credit, and input magnitude says how much that weight influenced the voltage.

### 7. Comparison, scale, and memory bookkeeping

SNN outputs still often feed losses and hardware budgets. A spike count or voltage score can be compared with softmax, normalized to control scale, and stored over time. The source content's numbers show why these bookkeeping steps are part of the model rather than afterthoughts.

```python
score_w, baseline_w = 1.850, 0.400
exp_score_w = np.exp(score_w)
exp_base_w = np.exp(baseline_w)
prob_w = exp_score_w / (exp_score_w + exp_base_w)
print("exp(score):", round(exp_score_w, 3), "exp(base):", round(exp_base_w, 3))
print("softmax probability:", round(prob_w, 3))
assert round(exp_score_w, 3) == 6.360 and round(exp_base_w, 3) == 1.492 and round(prob_w, 3) == 0.810
```
▶ What you'll see: the spiking-derived score becomes a calibrated comparison probability of about 0.810.

```python
mean_w, var_w, eps_w = 1.000, 0.250, 0.00001
normed_w = (score_w - mean_w) / np.sqrt(var_w + eps_w)
mem_kb_w = 4 * 128 * 4 / 1024
print("normalized value:", round(normed_w, 3))
print("activation memory KB:", round(mem_kb_w, 3))
assert round(normed_w, 3) == 1.700 and round(mem_kb_w, 3) == 2.000
```
▶ What you'll see: the same score is 1.700 standard-deviation units above mean, and a tiny stored activation block uses 2 KB.

```python
plt.figure(figsize=(4.8, 3))
plt.bar(["score", "baseline", "softmax p", "normed"], [score_w, baseline_w, prob_w, normed_w], color=["teal", "gray", "orange", "purple"])
plt.title("7: comparison and scale diagnostics")
plt.ylabel("value")
plt.show()
```
▶ What you'll see: the raw score, probability, and normalized value live on different scales, so each answers a different question.

*Why it's done this way:* a model usually needs relative evidence for a loss, controlled scale for stable gradients, and explicit memory estimates for sequence length and hardware. Spiking sparsity helps, but storing voltage and spike history across time still has a real cost.

### ✍️ Toy 1 · Affine features become input current

A spiking neuron still starts by mixing features into one current value before membrane dynamics begin.

```python
import numpy as np
import matplotlib.pyplot as plt

# Seed a generator even though this hand-built toy is deterministic.
t1_rng = np.random.default_rng(0)

```
▶ What you'll see: the feature contributions plus bias create a positive current of `1.1`.

### ✍️ Toy 2 · Leak lets weak currents accumulate over time

```python
import numpy as np
```

### ✍️ Toy 3 · Threshold firing resets the membrane

When voltage crosses threshold, the neuron emits a spike and the next step starts from reset.

```python
import numpy as np

# Seed a generator even though this hand-built toy is deterministic.
t3_rng = np.random.default_rng(0)
t3_currents = np.full(6, 0.4)                                    # -> [0.4, 0.4, 0.4, 0.4, 0.4, 0.4]
t3_alpha = 0.7                                                    # -> 0.7
t3_tau = 1.0                                                      # -> 1.0
print("currents:", np.round(t3_currents, 3).tolist())             # -> [0.4, 0.4, 0.4, 0.4, 0.4, 0.4]
print("alpha and threshold:", t3_alpha, t3_tau)                  # -> 0.7 1.0
t3_voltages = []                                                  # -> []
t3_spikes = []                                                    # -> []
t3_prev = 0.0                                                     # -> 0.0
for t3_current in t3_currents:
    t3_now = t3_alpha * t3_prev + t3_current
    t3_spike = 1 if t3_now >= t3_tau else 0

print("spikes:", t3_spikes.tolist())                             # -> [0, 0, 0, 1, 0, 0]
assert t3_spikes.tolist() == [0, 0, 0, 1, 0, 0]

plt.figure(figsize=(4.8, 2.8))
plt.plot(t3_voltages, marker="o", color="#54a24b", label="voltage")

```
▶ What you'll see: the fourth time step spikes, then voltage returns to the low reset trajectory.

### ✍️ Toy 4 · Stronger current creates denser spike trains

### ✍️ Toy 5 · Surrogate gradients peak near threshold

The forward spike is hard, but the surrogate gradient gives useful credit to voltages close to threshold.

```python
import numpy as np

# Seed a generator even though this hand-built toy is deterministic.
t5_rng = np.random.default_rng(0)
t5_voltages = np.array([0.6, 0.8, 0.95, 1.0, 1.05, 1.2])          # -> [0.6, 0.8, 0.95, 1.0, 1.05, 1.2]
t5_tau = 1.0                                                      # -> 1.0
t5_slope = 5.0                                                    # -> 5.0
print("voltages:", t5_voltages.tolist())                         # -> [0.6, 0.8, 0.95, 1.0, 1.05, 1.2]

print("hard spikes:", t5_spikes.tolist())                        # -> [0, 0, 0, 1, 1, 1]
t5_distance = np.abs(t5_voltages - t5_tau)                        # -> [0.4, 0.2, 0.05, 0.0, 0.05, 0.2]

assert int(np.argmax(t5_surrogate)) == 3

plt.figure(figsize=(4.8, 2.8))
plt.plot(t5_voltages, t5_spikes, marker="o", label="hard spike", color="black")
plt.plot(t5_voltages, t5_surrogate, marker="s", label="surrogate", color="#e45756")
plt.xlabel("voltage")
plt.ylabel("value")
plt.title("Toy 5 · learning signal near threshold")
plt.legend()
plt.show()
```
▶ What you'll see: the surrogate curve is largest exactly at voltage `1.0`, where the hard spike jumps.

### ✍️ Toy 6 · Spike error times surrogate slope updates a weight

A local SNN gradient multiplies spike error, surrogate slope, and the input that affected voltage.

```python
import numpy as np

# Seed a generator even though this hand-built toy is deterministic.
```

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, recurrences, random currents, and numerical checks.
import matplotlib.pyplot as plt # load Matplotlib for voltage traces, spike rasters, and training diagnostics.
np.random.seed(0) # make all random examples reproducible across notebook runs.

def lif_run(currents, alpha=0.8, tau=1.0, reset=0.0): # simulate one leaky integrate-and-fire neuron.
    currents = np.asarray(currents, dtype=float) # convert the input current sequence to a float array.
    voltages = np.zeros_like(currents) # store pre-reset membrane voltage at each time step.
    spikes = np.zeros_like(currents) # store binary threshold events at each time step.
    v_prev = 0.0 # start with no stored charge.
    for t, current in enumerate(currents): # step through time in order.
        v_now = alpha * v_prev + current # leak old voltage and add the new input current.
        spike = 1.0 if v_now >= tau else 0.0 # emit an event when the voltage crosses threshold.
        voltages[t] = v_now # record the voltage before any reset.
        spikes[t] = spike # record the binary communication event.
        v_prev = reset if spike else v_now # reset after a spike; otherwise keep the current voltage.
    return voltages, spikes # return both analog state and event train.

def surrogate_slope(v, tau=1.0, scale=10.0): # define a peaked pseudo-derivative around threshold.
    return 1.0 / (1.0 + scale * np.abs(np.asarray(v) - tau)) ** 2 # large near tau, small far away.

def softmax2(a, b): # compute a two-score softmax probability safely for small lesson examples.
    ea, eb = np.exp(a), np.exp(b) # exponentiate both comparison scores.
    return float(ea / (ea + eb)) # normalize the first score by the total evidence.
```
