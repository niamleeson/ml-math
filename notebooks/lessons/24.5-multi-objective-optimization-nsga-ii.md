# 24.5 — Multi-Objective Optimization (NSGA-II)

NSGA-II searches for a diverse Pareto front instead of pretending there is only one objective. In this lesson, we build dominance, non-dominated sorting, crowding distance, and a tiny NSGA-II loop from scratch so the tradeoff surface is visible in objective space.

This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

### 1. Conflicting objectives create a partial order, not one winner

Multi-objective optimization starts when goals honestly conflict: a model may be accurate but slow, or fast but inaccurate. If we minimize two objectives, such as error and latency, we should not collapse them into one arbitrary score before seeing the tradeoff. A candidate is clearly worse only when another candidate is no worse on every objective and strictly better on at least one.

```python
F_w = np.array([[1., 5.], [2., 3.], [3., 2.], [5., 1.], [3., 4.], [4., 3.]])  # objective pairs to minimize.
labels_w = ["A", "B", "C", "D", "E", "F"]  # readable candidate names.
print("objectives [error, latency]:\n", F_w)  # inspect the tradeoff table.

def dominates_w(a, b):  # True if a Pareto-dominates b for minimization.
    return bool(np.all(a <= b) and np.any(a < b))  # no worse in all objectives and better in at least one.

for i_w, name_w in enumerate(labels_w):  # list who dominates whom.
    dominated_by_w = [labels_w[j_w] for j_w in range(len(F_w)) if dominates_w(F_w[j_w], F_w[i_w])]
    print(name_w, "dominated by", dominated_by_w if dominated_by_w else "nobody")  # show the partial order.

plt.figure(figsize=(4.6, 3.6))  # create objective-space scatter.
plt.scatter(F_w[:, 0], F_w[:, 1], s=90, color="steelblue")  # plot candidates in objective space.
for i_w, name_w in enumerate(labels_w):  # annotate each candidate.
    plt.text(F_w[i_w, 0] + 0.05, F_w[i_w, 1] + 0.05, name_w)  # place label near point.
plt.xlabel("objective 1: error (minimize)")  # label first objective.
plt.ylabel("objective 2: latency (minimize)")  # label second objective.
plt.title("1: tradeoffs form a partial order")  # title the plot.
plt.gca().invert_yaxis()  # lower latency should visually appear better.
plt.show()  # display the relevant objective-space visualization.
```
▶ What you'll see: some points are clearly dominated, but several alternatives remain incomparable because each wins on a different objective.

*Why it's done this way:* Pareto dominance preserves tradeoffs that a weighted sum might hide; it only removes candidates that are unambiguously worse.

### 2. The first Pareto front is the set nobody dominates

The first front contains all candidates with domination count zero. These are not all equally useful forever, but none can be discarded by dominance alone. In the lesson points, $(3,4)$ is dominated by $(2,3)$, and $(4,3)$ is dominated by $(3,2)$, leaving a four-point efficient frontier.

```python
n_w = len(F_w)  # number of candidates.
dom_count_w = np.zeros(n_w, dtype=int)  # how many candidates dominate each point.
dominates_list_w = [[] for _ in range(n_w)]  # which points each candidate dominates.
for p_w in range(n_w):  # compare every ordered pair.
    for q_w in range(n_w):  # q is the possible dominated point.
        if not p_w == q_w and dominates_w(F_w[p_w], F_w[q_w]):  # test Pareto dominance.
            dominates_list_w[p_w].append(q_w)  # record p dominates q.
            dom_count_w[q_w] += 1  # increment q's domination count.
front1_w = np.where(dom_count_w == 0)[0]  # first front = candidates dominated by nobody.
print("domination counts:", dict(zip(labels_w, dom_count_w)))  # inspect counts.
print("front 1:", [labels_w[i_w] for i_w in front1_w])  # inspect non-dominated set.
assert [labels_w[i_w] for i_w in front1_w] == ["A", "B", "C", "D"]  # verify lesson front.

is_front_w = np.zeros(n_w, dtype=bool)  # mark first-front points.
is_front_w[front1_w] = True  # mark non-dominated candidates.
plt.figure(figsize=(4.6, 3.6))  # create front plot.

plt.scatter(F_w[is_front_w, 0], F_w[is_front_w, 1], s=110, color="seagreen", label="front 1")  # front points.

    plt.text(F_w[i_w, 0] + 0.05, F_w[i_w, 1] + 0.05, name_w)  # label candidate.
plt.plot(F_w[front1_w, 0], F_w[front1_w, 1], color="seagreen", alpha=0.5)  # connect front visually.
plt.xlabel("objective 1")  # label x-axis.
plt.ylabel("objective 2")  # label y-axis.

plt.legend()  # show meaning of colors.
plt.gca().invert_yaxis()  # lower objective values are better.
plt.show()  # display the Pareto front visualization.
```
▶ What you'll see: A, B, C, and D form the first front; E and F sit behind it because better points exist.

*Why it's done this way:* the first front is a dominance-based survivor pool that keeps efficient alternatives without requiring a premature objective weight.

### 3. Fast non-dominated sorting peels fronts by rank

NSGA-II does not stop after the first front. It assigns rank 0 to non-dominated points, removes them conceptually, then reveals the next non-dominated layer. This creates a scalar rank from a partial order: lower rank is always preferred, and ties inside a rank are handled later by crowding distance.

```python
def fast_non_dominated_sort_w(F):  # implement NSGA-II sorting for minimization.
    n = len(F)  # number of candidates.
    S = [[] for _ in range(n)]  # S[p] = points dominated by p.
    count = np.zeros(n, dtype=int)  # count[p] = number of points dominating p.
    fronts = [[]]  # first front starts empty.
    for p in range(n):  # compare p to everyone.
        for q in range(n):  # compare q to p.
            if p == q:  # skip self-comparison.
                continue  # no candidate dominates itself.
            if np.all(F[p] <= F[q]) and np.any(F[p] < F[q]):  # p dominates q.
                S[p].append(q)  # remember that q depends on p being removed.
            elif np.all(F[q] <= F[p]) and np.any(F[q] < F[p]):  # q dominates p.
                count[p] += 1  # p has one more dominator.
        if count[p] == 0:  # p is non-dominated in the full set.
            fronts[0].append(p)  # add p to the first front.
    rank = np.full(n, -1, dtype=int)  # store front rank for each candidate.
    i = 0  # current front index.
    while fronts[i]:  # peel layers until no candidates remain.
        next_front = []  # candidates unlocked by removing this front.
        for p in fronts[i]:  # each current-front candidate.
            rank[p] = i  # assign its rank.
            for q in S[p]:  # decrease domination counts for points p dominated.
                count[q] -= 1  # one dominator has been removed.
                if count[q] == 0:  # q is now non-dominated among remaining points.
                    next_front.append(q)  # move q to the next front.
        i += 1  # advance to next rank.
        fronts.append(next_front)  # store next layer.
    return fronts[:-1], rank  # drop the final empty front.

fronts_w, rank_w = fast_non_dominated_sort_w(F_w)  # sort the lesson points.
print("fronts:", [[labels_w[i] for i in fr] for fr in fronts_w])  # inspect front layers.
print("ranks:", dict(zip(labels_w, rank_w)))  # inspect each candidate's rank.
assert np.array_equal(rank_w, np.array([0, 0, 0, 0, 1, 1]))  # verify expected ranks.

plt.figure(figsize=(4.8, 3.6))  # create rank visualization.
for r_w in np.unique(rank_w):  # draw one color per rank.
    idx_w = np.where(rank_w == r_w)[0]  # candidates in this rank.
    plt.scatter(F_w[idx_w, 0], F_w[idx_w, 1], s=110, label=f"rank {r_w}")  # plot rank group.
for i_w, name_w in enumerate(labels_w):  # label all points.
    plt.text(F_w[i_w, 0] + 0.05, F_w[i_w, 1] + 0.05, name_w)  # add label.
plt.xlabel("objective 1")  # label x-axis.
plt.ylabel("objective 2")  # label y-axis.
plt.title("3: non-dominated sorting ranks")  # title plot.
plt.legend()  # show ranks.
plt.gca().invert_yaxis()  # lower values are better.
plt.show()  # display rank-colored objective plot.
```
▶ What you'll see: front 0 contains efficient alternatives, while dominated points move to rank 1.

*Why it's done this way:* rank converts a Pareto partial order into selection layers while still refusing to choose a single scalar champion within each layer.

### 4. Crowding distance protects spread along a front

Rank alone can keep many nearly identical non-dominated points. NSGA-II therefore estimates how isolated each point is inside its front. For each objective, it sorts the front, gives boundary points infinite distance, and adds the normalized gap between each point's two neighbors. Large crowding distance means the point preserves an underrepresented region of the tradeoff surface.

```python
def crowding_distance_w(F, front):  # compute NSGA-II crowding distance for one front.
    front = np.asarray(front, dtype=int)  # make front indices an array.
    m = F.shape[1]  # number of objectives.
    dist = np.zeros(len(front), dtype=float)  # distance per point within the front.
    if len(front) <= 2:  # boundaries are all points if the front is tiny.
        dist[:] = np.inf  # protect endpoints.
        return dist  # done.
    for j in range(m):  # accumulate normalized gaps objective by objective.
        values = F[front, j]  # objective values for this front.
        order = np.argsort(values)  # sort from best/smallest to worst/largest.
        dist[order[0]] = np.inf  # preserve one boundary.
        dist[order[-1]] = np.inf  # preserve the other boundary.
        span = values[order[-1]] - values[order[0]]  # normalization range.
        if span == 0:  # identical objective values add no crowding signal.
            continue  # avoid divide-by-zero.
        for k in range(1, len(front) - 1):  # interior points only.
            dist[order[k]] += (values[order[k + 1]] - values[order[k - 1]]) / span  # normalized neighbor gap.
    return dist  # crowding distances aligned with front order.

cd_w = crowding_distance_w(F_w, front1_w)  # compute front-1 crowding distances.
print("front points:", [labels_w[i] for i in front1_w])  # list points.
print("crowding distances:", cd_w)  # inspect infinity endpoints and interior distances.
assert np.isinf(cd_w[0]) and np.isinf(cd_w[-1])  # endpoints are protected.
assert np.allclose(cd_w[1:3], [1.25, 1.25])  # verify lesson crowding calculation.

finite_cd_w = np.where(np.isinf(cd_w), 1.55, cd_w)  # finite bar heights for plotting infinities.
plt.figure(figsize=(4.8, 3.2))  # create crowding bar chart.
plt.bar([labels_w[i] for i in front1_w], finite_cd_w, color="darkorange")  # draw distances.
plt.ylabel("crowding distance (∞ clipped for plot)")  # label y-axis.
plt.title("4: crowding protects front spread")  # title plot.
plt.show()  # display the crowding visualization.
```
▶ What you'll see: boundary points are protected, while interior B and C each receive crowding distance 1.25.

*Why it's done this way:* diversity pressure prevents selection from collapsing to a crowded corner of the same Pareto front.

### 5. Binary tournament selection prefers rank, then crowding

NSGA-II chooses parents by tournament. Between two candidates, lower rank wins. If ranks tie, the less crowded candidate wins. This rule says convergence toward the front comes first, but diversity decides among equally ranked alternatives.

```python
cd_all_w = np.zeros(len(F_w), dtype=float)  # crowding distance for every candidate.
for fr_w in fronts_w:  # compute crowding within each front.
    cd_all_w[fr_w] = crowding_distance_w(F_w, fr_w)  # store distances aligned to original indices.

def tournament_better_w(i, j):  # deterministic comparison used inside stochastic tournaments.
    if rank_w[i] < rank_w[j]:  # lower rank is better.
        return i  # candidate i wins.
    if rank_w[j] < rank_w[i]:  # lower rank is better.
        return j  # candidate j wins.
    if cd_all_w[i] > cd_all_w[j]:  # when ranks tie, larger crowding is better.
        return i  # i is less crowded.
    return j  # otherwise j wins.

pairs_w = [(0, 4), (1, 2), (4, 5)]  # sample tournaments.
winners_w = [tournament_better_w(i, j) for i, j in pairs_w]  # run comparisons.
print("ranks:", rank_w)  # inspect ranks.
print("crowding:", cd_all_w)  # inspect crowding values.
print("winners:", [labels_w[i] for i in winners_w])  # inspect tournament winners.
assert winners_w[0] == 0 and winners_w[1] == 2  # rank beats dominated, then tie uses crowding/tie rule.

plt.figure(figsize=(4.8, 3.4))  # create tournament diagnostic plot.
plt.scatter(rank_w, np.where(np.isinf(cd_all_w), 1.6, cd_all_w), s=100, color="purple")  # rank vs crowding.
for i_w, name_w in enumerate(labels_w):  # label candidates.
    plt.text(rank_w[i_w] + 0.02, np.where(np.isinf(cd_all_w[i_w]), 1.6, cd_all_w[i_w]) + 0.03, name_w)  # annotate point.
plt.xlabel("rank (lower wins first)")  # label rank axis.
plt.ylabel("crowding (higher wins within rank)")  # label crowding axis.
plt.title("5: tournament preference rule")  # title plot.
plt.show()  # display rank-crowding visualization.
```
▶ What you'll see: dominated candidates lose to rank-0 candidates, and ties among rank-0 candidates favor more isolated points.

*Why it's done this way:* selection needs one ordering for reproduction, but NSGA-II builds it from Pareto rank first and diversity second.

### 6. Genetic operators still create the candidate pool

NSGA-II changes survivor ranking, not the fact that evolution needs variation. We still select parents, recombine them, mutate the child, and evaluate objectives. The difference is that the child is judged by dominance and crowding instead of one scalar fitness.

```python
rng_w = np.random.default_rng(2)  # local random generator.
parents_x_w = np.array([-1.8, 0.4])  # two parent decision variables.
alpha_w = 0.35  # arithmetic crossover weight.
child_x_w = alpha_w * parents_x_w[0] + (1 - alpha_w) * parents_x_w[1]  # blend parents.
mutated_x_w = child_x_w + rng_w.normal(0, 0.25)  # add Gaussian mutation.
mutated_x_w = float(np.clip(mutated_x_w, -3, 3))  # keep child inside the search interval.

def objectives_w(x):  # two conflicting minimization objectives.
    return np.array([(x + 1.0) ** 2, (x - 1.0) ** 2])  # left objective likes x=-1, right objective likes x=1.

parent_F_w = np.vstack([objectives_w(x) for x in parents_x_w])  # evaluate parents.
child_F_w = objectives_w(mutated_x_w)  # evaluate child.
print("parents x:", parents_x_w, "child x:", round(mutated_x_w, 3))  # inspect decision variables.
print("parent objectives:\n", np.round(parent_F_w, 3))  # inspect parent tradeoffs.
print("child objectives:", np.round(child_F_w, 3))  # inspect child tradeoff.

x_grid_w = np.linspace(-3, 3, 200)  # dense decision grid for objective-space curve.
curve_w = np.vstack([objectives_w(x) for x in x_grid_w])  # evaluate tradeoff curve.
plt.figure(figsize=(4.8, 3.6))  # create objective-space plot.
plt.plot(curve_w[:, 0], curve_w[:, 1], color="lightgray", label="search curve")  # show possible tradeoffs.
plt.scatter(parent_F_w[:, 0], parent_F_w[:, 1], s=100, color="steelblue", label="parents")  # parent objectives.
plt.scatter(child_F_w[0], child_F_w[1], s=120, color="crimson", label="mutated child")  # child objective.
plt.xlabel("f1(x) = (x+1)^2")  # label first objective.
plt.ylabel("f2(x) = (x-1)^2")  # label second objective.
plt.title("6: variation creates new tradeoffs")  # title plot.
plt.legend()  # show labels.
plt.show()  # display relevant child objective visualization.
```
▶ What you'll see: crossover and mutation move a child to a new place on the objective tradeoff curve.

*Why it's done this way:* variation explores the decision space, while non-dominated sorting decides which explored tradeoffs survive.

### 7. Elitist survivor selection builds a well-spaced coastline

Each generation combines parents and children, sorts the combined pool, and fills the next population by taking whole fronts until a front does not fit. The partial front is then trimmed by highest crowding distance. This elitism keeps the best discovered tradeoffs while preserving spread.

```python
combined_F_w = np.array([[0.1, 4.2], [0.4, 2.8], [0.9, 1.6], [1.8, 0.8], [3.4, 0.2], [0.5, 3.1], [1.0, 1.9], [2.2, 0.7]])  # parent+child pool.
fronts2_w, rank2_w = fast_non_dominated_sort_w(combined_F_w)  # sort the combined pool.
N_w = 5  # desired next population size.
selected_w = []  # survivor indices.
for fr_w in fronts2_w:  # fill with fronts in order.
    if len(selected_w) + len(fr_w) <= N_w:  # whole front fits.
        selected_w.extend(fr_w)  # keep all of it.
    else:  # this front must be trimmed.
        cd_w2 = crowding_distance_w(combined_F_w, fr_w)  # compute diversity inside the split front.
        order_w2 = np.argsort(-cd_w2)  # largest crowding first.
        selected_w.extend([fr_w[i] for i in order_w2[:N_w - len(selected_w)]])  # keep least crowded points.
        break  # population is full.
selected_w = np.array(selected_w, dtype=int)  # convert to array.
print("fronts:", fronts2_w)  # inspect sorted layers.
print("selected survivors:", selected_w.tolist())  # inspect survivors.
assert len(selected_w) == N_w  # verify population size.

plt.figure(figsize=(4.8, 3.6))  # create survivor plot.
plt.scatter(combined_F_w[:, 0], combined_F_w[:, 1], s=70, color="lightgray", label="combined pool")  # all candidates.
plt.scatter(combined_F_w[selected_w, 0], combined_F_w[selected_w, 1], s=120, color="seagreen", label="survivors")  # selected candidates.
for i_w in range(len(combined_F_w)):  # annotate indices.
    plt.text(combined_F_w[i_w, 0] + 0.03, combined_F_w[i_w, 1] + 0.03, str(i_w))  # label point.
plt.xlabel("objective 1")  # label x-axis.
plt.ylabel("objective 2")  # label y-axis.
plt.title("7: elitist NSGA-II survivor selection")  # title plot.
plt.legend()  # show selected vs pool.
plt.gca().invert_yaxis()  # lower objective values are better.
plt.show()  # display survivor selection visualization.
```
▶ What you'll see: survivors lie on the better layers and remain spread across the objective-space coastline.

*Why it's done this way:* elitism prevents losing good tradeoffs, and crowding chooses a useful menu rather than duplicate near-neighbors.


## 🛠️ Setup

```python
import numpy as np  # load NumPy for vectors, objectives, sorting, and simulation.
import matplotlib.pyplot as plt  # load Matplotlib for Pareto-front and evolution visualizations.
np.random.seed(0)  # make the lesson deterministic when examples use NumPy's global RNG.

def dominates(a, b):  # Return True when objective vector a Pareto-dominates b for minimization.
    a = np.asarray(a, dtype=float)  # Ensure numeric array input.
    b = np.asarray(b, dtype=float)  # Ensure numeric array input.
    return bool(np.all(a <= b) and np.any(a < b))  # No worse on all objectives and better on at least one.

def fast_non_dominated_sort(F):  # Implement NSGA-II fast non-dominated sorting from scratch.
    F = np.asarray(F, dtype=float)  # Convert objective table to floats.
    n = len(F)  # Count candidates.
    dominates_sets = [[] for _ in range(n)]  # Store candidates dominated by each candidate.
    domination_counts = np.zeros(n, dtype=int)  # Store how many candidates dominate each candidate.
    fronts = [[]]  # Start the first front.
    for p in range(n):  # Compare every candidate p.
        for q in range(n):  # Against every candidate q.
            if p == q:  # Skip self-comparison.
                continue  # A point does not dominate itself.
            if dominates(F[p], F[q]):  # p dominates q.
                dominates_sets[p].append(q)  # q waits for p to be removed.
            elif dominates(F[q], F[p]):  # q dominates p.
                domination_counts[p] += 1  # p has one more dominator.
        if domination_counts[p] == 0:  # p is in the first front.
            fronts[0].append(p)  # Add p to front 0.
    rank = np.full(n, -1, dtype=int)  # Prepare rank output.
    i = 0  # Current front index.
    while fronts[i]:  # Continue until no candidates remain.
        next_front = []  # Candidates for the next layer.
        for p in fronts[i]:  # Remove each current-front candidate.
            rank[p] = i  # Assign p's rank.
            for q in dominates_sets[p]:  # Visit candidates p dominated.
                domination_counts[q] -= 1  # Remove p as one dominator.
                if domination_counts[q] == 0:  # q has become non-dominated.
                    next_front.append(q)  # Place q in the next front.
        i += 1  # Move to next rank.
        fronts.append(next_front)  # Store the next front.
    return fronts[:-1], rank  # Return all nonempty fronts and ranks.

def crowding_distance(F, front):  # Compute NSGA-II crowding distance for one front.
    F = np.asarray(F, dtype=float)  # Convert objective table.
    front = np.asarray(front, dtype=int)  # Convert front indices.
    distance = np.zeros(len(front), dtype=float)  # One distance per front member.
    if len(front) == 0:  # Empty front guard.
        return distance  # Nothing to compute.
    if len(front) <= 2:  # A one- or two-point front has only boundaries.
        distance[:] = np.inf  # Protect all boundary points.
        return distance  # Return boundary distances.
    for m in range(F.shape[1]):  # Accumulate contribution from each objective.
        values = F[front, m]  # Objective m values within this front.
        order = np.argsort(values)  # Sort by this objective.
        distance[order[0]] = np.inf  # Protect low boundary.
        distance[order[-1]] = np.inf  # Protect high boundary.
        span = values[order[-1]] - values[order[0]]  # Objective range for normalization.
        if span == 0:  # If all values tie, this objective adds nothing.
            continue  # Avoid dividing by zero.
        for k in range(1, len(front) - 1):  # Interior points receive normalized neighbor gaps.
            distance[order[k]] += (values[order[k + 1]] - values[order[k - 1]]) / span  # Add crowding contribution.
    return distance  # Return distances aligned with the front order.

def rank_and_crowding(F):  # Convenience helper to compute rank and crowding for all candidates.
    fronts, rank = fast_non_dominated_sort(F)  # Sort fronts first.
    crowd = np.zeros(len(F), dtype=float)  # Prepare global crowding array.
    for front in fronts:  # Process each front independently.
        crowd[np.asarray(front, dtype=int)] = crowding_distance(F, front)  # Store front-local distances.
    return fronts, rank, crowd  # Return all selection metadata.

def two_objectives(x):  # Define a simple conflicting minimization problem over one decision variable.
    x = np.asarray(x, dtype=float)  # Accept scalar or vector input.
    return np.column_stack(((x + 1.0) ** 2, (x - 1.0) ** 2))  # f1 prefers -1, f2 prefers +1.

def make_children(pop, rng, sigma=0.18):  # Create children with arithmetic crossover and Gaussian mutation.
    children = []  # Store child decision variables.
    for _ in range(len(pop)):  # Make one child per parent.
        i, j = rng.integers(0, len(pop), size=2)  # Choose two parents.
        alpha = rng.random()  # Random blend weight.
        child = alpha * pop[i] + (1 - alpha) * pop[j] + rng.normal(0, sigma)  # Crossover plus mutation.
        children.append(float(np.clip(child, -3.0, 3.0)))  # Keep inside bounds.
    return np.array(children)  # Return child population.

def nsga2_step(pop, rng, sigma=0.18):  # Run one elitist NSGA-II generation.
    children = make_children(pop, rng, sigma=sigma)  # Generate offspring.
    combined = np.concatenate([pop, children])  # Combine parents and children.
    F = two_objectives(combined)  # Evaluate both objectives.
    fronts, rank, crowd = rank_and_crowding(F)  # Rank and crowd the combined pool.
    selected = []  # Store survivor indices.
    N = len(pop)  # Target population size.
    for front in fronts:  # Fill survivors by front order.
        if len(selected) + len(front) <= N:  # Whole front fits.
            selected.extend(front)  # Keep every member.
        else:  # Need to split this front.
            cd = crowding_distance(F, front)  # Compute distances inside the split front.
            order = np.argsort(-cd)  # Highest crowding first.
            selected.extend([front[i] for i in order[:N - len(selected)]])  # Keep least crowded needed members.
            break  # Population is full.
```

#### E5. Measure hypervolume for two approximate fronts

```python
def hypervolume_2d_min(points, ref):  # Compute 2-D hypervolume for non-dominated minimization points.
    pts = np.asarray(points, dtype=float)  # Convert points.
    order = np.argsort(pts[:, 0])  # Sort by objective 1 ascending.
    hv = 0.0  # Accumulate area.
    prev_y = ref[1]  # Current top boundary in objective 2.
    for idx in order:  # Sweep from low f1 to high f1.
        x, y = pts[idx]  # Current objective pair.
        width = max(ref[0] - x, 0.0)  # Width to reference x.
        height = max(prev_y - y, 0.0)  # New non-overlapping height.
        hv += width * height  # Add rectangle area.
        prev_y = min(prev_y, y)  # Update best y boundary.
    return float(hv)  # Return hypervolume.

hv_good_e5 = hypervolume_2d_min(front_good_e5, ref_e5)  # Hypervolume for better front.
hv_bad_e5 = hypervolume_2d_min(front_bad_e5, ref_e5)  # Hypervolume for worse front.
print("hypervolumes:", round(hv_good_e5, 3), round(hv_bad_e5, 3))  # Inspect values.
assert hv_good_e5 > hv_bad_e5  # Better front dominates more area.
```
