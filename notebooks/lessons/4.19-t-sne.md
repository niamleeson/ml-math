# 4.19 — t-SNE

t-SNE turns a high-dimensional cloud into a two-dimensional map by preserving **local neighbor probabilities**, not by preserving every distance. In this lesson, you will build the pieces from scratch with NumPy: squared distances, Gaussian high-dimensional affinities, normalized influence weights, Student-t low-dimensional affinities, and the KL-divergence gradient that moves nearby points together while pushing mismatched impostors apart.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build t-SNE one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math is made inspectable, so the embedding is a consequence of probabilities and gradients rather than a black box. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, pairwise distances, probability normalization, and gradient updates.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for toy data and initialization.
```

### 1. Distances are the raw material

t-SNE begins with geometry. Before it can say which points should stay close, it must compute pairwise squared Euclidean distances in the original feature space. Squared distances matter because the Gaussian kernel uses $\exp(-d^2/2h^2)$: a point twice as far is not merely half as influential; its influence decays exponentially.

```python
X_w = np.array([[0.0, 0.0, 0.1],
                [0.2, 0.1, 0.0],
                [3.0, 3.1, 3.0],
                [3.2, 2.9, 3.1],
                [0.1, 3.0, 0.2]])  # five points in 3 measured coordinates.
labels_w = np.array([0, 0, 1, 1, 2])  # only for coloring; t-SNE itself does not use labels.
print("X shape:", X_w.shape)
print("first two points:\n", X_w[:2])
```
▶ What you'll see: a 5×3 matrix, with two nearby low-valued points, two nearby high-valued points, and one off-axis point.

```python
diff_w = X_w[:, None, :] - X_w[None, :, :]  # all pairwise coordinate differences.
D2_w = np.sum(diff_w ** 2, axis=2)  # squared Euclidean distance matrix.
print("squared distances:\n", np.round(D2_w, 3))
assert D2_w.shape == (5, 5)
assert round(float(D2_w[0, 1]), 3) == 0.060
```
▶ What you'll see: the diagonal is zero, point 0 is very close to point 1, and points from different groups have much larger distances.

```python
plt.figure(figsize=(4.2, 3.4))
plt.imshow(D2_w, cmap="magma")
plt.colorbar(label="squared distance")
plt.title("1: high-dimensional squared distances")
plt.xlabel("point j")
plt.ylabel("point i")
plt.show()
```
▶ What you'll see: dark diagonal blocks reveal local neighborhoods before any embedding exists.

*Why it's done this way:* the distance matrix is the only geometric evidence t-SNE receives. Squaring pairs naturally with the Gaussian density formula and exaggerates large separations, so local neighbors can dominate the probability normalization instead of being washed out by faraway points.

### 2. Gaussian affinities become neighbor probabilities

A distance alone is not yet a t-SNE target. For each anchor point $i$, t-SNE converts distances to unnormalized weights $\exp(-d_{ij}^2/2h^2)$ and then normalizes the row so the weights sum to 1. The result $p_{j|i}$ is a probability distribution over neighbors: it says where point $i$ places its local attention.

```python
h_w = 1.0  # locality scale for this first pass.
weights0_w = np.exp(-D2_w[0] / (2 * h_w ** 2))  # Gaussian weights from point 0 to every point.
weights0_w[0] = 0.0  # t-SNE excludes self-neighbor probability.
print("raw weights from point 0:", np.round(weights0_w, 3))
assert round(float(np.exp(-0.06 / 2)), 3) == 0.970
```
▶ What you'll see: point 1 gets weight about 0.970 while far points are almost zero.

```python
p0_w = weights0_w / weights0_w.sum()  # normalize into a probability row.
print("p(j | 0):", np.round(p0_w, 3))
print("row sum:", round(float(p0_w.sum()), 6))
assert round(float(p0_w[1]), 3) == 0.989
assert np.isclose(p0_w.sum(), 1.0)
```
▶ What you'll see: almost all probability mass from point 0 lands on point 1.

```python
P_cond_w = np.zeros_like(D2_w)  # conditional probabilities p(j|i).
for i_w in range(len(X_w)):
    row_w = np.exp(-D2_w[i_w] / (2 * h_w ** 2))
    row_w[i_w] = 0.0
    P_cond_w[i_w] = row_w / row_w.sum()
print("conditional P rows sum to:", np.round(P_cond_w.sum(axis=1), 6))
```
▶ What you'll see: every row sums to 1, so each point owns its own local probability distribution.

```python
plt.figure(figsize=(4.2, 3.4))
plt.imshow(P_cond_w, cmap="viridis")
plt.colorbar(label="p(j | i)")
plt.title("2: conditional neighbor probabilities")
plt.xlabel("neighbor j")
plt.ylabel("anchor i")
plt.show()
```
▶ What you'll see: each row highlights the neighbors that receive influence from that anchor.

*Why it's done this way:* normalization turns arbitrary distance-based scores into a fair competition among candidate neighbors. That is the math behind the lesson's core formula: the numerator measures local influence, while the denominator makes the influences comparable as probabilities.

### 3. The bandwidth controls locality and perplexity

The scale $h$ decides what counts as nearby. A tiny $h$ makes only the closest point matter; a large $h$ spreads influence across many points. t-SNE usually chooses a separate bandwidth per point to match a target perplexity, but the core idea is already visible by sweeping $h$ and measuring the effective number of neighbors.

```python
def entropy_bits_w(p_w):
    p_w = p_w[p_w > 0]
    return float(-np.sum(p_w * np.log2(p_w)))

def perplexity_w(p_w):
    return 2 ** entropy_bits_w(p_w)

for h_try_w in [0.25, 1.0, 3.0]:
    row_w = np.exp(-D2_w[0] / (2 * h_try_w ** 2))
    row_w[0] = 0.0
    prob_w = row_w / row_w.sum()
    print("h=", h_try_w, "p(j|0)=", np.round(prob_w, 3), "perplexity=", round(perplexity_w(prob_w), 3))
```
▶ What you'll see: small bandwidth gives nearly one effective neighbor; large bandwidth spreads mass over several neighbors.

```python
h_grid_w = np.linspace(0.2, 4.0, 60)
perps_w = []
for h_try_w in h_grid_w:
    row_w = np.exp(-D2_w[0] / (2 * h_try_w ** 2))
    row_w[0] = 0.0
    prob_w = row_w / row_w.sum()
    perps_w.append(perplexity_w(prob_w))
print("perplexity range:", round(min(perps_w), 3), "to", round(max(perps_w), 3))
assert min(perps_w) >= 1.0
```
▶ What you'll see: the effective neighbor count increases smoothly as the bandwidth widens.

```python
plt.figure(figsize=(4.4, 3))
plt.plot(h_grid_w, perps_w, color="purple")
plt.axhline(2, color="gray", linestyle="--", label="2 effective neighbors")
plt.xlabel("bandwidth h")
plt.ylabel("perplexity")
plt.title("3: h controls effective neighborhood size")
plt.legend()
plt.show()
```
▶ What you'll see: a monotone curve; the same distances become local or broad depending on $h$.

*Why it's done this way:* perplexity is $2^{\text{entropy}}$, so it translates a probability distribution into an intuitive effective-neighbor count. Choosing bandwidth through perplexity prevents dense regions from becoming too crowded and sparse regions from becoming too isolated.

### 4. Symmetric high-dimensional targets

The conditional probabilities $p_{j|i}$ are directional: point $i$ can consider $j$ important even if $j$ has other closer neighbors. The common t-SNE objective uses a symmetric joint probability $P_{ij}=(p_{j|i}+p_{i|j})/(2n)$ so every unordered pair contributes one comparable attraction target.

```python
n_w = len(X_w)
P_joint_w = (P_cond_w + P_cond_w.T) / (2 * n_w)  # symmetric pair probabilities.
np.fill_diagonal(P_joint_w, 0.0)
print("P symmetric?", np.allclose(P_joint_w, P_joint_w.T))
print("P sum:", round(float(P_joint_w.sum()), 6))
assert np.allclose(P_joint_w, P_joint_w.T)
assert np.isclose(P_joint_w.sum(), 1.0)
```
▶ What you'll see: the joint matrix is symmetric and sums to 1 across all ordered off-diagonal pairs.

```python
pairs_w = [(0, 1), (0, 2), (2, 3), (0, 4)]
for i_w, j_w in pairs_w:
    print(f"P[{i_w},{j_w}] =", round(float(P_joint_w[i_w, j_w]), 4))
```
▶ What you'll see: close pairs such as (0,1) and (2,3) have much larger target probabilities than far pairs.

```python
plt.figure(figsize=(4.2, 3.4))
plt.imshow(P_joint_w, cmap="viridis")
plt.colorbar(label="P_ij")
plt.title("4: symmetric high-dimensional target P")
plt.xlabel("point j")
plt.ylabel("point i")
plt.show()
```
▶ What you'll see: bright symmetric entries mark pairs the embedding should keep close.

*Why it's done this way:* the KL objective compares one global pair distribution $P$ with one low-dimensional pair distribution $Q$. Symmetrizing removes directional bookkeeping and the division by $2n$ makes the whole matrix a probability distribution, so no point's row can dominate merely by having been normalized separately.

### 5. Student-t affinities in the map

In the two-dimensional map, t-SNE uses a heavy-tailed Student-t kernel: $q_{ij}\propto(1+\lVert y_i-y_j\rVert^2)^{-1}$. The heavy tail is deliberate. It lets moderately far low-dimensional points still exert repulsion, which helps fight the crowding problem that appears when many high-dimensional neighbors must fit into a small 2-D plot.

```python
rng_w = np.random.default_rng(0)
Y_w = 0.01 * rng_w.normal(size=(n_w, 2))  # tiny random 2-D initialization.
print("initial Y:\n", np.round(Y_w, 4))
assert Y_w.shape == (5, 2)
```
▶ What you'll see: all embedded points start near the origin, before probabilities push them apart.

```python
def q_distribution_w(Y_in_w):
    dY_w = Y_in_w[:, None, :] - Y_in_w[None, :, :]
    dist2_w = np.sum(dY_w ** 2, axis=2)
    num_w = 1 / (1 + dist2_w)
    np.fill_diagonal(num_w, 0.0)
    Q_w = num_w / num_w.sum()
    return Q_w, num_w, dist2_w

Q_w, num_w, DY2_w = q_distribution_w(Y_w)
print("Q sum:", round(float(Q_w.sum()), 6))
print("Q first row:", np.round(Q_w[0], 4))
assert np.isclose(Q_w.sum(), 1.0)
```
▶ What you'll see: because the initial points are all close together, low-dimensional probabilities start almost uniform.

```python
plt.figure(figsize=(4.2, 3.4))
plt.imshow(Q_w, cmap="viridis")
plt.colorbar(label="Q_ij")
plt.title("5: low-dimensional probability Q at initialization")
plt.xlabel("point j")
plt.ylabel("point i")
plt.show()
```
▶ What you'll see: the map does not yet match the bright local structure in $P$.

*Why it's done this way:* a Gaussian in the low-dimensional map would make far points almost stop interacting. The Student-t denominator decays more slowly, so false neighbors can still repel each other and create room for separate local neighborhoods.

### 6. KL divergence and gradient descent make the map

The objective is $KL(P\|Q)=\sum_{ij}P_{ij}\log(P_{ij}/Q_{ij})$. If a pair has high $P_{ij}$ but low $Q_{ij}$, the map is separating true neighbors and the gradient pulls them together. If a pair has low $P_{ij}$ but high $Q_{ij}$, the map is creating an impostor neighbor and the gradient pushes them apart.

```python
def kl_w(P_in_w, Q_in_w):
    mask_w = P_in_w > 0
    return float(np.sum(P_in_w[mask_w] * np.log(P_in_w[mask_w] / Q_in_w[mask_w])))

initial_kl_w = kl_w(P_joint_w, Q_w)
print("initial KL:", round(initial_kl_w, 4))
assert initial_kl_w > 0
```
▶ What you'll see: KL is positive because the random map does not yet reproduce high-dimensional neighbors.

```python
def tsne_grad_w(P_in_w, Y_in_w):
    Q_in_w, num_in_w, _ = q_distribution_w(Y_in_w)
    grad_w = np.zeros_like(Y_in_w)
    for i_w in range(len(Y_in_w)):
        pull_push_w = (P_in_w[i_w, :, None] - Q_in_w[i_w, :, None]) * num_in_w[i_w, :, None] * (Y_in_w[i_w] - Y_in_w)
        grad_w[i_w] = 4 * np.sum(pull_push_w, axis=0)
    return grad_w, Q_in_w

grad0_w, Q0_w = tsne_grad_w(P_joint_w, Y_w)
print("gradient shape:", grad0_w.shape)
print("gradient for point 0:", np.round(grad0_w[0], 5))
assert grad0_w.shape == Y_w.shape
```
▶ What you'll see: every point receives a two-coordinate update direction computed from all pairwise probability mismatches.

```python
Y_fit_w = Y_w.copy()
kl_curve_w = []
for step_w in range(250):
    grad_w, Q_fit_w = tsne_grad_w(P_joint_w, Y_fit_w)
    Y_fit_w = Y_fit_w - 20.0 * grad_w
    if step_w % 10 == 0:
        kl_curve_w.append(kl_w(P_joint_w, q_distribution_w(Y_fit_w)[0]))
print("KL start -> end:", round(kl_curve_w[0], 4), "->", round(kl_curve_w[-1], 4))
assert kl_curve_w[-1] < kl_curve_w[0]
```
▶ What you'll see: the KL objective decreases, showing that the map is becoming more faithful to the target probabilities.

```python
plt.figure(figsize=(4.4, 3))
plt.plot(np.arange(len(kl_curve_w)) * 10, kl_curve_w, color="darkorange")
plt.xlabel("gradient step")
plt.ylabel("KL(P || Q)")
plt.title("6: t-SNE objective decreases")
plt.show()
```
▶ What you'll see: a falling curve; optimization is converting probability mismatch into a better map.

```python
plt.figure(figsize=(4.4, 3.6))
plt.scatter(Y_fit_w[:, 0], Y_fit_w[:, 1], c=labels_w, cmap="tab10", s=90)
for i_w in range(n_w):
    plt.text(Y_fit_w[i_w, 0] + 0.02, Y_fit_w[i_w, 1] + 0.02, str(i_w))
plt.title("6: learned 2-D t-SNE-style map")
plt.xlabel("embedding axis 0")
plt.ylabel("embedding axis 1")
plt.show()
```
▶ What you'll see: points 0–1 and 2–3 tend to form local pairs; exact global distances should not be over-interpreted.

*Why it's done this way:* KL divergence is asymmetric, so it heavily penalizes missing true neighbors ($P$ large, $Q$ small) while being more tolerant of global layout distortion. That is why t-SNE maps are excellent for local neighborhoods but unreliable as metric maps of global distance.

### 7. Scaling and stability checks keep the lens honest

t-SNE is a lens, not an oracle. Because it starts from distances, feature scaling changes the probability matrix. Because it optimizes a nonconvex objective, nearby random seeds or perplexities can move clusters around. A responsible workflow therefore checks preprocessing and reruns the map before treating a pattern as real.

```python
X_bad_w = X_w.copy()
X_bad_w[:, 0] *= 20.0  # one feature gets a much larger unit scale.
D2_bad_w = np.sum((X_bad_w[:, None, :] - X_bad_w[None, :, :]) ** 2, axis=2)
print("original d²(0,1):", round(float(D2_w[0, 1]), 3))
print("scaled d²(0,1):", round(float(D2_bad_w[0, 1]), 3))
assert round(float(D2_bad_w[0, 1]), 3) == 16.020
```
▶ What you'll see: changing units, not meaning, dramatically changes the distances t-SNE sees.

```python
X_scaled_w = (X_w - X_w.mean(axis=0)) / X_w.std(axis=0)
D2_scaled_w = np.sum((X_scaled_w[:, None, :] - X_scaled_w[None, :, :]) ** 2, axis=2)
print("standardized feature means:", np.round(X_scaled_w.mean(axis=0), 6))
print("standardized feature stds:", np.round(X_scaled_w.std(axis=0), 6))
assert np.allclose(X_scaled_w.mean(axis=0), 0.0)
assert np.allclose(X_scaled_w.std(axis=0), 1.0)
```
▶ What you'll see: standardized coordinates put features on comparable scales before the Gaussian kernel sees them.

```python
plt.figure(figsize=(5, 3))
plt.bar(["original", "badly scaled", "standardized"],
        [D2_w[0, 1], D2_bad_w[0, 1], D2_scaled_w[0, 1]],
        color=["seagreen", "crimson", "steelblue"])
plt.ylabel("squared distance between points 0 and 1")
plt.title("7: preprocessing changes the t-SNE input")
plt.xticks(rotation=12)
plt.show()
```
▶ What you'll see: the same pair looks close or far depending on scale, which would change the neighbor probabilities.

*Why it's done this way:* t-SNE optimizes exactly the probabilities created from your numeric features. If a large-unit coordinate dominates $d^2$, then the embedding faithfully visualizes the wrong notion of closeness; scaling and stability checks protect you from mistaking an artifact for structure.

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, distances, probability normalization, and small optimization loops.
import matplotlib.pyplot as plt # load Matplotlib for heatmaps, line plots, and embedding scatter plots.
np.random.seed(0) # make examples reproducible across notebook runs.

def pairwise_sq_dists(X): # compute all pairwise squared Euclidean distances for rows of X.
    X = np.asarray(X, dtype=float) # ensure predictable numeric operations.
    diff = X[:, None, :] - X[None, :, :] # broadcast every row against every row.
    return np.sum(diff ** 2, axis=2) # sum squared coordinate gaps.

def gaussian_conditional(D2, h): # turn squared distances into row-wise Gaussian probabilities.
    W = np.exp(-D2 / (2 * h ** 2)) # apply the Gaussian kernel to every distance.
    np.fill_diagonal(W, 0.0) # remove self-neighbor mass.
    return W / W.sum(axis=1, keepdims=True) # normalize each row into p(j|i).

def symmetrize_probs(P_cond): # convert directional probabilities into a symmetric joint distribution.
    n = P_cond.shape[0] # count points for the 2n normalization.
    P = (P_cond + P_cond.T) / (2 * n) # make pair probabilities symmetric and globally normalized.
    np.fill_diagonal(P, 0.0) # keep self-pairs at zero.
    return P / P.sum() # guard against tiny floating drift.

def student_q(Y): # compute low-dimensional Student-t pair probabilities.
    D2 = pairwise_sq_dists(Y) # low-dimensional squared distances.
    num = 1 / (1 + D2) # heavy-tailed Student-t numerator.
    np.fill_diagonal(num, 0.0) # no self-pairs.
    return num / num.sum(), num # return normalized Q and unnormalized kernel values.

def kl_divergence(P, Q): # compute KL(P || Q) only where P has positive mass.
    mask = P > 0 # avoid log of zeros from self-pairs.
    return float(np.sum(P[mask] * np.log(P[mask] / Q[mask]))) # asymmetric mismatch penalty.

def tsne_gradient(P, Y): # compute the symmetric t-SNE gradient for a small toy map.
    Q, num = student_q(Y) # current low-dimensional probabilities and heavy-tail weights.
    grad = np.zeros_like(Y) # one 2-D gradient vector per point.
    for i in range(Y.shape[0]): # sum pairwise attractions and repulsions for each anchor.
        terms = (P[i, :, None] - Q[i, :, None]) * num[i, :, None] * (Y[i] - Y) # probability mismatch times direction.
        grad[i] = 4 * np.sum(terms, axis=0) # t-SNE's symmetric gradient scale.
    return grad, Q # return both for optimization and diagnostics.
```

### Basic 4 — Exclude self-neighbors

**Goal.** Remove diagonal probability, because every point is trivially closest to itself and would otherwise waste probability mass. We build it in 2 steps.

```python
X_b4 = np.array([[0.0, 0.0], [0.2, 0.0], [2.0, 2.0]]) # define a tiny three-point cloud.
D2_b4 = pairwise_sq_dists(X_b4) # compute squared distances.
W_bad_b4 = np.exp(-D2_b4 / 2) # compute Gaussian weights without removing self-pairs.
print("diagonal before exclusion:", np.round(np.diag(W_bad_b4), 3)) # inspect self-weights.
assert np.allclose(np.diag(W_bad_b4), 1.0) # self distance is zero, so self weight is one.
```
▶ What you'll see: every point gives itself weight 1, which would dominate many rows.

```python
P_b4 = gaussian_conditional(D2_b4, h=1.0) # compute conditional probabilities with diagonal zeroed.
print("diagonal after exclusion:", np.round(np.diag(P_b4), 3)) # verify self-probabilities are removed.
print("row sums:", np.round(P_b4.sum(axis=1), 6)) # verify each row still normalizes.
assert np.allclose(np.diag(P_b4), 0.0) # self-check the diagonal.
```
▶ What you'll see: diagonal entries are zero and rows still sum to 1.

👀 Takeaway: self-neighbors are removed so the model learns relationships between distinct points.

### Basic 5 — Sweep the bandwidth h

**Goal.** See how $h$ changes locality, because the same distance can be decisive or minor depending on the kernel scale. We build it in 2 steps.

```python
D2_row_b5 = np.array([0.0, 0.25, 1.0, 9.0]) # one anchor's squared distances.
hs_b5 = np.array([0.5, 1.0, 2.0]) # compare narrow, medium, and broad kernels.
for h_b5 in hs_b5: # compute one probability row per bandwidth.
    w_b5 = np.exp(-D2_row_b5 / (2 * h_b5 ** 2)); w_b5[0] = 0.0 # Gaussian weights with no self.
    p_b5 = w_b5 / w_b5.sum() # normalize into probabilities.
    print("h", h_b5, "prob", np.round(p_b5, 3)) # inspect locality.
```
▶ What you'll see: small h concentrates mass on the nearest point; large h spreads it.

### Advanced 1 — Binary-search a bandwidth for target perplexity

**Goal.** Choose a bandwidth that matches a desired perplexity, because full t-SNE adapts locality scale per point. We build it in 4 steps.

```python
D2_row_a1 = np.array([0.0, 0.2, 0.7, 3.0, 6.0]) # squared distances from one anchor.
target_perp_a1 = 2.0 # aim for about two effective neighbors.
lo_a1, hi_a1 = 0.05, 10.0 # bracket possible bandwidth values.

```

```python

    w_a1 = np.exp(-D2_row_a1 / (2 * mid_a1 ** 2)); w_a1[0] = 0.0 # Gaussian weights.
    p_a1 = w_a1 / w_a1.sum() # normalize row.
    entropy_a1 = -np.sum(p_a1[p_a1 > 0] * np.log2(p_a1[p_a1 > 0])) # entropy in bits.

```
▶ What you'll see: binary search finds a bandwidth whose row perplexity is essentially 2.

**Goal.** Compare two perplexity settings and inspect neighborhood changes, because hyperparameters can reveal structure that is stable or fragile. We build it in 4 steps.
