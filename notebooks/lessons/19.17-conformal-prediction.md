# 19.17 — Conformal Prediction

Conformal prediction wraps an ordinary model with a calibration ruler: reserve exchangeable examples, measure how wrong the model looked on them, and use a corrected quantile of those nonconformity scores to make prediction intervals or label sets with finite-sample marginal coverage.

## 📖 Concept walkthrough — build each idea from scratch

Before the terse worked examples, we build conformal prediction one idea at a time. Run each cell in order and read the printed intermediate values — every piece of math is visible, from residual scores to the finite-sample quantile correction. This walkthrough is self-contained and uses a `_w` suffix on its variables so it never clashes with the examples below.

```python
import numpy as np  # arrays, quantiles, and small synthetic predictors.
import matplotlib.pyplot as plt  # all walkthrough visualizations.
np.random.seed(0)  # reproducibility for every toy sample.
```

### 1. Nonconformity scores: turn errors into a calibration ruler

Conformal prediction needs a scalar score where larger means "this example looks less compatible with the model." For regression, the simplest score is the absolute residual, $s_i=|y_i-\hat y_i|$. The score forgets sign on purpose: an interval must protect against misses above and below the point prediction, so the ruler is distance from the prediction, not direction.

```python
x_w = np.linspace(-2, 2, 25)  # calibration inputs.
y_true_w = 1.0 + 0.8 * x_w  # the noiseless linear trend.
noise_w = 0.25 * np.sin(4 * x_w) + 0.15 * np.random.randn(len(x_w))  # structured + random error.
y_w = y_true_w + noise_w  # observed calibration labels.
yhat_w = 1.0 + 0.75 * x_w  # a fixed toy predictor, intentionally imperfect.
scores_w = np.abs(y_w - yhat_w)  # regression nonconformity scores.
print("first residual scores:", np.round(scores_w[:6], 3))
print("largest score:", round(float(scores_w.max()), 3))
```
▶ What you'll see: absolute residuals are nonnegative distances; the largest one is the worst calibration miss.

```python
plt.figure(figsize=(5, 3))
plt.scatter(x_w, y_w, label="calibration data", color="steelblue")
plt.plot(x_w, yhat_w, label="toy predictor", color="black")
for xi_w, yi_w, yh_w in zip(x_w[::4], y_w[::4], yhat_w[::4]):
    plt.plot([xi_w, xi_w], [yi_w, yh_w], color="crimson", alpha=0.7)
plt.title("1: nonconformity = vertical residual size")
plt.xlabel("x"); plt.ylabel("y")
plt.legend(); plt.show()
```
▶ What you'll see: red vertical segments are the distances that become calibration scores.

*Why it's done this way:* conformal prediction does not need the model to output a correct probability distribution. It only needs an ordering of "more ordinary" versus "less ordinary" examples. Absolute residuals create that ordering for regression because a future label is covered exactly when its residual is no larger than the chosen calibration cutoff.

### 2. Split conformal regression: calibrate once, then widen future predictions

Split conformal separates model fitting from calibration. We train or choose a predictor without looking at calibration labels, compute residual scores on the calibration split, and set the interval width to a high corrected quantile. A future point prediction $\hat y(x)$ becomes $[\hat y(x)-q,\hat y(x)+q]$.

```python
alpha_w = 0.1  # target miscoverage, so target coverage is 90%.
n_cal_w = len(scores_w)  # calibration sample size.
k_w = int(np.ceil((n_cal_w + 1) * (1 - alpha_w)))  # finite-sample rank.
sorted_scores_w = np.sort(scores_w)  # order residuals from most conforming to least.
q_w = sorted_scores_w[min(k_w, n_cal_w) - 1]  # rank is 1-based; cap at n.
print("n_cal:", n_cal_w, "rank k:", k_w)
print("corrected cutoff q:", round(float(q_w), 3))
assert k_w == 24
```
▶ What you'll see: with 25 calibration points and 90% target coverage, the cutoff is the 24th smallest residual.

```python
x_grid_w = np.linspace(-2.5, 2.5, 120)  # future inputs to visualize.
yhat_grid_w = 1.0 + 0.75 * x_grid_w  # the same toy predictor on future inputs.
lo_w = yhat_grid_w - q_w  # lower conformal interval edge.
hi_w = yhat_grid_w + q_w  # upper conformal interval edge.
plt.figure(figsize=(6, 3.4))
plt.scatter(x_w, y_w, s=25, color="steelblue", label="calibration")
plt.plot(x_grid_w, yhat_grid_w, color="black", label="prediction")
plt.fill_between(x_grid_w, lo_w, hi_w, color="orange", alpha=0.25, label="90% split conformal interval")
plt.title("2: one residual quantile widens every prediction")
plt.xlabel("x"); plt.ylabel("y")
plt.legend(); plt.show()
```
▶ What you'll see: a constant-width orange band around the predictor; its width is exactly the calibration residual cutoff.

*Why it's done this way:* the calibration residuals and the next residual are exchangeable ranks if calibration and deployment examples are drawn the same way. Choosing the $\lceil(n+1)(1-\alpha)\rceil$-th score leaves at most an $\alpha$ fraction of possible ranks above the cutoff, which is the finite-sample coverage argument.

### 3. The quantile correction: why `ceil((n+1)(1-alpha))` matters

The correction is not a cosmetic off-by-one. A naive empirical 90th percentile can pick the 23rd score for 25 calibration examples, but the finite-sample split conformal guarantee uses the 24th score. The extra conservatism pays for the unknown rank of the future test example among the calibration examples plus itself.

```python
naive_rank_w = int(np.ceil(n_cal_w * (1 - alpha_w)))  # tempting but not finite-sample conformal.
naive_q_w = sorted_scores_w[naive_rank_w - 1]
print("naive rank:", naive_rank_w, "naive q:", round(float(naive_q_w), 3))
print("conformal rank:", k_w, "conformal q:", round(float(q_w), 3))
assert k_w == naive_rank_w + 1
```
▶ What you'll see: the conformal cutoff uses one rank farther into the upper tail than the naive percentile.

```python
plt.figure(figsize=(5, 3))
plt.plot(np.arange(1, n_cal_w + 1), sorted_scores_w, marker="o", color="slateblue")
plt.axvline(naive_rank_w, color="crimson", linestyle="--", label="naive rank")
plt.axvline(k_w, color="seagreen", linestyle="--", label="conformal rank")
plt.title("3: corrected quantile chooses a safer score")
plt.xlabel("sorted residual rank"); plt.ylabel("score")
plt.legend(); plt.show()
```
▶ What you'll see: the green conformal rank is just to the right of the red naive rank, so the interval is at least as wide.

*Why it's done this way:* with $n$ calibration scores plus one future score, there are $n+1$ equally likely rank positions for the future score. To guarantee miscoverage no larger than $\alpha$, the cutoff must exclude no more than $\alpha(n+1)$ top ranks, hence the $(n+1)$ inside the ceiling.

### 4. Empirical coverage: the guarantee is marginal under exchangeability

Coverage is a statement about the long-run fraction of future labels contained in the set, not about every individual point. We can simulate new exchangeable test examples from the same process and count how often the interval contains the true label. The result should hover around or above 90%, with sampling noise.

```python
rng_w = np.random.default_rng(1)
x_test_w = rng_w.uniform(-2.5, 2.5, size=800)
y_test_w = 1.0 + 0.8 * x_test_w + 0.25 * np.sin(4 * x_test_w) + 0.15 * rng_w.normal(size=len(x_test_w))
yhat_test_w = 1.0 + 0.75 * x_test_w
covered_w = (y_test_w >= yhat_test_w - q_w) & (y_test_w <= yhat_test_w + q_w)
coverage_w = float(np.mean(covered_w))
print("empirical coverage:", round(coverage_w, 3))
print("misses:", int((~covered_w).sum()), "of", len(covered_w))
assert coverage_w > 0.88
```
▶ What you'll see: empirical coverage is close to the 90% target, with a concrete miss count.

```python
plt.figure(figsize=(6, 3.4))
plt.scatter(x_test_w[covered_w], y_test_w[covered_w], s=10, alpha=0.35, color="seagreen", label="covered")
plt.scatter(x_test_w[~covered_w], y_test_w[~covered_w], s=18, color="crimson", label="missed")
order_w = np.argsort(x_test_w)
plt.plot(x_test_w[order_w], yhat_test_w[order_w], color="black")
plt.fill_between(x_test_w[order_w], (yhat_test_w - q_w)[order_w], (yhat_test_w + q_w)[order_w], color="orange", alpha=0.2)
plt.title("4: empirical coverage on exchangeable test data")
plt.xlabel("x"); plt.ylabel("y")
plt.legend(); plt.show()
```
▶ What you'll see: most green points fall inside the band, while red misses sit outside the interval.

*Why it's done this way:* the guarantee is marginal because it averages over future draws. It does not say every subgroup, every value of $x$, or every single input has exactly 90% conditional coverage. That distinction is why subgroup and shift checks remain necessary.

### 5. Classification conformal sets: include labels whose scores are small enough

For classification, a common nonconformity score is $s(x,y)=1-p_y(x)$, where $p_y(x)$ is the model's probability for the true label. High true-label probability gives a small score; low true-label probability gives a large score. A prediction set includes every label whose score is below the calibrated cutoff.

```python
probs_cal_w = np.array([[0.80, 0.15, 0.05], [0.55, 0.35, 0.10], [0.20, 0.70, 0.10],
                        [0.10, 0.25, 0.65], [0.45, 0.40, 0.15], [0.15, 0.30, 0.55],
                        [0.60, 0.25, 0.15], [0.25, 0.60, 0.15], [0.20, 0.20, 0.60],
                        [0.42, 0.36, 0.22]])
y_cal_cls_w = np.array([0, 1, 1, 2, 0, 2, 0, 1, 2, 1])
cls_scores_w = 1 - probs_cal_w[np.arange(len(y_cal_cls_w)), y_cal_cls_w]
alpha_cls_w = 0.2
k_cls_w = int(np.ceil((len(cls_scores_w) + 1) * (1 - alpha_cls_w)))
q_cls_w = np.sort(cls_scores_w)[min(k_cls_w, len(cls_scores_w)) - 1]
print("classification scores:", np.round(cls_scores_w, 2))
print("cutoff q:", round(float(q_cls_w), 2))
assert round(float(q_cls_w), 2) == 0.64
```
▶ What you'll see: examples where the model assigned low probability to the true label create large scores.

```python
probs_new_w = np.array([0.50, 0.38, 0.12])
set_new_w = np.where(1 - probs_new_w <= q_cls_w)[0]
print("new probabilities:", probs_new_w)
print("prediction set labels:", set_new_w)
assert np.array_equal(set_new_w, np.array([0, 1]))
```
▶ What you'll see: the two labels with probability at least `1 - q` enter the set, while the weakest label is excluded.

*Why it's done this way:* classification sets invert the score rule. Instead of asking "which label has the largest probability?" conformal asks "which labels would not look too strange compared with calibration true labels?" Ambiguous inputs naturally get multiple labels, making uncertainty visible.

### 6. Adaptive prediction sets (APS): calibrate cumulative probability, not a fixed threshold

A fixed probability threshold can be inefficient when class probabilities are uneven. APS instead sorts labels by model probability and scores the true label by the cumulative probability needed to reach it. Easy examples have small cumulative scores; hard examples require including several labels. The prediction set includes top labels until the cumulative mass reaches the calibrated cutoff.

```python
def aps_score_w(p_w, y_w):
    order_w = np.argsort(-p_w)
    rank_w = int(np.where(order_w == y_w)[0][0])
    return float(np.sum(p_w[order_w[:rank_w + 1]]))
aps_scores_w = np.array([aps_score_w(p_w, y_w) for p_w, y_w in zip(probs_cal_w, y_cal_cls_w)])
k_aps_w = int(np.ceil((len(aps_scores_w) + 1) * (1 - alpha_cls_w)))
q_aps_w = np.sort(aps_scores_w)[min(k_aps_w, len(aps_scores_w)) - 1]
print("APS scores:", np.round(aps_scores_w, 2))
print("APS cutoff:", round(float(q_aps_w), 2))
assert round(float(q_aps_w), 2) == 0.80
```
▶ What you'll see: APS scores are cumulative masses, so they live between the true-label probability and 1.

```python
order_new_w = np.argsort(-probs_new_w)
cum_new_w = np.cumsum(probs_new_w[order_new_w])
aps_set_w = order_new_w[cum_new_w <= q_aps_w]
if len(aps_set_w) == 0 or cum_new_w[len(aps_set_w) - 1] < q_aps_w:
    aps_set_w = order_new_w[:min(len(order_new_w), len(aps_set_w) + 1)]
print("sorted labels:", order_new_w)
print("cumulative probabilities:", np.round(cum_new_w, 2))
print("APS prediction set:", aps_set_w)
assert np.array_equal(aps_set_w, np.array([0, 1]))
```
▶ What you'll see: labels are added from most to least probable until the cumulative mass crosses the APS cutoff.

*Why it's done this way:* APS adapts set size to difficulty. If the model is very confident, the top label alone may cross the cutoff; if probability mass is spread out, the set grows. The coverage logic still comes from conformal rank calibration, but the score better matches classification ambiguity.

## 🛠️ Setup

```python
import numpy as np # load NumPy for arrays, quantiles, masks, and synthetic data.
import matplotlib.pyplot as plt # load Matplotlib for interval, coverage, and set-size plots.
np.random.seed(0) # make every random notebook cell reproducible.

def conformal_quantile(scores, alpha): # compute the split conformal finite-sample score cutoff.
    scores = np.sort(np.asarray(scores, dtype=float)) # sort calibration scores from smallest to largest.
    k = int(np.ceil((len(scores) + 1) * (1 - alpha))) # rank correction for n calibration scores plus one future score.
    return scores[min(k, len(scores)) - 1] # convert the 1-based rank to a safe 0-based array index.

def regression_data(n, seed=0): # synthesize a one-dimensional regression problem.
    rng = np.random.default_rng(seed) # use a local generator so examples are reproducible.
    x = rng.uniform(-3, 3, size=n) # sample inputs from one exchangeable distribution.
    y = 1.0 + 0.7 * x + 0.25 * np.sin(3 * x) + 0.35 * rng.normal(size=n) # create noisy labels.
    return x, y # return arrays for calibration or testing.

def toy_predict(x): # define a fixed imperfect regression predictor.
    return 1.0 + 0.65 * np.asarray(x) # use a simple line so residuals remain interpretable.

def softmax_logits(logits): # convert logits into probabilities using only NumPy.
    z = logits - np.max(logits, axis=1, keepdims=True) # subtract row max for numerical stability.
    e = np.exp(z) # exponentiate shifted logits.
    return e / np.sum(e, axis=1, keepdims=True) # normalize each row to probability 1.
```

### Basic 1 — Make residual nonconformity scores

**Goal.** Convert prediction errors into absolute residual scores, because split conformal regression calibrates the size of future misses. We build it in 2 steps.

### Basic 2 — Sort scores and choose a corrected quantile

**Goal.** Compute the conformal cutoff using `ceil((n+1)(1-alpha))`, because this rank is what gives finite-sample marginal coverage. We build it in 2 steps.

```python
scores_b2 = np.array([0.20, 0.15, 0.40, 0.15, 0.30]) # reuse five calibration residuals.

```

### Basic 5 — Estimate empirical coverage

### Basic 7 — See exchangeability break under shift

**Goal.** Compare in-distribution and shifted coverage, because conformal guarantees require calibration and test examples to be exchangeable. We build it in 3 steps.

```python
x_cal_b7, y_cal_b7 = regression_data(100, seed=8) # draw calibration data from the original distribution.
q_b7 = conformal_quantile(np.abs(y_cal_b7 - toy_predict(x_cal_b7)), 0.1) # calibrate a 90% interval.
print("calibrated q:", round(float(q_b7), 3)) # inspect the cutoff before testing.
```
▶ What you'll see: the cutoff is learned only from the original calibration distribution.

```python
x_id_b7, y_id_b7 = regression_data(500, seed=9) # draw exchangeable test data.
rng_shift_b7 = np.random.default_rng(10) # create a generator for shifted data.
x_shift_b7 = rng_shift_b7.uniform(-3, 3, size=500) # draw shifted inputs on the same x range.
y_shift_b7 = 1.4 + 1.1 * x_shift_b7 + 0.25 * np.sin(3 * x_shift_b7) + 0.55 * rng_shift_b7.normal(size=500) # change slope, intercept, and noise.
cov_id_b7 = float(np.mean(np.abs(y_id_b7 - toy_predict(x_id_b7)) <= q_b7)) # coverage under exchangeability.
cov_shift_b7 = float(np.mean(np.abs(y_shift_b7 - toy_predict(x_shift_b7)) <= q_b7)) # coverage under shift.
print("in-distribution coverage:", round(cov_id_b7, 3)) # inspect valid-setting coverage.
```

### Advanced 4 — Build APS sets and evaluate coverage

**Goal.** Evaluate APS on synthetic multi-class data, because adaptive cumulative scores are common for classification with many labels. We build it in 5 steps.

```python
def aps_calibrate_a4(probs_a4, labels_a4, alpha_a4): # calibrate APS cutoff from probabilities and labels.
    scores_a4 = [] # store cumulative true-label masses.
    for row_a4, y_a4 in zip(probs_a4, labels_a4): # loop over calibration examples.
        order_a4 = np.argsort(-row_a4) # sort labels descending.
        rank_a4 = int(np.where(order_a4 == y_a4)[0][0]) # find true-label rank.
        scores_a4.append(float(np.sum(row_a4[order_a4[:rank_a4 + 1]]))) # cumulative mass through true label.
    return conformal_quantile(np.array(scores_a4), alpha_a4) # return corrected quantile.

rng_a4 = np.random.default_rng(41) # create reproducible classification data.
probs_cal_a4 = softmax_logits(1.4 * rng_a4.normal(size=(180, 5))) # calibration probabilities for five classes.
y_cal_a4 = np.array([rng_a4.choice(5, p=row_a4) for row_a4 in probs_cal_a4]) # sample exchangeable labels.
print("calibration examples:", len(y_cal_a4)) # inspect sample size.
```
▶ What you'll see: APS calibration uses many labeled probability rows.

```python
q_aps_a4 = aps_calibrate_a4(probs_cal_a4, y_cal_a4, alpha_a4=0.1) # calibrate for 90% coverage.
print("APS q:", round(float(q_aps_a4), 3)) # inspect cumulative cutoff.
assert 0 < q_aps_a4 <= 1 # verify a valid cumulative probability cutoff.
```
▶ What you'll see: the APS cutoff is a cumulative probability mass threshold.

```python
probs_test_a4 = softmax_logits(1.4 * rng_a4.normal(size=(500, 5))) # test probabilities.
y_test_a4 = np.array([rng_a4.choice(5, p=row_a4) for row_a4 in probs_test_a4]) # test labels.
sets_a4 = [] # store APS sets.
for row_a4 in probs_test_a4: # build set for each test example.
    order_a4 = np.argsort(-row_a4) # sorted labels.
    cum_a4 = np.cumsum(row_a4[order_a4]) # sorted cumulative mass.
    m_a4 = int(np.searchsorted(cum_a4, q_aps_a4, side="left")) + 1 # labels needed to cross cutoff.
    sets_a4.append(order_a4[:m_a4]) # store APS label set.
covered_a4 = np.array([y_test_a4[i_a4] in sets_a4[i_a4] for i_a4 in range(len(y_test_a4))]) # coverage indicators.

assert float(np.mean(covered_a4)) > 0.86 # verify near 90% coverage in simulation.
```
▶ What you'll see: APS achieves near-target coverage with variable set sizes.

```python

```
▶ What you'll see: high-confidence examples have smaller or equal average APS set size.

