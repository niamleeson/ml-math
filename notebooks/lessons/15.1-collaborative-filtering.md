# 15.1 · Collaborative Filtering

Collaborative filtering (CF) recommends items from patterns in a user×item interaction matrix, not from item descriptions. In this lesson, `0` always means **unobserved/unknown**, so we carefully mask missing entries before using neighbors to predict ratings.

## Setup

```python
# !pip install numpy matplotlib  # Colab already has these; uncomment only if your runtime is missing them.
import numpy as np  # Import NumPy for arrays, linear algebra, masks, and reproducible simulation.
import matplotlib.pyplot as plt  # Import Matplotlib for the heatmaps, bars, scatters, and lines used for debugging CF.
np.random.seed(0)  # Fix the global random seed so every stochastic example is repeatable.
def cosine(a, b):  # Define full-vector cosine for dense vectors where every coordinate is meaningful.
    a = np.asarray(a, dtype=float)  # Convert the first input to a float array so arithmetic is predictable.
    b = np.asarray(b, dtype=float)  # Convert the second input to a float array so arithmetic is predictable.
    denom = np.linalg.norm(a) * np.linalg.norm(b)  # Compute the product of vector lengths used to normalize the dot product.
    return 0.0 if denom == 0 else float(np.dot(a, b) / denom)  # Return 0 for empty evidence; otherwise return cosine similarity.
def masked_cosine(a, b):  # Define CF cosine that only compares positions observed by both vectors.
    a = np.asarray(a, dtype=float)  # Convert the first rating vector to floats for masking and dot products.
    b = np.asarray(b, dtype=float)  # Convert the second rating vector to floats for masking and dot products.
    mask = (a > 0) & (b > 0)  # Keep only shared observed coordinates because zeros mean unknown, not dislike.
    if np.sum(mask) == 0:  # Check whether the two vectors have any common evidence.
        return 0.0  # Return 0 similarity when there is no overlap to compare.
    denom = np.linalg.norm(a[mask]) * np.linalg.norm(b[mask])  # Normalize using only the shared observed coordinates.
    return 0.0 if denom == 0 else float(np.dot(a[mask], b[mask]) / denom)  # Guard against divide-by-zero and return the masked cosine.
def anchor_cosine(a, b, cols):  # Define the lesson's target-context cosine over a chosen set of evidence columns.
    a = np.asarray(a, dtype=float)  # Convert the anchor user vector to floats.
    b = np.asarray(b, dtype=float)  # Convert the neighbor user vector to floats.
    cols = np.asarray(cols, dtype=int)  # Convert the evidence column list to integer indices.
    denom = np.linalg.norm(a[cols]) * np.linalg.norm(b[cols])  # Normalize over the same visible evidence columns.
    return 0.0 if denom == 0 else float(np.dot(a[cols], b[cols]) / denom)  # Return 0 for no evidence; otherwise return the context cosine.
def show_matrix(M, title):  # Define a small heatmap helper so matrices are easy to inspect.
    plt.figure(figsize=(4, 3))  # Start a compact figure that fits well in a notebook cell.
    plt.imshow(M, cmap="viridis", aspect="auto")  # Draw the matrix as color, with rows and columns kept readable.
    plt.colorbar(label="value")  # Add a colorbar so the colors can be interpreted numerically.
    plt.title(title)  # Add a title describing the matrix being shown.
    plt.xlabel("items")  # Label columns as items because CF matrices are user by item.
    plt.ylabel("users")  # Label rows as users because each row is a user profile.
    plt.show()  # Display the figure in the notebook.
```

#### E1. Predict with user-user CF

**Goal.** Implement the user-user formula $$\hat r_{ui}=\frac{\sum_v s(u,v)r_{vi}}{\sum_v s(u,v)}$$ with $$s(u,v)=\frac{R_u\cdot R_v}{\lVert R_u\rVert\lVert R_v\rVert}$$, because the missing cell is filled from similar users who rated that item. We build it in 3 steps.

```python
R_e1 = np.array([[5., 4., 0., 1.], [4., 5., 0., 1.], [1., 1., 5., 4.], [0., 1., 4., 5.]])  # Recreate the canonical matrix locally.
user_e1 = 0  # Choose Ava as the target user.
item_e1 = 2  # Choose item 2 as the missing target cell.
cols_e1 = np.array([0, 1, 3])  # Use Ava's observed columns as the context for lesson-number reproduction.
print("target cell before prediction:", R_e1[user_e1, item_e1])  # Confirm the target is unobserved.
```
▶ What you'll see: the target cell is 0, meaning unknown.

```python
neighbors_e1 = np.array([2, 3])  # Keep neighbors who actually rated item 2.
sims_e1 = np.array([anchor_cosine(R_e1[user_e1], R_e1[v], cols_e1) for v in neighbors_e1])  # Compute the lesson similarities to Cam and Dee.
ratings_e1 = R_e1[neighbors_e1, item_e1]  # Gather neighbor ratings for the target item.
print("similarities:", np.round(sims_e1, 3))  # Inspect weights used in the prediction.
print("ratings:", ratings_e1)  # Inspect evidence values being averaged.
```

```python

assert round(pred_e1, 3) == 4.635  # Self-check the canonical user-user prediction.
plt.figure(figsize=(4, 3))  # Create a compact neighbor-weight plot.
plt.bar(["Cam", "Dee"], sims_e1, color="seagreen")  # Visualize which neighbors dominate the prediction.

plt.ylabel("similarity")  # Label the weight axis.
plt.show()  # Display the neighbor weights.
```
▶ What you'll see: Cam receives more weight than Dee, pulling the result upward.

👀 Takeaway: user-user CF fills a missing cell by averaging ratings from similar users on the same item.

#### A1. Sweep sparsity and track coverage

**Goal.** Make matrices progressively sparser and measure prediction coverage, because pure CF cannot score cells when too little neighbor evidence remains. We build it in 3 steps.

```python
base_A1 = np.random.default_rng(0).integers(1, 6, size=(30, 20)).astype(float)  # Create a dense synthetic rating matrix with values from 1 to 5.
keep_rates_A1 = np.array([0.8, 0.5, 0.2, 0.1, 0.05])  # Define observed fractions to test from dense to sparse.
print("possible user-item pairs:", base_A1.size)  # Inspect the number of candidate ratings in the synthetic matrix.
```
▶ What you'll see: the experiment starts from a fixed 30×20 matrix.

```python
coverage_A1 = []  # Store the fraction of missing cells that have at least one neighbor.
for keep_A1 in keep_rates_A1:  # Loop over progressively smaller observed fractions.
    rng_A1 = np.random.default_rng(int(keep_A1 * 1000))  # Use a deterministic local generator per sparsity level.
    observed_A1 = rng_A1.random(base_A1.shape) < keep_A1  # Randomly decide which entries remain observed.
    R_A1 = np.where(observed_A1, base_A1, 0.0)  # Hide unobserved entries as zeros.
    missing_A1 = np.argwhere(R_A1 == 0)  # List target cells that would need prediction.
    cover_A1 = np.mean([np.any(R_A1[:, j] > 0) and np.any(R_A1[i] > 0) for i, j in missing_A1])  # Estimate whether each missing cell has user and item evidence.
    coverage_A1.append(cover_A1)  # Save the coverage value for plotting.
print("coverage:", np.round(coverage_A1, 3))  # Inspect coverage as sparsity increases.
```

```python

plt.xlabel("sparsity fraction")  # Label the x-axis.
plt.ylabel("coverage fraction")  # Label the y-axis.
plt.ylim(0, 1.05)  # Keep the coverage scale bounded from 0 to 1.
plt.show()  # Display the line chart.
```
▶ What you'll see: coverage generally drops as fewer ratings remain observed.

👀 Takeaway: at scale, sparsity directly limits where pure CF can make predictions.

#### A2. Sweep minimum overlap thresholds

**Goal.** Vary the minimum shared-rating threshold and measure coverage versus reliability, because stricter neighbor rules reduce noisy similarities but leave fewer predictions. We build it in 3 steps.

```python
R_A2 = np.array([[5., 4., 0., 1., 0.], [4., 5., 0., 1., 2.], [1., 1., 5., 4., 5.], [0., 1., 4., 5., 4.], [5., 0., 1., 0., 1.]])  # Create a small matrix with varied overlaps.

```
▶ What you'll see: the sweep will compare one-, two-, and three-overlap rules.

```python
coverage_A2 = []  # Store whether Ava item 2 has enough valid neighbors under each rule.
avg_overlap_A2 = []  # Store the average overlap among accepted neighbors as a reliability proxy.
for min_ov_A2 in thresholds_A2:  # Loop over threshold values.
    accepted_A2 = []  # Store accepted neighbor overlaps for this threshold.
    for v_A2 in range(1, R_A2.shape[0]):  # Compare Ava with every other user.
        overlap_A2 = np.sum((R_A2[0] > 0) & (R_A2[v_A2] > 0))  # Count shared observed items.
        if R_A2[v_A2, 2] > 0 and overlap_A2 >= min_ov_A2:  # Accept only item-2 raters with enough overlap.
            accepted_A2.append(overlap_A2)  # Save the overlap for accepted neighbors.
    coverage_A2.append(1.0 if len(accepted_A2) > 0 else 0.0)  # Record whether prediction remains possible.
    avg_overlap_A2.append(np.mean(accepted_A2) if accepted_A2 else 0.0)  # Record reliability proxy for accepted neighbors.
print("coverage:", coverage_A2, "avg overlap:", np.round(avg_overlap_A2, 2))  # Inspect the tradeoff data.
```

```python
plt.figure(figsize=(5, 3))  # Create a compact tradeoff figure.
```

#### A5. Sweep neighborhood size k

**Goal.** Evaluate k-nearest-neighbor CF for several k values, because small k can be noisy while large k can include weak neighbors. We build it in 3 steps.

```python
R_A5 = np.array([[5., 4., 0., 1., 0.], [4., 5., 0., 1., 2.], [1., 1., 5., 4., 5.], [0., 1., 4., 5., 4.], [5., 0., 1., 0., 1.], [2., 2., 5., 4., 0.]])  # Create a slightly larger matrix for kNN testing.

ks_A5 = np.array([1, 2, 3, 4])  # Test neighborhood sizes from very local to broader.
print("k values:", ks_A5)  # Inspect the sweep settings.
```
▶ What you'll see: the validation set lets us compare several neighborhood sizes.

```python

for k_A5 in ks_A5:  # Loop over candidate neighborhood sizes.
    preds_A5 = []  # Store predictions for this k.
    for u_A5, i_A5, truth_A5 in truths_A5:  # Loop over validation triples.
        u_A5 = int(u_A5)  # Convert the user index from float array storage to int.
        i_A5 = int(i_A5)  # Convert the item index from float array storage to int.

        top_A5 = np.argsort(sims_A5)[::-1][:k_A5]  # Keep the k most similar raters.
        pred_A5 = np.sum(sims_A5[top_A5] * R_A5[raters_A5[top_A5], i_A5]) / np.sum(sims_A5[top_A5]) if np.sum(sims_A5[top_A5]) > 0 else np.mean(R_A5[R_A5 > 0])  # Predict with kNN or fall back to global mean.
```
